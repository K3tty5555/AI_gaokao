## Tier 1:高考大省(9 省)

### 河南(henan-zhiyuan)
- **政策**:老高考(文/理分科)→ 2025 起 3+1+2(2026 届第二届)
- **考生量**:全国最多,~125 万,竞争激烈
- **重点高校**:郑州大学(211)/ 河南大学(211)/ 河南师范大学 / 河南农业大学 / 解放军信息工程大学
- **代表产业**:制造业(郑州富士康 / 宇通)/ 农业(玉米小麦)/ 物流(郑州航空港)/ 食品工业
- **考公环境**:省考竞争极卷,基层岗位 100:1 起步;选调走 985 + 河南本地校;岗位多但门槛高
- **代表城市**:郑州 / 洛阳 / 开封 / 南阳 / 安阳 / 新乡 / 信阳 / 周口
- **家庭画像特点**:农村比例高(>50%),普遍信息差大;"出豫"心理压力极强(出河南 = 跨阶级);重男轻女文化犹存

### 山东(shandong-zhiyuan)
- **政策**:3+3(自 2020 年首届)
- **考生量**:~80 万,竞争激烈
- **重点高校**:山东大学(985)/ 中国海洋大学(985)/ 中国石油大学(华东)/ 山东师范 / 山东财经 / 青岛大学 / 哈工大威海(985 校区)
- **代表产业**:制造业(海尔 / 海信 / 潍柴)/ 能源化工(青岛中石化)/ 农业(寿光蔬菜)/ 海洋经济
- **考公环境**:儒家文化体制内偏好极强,父母对"考公"几乎是默认;鲁籍考生在全国选调中竞争力强
- **代表城市**:济南 / 青岛 / 烟台 / 威海 / 潍坊 / 临沂 / 淄博 / 济宁
- **家庭画像特点**:工薪家庭比例高,普遍稳定 + 重视编制;"留鲁"心态重(山东人不愿出省);独生子女男生压力大

### 广东(guangdong-zhiyuan)
- **政策**:3+1+2(自 2021 首届)
- **考生量**:~75 万
- **重点高校**:中山大学(985)/ 华南理工(985)/ 暨南大学(211)/ 华南师范(211)/ 深圳大学 / 南方科技大学 / 华南农业大学 / 广东工业大学
- **代表产业**:IT 互联网(华为 / 腾讯 / 大疆)/ 制造业(广汽 / 美的 / 格力)/ 金融(深圳)/ 外贸
- **考公环境**:体制 vs 私企比湖北弱(私企天花板高,留 IT/金融大厂的多);省考粤东西北岗位需要本地户籍;深圳/广州编制吃香
- **代表城市**:广州 / 深圳 / 佛山 / 东莞 / 珠海 / 中山 / 汕头 / 茂名 / 湛江 / 惠州
- **家庭画像特点**:私企家庭比例高(很多潮汕 / 客家家族企业);粤东西北农村家庭与珠三角中产差距悬殊;"留粤"是普遍偏好

### 江苏(jiangsu-zhiyuan)
- **政策**:3+1+2(自 2021 首届)
- **考生量**:~40 万,但内部竞争极卷("江苏卷")
- **重点高校**:南京大学(C9)/ 东南大学(985)/ 南京理工(211)/ 南京航空航天(211)/ 南京师范(211)/ 苏州大学(211)/ 河海大学(211)/ 中国矿大(211)/ 江南大学(211)/ 南京农业(211)
- **代表产业**:电子信息(苏州工业园)/ 高端制造(无锡)/ 化工(南京)/ 金融(南京)/ 生物医药(泰州)
- **考公环境**:**江苏选调全国最强**(江苏籍 985 选调全国最优渥);苏南苏北分化严重,苏南私企盛 / 苏北体制内偏好重
- **代表城市**:南京 / 苏州 / 无锡 / 常州 / 镇江(苏南);徐州 / 南通 / 盐城 / 扬州 / 淮安(苏北)
- **家庭画像特点**:苏南家庭"重私企/外企"(投行 / 互联网 / 制造业总部);苏北家庭"重体制内/编制";"鸡娃"文化全国第一,家长教育投入极大

### 河北(hebei-zhiyuan)
- **政策**:3+1+2(自 2021 首届)
- **考生量**:~70 万,人才外流严重(出省到京津)
- **重点高校**:燕山大学(双一流)/ 河北大学 / 华北电力大学(保定校区,211 但低分)/ 河北工业大学(211 在天津)/ 河北医科大学
- **代表产业**:钢铁(唐山 / 邯郸)/ 装备制造 / 农业 / 京津冀承接产业
- **考公环境**:省考门槛适中;**选调到雄安新区** = 隐藏跃迁路径(2017 年起雄安建设带来岗位 + 政策红利)
- **代表城市**:石家庄 / 保定 / 唐山 / 邯郸 / 廊坊 / 沧州 / 张家口
- **家庭画像特点**:工薪家庭比例高;**普遍想"出河北留京津"**(河北父母对"留京津发展"接受度高于其他省 — 因地理近);河北本省高校选项偏少导致出省竞争激烈

### 四川(sichuan-zhiyuan)
- **政策**:3+1+2(自 2022)
- **考生量**:~80 万
- **重点高校**:四川大学(985)/ 电子科技大学(985)/ 西南财经(211)/ 西南交通(211)/ 西南民族 / 成都理工 / 四川农业(211)/ 西南石油
- **代表产业**:电子信息(电子科大 + 成都华为研究所)/ 航空航天(中航工业)/ 文创旅游 / 白酒(宜宾五粮液 / 泸州老窖)/ 汽车(成都丰田)
- **考公环境**:省考岗位多;**选调留川** = 川大/电子科大主供给;成都 / 绵阳 / 德阳"成绵德"经济圈 + 川南川北等区域分化
- **代表城市**:成都 / 绵阳 / 德阳 / 自贡 / 攀枝花 / 泸州 / 宜宾 / 南充 / 凉山(彝族)/ 阿坝(藏族)
- **家庭画像特点**:**"留川"是非常普遍的家庭偏好**(成都生活舒适度高 + 父母老人观念);藏区彝区少数民族家庭有民族优惠 + 国家专项

### 安徽(anhui-zhiyuan)
- **政策**:3+1+2(自 2022)
- **考生量**:~62 万
- **重点高校**:中国科学技术大学(C9)/ 合肥工业大学(211)/ 安徽大学(211)/ 安徽医科 / 安徽师范 / 安徽工业 / 中国矿业大学
- **代表产业**:科技(中科大 + 合肥京东方 + 蔚来)/ 钢铁(马钢)/ 农业 / 文旅(黄山徽州)
- **考公环境**:**安徽人才外流严重**(科大本科去向以美国/北上深为主,留皖率不到 20%);省考岗位多但顶尖人才不留
- **代表城市**:合肥 / 芜湖 / 蚌埠 / 马鞍山 / 安庆 / 黄山 / 阜阳 / 宿州
- **家庭画像特点**:"安徽北高南低"(皖北农业贫困 vs 皖南徽州文化富裕);考大学 = 跳出安徽是默认期待;**徽商基因**(私企氛围比湖北强,创业接受度高)

### 湖南(hunan-zhiyuan)
- **政策**:3+1+2(自 2021 首届)
- **考生量**:~50 万
- **重点高校**:中南大学(985)/ 湖南大学(985)/ 湖南师范大学(211)/ 国防科技大学(985 军校,免学费)/ 湘潭大学(双一流)/ 长沙理工 / 湖南农大(双一流)
- **代表产业**:工程机械(长沙三一重工 / 中联重科)/ 轨道交通(中车株机)/ 文化娱乐(湖南台 / 影视)/ 烟草(常德)
- **考公环境**:省考岗位多;**长沙互联网"中部硅谷"** + 国防科大军队系统输出;湖南选调走中南/湖大主供给
- **代表城市**:长沙 / 株洲 / 湘潭 / 衡阳 / 岳阳 / 常德 / 邵阳 / 怀化 / 张家界 / 湘西(土家苗族)
- **家庭画像特点**:**长株潭一体化** 想留长沙的家庭很多;湘西山区家庭出省路径明确(走湖北 / 广东);"湖湘文化"硬气考公倾向重

### 浙江(zhejiang-zhiyuan)
- **政策**:3+3(自 2017 年首届)
- **考生量**:~36 万
- **重点高校**:浙江大学(C9 独大)/ 宁波大学(双一流)/ 浙江工业大学 / 浙江师范 / 浙江工商 / 杭州电子科技
- **代表产业**:互联网(杭州阿里 / 网易 / 字节杭州)/ 民营经济(温州 / 义乌 / 宁波港)/ 制造业 / 跨境电商
- **考公环境**:**民营经济发达 = 体制内偏好弱**(浙江人愿意创业 / 进民企 > 考公);浙江选调主要供给浙大;省考岗位竞争平稳
- **代表城市**:杭州 / 宁波 / 温州 / 金华 / 嘉兴 / 绍兴 / 台州 / 义乌 / 衢州 / 丽水
- **家庭画像特点**:**民营企业主 / 创业家庭比例全国最高**;温州 / 义乌 / 台州家庭普遍"重私企/外企/创业"超过体制;浙江出国留学比例极高(很多家庭选 中外合作 / 直接出国)

## Tier 2:中等省份(14 省)

- **代表城市**:福州 / 厦门 / 泉州 / 漳州 / 莆田 / 龙岩 / 宁德 / 三明

### 江西(jiangxi-zhiyuan)
- **政策**:3+1+2(自 2024 首届)
- **重点高校**:南昌大学(211)/ 江西师范大学 / 江西财经大学(强 211 候选,双一流)/ 江西农业大学 / 南昌航空大学

### 北京(beijing-zhiyuan)
- **政策**:3+3(自 2017 首届)
- **考生量**:~6 万,北京户口本地考生
- **重点高校**:清华 / 北大 / 人大 / 北航 / 北理 / 北邮 / 北师大 / 央财 / 外经贸 / 北外 / 中政法 / 北科大 / 中传 / 北邮 / 中农大 / 北中医 等几乎全国最密集 985/211 集群
- **代表产业**:互联网(字节 / 美团 / 百度)/ 金融(中央金融)/ 央企总部 / 文化传媒 / 科技
- **考公环境**:**北京户口的隐性价值**让本地考生选公务员极有诱惑;选调走清北人北航;但北京"出口"也最多元(IT/金融/创业 vs 体制内)
- **代表城市**:北京(单一城市)
- **家庭画像特点**:**家庭普遍中产以上** + 信息差小 + 父母多懂"清北 / 985 / 211"路径;**"留京户口"是隐性诉求**;北京户口女生独生子女比例高,父母期望多元

### 上海(shanghai-zhiyuan)
- **政策**:3+3(自 2017 首届)
- **考生量**:~6 万,上海户口本地考生
- **重点高校**:复旦(C9)/ 上海交大(C9)/ 同济(985)/ 华东师大(985)/ 上海财经(211)/ 华东理工(211)/ 上海大学 / 东华大学(211)/ 上海中医药 / 上海外国语(211)

- **考公环境**:**上海体制内 vs 外企/私企** = 双轨 — 体制内待遇平平,但金融/科创外企/民企天花板极高
- **代表城市**:上海(单一城市)
- **家庭画像特点**:**家庭中产 / 高知比例最高**;独生子女女生比例特高;父母对"出上海"心理底线 — 留沪是默认;**国际化诉求强**(出国读研 / 中外合作)

### 天津(tianjin-zhiyuan)

- **重点高校**:天津大学(985)/ 南开大学(985)/ 天津医科 / 天津工业 / 河北工业大学(211 实际在天津)/ 天津财经

- **家庭画像特点**:工薪家庭比例高;**"卫嘴子"文化** — 务实 + 安稳偏好;独生子女比例高
