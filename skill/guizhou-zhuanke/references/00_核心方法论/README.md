# 贵州专科 skill 核心方法论(本省视角)

## 一、为什么贵州专科不能照搬其他省的逻辑

如果把湖北 / 广东 / 江苏 等沿海省份的专科填报逻辑直接搬到贵州,会犯三大错:

### 错 1:照搬"专升本路径"
- 沿海省份(湖北 / 广东)专升本录取率 30% 左右,且本科扩招相对慢
- **贵州专升本录取率 40%+(高于沿海)+ 国家西部专项 + 建档立卡专项 + 本科扩招积极**
- 贵州山区考生走专升本是真实可行的"改命"路径,沿海家庭可能觉得"太慢",但对贵州家庭很值

### 错 2:照搬"行业出口"
- 沿海:互联网 / 制造业 / 金融 / 外贸 是大头
- **贵州:茅台白酒 / 贵阳大数据 / 南方电网 / 成都局贵阳枢纽 / 山区医疗教育**
- 学旅游管理在沿海是坑,**在贵州景区附近 + 家里有民宿 = 可能是好路**
- 学护理 / 学前教育 在沿海起薪低,**在贵州山区 + 编制 + 山区补贴 + 老家附近 = 性价比之王**

### 错 3:照搬"民办 vs 公办判断标准"
- 沿海有些民办本科 / 独立学院虽贵但出路 OK(因为本地就业市场大)
- **贵州民办专科 = 几乎全是坑**(本地就业市场小 + 民办无行业资源 + 学费对山区家庭压力大)
- 贵州的判断标准:**公办优先,民办尽量避开**,且**公办里行业类 > 民族职业 > 综合性**

## 二、贵州专科决策的核心三问

agent 在与用户对话时,**这三个问题必须问清楚**,顺序也固定:

### 问题 1:**家在哪?户籍在哪?是否少数民族?**

为什么这是第一问:
- **山区农村 vs 城市工薪 vs 中产** → 直接决定经济承受力(民办 vs 公办)
- **建档立卡户** → 有专项指标 + 降分录取 + 升本专项
- **少数民族(苗 / 侗 / 布依 / 水 / 仡佬 等)** → 有民族加分 + 国家专项 + 民族班
- **户籍在景区附近 / 黔北仁怀 / 民族村寨** → 解锁特定行业的地缘优势

### 问题 2:**专升本意愿强度 1-5?**

为什么这是第二问:
- 强度 5(必升) → 选**公办专科 + 升学率高的专业 + 专升本对口面广的大类**
- 强度 1-2(直接就业) → 选**就业出口清晰的对口专科**(护理 / 电力 / 铁路 / 酿酒 / 大数据)
- 强度 3-4(看情况) → 选两边都能走的(护理 / 大数据 / 学前教育)
- **不问清楚这一项,后面所有推荐都会方向错误**

### 问题 3:**留贵州 vs 出贵州?**

为什么这是第三问:
- 留贵州 → **本省国央企**(茅台 / 南网贵州 / 成都局贵阳 / 山区医院教育)是好出口
- 出贵州 → 优先**广东**(同分能去更好的广东专科 + 沿海就业市场大)/ **长三角**(进厂 / 服务业)
- **大部分贵州家庭默认留贵州**(老人观念 + 父母同乡 + 房子便宜),agent 不要默认推荐出省

## 三、贵州专科 6 大本省赛道

按"贵州本省政策红利 + 行业景气度 + 专科生进入门槛" 排序:

### Tier 1:贵州专属赛道(其他省没有)
1. **酿酒 / 食品**(茅台 / 习酒 / 国台 / 仁怀产业链) — **黔北本地考生王者赛道**
2. **大数据 / 电子信息**(贵阳产业园 + 国家算力枢纽) — **政策红利最强,出路较广**

### Tier 2:贵州体制内 / 央企赛道
3. **电气**(南方电网贵州 + 华电贵州) — **男生求稳王者赛道**
4. **铁路**(成都局贵阳段 + 中铁二局 / 五局) — **男生体制内交通赛道**

### Tier 3:稳定就业赛道(全国通用 + 贵州特别合适)
5. **护理**(山区缺医少药 + 老龄化 + 男护士稀缺) — **女生 / 男生稳定路径**
6. **学前教育**(山区特岗 + 公办园扩张) — **女生稳定路径 + 男幼师稀缺红利**

### Tier 4:挑选条件极严的赛道
7. **旅游 / 酒店管理** — **只有景区附近 + 家里有路子 + 接受服务业辛苦 才适合,默认劝退**

## 四、贵州专科决策矩阵(简版)

### 按家庭画像

| 家庭画像 | 默认推荐 | 备选 |
|---|---|---|
| 山区农村 + 建档立卡 | **公办行业类(护理/学前/电力/电子信息)+ 走专升本专项** | 民族职业 + 老家就业 |
| 山区农村 + 少数民族 | 民族职业 + 民族加分 + 山区特岗 / 民族地区岗位 | 公办行业类 |

| 黔北本地(仁怀 / 习水 / 遵义) | 酿酒 / 食品 + 茅台 / 习酒 渠道 | 遵义医药专科 |
| 贵阳本地工薪 | 公办头部高职 | 专升本 + 留贵阳 |
| 中产以上 | 公办专科 + 专升本 / 出省 | 视家庭资源定 |

| 性别 + 性格 | 推荐方向 |
|---|---|
| 女 + 求稳 + 接受医院 | 护理 |
| 女 + 求稳 + 喜欢小孩 | 学前教育 |
| 女 + 接受出差 / 跑车 + 形象好 | 高铁乘务 |
| 男 + 求稳 + 数物好 | 电气 / 铁路 |
| 男 + 求稳 + 数物一般 | 大数据 / 电子信息 |

## 五、agent 输出时必须强调的几条

1. **专科生第一年就要确定专升本意愿**(决定 3 年学习节奏)
2. **专升本对口专业 = 选专科时已锁死**(选错专科 = 砍半本科选择)
3. **建档立卡考生一定要走专项计划**(国家给贵州山区孩子的实打实福利)
4. **少数民族 + 民族地区户籍 = 用足民族加分 + 国家专项 + 民族班**
5. **公办专科起码 > 民办专科**(尤其山区农村家庭)
6. **行业类专科 + 对口央企校招 比 综合性专科 强得多**(电力 / 铁路 / 幼师 / 护理 / 电子信息)
7. **本地民族职业 = 山区考生回家就业的好选择**(地州市编制岗位倾向本地专科)
8. **不诋毁专科教育**(山区考生上专科 = 走出大山的第一步,值得尊重)
9. **不轻易推荐复读**(贵州考生量少 + 复读风险高 + 专科 + 专升本 完全可走通)
10. **以上为参考建议,实际填报请结合最新招生章程 + 贵州省教育厅文件**

## 六、安全规则(对应 SKILL.md 第八节)

- 不承诺"一定能录取"
- 不诋毁专科教育
- 涉及专升本具体政策 → 让用户咨询学校招生办或贵州省教育厅
- 涉及民族加分 / 国家专项 → 让用户去县/州教育局核实
- 推荐方案末尾必须加免责声明
- **不推荐复读**(参考 SKILL.md 第八节)
