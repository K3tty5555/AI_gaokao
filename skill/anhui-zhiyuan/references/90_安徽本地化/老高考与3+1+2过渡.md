# 安徽老高考与 3+1+2 过渡

## 核心结论

**安徽 2021 年加入新高考第四批**(同江西/广西/贵州/黑龙江/吉林/甘肃),**2021 入学高一 → 2024 首届 3+1+2 高考**。所以:

- **2021、2022、2023 高考 = 老高考**(文科 / 理科,文综 / 理综)
- **2024、2025、2026+ 高考 = 3+1+2 新高考**(物理类 / 历史类,12 种选科组合)

agent 必须根据用户届别判断走哪套口径,**不能默认所有用户都是 3+1+2**。

## 关键事实

### 老高考(2021-2023)结构
- 语文 / 数学 / 英语,各 150 分
- **文科**:文综(政治+历史+地理,共 300 分)
- **理科**:理综(物理+化学+生物,共 300 分)
- **总分 750 分**
- 用 **全国卷 I**(后改为新高考 II 卷过渡)

### 3+1+2 新高考(2024+)结构
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2024+)
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- 安徽物理类约 60-65%,历史类约 35-40%

### 数据现状(`data/yifenduyiduan/`)
- 2021、2022、2023 → `<年>_文科_anhui.csv` / `<年>_理科_anhui.csv`(老高考)
- 2024、2025+ → `<年>_物理类_anhui.csv` / `<年>_历史类_anhui.csv`(3+1+2)
- agent 调 score_to_rank / query_school 时,**type 参数必须根据年份选对**(2024 之前用文科/理科,2024 起用物理类/历史类)

### 院校专业组(2024+ 起用)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **安徽本科批 96 个院校专业组志愿**(全国前列志愿数)

### 老高考填报模式(2021-2023)
- 按"院校 + 专业"或"专业 + 院校"模式(平行志愿)
- 服从调剂在全校范围内
- 2023 本科一批 / 二批合并为本科批前夕

## 安徽特殊性(关键!!)

### 1. 合肥科创崛起 = "中部硅谷"
- **科大讯飞**(语音 AI 全国第 1)总部合肥
- **蔚来汽车**(新能源车头部)中国总部合肥(2020 落地)
- **京东方**(显示面板全球前 2)合肥基地
- **比亚迪合肥基地**(整车 + 电池 + 半导体,2021 落地)
- **大众安徽**(大众集团第三家中国合资,纯电导向)
- **长鑫存储**(国产 DRAM 主力)合肥
- **中科院合肥物质科学研究院**(国家实验室矩阵)

→ **安徽考生留皖竞争力大幅提升**,以前安徽强校(中科大/合工大)毕业生大量外流(去长三角/北上广),**现在合肥本地有真正的科创对口岗位**,留皖性价比拐点。

### 2. 安徽考生体量大(高考人口大省)
- 2024 高考报名 ~64 万,**与河南 / 广东同档**(全国前 5)
- **985 / 211 名额相对吃紧**(本省 1 个 985 + 2 个 211,人均比江苏/湖北少)
- **录取结果**:安徽考生上 985 / 211 比江苏 / 湖北难

### 3. 皖南 vs 皖北 差异显著
- **皖南**(合肥 / 芜湖 / 马鞍山 / 安庆 / 黄山 / 池州):基础教育强,合肥一中 / 马鞍山二中 / 芜湖一中等顶尖高中聚集
- **皖北**(阜阳 / 亳州 / 宿州 / 蚌埠 / 淮南 / 淮北):录取分数线相对低,考生体量大但顶尖资源少
- 影响:同样位次,合肥一中第 100 名 ≈ 皖北县中前 10 名
- **国家专项 / 地方专项**对皖北部分县考生有利,agent 在 L2 收完地市后要判断是否提示这两类招生

### 4. 长三角认可度极高(安徽是长三角扩展省)
- 安徽 2019 年正式加入长三角一体化
- **沪宁苏锡常都把安徽考生当本省看**(户口 / 校招 / 落户都友好)
- 安徽考生留长三角就业概率 60%+(沪苏浙皖)
- **跨省就业跟省内差不多**(地理近 + 文化近 + 高铁 1-3 小时圈)

### 5. 中科大独立性强 = 全国理科顶尖学子聚集
- **中科大隶属中国科学院**(不归教育部,跟清北复交一线 985 不同体制)
- 在合肥但**全国招生,本省考生进中科大并不容易**
- 中科大约 50% 学生出国 / 读博,**走科研路线**;**不打算读博的考生慎选中科大**(纯应用型岗位中科大优势不及华科 / 西交)

## 易错认知(agent 要纠正用户的)

- **"安徽高考一直都是文科/理科"** — 错。**2024 起改 3+1+2**,2021-2023 老高考届的位次跟 2024+ 不可直接比
- **"中科大就在合肥,本省考生应该很好考"** — 错。中科大全国统招,**安徽本省名额并不多**,中科大本省录取位次约前 1500-2500 名
- **"安徽 985/211 少,所以考好难"** — 半对。**本省 1 个 985(中科大)+ 2 个 211(合工大/安大),人均紧张**,但跨省 985/211 也是常规路径
- **"96 个志愿都是学校,选哪个学校都行"** — 严重错误。**安徽是 96 个院校专业组**,组内可调专业,不同组完全独立投档
- **"留皖没出息,必须去长三角"** — **过时了**。合肥 2020 后科创崛起,**留皖性价比拐点已到**,蔚来 / 科大讯飞 / 京东方 / 比亚迪 / 长鑫 等头部都在合肥

## 关键提醒(agent 必须强调)

1. **安徽 96 个志愿**(2024+,比江苏 40 个 / 湖北 45 个 多得多)
2. **2024 是 3+1+2 首届**,数据参考性比老高考届差,**多看位次少看分数**
3. **再选科目限制**(必选化学/必选政治等)是硬约束,agent 要主动 check
4. **皖南 / 皖北 高中层次差异**(出分前估算位次时要考虑)
5. **合肥科创就业生态**已成型,**留皖不再是次选**(对比 2018 之前)
6. **中科大全国统招**,本省考生不享受太多本省照顾,做心理准备

## 96 个志愿的填报策略(2024+ 安徽特色)

### 安徽 96 vs 江苏 40 vs 湖北 45 的差异

| 维度 | 安徽(96) | 江苏(40) | 湖北(45) |
|---|---|---|---|
| 志愿数 | **96 个院校专业组** | 40 个 | 45 个 |
| 投档单位 | 院校专业组 | 院校专业组 | 院校专业组 |
| 服从调剂范围 | 组内 | 组内 | 组内 |
| 容错率 | **极高** | 中 | 中 |
| 填报压力 | **梯度可拉得很开** | 紧凑 | 中等 |

→ **安徽 96 个志愿 = 全国前列志愿数**,**冲稳保梯度可以拉得很开** —— 但这也意味着**填报时间成本极高**,需要从一分一段表 + 历年录取数据 + 院校专业组组内分析中筛选 96 个

### 推荐 96 志愿冲稳保结构(典型安徽考生)

- **冲(1-15)**:比平均录取位次高 5-15% 的院校专业组(博弈大小年 / 冷门组)
- **稳(16-50)**:与位次匹配的主流院校专业组(占 35 个)
- **保(51-80)**:比位次低 10-25% 的安全院校专业组(占 30 个)
- **垫(81-96)**:绝对兜底(本省二本 / 双非师范 / 省内行业校,占 16 个)

→ **保和垫 一定要填满**,**安徽考生最常见错误是把 96 个志愿填成"全冲" / "全稳"**,**没保没垫导致滑档掉到下一批次**

## 院校专业组填报陷阱(安徽特色)

### 1. 中科大组内陷阱
- 中科大本科组多为"理科试验班 / 工科试验班 / 物理类",**组内可能含化学 / 生物 / 材料 / 物理等多个方向**
- **服从调剂前务必查 2026 年招生章程具体组内有什么**,避免被调剂到生化环材冷门方向
- **少年班 / 强基计划走提前批 / 单独录取**,跟普通本科批分开

### 2. 合工大本部 vs 宣城校区陷阱
- 合工大有两个校区:**合肥本部**(屯溪路 + 翡翠湖)和**宣城校区**
- **录取分宣城比本部低 5-10 分**,**毕业证一模一样**
- 部分专业(物流管理 / 文化产业管理 / 食品质量)只放宣城
- **报志愿前看清专业组在哪个校区**,有些考生想去本部结果被分到宣城后悔

### 3. 安农大 / 安师大 / 安农大独立学院陷阱
- 安农大本部 vs 经海学院(独立学院 / 民办)
- 安师大本部 vs 皖江学院(独立学院 / 民办)
- 安大本部 vs 江淮学院(独立学院 / 民办)
- **学费差几万 / 牌子差很多**,**报志愿前看清代码**!

### 4. 提前批 vs 普通批分流
- **提前批**:公费师范(安师大 / 阜阳师大 / 淮北师大) / 优师计划 / 公安院校 / 军校 / 部分定向医学生 / 国家专项
- **普通批**:本科批 / 高校专项 / 地方专项
- **提前批一旦录取就锁死**,普通批不能再投。**家长跟孩子聊清楚是否愿意去乡村 / 公安 / 军校,免得后悔**

## 国家专项 / 高校专项 / 地方专项(安徽视角)

### 三种专项区别(2024 实况)

| 专项 | 适用对象 | 优惠幅度 | 安徽适用范围 |
|---|---|---|---|
| **国家专项** | 国家级贫困县 / 中央指定县 农村户籍 | **比统招分低 20-30 分** | 安徽 22 个国家级贫困县(主要在皖北 + 大别山区) |
| **高校专项**(自强 / 筑梦计划) | 全国农村户籍考生(部分高校放宽到县级以下) | **比统招分低 30-50 分** | 全国农村户籍均可报,但要校测 |
| **地方专项** | 安徽本省指定区县农村户籍 | **比统招分低 10-20 分** | 安徽 30+ 县(扩展到皖南山区) |

### 安徽国家级贫困县(国家专项核心区)

**皖北 6 市**:
- 阜阳市(颍上 / 阜南 / 临泉 / 太和)
- 亳州市(蒙城 / 利辛 / 涡阳)
- 宿州市(萧县 / 砀山 / 灵璧 / 泗县)
- 蚌埠市(怀远 / 五河 / 固镇)

**皖西大别山区**:
- 六安市(金寨 / 霍邱 / 寿县 / 霍山)
- 安庆市(岳西 / 太湖 / 望江)

**国家专项最大红利方**:**金寨 / 岳西 / 太湖 / 颍上 等大别山 + 皖北农村考生**,通过国家专项**比统招分低 25-30 分进 985/211**(可摸到中科大 / 复旦 / 武大 / 兰大 等顶级名校)

### 操作建议(agent 必须主动 check)

- **L2 收完地市 + 农村户籍后**,主动告知用户是否符合国家专项 / 高校专项 / 地方专项资格
- **皖北 6 市 + 大别山区农村户籍考生** 必须填国家专项志愿(否则浪费 25-30 分红利)
- **高校专项面向所有农村户籍**,但要校测 + 部分高校(清北 / 复旦 / 上交)还要面试
- **地方专项** 适合刚够安徽省内 211 的考生(分够安大 / 合工大但不够外省 985 的)

## 合肥科创崛起的具体案例(2020-2025)

### 头部企业落户合肥时间轴
- **2017**:京东方合肥基地(显示面板,200 亿投资)
- **2018**:长鑫存储(国产 DRAM 主力)启动
- **2020**:**蔚来汽车中国总部**落户合肥(110 亿投资)
- **2020**:**比亚迪合肥基地**(整车 + 电池 + 半导体)
- **2021**:**大众安徽**(大众集团第三家中国合资,纯电导向)
- **2022**:阳光电源全球光伏逆变器市占率前 3
- **2023**:**国盾量子**(量子通信全国第 1)上市
- **2024**:科大讯飞 + 蔚来 + 长鑫 + 比亚迪合肥 + 京东方 校招总规模超 1.5 万人

### 对安徽考生的影响
- **2018 之前**:中科大 / 合工大 顶尖学生 80%+ 出皖(去长三角 / 北上深)
- **2024 之后**:中科大 / 合工大 顶尖学生 30%+ 留皖(蔚来 / 科大讯飞 / 长鑫 / 比亚迪 / 国盾量子 直接对口)
- **安徽考生填报心态需要更新**:**留皖不再是次选**,合肥房价 1.5w / 上海 6w,**安徽中产家庭可以认真考虑留皖**
