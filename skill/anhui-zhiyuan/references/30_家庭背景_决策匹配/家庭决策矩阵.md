# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(安徽视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**安徽特殊性**:
1. **皖南 vs 皖北 经济差距显著**(皖南合肥 / 芜湖 / 马鞍山富裕;皖北阜阳 / 亳州 / 宿州贫困)— 同档家庭在皖南 vs 皖北的实际购买力 / 信息差差异巨大
2. **徽商基因 + 私企接受度高**(皖南尤其,跟河南 / 山东体制内偏好不同)— 创业家庭比例比中部其他省高
3. **合肥科创崛起** = 留皖路径的"中产升级版"(以前留皖 = 没出息,现在留皖 = 蔚来 / 科大讯飞 / 京东方 / 长鑫)

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211(中科大 / 合工大 / 安大 / 出皖 985),**走选调生比国考省考更优**(起点更高、竞争内部化)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校 / 公安专业(中国人民公安大学 / 安徽警官职业学院)+ 公安联考 = 父母编制资源能用上

**典型 case(安徽本地)**:
- **合肥某中产体制内家庭**(父亲省直机关,母亲教育局)→ 孩子 615 分历史类 → **推安大法学**(211 综合,安徽公检法对口)→ 毕业选调进合肥市委办,**家庭路径完美匹配**
- **失败 case**:同样家庭,孩子被推去中科大物理学 → **8 年读博后留科研**,父母不满"没编制 + 30 岁不结婚",**两代人价值观冲突**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(安师大 / 阜阳师大);医生家庭 → 临床 / 口腔(8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → 法学(安大 / 中南财法 / 华政 等);工程师家庭 → 对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case(安徽本地)**:
- **母亲合肥一六八中学语文老师 + 父亲普通工薪** → 孩子 605 分历史类 → **公费师范生汉语言**(安师大) → 毕业回原校系统 / 同区编制,**母亲资源直接复用**
- **父母都是临床医生(合肥)** → 孩子 670 分物理类 → **上交医临床八年制 / 中科大医学院八年制** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- **父亲奇瑞高级工程师(芜湖)** → 孩子 600 分物理类 → **合工大车辆工程**(对应奇瑞 / 蔚来 / 比亚迪合肥)→ 毕业进父亲行业内推荐的车企整车厂,**家庭工科基因延续**

## 档位 ③ 私企管理 / 创业家庭(安徽特色 — 徽商基因)

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **安徽特色:徽商家族文化** — 比中部其他省创业氛围浓(对应浙江温州 / 福建泉州但弱一档)。**皖南家庭尤其多**(合肥 / 芜湖 / 黄山徽州 等)

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(**徽商家族出国留学比例比湖北 / 河南高**)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case(安徽本地)**:
- **黄山徽商家族**(年入 200w+,茶产业)→ 孩子 580 分物理类 → **推安农大茶学(全国第 1)+ 出国硕士**(伦敦商学院食品管理) → 接班家族茶业 / 国际化运营
- **合肥某私企老板家庭**(年入 150w+,装修建材)→ 孩子 595 分物理类 → 推**香港城市大学 / 上海纽约大学 中外合作办学**(学费 8-15w/年家里能撑)→ 出国背景做家族企业接班
- **失败 case**:**芜湖某创业家庭**(自己开物流公司)→ 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(安徽工薪基线比湖北 / 江苏低)。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **安徽特色:皖北工薪家庭信息差比皖南更大**(阜阳 / 亳州 / 宿州 父母大多没上过大学,完全不懂"专业组 / 选调 / 985 / 211")

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - 公费师范生(安师大 / 阜阳师大 / 淮北师大)= 高考分适中 + 直接编制 + 无学费
   - 警校(中国人民公安大学 等)+ 公安联考 = 进警察系统编制
   - 医学技术(医学影像 / 检验)= 三甲医院技术岗 + 4 年本科即可
   - 殡葬专业 = 100% 编制 + 收入意外不错
3. **次推稳定就业型**:
   - 电气工程进国电网 / 蔚来三电(分够合工大 / 985)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
   - **合工大车辆 / 电气 / 机械 + 留皖进车企**(蔚来 / 比亚迪合肥 / 大众安徽 / 奇瑞)= 普通家庭男生在安徽特有的逆袭路径
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-10w,跟双非工科没差,且合肥头部不收双非)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)
   - **新闻传播 / 网络与新媒体 / 广告**(合肥媒体生态弱 + 全国行业衰退)

**典型 case(安徽本地)**:
- **马鞍山宝武钢铁工人家庭** → 孩子 590 分物理类 → 推**安工大冶金工程**(双非但宝武集团对口)→ 毕业直接进马钢,**月入 1.0w + 编制,父辈血脉延续**
- **阜阳工薪家庭(皖北)** → 孩子 540 分文史类 → 推**阜阳师大公费师范汉语言**(双非但定向培养 + 零学费)→ 毕业当年回阜阳县编制,**家庭命运改变**
- **合肥工薪家庭** → 孩子 620 分物理类 → 推**合工大电气工程** → 毕业进国网安徽省公司管理岗 8k + 编制 / 或蔚来三电系统工程师 25w → **本省最稳路径之一**

## 档位 ⑤ 农村 / 临工家庭(皖北重灾区)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万(安徽口径,比中部其他省略低)。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **安徽特色:皖北 6 市农村比例高**(阜阳 / 亳州 / 宿州 / 蚌埠 / 淮南 / 淮北),**国家专项计划 / 高校专项 / 地方专项 对皖北部分县考生倾斜**

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - 公费师范生(无学费 + 编制)= 农村家庭神器(**阜阳师大 / 淮北师大 / 安师大** 公费师范汉语言 / 数学)
   - 国家专项计划 / 高校专项 = **皖北 6 市部分县考生有指标**(分数比统招低 20-30 分)
   - 警校 / 军校(无学费 + 编制 + 包分配)
   - 农林牧水(安农大国家专项)= 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - 国家专项计划:**皖北 6 市农村户籍**,985/211 名校多个专项指标(比统招低 20-30 分)
   - 强基计划:数学 / 物理 / 化学 单科特别强的农村学生有机会(中科大强基对皖北农村友好)
   - 殡葬专业(冷门但 100% 编制 + 收入不错)

**典型 case(安徽本地)**:
- **阜阳颍泉区农村家庭** → 孩子 595 分物理类 → 通过**国家专项**进**中科大化学**(比统招分低 25 分)→ C9 牌子 + 国家专项编制路径,**整个家族第一个 985**
- **亳州蒙城县农村女孩** → 605 分文史类 → 推**阜阳师大公费师范汉语言** → 4 年无学费 + 毕业回原县编制,**最适合皖北农村家庭的"零风险"路径**
- **宿州萧县农村男生** → 580 分物理类 → 推**安农大农学(国家专项)**或**安工大冶金工程** → 安工大对口宝武集团 / 安农大对口安徽各市农技推广站,**双线编制保底**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 安徽特有的家庭决策反常识

1. **"出皖才有出息" 已过时**(2024+):合肥科创崛起后,**留皖中产升级路径成立**。普通工薪家庭男生**合工大留皖进蔚来 / 比亚迪合肥** 比 985 弱专业去北上深更划算。
2. **皖北 vs 皖南 不是同一条赛道**:皖北农村家庭 = 极端保守路径(国家专项 + 公费师范 + 警校);皖南中产 / 私企 = 可冒险路径(创业 / 出国 / 头部院校)。Agent 必须先问清地市再判断家庭档。
3. **徽商家族 ≠ 普通中产**:徽商家族可冒险 / 可出国 / 可接班 = 跟江浙温州 / 福建泉州 同一档,但**外人很难判断**(很多徽商家族不在合肥而在皖南三四线 / 五线县级市)。Agent 收 L2 时如果是黄山 / 池州 / 宣城 / 黟县这类皖南山区城市,要追问是否是茶企 / 木雕 / 文房四宝家族,可能是隐性中产。
4. **安医大 / 安师大 / 安农大 双非 ≠ 二档**:在安徽医生圈 / 教育圈 / 农林圈,**这三所双非的本地认可度高于多数 211 综合校**。普通家庭要破除"必须 211" 的迷信。
