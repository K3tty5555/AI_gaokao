# 用户意向冲突 — Reality Check 金句库(安徽视角)

很多家长 / 考生有具体的意向("想上中科大"、"非合肥不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

---

## 4 类意向冲突 + 金句模板(安徽案例)

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 580 分要中科大主流组 / 600 分要清北)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(安徽 580 分,意向中科大)**:
> "中科大主流组在安徽物理类全省前 1,200 名以内。你 32,400 名,差 3 万多名,**中科大没戏**(就连冷门组天文 / 地球物理 也要全省前 1,800 名)。
>
> 但你能上合工大主流组 + 安大理工科组 + 安医大临床 — 这三所留皖就业,**蔚来 / 科大讯飞 / 京东方 / 长鑫 校招里**跟中科大冷门组校友地位差不多(都是'合肥 211/双非顶级 + 留皖同档')。**特别是合工大车辆 / 电气专业,在长三角车企认可度比中科大物理冷门组还实在**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(安徽工科 + 普通工薪家庭)**:
> "中科大你 620 能擦边冲 — 但只能进材料科学 / 生命科学 / 地球物理 这种冷门组。**C9 牌子 + 生化环材 = 双重坑**(强基计划除外,但你没报)。
>
> 同分能上的合工大车辆工程(管理科学与工程全国前 5,蔚来 / 比亚迪 / 大众安徽 直招)出来对口程度更高,**留合肥进车企起薪 20w+,中科大材料生命冷门组毕业读博 8 年才稳**。冲中科大留一个心理慰藉位即可,**主推合工大车辆才是你普通工薪家庭真正的最优解**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [上交医临床八年制 / 协和])
> - 撑不起 → 走 **[替代短路径]**(如 [安医大医学影像技术 / 麻醉学 / 护理学] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(皖北农村 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 6-8k**。皖北农村家庭还要供 8 年,**这是几乎不可能的**。
>
> 撑得起 → 推上交医 / 协和 八年制,长期天花板高。
>
> 撑不起 → **建议安医大医学影像技术(4 年本科直接进合肥三甲技师岗,起薪 5-7k,早 4 年挣钱)**,或者**安农大兽医**(走宠物经济 + 农技推广双轨),或者放弃医学走**安工大冶金 / 阜阳师大公费师范** 这种本科直接挣钱的赛道。"

**真实案例(合肥工薪 + 想学医)**:
> "合肥三甲临床医生现在基本只要博士。你 600 分上不了上交医协和,合肥本地也就中科大医学院八年制 / 安医大临床 5+3。
>
> 中产能撑 8 年 → **安医大临床**(双非但安徽医生圈血脉强,附属医院顶级,**比 211 综合校临床 + 出皖更对口安徽医院体系**)。
>
> 撑不动 → **安医大医学影像技术 / 检验技术 4 年本科** 进合肥三甲做技师,合肥三甲技师岗工资跟安医大临床本科毕业差不多。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非合肥不去" / "非长三角不去"),拒绝出皖 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留合肥没意义,要去西工大),**要灵活退一步**。"

**真实案例(合肥本地 + 工科方向 + 600 分)**:
> "你只留合肥,这位次 1.5 万名,中科大主流组够不上。
>
> **留合肥最稳路径**:**合工大车辆工程 / 电气工程**(211 + 蔚来 / 比亚迪合肥 / 大众安徽 / 阳光电源 直招校,长三角车企认可度高)。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 户口可能也没了**,毕业回合肥跟合工大车辆 / 电气工程同学比还要落后,综合不划算。"

**真实案例(皖北家庭 + "非长三角不去")**:
> "你父母想让你毕业留长三角,这是最近 5 年安徽考生最普遍的诉求。
>
> 长三角认可的安徽强校 = 中科大 / 合工大 / 安大 / 安医大临床。**这 4 所毕业留长三角(沪苏浙皖)概率 70%+**(因为 2019 年后安徽正式纳入长三角一体化)。
>
> 不要为了'留长三角'去苏州大学 / 浙工大冷门组 — **同档合工大车辆 / 电气主流组 + 长三角车企对口 比 苏大 / 浙工大冷门组 实在得多**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 中科大 / 想学医 / 想留合肥 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 安徽特有的意向冲突场景

### 1. "中科大情结" — 安徽考生最常见误区

**特征**:安徽家长普遍把"中科大"当成"安徽清华",**总想擦边冲**。

**reality check**:
> "中科大不是给所有人准备的。**打算读博 / 进科研 → 中科大顶级**;**打算工作就业 → 复交 / 西交 / 华科 / 上交 工科可能更对口**。强行擦边进中科大冷门组(材料 / 生命 / 地球物理),5 年后跟合工大主流组比未必赢。"

### 2. "出皖才有出息" — 父母辈的过时认知

**特征**:**60 后 / 70 后家长普遍认为留皖 = 没出息**(因为他们记忆里的合肥 = 落后),不知道 2020 年后合肥科创崛起。

**reality check**:
> "**合肥 2020 年后是中部硅谷**,蔚来 / 科大讯飞 / 京东方 / 比亚迪 / 长鑫 全在合肥。**留皖竞争力已经拐点,不再是次选**。**普通工薪家庭男生留合肥进蔚来 / 比亚迪 比北漂去苏州 / 杭州双非工厂划算**(房价 / 父母距离 / 编制属性 / 长期上限 综合算)。"

### 3. "安医大双非,不如 211" — 学医家庭最常见误区

**特征**:家长追求"211 牌子"看不上"安医大双非"。

**reality check**:
> "**安医大临床医学录取位次接近 211 综合**,**附属医院强 + 安徽医生圈血脉** 让安医大在医疗体系内认可度比很多 211 综合校的临床医学还高。**学医不要只看牌子,看附属医院**。**留皖学医的最优解就是安医大,不是中科大医学院,也不是出皖 211 综合校的临床医学**。"

### 4. "皖北农村 = 出不去" — 家长信息差最大区

**特征**:**皖北农村家庭普遍不知道国家专项 / 高校专项 / 公费师范** 这些专属优惠。

**reality check**:
> "**皖北 6 市部分县农村户籍考生,985/211 名校国家专项指标比统招低 20-30 分** —— 你考 580 分,通过国家专项可以摸到中科大 / 武大 / 兰大 等名校。**皖北家庭最大的红利是国家专项 + 公费师范双叠加,但很多家长不知道**。"

### 5. "徽商家族要接班 = 必须学商科"

**特征**:**徽商家族**(黄山 / 池州 / 宣城 茶 / 木雕 / 文房四宝 / 餐饮)默认要孩子学商科继承。

**reality check**:
> "接班家族企业不一定要学商科本科。**黄山茶产业 → 安农大茶学(全国第 1)+ 出国硕士读食品管理 / 国际贸易**, 比国内本科商科 + 不懂茶 更适合接班。**接班 ≠ 学商科**,看具体行业。"
