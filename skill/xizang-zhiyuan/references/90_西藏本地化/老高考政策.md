# 西藏老高考政策 — 数据口径与改革推迟说明

## 一句话总结

**西藏 2021-2025 年全部沿用老高考(文科 / 理科),高考综合改革推迟至 2027 届或更晚**(具体最终时间表以自治区教育厅公告为准)。**藏汉两套招生分数线 + 民族加分 + 援藏定向 + 内地西藏班** 是西藏志愿填报四大独有变量,这些是绝大多数志愿工具忽视的关键点。

---

## 一、改革时点(关键!)

### 全国新高考改革进度对比

| 批次 | 启动年份 | 涉及省份 |
|---|---|---|
| 第一批 | 2014 | 上海、浙江(3+3) |
| 第二批 | 2017 | 北京、天津、山东、海南(3+3) |
| 第三批 | 2018 | 河北、辽宁、江苏、福建、湖北、湖南、广东、重庆(3+1+2) |
| 第四批 | 2019-2021 | 黑吉辽、安徽、江西、贵州、广西、甘肃 等(3+1+2) |
| 第五批(原计划) | 2022 | 河南、陕西、山西、青海、宁夏、新疆、内蒙、四川、云南、**西藏** 等 |
| **西藏实际** | **推迟至 2027 或更晚** | **目前 2021-2025 全部 文/理 老高考** |

### 西藏推迟改革的原因(背景理解)

- **教学条件特殊**:藏区中学双语教学(藏汉双语)+ 农牧区基础教育条件不均,选科改革实施难度高
- **考生体量小**:西藏每年高考考生约 **3 万人**(全国最少之一),改革成本相对高、收益相对低
- **民族文化考量**:藏族考生民族课程 / 藏语文教学需要单独安排,改革涉及面广
- **配套资源不足**:走班制、生涯规划、新高考评价体系 等配套需投入大量资源
- **政策保守**:西藏历来在教育改革上偏保守,先观望其他省份再启动是常态

### 实操影响

- **2025 届(2025 年 6 月高考)**:**仍是文 / 理**,数据用 `2025_文科_xizang.csv` / `2025_理科_xizang.csv`
- **2026 届**:**仍是文 / 理**(2025-2026 学年高一学生入学时未启动新高考)
- **2027 届及以后**:**目前规划仍是文 / 理**(具体看自治区教育厅最终通知,**agent 不要承诺改革时间**)
- **不存在跨改革过渡期**:不像河南/四川/云南等省 2025 是首届新高考,西藏目前没有切换问题

## 二、西藏老高考结构(科类 + 招生分类)

### 科目设置

- **文科**:语文 + 数学(文)+ 外语 + 文综(政治/历史/地理 三合一,300 分)
- **理科**:语文 + 数学(理)+ 外语 + 理综(物理/化学/生物 三合一,300 分)
- **总分**:750 分(语数外各 150 + 文综/理综 300)
- **外语**:大多数考生英语,藏族考生可选藏语 / 部分少数民族考生可选其他

### 西藏专属:科类与民族身份的交叉

**西藏招生按 民族 × 科类 × 招生类型 三维分类**,数据库里的批次 / 录取分数都按这套维度切分:

| 维度 | 取值 |
|---|---|
| 科类 | 文科 / 理科 |
| 民族 | 汉族 / 少数民族(藏族 / 门巴 / 珞巴 等) |
| 招生类型 | 普通类 / 国家专项 / 地方专项 / 民族班 / 援藏定向 / 内地西藏班 |

**典型组合举例**:
- "藏族 + 理科 + 普通类" → 走少民理科线
- "汉族 + 文科 + 普通类" → 走汉族文科线
- "藏族 + 理科 + 援藏定向" → 走援藏定向理科线(分数更低)

## 三、西藏分数线的特殊性(重要!)

### 本科线参考(近年大致区间,以自治区招办每年公布为准)

| 类别 | 文科本一 | 文科本二 | 理科本一 | 理科本二 |
|---|---|---|---|---|
| **汉族** | ~ 440-460 | ~ 350-380 | ~ 410-430 | ~ 320-350 |
| **少数民族(藏族等)** | ~ 360-385 | ~ 320-345 | ~ 320-345 | ~ 280-310 |

> ⚠️ 上述数字为多年趋势区间,**具体某一年请用 `score_to_rank.py` 查实际批次线**。**藏族线显著低于汉族线 80-120 分**,这是西藏分数线最大的结构特征。

### 与内地省份对比的"反常感"

- **西藏汉族本科线 ≈ 内地老高考省份的专科线**(如河南老高考理科本二线 ~ 400+,西藏汉族理科本二只要 ~ 320-350)
- **西藏少民本科线比汉族线低 80-120 分**(藏族考生 280-300 分能上本二,内地不可想象)
- **原因**:① 西藏考生体量小,招生计划相对宽松;② 国家对西藏少民有政策性倾斜;③ 西藏基础教育条件相对薄弱,分数线对应同等学力实际更高

### 民族加分(浮动政策,以当年为准)

- **藏族 / 门巴族 / 珞巴族 / 其他西藏世居少数民族**:通常加 5-10 分(早年加分曾达 20-30 分,近年逐步收窄)
- **汉族西藏籍**:**部分年份**有少量加分(西藏汉族户籍倾斜),近年趋于取消
- **政策动态**:**民族加分每年微调**,**agent 必须提示"以当年自治区招办公布为准"**,不可硬编码

## 四、西藏招生 4 类专项(独有)

### 1. 民族班 / 民族预科

- **专为西藏少数民族考生(以藏族为主)开设**
- 内地 985/211 院校(如清华 / 北大 / 复旦 / 武大 / 川大 / 兰大 等)有民族班指标
- **录取分数比普通批低 40-80 分**,但**入校后通常先读 1 年预科再进入本科**
- 适合 **藏族考生 + 想冲内地名校但分数差一截** 的家庭

### 2. 援藏定向(关键!)

- **针对援藏干部 / 教师 / 医生子女**(父母现役援藏满若干年)
- 部分对口省份院校有定向指标(京沪粤鲁苏 等 18 省份援藏对口校)
- **录取分数较普通批低 20-50 分**
- **毕业后通常需返藏服务若干年**(具体期限看签约)
- **资格审查严格**:父母在职状态 / 援藏年限 / 户籍 都要核实

### 3. 内地西藏班(本科前)

- **不是高考类型,而是高中教育安排**
- 西藏部分初中毕业生分配到内地中学(北京西藏中学 / 上海共康中学 / 成都西藏中学 / 重庆西藏中学 / 广东深圳西藏中学 等 21 所)读高中
- **内地班学生高考时仍按西藏籍报名**(户籍未迁出),享受西藏分数线 + 民族加分
- **优势**:师资远超本地 + 适应内地学习节奏 + 出藏意愿更强
- **agent 注意**:用户若说"我在北京读西藏班",仍按西藏考生处理

### 4. 国家专项 / 地方专项

- 国家专项:面向农村 / 边远地区考生,分数较普通批低
- 地方专项:面向自治区内偏远地市考生(那曲 / 阿里 等)
- 西藏全境很多地市本身就符合"边远"定义,**多数西藏考生可同时享受国家专项**

## 五、藏汉两套招生体系的实操指引

### 数据查询时必须传民族参数

```bash
# 藏族理科考生 380 分查位次
GAOKAO_PROV=xizang scripts/score_to_rank.py --score 380 --type 理科 --year 2025 --minzu 藏族 --json

# 汉族文科考生 460 分查位次
GAOKAO_PROV=xizang scripts/score_to_rank.py --score 460 --type 文科 --year 2025 --minzu 汉族 --json
```

### 推荐时必须分别考虑

- **藏族 + 普通类** → 优先看少民批数据
- **藏族 + 援藏定向**(若资格符合) → 双轨规划:普通 + 定向
- **汉族 + 普通类** → 看汉族批数据
- **汉族 + 援藏子女** → 援藏定向通道是核心(汉族普通批分数线对汉族不算友好,定向更优)

### 民族加分如何处理

- **预测时**:用考生**裸分**算位次,不预先加分(避免加分政策变动导致预测偏差)
- **推荐时**:在卡片"关键提醒"里标注"如当年加 X 分,实际位次可上浮 ~ Y 名"
- **千万不要**把加分加进总分再查位次:加分政策每年浮动,这种硬编码会出错

## 六、数据现状(skill 内部)

### 一分一段表
- 路径:`data/yifenduyiduan/`
- **2021-2025 全部 文科 / 理科**(老高考连续 5 年)
- 若数据按民族分库:`yifenduyiduan_汉族_理科_2025.csv` / `yifenduyiduan_少民_理科_2025.csv`
- **没有 物理类 / 历史类 数据**(因为西藏没启动新高考)

### 录取数据库
- 路径:`data/gaokao_xizang_<YYYY>.db`(由爬虫生成)
- 字段含 `minzu`(汉族/少民)、`zslx`(普通类/民族班/援藏定向/国家专项)、`type`(文科/理科)
- 查询时这三个字段必须组合过滤

### 批次线表
- 自治区招办每年公布 4 套(汉文/汉理/少民文/少民理)的本一/本二/专科线
- 调 `score_to_rank.py` 时 `batch.bracket` 字段自动按 `--minzu` 参数选对应批次线

## 七、给 agent 的纪律提醒

1. **L0 阶段必问民族 + 援藏身份**:这两个变量决定后续所有数据查询路径,不能跳过
2. **不要假设"西藏考生 = 藏族考生"**:西藏汉族户籍考生不少(援藏二代 / 商人子女 / 长期定居汉族),走汉族线
3. **不要把民族加分加进总分**:用裸分查位次,加分作为"上浮空间"提示
4. **援藏定向有资格门槛**:推荐前提示用户"请向自治区招生考试委员会核实定向资格"
5. **承认数据精度限制**:西藏体量小,某些冷门组合(如"藏族 + 文科 + 民族班")数据稀疏,**给推荐时主动声明精度**
6. **改革时间不可硬编码**:**永远不要承诺"西藏 2027 年改革"**,只说"目前规划仍是文/理,具体看自治区教育厅最终通知"
7. **民族文化敏感**:在跟藏族 / 汉族考生对话时,不假设他们的留藏意愿和文化倾向 —— 用 L3.5 量表客观采集
