# 用户意向冲突 — Reality Check 金句库(西藏视角)

很多西藏家长 / 考生有具体的意向("想上清华藏族民族班"、"非北京不去"、"想学医出藏当主任医师"、"留藏不接受 + 想要互联网大厂"),但**意向不一定跟分数 / 民族身份 / 援藏身份 / 留藏意愿 匹配**。**Agent 不能盲从意向**(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

**西藏意向冲突比内地更复杂**:多了 **民族身份 + 援藏身份 + 留藏 vs 出藏 + 高原适应 + 多通道叠加** 多个维度,**意向跟这些约束都可能冲突**,要分别处理。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 民族身份不符 / 服务期不可接受,**不要绕弯子**。家长来咨询不是听安慰话,是要决策
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **民族班 / 援藏定向 / 国家专项是西藏独家通道** — 家长不知道的多,要主动揭示
5. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(尤其在西藏 + 留藏路径上,藏民大 / 藏大 / 农牧学院 + 编制 + 高原补贴 ≠ 弱选)
6. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,**西藏临床医生路径除外**(藏区医生紧缺 + 编制 + 高原补贴)
7. **留藏 ≠ 没出息** — 西藏体制内 + 编制 + 央企在藏分支 + 援藏接续岗位 + 高原补贴 = 综合 ≈ 内地一线,要纠正"留藏没前途"误区

---

## 5 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / 民族身份不符 / 资格不够

**特征**:用户意向校 / 意向城市 / 意向身份(援藏定向 / 民族班),跟分数 / 身份完全不匹配。

**金句模板(分数不可达)**:
> "你说想上 [意向校 985],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [西藏本地 / 留藏路径] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作藏大 / 藏民大 / 出藏对口援藏 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**金句模板(民族身份不符)**:
> "你想走 [民族班 / 国家专项 / 援藏定向],但 [汉族西藏长期户籍 / 不在农牧区 / 父母不是援藏干部] —— **资格不符**。
>
> [国家专项需要农牧区户籍 / 援藏定向需要父母满足年限审查 / 民族班只对藏族 / 门巴族 / 珞巴族 等开放]。
>
> 你的实际通道是 [普通批 / 西藏籍考生加分 / 走藏大 / 藏民大留藏路径]。**不要为不符合的资格虚耗心思**。"

**真实案例(藏族 + 想上清华 CS + 民族班)**:
> "藏族民族班上清华 / 北大 CS 是真实路径,但**录取分仍要 500-580 段**(汉族普通批要 680+,民族班降 100-150 分仍需 500+)。
>
> 你 380 分(藏族 A 类),**清北民族班够不上**。
>
> 但你能走 **国家专项 + 民族班 + 农牧区专项 三重叠加** → **西交 CS / 西电 CS / 川大 CS** 都有藏族民族班降分通道(可能降到 380-420 段) — 这些 985/211 CS 在西部 + 留藏 IT 编制 + 出藏内地 IT 都有出口,跟"清北 CS 牌子" 在西藏家长资源层级里差距没你想的那么大。"

**真实案例(汉族 + 想走援藏定向)**:
> "你说想走援藏定向 武大法学,但你父亲在内地工作没援藏过 — **资格不符**(援藏定向要求父母现役援藏满若干年 + 资格审查)。
>
> 你的实际通道是 **普通批 武大法学**(分够就直接报)+ **西藏籍考生地区考生加分**(以当年自治区招办公布为准)。
>
> **不要试图通过虚假关系造援藏定向资格,资格审查不过会被取消录取**。"

### 模式 B:边缘可达 — 意向校能擦但只能进冷门组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**留藏路径上的特殊冲突**:能擦藏大但只能进冷门组(对藏大不熟的家长以为 211 全好,实际要看专业)。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 / 211 就是 985 / 211',但 **985 / 211 的冷门组(生化环材天坑 / 哲学)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(理工科 + 普通家庭)**:
> "藏族考生理科 410 分,藏大你能上,但**只能进生化环材 / 边缘理科**。
>
> 同分能上的 **农牧学院水利水电 / 食品科学(藏药 / 青稞)** 出来对口程度更高(留藏进国家电网西藏 / 中国电建西藏 + 编制 + 高原补贴 + 项目奖金) —— **跟藏大冷门组比,综合年薪 + 编制 + 留藏就业远超**。
>
> 冲藏大留一个心理慰藉位即可,主推农牧学院水利水电。"

**真实案例(汉族 + 想要 985 牌子)**:
> "援藏二代汉族 540 分,**援藏定向 985 你能擦**(武大 / 川大 / 中央民大),但**只能进冷门组**(如武大哲学 / 川大新闻 / 中央民大冷门方向)。
>
> 同分能上的 **藏大法学 / 藏大民族学 / 藏民大法学(民族法方向)** —— **211 + 双一流 + 留藏对口检法 / 自治区民委 + 编制 + 援藏接续** 远好于"985 冷门组 + 服务期回藏冷门岗"。
>
> **985 的虚牌子 vs 211 的实编制,在西藏选实编制更稳**。"

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农牧。**西藏特殊性**:**藏区临床医学 + 农牧区藏族家庭** 是反例(撑得起 + 编制易拿)。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [华西临床八年制援藏定向 / 北医临床民族班])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像技术 / 检验技术 / 护理 4 年本科 + 编制 / 藏医学 5+3 比临床快]),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,期间月薪 7-10k(藏区比内地稍高 + 高原补贴)。
>
> 撑得起 → 推 **援藏定向华西临床医学八年制 / 北医临床民族班(藏族)** → 8 年后回藏顶尖三甲。
>
> 撑不起 → 走 **医学影像技术 / 医学检验技术 / 护理学 4 年本科** → 直接进藏区医院技师岗 + 编制 + 高原补贴(综合年薪 7-12w + 一辈子稳)。**比临床 8 年长周期对普通家庭友好 5 倍**。
>
> **特殊路径**:藏族 + 想做藏医 → **西藏藏医药大学 藏医学(5+3)+ 全国独家 + 民族文化传承** = 长周期但学费低 + 编制易拿 + 政策扶持。"

**真实案例(农牧区藏族 + 想出藏当主任医师)**:
> "那曲牧区藏族 380 分,想出藏读临床当三甲主任医师 — **路径不切实际**:
>
> 1. **学历门槛**:内地一线三甲 95% 要博士,你 8+5 = 13 年才能当主任医师,**农牧区家庭撑不起 13 年读书**
> 2. **更优路径**:**国家专项 + 民族班 + 兰大医学 / 川大华西** → 8 年后回藏 + 进自治区人民医院 / 拉萨各地市医院 + 编制 + 高原补贴 → **5 年后晋升副主任医师**(藏区职称晋升比内地快 + 编制稳)
> 3. **真正的目标**:不是"内地三甲主任医师" 而是**回藏当稀缺医生** —— **藏区医生紧缺 + 高原补贴 + 编制 + 援藏接续岗位 = 综合 ≈ 内地一线主任医师**"

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去 / 非留藏不可 / 必须出藏"

**特征**:用户只想留某个城市("非北京不去" / "非留藏不可" / "必须出藏"),拒绝其他选项。**西藏特殊性**:**留藏 vs 出藏的"非 X 不可"心结特别强**。

**金句模板(必须留藏 + 拒绝出藏)**:
> "你只想留藏,那同档要在 **藏大 / 藏民大 / 农牧学院** 之间选 —— 这没问题,**留藏就业的核心是自治区编制 + 央企在藏分支 + 援藏接续岗位**。
>
> **留藏不等于没出息** —— 那曲 / 阿里 高海拔综合年薪 15-22w + 编制,**跟出藏内地三线城市起薪差不多,且编制更稳 + 服务家乡 + 文化适应不需重新做**。
>
> 但!如果你想做的方向 [互联网大厂 / 头部金融 / 一线媒体] 西藏没强校(留藏对口弱),**要灵活退一步** —— 出藏走 **援藏定向 + 服务期回藏** 或 **民族班 985 + 出藏发展** 是更稳的路径。"

**金句模板(必须出藏 + 拒绝留藏)**:
> "你坚决出藏,**家长担心是对的** —— 出藏到沿海卷的 ROI 通常不健康(生活成本高 + 文化适应难 + 父母资源用不上 + 毕业回藏二次成本)。
>
> **三条出藏路径要分清**:
> 1. **援藏定向 985** = 出藏读名校 + 服务期回藏(7-13 年规划) — **最稳路径**
> 2. **民族班 985 + 出藏不回** = 用低分上 985 + 内地就业 — **要看孩子能否在内地立足**
> 3. **普通批出藏 + 双非** = 没多大优势,**不如留藏 + 藏民大 / 藏大 + 编制**
>
> 选 1 还是 2,看孩子是不是想长期留内地;**选 3 不如留藏**。"

**真实案例(藏族 + 必须出藏到一线大都市)**:
> "藏族 + 拉萨城里 + 想出藏到深圳 / 上海卷互联网。
>
> **现实**:**沿海互联网公司从未在藏大 / 藏民大办过校招**,你出藏读双非或普通批,**毕业就业卷不过内地考生**(你没有沿海实习 + 校友网 + 一线技术氛围)。
>
> **更优路径**:**民族班 + 国家专项 三重叠加 + 西交 CS / 哈工大 CS / 北航 CS** → 985 + 民族班降 60-150 分 → 毕业去内地一线大厂(华为 / 字节 / 腾讯 校招)。
>
> **不要为'出藏到一线城市'放弃多通道叠加,反而走双非路径** —— 那是双重劣势(双非 + 西藏籍)。"

**真实案例(汉族西藏长期户籍 + 必须留藏)**:
> "汉族西藏长期户籍 + 父母在拉萨经商 + 必须留藏 + 想做金融。
>
> **现实**:**西藏没有金融业**(西藏银行 / 邮储银行西藏 / 拉萨各地市行 等岗位有限,起薪 6-9w + 编制),**留藏 + 金融 = 错配**。
>
> **更优路径**:**改藏民大经济(民族经济方向) / 藏民大行政管理 / 藏大经济** → 留藏考公 / 进自治区财政厅 / 自治区国资委 / 藏民大党校 → 编制 + 高原补贴。**'金融'变成'体制内财经岗',对汉族西藏长期户籍家庭更友好**。"

### 模式 E:意向跟"民族 / 援藏 / 留藏 多通道"冲突 — 西藏独有

**特征**:用户(或家长)对民族班 / 援藏定向 / 国家专项的多通道叠加机制不熟,**意向 vs 实际可走通道** 错位。

**金句模板**:
> "你说想 [意向方向],你的身份是 [藏族 / 汉族 + 援藏二代 / 农牧区户籍]。
>
> **你不知道的是,你身份能走的通道有 [N] 个**:[列出具体通道]。**这些通道叠加 = 比同分汉族普通批考生多 [60-150] 分的录取优势**。
>
> [意向方向] 在 [民族班 / 援藏定向 / 国家专项] 通道下,实际可达性是 [Y]。**不用 = 浪费**。"

**真实案例(农牧区藏族 + 想上 985 工科)**:
> "那曲牧区藏族男生 410 分,想上 985 工科。
>
> **你能走的通道**:
> 1. **民族班**(清华 / 北大 / 复旦 / 上交 / 浙大 / 西交 / 武大 985,降 60-150 分)
> 2. **国家专项**(农牧区户籍,降 20-40 分)
> 3. **农牧区专项 / 边境县专项**(那曲 / 阿里 / 昌都,再降)
> 4. 上述 1+2+3 **三重叠加**
>
> 三重叠加下,**你 410 分能冲 985 工科**(西交 / 重大 / 兰大 / 川大),普通批汉族要 580+。
>
> 你的实际可达性 = **985 工科多通道叠加 + 出藏 / 留藏双轨**。**不知道 = 浪费,这是西藏考生最该重视的隐藏福利**。"

**真实案例(援藏二代 + 不知道援藏定向)**:
> "援藏二代汉族 540 分,父亲援藏教师驻藏 8 年。
>
> **你能走的通道(援藏定向)**:**北师大公费师范 / 武大法学 / 中政法 / 中央民大民族学 / 川大文学 / 西交电气 / 兰大医 / 重大工科** 等多所 985 + 援藏定向,降 20-50 分进入 + 服务期 5-8 年回藏 + 援藏接续岗位。
>
> **比普通批降 30-50 分进 985,且服务期回藏进高级编制岗位**(自治区机关 / 高级中学 / 自治区人民医院 / 中国电建西藏总部岗) —— **远好于普通批 985 冷门组**。
>
> **援藏二代家长一定要主动核实援藏定向资格 + 选择对口院校,这是独家福利不能浪费**。"

## Agent 处理意向的 5 步(西藏)

收到 L4.5 意向锚点后,**强制做这 5 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比(藏族 A 类 / 汉族 B 类 分别)
2. **核查身份资格** — 民族(藏族 / 汉族)/ 援藏二代(年限 + 在职状态) / 农牧区户籍 / 边境县户籍 → 决定可走的多通道
3. **打 3 档**(可达 / 边缘 / 不可达)— 考虑多通道叠加后的可达性
4. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子 + 留藏路径"权衡
5. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径 + 多通道叠加方案**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **遗漏多通道叠加**(漏说民族班 / 援藏定向 / 国家专项)— 西藏家长信息差大,要主动揭示

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨(西藏特有:留藏 vs 出藏)

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业 + 民族 / 援藏通道**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**(如改用多通道叠加)

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

**西藏特有的双轨**:
- **留藏 vs 出藏双轨**:留藏 = 藏大 / 藏民大 / 农牧学院 + 编制;出藏 = 民族班 / 援藏定向 985 + 服务期回藏
- **多通道叠加 vs 普通批**:多通道叠加(民族班 + 国家专项 + 农牧区专项)= 用低分上 985;普通批 = 按裸分上对应档次

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 清华民族班 / 想留藏当大医生 / 想出藏到一线大都市 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 民族 / 援藏身份审查 + 给替代多通道方案 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向 + 揭示多通道叠加福利,而不是机械执行意向**。
