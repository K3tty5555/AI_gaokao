# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(西藏视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。**西藏家庭背景比内地更复杂** —— 多了 **藏族 vs 汉族 + 援藏二代 vs 西藏长期户籍 + 牧区 vs 城里 + 民族干部 vs 农牧民** 等维度,**5 档家庭分类要叠加民族 + 援藏身份才完整**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入)+ 民族身份 + 援藏身份(L0.1)+ 户籍属性(拉萨城里 / 农牧区 / 援藏长期),按本文件的 5 档矩阵套对应策略。

---

## 档位 ① 体制内家庭(自治区机关 / 国企 / 事业编 / 民族干部)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。**西藏特殊性**:**自治区组织部 / 党校 / 各地市委 / 自治区民委 / 民族出版 / 自治区直属单位 民族干部** 比例极高(藏族干部 > 50%)。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低,**但有高原补贴 + 援藏接续福利**)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程 / 民族干部通道)
- **孩子考公 / 留藏当干部 几乎是默认路径**(父母期望 + 信息差小)
- 资源:**自治区机关人脉 + 民族干部网络 + 援藏接续岗位渠道**

**推荐策略**:
1. **强烈考公友好型**:**汉语言文学 / 法学(民族法方向) / 行政管理 / 政治学 / 经济学 / 会计学**(藏民大优先) — **西藏自治区考公竞争比 1:5-15(全国最低之一),藏族 + 汉语言文学上岸概率极高**
2. **藏族干部主路径**:**藏民大行政管理 / 政治学 / 民族学** = **自治区组织部 / 党校 / 各地市委优先选录主供校**
3. **留藏 211 选调生路径**:**藏大法学 / 民族学 / 中国少数民族语言文学(藏语)** = 选调生通道(西藏选调比内地选调上岸率高 5-10 倍)
4. **避免体制外才有出路的专业**:**CS 留藏 / 金融留藏 / 创业类** — 跟父母期待冲突,孩子毕业容易被劝回考公,**3 年损耗**;**留藏 IT / 金融出口极弱,撑不起家庭期待**
5. **特殊机会**:**民族班 + 援藏定向出藏 985 法学 / 经济学 / 政治学** + 服务期回藏 + 进自治区高级岗位

**典型 case**:
- **拉萨城里藏族 + 父母自治区机关公务员** → 孩子文科 460 分 → **推藏民大法学 / 行政管理** → 毕业进自治区组织部选调生路径,**家庭路径完美匹配**(藏民大是自治区组织部主供校)
- **失败 case**:同样家庭,孩子被推去藏大 CS → 毕业留藏 IT 出口窄,起薪 6-9w,家长不满"不稳定"劝其离职考公,**两年时间损耗 + 心理纠结**
- **援藏二代汉族 + 父亲援藏教师** → 孩子文科 540 分 → **推援藏定向 武大法学 / 北师大汉语言** → 服务期回藏自治区机关编制,**家庭援藏纽带 + 编制双赢**

## 档位 ② 专业人员家庭(援藏教师 / 援藏医生 / 工程师 / 律师)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。**西藏特殊性**:**援藏专业人员家庭** = 援藏二代独家 + 双重资源(原籍内地校友网 + 西藏服务期人脉)。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉 + 援藏接续)
- **行业拐杖最有力**:子承父业的成功率高
- **援藏二代** = 独特身份 + 援藏定向多通道
- 资源:**原籍 985/211 校友网 + 西藏服务期内的卫健委 / 教育厅 / 行业协会人脉 + 援藏接续岗位**

**推荐策略**:
1. **优先子承父业**:**援藏教师家庭 → 援藏定向师范(华东师大 / 北师大);援藏医生家庭 → 援藏定向临床(华西 / 北医民族班);律师家庭 → 援藏定向法学(中政法 / 武大法学)**
2. **行业相关延伸 + 援藏定向**:**援藏定向 + 同行业 985** = 服务期回藏对口岗位 + 父母资源直接复用
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)+ 援藏定向降分
4. **避免完全无拐杖的方向**:如金融头部(西藏没有金融行业资源 + 留藏对口弱)
5. **援藏接续岗位是隐藏福利**:服务期满后,援藏接续岗位让援藏二代在西藏体制内晋升优先

**典型 case**:
- **援藏教师母亲 + 内地原籍北师大** → 孩子文科 580 分 → **援藏定向 北师大汉语言文学公费师范** → 毕业回藏当中学语文老师 + 编制 + 援藏接续 → **母亲资源直接复用**(北师大校友网 + 服务期内自治区教育厅人脉)
- **援藏医生父母 + 都是临床医生** → 孩子理科 600 分 → **援藏定向 华西临床医学八年制 / 北医临床民族班** → 毕业回藏自治区人民医院 / 各地市三甲 → **典型子承父业路径 + 援藏接续 + 高原补贴**
- **援藏工程师父亲 + 中国电建系统** → 孩子理科 540 分 → **援藏定向 武大水利水电 / 西交电气** → 毕业回藏中国电建西藏 + 编制 + 项目奖金 → 父亲行业资源 + 服务期央企人脉直接复用

## 档位 ③ 私企管理 / 创业家庭(拉萨商人 / 西藏籍企业主)

**定义**:父母私企中高管 / 自主创业 / 企业主。**西藏特殊性**:**拉萨 / 各地市商人家庭(以汉族 + 西藏长期户籍为主)+ 藏族牧区企业主(藏药 / 牦牛肉 / 旅游民宿)+ 进藏经商家庭**。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- **私企家庭比例较低**(西藏经济结构 = 国企 + 体制 + 援藏接续 主导)
- 资源:**商业人脉(拉萨商圈 / 各地市商圈)+ 西藏特色产业(藏药 / 牦牛肉 / 旅游 / 民族手工艺)+ 部分继承家业**

**推荐策略**:
1. **可选商科 / 创业方向**:**经济学 / 国贸(头部院校 + 援藏定向)**;但**留藏金融 / 互联网出口弱**,出藏更优
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出藏 + 民族班 / 援藏定向 + 中外合作办学**:**藏族民族班 + 国外大学合作项目**(西藏籍学生有出国奖学金 / 民族文化交流项目)
4. **可走小众路径**:**艺术 / 设计 / 自由职业 / 创业 / 民族手工艺产业 / 旅游业 + 藏文化 IP**
5. **西藏特色产业接班路径**:**藏药学 + 农牧学院(回家继承藏药企业)/ 食品科学 + 农牧学院(继承牦牛肉 / 青稞酒企业)/ 旅游管理(继承家庭民宿 / 旅游公司)**
6. **避免:进体制内基层**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- **拉萨进藏经商家庭(年入 100-200w+)** → 孩子文科 580 分 → 推**援藏定向 武大经济 / 中山大学经济** → 毕业可进家族商业 + 拉萨市场;或继续读研出藏发展(家庭兜底厚)
- **失败 case**:私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**
- **藏族民宿家庭(林芝 / 香格里拉)** → 孩子文科 440 分 → 推**农牧学院旅游管理 / 食品科学(藏区食品)** → 毕业回家继承民宿 + 旅游 + 食品产业链 → **西藏特色产业接班路径**

## 档位 ④ 普通工薪家庭(自治区直属单位职工 / 拉萨工厂 / 各地市基层公务员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(**西藏工薪家庭收入低于内地 + 但生活成本低 + 高原补贴**)。**西藏特殊性**:**自治区直属单位 + 国企子弟 + 西藏银行 / 邮政 / 移动电信 子弟 + 中铁西藏 / 中国电建西藏 子弟**。

**家庭画像**:
- **抗风险能力中下**(失业 / 失败的代价大,但西藏体制内稳定)
- 信息差大,不太懂 985 / 211 / 民族班 / 援藏定向 多通道
- 通常希望孩子稳定 / 编制 / 不要折腾 / 留藏服务家乡
- 资源:**几乎无,需要孩子靠学校 + 努力跨阶级**;**但西藏特有的"民族班 + 国家专项 + 援藏定向"多通道是隐藏福利**

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(拉萨师专 / 藏大教育 / 藏民大教育)** = 高考分适中 + 直接编制 + 无学费 + 包分配回乡 + 高原补贴
   - **公费医学生(藏大临床 / 藏民大医学院)** = 编制 + 高原补贴 + 服务家乡
   - **农牧学院水利水电** = 进国家电网西藏 / 中国电建西藏 / 自治区水利水电勘测设计院 + 编制 + 项目奖金
   - **藏大电气工程 / 临床医学 / 法学 / 行政管理** = 211 + 编制铁饭碗
   - **藏民大行政管理 / 政治学 / 法学** = 自治区组织部主供校 + 留藏率 70-80%
3. **次推稳定就业型**:
   - **藏大藏学 / 民族学 / 中国少数民族语言文学(藏语)** = 自治区民委 / 民族出版 / 西藏官方媒体 编制
   - **农牧学院藏药学 / 农学 / 林学 / 动物科学** = 自治区农业农村厅 / 林草局 / 藏药企业 编制
4. **避免高风险方向**:
   - **金融 / 经济 / 工商管理 留藏**(西藏金融业 / 私企发达度低,**双非这些 = 死局**)
   - **CS 留藏**(留藏 IT 出口窄)
   - **生化环材**(必须读博才有出路,普通家庭撑不起)
   - **临床医学留藏 8 年长周期**(撑得起的话 OK,撑不起改医学影像 / 检验 / 护理)
   - **心理学 / 历史学 / 哲学**(本科出口窄,必须读研)

**典型 case**:
- **拉萨工薪家庭(自治区直属单位职工)** → 孩子(藏族 A 类)理科 380 分 → 推**农牧学院水利水电** → 毕业进国家电网西藏 / 中国电建西藏 + 编制 + 高原补贴(综合年薪 12-16w + 一辈子稳),**家庭逆袭**
- **日喀则工薪家庭(中国电建西藏子弟)** → 孩子文科 420 分(藏族 A 类)→ 推**藏民大行政管理 / 法学** → 毕业进自治区组织部 / 各地市委选调,**家庭命运改变**
- **林芝工薪家庭(汉族西藏长期户籍)** → 孩子理科 460 分 → 推**农牧学院食品科学(藏药 / 青稞)** → 毕业进西藏奇正藏药 / 5100 矿泉水 + 编制 + 项目奖金,留林芝家乡服务

## 档位 ⑤ 农牧 / 临工家庭(藏族牧民 / 农区藏族 / 临时工)

**定义**:父母务农 / 牧民 / 临时工 / 零散工作,家庭年收入通常 < 8 万。**西藏特殊性**:**藏族牧区 / 农区家庭比例较高 + 国家专项 + 民族班 + 农牧区专项 多通道叠加**。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解 + 多数父母不懂普通话精细化教育规划)
- 期待孩子跨阶级,跳出当前生活,**或回乡服务家乡 + 编制铁饭碗**
- 资源:**零,完全靠孩子自己 + 学校 + 西藏特有的多通道扶持政策**

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - **211 牌子 + 多校对口支援的藏大 = 农牧区藏族跨阶级首要工具**
   - **国家专项 + 民族班 + 农牧区专项 多通道叠加 + 出藏 985(川大 / 西交 / 中山 / 武大)** = 藏族牧区独家福利
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(拉萨师专双语方向 / 藏民大公费师范)** = 农牧区牧区子弟回乡执教 = 西藏专科最优解(免学费 + 包分配 + 编制 + 高原补贴 + 民族地区补贴)
   - **公费医学生(藏大医学院 / 藏民大医学院)** = 回乡当医生 + 编制 + 高原补贴
   - **国家专项 + 农牧学院** = 农牧区子弟回乡服务农牧业 / 水利 / 林业 + 编制
   - **藏大藏学 / 民族学 / 藏语方向** = 民族文化传承 + 自治区民委 + 编制
3. **避免长周期投入**:
   - 医学 8 年(撑不起,改医学影像 / 检验 / 护理 / 藏医学 5+3)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**(西藏独家):
   - **国家专项计划**:西藏农牧区 / 边境县 户籍,**985/211 名校多个专项指标 + 藏族民族加分 + 民族班** 三重叠加(分数比统招低 60-150 分)
   - **农牧区专项 / 边境县专项**:那曲 / 阿里 / 昌都 牧区户籍专属
   - **藏族民族班**:**清华 / 北大 / 复旦 / 上交 / 浙大 / 西交 / 武大 / 川大 / 兰大** 民族班对藏族考生开放(降 60-150 分)
   - **西藏内地班 出身的农牧区藏族**:已在内地中学读高中(北京 / 上海 / 成都 / 重庆 / 深圳西藏中学),师资远超本省 → 高考时仍按西藏籍 → 多通道叠加 + 跨阶级首选
   - **拉萨师专公费师范双语 + 农牧区** = 西藏专科最稳铁饭碗(免学费 + 包分配 + 100% 留乡 + 编制 + 双重补贴)

**典型 case**:
- **那曲牧区藏族家庭** → 孩子(藏族 A 类)理科 380 分 → 通过**国家专项 + 民族班 + 农牧区专项 三重叠加** → 进**西交 CS / 西电 CS** → **985/双非顶配 + 服务期 / 民族班** → **整个家族第一个 985**
- **阿里牧区藏族女孩** → 孩子(藏族 A 类)文科 350 分 → **拉萨师专公费师范(藏汉双语小学教育)** → 4 年免学费 + 毕业回阿里牧区 / 县城小学当老师 + 编制 + 高海拔补贴 + 民族地区补贴(综合年薪 8-12w),**最适合农牧区藏族家庭的"零风险"路径**
- **昌都农区藏族男生** → 孩子理科 410 分(藏族 A 类)→ 通过**国家专项 + 民族班** → **农牧学院水利水电** → 毕业进国家电网西藏昌都分公司 / 中国电建西藏昌都项目 + 编制 + 项目奖金 + 高原补贴,**家庭跨阶级**
- **山南农区藏族家庭** → 孩子文科 390 分(藏族 A 类)→ **藏民大公费师范(汉语言文学 / 中学语文)** → 毕业回山南各地市中学当语文老师 + 编制 + 援藏接续岗位

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 + 民族 + 援藏身份**(L2 + L0.1 + L0.2)→ **本文件主导 + 西藏独有维度**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(留藏考公 / 出藏读研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位 × 民族 × 援藏身份 是 #2 优先级**,**仅次于硬阻断,高于兴趣**。**西藏特有的"民族班 + 援藏定向 + 国家专项"多通道叠加** 是西藏家长最该重视的隐藏福利 —— **不用上,等于浪费**。

如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 西藏家庭决策的隐藏维度(必须问)

1. **想留藏还是出藏?**(决定留藏对口路径 vs 出藏民族班 / 援藏定向)
2. **能否接受高海拔(拉萨 3650m / 那曲 4500m+)?**(汉族家庭尤其重要,选 林芝农牧学院 / 咸阳藏民大 vs 拉萨藏大)
3. **服务期是否可接受?**(援藏定向有 5-8 年服务期 + 违约赔偿,家庭要算清楚)
4. **农牧区户籍 / 边境县户籍?**(决定农牧区专项 / 国家专项资格)
5. **援藏年限 + 父母在职状态?**(决定援藏定向资格 + 援藏接续岗位)
6. **家庭对"民族干部"路径的认同?**(决定藏民大 / 藏大民族学 / 民族班 路径)

**这 6 个问题在 L0 阶段必须问清**,否则后续推荐全白做。
