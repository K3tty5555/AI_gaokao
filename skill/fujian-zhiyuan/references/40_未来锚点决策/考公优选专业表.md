# 考公优选专业表(福建本地视角)

## 核心结论

**专业决定考公选岗范围**。福建家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**福建考公环境的特殊性**:**省考偏向沿海 + 厦门福州编制吃香 + 闽商家族 / 华侨网络 不一定走考公 + 闽北闽西山区基层岗"多但卷"** — 这套生态下,**汉语言文学 / 法学 / 经济学 / 公安专业** 是福建考公四大主力。

---

## 关键事实(2024 国考 / 福建省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关(**厦门海关 / 福州海关 是福建国考热门**)、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — **福建涉外特色** + 外交部、海关、商务部 → 约 2-3%

### 福建省考特殊性

- **福建省考 + 厦门 / 福州 / 泉州 市考**,**汉语言文学和法学并列考公第一专业**
- **福州 / 厦门 / 泉州 沿海三市公务员岗位**对**汉语言、法学、经济学、会计学** 要求高
- **闽北闽西山区基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)
- **福建省考特色**:**对台办 / 对外华侨办公室 / 平潭综合实验区 等涉外岗位多**(因福建对台对侨特殊地位),**法学(涉外方向)+ 国际经济与贸易 + 东南亚小语种** 在这条线上有差异化优势

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(福建本地的选调生定向计划基本只对 985/211 + 部分省内重点高校)
- 福建选调生定向高校:**厦门大学 + 福州大学 + 福建师范大学 + 华侨大学** + 部分出省 985/211
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **福建选调留闽 = 福州 / 厦门 / 泉州 三市起步 + 省直机关备选**,**比基层国考省考起点高 2-3 个层级**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(**福建警察学院** + 中国人民公安大学 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,福建无中南财法 / 西南政法 这类专业政法,**走出省 211 法学 或 厦大法学**

### 厦门海关 / 福州海关 — 福建独家国考热门
- **厦门海关** = 全国最热门海关之一(因厦门港 + 自贸区 + 跨境电商)
- **福州海关 / 平潭海关** 同样是热门岗位
- **对口专业**:**国际经济与贸易 / 经济学 / 法学 / 海关管理 / 英语 / 日语**
- **录取门槛**:岗位竞争比 100-300:1 起步,**福建本地考生有微弱地缘优势但仍要拼笔试 + 面试**

## 福建本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业
- **厦门大学法学** — 全国前 15,**法考通过率高,选调路径最优**,**福建省直 / 福州 / 厦门 法检系统主供给**
- **厦门大学经济 / 财政 / 会计** — 全国前 5,**厦门海关 / 福州海关 / 福建税务系统 主供给**(南派经管在福建本地考公认可度极高)
- **厦门大学新闻 / 中文 / 历史** — 985 + 综合岗对口
- **福州大学管理科学 / 经济学** — 福建工科本营兼考公友好
- **福建师范大学汉语言文学(公费师范生)** — 不是考公但是教师编制,**等同于考公友好**

### 双非 + 性价比考公专业
- **福建师范大学法学 / 汉语言** — 双非但**汉语言是省考王者**,毕业考公成功率高
- **闽南师范大学法学 / 汉语言** — 漳州本地认可,**漳州 + 厦门 + 泉州 基层岗友好**
- **华侨大学法学(涉外)/ 国际经济与贸易** — 央属牌子,**对台办 / 对侨办 / 厦门海关 / 福州海关** 涉外岗位差异化
- **集美大学财政 / 国贸 / 法学** — 嘉庚商科传统 + 海事认证背景,**集美区 / 厦门 编制对口**

### 公安系统专属
- **福建警察学院** — 本科,**公安联考路径**,**毕业进福建本地公安概率极高**(基层警察)
- **出省公安**:中国人民公安大学(北京)/ 中国刑事警察学院(沈阳)— 福建考生可冲

### 福建独家路径(其他省没有)
- **华侨大学涉外法学 + 国贸** → **对台办 / 对外华侨办公室 / 厦门 / 福州 / 平潭 自贸区 涉外公务员岗**
- **福建师范大学闽南语 / 闽语方言学** → **对台办闽南语翻译岗 / 福建广电涉台节目岗**(独家)
- **集美大学航海技术 + 海事认证** → **海事局公务员岗**(海事局是福建独家热门 — 厦门海事局 / 福州海事局 / 泉州海事局)

## 典型 case(供 agent 引用)

### Case A(逆袭路径):
- 漳州工薪家庭考生 + 540 分文史类 + **普通家庭**
- 家长本想报"国际经济与贸易"(听起来高大上)
- **改报闽南师大汉语言文学**,毕业当年考上漳州市直某机关公务员,**家庭命运改变**

### Case B(选调路径):
- 福州考生 + 650 分文史类 + 中产家庭
- 家长想报"金融"(厦大经济学院)
- **改报厦大法学**,**毕业获得厦大选调生资格,直接进福建省委组织部**,起点远超经济学就业

### Case C(海关路径):
- 厦门考生 + 615 分物理类 + 公务员家庭
- 父亲是厦门海关公务员,孩子想接父亲衣钵
- **报厦大经济学 / 国贸 + 英语强化** → 毕业考上厦门海关,**对口家族体系 + 厦门户口稳定**

### Case D(失败路径):
- 泉州考生 + 580 分理科 + 普通家庭男生
- 家长想"考公兜底"
- **报了福师大计算机**(以为计算机考公也行)
- **毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**

### Case E(误区路径):
- 福建家长以为"行政管理"是考公专业 — **错**
- 公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**

### Case F(独家路径):
- 福建莆田华侨家族二代 + 555 分历史类 + 中产家庭
- 家里在马来西亚有产业 + 想留闽 + 想做对台对侨工作
- **推华侨大学法学(涉外)+ 闽南语强化** → **毕业考福建对外华侨办公室 / 平潭综合实验区涉外岗**,**独家通道**(其他省考生没法走)

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(福建 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放(福建警察学院主供给)**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对厦大 / 福大 / 福师大 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是福建家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**福建分数线低 → 考公也容易**" — 错。**福建省考竞争跟全国接近**,**沿海三市岗位卷,山区基层岗反而相对宽**

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是福建家长被严重低估的考公王者**。

**福建特色额外提醒**:
1. **闽商家族 / 华侨家族 → 不一定要走考公**,接班企业 / 走涉外路径 ROI 更高;**只有体制内 / 工薪 / 农村家庭** 才是考公的核心目标群体
2. **想留沿海 + 高潜力 → 选调生路径**(厦大 / 福大 / 福师大 / 华大)
3. **想留山区 / 县城 → 公费师范 + 福建警察学院** 比国考省考更对口
4. **想吃涉外红利**(对台办 / 海关 / 平潭自贸区)→ **华大涉外法学 + 国贸 + 英语 / 闽南语 / 东南亚语** 是独家路径
