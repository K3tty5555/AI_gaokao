# 福建农林大学(福建农林,FAFU)— 双非但菌草学全国第 1

## 一句话定位

**福建农林本省主力**,双非但**双一流学科:植物保护**,**菌草学(林占熺院士)全国第 1 + 援外 100+ 国家**(《山海情》原型),**林学 / 园艺 / 茶学 / 食品** 福建领先。**学农林 / 食品 / 茶学 / 林业 / 农业农村系统编制** → 福建农林是首选 + 唯一对口。**想做工科 / 商科别来**。

---

## 真实地位

- **双非 + 福建省政府 + 国家林业和草原局 + 农业农村部共建**,**双一流学科:植物保护**(全国前 20),综合排名双非中段(全国 130-180 名段)。
- **福建本省地位**:**福建农林农学第一**(福建唯一以农林为主体的省属重点),**福建农业农村系统 + 林业系统 + 茶产业 编制路径独家通道**。
- **同档对比**:跟江西农大 / 安徽农大 / 云南农大 同档 — 双非农林,**省内地位高,出省牌子认可度一般**;**菌草学独家全国第 1** 是福建农林差异化招牌。
- **校园结构**:**金山校区**(主校区,福州金山,**校园面积大 + 农林试验田 + 生活成本低**)+ 旗山校区(部分学院)+ 安溪校区(茶学方向,**位置在安溪铁观音产区**)。
- **学风农林务实派** + 男女比相对平衡 + 校园面积全省最大(适合养植物 / 跑步 / 安静读书)。

---

## 福建物理类录取位次区间

参考近 5 年掌上高考 + 福建一分一段表:

- **强势组(植物保护 / 园艺 / 食品科学 / 计算机)**:全省 **35,000-45,000 名**。
- **主流组(林学 / 农学 / 风景园林 / 动物科学)**:全省 **45,000-55,000 名**。
- **中段组(冷门农林 / 部分文科)**:全省 **55,000-70,000 名**。

**段位定位**:福建物理类 **省排 70,000 名内可冲福建农林**,**45,000 名内可挑王牌植保 / 园艺 / 食品组**。**以一分一段表反查为准**。

## 福建历史类录取位次区间

历史类专业组少(主要经管 / 部分文科),全省 **15,000-25,000 名**。**福建农林历史类不是强项,文科考生避开**。

## 性价比专业(独家或行业对口)

- **菌草科学**:**全国第 1 + 唯一**,**林占熺院士的菌草技术先后输出到斐济 / 巴布亚新几内亚 / 卢旺达 / 莱索托 / 中非 等 100+ 国家**,**国际项目机会多 + 联合国援外项目对口** + 国家形象工程,**对国际农业 / 援外感兴趣的考生 → 福建农林独家路径**。
- **茶学(食品科学茶学方向)**:**武夷山 / 安溪 / 福鼎 茶企校招直供**(八马茶业 / 大益 / 福鼎白茶集团),**福建茶产业本科教育第一**,**家在闽北闽南茶乡的考生 ROI 高**。
- **林学**:**福建林业系统编制路径**(福建省林业局 + 各地林业局 + 国家林草局),**留闽进林业部门铁饭碗**。
- **园艺(花卉 / 蔬果方向)**:**福建花卉 + 漳州蔬果 + 厦门花博会** 产业对口,沿海农业经济活跃。

## 坑专业 / 慎选(在福建农林里相对弱)

- **非农林相关的工科 / 经管 / 计算机**:**福建农林工科 / 商科 / IT 边缘**,**学这些直接选福大 / 厦大 / 华大** 更优,**福建农林 CS 跟一般双非没差**。
- **法学 / 中文 / 新闻**:**农林大学的文科是边缘**,**学文科选福师大或厦大** 更对口。
- **东方学院(独立学院)**:**民办独立学院,跟福建农林本部牌子有差**,**报志愿别看错代码**。
- **动物医学(兽医方向)**:**学制长(5 年)+ 出路相对窄**(主要是宠物医院 / 福建禽业 / 福建畜牧),**对临床医学有兴趣建议直接学医,不要走兽医**。

## 关键提醒(填报陷阱)

1. **金山 vs 安溪 — 校区差别**:
   - **金山主校区**(福州市仓山区金山)= 主体,**校园面积大** + 福州市区 30 分钟
   - **安溪校区**(2018 启用,茶学方向)= **位置在泉州安溪铁观音产区**,**学茶学的部分专业在这**,生活配套不如金山
   - **报志愿要看清专业组对应校区**
2. **专业名称陷阱 — 农学 vs 园艺 vs 林学 vs 植保**:
   - **农学** = 大田作物(水稻 / 小麦)+ 作物育种,**福建农业不是大田主导**,出路一般
   - **园艺** = 蔬菜 / 水果 / 花卉,**福建漳州 / 漳浦 / 厦门 同安 蔬果产业对口**
   - **林学** = 森林 / 林业系统编制,**福建林业系统对口**
   - **植物保护** = **双一流学科**,做农药 / 病虫害防治 + 研究方向
3. **菌草科学是独立专业**:**全国唯一**,但**录取分相对较低**(冷门 + 大众认知少),**真懂农林国际项目的考生 → 这是性价比之王**。
4. **茶学方向在安溪校区**:**学茶学要做好在县城读 4 年的准备**(安溪不是大城市,生活配套有限),**优势是茶产业实习对口**。
5. **服从调剂**:农林组分化没那么大,但要查清是不是你能接受的农林方向。
6. **东方学院**:**民办独立学院**,**代码不同**,**别看错**。

## 毕业出口(2024 数据)

- **留福建就业**:约 60-65%(**福州占 ~25%,泉州 / 漳州 ~15-20%,闽北闽东 ~15%**,留闽率比一般双非高,因为农林系统主要在福建)
- **出省(长三角)就业**:约 15-20%
- **考研 / 读博**:约 25-30%(保研率 ~12-15%,**农林学科考研 985 / 中农 / 南农 相对容易**)
- **出国 / 海外援外**:约 5-10%(**菌草援外项目 + 国际农业组织** 独家路径)
- **进央企 / 国企概率**:约 15-20%(福建农垦 / 福建林业系统 / 福建茶企国企化部分)
- **进编制(林业局 / 农业农村局 / 食药监)概率**:约 25-30%(**福建涉农编制对口路径强**)
- **起薪范围**:农林系统编制 6-10w + 福利,茶企 / 食品企业 8-12w,园林设计 10-15w,菌草援外项目 15-25w(包食宿)。

## 同档对比

| 维度 | 福建农林 | 南农 / 华农 | 福师大(非师范) | 集美大学 |
|---|---|---|---|---|
| 综合排名 | 双非 | **211 / 985** | 双非 | 双非 |
| 农林学科 | **福建第一(植保双一流)** | 全国顶级 | 弱 | 中(水产强) |
| 福建本地认可度 | **农林系统第一** | 中 | 师范第一 | 海事第一 |
| 菌草 / 茶学 | **菌草全国第 1** + 茶学强 | 强 | 弱 | 弱 |
| 校园面积 / 生活成本 | **极大 / 低** | 中 | 中 | 中 |

**简单结论**:**学农林 / 食品 / 茶学 / 林业留闽 → 福建农林首选**;**分数够 211 → 南农 / 华农 学农林牌子更硬**;**学水产 / 渔业 → 集美大学**;福建农林独家是**菌草援外路径**。

## 适合谁

- 福建物理类 **省排 35,000-70,000 名** / 历史类 **15,000-25,000 名** 的考生。
- 学**农学 / 林学 / 园艺 / 植物保护 / 食品科学 / 茶学**的学生。
- **想去福建林业局 / 农业农村局 / 食药监 / 自然资源系统 编制路径** → 福建农林对口。
- **家在闽北 / 闽南 / 闽东茶乡(武夷山 / 安溪 / 福鼎 / 政和)** + 想接班茶产业 / 农林产业。
- **对菌草援外项目 / 国际农业有兴趣 + 想做联合国援外项目** → 福建农林独家路径。
- 喜欢**校园面积大 + 安静 + 农林试验田生活 + 性价比高(学费便宜 + 生活成本低)**的考生。
- **不抗拒农林行业 + 求稳定 + 求编制**的工薪 / 农村家庭。

## 不适合谁

- **想学工科 / 商科 / CS / 法学**:**福建农林的非农林专业跟一般双非没差**,**直接选福大 / 厦大 / 华大 / 福师大** 更优。
- **想去北上深大厂 / 互联网 / 金融**:**农林大学牌子不通用**,**选厦大 / 福大或外省 211** 更对口。
- **闽商家族二代想接班做生意**:**学经管去厦大或华侨大学** 更对口。
- **抗拒农林行业 / 觉得"农大丢人"**:**别来福建农林,在这里学非农林是浪费**。
- **不想留闽 / 想出省北上深**:**福建农林牌子在出省竞争中弱于一般 211**,出省找工作吃亏。
