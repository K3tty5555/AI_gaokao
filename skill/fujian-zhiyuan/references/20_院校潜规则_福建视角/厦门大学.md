# 厦门大学(厦大,XMU)— 福建独苗 985,南派经管 + 海洋顶级

## 一句话定位

**福建本地"心理上限"高校**,综合排名 Top 20 985,**经济 / 会计 / 统计 / 海洋 / 化学 / 法学** 全国前 5-15,南派经管重镇 + 中国最美校园之一,**对福建本省 = 中山大学对广东本省 的地位**。纯工科和医学不是首选。

---

## 真实地位

- **综合 Top 20 985**(常年 15-23 名波动),福建唯一部属 985,跟中山 / 武大 同档。
- **南派经济学/会计学重镇**:王亚南经济研究院 + 管理学院 + 会计系,跟人大 / 复旦 / 上财 抗衡,**校招投行 / 四大 / 大厂金融 直供**。
- **沿海地理 + 海洋学科顶级**:海洋与地球学院全国前 3,翔安校区紧邻海边,出海实习方便。
- **三校区结构**:**思明校区**(本部,白城海滨,凤凰木 + 嘉庚建筑,本科文科 / 经管 / 理学主体)/ **翔安校区**(海洋 / 生物 / 医学 / 环境 / 部分工科 + 国际学院新址)/ **漳州校区**(主要是嘉庚学院 — 民办独立学院,跟厦大本部不是同一牌子,**报志愿务必看清代码**)。
- **校园美**+**学风自由散漫**+**南方滨海气质**,文艺青年聚集地。

---

## 福建物理类录取位次区间

参考近 5 年掌上高考 + 福建一分一段表:

- **顶级组(经济金融 / 会计 / 计算机 / 临床医学 5+3)**:全省 **1,500-3,500 名**。
- **主流组(理工科 / 文科 / 海洋 / 化学)**:全省 **3,500-6,500 名**。
- **中段组(部分理工 / 农林相关 / 冷门组)**:全省 **6,500-9,000 名**。

**段位定位**:福建物理类 **省排 9,000 名内可冲厦大**,**3,500 名内可挑王牌经管 / 计算机**。**以一分一段表反查为准**。

## 福建历史类录取位次区间

历史类主要法学 / 中文 / 经管 / 新闻,全省 **300-1,500 名**。**经管法实验班录取压一些外省 985 弱组**。

## 性价比专业(顶尖学科 + 录取相对宽)

- **海洋科学 / 海洋技术**:全国前 3,**翔安校区出海实习 + 自然资源部 / 国家海洋局 编制对口**,录取分比经管低一截,沿海地理优势强。
- **化学 / 化工**:全国前 10,**卢嘉锡 / 蔡启瑞院士传承**,录取分相对宽,理工科冲厦大的好选择。
- **统计学**:跟金融经济同院系但录取分稍低,**长三角金融机构 / 互联网数据岗** 通吃。
- **国际学院(翔安)/ 嘉庚学院(漳州)**:**别报错**,嘉庚学院是独立学院,牌子跟本部差很多。

## 坑专业 / 慎选(在厦大里相对弱)

- **机械 / 电子 / 自动化 / 航空航天**:厦大纯工科边缘,**学硬工科直接选福大化工 / 出省工科 985**(华南理工 / 哈工大)。
- **农林相关**:厦大几乎没有,**学农林选福建农林**。
- **临床医学(传统 5 年制)**:**新办医学院**,比中山医 / 川大华西 / 协和 弱,**学医建议出省或选福建医科**。
- **嘉庚学院(漳州)**:**民办独立学院**,跟厦大本部牌子有差,**录取分低很多但性价比争议大**。
- **马克思主义理论 / 公共管理**:综合性 985 通病,毕业改行率高。

## 关键提醒(填报陷阱)

1. **思明 vs 翔安 vs 漳州 — 三校区差别巨大**:
   - **思明**(本部)= 文科 / 经管 / 理学主体 + 风景顶级,大三大四多在本部
   - **翔安**(2012 年启用)= 海洋 / 生物 / 医学 / 环境 / 国际学院,大一大二多在翔安
   - **漳州**(隔海)= 嘉庚学院(独立学院,**不是厦大本部**)
   - **报志愿看清专业组对应校区**,部分专业组前两年在翔安住宿
2. **物理类专业组分化大**:王牌组(经管 / 海洋 / 化学)与中段组(部分理工 / 文科)录取位次差 3,000+ 名,**勾服从前查清组内含哪些专业**。
3. **服从调剂**强烈建议勾,但要预想"组内最差专业" — 如某组含图书情报 / 公共管理,愿意接受吗?
4. **嘉庚学院(漳州)别看错代码**:**民办独立学院,跟厦大本部不是一回事**,学费贵 + 牌子差。

## 毕业出口(2024 数据)

- **留福建就业**:约 35-40%(厦门占大头 ~25%,福州 / 泉州 ~10-15%)
- **出省(北上深 + 长三角)就业**:约 35-40%(**经管牌子全国吃香**,北上深大厂 / 投行 / 四大 校招直供)
- **考研 / 读博**:约 25-30%(保研率 ~25%,985 中段)
- **出国**:约 10-15%(**南派经管国际化路径强**,港新 / 北美 留学率高)
- **起薪范围**:经管金融 18-35w,CS / 软工 20-30w,海洋 / 化学 12-18w,临床医学规培期 10-15w,文科考公 10w+。

## 适合谁

- 福建物理类 **省排 1,500-9,000 名** / 历史类 **300-1,500 名** 的考生。
- **想留厦门 / 留闽就业**的考生 → 厦大就是天选。
- 学**经管 / 金融 / 会计 / 海洋 / 化学 / 法学 / 文科**的学生。
- **想去北上深 + 长三角金融业 / 投行 / 四大** → 厦大经管牌子全国吃香。
- 喜欢**滨海气质 + 自由学风 + 文化氛围**的文艺青年。

## 不适合谁

- **铁了心要学硬工科(机械 / 航空 / 兵器)**:对应工科强校(华南理工 / 哈工大 / 北航)更对口。
- **想学医做三甲医生**:厦大医学院弱于老牌医学院校,**学医优先福建医科 / 出省 985 医学**。
- **想做老师走编制路径**:厦大不是师范校,**留闽教师选福师大公费师范**更直接。
- **学航海 / 水产 / 渔业**:厦大没这些,**选集美大学**。
