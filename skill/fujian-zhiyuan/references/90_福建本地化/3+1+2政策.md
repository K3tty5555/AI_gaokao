# 福建 3+1+2 高考政策

## 核心结论

**福建是全国第三批新高考改革省份**(2018 年启动选科,**2021 年首届 3+1+2 高考**,跟湖北/湖南/广东/江苏/河北 同批)。**总体规则跟湖北/江苏一致**,但福建有几个**重要本地特殊性**值得注意:**1 所 985(厦大)+ 1 所 211(福大)+ 央属华侨大学 + 闽台合作办学独家通道 + 闽商沿海经济**,跟内陆省份的志愿逻辑有显著差异。

## 关键事实

### 考试结构(同湖北/江苏)
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类** — 选物理为首选的考生
- **历史类** — 选历史为首选的考生
- **两类完全分开排名、分开录取**,**互不影响**
- 福建物理类报考人数约 60-65%,历史类约 35-40%(沿海福建文科氛围相对偏强,历史类比例略高于工业大省)

### 院校专业组(同湖北/江苏)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **福建本省高校(厦大 / 福大 / 华侨 / 福师大)在福建拆出多个专业组**,选错组差几十名位次

### 填报志愿数量
- **福建本科批 40 个志愿**(跟江苏一致,**比湖北/湖南/广东的 45 个少 5 个**)
- 专科批 40 个

## 福建特殊性(关键!!)

### 1. 福建 985/211 数量稀缺(只有 2 所部属高校)

- **1 所 985**:**厦门大学**(沿海综合性顶级,经济/会计/海洋/化学顶级)
- **1 所 211**:**福州大学**(化工/管理科学顶级,福建工科本营)
- **1 所中央部委直属(非 211)**:**华侨大学**(国务院侨办直属,华侨港澳台招生通道)
- **省属重点**:福建师范大学 / 福建农林大学 / 集美大学 / 福建医科大学 / 福建中医药大学 / 闽南师范大学

**对比江苏 / 湖北**:
- 江苏 11 所 211,湖北 7 所(华科/武大/华师/中南财/中地大/华农/武理工)
- **福建本省可选的 985/211 数量是全国倒数**(跟海南/西藏/宁夏 同档)
- **结果**:中分考生(550-590 物理类)被挤压到"出省冲外省 211 / 留闽读华侨/福师大/集美"的二选一

### 2. 闽台合作办学独家通道

- **福建多所高校跟台湾高校有联合办学项目**(华侨大学 / 福州大学 / 福建师大 / 集美大学 / 厦门理工 / 仰恩大学 等)
- **典型项目**:
  - **闽台 4+0 项目**(全程在福建,但课程引入台湾高校 / 共同颁发学位)
  - **闽台 3+1 项目**(3 年福建 + 1 年台湾)
  - **闽台 2+2 项目**(2 年福建 + 2 年台湾)
- **特点**:
  - **学费比普通班贵**(2-3 万/年起,部分到 5 万+)
  - **录取分一般比同校普通组低 20-50 分**(性价比通道)
  - **课程引入台湾教学体系**,毕业后到台湾深造 / 闽台外贸路径加分
- **适合**:对台湾高校感兴趣 + 家庭能撑高一点学费 + 想做闽台外贸/旅游的考生

### 3. 华侨大学的特殊地位

- **华侨大学(华大)**是**国务院侨务办公室直属**的中央部属高校(注意:**不是 985 也不是 211**,但牌子是"中央部委直属")
- **历史使命**:为海外华侨华人 / 港澳台 / 外籍学生提供高等教育
- **生源结构特殊**:**港澳台 + 海外华侨生比例约 30%+**,氛围国际化(类似暨南大学)
- **双校区**:泉州本部 + 厦门校区(厦门校区位置极佳)
- **王牌专业**:工商管理 / 国际经济与贸易 / 土木工程 / 法学 / 新闻传播
- **特色路径**:**留闽 / 留东南亚(印尼/马来西亚/菲律宾华侨网络)/ 港澳实习** 三大独家就业通道
- **录取分**:物理类约省排前 1.5w-2w 名(强势组接近 211 中段)

### 4. 福建沿海经济的产业特点

- **GDP 大省**(2024 年福建 GDP 排名全国第 8,人均排名前 5)
- **核心产业**:
  - **纺织鞋服**(晋江 / 石狮 / 福州 — 安踏 / 特步 / 361° / 鸿星尔克 / 七匹狼 / 利郎 大本营)
  - **电子信息**(福州马尾 / 厦门 / 泉州 — 京东方 / 联想 / 戴尔 / 富士康 / 厦门光电)
  - **石化**(福建炼化 / 漳州古雷 / 福建联合石化)
  - **物流海运**(厦门港 / 福州港 / 泉州港 — 全国前列港口集群)
  - **旅游业**(武夷山 / 鼓浪屿 / 土楼 / 平潭)
  - **茶产业**(武夷岩茶 / 安溪铁观音 / 福鼎白茶 — 全国茶大省)
- **闽商网络全球化**:**福建华侨华人遍布东南亚 / 北美 / 欧洲**,**海外闽商资产规模全国前列**(尤其晋江 / 石狮 / 福清 / 莆田 / 长乐 等地侨乡)
- **就业意义**:**福建本省考生留闽就业率 70%+**(跟广东留粤、湖南留湘 类似),**留闽路径需要的是"本地认可度高的院校"而不是"出省牌子"**

### 5. 福建本省考生留闽就业率高(关键!)

- **福建大学生留闽就业率约 70-75%**(全国前列,接近粤鲁川等本省就业大省)
- **为什么**:
  - **闽商家族网络发达**,本地"内推"机会多
  - **沿海生活成本相对友好**(房价比北上深 / 杭苏低 30-50%)
  - **闽南语 / 福州话文化壁垒**让外省人融入难,反过来让本地人留闽友好
  - **气候 / 饮食 / 海鲜文化** 让福建人"恋家程度"高
- **结果**:**福建本省院校(厦大/福大/华侨/福师大/集美/福建医科) 的本地认可度 + 就业网络 远高于"低段位外省 211"**
- **决策推论**:**如果孩子明确想留闽,优先填本省强校;如果想出省/出国,才考虑外省 211**

## 易错认知(agent 要纠正用户的)

- **"福建只有 1 所 985,所以 985 容易上"** — **严重错误**。**厦大 在福建本省录取分极高**(物理类省排前 3500-5000 名),不比湖北/江苏 985 容易。福建考生上 985 总名额(本省 + 外省)反而比湖北少。
- **"华侨大学不是 211,层次低"** — **半错**。**华大是中央部委直属**,牌子认可度比一般双非高;**留闽 / 留东南亚 / 留港澳 路径独家**,**比"末段外省 211"在福建本地反而吃香**。
- **"集美大学 / 福师大 是双非,不如外省 211"** — **半错**。**留闽就业、福建编制路径、闽商家族网络** 这三条上,**集美航海 / 福师大语言学 / 福师大教育学 在福建本地的实质 ROI 高于很多外省一般 211**。
- **"40 个志愿都是学校,选哪个学校都行"** — **严重错误**。**福建是 40 个院校专业组,且每个组的服从调剂规则只在组内生效**。
- **"闽台合作办学就是低分上同一所学校"** — **半对**。**闽台合作录取分确实低 20-50 分,但学费贵 2-3 倍 + 课程体系不同**,**家庭撑得起 + 想走闽台路径 才划算**,普通家庭慎选。
- **"福建分数线低 = 福建容易"** — **错**。**看位次不看分数**。福建考生少但 985/211 名额按比例看也少,整体竞争跟湖北接近。

## 关键提醒(agent 必须强调)

1. **福建 40 个志愿**(不是湖北/湖南/广东的 45 个,跟江苏一致)
2. **看位次不看分数**(各省卷子 / 试题不同,跨省比较无意义)
3. **再选科目限制**(必选化学 / 必选政治 等)是硬约束
4. **沿海与山区高中层次差异**(出分前估算位次时要考虑)— 福州 / 厦门 / 泉州沿海高中第 100 名 ≈ 闽北闽西山区高中前 30 名
5. **闽台合作办学组单独成组,学费明显高**(2-5 万/年),普通家庭看清楚再填
6. **华侨大学有面向华侨/港澳台的特殊招生通道**,本省普通考生走的是普通批,不要跟侨生通道混淆
7. **留闽 vs 出省 决策很重要** —— 想留闽就重视本省强校的本地认可度,想出省/出国 才优先看外省 211 牌子

## 福建近年志愿填报常见踩坑事件(供 agent 引用)

### 踩坑 1:错把"嘉庚学院 / 协和学院 / 阳光学院" 当本部
- 厦大嘉庚学院(漳州)/ 福师大协和学院 / 福大阳光学院 / 福建农林东方学院 / 集美诚毅学院 — **都是民办独立学院,不是本部**
- **学费贵 2-3 倍 + 录取分低 60-100 分 + 牌子完全不同**
- **每年都有 100+ 福建考生因为没看清楚代码**,以为报的是本部,实际录取到独立学院

### 踩坑 2:闽台合作办学不知道学费高
- 闽台 4+0 / 3+1 / 2+2 项目学费 2-5w/年(部分到 5+w/年),**比同校普通组学费高 4-10 倍**
- 工薪家庭报志愿时**没看学费 → 录取后家庭破产**

### 踩坑 3:福师大公费师范的 6 年原籍服务
- 公费师范要求**服务 6 年回原籍** — 部分考生 / 家长不知道这个硬约束
- **闽北闽西山区考生 + 不想回老家** → 公费师范成枷锁,违约要赔学费 4-6w + 影响考公考编

### 踩坑 4:航海类视力不达标也报了
- **集美大学航海 / 轮机** 体检 + 视力要求严
- 部分考生 / 家长不知道,**视力 4.3 也报了航海** → **录取后体检退档**

### 踩坑 5:服从调剂调到组内最差专业
- 福建院校专业组分化大(尤其厦大 / 福大),**组内 5-15 个专业 录取分差几千名位次**
- 不查清组内含什么就勾服从 → 被调到图书情报 / 公共管理 / 哲学 / 材料 / 化工 等冷门专业

### 踩坑 6:把"分数"当指标而不是位次
- 福建近年分数线波动大(2021 物理本科 423 / 2024 物理本科 449)
- **"我家孩子考了 500 分,跟去年 500 分对应的学校能上吗?"** — 错!**500 分在不同年份对应的位次完全不同**

### 踩坑 7:闽南语 / 闽语 跟北方话考生的"听力 + 表达"差异
- **部分专业的英语口语面试** — 闽南语母语考生英语口语 / 普通话发音 略有"塑料感",**部分外语类专业 + 师范类专业 面试有这个隐性门槛**(如对外汉语 / 部分翻译方向)

## 福建出分前后的常见心理 / 决策节奏

### 出分前(模考期 1 月 - 5 月)
- **闽商家族**:忙生意 / 跨年订单 + 不太管孩子高考(默认厦大 / 出国)
- **工薪家庭**:**焦虑指数全省最高** + 信息差大 + 怕选错专业
- **农村家庭**:基本不参与 + 等出分再说

### 出分日(6 月 25 日左右)
- **沿海三市**(福州 / 厦门 / 泉州)出分日家长群里**爆炸式咨询**
- **山区家庭**:多数家长当晚才得知分数

### 填报志愿(6 月 30 日 - 7 月 5 日左右)
- **6 天紧急决策窗口** — 比湖北 / 江苏 略短
- **闽商家族二代**:多数家庭 5 天内决定 + 部分会咨询知名规划师 / 厦大 / 福大 招办
- **工薪 / 农村家庭**:**决策最纠结** + 容易被骗交"志愿规划费"(2-5w 一单)+ 信息差最大

### 录取结果(7 月 15 日 - 8 月 10 日)
- **本科批 7 月下旬开始投档**
- **8 月初提前批结果(公费师范 / 警校 / 航海类)出**
- **本科一批 8 月中旬基本结束**
