# 用户意向冲突 — Reality Check 金句库(福建版)

很多福建家长 / 考生有具体的意向("想上厦大"、"非厦门福州不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **福建特色**:**闽商家族二代不要套用工薪家庭逻辑** — 闽商家族孩子去考公基层 = 浪费家族资源;**工薪家庭孩子去冲闽商爱报的"金融国贸" = 双非死局**

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 480 分要厦大 / 565 分要厦大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(福建 565 分,意向厦大)**:
> "厦大主流组在福建物理类 3,500-6,500 名。你 18000 名,差 1.2 万名,**厦大没戏**。
>
> 但你能上福州大学(化工 / 管理科学全国前 10-20)+ 华侨大学(央属 + 涉外通道)+ 集美大学(航海 / 水产)— 这三所留闽就业,**福建本地国企 / 体制内招聘里跟厦大冷门组校友地位差不多**(都是'福建本地强校 + 留闽同档')。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(福建 590 分,意向厦大)**:
> "厦大你 590 能擦边冲 — 但只能进生命科学 / 化学 / 哲学 / 历史 等冷门组。**985 牌子 + 福建本省高分 + 生化环材** = 双重坑。
>
> 同分能上的福州大学化学工程(全国前 10 + 双一流学科,福建联化 / 万华 / 宁德时代 校招对口)出来对口程度更高 + 留闽工程口稳定。冲厦大留一个心理慰藉位即可。"

**真实案例(福建 575 分,意向厦大文科)**:
> "厦大文科 575 能擦冲 — 但只能进图书情报 / 公共管理 / 哲学 等。**985 + 文科冷门 = 毕业改行率高**。
>
> 同分能上的福师大公费师范汉语言(B+ 全国前 20 + 留闽教师编制 + 免学费 + 服务 6 年)出来直接编制。**家庭工薪 → 公费师范 ROI 顶配,冲厦大留一个心理慰藉位即可**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [厦大医学院八年制 / 出省协和华西])
> - 撑不起 → 走 **[替代短路径]**(如 [福医医学影像 / 检验 / 护理 — 4 年本科直接进福建三甲技师岗]),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(福建普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-9k**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推厦大医学院八年制 / 福医临床本博连读,长期天花板高(福建省立 / 协和 / 厦大附一)。
>
> 撑不起 → **建议口腔(5 年本科直接进诊所,起薪 8-15w,早 3 年挣钱)**,或者**福医医学影像 / 检验技术(4 年本科进福州 / 厦门 三甲技师岗,起薪 6-10w + 编制)**,或者**福医护理(本科 + 出国海外护士 = 闽商华侨网络兜底,起薪 1.5-3w 美金)** — 后三条都是福建工薪家庭"想学医但撑不起 8 年"的最优解。"

**真实案例(福建闽北山区农村 + 想学医)**:
> "你家在三明 / 南平山区,父母年收入加起来不到 8w,要供你学医 8 年是绝路。
>
> **直接劝退临床医学**。
>
> 替代路径:
> 1. **福医护理本科** → **福建三甲护士编制 + 海外护士移民通道**(闽商华侨网络兜底)
> 2. **福医医学检验 / 影像技术** → 4 年本科进福建县市三甲,起薪 6-8w + 编制
> 3. **福建中医药大学中医学** → 5+3,但中医本科可进基层中医院 + 闽南中医诊所,**农村家庭 5 年比临床 8 年早 3 年挣钱**
> 4. **如果还想冲临床** → 国家专项 + 福医临床(分数线降 30 分),但要做好"30 岁前不挣钱" 的心理准备"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非厦门不去" / "非福州不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留北京没意义,要去西工大),**要灵活退一步**。"

**真实案例(福建厦门户籍 + 经管方向 + 580 分)**:
> "你只留厦门,这分数 18000 名,厦大主流组够不上。
>
> **留厦最稳路径**:
> - **集美大学嘉庚商科**(财政 / 国贸 / 工商,留闽厦门口碑) + 父母厦门人脉资源 + 福建银行 / 兴业 / 厦门金融科技 校招 → 留厦稳定中产路径
> - **华侨大学厦门校区国贸 / 涉外法学**(在集美区,中央部委直属) + 跨境电商 / 涉外法律事务 → 留厦门 + 走外贸路径
>
> 不要为了'外省 985 牌子'去东北大学 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 户口没了**,**毕业回厦门反而比集美大学还吃亏**(因为集美大学校友网在厦门密度大)。"

**真实案例(福建闽北南平 + 想留福州)**:
> "你 555 分物理类,想留福州。
>
> 福大主流组够,**福州大学是天然选项**(福建工科本营 + 福州 4 年校友网 + 留福州工程口稳定)。
>
> 别为了"出省 211 牌子" 去甘农大 / 内蒙工业大学 等冷门 211 — **回福州找工作没人认你这个外省双一流**,反而不如福大本地认可度。"

**真实案例(闽商家族二代 + 想留厦门 + 565 分)**:
> "你家里在晋江做鞋服,父母希望你留闽接班,但你想出去看看,562 分。
>
> 双轨思考:
> - **留厦门 + 接班外贸** → 集美大学嘉庚商科国贸 / 华侨大学厦门校区国贸 + 跨境电商方向 → 4 年厦门生活 + 实习闽商家族企业 + 接班准备
> - **出省看世界** → 出省 211 财经(西南财经 / 中南财法)国贸方向 → 4 年外地生活 + 暑假回福建实习 → 毕业回闽接班(出省经历加分)
>
> **闽商家族二代不要因为"想出去看世界" 就完全放弃留闽路径**,因为接班才是你真正的护城河,出省 4 年只是体验。**双轨同时考虑才是上策**。"

## 福建特殊意向冲突场景

### 场景 A:闽商家族二代 vs 父母期待"接班 / 走涉外"

**冲突**:孩子想做体制内公务员(觉得稳),父母希望接班家族企业 / 走涉外路径

**金句模板**:
> "你家做 [纺织鞋服 / 茶叶 / 跨境电商],年入 [X],父母希望你接班。**接班是你最大的护城河,公务员是别人家孩子的护城河**。
>
> 你想考公的真实原因是什么?
> - 怕家族企业不稳 → **错觉**,闽商家族企业稳定性远超你想象,你的父母已经替你扛了 30 年风险
> - 觉得做生意辛苦 → **真实**,但接班不等于从零开始,你是接现成的网络
> - 喜欢稳定不想冒险 → 那就走"考公 + 兼接家族某个版块" 的双轨,不要纯走考公
>
> **建议**:厦大经管 / 华侨大学国贸 + 实习家族企业 + 大三大四了解家族业务,**毕业再决定接班还是另起炉灶**。**纯走考公 = 浪费家族 30 年积累的网络**。"

### 场景 B:闽商家族二代 + 想出国 + 父母担心不回来

**冲突**:孩子想出国留学(走美澳英加),父母担心一去不回 / 学费贵

**金句模板**:
> "你想出国是真兴趣还是逃避?父母担心你不回来 / 学费贵是真的。
>
> 折中方案:
> 1. **闽台合作办学**(华侨大学 / 福师大 / 集美大学 等闽台 4+0 / 3+1 / 2+2 项目)= 学费 2-5w/年 + 半本土半台湾体验,**比出国便宜 3-5 倍 + 离家近**
> 2. **厦门大学马来西亚分校**(厦大本部牌子 + 马来本土校区 + 闽商东南亚网络密集)= **闽商家族二代天然路径**
> 3. **本科厦大 / 华大 + 研究生出国** = 4 年本省生活 + 研究生再出国,**家族网络稳定 + 国际视野并存**
>
> 别一上来就"高考完直接出国" — **闽商家族网络是你 4 年大学就该开始铺的,出国 4 年彻底断网**。"

### 场景 C:工薪家庭 + 想冲厦大但分数不够 + 父母情怀

**冲突**:父母觉得"福建只有厦大像样,孩子必须上厦大",分数明显不够

**金句模板**:
> "父母的'必须厦大' 是 90 年代的认知。**今天的福建是:厦大经管 + 福大化工 + 福师大公费师范 + 集美航海 + 福医医学技术 + 华大涉外** 这一套生态,**不是厦大独大**。
>
> 你工薪家庭,孩子分数 [X],真冲厦大冷门组(比如哲学 / 图书情报)毕业改行,跟双非毕业一样;**改报福师大公费师范 = 留闽教师编制 + 免学费,4 年给家里省 4-6w 学费 + 毕业直接铁饭碗**。**这才是工薪家庭的最优解**。
>
> 父母觉得"福师大不如厦大" — **看专业看出口,不看校名虚荣**。"

### 场景 D:闽北闽西山区农村 + 父母希望"出大山留沿海"

**冲突**:父母希望孩子"出山留福州 / 厦门",但分数只够本省双非或外省 211

**金句模板**:
> "你家在 [南平 / 三明 / 龙岩 / 宁德山区],父母希望你留福州 / 厦门 = 跨阶级。**跨阶级靠学校牌子 + 留沿海 + 城市圈子**,这三个一起才能成。
>
> 你分数 [X],推荐路径:
> 1. **国家专项**:福建农村专属优惠(厦大 / 福大 / 福师大 / 福建农林 都有专项指标),**比统招分低 20-30 分**,985/211 牌子直接到手
> 2. **福师大公费师范**(免学费 + 编制 + 服务 6 年)= **零成本上福州 + 留闽教师铁饭碗**
> 3. **集美大学航海技术** = 厦门集美区 4 年 + 远洋船公司 + 起薪 15-25w,**农村男孩跨阶级最高 ROI 路径之一**
>
> 别为了"出省 985 弱专业" 跑去东北 / 西北 — **回福建反而没竞争力,牌子在福建本地不通用**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**福建特殊步骤** — 在第 4 步前 加 **0. 识别家庭档位**:
- 闽商家族 → 优先考虑接班 / 涉外路径,意向冲突按家族产业逻辑给替代
- 工薪 / 农村家庭 → 优先稳定 / 编制路径,意向冲突按"福师大公费 / 集美航海 / 福建农林" 给替代
- 体制内家庭 → 优先选调 / 考公路径,意向冲突按"厦大法学 / 经济 + 选调" 给替代

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上厦大,那我就推厦大的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("厦大不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **把闽商家族当工薪家庭对待**(推考公基层) — 家庭基因错配,父母不会满意

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 厦大 / 想学医 / 想留厦门 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。
