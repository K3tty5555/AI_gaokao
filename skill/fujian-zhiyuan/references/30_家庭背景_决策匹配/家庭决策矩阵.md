# 家庭背景决策矩阵 — 福建 5 档家庭 × 推荐策略

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**福建闽商家族二代 vs 闽北闽西山区农村家庭 的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。**福建独有的"闽商家族 / 华侨家族"档位 跟内陆省份完全不同,要单独识别处理**。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障(福建省直 / 市直机关 / 福建省电力 / 福建中烟 / 兴业银行 / 福建联通 等国企)。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **福建特色**:**闽商家族文化 + 体制内文化并存**,体制内家庭对"经商"也持开放态度(不像内陆只盯体制)

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(福建省直 / 厦门 / 福州 体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211(厦大 / 福大 / 出省 985),**走选调生比国考省考更优**(起点更高、竞争内部化)。**福建定向选调主要走厦大 + 福大 + 福师大 + 出省 985**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:**福建警察学院 + 公安联考** = 父母编制资源能用上,**留闽进福建公安系统** 是对口路径

**典型 case**:
- 福州省直机关家庭 + 母亲兴业银行 → 孩子 605 分历史类 → 推**厦大法学 / 中南财法法学(出省)** → 毕业选调进福建省委办,**家庭路径完美匹配**
- 厦门海关公务员家庭 → 孩子 595 分物理类 → 推**厦大经济 / 财政学** → 毕业选调进厦门市直,**对口家庭体系**
- 失败 case:同样体制内家庭,孩子被推去厦大 CS → 毕业 25w 起薪很高,但家长不满"不稳定",劝其离职考公,**两年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师 / 律师 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域(福建省立医院医生 / 厦门一中老师 / 福州马尾软件园工程师 / 福建建工设计院 / 厦门律所合伙人 等)。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:
   - 教师家庭 → **福师大公费师范 / 厦大中文 / 闽南师大公费师范**(留闽教师编制)
   - 医生家庭 → **厦大医学院 / 福医临床 / 福医口腔**(8 年长周期父母能撑)
   - 律师家庭 → **厦大法学 / 中南财法法学(出省)**(法考 + 实习对口)
   - 工程师家庭 → 对应工科(**福大化工 / 福大电气 / 厦大软工**)
2. **行业相关延伸**:闽商企业管理家庭 → 厦大经管 / 华侨大学国贸
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 厦门一中语文老师 + 父亲普通工薪 → 孩子 615 分历史类 → **公费师范生汉语言**(福师大) → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是福建省立医院临床医生 → 孩子 660 分物理类 → **厦大医学院八年制 / 福医临床本博连读** → 父母能撑 8 年读书 + 福建协和 / 福医附一 推荐 → **典型子承父业路径**
- 福州马尾软件园工程师家庭 → 孩子 580 分物理类 → 福大软工 → 父亲资源推美图 / 美亚柏科实习 → 校招进福州网龙 / 兴业银行 IT,**典型工程师家族延伸**

## 档位 ③ 闽商家族 / 私企管理 / 创业家庭(福建特色档位 ★★★)

**定义**:父母私企中高管 / 自主创业 / 闽商家族企业(晋江安踏 / 石狮纺织 / 莆田鞋业 / 福鼎白茶 / 福州私企 / 泉州外贸 等)。**这是福建独有的厚重档位**(占比远高于内陆),决定福建很多家庭的志愿逻辑跟内陆完全不同。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业 + **海外华侨网络**(印尼 / 马来西亚 / 菲律宾 / 港澳)
- **福建特色**:闽商家族二代有"接班 vs 自由发展" 的两难,父母大多希望接班但理解孩子要先在外历练

**推荐策略**:
1. **可选商科 / 创业方向**:**厦大经管(全国前 5)** / 华侨大学国贸 / 福大管理科学 / 出省商科顶级(上财 / 央财 / 复旦经管)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学 / 闽台合作办学**:学费贵 + 国际视野,**福建闽台合作办学项目** 跟一般中外合作不同(学费 2-5w/年,可走台湾深造)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **闽商家族二代的"接班准备" 路径**:
   - **家里做纺织鞋服 / 跨境电商**(晋江 / 石狮 / 莆田) → 厦大经管 + 跨境电商方向 / 华侨大学国贸
   - **家里做茶叶 / 食品**(武夷山 / 安溪 / 福鼎) → 福建农林茶学 / 食品科学 + 家族企业接班
   - **家里有华侨亲戚 / 想做东南亚生意** → **华侨大学国贸 / 法学(涉外)**(独家通道)
   - **家里做闽商投资** → 厦大经济 / 出省金融顶级(上财 / 复旦)
6. **避免:进体制内基层**(跟家庭基因不匹配,父母提供的资源全用不上)— 但可以走"考公 + 接班企业" 的双轨路径

**典型 case**:
- 晋江安踏家族 / 石狮纺织私企老板(年入 1000w+) → 孩子 580 分物理类 → 推**厦大马来西亚分校 + 出省中外合作**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班 / 跨境电商
- 福清华侨家族(家里在马来西亚 / 印尼有产业) → 孩子 590 分物理类 → 推**华侨大学国贸 + 法学(涉外)** → 毕业去东南亚接管家族业务,**华大独家通道**
- 莆田中医世家 + 私企老板 → 孩子 575 分物理类 → 推**福建中医药大学中医学** + 接班家族中医诊所 / 中药店,**家族传承 + 政策红利双兜底**
- 泉州茶商家族(武夷山岩茶 / 安溪铁观音) → 孩子 540 分物理类 → 推**福建农林大学茶学** → 毕业接班家族茶企 / 武夷山八马 等龙头企业,**专业对口家族产业**
- 失败 case:闽商家庭 → 孩子被推考公 → 进福建省直某基层公务员后被父母嫌"没出息" → **家庭基因不对路 + 父母希望接班企业** → 2 年后辞职接班,白学 4 年汉语言

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(福建沿海中小工厂工人 / 餐饮服务业 / 物流港口工人 / 闽商家族企业基层员工 等)。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **福建特色**:**普通工薪家庭看到身边闽商家族暴富,有"一夜暴富" 幻想 → 容易被推"金融 / 国贸 / 创业" 等高风险专业**,这种错配在福建特别常见

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **福师大 / 闽南师大 公费师范生** = 高考分适中 + 直接编制 + 无学费(**福建工薪家庭神券**)
   - **福建警察学院 + 公安联考** = 进福建公安系统编制
   - **福医医学技术(医学影像 / 检验)+ 护理** = 三甲医院技术岗 + 4 年本科即可
   - **集美大学航海技术 / 轮机工程** = **男生海上跑船 + 起薪 15-25w 起 + 远洋船公司编制**(福建特色,湖北等内陆省没有这条路径)
3. **次推稳定就业型**:
   - **福大电气 / 厦大电气** 进福建电网(分够 985/211)
   - **集美大学水产养殖 / 海洋渔业 / 食品科学** 进福建沿海产业
   - **福建农林农林相关** 进福建林业 / 农业系统编制
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-10w,跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)
   - **国际经济与贸易 / 工商管理** 双非(福建工薪家庭最容易踩的坑 — 看到闽商暴富觉得"学国贸有用",实际是低端外贸 + 跨境电商运营,跟科班关系不大)

**典型 case**:
- 闽东宁德渔业家庭 → 孩子 545 分物理类 → 推**集美大学水产养殖 / 海洋渔业**(2024 福建宁德大黄鱼 + 福鼎海带产业蓬勃)→ 毕业进福建水产龙头 / 海洋渔业局编制,**月入 0.7-1.0w + 编制,家庭逆袭**
- 漳州工薪家庭男孩 → 580 分物理类 → 推**福州大学电气** → 毕业进福建电网漳州地市公司,**月入 0.9w + 编制 + 福建本省户口稳定**
- 莆田工薪家庭男孩 + 视力好 + 体能好 → 555 分物理类 → 推**集美大学航海技术** → 毕业进中远海运 / 福建外轮代理,**起薪 1.5-2.5w / 月 + 远洋船公司,5 年内升大副工资 30-50w**,**福建工薪家庭男孩起薪最高路径**
- 三明工薪家庭女孩 → 540 分文史类 → 推**福师大公费师范汉语言文学** → 毕业当年回三明县城重点中学编制,**家庭命运改变 + 4 年免学费**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。**福建闽北闽西山区(南平 / 三明 / 龙岩 / 宁德山区)+ 闽南部分山区** 农村家庭。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **福建特色**:闽北闽西山区跟沿海城市差距大,**山区农村家庭"出闽" 心理不强(福建人留闽率高),但"出山进城" 心理强**(从龙岩山区到福州 / 厦门 / 泉州 = 跨阶级)

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **福师大 / 闽南师大 公费师范生**(无学费 + 编制)= 福建农村家庭神器
   - **国家专项计划 / 高校专项 / 农村专项** = 福建农村专属优惠(厦大 / 福大 / 福师大 / 福建农林 等都有专项指标)
   - **福建警察学院 + 公安联考**(无学费 + 编制 + 包分配)
   - **福建农林大学** = 福建省内涉农 / 林业 编制 + 行业有出路
   - **集美大学航海技术** = 福建男生跨阶级最高 ROI 路径 + 远洋船公司编制(虽要海上跑船但工资高)
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作 / 闽台合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:福建农村户籍,985/211 名校多个专项指标(分数比统招低 20-30 分)
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **福建农林菌草科学** = 林占熺院士研究的方向,**援外项目 + 国际机会**(全国唯一)

**典型 case**:
- 闽北南平山区农村家庭 → 孩子 580 分物理类 → 通过**国家专项**进**厦大化学 / 福大化工**(比统招分低 30 分)→ 985/211 牌子 + 国家专项编制路径,**整个家族第一个 985/211**
- 闽西龙岩山区农村女孩 → 605 分文史类 → 推**福师大公费师范汉语言** → 4 年无学费 + 毕业回原县编制,**最适合福建农村家庭的"零风险"路径**
- 闽东宁德山区农村男孩 + 视力好 + 体能好 → 565 分物理类 → 推**集美大学航海技术** → 毕业进远洋船公司,**起薪 1.5-2.5w / 月,5 年内攒钱在家乡盖房 + 接父母进城**,**福建农村男孩跨阶级最高效路径**
- 三明山区客家农村男孩 → 525 分物理类 → 推**福建农林大学林学 / 菌草科学** → 毕业进福建林业局 / 援外项目,**省内编制 + 偶尔出国援外项目 → 整个家族第一个吃公家饭的人**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 福建独有的"闽商二代识别" 注意事项

**福建跟内陆的最大区别是**:**闽商家族 + 海外华侨家族** 比例特别高(沿海地区 30-50%)。**家长 自报职业时**可能说"做点小生意"(实际可能是闽商家族年入 500w),agent 要追问:

1. **家里做什么生意?** — 纺织 / 鞋服 / 茶叶 / 跨境电商 / 海外 → 可能是闽商家族
2. **家里有海外亲戚吗?** — 印尼 / 马来西亚 / 菲律宾 / 港澳 → 可能有华侨网络
3. **家庭年收入 / 父母储蓄能撑 8 年读书吗?** — 撑得起 → 闽商档;撑不起 → 工薪档
4. **父母的期待是接班还是自由发展?** — 接班 → 走对应家族产业方向;自由 → 看孩子兴趣

**识别错档位的代价**:把闽商家族二代推汉语言考公 = 浪费家族网络;把工薪家庭推中外合作办学 = 家庭破产。**福建 agent 必须有这层敏感度**。

## 一句话原则

**家庭档位决定专业大方向,兴趣只在档位允许范围内选择**。福建的特殊性是**闽商家族档位单独识别 + 海外华侨网络是真实资源,不是噱头**。
