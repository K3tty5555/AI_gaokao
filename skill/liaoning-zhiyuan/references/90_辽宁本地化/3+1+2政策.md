# 辽宁 3+1+2 高考政策

## 核心结论

**辽宁 2018 年加入新高考第三批,2021 年高考首届实行 3+1+2**(跟湖北 / 湖南 / 江苏 / 广东 / 河北 / 重庆 / 福建 同批)。**总体规则跟湖北一致**,但辽宁有几个**非常重要的本地特殊性**:**取消了一本二本合并后批次线划线低 + 体量小 + 京津/长三角虹吸 + 东北就业生态衰退**。

## 关键事实

### 考试结构(同湖北)
- **3 = 语文 + 数学 + 英语**(各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- **两类完全分开排名、分开录取**
- 辽宁物理类约 65-70%,历史类约 30-35%(物理占比高于全国平均)

### 院校专业组(同湖北)
- 不再按"学校"投档,**按"院校专业组"投档**
- 一所学校可有多个专业组
- 同一学校的不同专业组独立投档
- **服从调剂只在本专业组内调剂**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量(辽宁全国最多)
- **辽宁本科批 112 个志愿**(**全国最多**!对比湖北/湖南 45,江苏 40,河北 96)
- **专科批 60 个**
- 每个志愿 = 1 个院校专业组
- **意义**:辽宁填报"操作空间极大",冲稳保梯度可以铺得最开,但也意味着**填错容易、信息搜集成本最高**,需要更精细的位次梯度

### 12 种选科组合
跟湖北一致(物 + 化生 / 物 + 化政 / 物 + 化地 / 物 + 生政 / 物 + 生地 / 物 + 政地 / 史 + 化生 / 史 + 化政 / 史 + 化地 / 史 + 生政 / 史 + 生地 / 史 + 政地)。

可报专业范围参考详见 `_shared/references/00_核心方法论/采集_rubric.md` L1 单科分数判断。

## 辽宁最大特殊性(关键!!)

### 1. 辽宁是**东北高考最容易省**

东北三省里(辽吉黑),**辽宁高考整体最容易**:
- **分数线低**(本科批划线低)
- **985/211 名额相对多**(2 所 985 + 2 所 211 在本省,招生倾斜)
- **考生体量小**(2024 年高考报名约 24-25 万,**远少于河北 75 万 / 河南 130 万**)

但"容易"是相对的 —— 上 985 的难度跟其他省差不多,**真正容易的是上一本本科 + 部分中等 211**。

### 2. 辽宁取消了一本二本合并(本科批划线低)

**关键认知**:辽宁 2021 年起取消一本二本合并,**只有"本科批"和"特控线"两条线**:
- **本科批** = 原一本二本合并后的最低控制线(包含原二本三本)
- **特控线**(原一本线)= 985/211 + 强势院校的最低门槛

**结果**:辽宁本科线极低,2024 年物理本科 368 分(同年湖北 437 / 江苏 462 / 河北 448),**这不是辽宁考生水平低,是划线规则不同**。

### 3. 京津 + 长三角虹吸 + 东北经济衰退

- **辽宁人口外流严重**,留辽就业率仅约 50%
- 东北经济衰退 → 高分考生大量流向京津 / 长三角 / 珠三角
- 留辽 = 接受东北就业生态(国企铁饭碗多 + 民企就业弱)
- **本省高校在高分段竞争力中等**(大工 / 东大 顶尖,但下面拉开档次)

### 4. 辽宁名校结构(简洁但有特色)

- **2 所 985**:大连理工大学 / 东北大学(沈阳)
- **2 所 211**:辽宁大学(沈阳)/ 大连海事大学(交通部直属,航海类全国前 1)
- **东北财经大学**:双非但财经全国前 5(原"两财一贸"成员之一,大连)
- **中国医科大学**:双非但临床医学全国前列(沈阳)
- **海军大连舰艇学院**:海军军官摇篮(军校,大连)

详见 `辽宁强校真实地位.md`。

## 辽宁特色路径

### 1. 海军大连舰艇学院 — 海军军官摇篮
- **军校,海军直属**,中国 4 大军种最高军事学府之一(陆军南京 / 海军大连 / 空军长春 / 火箭军咸阳)
- **大连地理**(海军北海舰队对口)
- **男生硬汉路径首选**,体检 + 政审 + 高考分都要够
- 提前批,不影响其他批次

### 2. 大连海事大学 — 211 + 交通部直属
- **航海类全国第 1**(中国唯二的"双一流"+ 交通部直属海事高校,另一所是上海海事)
- **远洋船员 / 中远海运 / 海事局** 直接对口
- **男生硬汉路径**(航海类只招男生 + 体检严格)

### 3. 东北财经大学 — 双非财经顶配
- 原"两财一贸"成员(80年代财经四大名校之一,跟央财、上财、中南财法、对外经贸 同档)
- **2000 年合并风潮中没并入 985,留下双非牌子**,但学科实力 + 就业 + 校友网络 = 211 水平
- 大连地理 + 长三角珠三角认可度高

### 4. 中国医科大学 — 双非临床顶配
- **沈阳大本营**,临床医学全国前列
- **军医出身**(原中国人民解放军军医大学传承),老牌名医院校
- **就业辐射东北 + 京津**,东北最重要的医学供给校

## 易错认知(agent 要纠正用户的)

- **"还是按文科 / 理科算的吧"** — 严重过时。辽宁 2021 年起就没文理分科了,**只有物理类和历史类**
- **"3+1+2 跟老高考差不多,只是叫法不同"** — 错。**录取规则不同,投档单位不同,服从调剂规则不同**
- **"112 个志愿都是学校,选哪个学校都行"** — 严重错误。**112 个志愿是 112 个"院校专业组"**
- **"辽宁分数线低,所以辽宁考生水平低"** — **严重错**。**辽宁取消了一本二本合并**,本科线低是划线规则,不是水平低。看位次。
- **"辽宁本科 368 分能上 = 我也能去辽宁读书"** — 错。**这是辽宁本省考生的本科最低控制线**,外省考辽宁高校(包括辽宁高校录辽宁本省考生)实际分数线远高于 368。本科批的下限校大量是民办本科 / 独立学院。
- **"服从调剂会被调到本校其他专业"** — 错。**只在本专业组内调剂**,不会跨组
- **"辽宁名校少,留辽就只能上双非"** — 半错。**留辽有 2 所 985(大工 / 东大)+ 2 所 211(辽大 / 大海)+ 东财顶配双非**,选择不少。但东北就业生态衰退是真的,出省京津/长三角 是高分考生的主流。

## 关键提醒(agent 必须强调)

1. **辽宁 112 个志愿组**(全国最多),冲稳保梯度要铺开,信息搜集成本高
2. **服从调剂**通常推荐勾选,**但要确认本专业组内你能接受的最差专业**
3. **看位次而不是分数**(辽宁取消了一本二本合并,本科线低,跟其他省没法直接比)
4. **再选科目限制**(必选化学/必选政治等)是硬约束,**填报前一定核对每个目标专业**
5. **东北就业生态衰退,留辽就业率仅 50%** — 出省的心理准备要做好,京津 / 长三角 是主流
6. **军校 / 海事 / 海军大连舰院** 是辽宁特色,**男生 + 体检过关 + 想稳定** 的路径要重点考虑

## 112 个志愿的填报策略(辽宁特色,全国最多)

### 冲稳保比例
- **常规建议**:**冲 2 / 稳 5 / 保 3 比例 → 落到 112 志愿就是 冲 22 / 稳 56 / 保 34**
- **辽宁实操**:**冲 25 / 稳 60 / 保 27** = 比例略向"稳" 倾斜(因为辽宁经济下行 + 不能有断档风险)
- **关键提示**:**112 志愿全填满 + 不要空着**,辽宁有充足的院校资源,**空 1 个志愿 = 浪费 1 次机会**

### 三梯度细化
- **冲(高于自己位次 5%-10%)**:**用提前批冲军校 / 警校 + 本科批冲热门 985 / 211 王牌专业组**,**填错也无伤大雅**(后续有 90+ 志愿兜底)。
- **稳(位次接近自己位次)**:**主力填段 + 各专业组分散 5-15 个**,**这是辽宁本科批"决战段"**,梯度细化 50-80 名一档。
- **保(低于自己位次 10%-30%)**:**填辽宁本省双非 + 部分外省二本 + 民办本科兜底**,**保证不掉档**。

### 辽宁 112 志愿独家踩坑
- **踩坑 1**:**只填"冲" 部分** = 28 个志愿全填高分,后面 84 个空着 → **失败掉档**(辽宁本科批一档 + 不能补录)。
- **踩坑 2**:**112 志愿都填一所学校的不同专业组** → **风险集中 + 一所学校录取波动 = 全掉档**,**辽宁多校分散原则**。
- **踩坑 3**:**保底志愿不够保**(填的"保" 实际录取分高于自己位次)→ **真正的保底要用辽宁地市本科 / 民办本科 / 中外合作 等"分位次低于自己 30%" 的志愿**。
- **踩坑 4**:**不勾服从调剂** → 辽宁 112 志愿不勾服从调剂 = 退档风险陡增,**辽宁本科批必须勾服从**(除非确认本专业组所有专业都能接受最差的)。

## 选科组合的辽宁特殊性

### 物化生 / 物化地 / 物化政 三大主流(物理类)
- **物化生**:**医学 + 农林 + 生物相关 主路径**,**辽宁中国医大 / 大医 / 沈阳药科 + 全国医学院 都收**,**女生学医独女首选**。
- **物化地**:**地球科学 + 海洋 + 部分工科**,**大连海事 + 中国海洋大学 + 各种地学专业 主路径**,**辽宁沿海家庭偏好选**。
- **物化政**:**计算机 + 电气 + 工科 + 考公友好**,**大工 / 东大 / 沈工大电气 / 全国工科 985 + 考公 双向兼容**,**辽宁工薪家庭独子男 主流选择**。

### 历史类组合
- **史政地**:**文科考公主路径 + 法学 / 中文 / 经济 / 师范 全收**,**辽大法学 + 辽师 + 沈师 + 东财文科 主路径**,**辽宁文科考生 默认组合**。
- **史化政**:**化学 + 历史的特殊组合**,**部分医学院 + 部分工科 + 文科 三向兼容**,**辽宁少数文科 + 想做医学法医的孩子选**。
- **史化生**:**辽宁罕见组合**,**仅医学法医方向 + 部分文科**,**报考极受限 + 不推荐**。

### 选科地雷区
- **史化生 / 史生地 / 史生政**:**报考受限严重**,**辽宁没几所学校的专业组接收这种组合**,**想报必查每所目标学校的专业组要求**。
- **物政地**:**化学 / 生物缺位**,**医学 / 化工 / 大部分理工科 拒绝**,**仅适合走纯地学 / 文理交叉路径**,**辽宁极少考生选**。

## 辽宁批次线深度解读(为什么"低"?)

### "辽宁本科 368 分"的真实意思
- **368 是辽宁本科批最低控制线**(原一本二本三本合并后的最低线),**实际能进辽宁本省 985(大工 / 东大)需要 600+ 分**,**能进辽宁本省 211(辽大 / 大海)需要 530-580 分**。
- **368 这个分数对应的位次大约是辽宁物理类全省 60,000-65,000 名**(2024 数据),**这个位次对应能上的学校大多是辽宁省内民办本科 + 独立学院 + 三本院校**,**不是普通家长想象的"本科都能上 985"**。
- **辽宁本科线 vs 河北 / 河南 / 江苏 等省的"一本线" 对比 → 辽宁特控线(原一本线)= 物理 494 / 历史 518** 才是真正可比的"上 985/211 门槛"。

### 辽宁特控线的真实门槛
- **物理特控 494 分**:对应位次约 28,000-32,000 名(2024 数据),**这是辽宁物理类考生进入"重点本科"+ 985/211 候选的门槛**,**辽宁特控线下的考生几乎不能报 985/211**。
- **历史特控 518 分**:对应位次约 5,500-6,500 名(2024 数据),**辽宁历史类特控线竞争更激烈**(因为辽宁文科考生少 + 优质院校少 + 留辽 211 几乎只有辽大文科)。

### 辽宁分数 vs 位次 转换关键
- **辽宁考生务必看位次,不能看分数**。**辽宁 600 分 ≠ 湖北 600 分** ≠ **江苏 600 分**(各省赋分制 + 划线规则不同)。**辽宁 600 分对应位次约 9,000-10,000 名 = 大工 / 东大 中等专业组**;**辽宁 650 分对应位次约 1,500-2,000 名 = 大工 / 东大 王牌组 + 出省 985 中段**。

- **2018 年**:辽宁宣布加入新高考第三批(同湖北 / 湖南 / 江苏 / 广东 / 河北 / 重庆 / 福建 同批)。
- **2018-2020 年**:**最后一届老高考(文理分科)** + 政策过渡期。
- **2021 年首届 3+1+2**:辽宁 2018 级高一新生进入新高考实验,2021 年 6 月首届 3+1+2 高考。

- **2024 年第四届 3+1+2** + **辽宁高考批次稳定**:政策已成熟 + 考生 + 家长 + 学校都熟悉新高考。
- **2025 届(本届)**:辽宁 3+1+2 第五届,**政策已稳定 + 大数据可参考的最近 5 年录取数据**(2021-2025)。

## 辽宁选科最大坑(实战)

### 坑 1:跟风物化生 / 物化政,但孩子化学差
- **辽宁化学赋分制 + 化学难度大** → **化学差的孩子选化学 = 自杀级别**(被赋分制压低,实际原始分 70 → 赋分 50-55)。
- **决策口径**:**化学高三模考稳定在年级前 30% 才能选化学**,**化学不稳定 → 选物 + 生物 / 政治 / 地理**,**避免化学**。
- **辽宁高中老师"化学是工科基础" 引导误区**:**化学不是工科基础,数学物理才是**,**部分工科(机械 / 电气 / 计算机)不强制化学**,**别被高中老师的"工科必选化"误导**。

### 坑 2:文科孩子选史化政
- **史化政在辽宁报考受限严重 + 化学赋分压低 + 文科考生选化学 实际优势小**。
- **决策口径**:**历史类首选史政地** = 标准文科组合 + 报考最广 + 考公最友好。
- **史化政的极少数适用场景**:**孩子既想学法医 又是文科 + 化学不差** → 这种特殊画像才选史化政。

### 坑 3:不选物理但报考工科
- **辽宁工科 99% 要求物理类**(首选物理),**没选物理首选历史 → 几乎不能报工科 + 计算机 + 电气 + 机械 + 土木**。
- **决策口径**:**男生工科派 默认首选物理**,**首选历史的男生只能走文科 + 经管 + 法学 + 师范 + 部分医学辅助**。

## 辽宁高考志愿填报时间轴(本届考生)

- **5 月底-6 月初**:模考 + 估分 + 初选目标院校(辽宁 3-5 月模考期是规划黄金期)。
- **6 月 7-8 日**:高考。
- **6 月 22 日左右**:成绩公布 + 一分一段表发布。
- **6 月 24-26 日**:**辽宁本科批志愿填报**(7 天紧急填报期)。
- **6 月 27-28 日**:**专科批志愿填报**。
- **7 月 上旬**:**提前批录取**(军校 / 警校 / 公费师范 / 国家专项 + 高校专项)。
