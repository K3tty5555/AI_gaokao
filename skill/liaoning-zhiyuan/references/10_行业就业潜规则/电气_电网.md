# 电气 / 国家电网 — 行业潜规则(辽宁视角)

## 一句话真相

电气工程是 985/211 工科里**就业最稳的方向之一**,核心出路是国家电网 + 南方电网 + 五大发电(华能 / 大唐 / 华电 / 国电 / 国电投)+ 设备制造商(西电 / 平高 / 特变)。辽宁孩子学电气有一个独特优势:**国家电网辽宁分公司每年大量招辽宁本省 985/211 电气** + 辽宁是中国电力装备制造重镇(沈阳沈鼓 / 沈阳变压器 / 大连重工)。

---

## 全国行业 truth(跨省共享)

### 1. 国家电网 / 南方电网"两网"是核心去向

- **两网招聘批次**:每年一批(秋招主)+ 二批(春招补录),**第一批是核心,二批名额少 + 岗位偏远**。
- **能进两网的学校**:**电气两电一邮 + 华北电力 + 西交 + 武大 + 哈工大 + 华中科大 + 浙大 + 重大 + 川大 + 沈阳工业 + 东北电力**(注意:沈阳工业 + 东北电力虽是双非,但电气专业历史悠久 + 两网认可度高,辽宁本地考生可重点关注)。
- **岗位差异**:① 国网总部(北京)/ 省公司本部 / 地市公司 / 县公司 — **总部 > 省公司 > 地市 > 县**,但越往下越好考,县公司适合**留本地 + 体制内偏好** 的孩子。② 国调中心(电力调度,国网最高技术岗)/ 经研院(规划)/ 信通(信息通信) — 这些是技术型路径。
- **薪资**:国网省公司本部 15-22w + 福利;地市公司 12-18w;县公司 8-13w + 补贴。比互联网少,但稳定 + 不裁员 + 福利好(房子 / 食堂 / 子女教育)。

### 2. 进两网的隐性门槛

- **学历**:本科起,部分总部 / 经研院 / 调度中心岗位要硕士。
- **党员加分**:**学生党员是软门槛**,大三发展党员能进可以争取一下。
- **学校排名**:同档学校竞争激烈时**985 > 211 > 双非电气强校 > 普通双非**。
- **籍贯优势**:**国网各省公司在本省校招会优先考虑本省籍贯学生**,辽宁籍贯学生进国网辽宁分公司的优势明显。
- **关系**:坦白讲,**县公司岗位有"关系"成分**,但近年纪检整顿后阳光化程度提高,大头还是看笔试 + 面试。**关系多的家庭进国网县公司起步,关系少的孩子进省公司本部反而更靠实力筛选**。

### 3. 电气专业内部分化

- **电力系统及其自动化(传统电气)**:进两网主流。
- **高电压与绝缘技术**:进两网 + 设备制造(西电 / 平高)。
- **电机与电器**:偏制造,进沈阳变压器 / 卧龙电气 / 大连电机。
- **电气工程及其自动化(综合)**:本科覆盖以上三块,看研究生再细分。

### 4. 五大发电(电力央企第二梯队)

- **华能 / 大唐 / 华电 / 国电(国家能源)/ 国电投**,加上中广核 / 中核 / 三峡集团等。
- **薪资**:略高于国网(基层),但**生活地点偏远**(发电厂多在山区 / 海边 / 沙漠 / 戈壁)。
- **辽宁视角**:**辽宁有大量火电厂(锦州 / 鞍山 / 抚顺)+ 风电基地(辽东风电带)+ 大连红沿河核电站**,五大发电在辽宁就业岗位多。
- **核电**:中广核 + 中核,**大连红沿河核电站** 是辽宁孩子核电就业重要去向,**核工程专业极冷门 + 招聘门槛低 + 薪资高 + 福利好**。

## 辽宁本地化(关键!)

### 国家电网辽宁分公司

- **辽宁电力公司总部在沈阳**,下设 14 个地市公司(沈阳 / 大连 / 鞍山 / 抚顺 / 本溪 / 丹东 / 锦州 / 营口 / 阜新 / 辽阳 / 盘锦 / 铁岭 / 朝阳 / 葫芦岛)+ 经研院 + 信通 + 调度等。
- **每年校招辽宁分公司接收量**:约 800-1200 人(本科 + 硕士合计),**辽宁本省 985/211 电气是主供给**(沈阳工业大学 / 大连理工 / 东北大学 / 东北电力(吉林) / 沈阳工程学院 等)。
- **辽宁籍贯优势**:**辽宁籍 + 辽宁本地或东北 985/211 电气 → 进国网辽宁分公司 = 概率最高路径**,这是普通辽宁工薪家庭男孩"考公替代品"的最佳选择。

### 辽宁电力装备制造产业

- **沈阳变压器(特变电工子公司)**:沈阳本地大型变压器企业,**电机电器 / 高电压方向 直接对口**。
- **大连重工(船用电机 / 港机)+ 大连电机**:大连本地电力装备制造,**电机方向对口**。
- **沈阳鼓风机(沈鼓集团)**:虽然主业是鼓风机,但**电气控制系统 是核心组成**,**自动化 / 电气控制 方向对口**。
- **沈阳工业大学的特殊地位**:沈阳工业大学是辽宁本省电气类双非天花板,**电机与电器学科全国前 10**,**国网辽宁分校招认可度仅次于大工 / 东大**,辽宁本地考生分数不够大工 / 东大但够沈阳工大,**进国网概率不比 985 低**。

### 辽宁特色电力产业

- **风电带**:辽东(丹东 / 营口 / 大连)沿海风电基地,中国最早的海上风电试点 → 风电运维岗位多,**电气 + 机械 双背景受欢迎**。
- **核电**:**大连红沿河核电站(中广核)**,辽宁孩子进核电的主要去向,**核工程 / 电气 / 机械** 都能进,但红沿河地理偏远(瓦房店),不适合恋家女生。
- **火电**:辽宁有华能(锦州 / 营口)+ 国电投(沈阳 / 鞍山)等大型火电厂,本科电气进火电厂 = 起薪 12-15w + 包食宿,但工作环境偏苦累。

### 辽宁电气类高校天花板(留辽路径)

| 学校 | 档次 | 电气地位 | 进国网辽宁分概率 | 适合谁 |
|---|---|---|---|---|
| **大连理工** | 985 | B+ 全国前 30 | 高(985 + 辽宁籍优势) | 辽宁高分 + 想留沿海 |
| **东北大学** | 985 | B+ 全国前 30 | 高(985 + 辽宁籍 + 沈阳本地国企对口强) | 辽宁高分 + 想留沈阳 |
| **沈阳工业大学** | 双非一本 | **B+ 强势 / 电机与电器全国前 10** | **极高(辽宁电力系统认可度第一档)** | **辽宁工薪家庭男孩 + 想进国网铁饭碗** |
| **东北电力大学**(吉林) | 双非一本 | **A- 电气全国前 15** | 极高(电力老牌名校) | 辽宁孩子愿意去吉林 + 进电力系统 |

**关键结论**:**进国家电网不一定要 985,辽宁籍 + 沈阳工大 / 东北电力 电气专业 = 性价比比 985 大工 / 东大 电气还高**。因为 985 大工 / 东大电气也是和沈阳工大竞争国网岗位,985 学生本身有更多选择不一定都去国网,而沈阳工大学生几乎全军压上国网,**沈阳工大电气 → 国网辽宁分公司 = 60%+ 概率**。

## 辽宁电气类家庭画像

### 工薪家庭独子男 / 普通家庭男孩

- **核心诉求**:稳定 + 留辽宁 + 编制感 + 父母安心。
- **推荐路径**:**沈阳工业大学电气 / 东北电力大学电气 / 大工 / 东大电气 → 国网辽宁分公司 → 沈阳总部 / 大连地市公司 → 干 5-10 年成中层 → 一辈子稳定**。
- **替代路径**:核电(大连红沿河)+ 五大发电(辽宁火电厂)+ 沈阳变压器 / 大连电机 等设备厂。

### 体制内家庭(父母是国企 / 公务员)

- **核心诉求**:孩子接班体制 + 不掉档。
- **推荐路径**:**985 电气(大工 / 东大)+ 党员 + 国网总部(北京)/ 国网辽宁本部(沈阳)** → 比父母层级更高。
- **关键提示**:**别浪费 985 牌子去县公司**,985 电气进省本部以上岗位是默认路径。

### 想跳出东北的家庭

- **核心诉求**:孩子去南方发展。
- **推荐路径**:**985 电气 → 南方电网(广州 / 深圳 / 珠海)/ 国网长三角省公司 / 设备厂(西电(西安) / 平高(河南) / 特变(新疆))** → **南网比国网开放 + 薪资略高 + 珠三角生活舒适**,适合不愿留辽宁的辽宁高分孩子。

### 女生学电气

- **不推荐进基层电厂 / 县公司**(户外作业 + 巡检 + 倒班 + 男生主导环境)。
- **推荐路径**:**985 电气 + 考研到电力调度 / 经研院 / 信通方向 → 国网省公司机关 / 调度中心** → 办公室技术岗 + 不倒班 + 福利好。
- **辽宁女生学电气**:大工 / 东大 985 + 党员 + 调度方向 → 国网辽宁电力调度中心(沈阳)= 辽宁女生体制内最优解之一。
