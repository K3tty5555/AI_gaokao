# 计算机 / 软件工程 — 行业潜规则(辽宁视角)

## 一句话真相

CS 这个专业全国 truth 是**头部 985/211 通吃,中游学校转码挤破头,二本以下毕业即转行**。但放到辽宁,还要叠加一个东北特殊背景:**辽宁本地的 IT 产业天花板远低于长三角/珠三角**,留辽 = 起薪天花板就是大连软件园 / 沈阳东软,**想吃互联网红利必须出省**,这一点辽宁孩子一定要看清。

---

## 全国行业 truth(跨省共享)

### 1. 学校档次比专业方向更重要

- **985 计算机 / 软件 / 人工智能**:三选一无所谓,大厂校招都看,差异不大。
- **211 计算机系**:能进大厂,但相比 985 拿到 SP/SSP offer 概率低 30-50%,简历筛选时位次靠后。
- **双非一本计算机**:除非是西电 / 北邮 / 杭电这种特定行业强校,**否则大厂校招几乎绝缘**,只能走中小厂 / 外包 / 国企信息中心。
- **二本计算机**:**毕业即转行**比例高,真心想做 CS 必须考研冲 985/211。

### 2. CS 内部"伪细分"陷阱

- **"人工智能"专业 ≠ 比 CS 更值钱**:很多学校 AI 专业课程其实就是 CS 课减几门 + 加机器学习两门课,**用人单位主要还是看 CS 基础**,AI 专业纯名字红利,2020 年开的现在已经稀释。
- **"大数据 / 网络空间安全 / 物联网"**:除非该校在这方向有真实研究底子,否则就是 CS 的换皮专业,**优先选纯 CS 或软件工程**。
- **"软件工程 vs 计算机科学"**:软件工程偏工程实践 + 找工作友好,CS 偏理论 + 适合考研深造。**本科不打算读研直接就业 → 软件工程性价比高**。

### 3. 35 岁危机是真的

- **互联网大厂裁员潮持续**(2023-2025 字节 / 阿里 / 美团都裁了),**35 岁后业务岗位裁员概率显著增加**。
- 应对路径:① 30 岁前做到 P7+/ 高级,转管理 ② 转向稳定的研发型央企 / 银行科技子公司 ③ 提前考公(大龄考公难度极大,一定要提前)。
- **本科 CS → 大厂干 5-8 年 → 转大型国企 IT 部门 / 银行科技 / 互联网公司 base 二线** 是当下主流退路。

### 4. 学历要求隐性提高

- 2018 年大厂校招本科起步,2023 年开始**头部大厂研发岗实际门槛已经是 985 硕士**,本科想进只能进部分二线大厂或测试岗。
- **本科 CS 想进字节腾讯研发** = 必须考研,起码 985 硕士。

## 辽宁本地化(关键!)

### 留辽宁就业的真实天花板

- **大连**:东软集团总部(大连开发区软件园)+ 华信 / 文思海辉 / 简柏特 / 大连 IBM 全球服务中心。**起薪本科 8-15w / 硕士 12-20w**,资深 P7 等级 30-50w 封顶,**比北上深同等岗位低 30-50%**。
- **沈阳**:东软沈阳园 + 沈阳软件园 + 中兴 / 华为研究所(规模偏小)+ 各种政企信息化项目公司。**起薪本科 7-13w / 硕士 10-18w**,沈阳 IT 普遍偏"项目外包 + 政企对接",**纯互联网产品型公司极少**。
- **大连软件园 vs 沈阳软件园**:大连国际化更强(对日外包大本营,**会日语 + 会编程 = 大连 IT 园铁饭碗**),沈阳更偏国内政企项目。
- **硬伤**:**辽宁本地没有一线互联网产品大厂**(腾讯 / 阿里 / 字节都是研发 / 销售办事处规模),想做产品创新型工作只能出省。

### 出省路径(辽宁孩子的常见去向)

- **京津**(占出省 40%):北京字节 / 美团 / 百度 / 京东研发岗 + 中关村互联网公司,辽宁 985 本硕去得最多。沈阳 → 北京高铁 4h,**京津是辽宁高分孩子的"second home"**。
- **长三角**(占出省 30%):上海 / 杭州 / 苏州 / 南京,长三角薪资比辽宁高 60-80%,但生活成本同步上升。
- **珠三角**(占出省 20%):深圳腾讯华为 / 广州网易,**辽宁出深圳的孩子相对少**(地理远 + 文化差异 + 没有同乡网络),**愿意去深圳的辽宁孩子往往是高分段 + 有进大厂决心的**。
- **海外**:**辽宁 985 本科出国读研比例约 8-12%**,大工 / 东大去美国 + 香港 + 新加坡为主,大连孩子多有日韩留学传统(地理近 + 经济成本低)。

### 辽宁 CS / 软件 适合什么家庭

- **东北体制内家庭**:父母多是国企工人 / 退休职工 / 公务员,**家里希望孩子稳定 + 留辽**。这种家庭推 **东大软件 / 大工软件 + 留辽 IT 园 + 辅修日语 / 韩语 + 大连开发区对日外包**,起薪不高但稳定 + 国际化味道。
- **想跳出东北的家庭**:孩子有出省决心 + 父母不强求留辽 + 孩子学习能力强 → **大工 / 东大 CS 主线 + 大三主动去北京字节实习 + 京津长三角就业**,这是辽宁高分 CS 的最优解。
- **工薪家庭独子**:父母指望孩子留沈阳 / 大连接班养老 → **东大软件 / 大工软件 / 沈航软件 / 大连大学软件**,起薪本科 8-12w + 父母满意度高 + 离家近。
- **不要为了"留辽"而硬选辽宁双非**:如果孩子分数够 985(全省 1.5-2w 名以内),**为了离家选辽宁双非 CS = 自废武功**,大厂校招简历直接被刷,毕业后大概率转行。

### 辽宁本地高中孩子的常见误区

- **误区 1**:"我家孩子能进大工 CS 就稳了" → 大工 CS 在 985 里只能算中游,**和北邮 / 西电 / 哈工大 CS 比起来,大厂校招简历筛选权重明显低一档**。想做大厂研发,**辽宁 985 本科 + 出省考研** 才是稳的路径。
- **误区 2**:"东北 IT 没出路,孩子一定要去深圳" → 看孩子性格。大连本身有 IT 园 + 国际化港口 + 起步可以,**性格不爱漂泊的孩子留大连比硬去深圳更幸福**。深圳 IT 加班强度 + 房价 + 生活成本对东北家庭冲击非常大。
- **误区 3**:"AI / 大数据 / 区块链 听起来比 CS 高级" → **辽宁本地学校的 AI 专业大多是 2020 年新开的,师资是 CS 老师转岗的**,课程内容并不比纯 CS 强,反而少了编译原理 / 操作系统这些 CS 核心课。**优先选纯 CS / 软件工程**。
- **误区 4**:"留学日韩走不通 IT" → 大连开发区对日外包是真实存在的产业,**大工 / 东大软件 + 学日语 + 进东软日本部门 / 简柏特**,起薪不高但日企稳定 + 有机会派驻日本 + 不内卷,适合不想 996 的孩子。

### 性别差异

- **男生 + 工科严谨派 + 不抗拒加班** → 出省北上深大厂主线。
- **女生 + 学习好 + 想稳定 + 留辽** → 大工 / 东大软件 + 大连软件园对日外包 + 学日语 + 进日企或研究所路径。**辽宁 IT 圈女生留大连开发区对日外包比例高,生活舒适度比互联网大厂强很多**。
- **女生 + 想做产品 / 设计 / 测试** → 沈阳东软测试岗 + 大连 IT 园测试岗 / 项目管理岗,**985 软件 + 测试岗女生留辽就业是稳的路径**。

## 一句话送给辽宁 CS / 软件 考生家长

**留辽吃稳饭,出省搏天花板,二选一别骑墙。** 想留辽 → 大工 / 东大 / 大连大学软件 + 大连软件园对日外包 / 沈阳东软 / 政企 IT 项目;想出省 → 大工 / 东大 985 主线 + 大三去北京实习 + 长三角珠三角研发岗。**最怕的是辽宁双非 CS 强行考公或转行**,中间路径走得最痛苦。
