# 考公优选专业表(辽宁视角)

## 一句话总结

辽宁家庭"考公"几乎是默认选项 — 经济下行 + 国企收缩 + 体制内偏好极强。**但考公分国考 / 省考 / 选调生 / 事业编 / 教师编 / 警校直招** 6 条路径,**每条对应专业 / 学校 / 招录条件不同**,选错专业 = 4 年后才发现想考的岗位自己专业不对口。

---

## 辽宁考公环境真相

### 国考辽宁岗位特点

- **辽宁国考主力**:**海关(大连 / 营口 / 丹东)+ 海事局(大连 / 营口 / 丹东)+ 边检(丹东中朝边境 / 大连港)+ 税务总局辽宁省局 + 国家统计局辽宁调查总队 + 银保监会辽宁监管局**。
- **特色**:**辽宁是沿海 + 边境 + 港口大省,海关 / 海事 / 边检 国考岗位比内陆省份多**。
- **辽宁国考热门岗位**:大连海关 / 大连海事局 / 沈阳海关 / 沈阳税务系统 → 辽宁本地考生 + 985/211 + 党员 = 高竞争力组合。

### 辽宁省考真相

- **辽宁省考招录规模**:约 4000-6000 人 / 年(波动),沈阳 + 大连 两市直岗位含金量最高。
- **岗位分布**:**沈阳市直 + 大连市直 + 14 地市基层 + 乡镇街道**。
- **三不限岗位**:不限专业 + 不限户籍 + 不限基层经验 = 竞争最激烈(报录比常 100:1+)。
- **限专业岗位**:**财经 / 法学 / 中文 / 计算机 / 电气 / 土木 / 临床医学 / 公共卫生 / 统计 / 审计** 是高频招录方向。

### 辽宁选调生

- **辽宁选调生供给校**:辽大 + 大工 + 东大 + 大连海事 + 中国医大 + 大连交大 + 沈阳工业大学(部分年度) + 部分省外 985(清北人复交 等)。
- **辽宁定向选调**:**面向 985 大学 + 部分 211(辽大 / 大连海事 等)+ 党员 + 学生干部 + 担任过班长 / 学生会主席 等**。
- **岗位特点**:**辽宁定向选调起步副科级**(乡镇党委副书记 / 县直科级岗),**比省考起点高一档**,2-3 年提副科 + 5-7 年提正科是常态路径。

### 辽宁警察 / 警校直招

- **中国刑警学院(沈阳)**:**辽宁本地最强警校 + 公安部直属**,毕业后**全国铁公检系统** 都能进,辽宁孩子学公安天花板。
- **辽宁警察学院**:辽宁本省警校,毕业留辽宁公安系统。
- **入警门槛**:**身体条件 + 政审 + 党员 / 团员 + 高考分数过警校线 + 公安联考 = 全套通关 → 入警**。

## 优选专业 — 按"考公适配度"排序

### Tier 1:考公"高速公路" 专业(招录数 + 适配岗位最多)

#### 1. 法学 / 法律(三大文)

**适配岗位**:法院 / 检察院 / 公安(法制岗)/ 司法局 / 各部委法规处 / 政府法务岗 / 银保监 / 证监会。

**辽宁本地强校**:
- **辽宁大学法学**(辽宁本省法学第一档,选调主供给)
- **大连海事大学法学**(海商法是大海事独门绝技,海事局 / 海关法务 对口)
- **东北财经大学法学**(财经背景法学,适合金融监管岗)
- **沈阳师范大学法学 / 渤海大学法学**(双非但辽宁地市基层公检法对口)

**关键路径**:**辽大法学 → 法考通过 → 党员 → 选调到沈阳 / 大连基层 → 副科起步**。

#### 2. 汉语言文学 / 中国语言文学类

**适配岗位**:党委办公室 / 政府办 / 宣传部 / 文旅局 / 党校 / 教师编(初高中语文)。

**辽宁本地强校**:
- **辽宁大学汉语言**(辽宁省直机关秘书岗主供给)
- **辽宁师范大学汉语言**(大连本地教师编主供给)
- **沈阳师范大学汉语言**(沈阳本地教师编主供给)
- **大连大学 / 渤海大学**(地市基层岗位)

**关键路径(女孩)**:**辽师 / 沈师汉语言(师范方向) → 教师资格证 → 普通话二甲 → 大连 / 沈阳市直高中教师编**。

#### 3. 财政学 / 会计学 / 审计学 / 经济学

**适配岗位**:税务系统(国税地税合并后)/ 财政局 / 审计署 / 人民银行 / 银保监 / 海关核估岗 / 国资委 / 国企财务岗。

**辽宁本地强校**:
- **东北财经大学**(财经第一档,东北财政税务系统主供给,辽宁财经类公务员"黄埔军校")
- **辽宁大学会计 / 财政**(综合 211,选调路径强)
- **大连理工经济管理学院**(985 牌子兜底,会计 / 经管 也能进体制)

**关键路径**:**东财财政学 / 税收学 → 党员 → 国考税务系统辽宁分局** = 辽宁财经考公性价比之王。

#### 4. 计算机科学与技术 / 软件工程 / 网络工程

**适配岗位**:**信息中心 / 网信办 / 公安网监 / 国安 / 海关信息中心 / 银保监技术岗 / 政府数字化转型岗**。

**辽宁本地强校**:
- **大连理工 / 东北大学 软件 / 计算机**(985 牌子 + 党员 → 国考公安部网监 / 网信办 顶级路径)
- **大连海事大学计算机**(211 + 海事系统对口)
- **沈阳工业大学计算机 / 大连交通大学**(双非但辽宁本地体制内技术岗对口)

**关键路径**:**大工 / 东大计算机 + 党员 → 国家网信办 / 公安部网监 / 海关信息中心** = CS 专业进体制的最佳路径。

#### 5. 师范类(教师编)

**适配岗位**:中小学教师编(就近分配)/ 高校辅导员 / 教育局编制岗。

**辽宁本地强校**:
- **辽宁师范大学**(大连本地中小学认可度第一档 + 大连市直编制主供给)
- **沈阳师范大学**(沈阳本地中小学认可度第一档 + 沈阳市直编制主供给)
- **渤海大学**(锦州本地及辽西基层中小学)
- **鞍山师范学院**(鞍山及周边基层)

**关键路径**:**辽师 / 沈师师范专业 → 教师资格证 → 普通话二甲 → 大连 / 沈阳市直中小学编制**。

### Tier 2:考公"中速公路"(部委 / 行业部门强对口)

#### 6. 临床医学 / 公共卫生 / 预防医学

**适配岗位**:卫健委 / 疾控中心 / 医院预防保健科(事业编)/ 海关卫生检疫岗。

**辽宁本地强校**:
- **中国医科大学公卫学院**(辽宁省疾控中心主供给)
- **大连医科大学公卫**

**关键路径**:**中国医大公卫 → 辽宁省 / 沈阳市疾控中心编制**(技术岗朝九晚五)。

#### 7. 统计学 / 应用统计

**适配岗位**:统计局 / 调查总队 / 央行统计司。

**辽宁本地强校**:东北财经大学统计学院。

#### 8. 公共管理 / 行政管理 / 社会工作

**适配岗位**:民政局 / 街道办 / 残联 / 妇联 / 工会。

**关键提示**:**公共管理是"看似考公专业实则鸡肋"**,招录数远低于法学 / 汉语言;**别为了"考公好考"选公共管理**,本科公管竞争力低于法学 + 经济。

#### 9. 海关管理 / 国际经济与贸易

**适配岗位**:海关核估 / 缉私 / 海事局 / 边检 / 商务部门外事岗。

**辽宁本地强校**:
- **大连海事大学**(海事 / 海关对口最强,辽宁海事编制主供给)
- **东北财经大学国贸**

**关键路径**:**大连海事大学 海事管理 / 海商法 → 国考大连海关 / 营口海关 / 丹东海关**。

### Tier 3:专业性强 + 行业部委对口

#### 10. 电气工程及其自动化

**适配岗位**:**国家电网 / 南方电网 / 五大发电(虽是央企国企非公务员,但等同铁饭碗)+ 应急管理部能源岗 + 电力监管委** 。

**辽宁本地强校**:沈阳工业大学 / 大工 / 东大 / 东北电力大学。

#### 11. 土木 / 水利 / 交通运输

**适配岗位**:住建局 / 自然资源局 / 水利局 / 交通局 / 中国铁路 / 中交集团等。

**辽宁本地强校**:大连理工土木 / 大连交通大学(铁路对口)。

#### 12. 警察类专业(治安学 / 侦查学 / 经济犯罪侦查 等)

**适配岗位**:**全国铁公检系统 + 公安部各局 + 国安部** = 警校独有的"提前批 + 公安联考" 直招路径。

**辽宁本地强校**:
- **中国刑警学院(沈阳)** = 公安部直属警校,辽宁警察天花板。
- **辽宁警察学院** = 辽宁本省警校,毕业留辽宁公安。

**关键路径**:**中国刑警学院 → 公安联考通过 → 全国 / 辽宁公安系统入警**。

## 辽宁考公"避坑专业"

### 看似考公友好但实际惨的专业

#### 1. 工商管理 / 市场营销 / 旅游管理 / 物流管理

- **真相**:**招录岗位极少 + 多对应"三不限"高竞争岗**,**没有任何专业壁垒**。**别为了"管理类听起来好"选这些专业**,考公竞争力远不如法学 / 财政 / 中文。

#### 2. 哲学 / 历史学 / 社会学 / 心理学

- **真相**:**招录岗位极少 + 主要进党校 / 高校 / 研究院**(都要博士起步)。**本科哲学 / 历史 / 社会学 → 考公基本走"三不限" 拼运气**,适配性差。
- **辽宁视角**:辽大有这些专业但**纯文科本科考公 = 辽大法学 / 中文 > 哲学 / 历史**。

#### 3. 农林类(非辽宁主流)

- **真相**:**辽宁本省农林岗位招录不多**(辽宁是工业省非农业省),**学农林考公 → 多数要去基层农业局 / 林业局**,岗位偏远 + 待遇低。
- **辽宁视角**:**沈阳农业大学农林专业** 在辽宁考公并不强势,**别学农林冲辽宁体制内**。

#### 4. 艺术类(美术 / 音乐 / 设计)

- **真相**:**艺术类考公岗位极少 + 几乎只能进文化馆 / 图书馆 / 美术馆 等清水衙门**,**起薪低 + 晋升慢**。
- **辽宁视角**:**鲁迅美术学院 + 沈阳音乐学院** 学生考公主要去文化系统,**别为考公选艺术**。

## 辽宁考公家庭画像匹配

### 工薪独女考公 = 黄金路径

- **首选**:**辽大法学 / 辽大汉语言 + 党员 + 选调** → 沈阳市直 / 省直公务员副科起步。
- **次选**:**辽师 / 沈师汉语言(师范) → 大连 / 沈阳市直教师编**。
- **保底**:**渤海大学 / 沈阳师范大学法学 / 中文 → 辽宁地市基层公检法**。

### 工薪独子男考公 + 进央企 = 双保险

- **A 路径**:**沈阳工业大学电气 → 国家电网辽宁分公司**(虽非公务员但等同铁饭碗)。
- **B 路径**:**辽大法学 + 党员 → 沈阳 / 大连选调 → 副科起步**。
- **C 路径**:**中国刑警学院 → 公安联考 → 全国 / 辽宁公安**(适合身体条件好 + 稳定偏好的男孩)。

### 中产体制内家庭独生子女 = 选调路径

- **A 路径**:**辽大 / 大工 / 东大 985/211 + 党员 + 学生干部 → 辽宁定向选调 → 起步副科**。
- **B 路径**:**出省 985 文科(人大 / 武大 / 复旦) + 选调返辽** → 起点高于父母资源。

### 想做警察 / 公安系统的男孩

- **首选**:**中国刑警学院(沈阳)**(全国铁公检最佳路径)。
- **次选**:**辽宁警察学院**(辽宁本省公安)。

## 辽宁考公"早规划" 时间轴

- **大一**:发展党员(预备党员 → 党员)+ 学生干部(班长 / 学生会)+ 普通话二甲 + 英语四级。
- **大二**:法考(法学专业必备)+ 计算机二级 + 第二学位(法学 / 经济学 双修最强)。
- **大三**:**实习关键 → 政府机关 / 国企 / 银行 实习** + 教师资格证(师范类)+ 准备申论 + 行测刷题。
- **大四**:省考 + 国考 + 选调生考试 + 教师编考试 全套报名。
- **关键提示**:**辽宁选调生 必须大四上学期报名 + 党员 + 学生干部 双硬指标缺一不可**,大三发现自己不是党员就来不及了。
