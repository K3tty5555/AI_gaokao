# 中国医科大学(中国医大,CMU)— 双非但临床医学顶级

## 一句话定位

**沈阳大本营,临床医学全国前 15**,**协和医学院前身之一**(1931 年从同济大学医学院分出独立),**军医出身 + 老牌名医院校**。**附属一院 / 盛京医院 / 第四医院** 都是东北顶级三甲。**辽宁本土医学第 1 + 双非但临床校招卡不动**(医学卡的是临床实力,不是综合排名)。

---

## 真实地位

- **辽宁省 / 国家卫健委 / 教育部 共建**,**双非但临床顶级**,**辽宁医学校 No.1**。
- **历史血脉**:**1931 年中国工农红军军医学校**(瑞金成立)→ **1940 年定名"中国医科大学"** → **1948 年合并原"满洲医科大学"** → **现今的沈阳大本营**。**协和医学院体系 + 同济医学院体系前身之一**(1931 年从同济大学医学院分出),**老牌底蕴 + 红色血脉 + 军医基因**。
- **附属医院群辐射东北**:**盛京医院**(综合实力东北顶级)、**附属一院**(综合)、**附属四院**(口腔 / 妇产)、**附属三院**(肿瘤)、**附属盛京沈阳市儿童医院**等,**实习 + 工作机会东北最丰富**。
- **沈阳浑南主校区(主)+ 北区**,大碴子味中等,**医学院氛围严肃苦累**。
- **男女比约 4:6**(临床 / 护理女生多),**学风极卷**(临床医学考研率 60%+ / 5+3 一体化是主流路径)。

---

## 辽宁物理类录取位次区间

参考近 5 年辽宁一分一段表(医学专业必选化学 / 生物):

- **顶级组(临床 5+3 一体化 / 口腔 5+3 / 八年制本博)**:全省 **2,000-4,500 名**(**逼近 985 大工 / 东大录取分**,因为医学顶配)。
- **王牌组(临床医学 5 年制 / 口腔医学 5 年制)**:全省 **4,500-8,000 名**。
- **主流组(影像医学 / 麻醉学 / 儿科学 / 法医学)**:全省 **8,000-13,000 名**。
- **边缘组(护理学 / 公共卫生 / 药学 / 部分医学技术)**:全省 **13,000-25,000 名**。

**段位定位**:辽宁物理类 **省排 2,000-25,000 名** 可冲中国医大不同方向。**临床医学 5+3 + 八年制录取分逼近 985**,**护理 / 公卫 / 药学 等非临床专业录取分相对低但出口窄**。

## 性价比专业 / 关键路径

- **临床 5+3 一体化(本硕一体化)**:**录取分逼近 985 但毕业即硕士 + 节省 1 年**,**走规培直接进三甲医院** 的最优路径。
- **口腔医学**:**沈阳 + 大连私立口腔行业蓬勃 + 高薪**(主治医师 30-50w/年),**比纯临床自由度更高 + 不靠编制活**。
- **法医学**:**全国前列 + 录取分相对低 + 公安系统 / 司法鉴定 编制对口**,**冷门但出口稳定**。
- **影像医学(放射科 + 超声科)**:**临床里相对"轻松"的科室 + 起薪不输临床**,适合不想做手术的医学生。

## 坑专业 / 慎选(在中国医大里相对弱)

- **护理学**:**双非中国医大牌子救不了护理出口窄**,**护士起薪低 + 工作累 + 晋升慢**,**学护理出省北医协和护理 / 川大华西护理 才是顶配**(实在想留辽就业看)。
- **公共卫生 / 预防医学**:**疫情后稍受关注但出口仍然窄**,**疾控中心 + 卫健委 编制有限 + 起薪低**。
- **药学 / 中药学**:**药企 / 医院药剂科 + 起薪不如临床 + 行业偏冷门**,**学药学想做研发出省北大医药 / 沈阳药科大学**。
- **医学技术 / 医学信息工程**:**医学+技术交叉学科**,**毕业出口模糊**,**不如选纯临床或纯技术(CS)**。
- **报中国医大但分数不到临床的考生**:**别为了"中国医大牌子"上护理 / 公卫 / 药学**,**这些专业出口不如同分的辽大经管 / 双非 211 计算机**。

## 关键提醒(填报陷阱)

1. **医学路径漫长 + 普通家庭慎重**:**5 年本科 + 3 年规培 + N 年专硕 / 专博 + 30 岁才独立行医**,**经济回报延迟 + 压力大 + 错过结婚年龄**。**家庭经济一般 + 急需就业的别冲医学**。
2. **5+3 vs 5 年制 vs 八年制**:
   - **5+3 一体化**:本硕连读 8 年(出来硕士),**主流路径**,**性价比最高**
   - **5 年制临床**:本科 5 年(出来本科),**必须考研 + 医院招聘卡硕士**,**实质要 7-8 年**
   - **八年制本博**:本博连读 8 年(出来博士),**附属医院直接录用 + 跨阶级路径** + **录取分顶配**
3. **报考必选化学 + 生物**:**辽宁 3+1+2 选科**,**医学绝大多数专业必选化学 + 生物**,**没选化生别冲医学**。
4. **服从调剂注意**:**临床冲不上 + 调剂可能进护理 / 公卫 / 药学**,**勾服从前问问能不能接受**(护理 / 公卫 出口和临床差距巨大)。
5. **附属医院 vs 自找医院**:**中国医大附属医院系统庞大**(盛京 / 一院 / 四院 等),**留校进附属医院规培 / 工作概率高**(辽宁本省考生天然优势)。

## 中国医大 vs 同档医学校(辽宁视角)

| 维度 | 中国医大 | 大连医科大学 | 北医协和(出省) | 川大华西(出省) |
|---|---|---|---|---|
| 综合定位 | 双非临床顶 | 双非临床第二档 | 985/双一流(协和) | 985(华西医学) |
| 临床地位 | 全国前 15 | 中上 | **全国第 1-3** | **全国前 5** |
| 城市 | 沈阳(辽宁本省) | 大连(辽宁本省) | 北京(顶配地理) | 成都(西南顶) |
| 留辽优势 | **极强(附属医院辐射东北)** | 中上(大连本地) | 弱 | 弱 |

**简单结论**:**辽宁本省学医 + 留东北 → 中国医大 No.1**;**分够北医协和 / 华西出省顶配 → 出省医学 985 更好**;**分不到中国医大 → 大连医科大学(双非第二档)**。

## 毕业出口(2024 数据估算)

- **留辽宁就业**:约 60-65%(沈阳 35% + 大连 15% + 鞍山 / 营口 / 锦州等 15%,**辽大附属医院系统是主战场**)
- **京津出省**:约 20%(北京 / 天津三甲医院 + 协和体系医院,**协和血脉加成在京津认可度高**)
- **长三角出省**:约 8-10%(上海 / 杭州三甲)
- **其他(华南 + 海外)**:约 5-8%
- **考研 / 读博 / 规培**:**约 60%+**(医学校保研 + 考研率最高,**5 年制必须考研才有医院要**)
- **进三甲医院概率**:**约 50-55%**(规培 + 留院 + 跳槽 三甲)
- **起薪范围**:**主治医师(规培完 3-5 年后)10-25w / 年**,**副主任医师 30-50w / 年**,**口腔医生 / 私立医院 30-80w / 年**,**护理 / 公卫 6-12w / 年**(差距大)。

## 适合谁

- 辽宁物理类 **省排 2,000-8,000 名** + **必选化生 + 想做医生 + 留东北/京津** 的考生(临床 / 口腔)。
- **家庭经济中上 + 能熬 8-13 年医学路径 + 不急着工作挣钱**。
- **想做医生 + 进附属盛京医院 / 一院体系**(辽宁本省考生天然优势)。
- **想做口腔 / 法医 等"特色路径"** 的考生(口腔高薪 + 法医冷门稳定)。
- **女生学医 + 想留沈阳/大连家门口** 的考生(医学校女生多 + 留辽率高)。

## 不适合谁

- **没选化学 / 生物**:辽宁 3+1+2 选科,医学必选化生,**没选别冲**。
- **家庭经济一般 + 急需就业挣钱**:**医学 8-13 年延迟回报**,**普通家庭压力大**,**选大工 / 东大工科 + 4 年本科 + 大厂 30w 起薪**性价比更高。
- **学护理 / 公卫 / 药学但不爱医**:**为了"中国医大牌子"上边缘专业 = 出口和临床差距巨大**。
- **不能接受漫长规培 + 三甲医院压力**:**医学路径心理压力 + 加班 + 医患关系**,**心理脆弱 + 不能熬夜值班的慎重**。
- **分够北医协和 / 华西的高分段**:**出省医学 985 + 北京/成都地理优势 + 顶级医院规培资源**,**辽宁高分段医学生别 stuck 留辽**。
