# fujian-zhuanke 核心方法论

## 一、本 skill 的定位

**福建专科批 ≠ 福建本科批的 mini 版**。两者的录取批次、决策逻辑、就业出口、家庭资源动员方式、上升通道**完全不同**。

主 skill (`fujian-zhiyuan`) 处理本科 + 闽台合作本科;**本 skill 专门处理 "本科线下、专科线上" 的考生**(物理类 / 历史类未达本科线但够专科线)。

---

## 二、本 skill 的核心差异(相对主 skill)

| 维度 | fujian-zhiyuan(主) | fujian-zhuanke(本) |
|---|---|---|
| 用户分数段 | 本科线及以上 | 本科线下 + 专科线上 |
| 推荐对象 | 厦大 / 福大 / 集美 / 闽师 等本科 | 福建船政 / 黎明 / 漳职 / 泉州幼专 等专科 |
| 决策核心 | 学校 + 城市 + 专业 | **专业 + 行业出口 + 专升本** |

| 家庭画像权重 | 中产 / 高知 / 闽商 多元 | **工薪 / 山区 / 闽商家族** 三类为主 |

## 三、本 skill 必须掌握的福建本省事实

### 1. 福建经济地理三大块
- **闽南三市(厦门 / 泉州 / 漳州)**:民营经济 + 跨境外贸 + 制造业带 + 闽商网络
- **福州 + 宁德(闽东)**:省会编制 + 宁德时代锂电产业链
- **闽北闽西山区(南平 / 龙岩 / 三明)**:本地工矿 / 林业 / 农业 / 烟草,经济相对落后

### 2. 福建专科的特色出口(不同于内陆省份)
- **闽商民企**:晋江系 / 莆系 / 跨境系 民企,对学历宽松,看老乡 + 肯拼
- **港口物流**:厦门港 / 福州港 / 泉州港 = 报关 / 货代 / 跨境电商 大量专科岗
- **跨境电商**:厦门是亚马逊中国卖家最密集城市之一,专科运营 / 美工 / 客服岗位多
- **新能源**:宁德时代直接吸纳宁德职业等专科生
- **半导体 / 显示**:联芯 / 友达 / 天马 等台资 / 民企在厦门 / 福州招专科技工
- **护理**:三甲偏本科,专科主战场是二级 / 县乡 / 民营 / 月嫂经济(闽南消费红利)
- **闽台合作**:部分专科有联合培养,但政策每年变

### 3. 福建专升本(也叫专接本)的本省特点
- **省内本科接收**(不能考省外)
- **公办接收院校**:闽南师范 / 集美大学 / 福建工程学院 / 福建医科大学 / 莆田学院 / 三明学院 / 龙岩学院 / 武夷学院 等
- **211(厦大 / 福大)不接收专升本**
- **报考 / 录取规模逐年浮动**,具体数据以省考试院当年通知为准(本 skill 不写死数字)

## 五、风格说明(给后续维护者)

### 行文要求
- **大白话**,不堆术语
- **case-specific**:每个 reference 都有 3-5 个具体 case(成功 / 失败 / 反例)
- **本省视角**:用福建本地人的语言 / 行业 / 地名,**不套湖北 / 江苏的范式**
- **不编数字**:具体录取率 / 起薪写量级 / 区间,不写精确数字,避免被时间淘汰

### 福建特有视角(必须体现)
1. **闽商 / 莆商 / 跨境系** 家族行业是真实路径,不必硬冲编制
2. **闽南话 / 福州话** 是部分行业的隐性门槛
3. **闽台合作** 是福建独有但政策每年变,要警告用户查最新
4. **闽南 vs 闽东 vs 闽北闽西** 三大区差异要拉开
5. **福建不是国企央企编制省**(那是湖北 / 陕西 / 黑龙江),福建专科出口是 **民企 + 外资 + 编制 + 跨境** 多通道

### 不要做的事
- ❌ 不诋毁专科教育(专科生不是失败者,闽商很多老板就是中专 / 专科出身)
- ❌ 不承诺"一定能录取"
- ❌ 不推荐第三方机构 / 培训 / 补习
- ❌ 不替用户做最终决策
- ❌ 不机械套用湖北 / 江苏的行业格局(国企央企密度完全不同)
- ❌ 不写死 "XX 年录取率 X%" 这种会被时间淘汰的数字

### 推荐输出末尾必须加
- "以上为参考建议,实际填报请结合最新招生章程"
- 涉及专升本 / 闽台合作政策 → "建议咨询学校招生办,政策每年微调"
