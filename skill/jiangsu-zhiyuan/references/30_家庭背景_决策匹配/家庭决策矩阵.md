# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(江苏视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

**江苏特殊性**:**苏南苏中苏北分化是家庭档位之外的第二维度**。**苏南家庭普遍重私企/外企/创业**(全国家长里"父母觉得编制没出息"比例最高的省之一),**苏中苏北家庭普遍重体制/编制**。Agent 在套档位之前要先问考生**所在地市**,然后叠加地理维度判断。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入)+ 地理(苏南/苏中/苏北),按本文件的 5 档矩阵 × 苏南苏北 套对应策略。

## 江苏地理三档(必须先认这个)

| 区域 | 城市 | 家庭普遍偏好 | 学校选择倾向 |
|---|---|---|---|
| **苏南** | 南京 / 苏州 / 无锡 / 常州 / 镇江 | **重私企外企创业 + 留长三角** | 南大东南 + 苏大 + 上海/复旦 + 中外合作 |
| **苏中** | 南通 / 扬州 / 泰州 | 平衡型(私企体制各半) | 苏大 + 南理工/南航 + 南师定向 |
| **苏北** | 徐州 / 盐城 / 连云港 / 淮安 / 宿迁 | **重体制内 + 编制 + 留省内** | 南师定向 + 矿大(徐州本地)+ 警校 + 国网 |

**关键**:同样工薪家庭,**苏南家庭可能更愿意冒险走苏州中产路径**,**苏北家庭更倾向编制兜底**。这是江苏家长之间的隐性鸿沟。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易

**江苏独有**:**江苏选调生待遇全国最优**(苏南苏中市直机关起点),**江苏体制内家庭推 985/211 选调路径优先级 = 国考 > 省考**

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化)
   - **南大文科 / 法学 / 经济学** = 江苏选调顶配
   - **东南马克思主义理论 / 法学** = 工科校选调路径
   - **苏大法学 / 中文** = 211 选调路径(江苏选调指标多)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突
4. **特殊机会**:**江苏警官学院 + 公安联考** = 父母编制资源能用上;**南师定向师范** 也是体制内家庭"内部资源"路径(父母在教育系统的话)

**典型 case**:
- 南京某中产体制内家庭(父亲省直机关,母亲银行)→ 孩子 615 分历史类 → 推南大法学 → 毕业选调进江苏省委办,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去东南 CS → 毕业 30w 起薪很高,但家长不满"不稳定",劝其离职考公,**两年的时间损耗 + 心理纠结**
- 苏北徐州体制内家庭 → 孩子 580 分文史类 → 推江苏师范大学(徐州)汉语言 → 毕业徐州市考公考编,**苏北体制内家庭最匹配**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:
   - **教师家庭** → 师范 / 公费师范 / 南师江苏定向师范(**江苏苏北苏中尤其友好**)
   - **医生家庭** → 临床 / 口腔(8 年长周期父母能撑);**江苏特色:药学(中国药科大学)也是医生家庭的好替代**
2. **行业相关延伸**:律师家庭 → 法学(南大法学 / 苏大王健法学院);工程师家庭 → 对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲苏州中学语文老师 + 父亲普通工薪 → 孩子 600 分历史类 → **南师江苏省定向师范汉语言(签约苏州)** → 毕业回原校或同区编制,**母亲资源直接复用**
- 父母都是江苏省人民医院临床医生 → 孩子 670 分物理类 → **南大临床八年制 / 上交医八年制** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 父亲苏州某医药企业研发 → 孩子 620 分物理类 → **中国药科大学药学** → 毕业进苏州恒瑞/信达,**父亲行业拐杖 + 江苏药企总部对口**

## 档位 ③ 私企管理 / 创业家庭(江苏苏南最常见 ★★★)

**定义**:父母私企中高管 / 自主创业 / 企业主。

**江苏特殊性**:**这一档在苏南占比全国最高(可能仅次于浙江)**。苏州 / 无锡 / 常州 / 南京 民营经济发达,**潮汕 / 苏南家族企业 + 工业园区中产 + 服装制造业老板** 普遍是这一档。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **苏南私企家庭普遍嫌"考公没出息"**,跟体制内家庭推荐方向几乎相反

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
   - 南大商学院 / 上财(出省) / 央财(出省) / 中欧(MBA 后路径)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野
   - **苏南家庭中外合作选项极丰富**:西交利物浦(苏州)、昆山杜克、宁诺中外合作、香港中文(深圳)、各地 985 中外合作项目
   - **苏州 + 西交利物浦** = 苏南私企家庭"留苏 + 国际化"完美组合
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内基层**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **接班路径**:管理 / 财务 / 法律 = 接班三件套,优先选实用商科

**典型 case**:
- 苏州某外贸私企老板家庭(年入 300w+) → 孩子 580 分物理类 → 推**西交利物浦大学(苏州)国际经济与贸易**(中外合作,学费 8-12w/年家里能撑) → 接班外贸或英国读研后回苏州做家族企业升级
- 无锡某机械私企家庭(年入 100w+) → 孩子 615 分物理类 → **东南机械工程**(技术接班) + 父亲推荐家族企业实习 → **985 工科 + 父亲行业资源**完美组合
- 失败 case:苏南私企家庭 → 孩子被推考公(因为"稳") → 进苏北基层公务员后被父母嫌"没出息" → 3 年后离职接班,**家庭基因不对路 + 时间损耗**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 10-30 万为主。

**江苏特殊性**:**苏南工薪 vs 苏北工薪生活水平差异大**。苏南工薪(苏州/无锡工厂工人)年入 15-25w + 房子是父辈的,**比苏北工薪(徐州/盐城工厂)实际可支配高**。但**苏南房价高,孩子留苏南买房压力大;苏北留省内压力小**。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **南师江苏省定向师范** = 江苏工薪家庭神器(免学费 + 211 牌子 + 直接编制 + 父母身边)
   - **江苏警官学院 + 公安联考** = 进警察系统编制
   - **南京工程学院电气** = 江苏隐藏王牌,**双非进国网概率压一些 211**(参考 10_行业就业潜规则/电气_电网.md)
   - 医学技术(医学影像 / 检验) = 三甲医院技术岗 + 4 年本科即可
3. **次推稳定就业型**:
   - **东南/南理工/南航 工科** 进央企(分够 211 头部以上)
   - **中国药科大学药学** 进江苏药企(分够头部 211)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-12w,跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)
   - **苏州/上海中外合作办学**(8-15w/年学费,工薪撑不起)

**典型 case**:
- 苏州工厂工薪家庭 → 孩子 580 分物理类 → 推**南京工程学院电气**(2024 进国家电网 江苏省主供给校) → 毕业进苏州供电公司,**月入 1.0-1.4w + 编制,家庭逆袭**
- 苏北徐州工薪家庭 → 孩子 595 分历史类 → 推**南师江苏省定向师范汉语言(签约徐州市)** → 毕业回徐州中学有编有岗 + 不要学费 + 211 牌子,**苏北工薪家庭命运改变路径**
- 苏中南通工薪家庭 → 孩子 605 分物理类 → 推**南京邮电大学通信工程** → 毕业进江苏移动 / 苏州中兴 / 华为南研基层岗 + 编制式稳定 + 起薪 12-15w
- **(失败案例)**:苏州工薪家庭被"互联网光鲜"洗脑 → 孩子推双非 CS → 毕业进苏州工业园某外包公司 7k → 跟同村南京工程学院电气男生(月入 1.0w + 编制)对比反差强烈

## 档位 ⑤ 农村 / 临工家庭(江苏苏北较多)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。

**江苏特殊性**:**江苏农村家庭主要分布苏北(徐州 / 盐城 / 宿迁 / 淮安农村)**,**苏南"农村"实际生活水平接近苏中工薪**(因为长三角辐射 + 工业园区产业带)。**真正需要"跨阶级"的江苏农村家庭基本在苏北**。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **南师江苏省定向师范** = 江苏苏北农村家庭神器(无学费 + 编制 + 父母身边)
   - **国家专项计划 / 高校专项** = 农村专属优惠(江苏农村户籍优惠多)
   - **江苏警官学院 + 公安联考** = 进警察系统编制
   - **南京工程学院电气** = 双非进国网,苏北县级供电所稳定铁饭碗
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:江苏农村户籍,985/211 名校多个专项指标(分数比统招低 20-30 分)
     - **南大 / 东南国家专项** = 苏北农村孩子上 985 关键路径
     - **苏大 / 河海 / 南理工 / 南航 国家专项** = 211 + 农村专项
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会(南大强基)
   - **军校(国防科大、解放军理工等)** = 无学费 + 编制 + 包分配,**苏北农村适配**
   - **中国矿大(徐州本地)** = 苏北徐州农村学生**省内 211 + 离家近 + 矿业央企对口**

**典型 case**:
- 江苏徐州农村家庭 → 孩子 605 分物理类 → 通过**国家专项**进**南京大学化学**(比统招分低 20-25 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985**
- 江苏宿迁农村女孩 → 600 分历史类 → 推**南师江苏省定向师范汉语言(签约宿迁某县)** → 4 年无学费 + 毕业回原县编制,**最适合江苏苏北农村家庭的"零风险"路径**
- 江苏盐城农村男孩 → 580 分物理类 → 推**南京工程学院电气**(双非但是江苏国网主供给校) → 毕业进盐城供电公司基层 + 编制,**苏北农村工薪 + 不要 985 牌子但要稳定**的最优路径
- 江苏徐州农村家庭 → 孩子 615 分物理类 → 推**中国矿业大学(徐州)采矿工程** → 211 牌子 + 矿业央企对口(国家能源/中煤等) + 家在徐州不用出远门,**苏北家庭独有路径**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 × 江苏地理**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**江苏特别原则**:**苏南私企家庭跟苏北农村家庭即使家庭年收入一样,推荐方向也可能完全相反**。**苏南更愿意冒险走中产路径,苏北更需要编制兜底**。Agent 必须显式问"考生家在江苏哪个城市"。
