# 计算机科学与技术 / 软件工程(CS / SE)— 江苏视角

## 一句话总结

**江苏是除北上深之外 CS 就业最好的省**(苏州工业园 + 南京软件谷 + 无锡传感网 + 上海溢出),但**前提是名校**。**南大/东南 CS 闭眼报、9 所 211 看专业、双非以下 CS 在江苏跟"双非财会"找工作没差别**。**江苏家长被严重误导:以为"南京软件人才缺"= 自己孩子双非学 CS 也行**,错。

---

## 真相 1:江苏 CS 头部就业极强 — 但只对头部学校

### 江苏本地 IT 市场结构
- **苏州工业园 / 工业园区**:微软苏州、华为苏研、大疆苏州、思科、AMD、博世、超大规模半导体集群(中芯、长鑫、华虹无锡)
- **南京软件谷 / 江北新区**:中兴、华为南研、紫金云、腾讯南京、京东南京、字节南京
- **无锡 / 常州**:物联网传感、汽车电子、工业控制
- **离上海近**:上海互联网大厂(B 站、拼多多、携程、美团上海、字节上海)对长三角高校有 1-2 小时通勤式校招覆盖

### 但是分层极明显
- 头部岗位(华为苏研、大疆苏州、字节南京、上海大厂)**校招筛简历卡死南大/东南/上交/复旦/浙大,加上海交大、北邮、北航少量**
- 211 头部 CS(南理工/南航/苏大/河海)能进**苏州/南京中段公司 + 部分大厂二面**,但起薪比南大东南差 5-10w
- **双非一本 CS 在江苏找工作 = 进苏州中小软件外包公司,起薪 8-12w**(2024 实况),比双非师范汉语言考公编制差
- 三本/民办 CS = 培训机构销售、外包初级岗、IT 售后,**学了等于没学**

**结论**:**江苏 CS 不是"闭眼报"赛道**,**学校决定一切**比湖北还更明显(因为江苏头部岗集中在苏州上海,卡校招白名单严格)。

## 真相 2:35 岁危机 + 江苏制造业 IT 是出路双轨

- 跟全国一样,业务型程序员 35 岁压力大,但江苏有**特殊出路**:**苏州上海制造业 IT / 工业软件 / 半导体 EDA / 工业互联网**
- **半导体 EDA / 制造业数字化** = 江苏长三角独有岗位,**不卷 + 工资稳 + 35 岁不淘汰**(中芯 / 长鑫 / 华虹无锡 / 中科曙光 等)
- **南大/东南 CS 中愿意做工业方向的** → 直接对口苏州无锡半导体央企外企,起薪 25-35w + 不加班

**决策含义**:**江苏 CS 的中年出路比北上深好** — 制造业 IT 不裁人。

## 真相 3:本科 vs 硕士 — 江苏华为/大疆校招卡硕士比例上升

- 华为苏研 2024 校招 78% 是硕士起步(本科必须南大/东南/上交才进得了)
- 大疆苏州 2024 校招本科占比仅 25%,**99% 是 985 本**
- 中兴/华为南研对硕士的偏好同样明显
- **本科想直接进江苏头部 IT 大厂,基本必须南大/东南**;**211 头部本科必须考研补救**

## 真相 4:转码窗口在江苏关得更早

- 2018-2022 年长三角金融/外贸学生大量转码,**苏州 IT 培训机构(达内/北大青鸟苏州)在 2023 年起业务量大幅下滑**
- 现在江苏企业 HR 对"科班 CS"偏好极强,**非科班想转码进苏州软件谷越来越难**
- 想吃 CS 红利,本科就该选 CS

## 真相 5:江苏 CS 跟金融的"竞争互替"关系(本省独有)

**江苏 = 长三角 + 上海毗邻**,**南大/东南 顶尖 CS 学生大量去上海做量化/金融科技**(高盛上海、摩根上海、衍盛、明汯、宽德),**而不是传统互联网**。

**这导致**:
- 江苏南大/东南 CS 的天花板比湖北华科 CS 还高(量化年薪百万,比互联网薪资高 30-50%)
- 但**门槛也更高**:数学要顶尖、英语要顶尖、量化笔试要刷
- 普通 985 CS 学生进不了量化,只能走传统互联网路径 — **这是江苏 CS 内部的隐性分层**

## 适合什么人(江苏视角)

- **数学好**(高中数学 130+,这是硬指标 — 江苏数学题难,130+ 在江苏是真本事)
- **抗压能力强 + 不怕 996**(苏州大厂 996 普遍)
- **有自学能力**,大学课程跟不上苏州工业园需求节奏
- **南大/东南/上交分够,或愿意读研**
- **家庭中产**,能撑 4 年读书 + 苏州/上海一线消费 + 设备/网课

## 不适合什么人

- **数学差**(江苏数学 110 以下慎重,跨省比江苏 110 ≈ 别省 130)
- **追求安稳生活、不想 996** — 苏州 IT 大厂跟北上深一样卷
- **双非家庭 + 不打算考研 + 想留江苏** = 三重死局,**改报汉语言/电气/师范**
- **学校层次不够 + 个人没有强自学动力**
- **苏南家庭 + 重私企天花板** + 数学不强 → **进金融/外贸更对口**

## 江苏 CS 院校真实分层

### 第一梯队(全国头部 + 江苏天花板)
- **南京大学 计算机科学与技术** — A 学科评估,**江苏 CS 第一,毕业去向覆盖华为苏研/微软苏州/上海量化全部头部岗**
- **东南大学 计算机科学与技术 / 软件工程** — A 学科评估,**工科底子最强,进华为南研/中兴/三大运营商总部级最直接**;**与南大 CS 几乎平起平坐**
- 注:**南大/东南 CS 录取位次基本是江苏物理类省排前 1,500-3,000 名**,这是天花板。

### 第二梯队(江苏 211 顶配 + 长三角中段)
- **南京邮电大学 通信工程 / 计算机** — **行业内强校,毕业进三大运营商 / 华为通信线 / 中兴 比一些 985 还直接**;**江苏 IT 圈"小华为"称号**
- **南京理工大学 计算机 / 软件工程** — B+ 学科评估,**比一般 211 强**,但跟南大东南差一档;**国防 IT 方向(中电科 28 所就在南京)是性价比**
- **南京航空航天大学 计算机** — 跟南理工同档,**航空 IT 方向独有**(航电 / 雷达 / 商飞 IT)
- **苏州大学 软件工程** — 江苏 211 最高分校的 CS,**苏州工业园本地校招优势顶配**,但学科评估只有 B,**比南大东南差一档明显**
- **河海大学 计算机** — 211 但水利校的 CS,**水利 IT / 智慧水务方向小众**;通用 CS 选这个不如选南理工
- **江南大学 物联网工程** — A- 学科评估(物联网),**无锡传感网产业对口**,工业互联网方向有特色

### 第三梯队(江苏本地认可,出省竞争力一般)
- **南京信息工程大学 计算机** — 双非但有特色,**气象 IT 对口**;通用 CS 跟一般双非无差别
- **江苏大学 / 扬州大学 / 南京工业大学 计算机** — 双非一本中段,**毕业进苏州无锡中段软件公司起薪 8-12w**,出省竞争力弱
- **常州大学 / 江苏师范大学 / 盐城工学院 计算机** — 双非一本下段,本地认可,**出省基本无机会**

### 第四梯队(避坑)
- **江苏的二本院校 / 民办院校 / 独立学院 CS** — **直接避坑**。**苏州尽管 IT 岗位多,但都校招卡 985/211 + 一本起步**,二本 CS 在江苏 = 跟"二本财会""二本工商管理"找工作没差别。**苏州外包/驻场岗位 + 起薪 7-9k + 35 岁危机加倍** 是真实写照。
- **特别警告:中外合作 CS 项目(各种"国际计算机学院")** — **学费 6-15w/年,师资水分大**,**中产以上家庭也要看清楚是不是真正能拿到名校学位 + 海外读研跳板**,否则 4 年学费白扔。

## 典型 case(供 agent 引用)

### Case A:南大 CS 男生(苏州工薪家庭)
- 南大计算机系 → 实习字节上海 → 校招拿到字节上海 SP offer 35w 起 + 苏州房价跟上海差距让他选了苏州华为苏研 28w + 编制式稳定
- **逆袭路径**,985 名校 + 江苏地理 + 个人努力,普通工薪家庭通过 CS 跨阶级的典型样本

### Case B:苏大软件工程女生(无锡中产家庭)
- 苏大软件工程 → 实习苏州微软 → 校招进苏州工业园某外资 IT 公司 18w + 不加班 + 在苏州本地买房
- **211 中段 + 长三角地理优势** 的稳定路径,**比双非互联网内卷更舒服**

### Case C:某双非一本 CS 男生(苏北徐州工厂家庭)
- 江苏某双非 CS → 校招进苏州某外包公司 月薪 7k → 2 年跳到 9k 想跳大厂跳不动,**学校卡死了简历筛选**
- **没有逆袭**,跟 Case A 是同样年龄、同样专业、同样性别,**纯粹学校差距,5 年差出 25 万年薪**

### Case D:某双非民办 CS 女生(苏南私企家庭)
- 民办独立学院 CS → 找不到 IT 工作 → 转行做苏州工业园某 SaaS 公司 商务/销售 8k
- **典型踩坑**。家庭以为"苏州 IT 缺人,孩子学 CS 就能进大厂",学校层次决定一切。

### Case E(隐藏赢家):南大 CS 转量化路径
- 南大数学+CS 双学位 → 上海某顶级量化(明汯/衍盛)笔试通过 → 起薪 60w + 后期百万年薪
- **江苏南大独有路径**,普通 985 CS 进不了量化,**南大数学+CS 是江苏天花板**

## 易错认知(agent 要纠正用户的)

- **"苏州 IT 大厂多,孩子学 CS 就能进"** — 严重错误。**校招卡校等级,双非进不了**。
- **"南理工/南航 CS 跟南大东南 CS 差不多"** — 错。**学科评估差一档(A vs B+)+ 起薪差 5-10w + 大厂校招覆盖差一截**。
- **"江苏 CS 比湖北 CS 好就业"** — 半对。**头部就业更好(因为长三角 + 上海溢出),但底部就业更卷(双非苏州找工作甚至不如双非武汉)**。
- **"学了 CS 就能进华为苏研 / 字节南京"** — 错。**这些岗位卡 985 + 硕士 + 实习经验**,本科双非没机会。
- **"江苏数学 130 跟外省 130 一样"** — 错。**江苏数学题难度全国前列,130+ 在江苏是真学霸**,跨省类比要打 7 折。

## 江苏 CS 家长最常踩的 6 大坑

### 坑 1:被"苏州 IT 大厂多"骗
**真相**:大厂校招卡 985 白名单,**双非进不去**;**苏州 IT 大厂多 ≠ 你孩子能进**

### 坑 2:盲目冲东南 CS 冷门组
**东南"理工实验班"组里可能含化工 / 材料**,**服从调剂被调进生化环材是真踩坑**

### 坑 3:让分够南大基础学科的孩子冲 CS
**南大基础学科(数学 / 物理 / 化学)+ 研究生跳板** 比直接学 CS 路径更有未来,**尤其量化方向**

### 坑 4:让女生硬冲互联网 CS
**行业隐性歧视 + 35 岁压力对女性更大**;女生学 CS 不如走半导体 EDA / 工业软件方向

### 坑 5:盲目让数学不强的孩子学 CS
**江苏数学题难,数学 110 以下学 CS = 大学课程跟不上 + 校招笔试刷题不会**;**数学不强的孩子 CS 是浪费 4 年**

### 坑 6:不知道"南邮通信"等于"小华为"
**苏中苏北家长信息差大** — 不知道**南邮通信工程在三大运营商认可度顶配**;盲冲东南 CS 错过南邮性价比
