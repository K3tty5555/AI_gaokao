# 电气工程及其自动化 / 电网 — 江苏视角

## 核心结论

**江苏是国家电网"江苏省电力公司"的核心战场,也是华东电网区域中枢**。**普通家庭男生通过电气进电网的路在江苏依然好走,且比中西部省份多一个隐藏出路:进核电(中核中广核大本营)/ 风电光伏(盐城南通海上风电基地) / 半导体配套(中芯长鑫供电)**。**学校 + 专业方向选对,这条路在江苏比 CS 性价比高,前提是认清"国网江苏 vs 国网外省 vs 南网"的三档路径**。

## 关键事实

### 行业格局
- **国家电网**(江苏省电力公司隶属) + **南方电网**(广东总部,江苏不直接覆盖)
- **国家电网江苏省电力公司**:总部南京,江苏省内 13 地市公司 + 县级供电所,**编制总数 5w+**,2024 年校招总量约 3,000-3,500 人
- **国家电网每年江苏校招** = 江苏省内 985/211 + 电力八校 是主力,**双非一本要拼硕士**
- **隐藏赛道**:江苏独有的核电 / 海上风电 / 半导体大厂供电 三大新能源/工业用电,**对电气专业本科 / 硕士需求量大**

### 招聘门槛(2024 实况,江苏视角)
- **985 电气专业**(南大/东南/上交 等)≈ 闭眼进国网江苏省公司管理岗 / 中核中广核
- **电力八校**(华北电力 / 上交 / 浙大 / 华科 / 重大 / 西交 / 华南理工 / 武大)电气 ≈ 进国网江苏省公司或地市公司管理岗概率极高
- **东南大学电气**(虽不在电力八校但江苏本地认可顶配)≈ 国网江苏省公司管理岗主供给
- **江苏 211 电气**(河海/南理工/南航 — 注意这 3 所电气都不强,详见下文)→ **本科只能进市级或县级**
- **南京工程学院**(双非,但是江苏本地"电力黄埔") → 江苏家长隐藏王牌,**本科直接进江苏国网县级供电所概率极高**
- **双非一本电气** → **硕士可以进省级,本科只能进基层**
- **二本三本电气** → 基本只能进基层(县乡变电站、抢修班),**也是编制**

### 薪资水平(国网江苏,2024 实况)
- 省公司管理岗:9000-16000/月 + 五险一金 + 公积金 12% + 各种补贴(**江苏经济发达,比中西部省网工资高 20-30%**)
- 苏南地市公司(苏州/无锡/常州):8000-14000/月
- 苏中地市公司(南通/扬州/泰州):7000-12000/月
- 苏北地市公司(徐州/盐城/连云港/宿迁/淮安):6000-10000/月
- 县级公司:5500-9000/月
- **核电(中核 / 中广核)在田湾 / 苏州**:管理岗 12-20w + 高补贴 + 倒班(辐射岗有特殊补贴)
- **海上风电(国家电投盐城/南通基地)**:基层 12-18w + 海上倒班(海洋作业补贴)
- 全部带编制,**福利住房 / 子女教育 / 医疗 / 退休稳定**

### 工作内容现实(江苏)
- 基层岗:抢修、巡线、检修、调度,**有夜班 + 户外 + 体力要求**(女生慎重)
- 管理岗:办公室、运营、规划、营销,体力要求小
- 专业技术岗:研究院、调度中心,**对学历要求高,硕士起步**
- **江苏特殊**:苏州工业园配电(给中芯/长鑫等半导体厂供电的特殊岗位)、海上风电(盐城/南通海上倒班)、核电(田湾/连云港核电站岗位)— 三类岗工资高 + 编制 + 但有特殊工作环境

## 易错认知(agent 要纠正用户的)

- "**学电气一定能进电网**" — 错。电网每年招 3w 人,看学校 + 专业排名 + 综合表现。**双非毕业不考研基本只能进基层**;**南京工程学院是江苏隐藏王牌例外**
- "**进电网就是当电工**" — 错。管理岗、调度岗、市场营销岗都是办公室工作。基层电工只是其中一种岗位
- "**女生不适合电气**" — 半对。基层不适合(体力 + 户外),**省级管理岗女生完全 OK**,但门槛高(东南/上交)
- "**电气就是国家电网,没别的出路**" — 错。**江苏特殊**还有:核电(中核中广核连云港田湾 / 苏州大亚湾分部)、风电(盐城/南通海上风电)、半导体配套(中芯/长鑫/华虹无锡 配电技术岗)、各发电集团(华能/大唐/华电/国电/三峡)、电气设备公司
- "**电气和自动化是一回事**" — 错。**电气 = 强电(电网、电机、电力系统)**,自动化 = 弱电(控制、传感、机械控制)。**找电网工作认电气,不认自动化**
- "**南京工程学院就是普通双非**" — 严重错误。**江苏家长一定要知道,南京工程学院在国网江苏招聘里跟 211 电气几乎平起平坐**,这是江苏独有的隐藏王牌
- "**苏南考生要去苏南国网**" — 半对。**苏南国网竞争极激烈**(苏州/无锡/常州工业基础好,工资高,所有人都想留),苏北国网竞争小很多 + 编制同样稳定 + 苏北本地房价低 + 离家近,**有时苏北国网比苏南国网性价比更高**

## 关键提醒

**报电气不是为了"学技术",是为了"进电网"或"进核电/风电"**。如果学校层次不够进不了管理岗,**这个专业的吸引力大打折扣**(技术含量并不比其他工科高,薪资也不如苏州 IT)。**所以学校选择是这个专业的核心决策**。

**江苏特别提醒**:
1. **南京工程学院是江苏家长必须知道的隐藏王牌**(双非 + 进国网概率比一般 211 还高)
2. **核电(连云港田湾)+ 海上风电(盐城/南通)**是江苏独有出路,东南/河海电气可走
3. **苏北国网编制比苏南更易拿** — 苏北考生别盲目挤苏南

### 坑 1:认为"南京工程学院就是普通双非"
