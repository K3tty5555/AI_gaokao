# 考公优选专业表(江苏本地视角)

## 核心结论

**专业决定考公选岗范围**。江苏家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**江苏特殊性**:**江苏选调生在全国所有省里待遇最优**(苏南/苏中/苏北市直机关起点 + 编制 + 工资比一般省份高 20-30%),**江苏 985/211 学生选调路径优先级 > 国考 > 省考**。**苏南家庭对考公的接受度比苏中苏北低**(因为私企机会多),但**苏中苏北家庭考公意愿全国前列**。

## 关键事实(2024 国考 / 江苏省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 江苏省考特殊性
- 江苏省考 + 各市公务员考试,**汉语言文学和法学并列考公第一专业**
- 江苏各地市公务员岗位**对法学要求高**(法院、检察院、司法局)
- **苏南市直机关**(南京/苏州/无锡):岗位高质量 + 报名比 50-100:1
- **苏中地市**(南通/扬州/泰州):岗位适中 + 报名比 30-50:1
- **苏北基层岗位**(徐州/盐城/宿迁/淮安):岗位多 + 报名比 20-50:1,**苏北本地户籍优势**
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)

### 江苏选调生 ★★★ 全国最强(必读!)
- **江苏选调生 = 党政机关后备干部储备**,起点比普通公务员高
- **江苏选调生待遇全国领先**:
  - **南京市直机关选调生** 起点级别 + 苏南工资水平
  - **苏中地市直机关选调生** 起点 + 中等工资
  - **苏北基层选调** 起点 + 编制 + 福利住房 + 苏北本地房价低 + 父母身边
- **985/211 才有资格报**:江苏本地的选调生定向计划基本只对 **985/211 + 部分省内重点高校**
- **优势专业**:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **江苏选调生具体路径**:
  - **南大 / 东南** 学生 → 江苏省级选调指标主供给
  - **苏大 / 南师 / 南理工 / 南航 / 河海 / 矿大 / 南农 / 江南 / 南医 / 中药 / 南邮** → 江苏省内选调
  - **出省 985(清北/复交/上海/浙大/中科大)** → 江苏选调跨省生源,**特别欢迎,待遇好**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、江苏警官学院等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,江苏本地南京政法 / 苏大王健法学院对口

- **Case C(苏南选调)**:江苏苏州考生,640 分历史类,中产家庭。**报东南大学法学** → 毕业获得江苏选调生资格,直接进苏州市某区委办,**苏南市直机关选调起点 + 苏南房价压力但工资水平高**
- **Case D(苏北选调)**:江苏盐城考生,610 分历史类,普通家庭。**报苏大王健法学院** → 毕业回盐城走选调,**苏北基层选调编制 + 编制稳 + 房价低 + 父母身边**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(江苏 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**(江苏警官学院对口)
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考。**江苏选调生待遇全国最优,资格内竞争激烈但回报最高**
- "**汉语言文学就是当老师**" — 严重错误。**这是江苏家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**江苏 985 选调要去苏南苏中**" — 错。**苏北选调岗位多 + 苏北本地户籍优势 + 苏北基层 = 升迁起点,3-5 年后调动到苏南也是常态**;苏北农村家庭孩子选调留苏北是非常好的选择
- "**苏南家庭让孩子考公没出息**" — 半对。**苏南私企家庭确实考公意愿低**,但**苏南名校 + 选调路径 = 进江苏省委 / 苏州市委,起点远超双非进苏州工厂**;关键是家长能不能放下"私企天花板高"的执念

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是江苏家长被严重低估的考公王者**。

**江苏特别提醒**:
1. **江苏选调生 = 全国最优渥的选调路径**(苏南苏中市直机关起点 + 工资压全国一票省份)
2. **南大 / 东南 法学 / 中文 / 经济 / 马院 = 江苏选调金牌专业**
3. **苏大王健法学院 = 211 选调路径**,苏南律所 + 司法系统认可顶配
4. **苏北本地户籍 + 苏北基层选调 = 苏北农村孩子最稳跨阶级路径**(本地户籍优势 + 编制 + 房价低)
5. **江苏苏南家庭对考公接受度比苏中苏北低 + 名校选调起点远超双非进私企**:agent 要敢于直接 reality check 苏南家长的"考公没出息"偏见

## 江苏考公具体路径分级

### 路径 1:江苏选调生(985/211 才有资格)
- **省级选调**:江苏省委组织部统一招录,毕业直接到江苏省直机关 / 各市直机关
- **市级选调**:各市选调生计划(南京 / 苏州 / 无锡 / 徐州等)
- **基层选调**:苏北基层乡镇 / 县直机关
- **优势**:起点高 + 编制稳 + 江苏选调待遇全国前列 + 升迁通道清晰

### 路径 2:江苏省考(本科都能报)
- **江苏省直机关 + 13 个地市的市直机关 + 县级 + 乡镇**
- **苏南市直机关报名比 50-100:1**
- **苏北基层 20-50:1 + 本地户籍优势**
- **三不限岗位 1000:1**(竞争最激烈)

### 路径 3:国考
- **国家公务员考试**,在江苏的中央驻苏机构(国税 / 海关 / 银保监 / 海事局 等)
- **南京海关 / 苏州海关 / 江苏国税局** 是重点对口
- **国考竞争激烈但跨地域调度**

### 路径 4:事业编 + 教师编 + 医院编
- **教师编**:走教师招聘考试(江苏各市统考)
- **医院编**:三甲医院公开招聘
- **事业编**:江苏各事业单位招聘(人才引进 / 公开招聘)

### 路径 5:警察 / 公安联考(江苏警官学院专属通道)
- **江苏警官学院** 毕业生走"公安联考",**江苏本地公安系统编制**
- **不走普通公务员通道**

### 路径 6:三支一扶 + 西部计划(基层路径)
- **三支一扶**:江苏苏北基层岗位 + 服务期满享受公考加分
- **西部计划**:服务西部省份 + 期满返苏加分

### 机会 1:江苏定向选调(全国最优渥)

- **苏北家庭 + 苏北本地户籍** = 报江苏苏北基层选调有"本地户籍优惠"
- **苏北基层选调上岸后 3-5 年常调动到苏南苏中**(隐藏跃迁)

## 江苏考公家长最常踩的坑

### 坑 1:苏南家长嫌"考公没出息"

### 坑 2:盲推"行政管理"以为考公
**错**。**汉语言 / 法学的考公优势远超行政管理**;**行政管理本科水分大 + 考研也卷**

**错**。**江苏理科生学汉语言考公优势更大**(行测思维严谨);江苏 3+1+2 物理类报汉语言完全可以

### 坑 4:不知道"江苏选调生 vs 普通公考"区别
**江苏家长只听说过"考公务员"** — 不知道**选调生是另一个通道**;**985/211 学生强烈推荐选调生路径(资格内竞争小 + 起点高)**
