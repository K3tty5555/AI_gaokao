# 南京航空航天大学(南航,NUAA)— 211 航空航天顶配

## 一句话定位

**民航 + 航空航天工业对口校**,飞行器设计 / 航空宇航 / 民航工程 全国前列。**进中国商飞 / 中航工业 / 三大航空公司 / 国产大飞机项目 = 南航第一对口**,民航飞行员定向班是顶级路径(分高 + 体检过)。

---

## 真实地位

- **211 + 工信部直属高校**(原"南航 + 南理工"双子,都是国防工业系统 211)。
- **江苏本省地位**:江苏 211 工科前列,跟南理工同档但行业不同口(南航偏航空航天 / 民航,南理工偏兵器陆军)。
- **同档对比**:北航(北京)/ 西工大(西安) 都是航空航天 985,**南航是航空航天体系里唯一非 985 的顶级 211**,长三角地理 + 录取分相对低。
- 学风工科严谨 + 男多女少(约 7:3)+ 将军路 / 明故宫双校区。

---

## 江苏物理类录取位次区间

参考近 5 年掌上高考 + 江苏一分一段表:

- **顶级组(飞行器设计 / 计算机 / 自动化 / 民航工程)**:全省 **8,000-13,000 名**。
- **主流组(电气 / 通信 / 机械 / 材料)**:全省 **13,000-22,000 名**。
- **冷门组(部分理学 / 经管)**:全省 **22,000-30,000 名**。
- **民航飞行员定向班(提前批 / 体检过)**:全省 **15,000-30,000 名**(**分数比裸分进南航低 30-50 分,但要过严格民航体检**)。

**段位定位**:江苏物理类 **省排 30,000 名内可冲南航**,**13,000 名内可挑王牌组**。**以一分一段表反查为准**。

## 性价比专业

- **民航工程 / 飞行器适航技术**:**进民航局 / 三大航(国航 / 东航 / 南航公司) / 机场集团**对口,行业稳定。
- **飞行员定向班(提前批)**:**比裸分录取分低 30-50 分,但毕业直接是机长培养路径,起薪 30-50w + 后期百万年薪**;**条件:民航体检过 + 视力 / 身高达标 + 政审过**。
- **航空材料 / 航空发动机**:**进中国航发 / 中航工业**,行业冷门 + 录取分相对低。

## 坑专业 / 慎选(在南航里相对弱)

- **文科 / 经管 / 法学**:南航文科边缘,**学文科直接选南大或南师**。
- **生物 / 化学 / 材料(非航空方向)**:生化环材天坑,**别报通用材料,要报就报航空材料**。
- **公共管理 / 信息管理**:水专业,**慎入**。
- **空中乘务 / 空乘类**(部分专科 / 高职批):**学历段较低 + 行业内卷**,本科考生别冲。

## 关键提醒(填报陷阱)

1. **南航本部 vs 南航金城学院**:**本部才是 211**,金城学院是独立学院,**学费贵 + 牌子差**,**报志愿别看错代码**。
2. **飞行员定向班是顶级路径但有硬约束**:
   - **民航体检要过**(色弱 / 近视过深 / 身高不达标都不行)
   - **政审要过**(三代直系亲属无重大问题)
   - **签订定向协议**(毕业必须去签约航司)
   - **失败成本**:体检不过 → 退回普通批
3. **物理类专业组分化**:
   - **顶级组**:航空航天 / 计算机 / 自动化
   - **主流组**:电气 / 通信 / 机械 / 民航工程
   - **冷门组**:理学 / 经管 / 部分材料
4. **南航 vs 北航 vs 西工大**:**北航 985 + 北京地理 + 录取分高一档**;**西工大 985 + 三航(航空航天航海)+ 西安地理**;**南航 211 + 长三角 + 录取分友好 + 民航对口最强**。
5. **南航 vs 南理工**:**同样国防系统 211,行业不同**,航空航天选南航,兵器选南理工。

## 毕业出口(2024 数据)

- **留江苏就业**:约 35-40%(南京 / 苏州为主)
- **出省(上海 / 北京 / 西安 / 成都)就业**:约 45-50%(**航空航天产业分布全国,出省多**)
- **考研 / 读博**:约 35%(保研率 ~15%,211 中段)
- **出国**:约 8-12%
- **进央企 / 国企概率**:**约 35-40%**(**中国商飞 / 中航工业 / 航天科技 / 三大航空公司 / 民航局 / 机场集团** 招聘大户)
- **起薪范围**:CS / 自动化 18-30w,航空航天对口央企 12-18w + 编制 + 房补,飞行员定向 30-50w 起。

## 适合谁

- 江苏物理类 **省排 8,000-30,000 名** + 想学航空航天 / 民航的考生。
- 笃定走**中国商飞 / 中航工业 / 航天科技 / 三大航 / 民航局** 央企路径的考生。
- **想当飞行员**(分数中段 + 民航体检过 + 政审过):**南航定向班是性价比最优**。
- **普通工薪家庭男孩**,想要稳定铁饭碗 + 央企编制路径。
- 男生 + 工科严谨派。

## 不适合谁

- **学文科 / 财经 / 法学**:南航文科弱,选南大或苏大。
- **学医 / 生物**:南航无医学,选南大医学院 / 苏大医学部。
- **学纯互联网 CS**:南航 CS 不如东南,**对口航空 IT 才是南航 CS 的核心优势**。
- **分够 985(北航 / 西工大)**:别在南航将就。
- **女生 + 不想进重工业 + 不想做飞行员**:航空航天工业整体男性主导。
