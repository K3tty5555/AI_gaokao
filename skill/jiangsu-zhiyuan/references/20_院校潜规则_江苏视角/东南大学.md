# 东南大学(东南,SEU)— 工科顶配 985

## 一句话定位

**南方工科第一档**,综合排名 Top 30 985,**建筑 / 电子信息 / 通信 / 交通 / 仪器 / 生物医学工程** 全国前 5,工科领域可与清华媲美。**江苏考生想学纯工科 + 留长三角 = 东南首选**,比南大工科强一大截。

---

## 真实地位

- **全国排名 Top 30 985**,但**工科实力压一票综合性 985**(浙大除外),建筑学全国第 1(老八校之首),仪器 / 生物医学工程全国第 1。
- **江苏本省地位**:仅次于南大的 985,物理类江苏省排前 5,000 内的主战场,**工科专业组分数甚至压南大冷门组**。
- **国防 / 央企认可度极高**:中国电科 / 中国建筑 / 中铁中交 / 中国移动 / 三大运营商 总部级招聘进东南是常态。
- 工科严谨学风 + 男多女少(约 7:3)+ 九龙湖校区现代工科风。

---

## 江苏物理类录取位次区间

参考近 5 年掌上高考 + 江苏一分一段表:

- **顶级组(电子信息类 / 计算机 / 建筑学 / 临床医学)**:全省 **1,500-3,500 名**。
- **主流工科组(自动化 / 通信 / 电气 / 土木)**:全省 **3,500-5,500 名**。
- **冷门组(化工 / 材料 / 部分文理混招)**:全省 **5,000-7,000 名**。

**段位定位**:江苏物理类 **省排 5,000 名内可冲东南**,3,000 名内可挑王牌组,**1,500 名内可冲顶级组**。**分数以一分一段表反查为准**,不要锚死历史分数。

## 江苏历史类录取位次区间

东南历史类招生量小(主要法学 / 经管 / 公管),全省 **前 800-1,500 名**。

## 性价比专业

- **仪器科学 / 生物医学工程**:全国第 1 但行业相对冷门,**录取分比电子信息 CS 低一档**,**进医疗器械 / 仪器制造对口央企**。
- **交通运输工程**:全国前 5,**进中铁 / 中交 / 地铁集团是稳的**,但行业基层有出差,录取分相对低。
- **马克思主义理论**:工科校的马院,**选调考公友好,录取分比工科主流低**。

## 坑专业 / 慎选(在东南里相对弱)

- **文科(中文 / 历史 / 哲学)**:东南文科边缘,**学文科直接选南大**。
- **经管 / 工商管理 / 金融**:东南经管不如南大商学院 / 上财 / 央财,**学纯财经直接换校**。
- **化学 / 材料 / 生物(纯理)**:生化环材天坑,**东南牌子救不了本科直接就业的尴尬**。
- **风景园林 / 城乡规划**:虽是建筑老八校体系,但**地产凋零 + 设计院过冬**,慎入。

## 关键提醒(填报陷阱)

1. **东南物理类专业组分组复杂**,主要分为:
   - **顶级组**:电子信息类(含 CS / 通信)、建筑类、临床医学
   - **主流工科组**:能源动力 / 自动化 / 电气 / 土木 / 交通
   - **理学 / 经管法组**:数学 / 物理 / 经管 / 法学
   - **冷门组**:化工 / 材料 / 部分文理混招
2. **建筑学是 5 年制**,要画图 + 美术功底,**不喜欢动手画图的别冲建筑学**。
3. **服从调剂注意**:工科主流组可能调到化工 / 材料等天坑方向,**勾服从前预想最差专业能否接受**。
4. **东南 vs 南大 vs 上交**:学纯工科建议东南或上交;学综合 / 文理选南大;**分够上交且想冲上海建议上交**(上交工科与东南同档 + 上海地理)。
5. **吴健雄学院(东南强基 + 拔尖班)**:本科直博 + 顶级师资,适合学术苗子。

## 毕业出口(2024 数据)

- **留江苏就业**:约 40-45%(南京 / 苏州为主)
- **出省(上海 / 深圳)就业**:约 35-40%(长三角占比 75%+)
- **保研 / 考研 / 读博**:约 50%(东南保研率 ~30%)
- **出国**:约 10-15%
- **进央企 / 国企概率**:**约 30-35%**(东南是中电科 / 中建 / 中铁 / 中交 / 国家电网的招聘大户)
- **起薪范围**:电子信息 / CS 25-40w,建筑学 15-25w(行业过冬),传统工科进央企 12-18w + 编制。

## 适合谁

- 江苏物理类 **省排 5,000 名内** + 想学纯工科的考生。
- 笃定走**电子信息 / 通信 / 建筑 / 交通 / 医疗器械** 任一行业的学生。
- **想进国家电网 / 中电科 / 中建 / 中铁中交 / 三大运营商 等央企**,东南是江苏对口校。
- 男生 + 工科严谨派 + 不在意校园文科氛围。
- 普通工薪家庭想本科直接就业出活的工科苗子。

## 不适合谁

- **学文科 / 哲学 / 中文 / 历史**:别在东南将就,选南大或南师。
- **学纯财经金融**:东南经管不如上财 / 央财 / 南大商学院。
- **想要文科氛围 + 老牌历史校园**:东南九龙湖现代工科风,文化氛围弱于南大。
- **分够上交且笃定要冲上海**:同档工科去上交更优。

## 校园 / 生活 / 学风(江苏家长关心的"软指标")

- **九龙湖校区(主校区)**:**现代化工科风**,大一到大四绝大部分专业在九龙湖。**远离市区(江宁开发区)+ 一进去就是工科氛围**,跟南大老校区"民国底蕴"形成鲜明对比。
- **四牌楼校区(老校区)**:在南京市中心鸡鸣寺旁边,**老建筑 + 民国底蕴**,但只有少数专业(如建筑学院)留四牌楼。
- **苏州校区**:在苏州工业园,**信息工程 / 集成电路 / 创新创业方向新校区**,**苏州本地考生新选项**(留苏州读 985 + 苏州工业园资源对接)
- **学风**:**严谨工科派 + 男多女少(7:3)+ 自习室通宵开** — 跟南大文科氛围完全相反,"东南理工男 / 南大文艺女"是江苏家长口中的对比
- **本科生宿舍**:九龙湖宿舍**条件比仙林新但远**,**生活朴素 + 不重氛围**;江苏家长选东南的不是冲校园来的,是冲"出活"
- **男女比**:**男多女少 7:3**,跟苏大 / 南师比氛围完全不同;**女生选东南要做好心理准备**(尤其工科专业)

## 苏南 vs 苏中 vs 苏北 家长视角分化(江苏特别)

- **苏南家长**:**东南是"留南京 + 进苏州/上海大厂"的对口校** — 苏南家庭看重东南的"工科 + 长三角对口央企"路径,比南大文理还更接地气
- **苏中家长**:**东南是"工科出活快"的代名词** — 苏中家庭(尤其工厂主家庭)对东南机械 / 电子 / 建筑有天然认同;**比南大更适合"出来直接挣钱"的家庭**
- **苏北家长**:**东南是"跨阶级 + 不走文科虚路"的优选** — 苏北农村男孩通过国家专项进东南工科 = 直接进央企编制,**比南大冷门组更稳**

## 大小年趋势提示(填报陷阱)

- **东南"吴健雄学院"**(强基 / 拔尖班)→ 录取分**比裸分进东南顶级组还高一档**,要做好直博承诺
- **东南建筑学**:**江苏家长每年扎堆冲**,**录取分压一些 985 工科**;**但建筑行业凋零(地产过冬),起薪 15-25w 不算高,慎冲**
- **东南苏州校区**(信息工程方向):**苏州本地考生 + 留苏州偏好** = 录取分**比九龙湖本部信息工程低一截**(地理偏好折扣),性价比反而高
- **东南医学院**(临床八年制)→ 录取分**比南大临床八年制略低**,**笃定走医的家庭可考虑**;但江苏中大医院规模 / 资源不如南大鼓楼医院
- **东南"理工实验班"组**:**组内可能含化工 / 材料**,**服从调剂前一定查招生章程具体组内有什么**;江苏苏中苏北考生最容易踩这个坑
