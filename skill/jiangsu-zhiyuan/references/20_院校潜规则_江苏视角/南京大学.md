# 南京大学(南大,NJU)— 综合性 985 第一档

## 一句话定位

**江苏本省"心理上限"高校**,综合排名 Top 10 985,文 / 理 / 医 / 法 / 经 全国前列,**天文地理化学物理生物中文哲学社会** 都是顶级。**江苏考生分够清北边缘 + 想留长三角 = 南大首选**。

---

## 真实地位

- **全国排名 Top 10 985**,跟北大复旦齐名,是 C9 联盟里唯一以"基础学科 + 综合性"立校的代表。
- **江苏本省地位**:江苏物理类省排前 2,000 内 + 历史类省排前 200 内的天花板,本省录取分常年压复旦交大同济。
- **同档对比**:文理基础学科与北大同档,医学与上交瑞金 / 复旦中山差一档但比浙大稍弱,工科明显不如东南 / 上交。
- 江苏家长心目中"读完出来体面 + 留沪宁苏锡常没问题 + 考公选调有指标"的代名词。

---

## 江苏物理类录取位次区间

参考近 5 年掌上高考 + 江苏一分一段表反查:

- **顶级组(强基 / 数理 / 计科 / 临床八年制)**:全省 **前 500-1,500 名**,基本对应 660+。
- **主流组(理工实验班 / 经管法 / 化学生物组)**:全省 **1,500-3,000 名**。
- **冷门组(地球科学 / 大气 / 部分文理混招)**:全省 **2,500-4,000 名**。

**段位定位**:江苏物理类 **想冲南大基本要省排 3,000 名内**,1,500 名内可挑专业,500 名内任选。**具体分数以当年一分一段表反查为准**,不要锚死历史分数。

## 江苏历史类录取位次区间

- 主流文科组(中文 / 历史 / 哲学 / 经管法):全省 **前 200-500 名**。
- 江苏历史类竞争异常激烈,南大历史类压复旦,**500 名外基本无戏**。

## 性价比专业(同样南大牌子,录取相对低)

- **天文学 / 地球科学 / 大气科学**:全国第 1 / 前 5 但行业冷门,录取分比 CS / 经管低,**适合喜欢学术 + 不在意就业广度的考生**。
- **哲学 / 古文字学 / 历史学**:适合考公选调路径,**南大文科牌子在江苏体制内极硬**。
- **强基计划(数学 / 物理 / 化学 / 生物 / 古文字)**:**比裸分进南大低一档录取**,但要承诺直博 + 不能转专业,适合学术苗子。

## 坑专业 / 慎选(在南大里相对弱)

- **纯工科(机械 / 自动化 / 电子)**:**南大工科不如东南**,出来跟东南同方向毕业生比薪资差一截,**这些专业直接选东南**。
- **生物科学 / 生物技术**:全国前 5 也救不了"必须读博"的现实,**慎选,除非笃定走学术**。
- **材料 / 化学(纯理学方向)**:生化环材天坑组合,**南大牌子也救不了本科直接就业的尴尬**。
- **新闻传播**:行业整体凋零,南大新闻不如复旦 / 人大,**毕业大量改行考公**。

## 关键提醒(填报陷阱)

1. **南大物理类专业组多达 6-8 个**,**"理工实验班"组内可能含化学 / 生物 / 材料 / 物理等多个方向**,服从调剂前务必查 2026 年招生章程具体组内有什么。
2. **强基计划 vs 裸分**:强基低 5-15 分进南大,但**直博绑定 + 不能转专业**,慎选。
3. **南大医学院 vs 上交医 / 复旦上医**:南大医学院在长三角认可度不如上交瑞金 / 复旦中山,**笃定走医的学生分够建议优先上交医 / 复旦上医**。
4. **南大 vs 复旦**:复旦在上海地理优势 + 财经更强;**学基础学科 / 文史哲 / 中文 → 南大不亏**;学金融 / 新闻 / 临床 → 复旦更优。

## 毕业出口(2024 数据)

- **留江苏就业**:约 35-40%(南京 / 苏州 / 无锡为主)
- **出省(上海 / 北深)就业**:约 35-40%(上海占大头,长三角整体 70%+)
- **保研 / 考研 / 读博**:约 50%+(南大保研率 ~30%,985 第一档水平)
- **出国**:约 15-20%
- **考公 / 选调**:约 10-15%(南大有省级选调指标)
- **起薪范围**:CS / 金融方向 25-45w,基础学科读博后 15-25w,文科考公进体制起薪 15w+ 编制。
- **进央企概率**:工科 / 经管类约 20-25%,基础学科以科研院所为主。

## 适合谁

- 江苏物理类省排 **3,000 名内** / 历史类 **500 名内** 的考生。
- 喜欢**基础学科 / 文史哲 / 综合通识** 的学术型选手。
- 家庭中产以上 + 父母不限定行业 + 鼓励读研读博 → 南大基础学科最合适。
- 想留长三角(尤其南京 / 上海)考公选调进体制内的考生。

## 不适合谁

- **铁了心要学顶级工科**(机械 / 电子 / 建筑)→ 选东南更对口。
- **家庭普通工薪 / 想本科直接就业出活**:南大基础学科多数要读研读博,本科直接就业不如东南/南理工工科出活快。
- **笃定要进互联网大厂搞 CS** + 分数刚够南大冷门组:**进了被调剂到天文 / 地理可能后悔**,不如稳东南 CS 或上交 CS。
- 想做医生但分够上交医 / 复旦上医 → 别在南大医学院将就。
