# 南京师范大学(南师,NNU)— 211 师范第一档

## 一句话定位

**江苏师范第一**,跟华师 / 东师 / 陕师 同档,**江苏公费师范主力 + 留江苏当老师的标准路径**。教育学 / 心理学 / 中国语言文学 / 历史学 / 地理学 全国前列,**普通工薪家庭 + 想进编制做老师的最优解**。

---

## 真实地位

- **211 + 教育部与江苏省共建**,江苏师范无可争议的老大,文科底蕴比东师 / 陕师还略强(地处江南文化重镇南京)。
- **江苏本省地位**:**江苏中小学 + 高中教师培养主力**,江苏大部分名校教师都来自南师 + 师范定向培养。
- **同档对比**:与北师 / 华东师 985 师范双子星错档(它俩 985);跟华师(湖北)/ 东师(吉林)/ 陕师(陕西)/ 西南大学(重庆)同为部委直属或共建的 211 / 准 211 师范。
- 仙林 / 随园 双校区,随园是民国老校区(原金陵女子大学旧址),文化底蕴顶配,**江苏家长心目中"女孩去南师做老师 = 完美归宿"**。

---

## 江苏物理类录取位次区间

参考近 5 年掌上高考 + 江苏一分一段表:

- **顶级组(公费师范物理 / 化学 / 数学 / 计算机 / 法学)**:全省 **15,000-25,000 名**。
- **主流组(普通师范 / 心理学 / 经管)**:全省 **25,000-38,000 名**。
- **冷门组(部分理工 / 中外合办)**:全省 **38,000-50,000 名**。

**段位定位**:江苏物理类 **省排 50,000 名内可冲南师**,**25,000 名内可挑公费师范王牌组**。**以一分一段表反查为准**。

## 江苏历史类录取位次区间

**南师历史类竞争极激烈**(江苏历史类总人数本就少,师范又是历史类大头):

- **顶级组(公费师范汉语言 / 历史 / 政治 / 英语)**:全省 **2,500-5,000 名**。
- **主流组(教育学 / 心理学 / 文学)**:全省 **5,000-10,000 名**。
- **冷门组**:全省 **10,000-18,000 名**。

**江苏历史类家长注意**:**南师历史类公费师范分常年压一些 985 弱组**,要想冲必须省排 5,000 名内。

## 公费师范 / 师范定向(南师最大特色 ★★★)

**公费师范生政策(教育部直属六大师范不直接给名额,南师走的是江苏省内"江苏省师范定向"路径)**:

- **江苏省师范定向培养**:面向江苏各市县,**毕业回签约市县任教 6 年**(类似公费师范但是省内政策)
- **学费 + 住宿费**:由签约地市补贴或免除(各市县政策不同)
- **生活补贴**:部分有(看签约地市)
- **毕业直接编制**:**回签约市县中小学,**有编有岗**(对江苏小县城 / 苏北家庭尤其友好)
- **录取分较高**:江苏物理类约 15,000-25,000 名,历史类约 2,500-5,000 名

**最适合**:
- 普通工薪 / 农村家庭(经济压力大,定向 = 零成本上 211 + 编制)
- 父母希望孩子做老师 / 进体制内
- 性格内向稳健 + 不喜欢都市内卷
- **苏北 / 苏中县城考生想回老家工作**(定向就是最稳的路径)

**最不适合**:
- 完全不想做老师的(定向要求服务 6 年,违约要赔钱 + 影响考公考编)
- 想留南京都市核心(定向要回签约市县,**苏南考生定向苏北是常事**)

## 性价比专业

- **公费 / 定向师范汉语言 / 数学 / 物理 / 化学**:**江苏小县城教师常年缺人**,定向师范几乎 100% 上岸编制。
- **教育学 / 心理学**:**全国前 10-15**,适合读研 + 进高校教育系统 / 心理咨询。
- **马克思主义理论**:**选调考公王者**,南师马院在江苏体制内认可度极高。

## 坑专业 / 慎选(在南师里相对弱)

- **计算机 / 软件工程(非师范方向)**:**师范院校学非师范 CS 是怪胎**,出来跟双非一本 CS 没差,**学 CS 直接选东南 / 南理工**。
- **经济学 / 金融 / 工商管理**:南师非财经强校,**学财经直接选南大或苏大**。
- **生物 / 化学(非师范)**:生化环材天坑组合,**别报通用方向,要报就报师范方向(进中小学)**。
- **教育技术学 / 数学与应用数学(非师范)**:**听起来像师范但不是定向**,**当心被忽悠混进去自己找工作**。
- **新闻传播 / 广播电视编导**:文科非师范,行业凋零 + 师范牌子加成弱。

## 关键提醒(填报陷阱)

1. **公费 / 定向师范 vs 非定向师范 vs 非师范专业** 三个层级要分清:
   - **江苏省内定向师范**:**提前批录取**,免费 + 编制 + 服务 6 年
   - **普通师范**(本科批):自费 + 自找工作(走教师招聘考试上岸编制)
   - **非师范专业**(数学 / 物理 / 历史 等带"科学"或"应用"后缀的):**不是师范,毕业不能直接当老师**(要考教师资格证 + 教师招聘)
2. **南师本部 vs 南师中北学院 / 泰州学院**:**仙林 / 随园本部才是 211**,中北学院 / 泰州学院是独立学院,**学费贵 + 牌子差**,**报志愿别看错代码**。
3. **服从调剂**:南师物理类组内可能含心理学 / 教育技术 / 学前教育等冷门,被调剂的话能不能接受?
4. **江苏省内定向 6 年硬约束**:**违约要赔学费 + 写违约记录**,**家长一定要跟孩子聊清楚这 6 年要回签约市县**。
5. **南师 vs 北师 / 华东师 / 华师**:北师 / 华东师 985 全国通用 + 分高;**江苏考生留江苏当老师南师最对口**;**华师(湖北)分够也可以考虑但要跨省**。

## 毕业出口(2024 数据)

- **公费 / 定向师范生**:**100% 进入教师编制**(江苏各市县中小学,**苏北 / 苏中 / 苏南都有名额**)
- **普通师范生**:**约 50-60% 通过省考 / 市考考编**(江苏教师招聘考试),约 25% 进民办学校 / 培训机构,约 15-20% 改行
- **非师范类**:约 30% 留江苏(以苏中苏北为主),约 50% 出省,**就业不如纯综合类 211**(因为南师牌子在非师范圈认可度低于苏大)
- **考研 / 读博**:约 25-30%(保研率 ~12-15%)
- **进体制内概率**:**约 50%+**(教师 + 公务员 + 选调 + 事业单位)
- **起薪范围**:江苏中小学教师编制 8-15w + 寒暑假 + 福利,长三角名校教师 15-25w(江苏初高中名校招南师本部硕博为主)。

## 同档对比

| 维度 | 南师 | 苏大 | 北师 | 华东师 |
|---|---|---|---|---|
| 综合排名 | 211 | 211 | **985** | **985** |
| 师范第一档 | **江苏第一** | 弱(无师范) | **全国第 1** | **全国第 2** |
| 留江苏 | **极易** | **极易** | 一般 | 沪苏(更优) |
| 公费 / 定向 | **江苏定向多** | 无 | 公费 | 公费(少) |
| 录取分 | 中 | **江苏 211 最高** | 高一档(985) | 高一档(985) |

**简单结论**:**江苏考生想做老师 + 留江苏 → 南师定向师范第一**;**分够 985 想做老师 → 北师 / 华东师**;**不做老师走综合 → 苏大**。

## 适合谁

- 江苏物理类 **省排 15,000-50,000 名** / 历史类 **省排 2,500-18,000 名** 的考生。
- **想做老师 / 进教育系统编制**的学生(尤其苏北 / 苏中县城考生)。
- **女生家庭** + 父母希望孩子稳定 + 不想出省 → 南师是江苏家长心目中的"完美归宿"。
- 性格内向稳健 + 不喜欢都市内卷 + 不想出差。
- 普通工薪 / 农村家庭 + 想要 211 牌子 + 进编制路径 → 南师定向师范最优。

## 不适合谁

- **完全不想做老师 + 不想进体制**:别在南师将就,选苏大综合性更对口。
- **想去互联网大厂 / 头部金融**:**南师 CS / 经管在大厂招聘中竞争力弱**,选东南 / 南大。
- **想留南京都市核心 + 不愿回县城**:**南师定向师范要回签约市县**,苏南考生分到苏北是常事。
- **学纯工科 / 财经 / 法学**:对应专业 211 比南师对口(东南 / 南大 / 苏大)。
- **分够 985 师范(北师 / 华东师)**:**不在意离家可考虑**,985 牌子全国通用。
