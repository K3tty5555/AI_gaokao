# 江苏 3+1+2 高考政策

## 核心结论

**江苏 2018 年加入新高考第三批,2021 年高考首届实行 3+1+2**(跟湖北/湖南/广东/河北 同批)。**总体规则跟湖北一致**,但江苏有几个**重要本地特殊性**值得注意。

## 关键事实

### 考试结构(同湖北)
- **3 = 语文 + 数学 + 英语**(全国卷/江苏卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类**(类型代号 2073)— 选物理为首选
- **历史类**(类型代号 2074)— 选历史为首选
- 江苏物理类约 60-65%,历史类约 35-40%

### 院校专业组(同湖北)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量
- **江苏本科批 40 个志愿**(注意!**比湖北 / 湖南的 45 个少 5 个**)
- 专科批 40 个

## 江苏特殊性(关键!!)

### 1. 江苏 211/985 数量全国前列
- **2 所 985**:南京大学 / 东南大学
- **11 所 211**:苏州大学 / 南京理工 / 南京航空航天 / 南京师范 / 河海 / 中国矿业(徐州)/ 中国药科 / 江南 / 南京农业 / 南京中医药 / 南京邮电(部分双一流)
- **江苏本省考生上 211 比湖北/湖南宽松**(虽然江苏考生数 ~40 万,但 211 名额多)

### 2. 江苏卷难度大 → 一分一段表压缩
- 江苏数学 / 语文 出名难,**高分段相对密集**
- 580 分以上区段一分压人数比湖北/湖南更多

### 3. 苏南 vs 苏北 差异显著
- **苏南**(南京 / 苏州 / 无锡 / 常州):基础教育强,考生竞争激烈
- **苏北**(徐州 / 连云港 / 宿迁 / 淮安):录取分数线相对宽松
- 影响:同样位次,苏南高中第 100 名 ≈ 苏北高中前 30 名

### 4. 长三角就业协同
- 江苏考生留长三角就业概率 70%+(沪宁苏锡常带)
- 苏州 / 无锡 工业制造 + 上海金融 / 互联网 + 杭州互联网 = 同一就业圈
- **跨省就业跟省内差不多**(地理近 + 文化近)

## 易错认知(agent 要纠正用户的)

- **"江苏卷难,孩子分数低代表水平低"** — 错。**江苏分数体系跟其他省独立**,看位次不看分数
- **"江苏 985 才两所,所以 985 难"** — 半对。两所 985 录取本省考生 + 长三角名额多,**江苏考生上 985 难度跟湖北接近**
- **"江苏 11 所 211 太多,牌子贬值"** — 错。**江苏 211 大多有特色专业**(苏大综合 / 河海水利 / 矿大矿业 / 药大药学 等),不是"水牌子"
- **"45 个志愿都是学校,选哪个学校都行"** — 严重错误。**江苏是 40 个志愿,且每个是"院校专业组"**

## 关键提醒(agent 必须强调)

1. **江苏 40 个志愿**(不是湖北/湖南的 45 个)
2. **看位次不看分数**(江苏卷难度跟其他省不可比)
3. **再选科目限制**(必选化学/必选政治等)是硬约束
4. **苏南苏北高中层次差异**(出分前估算位次时要考虑)
5. **江苏分数线比湖北高 30 分**,但不代表江苏比湖北难

## 江苏 3+1+2 投档与录取流程(详细版)

### 投档流程(物理类 / 历史类分别独立)
1. **按位次排队**:同类(物理类 / 历史类)考生按高考总分(750 分制)从高到低排队
2. **轮流检索 40 个志愿**:从位次第 1 名开始,系统按该考生填报的 1-40 顺序检索每一个院校专业组,**第一个能投到的志愿组,投档**
3. **投档比例**:江苏新高考采取**平行志愿 1:1 投档**(避免退档风险)
4. **本志愿组内分配专业**:投档后,本志愿组内按专业最低分录取
5. **服从调剂规则**:如果没录取上具体专业,**服从调剂会被调到本组其他未录满专业**;**不服从调剂 + 没录取上 → 退档,本批次落榜(滑档)**

### 江苏批次设置
- **本科提前批**(如军校 / 公安 / 公费师范 / 飞行员定向)
- **本科批**(40 个院校专业组)
- **专科提前批**(部分公费专科)
- **专科批**

### 江苏特殊批次
- **江苏省内师范定向**(本科批提前批,**免学费 + 编制 + 服务 6 年**)
- **国家专项 / 高校专项**(农村户籍专属,降 20-25 分进 985/211)
- **强基计划**(南大/东南各有名额,本科直博,**不能转专业**)
- **军工提前批**(南理工 / 南航部分专业)
- **飞行员定向班**(南航,**比裸分进南航低 30-50 分**)

**江苏一分一段表压人数密集,跨年对比时要看相对位次,不要看绝对分数**:

- 560-579 分:全省约 25,000 人(211 冷门 / 双非中段 招生区)

### 江苏跨年对比建议
- **2021-2022**:江苏新高考首两届,数据相对不稳定,参考价值低
- **2023-2024**:数据相对稳定,可作为主参考
- **2025**:出分后才有,**当年数据要等高考结束后掌上高考更新**

**关键**:**用位次对比,不要用分数对比** — 江苏卷难度年年微变,580 分在 2023 年和 2024 年对应的位次可能差 2,000 名。

## 苏南 vs 苏北 高中层次详细分化(出分前估位次必备)

### 苏南顶尖梯队(全国名校梯队)
- **南京外国语学校**(南外):**江苏顶级**,清北人均 + 出国大批
- **南师附中 / 南京一中 / 金陵中学**:**南京顶级**,清北每年若干
- **江苏省天一中学**(无锡):**苏锡常顶级**
- **苏州中学**:**苏州顶级**
- **常州高级中学**:常州顶级
- **苏州十中 / 江苏省苏州实验中学**:苏州一线

### 苏中梯队
- **南通中学 / 海安中学 / 启东中学**(南通):**苏中名校,苏中"南通教育"全国知名,清北 + 985 大批**
- **扬州中学 / 泰兴中学**:扬州 / 泰州顶级
- **黄桥中学**:泰州一线

### 苏北梯队
- **徐州一中 / 徐州三中**:徐州顶级
- **盐城中学 / 阜宁中学**:盐城顶级
- **淮阴中学**:淮安顶级
- **连云港高级中学**:连云港顶级

### 关键提示(给 agent 出分前估位次用)
- **苏南名校第 100 名 ≈ 苏北名校前 30 名 ≈ 江苏全省前 5,000-8,000 名**(估算)
- **苏南普高第 50 名 ≈ 苏中名校前 100 名 ≈ 全省 15,000-20,000 名**
- **苏北普高第 50 名 ≈ 全省 30,000-50,000 名**
- **苏中"南通教育"是全国奇迹**:南通 / 海安 / 启东 中学的考生密集占据江苏顶级位次,**苏中考生家长不要小看南通中学的"地理优势"**

### 出分前 agent 必问
1. 考生在哪个地市?(苏南 / 苏中 / 苏北)
2. 考生在哪所高中?(顶级 / 一线 / 普高)
3. 考生在校排名?(前 5% / 前 20% / 前 50%)

**这三个问题确定后,agent 才能给出靠谱的位次估算**;否则给出的"分数对应位次"完全无意义(因为江苏不同高中考分体系差异极大)。

## 江苏特控线 vs 本科线 的实际意义

- **本科线**:**进本科批最低门槛**(2024 物理 462 / 历史 478)— 低于本科线只能去专科
- **特控线**:**重点院校的实际门槛**(2024 物理 531 / 历史 530)— 类似老高考"一本线",**特控线以上的考生才有机会冲 211/985**
- **特控线以上人数**:江苏 2024 物理类特控线以上约 80,000 人,历史类特控线以上约 30,000 人
- **关键**:**特控线 = 211 的实际起跑线**(以下 211 录取很难) — 江苏家长重点关注特控线,而非本科线

## 江苏家长常见踩坑(2024 实测)

### 踩坑 1:志愿组数搞错(以为还是 8 个)
2017 年前江苏有过"AB志愿"等小批量平行志愿,**家长记忆停留在老规则**。**2021 年起新高考已经是 40 个院校专业组**,**家长一定要更新认知**。

### 踩坑 2:专业组内不查具体专业
家长以为"勾了苏大就是录到苏大",**实际可能被调剂到苏大冷门专业(纺织 / 部分材料)**。**报志愿前必须查清每个专业组内具体含哪些专业**。

### 踩坑 3:服从调剂全勾或全不勾
- **全勾**:有"被调到本组冷门专业"风险(如东南调到化工材料)
- **全不勾**:**有"高分滑档"风险**(本组目标专业没录取上,直接退档,落到下一批次)
- **正确做法**:**冲档(前 5-10 个志愿)勾,稳保档(后面)看专业组内能接受的最差专业**

### 踩坑 4:"江苏 985 太少,要冲外省 985"
**错**。**江苏 11 所 211 + 2 所 985 = 江苏考生上 985/211 比湖北 / 湖南多个名额选择**。**江苏考生留省内 211 + 长三角就业,大概率比出省冲外省 985 弱专业更好**。

### 踩坑 5:跨省类比分数
**错**。**江苏数学 / 语文比全国卷难,江苏 580 ≈ 别省 600**。**家长跨省类比要看位次不看分数**。

### 踩坑 6:忽视江苏定向师范
**苏中苏北家长**经常不知道**江苏省内定向师范** = 211 + 免学费 + 编制路径,**这是江苏特有福利**,**省外没有这种政策**。
