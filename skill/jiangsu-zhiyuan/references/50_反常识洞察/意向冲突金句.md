# 用户意向冲突 — Reality Check 金句库(江苏视角)

很多家长 / 考生有具体的意向("想上南大"、"非苏南不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

**江苏特别原则**:
- **江苏家长被"长三角名校光环"绑架最深** — 觉得"非南大东南不读"或"非苏南不去",对苏中苏北 211 / 出省 985 偏见大
- **苏南私企家庭对"考公没出息"的执念** vs **苏中苏北家庭对"必须编制"的执念**,是江苏 reality check 的两种极端

---

## 5 类意向冲突 + 金句模板(江苏版)

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 580 分要南大主流组 / 540 分要东南)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [江苏本地 / 长三角] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(江苏 580 分,意向南大)**:
> "南大主流组在江苏物理类省排前 1,500-3,000 名。你 18,500 名,差 2 万名,**南大没戏**。
>
> 但你能上**苏大(法学/医学/计算机)+ 南理工(兵器/光电/化工)+ 河海(水利/土木)+ 南邮(通信)** — 这几所留长三角就业,**国企 / 体制内招聘里跟南大冷门组校友地位差不多**(都是'江苏 211 + 留长三角同档')。
>
> 而且**苏大法学 / 河海水利 / 药大药学 / 南邮通信 都是行业内全国前 5,出来比南大的工商管理/国贸还有用**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(江苏理工科 + 普通家庭 + 想冲东南)**:
> "东南你 605 能擦 — 但只能进**化工 / 材料 / 部分土木 / 风景园林**。**985 牌子 + 生化环材天坑 + 建筑/地产凋零** = 三重坑。
>
> 同分能上的 **南理工 计算机(B+ 但江苏对口央企招聘强势)/ 南航 自动化 / 苏大 软件工程 / 中国药科大学 药学** 出来对口程度更高。冲东南留一个冷门组心理慰藉位即可,**主推 211 强势专业**。"

**真实案例(江苏文科 580 分 + 想冲南大)**:
> "南大文科组你 580 分,差 50 分起步,基本不可能。
>
> 同档能上的 **苏大王健法学院 / 南师汉语言定向师范 / 江苏师范大学(徐州)中文** 出来对口程度更高。
>
> 江苏选调生在苏大法学和南师汉语言定向都有指标,**比'冲南大冷门组进哲学'结果好**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [南大 / 上交医 / 复旦上医 临床八年制])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像技术 / 护理 / 医学检验 / 药学(中国药科大学)] — 早 3-4 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**江苏苏南三甲医院招聘 95% 要博士,意味着实际是 11 年才稳定**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**南大临床八年制 / 上交医 / 复旦上医**,长期天花板高。
>
> 撑不起 → **建议口腔(5 年本科)/ 中国药科大学药学(6-7 年进药企)**,或者**放弃医学走医学影像技术 / 护理(本科 4 年进江苏三甲医院技术岗)**。
>
> 江苏特色:**药学(中国药科大学)是医学家庭撑不起 8 年的最佳替代** — 苏州/上海药企总部进恒瑞硕士起薪 25-40w,比临床本科一线城市规培期 6-9k 强得多。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非南京不去" / "非苏南不去" / "非上海不去"),拒绝出省 985 或拒绝苏北 211。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留南京没意义,要去西工大),**要灵活退一步**。"

**真实案例(苏南家庭 + 法学 + 600 分)**:
> "你只留南京 / 苏州,这位次 8,000,**南大法学 (3,000 名内) 不够,东南法学 (5,000 名内) 也擦边**。
>
> **苏南最稳路径**:**苏大王健法学院**(王健法学院在苏南律所认可度顶配 + 长三角律所 + 选调指标)+ 父母如果是律师家庭资源 + 法考 → **江苏律所合伙人 / 苏南选调路径仍然能走**。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 户口没了**,综合不划算。"

**真实案例(苏北农村 + 想留苏北 + 580 分)**:
> "你苏北农村,想留苏北本地。这分数能上**南师江苏省定向师范汉语言(签约苏北市县)/ 中国矿大(徐州)/ 江苏师范大学(徐州)**。
>
> **苏北最稳路径**:**南师定向(免学费 + 211 牌子 + 直接编制 + 父母身边) 或 矿大本地 211 + 矿业央企对口**。
>
> 不要被人忽悠'必须出江苏冲外省 985' — 苏北农村孩子去外省 985 弱专业,**家庭资源不够 + 人脉断了 + 毕业没人接应回苏北**,跨阶级反而更慢。"

### 模式 E ★★★ 江苏专属:苏南 vs 苏北 / 体制 vs 私企 偏见冲突

**特征**(江苏独有):
- **苏南私企家庭嫌"考公没出息"** — 推考公时家长抵触
- **苏北家庭嫌"留苏北没前途"** — 推苏北本地 211 时家长抵触
- **苏中地市考生家长想"冲南京苏州"**,不愿回本地

**金句模板(苏南家庭嫌考公)**:
> "你家做外贸/制造业生意,觉得考公没出息,这我理解。但你儿子分数 [X],能进的是 [南大法学 / 东南马院 / 苏大王健],**这不是基层公务员路径,这是江苏选调路径** —
>
> 江苏选调生待遇全国最优:**南京市直机关 / 苏州市直机关起点 + 工资水平压一票省份**。
>
> 你儿子如果走选调,5 年后是苏州市某区科长 / 副处级,**起点远超双非进苏州工厂的工程师**。**这不是'没出息',这是另一条天花板更高的赛道**。
>
> 你的私企资源 + 他的选调身份 + 苏南体制内背景 = 长期对家族企业反而是助力(政府关系 / 政策红利)。"

**金句模板(苏北家庭被忽悠出省冲弱 985)**:
> "你儿子苏北徐州农村孩子,605 分。家长被忽悠说'必须出省冲 985,不能留苏北'。
>
> **客观说,出省 985 给你儿子的是什么?**
> - 末流 985 弱专业(兰大生物 / 西农大食品 / 东北林业 等)→ **专业坑 + 跨省人脉断 + 毕业回苏北没竞争力**
>
> **留苏北 / 留江苏给你儿子的是什么?**
> - 中国矿大(徐州本地 211)矿业工程 → 本地 211 + 矿业央企对口编制 + 家在徐州
> - 南师江苏省定向师范(签约苏北市县)→ 免学费 + 211 + 苏北中学编制 + 父母身边
> - 国家专项南大 / 东南(苏北农村户籍降 20-25 分)→ 985 + 专项编制 + 留江苏
>
> **苏北农村孩子最大的资源是江苏省内的'国家专项'+ '苏北本地户籍优势'**,出省冲外省弱 985 是浪费这两个资源。"

**金句模板(苏中考生家长想"冲南京")**:
> "你儿子南通考生,615 分。家长说'必须冲南京'。
>
> 你以为南京就是好,但你儿子这分数在南京能进的是**南理工冷门组 / 南航冷门组 / 河海冷门组**。
>
> 同样分数能进**苏大医学部(苏州)/ 江南大学食品(无锡)/ 中国药科大学(南京但不是冷门组)**,**比南京 211 冷门组性价比高得多**。
>
> 而且南通家庭离苏州无锡比离南京还近,**留长三角不一定非得是南京**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**江苏 agent 额外步骤**:
5. **判断地理偏见** — 苏南 vs 苏中 vs 苏北家长视角不同,主动 reality check
6. **判断"考公 vs 私企"偏见** — 苏南家庭嫌考公没出息时,**讲清楚江苏选调跟基层公务员不是一回事**

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **江苏特别**:盲从苏南家长"考公没出息"偏见 → 推 CS / 金融,结果中段双非 CS 起薪比苏南选调还低

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 南大 / 想学医 / 想留南京 / 嫌考公没出息 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**江苏特别一句话**:**苏南家长的"考公没出息"偏见 + 苏北家长的"必须留省内编制"执念 + 苏中家长的"必须冲南京"心理 — 这三种地理偏见是江苏 agent 必须主动 reality check 的核心**。
