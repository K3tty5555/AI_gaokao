## 一、内蒙古专科 skill 的差异化定位

跟主 skill (neimenggu-zhiyuan) 与外省专科 skill (hubei-zhuanke / jiangsu-zhuanke) 的关键差异:

### vs neimenggu-zhiyuan(主 skill)
- 主 skill 处理本科线以上考生,专 skill 处理"本科线下、专科线上"区间
- 主 skill 重"学校层次 + 城市 + 985/211 牌子",专 skill 重"专业 + 行业出口 + 专升本资格 + 民族政策"
- 主 skill 走 5 推 + 3 避坑卡片输出,专 skill 走简化版"档位定位 + 5 所推荐 + 关键提醒"

### vs hubei-zhuanke / jiangsu-zhuanke(外省专科)
- 内蒙古专科**有湖北 / 江苏完全没有的产业链**:
  - **资源型央企**:神华(国家能源集团)/ 中煤 / 包钢 / 中国稀土集团 — 鄂尔多斯 / 包头 子弟王者赛道
  - **草原畜牧业 + 乳业巨头**:伊利 / 蒙牛 / 圣牧高科 / 鄂尔多斯羊绒 — 内蒙古独家全球级产业
  - **风电 / 光伏运行**:全国前 3 风电大区,新能源新增量
  - **蒙东 / 蒙西电网**:中国 5 大独立电网中的 2 个,自己招工自己用
- 内蒙古专科**有民族政策红利**:蒙古族 / 双语考生在专科批同样有民族加分 + 蒙授单列录取通道 + 蒙汉双语对口岗位
- 内蒙古专科**有京津冀近距离辐射红利**:呼和浩特 / 乌兰察布 → 北京 1-2 小时高铁,出区到京津冀专科 / 民营医院起薪不输留蒙
- 内蒙古专科**有牧区基层编制红利**:旗县兽医站 / 苏木卫生院 / 嘎查卫生室 / 旗县幼儿园 / 草原管理站 大量事业编缺人,蒙古族学生 + 双语优先

## 四、风格纪律(写后续 references 必须遵守)

跟着已写的 5 篇风格走:

1. **大白话讲清楚利害,不绕弯子** —— 不要套学术腔,不要"建议考虑"这种弱判断
2. **case-specific** —— 每篇要有 3-5 个内蒙古真实画像 case,不是 generic 通用模板
3. **本省视角** —— 所有数据 / 院校 / 企业 / 路径都要带"内蒙古"维度,不要照抄湖北 / 江苏
4. **不套湖北** —— 同样是讲护理,内蒙古的重点是"基层医院 + 蒙医医院 + 京津冀辐射",不能写成"武汉三甲"
5. **不编数字** —— 起薪 / 录取率 / 招聘量 等数字要带"参考"措辞,不要给精确到百位的假数据;无法确认的具体数字写"参考近年数据,具体以当年文件为准"
6. **避坑要点名** —— 民办专科 / 经管类专科 / 跟内蒙古产业脱节的专业 必须明确点出避免,不能含糊
7. **政策提醒到位** —— 民族加分 / 蒙授通道 / 专升本只能区内 / 2025 首届新高考数据稀薄 这几个内蒙古特色提醒每篇都要带
8. **每篇结构** —— 核心结论 + 现状速查 + 适合什么人 + 推荐院校 + 决策映射 + 专升本路径 + 典型 case + 易错认知
