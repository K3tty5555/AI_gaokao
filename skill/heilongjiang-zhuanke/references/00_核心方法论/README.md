# 黑龙江专科决策核心方法论

这份方法论是给 agent 看的:**给黑龙江考生推荐专科,跟给湖北考生推荐专科的底层逻辑不一样**。如果直接套用东部省份的模板,会把考生引到错的方向上。

---

## 一、黑龙江专科决策的四条底色

### 1. 人口外流是常态,但"专科出省 ≠ 跨阶级"

黑龙江本科生外流到山东 / 北京 / 长三角是合理的(本科有学历背书,异乡也能找到岗),**但专科生外流大多数是把自己变成"东北异乡打工者"**。

- 出省读专科 → 学费贵 + 异乡没人脉 + 毕业后跟当地专科生抢同样的岗,**没优势**
- 留省读专科 → 学费便宜(公办 4-7 千 / 年)+ 直接对接哈电 / 大庆 / 农垦 / 铁路 国企体系
- **agent 默认应该建议留省读专科**,除非考生明确有"去山东接亲戚厂 / 去珠三角投奔家人" 之类的具体目标

### 2. 国企央企比民企发达得多 — 这是黑龙江专科最大的红利

黑龙江民营经济弱,但**国企 / 央企 / 农垦体系吸纳专科技工的量极大**。这跟湖北 / 江苏的"民企 + 国企混合就业"不一样。

主要的专科出口:
- **大庆油田 + 大庆石化** — 石油化工类专科的主要出口
- **北大荒农垦集团** — 农机 / 农艺 / 食品加工 / 物流 类专科的主要出口(总场在哈尔滨,各分公司散布在三江平原)
- **中车齐齐哈尔车辆有限公司** — 铁路装备制造,机电 / 焊接 类专科出口
- **哈电集团**(哈尔滨电气) — 电力装备制造,机电 / 电气类专科出口
- **哈飞 / 中航工业东北分部** — 航空制造,机电 / 数控类专科出口
- **国家电网黑龙江分公司** — 电气类专科出口
- **哈尔滨铁路局集团** — 铁路类专科主出口
- **龙煤集团**(鸡西 / 鹤岗 / 双鸭山 / 七台河 四煤城)— 采矿 / 机电 类专科出口,但**煤城在衰退,慎选**

**agent 推荐时的核心动作**:不是"推荐学校"先,而是"先问考生想进哪类国企",再倒推专科和专业。

### 3. 冬季漫长 + 户外岗位多 = 体力 / 心理成本要明说

黑龙江很多对口岗位是户外 / 油田 / 农场 / 林区 / 铁路工务,**11 月到次年 3 月零下 25-30 度作业是常态**。

- 大庆油田井队 / 钻井 → 户外作业,冬天极冷
- 北大荒农场农机岗 → 春耕 / 秋收旺季高强度,冬季则相对轻松但户外巡检
- 铁路工务段 → 任何天气都要上线路检修
- 林业 / 林区岗位 → 偏远 + 寒冷
- 龙煤系统井下岗 → 危险 + 24 小时三班倒

**家长和考生在咨询时常常忽略这点**。agent 必须在推荐这类专业前**明确询问"能不能接受冬季户外 / 三班倒"**,否则录取后退学率会很高。

### 4. 对俄边境是稀缺红利,但要看户籍和家庭

黑龙江 2900+ 公里中俄边境线,绥芬河 / 黑河 / 同江 / 抚远 等口岸有持续的对俄贸易。**俄语应用 / 国际贸易(对俄方向)** 是其他省份没有的专科赛道。

- 适合谁:**家在边境州市 + 家里有跨境生意 / 亲戚做对俄贸易** 的考生
- 不适合谁:**没家庭背景的考生**单独学俄语应用专科 → 出口窄,主要靠口岸城市的小型贸易公司,薪资不稳
- agent 推荐俄语方向时一定要先确认家庭背景,**避免没背景的考生掉坑**

## 二、agent 应该问的关键追问问题

模板的 L1 / L2 / L3 之外,黑龙江专科咨询有几个**必须追问** 的问题:

1. **"你家是哪个市的?"**
   - 哈尔滨 → 留哈选项最多(哈职 / 黑职 / 哈铁院 等)
   - 齐齐哈尔 → 中车齐车 / 齐齐哈尔工程学院 路径清晰
   - 大庆 → 大庆油田 / 大庆职业学院 是天然组合
   - 牡丹江 / 佳木斯 / 绥化 → 接本地国企或考虑哈尔滨求学
   - 鸡西 / 鹤岗 / 双鸭山 / 七台河(四煤城) → **谨慎,煤城在衰退**,优先建议出煤城读哈尔滨专科
   - 绥芬河 / 黑河 → 对俄贸易路径可考虑

2. **"家里有没有体制内 / 国企的亲戚?"**
   - 黑龙江体制内家庭比例高,**有人脉 = 走对口专科,毕业回家直接接班**
   - 没人脉 = 走"硬技能 + 工种证 + 公开校招" 路径,选哈职 / 黑职 / 哈铁院 等省内顶配公办

3. **"想留东北还是出去?"**
   - 想留 → 公办 + 对口本省国企(本 skill 重点路径)
   - 想出 → **不建议出省读专科**,但可以读本省专科 + 毕业后去山东 / 长三角 找工作。**学历起点在哪不重要,工作落在哪才重要**

4. **"考虑过当兵 / 警校吗?"**(冷门但重要)
   - 黑龙江警官职业学院 / 黑龙江公安警官学院 是体制内路径之一
   - 部队招专科兵在黑龙江是合法路径,**当兵两年回来考事业编 / 退役军人岗** 是性价比之王
   - 这个选项很多家长想不到,agent 要主动提

## 三、决策矩阵(给 agent 落输出用)

| 考生类型 | 推荐方向 | 备注 |
|---|---|---|
| 哈尔滨城市男生 + 普通工薪 | 哈铁院(铁路)/ 黑职(机电 / 电气) → 国电网 / 铁路局 | 留省接对口央企 |
| 哈尔滨城市女生 + 普通工薪 | 哈职(护理 / 学前)→ 公立医院 / 公办幼儿园 | 编制路径 |
| 大庆考生 + 父母石油系统 | 大庆职业学院(石油 / 化工) → 大庆油田对口 | 子弟优势仍在 |
| 齐齐哈尔考生 + 父母在中车 | 齐齐哈尔工程学院(机械 / 焊接) → 中车齐车 | 装备制造专科黄金路径 |
| 三江平原(佳木斯 / 绥化)+ 农村家庭 | 黑龙江农业工程职业学院(农机 / 农艺) → 北大荒农垦 | 农垦系统是公认的稳 |
| 煤城(鸡西 / 鹤岗 / 双鸭山 / 七台河) | **建议出煤城读哈职 / 哈铁院,不读本地煤炭专科** | 煤城衰退,本地接班价值低 |
| 绥芬河 / 黑河 + 家里有对俄生意 | 黑龙江外国语 / 牡丹江大学 俄语应用 / 国际贸易(对俄) | 稀缺路径 |
| 想专升本 + 普通家庭 | 公办专科 + 升学率高的专业(护理 / 学前 / 机电 / 计算机) | 详见 30_专升本路径 |
| 体制内家庭男生 | 黑龙江警官职业学院 / 部队专科兵 / 哈职体制对口 | 利用家庭信息差 |

## 四、不能犯的错(agent 红线)

1. **不要套湖北 / 长三角的"专科 = 民营企业灵活就业"叙事** — 黑龙江民营弱,这套不成立
2. **不要推荐"金融管理 / 工商企业管理 / 国际贸易(非对俄)"等水专科** — 黑龙江本省民企吸纳极少,出省又比不过山东专科生
3. **不要鼓励盲目出省读专科** — 大多数情况下是坑
4. **不要回避冬季户外的真实成本** — 家长和考生现在不知道,录取后退学就晚了
5. **不要强化"投资不过山海关"叙事** — 用户来咨询是为了做决定,不是听情绪。承认外流问题但要给具体路径
6. **不要把农垦 / 油田 / 铁路简单等同于"铁饭碗"** — 这些系统这十年也在改革,合同制 / 派遣制比例在升,要说清楚"国企编制 vs 国企合同 vs 国企派遣"的区别(详见行业篇)

## 五、本方法论 vs 主 skill (`heilongjiang-zhiyuan`) 的边界

| 触发场景 | 走哪个 skill |
|---|---|
| 考生分数过本科线 | 主 skill |
| 考生分数本科线下、专科线上 | **本 skill** |
| 模考分数预测且不确定批次 | 先主 skill,bracket 信号触发后切到本 skill |
| 用户明确说"我要专科 / 我考不上本科" | 直接本 skill |
| 复读 vs 上专科 的纠结 | **本 skill 优先回答**(主 skill 不熟悉专科真实出路,容易劝复读) |

agent 切换时务必带上已收集的 L1 / L2 信息,**不要让用户重复输入分数 / 位次 / 选科**。
