## 风格约定(参考已写文件)

- **大白话 + case-specific**(每篇 5-8 个真实 case,不要堆砌数据)
- **本省视角**(广东独家红利:跨境电商 / 港澳路径 / 潮汕家族 / 珠三角制造业)
- **不套湖北**(规则不一样,行业不一样,家庭画像不一样)
- **不编数字**(分数线 / 录取率 / 薪资 都用 2024 年公开可查的近似区间,标"以最新公布为准")
- **每篇含**: 核心结论 / 行业现状 / 决策映射 / 推荐院校 / 专插本路径 / 典型 case(成功 + 失败) / 易错认知
