# 用户意向冲突 — Reality Check 金句库(云南视角)

很多家长 / 考生有具体的意向("想上云大"、"非昆明不去"、"想学医"、"想去成都"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。**云南独家变量** — 少数民族 / 边境 / 出省 vs 留云 / 东盟门户 / 民族班 等,**让意向冲突更复杂,reality check 更需要**。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **云南独家**:**少数民族 + 政策红利 五通道 = "档外杠杆"**,意向冲突时要算上这个变量(少数民族能用降分跨档的话,就别死磕意向校)

---

## 4 类意向冲突 + 金句模板(云南视角)

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 400 分要清北 / 480 分要云大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 211 牌子的执念,还是把 [替代校] 当作双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(云南 480 分,意向云大)**:
> "云大主流组在云南文科 3000-6000 名 / 理科 6000-12000 名。你 18000 名,差 1.2 万名,**云大没戏**。
>
> 但你能上**云财大 + 云师大 + 云农大 + 大理大学** — 这几所留云就业,**云南本土公务员 / 教师编 / 医院技师岗 + 云烟 / 云铜 招聘里跟云大冷门组校友地位差不多**(都是'云南本地双非顶配 + 留云同档')。
>
> 如果你是少数民族(彝 / 白 / 傣 / 哈尼 等),还可以叠加民族加分 + 民族班 + 国家专项,这叫'五通道',**云南独家政策红利**,搞清楚资格再决定是不是死磕云大。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'211 就是 211',但 **211 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非工科还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(云南理工科 + 普通家庭,云大擦边)**:
> "云大你 580 能冲 — 但只能进生命科学 / 草学 / 部分农林相关。**211 牌子 + 云南偏远 + 生化环材** = 三重坑(虽然云南本地认可,但出云南找工作没优势)。
>
> 同分能上的**昆工冶金 / 有色金属(全国前 5,云铜云锡中铝直接对口,起薪 12-15w)**,出来对口程度更高。
>
> 冲云大留一个心理慰藉位即可。**真要 211 牌子,不如出省冲川大 / 重大冷门组(985,云南到成都重庆近)**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村 / 少数民族,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [昆医临床 5+3 一体化 / 出省冲川大华西医])
> - 撑不起 → 走 **[替代短路径]**(如 **[昆医医学影像 / 检验 / 护理 — 4 年本科 + 编制,早 4 年挣钱]**),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(云南农村普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-7k**(云南三甲规培期工资比一线低)。云南农村普通工薪父母还要供 8 年。
>
> 撑得起 → 推**昆医临床 5+3 一体化(本硕一体)/ 出省川大华西医**,长期天花板高。
>
> 撑不起 → **建议昆医医学影像 / 检验 / 护理(4 年本科 + 返乡州市医院 + 编制 + 边远艰苦补贴,早 4 年挣钱)**,或者放弃医学走**云师大公费师范(无学费 + 包返乡编制) / 昆工电气(进南方电网县级供电所)** 这种本科直接就业 + 编制的赛道。
>
> 如果你是少数民族(彝 / 白 / 傣 / 哈尼 等),**国家专项 + 民族班 + 公费师范** 三重红利叠加,**昆医医学影像 / 大理大学护理 + 返乡边境州市 = 100% 编制 + 边远补贴 + 政策红利全用上**。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去" / "非昆明不去" / "想出云南"

**特征 D1**:用户只想留昆明("非昆明不去"),拒绝出省。

**金句模板**:
> "你只想留昆明,那同档要在 **[云大 / 昆工 / 云财大 / 云师大 / 云民大 / 昆医]** 之间选。
>
> **留昆明 = 211 + 双非顶配 多个选项,但出云南到一线就吃亏**(云大牌子比中游 211 略弱,昆工双非但本地认可)。
>
> 但!如果你想做的方向 [意向方向] 在昆明没强校(如想学航天 → 昆明没意义,要去西工大 / 北航;想学顶级 CS → 要去成电 / 西电),**要灵活退一步**。
>
> 父母想让你留昆明的核心动机是什么?**离家近 + 父母安心 + 留省考公编制 → 留昆是对的**;**'反正出省也能回来' → 出省 985 / 211 反而更划算**(云大牌子比不上川大 / 重大 / 西交 / 中山 / 华工)。"

**真实案例(昆明本地家庭 + 法学方向 + 590 分)**:
> "你只留昆明,这位次 12000 文科,云大法学差一点(云大法学顶配组在 1500-3000 名)。
>
> **留昆明最稳路径**:**云大法学冲档(留 1 个志愿)+ 云大行政管理 / 民族学 主推(可上)+ 云财大法学保底**。父母律师家庭资源 + 法考 → 留昆律所 + 体制内双轨。
>
> **不要为了'非昆明'放弃出省 985 法学**(西南政法 / 中南财法 / 武大法学,这些都是云南考生分够能冲的 985 法学)。**法学就业看牌子 + 资源 + 法考三角**,出省牌子优势 > 昆明本地小优势,**5 年后回昆明工作完全可以**。"

**特征 D2**:用户想出云南("再也不留云了 → 想去成都 / 深圳 / 北京 / 上海")。

**金句模板**:
> "想出云南是好事,关键是**出去之后能回来吗 / 想回来吗?**
>
> 出省到 **[成都 / 重庆](离云南近,文化亲)** → 川大 / 重大 / 电子科大 / 西南交大 / 西南财经 / 西南政法 / 川美 等,云南到成都火车 6-8 小时,**实习 / 假期回家方便**
>
> 出省到 **[广东大湾区](IT / 制造业最强)** → 华工 / 中山 / 深大 / 暨南 / 哈工大深圳,云南到深圳飞机 1.5 小时,**适合想吃 IT / 互联网红利**
>
> 出省到 **[长三角](金融 / 互联网最强)** → 复旦 / 上交 / 浙大 / 南大 / 上财 等,云南到上海飞机 3 小时,**距离最远 + 生活成本最高 + 父母担心多**
>
> 出省到 **[北京](央企 / 央媒 / 金融最强)** → 清北人北航等,云南到北京飞机 3.5 小时,**离家最远 + 父母最不放心 + 户口含金量最高**
>
> 普通家庭 + 想出云的话,**首选成渝两条路径**(地理近 + 文化近 + 父母接受度高 + 实习成本低)。
>
> 中产家庭 + 分够 985 → 大湾区 / 长三角 / 北京 三选一,看孩子方向。"

### 模式 E(云南独有):意向 vs 政策红利错配

**特征**:用户是少数民族 / 农村户籍 / 直过民族,但意向校 / 意向专业**不用上"五通道"**(国家专项 / 民族班 / 加分 / 预科 / 直过民族专项),等于浪费政策红利。

**金句模板**:
> "你是 [民族,如彝族 / 白族 / 傣族 / 哈尼族],来自 [户籍,如怒江 / 迪庆 / 临沧 / 德宏 / 西双版纳],**云南独家政策红利你应该全用上**:
> - 少数民族加分(5-20 分)
> - 民族班(降分 30+)
> - 国家专项(降分 30-60)
> - 高校专项(部分顶级 985 名额)
> - 直过民族专项(独龙 / 德昂 / 基诺 等)
>
> 你想报 [意向校] [意向专业],**没用这些通道,等于浪费 30-60 分等效降分**。
>
> 用上 [国家专项 + 民族加分] 后,**等效分数 +30-50 分,可以从 [当前能上的档] 跨到 [上一档]**。这不是作弊,是云南独有的政策红利。"

**真实案例(怒江傈僳族 540 分理科)**:
> "你是傈僳族 + 怒江户籍(直过民族 + 边境艰苦地区),**'五通道'你能用 4 个**(直过专项 + 民族加分 + 国家专项 + 高校专项)。
>
> 不用政策 → **540 分能上昆工普通组 / 大理大学**
>
> 用上政策(等效降分 50+)→ **可冲云大民族学双一流 A 类(国家专项 + 民族班) / 出省西南交大 / 川农 / 重大冷门组(高校专项)/ 北京民族大学(预科 / 民族班)**
>
> **同样 540 分,差距是'双非二本' vs '211/985'**。意向是云大 → 用上政策能达;意向是出省 985 → 用上政策也能达;**前提是你查清自己资格,然后申请通道**。"

## Agent 处理意向的 5 步(云南独家加 1 步)

收到 L4.5 意向锚点后,**强制做这 5 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比(**云南 2025 首届新高考,样本量小,要标注"数据待校准"**)
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **检查"五通道"政策红利**(云南独有!) — 民族 + 户籍 + 是否享受国家专项 / 高校专项 / 民族专项 / 直过民族专项
4. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡;**用上政策红利后 重新评估可达性**
5. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **忽略"五通道"政策红利** — 云南独家,**跨档机会 30-60 分等效降分**,不查清是 agent 失职

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

**云南独家**:如果用户是少数民族 / 农村户籍,**双轨之外加一条"五通道"轨**:
- **轨道 3:用上政策红利后 跨档 推荐**(可能比 轨道 1 / 2 都更优)

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 [云大 / 想学医 / 想留昆明 / 想出云南] — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]

[ 如果用户是少数民族 / 农村:政策红利评估,3 句话 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**云南独家加一句**:**少数民族家庭别只看意向校的"明面分数线",要算上"五通道"政策红利后的等效分数 — 跨档机会被严重低估**。
