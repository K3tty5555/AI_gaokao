# 考公优选专业表(云南本地视角)

## 核心结论

**专业决定考公选岗范围**。云南家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**云南考公的独家结构性优势**:
1. **38 万考生 + 211/985 极少 → 本科生进入公务员系统的比例比湖北 / 河南 高**
2. **少数民族选调专项**(彝 / 白 / 傣 / 哈尼 / 壮 / 苗 等独家通道,竞争更小)
3. **边境州市岗位倾斜 + 边远艰苦补贴**(怒江 / 迪庆 / 临沧 / 德宏 / 西双版纳 / 文山 等加补贴 1500-3000/月)
4. **西部大开发 + 一带一路 + 中老铁路**:云南公务员体系扩张,基层岗位多

## 关键事实(2024 国考 / 云南省考分析)

### 国考可报岗位数 排名(Top 10 大类)

1. **法学** — 法院、检察院、监狱、纪委监委 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语**(英语 / 越南语 / 老挝语 / 缅甸语 / 泰语 — **东盟语种是云南独家方向!**)→ 约 2%

### 云南省考特殊性

- 云南省考 + 16 个州市考 + 各县乡基层岗位,**汉语言文学和法学并列考公第一专业**
- **云南各州市机关对法学要求高**(法院、检察院、司法局、监察委)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)
- **少数民族选调专项**:云南独有,**彝族 / 白族 / 傣族 / 哈尼族 / 壮族 / 苗族 等 有专门通道**(竞争更小,报名条件包含特定民族成分要求)
- **边境州市倾斜**:怒江 / 迪庆 / 临沧 / 德宏 / 西双版纳 / 文山 等基层岗位**降低门槛 + 边远艰苦补贴 1500-3000/月**

### 云南选调生(不是普通公务员,是高潜力路径)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **211/985 才有资格报**(云南本地的选调生定向计划主要对**云大 + 云师大 + 云财大 + 云民大 + 出省 985/211**)
- **云大是云南本地选调主力供给校**(因为是云南唯一 211)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **少数民族选调专项**:云南独有,**给少数民族 985/211 学生开专门通道**(竞争更小)

### 公检法岗位的硬要求(云南视角)

- **公安**:多数岗位要求"公安专业"(中国人民公安大学 / 云南警官学院 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,云大法学 / 出省西南政法 / 中南财法 对口
- **边境海关 + 缉毒岗位** — 云南独家(云南是中国缉毒前线),**法学 + 警校 + 民族语言(傣 / 哈尼 / 缅甸语)= 复合型人才稀缺**

## 云南本地院校 × 专业组合(考公视角)

### 211 + 强势考公专业

- **云南大学法学** — 云南唯一 211 + 双一流加成,**云南法学最优,留云考公认可度顶配**
- **云南大学行政管理 / 政治学 / 经济学** — 综合就业 + 考公双友好
- **云南大学汉语言文学** — 211 牌子 + 西南联大文科血脉
- **云南大学民族学** — 双一流 A 类,**少数民族选调专项 + 民委系统对口**

### 双非 + 性价比考公专业(留云首选)

- **云师大公费师范汉语言** — 不是考公但是教师编制,**等同于考公友好**(返乡州县中学编制)
- **云财大会计 / 财政学 / 税收学** — 留云做财税系统对口
- **云民大东南亚语种(越南语 / 老挝语 / 缅甸语 / 泰语)** — **外交部 / 商务部 / 海关 定向招录**(云南独家,跟广民大并列全国前 2)
- **云南警官学院公安专业** — 公安联考路径,**毕业进云南本地公安概率极高**

### 公安系统专属

- **云南警官学院** — 本科,公安联考路径,**毕业进云南本地公安概率极高**(基层警察 / 边境海关 / 缉毒)
- 出省冲 → **中国人民公安大学 / 中国刑事警察学院 / 中国人民武装警察部队学院**(分够)

### 出省路径(分够别死磕本省)

- **武大法学**(全国前 5)— 法考通过率高,选调路径最优
- **西南政法 法学**(重庆,五院四系之一)— 离云南近,法学极强
- **中南财经政法 法学 / 经济学 / 会计学** — 211 双一流,**法考 + 考公 + 经济学** 三栖
- **中央财经 / 上海财经 / 西南财经 / 东北财经** — 财经四强,出省冲分够
- **北外 / 上外 + 越南语 / 缅甸语 / 泰语 / 老挝语** — 东盟语种顶配
- **中国政法大学** — 法学顶配

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:云南楚雄考生,540 分文史类,**普通彝族农村家庭**(有民族加分 + 国家专项)。家长本想报"国际经济与贸易"(听起来高大上)。**改报云大法学(用国家专项降分)**,毕业用**少数民族选调专项**通道考云南省委组织部,**家庭命运改变**
- **Case B(选调路径)**:云南昆明考生,650 分文史类,中产家庭。家长想报"金融"(云大经济学院)。**改报云大法学**,**毕业获得云大选调生资格,直接进云南省直机关或回乡党政岗**,起点远超经济学就业
- **Case C(失败路径)**:云南大理考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了云大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行做 IT 但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:云南家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(独家路径 — 东盟语种考公)**:云南西双版纳傣族考生,560 分历史类(用民族加分 + 民族班)。**报云民大缅甸语**,毕业进**商务部驻缅甸经济参赞处 / 中老铁路沿线海关**,**云南独家路径,被严重低估**
- **Case F(独家路径 — 边境警察)**:云南怒江傈僳族考生,540 分理科(国家专项)。**报云南警官学院 + 公安联考** → 毕业回怒江公安局缉毒大队 + 边远艰苦补贴,**家庭跨阶级 + 服务边境**
- **Case G(返乡公费师范路径)**:云南文山苗族考生,540 分文史类。**云师大公费师范汉语言**,毕业回文山某县中学教语文 + 编制 + 无学费,**最适合云南农村少数民族家庭**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(云南 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**211 牌子大,什么专业都行**" — 错。**211 + 烂专业(国贸、工商管理) = 不如双非 + 好专业(汉语言、法学)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 211/985 才有资格,但是**资格内的竞争小**,所以**对云大 / 出省 985 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是云南家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**少数民族选调跟普通选调一样**" — 错。**云南少数民族选调专项有专门通道,竞争更小**(报名条件包含特定民族成分要求,大量名额单独划出)
- "**边境州市公务员条件差,不如昆明**" — **半错**。边境州市基层公务员**起薪 4-6k + 边远艰苦补贴 1500-3000/月 + 当地房价 5-8k/㎡** = **实际生活质量 + 可支配收入** 不输昆明文职公务员
- "**东盟语种公务员小众没用**" — 严重错误。**外交部 / 商务部 / 海关 / 中老铁路 沿线公职 有定向招录**,**报名人数极少 + 国家战略重点保障 = 隐藏跃迁通道**

## 关键提醒

**考公是云南普通家庭最稳定的上升通道**。云南考公优势比湖北 / 河南 还大:

1. **38 万考生 + 211/985 极少** → **本科生进入公务员系统的比例高**
2. **少数民族选调专项 + 边境州市倾斜** → **彝 / 白 / 傣 / 哈尼 / 壮 / 苗 / 傈僳 / 拉祜 等 少数民族考生有独家通道**
3. **西部大开发 + 一带一路 + 中老铁路 + 西部陆海新通道** → **云南公务员系统扩张 + 边境州市岗位倾斜**

如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。

**云南独家考公路径(被严重低估)**:
- **少数民族选调专项**(彝 / 白 / 傣 / 哈尼 / 壮 / 苗 / 傈僳 / 拉祜 / 佤 / 纳西 等 → 云大法学 / 行政管理 + 选调专项)
- **边境海关 / 缉毒岗位**(云南警官学院 / 法学 + 民族语言 = 复合型人才稀缺)
- **东盟语种公职**(云民大越南语 / 老挝语 / 缅甸语 / 泰语 → 外交部 / 商务部 / 海关 / 中老铁路 定向招录)
- **公费师范返乡 + 编制**(云师大公费师范 + 民族地区返乡 = 双重红利,无学费 + 包返乡州县中学编制,等同考公)

**汉语言文学是云南家长被严重低估的考公王者**。
