# 云南老高考 → 3+1+2 过渡(2025 首届新高考)

## 核心结论

**云南 2022 年加入新高考第五批,2025 年首届高考实行 3+1+2**(跟山西/河南/陕西/四川/青海/宁夏/内蒙古 同批,**全国新高考最后一批省份**)。这意味着:**2021-2024 高考还是老高考(文/理科),2025 才是首届新高考**。

**对志愿咨询的最关键影响**:**新口径(物理类/历史类)历年数据只有 2025 一年**,样本量极小(只有 1 年!),大小年风险无法用 3 年数据判断;而 2021-2024 的文/理科数据只能"作为参考",不能直接换算到新口径。**这是云南考生 2026 年填志愿最大的难点**。

---

## 一、考试结构(新高考 3+1+2,2025 起)

- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制 / 等级赋分**)
- **总分 = 750 分**

### 物理类 vs 历史类

- **物理类** — 选物理为首选(云南 2025 物理类约 55-58%,西部边疆理科占比偏高)
- **历史类** — 选历史为首选(约 42-45%)

### 院校专业组

- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量

- **本科批 96 个志愿**(云南本科批一次性 96 个,不分批次)— **跟贵州/广西/四川 持平,比江苏 40 个 / 湖北湖南 45 个 都多**
- 专科批 96 个

## 二、云南考生数据画像

- **每年高考报名考生约 38 万**(云南 2025 高考报名 38.x 万,跟贵州差不多但少于广西)
- **985 = 0**:本省**没有任何 985**
- **211 = 1**:**只有云南大学**(西部计划升级 211,2017 年入选双一流 A 类)
- **双一流学科建设高校 = 1**:云南大学(民族学、生态学)
- **省外 985/211 名额相对宽松**(因为本省考生总数中等 + 西部专项计划倾斜)

**结论**:**云南考生上 211/985 主要靠出省**,本省只有云大一个 211 选项。

## 三、云南本地特殊性(志愿决策必读)

### 1. 民族多元 → 少数民族加分 + 民族班

- **云南 26 个世居民族**(汉、彝、白、傣、哈尼、壮、苗、回、傈僳、拉祜、佤、纳西、瑶、藏、景颇、布朗、普米、阿昌、怒、基诺、德昂、蒙古、水、满、独龙、布依),**少数民族占比约 33%**(全国第 2,仅次于贵州)
- **少数民族考生有加分政策**(具体加分根据民族 + 地区,5-20 分不等;agent 不深入加分政策细节,只提示"如果是少数民族,记得查当年加分细则")
- **民族班 / 民族专项**:云南大学 / 云南民族大学 / 云南师范大学 等都有民族班招生(分数线低 + 专业受限)
- **直过民族**(独龙族、德昂族、基诺族等)有专项扶持,可重点关注

### 2. 东南亚门户(独家就业出口!)

- **云南陆地边境线 4060 公里**,跟**越南 / 老挝 / 缅甸** 接壤,**昆明 = 中国-东盟自贸区核心枢纽**(磨憨口岸 / 河口口岸 / 瑞丽口岸 / 中老铁路全线开通)
- **影响**:
  - **东南亚语种**(越南语 / 老挝语 / 缅甸语 / 泰语)在云南有独家实战环境(云民大主力)
  - **跨境贸易 / 边贸企业 / 跨境电商** 起薪 12-18k(在云南本省就能拿到一线水平)
  - **国际陆海贸易新通道**(西部陆海新通道) 国家战略,云南是核心节点
- **agent 推荐时务必把"东南亚门户"作为云南考生独家路径,不要默认所有文科都是"考公或当老师"那套老逻辑**

### 3. 旅游 + 生物多样性 + 高原特色产业

- **旅游业**:云南是中国旅游核心省,丽江/大理/西双版纳/香格里拉/腾冲 全国知名 → **旅游管理 / 酒店管理 / 民俗文化** 对口
- **普洱茶 / 烟草(红云红河 + 云烟) / 鲜花(斗南鲜花市场,亚洲第一) / 咖啡(普洱/保山 中国咖啡主产区)** = 云南特色农业产业链 → 云农大 / 云财大对口
- **生物多样性 + 中草药**(云南是中国药用植物宝库,三七/天麻/灯盏花 主产区) → 昆医 / 云中医 / 云农大对口
- **有色金属**(铜/锡/铅/锌,云南是中国有色金属王国) → **昆工冶金 / 有色金属** 对口(云铜 / 云锡 等省内龙头央企)

### 4. 区域教育资源差异极大

- **教育最强地区**:**昆明**(昆一中 / 师大附中 / 云师大附中 / 昆三中 / 滇池中学 等)
- **第二档**:**曲靖**(曲靖一中,云南状元大户)+ **玉溪**(玉溪一中)+ **大理**(大理一中)
- **第三档**:**昭通 / 红河 / 文山 / 楚雄**(各州一中)
- **相对弱**:**怒江 / 迪庆 / 临沧 / 德宏**(边境州市,部分县级中学条件有限)
- **影响**:同样位次,昆一中第 50 名 ≈ 县中前 10 名;agent 在 L1-A 模考估算时务必结合学校层次

### 5. 留云 vs 出省 经济收入对比 + 留云率

- **留云率约 40-50%**(云南考生 50% 以上选择出省,主要流向**成渝 / 广东大湾区 / 长三角**)
- **留云传统行业**(体制内 / 教师 / 医生 / 普通文职):**起薪 4-6k**(税后 5-7w/年)
- **留云本土产业链**(云烟 / 云铜 / 云锡 / 普洱茶产业链 / 旅游业 / 生物制药):**起薪 8-15w**(在云南算高薪)
- **出省成都 IT / 金融**:**起薪 12-18w**
- **出省广东大湾区 IT / 制造业**:**起薪 15-25w**
- **出省长三角金融 / 互联网**:**起薪 15-25w**

**关键洞察**:**云南考生留云不一定低薪,但必须进对路径(本土产业链 / 东南亚门户 / 大数据)**。普通工科 / 文科留云收入明显低,但进云烟 / 云铜 / 云锡 / 生物制药 / 旅游高端 等本土龙头则起薪不输一线。

### 6. 昆明海拔影响(隐性变量)

- **昆明海拔约 1900 米**,大理/丽江/香格里拉 海拔 2000-3300 米
- **气候温和**(昆明四季如春)但**高原反应** 是从平原省份来读书学生的真实问题(湖南/江西/江浙考生考虑出省到云南要纳入考量)
- **本省考生反向**:昆明读书 → 出省到平原省份基本无适应问题
- agent 提醒:平原省份考生填云南院校,体育生 / 心血管慢病史 要谨慎

## 七、易错认知(agent 要纠正用户的)

- **"云南没 985,出去也比不过别人"** — 错。**云南考生考省外 985(川大/重大/电子科大/西交/中山等)分数不高于本省冲云大 211**,且平台天花板高得多。云大 2025 物理类录取位次约 1-1.5 万,这个位次出省可冲川大/重大/西南交大。
- **"留云南只能当公务员 / 老师"** — 错。**云烟 / 云铜 / 云锡 / 红云红河 / 云南白药 / 中国铜业 / 中铝云南** 都是本土龙头,起薪 8-15w,普通工科留云的真正高薪 outlet 是这些本土产业链。
- **"云大就是云南最好的"** — 部分对。**云大综合性最强 + 民族学/生态学全国前列**,但**临床医学 → 昆医更强,师范 → 云师大更强,有色金属/冶金 → 昆工更强,东南亚语 → 云民大更强**(双非不影响这些专业的就业认可度)。
- **"少数民族加分跟分数线直接相加"** — 半对。加分**只对部分院校生效**(教育部直属高校认全国通用加分,部分省外院校只认 5 分以内),具体看院校招生章程。**直过民族(独龙/德昂/基诺)有专项扶持,资格更宽**。
- **"96 个志愿全填学校"** — 错。**96 个志愿每个都是"院校专业组"**,要精准到组,不是只填学校名。
- **"昆明海拔不高,影响不大"** — 半错。昆明 1900m 影响有限,但大理/丽江/香格里拉 海拔 2000-3300m,平原省份学生填这些地方院校(如大理大学/迪庆藏文学院)要慎重。
- **"云南就是个旅游省份,没什么产业"** — 严重错。**云南是中国有色金属王国 + 烟草巨头(云烟全国第二) + 中草药基地 + 中国-东盟门户 + 中老铁路核心节点** —— 真实产业纵深比家长印象深得多。

## 八、关键提醒(agent 必须强调)

1. **云南 2025 才首届 3+1+2,新口径数据只有 2025 一年**(单点数据,大小年风险无法判断,**比贵州/广西的样本量更紧张**)
2. **云南本科批 96 个志愿**(比湖北湖南江苏都多)
3. **看位次不看分数**(老高考与新高考分数不可直接换算,云南 2024 分数线偏高,新高考会重置)
4. **再选科目限制**(必选化学 / 必选政治等)是硬约束
5. **少数民族加分 + 直过民族专项 + 民族班** 是云南独有政策红利,要查当年具体政策 + 院校认可度
6. **东南亚门户**(云民大东南亚语 / 跨境电商 / 边贸)是云南独家高薪 outlet
7. **本土产业链**(云烟/云铜/云锡/云南白药/普洱茶/旅游) 是留云高薪路径,起薪 8-15w 不输出省一线
8. **云南唯一 211 是云南大学**,其他都是双非(但部分双非专业全国前列,如昆工冶金/有色金属、昆医临床、云师大教育、云民大民族学/东南亚语)
9. **昆明海拔 1900m**,平原省份考生填云南院校要纳入考量;云南考生出省基本无适应问题
