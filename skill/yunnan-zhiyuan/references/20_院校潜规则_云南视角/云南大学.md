# 云南大学(云大,YNU)— 211 + 双一流 A 类,云南唯一 211,本省第一首选

## 一句话总结

**云南唯一 211 + 双一流 A 类(民族学 / 生态学)**,本省综合实力第一,**1923 年东陆大学血脉 + 西南联大办学传统部分继承者**,文科底蕴比想象深。**民族学 + 生态学 全国前列**(中央民大 + 云大 + 中南民大 三足鼎立),**留省考公考编 + 区直机关 + 央企云南分公司 = 云大本地认可度独家**。**云南家长心目中"上不了 985 就退而求其次的最稳一档"** —— 走出云南牌子比中游 211 略弱,但双一流 A 类加成让云大比纯中游 211 值钱一档。

---

## 真实地位

- **211 + 双一流 A 类**(民族学 / 生态学双一流学科),教育部与云南省"区部共建"老牌综合性大学
- **全国 211 排名靠后**(跟山西大学 / 海南大学 / 新疆大学 / 宁夏大学 / 广西大学 一档),但**双一流 A 类学科加成 让牌子比纯中游 211 值钱一档**
- **本省地位**:**云南综合实力第一,本省第一首选,无替代**(云南唯一 211)
- **历史血统**:1923 年东陆大学创办 → 国立云南大学 → 西南联大撤离后部分师资留昆并入云大,文科血脉深
- **校区地理**:**昆明呈贡区(主校区)+ 翠湖校区(老校区,文科底蕴)**,**昆明海拔 1900m 四季如春,生活宜居度全国前列**

## 性价比专业(云大独家)

- **民族学(双一流 A 类)**:**全国跟中央民大 / 中南民大并列三足鼎立**,**云南民族研究 + 跨境民族(中越/中老/中缅边境)研究 全国独家资源**。出云南到一线认可度也高(双一流学科加成)。
- **生态学(双一流 A 类)**:**云南是中国生物多样性宝库**(植物 / 动物 / 微生物种类全国第一),**云大生态学背靠中科院昆明植物所 + 中科院昆明动物所**,**学术 / 环保 / 生物医药 路径都通**。
- **天文学**:**全国仅 10 所左右开设的小众专业**,云大背靠丽江高美古天文台 + 中科院云南天文台,适合喜欢理论物理 / 天文方向的考生。
- **东南亚研究 / 国际关系**:**云南是面向东盟门户**,云大东盟研究跟云民大并列区内顶配,**做外交部 / 商务部驻东盟 / 智库 / 跨境贸易 = 云大平台够用**。

## 坑专业 / 慎选(在云大里相对弱)

- **计算机 / 软件工程**:**云大 CS 不弱但不如成电 / 重大 / 川大**,跟出省 985 比无优势,**只适合"想留昆明 IT" 的考生**,出省卷大厂牌子拖后腿。
- **法学**:在云大里中等,**跟西南政法 / 川大法 / 中南财法 比无优势**,**留云考公 OK,出省进律所牌子不够**。
- **临床医学(云大医学院)**:**比昆医弱,选医学优先昆医**(云大医学院规模小 + 附属医院不如昆医)。
- **新闻传播 / 教育学**:中等,跟出省专业类强校比无优势。

## 关键提醒(填报陷阱)

1. **云大本部 vs 云大滇池学院**:**只有本部是 211**,**滇池学院 = 独立学院 / 民办**,**学费贵 + 牌子差,报志愿别看错代码**。
2. **云大呈贡校区 vs 翠湖校区**:**本科生主要在呈贡(新区,离主城远)**,**翠湖校区(老校区,主城核心)主要研究生 + 部分文科**,**接受不了呈贡偏的别报**。
3. **服从调剂**:云大组内可能含天文学 / 部分理科冷门,**勾服从前查清组内有什么** —— 想做民族学 / 生态学的别被调到经管。
4. **云大 vs 昆工**:**学综合性 + 想要 211 牌子 → 云大**;**学冶金 / 有色金属 / 矿业 + 进央企 → 昆工对口工科超过云大**;**两校综合排名互有胜负,关键看专业方向**。

## 毕业出口(2024 数据)

- **留云就业**:**约 45-50%**(**昆明 70% + 玉溪 / 红河 / 大理 / 曲靖 / 楚雄 各州市**)—— 云南本地考公考编 + 云烟 / 云南白药 / 云南本地银行 / 云南旅游业 + 区直机关 + 央企云南分公司
- **去成渝就业**:约 15-20%(成都 / 重庆 — 云南到成渝火车 6-8 小时,文化亲缘 + 互联网公司 + 金融)
- **去长三角(沪杭)**:约 8-10%(部分考研后流向)
- **去广东大湾区**:约 10-12%(深圳 / 广州 — 互联网 + 跨境电商,**双一流加成大湾区接受度还行**)
- **考研 / 读博 / 出国**:约 25-30%(保研率 ~10-13%,**云大保研中山 / 复旦 / 浙大 / 北大有少量名额**)
- **进央企 / 国企概率**:约 15-20%(中烟云南 / 云南电网 / 中铁云南 / 国家电网云南 / 云南本地银行)

**起薪反差**:
- **留云考公 / 文职 / 教师编**:4-6k(实在话,留昆明编制起薪不高)
- **进云烟集团(技术岗 / 管培生)**:**8-15w(留云高薪 outlet 第一档)**
- **进云南白药 / 昆药集团(医药相关)**:8-12w
- **出成渝互联网 / 金融**:12-20w
- **出广东大湾区互联网**:**15-25w**(差距 2-3 倍,但生活成本也高)

## 同档对比

| 维度 | 云大 | 昆工 | 中游 211(海大 / 新大 / 宁大) | 出省川大 / 重大(985) |
|---|---|---|---|---|
| 牌子 | **211 + 双一流 A** | 双非"准 211" | 211(纯) | **985** |
| 综合性 | **强(本省第一)** | 工科为主 | 中等 | 强 |
| 工科 | 一般 | **强(冶金顶配)** | 中等 | 强 |
| 民族学 / 生态学 | **全国前列(双一流)** | 弱 | 弱 | 中等 |
| 留云优势 | **顶配(本省第一首选)** | **顶配(工科对口)** | 弱 | 中(出省回流) |
| 录取分(云南) | **本省第一档** | 高(略低于云大) | 中(部分低于云大) | **极高** |

**简单结论**:**留云想要 211 牌子 + 综合性 → 云大无替代**;**学冶金 / 有色金属工科 → 昆工对口超过云大**;**分够冲出省 985 → 川大 / 重大 / 西交 / 中山 / 华工 优于云大**;**云大留作"想稳云南 + 体制内 / 综合发展" 的备选**。

## 适合谁

- 云南文科 **省排 1,500-9,000 名** / 理科 **3,000-18,000 名**(以一分一段表反查为准)
- **想留云南 + 想要 211 牌子 + 综合性发展** → 云大首选,无替代
- **想做民族学 / 生态学 / 生物多样性 / 东南亚研究** → 云大双一流 A 类,云南最优
- **想留云考公 / 进区直机关 / 央企云南分公司** → 云大本地认可度顶配
- **农村少数民族(彝族/白族/傣族/哈尼族 等)+ 国家专项 + 民族班** → 云大对口跨阶级通道
- **家庭普通工薪 + 不愿出省 + 想要稳定** → 云大留省考编最稳

## 不适合谁

- **想做硬工科(冶金 / 有色金属 / 矿业 / 材料)** → 昆工对口超过云大
- **想做医生 + 留云南** → 昆医临床比云大医学院强
- **能上出省 985(川大/重大/中山/华工/西交)** → 优先出省,云大留作备选
- **想做 IT / CS + 进华为 / 大厂** → 出省成电 / 西电 / 华工对口超云大
- **不想留云 + 必须出省一线** → 云大牌子在出省竞争中弱于一般 985
