# 云南师范大学(云师大,YNNU)— 双非但抗战时期西南联大师范学院血脉,云南留省教师主力

## 一句话总结

**云南师范主力高校**,**起源于 1938 年北大 / 清华 / 南开 三校南迁昆明组建的西南联大师范学院**(西南联大撤离后留昆明独立办学),是西南联大唯一留下来的"血脉延续"高校。**马克思主义理论 / 教育学 / 地理学 / 中国语言文学 / 数学(师范方向) / 物理(师范) 全国中等偏上**(双非师范主力档),**留云当老师 + 进云南教研院 / 云南教育出版社 / 课外辅导产业** 标准路径。**师范类双非里"中等偏上"档,跟广师大 / 河北师大 / 江西师大 / 安徽师大 同档**。**女生 + 想当老师 + 留云南公费师范 = 普通家庭最稳铁饭碗**。

## 真实地位

- **双非但师范实力强势**(教育学 / 地理学 / 马克思主义理论 / 中国语言文学 区内第一档)
- **历史血统(独家招牌 ★)**:**1938 年北大 / 清华 / 南开 西南联大师范学院 + 1946 年西南联大撤离时大量教师留昆明组建云师大前身(国立昆明师范学院)**,**西南联大唯一血脉延续高校**,**文科底蕴比想象深**
- **本省地位**:**云南师范主力供给校**(云南各州县中学骨干 80% 出自云师大),**云南教研院 / 云南教育出版社 / 课外辅导机构 主力**
- **同档对比**:**双非师范"中等偏上"档,跟广师大(广州)/ 河北师大 / 江西师大 / 安徽师大 同档**(都是省属师范主力,公费师范资源丰富)
- **校区地理**:**呈贡校区(主校区,新区)+ 一二一校区(老校区,主城核心,西南联大原址)**,**昆明四季如春,师范生生活宜居**

## 性价比专业(云师大独家)

- **公费师范生(教育部直属六大师范以外的"省属公费师范")★**:**学费 + 住宿费全免 + 生活补贴 + 毕业回云南州县中学编制**(返乡服务 6 年),**普通工薪 / 农村家庭最稳铁饭碗路径**。**云师大公费师范覆盖语文 / 数学 / 英语 / 物理 / 化学 / 生物 / 历史 / 政治 / 地理 / 体育 等全学科**。
- **地理学(西南联大血脉)**:**云南地形地貌多样性(高山 / 高原 / 盆地 / 河谷 / 喀斯特)= 地理研究天然实验室**,**云师大地理学是全国双非中前列**,做地理研究 / 中学地理教师 / 国土资源系统都顺。
- **马克思主义理论 / 政治学**:**云南党校 / 思政教师主力供给**,**留云考公考编 + 进党政机关 是性价比之王**。
- **太阳能 / 新能源科学与工程**:**云南光照资源全国前列(2000+ 小时年均日照)**,云师大该专业区内独家,**进隆基绿能 / 通威 / 阳光电源 等光伏企业 起薪 8-15w**(顺周期赛道)。

## 坑专业 / 慎选(在云师大里相对弱)

- **大部分理工科非师范类(纯工科 / 计算机 / 自动化)**:**在云师大里边缘,别为师大牌子学非师范工科**,出云南跟双非工科没差,**学工科选昆工**。
- **经管类(纯非师范金融 / 会计 / 工商)**:**双非师范的经管出省竞争力弱**,**学经管选云财大**。
- **法学**:中等,**学法学选云大法学(留云考公) / 出省西南政法**。
- **新闻传播 / 广告学**:水分大,**毕业改行率高**。
- **独立学院(云师大商学院 / 文理学院)**:**和本部牌子有差**,**勾报前查清楚是不是本部**。

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生(★)**:
   - **名字里有"师范"且是提前批录取 → 公费师范**(免学费 + 编制 + 服务 6 年)
   - **名字里有"师范"但是普通批录取 → 普通师范**(自费 + 自找工作)
   - **千万分清,差几十万学费**
   - **云师大公费师范 vs 教育部直属六大师范公费师范**:**全国通用度上六大师范 > 云师大省属公费**,**但云师大公费可以更稳定地留云州县中学编制**
2. **公费师范的"返乡服务 6 年"是硬约束**:**违约要赔学费 + 写违约记录 + 影响以后考公考编**,**家长一定要跟孩子聊清楚这 6 年要回原籍**(如曲靖学生回曲靖 / 玉溪学生回玉溪)
3. **服从调剂**:云师大组内可能调到非师范专业(纯工科 / 经管),**接受不了的别勾**(想读公费师范的别被调到普通批的非师范)
4. **云师大本部 vs 云师大商学院 / 文理学院**:**只有本部是公办**,**商学院 / 文理学院 = 独立学院 / 民办**,**学费贵 + 牌子差,报志愿别看错代码**
5. **云师大 vs 西南大学(原西南师大,985)/ 出省华师 / 北师**:**分够冲教育部直属六师范(北师 / 华东师 / 东北师 / 华中师 / 陕师 / 西南大学)→ 优先出省**(全国通用编制),**云师大留作"想稳云南州县编制"的备选**
6. **男女比例**:**云师大整体女生为主(7:3),师范类专业女生 8:2**,**男生进师范 反而稀缺(部分中学男教师有招聘倾斜)**

## 毕业出口(2024 数据)

- **留云就业**:**约 70-75%**(云师大留云率全省高校最高)—— **昆明 30% + 曲靖 / 玉溪 / 红河 / 楚雄 / 大理 / 文山 / 普洱 / 西双版纳 / 德宏 / 怒江 各州县中学** —— **公费师范回原籍编制 + 普通师范考省考 / 市考 / 县考编制**
- **去成渝就业**:约 8-10%(成都 / 重庆 — 部分考研后流向 + 部分跨省考编)
- **去长三角(沪杭)**:约 3-5%(部分考研后流向)
- **去广东大湾区**:约 5-8%(深圳 / 广州 — 国际学校 / 民办名校 / 课外辅导产业 + 比亚迪 / 隆基绿能 等新能源企业)
- **考研 / 读博**:**约 20-25%**(保研率 ~5-7%;**云师大保研北师 / 华东师 / 华中师 / 西南大学 有少量名额**)

**起薪反差**:
- **留云州县中学公费师范编制**:**5-7k(月薪)+ 寒暑假 + 五险一金 + 编制稳**(实在话,留云教师起薪不高但稳定 + 五年内涨到 7-9k)
- **留昆明重点中学(云师大附中 / 昆一中 / 昆三中 等)**:**月薪 8-15k + 课后辅导 + 编制顶配**(竞争激烈)
- **进民办名校 / 国际学校(留昆明 / 出粤)**:**月薪 12-20k**(无编制但高薪 + 灵活)
- **进课外辅导产业(新东方 / 学而思在昆明 / 出昆明)**:8-15k(双减后行业受限,但素质教育还有机会)
- **出粤进国际学校 / 民办名校(深圳 / 广州)**:**15-25k**(出粤教师溢价,但生活成本也高)

**简单结论**:**想留云州县当老师 + 普通家庭 + 公费师范零成本 → 云师大省属公费是首选(留云最稳)**;**分够冲教育部直属六师范 → 北师 / 华东师 / 华中师 / 西南大学 优先(全国通用编制)**;**学综合性 + 想要 211 → 云大**(但云大不是师范主力);**分不够云师大 → 大理大学师范 / 曲靖师院 / 红河学院 也是州县编制路径**。

## 适合谁

- 云南文科 **省排 3,500-18,000 名** / 理科 **省排 15,000-60,000 名**(以一分一段表反查为准)
- **女生 + 想当老师 + 留云南州县编制 + 普通家庭** → 云师大公费师范是首选(返乡州县中学编制最稳)
- **男生 + 想当老师**(中学男教师稀缺有招聘倾斜) → 云师大公费师范也很稳
- **想做地理 / 文史研究** → 云师大底蕴比想象深(西南联大血脉)
- **想做党政 / 思政 / 公务员** → 云师大马克思主义理论 + 政治学对口
- **想做光伏 / 新能源**(隆基 / 通威 / 阳光电源) → 云师大太阳能专业区内独家
- **农村少数民族 + 国家专项 + 公费师范 = 双重铁饭碗** → 云师大是隐藏跃迁通道

## 不适合谁

- **完全不想当老师**(公费要求服务 6 年,违约赔钱 + 影响考公记录) → 别勾公费师范
- **男生 + 想做硬工科 / 矿业 / 央企** → 选昆工
- **想做 IT / 大厂 / 互联网** → 出省成电 / 西电 / 华南理工
- **想做财经 / 金融** → 云财大
- **能上 985 / 教育部直属六师范** → 优先出省(全国通用编制)
- **怕教师工资低 / 怕回州县偏远** → 别选公费师范(返乡 6 年是硬约束)
