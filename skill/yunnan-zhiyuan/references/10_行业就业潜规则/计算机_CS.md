# 计算机科学与技术 / 软件工程(CS / SE)— 云南视角

## 一句话总结

**云南本省没有 985 计算机,云大 / 昆工的 CS 出省卷大厂吃亏**。云南考生想吃 CS 红利,**首选出省到成电 / 西电 / 西交 / 华工 / 中山 / 重大**(成渝大湾区两条路径都行,云南到成都火车 6-8 小时);留云只有一条窄路 — **昆工电子 / 云大数学 + 大湾区跨省就业**。**双非 CS 留云 = 进对路径起薪 6-10w(云南本地 IT)/ 进错路径起薪 5-7k**。

---

## 真相 1:云南本地 IT 容量小,留云吃 CS 饭天花板低

- **昆明本地 IT 公司**主要是:云南电网信息中心 / 中国移动云南公司 / 云南本地银行 IT 部 / 一些昆明的小型互联网公司(做旅游订票 / 跨境电商 / 烟草 ERP / 政务系统)
- **没有华为 / 阿里 / 腾讯 / 字节 的研发中心在昆明**(华为有过销售办事处,不是研发)
- **昆明本地 IT 公司起薪 6-10k**,跟成都华为研究所起薪 18-25k 差 2-3 倍
- **结论**:留云吃 CS 饭天花板明确 — **想要互联网大厂级别的薪资就必须出省**

---

## 真相 2:云南考生考 CS 大厂的"地理劣势"被严重低估

- 大厂校招实习招聘高度集中在**北京 / 上海 / 深圳 / 杭州 / 成都(西区分部)**
- 云南本地 IT 公司提供不了"大厂 SP offer 起跳"的实习机会,云大 / 昆工 CS 学生想拿大厂 offer 必须**异地实习**(成都 / 深圳 / 杭州)— **机票 + 住宿成本对普通家庭是 3-5w/年的额外开销**
- 同档 985(成电 / 重大 / 西交 / 华工)在地大厂校招优势天然超过云大 / 昆工
- **云南考生想吃 CS 红利 = 出省读 985,异地实习成本最低**

---

## 真相 3:寒冬 + 学校层次决定一切,这两条云南家长容易低估

- 2022-2024 互联网大厂裁员潮,**头部 985 CS 仍有 25w+ 起薪,双非 CS 起薪掉到 6-8k**(在云南本地)
- 云大 CS 介于"末流 985 — 中游 211" 之间,**双一流 A 类是民族学/生态学不是 CS**,出省校招进大厂概率低于电子科大 / 西电 / 重大
- **昆工电子双非顶配,但出省 IT 招聘认可度比桂电 / 杭电 弱**(桂电更近大湾区,杭电近杭州,昆工地理偏)
- **云南双非二本 / 三本 CS 直接避坑** — 在云南本地 IT 公司起薪 4-6k,跟双非师范 / 双非汉语言考公 比劣势明显

---

## 真相 4:35 岁危机 + 跨省成本是云南考生的双重考验

- 35 岁危机集中在**业务型程序员**(CRUD 调包),**核心技术岗(算法 / 底层 / 芯片)的 35 岁是黄金期**
- 云南考生在大湾区 / 长三角做 CS 到 35 岁,**回云南就业 = 找不到对口大厂岗位**(云南本地 IT 公司养不起 35 岁高薪程序员)
- **结果**:留大湾区生活成本高(深圳 100w 房产首付的水平)/ 回云南做不了对口工作 → **CS 跨省路径对云南家庭的"养老兜底"压力比本地省份(广东 / 江浙)大**

---

## 适合什么人(云南视角)

- **数学好**(高中数学 130+,高考前模考稳定)
- **能上 985 / 211 + 愿意出省读书**(云大 CS 留作云南本地保底,出省 985 是真路径)
- **抗压能力强 + 不怕加班 + 不怕异地实习**
- **家庭中产或以上,撑得起 4 年读书 + 设备 + 异地实习成本**
- **接受跨省工作 5-10 年,30 岁后再决定回云南还是定居一线**

## 不适合什么人(云南视角)

- **数学差**(高中数学 110 以下,CS 学不下去)
- **追求安稳 + 不想 996 + 想留云南 → 选云大法学 / 民族学 / 公费师范 / 昆工冶金 都比 CS 性价比高**
- **双非家庭 + 不打算考研 + 不愿出省 → 别学 CS,等于浪费 4 年**(云南双非 CS 留云就业 5-7k 起薪)
- **农村家庭 + 没有跨省实习预算** → 用同等分数报昆工冶金 / 公费师范 性价比远高于 CS
- **女生 + 不想跟工科男比例 7:3 卷** → 同分情况下汉语言 / 法学 / 教师 在云南考公性价比都超过 CS

## 云南本地 CS 院校真实分层

### 第一梯队(留云 IT / 出省 985 跳板)

- **云南大学 CS** — 211 + 双一流(民族学/生态学,**非 CS 双一流**),CS 评估 B-,**云大 CS 在云南本地 IT 招聘有名校优势,留云做政府 IT / 银行 IT / 移动云南 OK**;**出云南到大湾区 / 成渝 IT 大厂卷不过同档 985**(成电 / 西电 / 重大),**只能拼实习 + 项目**
- **昆工电子 / 计算机** — 双非但工科底子厚,**留云做电网 / 政务系统 IT / 昆明本地 IT** 性价比可以,**出省 IT 大厂招聘弱于桂电 / 杭电**(地理 + 行业认可度差距)

### 第二梯队(避坑梯队)

- **云南民族大学 / 云南师范大学 / 云南农业大学 计算机** — **双非 CS 边缘专业**,在该校都不是强项,**留云做 IT 起薪 5-7k**,**强烈不推荐**(选这些学校就别学 CS,选民族学 / 公费师范 / 烟草工程 才是性价比之王)
- **大理大学 / 红河学院 / 西南林业大学 计算机** — 二本 CS,**留云本地小公司 / 政务外包 起薪 4-6k**,**直接避坑**

### 第三梯队(直接避坑)

- **云南各类民办院校 / 独立学院 CS**(云大滇池学院 / 昆工津桥学院 等)— **学费贵 + 牌子差 + 就业极差**,**普通家庭别为"学计算机能挣钱"幻想送孩子来这里**

## 云南考生出省 CS 推荐路径

| 路径 | 适合谁 | 理由 |
|---|---|---|
| **电子科大 CS / 软件**(成都) | 云南顶级理科考生(物理类省排前 3000) | 云南到成都火车 6-8 小时,**地理近 + 文化亲 + 留成都 / 回昆 双向通勤** |
| **西电 CS**(西安) | 物理类省排 3000-6000 | 西电 CS 是双非顶配 / 双一流加成,**性价比超过部分中游 211** |
| **重大 CS / 西南交大 计算机**(重庆 / 成都) | 物理类省排 5000-10000 | 985 牌子 + 离云南近 + 成渝 IT 招聘 |
| **华南理工 CS**(广州) | 物理类省排前 3000 | 大湾区 IT 主力供给校,云南到深圳飞机 1.5 小时,大湾区路径 |
| **桂林电子科技 CS**(桂林) | 物理类省排 8000-15000 | 双非顶配 + 离云南近(桂林到昆明火车 5 小时)+ 大湾区辐射 |

**核心建议**:**云南考生想吃 CS 红利,优先出省**(成渝两条路径都行),云大 / 昆工 CS 留作"想留昆 + 接受 IT 起薪 6-10k"的保底。

## 典型 case(供 agent 引用)

### Case A:昆工电子男生(普通家庭,昆明)

- 昆工电子工程 → 实习昆明本地 IT(中国移动云南分公司)→ 校招进昆明本地银行 IT 部 月薪 8k + 五险一金
- **属于"留云 IT 中等" 路径**,稳定但天花板低,**不算逆袭也不算踩坑**
- 跟 同等分数出省到桂电 / 西电 比,起薪差 1 倍以上(出省可拿 16-20k)

### Case B:云大 CS 男生(中产家庭,昆明)

- 云大计算机学院 → 大三去深圳实习字节 → 校招拿到字节深圳 SP offer 28w 起 → 入行
- **逆袭路径,但前提是"中产家庭撑得起异地实习成本"**(深圳实习 6 个月 + 房租 + 交通约 5w)
- **同样位次 同样选择 CS 留昆 → 完全没有这个机会**

### Case C:云南二本 CS 男生(农村家庭)

- 云南某二本 CS → 校招进昆明本地小型外包公司 月薪 5k → 2 年后跳槽到云南某政务外包 月薪 7k
- **没有逆袭,跟同校汉语言 / 师范专业考公成功的同学比明显劣势**(后者考上事业编 + 编制稳)
- **典型踩坑**:家长以为"学计算机能挣钱",学校层次不够 + 留云 IT 容量小,起薪还不如双非汉语言考公

### Case D(反面):云南农村女生(普通家庭)

- 高考 580 分物理类 → 家长想"学 CS 听起来挣钱多"→ 报云大 CS
- **建议改报云大民族学 / 法学 + 留云考公** — 双一流加成 + 留云考公 + 编制稳
- 学 CS 的代价:**异地实习撑不起 + 双非家庭跟不上信息差 + 留云 IT 起薪 6-8k 跟编制差不多 + 35 岁危机风险大**

## 给云南家长的金句(实在话)

> "**'计算机一定好就业'是 5 年前的认知,在云南尤其要打折扣**。云南本地没有华为 / 阿里 / 腾讯 / 字节 的研发中心,本地 IT 公司起薪 6-10k —— 跟事业编公务员差不多,**但 CS 没有 35 年退休保障,不如编制稳**。"

> "**云南考生想吃 CS 红利,基本盘是出省 985 / 211**(电子科大 / 西电 / 重大 / 西南交大 / 华工 / 中山)+ 异地实习 + 大湾区或长三角就业。**云大 / 昆工 CS 留昆 = 能找到工作但起薪一般,跟事业编差不多 + 风险更高**。"

> "**双非 CS 留云 = 死局**。跟双非汉语言考公比 / 跟昆工冶金进央企比 / 跟云农大烟草工程进云烟比 — **CS 起薪没优势 + 35 岁风险大**,云南家长报这个等于让孩子白学 4 年代码然后毕业去做销售。"

> "**云南家长容易踩的坑**:听说"计算机挣钱"就让孩子报二本三本 CS。**真相是 — 985 计算机依然好就业(出省到大厂),双非二本三本 CS 在云南就业不如双非师范 / 双非汉语言**。同样位次报错专业,5 年后差距 10-15w 年薪 + 编制保障。"

## 易错认知(agent 要纠正用户的)

- **"留云就有云大 / 昆工 CS,出去干嘛"** — 错。**云大 CS 在云南有名校优势但本地 IT 容量小**,**想吃大厂红利必须出省**。云南到成都 6-8 小时火车,出省没那么远。
- **"昆明的字节 / 阿里都有"** — 错。**这俩公司在昆明只有销售办事处不是研发中心**,**没有大厂研发岗在云南**,云南考生想做研发必须跨省。
- **"双非 CS 也能进华为"** — 半对。**华为校招主要看 985/211 工科 + 实习项目**,双非二本三本极少能进。**昆工电子 / 桂电 / 杭电 双非顶配进华为有可能,云南其他双非 CS 基本没机会**。
- **"学 CS 抗失业"** — 错。**双非二本 CS 比双非汉语言考公的失业率高得多**(35 岁危机 + 行业波动),云南家庭抗风险弱不该选 CS 当兜底专业。

## 关键提醒

**云南考生学 CS 的隐性条件**:
1. **能上 985 / 211**(云大 CS 是底线,以下都是踩坑)
2. **家庭中产以上**(撑得起 4 年读书 + 异地实习 5w/年)
3. **接受出省 5-10 年再回云南**(留云做不了对口大厂岗位)
4. **数学好 + 抗压强 + 不怕跟全国卷王竞争**

**符合 4 个条件 → CS 是云南考生跨阶级路径之一**;**4 个条件少一个 → 改其他专业,云南有更适合的路径**(冶金 / 烟草 / 公费师范 / 民族学 / 东盟语)。
