# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(云南视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。**云南考生家庭画像比湖北 / 河南 多一个变量** —— **少数民族成分**(云南 33% 少数民族,全国第 2),**少数民族加分 + 民族班 + 国家专项 + 直过民族专项 = "五通道"政策红利,这是云南独有的"档外变量"**。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**;**汉族 vs 少数民族 农村家庭的最优解也可能不同**(后者多了"五通道"杠杆)。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入 + L2.3 民族成分),按本文件的 5 档矩阵 + 民族变量 套对应策略。

---

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。云南体制内家庭多分布在**昆明 / 玉溪 / 红河 / 大理 / 曲靖** 州市机关 + 烟草系统(云烟 / 红云红河 / 红塔)+ 电网系统(南方电网云南分公司)+ 烟草批发系统。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易;**云南体制内家庭"资源圈"通常局限在一个州市**(不像北上广跨省流动)
- **少数民族体制内家庭**(彝族 / 白族 / 傣族 / 哈尼族 干部)在民族地区 / 边境州市 有独家资源

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **211 选调生路径**:如果孩子能上 985/211(云大或出省 985),**走选调生比国考省考更优**(起点更高、竞争内部化)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:云南警官学院 / 公安联考 + 父母编制资源 = 进云南公安系统;**烟草系统二代** 父母资源直接对口云农大烟草工程 → 进云烟 / 红塔 / 红云红河

**典型 case**:
- 昆明某州直机关家庭(父亲烟草专卖局,母亲事业编)→ 孩子 590 分历史类 → 推**云大法学 / 行政管理** → 毕业留昆考公 / 选调进云南省直,**家庭路径完美匹配**
- 玉溪某体制内家庭(父亲玉溪烟厂,母亲教师)→ 孩子 600 分物理类 → 推**云农大烟草工程 + 父亲资源直接对口云烟集团** → 起薪 10-15w + 编制,**家族烟草系统接力**
- 失败 case:同样家庭,孩子被推去出省读 CS → 毕业 25w 起薪很高,但家长不满"不稳定 + 离家远",劝其回云南,**两年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师 / 律师)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。云南专业人员家庭多分布在**昆明 + 各州市城区**(昆明医科大学附属医院 + 各州三甲医院医生群 + 各州一中老师群 + 昆工 / 云大 / 云师大 教职工二代)。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道
- **云南医生家庭** 资源主要在昆医系附属医院群;**教师家庭** 资源主要在各州一中 + 云师大

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(云师大);医生家庭 → 临床 / 口腔(昆医)/ 中医(云中医)
2. **行业相关延伸**:律师家庭 → 法学(云大 / 出省);工程师家庭 → 对应工科(昆工 / 出省)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(云南没金融行业资源,要拐杖去出省)

**典型 case**:
- 母亲昆明师范附中语文老师 + 父亲普通工薪 → 孩子 580 分历史类 → **云师大公费师范汉语言** → 毕业回昆明本地中学 / 同区编制,**母亲资源直接复用**
- 父母都是昆医一附院医生 → 孩子 640 分物理类 → **昆医临床 5+3 一体化** → 父母能撑 8 年读书 + 昆医附属医院推荐 → **典型子承父业路径**
- 玉溪某医生家庭 + 孩子 620 分物理类 → 父母推**昆医口腔(留云开诊所路径)**或者**出省冲武大口腔 / 川大华西口腔**(若分够,行业拐杖出省也通)

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。云南私企家庭多分布在**昆明 + 旅游城市(大理 / 丽江 / 西双版纳 / 腾冲 高端旅游业主) + 普洱(普洱茶产业链) + 瑞丽 / 磨憨(跨境贸易) + 斗南(鲜花产业)**。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **云南私企家庭"接班产业" 多元**:旅游业 / 普洱茶 / 鲜花 / 跨境贸易 / 餐饮(过桥米线 / 鲜花饼) / 民族文创

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(云财大 / 出省)/ 经济学 / 金融 / 国贸(出省顶配)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野;**云南到东南亚距离近,留学泰国 / 新加坡 / 马来 性价比高**
4. **接班路径独家**:
   - **普洱茶家族二代** → 云农大茶学 + 创业 / 电商接班
   - **旅游业家族二代** → 云财大旅游管理 + 高端酒店 / 文旅公司接班
   - **跨境贸易家族二代** → 云民大越南语 / 缅语 / 老挝语 + 跨境电商接班
   - **斗南鲜花家族二代** → 云农大园艺 + 鲜花电商接班
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 大理某高端民宿老板家庭(年入 200w+) → 孩子 580 分历史类 → 推**云财大旅游管理 / 出省中山大学旅游(分够冲)** → 接班高端旅游业,**家庭基因完美匹配**
- 普洱某茶业老板家庭 → 孩子 560 分物理类 → 推**云农大茶学 + 学电商运营** → 接班普洱茶产业 + 电商化转型
- 瑞丽某跨境贸易家庭 → 孩子 540 分历史类(傣族,有民族加分)→ 推**云民大缅甸语 + 国际经济与贸易** → 接班中缅边贸 + 跨境电商
- 失败 case:云南私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主。云南普通工薪家庭多分布在**昆明城区(三产服务业 / 烟草系统基层 / 电网基层)+ 玉溪(烟草) + 各州市城区(教师 / 医生 / 公务员 基层) + 国营烟厂工人 / 云铜云锡基层员工**。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(云师大)= 高考分适中 + 直接编制 + 无学费**(云南州县缺教师严重,返乡 100% 编制)
   - **云南警官学院 + 公安联考** = 进云南警察系统编制
   - **昆医医学影像 / 检验 / 护理** = 三甲医院技术岗 + 4 年本科即可
   - **殡葬专业**(出省到长沙民政 / 北京社管)= 100% 编制 + 收入意外不错
3. **次推稳定就业型**:
   - **昆工电气进南方电网云南**(分够昆工,本地认可)
   - **昆工冶金进云铜 / 云锡 / 中铝云南**(对口央企,起薪 10-15w)
   - **云农大烟草工程进云烟 / 红塔 / 红云红河**(对口烟草巨头,起薪 10-15w)
   - **师范类(汉语言 / 数学师范)+ 公费师范**
   - **护理本科 + 边境州市医院 + 边远艰苦补贴**
4. **避免高风险方向**:
   - **金融 / 经济 / 工商管理**(云南双非这些 = 死局)
   - **双非 CS**(云南本地 IT 容量小,起薪 5-7k 不如双非师范)
   - **生化环材**(必须读博才有出路,普通家庭撑不起)
   - **临床医学**(5+3+规培 8 年长周期,普通家庭撑不起)
   - **心理学 / 历史学 / 哲学**(本科出口窄,必须读研)
   - **新闻学双非**(云南媒体小,出路差)

**典型 case**:
- 玉溪某烟厂工人家庭 → 孩子 600 分物理类 → 推**云农大烟草工程 + 进云烟 / 红云红河** → 毕业进玉溪烟厂技术岗,**月入 1.2w + 编制,家庭代际接力**
- 昆明某普通工薪家庭 → 孩子 540 分历史类 → 推**云师大公费师范汉语言** → **无学费 + 毕业回昆明本地中学编制,家庭命运改变**
- 大理某汉族普通家庭 → 孩子 580 分物理类 → 推**昆工电气 + 进南方电网大理供电局** → 起薪 8k + 编制
- 楚雄某汉族普通家庭 → 孩子 560 分物理类 → 推**昆医医学影像技术 + 返乡楚雄州医院** → 起薪 6-8k + 编制 + 当地住房成本极低
- 红河某汉族普通家庭 → 孩子 590 分历史类 → 推**云大法学 / 行政管理 + 留昆考公** → 编制铁饭碗

## 档位 ⑤ 农村 / 临工家庭(云南独家:细分汉族 vs 少数民族)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。云南农村家庭分布广 — **山区农村(楚雄 / 红河 / 文山 / 怒江 / 迪庆 / 临沧 / 德宏 / 西双版纳 等)+ 坝区农村(玉溪 / 大理 / 楚雄 部分)**。**约 70% 云南农村家庭是少数民族**(彝 / 白 / 傣 / 哈尼 / 壮 / 苗 / 傈僳 / 拉祜 / 佤 / 纳西 / 瑶 / 藏 / 景颇 / 布朗 / 普米 / 阿昌 / 怒 / 基诺 / 德昂 / 蒙古 / 水 / 满 / 独龙 / 布依),**汉化程度差异极大**。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校 + 政策红利
- **少数民族家庭 多了"五通道"政策红利**(加分 + 民族班 + 国家专项 + 高校专项 + 直过民族专项),**这是云南独家"杠杆"**

**推荐策略**:

### 5A. 汉族农村家庭

1. **学校牌子 > 专业方向**(到一定程度)
   - 云大牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**云大弱专业 > 双非强专业**(对汉族农村家庭而言,牌子价值 > 专业价值)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(云师大)= 无学费 + 编制** = 农村家庭神器
   - **国家专项计划 / 高校专项**(云大 / 昆工 / 出省 985 都有名额,降分 30-50)
   - **云南警官学院 + 公安联考** = 进云南警察系统编制
   - **昆医医学影像 / 检验 / 护理 + 返乡** = 4 年本科 + 编制
   - **昆工电气 + 南方电网县级供电所** = 编制基层路径
3. **避免长周期投入**:
   - **临床医学 8 年**(撑不起)
   - **必须读博的基础学科**(撑不起)
   - **出国 / 中外合作**(撑不起)

### 5B. 少数民族农村家庭(云南独家"五通道"杠杆!)

**所有 5A 推荐都适用,但加上"五通道"红利,跨档机会更大**:

1. **少数民族加分**:5-20 分(具体看民族 + 地区,**怒江 / 迪庆 / 西双版纳 / 德宏 / 临沧 等边境艰苦地区加分更高**)
2. **民族班**:云大 / 云民大 / 云师大 / 出省民族大学 都有民族班招生(降分 30+)
3. **预科班**:适合分数差但有潜力的少数民族学生(降分 30-50,读 1 年预科再升本科)
4. **国家专项计划**(教育部直属高校 + 985/211 多个名额):**降分 30-60**
5. **直过民族专项**(独龙 / 德昂 / 基诺 / 怒 / 傈僳 / 拉祜 / 佤 / 景颇 等"直过民族"专项扶持):**最大降分**

**叠加用法举例**:
- 怒江傈僳族考生 540 分(理科)→ 加分 + 国家专项 → 实际等效 580+ 分 → **可冲云大 / 昆工 / 部分出省 211**
- 西双版纳傣族考生 510 分(文科)→ 加分 + 民族班 → 实际等效 545+ 分 → **可冲云民大东南亚语种**
- 独龙江独龙族考生 470 分 → 直过民族专项 + 加分 → **降分 60+ 进云大民族班**

**特殊机会**:
- **国家专项计划**:云南农村户籍,985/211 名校多个专项指标(分数比统招低 30-60 分)
- **高校专项计划**:同等农村户籍,部分顶级 985(清华 / 北大 / 复旦 等)有专项
- **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
- **公费师范生 + 民族地区返乡**:**云师大公费师范 + 民族班 = 双重红利,无学费 + 包返乡州县中学编制**

**典型 case**:
- 怒江傈僳族汉族家庭 → 孩子 540 分物理类 → 通过**国家专项 + 民族加分**进**云大生态学**(比统招分低 40 分)→ 211 + 双一流 A 类牌子 + 民族 + 农村专项,**整个家族第一个 211**
- 西双版纳傣族家庭 → 孩子 520 分历史类 → 通过**民族班**进**云民大泰语 / 缅甸语** → 毕业进瑞丽口岸跨境电商,**家庭命运改变(传统农户 → 跨境贸易从业者)**
- 独龙江独龙族家庭 → 孩子 460 分理科 → 通过**直过民族专项**进**云大民族学预科班** → **大学第一个独龙族学生 + 民族学研究方向 + 留省考公编制**
- 楚雄彝族农村家庭 → 孩子 580 分文史类 → **加分 + 公费师范** → 推**云师大汉语言文学公费师范** → 4 年无学费 + 毕业回楚雄某县中学当语文老师,**最适合彝族农村家庭的"零风险"路径**
- 文山苗族山区家庭 → 孩子 500 分理科 → **加分 + 国家专项** → 推**昆医医学影像技术** → 返乡文山州医院技术岗 + 编制,**家庭跨阶级**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 + 民族成分**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**云南独家变量** — **少数民族成分 + "五通道"政策红利** 必须在 L2 阶段就采集清楚:
- L2.3 民族(汉 / 彝 / 白 / 傣 / 哈尼 / 壮 / 苗 / 回 / 傈僳 / 拉祜 / 佤 / 纳西 / 瑶 / 藏 / 景颇 / 布朗 / 普米 / 阿昌 / 怒 / 基诺 / 德昂 / 蒙古 / 水 / 满 / 独龙 / 布依)
- L2.4 户籍(城市 / 县乡 / 山区 / 边境)
- L2.5 是否享受国家专项 / 高校专项 / 民族专项资格

不查清这些 = 浪费云南独有的政策红利,**这是云南 agent 跟其他省 agent 最大的差异**。
