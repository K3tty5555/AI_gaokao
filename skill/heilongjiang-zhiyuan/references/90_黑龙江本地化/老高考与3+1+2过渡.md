# 黑龙江 老高考 → 3+1+2 过渡(数据现状 + 政策对比)

## 核心结论

**黑龙江 2021 年加入新高考第四批,2024 年高考首届实行 3+1+2**(跟甘肃 / 吉林 / 安徽 / 江西 / 贵州 同批)。**这意味着 2024 年是分水岭**:**2021-2023 年仍是文/理科老高考,2024-2025 年是 3+1+2 物理/历史类**。**跨年比较录取数据时必须分两段看,不能直接拿 2023 文/理科分数对应 2024 物理/历史类**。

总体规则跟辽宁 / 湖北一致,但黑龙江有几个**非常重要的本地特殊性**:**国防工业重镇 + 哈工大 C9 顶配 + 体量小 + 985 名额相对宽松 + 留黑率仅 30-40% + 京津/长三角/沿海虹吸严重**。

## 关键事实

### 时间表

| 年份 | 高考类型 | 录取数据格式 |
|---|---|---|
| 2021 | 文科 / 理科(老高考) | 文/理科 + 一本/二本/专科 |
| 2022 | 文科 / 理科(老高考) | 文/理科 + 一本/二本/专科 |
| 2023 | 文科 / 理科(老高考) | 文/理科 + 一本/二本/专科 |
| **2024** | **物理类 / 历史类(首届 3+1+2)** | 物理/历史类 + 本科批/特控线 |
| 2025 | 物理类 / 历史类 | 物理/历史类 + 本科批/特控线 |

**意义**:**2024 是首届新高考 + 取消一二本合并的过渡年**,新规则下的录取分数线、位次结构、专业组划分都跟老高考不同。家长拿 2023 年理科分数 / 一本线对应 2024 物理类是错的。

### 考试结构(2024 起)

- **3 = 语文 + 数学 + 英语**(各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- **两类完全分开排名、分开录取**
- 黑龙江物理类约 65-70%,历史类约 30-35%(物理占比高于全国平均,因为本省工科强校多)

### 院校专业组(2024 起)
- 不再按"学校"投档,**按"院校专业组"投档**
- 一所学校可有多个专业组
- 同一学校的不同专业组独立投档
- **服从调剂只在本专业组内调剂**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量
- **黑龙江本科批 96 个志愿**(2024 起,跟河北 / 辽宁部分批次相当;具体数字以黑龙江省招办最新文件为准,部分批次报道为 96-112 个)
- **专科批 60 个**
- 每个志愿 = 1 个院校专业组
- **意义**:黑龙江填报"操作空间大",冲稳保梯度可以铺得开,但也意味着**填错容易、信息搜集成本高**,需要更精细的位次梯度

### 12 种选科组合
跟全国新高考统一(物 + 化生 / 物 + 化政 / 物 + 化地 / 物 + 生政 / 物 + 生地 / 物 + 政地 / 史 + 化生 / 史 + 化政 / 史 + 化地 / 史 + 生政 / 史 + 生地 / 史 + 政地)。

可报专业范围参考详见 `_shared/references/00_核心方法论/采集_rubric.md` L1 单科分数判断。

## 黑龙江最大特殊性(关键!!)

### 1. 黑龙江是**东北高考相对友好省**(同辽宁,优于吉林)

东北三省里(辽吉黑),**黑龙江本科分数线偏低 + 985 名额相对宽松**:
- **本科分数线偏低**(2024 取消一本二本合并后划线低,跟辽宁同档)
- **985 名额倾斜本省**(哈工大 / 哈工程在本省招生量大)
- **考生体量小**(黑龙江高考报名约 19 万 / 年,**远少于河北 75 万 / 河南 130 万**;近年因人口外流持续下降)

但"友好"是相对的 —— 上 985 的难度跟其他省差不多,**真正友好的是上一本本科 + 部分中等 211**。

### 2. 黑龙江是**国防工业重镇**(航天 / 船舶 / 兵器)

哈尔滨是中国国防工业大本营之一:
- **哈工大** = 中国航天系统对口神校(神舟 / 嫦娥 / 天宫;C9 + 国防七子之首)
- **哈工程** = 船舶与海洋工程全国第 1(原哈军工分支,中船重工 / 海军装备对口)
- **哈电集团** = 中国三大动力集团之一(哈电 / 上电 / 东方电气)
- **哈飞 / 哈轴 / 哈一机** = 老牌军工企业群

**意义**:黑龙江**工科教育资源全国一流**,跟地理北 / 冷形成鲜明反差。**男生 + 工科 + 想进国防系统/央企 → 黑龙江本省院校就是天花板**。

### 3. 留黑率仅 30-40%(人口外流极严重)

- 黑龙江人口外流是东三省最严重的省份
- **留黑就业率仅 30-40%**(辽宁约 50%,吉林约 40-45%)
- 高分段考生大量流向京津 / 长三角 / 珠三角 / 沿海
- 留黑 = 接受东北就业生态(国企铁饭碗多 + 民企就业极弱)
- **本省哈工大 / 哈工程毕业生留黑比例不到 20%**(主流是去航天院所 / 中船重工各地分院 / 京津长三角)

### 4. 黑龙江 2024 取消一本二本合并(本科批划线低)

**关键认知**:黑龙江 2024 年起(首届 3+1+2),**只有"本科批"和"特控线"两条线**:
- **本科批** = 原一本二本合并后的最低控制线
- **特控线**(原一本线)= 985/211 + 强势院校的最低门槛

**结果**:黑龙江本科线不高,**这不是黑龙江考生水平低,是划线规则不同**。看位次别看分数。

### 5. 黑龙江名校结构(精炼但顶配)

- **2 所 985**:哈尔滨工业大学(C9 + 国防七子之首)/ ~~东北农业大学和东北林业大学不是 985~~(纠正:黑龙江 985 只有 1 所哈工大;**严格意义上 985 = 哈工大 1 所**;但哈工程虽是 211 不是 985,因 C9/国防七子并列地位社会认可度极高,本知识库按"准 985"对待)
- **正式 211**:哈工大(985 兼 211)/ 哈尔滨工程大学 / 东北农业大学 / 东北林业大学 — **共 4 所 211**
- **国防七子**:哈工大 / 哈工程(7 所国防工业部直属院校,黑龙江占 2 所)
- **黑龙江大学(黑大)**:双非但俄语全国第 1
- **哈尔滨医科大学(哈医大)**:双非但临床医学顶级
- **哈尔滨理工大学(哈理工)**:双非但电气工程强

详见 `黑龙江强校真实地位.md`。

> **注**:哈工大常被合并简称为"黑龙江两所 985"(因哈工程社会认可接近 985),严格 985 名单里黑龙江只有哈工大 1 所。本系列文档里两种说法都会出现,以"哈工大正式 985,哈工程 211 但 C9 待遇"为准。

## 黑龙江 跨年录取数据 怎么对比(关键!!)

### 数据现状

| 年份 | 字段 | 处理建议 |
|---|---|---|
| 2021-2023 | `subject_type = 文科 / 理科`,批次 = `本科一批 / 本科二批 / 专科` | **理科 ≈ 物理类**(粗略对应,**位次 ≈ 位次**,不是分数 = 分数) |
| 2024-2025 | `subject_type = 物理类 / 历史类`,批次 = `本科批 / 本科特控批` | 直接看 |

### 跨年对比的正确姿势

**1. 老高考 → 3+1+2 跨年比对,只看位次,不看分数**

例:
- 2023 理科某校投档线 580 分 / 位次 8500
- 2024 物理类某校投档线 540 分 / 位次 8800
- **位次相近**(8500 vs 8800),**分数差 40 分但其实是同档**(2024 划线规则变化导致总分体系下移)

**2. 文科 ≠ 历史类 严格对应,但位次有参考价值**

文科和历史类**考试结构相似**(语数英 + 文综 vs 语数英 + 历史 + 再选 2)、**人群相似**(都是文科生),**位次大致可比**。但因为再选科目选择面变了,**部分专业组(如要求"政治"的)位次会有 5-10% 浮动**。

**3. 数据库 query_school 的处理**

`query_school.py` 在黑龙江按 `--type 物理类 / 历史类` 查询时,**默认拉取 2024-2025 数据**(新高考时代);如果需要看 2021-2023 老高考趋势,**需要单独 query 文/理科**。**生成志愿卡片时,2024-2025 用物理/历史,2023 用理/文标注转换**。

## 选科建议(黑龙江视角)

### 物理类 vs 历史类 怎么选

**物理类**(强烈建议优先):
- 可报专业**约 90%**(几乎所有理工科 / 大部分经管 / 部分医学要求物化)
- 985/211 在黑龙江物理类招生量 **>>** 历史类(哈工大 / 哈工程 / 东北农大 / 东北林大 都是工科主导)
- 起薪 + 就业 + 考研 全面优势
- 黑龙江物理类约 65-70% 考生

**历史类**:
- 可报专业**约 40%**(文史哲 / 法学 / 部分经济 / 部分管理)
- 哈工大 / 哈工程 历史类招生少(哈工大不在黑龙江历史类招生,哈工程极少)
- **优势:卷得稍轻 + 适合考公方向**(汉语言 / 法学 / 历史 等公考友好专业)
- 黑龙江历史类约 30-35% 考生

**结论**:**除非数学物理底子真的差(物理常 50 分以下),否则优先物理类**。这跟全国新高考省份一致,但黑龙江因为本省强校都是理工科,差异更明显。

### 再选科目组合(物理类)

**强推:物化生**(可报专业最广,医学 + 化工 + 生物 + 计算机 + 大部分工科都开;劣势:卷)

**次选:物化政 / 物化地**(物化是 90%+ 工科要求的硬通货;再加政 = 考公友好,加地 = 难度低 + 不冲突)

**避坑:物生政 / 物生地 / 物政地**(不选化学 → **直接砍掉化工 / 材料 / 部分医学 / 部分军工**;**哈工大 / 哈工程 / 东北农林大的多数王牌专业都要求"必选化学"**)

### 再选科目组合(历史类)

**强推:史政地**(传统文科黄金组合,法学 / 汉语言 / 历史 / 公考方向通吃)

**次选:史政生 / 史政化**(政是公考神科,搭一个理科再选可拓宽专业面)

**避坑:史化生 / 史生地**(历史类选两理科是错位 — 选了历史就别再纠结理科,可报专业反而变窄)

## 黑龙江志愿填报特殊提醒

### 1. **本省 985/211 在本省招生量大,优先填本省冲一档**

哈工大 / 哈工程 / 东北农大 / 东北林大 在本省招生量 **>>** 出省学生进同档985/211 的概率。**用同样位次,留黑反而能上更好的本省名校**(本省 985 vs 出省 211)。

但要权衡 → 见"留黑率"的反面(就业 + 跨省 + 户口都不利)。

### 2. **国防七子 / 军工系统的特殊路径(关键!)**

哈工大 / 哈工程 是中国航天系统 + 中船重工的对口校。**毕业生进国防院所 = 编制 + 体面 + 普通家庭顶级 ROI**:
- 中国航天科技 / 航天科工(神舟 / 嫦娥 / 长征火箭团队)
- 中船重工 / 中国船舶集团(航母 / 核潜艇 / 大型船舶)
- 兵器工业集团 / 中航工业(军工央企)

**这条路径黑龙江本省考生最容易切入**(本省校 + 本省名额 + 国防系统校招直接来哈尔滨)。

### 3. **冲稳保比例 1:2:5(留黑保底)或 2:3:3(出省冲档)**

留黑路径:冲 1-2 个本省 985/211 + 稳 3-4 个本省 211/双一流学科 + 保 4-5 个本省双非或东三省双非

出省路径:冲 2-3 个出省 211/985 + 稳 3-4 个京津/长三角双非 + 保 3-4 个本省双非

### 4. **跨省 211/985 的"鸡头凤尾"权衡**

例:同样位次能上**本省 哈工程 强势组(冲档)** 或者 **东北财经 双非顶配** 或者 **京津双非好城市**:
- 想做工科 + 进国防系统 → 哈工程 完胜
- 想做财经金融 → 东财 完胜(财经领域东财 ≈ 211 待遇)
- 想留京津 + 一线城市 → 京津双非 + 城市 vs 哈工程牌子,看权重

### 5. **数据来源警告**

- 黑龙江省考试院官网批次线为准
- 哈尔滨招生考试网 / 黑龙江省招生考试委员会
- 一分一段表 = 唯一精确数据(`scripts/score_to_rank.py` 已收录)
- **第三方数据(如各 App)**:**警惕 2024 数据可能不完整**(首届 3+1+2,部分院校专业组数据缺失)
