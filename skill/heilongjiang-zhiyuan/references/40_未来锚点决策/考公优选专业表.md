# 考公优选专业表(黑龙江本地视角)

## 核心结论

**专业决定考公选岗范围**。黑龙江家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**黑龙江特殊放大**:**经济下行 + 民营经济极弱 + 体制内偏好极强 → 考公在黑龙江的"必要性"比湖北 / 江苏 更高**。**留省家庭 70%+ 走党政路线**(湖北是 50%、江苏只有 30%),所以**黑龙江本省考公专业的权重应该比全国平均更重**。

## 关键事实(2024 国考 / 黑龙江省考分析)

### 国考可报岗位数 排名(Top 10 大类,全国通用)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 黑龙江省考特殊性
- 黑龙江省考 + 哈尔滨市考,**汉语言文学和法学并列考公第一专业**
- **黑龙江各地市公务员岗位对法学要求高**(法院、检察院、司法局),**省纪委 / 省检察院 / 省高院 法学院校招主力 = 黑大法学 + 出省政法**
- **基层乡镇 / 县直公务员**(伊春 / 鹤岗 / 七台河 / 双鸭山 / 鸡西 等四五线城市):岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)
- **黑龙江独家:对俄外事岗 + 边境口岸岗** — 黑河 / 绥芬河 / 同江 / 抚远 / 东宁 等中俄口岸的海关 / 边检 / 外事办岗位需要俄语,**这是黑龙江版独家的"地理红利岗"**

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(黑龙江本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- **黑龙江选调生主要定向校(认这几所)**:
  - **哈尔滨工业大学**(本部 + 威海 + 深圳 三校区都认)— 985 + C9
  - **哈尔滨工程大学**(211 + 国防七子,等同 985 待遇)
  - **黑龙江大学**(双非但本省综合性 No.1,**留省考公主力供给校**)— 是少数几个双非里能进黑龙江选调的校
  - **东北农业大学 / 东北林业大学**(211)
  - **东北师范大学**(吉林 985)+ **东北财经大学**(辽宁双非但财经强)— 出省但黑龙江选调认可
  - **出省 985 路径**:北大 / 清华 / 人大 / 北师 / 中政法 / 中财 / 武大 / 中南财法 / 上交 / 复旦 / 华政 / 西交 / 兰大 等
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**

### 公检法岗位的硬要求(黑龙江本地)
- **公安**:多数岗位要求"公安专业"+ 通过公安联考。**黑龙江孩子主要走中国刑警学院(沈阳)+ 中国人民公安大学(北京)+ 中国人民武装警察部队学院(廊坊)**
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)。**黑龙江省本地法检系统校招主力 = 黑大法学 + 出省政法 211**(中南财法 / 西南政法 / 华东政法 / 中政法)
- **监狱、戒毒**:法学 + 监狱学,**黑龙江本省没有强势监狱学校,走出省中央司法警官学院(河北保定) / 中国人民公安大学**

## 黑龙江本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业
- **哈尔滨工业大学(本部 / 威海 / 深圳)文学 / 法学 / 公管** — 985 + C9 + 国防七子,**选调生认可度顶**,毕业进省委办 / 各部委后备干部
- **哈尔滨工程大学 法学 / 公管 / 经管** — 211 + 国防七子,**选调生认可度等同 985**,**国防系统 + 公检法 双向友好**
- **东北师范大学(吉林 / 出省)汉语言 / 法学** — 985 师范第一档,**公费师范 = 教师编制**,**也认黑龙江选调**
- **中南财经政法大学 法学 / 经济学 / 会计学**(出省武汉)— 211 + 双一流,**全国法检系统 / 财税系统 校招大户**

### 双非 + 性价比考公专业(黑龙江本省)
- **黑龙江大学汉语言文学 / 法学 / 哲学 / 俄语** — **留黑党政 / 选调 No.1 双非校**,**省委 / 省政府 / 省纪委 / 省检察院 / 省高院 / 省外事办 校招主力** ★
- **哈尔滨师范大学汉语言文学(公费师范生)** — **教师编制(等同考公友好)**,黑龙江县中 / 城市初中校招主力
- **东北财经大学(辽宁,出省)** — 双非但财经全国前 5,**财税系统 + 海关 + 国税地税 校招大户**

### 公安系统专属
- **中国刑警学院(沈阳)** — **东北唯一公安部直属院校**,本科,公安联考路径,**毕业进黑龙江 / 辽宁 / 吉林 公安系统概率极高**
- **中国人民公安大学(北京)** — 公安系统第一校,**进部级 / 省级公安岗**
- 出省**中央司法警官学院 / 中国人民武装警察部队学院** — 司法 / 边防 系统对口

### 黑龙江独家:对俄外事岗 / 边境口岸岗
- **黑龙江大学俄语**(全国第 1)— **黑河海关 / 绥芬河海关 / 同江口岸 / 抚远口岸 / 黑龙江省外事办** 校招主力,**这是黑龙江本省独家的"地理红利岗"**
- **解放军外国语学院 / 北外俄语**(出省)— 进外交部 / 外文局 / 中央外宣

## 典型 case(黑龙江本地)

- **Case A(逆袭路径)**:**鸡西矿工家庭考生**,540 分文史类(老高考),**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报黑龙江大学汉语言文学**,毕业当年考上**黑龙江省直某机关公务员**,**家庭命运改变**
- **Case B(选调路径)**:**哈尔滨城市中产家庭考生**,650 分文史类。家长想报"金融"(出省东财)。**改报哈工大本部文学 + 法学双修**,**毕业获得哈工大选调生资格,直接进黑龙江省委组织部**,起点远超经济学就业
- **Case C(失败路径)**:**佳木斯考生**,580 分理科,普通家庭男生。家长想"考公兜底"。**报了哈尔滨理工大学计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:**伊春家长以为"行政管理"是考公专业** — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**。最后家长改让孩子报黑大行政管理,**毕业考公成功率比汉语言低 30%**
- **Case E(独家路径)**:**绥芬河中俄边贸家庭考生**(550 分历史类)→ **黑大俄语** → 毕业考**绥芬河海关编制**(俄语 + 边境地理优势 + 黑龙江户籍三重红利)→ **家门口工作 + 编制 + 涉外津贴 + 父母资源继续做边贸副业**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(黑龙江 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是黑龙江家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**留东北考公没出息,应该出省考北上深**" — 错。**北上深公考竞争极卷 + 户口门槛高 + 生活成本高**,黑龙江本地公考竞争比反而更友好(本省高校少 + 留黑率低 → 同档岗位本省竞争少 30-50%);**留省考公 + 父母资源 = 黑龙江普通家庭最稳路径**
- "**对俄外事岗工资低,不如哈尔滨市直**" — 半对。**黑河 / 绥芬河 海关编制工资 + 涉外津贴 + 边境补贴 + 出差补助 = 实际收入不输哈尔滨市直**,且**地理红利可叠加副业(对俄边贸)**

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是黑龙江家长被严重低估的考公王者**。

**黑龙江独家提醒**:
1. **黑大文科 = 留省考公 / 选调 No.1 双非校**,**家长不能只盯 211/985**,黑大文科考公认可度 >> 同分双非综合大学
2. **对俄外事岗 / 边境口岸海关 = 黑龙江独家地理红利岗**,**学俄语 + 黑龙江户籍 = 双重加分**,普通家庭 + 留省最稳的隐藏路径
3. **东北高校选调生认可面广**:除哈工大 / 哈工程 / 黑大,**东师 / 东财(出省东北兄弟校)也认黑龙江选调**,这是东北三省的"共享红利"

## 黑龙江公考路径选择(给 agent 的判断框架)

### 路径 A:留黑龙江(适合 70%+ 黑龙江普通家庭)
- 黑龙江省考(笔试 → 面试 → 体检 → 入职)
- 选调生(985/211 + 部分双非如黑大)
- 哈尔滨市考(竞争略高于省考其他地市)
- 黑龙江政法系统(法检院 / 司法局)
- 哈尔滨 + 各地市事业编

### 路径 B:京津沿海考公(适合家庭条件好 + 想出东北的)
- 北京国考岗(竞争极卷,1000+ 比 1)
- 上海 / 江苏 / 浙江 / 广东 公务员(户籍门槛 + 竞争激烈)
- 沿海央企 / 国企(中石油 / 中石化 / 国家电网)— 走"工科生考公"路径(不是行政岗)

### 路径 C:对俄外事岗(黑龙江独家)
- 黑河 / 绥芬河 / 同江 / 抚远 海关编制
- 黑龙江省外事办 / 各市外事办
- 中俄边境贸易公司编制岗 + 涉外津贴

### 路径 D:农村定向 / 公费师范(普通家庭兜底路径)
- 国家专项计划(985/211 名校,分数比统招低 20-30 分)
- 哈师大公费师范 / 东师公费师范(教师编)
- 公费医学定向 / 涉农定向(回县级医院 / 县农业局编制 + 服务期)

### Agent 输出建议
当家长说"想让孩子考公"时,**追问 3 个问题**:
1. **想留东北还是出东北?** — 决定路径 A vs B
2. **接受不接受农村 / 县级岗位?** — 决定路径 D 是否可选
3. **孩子有特殊技能(俄语 / 法学 / 公安专业)吗?** — 决定路径 C / 公安联考 是否可选

不追问,直接推"汉语言文学 + 黑大",可能错过更适合的路径(尤其是 D 农村定向 / C 对俄独家)。
