# 用户意向冲突 — Reality Check 金句库(黑龙江版)

很多家长 / 考生有具体的意向("想上哈工大"、"非北京不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **黑龙江版加分项**:**留东北 vs 出东北 是黑龙江版意向冲突里的隐藏第 5 类**(湖北 / 江苏 没这么强烈)

---

## 5 类意向冲突 + 金句模板(前 4 类全国通用,第 5 类黑龙江独家)

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 530 分要哈工大本部 / 580 分要北医协和)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(黑龙江 580 分,意向哈工大本部)**:
> "哈工大本部主流组在黑龙江物理类 1,500-3,500 名。你 7,800 名,差 4,000+ 名,**哈工大本部主流组没戏**。
>
> 但你能上**哈工大威海(2,500-5,500)/ 哈工程王牌组(2,500-5,500)/ 哈理工电气**(双非但黑龙江电力 + 哈电对口)— 这三所留黑就业,**哈电集团 / 黑龙江省网 / 中船重工 招聘里跟哈工大本部冷门组校友地位差不多**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(黑龙江理工科 + 普通家庭擦哈工大本部冷门组)**:
> "哈工大本部你 4,500 名能擦 — 但只能进材料 / 环境 / 部分理学基础。**985 + C9 牌子 + 黑龙江冷 + 生化环材** = 三重坑(虽然哈工大本部材料 A+ 但本科直接就业惨,起薪和哈理工电气差不多还要熬考研)。
>
> 同分能上的**哈工程船舶 / 核工程王牌组**(双一流学科 + 中船重工 / 中核 校招)出来对口程度更高,**起薪 12-22w + 编制 + 国家队待遇**。冲哈工大本部留一个心理慰藉位即可。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华临床 / 北医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(黑龙江普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k,黑龙江本省更低**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**哈医大临床 5+3 一体化**(逼近哈工程王牌录取线,8 年出来硕士,留附属医院),或冲北医协和八年制。
>
> 撑不起 → **建议哈医大麻醉学**(全国前 5 + 双非分数 + 起薪 15-25w + 编制 + 比临床早 3 年挣钱),或**哈医大医学影像技术 4 年本科**(三甲医院技术岗 + 起薪 6-9w + 编制),或者直接放弃医学走**哈理工电气 + 哈电集团** 这种本科直接挣钱的赛道。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非北京不去" / "非哈尔滨不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留北京没意义,要去西工大),**要灵活退一步**。"

**真实案例(黑龙江 + 想留哈尔滨 + 590 分物理类)**:
> "你只留哈尔滨,这位次 6,500 名,哈工大本部主流组够擦,哈工程王牌组够稳。
>
> **留哈最稳路径**:**哈工程船舶 / 核工程王牌组(2,500-5,500 名内可冲)+ 留校 / 中船重工 711 所(上海分院在哈尔滨设点)**。
>
> 不要为了'外省 985 牌子'去兰大 / 中山大学冷门组 — 牌子有了但**人脉断了 / 春节回家成本高 / 毕业回哈尔滨没竞争优势**,综合不划算。
>
> **但你要清楚一件事**:**哈工程毕业进中船 711 所(上海) → 中船在上海 + 武汉 + 青岛 + 大连 都有院所,'留哈'的概率是 30%,'分配上海/武汉'的概率 40%**。'留哈'是相对的,真正一辈子留哈的本科同学只有 1/3。"

---

### 模式 E(黑龙江独家):"留东北 vs 出东北" 这道每个家庭都要直面的题

**特征**:黑龙江本省考生家长的隐藏冲突 — **父母想孩子留东北 / 留哈尔滨**(因为人口外流严重 + 父母怕失去陪伴),**但孩子分够 985 / 想去南方 / 想去一线城市**(因为本省经济下行 + 同学都南下)。

**这道题在湖北 / 江苏 没这么强烈,但在黑龙江几乎每个 600 分以上家庭都要直面**。

**金句模板**:
> "你妈妈说'孩子能不能就近上学,留哈尔滨/留东北最好' — 这是黑龙江家长的普遍诉求。
>
> 但你必须告诉她一件事:**黑龙江每年大学毕业生留省率不到 30%**,**这意味着你这一代的'同学/朋友圈/对象资源' 70%+ 都不在黑龙江**。
>
> - **留东北读大学(哈工大 / 哈工程 / 黑大)** → 毕业 70% 还是去了北上深 → 父母只是'晚 4 年面对孩子离巢'
> - **直接出东北读大学(出省 985 / 哈工大深圳)** → 提前 4 年适应 + 落户当地 + 毕业不用'回不去'
>
> 这道题没标准答案,但**家长要清楚:'让孩子留省读大学' 不等于 '让孩子留东北一辈子'**。
>
> 我建议:
> - 分够哈工大本部 / 哈工程 王牌组 + 想做工科 / 国防 / 医学 → **留哈尔滨读大学,毕业再做留 vs 出的决定**
> - 分够 985 但本省没强势学科(如学金融 / 互联网 / 文创)→ **直接出东北,别耗 4 年再走**
> - 分双非 + 想考公 + 父母想陪伴 → **黑大 / 哈师大 + 留省考公** 是真正的"留东北"路径"

**真实案例(黑龙江 + 哈尔滨城市中产 + 父母想陪伴)**:
> "你 620 分物理类,本来够哈工大本部主流组 + 想做 CS。
>
> **父母希望留哈** vs **CS 出口在深圳/京津**,这是死结。
>
> 三条路:
> 1. 哈工大本部 + 计算机 → 大概率毕业去深圳 / 北京 / 杭州,**4 年后离巢,父母要做心理建设**
> 2. **哈工大深圳校区 + 计算机** → **大学就在深圳,父母提前 4 年适应**,深圳就业 + 户口加成 → **跨阶级 + 父母接受度 比'毕业才南下'更高**(因为有 4 年缓冲期)
> 3. 哈工大本部 + 航天 / 机械 / 控制 → **走国防系统 = 留哈尔滨概率最高**(哈工大本部国防系统毕业 25-30% 留黑,**这是真正想留东北的路径**)
>
> **结论**:想留哈尔滨 + 学 CS = 内在冲突,改学航天/机械/控制 才是真正的'留东北';想学 CS 就接受出东北。"

## Agent 处理意向的 5 步(黑龙江版)

收到 L4.5 意向锚点后,**强制做这 5 步**(比通用版多 1 步):

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向
5. **黑龙江独家:摆"留东北 vs 出东北"题** — 当家长 + 孩子在这道题上有分歧时,**必须把它摆到台面上谈**(不要假设默认值)

**禁止的反面行为**(实测踩过的坑):
- 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- **黑龙江独家**:**默认"留东北最好"** — 这是家长视角,不是孩子视角,**Agent 必须把两个视角都摆出来**

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

**黑龙江独家:留省 vs 出省 双轨**

对黑龙江普通家庭 + 边缘可达 985 的考生,**额外输出"留省 vs 出省"双轨**:
- **轨道 A(留省)**:哈工大本部 + 工科 / 哈工程 / 黑大文科 / 哈医大医学
- **轨道 B(出省)**:哈工大深圳 / 出省 985 / 出省公费师范 / 出省政法

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 哈工大本部 / 想学医 / 想留哈尔滨 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]

[ 黑龙江独家:留东北 vs 出东北 的态度,1-2 句话 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则(黑龙江版)

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**黑龙江独家加一句**:**"留东北" 这个意向不仅是孩子的,更是父母的** — Agent 不能假装看不见,必须把这道题在每个 600 分以上家庭面前摆开谈。
