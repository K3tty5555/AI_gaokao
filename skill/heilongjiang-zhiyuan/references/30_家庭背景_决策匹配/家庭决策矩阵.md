# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(黑龙江版)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**黑龙江特殊放大**:**本省经济长期下行 + 人口外流(连续 10+ 年净流出全国第一)+ 民营经济极弱 + 体制内偏好极强 → 比湖北 / 江苏更倾向"编制" / "出省留京津沿海"两条路**。**家庭档位决定的不只是"选什么专业",还包括"留省 vs 出省"这道前置选择题**。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**(黑龙江本地):
- 抗风险能力中等(收入稳但天花板低,黑龙江体制内工资比湖北 / 江苏 同档低 20-30%)
- **懂体制游戏规则**(黑龙江省委选调 / 省考 / 哈尔滨市考 流程清晰)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易,**尤其知道留黑龙江本省体制的潜规则**(选调认黑大 / 哈工大文科;省纪委 / 法检系统 认中南财法 / 黑大法学)

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化)。**黑龙江选调主要供给:哈工大 + 哈工程 + 黑大 + 东师(吉林) + 东财(辽宁)**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校 / 公安专业(中国刑警学院在沈阳,黑龙江孩子优先考虑)+ 公安联考 = 父母编制资源能用上

**典型 case**(黑龙江):
- **哈尔滨某体制内家庭(父亲哈尔滨市直机关,母亲龙江银行)** → 孩子 605 分历史类 → 推**黑大法学**(双非但留省考公 / 选调主力)→ 毕业选调进黑龙江省纪委 → **家庭路径完美匹配 + 留省 + 编制**
- 失败 case:同样家庭,孩子被推去哈工大本部 CS → 毕业被字节深圳挖走拿 35w → 父母两年后还是劝其离职考公,**不仅时间损耗 + 心理纠结,还面临"出去了的人难再考公"的现实**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**(黑龙江本地):
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:**黑龙江本省教师群体 + 哈医大附属医院系统 + 哈电研究院** 这三个圈子里,父母资源能直接给孩子打通实习 / 推荐 / 留校规培

**推荐策略**:
1. **优先子承父业**:
   - 教师家庭 → **哈师大公费师范汉语言 / 数学** / **东师公费师范**(出省)
   - 医生家庭 → **哈医大临床 5+3 一体化 / 哈医大口腔 5+3 / 哈医大麻醉学**(父母医生圈子能撑 8 年长周期 + 三甲医院推荐)
2. **行业相关延伸**:律师家庭 → 黑大法学 / 中南财法(出省);工程师家庭 → 对应工科(哈工大 / 哈工程 / 哈理工)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难;**黑龙江本省金融业极弱,除非父母是金融出身,否则学金融等于双非毕业即转行**)

**典型 case**(黑龙江):
- **哈尔滨某哈医大附属一院主治医师家庭** → 孩子 640 分物理类 → **哈医大临床 5+3 一体化**(本硕一体化 + 父母资源直接打通规培 + 留附属一院)→ 30 岁独立行医 → **典型子承父业路径**
- **齐齐哈尔某重点中学语文老师家庭** → 孩子 600 分历史类 → **哈师大公费师范汉语言** → 毕业回原学校 / 同区编制 + 母亲资源直接复用 → **零经济压力 + 母亲圈子复用**
- **大庆油田工程师家庭** → 孩子 620 分物理类 → **哈工程电气工程**(船舶 + 油田电气方向)→ 毕业进大庆油田电气院 / 中石油俄罗斯项目部 → **父亲油田圈子全开**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**(黑龙江本地):
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **黑龙江特殊性**:本省民营经济弱 → 私企家庭比例远低于江苏 / 浙江 / 广东。**典型黑龙江私企家庭**:**哈尔滨/大庆/绥芬河 中俄边贸商人 + 房地产 / 矿产小老板 + 餐饮酒店连锁 + 农产品深加工**(数量少但存在)

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
   - **黑龙江特色**:**做中俄边贸 → 黑大俄语 / 哈工大经管 + 俄语辅修 = 接班最优** ★
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(**黑龙江孩子去俄罗斯远东联邦大学 / 圣彼得堡大学 留学路径** = 中俄边贸家庭独家红利,学费比英美低 + 距离近)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**(黑龙江):
- **绥芬河中俄边贸商人家庭(年入 200w+)** → 孩子 570 分历史类 → 推**黑大俄语 + 国际经济与贸易双辅修** → 毕业接班对俄边贸 / 派驻海参崴分公司 → **典型继承家业路径,黑龙江独家**
- **哈尔滨房地产小老板家庭** → 孩子 580 分物理类 → 推**香港城市大学 / 中外合作办学**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班
- 失败 case:大庆油田周边私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(**黑龙江工薪家庭比湖北 / 江苏低 30-40%,这是基本事实**)。

**家庭画像**(黑龙江本地):
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾 / **留东北最好**
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **黑龙江特殊画像**:**国企工人家庭**(哈电 / 哈飞 / 哈尔滨锅炉厂 / 一重 / 大庆油田等)+ **资源型城市衰退家庭**(鸡西 / 鹤岗 / 七台河 / 双鸭山 / 伊春 等"四煤一林"工人下岗潮后代)+ **农村脱贫家庭**(哈尔滨郊区 / 齐齐哈尔郊区 / 佳木斯郊区)

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - 公费师范生(哈师大 / 东师 出省)= 高考分适中 + 直接编制 + 无学费
   - 中国刑警学院(沈阳)+ 公安联考 = 进警察系统编制
   - **哈医大医学影像 / 检验 / 护理 = 三甲医院技术岗 + 4 年本科即可**
   - 殡葬专业 = 100% 编制 + 收入意外不错(全国 4 所之一,哈尔滨没有,但黑龙江孩子可以报长沙民政 / 北京社管)
3. **次推稳定就业型**:
   - **哈理工电气进黑龙江省网 / 哈电集团**(类似湖北"三峡大学"角色)★
   - 哈工程 王牌组进中船 / 中核 / 中广核(普通家庭男生跨阶级路径顶配)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局,黑龙江本省金融业极弱)
   - **双非 CS**(2024 起薪 8-9k,跟双非工科没差;**且黑龙江本省没大厂 → 双非 CS 留省直接死路**)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)— **改推哈医大医学影像 / 麻醉**
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**(黑龙江):
- **伊春工厂家庭男生**(580 分物理类,2024)→ 推**哈尔滨理工大学电气**(2024 进国家电网黑龙江分公司主供给校之一)→ 毕业进黑龙江省网 → **月入 8-10k + 编制,家庭逆袭** ★
- **鸡西矿工家庭女生**(540 分文史类,老高考)→ 推**黑大汉语言文学**(双非但考公王者)→ 毕业当年考上黑龙江省直机关 → **家庭命运改变**
- **七台河下岗工人家庭男生**(620 分物理类,2024)→ 推**哈工程船舶与海洋工程王牌组** → 毕业进中船 711 所(上海)起薪 12-18w + 编制 → **跨阶级 + 出东北**
- **齐齐哈尔工人家庭独子**(595 分物理类)→ 推**哈医大医学影像技术** → 毕业进齐齐哈尔市第一医院技术岗 6-8k + 编制 → **留齐齐哈尔陪父母 + 编制**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万(**黑龙江农村家庭比湖北 / 江苏更穷,这是基本事实**)。

**家庭画像**(黑龙江本地):
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **黑龙江特殊画像**:**北大荒农场家庭 + 黑河 / 双鸭山 / 鸡西 / 鹤岗 农村家庭 + 三江平原种植户**(玉米 / 大豆主产区)

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生 哈师大 / 东师**(无学费 + 编制)= 农村家庭神器
   - **国家专项计划 / 高校专项 = 农村专属优惠**(黑龙江农村户籍,985/211 名校多个专项指标,分数比统招低 20-30 分)★
   - **农村专项 + 哈工大本部 / 哈工程 王牌组** = 黑龙江农村孩子跨阶级的最稳路径
   - 警校 / 军校(无学费 + 编制 + 包分配)
   - **东农 / 东林 农林牧水** = 编制 + 北大荒粮食集团 / 黑龙江垦区 编制对口
3. **避免长周期投入**:
   - 医学 8 年(撑不起)— **改推哈医大医学影像 4 年制**
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划:黑龙江农村户籍,哈工大 / 哈工程 / 东农 / 东林 / 哈医大 都有专项指标**(分数比统招低 20-30 分)★
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会(哈工大本部强基)
   - **殡葬专业(冷门但 100% 编制 + 收入不错)** — 全国 4 所(长沙民政 / 福建华南女子 / 武汉民政 / 北京社管)
   - **东农公费农科生 / 涉农定向** = 北大荒粮食集团 / 黑龙江省农业农村厅 编制对口

**典型 case**(黑龙江):
- **黑河农村家庭(中俄边境)** → 孩子 590 分物理类 → 通过**国家专项**进**哈工大本部环境工程**(比统招低 30 分)→ 985 牌子 + 国家专项编制路径,**整个村第一个 985**
- **双鸭山农村女孩**(605 分历史类)→ 推**哈师大公费师范汉语言** → 4 年无学费 + 毕业回双鸭山某县中编制,**最适合农村家庭的"零风险"路径**
- **嫩江北大荒农场家庭**(560 分物理类)→ **东农公费农科生** → 毕业进北大荒粮食集团编制 → **延续农场基因 + 编制 + 留黑**(普通农村家庭跨阶级的现实路径)
- **三江平原种粮户家庭**(580 分物理类)→ 推**东农农学(寒地作物方向)** → 毕业进黑龙江省农科院 / 各市县农业局 → **编制 + 工资 6-8k + 家门口工作**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 黑龙江特殊提醒:留省 vs 出省 是档位 ④⑤ 必答的隐藏题

**黑龙江家庭档位 ④⑤ 在选专业前还要先回答一道隐藏题:留东北 vs 出东北**:

- **留东北 + 工薪 / 农村家庭** → 哈理工电气 / 哈医大医学技术 / 哈师大公费师范 / 黑大文科考公 / 东农涉农定向 / 哈电集团编制路径
- **出东北 + 工薪 / 农村家庭** → 哈工大本部 / 哈工程王牌组 / 哈工大深圳校区 / 出省 985 国家专项 / 出省公费师范

**这两条路对父母心理建设要求不同**:
- 留东北 → 父母最舒服(陪伴 + 信息差小 + 落户简单),但工资天花板低 + 经济上行空间有限
- 出东北 → 工资 + 上升空间更大,但父母接受度低 + 春节回家成本高 + 长期独居北上深心理压力

**Agent 在跟黑龙江普通家庭对话时,必须把这道题摆在台面上谈,而不是默认"留省最优"或"出省最优"**。
