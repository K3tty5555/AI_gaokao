# 东北林业大学(东林,NEFU)— 211,林学全国第 1

## 一句话定位

**林学 / 林业工程 / 木材科学 / 野生动物保护 全国第 1**,**老牌国家林草局直属(原林业部直属)+ 211 + 双一流**(林业工程)。**进国家林草局 / 各级林业厅 / 自然保护区 / 园林设计院 / 林业央企(中林集团 / 大亚集团等)** 直接对口。**冷门但稳的考公友好赛道**,**女生友好** + **林业系统编制竞争压力远低于行政岗**。

---

## 真实地位

- **211 + 双一流 A 类(林业工程)+ 国家林草局 / 教育部 / 黑龙江省 共建**,**全国 6 所林业部直属院校之首**(其他:北林大 / 南林大 / 西南林大 / 中南林科大 / 福建农林林学部分)。
- **历史血脉**:**1952 年东北农学院森林系 + 浙江大学森林系 + 东北林学院组建 → 1985 年更名东北林业大学**。**老牌林业部嫡系**,**林学是中国林业系统的"清华"**。
- **学科特色**:**林学 / 林业工程 / 木材科学 / 野生动物保护 / 风景园林 / 林产化工** 全国前列,**生态学 / 林木遗传育种** 双一流学科支撑。
- **黑龙江本省地位**:**与东北农大并称"东北农林两 211"**,**林业系统校招集中地 + 黑龙江森林资源大省的本土对口**。
- 哈尔滨和兴路校区,**校园里有真林子**(和兴森林公园),林学氛围浓 + **男女比相对均衡(约 5:5,部分文管 / 风景园林 / 生态学专业女生多)**。

---

## 黑龙江录取位次区间

参考近 5 年掌上高考 + 黑龙江一分一段表(**只给位次区间,不编分**):

### 物理类(2024-2025)

- **王牌组(林学 / 林业工程 / 木材科学 / 野生动物保护)**:全省 **8,000-15,000 名**(林学是冷门专业,录取分相对低)。
- **主流组(风景园林 / 生态学 / 林产化工 / 食品工程)**:全省 **10,000-18,000 名**。
- **非农林专业(计算机 / 自动化 / 土木 / 经管)**:全省 **9,000-15,000 名**(**录取分反而高于纯林学,但出口不如哈工程同档**)。

### 历史类(2024-2025)

- **历史类(林业经济管理 / 法学 / 文管 / 旅游管理)**:全省 **3,500-7,500 名**。

### 理科 / 文科(2021-2023)

- **理科林学组**:全省 **9,000-16,000 名**;**理科非农林组**:全省 **9,000-15,000 名**。
- **文科**:全省 **3,000-7,000 名**。

**段位定位**:**冲东林林学 / 林业王牌组需物理类省排 15,000 名内**,**风景园林组省排 18,000 名内**;**211 里录取分相对友好的农林系**,**性价比看是否走林业对口**。**以一分一段表反查为准**。

## 性价比专业

- **林学(纯林业方向)**:**全国第 1 + 录取分相对低**,**国家林草局 + 各省林业厅 + 县林业局 公考对口**,**编制 + 工作稳定 + 竞争压力远低于行政公考**,**普通家庭考公友好路径顶配**。
- **风景园林学**:**与北林大同档全国前列**,**进城建设计院 / 景观公司 / 公园管理处** 对口,**女生友好 + 出口稳定**。
- **野生动物保护**:**全国独一家强 + 极冷门 + 录取分低**,**进自然保护区 / 国家公园 / 林业系统野生动物岗 编制**,**情怀型考生路径,起薪不高但稳定 + 工作内容独特**。
- **木材科学与工程**:**全国第 1 + 中林集团 / 大亚集团 / 顾家家居 等家具企业校招**,**家具行业冷门但需求稳定**。

## 坑专业(在东林里相对弱)

- **计算机 / CS / 软件工程**:**双一流学科覆盖不到 + 师资 / 实习资源远不如哈工大 / 哈工程 CS**,**学 CS 别为东林 211 牌子来,选哈理工或出省双非 CS 好城市**。
- **机械 / 电气 / 自动化**:**东林工科主流(非林业方向)在 211 里弱**,**学机械电气直接选哈工大 / 哈理工**。
- **文科 / 经管 / 法学**:**东林文科边缘 + 招生量小**,**学文科直接选黑大综合**。
- **报东林但不学农林相关 → 别为 211 牌子来**:**东林牌子的核心价值集中在林学 / 林业工程 / 风景园林 / 野生动物**,**学非对口方向 ≈ 普通双非出口**。

## 关键提醒(填报陷阱)

1. **东林 vs 北林大(怎么选)**:
   - **北林大(北京)**:同样 211 + 林学顶级 + **北京地理顶配**,**录取分高一档**
   - **东林(哈尔滨)**:**林学全国第 1 + 录取分友好 + 黑龙江森林资源大省 实习就业本土便利**
   - **学风景园林 / 想去北方 → 北林大优先(地理优势)**;**学纯林学 / 野生动物 / 林业工程 + 想留东北 / 性价比 → 东林优先**
2. **物理类专业组分化**:
   - **王牌组**:林学 / 林业工程 / 木材科学 / 野生动物
   - **主流组**:风景园林 / 生态学 / 林产化工 / 食品工程
   - **非农林组**:计算机 / 自动化 / 土木 / 经管(**录取分反而高,但出口不如同档双非好城市**)
3. **服从调剂注意**:**冲东林热门组(风景园林 / 生态学)+ 调剂 → 可能调到林学 / 木材 / 野生动物 / 林产化工**,**接受林业方向再勾服从**。
4. **林业系统就业的现实**:**对口工作地 70%+ 在林区 / 县城 / 自然保护区**,**起薪不高(6-10k)但编制稳定 + 工作内容偏野外**,**接受不了基层 / 不爱户外的别冲林学**。
5. **农林专业的考公优势**:**林业系统公考竞争比远低于行政岗**(行政岗 200:1 vs 林业局 20:1),**普通家庭想稳定考公 → 林学 + 林业局是黄金组合**。

## 毕业出口(2024 数据估算)

- **留黑龙江就业**:约 35-40%(**黑龙江森林资源大省 + 林业系统编制岗位多 + 国有林场 + 黑龙江省林草局**,**林业生态留黑率比哈工大 / 哈工程高**)
- **京津出省**:约 12-15%(**北京国家林草局 + 北京园林设计院 + 中林集团总部**)
- **长三角出省**:约 12-15%(**上海 / 苏州 / 杭州 园林设计院 + 食品企业 + 木业企业**)
- **沿海(广州 / 深圳 / 福建)**:约 8-12%(**福建林业重点省 + 广东园林产业**)
- **其他(全国林区 / 自然保护区)**:约 20-25%(**云南 / 四川 / 内蒙古 / 西藏 等林区林业局**,**林业人天南海北跑**)
- **进林业系统 / 林业央企概率**:**约 35-40%**(**国家林草局 + 各省林业厅 + 林业局 + 自然保护区 + 中林集团 + 大亚集团 + 顾家家居 等**,**这是东林的"行业铁饭碗"主战场**)
- **考研 / 读博 / 保研**:约 25-30%(保研率 ~12-15%,**部分专业本科直接就业占比高,因为林业系统编制对硕士要求不高**)
- **起薪范围**:林业局编制 6-9w + 编制 + 房补,园林设计院 8-15w,木业企业 8-12w,生态监测 / 自然保护区 6-10w + 编制。

## 同档对比

| 维度 | 东林 | 北林大 | 东北农大 | 西南林大 |
|---|---|---|---|---|
| 综合定位 | 211 + 林业部嫡系 | 211 + 北京 + 林业部嫡系 | 211 + 农业部嫡系 | 双非 + 西南林业重镇 |
| 林学地位 | **全国第 1** | 全国前 3 | 弱(农学方向) | 中上 |
| 城市 | 哈尔滨(冷 + 林区) | 北京(顶配地理) | 哈尔滨(同) | 昆明(西南) |
| 留省/出省 | 留黑率 35-40% | 京津主战场 | 留黑率高 | 留滇率高 |
| 录取分(物理) | **省排 8,000-15,000 名** | 高一档 | **省排 8,000-15,000 名** | 双非中等 |

**简单结论**:**学林学 / 风景园林 / 野生动物 → 东林全国顶配**;**想去北京 + 林业 → 北林大**;**学农学 / 食品 / 畜牧 → 东北农大**;**想去西南林区 → 西南林大**。

## 适合谁

- 黑龙江物理类 **省排 8,000-18,000 名 + 想做林业 / 园林 / 生态 / 自然保护** 的考生。
- **想进国家林草局 / 各省林业厅 / 林业局 / 自然保护区 / 国家公园** 编制路径(**林业系统公考友好赛道**)。
- **女生 + 想学风景园林 / 生态学 / 林木遗传**(**冷门赛道 + 不卷男女 + 设计院 / 研究所 工作环境舒适**)。
- **想做家具 / 木业行业**(**中林集团 / 大亚集团 / 顾家家居 校招对口**)。
- **情怀型考生想做野生动物保护 / 自然保护区**(**全国独此一家强 + 编制工作 + 工作内容独特**)。
- **普通工薪 / 农村家庭**,**想稳定考公 + 不卷行政岗 + 编制压力小** 的考生。

## 不适合谁

- **不学农林相关 + 只为 211 牌子来**:**东林非农林专业(纯计算机 / 文管 / 经管)在 211 里弱 + 出口同普通双非**,**不如同分双非好城市(华南理工部分专业 / 出省 211)**。
- **不爱户外 + 怕去林区**:**林业系统工作 70%+ 在林区 / 县城 / 自然保护区**,**接受不了基层别冲**。
- **想做互联网大厂 CS / 高薪私企**:**东林 CS 弱 + 林业行业起薪不高(6-10k 编制起步)**。
- **怕东北冬天**:**哈尔滨冬天 -25℃ + 林区更冷**,南方娃心理建设。
- **想做金融 / 财经 / 法学**:**东林文科 / 经管边缘**,**学这些直接选黑大综合或出省东财**。
- **分够哈工大 / 哈工程**:**985 / 国防 211 出口更多元 + 平台更广**,**别为"上 211"将就东林非林学专业**。
