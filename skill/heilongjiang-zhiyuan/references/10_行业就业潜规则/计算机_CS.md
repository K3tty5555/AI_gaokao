# 计算机科学与技术 / 软件工程(CS / SE)— 黑龙江视角

## 一句话总结

**CS 已经过了"闭眼报"的黄金时代**。在黑龙江这个**没有互联网原生大厂、整个省 IT 就业全靠出省**的省份,**学校层次决定一切**比湖北 / 江苏 / 广东更残酷 — 你要么进哈工大 / 哈工程那一档(校招大厂直接来哈尔滨开宣讲),要么直接放弃在本省做 CS 的幻想。**普通家庭男生学 CS 想跨阶级 → 必须冲到哈工大本部 / 哈工大深圳 / 哈工程王牌组,否则改电气 / 船舶 / 国防方向更稳**。

---

## 真相 1:寒冬是阶段性的,但分化是结构性的(全国通用)

- 2022-2024 互联网大厂裁员潮(腾讯 / 阿里 / 美团 / 字节 大规模优化),**应届生 offer 数量比 2020 年峰值少了至少 30%**
- 头部学校 CS 学生仍然有 35w+ 起薪,但中下层学校学生从 15w 跌到 8-10w,**两极分化加剧**
- 行业总需求依然在(AI / 芯片 / 云计算),但门槛被抬高了 — 没 985 学历或硬核项目经验,简历都进不了筛选系统

**结论**:CS 不是不能学,**学校决定一切**。

---

## 真相 2:35 岁危机集中在业务码农,核心技术岗仍是黄金期(全国通用)

- 35 岁危机集中在**业务型程序员**(增删改查、CRUD、调用别人轮子的那类)
- **核心技术岗(底层 / 算法 / 架构 / 芯片)的 35 岁不是危机是黄金期**,薪资还在涨
- 区别:你是"会写代码的人"还是"懂技术的人"

**结论**:目标核心技术岗,本科就要练算法 / 底层 / 数学,**双非很难做到**。

---

## 真相 3:本科 < 硕士的差距越来越明显(全国通用)

- 5 年前 985 本科 CS 直接拿 SP offer
- 现在 985 本科起薪可能跟 211 硕士差不多甚至略低
- 大厂校招在向"硕士起步"倾斜,本科想拿好 offer 必须**实习 + ACM + 项目** 三件套都拿到顶
- **如果你打算学 CS 但学校只是普通 985/211,本科就必须做好读研的准备**

---

## 真相 4:转码内卷已经到顶(全国通用)

- 2018-2022 年大量文科生 / 其他工科生通过培训班转码成功,**这个窗口已经关闭**
- 现在企业对"科班 CS"偏好极强,**非科班想转码越来越难**
- 想吃 CS 红利,本科就该选 CS,中途想转的窗口已经很窄

---

## 黑龙江本地 CS 就业的特殊残酷性

### 残酷事实 1:黑龙江本省没有互联网原生大厂

- **哈尔滨没有华为 / 腾讯 / 阿里 / 字节 / 美团 / 百度 的研发中心**(顶多有销售办事处或区域客服中心)
- 全省最像"互联网"的本地企业是**哈尔滨电气集团 IT 部 / 中国一重 IT 部 / 大庆油田信息中心 / 龙江银行科技 / 黑龙江电信 IT 部** — 都是国企信息化岗,**不是互联网研发**,薪资跟一线大厂差 2-3 倍
- 想做真正的 CS 研发 / 算法 / 大模型 / 芯片 → **必须出省**(京津 / 长三角 / 深圳)
- **想留省 + 想做 CS** = 死循环 → 现实里只能进国企 IT 部或者考公的"信息岗"

### 残酷事实 2:黑龙江 → 北上深的"虹吸落差"

- 哈尔滨毕业生去北京 / 上海 / 深圳的初次就业落地比湖北 / 湖南 / 安徽 多一层心理阻力(地理远 + 气候反差大 + 同学少)
- 但因为本省 IT 没出口,**真正能做 CS 的黑龙江娃几乎全去了京津/沿海**,留省的反而是去考公或转行的
- **结果**:CS 这条赛道**从一开始就是"出省赛道"**,家长别幻想"留哈尔滨做程序员"

### 残酷事实 3:深圳校区比本部更适合做 CS

- 哈工大深圳校区 = 985 牌子 + 深圳一线地理 + 大厂直招
- **CS / 互联网就业 深圳校区 > 本部**(华为 / 腾讯 / 大疆 / 比亚迪 校招直接到深圳校区开宣讲会)
- 本部 CS 也强,但**毕业不去深圳就要北漂**,长三角招聘力度反而不如京深
- **想做 CS 互联网 + 不留东北 → 直接报哈工大深圳校区,本部留给"想做航天/机械/控制"的考生**

### 残酷事实 4:本省内的 CS 院校分层极陡

- 哈工大本部 / 哈工大深圳 / 哈工程 王牌组 = 第一档(大厂校招直接覆盖)
- 哈尔滨理工大学 / 哈尔滨工业大学(威海)CS = 第二档(进互联网中段公司,不是大厂)
- 黑龙江大学 / 哈尔滨师范大学 / 东北农大 / 东北林大 CS = 第三档(留省进国企 IT 部 / 考公信息岗,不是真做研发)
- 哈尔滨商业大学 / 黑龙江工程学院 / 哈尔滨学院 / 黑龙江科技大学 CS = 第四档(**直接避坑**)

## 适合什么人(本地化)

- **数学好**(高中数学 130+,这是硬指标)
- **抗压能力强 + 不怕加班**
- **有自学能力**(大学课程跟不上行业实际需求)
- **能上哈工大本部 / 深圳 / 哈工程王牌组**,或者愿意出省读 985/211
- **家庭中产 + 心理上能接受出东北**(因为留省做不了真 CS,父母要做心理建设)

## 不适合什么人(本地化)

- **数学差**(高中数学 110 以下慎重)
- **追求安稳 / 不想出东北 / 不想 996** → 直接改电气 / 船舶 / 汉语言考公
- **双非家庭 + 不打算考研 + 不打算出省**(这个组合学 CS 等于浪费 4 年)
- **学校层次到不了哈工大 / 哈工程 / 哈理工 + 个人没有强自学动力** → 直接换专业
- **女生中讨厌技术钻研 + 只图高薪的**(行业对女性有客观存在的隐性歧视)
- **想留哈尔滨工作 + 想拿一线大厂薪资** → 不可能,放弃幻想

## 黑龙江本地 CS 院校真实分层

### 第一档(全国可比 + 大厂直招)
- **哈工大本部 计算机 / 软件 / 人工智能** — 全国前 5,**毕业去华为 / 腾讯 / 字节 / 国防 IT 都没问题**,起薪 25-40w
- **哈工大深圳校区 计算机 / 软件** — **录取分已超本部** + **深圳大厂直招 + 户口加成**,**做 CS 互联网就该来这里**,起薪 30-50w
- **哈工程 计算机 / 软件** — 双一流学科边缘但有国防 IT 出口(中船 IT / 海军装备信息化 / 国防院所),起薪 18-30w(出省)

### 第二档(中段公司 + 国企 IT)
- **哈工大威海校区 计算机** — 985 牌子 + 山东沿海地理,**性价比之王**(比本部低 30-50 分),进互联网中段公司没问题
- **哈尔滨理工大学 计算机** — 双非里黑龙江 CS 第一档,**留省进国企 IT 部 / 出省进互联网中等公司** 都有路径
- **黑龙江大学 计算机** — 双非但综合性大学,**留省考公信息岗 / 国企 IT 部 优先** ,做研发竞争力一般

### 第三档(留省国企 IT / 考公信息岗为主)
- **东北农业大学 / 东北林业大学 CS** — 211 牌子救不了 CS,**学 CS 别为这俩 211 牌子来**,选哈理工或出省
- **哈尔滨师范大学 CS** — 师范院校学 CS 主要是教育技术方向,**不是真正 CS**
- **哈尔滨商业大学 / 黑龙江科技大学 CS** — 留省进中小公司 IT 部 / 转行,跟"互联网大厂"完全无缘

### 第四档(避坑)
- **哈尔滨学院 / 黑龙江工程学院 / 黑龙江工商学院 / 各民办独立学院 CS** — **直接避坑**。这一档学 CS 不如学护理 / 师范 / 会计等有明确出路的专业,**普通家庭孩子在这些学校学 CS 出来基本就业极差**

## 典型 case(黑龙江本地)

### Case A:哈工大深圳 CS 男生(齐齐哈尔工人家庭)
- 哈工大深圳计算机学院 → 大三实习华为深圳 → 校招拿到字节深圳 SP offer 35w 起 → 入行
- **逆袭路径**,985 名校 + 深圳地理 + 行业红利,**齐齐哈尔工厂家庭通过 CS 跨阶级 + 落户深圳的典型样本**

### Case B:哈尔滨双非 CS 男生(哈尔滨工薪家庭)
- 哈尔滨某双非一本 CS → 校招进哈尔滨某国企 IT 部 月薪 7k(无编)→ 3 年后离职去北京一家中等互联网公司,月薪 1.5w
- **没有大幅逆袭**,跟 Case A 同年龄、同性别、同专业,**纯粹学校差距,5 年差出 30 万年薪**

### Case C:大庆三本 CS 女生
- 大庆某独立学院 CS → 找不到 IT 工作 → 转行做培训机构销售
- **典型踩坑**,家长以为"学了计算机就能赚钱",**学校层次决定一切**

### Case D:哈工大本部 CS 男生(佳木斯农村家庭)
- 哈工大本部计算机学院 → 校招拿到航天科技集团 IT 岗 offer 18w + 北京户口 + 编制 → 留京
- **国防 IT 路径**(很多家长不知道哈工大 CS 不只能去互联网,**进国防 / 航天 IT 体系 也是高 ROI 路径**),起薪不如互联网但**编制 + 户口 + 工作稳定**,**农村家庭跨阶级**

### Case E(反面):伊春孩子被推哈工大威海"想做 CS 但留东北"
- 父母不让出南方 → 孩子被劝去哈工大威海 CS → 毕业发现山东沿海 IT 公司多但比深圳少 → 最后还是要北上深就业
- **想做 CS 早就该接受出东北的事实**,父母对"留北方"的执念只会让孩子绕路

## 易错认知(agent 要纠正用户的)

- "**学 CS 一定好就业**" — 错。**只有第一档学校 + 顶配组的 CS 才好就业**,其他档的 CS 出口跟双非师范差不多,且没编制
- "**留哈尔滨做程序员挺好**" — 错。**哈尔滨没真正的互联网研发岗位**,留省 = 国企 IT 部 / 考公信息岗,跟"程序员"是两个职业
- "**哈工大本部 CS > 哈工大深圳 CS**" — 错。**做 CS 互联网 → 深圳校区已经超过本部**(深圳地理 + 大厂直招),做航天/机械才选本部
- "**哈工程也是国防七子,CS 应该跟哈工大本部差不多**" — 半对。哈工程 CS 出口主要是"国防 IT + 中船 IT",**跟互联网大厂的 CS 不是同一条赛道**
- "**双非 CS 至少比双非师范好**" — 错。**双非师范有教师编 + 公费师范零学费**,双非 CS 起薪 7-9k 无编,**长期来看双非师范完胜双非 CS**
- "**女生别学 CS**" — 半对。**哈工大本部 / 深圳 CS 女生完全 OK**(行业最缺女算法工程师之一);**双非 CS 女生确实出路一般**(大厂招的少 + 国企 IT 部偏男)
