# 陕西 老高考 → 3+1+2 过渡(数据现状 + 政策对比)

## 核心结论

**陕西 2022 年加入新高考第五批,2025 年高考首届实行 3+1+2**(跟山西 / 内蒙古 / 河南 / 四川 / 云南 / 青海 / 宁夏 / 新疆 同批,**第五批是全国新高考的最后一批**)。**这意味着 2025 年是分水岭**:**2021-2024 年仍是文/理科老高考,2025 年是首届 3+1+2 物理/历史类**。**跨年比较录取数据时必须分两段看,不能直接拿 2024 文/理科分数对应 2025 物理/历史类**。

总体规则跟全国第五批新高考一致,但陕西有几个**非常重要的本地特殊性**:**国防工业重镇 + 西交大 C9 顶配 + 国防七子两所(西工大 + 西电)+ 西安是西北教育/经济中心 + 留陕率约 50% + 普通家庭男生通过国防央企跨阶级路径**。

## 关键事实

### 时间表

| 年份 | 高考类型 | 录取数据格式 |
|---|---|---|
| 2021 | 文科 / 理科(老高考) | 文/理科 + 一本/二本/专科 |
| 2022 | 文科 / 理科(老高考) | 文/理科 + 一本/二本/专科 |
| 2023 | 文科 / 理科(老高考) | 文/理科 + 一本/二本/专科 |
| 2024 | 文科 / 理科(老高考末届) | 文/理科 + 一本/二本/专科 |
| **2025** | **物理类 / 历史类(首届 3+1+2)** | 物理/历史类 + 本科批/特控线 |

**意义**:**2025 是首届新高考 + 取消一二本合并的过渡年**,新规则下的录取分数线、位次结构、专业组划分都跟老高考不同。家长拿 2024 年理科分数 / 一本线对应 2025 物理类是错的。

**陕西作为第五批最后一批,有"后发优势"** —— 第一批(沪浙)、第二批(京津鲁苏粤琼)、第三批(辽闽渝鄂湘)、第四批(黑吉甘皖赣贵)的踩坑经验都有,**陕西考生 + 家长可以直接参考前几批省份的实际录取数据规律**(比如选物理类比例上升、化学绑定加严等)。

### 考试结构(2025 起)

- **3 = 语文 + 数学 + 英语**(各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- **两类完全分开排名、分开录取**
- 陕西物理类约 65-70%,历史类约 30-35%(物理占比偏高,因为本省工科强校多 + 国防工业氛围)

### 院校专业组(2025 起)
- 不再按"学校"投档,**按"院校专业组"投档**
- 一所学校可有多个专业组
- 同一学校的不同专业组独立投档
- **服从调剂只在本专业组内调剂**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量
- **陕西本科批 96 个志愿**(2025 起,**新高考第五批主流配置**;具体以陕西省招办最新文件为准)
- **专科批 96 个**
- 每个志愿 = 1 个院校专业组
- **意义**:陕西填报"操作空间大",冲稳保梯度可以铺得开,但也意味着**填错容易、信息搜集成本高**,需要更精细的位次梯度

### 12 种选科组合
跟全国新高考统一(物 + 化生 / 物 + 化政 / 物 + 化地 / 物 + 生政 / 物 + 生地 / 物 + 政地 / 史 + 化生 / 史 + 化政 / 史 + 化地 / 史 + 生政 / 史 + 生地 / 史 + 政地)。

可报专业范围参考详见 `_shared/references/00_核心方法论/采集_rubric.md` L1 单科分数判断。

## 陕西最大特殊性(关键!!)

### 1. 陕西是**西北高考第一大省**(教育资源 + 考生体量)

陕西在西北五省里:
- **考生体量约 32w/年**(陕西 32w / 甘肃 24w / 宁夏 7w / 青海 5w / 新疆 17w),**第一**
- **985/211 数量 全国前列**(3 所 985 + 5 所 211)
- 西安在国务院定义里是**国家中心城市**(西北唯一)
- **西安高校扎堆**(64 所本科,仅次北京/武汉/上海/南京/广州 一线档)

**意义**:陕西考生**留省机会多 + 名校结构齐全**,跟河南 / 河北等高考大省的"卷出血还得出省"完全不是一个生态。

### 2. 陕西是**国防工业重镇**(航天 / 航空 / 兵器 / 核工业)

西安是中国国防工业大本营之一(跟北京 / 哈尔滨 / 沈阳 / 成都 同档):
- **西工大** = 中国航空 / 航天 / 航海 系统对口神校(运 20 / 歼 20 主力研发,**国防七子**)
- **西电** = 电子信息全国前 3,军工电子对口(**国防七子之一**)
- **航天科技集团第六研究院**(液体火箭发动机)/ **航天科技四院**(固体火箭) — 都在西安
- **西飞集团**(运 20/轰 6)/ **西飞民机** — 西安阎良
- **中船重工 705 所**(水下兵器)/ **中航工业第一飞机设计研究院** — 西安
- **中国兵器工业第 203 研究所** / 西安微电子技术研究所 — 西安

**意义**:**陕西本省考生进国防央企的路径全国前列** —— 西工大 / 西电 是国防七子里唯二在同一城市的两所,**普通家庭男生通过西工大航空 / 西电军工电子进国防央企 = 编制 + 起薪 12-20k + 终身稳定**,这是陕西最大的本地化金牌路径。

### 3. 留陕率约 50%(关中经济好,但仍大量去京津/沿海)

- 陕西人口流出比东三省好,留陕就业率约 50%(西安 + 咸阳 + 宝鸡 经济相对好)
- **西安经济体量约 1.2w 亿(2024)**,在西部仅次重庆 + 成都
- 但陕西高分段考生仍大量去京津 / 长三角 / 珠三角(西交大 / 西工大 留陕比例不到 35%,顶尖人才虹吸至京沪深)
- **本省 985/211 毕业生留陕约 30-40%**,**走国防系统反而留陕比例更高**(航天院所 / 西飞 / 西电 都在西安本地)

### 4. 陕西 2025 取消一本二本合并(本科批划线低)

**关键认知**:陕西 2025 年起(首届 3+1+2),**只有"本科批"和"特控线"两条线**:
- **本科批** = 原一本二本合并后的最低控制线
- **特控线**(原一本线)= 985/211 + 强势院校的最低门槛

**结果**:陕西本科线不高,**这不是陕西考生水平低,是划线规则不同**。看位次别看分数。

### 5. 陕西名校结构(精炼且顶配)

- **3 所 985**:
  - **西安交通大学** — C9 + 985 + 全国 Top 10(电气/机械/能动/管理 顶级)
  - **西北工业大学** — 985 + 国防七子(航空/航天/航海 全国前 3)
  - **西北农林科技大学(杨凌)** — 985(被吐槽末流但学科评估好,作物学/林学全国前 10)
- **5 所 211**(以上 3 + 2):
  - **西安电子科技大学** — 211 + 国防七子(电子信息全国前 3,跟电子科大/清华齐名)
  - **长安大学** — 211(公路工程全国前列,交通运输部直属)
  - **陕西师范大学** — 211 师范(师范全国前 5,跟北师大/华师大同档)
  - **西北大学** — 211 综合(地质学/考古学全国前列)
- **国防七子**:**西工大 + 西电**(陕西占 2/7,仅次黑龙江占 2/7,**全国国防工业教育资源最集中省份之一**)
- **顶配双非**:
  - **西安理工大学** — 双非但水利水电 + 印刷工程强
  - **西安建筑科技大学** — 双非但**建筑老八校之一**(跟同济 / 东南 / 清华建筑同档)

详见 `陕西强校真实地位.md`。

## 陕西 跨年录取数据 怎么对比(关键!!)

### 数据现状

| 年份 | 字段 | 处理建议 |
|---|---|---|
| 2021-2024 | `subject_type = 文科 / 理科`,批次 = `本科一批 / 本科二批 / 专科` | **理科 ≈ 物理类**(粗略对应,**位次 ≈ 位次**,不是分数 = 分数) |
| 2025 | `subject_type = 物理类 / 历史类`,批次 = `本科批 / 本科特控批` | 直接看 |

### 跨年对比的正确姿势

**1. 老高考 → 3+1+2 跨年比对,只看位次,不看分数**

例:
- 2024 理科某校投档线 580 分 / 位次 8500
- 2025 物理类某校投档线 540 分 / 位次 8800
- **位次相近**(8500 vs 8800),**分数差 40 分但其实是同档**(2025 划线规则变化导致总分体系下移)

**2. 文科 ≠ 历史类 严格对应,但位次有参考价值**

文科和历史类**考试结构相似**(语数英 + 文综 vs 语数英 + 历史 + 再选 2)、**人群相似**(都是文科生),**位次大致可比**。但因为再选科目选择面变了,**部分专业组(如要求"政治"的)位次会有 5-10% 浮动**。

**3. 数据库 query_school 的处理**

`query_school.py` 在陕西按 `--type 物理类 / 历史类` 查询时,**默认拉取 2025 数据**(新高考首届);如果需要看 2021-2024 老高考趋势,**需要单独 query 文/理科**。**生成志愿卡片时,2025 用物理/历史,2024 及之前用理/文标注转换**。

**4. 陕西"后发优势"的运用**

陕西作为第五批最后一批,**前面 4 批省份(尤其第三批湖北/湖南、第四批黑龙江/吉林)的 2024 录取数据规律可以参考**:
- 物理类比例上升,历史类竞争反而变激烈(因为分母小)
- 化学绑定加严(医学 / 化工 / 材料 普遍要求"必选化学")
- 公费师范 / 国防生 / 地方专项 受欢迎度上升

## 选科建议(陕西视角)

### 物理类 vs 历史类 怎么选

**物理类**(强烈建议优先):
- 可报专业**约 90%**(几乎所有理工科 / 大部分经管 / 部分医学要求物化)
- 985/211 在陕西物理类招生量 **>>** 历史类(西交大 / 西工大 / 西农 / 西电 / 长安 都是工科主导)
- 起薪 + 就业 + 考研 全面优势
- 国防系统校招几乎全要物理类(西工大航空/西电军工电子的就业核心)
- 陕西物理类约 65-70% 考生

**历史类**:
- 可报专业**约 40%**(文史哲 / 法学 / 部分经济 / 部分管理)
- 西交大 / 西工大 历史类招生少(西工大不在陕西历史类招主要工科,西农大 / 长安大学 历史类极少)
- **优势:卷得稍轻 + 适合考公方向**(汉语言 / 法学 / 历史 等公考友好专业)
- 陕师大历史类是亮点(师范 + 历史/中文/政治 留陕当老师顶级路径)
- 陕西历史类约 30-35% 考生

**结论**:**除非数学物理底子真的差(物理常 50 分以下),否则优先物理类**。这跟全国新高考省份一致,**陕西因为本省国防工业 / 工科强校都是理工科主导,差异更明显**。

### 再选科目组合(物理类)

**强推:物化生**(可报专业最广,医学 + 化工 + 生物 + 计算机 + 大部分工科都开;劣势:卷)

**次选:物化政 / 物化地**(物化是 90%+ 工科要求的硬通货;再加政 = 考公友好,加地 = 难度低 + 不冲突;**长安大学 / 西农大 部分专业偏好地理**)

**避坑:物生政 / 物生地 / 物政地**(不选化学 → **直接砍掉化工 / 材料 / 部分医学 / 部分军工**;**西交大能动 / 西工大材料 / 西电信电 / 西农大化工的多数王牌专业都要求"必选化学"**)

### 再选科目组合(历史类)

**强推:史政地**(传统文科黄金组合,法学 / 汉语言 / 历史 / 公考方向通吃;陕师大 / 西大 历史类主流推这个)

**次选:史政生 / 史政化**(政是公考神科,搭一个理科再选可拓宽专业面)

**避坑:史化生 / 史生地**(历史类选两理科是错位 — 选了历史就别再纠结理科,可报专业反而变窄)

## 陕西志愿填报特殊提醒

### 1. **本省 985/211 在本省招生量大,优先填本省冲一档**

西交大 / 西工大 / 西农 / 西电 / 长安 / 陕师 / 西大 在本省招生量 **>>** 出省学生进同档985/211 的概率。**用同样位次,留陕反而能上更好的本省名校**(本省 985 vs 出省 211)。

但要权衡 → 见"留陕率"反面(陕西高分段考生仍倾向去京津/沿海)。

### 2. **国防七子 / 军工系统的特殊路径(陕西最大金牌!)**

西工大 / 西电 是中国航天 / 航空 / 军工电子 系统对口校(国防七子)。**毕业生进国防院所 = 编制 + 体面 + 普通家庭顶级 ROI**:
- 中国航天科技 / 航天科工(液体/固体火箭团队)
- 中航工业(运 20 / 歼 20 / 教练机)
- 中船重工 705 所 / 西飞 / 中国兵器
- 中电 14 所 / 中电 38 所(雷达系统)/ 华为西安研究所

**这条路径陕西本省考生最容易切入**(本省校 + 本省名额 + 国防系统校招直接来西安,**西安直接是核心校招城市**)。**普通家庭男生进国防央企铁饭碗 = 陕西最大本地优势**。

### 3. **冲稳保比例 1:2:5(留陕保底)或 2:3:3(出省冲档)**

留陕路径:冲 1-2 个本省 985/211 + 稳 3-4 个本省 211/双一流学科 + 保 4-5 个本省双非或西北双非

出省路径:冲 2-3 个出省 211/985 + 稳 3-4 个京津/长三角双非 + 保 3-4 个本省双非

### 4. **跨省 211/985 的"鸡头凤尾"权衡**

例:同样位次能上**本省 西电 强势组(冲档)** 或者 **出省 211 财经类** 或者 **京津双非好城市**:
- 想做电子信息 + 进国防系统 → 西电 完胜
- 想做财经金融 → 出省东财 / 央财(财经领域陕西本省没有顶级 211)
- 想留京津 + 一线城市 → 京津双非 + 城市 vs 西电牌子,看权重

### 5. **数据来源警告**

- 陕西省考试管理中心(招办)官网批次线为准
- 陕西招生考试信息网
- 一分一段表 = 唯一精确数据(`scripts/score_to_rank.py` 已收录)
- **第三方数据(如各 App)**:**警惕 2025 数据可能不完整**(首届 3+1+2,部分院校专业组数据缺失)

## 给家长的金句(本地化)

> "陕西 2025 才首届 3+1+2,**家长拿 2024 年理科分数对照 2025 物理类是错的**。新高考体系下,看位次别看分数,**孩子 2025 物理类 9000 名 ≠ 2024 理科 9000 名考多少分**。"

> "**陕西是国防工业重镇,西工大 + 西电 都是国防七子**。普通家庭男生想跨阶级,**西工大航空 / 航天** 或者 **西电军工电子** = 起薪 12-20k + 编制 + 国防央企铁饭碗,**这是陕西本省最高 ROI 路径,全国名次都拿得出手**,而且**留陕就能进**(西飞 / 航天院所 / 中电 14 所都在西安)。"
