# 长安大学(长大,CHD)— 211 + 交通运输部直属,公路工程全国前列

## 一句话定位

**211 + 双一流 + 教育部 / 交通运输部 / 自然资源部 / 住建部 共建**,**交通运输工程 / 道路与铁道工程 全国前 3**(公路工程行业天花板)。**中国交通系统对口神校**(中交集团 / 中铁集团 / 各省公路局 / 各省交通厅 校招主力)。**男生 + 普通家庭 + 想进交通 / 建设系统编制** 的最直接路径,陕西 211 性价比突出。

---

## 真实地位

- **211 + 双一流 + 教育部直属 + 交通运输部 / 自然资源部 / 住建部 三部 共建**,**双一流学科 1 个:交通运输工程**。
- **学科评估**:**交通运输工程 A-(全国前 5)+ 地质资源与地质工程 B+ + 土木工程 B+ + 城乡规划 B+ + 风景园林 B+**,**公路工程 + 地质 + 建筑 三栖**。
- **历史血脉**:**2000 年由原西安公路交通大学(原交通部直属)+ 西安工程学院(原地矿部直属)+ 西北建筑工程学院(原建设部直属)合并组建**,**根正苗红的中国交通 + 地质 + 建筑 三大行业系统教育合体**。
- **陕西本省地位**:**211 但行业认可 ≈ 985 行业级**(在交通系统内),**录取分在陕西 211 里中等偏下**(物理类 2-3w 名可冲),**性价比之王**。
- **对口红利**:**交通运输部直属 = 中交集团 / 中铁集团 / 各省交通厅 / 各级公路局 / 高速公路集团** 校招对口,**公路工程系统天花板**。
- 渭水校区(本部,长安区)+ 雁塔校区(老校区),**学风工科务实 + 男多女少 7:3 + 公路 / 地质 / 建筑 氛围浓**。

- **王牌组(交通运输 / 道桥 / 计算机 / 车辆工程)**:全省 **8,000-15,000 名**。
- **主流组(土木 / 地质 / 测绘 / 城乡规划 / 建筑学 / 汽车工程)**:全省 **15,000-22,000 名**。
- **冷门组(部分材料 / 资源勘查 / 国土资源 / 经管)**:全省 **22,000-30,000 名**。

### 历史类 / 2025 历史(首届新高考)

- **历史类(经管 / 法学 / 文管,招生量小)**:全省 **3,000-7,000 名**。

- **理科王牌组**:全省 **8,000-15,000 名**;**理科冷门组**:全省 **22,000-30,000 名**。
- **文科**:全省 **3,000-7,000 名**(招生量小)。

**段位定位**:**冲长大物理类省排 30,000 名内**,**王牌组(交通 / 道桥 / 车辆)要 15,000 名内**;**比西电 / 西农大略低 + 性价比突出**。**以一分一段表反查为准**。

## 性价比专业

- **道路与铁道工程**:**全国前 3 + 中交一公局 / 二公局 / 中铁建 直接对口 + 编制 + 起薪 8-12k + 房补**,**普通家庭男生稳定路径** + **中国基建狂魔时代红利**。
- **桥梁与隧道工程**:**全国前 5 + 中交集团 / 中铁建 + 项目奖金高**,**男生不怕基层出差的高 ROI 路径**。
- **车辆工程**:**比亚迪 / 长安 / 一汽 / 陕汽** 对口,**新能源汽车风口 + 起薪 12-18k(比亚迪应届)**。
- **测绘科学与技术**:**自然资源部 / 各省测绘院 / 北斗导航产业链** 对口,**冷门但稳定 + 公考友好**。
- **建筑学(原西北建筑工程学院血脉)**:**老八校 + 同济 / 东南 之外的西北建筑教育头牌**,**录取分相对低 + 中建 / 西北建筑设计院** 对口。
- **地质资源与地质工程**:**中石油 / 中石化 / 中煤 / 自然资源部** 对口,**冷门但出口稳 + 编制路径**。

## 坑专业(在长大里相对弱)

- **计算机 / CS / 软件**:**长大 CS 是中等(B 级)+ 不如西电 / 西交大同方向**,**学 CS 别来长大**。
- **文科 / 经管 / 法学 / 新闻**:**工科主导 + 文科边缘**,**学文科直接选西大综合或陕师大**。
- **医学 / 农林**:**长大没医学院 / 没农林**,**对口走西交大医学部 / 西农大**。
- **化工 / 材料**:**长大化材是配套 + 不如西交大 / 西工大同方向**。
- **报长大但不学交通 / 土木 / 建筑 / 地质 / 车辆**:**长大牌子的核心价值集中在这几块**,**学非对口方向等于浪费 211 名额**。

## 关键提醒(填报陷阱)

1. **长大 vs 同档行业 211(河海 / 矿大)怎么选**:
   - **学公路 / 道桥 / 交通 → 长大**(交通运输部直属 + 公路工程全国前列)
   - **学水利 / 水电 → 河海**(水利全国第 1 + 水利部直属)
   - **学矿业 / 能源 → 矿大**(矿业全国第 1)
   - **方向不对 → 211 牌子也是浪费**;**陕西本省考生留陕走交通系统 → 长大首选**
2. **物理类专业组分化**:
   - **王牌组**:交通运输 / 道桥 / 计算机 / 车辆(招生量主流,15,000 名内)
   - **主流组**:土木 / 地质 / 测绘 / 城乡规划 / 建筑学(15,000-22,000 名)
   - **冷门组**:材料 / 资源勘查 / 经管(22,000-30,000 名)
3. **服从调剂**:**主流组可能调到地质 / 资源勘查 / 部分材料**(基层出差概率高,接受不了别勾)。
4. **交通行业的现实**:**对口央企(中交集团 / 中铁建 / 高速集团)项目常在西部 / 山区 / 高速工地**,**前 5 年基层跟工程跑 + 工资稳定但生活不舒服**;**接受不了基层别报道桥 / 公路**(可改报城乡规划 / 建筑学 / 测绘 走设计院路径)。
5. **建筑学专业课要求**:**部分招生有美术加试 / 专业课成绩**,**报建筑学 / 城乡规划 / 风景园林 注意省考美术联考要求**。

## 毕业出口(2024 数据估算)

- **留陕就业**:约 **35-40%**(**西安比亚迪 / 长安汽车 / 陕汽 / 西安建筑设计院 / 陕西交通建设集团 / 陕西高速集团 / 陕西公路局** 校招主力,**留陕走交通 / 汽车 / 建筑系统是长大的最优路径之一**)。
- **京津出省**:约 12-15%(**北京中交集团总部 + 中铁建总部 + 自然资源部 + 设计院总部**)。
- **长三角 / 沿海 / 全国基建项目(上海 / 深圳 / 江苏 / 全国高速公路项目)**:约 35-40%(**中交集团各局公司 + 中铁建各局公司 + 项目跟着工程跑**)。
- **进央企 / 国企概率**:约 **40-45%**(**中交集团 / 中铁建 / 中铁工 / 各省高速集团 / 公路局 / 设计院 校招大户**,**交通系统 211 顶配**)。
- **考研 / 读博 / 保研**:约 30-35%(保研率 ~13-15%)。
- **起薪范围**:中交 / 中铁建项目部 8-13w + 项目补贴 + 房补,设计院 12-18w,陕西交通建设集团 / 高速集团 8-12w + 编制,比亚迪 / 长安汽车 12-18w,公考交通系统 6-10w + 编制。

## 适合谁

- 陕西物理类 **省排 30,000 名内 + 男生 + 想做交通 / 公路 / 道桥 / 车辆 / 建筑** 的考生(**陕西 211 性价比突出**)。
- **想进中交集团 / 中铁建 / 各省高速集团 / 公路局 / 交通厅**:**长大直接对口 + 编制 + 起薪 8-13w + 终身稳定**。
- **男生 + 不怕基层出差 + 想要央企铁饭碗**:**中交 / 中铁建项目部跟工程跑 + 工资稳定**,**普通家庭男生稳定路径**。
- **女生 + 城乡规划 / 建筑学 / 风景园林 / 测绘 + 想去设计院**:**长大女生友好(规划 / 建筑方向)+ 西安建筑设计院对口**。
- **学车辆工程 + 想进比亚迪 / 长安 / 陕汽 + 留陕**:**长大汽车学院对口陕汽 / 比亚迪西安基地**。
- **想做地质 / 资源勘查 + 中石油 / 中石化 / 自然资源部**:**长大地质资源 = 西安地质学院血脉**。

## 不适合谁

- **想做 CS / 互联网**:**长大 CS 中等(B 级)+ 不如西电 / 西交大同方向**。
- **想做电子信息 / 通信**:**走西电 + 全国前 3**。
- **女生 + 不想出差跑工地**:**公路 / 道桥前 5 年基层出差是常态**,**追求都市稳定生活的女生选规划 / 建筑 / 测绘 设计院方向**。
- **学医 / 农林 / 财经 / 法学**:**长大没医学院 / 没农林,文科边缘**,**选西交大医学部 / 西农大 / 西大综合 / 西交管院**。
- **报 211 牌子但不接受交通 / 土木 / 建筑 / 地质 + 不接受调剂**:**长大非对口方向也是边缘**,**牌子虚浪费名额**。
- **想留南方都市核心 + 不想出差**:**长大对口工作地 50%+ 在外地基建项目**。
- **分够 985(西交大 / 西工大 / 西农大)**:**985 牌子在非交通领域应聘 / 出国 / 跨行业更通用**。
