# 陕西师范大学(陕师大,SNNU)— 211 + 双一流,西部唯一教育部直属师范

## 一句话定位

**211 + 双一流 + 教育部直属 6 大师范之一**(跟北师 / 华师 / 东师 / 华中师 / 西南师 同档),**师范全国前 5**,**西部地区"小北师"地位**。**留陕 + 西北当老师顶级**,**公费师范生 = 4 年免学费 + 包分配回生源地中学 + 教育系统编制**。陕西文科女生 + 想当老师 + 留西北 的最稳路径。

---

## 真实地位

- **211 + 双一流 + 教育部直属(全国 6 所部属师范之一,与北师大 / 华东师大 / 东北师大 / 华中师大 / 西南大学 同档)+ 国家"985 工程优势学科创新平台"建设高校**,**双一流学科 2 个:中国语言文学 / 教育学(自定)**。
- **学科评估**:**教育学 A-(全国前 5)+ 心理学 B+ + 中国语言文学 A-(全国前 10)+ 历史学 B+ + 哲学 B+ + 数学 B+**,**师范专业全国前列**。
- **历史血脉**:**1944 年陕西省立师范专科学校(于右任题写校名)→ 1954 年西安师范学院 + 陕西师范学院 → 1960 年合并为陕西师范大学**,**根正苗红的中国西部师范教育脊梁**。
- **6 大部属师范唯一在西部**:**北师大(北京)/ 华东师大(上海)/ 东北师大(长春)/ 华中师大(武汉)/ 西南大学(重庆)/ 陕师大(西安)**,**陕师大独占西北市场**。
- **陕西本省地位**:**师范专业 + 留陕路径强 + 录取分在陕西 211 里中等**(物理类 1.5-2w 名 / 历史类 5-8k 名),**文科考生顶配 + 女生友好**。
- 雁塔校区(老校区,文科主导)+ 长安校区(新校区,理科 + 主校),**学风文气重 + 男女比 3:7(女生主流)+ 师范 + 文科氛围浓**。

- **公费师范组(汉语言 / 历史 / 政治 / 英语 师范)**:全省 **2,500-5,000 名**。
- **王牌组(教育学 / 心理学 / 中国语言文学 / 历史学 / 哲学)**:全省 **5,000-9,000 名**。

- **文科公费师范组**:全省 **2,500-5,000 名**;**文科主流组**:全省 **5,000-15,000 名**(陕师大文科招生量极大)。
- **理科公费师范组**:全省 **10,000-15,000 名**;**理科主流组**:全省 **15,000-32,000 名**。

**段位定位**:**冲陕师大物理类省排 32,000 名内 / 历史类 15,000 名内**,**公费师范组(竞争激烈)历史类要 5,000 名内 / 物理类要 15,000 名内**;**陕西文科女生想当老师 + 留陕的最优路径**。**以一分一段表反查为准**。

## 性价比专业(公费师范生最大特色 ★★★)

**公费师范生政策(教育部直属 6 大师范执行)**:

- **学费 + 住宿费 全免**(国家承担)
- **生活补贴**:每月约 800-1000 元
- **毕业直接编制**:**回原籍服务 6 年**(陕西生源回陕西 / 甘肃生源回甘肃 / 新疆生源回新疆)
- **录取分较高**:陕西历史类 2,500-5,000 名 / 物理类 10,000-15,000 名(公费师范名额相对少,竞争激烈)

**最适合**:
- 普通工薪 / 农村家庭(经济压力大,**公费 = 零成本上 211**)
- 父母希望孩子做老师 / 进体制内
- 想留陕 / 西北 当老师(陕师大公费师范在陕西 / 甘肃 / 新疆 / 宁夏 / 青海 都有名额)
- 性格内向稳健 / 不想出去闯荡

**最不适合**:
- 完全不想做老师的(公费要求服务 6 年,**违约要赔学费 + 写违约记录 + 影响考公考编**)
- ENTP / 不适合流程化教育的性格

## 坑专业(在陕师大里相对弱)

- **工科 / CS / 软件**:**师范主导 + 工科是边缘 + 不如西电 / 西交大同方向**,**学 CS 别来陕师大**。
- **经管 / 法学**:**陕师大经管 / 法学是配套 + 不如西大综合 / 西交管院**。
- **医学 / 农林**:**陕师大没医学院 / 没农林**,**对口走西交大医学部 / 西农大**。
- **报陕师大但不当老师 + 学非师范专业 + 只为 211 牌子**:**非师范方向在陕师大里也是边缘**,**不如同分的西电 / 长大对口专业 211**。

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生(关键!)**:
   - **名字里有"师范"且是提前批录取** → 公费师范(免学费 + 编制 + 回原籍服务 6 年)
   - **名字里有"师范"但是普通批录取** → 普通师范(自费 + 自找工作)
   - **千万分清,差几十万学费 + 编制路径**
2. **公费师范的"原籍服务 6 年"是硬约束**:**违约要赔学费 + 写违约记录 + 影响以后考公考编**。**家长一定要跟孩子聊清楚这 6 年要回原籍县市中学**。
3. **陕西生源 vs 跨省生源公费师范**:**陕西考生上陕师大公费师范,毕业回陕西本地县市中学**(优先安排到生源地或西部欠发达县市);**甘肃 / 新疆 / 宁夏 / 青海 / 内蒙 跨省生源回各省**。
4. **陕师大 vs 北师 / 华东师**:
   - **学师范 + 想留陕 / 西北 → 陕师大首选**(西部唯一部属师范 + 公费师范留陕)
   - **学师范 + 想去全国一线 → 分够走北师 / 华师 / 华中师**(综合排名更高 + 平台更广)
   - **分够北师大 → 别 stuck 陕师大**(北师大全国通用 + 一线就业)
5. **服从调剂**:**陕师大物理类组内可能含心理学 / 教育技术 / 部分理学基础**(被调剂能不能接受?)**文科组组内可能含教育学 / 哲学 / 思政**(基本都对口师范出口)。

## 毕业出口(2024 数据估算)

- **公费师范生**:**100% 进入教师编制**(陕西 / 甘肃 / 新疆 / 宁夏 / 青海 各市县中学)。
- **普通师范生**:**约 50-60% 通过省考 / 市考考编进入教师编制**,约 25% 进民办学校 / 培训机构,约 15% 改行。
- **非师范类**:**约 30% 留陕**,**约 50% 出省**,**就业不如纯综合类 211**(因为陕师大牌子在非师范圈认可度低于 985 / 综合性 211)。
- **留陕就业**:约 **45-55%**(**陕师大公费师范留陕主力 + 西安各重点中学(西工大附中 / 高新一中 / 铁一中 / 交大附中 / 西工大附中分校)校招对口**,**陕西教育系统留陕率最高的 211**)。
- **西部其他省份(甘肃 / 新疆 / 宁夏 / 青海)**:约 **15-20%**(公费师范跨省生源 + 西部教育扶贫路径)。
- **京津 / 沿海(出省)**:约 18-22%(**北京 / 深圳 / 杭州民办教育 / 高校行政 / 教育出版社**,**陕师大牌子在出省一线民办教育有竞争力**)。
- **进体制内 / 编制概率**:**约 60-70%**(**6 大部属师范里编制对口路径最直接**)。
- **考研 / 读博 / 保研**:约 30-35%(保研率 ~13-15%)。
- **起薪范围**:中学教师编制 6-10w + 寒暑假 + 公积金,**西安重点中学(高新一中 / 铁一中 / 西工大附中)10-15w + 编制 + 寒暑假**,民办教育 / 培训机构 12-18w(出省一线)。

**简单结论**:**陕西文科女生想当老师 + 留陕 / 西北 → 陕师大公费师范首选**;**分够北师大 + 想去一线 → 出省北师**;**两都不行 → 西南大学(重庆)/ 东北师大(长春)备胎**;**陕西考生留陕教育系统 → 陕师大就是天花板**。

## 适合谁

- **陕西历史类 5,000-15,000 名 + 女生 + 想当老师 + 留陕** 的考生(**陕西文科女生最稳路径**)。
- **公费师范生路径**:**普通工薪 / 农村家庭 + 经济压力 + 想要 211 学历 + 编制 + 留西北**(免学费 + 包分配 + 编制 = 跨阶级最稳)。
- **想进西安重点中学(西工大附中 / 高新一中 / 铁一中 / 交大附中 / 西工大附中分校)当老师**:**陕师大是这些中学校招直接对口**。
- **女生 + 学前教育 / 小学教育 / 心理学 + 想要稳定职业**:**陕师大学前教育 / 小学教育 + 西安市直幼儿园 / 小学编制对口**。
- **想进教育出版 / 考试院 / 教育局 / 教育科研单位**:**陕师大教育学全国前 5 + 体制内对口路径**。
- **历史类 + 想做考古辅助 / 文博 / 博物馆**(走历史师范 + 转博物馆,跟西大考古不同方向)。
- **物理类 + 想当中学物理 / 化学 / 数学老师 + 留陕**:**陕师大理科师范 + 公费**。

## 不适合谁

- **完全不想做老师**:**公费师范服务 6 年硬约束 + 普通师范出口窄**,**别为 211 牌子来陕师大**。
- **想做工科 / CS / 互联网 / 国防**:**陕师大工科边缘**,**走西电 / 西工大 / 西交大对口方向**。
- **想做财经 / 金融 / 法学 / 新闻 / 财会**:**陕师大经管法律边缘**,**走西交管院 / 西大经济 / 西北政法**。
- **想做医学 / 农林**:**陕师大没医学院 / 没农林**,**走西交大医学部 / 西农大**。
- **想出省一线 + 想做高薪互联网 / 投行**:**陕师大牌子在非师范圈认可度低**,**出省京沪深 + 互联网 / 投行 走 985 综合更优**。
- **男生 + 不想做老师 + 不想留西北**:**陕师大男生比例低 + 师范氛围浓 + 选西交大 / 西工大 / 西电更对口男生需求**。
- **分够北师大 / 华东师**:**别 stuck 陕师大**,**北师 / 华师全国通用 + 一线就业平台更广**。
