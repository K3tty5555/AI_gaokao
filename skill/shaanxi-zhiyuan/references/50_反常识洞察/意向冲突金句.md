# 用户意向冲突 — Reality Check 金句库(陕西视角)

很多家长 / 考生有具体的意向("想上西交大"、"非西安不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) ─ 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** ─ 客观差距 30 分 / 1 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** ─ 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** ─ 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** ─ 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** ─ 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 ─ 分数差距 >30 分 / >1 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 500 分要西交大 / 580 分要西交大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** ─ 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(陕西 580 分,意向西交大)**:
> "西交大主流组在陕西物理类 1,500-4,500 名。你 12,000 名,差 7,500 名,**西交大没戏**。
>
> 但你能上**西电(通信 / 网安) + 西工大(三航主流组) + 长安大学(公路桥梁) + 西北大学(综合性大学 211)** ─ 这四所留陕就业,**国企 / 体制内招聘里跟西交大冷门组校友地位差不多**(都是'西安本地 985/211 + 留陕同档'),**而且西电通信 / 西工大三航 在华为西安 / 中航工业 校招认可度比西交大综合冷门组更高**。"

**真实案例(陕西 540 分,意向西工大)**:
> "西工大主流组在陕西物理类 4,500-7,000 名。你 25,000 名,差 18,000 名,**西工大没戏**。
>
> 但你能上**西安理工(水电方向) / 西安建大(建筑老八校) / 长安大学冷门组(公路工程 / 交通工程) / 陕西科技大学** ─ 这四所留陕就业,**陕西本地工科产业链(建筑 / 交通 / 水电) 编制岗位认可度跟西工大主流组一档**。"

---

### 模式 B:边缘可达 ─ 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(陕西考生 + 普通家庭 + 想冲西交大)**:
> "西交大你 600 分能擦 ─ 但只能进材料 / 化工 / 生命科学 / 部分理科。**985 牌子 + 生化环材天坑** = 双重坑(陕西理科生的常见误区是'反正西交大牌子大,啥专业都行')。
>
> 同分能上的**西电通信工程 / 西工大三航主流组 / 长安大学公路桥梁 / 西农大食品科学**(985 + 双一流学科,中粮校招主力)出来对口程度更高。冲西交大留一个心理慰藉位即可,**但别让孩子最终被调剂到西交大材料而错过西电通信主力**。"

**真实案例(陕西农村考生想冲西农大)**:
> "西农大你 480 能冲(国家专项)─ 但能进作物学 / 林学 / 园艺学 这些 985 + 双一流主力。**西农大被吐槽末流 985,但对陕西农村学生而言,985 牌子 + 国家专项分数低 + 西部农林产业链对口** = **不是末流,是宝藏**。
>
> 同分能上的双非二本,出口完全是另一档。**西农大冲就对了**(对陕西农村学生而言)。"

### 模式 C:意向方向 vs 家庭抗风险 ─ 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 ─ [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [西交大医学部八年制 / 空军军医大学])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] ─ 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(陕西普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 8-12k**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**西交大医学部 临床 8 年制 / 空军军医大学 临床 8 年制**,长期天花板高。
>
> 撑不起 → **建议口腔(西交大 / 空军军医大学 5 年本科直接进诊所,起薪 8-15k,早 3 年挣钱)** 或**空军军医大学 5 年制临床(无学费 + 包分配进部队医院)** ─ **空军军医大学是陕西特有的'普通家庭学医金牌路径'**,放弃这个直接转 CS / 会计就太可惜了。"

**真实案例(陕西农村男孩 + 想学医 + 撑不起)**:
> "你陕西商洛农村出身,父母务农 + 临时工。学医本科 5 年 + 规培 3 年,期间月薪 5-8k,父母还要供你 8 年,**撑不起**。
>
> **但陕西特有路径** ─ **空军军医大学 临床医学 5 年制(无学费 + 有津贴 + 包分配进部队医院)** = **0 成本读医 + 编制 + 部队医院医生** = 你这家庭画像最完美的路径。
>
> 别错过这个机会,这是陕西农村学医男孩的金牌路径,其他省份都没这个独特红利。"

---

### 模式 D:意向城市 vs 院校层次 ─ "非西安不去"

**特征**:用户只想留某个城市("非西安不去" / "非北京不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** ─
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留北京没意义,要去西工大),**要灵活退一步**。"

**真实案例(陕西考生 + 想留西安 + 615 分)**:
> "你只留西安,这位次 4,500 名,西交大主流组够不上(差 1,000 名),只能擦冷门组。
>
> **留西安最稳路径**:**西工大三航主流组 / 西电通信工程 / 西大法学 / 西北政法 / 长安大学公路桥梁** ─ 这五所留陕就业,**陕西本地校友网密度极高 + 西安各军工央企校招主供给 + 比西交大冷门组就业更对口**。
>
> 不要为了'西交大牌子'去交大材料 / 化工 ─ 牌子有了但**专业出口惨 / 实习机会少了 / 转行成本高**,综合不划算。"

**真实案例(陕西考生 + 想出陕 + 中产家庭 + 650 分)**:
> "你想出陕,这位次 1,200 名,**西交大 / 西工大顶级组 都够**(留陕),但你想'见见世面'。
>
> **出陕最优路径**:
> - 学工科 → **上交大 / 浙大 / 哈工大本部 / 中科大** 同档可冲
> - 学综合 → **复旦 / 南大** 同档可冲
> - 学航空 / 航天 / 兵器 → **北航 / 北理工 / 哈工大** 顶级
> - **学电气 / 机械 / 能动 / 管理 → 留陕西交大反而最优**(全国第 1 学科 + 留陕进西电集团 / 国网西北分部 顶配)
>
> **学电气出陕反而损失校招本地资源**(西交大电气 / 西安军工央企扎堆,出陕进同样级别院校但失去本地优势)。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** ─ 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比(参考 90_陕西本地化 数据)
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** ─ 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** ─ 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") ─ 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") ─ 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") ─ 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") ─ 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 ─ 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 西交大 / 想学医 / 想留西安 ─ 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 ─ **解读用户的意向,而不是机械执行意向**。

## 陕西特有的 5 个常见意向冲突

### 冲突 1:"非西交大不去" + 分数差 1 万名

**陕西考生最常见的意向冲突** ─ "西交大是陕西最高 985,我家孩子非西交大不去"。**典型在西安城区中产家庭**,信息差小但被"西交大执念"束缚。

**Reality Check**:
- 西交大主流组 = 陕西物理类 1,500-4,500 名;**冲不上的家庭别死磕**
- **西工大 / 西电 / 西大 在陕西本地认可度跟西交大冷门组同档**;**陕西本地企业校招根本不区分这四所**(都是"西安顶级 985/211 + 留陕同档")
- **学航空 / 航天 / 兵器 → 西工大比西交大对口**;**学通信 / IT → 西电比西交大对口**;**学法学 / 综合人文 → 西大比西交大对口**

### 冲突 2:"非西安不去" + 想做的方向西安没强校

**陕西考生第二常见意向冲突** ─ "我家孩子想留西安,但孩子想学航天 / 金融 / 投行"。

**Reality Check**:
- **学航天 → 留西安西工大反而是顶配**(北航航空 / 西工大三航 / 哈工大本部航天 = 三足鼎立)
- **学金融 → 留西安西交管院是中国西部第一商科**,但**真想做投行 / 顶级金融 → 必须出陕**(沪上 / 北京)
- **学法学 → 留西安西北政法 / 西大 在陕西公检法系统认可度高**,但**想去最高人民法院 / 律所 → 出陕走人大 / 武大法学**

### 冲突 3:"考公一定要法学" + 没数据基础

**陕西考生(尤其农村 + 工薪)** 误以为"考公就要学法学"。

**Reality Check**:
- **国考 / 陕西省考 汉语言文学可报岗位 ≥ 法学**(虽然法学绝对数也多,但汉语言竞争更小)
- **陕西公检法系统认西北政法 / 西大法学 = 五院四系一档**,**但其他公考岗位汉语言更优**
- **陕北 / 陕南 艰苦补贴公考岗 → 任何文科都行,汉语言反而比法学更容易上岸**

### 冲突 4:"陕北能源富裕家庭"想推女儿"金融 / 经济"

**陕北榆林煤老板 / 延安油气家族** 普遍想"女儿做金融 / 经济"(从家长视角,体面 + 跟生意结合)。

**Reality Check**:
- **女儿做金融头部 = 北上深投行 / 私募 + 双 985 法学硕士起步 = 陕北家庭的资源完全用不上**(没金融行业人脉)
- **女儿做"陕西本地金融" = 陕西农信社 / 长安银行 / 陕西工行 = 待遇平平 + 不需要专门学金融**
- **更优解** = **陕师大公费师范汉语言 / 西交大医学 → 女儿稳定 + 体面 + 家庭财富与孩子职业互补**(典型陕北能源家庭"显学")

### 冲突 5:"工矿子弟"想"逃离父母厂子"

**西飞 / 西电集团 / 陕汽 工矿子弟** 部分想"反叛父母厂子,做完全不一样的工作"。

**Reality Check**:
- **理解年轻人想"反叛"的心情** ─ **但你的家庭最大的资源就是父母厂子的人脉 + 知识传承**
- **不进父母厂子 / 进同行业** → 你跟普通家庭出身的同学起跑线一样,**而你本来可以"父母厂子隔壁单位 + 家学传承"领先 5 年**
- **陕西工矿子弟跨阶级最稳路径** = **西工大三航 / 西交大电气 / 西电通信** + **进父母厂子隔壁单位 / 同行业央企**(子承父业不是丢人,是你的最大优势)

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** ─ 两者都要,且 reality check 优先。
