# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(陕西视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**陕西特有家庭画像**:
- **工矿子弟家庭**(西飞 / 西电集团 / 陕汽 / 中航工业 西安各厂矿子弟)─ 工薪稳态 + 国防工业偏好基因
- **陕北能源富裕家庭**(榆林 / 延安 煤老板 / 油气家族)─ 类似鄂尔多斯,中产以上但商业基因弱
- **关中农村家庭**(渭南 / 咸阳 / 宝鸡 / 汉中 / 安康 / 商洛 农村)─ 跨阶级心理压力强 + 公费师范 / 国家专项受益最大
- **西安城区中产家庭**(公务员 / 教师 / 医生 / 央企管理 多)─ 体制偏好基因 + 信息差小

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。**陕西特有**:**西飞 / 西电集团 / 陕汽 / 西安飞机工业集团 / 中航工业各厂 国企工人家庭** 也归这一档。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **西安体制内家庭普遍信息差小**(西安公务员 / 国企密度高 + 西安公务员论坛 / 微信群活跃)

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化);**陕西选调主要走西交大 / 西工大 / 西电 / 西大 / 陕师大**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 ─ 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:**警校(中国人民公安大学 / 西北政法警官学院)+ 公安联考 = 父母编制资源能用上**
5. **国防央企子承父业**:**西飞 / 西电集团 / 陕汽 / 中航工业 / 航天院所 工人家庭** → **西工大 三航 / 西交大 电气 / 长大 交通运输** 子承父业路径明确

**典型 case**:
- 西安某体制内家庭(父亲省直机关,母亲西安某国企) → 孩子 605 分历史类 → 推**西大法学**(陕西本省法学顶配,出省比西北政法 牌子硬) → 毕业选调进陕西省委办,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去西交大 CS → 毕业 30w 起薪很高,但家长不满"不稳定",劝其离职考公,**两年的时间损耗 + 心理纠结**
- 西飞工人家庭 → 孩子 615 分物理类 → **推西工大 飞行器设计**(子承父业)→ 毕业进西安阎良中航工业第一飞机设计研究院 = **父母厂子隔壁单位 + 编制 + 国防央企稳态**,典型国防工业子承父业

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(陕师大公费师范是首选);医生家庭 → 临床 / 口腔(8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → 法学(西大 / 西北政法);工程师家庭 → 对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲西安铁一中 / 高新一中 语文老师 + 父亲普通工薪 → 孩子 615 分历史类 → **公费师范生汉语言**(陕师大) → 毕业回母亲所在区编制,**母亲资源直接复用**
- 父母都是西安交大医学部一附院 / 西京医院 临床医生 → 孩子 650 分物理类 → **西交大医学部八年制临床** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 父母都是西安某中央驻陕国企工程师(西飞 / 西电集团) → 孩子 620 分物理类 → 推**西工大 飞行器设计 / 西交大 电气**(对口父母行业,实习 / 就业有人脉)

## 档位 ③ 私企管理 / 创业家庭(陕西较少)

**定义**:父母私企中高管 / 自主创业 / 企业主。

**陕西特殊性**:**陕西民营经济不如东南沿海** ─ 私企家庭比例显著低于江浙广;**主要的私企家庭画像**:**陕北能源(榆林煤老板 / 延安油气家族)+ 西安本地民营企业(餐饮 / 商贸 / 房地产)**

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **陕北能源家庭特殊**:类似鄂尔多斯,**钱多但商业基因弱**(主要靠资源 / 关系做生意)+ **家长普遍想孩子稳定 + 体面**(不想孩子继续赌煤价 / 油价)

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(西交管院 = 中国西部第一商科) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 ─ 父母给得起 5-10 年试错成本
5. **避免:进体制内基层**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **陕北能源家庭特殊**:**家长想孩子"洗白" + 稳定** → 推**陕师大公费师范 / 西交大医学 / 西交大管院** ─ 跟家长商业基因不冲突 + 给出体面选项

**典型 case**:
- 西安某私企老板家庭(年入 200w+) → 孩子 580 分物理类 → 推**西交大苏州研究院(中外合作办学) / 香港城市大学**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班
- 失败 case:私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**
- **陕北榆林煤老板家庭** → 孩子 600 分物理类 → 家长想"稳定 + 体面" → **推西交大 临床医学 / 陕师大公费师范汉语言** → **家长安心 + 孩子有体面职业 + 家族财富与孩子职业互补**(典型陕北能源家庭路径)

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 10-30 万为主。**陕西特有**:**西飞 / 西电集团 / 陕汽 / 中航工业 各厂的普通工人家庭**(非管理岗)归这一档。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **陕西工矿家庭特殊**:**虽然父母在国防央企工作,但本身是工人,无法给子女"管理岗"资源** ─ **孩子要靠 985 学历 + 国防七子专业(西工大三航 / 西电通信)** 才能进父母厂子的管理岗 / 研发岗

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(陕师大) = 高考分适中 + 直接编制 + 无学费**(陕西工薪家庭首选)
   - **空军军医大学 = 无学费 + 包分配军医**(陕西特有金牌路径)
   - **警校(中国人民公安大学 / 西北政法警官学院 / 中国刑事警察学院)+ 公安联考 = 进警察系统编制**
   - **医学技术(医学影像 / 检验)= 三甲医院技术岗 + 4 年本科即可**
   - **西工大三航 / 西电通信 = 国防央企编制对口**(陕西工矿家庭性价比之王)
3. **次推稳定就业型**:
   - **电气工程进国家电网**(分够 985/211 / 西安理工 / 长安大学等性价比之选)
   - **师范类**(汉语言 / 数学师范 / 物理师范)
   - **护理(本科,专科也行)**
4. **避免高风险方向**:
   - **金融 / 经济 / 工商管理**(双非这些 = 死局,西安双非金融在西安体制外极难就业)
   - **双非 CS**(2024 起薪 7-9w,跟双非工科没差;**西安双非 CS 在西安市场尤其惨**,因为西安 IT 用人方主要看 985/211)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- **西安西飞工人家庭**(普通工薪)→ 孩子 615 分物理类 → 推**西工大 飞行器设计 / 自动化** → 毕业进**西飞集团(父母厂子)研发岗 / 中航工业第一飞机设计研究院** → 编制 + 月薪 1.2-1.5w + 西安户口 → **比父母上一代的车间工人岗向上跃迁一档**(典型陕西工矿家庭跨阶级)
- **陕西宝鸡工厂家庭** → 孩子 580 分物理类 → 推**长安大学电气**(2024 进国家电网西北分部 + 西电集团 校招主力) → 毕业进国家电网陕西宝鸡分公司,**月入 1w + 编制,家庭逆袭**
- **陕西汉中工薪家庭** → 孩子 540 分文史类 → 推**安康学院 / 渭南师范汉语言文学**(双非但考公 / 教师编主供给) → 毕业当年考上汉中市某区机关公务员,**家庭命运改变**

## 档位 ⑤ 农村 / 临工家庭(陕西关中 + 陕北 + 陕南)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。**陕西特有**:**关中渭南 / 咸阳 / 宝鸡 农村 + 陕北榆林 / 延安 黄土高原农村 + 陕南汉中 / 安康 / 商洛 山区农村**

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **陕西农村特点**:**陕南山区(汉中 / 安康 / 商洛)+ 陕北高原(榆林 / 延安)地理偏远 + 教育资源差** + 但**国家专项 / 高校专项 / 农村专项 + 公费师范 + 空军军医大学** 给陕西农村学生 4 条独特通道

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
   - **陕西本省 985(西交大 / 西工大 / 西农大)+ 211(西电 / 长大 / 陕师大 / 西大) 全国排名都不错 + 国家专项分数低 20-30 分** → **陕西农村学生留陕进 985 是其他省份不具备的优势**
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(陕师大,无学费 + 编制)= 农村家庭神器**
   - **空军军医大学(无学费 + 包分配)= 陕西农村男孩跨阶级金牌路径**
   - **国家专项计划 / 高校专项 = 陕西农村专属优惠**(陕西本省 985 专项分数低 20-30 分)
   - **警校 / 军校(无学费 + 编制 + 包分配)**
   - **西农大 国家专项 / 农林牧水** = 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起,**改空军军医大学**)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **陕西农村特殊机会**:
   - **国家专项**:陕西户籍农村,**985/211 名校多个专项指标(分数比统招低 20-30 分)** ─ **西交大 / 西工大 / 西大 / 陕师大 / 西农大 / 西电 / 长大** 都有专项
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会(西交大数学 / 物理强基)
   - **公费师范**:**陕师大公费师范** 是教育部直属六大师范之一 + **陕西农村出身的公费师范生回乡编制对口度极高**

**典型 case**:
- **陕西汉中农村家庭** → 孩子 590 分物理类 → 通过**国家专项**进**西交大医学部 临床医学**(比统招分低 30 分) → 985 牌子 + 国家专项编制路径,**整个家族第一个 985**
- **陕西延安农村女孩** → 605 分文史类 → 推**陕师大公费师范汉语言** → 4 年无学费 + 毕业回延安编制,**最适合陕西农村家庭的"零风险"路径**
- **陕西商洛山区农村男孩** → 580 分物理类 → 推**空军军医大学 临床医学 5 年制(无学费 + 包分配 + 部队医院编制)** → **跨阶级金牌路径**(典型陕西农村男孩 跨阶级最稳路径,远好于赌命双非 CS)
- **陕西渭南农村家庭** → 孩子 600 分物理类 → 推**西农大 农林国家专项**(分数低 30 分进 985) → 毕业进**陕西省农业科学院 / 西安各农业科技公司 / 中粮集团 西安公司** → 985 农林路径稳态
- **陕西榆林农村家庭(非煤老板)** → 孩子 580 分物理类 → 推**长安大学 公路工程 / 桥梁工程 + 国家专项** → **进中铁系统 / 中交系统 / 陕西交通建设集团 编制路径** → 农村男孩跨阶级稳态

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 陕西特有的 4 个家庭画像 deep dive

### 画像 A:西飞 / 西电集团 / 陕汽 工矿子弟家庭

- 父母:国防央企车间工人 / 中层管理 / 工程师
- 收入:中等(15-30w/家庭)
- 偏好:**国防工业稳态 + 子承父业**(父母厂子是国家队,孩子进同行业体面)
- **最优路径**:**西工大三航 / 西交大电气 / 西电通信 / 长大交通运输**(子承父业方向)+ 进父母厂子隔壁单位

### 画像 B:陕北能源富裕家庭(榆林煤老板 / 延安油气)

- 父母:陕北煤炭 / 油气产业从业 + 资源型生意
- 收入:高(50-300w/家庭,但波动大)
- 偏好:**孩子稳定 + 体面**(不想孩子继续赌资源价格)+ **不必跨阶级**(已经富裕)
- **最优路径**:**西交大医学部临床(8 年长周期撑得起) / 西交大管院(中国西部第一商科) / 陕师大公费师范汉语言(女儿稳定首选) / 出国留学**

### 画像 C:关中农村家庭(渭南 / 咸阳 / 宝鸡)

- 父母:农民 / 临时工
- 收入:低(< 10w/家庭)
- 偏好:**跨阶级 + 编制**(典型农村跨阶级心态)
- **最优路径**:**陕师大公费师范汉语言 / 数学师范(无学费 + 编制) + 国家专项 / 空军军医大学 / 西农大国家专项**

### 画像 D:陕南山区农村家庭(汉中 / 安康 / 商洛)

- 父母:山区农民 / 山区临时工
- 收入:极低(< 8w/家庭)
- 偏好:**跨阶级 + 100% 编制 + 父母完全放心**
- **最优路径**:**空军军医大学(无学费 + 包分配) / 陕师大公费师范 + 国家专项 / 西农大国家专项 / 长大公路桥梁国家专项**
