# 考公优选专业表(陕西本地视角)

## 核心结论

**专业决定考公选岗范围**。陕西家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**陕西特殊性**:
- **陕西考公环境** = **西部大开发岗位倾斜 + 国家公务员对陕西本省考生有定向计划 + 选调生主要走西交大 / 西工大 / 西电 / 西大 / 陕师大 / 西农大** + **陕西省考竞争比东南沿海宽松**(考生量 32 万,在大省中偏少)
- **陕西考生考公的隐藏王者路径** = **西部大开发选调 + 西电西交大军工央企校招(算半个体制内)** + **陕北榆林 / 延安 等市县基层公务员西部艰苦补贴**
- **军工央企招聘也有"准编制"属性** ─ 中航工业 / 航天科技 / 兵器集团 / 中船 705 所 在陕西扎堆,**虽然不是公务员但稳态等同于编制**

## 关键事实(2024 国考 / 陕西省考分析)

### 国考可报岗位数 排名(Top 10 大类)

1. **法学** ─ 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** ─ 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** ─ 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** ─ 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** ─ 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** ─ 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** ─ 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** ─ 审计局、纪委 → 约 3%
9. **医学相关** ─ 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** ─ 外交部、海关、商务部 → 约 2%

### 陕西省考特殊性

- **陕西省考 + 西安市考**,**汉语言文学和法学并列考公第一专业**
- **陕西各地市公务员岗位对法学要求高**(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)
- **陕北榆林 / 延安 + 陕南汉中 / 安康 / 商洛**:**艰苦边远地区基层公务员有补贴**(月 1000-3000 不等),**且报考人数少 = 竞争比西安咸阳宝鸡 低 1-2 个数量级**(陕西本地公考宝藏路径)

### 选调生(不是普通公务员,是高潜力路径)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(陕西本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- **陕西选调生主要供给**:**西交大 / 西工大 / 西电 / 西大 / 陕师大 / 西农大 / 西北政法 / 长安大学**
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、中国刑事警察学院、西北政法警官学院 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**陕西本地西北政法对口**(陕西本省法学顶配 211)
- **西北政法大学** ─ **陕西公检法系统主供给** + **西北法学唯一独立 211 + 政法部委直属传统**(虽然政法部委直属身份是过去时)

## 陕西本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业

- **西北大学法学** ─ 211 + 双一流 + 西大法学是陕西本省综合性大学法学最顶,**陕西公检法系统校友极多**
- **西北政法大学 法学 / 行政法学 / 监狱学 / 侦查学** ─ **陕西本省法学最顶配 + 西北法学唯一独立 211 + 政法部委直属传统**;**陕西公检法系统主供给**(法院 / 检察院 / 司法局 / 监狱 / 公安部门 校友覆盖度极高)
- **西安交通大学法学 / 经济学** ─ 985 + C9 + 选调路径最优
- **陕师大 汉语言文学 / 法学 / 马克思主义理论(全国前列)+ 公费师范生** ─ 陕师大马院是全国马列学科前列,**做党政干部首选**;**公费师范汉语言 = 等同于教师编制(对农村家庭等同于考公友好)**
- **西交大经济金融学院 / 西大经管学院** ─ 综合就业 + 考公双友好

### 双非 + 性价比考公专业

- **西安财经大学**(陕西本省财经类一本) ─ **陕西本省财经主供给** + 法学 / 经济 / 会计 / 财政 / 审计 都是 211 同档替代;**陕西考生进财政 / 税务 / 审计系统最对口**
- **陕西本省师范学院**(咸阳师范 / 渭南师范 / 宝鸡文理 / 安康学院 / 商洛学院 / 榆林学院) **汉语言文学 / 法学** ─ 二本中等,但**陕西本省考公认可度极高**,毕业考公成功率高(尤其本地 / 邻近地市)
- **西安外国语大学 中文 / 法学 / 国际经济与贸易** ─ 一本中段,**外语 + 复合背景** 在外交部 / 海关 / 商务部 国考有竞争力

### 公安系统专属

- **中国人民公安大学**(北京)、**中国刑事警察学院**(沈阳)─ 全国公安顶配 + 陕西考生定向计划
- **西北政法大学公安学院**(原西北政法警官学院)─ **陕西本地公安系统主供给** + 公安联考路径,**毕业进陕西本地公安概率极高**(基层警察 / 监狱警察 / 法院司法警察)
- **陕西警察学院** ─ **陕西本省公安专科 / 本科一体校**,**毕业进陕西本地基层公安(各地市县警察)主供给**(注意:陕西警察学院 ≠ 西北政法,前者是公安部 + 陕西省共建,后者是综合性政法大学)

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:**陕西汉中考生**,540 分文史类,**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报安康学院 / 渭南师范汉语言文学**,毕业当年考上陕西省直某机关公务员,**家庭命运改变**;**陕西本省二本汉语言 + 考公,是陕西农村女孩最稳的逆袭路径**
- **Case B(选调路径)**:**陕西西安考生**,650 分文史类,中产家庭。家长想报"金融"(西交大经金学院)。**改报西交大法学**,**毕业获得西交大选调生资格,直接进陕西省委组织部**,起点远超经济学就业
- **Case C(失败路径)**:**陕西宝鸡考生**,580 分理科,普通家庭男生。家长想"考公兜底"。**报了陕师大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:陕西家长以为"行政管理"是考公专业 ─ **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(陕北艰苦补贴红利)**:**陕西延安考生**,560 分文史类,普通工薪家庭。家长想去西安公考。**改报陕师大公费师范汉语言 + 回延安编制**(回原省) → 编制 + 艰苦补贴 + 陕北本地房子便宜 + 父母在身边 → **比西安公考竞争小且生活质量高**;**陕北 / 陕南 艰苦补贴是陕西考公最被低估的红利**
- **Case F(西北政法宝藏)**:**陕西渭南考生**,580 分文史类,普通家庭男生。家长本想报"法学"(西交大 / 西大,够不上)。**改报西北政法大学法学 + 法考 + 公考** → **毕业进陕西渭南法院 / 检察院 / 司法局** → **西北政法在陕西公检法系统的认可度 = 西大法学 / 西交大法学 同档**(因为西北政法毕业生在陕西公检法系统占比极高)
- **Case G(陕北能源家庭红利)**:**陕西榆林考生**,**陕北能源富裕家庭**,女孩 615 分文史类。家长想"稳定 + 体面"。**强推陕师大公费师范汉语言 → 回榆林市区高中编制** → 家长完全满意 + 孩子工作稳态 + 家庭财富与孩子职业互补;**陕北能源家庭女儿读公费师范 是陕西特有的"显学"**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" ─ 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" ─ 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(陕西 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" ─ 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" ─ 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" ─ 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" ─ 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" ─ 严重错误。**这是陕西家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**西北政法不是 985,不如出省 985 法学**" ─ 严重错误。**西北政法在陕西公检法系统的认可度 = 五院四系一档**(虽然全国排名不如人大法 / 武大法,但**陕西本地考公优势远超出省 985 弱专业**);**陕西本地考公就推西北政法**
- "**艰苦边远地区不要去**" ─ 错。**陕北 / 陕南 艰苦补贴 + 竞争小 + 本地生活成本低** = **陕西本地公考最被低估的宝藏路径**;**陕西籍学生回原市县基层公务员是最稳的"零风险逆袭"**

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是陕西家长被严重低估的考公王者**。

**陕西特有的 3 个隐藏路径**:
1. **西北政法法学 + 陕西公检法系统校招** ─ 比出省 985 弱法学优 3 倍
2. **陕师大公费师范 + 编制(等同于考公)** ─ 农村 + 工薪家庭神器
3. **陕北 / 陕南 艰苦边远基层公务员 + 艰苦补贴** ─ 竞争小 + 上岸快 + 本地房子便宜
