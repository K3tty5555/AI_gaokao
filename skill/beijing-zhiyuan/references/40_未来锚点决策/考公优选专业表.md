# 考公优选专业表(北京视角)

## 核心结论

**专业决定考公选岗范围**。北京家长的"考公"跟外省家长的"考公"不是一回事 — **北京家庭考公的最优出口是部委 / 中央办公厅 / 国务院系统 / 央企总部 / 北京市直机关**,**这是全国体制金字塔最顶,起点远超外省省考**。**有些专业能报的部委岗位是其他专业的 5-10 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"部委可报岗位多 + 选调路径直"展开**,而不是看专业本身的"高大上"程度。

**北京独有红利**:
- **国考北京岗位 = 全国部委岗位**,数量是其他省的 3-5 倍
- **985 选调直进部委 / 央企总部** 是清北人法北师等 5-7 所北京顶配 985/211 独有路径
- **京考(北京市考)+ 京籍户口** 是只有北京考生能直接享受的"性价比高地"

## 关键事实(2024 国考 / 京考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委、最高法、最高检、司法部、各部委法务司 → 约 18-20% 岗位
2. **财政学 / 经济学 / 会计学** — 财政部、税务总局、海关总署、银保监、央行、各部委财务司 → 约 15-18%
3. **汉语言文学 / 中文 / 新闻** — 中宣部、国务院新闻办、各部委综合岗 / 政研室 / 办公厅 / 宣传司 → 约 13-18%(**北京岗位中占比尤高**)
4. **计算机 / 软件工程 / 信息安全** — 网信办、各部委信息中心、国家计算机中心 → 约 10-12%
5. **统计学 / 经济统计** — 国家统计局、央行调统司、税务总局 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(**实际不如"汉语言"好**)
7. **马克思主义理论 / 思想政治教育** — 党群岗、中组部、中宣部 → 约 4%
8. **审计学 / 监察** — 审计署、纪委监委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语 / 阿拉伯语 等)** — 外交部、海关、商务部、各部委国际司 → 约 2-3%(**北京岗位中外交部占比突出**)

### 北京京考(北京市公务员考试)特殊性
- **北京市直 / 各区岗位**,北京户籍优先(部分岗位仅限北京户籍)
- **京考时间一般早于国考**(11 月底京考 / 12 月初国考),**京籍考生可以"京考 + 国考双线申请"**
- **汉语言文学和法学并列京考第一专业**
- 北京各区公务员岗位**对法学、汉语言、行政管理要求高**(法院、检察院、司法局、街道办、宣传部门)
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1500+ 比 1)

### 中央选调生(部委选调) — 北京独有最强路径
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **中央选调专门定向从清北人法北师 + 几所外地顶级 985 招生**(北京籍考生在这几所学校报选调成功率全国最高)
- **985/211 才有资格报**(中央定向选调对学校列表卡得严)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学、政治学**
- **直接进部委 / 中央办公厅 / 国务院办公厅 = 北京家庭体制内顶级跃迁路径**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学 / 中国刑警学院 / 北京警察学院)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **最高法 / 最高检**:**公开招录少 + 走选调或调任**,对学校层次要求极高(清北人 / 法大基本是必须)
- **监狱、戒毒**:法学 + 监狱学,中央司法警官学院主供应 + 法大对口

### 央企总部 / 国资系统 — 北京独有补充路径
- **国资委 / 国家电网 / 国电投 / 华能 / 中石油 / 中石化 / 中国移动 / 中国联通 / 国铁集团 / 中航 / 航天科工**:**总部全在北京** = 北京家庭"准体制内"补充路径
- 招聘对口专业:**经济管理 / 财务 / 法学 / 工程对口 / 计算机** 等
- **北京家长把"进央企总部"和"考公"等同对待** — 福利 / 编制 / 户口 几乎一致

## 北京本地院校 × 专业组合(考公视角)

### 985/211 + 中央部委选调路径(顶级)
- **北京大学法学** — **全国第 1**,**部委选调 + 最高检 / 司法部 / 各部委法务 + 红圈所合伙人** 通吃
- **中国人民大学法学 / 财政金融 / 公共管理** — **全国前 3** 文科,**部委选调最直接路径**(人大法 / 人大财政 / 人大公管 在中央选调比例全国最高)
- **中国政法大学法学 / 公安专业** — **全国法学顶配 211**,**法院 / 检察院 / 司法部对口最直**
- **中央财经大学财政 / 税收 / 会计** — **211**,**财政部 / 税务总局 / 央行 / 银保监 选调最直**
- **对外经济贸易大学(经贸)金融 / 国际法 / 国贸** — **211**,**商务部 / 海关总署 / 银保监对口**
- **北京师范大学汉语言 / 教育 / 哲学 / 历史 / 心理** — 985,**部委综合岗 / 中宣部 / 教育部 选调最直**
- **北京外国语大学 英语 / 阿拉伯语 / 日语 / 各小语种** — 211,**外交部 / 国安 / 商务部驻外岗 顶配路径**

### 双非 + 京考性价比专业
- **首都师范大学汉语言文学 / 公费师范** — 北京市属一本,**京考稳定路径 + 北京中学编制**
- **首都经济贸易大学经济 / 财政 / 会计** — 北京市属一本,**京考北京财政 / 税务系统对口**
- **北京建筑大学行政管理 / 城乡规划** — 北京市属一本,**北京住建系统 / 街道办对口**

### 公安 / 国安系统专属
- **中国人民公安大学** — **全国第 1 公安院校**,**公安联考路径**,**毕业进中央公安 / 北京公安概率极高**
- **中国刑事警察学院** — 公安部直属,**走刑警 / 国安路径**
- **北京警察学院** — 北京市属警校,**毕业进北京公安各分局** + 北京户口
- **中国政法大学侦查学 / 监狱学** — 进司法系统

## 典型 case(供 agent 引用)

- **Case A(部委逆袭)**:北京西城工薪家庭,综合 5500 名 → **北师大文学院汉语言文学** → 毕业当年考上中央部委某司局综合岗,**家庭路径完美匹配**
- **Case B(中央选调路径)**:北京海淀牛娃,综合 1500 名,中产家庭 → 父母想报"金融"(北大光华)。**改报北京大学法学院**,**毕业获得北大中央选调生资格,直接进司法部**,起点远超经济学就业
- **Case C(京考路径)**:北京朝阳工薪家庭,综合 7500 名 → **首都师范大学汉语言文学** → 毕业考京考朝阳区某街道办综合岗 → **京考一次成功 + 北京户口**
- **Case D(失败路径)**:北京海淀工薪家庭,综合 6000 名 → 家长想"考公兜底"。**报了北航计算机**(以为计算机考公也行)。**毕业考公发现:计算机岗位虽有但比汉语言少,且竞争对手都是 985 CS 名校 + 大厂经验**,2 年没考上,**改行当程序员但因北京 CS 校招卷 + 学校虽 985 但专业不顶,薪资也不算高,两头不靠**
- **Case E(误区路径)**:北京家长以为"行政管理"是考公专业 — **半错**。**人大行政管理是部委选调真路径**,但**首经贸 / 北建大 等双非的行政管理 不如双非的汉语言** 考公出路宽

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 半错。**人大公管是部委选调真路径,双非公管没用**;**汉语言、法学的考公优势远超双非公管**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(北京 3+3 制度允许选考组合灵活,理科生也可报多数大学的汉语言)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对北大 / 人大 / 法大 / 央财 / 北师 等北京顶配 985/211 学生而言**,中央选调生比国考省考好考
- "**汉语言文学就是当老师**" — **严重错误**。**汉语言文学是部委选调 + 央媒 + 国考王者**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**中央选调跟普通公务员一样**" — 错。**中央选调 = 直接进部委 / 中央办公厅 / 国务院办公厅 = 全国体制金字塔最顶**,起点比普通公务员高 5-10 年

## 关键提醒

**北京家庭考公的最优出口 = 部委 / 央企总部 / 北京市直机关 = 全国体制金字塔最顶**。如果家庭已经倾向考公,**专业选择必须围绕"部委可报岗位多 + 中央选调路径直"两个维度**,而不是表面的"专业高大上"。**汉语言文学 / 法学 / 财政经济 是北京家庭考公王者三件套**。

**京籍 + 985/211 + 文科 + 选调 = 北京家庭最高 ROI 体制路径,完爆任何"考公兜底"思路**。
