# 北京 3+3 高考政策(本地化必读)

## 一、改革时间线

- **2017 年**:北京启动新高考改革,**第二批改革省份**(同天津/山东/海南),不同于上海浙江(2014 第一批)
- **2020 年**:**首届"3+3"高考落地**(2017 入学的高一学生于 2020 年高考)
- **2021 年起**:本科批合并(本科普通批 + 特殊类型招生控制线),不再分一本二本
- 体系自 2020 起稳定运行,与江苏湖北的 3+1+2 截然不同

## 二、3+3 体系核心

**总分 = 语数外(150 × 3) + 选考 3 科(各 100 × 3) = 750 分**

### 必考 3 科(语数外)
- 语文 150,数学 150,英语 150
- 全部计原始分,不赋分
- 英语含听力 30 分(机考,2 次取最高)

### 选考 3 科(6 选 3,各 100 分,**赋分制**)
6 个科目任选 3 个组合:**物理 / 化学 / 生物 / 政治 / 历史 / 地理**

**共 20 种组合**(C(6,3) = 20),不分文理科。

#### 选考赋分规则(关键!)
- 卷面分先按全市排名分等级
- 5 个等级(A/B/C/D/E)→ 进一步细分 21 个赋分档
- 等级与赋分对照(简化):
  - 前 1% 赋 100;前 2% 赋 97;前 3% 赋 94;...
  - 最低 2% 赋 40
- **结果**:你最终拿到的"选考分"是赋分,**不是原始分**;但这分会算入 750 总分

### 选科与专业关联
教育部要求高校公布专业选科要求(3 类):
- **必选 X**:如医学多要求"化学+生物"必选,工科要求"物理"必选
- **3 选 1**:如某专业要求"物理 / 化学 / 生物 任选一"
- **不限**:文科类专业大多不限

**北京考生选科主流**:
- 物化生(纯理):覆盖率高,医学/工科/理科全开放,但卷
- 物化政(理 + 政):**京籍体制内/央企部委家庭强烈推荐**(物理覆盖工科 + 政治考公友好)
- 物化地:理科覆盖 + 地理稳分(地理是赋分友好科)
- 史政地(纯文):限报多,主要走文学/法学/经济(限选历史的专业偏少,2024 起多数法学不再限选历史)
- 物生政:**医学路径里的考公组合**(适合预备走医学院公共卫生 / 卫生事业管理)

## 三、志愿录取规则

### 北京本科批(2021 起合并)
- **本科普通批 + 特殊类型招生控制线**(原一本线概念,作为强基/综评/高校专项的资格门槛)
- 本科普通批:**30 个院校专业组**(平行志愿)
- 每个专业组下若干专业,组内服从调剂

### 提前批
- 军校 / 国防生 / 公费师范 / 公费医学 / 港校 / 香港中文大学(深圳)/ 部分艺术类
- 提前批不影响普通批

### 平行志愿规则
- 30 志愿"分数优先,遵循志愿,一次投档"
- **服从调剂**:被某专业组提档后,组内任何专业可被调剂到;不服从可能被退档,后续志愿全部失效
- 北京专业组细分:同一所大学可以有 5-15 个不同的专业组,每个组对应不同选科要求

## 四、北京最大特殊性(必懂!)

### A. 8 所 985 + 26 所 211 = 全国最多
北京拥有的 985 数量全国第一,远超第二名上海(4 所)/南京(2 所)/武汉(2 所):

**8 所 985**:
1. **清华大学**(C9 + Top 1 工科)
2. **北京大学**(C9 + Top 1 综合)
3. **中国人民大学**(综合人文社科顶级)
4. **北京师范大学**(师范 + 教育心理顶级)
5. **北京航空航天大学**(国防七子 + 航空航天)
6. **北京理工大学**(国防七子 + 兵器)
7. **中国农业大学**(农林顶级)
8. **中央民族大学**(民族学顶级)

外加**国防科技大学北京分校(信息通信、装备研究所)**等。

**26 所 211**(摘要):中央财经大学 / 对外经济贸易大学 / 中国政法大学 / 北京邮电大学 / 北京交通大学 / 北京科技大学 / 北京化工大学 / 中国传媒大学 / 北京林业大学 / 中央音乐学院 / 中央戏剧学院 / 中国地质大学(北京) / 中国矿业大学(北京) / 中国石油大学(北京) / 华北电力大学 / 中国人民公安大学 等。

**结果**:北京考生本市可报的 985+211 名校,数量是其他省份不可想象的。

### B. 京籍 vs 非京籍(关键差异!)
- **京籍考生**:享受北京户籍政策,本市录取分数线相对友好
- **非京籍 / 随迁子女考生**:
  - 想在北京高考需满足"九类人"或随迁子女政策(父母社保 / 居住证 / 学籍连续年限等硬要求)
  - **录取时按非京籍考生录取,分数线极高**(部分院校非京籍线比京籍高 30-80 分)
  - 实际操作中很多非京籍家长选择回原籍高考(因为分数线相对友好,但考试内容差异需备考)
- agent 必须在 L2 阶段问清楚 京籍/非京籍,这直接决定推荐策略

### C. 留京 ROI 极高(全国第一)
**北京考生留京率 90%+**,数据全国最高,原因:
1. **本市 8+26 所名校** → 优质校招市场就在家门口
2. **北京户口稀缺** → 在京读 985/211 → 本科或研究生留京有部分应届生落户名额
3. **央企部委密度** → 国资委央企总部 90%+ 在京 / 部委所在地 / 电网总部 / 国铁总部 / 国家电投 / 中石油中石化总部
4. **互联网大厂总部** → 字节 / 百度 / 美团 / 京东 / 快手 / 小米 / 滴滴 等总部都在北京
5. **教育资源** → 子女上学难度小(对比沪/深京广)
6. **医疗资源** → 协和 / 301 等顶级医院

### D. 强基 / 综评 / 三大学科竞赛保送
- 北京顶尖中学(人大附中 / 四中 / 十一学校 / 北师大附属实验)**竞赛资源全国最强**
- 数学/物理/化学/生物/信息学五大学科奥赛 → 强基计划友好
- 清北强基计划在京名额相对宽松(清北综合考虑生源地)
- 综合评价:北外 / 北外苏州 / 北航等部分专业有综评通道

### E. 北京考生约 5w/年
- **报名人数约 5-6 万**(全国最低梯队之一,与上海/天津持平)
- 但**985 录取率 ~14%、211 录取率 ~25%**(全国第一)
- 也就是说:**每 7 个北京考生就有 1 个上 985,每 4 个有 1 个上 211**(对比河南是 1.7% 和 4%)

## 五、选科建议(决策矩阵)

| 家庭+目标 | 推荐选科 | 理由 |
|---|---|---|
| 京籍体制内/央企家庭 + 想留京 | **物化政** | 物理覆盖工科主流 + 政治考公友好 |
| 想冲清北 + 理科底子强 | **物化生** | 清北强基/数院/物院/化院/生科 全开放 |
| 想学医(临床/口腔) | **物化生 / 物化政** | 医学要求"化学+生物"必选 |
| 想考公/法学/经济 | **物化政 / 史政地** | 政治+地理是文科赋分友好科 |
| 理科一般 + 想稳分 | **物化地 / 物生地** | 地理是赋分洼地,易拿高赋分 |
| 文科强 + 想冲人大/北师 | **史政地 / 政地+生** | 史政地是文科主流组合 |
| 不喜欢物理但想学工科 | **不推荐** | 北京 90% 工科要求"物理必选" |

## 六、志愿填报技巧(北京特色)

1. **本科批 30 个志愿用满,不要少填**:平行志愿次序对录取无负面影响,多填多机会
2. **冲档要服从调剂**:北京名校多,但好专业争抢激烈,不服从调剂被退档=下个志愿全废
3. **看清专业组选科要求**:同一所大学可能有 5-15 个不同选科要求的专业组
4. **关注"特殊类型招生控制线"**:这是强基 / 高校专项 / 综评的资格门槛,相当于过去的"一本线"
5. **京籍优势用足**:同分数下,北京院校优先选本市 211 > 外省 985(留京率高 + 校招方便)
6. **非京籍考生**:慎重评估"留京 vs 回原籍"决策(分数线、户籍、考试内容三方面平衡)

## 七、agent 在北京 case 中需特别注意

1. **L1 必问选考组合**:6 选 3 共 20 种,问清后才能匹配选科要求
2. **L2 必问京籍/非京籍**:这是北京独有维度,影响推荐分数线判断
3. **赋分制提醒**:用户给"模考分"时要确认"赋分后还是原始分",否则总分预测会偏差大
4. **强基/综评/竞赛保送**:顶级中学考生(人大附中 / 四中 / 十一学校 等)L2 应额外问"是否有竞赛背景 / 是否走强基 / 是否准备综评",这能改变推荐路径
5. **留京 vs 出京**:北京考生留京 ROI 全国最高,出京一定要有"专业 > 城市"的强理由(如清北已不可达 → 复旦/交大上海;或西安交大/哈工大特殊学科)
