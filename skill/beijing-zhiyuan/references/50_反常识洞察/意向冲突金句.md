# 用户意向冲突 — Reality Check 金句库(北京视角)

很多家长 / 考生有具体的意向("非清北不去"、"必须留京"、"想学医"、"想考公进部委"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是**北京家庭独有意向冲突**的金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 1500 位次以上,**不要绕弯子**。北京家长信息差小,听得懂客观判断,不喜欢"绕弯子的安慰话"
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(经典核心观点)
5. **京籍家庭别被"非清北不去"绑架** — **北京有 8 所 985 + 26 所 211**,**非清北一档下来还有北航 / 北理 / 北邮 / 央财 / 法大 / 北外 / 北师 / 中传 等"二线顶配"**,选错路径的代价无法弥补
6. **非京籍随迁子女别被"必须留京"绑架** — **北京户口 + 留京就业有"应届生落户名额 + 985/211 大厂校招"两条硬路径**,但失败成本极高,要算清楚 ROI

---

## 5 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2000 名(北京)

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如综合 5000 名要清北 / 综合 12000 名要北航 CS)。

**金句模板**:
> "你说想上 [意向校,如清华],客观说就是**不可能** — 北京 3+3 综合,这分数到清华 [意向组] 差 [X] 千名。
>
> 但同档你能上 [替代校 1,如北航 / 北理] / [替代校 2,如北邮 / 央财],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大,**北京家庭就业市场更看你毕业进哪个单位,不是学校 logo**。"

**真实案例(北京 600 分,意向清华)**:
> "清华工科主流组在北京综合 600 名内,理科主流前 800 名,文科前 1500 名。你 4500 名,**清华没戏**。
>
> 但你能上北航 / 北理 / 央财 / 法大 / 人大主流 — 这五所留京就业,**部委 / 央企总部 / 大厂校招里跟清华冷门组校友地位差不多**(都是'北京 985/211 + 留京同档')。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**经典反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学 / 农林]**。
>
> 你父母可能觉得'清北就是清北',但 **清北的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(海淀牛娃 + 综合 1200,清华擦边)**:
> "清华你 1200 名擦得上 — 但只能进**化工 / 材料 / 工业工程 / 工程力学** 这一档。**清华牌子 + 生化环材** = 5 年后毕业的同学 80% 出国读 PhD 或转码,真要走"工科直接就业"反而不如北航 CS / 北邮通信。
>
> 同分能上的**北航计算机 / 北邮计算机 / 人大法学 / 央财金融** = 985 / 211 主流组 + 北京就业顶配,**对父母期待和真实就业来说,这条路更实在**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 北京房贷压力大,**撑不起 5+3+11 / 30 岁前不挣钱 + 北京房贷**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N + 北京三甲博士门槛] 才能稳定就业,**北京普通家庭撑不起 30 岁前不挣钱 + 北京房贷压力**。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华协和八年制 / 北医八年制])
> - 撑不起 → 走 **[替代短路径]**(如 [首医医学影像技术 / 检验技术 — 4 年本科 + 北京三甲技术岗 + 北京户口 + 编制]),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(北京普通家庭 + 想学医)**:
> "学医本质是 11 年起步:5 年临床本科 + 3 年规培 + 3 年读博,**期间月薪 6-9k + 北京房贷**。北京普通工薪父母还要供 11 年。
>
> 撑得起 → 推清华协和 / 北医八年制,长期天花板高。
>
> 撑不起 → **建议首医医学影像技术 / 检验技术 / 护理 = 4 年本科 + 北京三甲技术岗 + 北京户口 + 编制 + 起薪 8-12w**,或者放弃医学走 CS / 央财金融 这种本科直接挣钱的赛道。"

---

### 模式 D:意向城市 vs 院校层次 — "非北京不去"

**特征**:用户只想留北京("非北京不去"),拒绝出省 985。**北京家庭这个意向最强烈**,海淀 / 西城牛娃尤甚。

**金句模板**:
> "你只想留北京,那同档要在 [北京 211 / 二线 985] 和 [外省 + 985 弱专业] 之间选。
>
> **留北京 211 反而更稳** —
> - 北京校友网密度全国最大,部委 / 央企总部 / 大厂招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回北京没竞争力**
> - 留北京你父母也安心 + 北京户口已有 / 应届生落户路径稳
>
> 但!如果你想做的方向北京没强校(如想学航天最强 → 西工大,不去北京;想学船舶最强 → 上交 / 哈工程,不去北京),**要灵活退一步 — 因为这些方向北京家庭也广泛接受出京**。"

**真实案例(京籍 + 法学方向 + 5500 名)**:
> "你只留北京,这位次 5500,人大法学 / 法大法学顶级组够不上。
>
> **留京最稳路径**:**首都师大法学 / 北京工商大学法学 / 北京物资学院法学(市属一本)+ 父母资源 + 法考 → 进北京基层法院 / 检察院 + 律所合伙人路径仍然能走**。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**北京人脉断了 / 实习机会少了 / 应届生落户名额没了**,综合不划算。"

---

### 模式 E:京籍 vs 非京籍 — "应届生落户名额"权衡

**特征**:**北京独有意向冲突** — 非京籍随迁子女家庭"必须留京 + 拿北京户口",但需要在"留京 985/211 + 应届生落户名额" 和 "回原籍考 985 + 不留京"之间权衡。

**金句模板**:
> "你是非京籍随迁子女,父母在京 [N] 年,这次能在京高考。但你要清楚:**留京和拿北京户口是两件事**。
>
> - **留京读 985/211 + 北京户口 = 应届生落户名额**(北邮 / 北航 / 首师 / 首医 等院校的部分专业,毕业进央企 / 大厂 / 部委有少数应届生落户名额)— 不是 100% 拿北京户口,看专业 + 用人单位
> - **回原籍考 985 + 在外省工作 = 不留京 + 老家户口** — 但分数门槛低 + 985 牌子可能更硬
> - **回原籍考 985 + 北京就业 + 工作落户北京 = 应届生落户名额(取决于学校 + 专业 + 用人单位)**
>
> 你父母对'留京拿北京户口'的执念多重?
> - 必须留京 + 拿北京户口 → **首师公费师范汉语言 / 首医医学技术 / 华电电气** = 北京户口 + 编制最稳路径
> - 留京但户口不强求 → **北邮 / 北航 / 北科 等北京 985/211 + 大厂校招** = 60-70% 概率拿北京户口
> - 户口不强求 → 回原籍考更高的 985 + 看就业地决定"

**真实案例(非京籍随迁 + 综合 6500 + 想留京)**:
> "你父母在京 8 年,户口在原籍。这位次 6500,**首师大公费师范汉语言 = 北京中学编制 + 户口** 是最稳路径。
>
> 北京邮电大学 / 北京建筑大学 也能上,**但应届生落户北京要看用人单位指标 + 不 100% 给** — 风险中等。
>
> 如果家庭执念是'必须 985 牌子',回原籍走河北 / 山东 985 路径,这分数能上更好的 985,但**留京变难**。给你父母看下这两条路,让他们权衡。"

## Agent 处理意向的 5 步(北京加强版)

收到 L4.5 意向锚点后,**强制做这 5 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **京籍 / 非京籍状态修饰** — 非京籍意向"必须留京"必须额外算"应届生落户名额"权衡
4. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
5. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 北京家长信息差小,听不懂等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **忽略京籍 / 非京籍维度** — 北京独有,**漏问 = agent 漏维度 = 推荐质量差**

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### 北京独有的双轨示例

**意向:必须留京 + 综合 4500 名**

```
轨道 1(贴近意向 - 留京):
  - 北邮 计算机 → 留京 + 大厂校招应届生落户
  - 北航 软件学院 → 留京 + 央企总部 / 大厂
  - 央财 财政学 → 留京 + 部委选调 / 央企总部

轨道 2(放弃留京但客观更优 - 出京 985 主流):
  - 上交 / 浙大 / 复旦 主流组 → 学校牌子比北京 211 硬 + 出京就业空间大
  - 但意向是"留京",所以这条不是首选
```

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 清华 / 想学医 / 必须留京 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。**北京独有维度:京籍 / 非京籍 + 留京户口 必须算清楚**。
