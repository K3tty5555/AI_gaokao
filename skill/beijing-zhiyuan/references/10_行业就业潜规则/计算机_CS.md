# 计算机科学与技术 / 软件工程(CS / SE)— 北京视角

## 一句话总结

**北京是全国 CS 红利最浓 + 学校最多 + 大厂最密集的城市,但也是分化最狠的城市**。京籍考生有"本市 985/211 + 留京户口 + 大厂总部就在隔壁"三重 buff,**但北京双非二本 CS 在大厂校招里跟外省双非一样进不了筛选系统**。**所有"清北人航邮"档以下的 CS,本质要靠学历 + 实习 + 项目"三件套"硬刚,京籍身份在校招里值不了几分**。

---

## 真相 1:寒冬阶段性,但分化结构性 — 北京尤其明显

- 2022-2024 大厂裁员潮,字节 / 美团 / 百度 / 滴滴 / 京东应届 offer 数量比 2021 峰值少 30-40%
- **但是北京头部学校 CS 起薪反而拉到 40-60w**(2024 字节算法 SP / 拼多多多多 / 华为天才少年 北京岗),原因是大厂在"砍量保头部"
- 双非 CS 北京毕业起薪从 2020 年 18-22w 掉到 2024 年 10-13w,**与外省双非趋同**
- 行业总需求(AI / 大模型 / 芯片 / 云)还在,**但"北京大厂校招简历筛选系统"对学校列表卡得越来越死**:清北人航邮+ C9 + Top10 海外 = 第一档,其余基本简历石沉大海

**结论**:**学校决定一切,北京户口救不了双非 CS**。

---

## 真相 2:35 岁危机存在,但北京顶级岗位例外

- 业务型程序员(增删改查 / 写小程序 / 调用第三方 API)35 岁危机最严重 — **北京中厂裁员潮里这类人最先走**
- **核心岗(算法 / 系统 / 底层 / 编译器 / 芯片 / 大模型预训练)35 岁是黄金期** — 字节 / 阿里 / 百度 / 蔚来 / 小米的 P8/P9 大量是 35-42 岁
- 区别:你是"会写代码的人"还是"懂技术的人"
- **北京的大模型创业潮**(智谱 / 月之暗面 / Minimax / 百川 等)进一步把"懂技术"和"写代码"分层 — 头部岗位起薪 80-150w,普通岗位被进一步压价

**结论**:目标核心岗,本科起就要扎数学 / 算法 / 底层基础。**北京清北人航邮 + 带强项目 = 35 岁前进核心岗有戏**。双非 + 业务岗 = 35 岁后大概率被裁去外包或地方分公司。

---

## 真相 3:本科 < 硕士的差距越来越明显 — 北京推研路径独特

- 5 年前 985 本科 CS 直接拿 SP offer 的时代已过
- 现在大厂校招"硕士起步"是常态,**北京尤其严格**(因为简历池太大,直接用学历筛)
- **但是北京 985 推免去美国 / 港校 + 清北本校直博通道异常顺畅** — 比外省 985 友好太多
- **如果你本科只是普通 985/211(如北科大 / 北邮 / 北交大 / 北化工 这档)的 CS,本科就要明确读研规划**:
  - 推免到清北人航 → 大厂 SP
  - 推免到本校 → 大厂普通档 offer
  - 出国留学(港三 / NUS / NTU / 美 Top30)→ 大厂海归档
  - 不读研直接就业 → **大厂校招簿弱,只能去中厂或外包**

---

## 真相 4:转码内卷已到顶 — 北京最严重

- 2018-2022 北京培训班(传智 / 北大青鸟 / 黑马程序员 等)鼎盛时期年输出 5-8 万转码人,**这个窗口已基本关闭**
- 现在大厂校招 + 社招都强调"科班出身"+"系统课程",**非科班想进大厂越来越难**
- 北京独特现象:**很多金融 / 法学 / 文科生想转码进字节 / 美团**,2024 年这条路已基本走死,**除非你是清北 / 复交背景才有破例机会**
- 想吃 CS 红利,本科就该选 CS

## 适合什么人

- **数学好**(高中数学 130+,北京海淀牛娃数学普遍 140+,这是隐性硬指标)
- **抗压能力强 + 不怕加班**(北京大厂 9-9-6 是默认,996 是常态)
- **有自学能力**(北邮 / 北航 课程跟不上行业,自学是必修)
- **京籍 + 海淀 / 西城 顶级中学 + 数学物理底子硬** → 闭眼报清北人航邮 CS
- **京籍中产以上 + 能撑读研 + 出国** → 北京 985/211 CS + 推免 / 留学
- **非京籍能在京高考的 + 海淀名校 + 学习能力强** → 同京籍中产路径

## 不适合什么人

- **数学差**(高中数学 110 以下,北京 110 以下基本是末流)
- **追求安稳 + 不想 996** → 北京 CS 不是养老行业,**改报央财金融 / 法大法学 / 北外英语考公**
- **京籍但中产以下家庭 + 双非二本 CS** → 这个组合在北京是"假 CS 红利",**改报北邮通信 / 北科大材料 / 北工大软件 都比双非 CS 强**
- **女生 + 讨厌技术钻研只想图高薪** → 北京 CS 行业对女性的隐性歧视客观存在,中厂尤甚
- **海淀 / 西城牛娃但只想留京体制内** → 闭眼报人大法学 / 央财财政 / 北师大,**别浪费 CS 学位去考公**

## 北京本地 CS 院校真实分层(2024 实况)

### 第一梯队(全国 + 北京双顶配,大厂校招"白名单")
- **清华大学 计算机系 / 交叉信息院(姚班 / 智班)** — 全国第 1 计算机,**姚班 / 智班 = 清华金字塔顶端**,毕业普遍直博 / 硅谷 / 量化 / 大模型核心岗,起薪 80-150w 不奇怪
- **北京大学 信息科学技术学院 / 元培理科** — 全国前 5 计算机,理论 + 系统都强,**元培书院 + 计算机方向是性价比之选**
- **北京航空航天大学 计算机学院 / 软件学院** — 国防七子 + CS 全国前 10,**北航 CS 是大厂校招白名单核心成员**(华为 / 字节 / 美团 / 拼多多都重点收)
- **北京邮电大学 计算机 / 软件工程 / 信息安全** — 211 但 **CS 校招认可度直追 985**,北京 IT 圈最早的"清北邮"校友网,字节 / 百度 / 网易等中层管理大量北邮校友

### 第二梯队(北京次顶配,大厂校招正常档)
- **中国人民大学 信息学院** — 985 + 文科牌子, **CS 不是人大主战场**,但人大 CS 配人大金融 / 经济交叉 = 量化 / 金融科技独特优势
- **北京理工大学 计算机学院** — 国防七子 + 985,CS 偏军工方向,**互联网大厂收但不优先**,军工方向(航天 / 兵器系统)反而吃香
- **北京师范大学 信息科学** — 985 牌子但 CS 不是主战场,**毕业去教育科技 / 字节教育 / 学而思编程** 比互联网核心强
- **北京科技大学 计算机** — 211,北京钢铁大学传统强项是材料 / 冶金,**CS 算"借 985 体系" 的次优选择**
- **中央财经大学 信息学院 / 信息管理** — 211 财经,**金融科技方向是唯一亮点**,纯 CS 不如北邮北航

### 第三梯队(北京本地认可,大厂校招吃力)
- **北京交通大学 计算机** — 211,通信 / 交通信息系统强,**直接进大厂校招比北邮吃力一档**,但中铁 / 国铁信息部对口
- **北京工业大学 计算机** — 北京市属 211,**留京中厂 / 北京国企 / 北京市政信息部门是优势**
- **首都经济贸易大学 信息学院** — 北京市属一本,**留京财经 / 国企信息岗有渠道**
- **中国地质大学(北京) / 中国矿业大学(北京) / 中国石油大学(北京) 计算机** — 211 行业校,**但 CS 不是行业校强项**,行业内信息岗有定向但互联网大厂收得少

### 第四梯队(避坑)
- **北京联合大学 / 北京物资学院 / 北京石油化工学院 / 北方工业大学 等北京二本 CS** — **京籍考生分够 985/211 别选这一档**,**双非二本 CS 在北京大厂校招里跟外省双非完全一样,简历过不了筛选**
- **民办本科 / 独立学院 CS(如北京工商大学嘉华学院 / 首都师大科德学院 等)** — **直接避坑**,这一档不如学护理 / 师范 / 会计有明确出路

## 典型 case(供 agent 引用)

### Case A:清华姚班男生(海淀牛娃)
- 人大附中竞赛保送 → 清华姚班 → 直博清华 / Stanford → 字节大模型核心岗 → 起薪 100w+
- **金字塔顶 1%**,海淀牛娃 + 顶级路径,普通家庭复制不来

### Case B:北邮 CS 女生(西城中产京籍)
- 北京四中 → 北邮 CS → 实习字节 → 校招拿百度算法岗 35w → 留京字节落户应届生通道
- **京籍中产标准路径**,**北邮 CS 是北京 IT 圈的"性价比天花板"**(分数比清北人航低,但 IT 圈认可度顶配)

### Case C:北工大 CS 男生(普通京籍家庭)
- 海淀某普通中学 → 北工大 CS → 校招进北京某中厂 月薪 1.5w
- **没有逆袭**,留京但起薪跟外省 985 CS 同档,**北京户口 + 父母在京 = 心理稳但财务上跟同档外省人差不多**

### Case D:京籍二本 CS 女生(海淀工薪家庭)
- 海淀某普通中学 → 北京某二本独立学院 CS → 找不到对口 IT 工作 → 转行做培训机构销售
- **典型踩坑**:家长以为"在北京学 CS 就有大厂 offer",**学校层次决定一切,京籍身份在校招里没用**

### Case E:非京籍学籍京考(随迁子女)
- 父母在京务工满 6 年 + 子女在京读初高中 → 非京籍京考 → 北邮 CS → 校招大厂 → **应届生留京户口名额(北京公司给 985/211 应届生有限户口指标)** → 5 年内拿到北京户口
- **北京 CS 对非京籍家庭的最大价值不在分数,而在"留京户口指标"** — 北邮 / 北航 CS 应届生在京大厂落户成功率高

## 给北京家长的金句

> "**'计算机一定好就业'是 5 年前的认知**。今天的真相是:**清华北邮北航 CS 闭眼有大厂,北京双非 CS 跟外省双非一样进不了字节简历池**。"

> "**你住在海淀,大厂总部走路 20 分钟到 — 但是你的简历得先过得了人事筛选系统**。北京户口在 HR 面前值不了 1 分,学校列表才值 100 分。"

> "海淀家长最爱踩的坑是 — 觉得'北工大 CS 跟北航 CS 都在北京差不多'。**这两所毕业起薪差 2-3 倍,北航出大厂总监,北工大出大厂外包**。"

> "**京籍 + 中产 + 想留京 + 分够 985** → CS 优先选北邮 / 北航。**京籍 + 工薪 + 双非 CS** → 不如改北邮通信工程 / 北科大材料 / 北建大土木。"

> "**非京籍随迁子女 + 想留京** → CS 是少数几个'靠学历 + 大厂应届生指标拿北京户口'的赛道之一,**比文科考公留京难度低**。"
