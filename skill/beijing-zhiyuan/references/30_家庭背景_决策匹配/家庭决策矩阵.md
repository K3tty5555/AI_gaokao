# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(北京视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**北京工薪和北京中产家庭的最优解可能完全相反**。

**北京独有维度**:除 5 档家庭之外,**京籍 / 非京籍 / 海淀-西城-朝阳-工薪 / 学区差异** 也是关键修饰变量。北京家庭普遍中产以上 + 信息差小 + 父母懂"清北 / 985 / 211"路径,但"留京户口"是隐性诉求,远超其他省份。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入)+ 京籍 / 非京籍状态,按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(部委 / 央企总部 / 北京市直机关)

**定义**:父母至少一方在部委 / 央企总部 / 北京市政机关 / 国家事业单位有稳定编制。

**北京独有特征**:
- 与其他省"省级体制内"不同,**北京体制内 = 部委 / 央企总部 / 国家级事业单位** = 全国体制金字塔最顶
- 父母通常已在京买房 / 有北京户口 / 子女享北京基础教育红利
- **海淀 / 西城重点中学 + 父母体制内 = 北京中产顶层标准画像**

**家庭画像**:
- 抗风险能力极高(部委 / 央企总部稳定 + 北京住房稳定 + 学区资源稳定)
- **极懂体制游戏规则**(部委 / 央企晋升路径 / 选调 / 调动 / 职级 全透明)
- **孩子考公进部委 = 几乎是默认路径**(尤其女孩,父母期望"留京 + 体制内 + 嫁给同档")
- 资源:能给孩子推荐部委 / 央企对口岗位、知道哪些专业进部委直接

**推荐策略**:
1. **强烈考公友好型(部委选调路径)**:法学(人大 / 北大 / 法大)/ 财政经济(人大 / 央财)/ 汉语言文学(北大 / 人大 / 北师)/ 行政管理(人大 / 北大 / 人民公安大学)
2. **985/211 选调生路径**:**清北 / 人大 / 北师 / 北航 / 法大 / 央财 = 部委定向选调最直路径**,**直接进部委 / 中央办公厅 / 国务院系统**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **央企总部对口专业**:能源(国电投 / 华能)→ 电气;通信(中国移动 / 联通)→ 通信工程;铁路(国铁集团)→ 北交大;国防(航天科工 / 中航)→ 北航 / 北理
5. **特殊机会**:**人民公安大学 + 公安联考 = 父母资源能直接复用进国安系统 / 北京公安**

**典型 case**:
- 西城某体制内家庭(父亲国务院某部司局长,母亲央企财务总监)→ 孩子综合 1500 名 → 推中国人民大学法学 → 毕业选调进司法部,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去清华 CS → 毕业 60w 起薪很高,但家长不满"不稳定 + 35 岁危机",劝其离职考公,**3 年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(协和医生 / 北大教师 / 红圈所律师 / 大厂工程师 等)

**定义**:父母至少一方在医疗 / 教育 / 工程 / 律师 / 学术等专业领域,**北京专业人员家庭 ≠ 普通医生 / 老师**,通常是协和系医生 / 985 高校教师 / 红圈所合伙人 / 互联网大厂中高层 这一档。

**家庭画像**:
- 抗风险能力高(专业资源 + 行业人脉 + 北京住房稳定)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好 + 海淀牛娃比例高
- 资源:能给孩子推荐内部实习、考研导师、就业渠道(协和实习 / 红圈所暑期实习 / 大厂内推)

**推荐策略**:
1. **优先子承父业**:协和医生家庭 → 协和八年制 / 北医临床(8-11 年长周期家庭能撑); 高校教师家庭 → 学术路径(强基 + 直博); 红圈所律师 → 法学(法大 / 人大);大厂工程师 → 北邮 / 北航 CS
2. **行业相关延伸**:学者家庭 → 强基 + 学术圈;律师家庭 → 法学 / 法治新闻;医生家庭 → 临床 / 口腔
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)— **但是北京特殊性**:即使没金融家庭背景,京籍 + 央财 / 北大光华 也能进券商 / 公募(因为校友密度高)

**典型 case**:
- 父母都是协和医生 → 孩子海淀牛娃综合 800 名 → **协和八年制临床** → 11 年读书家庭能撑 + 协和系内部推荐 → **典型子承父业**
- 母亲北师附中语文老师 + 父亲普通工程师 → 孩子综合 5000 名 → **北师大公费师范汉语言** → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父亲红圈所律师 + 母亲法务 → 孩子综合 1200 名 → **人大法学 + 法考 + 红圈所暑期实习 → 毕业进父亲所协助跑案**

## 档位 ③ 私企管理 / 创业家庭(互联网创业 / 商人 / 中小企业主)

**定义**:父母私企中高管 / 自主创业 / 中小企业主,**北京独有亚类型**:互联网创业 / 海归创业 / 朝阳商圈商人 / 北京老牌中小企业主。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业、出国读研资金充足

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理 / 金融(光华 / 人大经院 / 央财) / 国贸(对外经贸大学) / 经济(光华 / 人大经济学院)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:**北京家庭出国接受度全国第 1**;清华苏世民书院 / 燕京学堂 / 中外合作 / 香港中文大学(深圳)/ 直接申请 美 Top30 都是北京中产 / 创业家庭主流路径
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 朝阳某互联网创业家庭(年入 500w+) → 孩子综合 4000 名 → 推**香港中文大学(深圳)金融** + 父母规划继承家业 → 中外合作背景 + 商业资源
- 父母经营北京老牌小连锁(餐饮 / 教培 / 中小贸易)→ 孩子综合 5000 名 → 推**对外经贸大学国际经济与贸易 + 出国读研** → 双语 + 国际视野 + 接班
- 失败 case:互联网创业家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(北京市属事业单位 / 国企工人 / 服务业 / 白领)

**定义**:父母双方或一方稳定工作但收入有限,北京年收入 20-50 万为主。**北京普通工薪 ≠ 外省普通工薪** — 北京普通工薪通常已有北京户口 + 一套北京住房,但**北京房价 + 子女教育压力使他们对长周期投入抗性弱**。

**家庭画像**:
- **抗风险能力中等偏低**(失业的代价大 + 北京房贷压力)
- **信息差中等**(比外省工薪好,但不懂部委 / 央企总部细节)
- 通常希望孩子稳定 / 编制 / 不要折腾 / 留京 / 拿好工作
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制 / 户口路径**:
   - **北师大 / 首师大公费师范生汉语言 / 数学** = 高考分适中 + 直接北京中学编制 + 户口 / 学区资源
   - **首都医科大学医学影像 / 检验 / 护理** = 北京三甲医院技术岗 + 4 年本科 + 北京户口
   - **北京警察学院** + 公安联考 = 北京公安编制 + 户口
   - **华北电力大学(北京 / 保定)电气** = 国家电网北京公司编制 + 户口
3. **次推稳定就业型**:
   - 北邮通信 / 北航软件(进央企信息岗 / 北京中厂 IT)
   - 央财 / 对外经贸 二本档专业 + 考公(北京市直 / 区直)
   - 北京交通大学(北交大)轨道交通方向 + 进国铁北京局
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局,即使在北京)
   - 双非 CS(2024 起薪 12-15w,跟双非工科没差,留不下大厂)
   - 生化环材(必须读博才有出路,普通工薪撑不起)
   - 医学(临床 8-11 年长周期,北京房贷压力下家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 海淀某普通工薪家庭(父亲国企司机,母亲三甲医院后勤) → 孩子综合 4500 名 → 推**首都医科大学医学影像技术** → 毕业进北京三甲技术岗,**月入 1.2w + 北京户口已有 + 编制 + 家庭逆袭**
- 朝阳某工薪家庭(父亲超市经理,母亲社区工作者)→ 孩子综合 5500 名 → 推**北京师范大学公费师范生汉语言文学** → 毕业回朝阳某中学语文教师,**家庭命运改变**
- 通州某工薪家庭 → 孩子综合 7000 名 → 推**华北电力大学(保定校区)电气** → 毕业回北京通州供电公司,**国网北京编制 + 留京**

## 档位 ⑤ 非京籍随迁 / 城中村 / 北漂家庭

**定义**:父母在京务工 / 北漂 + 子女在京读初高中(满足"九类人"或随迁子女政策 + 在京高考资格)。家庭年收入差异大(从 10 万 到 80 万都可能),**核心特征是没有北京户口 + 没有北京住房 / 有租房**。

**家庭画像**:
- **抗风险能力低**(没有北京户口 = 子女继续北京发展的核心阻碍)
- 信息差中等(在京多年比外省工薪好,但不懂北京体制内细节)
- 期待孩子拿北京户口 + 跨阶级 + 留京
- **核心诉求 = "毕业拿北京户口"**(应届生落户名额是少数硬路径)

**推荐策略**:
1. **学校牌子 + 专业是否能"应届生落户"双重考虑**:
   - **985 / 部委所在地央企 / 三甲医院 应届生落户名额** 是非京籍随迁子女拿北京户口的稳定路径
   - **北邮 / 北航 / 北科大 CS / 软件工程 → 北京大厂应届生落户** 是少数稳定路径之一
   - **首都医科大学 医学影像 / 护理 → 北京三甲医院应届生落户**
   - **华北电力大学 电气 → 国家电网北京公司应届生落户**
2. **优先 100% 编制 / 应届生落户的路径**:
   - 公费师范生(首师大 / 北师大)= 北京中学编制 + 户口
   - 警校(北京警察学院)+ 联考 = 北京公安编制 + 户口
   - **国家专项计划**(部分非京籍可走原籍地国家专项,**清北华北电等会给非京籍京考生少数名额**)
3. **避免长周期投入**:
   - 医学 8-11 年(撑不起 + 落户名额变数大)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **非京籍可考虑回原籍高考**(如河北 / 山东 / 河南),**比在京考更可能进 985,代价是"留京户口"路径变难**
   - 北京大厂应届生落户名额对 985/211 应届生友好 — **本科 985 + 北京大厂校招** = 5 年内拿北京户口

**典型 case**:
- 父亲外卖站长(在京 8 年) + 母亲家政公司 → 孩子非京籍京考综合 6000 名 → **北邮通信工程** → 校招进中国移动北京公司 → 应届生落户北京 → **整个家族第一个北京户口**
- 北漂中产家庭(父母都是互联网公司员工,在京 10 年) → 孩子非京籍京考综合 4000 名 → **首师大公费师范生数学** → 毕业回朝阳某中学数学教师 + 北京户口
- 反面 case:北漂家庭 → 孩子坚持留京读双非 → 毕业拿不到北京户口 → 5 年后被劝退回原籍工作,**早知道当年回原籍考更稳**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 + 京籍 / 非京籍**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位 + 京籍非京籍是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 北京特殊修饰变量(agent 必查)

### A. 京籍 vs 非京籍
- **京籍** = 北京户口已有 → 不需要"应届生落户路径",可灵活选专业
- **非京籍京考** = 北京户口未有 + 在京高考资格 → 必须考虑"应届生落户路径"(北邮 / 首师 / 首医 / 华电 等)
- **非京籍回原籍考** = 不在京高考 → 北京 skill 不适用,走原籍 skill

### B. 海淀 / 西城 / 东城 vs 朝阳 / 丰台 / 通州
- **海淀 / 西城**:中产 / 体制内 / 学术家庭密集,**牛娃竞赛 + 强基 / 综评 路径**为主
- **朝阳**:互联网 / 创业 / 商人家庭,**出国 / 中外合作**接受度最高
- **丰台 / 通州 / 大兴 / 房山**:北京"内环外"工薪家庭,**编制 / 留京户口**诉求最强
- **顺义 / 昌平 / 国际学校** :精英国际化路径,出国为默认

### C. 学区资源 vs 体制内资源
- 京籍工薪 + 海淀学区房 → 可走"清北人航邮"高分路径
- 京籍工薪 + 非热门学区 → 走"留京 985 / 211"中等路径(北邮 / 首师 / 北科 / 北建)
- 京籍工薪 + 远郊 → 走"留京编制"路径(北京警察 / 首师公费师范 / 首医技术)
