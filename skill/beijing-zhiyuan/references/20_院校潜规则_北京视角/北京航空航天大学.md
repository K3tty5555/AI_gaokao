# 北京航空航天大学(北航,BUAA)— 985 + 国防七子(航空航天顶级)

## 一句话定位

**国防七子 No.1**,**航空 / 航天 / 飞行器设计 全国前 3**(对标西工大 / 哈工大),仪器科学全国第 1,材料 / 计算机 近 10 年崛起明显。**中国航天科技 / 航天科工 / 中国商飞 / 中航工业 校招大本营**。**京籍工科男想进国家队 + 拿北京户口 + 编制 + 大厂双轨 = 北航最优**。

---

## 真实地位

- **985 + 国防七子之首 + 双一流 A 类 + 工信部直属**,**根正苗红的航空航天工业重镇**,与西工大 / 哈工大 / 哈工程 / 北理 / 南航 / 南理工 并列国防七子。
- **学科评估**:航空宇航 A+ / 仪器科学 A+ / 软件工程 A+ / 材料 A+ / 计算机 A / 控制 A / 力学 A(**A+ 学科 6 个,工科顶配阵容**)。
- **航天系统铁饭碗**:**神舟 / 嫦娥 / 天宫 / 北斗 / C919 / 运 20 / J-20 关键岗位大量北航校友**,航天五院 / 一院 / 中航工业 / 商飞总装系点名招聘北航。
- **同档对比**:航空航天与西工大同档(西工大三航对口更直接),**北京地理 + 综合性 + 民航 / 互联网双轨** 是北航独家优势;计算机近 10 年逼近哈工大本部。

---

## 北京录取位次区间

参考近 5 年掌上高考 + 北京一分一段表(**北京 3+3,总分 750**):

- **顶级组(王牌实验班 / 计算机 / 软件 / 航空航天 / 强基)**:北京综合 **前 1500-2500 名**(部分逼近清华门槛)。
- **主流组(自动化 / 仪器 / 材料 / 电子 / 飞行器动力 / 工科试验班)**:北京综合 **前 2500-3500 名**。
- **冷门组(部分理学基础 / 部分文管 / 法学)**:北京综合 **前 3500-5000 名**。

**段位定位**:**冲北航需北京综合前 5000 名内**,王牌组要 2500 名内,计算机 / 软件 / 航天王牌实验班要 1500 名内。**北航部分王牌专业逼近清华最低分**。**以一分一段表反查为准**。

## 性价比专业(同样北航牌子,录取相对低)

- **航空航天工程 / 飞行器动力**:**录取分比 CS 略低**,但**进中国航天系统是稳的**(航天五院 / 一院 / 八院 / 商飞),**编制 + 国家队待遇 + 起薪 12-20w + 房补 + 户口**。
- **仪器科学**:全国第 1 但偏冷门,**录取分友好**,北航惯导是行业标杆。
- **材料 / 化学(航空材料方向)**:北航材料 A+,**比同分综合性 985 材料强**,航天对口。

## 坑专业 / 慎选(在北航里相对弱)

- **法学 / 行政管理 / 工商管理**:北航文科边缘,**学法学财经选人大 / 中财 / 法大**。
- **理学基础(数学 / 物理 / 化学纯学术)**:**学纯学术选清北 / 中科大**。
- **生物 / 环境 / 部分化学**:生化环材天坑,**北航救得了一部分但不如工科主流**。
- **设计学 / 工业设计**:北航工业设计有特色但**就业不如工科主流**。

## 关键提醒(填报陷阱)

1. **北航学院路校区(北京海淀)vs 沙河校区**:**本科前两年在沙河校区**,后两年回学院路本部,**与中关村 / 海淀核心区有距离**(地铁 1 小时),**京籍考生注意通勤**。
2. **北航国际学院 / 中外合作办学**:学费高(约 8w/年)+ 培养方案不同,**普通批与中外合办分数差大**,看清招生组别。
3. **物理类专业组分化**:
   - **顶级组**:王牌实验班 / 计算机 / 软件 / 航空航天 / 强基
   - **主流组**:自动化 / 仪器 / 材料 / 电子 / 飞行器动力
   - **冷门组**:理学基础 / 文管 / 法学
4. **服从调剂注意**:中段组可能调到材料 / 力学 / 部分理学,**接受不了别勾**(虽然航天对口出路不差)。
5. **强基 / 国防生 / 提前批**:**北航国防生公费 + 包就业**,普通家庭男孩冲清华无望可冲北航国防;强基计划数学 / 物理 / 化学 / 力学。
6. **北航 vs 西工大 vs 哈工大**:三校都是国防工业重镇,**北航地理 + 综合性 + 民航 / 互联网双轨最强**;**西工大三航对口最直接但西安偏远**;**哈工大综合工科最强但哈尔滨太冷**。

## 毕业出口(2024 数据估算)

- **留京就业**:约 50-55%(**北京户口直通 + 航天五院 / 一院总部 / 中航工业 / 商飞 / 互联网大厂 onsite**)
- **京津沪深一线**:约 80%+
- **保研 / 考研 / 读博**:约 50%+(保研率 ~28-30%,985 高位)
- **进央企 / 国防工业概率**:**约 35-45%**(**北航是航天科技 / 航天科工 / 中航工业 / 商飞 校招大户,顶配**)
- **互联网大厂(CS / 软件)**:约 25-35%(**北航 CS 校招认可度逼近清北**)
- **起薪范围**:**CS / 软件 25-45w,航天院所编制 12-20w + 房补 + 户口,航空 / 仪器 / 控制 15-25w 进央企**。

## 适合谁

- 北京综合 **前 5000 名内** + 学硬核工科 / 航空航天 / 计算机 男生。
- **京籍 + 体制内 / 央企 / 私企管理家庭**:北航航空航天 + 北京户口 + 互联网大厂双轨,**ROI 仅次于清北**。
- **普通工薪 / 农村家庭男孩,想跨阶级 + 进国家队 + 编制**:北航是航天科技 / 航天科工 校招大户,**北京户口直通**。
- **数学物理强 + 不怕苦 + 工科严谨派** 的考生(北航学风严谨)。
- **互联网工科男**:北航 CS / 软件 校招认可度逼近清北,**留京大厂直通**。

## 不适合谁

- **女生 + 不喜欢工科氛围**:北航男女比 7:3,工科氛围浓。
- **学文科 / 经管**:北航文科边缘,选人大 / 中财 / 法大。
- **学医 / 农林**:北航没医学院,选北大医学部 / 首医。
- **想本科直接就业 + 不读研**:北航保研 / 考研率 50%+,**本科直接就业氛围弱**。
- **分够清北**:别 stuck 北航,清北平台 + 校友圈更强。
