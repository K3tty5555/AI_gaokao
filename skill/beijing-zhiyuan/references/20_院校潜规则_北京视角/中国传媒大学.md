# 中国传媒大学(中传,CUC)— 211(传媒全国第 1)

## 一句话定位

**新闻传播 / 广播电视 / 戏剧影视 / 播音主持 全国第 1**(并列复旦新闻 / 北电影视),数字媒体艺术 / 动画 全国 Top 3。**央视 / 央广 / 中央广播电视总台 / 北京广电 / B 站 / 爱奇艺 / 字节抖音 校招大本营**。**京籍 + 想做传媒 / 影视 / 主播 / 内容创作 = 中传天花板,但只推王牌专业**。

---

## 真实地位

- **211 + 双一流(新闻传播学一流学科)+ 教育部直属 + 国家广电总局共建**,**前身为北京广播学院**,根正苗红的"中国传媒第一校"。
- **学科评估**:新闻传播学 A+ 全国第 1(并列复旦 / 人大);戏剧与影视学 A 全国第 1;艺术学理论 A- / 设计学 B+ / 中国语言文学 B+(**A+ 一个但是是传媒行业核心**)。
- **北京家长心目中"想进央视 / 做传媒就上中传"**:**中央电视台主持人 80% 来自中传播音系**,**新华社 / 央广 / 央视记者编导大量中传校友**。
- **同档对比**:**新闻传播与人大 / 复旦并列全国第 1**(各有侧重:**人大 = 财经新闻 / 时政,复旦 = 沪派国际化,中传 = 广电 / 影视 / 实务派**);**戏剧影视 / 播音主持碾压所有非艺术院校**(北电 / 上戏走艺考路径,中传走普通批 + 艺考双轨);**普通文管 / CS 中等**。

---

## 北京录取位次区间

参考近 5 年掌上高考 + 北京一分一段表(**北京 3+3,总分 750**)。**注意中传分普通批 + 艺考批两套体系**:

### 普通批(物理类 / 历史类不区分,3+3 综合)

- **顶级组(新闻学 / 传播学 / 网络与新媒体 / 数字媒体技术 / 智能媒体工程 / 国际新闻)**:北京综合 **前 5000-7000 名**。
- **主流组(广告 / 编辑出版 / 文化产业管理 / 计算机)**:北京综合 **前 6000-9000 名**。
- **冷门组(部分理学 / 部分文管 / 法学 / 经管)**:北京综合 **前 8000-12000 名**。

### 艺考批(独立招生 / 艺术校考)

- **王牌艺术专业**:**播音与主持艺术 / 戏剧影视导演 / 表演 / 戏剧影视文学**:**艺考校考 + 文化课双线**,文化课要求约本一线 90-100%,艺考校考竞争激烈。
- **数字媒体艺术 / 动画**:艺考批,文化课要求略低于纯艺术专业。

**段位定位**:**冲中传普通批需北京综合前 12000 名内**,王牌新闻组要 7000 名内,顶级新闻 / 智能媒体要 5000 名内。**艺考批走艺术校考 + 文化课双轨,与普通批并行不冲突**。**以一分一段表反查为准**。

## 性价比专业(同样中传牌子,录取相对低)

- **数字媒体技术 / 智能媒体工程**:**中传的"工科 + 传媒"交叉专业**,**录取分比纯艺术 / 纯新闻略低**,**互联网内容大厂技术岗对口(抖音 / B 站 / 爱奇艺)**,**起薪 18-30w**。
- **网络与新媒体 / 编辑出版**:**录取分比传统新闻略低**,但**互联网内容运营 / 字节抖音对口**,**新媒体行业认可度顶配**。
- **国际新闻(英语方向)**:**录取分相对低 + 英语 + 传媒**,**CGTN / 央视英文对口**,出口稳定。

## 坑专业 / 慎选(在中传里相对弱)

- **法学 / 行政管理 / 工商管理 / 经济学**:**中传文管经济不如人大 / 法大 / 中财**,**学法学财经选垂直校**。
- **计算机(非数媒方向)**:**中传纯 CS 不如北邮 / 北航**,**学纯 CS 选垂直校**。
- **理学基础**:**学纯理选清北 / 中科大**。
- **广告学 / 文化产业管理普通方向**:**虽是中传专业但行业头部稀缺**,**底层卷得厉害**,**毕业生大量改行考公 / 互联网运营**,**录取分相对低不是优势**。

## 关键提醒(填报陷阱)

1. **普通批 vs 艺考批 招生体系完全不同**:
   - **普通批(普通高考)**:**新闻 / 传播 / 网络新媒体 / 数媒技术 / 智能媒体 / 部分文管 / CS**
   - **艺考批(艺术校考 + 文化课)**:**播音主持 / 戏剧影视导演 / 表演 / 戏剧影视文学 / 数字媒体艺术 / 动画 / 摄影**
   - **两套体系并行,普通批考生不能直接报艺术专业**
2. **物理类 / 历史类专业组分化**:
   - **顶级组**:新闻 / 传播 / 网络新媒体 / 数媒技术 / 智能媒体 / 国际新闻
   - **主流组**:广告 / 编辑出版 / 文化产业管理 / CS
   - **冷门组**:理学 / 文管 / 法学 / 经管
3. **服从调剂注意**:中段组可能调到广告 / 编辑出版 / 文化产业管理 / 数字出版,**接受不了别勾**(虽然中传文管出来不差但不是新闻传媒主线)。
4. **传媒行业现状必须知道**:**头部稀缺(央视 / 总台 / 头部互联网内容大厂)+ 底层卷得厉害**(媒体记者起薪 6-10k),**只推王牌专业(新闻 / 传播 / 网络新媒体 / 数媒技术 / 智能媒体)**,**广告 / 文管 / 普通方向不如同分财经 / IT 211**。
5. **中传 vs 人大新闻 vs 复旦新闻**:
   - **中传**:**广电 / 影视 / 主持 / 实务派 + 央视 / 总台对口最直接**
   - **人大新闻**:**985 + 财经新闻 / 时政新闻 + 财新 / 央视新闻频道**
   - **复旦新闻**:**985 + 沪派 + 国际化 + 财经媒体**
   - **京籍想进央视 / 总台 / 广电 → 中传**;**想进财经媒体 / 选调 → 人大**;**留沪 → 复旦**

## 毕业出口(2024 数据估算)

- **留京就业**:约 55-65%(**北京户口 + 央视 / 央广 / 总台 / 北京广电 / 字节 / B 站 / 爱奇艺 onsite**)
- **京津沪深一线**:约 90%+
- **保研 / 考研 / 读博**:约 30-40%(保研率 ~15-20%)
- **进央媒 / 互联网内容大厂概率**:**约 50-60%**(**央视 / 总台 / 字节 / B 站 / 爱奇艺 校招大本营**)
- **传媒行业ROI 分化大**:**头部(央视主持 / 大厂内容总监 30-50w)+ 底层(地方电视台记者 8-12w / 改行)**
- **起薪范围**:**互联网内容大厂(字节 / B 站) 20-35w,央视 / 总台编制 12-18w + 户口 + 体制内,数媒技术 25-40w(技术岗待遇好),普通新闻 / 广告 8-15w**。

## 适合谁

- 北京综合 **前 12000 名内** + 学新闻 / 传播 / 影视 / 网络新媒体 / 数媒技术 的考生。
- **京籍 + 文化产业 / 媒体 / 互联网内容家庭**:**中传 + 北京户口 + 央视 / 总台 / 字节 / B 站 校招直通**。
- **未来锚点是央媒 / 影视 / 互联网内容创作 / 主持人** 的考生。
- **女生 + 文气 + 想做记者 / 编导 / 主持人 / 网红运营**:中传女生 60%+,文艺氛围浓。
- **艺考生想进顶级艺术院校** 的考生:**中传播音 / 戏剧影视 / 数媒艺术 与北电 / 上戏 同档**。

## 不适合谁

- **想搞硬核工科 / CS / 财经 / 法学**:**选清北 / 北航 / 北邮 / 中财 / 法大**,中传非工科 / 财经主战场。
- **学医 / 师范 / 农林**:**选北大医学部 / 首医 / 北师 / 中农大**。
- **想本科直接高薪就业 + 不在意行业头部稀缺**:**传媒行业头部稀缺 + 底层卷,只推王牌专业**,广告 / 文管类不如同分 IT / 财经。
- **分够人大新闻 / 北大新闻**:**别 stuck 中传**,985 文科牌子 + 选调路径更广(人大新闻进部委 / 选调更直接)。
- **非京籍 + 想进央视 / 总台**:**普通话标准 + 形象气质要求高**,**艺考批竞争更激烈**,需评估自身条件。
