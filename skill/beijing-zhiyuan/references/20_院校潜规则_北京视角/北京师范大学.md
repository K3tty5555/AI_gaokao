# 北京师范大学(北师,BNU)— 985 师范第一档

## 一句话定位

**师范全国第 1**(并列华东师大),**教育学 / 心理学 全国第 1**,中文 / 历史 / 数学 / 地理 也是顶级。**教育部直属六大师范之首**,**公费师范生 = 京籍家庭低成本拿编制 + 北京户口**的最优路径。**学教育 / 心理 / 师范 / 文科 + 想稳进体制 = 北师天花板**。

---

## 真实地位

- **985 + 双一流 A 类 + 教育部直属六大师范之首**,北京 8 所 985 之一,文科师范类排名压华东师大半身位。
- **学科评估**:教育学 A+ / 心理学 A+ / 中国语言文学 A+ / 中国史 A+ / 系统科学 A+(**心理学 + 教育学是绝对全国第 1**,与北大心理学 / 华东师大教育学并列顶配)。
- **北京家长心目中"想做老师"的天花板**:**北京公立中小学教师 70%+ 来自北师 + 首师大**,**北京户口直通编制**。
- **同档对比**:**师范类与华东师大同档**(华东师大上海地理优势 + 文气);**教育心理学碾压一切非师范类高校**;综合排名不如清北人复但**师范圈内地位最高**。

---

## 北京录取位次区间

参考近 5 年掌上高考 + 北京一分一段表(**北京 3+3,总分 750**):

- **顶级组(心理学 / 教育学 / 中文 / 数学 / 经济 / 强基理科)**:北京综合 **前 1500-2500 名**。
- **主流组(师范类各专业 / 历史 / 地理 / 物理 / 化学 / 信息学院)**:北京综合 **前 2000-3500 名**。
- **冷门组(部分理学 / 部分艺术 / 部分文科)**:北京综合 **前 3500-5000 名**。
- **公费师范生(提前批)**:综合 **前 2000-3500 名**(京籍线相对友好)。
- **珠海校区(独立招生代码)**:综合 **前 5000-8000 名**(比本部低 30+ 分)。

**段位定位**:**冲北师本部需北京综合前 5000 名内**,公费师范要 3500 名内,心理学 / 教育学要 2500 名内。**珠海校区分数低但毕业证一致**(注意识别)。**以一分一段表反查为准**。

## 公费师范生(北师最大特色 ★★★)

**教育部直属六大师范公费师范生政策**:

- **学费 + 住宿费 全免**(国家承担)
- **生活补贴**:每月 800-1000 元
- **毕业直接编制**:**回原籍服务 6 年**(北京籍学生回北京中小学,免选课考编)
- **录取分相对低**:京籍考生约 2000-3500 名段,普通工薪家庭性价比顶配
- **京籍 + 公费师范 = 北京户口 + 编制 + 6 年服务期 + 0 学费**

**最适合**:
- ④ 普通工薪 / 教师家庭
- 想做老师 / 进体制内
- 性格内向稳健 + 不想卷互联网

**最不适合**:
- 笃定不想做老师的(违约赔款 + 失信)
- 一心搞学术或互联网赚快钱的

## 性价比专业(同样北师牌子,录取相对低)

- **历史学 / 哲学 / 古文献**:文科基础学科,录取分比心理学低,**北师文科牌子在中学教育系统硬**。
- **地理学 / 资源环境**:全国前 5 但偏冷门,**录取分低 + 自然资源部 / 环保系统对口**。
- **珠海校区(BNUZH)**:**985 牌子 + 珠海地理 + 比本部低 30+ 分**,毕业证写"北师珠海"(用人单位识别),**留珠海 / 大湾区有优势**。

## 坑专业 / 慎选(在北师里相对弱)

- **法学 / 经济金融**:北师非财经法学强校,**学法学财经选人大 / 中财 / 法大**。
- **计算机 / 工程类**:**师范院校学非师范计算机是怪胎**,出来跟双非一本 CS 没差,选北邮 / 北航。
- **教育技术学 / 数学与应用数学(非师范)**:**听起来像师范但不是公费**,毕业自找工作,**当心被忽悠**。

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生**:
   - 名字带"师范"且**提前批录取** → 公费师范(免学费 + 编制)
   - 名字带"师范"但**普通批录取** → 普通师范(自费 + 自找工作)
   - **千万分清,差几十万学费 + 编制路径**
2. **北师本部(北京)vs 北师珠海校区**:招生代码独立,**录取分差 30+ 分**,**毕业证标识不同**(本部"北师大",珠海"北师大珠海校区")。
3. **服从调剂注意**:北师物理类组内可能含心理学 / 教育技术 / 系统科学等,**被调剂要能接受**。
4. **公费师范的"原籍服务 6 年"是硬约束**:**违约赔学费 + 影响考公考编诚信记录**,家长一定要跟孩子聊清楚。
5. **强基 / 综评**:北师强基计划数学 / 物理 / 化学 / 生物 / 历史 / 哲学,**适合学术苗子 + 想做大学教师**。

## 毕业出口(2024 数据估算)

- **公费师范生**:**100% 进入教师编制**(北京籍回北京公立中学,**直通海淀 / 西城 / 东城 / 朝阳重点中学**)
- **普通师范留京就业**:约 60-70%(**北京中小学 / 国际学校 / 教育机构 / 教师编制**)
- **非师范类**:约 50% 留京,**进出版 / 央媒 / 大厂用研 / 心理学应用**
- **保研 / 考研 / 读博**:约 40-50%(保研率 ~25%)
- **考公 / 选调**:约 15-20%(北师文科考公校友众多)
- **起薪范围**:**北京中学编制 12-18w + 五险二金 + 寒暑假,大厂用研(心理学)25-40w,出版社 / 央媒 12-18w + 编制**。

## 适合谁

- 北京综合 **前 5000 名内** + 想做教师 / 学心理 / 学教育 / 学文科 的考生。
- **京籍 + 教师家庭 / 普通工薪家庭**:**公费师范 = 0 学费 + 北京户口 + 编制**,跨阶级最稳路径之一。
- **想做心理咨询师 / 大厂用研 / 临床心理学** 的考生:北师心理学全国第 1,出口广。
- **女生 + 文科氛围 + 不想卷工科**:北师女生占 70%+,文气 + 师范氛围。
- **未来锚点是考公考编 / 进部委 / 进出版媒体** 的考生:北师文科牌子在体制内硬。

## 不适合谁

- **笃定不想做老师**:**别选公费师范**(违约成本高),普通批 OK 但 ROI 不如同分清北人。
- **学工科 / 计算机 / 金融**:北师工科边缘 + 财经弱,**学工科选清华 / 北航 / 北邮,学财经选人大 / 中财**。
- **学医**:北师没医学院,**学医选北大医学部 / 首医**。
- **分够清北人**:**别 stuck 北师**,清北人平台资源更强,普通家庭 ROI 更高。
- **非京籍 + 想做北京老师**:**公费师范要回原籍服务 6 年**,非京籍考生回原籍。
