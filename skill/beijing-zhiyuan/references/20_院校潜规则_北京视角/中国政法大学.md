# 中国政法大学(法大,CUPL)— 211(法学全国前 3)

## 一句话定位

**法学全国前 3**(并列人大 / 西南政法),**五院四系之首**,国际法 / 民商法 / 刑法 / 宪法行政法 全国前列。**司法部 / 最高检 / 公检法系统 校招大本营,法考通过率 60%+**。**京籍 + 体制内家庭 + 想做法官 / 检察官 / 律师 / 法务 / 选调 = 法大是性价比之选**。

---

## 真实地位

- **211 + 双一流(法学一流学科)+ 教育部直属 + 司法部共建**,**前身为北京政法学院**,根正苗红的"中央"字头法律第一校,**五院四系之首**(五院:法大 / 西政 / 华政 / 西北政法 / 中南政法;四系:北大 / 人大 / 武大 / 吉大)。
- **学科评估**:法学 A(并列人大 / 北大);政治学 A(全国前 5);**马克思主义理论 A-**;**侦查学 / 国家安全学 全国特色顶级**。
- **北京家长心目中"分不够人大法学就上法大"**:**法考通过率 60%+(远高于一般 211 的 20-30%)**,**毕业进公检法系统的概率全国第一**。
- **同档对比**:**法学垂直深度与人大法学并列全国第 1**;综合性不如 985 但**法律行业认可度碾压所有非政法类高校**;经济 / 新闻 / 文管中等。

---

## 北京录取位次区间

参考近 5 年掌上高考 + 北京一分一段表(**北京 3+3,总分 750**):

- **顶级组(法学实验班 / 法学(国际法 / 民商法 / 刑法)/ 法学(国际班 / 双学位))**:北京综合 **前 3000-4500 名**。
- **主流组(法学普通方向 / 政治学 / 国际政治 / 行政管理)**:北京综合 **前 4000-5500 名**。
- **冷门组(经济 / 新闻 / 工商管理 / 部分文管)**:北京综合 **前 5000-7000 名**。

**段位定位**:**冲法大需北京综合前 7000 名内**,王牌法学组要 4500 名内,法学实验班 / 国际班要 3000 名内。**法大法学录取分常压部分 985 法学**。**以一分一段表反查为准**。

## 性价比专业(同样法大牌子,录取相对低)

- **侦查学 / 国家安全学**:**全国特色顶级 + 司法警察 / 公安部对口**,**录取分相对低**(部分提前批),**进司法警察 / 公安系统是稳的**。
- **政治学 / 国际政治**:**录取分比法学主线低**,**法大政治学全国前 5 + 部委选调对口**,适合考公方向。
- **法学(辅修双学位)**:**录取分比纯法学略低**,但**入校后可辅修双学位**(法学+经济 / 法学+新闻),**双学位 = 复合型法律人才,出口更广**。

## 坑专业 / 慎选(在法大里相对弱)

- **计算机 / 信息管理**:**法大 CS 是法律辅助不是主业**,选北邮 / 北航 / 北理。
- **工商管理 / 经济金融**:**法大经管不如中财 / 贸大**,选财经垂直校。
- **理学基础(数学 / 物理纯理学)**:**学纯理选清北 / 中科大**。
- **新闻传播 / 文学(非法治方向)**:**选人大 / 中传**。

## 关键提醒(填报陷阱)

1. **昌平校区(本科)vs 海淀学院路校区(研究生)**:**本科四年都在昌平**,**离海淀核心区远**(地铁 1.5 小时+),**京籍考生注意通勤**(本科四年基本在昌平)。
2. **物理类专业组分化**:
   - **顶级组**:法学实验班 / 法学(国际法 / 民商法 / 刑法)/ 法学(双学位)
   - **主流组**:法学普通方向 / 政治学 / 国际政治 / 行政管理
   - **冷门组**:经济 / 新闻 / 工商管理 / 部分文管
3. **服从调剂注意**:中段组可能调到经济 / 新闻 / 工管,**接受不了别勾**(虽然法大文管出来不差但不是法学)。
4. **法考(司法考试)是法学生命线**:**法大法考通过率 60%+,远高于一般 211 的 20-30%**,**学法学就要做好法考心理准备**(本科第三年开始备考)。
5. **法大 vs 人大法学 vs 北大法学**:
   - **法大**:**法学最专业 + 法律行业垂直对口最强**,但**综合排名 211**
   - **人大法学**:**985 综合 + 法学并列第 1 + 财法结合 + 选调部委对口**
   - **北大法学**:**985 综合 + 法学并列第 1 + 学术派 + 校友圈最强**
   - **京籍家庭分够人大 / 北大就上 985 法学,分不够再上法大**

## 毕业出口(2024 数据估算)

- **留京就业**:约 60-70%(**北京户口直通 + 最高检 / 司法部 / 公检法系统 / 红圈所 onsite**)
- **京津沪深一线**:约 85%+
- **保研 / 考研 / 读博**:约 35-45%(保研率 ~20-25%)
- **考公 / 选调**:**约 30-40%**(**法大是公检法系统校招最大供应方**)
- **进体制内 / 律所概率**:**约 60-70%**(**司法 / 检察 / 公安 / 律所 / 政府法务**)
- **法考通过率**:**60%+(全国法学院校最高)**
- **起薪范围**:**红圈所(金杜 / 君合 / 中伦)25-40w,部委法务 12-18w + 编制 + 户口,公检法编制 12-18w + 户口 + 退休金,小所 / 法务 8-15w(看城市)**。

## 适合谁

- 北京综合 **前 7000 名内** + 学法学 / 政治学 / 国际政治 / 公安系统 的考生。
- **京籍 + 体制内 / 公检法 / 司法系统家庭**:**法大法学 = 公检法系统校招最大供应方**,**进司法部 / 最高检 / 律所合伙人路径明确**。
- **未来锚点是律师 / 法官 / 检察官 / 法务 / 选调** 的考生:法大法考通过率全国第 1,**红圈所 / 公检法编制对口**。
- **女生 + 文科氛围 + 偏严谨派**:法大女生占 60%+,法律氛围严肃。
- **学侦查学 / 公安方向** 的考生:法大侦查学全国特色,司法警察对口。

## 不适合谁

- **想学顶级工科 / 计算机 / 财经金融**:**选清北 / 北航 / 北邮 / 中财 / 贸大**,法大不是工科 / 财经主战场。
- **想搞纯学术 + 海外 PhD**:**纯学术北大法学院更优**,法大偏实务派。
- **不能接受法考 + 律师 5-7 年熬合伙人路径**:**法学路径长**,普通工薪家庭慎选(法考失败转行成本高)。
- **不能接受昌平校区四年通勤**:**京籍娃想周末回家方便的注意**。
- **分够人大 / 北大法学**:**别 stuck 法大**,985 法学综合性 + 校友圈更强。
