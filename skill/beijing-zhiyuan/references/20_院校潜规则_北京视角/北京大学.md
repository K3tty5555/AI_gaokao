# 北京大学(PKU)— 985 + C9 + Top 1 综合

## 一句话定位

**Top 1**(综合)/ **Top 2**(工科,与清华并列),**C9 联盟之首**,理科 / 医学 / 文科 全国顶配,光华金融 / 元培书院 / 法学院 招牌响当当。**北京理科前 200 名的天花板,清北双子星里偏文偏理的那一极**。**京籍家庭分够清北别想别的,北大文气 + 北京户口 = 体制内 / 学术 / 投行 通吃**。

---

## 真实地位

- **985 + C9(九校联盟)+ 双一流 A 类 + 教育部直属**,中国最高学府之一,论历史 / 文气 / 综合性 略强于清华。
- **学科评估全国第 1 学科数量与清华并列**:数学 / 物理 / 化学 / 生物 / 中文 / 历史 / 哲学 / 考古 / 法学 / 国际政治 / 基础医学 等近 20 个 A+。
- **北京家长心目中的"另一个最高目标"**:**清北是双子星不是上下级**,文理偏科决定选哪个。
- **同档对比**:理 / 文 / 医 / 法学整体压全国所有高校(含清华),工科主流不如清华但 PKU 计算机最近 10 年崛起明显。

---

## 北京录取位次区间

参考近 5 年掌上高考 + 北京一分一段表(**北京 3+3,总分 750**):

- **顶级组(光华管理 / 元培 / 数院 / 物院 / 临床医学八年制)**:北京综合 **前 50-150 名**。
- **主流组(经济学院 / 法学院 / 国关 / 计算机 / 信科 / 化院 / 生科)**:北京综合 **前 150-250 名**。
- **冷门组(北大医学部部分专业 / 部分文科 / 考古文博)**:北京综合 **前 250-500 名**。
- **北大医学部**:综合 **前 400-1000 名**(临床八年制要顶级组,口腔 / 基础医学 / 护理 分数递降)。

**段位定位**:**冲北大本部需北京综合前 500 名内**,王牌组要 250 名内,光华 / 元培要 100 名内。**北大医学部线略低,但医学路径长 8 年以上**。**京籍 vs 非京籍分差大,以一分一段表反查为准**。

## 性价比专业(同样北大牌子,录取相对低)

- **古文字学 / 考古文博 / 历史哲学**:**强基计划 + 录取分相对低**,但要承诺直博,**北大文科牌子在体制内极硬**。
- **北大医学部口腔 / 基础医学 / 护理**:比临床八年制低 200+ 名,但**北大医学部牌子留京三甲依然认**。
- **元培书院**:招生分高于普通理科,但**专业自选自由度全国最高**,适合不确定方向的牛娃。

## 坑专业 / 慎选(在北大里相对弱)

- **工科机械 / 材料**:北大工科边缘,**学工科选清华**,北大工科牌子不如同校文理。
- **新闻传播 / 信息管理**:北大新闻不如人大 / 复旦,**毕业改行率高**。
- **生命科学 / 化学(纯理学路径)**:生化环材天坑,**笃定走学术读博才选**。

## 关键提醒(填报陷阱)

1. **强基计划是北大主战场**:数学 / 物理 / 化学 / 生物 / 古文字 / 历史哲学,**比裸分低 5-15 分**,京籍考生强基机会多,**学术苗子优先**。
2. **元培书院 ≠ 普通专业**:招生分数 ≥ 普通理科主流,但**入学后专业自选 + 跨院系修课**,适合方向不定的牛娃。
3. **北大医学部 ≠ 北大本部**:**招生代码独立**,部分专业线比本部低,但**毕业证写"北京大学"统一**,留京三甲完全认可。
4. **协和八年制属清华医学院**:不是北大医学部!**京籍家庭学医注意区分:北医 = 北大医学部 ≠ 协和**。
5. **京籍 vs 非京籍**:非京籍录取线明显高于京籍,**九类人政策门槛严**,非京籍考生需评估"在京高考资格"。

## 毕业出口(2024 数据估算)

- **留京就业**:约 65%+(**北京户口直通 + 部委选调 / 央企总部 / 投行咨询 / 三甲医院 onsite**)
- **出国留学**:约 20%+(**全国最高 + 藤校 / 牛剑 / 海外 PhD 大本营**)
- **保研 / 考研 / 读博**:约 55%+(保研率 ~32%)
- **直接就业大头**:**投行 / 咨询 / 央企总部 / 部委选调 / 三甲医院 / 央媒**
- **进央企 / 部委概率**:**约 30-40%**(**北大文科 / 法学是部委选调最大供应方,仅次于人大**)
- **起薪范围**:**光华金融 40-60w,经济类 30-45w,文科考公 15w+ 编制 + 户口,临床医学规培期 8-12k 转编后稳定增长**。

## 适合谁

- 北京综合 **前 500 名内** + 学理科基础 / 医学 / 文科 / 法学 / 金融 的考生。
- **京籍 + 体制内 / 央企 / 部委 / 学术家庭**:北大法学 / 国关 / 经济 / 中文 = 部委选调最直接路径。
- **海淀牛娃 / 学术苗子 / 竞赛党**:强基 + 元培 + 数院神话。
- **学医笃定的考生**:北医临床八年制是 PKU 留京三甲最直路径。
- **文气派 / 不喜欢工科氛围 + 喜欢自由通识** 的牛娃:北大校园文化与清华截然不同。

## 不适合谁

- **想学顶级工科**:学工科直接清华,北大工科是综合配套不是核心。
- **想本科直接就业进互联网**:北大 CS 不如清华,**互联网大厂校招清华优先**。
- **想读"赚钱医学"快速回血**:北医临床八年制路径长,**前 5 年规培期收入低,看长线**。
- **非京籍九类人门槛达不到**:评估"留京难度",慎重决策。
