# 安徽专科 skill 核心方法论

## 一、本 skill 的定位

`anhui-zhuanke` 处理**安徽考生**中**本科线下 + 专科线上**(物理类/历史类约 200-460 区间,具体每年浮动)的填报咨询。**约占安徽 60 万考生的 15-20 万人**——这是被本科类咨询工具长期忽视的市场。

不是 `hubei-zhuanke` 的复制——**安徽和湖北的产业结构 / 家庭画像 / 升学路径 完全不同**。本 skill 必须用安徽视角、安徽事实、安徽 case。

---

## 二、与主 skill 的协作

### 数据共用
- `data/gaokao_anhui_<YYYY>.db`(掌上高考爬取,本科 + 专科都覆盖)
- 复用 `anhui-zhiyuan/scripts/score_to_rank.py`(score ↔ rank)
- 复用 `anhui-zhiyuan/scripts/predict.py`(模考分预测)
- 复用 `anhui-zhiyuan/scripts/query_school.py`(用 `--zslx 普通类`)

### 切换触发
主 skill 检测到 `score_to_rank.batch.bracket = "between_undergrad_and_vocational"` 时引导用户切换到本 skill。

或用户直接说"安徽专科怎么填""我在阜阳 350 分要报专科"等明确触发本 skill。

| **专升本考试科目** | **英语 + 高数**(理工偏好) | **政治 + 英语**(文科生反而占优) |

| **人才外流** | 中等(武汉留汉率高) | **严重**(科大本科留皖率不到 20%,皖北外流尤其重) |
| **家庭画像** | 武汉中产 / 鄂西山区 / 江汉农业 | **皖北农业贫困 vs 皖南徽商富裕** 二元分化极大 |

## 四、写每个 reference 的固定结构

参考 `hubei-zhuanke/references/` 风格,每个文件包含:

1. **核心结论**(1 段,直接说人话)
2. **行业现状 / 安徽视角速查**(数据 + 安徽特殊性)
3. **薪资真相**(表格,安徽 2024 真实薪资)
4. **专科 vs 本科的差距**(表格,本省语境)
5. **男女比 / 适合度 / 性别红利**(如适用)
6. **推荐院校梯队**(安徽本省院校,具体到城市)
7. **决策映射 / 适合什么人**(表格,给 agent 用)
8. **专升本路径 / 考公路径**(本省接收院校)
9. **典型 case**(至少 3-5 个,皖北 / 皖南 / 失败 case 都要)
10. **易错认知**(纠正用户常见误解)

## 五、风格要求

- **大白话**,不要堆专业术语
- **本省视角**(皖北 vs 皖南 / 徽商 / 黄山徽州 / 京东方蔚来 / 奇瑞江汽 / 马钢 / 阜阳幼师 / 合肥科技狂飙)
- **case-specific**(每个 case 写到具体县 / 具体专业 / 具体单位 / 具体薪资区间)
- **不套湖北**(湖北的护理 case / 电网 case 不能直接换名字)
- **不编数字**(数据写"约 / 大致 / 区间"而不是精确数字,避免误导)
- **承认不确定性**(政策每年变 / 实际填报请咨询招生办)

## 八、安全规则(写 references 时遵守)

- 不承诺"一定能录取" / "毕业一定进 X 厂"
- 不诋毁专科教育
- 涉及专升本 / 考编 政策的,**强调政策每年变,建议咨询招生办**
- 不推荐"复读 vs 上专科",只列两条路径的代价对比
- 推荐方案末尾必须加免责声明
- **不引用具体年份的精确分数线**(数据可能变),用"约 / 大致 / 区间"
