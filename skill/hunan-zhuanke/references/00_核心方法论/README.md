# 湖南专科 skill 核心方法论

## 一、本 skill 的差异化定位(为什么不直接套湖北)

湖南专科和湖北专科**不是镜像关系**,有 5 个底层差异 agent 必须知道:

| 维度 | 湖北 | 湖南 |
|---|---|---|
| **对口央企底色** | 国铁(武汉局)+ 国电网(湖北水利电力职院主供给)+ 武钢 | **中车株机制造 + 三一 / 中联工程机械 + 长沙地铁** |
| **专科电力路径** | 强(湖北水利电力职业是王牌)| **弱**(湖南没有同等专科直通国网的强校,要进国网湖南难度更大) |
| **专科工程机械路径** | 弱 | **强**(全国"工程机械之都",湖南机电 / 湖南工业职院直供三一中联) |
| **专科轨道交通路径** | 强但走"运营"(武汉铁院 → 武汉铁路局)| **强但走"制造"**(湖南铁道职院 → 中车株机) |
| **专升本对口严格度** | 严 | **更严**(湖南跨大类升本比湖北还卡) |
| **复读文化** | 中等(华师一 / 黄冈传统强,但已下行) | **更强**(长郡 / 雅礼 / 师大附中复读班体系活跃,涨分预期高) |

**结论**:agent 不能复制湖北 case 到湖南。湖北 case 里的"国电网 / 武钢 / 武汉铁路局"在湖南基本不成立,湖南要换成"中车 / 三一 / 长沙地铁 / 湘雅地市分院 / 公办幼儿园"。

## 二、推荐时的湖南本省视角清单

agent 在做推荐时,**先核对这 6 个本省事实**:

1. **长株潭一体化** — 湖南专科生 90% 留本省 = 集中在长沙 / 株洲 / 湘潭三角,不是长沙一个城市
2. **湘雅医院系统是医疗就业的主轴** — 但**湘雅本部基本不要专科**,专科主要进湘雅地市分院 + 县医院
3. **株洲 = 中国电力机车摇篮** — 想进中车系不要选长沙专科,要选株洲对口专科(湖南铁道 / 湖南汽车工程)
4. **长沙 = 中国工程机械之都** — 三一 / 中联 / 山河 / 铁建重工年招专科 5000+,这是湖北没有的红利
5. **湖南民办专科要更警惕** — 湖南民办高职数量多 + 名字花哨 + 学费贵 + 实习对接弱,坑比湖北深
6. **湖南复读体系活跃** — 距本科线 10-30 分内,要把复读作为正经选项摆上桌,不要默认推专科
