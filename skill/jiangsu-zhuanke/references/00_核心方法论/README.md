## 江苏专科咨询的核心思路

### 一、为什么江苏专科特殊

江苏在全国专科里有 3 个独特点,**agent 推荐时必须先吃透**:

1. **江苏制造业 + 外资 / 台资 / 民营 三层叠加**
   - 苏州工业园区 / 无锡新区 / 昆山 / 常州武进 / 张家港 — 这一带的电子信息 / 集成电路 / 精密制造 / 化工 / 生物医药 工厂 + 研发中心密度全国最高
   - **专科技工 = 这些企业的招聘主力**(本科主要做研发 / 工程师,产线 / 设备 / 检测 / 工艺等岗位是专科生的主战场)
   - 一个苏州工业园外资工厂的专科技工,起薪 5-8k,3 年后 8-12k,比很多双非本科文科的"市场专员"高一倍

2. **江苏的"专转本"制度全国最特殊**
   - 别的省都叫"专升本",江苏叫"**专转本**"
   - **江苏专转本录取率全国相对靠前**(2024 年全省录取率约 30-40%,部分公办接收院校录取率更高),比湖北 / 河南 / 山东都宽松
   - 这意味着**江苏专科生只要专业对口 + 不放飞自我,转本科的机会很大** — agent 推荐时一定要把这条优势讲透

3. **苏南 vs 苏北的二元分化在专科层级更尖锐**
   - **苏南专科生**:大概率留苏南就业,**进园区企业做技工 = 主流出口**,薪资跟当地中产水平差距小
   - **苏北专科生**:出口分两条 — 留本地考体制内(乡镇医院 / 县学校 / 县供电所),或去苏南打工(很多苏北专科生毕业后去苏州 / 无锡的工厂)
   - 苏北家庭倾向"有编制就行",苏南家庭对"进园区外资 / 民企当技师"接受度高 — **agent 收集"户籍 / 主要生活地"信息后,推荐倾向要对应调整**

### 二、agent 推荐的三层决策树

#### 第一层:户籍 / 主要生活地 → 大方向
```
苏南(南京 / 苏锡常 / 镇江)
  → 推荐苏南公办专科(无锡职业技术学院 / 苏州工业园区职业技术学院 / 江苏经贸职业技术学院 等)
  → 专业偏向园区企业对口(电子信息 / 集成电路 / 模具 / 化工 / 数控)

苏中(扬州 / 南通 / 泰州)
  → 推荐苏中公办或苏南公办都可
  → 专业看个人意愿,扬泰本地化工 / 医药也强

苏北(徐州 / 盐城 / 淮安 / 连云港 / 宿迁)
  → 第一选择:苏南公办专科(异地求学,毕业后就业出口好)
  → 第二选择:本地公办专科(留本地考体制内 — 护理 / 学前教育 / 公办文秘等)
  → 第三选择:去南京公办(综合性专科)
```

#### 第二层:专转本意愿 → 学校 + 专业筛选
```
强度 5(必转本)
  → 优先公办专科 + 优先专转本接收面广的专业(机电 / 计算机 / 学前 / 护理)
  → 苏南公办专转本氛围更卷(同学都在备考),适合自驱型学生

强度 3-4(可转可不转)
  → 平衡升学率 + 就业率,选"两边都行"的专业(护理 / 计算机 / 学前 / 数控)

强度 1-2(直接就业)
  → 重点看行业景气 + 苏南就业出口
  → 电子信息(进园区) / 模具数控(进苏锡常制造业) / 化工(进南京 / 泰州 / 连云港) / 护理(进医院) / 学前教育(进幼儿园)
```

#### 第三层:家庭画像 → 公办 vs 民办
```
家庭经济好(中产以上)+ 想转本 → 公办专科首选(便宜 + 师资好 + 转本氛围)
家庭经济一般 → 必须公办(民办学费 1.6-2.5w / 年,5 万 vs 2 万学费差距等于一年薪资)
家庭有园区 / 工厂资源 → 选父母行业对口专业(直接进父母公司接班 / 内推)
家庭无资源 + 苏北 → 选苏南公办,异地求学换出口
```

### 三、agent 输出的话术规范

- **称呼**:用"专转本"不用"专升本"(江苏特色)
- **地理**:用"苏南 / 苏中 / 苏北"或具体城市,不用"江苏省内"这种笼统说法
- **企业名称**:可以提"苏州工业园外企""无锡集成电路厂""昆山台资企业""泰州医药城""南京化工" — 这些是江苏家长一听就懂的标签
- **慎用术语**:"双高计划"专科 / "国家示范性高职"等术语 agent 可以用,但每次都要简短解释一句(很多家长听不懂)
- **不要套用其他省的逻辑**:别说"武汉职业技术学院" / "湖北水利电力" / "河南郑州铁路职业",江苏家长完全没概念

### 四、agent 必须避免的坑

1. **别把江苏专科说得跟全国其他省一样惨** — 江苏苏南专科生在制造业里活得比很多双非本科文科生好,这是事实
2. **别忽视苏北家庭的"编制执念"** — 苏北家庭对孩子"考个编制 / 进体制内"的期待非常重,推荐方案要给出体制内出口(医院 / 学校 / 供电所 / 乡镇政府辅助岗)
3. **别推民办专科** — 除非用户分数实在没公办可上,否则**江苏家长普遍歧视民办专科**(认为是"花钱买文凭"),推了会被反感
4. **别低估专转本难度** — 虽然江苏专转本录取率相对高,但**公办本科专转本仍然要前 20-30% 才行**,不是躺平就能上
5. **别推专科里的"行政管理 / 工商管理 / 国际贸易 / 市场营销"等纯文管类** — 这些专业在江苏专科一样没出口,且专转本对口面窄

### 五、跟主 skill (`jiangsu-zhiyuan`) 的衔接

- 主 skill 检测到用户分数 < 江苏本科线(物理类约 X 分 / 历史类约 X 分,具体年份具体看),提示分流
- 用户确认后切换到本 skill
- 主 skill 已经收集的信息(分数 / 位次 / 选科 / 户籍 / 家庭画像)**全部继承**,本 skill 不重复问
- 本 skill 只补问"专转本意愿 / 苏南苏北就业偏好 / 园区 vs 体制内倾向"3 个维度
