# 陕西专科 skill 核心方法论

## 这个 skill 跟主 skill (shaanxi-zhiyuan) 的关系

**主 skill 处理本科批,本 skill 处理专科批**。两个 skill 共享:
- 同一份 `data/gaokao_shaanxi_<YYYY>.db`(包含本科 + 专科数据)
- 同一份 `shaanxi-zhiyuan/scripts/score_to_rank.py`(score ↔ rank)
- 同一份 `shaanxi-zhiyuan/scripts/predict.py`(模考分预测)
- 同一份 `shaanxi-zhiyuan/scripts/query_school.py`(院校召回)

**专科决策跟本科决策最大的不同**:本科看"学校层次 + 城市 + 专业",专科看"**专业 + 行业出口 + 专升本资格**"。学校梯队差异在专科里重要性大幅下降,专业对口的行业入口反而是决定性的。

## 陕西专科生的 6 条独立判断逻辑

(这 6 条是 agent 在做陕西专科推荐时,**判断方向之前必须先确认**的事)

### 1. 家庭所在地是陕北、关中还是陕南?

陕西不是一块铁板,**三个区域的就业路径完全不同**:

| 区域 | 主要城市 | 优势行业 | 推荐专科方向 |
|---|---|---|---|
| **陕北** | 榆林 / 延安 / 神木 | 煤炭 / 油气 / 能源 | 煤炭工程 / 油气储运 / 矿井建设 / 化工类 |
| **关中** | 西安 / 咸阳 / 宝鸡 / 渭南 | 军工 / 装备制造 / 铁路 / 高校教辅 | 数控 / 机电 / 电气自动化 / 焊接 / 铁道类 |
| **陕南** | 汉中 / 安康 / 商洛 | 农林 / 中药材 / 文旅 / 茶业 | 园艺 / 中草药 / 旅游 / 学前教育 |

**关键提醒**:agent 看到陕北考生选"陕南方向"或反之,一定要追问 ——**是真的有跨区意愿,还是不知道家乡有什么对口?** 陕北家庭学了煤炭/油气专业,直接就近回神华 / 长庆 / 中煤,**起薪比西安高 + 五险一金齐全**,这是地缘红利。

### 2. 用户家庭是不是"军工子弟"?

陕西军工央企密度全国前列(西飞 / 陕飞 / 陕汽 / 兵器 / 中航 / 航天科工有大量分厂在西安、宝鸡、汉中)。**军工子弟家庭有内推 / 内招的隐形通道**,这是外人不知道的。

如果用户家长在西飞 / 陕汽 / 兵器工业 / 航天科工等单位工作,**强烈推荐对口专科**(陕西工业职业技术学院 / 陕西航空职业技术学院 / 陕西国防工业职业技术学院),毕业进父辈单位的概率很高。

### 3. 专升本的强度到底是几?

陕西"职教高考"改革后,专升本政策有调整(详见 `30_专升本路径/陕西专升本规则.md`)。**2024 年起部分政策放宽,但公办本科竞争依然激烈**。

agent 必须问清楚:
- **强度 5(必升本)** → 选公办专科 + 升学率高的专业(护理/学前/医学技术)
- **强度 3-4(看情况)** → 选两边都行的专业(护理 / 计算机 / 学前)
- **强度 1-2(直接就业)** → 选军工技工 / 铁路 / 电力 / 煤炭这种行业出口清晰的

**强度搞错 = 推荐方向完全错位**。

### 4. 留陕西还是出省?

陕西本地家庭"留省内"的接受度极高,跟河南 / 湖南 / 江西不一样。陕西家长普遍认为:
- 西安生活成本低 + 文化底蕴厚 + 不卷
- 出省读专科 = 不如复读
- 出省就业 = 除非进 BAT / 沿海央企,否则不划算

但 agent 也要注意:**家境特别差的农村家庭可能更想"出去闯"**。这时不要硬推"留陕西",尊重家庭意愿。

### 5. 考公 / 考编愿不愿意走?

陕西体制内偏好极强 ——**事业单位 / 公务员 / 央企子弟 / 教师编**是大多数陕西家庭的"理想终局"。专科生考公空间很小(大多数岗位卡本科),但有几条路:
- **专升本 → 考公**(主流路径)
- **专科直接考事业编**(部分艰苦边远地区岗位接受专科)
- **进央企(军工 / 铁路 / 电力 / 煤炭)即编制**(走央企内部体系)

agent 推荐时要把这条路径明确告诉用户,**不要让用户以为专科 = 没编制可能**。

### 6. 性别在陕西专科岗位上的影响很大

陕西很多优势行业(军工技工 / 铁路一线 / 煤炭 / 电力)**男生路径明显宽于女生**。但护理 / 学前教育 / 医学技术 / 文旅服务这些方向**女生反而占优**。

agent 不要推荐错性别的"虎口"赛道(比如不要推荐女生学煤炭工程 / 矿井建设,这种岗位绝大部分单位不招女生)。

## 用 agent 做决策的标准动作

1. **先问家庭所在地** → 锁定陕北 / 关中 / 陕南三套路径之一
2. **再问军工子弟身份** → 看有没有隐形通道
3. **问专升本强度** → 决定是优先升学率还是优先就业
4. **问留陕西意愿** → 决定院校推荐范围
5. **问考公/考编诉求** → 看推荐的专业能不能对接体制内
6. **问性别 + 接受的工作环境** → 排除虎口赛道

走完这 6 步,推荐方向基本就锁死了,剩下的就是用 `query_school.py` 做候选召回 + 排序。
