# 山西专科决策逻辑总览

## 为什么山西专科要单独写一套?

不是套湖北 / 河南那套通用专科逻辑就行。**山西的专科有它自己的省情**:

1. **山西是工业型省份,不是服务业 / 互联网型省份**
   - 煤(山西焦煤 / 潞安 / 阳煤 / 晋能)、钢(太钢)、电(国网山西 / 大唐山西 / 华能山西)、铁(太铁集团 / 中铁三局 / 中铁十二局太原局)
   - 这些央企国企**直接从对口专科招技术工人**,不需要本科
   - 所以山西专科生**对口出口比浙江 / 广东 / 福建 这种服务业大省专科生更稳**(那边专科生主要去民营服务业,流动性大)

2. **山西"晋商"文化弱化但留有民营基因 + 煤老板时代后遗症**
   - 1990-2010 煤老板暴富时代留下的认知:**进矿 / 进钢 / 进电 = 体面 + 稳定 + 中产**
   - 这种认知对专科家庭很受用 —— 不像沿海家庭觉得"专科 = 失败",山西工人家庭觉得"我儿子进焦煤当机电工 = 跟我一样光荣"
   - **agent 不要否定这种家庭认知**,这在山西是合理的

3. **"出晋"vs"留晋"对专科生反而结论清晰**
   - 本科生出晋 = 跨阶级机会(去东部读书 + 留东部就业)
   - **专科生出晋 = 砍掉 80% 的对口央企机会**(山西焦煤 / 太钢 / 太铁 / 国网山西 都从本省专科招,出省读专科再回来对口不上)
   - 例外:**计算机 / 互联网 类专科**可以考虑出省(山西本省互联网产业弱)

4. **煤炭周期与专业冷热**
   - 煤炭行业周期性极强:2020-2023 是煤炭高利润期,焦煤 / 阳煤 工人月薪 1.5-2w,专科采矿 / 矿山机电热度爆棚
   - 2024 后煤价回落 + 双碳压力,**煤炭岗位仍稳但起薪不会再像 2022 那样冲高**
   - 但**电力 / 新能源**(山西光伏 / 风电 / 储能)随双碳上行,**山西电力职业 / 工程职业** 的电气 / 新能源方向值得加权

## 山西专科生的三条主路径

### 路径 A:对口央企国企(山西本土)
- 适合人群:工人家庭男生 / 父辈在系统 / 求稳定 + 编制
- 对口大类:**采矿 / 矿山机电 / 冶金 / 机电 / 电气 / 铁道 / 城轨**
- 出口:山西焦煤 / 潞安 / 阳煤 / 太钢 / 国网山西 / 太铁
- 起薪:6-10k(井下 / 一线技术工人)
- 编制 / 五险一金 / 公积金:**多有**
- 升迁路径:技术工人 → 班组长 → 工段长 → 车间副主任(15-20 年)
- 想进管理岗:**必须专升本**(本科起步)

### 路径 B:医疗 / 教育稳就业
- 适合人群:求稳女生 / 普通家庭 / 求编制
- 对口:**护理 / 助产 / 学前教育 / 小学教育**
- 出口:山西省 / 市 / 县三级医院 + 公私立幼儿园
- 起薪:3-5k(医院编制起步)/ 3-4k(幼儿园)
- 升迁路径:护士 / 老师工龄 + 评职称
- **山西特色**:县医院 / 县幼儿园用人荒,县城护理 / 学前生回家就业容易,且**山西县城生活成本极低**(月薪 4k 在临汾 / 运城 县城活得很滋润)

### 路径 C:文物 / 旅游 / 文创(山西独有)
- 适合人群:对历史 / 文化感兴趣 + 不在意体制内大平台 / 接受小众路径
- 对口:**文物修复 / 博物馆管理 / 旅游管理 / 导游 / 文创设计**
- 出口:山西博物院 / 平遥古城 / 云冈石窟 / 五台山 / 晋祠 / 各市博物馆 / 民营文创
- 起薪:3-5k(编外编内差距大)
- **山西特色**:山西地上文物全国第一(国保单位 531 处,全国第一),文物 / 文博系统人手长期紧缺,但**编制岗少且对学历卡得严**,专科基本只能进编外岗或民营文创
- 适合**家在大同 / 平遥 / 临汾 / 运城** 这些文物重镇 + 家里能接受先编外的考生

## agent 决策逻辑流程

```
用户分数定位 → 山西专科档位
    ↓
确认专升本意愿(强度 1-5)
    ↓ 强度 5
    选公办 + 升学率高的专业(护理 / 学前 / 计算机 / 机电类)
    ↓ 强度 1
    确认家庭背景 + 性别 + 体力接受度
        ↓ 工人 / 矿工家庭男生 + 接受矿区
        路径 A:采矿 / 矿山机电 → 焦煤 / 潞安 / 阳煤
        ↓ 工人家庭男生 + 接受厂区 + 数物较好
        路径 A:电气 / 电力 → 国网山西 / 大唐山西
        ↓ 工人家庭男生 + 接受出差 / 跑车
        路径 A:铁道 → 太铁集团 / 中铁三局
        ↓ 普通家庭女生 + 求稳
        路径 B:护理 / 学前教育
        ↓ 历史 / 文化兴趣 + 家在文物重镇
        路径 C:文物 / 旅游(诚实告知编制门槛)
```

## 关键风险提醒

1. **不要被民办专科的招生宣传忽悠**
   - 山西部分民办高职打"包就业"旗号,实际把学生输送到东部代工厂 / 服务业,与山西本土央企一点关系都没有
   - 学费 1.2-2 万 / 年 + 三年 4-6 万,出口跟公办没法比

2. **煤炭井下岗的真实代价**
   - 月薪 1-1.5w 不假,但**矽肺病 / 关节病 / 睡眠紊乱**是真实风险
   - 适合家境特别困难 + 短期换钱 + 5-8 年后转地面岗 的策略,**不适合一辈子干**
   - agent 务必诚实说明,不要为了"看起来高薪"鼓励高中生选采矿

3. **山西文物 / 旅游路径的甜蜜陷阱**
   - 山西文物多 = 岗位多?**错**,文物多但**编制岗稀**,专科生基本进不去博物院 / 文物局
   - 民营文创(平遥 / 大同景区周边)起薪 3-4k 且不稳定
   - 除非真心热爱 + 家里能托底,否则别为"文化情怀"赌就业

4. **专升本是专科生最大杠杆,不是可选项**
   - 详见 `30_专升本路径/山西专升本规则.md`
   - 哪怕家里是煤矿系统铁定能进去,**升一个本科出来再回来,起步岗位档次差一截**
