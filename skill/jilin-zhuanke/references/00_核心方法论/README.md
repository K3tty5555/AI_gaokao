# 吉林专科 skill 核心方法论

## 与本科 skill (jilin-zhiyuan) 的区别

吉林专科填报的逻辑**不能从本科 skill 直接照搬**,需要切换到几条吉林本省的特殊主线:

1. **一汽 / 中车长客 / 沈铁 / 国网吉林 = 吉林专科生的"半内推"出口**
   - 这些央企对**对口高职**有制度化校招通道
   - 选错学校 = 错过这条线;选错专业 = 即使学校对了也进不去
2. **延边 / 朝鲜族 / 出韩出日 是独立赛道**
   - 不能用汉族专科生的就业逻辑去套
   - F-4 / H-2 / EPS / 介护 / 韩资外企 等概念是必备背景
3. **专升本是分水岭,不是加分项**
   - 吉林产业窄 + 体制内门槛高 → 专科直接就业天花板很低
   - "留吉林家庭"几乎都该把专升本当默认选项
4. **吉林冬天 / 户外岗 / 偏远厂区 / 三班倒** 是真实劝退因素
   - 铁路 / 电网 / 火电 / 油田 大量岗位户外作业 + 极冷 + 三班倒
   - 推荐时必须提示

## 推荐时的结构化输出顺序

1. **L1 硬数据**(分数 / 位次 / 选科 / 类别)
2. **L2 关键决策**(专升本意愿 / 留吉林 vs 出省 / 朝鲜族赛道 / 体能 / 性别接受度)
3. **L3 家庭画像**(经济档 / 父母行业 / 一汽中车长铁国网 子弟与否)
4. **匹配核心赛道**:
   - 汽车 / 一汽 → `汽车_一汽路径.md`
   - 铁路 / 中车长客 / 沈铁 → `铁路_中车长客_长铁局.md`
   - 电气 / 国网吉林 → `电气_国网吉林.md`
   - 护理 → `护理.md`
   - 朝鲜族 / 延边 → `朝鲜族_延边_出韩出日.md`
5. **绑定院校**:从 `吉林专科院校梯队.md` 选 5 所(冲 1 / 稳 2 / 保 2)
6. **专升本规划**:对应 `吉林专升本规则.md`,给出 3 年学习节奏建议
7. **关键提醒 + 免责声明**
