# 电气 / 国网吉林(吉林专科)

## 核心结论

**国家电网吉林省电力有限公司(简称"国网吉林")是吉林专科男生最稳的电力央企路径**。再加上**吉电股份(吉林本地国企发电)/ 华电吉林 / 大唐吉林 等发电集团**,**电力行业在吉林虽然不像汽车 / 铁路那么"招牌响",但却是另一条隐藏的稳定主线**。

跟铁路类似,**对口专科 = 半内推**,**电气专业的对口专科生进国网吉林基层岗的概率 远高于综合性专科**。

---

## 一、吉林电力行业拆解

### 三大出口

#### 1. 国网吉林(电网公司,输配电环节)
- **国家电网公司吉林省电力有限公司**,总部长春
- 下辖 9 个地市供电公司:长春 / 吉林 / 四平 / 通化 / 白山 / 白城 / 松原 / 辽源 / 延边
- 主要专科岗位:**变电站值班员 / 输电线路巡检 / 配电网检修 / 营业厅 / 抄表 / 抢修班**
- **国网吉林每年校招专科 200-400 人**(具体年份波动),主要从对口专科招
- 起薪 5-7k,5 年后 8-11k,**有编制 + 公积金 12% + 各种补贴**

#### 2. 五大发电集团 / 国电投 / 华能吉林分公司(发电环节)
- **吉电股份**(总部长春,吉林本地国企)— 吉林本地火电 / 风电 / 光伏
- **华电吉林分公司 / 大唐吉林发电公司 / 国电投吉林分公司 / 华能吉林分公司**
- 主要岗位:**电厂运行 / 检修 / 维护 / 化学处理**(火电厂特殊岗位)
- 起薪 5-7k,有三班倒补贴,**5 年后 8-11k**

#### 3. 东北电力大学体系(本科为主,但有相关专科对接)
- 东北电力大学在吉林市,本身是本科,**但有对口的专升本接收**(专科 → 东电大 是吉林电气专科生的目标之一)

### 共同特点
- **国企央企铁饭碗 + 五险二金 + 公积金 + 退休保障**
- 起薪比专科其他工科普遍高 1-2k
- **吉林冬天巡线 / 抢修户外作业极冷**(-30℃ 在野外爬铁塔不是开玩笑)
- **对口专科** 比综合性专科**进入率高得多**

## 二、吉林电气类专科院校

### 第一梯队
- **长春电子科技学院(原长春理工大学光电信息学院,2018 转设)**(注意:这是民办本科,**不是专科**,误区点)
- **东北电力大学(吉林市)** — 本科 / 研究生为主,**没有专科招生**
- **吉林电子信息职业技术学院(吉林市)** — 公办,**电气自动化技术 / 电力系统自动化 是主力专业**,**国网吉林 / 华电 / 吉电股份 校招对接**
- **长春职业技术学院** — 综合性,**电气自动化技术 / 机电一体化 也对口**

### 第二梯队
- **吉林工业职业技术学院**(吉林市) — 化工为主 + 部分电气
- **辽源职业技术学院** — 地方公办,有电气类专业,但出口主要是辽源本地

### 不推荐
- 民办高职的"电气工程""新能源" — **学费贵 + 国网校招通常不来民办**

## 三、岗位深度拆解

### 国网吉林(电网公司)

#### 专科主要岗位
- **变电站值班员** — 在变电站(110kV / 220kV / 500kV) 24 小时值班,**三班倒,但有编制**
- **输电线路巡检 / 检修** — 高压输电线路巡视 + 故障抢修,**爬铁塔 + 户外 + 极冷**(吉林冬天 -30℃)
- **配电网检修** — 城市低压配电网检修,**比输电相对轻松**
- **营业厅 / 抄表 / 客服** — 县城 / 乡镇供电所工作,**有女生岗**
- **抢修班** — 24 小时随叫随到的抢修队,**辛苦但工资好**

#### 真实薪资(吉林 2024 量级)
| 岗位 | 起薪 | 5 年后 | 编制 |
|---|---|---|---|
| 变电站值班 | 6-8k | 9-12k | 多有编 |
| 输电线路检修 | 6-9k | 9-13k(含户外补贴) | 多有编 |
| 配电网检修 | 5-7k | 8-11k | 多有编 |
| 营业厅 / 抄表 | 4-5k | 6-8k | 多有编 |
| 抢修班 | 6-9k | 9-13k | 多有编 |

### 吉电股份 / 华电 / 大唐 / 国电投(发电集团)

#### 专科主要岗位
- **电厂运行** — 控制室值班 + 设备监盘,**三班倒**
- **电厂检修** — 设备检修 + 维护
- **化学水处理** — 火电厂特有岗位,**化学专业对口** + 部分电气也能进
- **燃料管理** — 煤场 / 燃料调度

#### 真实薪资(吉林 2024 量级)
- 火电厂运行 5-7k 起 + 三班倒补贴,5 年后 8-11k
- 风电场 / 光伏电站运维 5-7k(派驻偏远地区,补贴高)

## 四、岗位的真实辛苦度 ★

### 输电线路 / 抢修班
- **爬高压铁塔**(几十米高)、零下 30℃ 户外作业、雷雨雪天紧急抢修
- **每年都有伤亡事故**(全国国网系统)
- 工资相对高,但**身体素质 + 心理素质 双门槛**

### 变电站值班
- **24 小时三班倒**,白班 / 夜班轮换
- 偏远变电站 = 远离家人(延边 / 白山 一些山区变电站,几个月轮换一次)
- 但相对**安全 + 室内**

### 火电厂运行
- 三班倒 + 噪音 + 高温(夏天值班室外 40℃ 是常态)
- 偏远厂区 = 通勤不便(很多火电厂在县城 / 农村)
- 但**伙食 + 宿舍 + 通勤班车** 央企配套全

### 营业厅 / 抄表
- 相对轻松 + 朝九晚五
- 但工资低 + 晋升慢
- **女生岗为主,男生进去会被边缘化**

## 五、女生学电气?

### 适合的岗位
- **营业厅 / 客服 / 抄表** — 国网县城 / 乡镇供电所有大量女生岗
- **变电站值班(部分)** — 室内值班,有女性班组
- **电力调度** — 总部 / 地市公司调度中心,**本科为主,但少量专科升本可以做**

### 不太适合
- 输电线路检修 / 抢修班 / 爬铁塔 — 体力 + 户外极限
- 火电厂检修 / 化学水处理 — 环境差

| 用户情况 | 推荐方向 |
|---|---|
| 男 + 数物较好 + 留吉林 + 求稳定 | **吉林电子信息职院 电气自动化 / 电力系统自动化** → 国网吉林 |

## 七、专升本路径

### 对口本科
- **电气工程及其自动化**(长春工业大学 / 长春工程学院 / 东北电力大学 / 北华大学)
- **自动化**(同上)
- **测控技术与仪器**(长春工业大学)
- **新能源科学与工程**(长春工程学院 等)

### **冲东北电力大学专升本 = 吉林专科电气的天花板** ★
- 东北电力大学是**电力行业系统院校**(原电力部直属)
- 升上去后:进国网各省公司 / 五大发电集团 比纯专科容易得多
- 但录取竞争激烈

### 升本后的路径
- 国网吉林 / 各省国网的**助理工程师岗**(比纯专科起薪高 1-2k)
- 走**调度 / 设备 / 项目管理** 路径
- 想做**国网管理岗(供电公司科长 / 副总)**,本科是最低门槛

## 八、典型 case

### Case A:国网吉林变电站值班路径
- 吉林四平农村男生 → 350 分物理类 → 报**吉林电子信息职院 电力系统自动化技术**
- 大学 3 年:专业绩点 + 拿电工进网作业许可证 + 国网吉林实习
- 毕业:**校招进国网吉林四平供电公司变电站值班员**,起薪 6.5k + 编制
- 5 年后:**值长 + 月薪 1w + 公积金 + 四平有房**

### Case B:输电线路检修(高薪 + 高辛苦)
- 吉林通化普通工薪男生 → 360 分物理类 → 报**吉林电子信息职院 电气自动化技术**
- 大学 3 年:专业绩点 + 体能 + 国网吉林实习
- 毕业:**进国网吉林通化供电公司输电运检班**,起薪 7k(含户外补贴)
- 工作模式:**春夏巡线 + 冬天抢修,经常爬铁塔 / 走山路**
- **辛苦但工资硬,5 年后月薪 1.2w + 编制**

### Case C:吉电股份火电厂运行
- 长春工薪家庭男生 → 340 分物理类 → 报**长春职业技术学院 电气自动化**
- 大学 3 年:专业绩点 + 实习
- 毕业:**进吉电股份某火电厂运行岗**,派驻吉林市某县级火电厂
- 起薪 5.5k + 三班倒补贴,**5 年后 8k + 编制**
- 局限:**派驻县城,远离长春,适合接受偏远厂区的人**

### Case D:女生进国网营业厅
- 吉林白山女生 → 300 分物理类 → 报**吉林电子信息职院 电气自动化**
- 毕业:**进国网白山某县供电营业厅**,起薪 4.5k + 编制
- 工作模式:朝九晚五 + 双休 + 县城稳定生活
- **5 年后转岗到客户经理 / 抄核收岗,月薪 6-7k**

### Case E:升本后的天花板
- 吉林电子信息职院 → **专升本上东北电力大学 电气工程及其自动化**
- 毕业:**国网某省公司助理工程师岗**,起薪 8-9k(比纯专科入职高 2-3k)
- **晋升路径开,5-10 年可做主管 / 工程师**

## 九、易错认知

- **"国网就包就业,进去稳一辈子"** — 半对。**正式合同制 = 稳**,**劳务派遣 / 第三方** 不稳,**校招正式岗有竞争**
- **"专科电气也能进国网总部"** — 错。**总部 / 地市本部岗 是 985/211 本科竞争的**,专科基本是基层 / 县级供电所
- **"国网年薪几十万"** — 半对。**专科基层岗 5-10 年大致 1-1.5w 月薪**,网传"国网年薪 30 万"主要是研发岗 / 总部 / 经营管理岗
- **"输电线路爬铁塔太危险"** — 真。**有伤亡风险**,所以**身体不好 / 心理素质差的不要选**
- **"电气专科都能进国网"** — 错。**对口专科 + 绩点 + 实习 + 校招** 综合竞争,不是包就业
- **"火电厂是夕阳行业"** — 半对。**新建火电少,但存量火电仍需要大量运维人员**,且**新能源(风电 / 光伏 / 储能)** 是新增蓝海
- **"东北电力大学就是个本科,跟我们专科无关"** — 错。**东电大每年接收专升本,是吉林专科电气的最高目标**
- **"国网营业厅就是收钱的"** — 半对。**朝九晚五 + 双休 + 编制** 是真实优势,但晋升慢
