# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(海南视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

**海南独家**:**海南家庭画像跟内陆省份有显著差别** —— **旅游业 / 服务业家庭比例高**、**渔业 / 农业家庭比例高**、**自贸港政策性岗位红利明显**、**黎苗少数民族享有民族优惠 + 国家专项**、**留琼 vs 出岛 是核心选择**(海南考生量约 6 万 / 年,高校选项极少 → 大部分本科生要出岛读书,但近年留琼率随自贸港红利上升至 60%+)。**普通家庭海南考生最大坑**:**硬冲外省 985 / 211 而忽略海大 + 海医 + 留琼 + 自贸港的高 ROI 路径**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企 / 自贸港机关)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**海南家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂海南体制游戏规则**(知道选岗 / 公考 / 编制流程 + 自贸港政策性机构动态)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小 + 海南考公"小省红利"友好)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易、**自贸港新设机构内部消息渠道**

**海南资源加分**:
- **自贸港工委办公室 / 海南国际仲裁院 / 江东新区管委会 / 三亚 CBD 管委会 / 博鳌乐城管理局 / 陵水黎安国际教育试验区** = **海南独家政策性岗位** —— 体制内家庭对这些新设机构的内部消息有信息差优势

**推荐策略**:
1. **强烈考公友好型**:海大汉语言文学 / 海大法学 / 海大经济学 / 海师大公费师范 / 海医预防医学(海南考公"小省红利" + 自贸港机关扩张红利)
2. **海大选调生路径**:海南综合 ≤ 4000 名能上海大主流组,**走海大选调生比国考省考更优**(海大是海南唯一 211,海南选调主供给校 + 起点更高 + 竞争内部化)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,**海南没有互联网大厂 / 顶级金融集群,孩子毕业容易被劝回考公,3 年损耗**
4. **海南独家:警校 / 海警** — 海南警察学院 + 公安联考 = 父母编制资源能用上;**海南海警** = **三沙南海岛礁海警驻防** = 海南独家高薪铁饭碗(海警学校卡视力 / 身体)

**典型 case**:
- **海口某中产体制内家庭(父亲海南省直机关,母亲海南银行)→ 孩子海南综合 3500 名 → 推海大法学** → **毕业海大选调进海南省委办 / 自贸港工委办**,**家庭路径完美匹配**
- **失败 case**:**同样家庭 → 孩子被推去出省读 985 CS** → 毕业拿大厂 25w + offer 很高,**但家长不满"留深圳不回海南",劝其离职考公**,**两年的时间损耗 + 心理纠结 + 海口考公竞争已变激烈**

## 档位 ② 专业人员家庭(教师 / 医生 / 自贸港律师 / 工程师)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**海南家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- **海南医生 / 教师 / 自贸港律师 群体跟内陆省份相比相对稀缺,资源相对集中** = 子承父业的"复用率"高

**海南独家拐杖**:
- **父母在海医 / 海大附属医院** = 海医临床本硕连读 + 留琼三甲规培编制 = 标准复用路径
- **父母在海师大 / 海南公办中学** = 海师大公费师范 + 留琼当老师 = 子承父业最优
- **父母在自贸港律所 / 海南国际仲裁院** = 海大法学 + 自贸港法律方向 = 海南独家拐杖
- **父母在央企海南分公司**(中海油海南 / 海南港航 / 海南电网 / 中免集团) = 对应工科 / 经管对口

**推荐策略**:
1. **优先子承父业**:教师家庭 → 海师大公费师范;医生家庭 → 海医临床 5+3 一体化(8 年长周期父母能撑);律师家庭 → 海大法学 + 自贸港方向
2. **行业相关延伸**:**海南独家** = 海大法学 / 国际经贸 / 海洋科学 / 旅游管理 / 临床医学 + 父母行业拐杖直接复用
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(海南没金融集群,**没金融行业资源会很难**)

**典型 case**:
- **母亲海南省人民医院主治医师 + 父亲普通工薪 → 孩子海南综合 4500 名 → 海医临床 5+3 一体化** → 毕业进海南省人民医院规培编制,**母亲资源直接复用**
- **父亲海口某律所合伙人(自贸港业务)+ 母亲海南银行 → 孩子海南综合 2800 名 → 海大法学(自贸港方向)** → **毕业进海南国际仲裁院 / 自贸港律所合伙人路径**,**父亲资源 + 海大法学省内 #1 = 典型子承父业路径**
- **父母均为海口某中学语文老师 → 孩子海南综合 9500 名 → 海师大汉语言公费师范** → 毕业回海口同区中学编制,**母亲资源直接复用 + 公费免学费 + 编制保底**

## 档位 ③ 私企管理 / 创业家庭(海南旅游业 / 自贸港产业 / 渔业海产)

**定义**:父母私企中高管 / 自主创业 / 企业主。

**海南家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- **海南独家**:**海南私企家庭主力 = 旅游业 / 酒店业 / 免税业 / 海产 渔业 / 房地产 / 跨境电商 / 自贸港医疗教育文创产业**(类似福建闽南商业文化但产业更聚焦旅游 + 服务业)
- 资源:商业人脉、行业 know-how、可能继承家业

**海南独家典型私企家庭**:
- **三亚海棠湾酒店业家族**(亚特兰蒂斯 / 美高梅 / 万豪供应商 / 物业 / 餐饮)
- **海口免税业家族**(海控 / 海发控 / 中免供应链 / 跨境电商)
- **海南渔业海产家族**(琼海潭门 / 文昌 / 万宁 渔船 / 海产加工 / 远洋渔业)
- **海南房地产家族**(海口 / 三亚 / 文昌 / 琼海 房地产开发,**虽 2018 年限购后体量缩水**)
- **博鳌乐城医疗 / 自贸港跨境业务家族**(医美 / 国际医疗中介 / 跨境电商)
- **儋州 / 文昌 农业 / 椰子 / 槟榔家族**(海南热带农业链家族)

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校) / 旅游管理 / 酒店管理(三亚学院旅游学院)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(海南私企家庭对国际化路径接受度高,**很多家庭选香港 / 新加坡 / 马来西亚留学**)
4. **海南独家:三亚学院旅游 / 酒店管理 / 翻译 / 国际经贸** = **家境中产 + 笃定继承家业(三亚酒店 / 海棠湾度假区) + 民办学费能负担** = 三亚学院旅游学院实习链路全国独一档
5. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
6. **避免:进海南体制内基层岗**(跟家庭基因不匹配,父母提供的资源全用不上 + 父母嫌"没出息")

**典型 case**:
- **三亚某酒店业家族(年入 200w+)→ 孩子海南综合 19000 名 → 推三亚学院旅游管理 + 海棠湾五星酒店实习链路 + 出国深造酒店管理硕士** → **毕业接管家族酒店 / 海棠湾度假村业务**,**家族复用最优**
- **海口免税业家族(年入 300w+)→ 孩子海南综合 5000 名 → 推海大国际经贸 / 跨境金融** + **大三海外交换 + 香港城市大学硕士** → 毕业进中免集团总部 / 海控集团 / 自贸港跨境电商 = **家族产业接班 + 国际化双轨**
- **失败 case**:**琼海某房地产家族 → 孩子被推考公** → 进海南某市基层公务员后被父母嫌"没出息" + 家族房地产业务也用不上 → **家庭基因不对路,3 年磨合期损耗**

## 档位 ④ 普通工薪家庭(海南公务员 / 海南国企 / 旅游业服务岗 / 文员 / 工厂工人)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主。

**海南家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾 / 最好留琼
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **海南独家典型工薪职业**:**海南各市县公务员基层 / 海南国企(海南港航 / 海航 / 海控)中下层 / 海南酒店服务业岗位 / 海南旅游业导游 / 海南渔业渔船工人 / 海南农业农场工人**

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **海师大公费师范**(免学费 + 编制 + 6 年原籍服务)= 海南家长重点关注,**比湖北华师公费师范 + 6 年服务期 + 仅限海南就业 = 家庭抗风险弱时性价比之王**
   - **海南警察学院 + 公安联考** = 进海南本地警察系统编制
   - **海医医学影像 / 检验技术 / 护理 / 药学** = 海南三甲医院技术岗 + 4 年本科即可 + 留琼率 75-80%
   - **海大法学 / 汉语言留琼考公** = 海南考公"小省红利"友好
3. **次推稳定就业型**:
   - **海大电气 + 留琼南方电网海南公司基层 / 县公司**(分够 211)
   - **三峡大学 / 华北电力 + 出岛 + 返琼南方电网管理岗**(普通家庭逆袭最优路径之一)
   - **师范类(汉语言 / 数学师范 + 公费 / 自费)**
   - **护理(本科,专科也行)**
4. **避免高风险方向**:
   - **金融 / 经济 / 工商管理(双非 / 民办 这些 = 死局)** —— 海南没金融集群 + 双非金融出口窄
   - **双非 CS**(2024 起薪 5-8w,海南没大厂 + 跨省竞争吃亏)
   - **生化环材**(必须读博才有出路,普通家庭撑不起)
   - **临床医学(8 年长周期)**(家庭撑不起 → 改学医学影像 / 护理 / 药学)
   - **心理学 / 历史学 / 哲学(本科出口窄,必须读研)**
   - **三亚学院民办**(2-3 万 / 年 + 食宿 1 万 / 年 = 4 年总成本 12-16 万,**普通工薪家庭学费门槛太高**)

**典型 case**:
- **海南琼海工薪家庭(父亲海南港航工人,母亲文员)→ 孩子海南综合 4500 名 + 物理类男生 → 推海大电气 + 校招南方电网海南公司琼海县公司** → **起薪 7k + 编制 + 留琼陪父母 + 海南房价相对友好**,**家庭路径完美匹配**
- **海南儋州工薪家庭(父亲砖厂工人,母亲家务)→ 孩子海南综合 13500 名 + 文科女生 → 推海师大汉语言公费师范** → **学费住宿全免 + 4 年生活补贴 + 毕业回儋州市某中学语文教师编制** → **家庭命运改变 + 普通家庭海南考生最稳路径**
- **失败反例**:**海南五指山工薪家庭 → 孩子海南综合 18000 名 → 报三亚学院"金融学"(民办)** → 4 年学费 + 食宿 16 万 + 毕业找不到对口金融工作 + 改行做销售 → **如果当时改成海南某双非二本汉语言文学留琼考公,学费便宜 8 万 + 编制保底**

## 档位 ⑤ 农村 / 临工 / 黎苗少数民族山区家庭

**定义**:父母务农 / 渔民 / 临时工 / 零散工作,家庭年收入通常 < 8 万。

**海南家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **海南独家**:**海南有 18 个市县,其中五指山 / 保亭 / 琼中 / 白沙 / 陵水 / 乐东 / 昌江 / 东方 / 三沙 是黎苗自治县(或民族聚居区)** —— **黎苗少数民族 + 农村家庭享有民族优惠 + 国家专项 + 民族班 = 降分 20-40 分进 985 / 211**

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**海大(本省 211 + 自贸港红利)= 农村家庭最优解**(留琼 + 211 + 编制路径)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **海师大公费师范**(无学费 + 编制 + 6 年原籍服务)= **海南农村 / 黎苗家庭神器**
   - **国家专项计划 / 高校专项**(海大 + 出省 985 / 211 都给海南农村专项指标)= 海南农村专属优惠
   - **民族班 / 民族预科 / 黎苗少数民族优惠**(海南独家)= 降分 20-40 分进 985 / 211
   - **海南警察学院 + 公安联考**(无学费 + 编制 + 包分配)
3. **避免长周期投入**:
   - **临床医学 8 年(撑不起)** → 改海医医学影像 / 检验 / 护理 / 药学
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
   - **三亚学院民办(学费 12-16 万,撑不起)**
4. **特殊机会**:
   - **国家专项计划**:海南农村户籍 / 海南省级贫困县(重点关注 五指山 / 保亭 / 琼中 / 白沙 / 临高 / 陵水 等市县),985 / 211 名校多个专项指标(分数比统招低 30-50 名)
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **黎苗民族班**:海南独家,**民族班录取分可低 1500-3000 名**
   - **海南农林优势专业**:海大作物学(双一流)+ 国家专项 + 三亚崖州湾种业振兴红利 = 海南农村黎苗考生独家路径
   - **海南热带海洋学院水产养殖 / 海洋科学 / 民族学 + 国家专项 + 五指山校区民族特色** = 农村黎苗考生公办二档备选

**典型 case**:
- **海南陵水黎苗自治县农村家庭男生 → 海南综合 5500 名 → 通过国家专项 + 民族班进海大法学(自贸港方向)** → 毕业海南国际仲裁院 / 海南公检法编制岗,**整个村寨第一个进海南省直机关**
- **海南五指山黎族家庭女生 → 海南综合 9500 名 → 海师大汉语言公费师范(民族班降分进入)** → 4 年无学费 + 毕业回五指山某中学编制岗,**最适合海南农村 / 民族家庭的"零风险"路径**
- **海南儋州农村家庭男生 → 海南综合 3000 名 → 通过国家专项进出省 211(三峡大学电气工程)** → **毕业校招南方电网海南公司海口分公司 + 海南落户加成**,**普通家庭电气逆袭路径标准模板**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业 / 留琼 vs 出岛)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**海南独家提醒**:**留琼 vs 出岛是海南考生独家决策维度**,在 L3 锚点环节必须明确询问家长。**普通工薪 / 农村 / 黎苗家庭的最优解大多是"留琼 + 海大 / 海医 / 海师大 + 自贸港红利"**,而不是"硬冲外省 985 / 211"。**家长的"出岛"情节往往是基于"海南没大学"的 90 年代认知**,**自贸港时代海大 + 海医 + 海师大 + 留琼路径的 ROI 已大幅上升**,需要 agent 主动给家长讲清。
