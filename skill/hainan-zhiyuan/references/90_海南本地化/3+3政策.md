# 海南 3+3 高考政策 + 900 标准分制解读

> agent 必读。海南考生进 L1 之前先消化这份。**900 总分是海南独家,误解了所有推荐都会出错**。

---

## 一、改革时间线(海南是第二批,2020 首届)

- **2017 年**:海南启动新高考改革(全国第二批,与北京/天津/山东共四省同批)
- **2020 年**:**首届新高考考生毕业** —— 这一届起开始 3+3 选科 + 院校专业组志愿
- **当前**(2026):已落地 6 届,数据相对成熟,但样本量仍是全国最小省之一

**对比一下**:
- 第一批(2014):上海 / 浙江 — 2017 首届毕业,3+3
- 第二批(2017):**海南** / 北京 / 天津 / 山东 — 2020 首届
- 第三批以后:大部分省份是 3+1+2(如湖北/湖南/广东)

**结论**:海南选的是 **3+3 路线,不是 3+1+2**。

## 二、考试体系 — 3+3,**总分 900(标准分换算)**

### 2.1 科目结构

- **必考 3 科**:语文 / 数学 / 英语 (各原始分 150,但**最终按标准分换算**)
- **选考 3 科**:从 6 科任选 3 科 — 物理 / 化学 / 生物 / 政治 / 历史 / 地理 (各原始分 100,**也按标准分换算**)
- **总计**:3 + 3 = 6 科

### 2.2 ★ 海南独家:900 总分(标准分换算)

**这是海南 vs 全国所有 3+3 省最关键的不同点**:

| 省份 | 高考总分 | 计分方式 |
|---|---|---|
| **海南** | **900** | **6 科全部转标准分,每科满分 150,合计 900** |
| 上海 | 660 | 语数外原始分 + 选考赋分(每科 70) |
| 浙江 | 750 | 语数外原始分 + 选考赋分(每科 100) |
| 北京 / 天津 / 山东 | 750 | 语数外原始分 + 选考赋分(每科 100) |
| 湖北等 3+1+2 省 | 750 | 语数外原始分 + 物/历原始分 + 2 科赋分 |

**标准分换算原理**(给家长一句话讲清就行,不用展开):

1. 每个考生 6 个科目原始分先算出全省**百分位**
2. 用百分位映射到 [100, 900] 之间的"标准分"(每科满分 150,6 科合计 900)
3. **位次相对位置不变,但绝对分数被"线性拉伸 + 标准化"**

**对家长的实用解读**:
- "我家孩子海南考了 750 分" → 不能直接对比湖北 750 = 985 中段;海南 750 在全省可能是 5000-6000 名,具体得查一分一段表
- "海南 700 分以上是什么概念" → 大致全省前 1 万名以内,**算分数高,但**绝不等于湖北 700 分(湖北 700 是全省前 200,清北段)
- **永远以位次为准,不要以分数为准**

### 2.3 为什么海南要用标准分

历史原因 + 海南考生少(约 6 万/年,全国小省样本):
- 标准分能消除单科难度波动
- 跨年份可比性更强
- **副作用**:跨省比较失真,家长容易误解

agent 必须主动给家长讲这一点,**不能让家长拿"我家孩子 850 分"去外省群里炫耀,会被误解为分数虚高**。

### 选科建议(海南本地化)

- **想冲 985 / 走理工医** → 物化生 / 物化政 优选(覆盖率 90%+)
- **想考公进省直机关 / 自贸港体制内** → 物化政 / 政史地(汉语言/法学/经济友好)
- **想读海大热带农业 / 海洋科学** → 物化生 / 物生地(海大 王牌专业要化学+生物)
- **想读海医临床医学 / 热带医学** → 物化生 必选(临床基本卡化学+生物)
- **想读旅游管理 / 酒店管理(海南特色就业)** → 灵活,政史地 / 物政地都行
- **不擅长理科想搏文科稳一本** → 政史地 / 化政史

**避坑**:
- **物理 + 历史同时选** → 海南没限制(3+3 都能选),但**外省院校录取时部分专业会要求二选一**,影响选择空间
- **纯文(政史地)** → 海南本省就业偏窄,**自贸港红利更多在国际经贸/金融,纯文不沾边**;除非铁了心考公,否则建议至少选一门理科

## 四、志愿数 — 院校专业组模式

### 4.1 普通类本科批

- **可填 24 个院校专业组**,每组内 6 个专业 + 是否服从专业组内调剂
- 平行志愿模式,一档一投
- **无 "院校 + 6 专业 + 调剂"老模式**,改为 "**院校专业组 + 6 专业 + 是否服从组内调剂**"
- "服从专业组内调剂" 只调到该专业组内,**不会调到组外**

### 4.2 平行志愿规则

- "分数优先 + 遵循志愿"
- 一档一投:档案投出去就锁,只能滑档进下一所
- **若 24 所都未录取 → 进征集志愿(分数允许)/ 滑入专科批 / 落榜**

### 4.3 海南考生数对志愿数的实际影响

- **海南考生约 6 万/年**(湖北约 50 万,河南约 130 万,海南约是湖北的 1/8)
- 同一名次跨度的院校选择**比大省更敏感**
- **冲档差 100 名就可能投不进,稳档区间窄**
- 推荐时冲稳保的位次差档位要比大省窄

## 五、海南特殊性(影响志愿决策)

### 5.1 总分 900,**不可直接对比外省**(再次强调)

家长群里最常见的混淆。**任何分数对比必须先转位次**。

### 5.2 0 所 985 + 1 所 211(海南大学,西部 211)

- **海南唯一 211 是海南大学**(海口),双一流学科是作物学
- 没有 985,所以海南考生想读顶级名校**必须出岛**
- 海大本省录取分相对偏低(西部 211 政策红利),**海南考生捡漏读海大相对友好**
- **海大分数线在外省偏低(双一流,但西部 211 招生政策红利)**,反向操作:外省考生海大分数低 ≠ 海南考生捡漏,海南本省海大反而是本省顶级

### 5.3 自贸港政策红利(2018 起,海南独家)

- 海南自由贸易港自 2018 年建设,2025 年全岛封关运作目标
- **国际化政策红利**:免税 / 离岸金融 / 跨境数据 / 国际医疗 / 国际教育
- 自贸港催生的就业机会:
  - **离岸贸易 / 跨境金融**:海口 / 三亚的外资企业多
  - **国际免税业**:三亚旅游免税、海口跨境电商
  - **国际医疗旅游先行区(博鳌)**:乐城先行区,**全国最开放的医疗试验区**,国际新药/新医疗器械先行先试
  - **国际教育**:陵水黎安国际教育创新试验区
- **对志愿决策影响**:海南本省考生**留琼性价比上升**,因自贸港政策性岗位增多

### 5.4 热带气候 + 旅游/医疗/养老特色产业

- 三亚旅游业 + 国际医疗旅游(博鳌乐城)
- 海口免税业 + 跨境电商
- 文昌航天发射 + 航天旅游
- 海南热带农业(橡胶 / 椰子 / 水稻种业)
- **就业地理特征**:海南本省好就业方向集中在 海口 / 三亚 / 博鳌 / 文昌 ,其他市县就业机会有限

### 5.5 海南考生留琼率约 60%+(并在上升)

- 历史:海南考生留琼率长期偏低(本省经济发展中,985 0 所),许多优秀生外流
- 近年:自贸港政策带动 + 海大上升,留琼率走高至 60%+
- **趋势**:省政府"留住人才"政策加码,本省高校就业资源倾斜

### 5.6 博鳌亚洲论坛 + 国际医疗旅游先行区(政策制高点)

- 博鳌每年办亚洲论坛 → 海南有"国际化窗口"概念
- 乐城国际医疗旅游先行区 → **海医临床医学 + 热带医学专业的天然实习/科研基地**,海南独家
- 这两个对**国际经贸 / 金融 / 翻译 / 医学 / 法律(国际法)**专业是政策性利好

## 七、其他关键政策

### 7.1 高考报名

- 海南考生需海南户籍 + 学籍(异地高考有限制,**本 skill 不深度处理报名政策,引导走官方渠道**)
- "高考移民"在海南是高敏感词 — 历史上海南分数线相对友好,曾有外省人做高考移民,2020 后政策严控

### 7.2 海南本省高校招生倾斜

- 海南大学 / 海南医学院 / 海南师范大学 等本省高校,**海南本省名额占比较高**
- 海南本省考生上海大相对外省考生友好

### 7.3 强基计划 / 综合评价

- 海南考生可参加全国 39 所强基高校的强基计划
- 综合评价(三位一体类)海南有部分院校开放(如中外合办的海南国际学院相关项目)

## 八、agent 实操要点

1. **任何海南考生开场,主动声明"海南满分 900 标准分制"** —— 避免家长拿外省 750 分对比
2. **位次优先于分数**,推荐时分数标注必须带"900 标准分"
3. **冲稳保位次差区间比大省窄**(海南考生总数 6 万)
4. **海大 / 海医 是本省顶级**,推荐海南本省考生时主推这两所(留琼方向)
5. **自贸港红利是海南独家牌**,推国际经贸 / 金融 / 旅游管理 / 医学 时记得点出
6. **不要让普通家庭考生硬冲外省 985** —— 海南本省 211(海大)留琼 + 自贸港就业,是普通家庭的高 ROI 路径
7. **博鳌乐城 / 三亚国际医疗** 是临床医学/热带医学专业的隐性加分项,推海医时务必提
