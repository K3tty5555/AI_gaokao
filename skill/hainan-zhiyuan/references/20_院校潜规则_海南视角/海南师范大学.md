# 海南师范大学(海师大,HNNU)— 双非但海南师范主力 + 留琼当老师对口

## 一句话定位

**海南本省师范主力**,留琼当老师对口校。**双非师范,海南唯一师范龙头**(海南本身就一所师范主力,海师大独占 + 琼台师范学院二档)。**想留海南当老师 + 普通工薪家庭 + 编制思维 = 海师大是海南本省最稳路径**。**师范类留琼率 70-80%,出省师范不占优势**。**海师大不是教育部直属六大师范,跟江师大 / 河北师大 / 安徽师大 同档(省级师范龙头)**,但**海南师资缺口大 + 自贸港教育扩张红利,留琼当老师真实需求旺**。

---

## 真实地位

- **双非 + 海南省 / 教育部 共建**(海南省属师范龙头,本省师资认可顶配)
- **海南本省地位**:**留琼当老师 = 海师大是默认路径**(海大师范类不强,这块海师大独占 + 琼台师范学院是二档备选)
- **海南公费师范生主要供给校**(教育部直属六大师范 = 华师 / 北师 / 华东师大 / 西南师大 / 陕师 / 东北师大,**海师大不是六大但是海南省公费师范主力 + 中央直属六师在海南有名额配额**)
- **校区**:**桂林洋校区(主校区,本科多在此,海口东部新区)+ 龙昆南校区(老校区,部分专业)**
- **特点**:**女多男少(约 7:3,师范校规律)**,桂林洋大学城地处海口郊区,生活相对单调,但**距海口主城 30 分钟 + 距三亚 2 小时高铁**

---

## 海南录取位次区间(900 分制)

参考 2021-2025 海南历年录取 + 一分一段表反查(**海南是 3+3 + 总分 900 制 + 只有"综合"一个口径**):

- **公费师范组 / 王牌师范(数学 / 物理 / 化学师范 / 汉语言师范)**:全省 **8,000-13,000 名**
- **主流师范组(英语 / 历史 / 地理 / 生物 / 思政师范)**:全省 **12,000-18,000 名**
- **非师范组 / 冷门(理学院 / 计算机 / 部分工科 / 经管)**:全省 **17,000-25,000 名**

**段位定位**:**海南综合省排 25,000 名内可冲海师大**,**师范组提档分明显高于非师范组 3,000-5,000 名**。**海南综合 13,000 名内可冲公费师范王牌**,**18,000 名内可冲普通师范**。**以一分一段表反查为准**。

## 公费师范生(海师大特色 ★★★)

**海南省公费师范生政策**(海师大执行,省级公费师范主力):

- **学费 + 住宿费 全免**(海南省财政承担)+ 生活补贴每月约 600-800 元
- **毕业直接编制 + 回原籍服务 6 年**(**定向到县乡 / 市县中学概率高,海口市区编制不一定保**)
- **录取分较高**:海南综合约 8,000-12,000 名(公费名额竞争激烈)

**最适合**:普通工薪 / 农村家庭 + 父母希望孩子做老师 + 接受县乡基层服务 6 年 + **黎苗少数民族考生**(中部山区市县编制对民族籍友好)

**最不适合**:完全不想做老师的(违约赔学费 + 影响考公)+ 追求海口市区编制(定向到县乡概率高)+ 性格外向想创业

## 性价比专业

- **公费师范汉语言文学 / 数学**:**留琼编制铁饭碗** + **考公友好(汉语言是考公王者之一)** + 数学师资稀缺竞争小
- **公费师范英语**:**自贸港红利下国际学校扩张,英语师资紧俏 + 海口三亚国际学校招聘对口**
- **教育学 / 心理学**:**进高校辅导员 / 中学心理老师 / 教育系统行政编** 多路径
- **思政师范 / 学前教育**:思政考公友好 + 海南二孩三孩政策幼师需求旺

## 坑专业(在海师大里相对弱)

- **非师范专业(理学院 / 工科 / 经管 / 法学)**:**别为了师大牌子学非师范**,出口跟双非二本差不多
- **教育技术学**:**听起来像师范但不是公费 + 不是教师编制对口**(命名陷阱)
- **旅游管理(海师大版)**:不如海大旅游学院,**想学旅游优先海大**
- **海师大独立学院 / 民办学院**:**不是海师大本部**,**填报别看错代码**

## 毕业出口(2024 数据)

- **留琼就业**:约 **75-80%**(**师范类留琼率全省最高**,海南各市县中学是主战场)
  - 海口市区编制(竞争最激烈)
  - 三亚市区编制(自贸港红利 + 旅游教育)
  - 海南其他市县(文昌 / 琼海 / 儋州 / 万宁 / 五指山 / 陵水 等)中学编制
  - 县乡 / 黎苗自治县中学编制(公费师范定向多在此)
- **出省到广东 / 长三角**:约 **10-15%**(**师范类出省 = 民办学校 / 培训机构 / 部分公办教师** + 非师范类去珠三角民营)
  - 广东:深圳 / 广州教师招聘 / 民办学校(深圳教师待遇高,但卡牌子)
  - 长三角:上海 / 杭州民办学校 / 培训机构(双减后机构萎缩)
- **考研 / 读博**:约 **10-15%**(保研率约 5-8%,考研出岛去华师 / 华南师大 / 北师 较常见)
- **考公 / 考编**:**师范类直接考教编**(占 50%+),**非师范类考公务员**(汉语言 / 法学 / 思政考公王者)

**海南考生主流路径**:**海师大公费师范 → 海南县乡 / 市县中学编制**(7-9 万年薪 + 编制铁饭碗) = 留琼稳定路径;**海师大普通师范 → 自己考教编(海口 / 三亚市区 / 出省民办)** = 灵活路径但不保编;**海师大非师范 → 出省找工作或考公** = 出口跟双非二本差不多

| 师范实力 | **海南本省第一** | 华中 / 华南顶配 | 全国第 1-3 | 弱(非主打) | 海南二档(乡镇师资) |
| 留琼就业 | **极高(75-80%)** | 中 | 中 | 中(走综合) | 高(乡镇基层) |
| 公费师范名额 | 多(省级) | 多(部级) | 多(部级) | 无 | 少(乡镇定向) |

## 关键提醒(填报陷阱)

1. **公费师范 vs 普通师范**:**提前批 = 公费(免学费 + 编制 + 6 年服务)**,**普通批 = 自费 + 自找工作**,**千万分清**
2. **海师大本部 vs 独立学院 / 民办学院**:**只有桂林洋 / 龙昆南本部是正牌**,**填报别看错代码**
3. **公费"原籍服务 6 年"是硬约束**:**违约赔学费 + 影响考公**,**家长跟孩子聊清楚这 6 年要回原籍 + 大概率到县乡 / 黎苗自治县**
4. **教育技术学 ≠ 师范 + 公费**:**听起来像师范但不是教师编制对口**,**别被名字忽悠**
5. **海南 3+3 选科与师范专业匹配**:**数学 / 物理 / 化学师范要求物理 + 化学**,**英语 / 历史 / 地理 / 思政师范物理历史均可**
6. **海师大公费 vs 华师 / 华南师大公费**:**华师 / 华南师大 = 全国通用 + 211 牌子**;**海师大 = 仅限海南 + 双非**;**海南籍分数够华师 / 华南师大的优先出省**;**笃定留琼 + 想要本省师资人脉 → 海师大公费**
7. **海南教育扩张红利**:**自贸港下国际学校扩张,英语 / 国际化方向师资紧俏**,**英语师范是海师大里出口最有想象空间的**

## 适合谁

- 海南综合 **省排 8,000-25,000 名** 的考生
- **想当老师 + 留海南** → 海师大是默认路径
- **女生 + 求稳 + 编制思维** → 公费师范 + 教编路径
- **普通工薪 / 农村家庭** + 想要稳定就业 + 接受县乡 / 黎苗自治县基层
- **黎苗少数民族考生** → 海南中部山区市县教师编制对民族籍友好,海师大公费师范是性价比最高路径
- 性格内向稳健 + 适合教学工作 + 喜欢跟孩子打交道
- 接受桂林洋大学城环境(海口郊区,生活相对单调)
- **学英语师范 + 想吃自贸港国际学校红利** → 海师大独家通道

## 不适合谁

- **想当老师但分数能上华师 / 华南师大 / 北师 / 华东师大**:**优先 985/211 师范,出省牌子明显高一档**
- **完全不想做老师**:**海师大非师范专业不强,出口跟双非二本差不多**,选海师大非师范是赔了平台
- **追求海口市区编制** + **怕去县乡 / 黎苗自治县基层**:**公费师范定向到县乡概率高**,**追求海口市区的 → 师大非定向 + 自己考教编 更灵活**
- **追求高薪互联网 / 金融 / 投行就业**:海师大平台对接不上,选海大或外省 211
- **性格外向 + 想做生意 / 创业 + 不喜欢流程化**:不适合教师职业 + 公费 6 年服务期捆绑
