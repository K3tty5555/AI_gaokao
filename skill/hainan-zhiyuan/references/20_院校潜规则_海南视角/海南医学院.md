# 海南医学院(海医,HNMC)— 双非但热带医学全国独家 + 海南医院主力供给

## 一句话定位

**海南医院系统主力供给校** —— **临床医学是国家一流本科 + 学科排名南方双非前列**。**类似昆明医科大 / 广西医科大 / 贵州医科大 的地位** —— 双非牌子,但临床实力跟中游 211 医学院相当。**海南区内三甲医院 80%+ 的医生出自海医**。**热带医学 / 热带传染病(疟疾 / 登革热 / 寄生虫病)研究 全国独家**(海南纬度 + 博鳌乐城国际医疗旅游先行区 = 天然实习 / 科研基地,WHO 东南亚热带病合作的中国前沿)。**学医留海南 → 海医临床是首选无替代,海大医学 < 海医**。**学医必须考研 + 8 年起步 + 30 岁前别想买房,普通工薪家庭要算账**。

---

## 真实地位

- **双非但临床医学海南唯一**(海南医学院校独苗,**热带医学是国内独家研究方向 + 国家级特色学科**)
- **历史血统**:**1947 年海强医事职业学校创办 → 1993 年海南医学院 → 2023 年正式更名海南医科大学**(更名后牌子升级,但仍是双非),**海南最早现代医学教育**
- **本省地位**:**海南医院系统主力供给校** —— **海医一附院 / 二附院 / 海南省人民医院 / 三亚中心医院 / 各市县三甲 骨干 80%+ 出自海医**,**海南医生圈是海医同学会的内网**
- **同档对比**:**跟昆医 / 广西医科 / 贵州医科 同档**(都是双非但临床顶级),**热带医学独家招牌全国第一**(WHO 东南亚热带病合作 + 博鳌乐城天然实验场)
- **博鳌乐城红利(★★★)**:**海南独家政策红利** — 博鳌乐城国际医疗旅游先行区是中央批准的特许医疗区(用药 / 医疗器械可比国际同步引进),**海医是博鳌乐城天然合作院校**,本科生有机会接触国际同步前沿用药 / 医疗器械研究,**这是全国其他双非医学院都给不出的资源**
- **校区**:**海口龙华校区(主校区)+ 城西校区(医学院本部)+ 桂林洋校区(新区)**,**海口生活成本中等 + 三亚 / 博鳌都在 1-2 小时高铁圈,实习便利**

## 性价比专业(海医独家)

- **临床医学 5+3 一体化(★★)**:**5 年本科 + 3 年硕士规培 = 8 年医生养成**,**本硕连读 + 毕业直接进三甲规培编制**(海医对接海医一附院 / 二附院 / 海南省人民医院 / 三亚中心医院 标准分配率高),**留琼当主治医师标准路径**
- **热带医学(★★★)**:**全国独家招牌** + 博鳌乐城天然实习基地 + WHO 东南亚合作,**疫情后热带病研究地位飙升**(登革热 / 疟疾 / 基孔肯雅 在海南南部时有暴发,海医是国家级研究阵地),**做学术 / 公卫方向有独家全国名片** —— **冲博士读研北医 / 协和 / 中山热带病所 接受度极高**
- **预防医学(疫情红利)**:**海南 CDC + 卫健委 + 国家疾病预防控制中心 + WHO 东南亚 对口**,疫情后公卫地位上升 + 海南热带病独家加成,**铁饭碗 + 编制 + 全国独家招牌**
- **国际医疗旅游方向**:**博鳌乐城 / 三亚国际医疗旅游先行区** 跨境医疗 + 国际患者接待 + 海外医疗器械同步引进研究,**全国独家路径**(其他省份的医学院给不了这个),**国际化 + 高薪 + 自贸港红利三件套**
- **药学**:**海南制药产业(齐鲁海南 / 华润海南 / 海南先声 / 葫芦娃)+ 医院药剂科** 主力供给,**起薪 7-12k + 留琼高薪稳定**(海南制药园区在海口秀英区集聚)
- **护理学**:**本科护士在海南三甲医院起薪 5-8k + 编制 + 五险一金**,**女生稳定铁饭碗 + 三班倒**,**护理是医学院校最稳的女生路径**(本科护士 vs 医生 8 年规培,前者性价比更高)

## 坑专业 / 慎选(在海医里相对弱)

- **医学之外的非医专业(英语 / 思政 / 行政管理 / 公共事业管理 / 应用心理学(非临床心理))**:**算医学院校的"水牌子"**,**报海医就是为了学医,非医专业别报**(出海医到非医岗位不如直接选海大 / 海师大)
- **生物医学工程 / 医学技术(部分细分)**:**算医学边缘**,出口窄,**学这些不如直接学临床或药学**
- **预防 / 检验(部分细分)**:CDC 编制少 + 出口窄,**但疫情后中等性价比**
- **海医独立学院(若有)**:**和本部牌子有差**,**勾报前查清楚**
- **4 年制非临床(护理 / 检验 / 影像 等)**:**不能当医生 + 不能改临床**,**当心被调剂错**(想做医生的别勾 4 年制服从)

## 关键提醒(填报陷阱)

1. **临床医学 5+3 一体化 vs 5 年制 vs 4 年制本科(★★)**:
   - **5+3 一体化**:分较高,**8 年制规培编制路径稳**,**首选**
   - **5 年制临床**:5 年本科 + 自找规培,**需要单独考研 / 规培 + 努力**
   - **4 年制非临床(护理 / 检验 / 影像)**:**不能当医生,不能改临床**,**当心被调剂错**(想做医生的别勾 4 年制服从)
2. **服从调剂**:**海医组内可能含护理 / 检验 / 公卫等冷门**,**勾服从前查清组内有什么** —— 不想做护士 / 公卫的话千万别勾服从
3. **学医的现实(★)**:
   - **8 年起步月薪 8-15k(规培期)**,**主治医师后年薪 15-25w**(海医一附院 / 二附院 主治),**30 岁前别想买房**(规培期 + 主治晋升期)
   - **学医苦 + 三班倒 + 医患关系紧张 + 8+ 年学制 + 规培 3 年 = 11 年起步**
   - **家庭抗风险弱的慎重**(普通家庭学医 → 父母要养孩子到 30 岁主治医师 + 医学院学费 + 生活费)
4. **学医必须考研**:**本科直接就业很难进三甲**,**海医本科 → 自家附属医院规培 → 考研 985 医学院 = 标准路径**
5. **海医 vs 海大医学 vs 出省中山医 / 北医 / 协和**:
   - **海医 > 海大医学**(海大医学规模有限,海医是海南医学独苗)
   - **学医留琼首选 → 海医临床**(性价比之王 + 校友网密度全国第一在海南)
   - **分够冲顶配 → 出省中山医 / 北医 / 协和 / 川大华西医**(海南综合 ≤ 1500 名才有机会)
   - **分不够海医 → 出省其他双非医(三本医学院)** —— 但海南本省考生几乎没必要这么干
6. **男女比例**:**海医临床男女比 4:6**(医学整体女生略多),**护理男女比 1:9**(本科护士女生为主),**口腔 / 麻醉 男女均衡**

## 录取位次区间(只给位次,不编分数,海南 900 分制)

参考 2021-2025 海南录取数据(**海南是 3+3 + 总分 900 制 + 只有"综合"一个口径**,以一分一段表反查为准):

- **顶级组(临床医学 5+3 一体化 / 口腔医学)**:全省 **3,500-6,500 名**
- **主流组(临床医学 5 年制 / 麻醉 / 影像 / 预防医学 / 热带医学)**:全省 **6,500-12,000 名**
- **冷门组(护理 / 检验 / 药学 / 4 年制非临床)**:全省 **12,000-22,000 名**

**段位定位**:**海南综合 22,000 名内可冲海医,6,500 名内可冲临床 5+3 顶配**。**学医必须选物理类(化 + 生组合)** —— **海南 3+3 推荐物理 + 化学 + 生物组合**(医学院校临床 90%+ 要求理化生齐备)

## 毕业出口(2024 数据)

- **留琼就业**:**约 75-80%**(**海医毕业留琼率是海南医学高校最高**,因为海南医院体系全是海医校友)—— **海口 50%+(海医一附院 / 二附院 / 海南省人民医院 / 海口市人民医院 等三甲)+ 三亚 / 琼海 / 文昌 / 儋州 / 万宁 各市县三甲 + 县医院**
- **博鳌乐城就业(独家路径)**:约 5-8%(**博鳌乐城国际医院 / 国际医疗机构 / 海外药企在海南落地点位**),**起薪比普通三甲高 30-50% + 国际化平台 + 自贸港红利**
- **去广东大湾区**:约 8-12%(深圳 / 广州 三甲医院 + 私立医疗集团 — 大湾区医院给非本地名校的 offer 越来越保守)
- **去长三角就业**:约 3-5%(上海 / 杭州 / 南京 三甲医院 — 主要是 5+3 一体化优秀生考研后流向)
- **东盟出口**:约 1-3%(WHO 东南亚 / 中越 / 中老 / 中柬 跨境医疗合作项目 + 国家卫健委派驻)
- **考研 / 读博**:**约 60%+(学医必须读研)**,本科直接就业很难进三甲
- **进医院体制(三甲医院 / 区县医院 / 编制岗)**:**80%+** —— 学医本质就是进医院

**起薪反差**:
- **海医本科留琼三甲医院(规培期)**:**月薪 8-12k**(规培期收入不高)
- **主治医师后(海医一附院 / 海南省人民医院)**:**年薪 15-25w**
- **博鳌乐城国际医院**:**年薪 20-35w**(自贸港红利 + 国际化加成)
- **进齐鲁海南 / 华润海南 / 海南先声(药学方向)**:8-12w + 编制(留琼高薪 outlet)
- **护理本科(三甲医院护士)**:5-8k + 编制 + 五险一金 + 三班倒
- **公卫(海南 CDC / 卫健委)**:5-8k + 编制(疫情后公卫地位上升 + 铁饭碗)

## 适合谁

- 海南综合 **省排 3,500-22,000 名** + 明确想当医生 + 想留海口 / 三亚 / 海南州市医院 的考生
- 想做**热带医学 / 热带传染病研究**(疫情后 CDC 地位上升 + 全国独家 + 博鳌乐城天然实习) → **海医西南独一档,全国独家**
- 想做**国际医疗 / 跨境医疗 / 博鳌乐城方向** → 海医独家路径(自贸港红利 + 国际化平台 + 高薪)
- 想做**药学 / 药企方向**(齐鲁海南 / 华润海南 / 海南先声 / 葫芦娃) → 海医药学好选择
- **能接受 8 年起步学医周期 + 工作强度大 + 30 岁前不富裕** 的考生
- 家庭抗风险中等以上(可以养孩子到 30 岁主治医师)+ 看重稳定铁饭碗的家庭
- **女生 + 想做护士本科**(留琼三甲护士编制) → 海医护理是海南主力

## 不适合谁

- **不确定要不要学医**:学医一辈子,**不喜欢医学别冲海医**,中途转专业极难
- **家庭抗风险弱 / 必须早工作早赚钱**:**8 年起步太长** — 可考虑陆军军医大学(军编 + 包分配 + 月津贴)
- **想出省互联网 / 金融大厂**:学医出口就是医院,**不是 IT / 金融 灵活路径**
- **怕脏 / 怕累 / 怕三班倒 / 怕医患**:海医临床 + 实习 + 规培,**4-8 年都在医院熬夜**
- **想报非医专业(经管 / 文科)**:海医非医都是水牌子,**直接选海大 / 海师大**
- **追求 985 牌子 + 学医** → 分够冲中山医 / 北医 / 协和(海南综合 ≤ 1500 名)
