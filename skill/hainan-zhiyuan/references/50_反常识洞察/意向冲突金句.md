# 用户意向冲突 — Reality Check 金句库(海南视角)

很多家长 / 考生有具体的意向("想上海大"、"非北京 / 上海不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)+ **海南独家本地化适配**(900 标准分制 / 海大独苗 211 / 自贸港红利 / 留琼 vs 出岛核心决策维度 / 黎苗少数民族优惠)。

---

## 核心原则

1. **直说不可达** — 客观差距明显(海南综合 4000 名以上),**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **海南独家**:**留琼 vs 出岛是海南考生独家决策维度**,**家长的"出岛"情节往往基于 90 年代"海南没大学"认知**,自贸港时代海大 + 海医 + 海师大 + 留琼路径 ROI 已大幅上升,**普通家庭海南考生不要被"出岛"情节绑架**

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 海南综合排名差距 >4000 名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 海南综合 8000 名要清北 / 海南综合 25000 名要海大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 海南综合 [实际排名]名,跟 [意向校主流组] 差 [X 千名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 211 牌子的执念,还是把 [替代校] 当作公办本科的实力?这两条路出来 5 年后差距没你想的那么大,**何况是在海南本省考公 / 自贸港机关 / 海南医院系统这些校友圈密集的领域**。"

**真实案例(海南综合 18000 名,意向海大)**:
> "海大主流组在海南综合 4500-8000 名段。你 18000 名,差 1 万名,**海大没戏**。
>
> 但你能上海南热带海洋学院水产养殖 / 海洋科学组 + 海师大非师范组 / 海医影像 / 海医检验等公办本科 — 这几所留琼就业,**海南本省考公 / 海南医院系统 / 海南海洋系统招聘里跟海大冷门组校友地位差不多**(都是'海南本省公办本科 + 留琼同档')。"

**真实案例(海南综合 9000 名,意向出省 985)**:
> "你 9000 名,出省 985 主线全够不上(海南综合 ≤ 1500 名才有 985 主线)。**清北复交华五对你完全不可能**。
>
> 但海大 211 + 自贸港红利,**比你硬上外省双非要香得多**:海大法学 / 国际经贸 / 旅游管理 / 作物学 / 海洋科学 都在你能上的范围,**留琼考公 / 自贸港机关 / 海南医院系统 / 海南文旅集团** 全是海大校友主场。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'211 就是 211 / 985 就是 985',但 **211 / 985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 海南公办主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(理工科 + 普通家庭 + 海南综合 8500 名,意向海大)**:
> "海大你能擦,但只能进材料 / 化工 / 部分农林 / 边缘工科。**211 牌子 + 海南海岛偏远(对外省校招而言)+ 生化环材** = 三重坑(出省校招本科直接就业惨)。
>
> 同分能上的海医医学影像技术 / 海医药学(本科 4 年留琼三甲技术岗 / 药企编制)出来对口程度更高 + 留琼率 75-80%。**冲海大留一个心理慰藉位即可**,但主推海医技术岗。"

**真实案例(理工科 + 中产家庭 + 海南综合 1500 名,意向北大)**:
> "北大你 1500 名能冲 — 但只能进生命科学 / 哲学 / 一部分弱专业组。**清北 985 牌子 + 北方寒冷 + 生化环材** = 名校弱专业的典型坑。
>
> 同分能上的复旦数学 / 上交计算机 / 浙大 CS 出来对口程度更高;同分留琼能上的海大法学 / 海大国际经贸 + 海南选调路径起点更高。**冲北大留一个心理慰藉位即可**,但主推 985 主线强专业 + 出省。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村 / 黎苗山区,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华临床 / 北医 / 协和 / 川大华西医])
> - 撑不起 → 走 **[替代短路径]**(如 [海医医学影像 / 海医检验 / 海医护理 / 海医药学] — 4 年本科直接进海南三甲技术岗,起薪 5-7k + 留琼率 75-80% + 编制 + 海南房价友好),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(海南普通工薪家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k**(海南规培期工资比北上低 10-20%)。普通工薪父母还要供 8 年。
>
> 撑得起 → 推海医临床 5+3 一体化(海南综合 ≤ 6500 名 + 留琼三甲编制),长期天花板高。
>
> 撑不起 → **建议海医医学影像 / 检验 / 护理 / 药学(4 年本科直接进海南三甲技术岗 + 留琼率 75-80% + 起薪 5-7k + 编制)**,或者放弃医学走海大法学 / 汉语言考公 这种本科直接挣钱 / 留琼考公的赛道。"

**真实案例(海南黎苗自治县农村家庭 + 想学医)**:
> "你家里在五指山,孩子海南综合 12000 名 + 黎族民族班降分。学临床医学 8 年规培期 → 8 年家里要养 + 三甲门槛博士起步 → **撑不起**。
>
> **建议**:**海医医学影像技术 / 海医检验 / 海医护理 + 民族班降分(降分 1500-3000 名进海医)**,4 年本科 + 直接进海南三甲技术岗 + 留琼 + 编制。**或者海师大公费师范汉语言(免学费 + 编制 + 6 年原籍服务)** = 海南农村 / 黎苗家庭最稳路径。"

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去" / "海南没大学,必须出岛"

**特征**:用户只想留某个城市("非北京不去" / "非上海不去"),或者**反过来,海南家长执念"海南没大学,必须出岛"** — 拒绝海大 + 海医 + 海师大留琼。

**金句模板(留意向城)**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留北京没意义,要去西工大),**要灵活退一步**。"

**金句模板(海南家长"出岛执念")★ 海南独家**:
> "你说'海南没好大学,孩子必须出岛',我理解 —— 但这是 90 年代的认知。
>
> 现在的真相:
> - 海大是 211 + 双一流(作物学)+ 部省合建 + 自贸港红利,**校招 / 考公门槛跟外省末流 211 一档**
> - 海医临床医学 + 热带医学 全国独家 + 博鳌乐城天然实习 = **海南医院系统 80%+ 三甲骨干出自海医**
> - 海师大公费师范 = **免学费 + 编制 + 6 年原籍服务,普通家庭海南考生最稳路径**
> - 自贸港 2018 起 30+ 个新设机构 + 大量综合 / 文秘 / 法律 / 经贸岗位 = **海南独家政策红利**
>
> 如果孩子海南综合 ≤ 4000 名 + 想做学术 / 顶尖大厂 / 出省发展 → 出岛 985 / 211;**如果孩子分数只够外省双非 + 普通家庭 + 想留琼陪父母 → 海大 / 海医 / 海师大留琼 ROI 远高于外省双非**(海南房价 / 生活成本 / 校友圈 / 自贸港红利综合)。
>
> **别让孩子为了'出岛'情节,放弃海大 211 + 自贸港红利 + 留琼考公 + 海南房价友好这套高 ROI 组合**。"

**真实案例(海南琼海工薪家庭 + 出岛执念)**:
> "你孩子海南综合 7500 名。**海大 / 海医 / 海师大都能上** — 但你说'海南没大学,孩子必须出岛'。
>
> 这分数**出岛只能上外省双非**(山东 / 河北 / 广西 / 贵州 等地的双非二本)。**外省双非 vs 海大 211 + 自贸港红利 + 留琼率 50%+** —— **后者完胜**。
>
> 你的'出岛'情节 = 90 年代'海南没大学'的老认知。**现在海南的真相:海大是 211 + 自贸港政策性岗位密度高 + 海南房价相对友好 + 海南机关编制密度高 + 海大校友网在海南本省独家主场**。
>
> **建议主推海大 + 王牌专业组(法学 / 国际经贸 / 旅游 / 海洋 / 作物学),不要为了出岛去外省双非**。"

**真实案例(京籍 + 法学方向 + 590 分,只留京)**:
> "你只留北京,这位次 12614,人大法学 / 法大主线全够不上。
>
> **留京最稳路径**:首师大 / 北工商 法学(市属一本)+ 父母律师家庭资源 + 法考 → 红圈所合伙人路径仍然能走。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 户口没了**,综合不划算。"

## 海南独家:5 种地名 / 院校情结对应金句

### 1. "孩子非要去北上广"
> "出岛去北上广 = 海南综合 ≤ 1500 名才有清北复交 + 上交 + 浙大 + 中山 + 华南理工等顶级校的机会。海南综合 4000-10000 名 = 出省只能上外省末流 211 / 双非,**不如海大 + 留琼**。"

### 2. "海南就是个旅游岛,没什么好大学"
> "海大是 211 + 双一流(作物学)+ 自贸港红利 + 海南唯一 211 + 部省合建。海大全国排名虚低是因为沿海考生用脚投票不来海岛读,但**海南考生用低分上 211 + 留琼自贸港红利,这是普通家庭海南考生独家友好的路径**,沿海考生想抢都抢不到。"

### 3. "孩子要出岛见世面"
> "见世面 = 985 / 211 顶级城市资源。但海南综合 ≤ 1500 名才有清北复交 / 985 主线,普通家庭海南考生**出岛只够上外省末流 211 / 双非**。**出省双非 vs 海大 211 + 海南本省校友圈 + 自贸港红利 = 后者完胜**。见世面可以读研出岛 / 工作出岛,本科留琼 ROI 更高。"

### 4. "海大是西部 211,凑数的 211"
> "**错**。海大是部省合建 + 双一流(作物学)+ 自贸港红利 + 海南唯一 211。**211 招牌在校招 / 考公 / 考研有硬门槛差异**(很多央企 / 海南机关明确"211 及以上",**海大入选,外省双非不入选**)。**海大 ≠ 凑数 211,海大留琼 ROI 高**。"

### 5. "海南考生分数低,在外省竞争吃亏"
> "海南是 900 标准分制(独家),**永远以位次为准,不看绝对分数**。海南考生量只有 6 万 / 年(全国小省第二),**海南考公 / 留琼考研 / 自贸港政策性岗位 = 海南本省考生有独家小省红利友好**。**外省竞争吃亏 = 出岛去外省工作时,但海南本省校招 / 考公 / 自贸港 = 海南考生独家主场**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次(海南 900 分制),跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **海南独家陷阱**:**默认家长"出岛"情节正确而忽略海大 + 自贸港红利留琼路径** —— 普通家庭海南考生留琼 ROI 远高于外省双非

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

**海南独家:留琼 vs 出岛双轨**:对于"想出岛"的普通家庭海南考生,**强制做留琼 vs 出岛双轨对比**:
- **轨道 A:留琼**(海大 / 海医 / 海师大 + 留琼考公 / 自贸港机关 / 海南医院系统)
- **轨道 B:出岛**(外省双非 / 211 + 出岛工作可能性)
- **对比维度**:学费 / 4 年总成本 / 校友网密度 / 留琼率 / 海南房价 / 自贸港红利 / 父母资源复用度

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 海大 / 想学医 / 想出岛 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]

[ 海南独家:留琼 vs 出岛双轨对比 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。
