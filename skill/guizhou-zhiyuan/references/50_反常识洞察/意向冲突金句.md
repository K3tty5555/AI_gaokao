# 用户意向冲突 — Reality Check 金句库(贵州本地视角)

很多家长 / 考生有具体的意向("想上贵大"、"非贵阳不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 1.5 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

**贵州独家纠偏**:
- **不要默认贵大冲档**:贵州考生上省外老牌 985 名额相对宽松(西部专项 + 国家专项 + 高校专项 三个通道),**冲档分数应该优先省外 985,不要为了"留省情绪"选贵大弱专业**
- **不要默认"留黔 = 低薪"**:贵安数据中心起薪 15-25w + 茅台年薪 25-50w + 留黔体制内 4-7k 但编制稳定,**留黔不一定低薪,但要进对路径**

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >1.5 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 300 分要清华 / 530 分要川大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(贵州 530 分,意向川大)**:
> "川大主流组在贵州物理类 4500-7000 名。你 27000 名,差 2 万名,**川大没戏**。
>
> 但你能上贵大主流组 + 三峡大学电气 + 西南民族大学 — 这三所留黔 / 川渝就业,**南网贵州 / 贵安数据中心 / 茅台 招聘里跟川大冷门组校友地位差不多**(都是'西南本地 211/双非 + 留黔同档')。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(贵州考生 + 普通家庭 + 想冲川大)**:
> "川大你 580 能擦边冲 — 但只能进材料 / 化工 / 生命科学。**985 牌子 + 川渝 + 生化环材** = 看着光鲜实际坑。
>
> 同分能上的贵大酿酒工程(双一流学科 + 茅台对口)出来对口程度更高。冲川大留一个心理慰藉位即可,主推贵大酿酒。"

**真实案例 2(贵州冲档兰大)**:
> "兰大你 540 能冲 — 但只能进生命科学 / 草学。**985 牌子 + 西部偏远 + 生化环材** = 三重坑。
>
> 同分能上的贵医临床医学 5+3 一体化(双非但贵州医院主力供给)出来留贵阳当医生 = 真编制 + 真三甲。冲兰大留一个心理慰藉位即可。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华临床 / 北医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(贵州黔东南农村家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k**。农村父母还要供 8 年,期间撑不起。
>
> 撑得起 → 推贵医临床 5+3 一体化(留贵阳当医生),长期天花板高。
>
> 撑不起 → **建议贵医医学影像技术(4 年本科直接进医院技师岗,起薪 7-10k,早 4 年挣钱)**,或者放弃临床走护理(本科 4 年 + 男护士稀缺)。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非贵阳不去" / "非北京不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留贵州没意义,要去西工大),**要灵活退一步**。"

**真实案例(贵州考生 + 想留贵阳 + 想学医 + 590 分)**:
> "你只留贵阳,这位次 8000,贵医临床 5+3 主线全够。
>
> **留贵阳最稳路径**:贵医临床 5+3 一体化 → 毕业进贵州省人民医院 / 贵阳一医 + 编制 + 父母在身边。
>
> 不要为了'外省 985 牌子'去兰大冷门 / 川大边缘组 — 牌子有了但**人脉断了 / 家在贵阳没用了 / 留省校友网弱了**,综合不划算。"

**真实案例 2(贵州考生 + 想出省冲 985 + 580 分)**:
> "你 580 分物理类,想出省冲 985,贵州考生上省外 985 名额相对宽松(西部专项 + 国家专项 + 高校专项)。
>
> 同分省外 985 路径:**重庆大学(电气 / 软件)+ 西南交大(交通)+ 兰大(冷门组)+ 中国海洋大学(冷门组)**,这些 985 弱专业贵州考生有戏,牌子比贵大主流组硬。
>
> 但务必想清楚:**985 弱专业出来想回贵州做什么?**如果想回贵州进体制内 / 大数据中心,**贵大主流组反而更稳**(贵州本地校友网 + 选调资格),不要为了 985 牌子吃专业坑。"

**真实案例 3(贵州少数民族考生 + 想留民族地区)**:
> "你苗族 + 黔东南考生,想留民族地区(凯里 / 都匀 等),这位次。
>
> **留民族地区最稳路径**:贵民大苗汉双语 / 布依汉双语 + 民族岗 → **民族 + 双语 + 民族岗 三重对口,几乎无竞争**。
>
> 不要为了'省外名校牌子'放弃民族岗资格 — 民族岗在民族地区考公竞争小 50%+,这是普通家庭考生独家优势。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 贵大 / 想学医 / 想留贵阳 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 贵州本地高频意向冲突场景(agent 必须熟练处理)

### 场景 1:**"我家孩子 580 分,要不要冲贵大?"**

- 580 分贵州物理类约全省 9000-11000 名 → 贵大主流组(机械 / 电气 / CS)能上,王牌组(酿酒 / 植保)边缘
- **不要默认推贵大** —— 580 分**也能冲省外 985 弱专业**(西部专项 + 国家专项 通道)
- **判断**:**家庭想留贵州 → 贵大;家庭可以接受出省 → 优先冲省外 985**(重大 / 西交 / 西工大 弱专业)

### 场景 2:**"我家孩子要学医,但我家是农村"**

- 直接 reality check:**临床 8 年长周期撑不起**
- 给替代:**贵医医学影像技术 / 检验技术 / 护理学**(4 年本科 + 三甲医院技术岗)+ 国家专项加分进贵医

### 场景 3:**"我家孩子是苗族 / 布依族,加分 5-20 分能冲什么?"**

- 不要让家长自己算加分线 → **直接推荐民族独家路径**:贵民大民族学 / 苗汉双语 / 布依汉双语 + 民族岗
- **少数民族考生考公优势 = 民族岗(竞争小 50%+)** + 民族地区编制倾斜

### 场景 4:**"我家孩子想去贵阳大数据中心挣钱"**

- 留黔挣钱 = CS / 通信 / 大数据 / 网络 / 信息安全 是真路径(起薪 15-25w)
- **门票要求**:**贵大 + 出省 985/211 才有校招资格**,双非贵州 CS 没资格
- **判断**:分数够贵大 CS / 出省 211 → 可以推留黔挣钱;不够 → 推电气 / 师范 / 医学技术 (其他稳定路径)

### 场景 5:**"听说茅台招人很厉害,我家孩子能不能进茅台?"**

- 茅台是真路径,但**不是所有专业都进得去**
- 主要对口:**贵大酿酒工程 / 食品科学(本科技术岗)+ 江南大学酿酒 / 西北农林酿酒 + 出省顶级 985 财务 / 销售 / IT**
- 茅台员工年薪 25-50w,**贵州本地 ROI 顶级**,中产家庭男生 + 喜欢化学化工 推荐

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**贵州独家原则**:**不要默认"留省 = 贵大"**(冲档分数应该优先省外 985);**不要默认"留黔 = 低薪"**(贵安数据中心 + 茅台 + 体制内编制 各有出路);**不要忽略少数民族 + 国家专项的隐藏通道**(贵州考生独家优势)。
