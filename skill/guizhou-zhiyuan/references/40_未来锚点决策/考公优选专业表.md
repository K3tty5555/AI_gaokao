# 考公优选专业表(贵州本地视角)

## 核心结论

**专业决定考公选岗范围**。贵州家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**贵州本地核心事实**:
- 贵州省考竞争比湖南河南江苏宽松一档(考生少 + 西部岗位多)
- **西部计划 / 三支一扶 / 特岗教师**是贵州独家的"曲线编制"通道
- **少数民族岗位**:贵州民族地区有大量"民族岗"(只招少数民族 / 双语干部),**少数民族考生考公竞争极小**
- **选调生**:贵州大学 + 出省 985/211 都有选调资格,**贵州选调每年招录 800-1000 人,比河南江苏宽松**

## 关键事实(2024 国考 / 贵州省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 贵州省考特殊性

- **贵州省考 + 贵阳市考**,**汉语言文学和法学并列考公第一专业**
- 贵州各地市公务员岗位**对法学要求高**(法院、检察院、司法局)
- **贵州县乡基层公务员岗位多**:岗位比例全国前列(贵州 88 个县,每个县每年招 50+ 人)→ **基层愿意去的考生竞争小**
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 500+ 比 1)
- **贵州省考相对宽松一档**:贵州考生少 + 西部岗位倾斜 → 同样的"省考成功率",贵州考生比河南考生高

### 选调生(不是普通公务员,是高潜力路径)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(贵州本地的选调生定向计划:贵大 + 出省 985/211 + 部分省内重点)
- **贵州每年选调录取 800-1000 人**,比河南 / 江苏宽松
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**

### 公检法岗位的硬要求(贵州本地)

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、贵州警察学院等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**贵州警察学院侦查学 / 监狱学** 直接对口

### 贵州独家通道:特岗教师 / 三支一扶 / 西部计划

- **特岗教师计划**:贵州山区中小学教师定向,**3 年服务期满后可入编**,**汉语言 / 数学 / 英语 / 思政 等师范类直接对口**
- **三支一扶**:支教 / 支农 / 支医 / 扶贫,**2 年服务期满后入编 / 报考公务员加分**
- **西部计划**:全国大学生志愿服务西部计划,**贵州是西部计划主接收省**,服务期满后选调 / 公考加分明显
- **农村振兴专项 / 选调村官**:贵州本省独家,服务 3 年后定向入编

### 民族岗(贵州独家)

- 贵州民族地区(黔东南 / 黔南 / 黔西南 / 毕节 / 铜仁 等)很多公务员岗位是**民族岗 = 只招少数民族**
- **苗 / 布依 / 侗 / 土家 / 水 / 仡佬 / 彝 等少数民族考生**,可以报民族岗 = **岗位竞争比汉族岗位小 50%+**
- **双语岗位**(苗汉双语 / 布依汉双语 等):民族语言能力者优先,**专业对口度低也能报**

## 贵州本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业
- **贵州大学法学** — 211 牌子,**贵州法考通过率高,选调路径最优**
- **贵州大学经济学院 / 公共管理学院** — 选调生友好
- **贵州大学汉语言文学** — 选调生 + 省考双友好
- **出省 985/211**(武大 / 中山 / 川大 / 重大 等)— **选调生路径回贵州 = 起点最高**

### 双非 + 性价比考公专业
- **贵州师范大学汉语言文学** — 双非但**贵州省考王者**,毕业考公成功率高 + 公费师范生兜底
- **贵州民族大学法学 / 民族学** — 双非但**民族岗 + 民族干部培养**,贵州民族地区考公独家
- **贵州财经大学会计 / 财政 / 税收** — 双非但**留黔财政 / 税务系统认可度第一**
- **贵州师范学院汉语言** — 双非二本,**贵州县级 / 乡镇汉语言考公的优秀跳板**
- **遵义师范学院 / 凯里学院 / 黔南民族师范学院 汉语言** — 二本但**本地考公 + 当老师的高性价比**

### 公安系统专属
- **贵州警察学院** — 本科,公安联考路径,**毕业进贵州本地公安概率极高**(基层警察 / 县公安局 / 司法系统)
- **贵州警察学院 侦查学 / 监狱学 / 治安学** — 进司法系统专属

### 民族 + 双语岗专属
- **贵州民族大学** 苗汉双语 / 布依汉双语 / 侗汉双语 等专业 → **民族地区双语干部岗,专业对口度极高,竞争小**

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:贵州毕节考生,540 分文史类,**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报贵师大汉语言文学**,毕业当年考上贵州省直某机关公务员,**家族首个体制内**
- **Case B(选调路径)**:贵州贵阳考生,650 分文史类,中产家庭。家长想报"金融"(贵财大)。**改报武大法学(出省 985)**,**毕业获得武大选调生资格,直接进贵州省委组织部**,起点远超经济学就业
- **Case C(民族 + 双语干部路径)**:**黔东南苗族考生**,520 分文史类,农村家庭。家长本想报普通汉语言。**改报贵民大苗汉双语专业** → **毕业进黔东南州民委 / 苗族干部岗**,民族 + 双语双重对口,几乎无竞争
- **Case D(失败路径)**:贵州遵义考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了贵师大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**
- **Case E(误区路径)**:贵州家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case F(特岗教师曲线编制)**:贵州黔南农村女生,520 分文史类,家长本想推她直接考公。**改报黔南民族师范学院汉语言** + 毕业后考特岗教师 → 服务 3 年后入编,**比直接公考稳得多**(双非考生直接公考成功率不高)
- **Case G(三支一扶 + 选调)**:贵州兴义市考生,560 分文科,普通工薪家庭。家长想直接考公。**改报贵大公共管理 + 毕业三支一扶**(支农 2 年贵州山区)→ 服务期满后**定向选调入贵州省直,起点比普通公考高一档**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(贵州 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是贵州家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**少数民族加分对考公没帮助**" — 错!**贵州民族地区有大量民族岗 = 只招少数民族**,且双语干部岗对苗 / 布依 / 侗 等语言能力者倾斜,**少数民族考生考公竞争比汉族小 50%**
- "**贵州山区岗位没人去,所以好考**" — 半对。山区岗位确实竞争小,**但贵州本地家长普遍接受去山区**(因为 4-7k 月薪 + 编制 + 离家近),所以山区岗位不是绝对蓝海,只是相对竞争小

## 关键提醒(贵州独家)

1. **考公是贵州普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是贵州家长被严重低估的考公王者**
2. **贵州省考相对宽松一档**:同样的备考努力,贵州考生考公成功率比河南 / 江苏 / 山东 高 ——但这不意味着随便选专业,**专业选错依然报不上对口岗位**
3. **少数民族 + 民族岗 + 双语干部** 是贵州独家路径,**苗 / 布依 / 侗 / 土家 / 水 / 仡佬 等少数民族考生务必查民族岗 + 双语干部岗信息**
4. **特岗教师 + 三支一扶 + 西部计划 + 选调村官**:贵州独家"曲线编制"通道,服务期满后入编 / 公考加分,**双非考生直接公考成功率不高,这些是更稳的路径**
5. **选调生路径**:贵州选调每年 800-1000 人,**贵大 + 出省 985/211 都可报**,起点比普通公考高一档,**家庭懂体制游戏规则的强烈推荐**
