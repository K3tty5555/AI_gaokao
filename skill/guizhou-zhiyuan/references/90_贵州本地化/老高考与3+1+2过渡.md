# 贵州老高考 → 3+1+2 过渡(2024 首届新高考)

## 核心结论

**贵州 2021 年加入新高考第四批,2024 年首届高考实行 3+1+2**(跟黑龙江/吉林/安徽/江西/广西/甘肃 同批,**全国新高考最后一批省份之一**)。这意味着:**2021-2023 高考还是老高考(文/理科),2024 才是首届新高考**。

**对志愿咨询的最关键影响**:**新口径(物理类/历史类)历年数据只有 2024 + 2025 两年**,样本量极小,大小年风险无法用 3 年数据判断;而 2021-2023 的文/理科数据只能"作为参考",不能直接换算到新口径。

---

## 一、考试结构(新高考 3+1+2,2024 起)

- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制 / 等级赋分**)
- **总分 = 750 分**

### 物理类 vs 历史类

- **物理类** — 选物理为首选(2024 贵州物理类约 56-60%,西部省份理科占比偏高)
- **历史类** — 选历史为首选(约 40-44%)

### 院校专业组

- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量

- **本科批 96 个志愿**(贵州本科批一次性 96 个,不分批次)— **比江苏 40 个 / 湖北湖南 45 个 都多**
- 专科批 96 个

## 二、贵州考生数据画像

- **每年高考报名考生约 47 万**(贵州 2024 高考报名 47.69 万)
- **985 = 0**:本省**没有任何 985**
- **211 = 1**:**只有贵州大学**(西部计划升级 211,2004 年)
- **双一流学科建设高校 = 1**:贵州大学(植物保护)
- **省外 985/211 名额相对宽松**(因为本省考生总数中等,且西部专项计划倾斜)

**结论**:**贵州考生上 211/985 主要靠出省**,本省只有贵大一个 211 选项。

## 三、贵州本地特殊性(志愿决策必读)

### 1. 本省经济相对落后,出省战略是主流

- **本科以上层次:出省占比 50%+**(西南占 25%、广东 15%、长三角 10% 是主要流向)
- **大数据 / IT:留黔有出路**(贵阳是国家大数据综合试验区)
- **公务员 / 事业编 / 教师:留黔为主**

### 2. 大数据产业是贵州独家筹码

- **贵阳 = 国家大数据综合试验区**(2015 年获批,全国第一个)
- **华为 / 腾讯 / 苹果 / 字节 / 中国电信 等都把核心数据中心放贵安新区**
  - 华为云贵安数据中心(亚洲最大)
  - 腾讯七星数据中心
  - 苹果中国 iCloud 数据中心
  - 字节跳动贵安数据中心
- **影响**:**大数据 / 云计算 / 网络安全 / 通信工程 等 IT 类专业留黔起薪 15-20w,跟一线接近**(普通工科留黔起薪只有 6-10w)
- **agent 推荐时务必把"大数据中心就业"作为留黔考生 ROI 最高的路径,不要默认所有理科都是"工科+央企"那套老逻辑**

### 3. 民族多元 → 少数民族加分

- **贵州 56 个民族都有,主要少数民族:苗族 / 布依族 / 侗族 / 土家族 / 彝族 / 仡佬族**
- **少数民族考生有加分政策**(具体加分根据民族 + 地区,5-20 分不等;agent 不深入加分政策细节,只提示"如果是少数民族,记得查当年加分细则")
- **民族班 / 民族专项**:贵州大学 / 贵州民族大学 等都有民族班招生(分数线低 + 专业受限)

### 4. 区域教育资源差异极大

- **教育最强地区**:**贵阳**(贵阳一中 / 清华中学 / 六中 / 实验三中 等)+ **遵义**(遵义四中 / 航天高级中学)
- **第二档**:**黔南州都匀**(都匀一中)+ **黔东南州凯里**(凯里一中)+ **黔西南州兴义**(兴义八中,以前出过状元)
- **相对弱**:**毕节 / 铜仁 / 六盘水**(乡镇高中较多,但近年有上升趋势)
- **影响**:同样位次,贵阳一中第 50 名 ≈ 县中前 10 名;agent 在 L1-A 模考估算时务必结合学校层次

### 5. 留黔 vs 出省 经济收入对比

- **留黔传统行业**(体制内 / 教师 / 医生 / 普通文职):**起薪 4-7k**(税后 5-8w/年)
- **留黔大数据中心**(华为云 / 腾讯七星 / 字节贵安):**起薪 15-20w**(跟一线接近)
- **出省广东 IT**:**起薪 15-25w**(深圳腾讯 / 广州网易)
- **出省成都 IT**:**起薪 12-18w**(成都游戏圈 / 西部互联网)
- **出省长三角金融**:**起薪 12-20w**(上海证券公司)

**关键洞察**:**贵州考生留黔不一定低薪,但必须进对路径(大数据为王)**。普通工科 / 文科留黔则收入明显低。

## 七、易错认知(agent 要纠正用户的)

- **"贵州没 985,出去也比不过别人"** — 错。**贵州考生考省外 985(川大/重大/西交/中山等)分数不高于本省冲贵大 211**,且平台天花板高得多
- **"留贵州只能当公务员 / 老师"** — 错。**贵阳大数据中心是真金白银的高薪 outlet**,只是知道的人少
- **"贵大就是贵州最好的"** — 部分对。**贵大综合性最强**,但**临床医学 → 贵医 / 遵医 更强,师范 → 贵师大更强**(双非不影响这些专业的就业认可度)
- **"民族加分跟分数线直接相加"** — 半对。加分**只对部分院校生效**(教育部直属高校认全国通用加分,部分省外院校只认 5 分以内),具体看院校招生章程
- **"96 个志愿全填学校"** — 错。**96 个志愿每个都是"院校专业组"**,要精准到组,不是只填学校名

## 九、贵州 96 志愿填报策略(本科批 + 专科批)

### 96 个志愿的"冲稳保"分配

贵州 96 个志愿是"院校专业组"志愿,推荐**冲稳保 = 30:50:16 比例**:

- **冲(30 个)**:位次比自己高 5,000-15,000 的专业组(可能录上 / 可能滑档)
  - 主要是 985/211 弱专业 / 边缘专业组
  - 主要是出省名校(西部专项 / 国家专项 通道)
- **稳(50 个)**:位次跟自己±3,000 内的专业组(高概率录上)
  - 主要是贵大主流组 + 同档双非顶配
  - 出省 211 / 双非顶配
- **保(16 个)**:位次比自己低 5,000-15,000 的专业组(几乎一定录上,做保底)
  - 主要是贵州本省双非二本(贵阳学院 / 黔南民族师范 / 凯里学院 等)
  - 部分省外双非性价比专业(三峡大学电气 / 长沙理工电气 等)

### 贵州 96 志愿的"专业组"内细分

每个志愿是"院校专业组",不是"院校" —— 一个专业组内 5-15 个专业,**服从调剂只在本组内**:

- **强烈推荐"勾服从"**:可以避免滑档(只要进组就有专业可读),**适合稳保位次**
- **慎重"勾服从"**:王牌组里有冷门专业 / 独立学院的专业组,**勾服从可能被调剂去不想读的专业**(如贵大酿酒组里有冷门工科,贵医临床组里有护理 / 检验 等)

## 十、贵州专项计划深度解读

### 1. 国家专项计划(贵州独立招生类型)

- **资格**:贵州**专项地区户籍 + 贵州专项地区高中连续就读 3 年**(主要是黔东南 / 黔南 / 黔西南 / 毕节 / 铜仁 等少数民族 + 山区 + 国家级贫困县)
- **覆盖院校**:**全国 95% 的 985/211**(贵大 / 重大 / 川大 / 武大 / 中山 / 华科 / 复旦 / 北大 / 清华 等)
- **优势**:**比统招分低 30-50 分**(贵大约 30 分,985 顶级约 40-50 分)
- **限制**:**毕业后服务期 8 年(原专项地区 / 同省服务)**,**违约要赔学费 + 写诚信记录**
- **推荐**:**贵州山区 + 农村 + 少数民族 考生强烈推荐** —— 跨阶级最快通道

### 2. 高校专项计划(贵州大学 + 出省 985 自主招生)

- **资格**:贵州**农村户籍 + 农村高中就读**(全省农村学生)
- **覆盖院校**:**全国 90+ 所 985/211**(贵大 / 出省 985)
- **优势**:**比统招分低 10-30 分**(贵大约 10 分,出省 985 约 20-30 分)
- **限制**:**毕业后无服务期约束**(比国家专项灵活),**但要参加自主招生 / 综合评价**(部分高校有面试 + 论文)
- **推荐**:**农村学生 + 学习成绩中上 + 想冲名校** 强烈推荐

### 3. 西部专项计划(贵州专属国家政策)

- **资格**:贵州**全省考生**(部分专业限户籍)
- **覆盖院校**:**部属 985/211**(教育部直属高校)
- **优势**:**比统招分低 10-30 分**
- **限制**:**毕业后服务西部 5-8 年**(贵州本省 / 西部其他省都行)
- **推荐**:**贵州城市考生 + 想冲出省 985** 推荐

### 4. 民族骨干人才计划(贵民大 / 中央民大独家)

- **资格**:**少数民族 + 部分专业限世居少数民族**(苗 / 布依 / 侗 等)
- **覆盖院校**:**贵民大 / 中央民大 / 中南民大 / 西南民大** 等民族院校
- **优势**:**比统招分低 30-50 分**,**专门民族干部培养**
- **限制**:**回贵州民族地区服务 5-8 年**(乡镇 / 自治州党政机关)
- **推荐**:**贵州世居少数民族考生 + 想做民族干部** 强烈推荐

### 5. 公费师范生(贵师大 + 部属六大师范)

- **贵师大省属公费**:贵州考生提前批,**学费全免 + 月补助 + 回原籍服务 6 年 + 编制**
- **部属六大师范公费**(华师 / 北师 / 华东师 / 陕师 / 西南大学 / 东北师大):**贵州考生分数较高才能上,但毕业回贵州服务 6 年 + 编制**
- **优势**:**农村 / 工薪家庭性价比之王**

### 6. 少数民族加分

- **贵州世居少数民族考生 + 部分加分(5-20 分,根据民族 + 地区)**
- **本省院校认全部加分**(贵大 / 贵师大 / 贵医 等)
- **省外院校只认 5 分以内或不加分**(各高校招生章程为准)
- **建议**:**填报省外院校时务必查招生章程的"民族加分政策"**
