# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(贵州本地视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**贵州独家变量**:
- **大数据中心 outlet**(贵安数据中心)— 改变了"留黔 = 低薪"的传统逻辑
- **少数民族加分**(苗 / 布依 / 侗 / 土家 / 水 / 仡佬 等)— 贵州专属加分通道
- **国家专项 / 高校专项 / 西部专项** — 贵州农村考生的三个独立通道
- **唯一 211 = 贵大** — 不像湖北 / 江苏有多个 985/211 选项,贵州本地名校稀缺

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障(贵州省直 / 市直 / 县直 / 国企编)。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低,贵州体制内月薪 5-9k)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程 / 选调生路径)
- **孩子考公 / 进国企几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易、有人脉点拨选调

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(贵州体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化)— 贵大 / 出省 985 都有选调资格
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:**贵州警察学院 + 公安联考 = 父母编制资源能用上**;贵中医学 → 贵州省中医院系统编制(父母在卫健委系统的话)
5. **南网贵州 / 国网贵州 / 茅台 / 中烟 等国企**:家庭懂体制游戏规则的话,这些央企国企也是好出路

**典型 case**:
- 贵阳某中产体制内家庭(父亲省直机关,母亲贵州银行)→ 孩子 605 分历史类 → 推贵大法学 → 毕业选调进贵州省委组织部,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去出省 985 CS → 毕业 18w 起薪很高,但家长不满"不稳定 + 不在身边",劝其离职考公,**两年的时间损耗 + 心理纠结**
- 遵义某体制内家庭(父亲市直,母亲县中老师)→ 孩子 590 分物理类 → 推贵医临床 5+3 一体化 → 毕业进遵义市第一人民医院 + 编制 + 家在遵义,**留省内 + 编制 + 父母资源全用上**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(贵师大 / 贵州师范学院);医生家庭 → 临床 / 口腔(贵医 / 遵医 8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → 法学(贵大法学留黔法检院);工程师家庭 → 对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲贵阳一中语文老师 + 父亲普通工薪 → 孩子 615 分历史类 → **公费师范生汉语言**(贵师大) → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是贵州省人民医院临床医生 → 孩子 650 分物理类 → **贵医临床 5+3 一体化** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 父亲贵阳建筑设计院结构工程师 → 孩子 600 分物理类 → 推重庆大学土木工程 → 毕业回贵州进设计院,**父亲行业资源直接对接**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。**贵州本地特点**:**茅台周边产业链 + 老干妈系列 + 贵州茶 / 刺梨 等农产品加工**家庭多;贵阳 / 遵义房地产开发也培养了一批私企家庭。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(贵州出国家庭近年增多,主要走加拿大 / 澳洲 / 香港)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 遵义某酱酒厂老板家庭(年入 500w+)→ 孩子 580 分物理类 → 推**贵大酿酒工程 / 江南大学酿酒** → **学完接班自家酱酒厂**,直接对口 + 家庭基因传承
- 贵阳某私企老板家庭(年入 200w+) → 孩子 580 分物理类 → 推**香港城市大学 / 中外合作办学**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班
- 失败 case:贵阳某餐饮连锁老板家庭 → 孩子被推考公(进社区) → **进基层公务员后被父母嫌"没出息"** → 家庭基因不对路
- 遵义茅台镇酱酒商人家庭 → 孩子 620 分物理类 → 推贵大食品科学与工程 + 酿酒辅修 → **毕业回家管厂 + 同时进茅台供应链关系**,资源叠加

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主。**贵州独家**:贵州本地工薪家庭月入 4-7k 普遍,年薪 10w 左右是中段。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(贵师大 / 贵州师范学院)= 高考分适中 + 直接编制 + 无学费 + 留黔县中**
   - 贵州警察学院 + 公安联考 = 进警察系统编制
   - **医学技术(医学影像 / 检验,贵医 / 遵医)= 三甲医院技术岗 + 4 年本科即可**
   - 殡葬专业 = 100% 编制 + 收入意外不错
3. **次推稳定就业型**:
   - **电气工程进南网贵州**(分够贵大 / 三峡大学 / 长沙理工 等性价比之选)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
   - **CS 进贵安数据中心**(贵大 / 出省 211 才有门票,普通家庭孩子如果 CS 就要死磕贵大)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(贵州本地双非 CS 起薪 5-7k,跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 贵州六盘水工矿家庭 → 孩子 580 分物理类 → 推**三峡大学电气**(2024 进国家电网 644 人,全国 TOP 2)→ 毕业进南网贵州六盘水分公司,**月入 7k + 编制,家庭逆袭**
- 遵义县城工薪家庭 → 孩子 540 分文史类 → 推**贵师大汉语言文学公费师范**(免学费 + 编制)→ 毕业回县中当语文老师,**家庭命运改变**
- 贵阳工薪家庭 → 孩子 605 分物理类 → 推**贵大 CS**(贵安数据中心校招优先校)→ 毕业进华为云贵安数据中心,**起薪 16w + 留贵阳**,普通家庭通过 CS 跨阶级
- 黔南布依族工薪家庭 → 孩子 575 分物理类 + 布依族加分 → 推**贵医临床 5 年制 + 民族岗** → 毕业回都匀市医院当医生,**家族第一个医生**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。**贵州独家**:贵州山区 / 民族地区农村家庭比例全国前列,**毕节 / 黔东南 / 黔南 / 黔西南 等地农村家庭年薪 3-5w 是常态**。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
   - **贵州考生上省外 985 名额相对宽松**(西部专项 + 国家专项 + 高校专项 三个通道)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生**(无学费 + 编制)= 农村家庭神器(贵师大 / 贵州师范学院 / 北师大 / 华师 公费师范都对贵州农村招生)
   - **国家专项计划 / 高校专项**:贵州农村户籍考生有专项指标,**比统招分低 30-50 分**进 985(协和 / 川大 / 中山 / 重大 等)
   - **西部专项**:贵州专属,贵州少数民族 + 山区户籍考生进 985 的隐藏通道
   - **警校 / 军校**(无学费 + 编制 + 包分配):贵州警察学院 / 国防科大 / 陆军军医大
   - **农林牧水**:贵大林学 / 农学,毕业进贵州林业 / 农业系统编制
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:贵州山区农村户籍 → 985/211 名校多个专项指标,**比统招分低 30-50 分**
   - **少数民族加分**:苗 / 布依 / 侗 / 土家 / 水 / 仡佬 等加分,**贵州本省院校(贵大 / 贵师大 / 贵医 等)认全部加分**
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **殡葬专业**(冷门但 100% 编制 + 收入不错)
   - **特岗教师计划 + 三支一扶 + 西部计划**:贵州山区岗位多,服务期满可以入编

**典型 case**:
- **黔东南苗族农村家庭** → 孩子 590 分物理类 + 苗族加分 → 通过**国家专项**进**贵州大学植物保护**(双一流学科,比统招分低 30 分)→ 211 牌子 + 国家专项 + 民族加分 三层叠加,**整个家族第一个 211**,毕业进茅台原料基地或贵州农科院
- **毕节农村女孩** → 605 分文史类 → 推**贵师大公费师范汉语言** → 4 年无学费 + 毕业回原县编制,**最适合贵州农村家庭的"零风险"路径**
- **黔南布依族山区家庭** → 男孩 580 分物理类 → 推**贵医临床 5 年制 + 民族岗** → 民族加分 + 民族岗双重优惠 → 毕业回县医院当医生,**村里第一个本科医生**
- **黔西南山区农村** → 男孩 570 分物理类 → 推**重庆大学电气工程(国家专项)** → 毕业进南网贵州贵阳分公司,**月薪 8k + 编制**,跨阶级
- **铜仁山区农村** → 女孩 550 分文史类 → 推**贵阳学院汉语言**(双非二本) + **三支一扶 + 特岗教师** → 服务期满后入编,**家族首个有编制的人**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 贵州独家 — 家庭档位的隐藏维度

agent 还要额外问 / 推断:
- **是否少数民族?**(苗 / 布依 / 侗 / 土家 / 水 / 仡佬 / 彝 等)→ 加分 + 民族岗倾斜
- **户籍是城市还是山区农村?**(贵阳市区 vs 黔东南山区)→ 国家专项 / 高校专项 资格
- **家庭是否有茅台 / 烟草 / 电网 / 卫健 / 教育 系统资源?**(贵州体制资源高度集中在这几个系统)→ 子承父业可行性

这三个变量,在贵州的权重比湖北大 —— 因为贵州本省"硬资源"少(没 985 / 211 也只有 1 个),家庭软资源(户籍 / 民族 / 体制位置)能多撬动 1 个档位的机会。
