# 贵州医科大学(贵医,GMU)— 双非但临床医学全国前列 + 贵州医院主力供给

## 一句话总结

**双非牌子,但临床医学全国 70-90 名(双非里的医学强校)**。**原贵阳医学院,2015 年更名贵医科大** —— **贵州医院主力供给校**,贵阳 / 遵义 / 黔南 / 黔东南 各级医院骨干基本都是贵医毕业。**法医学全国前列(双非里独一份)**,**预防医学 / 公共卫生** 强势。**学医留黔 = 贵医 vs 遵医 二选一,贵阳留省会 → 贵医,认麻醉学顶级招牌 → 遵医**。**报贵医就是为了学医,医学之外的非医专业(经管 / 文科)别选**。

---

## 真实地位

- **双非**(没有 211 牌子),**临床医学全国 70-90 名**(双非里的医学强校)
- **原贵阳医学院**(1938 年抗战期间国立贵阳医学院创建,根正苗红的老牌医学院),**2015 年更名贵州医科大学**
- **贵州本省地位**:**贵州省人民医院 / 贵阳市第一人民医院 / 各级三甲医院的骨干供给校**,留贵阳当医生贵医是首选(地理 + 校友网络双重优势)
- **同档对比**:跟**重庆医科大 / 哈尔滨医科大 / 南京医科大 / 中国医科大** 一档之后(都是双非但临床顶级),**比贵大医学院强很多**
- **校区**:贵阳南明区(老校区,临床实习便利) / 花溪大学城(新校区) —— **前两年大学城,后期回主城实习**

## 性价比专业(贵医独家招牌)

- **临床医学 5+3 一体化**:**5 年本科 + 3 年规培 = 8 年医生养成**,贵医对接贵州省人民医院 / 贵阳一医 / 二医 标准分配率高,**留黔当主治医师标准路径**。
- **法医学**:**双非里全国独一份,贵医独家招牌**,适合考公(公安系统法医岗 / 司法鉴定中心),**贵州 / 西南公安系统校招认贵医法医**。
- **预防医学**:**疫情后公卫地位上升,贵州 CDC / 卫健委对口**,本科 + 考研路径稳定。
- **护理学**:**本科护士在贵州三甲医院起薪 6-9k**,女生稳定铁饭碗 + 三班倒。

## 坑专业(在贵医里相对弱 / 注意!)

- **医学之外的非医专业(英语 / 思政 / 行政管理 / 经管)**:**算医学院校的"水牌子"**,**报贵医就是为了学医,非医专业别报**
- **生物医学工程 / 医学技术**:**算医学边缘**,出口窄,**学这些不如直接学临床**
- **预防 / 检验 / 公卫(部分细分)**:CDC 编制少 + 出口窄,**不如临床医学**(但疫情后中等性价比)
- **独立学院 / 神奇民族医药学院**:**和本部牌子有差**,**勾报前查清楚**

## 关键提醒(填报陷阱)

1. **临床医学 5+3 一体化 vs 5 年制 vs 4 年制本科**:
   - **5+3 一体化**:分较高,**8 年制规培编制路径稳**,首选
   - **5 年制临床**:5 年本科 + 自找规培,需要单独考研 / 规培 + 努力
   - **4 年制非临床(护理 / 检验 / 影像 等)**:不能当医生,不能改临床,**当心被调剂错**
2. **服从调剂**:贵医组内可能含护理 / 检验 / 公卫等冷门,**勾服从前查清组内有什么** —— 不想做护士 / 公卫的话千万别勾服从。
3. **学医的现实**:**8 年起步月薪 8-15k,30 岁前别想买房**(规培期 + 主治晋升期),**学医苦 + 三班倒 + 医患关系紧张**,家庭抗风险弱的慎重。
4. **学医必须考研**:**本科直接就业很难进三甲**,贵医本科 → 自家附属医院规培 → 考研 985 医学院 = 标准路径。

## 贵州历史类录取位次区间

- 贵医历史类招生量小(主要是英语 / 思政等非医学专业),**不是文科考生主选**。学医必须选物理类(化学 + 生物组合),历史类报贵医基本是**水专业陪跑,慎报**。

**段位定位**:**贵州物理类前 27,000 名内可冲贵医,前 9,000 名可挑临床 5+3 顶级组**。**以一分一段表反查为准,不编分数**。

## 毕业出口(留黔为主 + 成渝补充)

- **留贵州就业**:约 70-75%(**贵阳 50%+ 遵义 / 黔南 / 黔东南 各市三甲 + 县医院**)—— **贵医毕业留黔率是贵州医学高校最高**,因为贵州医院体系全是贵医校友
- **进成渝就业**:约 8-12%(成都 / 重庆 三甲医院,川渝医学体系认贵医)
- **进长三角就业**:约 3-5%(上海 / 杭州 / 南京 三甲医院,主要是 5+3 一体化优秀生考研后流向)
- **进广东就业**:约 3-5%(深圳 / 广州 三甲医院 + 私立医疗集团)
- **考研 / 读博**:约 60%+(**学医必须读研**,本科直接就业很难进三甲)
- **进医院体制(三甲医院 / 区县医院 / 编制岗)**:**80%+** —— 学医本质就是进医院

**关键比较**:贵医本科留黔三甲医院起薪 8-12w(规培期),**主治医师后年薪 15-25w**(贵阳三甲),贵阳生活成本远低于一线,**实际生活水平体面**。**想出省卷北京上海三甲?贵医本科很难,要 5+3 一体化 + 优秀硕博才有机会**。

## 适合谁

- 贵州物理类 **6,500-27,000 名** + 明确想当医生 + 想留贵阳 / 西南医院 的考生
- 想做**法医**(公安 / 司法鉴定系统对口) → 贵医独家招牌
- 想做**预防 / 公卫**(疫情后 CDC 地位上升) → 贵医西南独一档
- **能接受 8 年起步学医周期 + 工作强度大 + 30 岁前不富裕** 的考生
- 家庭抗风险中等以上(可以养孩子到 30 岁主治医师)+ 看重稳定铁饭碗的家庭
- 想做**药学 / 药企方向 + 不想做临床** → 贵医药学好选择

## 不适合谁

- **不确定要不要学医**:学医一辈子,**不喜欢医学别冲贵医**,中途转专业极难
- **家庭抗风险弱 / 必须早工作早赚钱**:**8 年起步太长** —— 可考虑陆军军医大学(军编 + 包分配 + 月津贴)
- **想出省互联网 / 金融大厂**:学医出口就是医院,**不是 IT / 金融 灵活路径**
- **怕脏 / 怕累 / 怕三班倒 / 怕医患**:贵医临床 + 实习 + 规培,**4-8 年都在医院熬夜**
- **想报非医专业(经管 / 文科)**:贵医非医都是水牌子,**直接选贵财 / 贵大 / 贵师大**
- **认麻醉顶级招牌**:**遵医麻醉 > 贵医麻醉**,做麻醉直接遵医

## 临床医学路径细分(贵州考生填报关键)

### 1. 临床医学 5+3 一体化(8 年制本硕连读)

- **录取位次**:贵州物理类全省 6,500-9,000 名
- **培养路径**:**5 年本科 + 3 年规培(直接拿硕士)**,**贵医对接贵州省人民医院 / 贵阳一医 / 贵阳二医 标准分配率高**
- **毕业出口**:**直接进贵州三甲医院 + 编制**,**这是贵州留省学医的最佳路径**
- **适合**:中产家庭 + 想留贵阳当医生 + 能撑 8 年读书

### 2. 临床医学 5 年制(本科)

- **录取位次**:贵州物理类全省 9,000-13,500 名
- **培养路径**:**5 年本科 + 自找 3 年规培 + 自主考研**
- **毕业出口**:**本科直接就业很难进三甲**,需要规培 + 考研提升才能稳定进三甲
- **风险**:**5 年制临床 = 中途路径不确定,需要个人努力 + 家庭撑得住**(规培期月薪 5-8k 撑 3 年)
- **适合**:中产家庭 + 不冲 5+3 但仍想做医生 + 能接受不确定性

### 3. 麻醉学 / 医学影像学(医学学位,5 年制)

- **录取位次**:贵州物理类全省 11,000-15,000 名
- **培养路径**:5 年本科,毕业可直接做麻醉医师 / 影像医师(规培后),**麻醉略弱于遵医,影像跟遵医同档**
- **毕业出口**:贵州三甲医院麻醉科 / 影像科 + 编制
- **适合**:想专精麻醉 / 影像方向(认遵医麻醉招牌 → 直接遵医)

### 4. 法医学

- **录取位次**:贵州物理类全省 13,000-17,000 名
- **培养路径**:5 年法医学本科 + 毕业进公安系统 / 司法鉴定中心 / 法医学研究所
- **毕业出口**:**贵州 / 西南公安系统校招认贵医法医**,**双非里全国独一份**
- **冷门红利**:报的人少 + 行业刚需 + 编制保障,**适合不想做临床但想留医疗系统的考生**
- **特别提醒**:法医学不是"看尸体"那么简单,涉及病理 / 毒理 / 法医临床 / 法医人类学 多个方向,**心理承受力是硬指标**

### 5. 医学影像技术 / 医学检验技术(技术学位,4 年)

- **录取位次**:贵州物理类全省 15,000-22,000 名
- **培养路径**:**4 年本科 + 直接进医院技师岗(影像科 / 检验科)**
- **毕业出口**:**贵州三甲医院技师岗 + 编制 + 起薪 7-10k**(普通家庭神级路径)
- **关键提醒**:**"医学影像技术(技术学位)" ≠ "医学影像学(医学学位)"** —— 报志愿时**专业代码看清楚**!

### 6. 护理学(本科,4 年)

- **录取位次**:贵州物理类全省 18,000-27,000 名
- **培养路径**:4 年本科 + 护士执业资格证 + 三甲医院护理岗
- **毕业出口**:**贵州三甲医院编制护士 + 起薪 4-7k + 五险一金 + 住房补贴**
- **男护士稀缺**:贵医男护士比例极低,起薪比同等学历女生高
- **隐藏路径**:本科护理可以走出国(澳洲 / 加拿大 / 新加坡)做护士移民,贵医每年都有少量学生走这条路

## 校园生活 / 学习氛围(贵州本地视角)

- **大学城新校区**(贵阳花溪):**前两年大一大二在大学城读基础课**,环境新、学习氛围紧张
- **南明区老校区**:**大三起回主城区**,贴近贵州省人民医院 / 贵阳一医 等附属医院,**临床实习便利**
- **学习氛围**:**医学院校学习强度全国统一卷**,贵医也不例外 —— 解剖 / 生理 / 病理 课程密集,**早 7 晚 11 是常态**,不能玩手游 / 谈恋爱过度
- **男女比例**:**临床男女约 4:6,护理 / 药学 女生为主(8:2),法医 / 影像 男生略多**
- **校园文化**:**贵医校友在贵州医院系统的密度极高**,**高年级学长学姐能帮你介绍三甲医院实习 / 规培岗位** —— 这是贵医独家的本地校友资源

## 贵医毕业生职业发展轨迹(贵州考生路径地图)

### 路径 A:留贵阳三甲医院主治医师(标准路径)

- **5+3 一体化** → 毕业进贵州省人民医院 / 贵阳一医 → 主治医师 → 副主任医师 → 主任医师
- **时间表**:本科 5 年 + 规培 3 年 + 主治积累 3-5 年 + 副主任医师 5-8 年 = 30+ 岁
- **薪资轨迹**:规培期 5-8k → 住院医师 8-12k → 主治 1.5-2.5w → 副主任 2.5-4w → 主任 4-6w(贵阳三甲)

### 路径 B:留贵州地市医院当主任(隐藏路径)

- **5 年制临床** → 规培 + 考研 → 毕业回**遵义 / 安顺 / 都匀 / 凯里 等地市三甲医院**
- **时间表**:本科 5 年 + 规培 3 年 + 主治 → 30 岁后能当地市主任医师
- **薪资 + 生活**:贵州地市三甲薪资比贵阳低 20%,但**生活成本低 + 父母在身边 + 不卷**

### 路径 C:出省 985 医学院读研 → 北上广深三甲

- **5+3 一体化** + 优秀成绩 → 考研 985(协和 / 川大华西 / 中南湘雅 / 上交医学院)→ 北上广深三甲
- **时间表**:本科 5 年 + 硕博 6 年 + 主治 → 35+ 岁稳定
- **薪资**:北上广深三甲住院医 12-18k → 主治 25-40w + 学术津贴
- **难度**:贵医本科考研顶级 985 医学院难度高,**每届约 5-10% 学生能走这条路**

### 路径 D:法医 / 公安系统(独家)

- **法医学本科** → 毕业进贵州 / 西南公安系统 / 司法鉴定中心
- **公务员编制 + 起薪 6-8k + 稳定**,**晋升清晰**
- **独家优势**:**贵医法医学双非里全国独一份**,公安系统校招对口度极高

### 路径 E:技师岗位(普通家庭神级路径)

- **医学影像技术 / 医学检验技术**(4 年)→ 直接进贵州三甲医院技师岗
- **起薪 7-10k + 编制 + 不卷**,**职业路径稳定但天花板比医生低**

## 与遵医的精确对比(填报决策核心)

很多贵州考生卡在"贵医 vs 遵医"的选择,这里给精确对比:

| 维度 | 贵医 | 遵医 |
|---|---|---|
| **临床医学整体** | **全国 70-90 + 贵阳留省主力** | 全国 70-90 + 西南医院重镇 |
| **麻醉学** | 强势(贵州省麻醉对口) | **全国前 5,双非独一档** |
| **法医学** | **全国前列(双非独一份)** | 强势(略弱于贵医) |
| **儿科学** | 中上 | **强势(西南儿科储备)** |
| **临床 5+3** | **贵阳省人医对接率高** | 遵义 / 川渝医院对接率高 |
| **留贵阳当医生** | **顶级首选** | 中等(主流向遵义) |
| **留遵义 / 川渝当医生** | 中等 | **顶级首选** |
| **录取分(贵州物理类)** | 中(略高于遵医) | 中(略低于贵医) |
| **大学城便利度** | **贵阳花溪 + 南明老校区,城市便利度高** | 遵义新蒲校区偏 + 大连路老校区 |

**简单结论**:
- **想留贵阳当医生** → **贵医首选**
- **认麻醉招牌(全国前 5)** → **遵医首选,别犹豫**
- **想做儿科医生** → **遵医优先**(儿科储备)
- **想做法医** → **贵医优先**(双非独一份)
- **想去珠三角当医生** → **遵医珠海校区**(地理优势)

## 贵医独家文化(agent 引用时强调)

1. **抗战遗产 + 老牌医学院基因** — **1938 年抗战期间国立贵阳医学院创建**,80+ 年历史,贵州医学根基所在
2. **贵州医院系统的"自家校友"** — 贵阳省人医 / 贵阳一医 / 各市州三甲 院长 / 主任 大多贵医出身,**校友提携文化强**
3. **苗医 / 民族医药融合** — 贵医有苗药 / 民族医药研究方向(虽然不如贵中医强),**少数民族学生 + 民族医药** 是隐藏路径
4. **法医 + 公卫 双非独一档** — 这两个专业不是"水牌子",**全国双非里贵医法医 / 公卫是数得上的强校**
5. **国家专项 / 高校专项进贵医**:**贵州农村考生通过国家专项考贵医 5+3 一体化,比统招分低 30 分**,普通家庭学医的隐藏路径
