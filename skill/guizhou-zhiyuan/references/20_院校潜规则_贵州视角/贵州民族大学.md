# 贵州民族大学(贵民大,GZMU)— 双非但少数民族研究 / 民族学全国前列,民族干部摇篮

## 一句话总结

**双非牌子,但少数民族研究 / 民族学全国前列**。**原贵州民族学院,2012 年更名贵州民族大学** —— **国家民委与贵州省共建**,**民族干部培养基地 + 少数民族研究的省内独家**。**贵州 56 民族都有(全国民族最齐的省份之一)**,**苗语 / 布依语 / 侗语 / 水语 / 彝语** 等少数民族语言文学专业全国独家。**少数民族干部 + 民族系统公务员 + 民族文化研究 = 贵民大独家路径**;**汉族 + 没考公考编计划 → 贵民大性价比一般,可考虑同分省外双非**。**报贵民大就是为了学民族学 / 走民族干部路径,工科 / CS / 财经 别选贵民大**。

## 真实地位

- **双非省属重点**(国家民委与贵州省共建)
- **原贵州民族学院**(1951 年创建,新中国早期民族学院之一),**2012 年更名贵州民族大学**
- **贵州本省地位**:**贵州民族干部培养主力供给校** —— 贵州省民委 / 各市州民委 / 民族文化系统 骨干基本都是贵民大毕业;贵州民族出版社 / 民族文化研究院 / 各民族自治州政府 也是主要出口
- **同档对比**:跟**广西民族大学 / 云南民族大学 / 西南民族大学 / 中南民族大学(部属 211)** 一档之下 —— **中央民族大学 / 中南民族大学 是部属民族院校天花板**,**贵民大跟广西民族 / 云南民族同档**(西南三省民族大学并列)
- **校区**:贵阳花溪大学城(主校区) / 大学城东校区 / 龙里校区(新区)

## 性价比专业(贵民大独家招牌)

- **民族学**:**贵州 56 民族都有(全国民族最齐的省份之一,苗 / 布依 / 侗 / 土家 / 彝 / 仡佬 / 水 / 回 等 17 个世居少数民族)**,**民族研究素材独家** —— 贵民大民族学跟中央民族大学 / 中南民族大学(211)差距小,**双非里独一档**。适合做民族文化研究 / 民族学硕博 / 国家民委系统。
- **少数民族语言文学(苗语 / 布依语 / 侗语 / 水语 / 彝语)**:**全国独家(只有西南三省民族大学 + 中央民族大学开设)**,**贵州各自治州 / 民族出版社 / 民族广播电视台 / 民族文化系统 校招独家**。**少数民族学生 + 想做民族文化系统对口 = 贵民大独家路径**。
- **法学(民族法方向)**:**贵州各民族自治州(黔东南苗族侗族自治州 / 黔南布依族苗族自治州 / 黔西南布依族苗族自治州)法检院** 校招认贵民大民族法,**少数民族干部考公友好**。
- **马克思主义民族理论与政策**:**贵州考公民族系统对口** —— 贵州省民委 / 各市州民委 / 各民族自治州党政机关 招聘认贵民大马民理。

## 坑专业(在贵民大里相对弱 / 慎选)

- **工科 / 计算机 / 电气 / 机械**:**民族院校学工科是怪胎**,出来跟双非一本工科没差,**学工科选贵大或出省**
- **财经类(经济 / 金融 / 会计)**:**民族院校学财经也是边缘**,**学财经选贵财大**
- **新闻传播(非民族方向)**:平庸,出省就业弱
- **教育技术学 / 学前教育**:不是贵民大强项,**学师范选贵师大**
- **独立学院 / 人文科技学院**:**和本部牌子有差**,**勾报前查清是不是本部**

## 关键提醒(填报陷阱)

1. **贵民大本部 vs 贵州民族大学人文科技学院**:**只有本部才认民族学招牌**,人文科技学院是独立学院,**学费贵 + 牌子差**,**别看错代码**。
2. **少数民族加分政策**:贵民大对**少数民族考生有院校加分**(部分专业),**但加分政策每年变化,以当年招生章程为准**。汉族考生报贵民大无民族加分。
3. **少数民族语言文学专业的招生限制**:**部分民族语言专业只招对应民族学生**(苗语只招苗族 / 侗语只招侗族 等),**汉族考生想学民族语言可能受限**,**勾报前查招生章程**。
4. **民族干部定向培养计划**:贵民大有**少数民族高层次骨干人才计划**(部分专业)+ 民族地区定向培养计划,**毕业回原籍服务**,**约束类似公费师范**。
5. **服从调剂**:贵民大组内可能含工科 / 财经等冷门,勾服从前查清。

## 毕业出口(留黔民族系统为主 + 少量出省)

- **留贵州就业**:约 70-75%(**贵阳 + 黔东南苗族侗族自治州 + 黔南布依族苗族自治州 + 黔西南布依族苗族自治州**)—— **贵民大留黔率仅次于贵师大**,因为民族系统就业主要在贵州本省 + 各民族自治州
- **进成渝就业**:约 5-8%(成都 / 重庆 民族文化系统 + 民族企业 + 非遗保护)
- **进长三角就业**:约 4-6%(**上海 / 杭州 / 苏州 民族文创 / 非遗保护 / 民族文化产业**,长三角民族文化市场小但有需求)
- **进广东就业**:约 4-6%(**深圳 / 广州 民族文化产业 + 民族电商 + 文创**,珠三角民族产品市场)
- **考研 / 读博**:约 18-22%(**主要去中央民族大学 / 中南民族大学 / 西南民族大学 + 中山大学人类学 / 北大社会学 等 985/211 民族学硕博**)
- **进民族系统体制内 / 民族干部 / 民族公务员**:**约 30-35%**(**贵州省民委 + 各市州民委 + 各民族自治州党政机关 + 民族法检院 + 民族出版社 + 民族文化研究院**)—— 这是贵民大独家就业池
- **考公**:约 15-20%(**贵州民族系统公务员对口贵民大**,贵州民族系统每年都在贵民大校招)

**关键洞察 — 贵民大民族干部红利**:**贵州各民族自治州党政干部** 招聘特别认贵民大,**少数民族 + 贵民大法学 / 民族学 / 马民理 = 民族干部路径** —— 起步乡镇党政办,5-10 年可晋升县处级,**贵州少数民族干部培养是国家民族政策红利**。**这是其他高校无法替代的独家路径**。

## 同档对比

| 维度 | 贵民大 | 中央民族大学 / 中南民族大学 | 广西民大 / 云南民大 | 西南民族大学 | 贵大民族学方向 |
|---|---|---|---|---|---|
| 牌子 | 双非省重点 | **211 + 部属** | 双非省重点 | 双非部属 | 211(贵大整体) |
| 民族学地位 | **省内第一,西南三省并列** | **全国第一档** | **西南三省并列** | **西南民族学第二档** | 中(不专攻) |
| 留黔民族系统 | **顶级首选** | 中(出省视角) | 一般 | 中(西南视角) | 中(贵大综合) |
| 录取分(贵州) | 中(汉族) / 低(少数民族加分) | **高** | 中 | 中 | 中(贵大整体) |
| 性价比 | **本省民族学最高** | 顶级但门槛高 | 同档可比 | 同档(出省视角) | 弱(贵大民族不专攻) |

**简单结论**:**少数民族 + 想做民族干部 / 民族系统公务员 → 贵民大首选**(独家路径);**冲档想学民族学 + 想要 211 牌子 → 出省冲中央民族大学 / 中南民族大学**;**汉族 + 没考公考编计划 → 贵民大性价比一般,可考虑同分省外双非**。

## 适合谁

- 贵州物理类 **22,000-55,000 名** / 历史类 **7,000-20,000 名** 的考生
- **少数民族(苗 / 布依 / 侗 / 土家 / 彝 / 仡佬 / 水 等贵州世居少数民族)+ 想做民族干部 / 民族系统公务员** —— 贵民大独家路径
- 想学**民族学 / 人类学 / 社会学**(适合做学术 / 智库 / 民族研究院) —— 贵民大民族研究素材独家
- 想学**少数民族语言文学(苗语 / 布依语 / 侗语 / 水语 / 彝语)** —— 全国独家专业
- **少数民族学生 + 想留各民族自治州(黔东南 / 黔南 / 黔西南)党政机关 / 法检院 / 文化系统** —— 贵民大本地校友网密
- 想做**民族文化产业 / 非遗保护 / 民族文创 / 民族电商** —— 贵民大民族艺术 + 苗银苗绣等贵州非遗资源加持
- 想做**贵州民族系统考公(党政民族岗 / 民委 / 民族文化局)** —— 贵民大马民理 + 法学对口

## 不适合谁

- **汉族 + 没考公考编计划 + 想出省做互联网 / 金融**:贵民大双非牌子在长三角 / 珠三角弱,民族学专业出省非民族系统就业难,**考虑同分省外双非更好**
- **想学工科 / CS / 财经**:**贵民大非民族类都是边缘**,学 CS 选贵大,学财经选贵财大,学工科出省
- **追求名校牌子**:贵民大双非,同分能上 211 优先选 211(中南民族 / 西南民族 / 出省 211 同档)
- **不接受贵州民族文化氛围 / 不想做民族系统**:贵民大整体氛围围绕民族文化,**不喜欢民族议题的别选**
- **数学好 + 想做量化 / 数据分析**:贵民大数理基础专业弱,**学量化选贵大 / 贵财大 / 出省**
- **想做西部以外的民族系统**(如西藏 / 新疆 / 内蒙):**优先冲西藏民院 / 中央民大 / 西北民大**,贵民大主要服务西南民族系统
