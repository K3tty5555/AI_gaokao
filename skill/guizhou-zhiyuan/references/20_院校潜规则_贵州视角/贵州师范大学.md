# 贵州师范大学(贵师大,GZNU)— 双非但贵州师范主力 + 留黔教师天花板

## 一句话总结

**双非省属重点,贵州师范主力供给校**,**留黔中小学教师认可度天花板**。**地理学(西南喀斯特地貌研究)国家重点学科 + 全国前列**,**教育学 / 心理学 / 马克思主义理论** 强势,**留黔进贵阳 / 遵义 / 凯里 各市重点中学认可度比省外 211 师范高**。**师范光环只在教育系统才发光** —— 不想当老师的别选贵师大,非师范专业(经管 / 工科 / 计算机)在贵师大都是边缘。

---

## 真实地位

- **双非(普通本科)+ 省属重点**(贵州省人民政府与教育部共建)
- **综合排名全国 200+ 名**,但**贵州中小学教师招聘里贵师大就是首选**
- **贵州本省地位**:**省内师范铁军**,贵阳一中 / 贵阳实验三中 / 遵义四中 / 凯里一中 等省内重点中学的骨干教师大多贵师大毕业
- **同档对比**:跟江西师范 / 云南师范 / 海南师范 一档(西部省属师范主力),**低于华师 / 华中师 / 北师 / 华东师** 等部属六大师范
- **校区**:贵阳花溪大学城(主校区) / 宝山校区(老校区) / 白云校区

## 性价比专业(贵师大独家招牌)

- **地理学**:**西南喀斯特地貌研究全国前列,贵师大独家**(贵州本身就是喀斯特地貌博物馆),适合做学术 / 自然资源 / 地质 / 国土系统。
- **公费师范生**:贵州省属公费师范生 + 部属公费师范代培。**学费 + 住宿费全免 + 月补贴 + 毕业回原籍编制 6 年** —— **农村 / 工薪家庭性价比之王**,但要接受 6 年原籍服务约束。
- **思想政治教育 / 马克思主义理论**:贵州省考思政岗 / 党政办岗对口,**贵州考公友好度仅次于汉语言**。
- **教育学 / 心理学**:全国师范类排名前 30,**适合读研 + 进高校教育系统 / 中小学心理咨询岗**。

## 坑专业(在贵师大里相对弱 / 慎选)

- **非师范类经管(经济 / 工商管理 / 财务 / 会计)**:贵师大经管在贵阳就业不如贵财大,**别选**
- **非师范类工科 / 计算机**:**师范院校学非师范 CS 是怪胎**,出来跟双非一本 CS 没差,**学 CS 直接选贵大或出省**
- **新闻传播**:弱,出省就业弱
- **教育技术学 / 数学与应用数学(非师范方向)**:**听起来像师范但不是公费**,**当心被忽悠**
- **独立学院 / 求是学院**:**和本部牌子有差**,**勾报前看清楚是不是本部**

---

## 关键提醒(填报陷阱)

1. **公费师范生 vs 普通师范生 vs 非师范专业**:
   - 名字里有"师范"且是**提前批录取** → 公费师范(免学费 + 月补贴 + 编制)
   - 名字里有"师范"但是**普通批录取** → 普通师范(自费 + 自找工作)
   - 名字里**没有"师范"** → 非师范专业(在贵师大都是边缘,慎选)
2. **公费师范"原籍服务 6 年"是硬约束**:**违约要赔学费 + 写违约记录**,影响以后考公考编。家长一定要跟孩子聊清楚这 6 年要回原籍(凯里 / 遵义 / 黔南 / 黔东南等)。
3. **贵阳籍 vs 跨州市籍**:贵阳学生上贵师大公费,毕业回贵阳本地编制;**州市学生回原籍**(凯里学生回凯里,遵义学生回遵义)。
4. **服从调剂**:贵师大物理类组内可能含教育技术 / 心理学等冷门,**勾服从前查清组内有什么**。

## 贵州物理类录取位次区间(2021-2025,只给位次)

- **2021-2023(老高考理科)**:全省 **15,000-35,000 名**
- **2024-2025(新高考物理类)**:全省 **17,000-38,000 名**
- **公费师范组(提前批)**:**位次较高**,全省 **15,000-22,000 名**(竞争激烈,免学费 + 编制吸引力大)
- **普通师范组**:全省 **22,000-30,000 名**
- **非师范冷门组**:全省 **30,000-38,000 名**

## 贵州历史类录取位次区间

- **2021-2023(老高考文科)**:全省 **5,000-13,000 名**
- **2024-2025(新高考历史类)**:全省 **5,500-14,000 名**
- **公费师范组(汉语言 / 历史 / 思政)**:全省 **5,000-7,000 名**
- **普通师范 + 非师范组**:全省 **7,000-14,000 名**

**段位定位**:**物理类前 38,000 名内可冲贵师大,前 22,000 名可挑公费师范**;**历史类前 14,000 名可冲,7,000 名内挑公费师范**。**以一分一段表反查为准**。

## 毕业出口(留黔教师为主 + 少量出省)

- **留贵州就业**:约 75-80%(**全省所有本科里留黔率最高**,贵阳 + 遵义 + 凯里 + 黔南 + 六盘水 各市重点中学和县中)
- **进成渝就业**:约 5-8%(成都 / 重庆 民办学校 / 培训机构,体制内编制少)
- **进长三角就业**:约 3-5%(上海 / 杭州 / 南京 民办学校 / 培训机构,**编制基本没机会**)
- **进广东就业**:约 4-6%(深圳 / 广州 民办教育集团 / 培训机构 / 教育公司)
- **考研 / 读博**:约 18-22%(主要去华东师 / 北师 / 西南大学 等)
- **公费师范生 100% 进编制**(回原籍服务 6 年)
- **普通师范生**:约 50% 通过省考 / 市考考编,约 30% 进民办 / 培训,约 20% 改行

**关键洞察 — 贵师大 vs 省外师范**:**贵师大牌子在贵州教育系统认可度比省外 211 师范(华师 / 华中师 / 陕师)高** —— 贵阳一中 / 贵阳实验三中 招聘骨干教师时贵师大毕业生有"本地师承"加分。**想留黔当老师别盲目冲省外名校师范,贵师大本地路径更稳**。

## 同档对比

| 维度 | 贵师大 | 华中师(部属) | 陕师(部属) | 西南大学(985) | 云师 / 江西师(同档) |
|---|---|---|---|---|---|
| 牌子 | 双非省重点 | **211 + 部属** | **211 + 部属** | **985 + 部属** | 双非省重点 |
| 留黔教师认可 | **顶级首选** | 高 | 高 | 高 | 一般 |
| 公费师范名额 | 多(省属公费) | 较多(部属公费) | 较多 | 较多 | 一般 |
| 录取分(贵州) | 中 | **较高** | 较高 | **高** | 中 |
| 性价比 | **本省师范最高** | 中 | 中 | 高(985 牌子) | 中 |

**简单结论**:**想留黔当中小学教师 → 贵师大首选**(本地师承 + 公费师范);**想全国通用师范牌子 / 想出省当老师 → 优先华中师 / 北师 / 华东师 / 西南大学**。

## 适合谁

- 贵州物理类 **17,000-38,000 名** / 历史类 **5,500-14,000 名** 的考生
- **想留黔当中小学教师**(贵阳 / 遵义 / 凯里 等市重点)的考生
- 农村 / 工薪家庭 + 想走公费师范"零成本上本科 + 编制" 路径
- 想学**地理学 / 喀斯特研究 / 西南民族文化** —— 贵师大独家优势
- 想做**贵州考公(党政机关思政岗 / 党办)** —— 贵师大马克思主义 / 思想政治教育对口
- 想做**高校教育系统 / 中小学心理咨询** —— 教育学 / 心理学 适合读研

## 不适合谁

- **完全不想做老师**:**公费要求服务 6 年,违约要赔钱 + 写记录**,慎选公费
- **想出省做互联网 / 金融大厂**:贵师大双非牌子在长三角 / 珠三角弱,出省名校优先
- **想学非师范类经管 / CS / 工科**:贵师大非师范都是边缘,**学经管选贵财大,学 CS 选贵大或出省**
- **追求名校牌子**:贵师大双非,同分能上 211 优先选 211
- **ENTP / 不适合流程化教育的性格**:中小学教师工作强度大 + 重复性强,做好心理准备
