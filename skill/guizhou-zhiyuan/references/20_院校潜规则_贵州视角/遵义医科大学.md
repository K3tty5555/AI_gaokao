# 遵义医科大学(遵医,ZMU)— 双非但麻醉学全国前 5,西南医院重镇

## 一句话总结

**双非牌子,但麻醉学全国前 5(双非里独一档)**。**原遵义医学院,2018 年更名遵义医科大学** —— **麻醉学是老牌特色专业,1986 年全国第一批麻醉学硕士点之一**,**全国麻醉医生有"东遵医、北徐医、南赣医"之说**,跟川大华西、湘雅麻醉排同档。**临床 / 儿科 / 法医** 也强势,**遵义 + 西南医院重镇** —— 川渝黔三省医院都认遵医。**别因为遵义城市层级低就跳过遵医** —— **临床专业最终就业看医院,不看学校所在城市**,遵医校友网在西南医院系统比贵阳还密。

## 真实地位

- **双非**(没有 211 牌子),**临床医学全国 70-90 名,麻醉学全国前 5**
- **原大连医学院 1969 年迁建遵义** —— 三线建设产物,根正苗红的老牌医学院,**2018 年更名遵义医科大学**
- **遵义本省地位**:**遵义医学重镇,西南三线建设医学瑰宝**,遵义 / 黔北 / 黔南 各市医院骨干基本都是遵医毕业,**重庆 / 四川 部分三甲医院麻醉科也认遵医**
- **同档对比**:跟**贵医 / 重医 / 哈医大 / 南京医科大** 一档(双非里临床顶级),**麻醉学单项跟川大华西、湘雅、徐州医科 排同档**
- **校区**:遵义新蒲(主校区,新区) / 大连路老校区 / 珠海校区(广东珠海,2001 年合作办学)

## 性价比专业(遵医独家招牌)

- **麻醉学**:**遵医无可替代的全国招牌** —— 1986 年全国第一批麻醉学硕士点,跟川大华西、湘雅麻醉同档,**全国三甲麻醉科都认遵医麻醉**,这是双非里的天花板专业,**性价比极高**(双非分数换 985 级麻醉路径)。
- **临床医学 5+3 一体化**:**8 年医生养成路径**,遵医在西南三甲医院分配率高,**留黔留渝当主治医师标准路径**。
- **儿科学**:儿科医生全国短缺,遵医儿科储备稳,**适合做儿科医生(累但稳定 + 短缺)**。
- **法医学**:跟贵医并列双非法医前列,**川渝黔公安系统对口**。

## 坑专业(在遵医里相对弱 / 注意!)

- **医学之外的非医专业(英语 / 思政 / 行政 / 经管)**:**水牌子**,**报遵医就是为了学医**
- **生物医学工程 / 医学技术**:边缘冷门,出口窄
- **公共卫生 / 预防医学(部分方向)**:CDC 编制少,出口窄于临床
- **遵义新蒲校区交通**:**新蒲校区比较偏**,**大学城配套不如贵阳花溪**,城市便利度有差
- **珠海校区**(广东珠海合作办学):**和遵义本部不同的招生代码**,**勾报前查清是哪个校区**

---

## 关键提醒(填报陷阱)

1. **遵医本部 vs 遵医珠海校区**:**两套招生代码 + 不同分数**,**珠海校区在广东珠海**(地理优势),**本部在遵义**(麻醉学招牌在本部),**勾报前看清楚**。
2. **临床医学 5+3 一体化 vs 5 年制**:5+3 一体化分较高但出口稳;5 年制要单独考研 + 规培,**不冲 5+3 慎入**。
3. **麻醉学 vs 麻醉医师**:**麻醉学专业本科**学的就是麻醉方向,**毕业可直接做麻醉医师**(规培后),**不是要先学临床再转麻醉**。这是遵医独家路径。
4. **遵义城市层级**:**遵义是地级市,不是省会**,生活便利度低于贵阳。但**临床专业最终就业看医院和校友网,不看学校所在城市** —— 遵医校友网在西南医院系统极密,担心遵义层级低纯属误区。
5. **服从调剂**:遵医组内可能含护理 / 检验 / 公卫,勾服从前查清。

## 贵州物理类录取位次区间(2021-2025,只给位次)

- **2021-2023(老高考理科)**:全省 **7,000-28,000 名**(略低于贵医 0.5-1k 名次,因为遵义城市层级)
- **2024-2025(新高考物理类)**:全省 **7,500-30,000 名**
- **顶级组(麻醉学 / 临床 5+3 一体化)**:全省 **7,000-10,000 名**(**麻醉学因招牌价值,部分年份位次靠前**)
- **主流组(临床 5 年制 / 儿科 / 口腔)**:全省 **10,000-16,000 名**
- **冷门组(护理 / 检验 / 公卫 / 影像)**:全省 **17,000-30,000 名**
- **珠海校区**:位次比本部更靠前(广东地理加分)

## 贵州历史类录取位次区间

- 遵医历史类招生量小(主要是英语 / 思政等非医学),**不是文科主选**,慎报。

**段位定位**:**贵州物理类前 30,000 名内可冲遵医,前 10,000 名可挑麻醉 / 5+3 顶级组**。**以一分一段表反查为准**。

## 毕业出口(留黔 + 成渝医院双向)

- **留贵州就业**:约 50-55%(**遵义 30%+ 贵阳 + 黔南 / 黔东南 各市三甲**)—— **遵医留黔率比贵医低,因为相当部分流向川渝**
- **进成渝就业**:约 18-22%(**重庆 / 成都 三甲医院,川渝医学体系特别认遵医麻醉**)—— **遵医出川渝就业率是贵州医学高校最高**
- **进长三角就业**:约 5-8%(主要是 5+3 优秀生考研后 / 麻醉学硕博流向上海仁济 / 浙大二院 等)
- **进广东就业**:约 8-12%(**珠海校区毕业流向珠三角**,广州中山一 / 深圳人民医院 等)
- **考研 / 读博**:约 60%+(**学医必须读研**,遵医保研率约 8-12%)
- **进医院体制(三甲医院 / 区县医院 / 编制岗)**:**80%+**

**关键洞察 — 遵医麻醉的全国流通性**:**麻醉学医生是全国紧缺岗位**,遵医麻醉本科 + 考研 985 麻醉硕博 → 北上广深三甲麻醉科招聘有戏。**这是遵医独家全国流通路径,贵医没有同等级专业**。**学麻醉别犹豫,直接遵医**。

## 同档对比

| 维度 | 遵医 | 贵医 | 川大华西医 | 徐州医科(麻醉同档) | 重医 |
|---|---|---|---|---|---|
| 临床顶级度 | 全国 70-90 | 全国 70-90 | **全国前 5** | 全国 80-100 | **全国前 20** |
| **麻醉学** | **全国前 5(双非独一档)** | 强势 | **全国前 5** | **全国前 5(双非)** | 强势 |
| 牌子 | 双非 | 双非 | **985** | 双非 | 双非 |
| 留贵阳当医生 | 中(主要遵义) | **顶级首选** | 中 | 弱 | 中 |
| 留遵义 / 西南医院 | **顶级首选** | 中 | 强(成都) | 弱 | 强(重庆) |
| 录取分(贵州) | 中(略低于贵医) | 中 | **高** | 中 | 中高 |

**简单结论**:**学医明确做麻醉 → 遵医首选**(双非里的麻醉天花板,跟徐州医科同档);**学医留贵阳 → 贵医**(地理 + 校友网络);**学医留遵义 + 西南医院 → 遵医**(校友网比贵阳更密);**冲档分数想 985 牌子 → 川大华西 / 中南湘雅 / 重医**。

## 适合谁

- 贵州物理类 **7,500-30,000 名** + 明确想当医生 的考生
- **想做麻醉医师** → **遵医是双非里的天花板,直接选,别犹豫** —— 这是遵医无可替代的全国独家招牌
- **想做儿科医生**(西南儿科储备) → 遵医儿科稳
- **想做西南医院系统**(成都 / 重庆 / 遵义 / 贵阳)→ 遵医校友网密
- **想去珠三角做医生** + 分数中等 → 遵医珠海校区(地理优势)
- **能接受遵义城市层级 + 4-5 年读书** 的考生 —— **遵义不是省会,生活便利度低于贵阳**,但**临床专业最终就业看医院,城市层级是次要因素**
- **能接受 8 年起步学医周期** 的家庭

## 不适合谁

- **不确定要不要学医**:学医一辈子,**不喜欢医学别冲遵医**
- **特别在意学校所在城市层级 / 大学城便利度**:遵义不是省会,大学城配套不如贵阳花溪,**做好心理准备**
- **想出省互联网 / 金融大厂**:学医出口就是医院,**不是灵活路径**
- **怕累怕熬夜怕医患**:麻醉医生工作强度更大(手术全程在场),**心理承受力差的别选麻醉**
- **想报非医专业**:遵医非医都是水牌子,**直接选贵财 / 贵大 / 贵师大**
- **想留贵阳当医生**:**优先贵医**(贵阳本地校友网更密),遵医更多流向遵义 + 川渝
