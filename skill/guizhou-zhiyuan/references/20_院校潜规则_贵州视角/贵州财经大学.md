# 贵州财经大学(贵财大,GUFE)— 双非但财经省内第一,留黔金融体制内首选

## 一句话总结

**双非牌子,但财经类省内第一**。**原贵州财经学院,2012 年更名贵州财经大学** —— **留黔进银行 / 财政系统 / 国企财务 / 公务员(财政岗 / 税务岗) 认可度最高**。**金融学 / 财政学 / 会计学 / 税收学 / 统计学** 是省内财经标杆。**留黔财经路径 = 贵财首选**,**冲投行 / 头部金融力不从心,直接出省冲央财 / 上财 / 西财 / 中南财法** —— 这是贵州财经填报核心反差点。**报贵财就是为了学财经,工科 / 计算机 / 文学 别选贵财**。

---

## 真实地位

- **双非省属重点**(贵州省与教育部共建)
- **原贵州财经学院**(1958 年创建,贵州财经类老校),**2012 年更名贵州财经大学**
- **贵州本省地位**:**贵州省财经类第一**,贵州省银行 / 农村信用社 / 财政厅 / 税务局 / 审计厅 / 国资委 系统骨干基本都是贵财毕业
- **同档对比**:跟**云南财经大学 / 江西财经大学(双非财经第一档)** 一档之下,跟**广东财经 / 浙江财经 / 山东财经** 同档,**低于央财 / 上财 / 西财 / 中南财法 / 东北财大 / 对外经贸** 等老牌财经名校
- **校区**:贵阳花溪大学城(主校区) / 鹿冲关老校区(MBA + 继续教育) / 贵安校区(新区)

## 性价比专业(贵财大独家招牌)

- **会计学 / 财务管理**:**留黔进国企财务最强专业** —— 贵州茅台财务 / 中烟贵州 / 国家电网贵州 等大型国企财务岗 + 四大贵州所 + 贵州本地会计师事务所 校招认贵财会计。**贵州本地 ROI 高**(国企财务岗稳定 + 茅台股票福利 + 体制内编制)。
- **税收学**:**贵财老财经底子的独家专业** —— 国内财经类只有少数高校开设独立税收学专业,贵财是其中之一,**贵州税务系统对口**。
- **金融学**:贵州省银行 / 农信社 / 信托 / 证券 校招认贵财金融,**留黔银行体系编制路径稳**。
- **财政学 / 审计学**:**贵州省考公的财政 / 审计岗对口专业**,**双非里考公性价比顶级**(贵州省财政厅 + 审计厅每年都在贵财校招)。

## 坑专业(在贵财里相对弱 / 慎选)

- **工科 / 计算机 / 软件工程**:**财经院校学非财经 CS 是怪胎**,出来跟双非一本 CS 没差,**学 CS 选贵大或出省**
- **文学 / 历史 / 哲学**:**财经底子的非财经文科都是边缘**,**学文学选贵大 / 贵师大**
- **马克思主义 / 思想政治教育**:贵财不是师范底子,留黔考公思政岗优先贵师大
- **国际经济与贸易**(部分方向):贵州外贸体量小,留黔出口少,出省竞争激烈,**比同分外省财经 211 同名专业弱**
- **独立学院 / 商务学院**:**和本部牌子有差**,**勾报前查清是不是本部**

## 关键提醒(填报陷阱)

1. **贵财大本部 vs 贵州财经大学商务学院**:**只有本部才认贵财财经招牌**,商务学院是独立学院 / 民办,**学费贵 + 牌子差**,**别看错代码报错**。
2. **服从调剂**:贵财物理类组内可能含工科 / CS 等冷门,**勾服从前查清组内有什么** —— 不想读 CS 千万别勾服从。
3. **出省考研路径**:贵财本科 → 央财 / 上财 / 中南财法 / 西财 985/211 财经硕,接受度极高,**贵财是"财经路径出省考研"性价比之王**。
4. **冲投行 / 一线券商 / 头部金融**:**贵财力不从心** —— 中金 / 中信 / 高盛 / 摩根 校招卡 985/211 名单,贵财双非进不了顶级金融机构。**想做投行直接出省冲央财 / 上财**。

- **2021-2023(老高考文科)**:全省 **3,500-10,000 名**(财经类历史 + 物理双招)

## 毕业出口(留黔财经体制内为主 + 长三角 / 广东补充)

- **留贵州就业**:约 60-65%(**贵阳 45%+ 遵义 / 黔南 等市州**)—— **银行 / 财政厅 / 税务局 / 审计厅 / 国企财务 / 四大贵州所** 是主力
- **进成渝就业**:约 8-12%(成都 / 重庆 银行 / 证券 / 财务公司,川渝财经体系认贵财)
- **进长三角就业**:约 8-12%(**上海 / 杭州 / 苏州 银行后台 + 财务共享中心 + 互联网金融**,长三角财经市场认贵财财经底子)
- **进广东就业**:约 6-10%(**深圳 / 广州 银行 / 证券 / 互联网金融**,珠三角财经市场广,贵财校招活跃)
- **考研 / 读博**:约 25-30%(贵财保研率约 5-8%,**主要去央财 / 上财 / 西财 / 中南财法 985/211 财经硕**)
- **进央企 / 国企**:约 25-30%(**贵州茅台财务 / 中烟贵州 / 国家电网贵州 / 中国电信贵州 / 中国农行贵州** 等,贵州大型国企财务岗校招认贵财)
- **考公**:约 15-20%(**贵州省财政厅 / 审计厅 / 税务局 / 各市财政局 校招认贵财财经专业**)

**关键洞察 — 贵财留黔的"国企 + 体制内 + 茅台"红利**:**贵州茅台财务岗 / 中烟贵州财务 / 国家电网贵州财务 等大型国企财务岗** 起薪 8-12w + 福利顶级 + 编制稳定 + 茅台股票福利,**留黔财经路径性价比远超省外双非财经**。**考公贵州财政 / 税务岗对口贵财**,贵财财经专业是贵州考公财政体系的"准对口学历"。

## 同档对比

| 维度 | 贵财 | 央财 / 上财 / 西财 | 中南财法 | 江西财大 / 云南财大 | 贵大经济金融 |
|---|---|---|---|---|---|
| 牌子 | 双非省重点 | **211 + 双一流** | **211 + 双一流** | 双非省重点 | 211 + 双一流 |
| 财经地位 | **省内第一** | **全国第一档** | **全国前列** | **西部 / 中部财经强校** | 中游 |
| 留黔财经认可 | **顶级首选** | 高 | 高 | 中 | 中 |
| 录取分(贵州) | 中 | **高** | **较高** | 中 | 中(贵大整体) |
| 性价比 | **本省财经最高** | 211 顶级 | 211 中段 | 中 | 中(贵大不强财经) |

**简单结论**:**留黔进银行 / 财政厅 / 税务局 / 国企财务 → 贵财首选**;**冲投行 / 一线金融 / 全国流通财经牌子 → 出省央财 / 上财 / 西财 / 中南财法**;**学非财经专业(CS / 工科 / 文学)别选贵财,贵大 / 贵师大 / 出省 是更好选择**。

## 适合谁

- 贵州物理类 **11,000-32,000 名** / 历史类 **4,000-11,000 名** 的考生
- **想留黔进银行 / 国企财务 / 茅台财务 / 财政厅 / 税务局 / 审计厅 / 公务员(财政岗)** —— 贵财是首选
- 女生 + 文理皆可 + 想做会计 / 财务 / 税务 / 审计 / 内审岗 → 贵财性价比之王
- 想走"贵财本 + 985/211 财经硕(央财 / 上财 / 中南财法)" 路径 → 贵财是出省考研最优本科平台
- 农村 / 工薪家庭 + 想要稳定铁饭碗 + 不愿出省 → 贵财兜底

## 不适合谁

- **想冲投行 / 头部金融 / 一线券商**:**贵财力不从心,直接出省冲央财 / 上财 / 西财** —— 一线金融机构卡 985/211 名单,贵财双非进不了
- **想学非财经专业(CS / 工科 / 文学 / 历史)**:**贵财非财经都是边缘**,学 CS 选贵大,学文学选贵师大,学医选贵医
- **追求名校牌子(出省全国通用)**:贵财双非牌子在长三角 / 珠三角弱于一般 211 财经
- **想出省做互联网 / 制造业**:贵财财经路径,不是工科路径
- **数学差 / 不喜欢和数字打交道**:财经类核心是数学 + 数据分析,数学差吃力

## 大小年趋势(贵州本省视角,2021-2025)

- **2021-2023(老高考)**:贵财王牌组(金融 / 会计 / 财政)位次稳定在全省理科 10,000-15,000 名 / 文科 3,500-6,000 名
- **2024(新高考首届)**:**3+1+2 首届大小年**,**贵财金融 / 会计 物理类爆冷一档**(部分家长不熟新政,捡漏机会出现),**财政 / 税收 物理类爆热**(因为家长发现"考公对口")
- **2025(新高考第二届)**:数据回归,**金融 / 会计 物理类回归 11,000-14,000 名**,**财政 / 税收 物理类 12,000-16,000 名**
- **关键观察**:**贵财各专业组之间的位次差距小**(王牌组 + 主流组 + 冷门组 = 集中在 11,000-32,000 名段),**意味着家长选错专业组的"专业价值差距"也小** —— 贵财不是"必须冲王牌组"的学校

## 贵财大毕业生职业发展轨迹

### 路径 A:留黔进银行 / 国企财务 → 中层晋升

- **会计 / 金融 本科** → 毕业进**贵州工行 / 农行 / 建行 / 农信社** OR **贵州茅台财务 / 中烟贵州财务**
- **时间表**:本科 4 年 + 银行柜员 2 年 + 客户经理 3-5 年 + 副行长 / 财务总监 8-15 年
- **薪资轨迹**:银行柜员 5-7k → 客户经理 8-12k → 副行长 1.5-2.5w → 行长 3-5w(贵阳)
- **国企财务**:**贵州茅台财务起薪 12-18w + 茅台股票福利**,中烟贵州 / 国家电网贵州 财务起薪 10-15w + 编制
- **关键优势**:**贵州茅台 / 中烟 等国企福利 + 编制稳定 + 留贵阳父母在身边** = 贵州考生留黔财经的天花板

### 路径 B:考公财政 / 税务 / 审计岗 → 体制内晋升

- **财政 / 税收 / 审计 本科** → 毕业考**贵州省财政厅 / 各市财政局 / 贵州省税务局 / 贵州省审计厅**
- **时间表**:本科 4 年 + 公考成功 + 科员 5 年 + 副主任科员 5 年 + 处级干部 8-15 年
- **薪资 + 路径**:省直机关 7-10k + 公积金 + 编制 + 晋升清晰
- **关键优势**:**贵州省考财政 / 税务 / 审计岗 校招认贵财专业**,**贵财财经专业是贵州考公财政体系的"准对口学历"**

### 路径 C:四大 / 贵州本地会计师事务所

- **会计 / 审计 本科** → 毕业进**德勤 / 普华 / 安永 / 毕马威 贵州所** OR **天健 / 信永中和 等贵州本地所**
- **薪资轨迹**:四大贵州所审计员起薪 8-10w → 高级审计员 12-15w → 经理 20-30w → 高级经理 / 合伙人 50w+
- **关键风险**:**审计行业卷 + 加班严重(年报季 6-7 天 996)+ 跳槽率高**,但**简历背书 + 转行机会** 多
- **隐藏路径**:四大 3-5 年后跳企业财务总监 / 财务公司高管 → 收入翻倍

### 路径 D:出省考研 985 财经硕 → 北上广深金融

- **金融 / 经济 本科** + 优秀成绩 → 考研 **央财 / 上财 / 西财 / 中南财法 / 厦大经济** 985/211 财经硕
- **时间表**:本科 4 年 + 硕 3 年 + 北上广深银行 / 证券 / 投行
- **薪资**:北上广深银行总行 + 证券公司起薪 25-40w,投行 / 资管起薪 50-100w
- **难度**:贵财本科考研 985 财经硕难度高,**每届约 5-10% 学生能走这条路** —— 但**贵财是"财经路径出省考研"性价比之王**(贵财财经底子比贵大经济强)

### 路径 E:互联网金融 / 跨境电商 / 数据分析(新兴)

- **金融 / 统计 / 国贸 本科** → 毕业进**杭州阿里 / 蚂蚁金服 / 字节金融** OR **深圳腾讯金融 / 跨境电商**
- **薪资**:互联网金融起薪 18-25w + 期权
- **门槛**:**学历 + 实习经验 + 数据分析能力**,贵财金融需要自己卷 + 出省实习

## 贵财大 vs 央财 / 上财 / 中南财法 同档对比(贵州考生视角)

| 项目 | 贵财(双非省重点) | 中南财法(211 + 双一流) | 央财 / 上财(211 + 双一流顶级) |
|---|---|---|---|
| 牌子 | 双非省重点 | **211 + 双一流(财经)** | **211 + 双一流(全国财经第一档)** |
| 留黔财经认可 | **顶级首选** | 高 | 中(出省牌子高,留黔贵财校友网更密) |
| 出省金融认可 | 弱(长三角 / 珠三角) | **强(全国通用 211 财经)** | **顶级(投行 / 一线券商认可)** |
| 录取分(贵州) | 中(物理 11,000-15,000 名) | **较高(物理 4,000-7,000 名)** | **极高(物理 1,500-3,000 名)** |
| 性价比(留黔) | **本省财经最高** | 中(高分但出省竞争激烈) | 中(高分浪费,如不出省) |

**简单结论**:**留黔进银行 / 国企财务 / 茅台财务 / 公考财政 → 贵财首选**;**想冲投行 / 一线金融 / 出省名校 → 央财 / 上财 / 中南财法 / 西财**。**贵财不是分数高的考生的目的地,是分数中等想稳定留黔的考生的最优解**。
