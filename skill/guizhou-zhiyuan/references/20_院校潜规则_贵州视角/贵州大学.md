# 贵州大学(贵大,GZU)— 贵州唯一 211 + 双一流,本省综合天花板

## 一句话总结

**贵州唯一 211 + 双一流(植物保护学科)**,**西部计划升级 211**,**贵州考生留黔体制内 / 国企认可度天花板**。**酿酒工程是茅台对口神级专业**(贵大独家无可替代),**植物保护双一流全国前列**。但**全国就业市场牌子明显弱于川大 / 重大 / 兰大** 等老牌西部 985,**冲档分数考生不要默认贵大冲档** —— 贵州考生上省外老牌 985 名额相对宽松。

---

## 真实地位

- **211 + 双一流**(2017 年学科建设高校,**植物保护**入选)
- **西部计划升级 211**(2004 年,跟石河子 / 海大 / 宁大 / 青大 同批)
- **综合排名全国 70-90 名**,跟传统老牌 211 排名差一档
- **贵州本省地位**:**省内一切招聘的最高门槛**,留黔体制内 / 国企 / 选调生 认可度顶级
- **同档对比**:类似宁夏大学 / 青海大学 / 海南大学(西部计划 211 同批),低于川大 / 重大 / 兰大 / 中山等老牌西部名校
- **校区**:贵阳花溪本部(主校区) / 北校区 / 蔡家关校区(原贵州工业大学,工科主力) / 茶学院(湄潭)

## 性价比专业(贵大独家招牌)

- **酿酒工程**:**茅台集团对口贵大,贵州唯一,本地 ROI 顶级** —— 茅台员工年薪体面 + 福利稳定,**这是贵大无可替代的本地路径**。想学酿酒 / 食品工程一定选贵大。
- **植物保护**:双一流学科,**前身贵州农学院**,茅台原料基地 + 农科院系统对口,**适合做农林科研 / 农业体制内**。
- **CS / 软件工程**:贵大 CS 全国排名一般,但**贵阳大数据中心(华为云贵安 / 腾讯七星 / 苹果 iCloud / 字节贵安)校招贵大优先**,**留黔起薪可追平一线 IT**(15-20w),贵大 CS 是隐藏性价比组。
- **法学**:留黔考公考编强势,贵州法检院 / 司法系统 / 选调生 认贵大法学。

## 坑专业(在贵大里相对弱 / 慎选)

- **金融 / 经济**:**比不过贵财大**,留黔进银行 / 财政系统 优先贵财
- **临床医学**:**贵大医学院规模有限,远不如贵医 / 遵医**,学医别选贵大
- **师范类**:贵师大才是贵州师范主力,贵大师范认可度低
- **新闻 / 传播**:平庸,出省就业弱
- **少数民族研究 / 民族学(对比角度)**:贵民大民族学全国前列,做民族研究优先贵民大
- **独立学院 / 应用技术学院**:**和贵大本部牌子有差**,**勾报志愿前看清楚是不是本部**

## 贵州物理类录取位次区间(2021-2025,只给位次)

参考近 5 年掌上高考 + 贵州一分一段表:

- **2021-2023(老高考理科)**:全省 **3,000-12,000 名**(老牌专业组靠前,新工科 / 冷门组靠后)
- **2024-2025(新高考物理类,3+1+2)**:全省 **3,500-13,000 名**
- **顶级组(酿酒工程 / 植物保护双一流 / 王牌临床)**:全省 **3,000-6,000 名**
- **主流组(机械 / 电气 / CS / 法学 / 经管)**:全省 **6,000-10,000 名**
- **冷门组(冷门工科 / 文科调剂)**:全省 **10,000-13,000 名**

## 贵州历史类录取位次区间

- **2021-2023(老高考文科)**:全省 **1,500-4,500 名**
- **2024-2025(新高考历史类)**:全省 **1,800-5,000 名**
- **法学 / 汉语言 / 历史民族学** 录取位次较高,文科冷门组靠后

**段位定位**:**贵州物理类前 13,000 名内可冲贵大,前 6,000 名内可挑王牌组**;**历史类前 5,000 名可冲,1,800 名内挑王牌**。**以一分一段表反查为准,不编分数**。

## 毕业出口(留黔 + 成渝 + 长三角 + 广东)

- **留贵州就业**:约 55-60%(贵阳 35%+ 遵义 / 六盘水 / 黔南 等)—— 贵大留黔率是省内所有高校最高
- **进成渝就业**:约 15-18%(成都 / 重庆 是西南就业第二池,川渝企业认贵大 211 牌子)
- **进长三角就业**:约 8-12%(主要 CS / 工科去上海 / 杭州 / 苏州互联网)
- **进广东就业**:约 6-10%(深圳 / 广州 IT / 制造业,大数据中心毕业生流向多)
- **考研 / 读博**:约 25-30%(保研率约 8-12%,211 中段)
- **进央企 / 国企**:约 20-25%(国家电网贵州 / 贵州茅台 / 中烟贵州 / 中国电信贵州 等)

**关键洞察 — 贵阳大数据中心红利**:**华为云贵安 / 腾讯七星 / 苹果 iCloud(云上贵州运营)/ 字节贵安**等数据中心校招贵大 CS / 通信 / 自动化 起薪 **12-20w**,**苹果 iCloud 数据中心可达 18-25w**(外企薪资)。**留黔 IT = 起薪一线水平 + 贵阳生活成本远低于一线,实际生活水平超北上广深 IT 中段**。这是贵大隐藏 outlet,**想留黔挣钱必走 IT / 大数据 / 通信 路线**。

| 维度 | 贵大 | 川大 | 重大 | 兰大 | 云大 |
|---|---|---|---|---|---|
| 牌子 | 211 + 双一流 | **985 + 双一流** | **985 + 双一流** | **985 + 双一流** | 211 + 双一流 |
| 综合排名 | 70-90 | 全国 15-20 | 全国 30-40 | 全国 35-45 | 全国 60-80 |
| 留黔认可 | **顶级** | 高 | 高 | 中 | 中 |

**简单结论**:**留黔体制内 / 国企 / 茅台 / 农林系统 → 贵大首选**;**冲档分数(刚够贵大)+ 不一定要留黔 → 优先川大 / 重大 / 兰大 / 中山** 等省外老牌 985(贵州考生上省外 985 名额相对宽松,西部专项 + 国家专项 + 高校专项 三个通道)。

## 适合谁

- 贵州物理类 **3,000-13,000 名** / 历史类 **1,800-5,000 名** 的考生
- **想留贵州 + 进体制内 / 国企 / 茅台 / 选调** 的考生(贵大牌子省内天花板)
- 想学**酿酒工程**(茅台对口)/ **植物保护**(双一流) → 贵大独家路径
- 想学**法学 + 考公** 留黔 → 贵大法学留黔法检院认可
- 想学 **CS + 留黔进大数据中心** → 贵大 CS 进华为云贵安 / 腾讯七星 校招池
- 农村家庭 / 工薪家庭 + 想要 211 牌子 + 不愿出省 → 贵大兜底

## 不适合谁

- **冲档分数刚够贵大 + 不一定要留黔**:**省外老牌 985 名额相对宽松,优先冲川大 / 重大 / 兰大**
- **想学医 / 师范 / 财经 / 民族学**:**贵医 / 遵医 / 贵师大 / 贵财大 / 贵民大** 各有更对口的双非选项
- **想出省做互联网 / 金融大厂**:贵大牌子在长三角 / 珠三角认可度弱于一般 985,**出省冲名校优先**
- **想做投行 / 头部金融**:贵大经济 / 金融力不从机,直接出省冲央财 / 上财 / 西财
- **不喜欢山地 / 适应能力差**:贵阳花溪校区在山地丘陵,**心理预期调好**

## 大小年趋势(贵州本省视角,2021-2025)

- **2021-2023(老高考)**:贵大主流组录取位次相对稳定,**理科一本线上 30-50 分基本能上**,文科一本线上 20-40 分能上
- **2024(新高考首届)**:**首届 3+1+2 大小年波动剧烈**(贵州考生不熟悉新口径,部分专业组爆冷或爆热),酿酒工程 / 植保 等王牌组**爆冷一档**(因为家长不熟新政,反而捡漏),CS / 大数据组**爆热**(贵安数据中心红利被家长发现)
- **2025(新高考第二届)**:数据回归相对正常,**酿酒工程位次回归到全省 5,000-7,000 名**(不再是捡漏机会),CS / 大数据组继续高位
- **2026 预测**:第三届新高考,数据样本足够后大小年风险下降,**贵大整体位次预计稳定在物理类全省 4,000-13,000 名 / 历史类 2,000-5,000 名**

## 本科 vs 考研路径(贵州考生视角)

### 贵大本科直接就业(不读研)

- **酿酒工程本科** → 茅台 / 习酒 / 国台 / 金沙 等酱酒厂(留黔顶级 ROI)
- **CS / 通信 / 大数据本科** → 贵安数据中心(华为云 / 腾讯七星 / 字节 / 苹果)起薪 12-18w
- **法学本科** → 选调生 + 贵州省考(留黔体制内)
- **机械 / 电气本科** → 南网贵州 / 中烟贵州 / 贵州能源集团 等国企(起薪 6-8k + 编制)
- **农学 / 植保本科** → 贵州农科院 / 茅台原料基地 / 林业系统(适合农村家庭兜底)

### 贵大考研出省 → 回流贵州 / 留省外

- **保研率约 8-12%**(211 中段),保研主要去向:中科院 / 川大 / 重大 / 武大 / 华中科大 / 浙大
- **考研出省 985**:贵州考生考研北上广深 985 难度比贵大本科直接进同档高,**但比河南 / 江苏考生宽松**(竞争小)
- **考研路径推荐**:酿酒工程考研江南大学 / 植物保护考研华中农大 / CS 考研中科院 / 法学考研武大 / 临床考研川大华西

### 贵大考公考编路径

- **省考 / 市考**:贵大法学 / 汉语言 / 行政管理 / 经济学 → 贵州省考 / 贵阳市考 → 体制内编制
- **选调生**:贵大有选调生定向计划,**每年约 50-80 人**,起点比普通公考高一档
- **出省选调**:贵大学生也可报江浙沪 / 广东 等省的非本地选调,**但成功率低**(主要还是留黔)
