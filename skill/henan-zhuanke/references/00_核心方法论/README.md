# 河南专科 skill 核心方法论

## 河南专科批的三个本省特殊点

1. **125 万考生的尾部 = 50+ 万专科考生**,全国规模最大,**信息差就是命运**
2. **本省考公考编认可度 > 出省找工作**:河南农村家庭 / 工薪家庭对"留河南 + 进体制"几乎是默认偏好
3. **专升本是河南"二次高考"**:报名人数 25 万,**专科 3 年的所有决策都要绕"专升本对口"展开**,选错专科 = 砍半本科选择面

## agent 推理顺序(不能跳)

```
L0  [触发判定] 用户分数本科线下、专科线上 → 进本 skill

L1  [硬数据] 分数 / 位次 / 选科 / 文理类
        ↓
L2  [专升本意愿强度 1-5] ← **这个不问,后续推荐全错位**
        ↓
L3  [家庭画像 + 性别 + 是否独生子女]
        ↓
L4  [行业取向]:护理 / 铁路 / 烟草 / 机电 / 学前 / 其他?
        ↓
L5  [输出 5 所推荐(冲 1 稳 2 保 2)+ 关键提醒]
```

## 专科推荐核心公式(河南版)

```
推荐院校 = 公办强势(黄河水利 / 河南工业职业 / 郑州铁路 / 漯河医专 / 许昌职业)
        × 升本对口面广的专业(护理 / 机电 / 计算机 / 学前 / 教育 / 电气)
        × 本省地缘优势行业(水利 / 烟草 / 铁路 / 食品 / 煤电)
        × 避免民办 + 避免水专业(国贸 / 工商管理 / 市场营销 / 电子商务)
```

## 风格约束

- **不套用湖北案例**:不提三峡大学 / 武汉七校 / 武汉职业技术学院 / 黄冈职业 / 襄阳职业
- **case 用河南地名**:郑州 / 洛阳 / 开封 / 漯河 / 许昌 / 平顶山 / 南阳 / 周口 / 商丘 / 信阳
- **大白话**:不用学术腔,直接给"普通家庭 / 农村女生 / 工薪男生"写决策
- **不编数字**:具体录取分 / 招聘人数 / 薪资范围给区间不给精确值,**关键政策标"以省考试院最新为准"**
