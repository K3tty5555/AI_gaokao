# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(河北视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**河北的特殊语境**:**本省名校稀缺(0 个 985,1 个不在本省的 211)+ 京津虹吸 + 雄安新区政策红利 + 工薪 / 农村家庭比例高**。这意味着对河北家庭而言,**"留河北 vs 出省"** 是除了"档位"之外的第二个核心决策维度,不能跟其他省一概而论。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **河北体制内家庭的特点**:多是石家庄 / 唐山 / 保定 等市级机关、河北各市国企(冀中能源 / 河钢 / 长城汽车河北子公司 / 国网河北电力)、雄安建设相关单位

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化);**河北体制内家庭尤其要关注河北省委组织部年度选调名单 + 雄安选调专项**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校 + 公安联考 = 父母编制资源能用上;**中央司法警官学院(在保定)+ 司法系统对口** 是河北家庭的特殊路径

**典型 case**:
- 石家庄某中产体制内家庭(父亲市直机关,母亲银行)→ 孩子 615 分历史类 → 推中国政法大学 / 西南政法 法学 → 毕业选调进河北省委组织部,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去燕山 CS → 毕业进互联网中型公司 12k,但家长不满"不稳定",劝其离职考公,**两年的时间损耗 + 心理纠结**
- **雄安红利路径**:保定雄安户籍体制内家庭 → 孩子 595 分文史类 → 推河北大学汉语言文学 + 雄安选调 → 毕业进雄安新区编办,**家族首位编制 + 雄安建设红利**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道
- **河北专业家庭特点**:多是石家庄 / 唐山 / 保定 / 邯郸 各市三甲医院医生、各市重点中学老师、河钢 / 冀中能源 / 长城汽车 / 国网河北 工程师子弟

**推荐策略**:
1. **优先子承父业**:教师家庭 → **河北师大公费师范** / 出省 211 师范公费(华师 / 陕师 / 东北师大);医生家庭 → 河北医大 / 出省顶配医(8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → 法学(中政法 / 西政 / 北大法 / 武大法);工程师家庭 → 对应工科(电气进电网 / 机械进装备制造)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)
- **河北钢铁系统子弟**特殊路径:学冶金 / 材料 / 机械 + 父母在河钢 / 首钢京唐 = **接班 + 行业稳定**(虽然钢铁行业下行,但河北钢铁工人编制依然铁饭碗)

**典型 case**:
- 石家庄四中语文老师(母)+ 父亲普通工薪 → 孩子 595 分历史类 → **公费师范生汉语言**(河北师大) → 毕业回石家庄某区编制,**母亲资源直接复用 + 留石家庄**
- 父母都是河北医大一院医生 → 孩子 645 分物理类 → **天津医科大学临床医学**(211 + 离家 + 比河北医大强一档) → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 唐山河钢工程师家庭 → 孩子 580 分物理类 → 推**燕山大学冶金工程 / 材料**(对口河钢)→ 毕业回唐山河钢,**家族企业般稳定**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **河北私企家庭特点**:**比浙江 / 福建少**(河北民营经济不发达,但有局部强势:**唐山民营钢铁企业主 / 沧州管道企业主 / 邯郸服装产业 / 廊坊大厂物流 / 衡水中小企业**);**京津冀边缘私企 + 跨京津冀贸易家庭**

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校,**出省央财 / 上财 / 西财 / 对外经贸**);**别选河北本省双非的工商管理(凑数水专业)**
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野,**河北私企家庭出国比例近年上升**(尤其京津冀外贸家庭 + 唐山钢铁家庭)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 唐山某民营钢铁老板家庭(年入 500w+) → 孩子 590 分物理类 → 推**香港城市大学 / 上海纽约大学(中外合作)** (学费 8-15w / 年家里能撑) → 海外背景做家族企业接班 / 出海贸易
- 沧州管道企业主家庭 → 孩子 615 分物理类 → 推**对外经贸大学国际经济** + 留京 / 京津冀贸易圈,**继承家族业务 + 京津冀贸易枢纽**
- 失败 case:廊坊私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 10-30 万为主。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **河北工薪家庭特点**:**比例最高的家庭档**(河北工薪家庭比例高于湖北 / 江苏)。多是石家庄 / 唐山 / 邯郸 / 保定 城市工人、铁路 / 公交 / 物流职工、各县城商铺店主、河钢 / 冀中煤矿一线工人;**心理倾向"留北方" + "京津距离近接受度高"**(不像安徽 / 江西父母舍不得孩子远离)

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**(河北本地化路径):
   - **河北师大公费师范**(汉语言 / 数学 / 英语 等)= 高考分适中 + 直接编制 + 无学费,**回原户籍市县服务 6 年**
   - **中央司法警官学院(在保定)+ 司法系统对口** = 进司法警察(法警 / 监狱)编制
   - **华电保定电气**(分够)= 进国家电网河北 / 京津冀电力公司 = 编制 + 起薪 8-10k
   - **河北医大 医学影像 / 检验 / 护理** = 进河北各市三甲医院技术岗 + 4 年本科即可
3. **次推稳定就业型**:
   - 燕山机械(分够 + 想读研)= 燕大本 + 哈工大 / 西交 985 硕路径
   - 石家庄铁道大学(土木 / 铁道)= 进中铁系统央企编制(接受 5-10 年基层项目部跑工地)
   - 河北医大临床(分够)= 进河北各市三甲医院(规培 3 年家庭能撑)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-10w,跟双非工科没差,**河北本省没顶尖 CS 校,留省学 CS 死路一条**)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 临床医学(5+3+规培 8 年长周期,普通家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 河北唐山钢铁工人家庭(父亲河钢一线,母亲家属厂)→ 孩子 605 分物理类 → 推**华电保定电气**(国家电网最对口供给校)→ 毕业进唐山供电公司,**月入 9k + 编制,家庭逆袭**
- 河北保定工薪家庭 → 孩子 545 分文史类 → 推**河北大学汉语言文学 / 河北师大公费师范汉语言**(双非但考公 / 教师编王者)→ 毕业当年考上保定某县编制,**家庭命运改变**
- 河北邯郸工薪家庭男生 → 孩子 568 分物理类 → 推**石家庄铁道大学土木工程**(铁道方向)→ 毕业进中铁十二局,**月入 7k + 项目奖金 + 中铁编制,接受 5-10 年项目部基层**
- 河北衡水工薪家庭女生 → 孩子 555 分物理类 → 推**承德医学院医学影像技术**(本科 4 年)→ 毕业进承德市第二医院影像科技师岗,**月入 6k + 编制 + 离家近**
- **失败 case**:河北沧州工薪家庭 → 孩子 575 分物理类 → 父母听亲戚说"计算机有前途",报河北科技大学 CS → 毕业找不到 IT 工作,被迫做销售月入 4k,**典型踩坑**(应该改报华电保定电气 / 河北医大医学影像 / 石铁土木)

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **河北农村家庭特点**:**张家口 / 承德 / 衡水 / 邢台 / 邯郸 各县农村**(燕山山区 + 太行山区 + 黑龙港流域贫困带);**河北国家专项 / 高校专项指标多**(国家级贫困县多)

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**(河北本地化):
   - **河北师大公费师范 + 国家专项**(免学费 + 编制 + 回原县中学)= 河北农村家庭神器
   - **国家专项计划 / 高校专项**:河北燕山山区 / 太行山区 / 黑龙港流域 等贫困县考生,985/211 名校多个专项指标(分数比统招低 20-30 分),**冲北大 / 清华 / 武大 / 华科 等顶配 985 国家专项**
   - **中央司法警官学院(保定)+ 司法系统编制** = 司法警察对口
   - **军校 / 国防生**:免学费 + 编制 + 包分配(国防科大 / 解放军院校)
3. **避免长周期投入**:
   - 医学 8 年(撑不起)→ 改医学技术 / 护理 4 年
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:河北农村户籍考生,985/211 名校多个专项指标,**比统招分低 20-30 分**;**燕山山区 / 太行山区 / 黑龙港流域** 贫困县考生优先
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **公费师范 + 农村专项**:河北师大公费师范有专门的"农村专项"名额,**贫困县农村学生可降分录取 + 免学费 + 6 年回家乡服务**

**典型 case**:
- 河北张家口某贫困县农村家庭 → 孩子 590 分物理类 → 通过**国家专项**进**武汉大学水利水电工程**(比统招分低 30 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985 + 国央企对口**
- 河北衡水某县农村女孩 → 595 分文史类 → 推**河北师大公费师范汉语言(农村专项)** → 4 年无学费 + 毕业回衡水某县中学语文老师编制,**最适合河北农村家庭的"零风险"路径**
- 河北邢台太行山区农村男生 → 580 分物理类 → 国家专项**电子科技大学 CS** → **985 + CS 行业**双红利,毕业进华为 / 字节,**家族首位逆袭**
- 河北承德山区农村男生 → 555 分物理类 → 国家专项**陕师大数学师范公费**(免学费 + 编制 + 回承德教数学)→ 出省读 211 + 编制,**比留省师范双非综合更优**

## 河北家庭额外考量:留省 vs 出省

由于河北本省名校稀缺,**所有档位的河北家庭都要面对一个特殊决策维度:留河北 vs 出省**。

| 家庭档 | 默认倾向 | 推荐战略 |
|---|---|---|
| ① 体制内 | **倾向留河北 / 京津**(资源用得上) | 留河北 + 京津选调 / 雄安红利 |
| ② 专业人员 | **拐杖在哪去哪**(医生家庭可留河北医大,教师家庭可河北师大) | 拐杖优先 |
| ③ 私企 / 创业 | **跟随生意走**(京津冀外贸 / 唐山钢铁系) | 出京 / 沪 / 出国可冒险 |
| ④ 普通工薪 | **倾向"留北方"(京津冀都行,不远走南方)** | 京津冀 211 > 河北本省 + 出省双非 |
| ⑤ 农村 / 临工 | **倾向"出省冲牌子"**(国家专项 + 公费 + 985) | 国家专项是核心工具 |

**关键判断**:
- **能上 985/211(出省 / 京津)→ 出省**(本省没竞争力的牌子)
- **分数只够双非 + 笃定要进编制 → 留河北**(本省双非进河北本地编制概率最高)
- **分数只够双非 + 想要 211 牌子 → 出省冲西北 / 东北性价比 211**(西工大 / 大连理工 / 兰大等)

## 与其他维度的交互(agent 推理顺序)
