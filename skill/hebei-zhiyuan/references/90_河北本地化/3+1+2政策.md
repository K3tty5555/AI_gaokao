# 河北 3+1+2 高考政策

## 核心结论

**河北从 2021 年起实行新高考"3+1+2"模式**(2018 年加入第三批,2021 年首届高考)。**总体规则跟湖北 / 湖南 / 江苏 / 广东 / 重庆 / 福建 / 辽宁 同批**,但**河北最大的特殊性在于**:**名校稀缺(0 个 985 + 1 个不在本省的 211)+ 京津虹吸 + 雄安新区政策红利 + 本科批 96 个志愿(全国最多档之一)+ 历史特控线全国前列**。这套规则比老高考复杂,**家长普遍弄不清楚**,导致填报时容易踩坑。

## 关键事实

### 考试结构(同湖北)
- **3 = 语文 + 数学 + 英语**(全国卷 I,各 150 分,**跟河南 / 山西 / 山东 等同卷**)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(关键!!)
- **物理类**(类型代号 2073)— 选物理为首选的考生
- **历史类**(类型代号 2074)— 选历史为首选的考生
- **两类完全分开排名、分开录取**,**互不影响**
- 河北物理类报考人数约 60-65%,历史类约 35-40%(河北历史类比例略高于湖北)
- **物理类专业选择面广(约 96%);历史类专业选择面窄(约 50%)**

### 12 种选科组合
首选 2 选 1 × 再选 4 选 2 = 12 种组合。常见组合及对应可报专业:

| 选科组合 | 可报专业范围 | 评价 |
|---|---|---|
| 物 + 化 + 生 | **97% 专业**,理工医全能 | 万金油,首选 |
| 物 + 化 + 地 | 96% 专业,工科 + 地学 | 优秀 |
| 物 + 化 + 政 | 96% 专业 + 考公友好 | 平衡型 |
| 物 + 生 + 政 | 90% 专业,但医学受限(部分医学要求"再选化学") | 一般 |
| 物 + 生 + 地 | 89% 专业 | 一般 |
| 物 + 政 + 地 | 80% 专业(理工受限,文理混报) | 慎重 |
| 史 + 政 + 地 | **传统文综组合**,可报 50%+ 专业 | 文科首选 |
| 史 + 政 + 生 | 文史 + 部分医学 | 偏文 |
| 史 + 政 + 化 | 罕见组合 | 慎重 |
| 史 + 化 + 地 | 罕见组合 | 慎重 |
| 史 + 化 + 生 | 罕见组合 | 慎重 |
| 史 + 生 + 地 | 罕见组合 | 慎重 |

### 再选科目专业限制(2024 年最新)
- **再选必含化学**:绝大多数医学(临床、口腔、护理)、化学、化工、材料、生物科学等
- **再选必含生物**:部分医学(生命科学方向)、生物、农林牧、动植物相关
- **再选必含化学和生物**(双选):临床医学、口腔医学的部分院校
- **再选必含政治**:马克思主义理论、政治学、国际关系、思想政治教育、部分公安院校(**中央司法警官学院在保定,部分专业必选政治**)
- **再选必含地理**:地理科学、地质学(部分院校)
- **绝大多数文史经管法学**:再选不限

### 院校专业组(投档单位)
- **不再按"学校"投档,按"院校专业组"投档**
- 一所学校可以有多个专业组(比如华电保定物理类,可能有 5-8 个专业组,**保定校区和北京校区的代码完全不同**)
- **同一学校的不同专业组独立投档,可以独立填报**
- **服从调剂只在本专业组内调剂**(不会被调到其他组)
- 一个专业组内通常 5-15 个专业

### 填报志愿数量(河北独有 ★★★)
- **河北本科批 96 个志愿**(2024 起,**比湖北 / 湖南的 45 个多得多**!**全国最多档之一**)
- **专科批 96 个**
- 每个志愿 = 1 个院校专业组
- **意义**:河北填报"操作空间大",**可以充分铺开冲稳保梯度**(比如冲 30 个 / 稳 40 个 / 保 26 个),也意味着**填错也容易,需要更精细的位次梯度**
- **副作用**:**家长填到第 50 个志愿就开始"凑数"**,**最后 30 个志愿如果不认真排,容易被调到"完全不想读"的学校**

### 投档与录取流程
1. 按位次投档:位次靠前的考生先选自己的 96 个志愿
2. 系统按 1-96 顺序检索投档:**第一个能投到的志愿组,投档**
3. 投档后,本志愿组内按专业最低分录取(如果没录取上具体专业,**服从调剂会被调到本组其他未录满专业**)
4. 不服从调剂 + 没录取上 → **退档,本批次落榜**(滑档)

### 一分一段表(河北位次)
- 高考结束后河北招办发布"一分一段表",**用于换算分数 ↔ 全省位次**
- **位次比分数更准**:不同年份卷子难度不同,但同样位次的考生水平相对稳定
- **报志愿应该看位次,不是看分数**(这是新手家长最常踩的坑)

## 河北最大特殊性(关键!!)

### 1. 河北是**名校稀缺大省**

- **本省 0 所 985**(全国 985 大省中唯一一个零 985 的人口大省级别)
- **本省 1 所 211**:**河北工业大学**(且**校区在天津**,行政归河北,地理在天津)
- **华北电力大学(保定校区)** 是 211 + 双一流,但**主校区在北京,保定校区是分校区性质**,分数比北京校区低 30+ 分
- **燕山大学(秦皇岛)** 是双非里"准 211"(机械全国前 5),但没进 211 名单

**结果**:河北本省考生想上 985/211,**几乎都得出省**。

### 2. 京津虹吸:河北高分考生大量流向北京 / 天津

- 京津高校多 + 距离近 + 经济辐射强
- 河北顶尖考生(物理类前 1500 名)首选清北,其次北邮 / 北航 / 北理工 / 天大 / 南开 等
- **本省高校在高分段没竞争力**(燕山 / 河工大 / 河大 都是双非或准 211)
- **河北家长对"留京津发展"接受度高于其他省**(因为地理近 + 京津就业回河北方便)

### 3. 河北考生数量大 + 分数线极高

- 河北 2024 年高考报名 ~75-80 万(物理类约 50 万 / 历史类约 25 万)
- **河北分数线在新高考省里属于"中高"档**(尤其历史特控线全国前列)
- 同样位次,河北考生竞争比湖北 / 湖南更激烈

### 4. 雄安新区(2017 起)= 河北独家政策红利

- 雄安编办 + 国家部委派出机构 + 雄安建设系统(电力 / 交通 / 教育 / 医疗) 持续扩招
- **雄安户籍 + 雄安选调专项** 是本省特殊路径
- **2017-2035 是雄安建设期** = 河北未来 10+ 年的政策红利

### 5. 京津冀一体化 = 河北就业辐射圈大

- 河北学生留北方就业 = 北京 + 天津 + 河北各市,**实际就业辐射圈比单纯本省大 3 倍**
- 京津冀联合招录(部分公考岗 / 央企岗)= 河北籍倾斜
- **京铁集团 / 国网河北 / 河北分行系统**:京津冀联动岗多

| 年份 | 物理本科 | 物理特控 | 历史本科 | 历史特控 |
|---|---|---|---|---|

| 2022 | 430 | 502 | 443 | 517 |
| 2023 | 439 | 502 | 430 | 521 |
| 2024 | 448 | 511 | 449 | 539 |
| 2025 | 451 | 514 | 449 | 542 |

**河北 vs. 湖北 批次线对比(2024)**:
- 物理本科:**河北 448 / 湖北 437**(河北高 11 分)
- 历史本科:**河北 449 / 湖北 432**(河北高 17 分)
- 物理特控:**河北 511 / 湖北 525**(河北低 14 分)

**关键含义**:**河北本科线比湖北高 10-20 分,历史特控线尤其高**(河北历史类竞争激烈,因为人口大省 + 京津虹吸 + 出省名校多需要高分)。

## 出省战略(河北考生必看)

由于本省名校稀缺,河北考生的**出省方向**比其他省更刚需:

| 流向 | 主要原因 | 代表院校 |
|---|---|---|
| **京 / 津**(主流) | 距离近 + 985/211 多 + 经济辐射(回河北就业仍方便) | 北航 / 北理工 / 北邮 / 天大 / 南开 / 中传 / 北科大 |
| **陕西**(西安) | 西交 / 西电 / 西工大 / 长安 等高性价比 985/211,工科强 | 西交 / 西电 / 西工大 / 陕师大 / 长安 |
| **山东**(济南 / 青岛) | 山大 / 中海大 等,文化习惯接近 | 山大 / 中海大 / 中国石油大学(华东) |
| **东北**(大连 / 哈尔滨 / 长春) | 大工 / 哈工大 / 吉大 等 985,分数比京津低 | 大连理工 / 哈工大 / 吉大 / 东北师大 |

| **南方**(广东 / 浙江 / 江苏) | 跨度大但行业红利强(广东 IT / 浙江民营 / 江苏制造) | 中山 / 浙大 / 南大 / 东南 |

## 河北家长 4 大高频混淆点(★★★ 必查)

### 1. 河大 vs 河工大
- **河大 = 河北大学(保定)**,双非综合
- **河工大 = 河北工业大学(天津)**,211 + 双一流
- **每年都有家长 / 学生填志愿填错**,代码差一个字

### 2. 华电保定 vs 华电北京
- **同一所大学(华北电力大学),两个校区**
- **毕业证一样,但录取代码不同 + 分数差 30+ 分**
- **校招资源差距明显**(国家电网总部 / 五大发电总部多在北京)
- **能上北京校区不要选保定**

### 3. 燕山(双非)vs 真 211
- **燕山是双非**,但机械工程全国前 5(部分专业分数比一般 211 还高)
- **不是 211** — 部分大公司校招卡 211 名单时燕山学生吃亏
- **适合考研路径**(燕山本 + 哈工大 / 西交 985 硕)

### 4. 中央司法警官学院 vs 公安院校
- **中央司法警官学院在保定**,司法部直属,**司法警察对口**(法警 / 监狱 / 戒毒)
- 跟 **中国人民公安大学 / 中国刑事警察学院 / 河北公安警察职业学院** 完全不同(治安 / 刑侦 / 交警)
- **司法警校毕业基本走司法系统**,不是公安系统

## 易错认知(agent 要纠正用户的)

- **"还是按文科 / 理科算的吧"** — 严重过时。河北 2021 年起就没文理分科了,**只有物理类和历史类**
- **"3+1+2 跟老高考差不多,只是叫法不同"** — 错。**录取规则不同,投档单位不同,服从调剂规则不同**
- **"96 个志愿都是学校,选哪个学校都行"** — 严重错误。**96 个志愿是 96 个"院校专业组"**
- **"河工大是河北的 211,留河北上河工大就行"** — 半错。**河工大校区在天津**,生活 / 实习 / 就业全在天津,不算"留河北"
- **"华电保定是 211,跟华电北京一样"** — 错。**保定校区分数低 30 分,但毕业证一样,但实习 / 校招资源差**
- **"服从调剂会被调到本校其他专业"** — 错。**只在本专业组内调剂**,不会跨组
- **"河北分数线 vs 湖北直接比"** — 错。**两省考生数 + 名校结构 + 出省比例完全不同**,看位次不看分数
- **"96 个志愿太多,后面随便填"** — 严重错。**最后 30-50 个志愿是"保底"环节**,**填到第 96 个的考生需要确保最后这个学校 / 专业组是"接受得了"的**,否则一旦掉到那里就是 4 年痛苦
- **"雄安户籍跟普通河北户籍一样"** — 错。**雄安户籍在选调 / 编办招录 / 部分电网岗有政策倾斜**,雄安户籍是河北独家红利
- **"河北历史类比物理类好考"** — 错。**河北历史类特控线全国前列**(2024 年 539 分),**历史类竞争激烈程度反而比物理类高**(尤其想冲 985/211)

## 关键提醒(agent 必须强调)

1. **河北 96 个志愿组**(全国最多档之一),冲稳保梯度要铺开
   - **冲 30 个** + **稳 40 个** + **保 26 个** 是经典配比
   - 最后 26 个保底志愿**绝对不能凑数**,要确保"被录上能接受"
2. **服从调剂**通常推荐勾选,**但要确认本专业组内你能接受的最差专业**
3. **看位次而不是分数**(分数受当年卷子难度影响很大)
4. **再选科目限制**(必选化学 / 必选政治等)是硬约束,**填报前一定核对每个目标专业**
5. **河北本省名校稀缺,出省是常态**,**不要 stuck 在"留河北"思维**
6. **河工大在天津,华电保定在保定**(校区地理 ≠ 学校归属,看清楚再填)
7. **雄安新区招录是河北独家红利**,**雄安户籍 + 河北籍考生 + 选调 / 编办岗** = 政策路径要重点关注
8. **京津冀一体化 = 河北学生出京津就业等于"扩展版本省就业"**,**北京 / 天津 985/211 比留省双非更值**
