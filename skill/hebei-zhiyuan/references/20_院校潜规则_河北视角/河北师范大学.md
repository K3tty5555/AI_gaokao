# 河北师范大学(河师大)— 河北师范主力,留河北当老师对口

## 一句话定位

**河北本省师范主力,公费师范主要供给校**,**留河北当中学老师 / 进教育系统的标配路径**。**双非师范**(跟二档师范大学同档),**教师编 / 公费师范 / 留河北当老师**对口,**非师范专业别报**。

---

## 真实地位

- **双非师范**(河北省与教育部省部共建),无 211 / 双一流标签;师范类学校全国排名约 25-35 位(在双非师大里中上)。
- **河北本省地位**:**河北本省师范第一**(超过石家庄师范 / 唐山师范学院 等地方师范),**河北各市县中学教师主要供给校**。
- **同档对比**:**跟东北师大下一档**(东北师大是 211 师范,河师大是双非),**接近湖北的湖北师大 / 江西的江西师大 / 河南的河南师大** 等省属师范天花板,**比华师 / 北师范 / 陕师 / 西南大学 师范低 1-2 档**。
- **校区归属**:**主校区在石家庄**(汇华校区 / 真定校区),**石家庄是河北省会**,**生活成本低 + 交通便利**(到北京高铁 1.5 小时)。
- **公费师范地位**:**河北省级公费师范** 主要供给校,**毕业直接进河北各市县中学编制**,**6 年服务期 + 不允许跨省 / 跨市流动**。

---

## 河北物理类 / 历史类录取位次区间(参考)

### 物理类
- **公费师范组**:全省 **30,000-50,000 名**(分数比普通组高 + 提前批录取)
- **普通师范组(数学 / 物理 / 化学 / 生物 等师范方向)**:全省 **45,000-65,000 名**
- **普通批冷门组(非师范专业)**:全省 **65,000-90,000 名**

### 历史类
- **公费师范组(汉语言 / 历史 / 政治 / 英语 / 地理 等)**:全省 **8,000-15,000 名**(分数比普通组高 + 提前批)
- **普通师范组**:全省 **15,000-25,000 名**
- **普通批冷门组**:全省 **25,000-35,000 名**

**段位定位**:**公费师范分较高,普通师范中段稳档**,**以一分一段表反查为准**。

## 公费师范生(河师大最大特色 ★★★)

**河北省级公费师范生政策**(每年招生,提前批录取):

- **学费 + 住宿费 全免**(河北省财政承担)
- **生活补贴**:每月 600-800 元
- **毕业直接编制**:**回原户籍所在市 / 县 中学服务 6 年**(河北省内不允许跨市流动)
- **录取分较高**:物理类公费师范约**省排 30,000-45,000 名**,历史类约**省排 8,000-12,000 名**

**最适合**:④ 普通工薪 / ⑤ 农村家庭(经济压力大,公费=零成本上大学)+ 父母希望孩子做老师 / 进体制内 + 性格内向稳健 + 笃定回河北本地。

**最不适合**:完全不想做老师的(违约赔钱 + 影响考公考编档案);想跨省 / 跨市发展的(回原户籍市 / 县流动严格)。

## 性价比专业

- **公费师范汉语言 / 数学 / 物理 / 化学 / 英语**:**免学费 + 编制 + 回河北本地中学**,**普通家庭性价比天花板**
- **学前教育 / 小学教育**:**留石家庄 / 各市县进幼儿园 / 小学编制**,**比中学竞争小一档**
- **心理学**:适合读研 + 进高校教育心理系统 / 心理咨询行业

## 坑专业(在河师大里相对弱)

- **法学 / 经济学 / 金融**:**师范院校学非师范法学 / 经济是怪胎**,出来跟双非一本法学 / 经济没差,**学法学财经选出省综合性大学**
- **计算机 / 工程类**:**师范院校学非师范 CS / 工程是怪胎**,**学 CS 选燕大 / 出省**
- **教育技术学 / 数学与应用数学(非师范)**:**听起来像师范但不是公费**,**当心被忽悠**
- **商务英语 / 旅游管理 / 工商管理**:典型水专业,慎入

## 关键提醒(填报陷阱)

1. **公费师范生 vs 普通师范生 (★★★)**:
   - 名字里有"师范"且是**提前批录取** → 公费师范(免学费 + 编制 + 6 年服务期)
   - 名字里有"师范"但是**普通批录取** → 普通师范(自费 + 自己考编)
   - **千万分清,差几万学费 + 差编制**
2. **公费师范"原籍市 / 县服务 6 年"是硬约束 (★★)**:石家庄户籍回石家庄各区县,唐山户籍回唐山各区县,衡水 / 沧州 / 张家口 等同理。**违约赔学费 + 写违约记录影响考公考编**,家长必须跟孩子聊清楚 6 年要回原籍。
3. **服从调剂注意**:可能调到教育技术 / 心理学非师范方向 / 边缘文科,**接受不了的别勾**。
4. **河师大 vs 河大**:**想当老师 / 公费师范 → 河师大**;**想做综合性文科 / 考公不当老师 → 河大**;两校录取分相近,选错赛道难转。
5. **河师大 vs 出省 211 师范**:**分够 211 师范(华师 / 陕师 / 东北师大 / 西南大学)→ 优先 211 牌子**(公费全国通用);**分不够 + 笃定留河北 → 河师大公费师范**;**别"分够 211 公费却选河师大公费"** —— 211 牌子价值远大。

## 毕业出口(2024 数据,粗略)

- **公费师范生**:**100% 进入河北省内市县中学教师编制**(分配回原户籍市 / 县)
- **普通师范生**:**约 50-60% 通过省考 / 市考考编**,约 25% 民办 / 培训机构,约 15% 改行
- **非师范类**:**约 50% 留河北 + 30% 出省 + 20% 考研**,就业不如纯综合双非
- **进体制内总比例**:**约 60-70%**(教师编 + 公务员 + 事业单位),起薪河北中学编 4-6k + 五险一金 + 寒暑假

## 同档对比

| 维度 | 河师大 | 华师(211) | 东北师大(211) | 河大(双非综合) |
|---|---|---|---|---|
| 牌子 | 双非师范 | **211 师范** | **211 师范** | 双非综合 |
| 师范实力 | 河北第一 | **华中第一** | 东北第一 | 师范专业弱 |
| 留河北就业 | **极高** | 一般 | 一般 | **极高** |
| 公费师范名额 | 多(河北省级) | 多(国家级) | 多(国家级) | 无 |
| 跨省认可度 | 河北省内强 | **全国通用** | **东北 + 全国** | 河北省内 |

**简单结论**:**笃定留河北当老师 → 河师大公费师范优先**(零成本 + 编制);**分够 211 → 出省 211 师范公费(华师 / 陕师 / 东北师大)**(全国通用 + 牌子大);**想做综合性文科不当老师 → 河大**(综合性更全)。

## 适合谁

- 河北物理类**省排 30,000-90,000 名** / 历史类**省排 8,000-35,000 名**
- **笃定回河北当中学老师 / 进教育系统**
- 父母希望孩子稳定 + 进体制内
- 普通工薪 / 农村家庭(公费师范零成本上大学)
- 性格内向稳健 + 接受 6 年服务期 + 接受河北本地工资水平
- 学科兴趣明确(语 / 数 / 英 / 理 / 化 / 生 / 史 / 地 / 政)

## 不适合谁

- **完全不想做老师的**(公费 6 年服务期违约成本高)
- **想跨省 / 跨市发展**(公费要求回原户籍市 / 县)
- **ENTP / ENFP 等不适合流程化教育的性格**
- **想学法学 / 财经 / CS / 工科**:河师大非师范专业弱,选对应专门校
- **分够 211 师范**:出省 211 师范公费 + 牌子大,河师大双非吃亏
- **想做综合性文科不教书**:选河大综合性更好
