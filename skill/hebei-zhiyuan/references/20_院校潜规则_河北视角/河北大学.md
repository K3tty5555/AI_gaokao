# 河北大学(河大)— 保定双非综合,文学历史认可度尚可

## 一句话定位

**河北本省综合性双非天花板之一**(跟河北师大并列双非综合 + 师范两强),**没有全国前列的招牌专业,但文学 / 历史 / 法学 / 新闻** 在河北本地认可度尚可。**留河北当老师 / 考公 / 进事业单位** 的对口校之一,**牌子在河北以外认可度有限**。

---

## 真实地位

- **双非综合性大学**(河北省与教育部省部共建),无 211 / 双一流标签;**学科评估全国靠后**,A 类学科 0,B+ 学科少。
- **河北本省地位**:**与河北师大并列河北省内综合性双非两强**(综合性主打文理 + 师大主打师范),**河北本地考公 / 事业单位 / 中学教师认可度高**。
- **同档对比**:跟陕西的延安大学 / 山西的山西大学 / 内蒙古大学 等省属双非综合性大学水平相近,**学校综合实力中等偏上,但缺乏顶尖招牌专业**。
- **校区归属**:**主校区在保定市**(河大本部 + 七一路校区),**离北京高铁 1 小时**,但**保定生活节奏 + 产业薄弱** 导致实习 / 校招机会有限。
- **特别说明**:河北大学和河北工业大学完全不同 — **河大不是 211,河工大才是 211(且校区在天津)**,河北家长经常混淆。

### 河大的历史血统
- **1921 年由天津工商学院**(法国天主教耶稣会)创办
- **1960 年迁到保定**,改名"河北大学"
- **1970 年河大整体迁出保定**,后来又迁回保定
- **缺乏国家重点投入** = 错过 211 工程 + 错过双一流
- **结果**:**省部共建双非,综合性偏文 + 法学 / 历史 / 新闻 在河北本省认可度高**,但全国没有顶尖招牌专业

### 雄安新区带来的政策红利
- **2017 年雄安新区设立后,河大被纳入"雄安建设支撑高校"**
- **雄安选调 / 雄安编办招录** 河大文科生(汉语言 / 法学 / 行政管理 / 城乡规划)是政策受益者
- **河大 + 雄安路径**(2017 起)= 河大文科生最大的隐性红利

## 河北物理类录取位次区间(参考)

- **物理类高分组(临床医学 / 计算机 / 法学)**:全省 **35,000-55,000 名**
- **物理类主流组(理工科 + 经管)**:全省 **55,000-75,000 名**
- **物理类冷门组**:全省 **75,000-95,000 名**
- **历史类高分组(汉语言 / 法学 / 新闻)**:全省 **8,000-15,000 名**
- **历史类主流组**:全省 **15,000-25,000 名**

**段位定位**:河北物理类**省排 95,000 名内可冲河大**,**35,000 名内挑高分专业**;**历史类省排 25,000 名内**,**以一分一段表反查为准**。

### 大小年趋势(2021-2025 观察)
- **2021-2022**:稳定在双非中段
- **2023**:**法学 / 汉语言组分数走高**(雄安选调红利发酵)
- **2024**:**整体微涨**(留省考公热)
- **趋势**:**河大文科组分数有缓涨压力**(因为雄安红利 + 河北考公热),工科组持续低迷

### 中国语言文学 / 历史学 / 新闻传播 — 河大文科核心
- **学科评估 B**(双非里中等偏上)
- **本省考公 / 教师编 / 雄安选调** 主要供给
- 出口:**河北各市政府机关 / 河北日报 / 长城新媒体 / 中学语文老师 / 雄安编办**
- **河大文学院出来的人**在河北本省党政机关 / 媒体系统比例不低,**校友网络对体制内就业有用**

### 法学 — 河北本省政法系统对口
- 学科评估 B 中等(双非法学常见水平)
- **河北各市法院 / 检察院 / 司法局 / 律所** 校招认可度高
- **法考通过率约 30%**(双非法学正常水平),**通过法考 + 河大法学** 在河北本地律所有竞争力
- **进顶级红圈所基本无门**(红圈所看 985/211/五院四系)

## 性价比专业(河大独家路径)

- **汉语言文学 / 历史学 / 新闻传播**:**留河北当中学老师(考编)+ 考公(党政机关)+ 进河北本地媒体**直接对口,**普通工薪家庭文科生求稳路径**
- **法学**:**河北本省政法系统 / 法检系统招公** 时河大法学有本省加成,**但律所就业受双非拖累**
- **临床医学(本硕连读)**:**进河北各市县医院** 对口,**比纯综合医院双非好一档**(但不如河北医科大学医学专业)
- **历史学 + 雄安**(隐性路径):**雄安建设期文物保护 / 文化产业岗** 招录历史学

## 坑专业(在河大里相对弱)

- **CS / 软件工程**:河大 CS 是纯双非 CS,**毕业起薪 8-10k,跟任何普通双非 CS 没差**,**学 CS 出河北直接选燕大 / 北邮 / 西电 / 电子科大**
- **大部分理工科**:河大理工不强,**学工科男生别选河大,选燕大 / 河工大**
- **经管 / 金融 / 工商管理**:河大非财经强校,**学财经直接选央财 / 上财 / 出省财经 211**
- **小语种(除英语外)**:河大小语种师资少,**学小语种选北外 / 上外 / 西外**

## 关键提醒(填报陷阱)

1. **河大 ≠ 河工大 (★★)**:
   - **河大 = 河北大学(保定),双非综合**
   - **河工大 = 河北工业大学(天津),211 + 双一流**
   - **每年都有家长 / 学生填志愿填错**,代码差一个字
2. **河大就业辐射范围(★)**:**河大牌子在河北本省强 + 京津冀其他地方一般 + 出省基本无认可度**。**适合笃定留河北的考生**,**想出省发展不要选河大**(双非综合 + 地域局限)。
3. **学医路径要分清**:**学医选河北医科大学 > 河大临床**(河北医大是医学专门校,河大医学是综合校副业)。
4. **服从调剂注意**:可能被调到冷门理工 / 部分文科边缘专业,**接受不了的别勾**。
5. **公费师范 vs 河大汉语言**:**想当老师选河北师大公费师范**(免学费 + 编制);**河大汉语言要自己考编**,**师范定向程度低于河师大**。
6. **保定地理优势**:**离北京 1 小时高铁 + 离雄安 30 分钟** = 实习 / 找工作可以辐射京津冀 + 雄安。**河大学生大三大四去北京 / 雄安实习成本低,这是河大隐性优势**。

## 留省内 vs 出省路径

### 留省内路径(河大主战场)
- **河北各市政府机关 + 雄安编办**:汉语言 / 法学 / 行政管理 主要去向
- **河北各市中学语文老师 / 历史老师**:本科 + 教师资格证 + 考编
- **河北日报集团 / 长城新媒体 / 各市电视台**:新闻 / 中文 主要去向
- **河北各市法院 / 检察院 / 律所**:法学 + 法考 主要去向
- **河大临床 → 河北各市三甲医院**(比纯综合双非有医学拐杖)

### 出省路径
- **考研 / 读博到 985 文科(北大 / 武大 / 华师 / 南师文学 / 中政法法学)**
- **京津媒体 / 律所**(部分河大新闻 / 法学毕业生)
- **跨省考公**(冷门省份的省考 / 选调对河大文科有认可度)

## 适合家庭画像

### 强推
- **河北农村 / 工薪家庭 + 文科生 + 笃定留河北**:河大文科 + 考公 / 教师编 = 改命路径
- **保定 / 雄安户籍家庭 + 想留本地**:**地理优势 + 雄安红利**双重利好
- **体制内家庭子弟**:河大文科 + 父母资源 + 雄安选调 = 稳定上升
- **想做河北本地律师 / 法检院公务员**:河大法学 + 法考 + 河北本地认可

### 不推荐
- **追求名校牌子 + 出省发展**:河大牌子出河北无认可度,选 211 / 985
- **想学工科**:河大工科边缘,选燕大 / 河工大
- **想学 CS / 互联网大厂**:河大 CS 双非天花板,选燕大 CS / 出省
- **想学医做医生**:河大临床不如河北医科大学,选河北医大
- **想做律师 + 进顶级律所**:律所招聘看 985/211/五院四系,河大法学进不了红圈所
- **分够 211**(河工大 / 华电保定 / 中国矿大):**别为留保定选河大**,211 牌子价值远高于河大双非

## 毕业出口(2024 数据,粗略)

- **留河北就业**:**约 60-70%**(河北各市县中学 / 政府 / 事业单位 / 媒体 / 法检 系统大头)
- **去北京 / 天津就业**:约 10-15%(京津冀一体化部分人去北京媒体 / 私企)
- **出省就业**:约 10-15%(主要去山东 / 北京周边 / 长三角)
- **考研 / 读博**:约 15-20%(汉语言 / 历史 / 法学读研出路较好)
- **考公 / 考编**:**约 25-30%**(河大文科生考公 / 考编是主流路径)
- **进央企 / 国企**:相对低,约 10-15%
- **起薪范围**:体制内编制 4-6k(稳定 + 五险一金),私企媒体 5-8k,CS 8-10k
- **5 年后**:体制内副科级 7-10k + 福利,中学老师 5-8k + 寒暑假,媒体记者 8-12k(看个人)

## 典型 case(供 agent 引用)

- **Case A(经典留省考公)**:河北衡水考生,工薪家庭女生,545 分文史类(全省 12000 名)→ 河大汉语言文学 → 4 年期间考行政能力测试 + 申论 → 毕业当年考上河北省考某省直机关综合岗 → 起薪 5k + 编制 + 公积金,**家庭命运改变**
- **Case B(雄安红利)**:河北保定(雄安户籍)考生,普通家庭女生,580 分文史类 → 河大新闻传播 → 毕业考雄安编办文宣岗 → 起薪 6k + 编制 + 雄安建设期红利
- **Case C(河大法学)**:河北邯郸考生,工薪家庭男生,560 分文史类 → 河大法学 → 4 年通过法考 → 毕业进邯郸某中型律所 + 后考上邯郸某区法院 → **法学 + 法考 + 河北本地** = 体制内路径
- **Case D(临床医学)**:河北承德考生,工薪家庭女生,560 分物理类 → 河大临床医学(本硕连读)→ 7 年后进承德医学院附属医院,**回家乡医院 + 综合性大学医学拐杖**
- **Case E(失败路径)**:河北唐山考生,中产家庭女生,575 分物理类 → 父母听说"河大综合性大学不错"报河大金融学 → 毕业进河北本地银行柜员月薪 4.5k → **应该改报央财 / 上财金融 + 出省**(河大金融在金融行业无认可度)
- **Case F(混淆陷阱)**:河北沧州考生,工薪家庭男生,612 分物理类 → 父母想报"河北 211 工业大学" → 实际填错代码,**填的是河大代码**(误以为是河工大)→ 录取后才发现是河大双非,**复读一年代价**
