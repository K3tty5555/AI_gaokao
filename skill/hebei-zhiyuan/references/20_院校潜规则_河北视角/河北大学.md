# 河北大学(河大)— 保定双非综合,文学历史认可度尚可

## 一句话定位

**河北本省综合性双非天花板之一**(跟河北师大并列双非综合 + 师范两强),**没有全国前列的招牌专业,但文学 / 历史 / 法学 / 新闻** 在河北本地认可度尚可。**留河北当老师 / 考公 / 进事业单位** 的对口校之一,**牌子在河北以外认可度有限**。

---

## 真实地位

- **双非综合性大学**(河北省与教育部省部共建),无 211 / 双一流标签;**学科评估全国靠后**,A 类学科 0,B+ 学科少。
- **河北本省地位**:**与河北师大并列河北省内综合性双非两强**(综合性主打文理 + 师大主打师范),**河北本地考公 / 事业单位 / 中学教师认可度高**。
- **同档对比**:跟陕西的延安大学 / 山西大学 / 内蒙古大学 等省属双非综合性大学水平相近,**学校综合实力中等偏上,但缺乏顶尖招牌专业**。
- **校区归属**:**主校区在保定市**(河大本部 + 七一路校区),**离北京高铁 1 小时**,但**保定生活节奏 + 产业薄弱** 导致实习 / 校招机会有限。
- **特别说明**:河北大学和河北工业大学完全不同——**河大不是 211,河工大才是 211(且校区在天津)**,河北家长经常混淆。

---

## 河北物理类录取位次区间(参考)

- **物理类高分组(临床医学 / 计算机 / 法学)**:全省 **35,000-55,000 名**
- **物理类主流组(理工科 + 经管)**:全省 **55,000-75,000 名**
- **物理类冷门组**:全省 **75,000-95,000 名**
- **历史类高分组(汉语言 / 法学 / 新闻)**:全省 **8,000-15,000 名**
- **历史类主流组**:全省 **15,000-25,000 名**

**段位定位**:河北物理类**省排 95,000 名内可冲河大**,**35,000 名内挑高分专业**;**历史类省排 25,000 名内**,**以一分一段表反查为准**。

## 性价比专业(河大独家路径)

- **汉语言文学 / 历史学 / 新闻传播**:**留河北当中学老师(考编)+ 考公(党政机关)+ 进河北本地媒体**直接对口,**普通工薪家庭文科生求稳路径**
- **法学**:**河北本省政法系统 / 法检系统招公** 时河大法学有本省加成,**但律所就业受双非拖累**
- **临床医学(本硕连读)**:**进河北各市县医院** 对口,**比纯综合医院双非好一档**(但不如河北医科大学医学专业)

## 坑专业(在河大里相对弱)

- **CS / 软件工程**:河大 CS 是纯双非 CS,**毕业起薪 8-10k,跟任何普通双非 CS 没差**,**学 CS 出河北直接选燕大 / 北邮 / 西电 / 电子科大**
- **大部分理工科**:河大理工不强,**学工科男生别选河大,选燕大 / 河工大**
- **经管 / 金融 / 工商管理**:河大非财经强校,**学财经直接选央财 / 上财 / 出省财经 211**
- **小语种(除英语外)**:河大小语种师资少,**学小语种选北外 / 上外 / 西外**

## 关键提醒(填报陷阱)

1. **河大 ≠ 河工大 (★★)**:
   - **河大 = 河北大学(保定),双非综合**
   - **河工大 = 河北工业大学(天津),211 + 双一流**
   - **每年都有家长 / 学生填志愿填错**,代码差一个字
2. **河大就业辐射范围(★)**:**河大牌子在河北本省强 + 京津冀其他地方一般 + 出省基本无认可度**。**适合笃定留河北的考生**,**想出省发展不要选河大**(双非综合 + 地域局限)。
3. **学医路径要分清**:**学医选河北医科大学 > 河大临床**(河北医大是医学专门校,河大医学是综合校副业)。
4. **服从调剂注意**:可能被调到冷门理工 / 部分文科边缘专业,**接受不了的别勾**。
5. **公费师范 vs 河大汉语言**:**想当老师选河北师大公费师范**(免学费 + 编制);**河大汉语言要自己考编**,**师范定向程度低于河师大**。

## 毕业出口(2024 数据,粗略)

- **留河北就业**:**约 60-70%**(河北各市县中学 / 政府 / 事业单位 / 媒体 / 法检 系统大头)
- **去北京 / 天津就业**:约 10-15%(京津冀一体化部分人去北京媒体 / 私企)
- **出省就业**:约 10-15%(主要去山东 / 北京周边 / 长三角)
- **考研 / 读博**:约 15-20%(汉语言 / 历史 / 法学读研出路较好)
- **考公 / 考编**:**约 25-30%**(河大文科生考公 / 考编是主流路径)
- **进央企 / 国企**:相对低,约 10-15%
- **起薪范围**:体制内编制 4-6k(稳定 + 五险一金),私企媒体 5-8k,CS 8-10k

## 同档对比

| 维度 | 河大(双非综合) | 河师大(双非师范) | 山西大学(双非综合) | 河大综合排名 |
|---|---|---|---|---|
| 牌子 | 双非综合 | 双非师范 | 双非"双一流" | 全国 100-120 名 |
| 王牌 | 文学 / 历史 / 法学 / 新闻 | 教育 / 学科师范 | 物理 / 哲学 | 综合中等 |
| 河北本省地位 | **综合双非第一** | **师范双非第一** | 跨省竞争 | |
| 留河北就业 | **极高** | **极高** | 一般 | 河北最优 |
| 出省认可度 | 一般 | 一般 | 中(双一流加成) | 受限 |
| 考公 / 考编对口 | 强 | **极强(教师编)** | 中 | |

**简单结论**:**留河北 + 综合性 / 文科 → 河大**;**留河北 + 当老师 → 河北师大公费**;**想跨省读双非综合 + 想要双一流牌子 → 山西大学 / 内蒙古大学**;**学法学想做律师 → 出省五院四系 + 西政 / 中政法**;**学医 → 河北医科大学**;**有 211 分数 → 河工大 / 华电保定**。

## 适合谁

- 河北物理类**省排 35,000-95,000 名** / 历史类**省排 8,000-25,000 名**
- **笃定留河北就业 + 考公 / 考编 / 当老师 / 进事业单位**
- **文科生 + 想学汉语言 / 新闻 / 历史 / 法学**
- 普通工薪 / 农村家庭,想要稳定路径 + 不在意"双非"标签
- 性格内向稳健 + 接受河北本地工资水平(4-7k 起薪)

## 不适合谁

- **追求名校牌子 + 出省发展**:河大牌子出河北无认可度,选 211 / 985
- **想学工科**:河大工科边缘,选燕大 / 河工大
- **想学 CS / 互联网大厂**:河大 CS 双非天花板,选燕大 CS / 出省
- **想学医做医生**:河大临床不如河北医科大学,选河北医大
- **想做律师 + 进顶级律所**:律所招聘看 985/211/五院四系,河大法学进不了红圈所
- **分够 211**(河工大 / 华电保定 / 中国矿大):**别为留保定选河大**,211 牌子价值远高于河大双非
