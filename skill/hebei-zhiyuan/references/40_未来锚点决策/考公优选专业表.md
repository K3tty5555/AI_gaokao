# 考公优选专业表(河北本地视角)

## 核心结论

**专业决定考公选岗范围**。河北家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**河北考公的特殊性**:
1. **国考 + 河北省考 + 11 地市市考 + 雄安新区招录 + 京津冀联合岗** = 5 套招录系统
2. **雄安新区(2017 起)是河北独有红利**:每年雄安编办 + 国家机关派出机构招录,**汉语言 / 法学 / 行政管理 优势岗多**
3. **京津冀一体化**:部分央企 / 部委河北分支岗位招录考虑河北籍优先(京铁 / 国网河北 / 河北分行系统)
4. **河北省考竞争激烈但岗位绝对数大**(75-80 万考生体量)

## 关键事实(2024 国考 / 河北省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 河北省考特殊性
- 河北省考 + 11 地市市考(石家庄 / 唐山 / 保定 / 沧州 / 邯郸 / 邢台 / 衡水 / 张家口 / 承德 / 廊坊 / 秦皇岛),**汉语言文学和法学并列考公第一专业**
- 河北各地市公务员岗位**对法学要求高**(法院、检察院、司法局)
- **基层乡镇公务员**(燕山山区 / 太行山区 / 黑龙港流域 县乡):岗位多,大类放宽,**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)
- **河北各市分化**:**雄安新区 / 廊坊(临京)/ 石家庄主城** 竞争最激烈;**张家口 / 承德 / 衡水 各县乡岗** 竞争温和(经常出现 5:1 以下)

### 雄安新区招录(★ 河北独家红利)
- **雄安编办** + **雄安党工委办公室** + **雄安建设领导小组办公室** 持续招录
- **国家部委派驻雄安机构**:司法 / 教育 / 医疗 / 环保 / 自然资源 / 文化等部委均在雄安设派出机构
- **优势专业**:汉语言文学 / 法学 / 行政管理 / 城乡规划 / 建筑学 / 工程管理 / 经济学
- **雄安户籍优先 + 河北籍倾斜**(部分岗位)
- **薪资 + 编制 + 雄安未来发展红利** = 河北家庭最该关注的政策红利

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(河北本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **河北选调主供给**:出省 985/211(因为本省 985 数量为 0)+ 河工大(本省唯一 211)+ 华电保定 + 燕山(部分名额)
- **雄安选调专项**:针对雄安建设的额外选调名额,**985/211 河北籍学生重点关注**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、河北公安警察职业学院 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒、法警**:法学 + 监狱学,**中央司法警官学院(在保定)是司法部直属唯一警校,司法系统对口**

## 河北本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业(出省)
- **武汉大学法学** — 全国前 5,**法考通过率高,选调路径最优**(出省)
- **中国政法大学 / 西南政法 法学** — 五院四系,**河北考生考公认可度极高**(出省)
- **中国人民大学 / 北大法 / 北大中文 / 北师大文学** — 出省顶配
- **天津大学 / 南开大学 / 北航 / 北理工 法学 / 经济** — 出省京津 211/985,**离河北近 + 牌子强**

### 河北本省 + 强势考公专业
- **河工大法学 / 经济学**(211 + 双一流,校区在天津)— 河北唯一 211 牌子,毕业进河北 / 京津考公认可度高
- **华电保定经济学 / 法学**(211)— **行业型 211 + 进国家电网相关法律 / 经济岗** + 考公辅助
- **河北师大 汉语言文学(公费师范生)** — 不是考公但是教师编制,**等同于考公友好**

### 双非 + 性价比考公专业(留河北)
- **河北大学汉语言文学 / 法学 / 历史学 / 新闻**(双非)— 河北本省考公王者,**留河北考公 / 进事业单位 / 进雄安编办** 直接对口
- **河北经贸大学 法学 / 经济学**(双非)— **河北本省经济 / 法学双强双非**,留河北考税务 / 财政对口
- **燕山大学法学 / 文学**(双非)— 燕大文科边缘,**学考公专业别选燕山**(燕山强项是工科)

### 公安 / 司法系统专属
- **中央司法警官学院(保定)** — **司法部直属唯一警校**,本科,**毕业进全国司法系统(法警 / 监狱 / 戒毒)**;**河北本省录取多,提前批必报**
- **河北公安警察职业学院**(石家庄,专科)— 公安联考路径,**进河北本地公安基层概率极高**
- **中国人民公安大学 / 中国刑事警察学院**(出省)— **公安系统顶配**,公安联考路径

### 雄安新区路径专属
- **河北大学 + 雄安选调**(汉语言 / 法学 / 行政管理 / 经济)
- **河工大 / 华电保定 + 雄安专项**(管理类 / 经济类)
- **出省 985/211 + 雄安选调**(全国 985/211 部分定向雄安选调名额)

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:河北衡水考生,540 分文史类,**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报河北大学汉语言文学**,毕业当年考上河北省直某机关公务员,**家庭命运改变**

- **Case B(选调路径)**:河北石家庄考生,650 分文史类,中产家庭。家长想报"金融"(出省央财)。**改报武大法学**,**毕业获得武大选调生资格,直接进河北省委组织部 / 雄安选调**,起点远超经济学就业

- **Case C(雄安红利)**:河北保定(雄安户籍)考生,580 分文史类,普通家庭女生。**报河北大学汉语言文学**,毕业考雄安新区编办,**雄安建设期 + 汉语言 + 户籍倾斜** 一次过省考,**编制 + 雄安事业岗 + 政策红利**

- **Case D(司法路径)**:河北唐山考生,565 分物理类,普通工薪家庭男生。家长本想"考公兜底"。**报中央司法警官学院 监狱学**(在保定提前批)→ 毕业通过司法警察联考进入河北某监狱系统,**100% 编制 + 离家近**

- **Case E(失败路径)**:河北邯郸考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了燕山大学计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**

- **Case F(误区路径)**:河北家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(河北 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是河北家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**雄安编办跟石家庄编办差不多**" — 错。**雄安建设期红利明显**(2017-2035),职级晋升空间 + 项目机会 + 政策倾斜 都比传统省直岗强,**985/211 学生 + 河北籍 + 雄安选调** = 最优路径
- "**中央司法警官学院 = 公安大学**" — 错。**司法警察 ≠ 公安警察**(司法警察是法警 / 监狱 / 戒毒,在司法部体系;公安警察是治安 / 刑侦 / 交警,在公安部体系)。**两者考公路径不同**,司法警校毕业基本走司法系统

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是河北家长被严重低估的考公王者**。

**河北考公的政策红利** = **雄安新区 + 京津冀一体化** + **11 地市分散招录**。河北家长别只盯着"省考"两个字,**雄安建设期红利(2017-2035)** + **京津冀联动岗** + **11 地市市考机会分散** 这三点是河北独家优势,远超中部其他省份。
