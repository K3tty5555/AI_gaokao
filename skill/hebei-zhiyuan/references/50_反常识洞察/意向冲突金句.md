# 用户意向冲突 — Reality Check 金句库(河北视角)

很多家长 / 考生有具体的意向("想上河工大"、"非北京不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

**河北独家原则**:
6. **"留河北 vs 出省" 是河北家庭额外的硬决策**(本省名校稀缺 + 京津虹吸,河北家长普遍纠结此事)
7. **"河工大 / 华电保定 / 中央司法警官学院" 是河北家长容易混淆的三个 211 / 准 211 / 双非"特殊校"**,要分清各自的真实定位

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 480 分要清华 / 540 分要河工大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(河北 540 分,意向河工大)**:
> "河工大物理类主流组在河北 28000-42000 名。你 60000 名,差 2 万名,**河工大没戏**。
>
> 但你能上河北科技大学 + 华北理工 + 河北工程大 — 这三所在河北本省国企 / 体制内招聘里**跟河工大冷门组校友地位差不多**(都是'河北本省双非工科 + 留省同档')。
>
> 退一步,你 60000 名能冲**燕山的冷门组(部分文科 / 经管)**,燕山是双非但'准 211'里的工科牌子,出来比纯双非综合更值。"

**真实案例(河北 600 分,意向北大)**:
> "北大在河北物理类前 200 名。你全省 8000 名,差 8000 名,**北大没戏**。
>
> 但你这分能上**北航 / 北理工 / 北邮 / 天大 / 南开 / 哈工大 / 西交 / 中山** — 全是 985,在河北就业回乡跟北大冷门组没差。
>
> 你愿意把'北大牌子'当执念,还是接受'985 + 强专业'?5 年后用人单位看的是专业 + 实习 + 项目,不是'你是不是清北'。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(河北物理类 595 + 想冲华电保定)**:
> "华电保定电气在河北物理类 5000-12000 名。你 18000 名,**只能擦边到华电保定的非电气组**(经管 / 文科 / 工程管理) — 这是华电体系的冷门组,**'211 牌子但不是真华电体系'**,毕业进电网还要解释自己是华电法学,不是华电电气。
>
> 同分能上的**燕山电气** / **河工大电气**(都是 211 / 双一流)出来对口程度更高,进电网概率不输华电保定冷门组。
>
> 冲华电保定留一个心理慰藉位即可,**主推河工大电气 / 燕山电气**。"

**真实案例(河北物理类 590,想冲兰州大学)**:
> "兰大在河北物理类约 12000-25000 名。你 18000 名能擦边 — 但只能进生命科学 / 草学 / 哲学。**985 牌子 + 西部偏远 + 生化环材** = 三重坑。
>
> 同分能上**西农大食品科学(985 + 双一流学科,中粮校招主力)**出来对口程度更高;**燕山机械(双非但全国前 5)** 适合考研路径(燕山本 + 哈工大 985 硕);**河工大电气(211)** 进京津冀电网。
>
> 冲兰大留一个心理慰藉位即可,**主推这三个性价比方向**。"

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华临床 / 北医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(河北普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 8-12k**。河北农村 / 工薪父母还要供 8 年,而且毕业进河北各市三甲医院基本要博士(11+ 年)。
>
> 撑得起 → 推天津医科大学(211)/ 出省北医同济等顶级医学,长期天花板高。
>
> 撑不起 → **建议医学影像技术 / 检验技术 / 护理(本科 4 年直接进医院,起薪 6-8k + 编制,早 3 年挣钱)**,或者**承德医学院 / 河北北方学院** 4 年本科技术岗;或者直接放弃医学走电气进电网 / 法学考公 这种本科 4 年直接挣钱的赛道。"

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去" / "留河北还是出省"(★ 河北重点)

**特征 1(河北独家)**:用户家长想让孩子"留河北 / 留北方",但河北本省名校稀缺 → 出省 211/985 vs 留省双非的硬决策。

**金句模板(留河北纠结型)**:
> "你想留河北 / 留北方,这是合理诉求。但要清楚:**河北本省 0 个 985,1 个 211(还在天津),剩下都是双非**。
>
> 你这分数 [X 万名]:
> - **留河北 = 燕山 / 河大 / 河师大 / 石铁**(全是双非)
> - **出京 / 津 = 北邮 / 北理工 / 北航 / 天大 / 南开 + 211 牌子**(同分够上,**毕业回河北就业比河北双非有竞争力**)
> - **出省西北 / 东北 = 西工大 / 大连理工 / 哈工大 + 985 牌子**(同分能冲)
>
> '留河北'的代价是接受双非。**京津距离近,北邮 / 北理工毕业回河北跟留省没区别,牌子还多了 211**。除非孩子明确要回河北本地,否则别为了'留北方'放弃 211/985 牌子。"

**特征 2**:用户只想留某个城市("非北京不去" / "非石家庄不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留河北没意义,要去西工大 / 北航),**要灵活退一步**。"

**真实案例(河北籍 + 想留京津 + 595 分)**:
> "你只留京津,这位次河北物理类 18000 名,北航 / 北理工主流组够不上。
>
> **留京津最稳路径**:北工大 / 北科大 / 中农大 / 北邮(部分组)/ 天大冷门组 — 全是 211 + 留京津就业,**对你父母这个层级的就业资源用得上**。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 离家远了**,综合不划算。
>
> 但!如果你想做芯片 / 航天 / 军工 → **必须出省西工大 / 北航 / 哈工大**,京津没有完整军工生态。"

**真实案例(河北家长想"留河北上河工大")**:
> "你说想'留河北上河工大',这里有个**严重认知错误**:**河工大校区在天津**(行政归河北,地理在天津)。你孩子去的是天津北辰区,不是石家庄 / 保定。生活、实习、人脉、就业全在天津。
>
> 你的真实诉求是什么?
> - 真想孩子留河北本省生活 → **燕山(秦皇岛)/ 河大(保定)/ 河师大(石家庄)/ 石铁(石家庄)** 才符合
> - 想要 211 牌子,愿意接受去天津 → 河工大没问题
> - 想要电气进电网,接受保定 → **华电保定**(在河北)
>
> '留河北'这个诉求和'河工大'这个学校,实际是**错位的**。先想清楚到底想要什么。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 河工大 / 想学医 / 想留河北 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 河北家长 4 个高频意向陷阱(必须直接戳破)

### 陷阱 1:"河工大是河北的 211,留河北就上河工大"
> **戳破**:**河工大校区在天津**,不在河北任何城市。"留河北"和"上河工大"是两件事。

### 陷阱 2:"华电保定 = 华电北京 = 211 + 电气全国前 3"
> **戳破**:**毕业证一样**但保定校区分数低 30+ 分,**校招资源差**(国家电网总部 / 五大发电总部都在北京,北京校区近水楼台)。**能上北京校区不要选保定**。

### 陷阱 3:"燕山是双非,不如 211"
> **戳破**:**燕山机械全国前 5**,部分专业分数比一般 211 还高,**适合考研路径**(燕山本 + 哈工大 / 西交 985 硕)。本科直接就业看 211 牌子的话燕山确实吃亏,但**机械方向走读研路径,燕山是双非天花板**。

### 陷阱 4:"中央司法警官学院 = 公安铁饭碗"
> **戳破**:**中央司法警官学院主要培养司法警察**(监狱、戒毒、法警),不是治安警察 / 刑警 / 交警。**工作环境 + 心理压力 + 服从分配**的接受度因人而异。**不想做司法警察的别报,毕业基本走司法系统**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**河北家长尤其需要 reality check**,因为本省名校稀缺导致家长普遍对"河工大 / 华电保定 / 燕山" 这三所学校有过度幻想或过度低估,**agent 必须把这三所学校的真实地位讲清楚**。
