# 西藏专科 skill 核心方法论

西藏专科填报的底层逻辑,**和内地任何一个省份都不一样**。这个文档是 agent 决策的根 — 推荐之前先把这 5 条想清楚,再开口。

---

## 一、西藏专科最重要的 5 个底层事实

### 1. 民族身份是分数线之外的"第二把尺子"

西藏高考的分数线分**藏族(含其他少数民族)**和**汉族**两个口径,藏族考生一般低 50-100 分起步。这个差距在专科批同样存在,有时比本科批更明显。

**对 agent 的意义**:
- 同样一个分数,藏族考生的可选盘子比汉族大得多
- 同样一所院校,藏族考生录取概率显著高于汉族
- 推荐时**必须先问民族**,不问就推 = 完全错位

### 2. 区内招生 vs 区外招生 = 两个完全不同的池子

西藏考生填报时,招生计划分两块:
- **区内招生**:在西藏本地院校(西藏职业技术学院 / 拉萨师专 等),分数低、招得多、几乎只录西藏户籍
- **区外招生**:内地院校在西藏投放的专科招生计划,分数高一些、招得少、出藏读

内地考生想去西藏读专科 → 走内地省份对西藏的"援藏 / 区内招生"通道,极少数情况;一般还是西藏本地学生用区外招生计划出藏读专科。

**对 agent 的意义**:
- 看到分数先判断**这个分数对应区内招生还是区外招生**,再去匹配院校
- 同一所院校在区内 vs 区外的分数差可能 100-200 分
- 不要把内地省份的"分数 → 位次 → 院校"那套直接套上来

### 3. 西藏本地就业市场极小,出口高度集中

西藏全区常住人口才 360 多万,GDP 在全国垫底,**真实的市场化就业岗位很少**。本地专科生的真实出口就那么几个:

- **公立医院 / 县乡医院**(护理 / 医技 / 藏医)
- **公立学校**(学前 / 小学教师,牧区紧缺)
- **公检法司基层 + 乡镇公务员**(警官高专 / 公考路径)
- **国企央企西藏分公司**(国电投西藏 / 华电西藏 / 中铁西藏指挥部)
- **文旅口**(布达拉宫景区 / 林芝旅游 / 珠峰大本营 / 拉萨酒店)
- **藏药企业**(奇正藏药 / 甘露藏药 等)

**对 agent 的意义**:
- 推荐时直接锚定这几个出口去倒推专业,不要扯"互联网 / 电商 / 跨境贸易"那些西藏没有的赛道
- "市场化就业"在西藏 = 极小赛道,**编制 + 央企 + 国企 = 大赛道**

### 4. 高原是隐性变量,影响读书 + 工作 + 健康

留藏读专科,3 年都在高原(拉萨海拔 3650 米,日喀则 3800 米,那曲 4500 米),**心肺 / 睡眠 / 体力 都是真实成本**。出藏读专科,毕业回藏工作,适应又要重来一次。

内地考生想进藏读专科或进藏工作:
- 短期(< 1 年):多数人能适应
- 长期(3-10 年):**心肌肥大 / 红细胞过多症 / 慢性头痛 / 失眠** 都是真实风险
- 服务期满返乡:很多内地援藏的人最后都回内地,西藏不是终身赛道

**对 agent 的意义**:
- 推荐"援藏路径"时要如实说健康成本,不能只讲 15-25k/月 补贴
- 牧区考生 → 不存在适应问题(本来就在高原)
- 城镇汉族考生 + 准备出藏 → 出去之后再回西藏工作 = 重新适应

### 5. 高校选项极少 + 路径明确,是西藏专科的"隐藏优势"

西藏区内本科就那么几所(西藏大学 / 西藏民族大学 / 西藏农牧学院 / 西藏藏医药大学),专科更少(西藏职业技术学院 / 拉萨师专 / 西藏警官高专 几所)。**选项少 = 决策简单 = 错位风险低**。

而且每所学校的"出口"非常明确:
- 西藏职业技术学院 → 区内国企 / 央企 / 县乡岗位
- 拉萨师专 → 牧区小学 / 幼儿园教师
- 西藏警官高专 → 区内公检法司基层

**对 agent 的意义**:
- 不需要像内地省份那样在几十所专科里挑,西藏专科推荐天然就是"3-5 所之内"
- 把每所学校的对口出口讲清楚,用户决策反而比内地省份更快

## 二、推荐时的优先级原则

### 优先级 1:民族 + 区内 / 区外 → 锁定盘子

先问清这两个,**再谈分数**。顺序错了,推荐会全错。

### 优先级 2:留藏 vs 出藏 → 锁定方向

牧区 / 农区 + 想回家乡考编 → 留藏读
城镇 + 想见世面 + 不一定回藏 → 出藏读
内地考生想进藏 → 走援藏路径,谨慎评估健康

### 优先级 3:专业 → 行业出口 → 院校

按"想做什么 → 哪个出口 → 哪所院校对口"倒着推,**不要按"哪所学校好 → 学什么"正着推**(西藏院校选项太少,正着推会推到死胡同)。

### 优先级 4:专升本 → 看意愿强度

专升本对西藏专科生的意义比内地更大 — 因为本地本科盘子小,升上去基本=进西藏大学/民族大学,等于直接拿"西藏体制内通行证"。

## 三、agent 不要犯的错

1. **不要套内地逻辑**:不要说"参考湖北的做法""跟四川类似" — 西藏就是西藏
2. **不要鼓吹市场化就业**:西藏没有阿里腾讯,不要推"互联网 / 跨境电商"
3. **不要忽视民族变量**:不问民族就推院校 = 给汉族考生的话推到藏族优惠盘子里去了
4. **不要美化高原生活**:健康成本是真的,要如实说
5. **不要劝退"留藏"**:很多内地家长一听"专科 + 西藏"就觉得没出息,但**西藏专科 + 编制 + 民族优惠 + 高补贴 = 在内地是普通本科都达不到的稳定性**
6. **不要美化民办出藏**:出藏读偏远地区民办专科 = 学费贵 + 路费贵 + 高原适应反复 + 毕业后内地不要 + 西藏也不要 = 死局

## 四、典型 case 心智模型

### 模型 A:藏族牧区女生 + 求稳路径
报西藏职业技术学院护理 / 拉萨师专学前 → 县乡医院 / 牧区小学 → 编制 + 民族补贴 + 老家结婚 = 闭环

### 模型 B:藏族城镇男生 + 想出去看看
出藏读陕西 / 四川公办专科(机电 / 电力 / 计算机)→ 大三专升本回西藏大学 → 进区内国企央企 → 升本 + 民族优惠 + 西藏体制内 = 跃迁

### 模型 C:汉族西藏考生 + 出藏读完不回来
出藏读内地公办专科(护理 / 计算机 / 会计)→ 留内地就业 → 没有民族优惠但学历起点不输普通内地考生 = 普通专科路径,但少一张民族牌

### 模型 D:内地考生 + 援藏路径
内地公办专科 → 服务期内调入西藏(援藏定向) → 高补贴 15-25k/月 + 服务期满返乡定向 → **健康风险换跃迁**,适合身体好 + 家境普通 + 想搏一把的人

格式上参考主 skill (`xizang-zhiyuan/references/`,若已建)。**但内容不要照抄主 skill** — 主 skill 是给本科生看的,本科是"挑学校挑专业",专科是"挑出口挑编制",底层逻辑不同。
