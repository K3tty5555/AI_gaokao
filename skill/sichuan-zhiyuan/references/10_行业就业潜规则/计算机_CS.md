# 计算机科学与技术 / 软件工程(CS / SE)— 四川视角

## 一句话总结

**CS 已经过了"闭眼报"的黄金时代,但成都是西部 IT 例外**。腾讯 / 字节 / 网易 / 阿里 / 华为 全部在成都设了千人级研发中心,**川大 + 电科大顶级 CS 留蓉直接拿 25-40w**;**双非以下的 CS 留蓉就业不如双非师范,出省更难**。学校层次 + 留蓉地利 是四川 CS 的两把关键钥匙。

---

## 真相 1:寒冬是阶段性的,但分化是结构性的

- 2022-2024 互联网大厂裁员潮(腾讯优化 / 阿里批量调整 / 字节 ROI 卡位),**应届生 offer 数量比 2020 年峰值少了至少 30%**
- **成都的特殊性**:研发中心不是利润中心,**裁员幅度反而比北上深总部小**(腾讯成都做 PCG 中后台 / 字节成都做飞书研发 / 网易成都做游戏研发)
- 头部学校(电科大 / 川大)的 CS 仍然有 25-40w 起薪,中下层学校从 12-15w 掉到 7-9w,**两极分化加剧**
- 行业总需求依然在(AI、芯片、云计算),但门槛抬高 — 没有 985 学历或者过硬的项目经验,简历进不了筛选系统

**结论**:CS 不是不能学,但**学校决定一切**。成都西部 IT 中心的红利,只有头部校吃得到。

---

## 真相 2:35 岁危机存在,但成都比北上深略缓

- 35 岁危机集中在**业务型程序员**(增删改查、CRUD、调用别人的轮子的那类)
- **核心技术岗(底层、算法、架构、芯片)的 35 岁不是危机,是黄金期**,薪资还在涨
- **成都的特殊性**:成都研发中心**给薪比北上深低 10-20%,但裁员强度也低**——很多 35+ 老员工在北京/深圳干不下去 transfer 回成都研发中心继续干到 40+
- **川大 / 电科大本硕同学校友老员工带刚毕业的师弟**,内部小圈子很厚,这是出省 CS 给不了的"软资源"

**结论**:目标是核心技术岗,得本科开始就有意识训练算法/底层/数学,**双非很难做到这件事**(资源、氛围、同伴差距)。

---

## 真相 3:本科 < 硕士的差距越来越明显

- 5 年前 985 本科 CS 毕业可以直接拿 SP offer
- 现在 985 本科 CS 起薪可能跟 211 硕士差不多甚至略低
- 大厂校招在向"硕士起步"倾斜,本科想拿好 offer 必须**实习 + ACM + 项目**三件套都拿到顶
- **如果你打算学 CS 但学校只是 211 / 普通 985,本科就必须做好读研的准备**
- 电科大 CS 保研率 30%+,**直博华为天才少年 / 海归博士路径** 是西部 CS 的顶级出口

---

## 真相 4:转码内卷已经到顶

- 2018-2022 年大量文科生 / 其他工科生通过培训班转码成功,这个窗口已经关闭
- 现在企业对"科班 CS"的偏好极强,**非科班想转码越来越难**
- 想吃 CS 的红利,本科就该选 CS,中途想转的窗口已经很窄
- 成都某些"民办计算机培训"号称 6 个月包就业,**九成是骗局或低端外包**,千万别信

---

## 适合什么人

- **数学好**(高中数学 130+,这是硬指标)
- **抗压能力强 + 不怕加班**
- **有自学能力**,因为大学课程跟不上行业实际需求
- **985 出身,或者愿意读研甚至读博**
- **家庭中产**,能撑你 4 年读书 + 设备 + 网课/培训
- **想留蓉**:成都互联网生态吃得到,起薪 25-40w(电科大 / 川大 + 大厂)

## 不适合什么人

- **数学差**(高中数学 110 以下慎重)
- **追求安稳生活、不想 996**(但成都研发中心比北深略松,可考虑)
- **双非家庭 + 不打算考研**(这个组合学 CS 等于浪费 4 年)
- **学校层次不够 + 个人没有强自学动力**
- **女生中讨厌技术钻研只想图高薪的**(行业对女性有客观存在的隐性歧视;但成都游戏 / UI / 产品 女生岗位比北深多)

## 四川提示 — 本地 CS 院校真实分层

### 第一梯队(全国可比 + 留蓉直签顶级)

- **电子科技大学 CS / 软件 / 网络空间安全** — 全国前 15,**电子信息底子托起来的 CS**,毕业直接腾讯成都 / 字节成都 / 华为 / 中兴 SP offer 25-40w 起,西部 IT 第一选择
- **电子科技大学 集成电路 / 微电子** — 全国前 5,**国家战略 IC 黄金赛道**,海思 / 海光 / 紫光展锐 / 中芯 校招主力,**录取分比 CS 略低但天花板更高**
- **四川大学 CS / 软件工程** — 985 综合性,**全国前 30 段位**,腾讯 / 字节 / 网易成都 校招认可,起薪 18-28w(略低于电科大,但综合资源好)

### 第二梯队(四川 211 + 留蓉中段)

- **西南交通大学 CS / 软件工程** — 211 但 CS 是中等,**轨道 IT(铁路系统信息化) 才是西南交大 CS 的核心优势**,中铁信息 / 各地铁公司 IT 部对口,**学纯互联网选电科大,别在西南交大学纯 CS**
- **西南财经大学 CS / 金融科技** — 财经校的 CS 是工具人,但**金融科技方向(招行 / 券商科技)对口稳**,起薪 12-18w(比 IT 大厂低,但走金融科技路径)
- **四川农业大学 CS / 智慧农业方向** — 双一流但 CS 是边缘,**别为 CS 报川农**

### 第三梯队(四川双非头部 + 留蓉本地认可)

- **成都信息工程大学 CS / 软件工程 / 网络工程** — 双非但**计算机+气象信息化**,本地认可度不错,毕业进华为 / 中兴 / 腾讯成都(中段岗)+ 气象局信息化系统,起薪 8-12w
- **西华大学 CS** — 双非综合,本地一般 IT 公司 + 留川考公兜底,**起薪 6-9w**
- **四川师范大学 CS(非师范)** — **避坑**,川师大牌子是师范赛道才香,CS 在川师大是边缘
- **西南民族大学 CS** — 双非 + 民族院校,**只对少数民族考生友好**(民族班路径)

### 第四梯队(避坑)

- **成都的二本院校 / 民办院校 / 独立学院 CS**(成都理工工程技术学院 / 四川大学锦江学院 / 西南交通大学希望学院 等)— **请直接避坑**。这一档学 CS 不如学护理、师范、会计等有明确出路的专业。普通家庭的孩子在这些学校学 CS 出来基本就业极差,你以为的"敲代码进腾讯"不会发生,大概率是去成都软件外包公司月薪 5-7k 干苦力。

## 典型 case(供 agent 引用)

### Case A:电科大 CS 男生(普通家庭,绵阳)
- 电科大计算机学院 → 大三实习字节飞书研发(成都) → 校招拿到字节成都 SP offer 32w → 入行
- **逆袭路径**,西部 985 工科顶级 + 行业红利 + 个人努力,普通家庭通过 CS 跨阶级的典型样本
- 关键变量:**留蓉,房价比深圳低 3-4 倍**,32w 在成都过得比深圳 50w 还舒服

### Case B:川大 CS 男生(成都中产)
- 川大计算机学院 → 实习腾讯成都 → 校招腾讯成都 22w
- 跟电科大同档薪资,但川大综合性资源给他后续转产品 / 转管理 留了路
- **典型综合 985 路径**,牌子大 + 城市留蓉 + 父母满意

### Case C:西南交大 CS 男生(自贡普通家庭)
- 西南交大软件 → 校招字节成都 ML 岗 18w(走的是 ACM 简历)
- 211 工科校的 CS 出口下限,**做对了就够吃饭,做不对就跟双非无差**
- 关键:**他在 ACM 拿了铜牌,简历里有"ACM"三个字才进的字节**——西南交大 CS 不刷题进不了一线大厂

### Case D:成信工 CS 男生(自流井普通家庭)
- 成都信息工程大学 CS → 校招华为成都(中段岗) 12w
- **典型双非头部出路**,在成都本地 IT 圈认可度还行,但出省到深圳总部基本无望
- 起薪比电科大同学少 20w,**5 年差距进一步拉大**

### Case E:成都某二本独立学院 CS 男生(德阳普通家庭)
- 双非二本 CS → 校招进成都某软件外包公司 月薪 6k → 半年后 996 + 项目 deadline 抑郁
- **典型踩坑**,家长以为"学了计算机就能赚钱",学校层次决定一切
- **如果当时报川师大公费师范数学 / 成中医针灸推拿** → 完全不一样的人生

### Case F:川大 CS 女生(成都中产)
- 川大 CS → 不爱写代码 → 校招进腾讯成都做产品经理 18w(代码弱但综合素养好)
- **女生 + 综合 985 + 不爱硬核技术** → 走产品 / 设计 / 用户研究 是更好的路径
- 川大 CS 女生比例 30%+,比电科大友好(电科大 CS 女生 < 20%)

## 给四川家长的金句

> "**'计算机一定好就业'是 5 年前的认知**。今天的真相是:**电科大计算机依然好就业,双非计算机就业不如双非师范**。"

> "你的孩子分数够电科大 / 川大计算机,闭眼冲;够西南交大 / 西财大,要拼考研;**双非建议直接换专业(改成电科大微电子 / 川师大公费师范 / 成中医针推 / 川农大动医 都更稳),别让孩子白学 4 年代码然后毕业进外包**。"

> "**留蓉是 CS 的隐藏王牌**。北上深给的薪资比成都高 30%,但成都房价是深圳的 1/3,**电科大 CS 留腾讯成都 30w,实际生活质量碾压深圳总部 50w**——别被'去东部'的虚执念蒙蔽。"

> "四川家长最容易踩的坑是 — 觉得'西南交大 CS 跟电科大 CS 差不多',这俩**毕业薪资差 1.5-2 倍**,一个是字节 SP 一个是华为外包级别;**或者觉得'川大 CS 跟电科大 CS 差不多',这俩对**纯 IT 男生**而言电科大对口度更高(虽然综合声誉川大稍占上风)**。"

> "**集成电路 / 微电子 比纯 CS 更值得冲**。电科大微电子全国前 5,海思 / 海光 / 中芯 起薪 25-40w,行业 10 年红利,**比互联网少裁员、国家战略支持**。男生工科第一选择不是 CS 是 IC。"
