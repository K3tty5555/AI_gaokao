# 用户意向冲突 — Reality Check 金句库(四川视角)

很多家长 / 考生有具体的意向("想上川大"、"非成都不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**),四川版聚焦 **留蓉 vs 出省 / 川大执念 / 成都中心 vs 三州 / 学医长周期 / 民族优惠用不用** 等四川独有冲突。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

---

## 5 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 500 分要清华 / 600 分要川大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(四川 595 分,意向川大主流组)**:
> "川大主流组在四川物理类 1,500-3,500 名段。你 8,800 名,差 5,000 名,**川大主流组没戏**。
>
> 但你能上**电科大主流(微电子 / CS)+ 西南交大王牌(交通 / 电气)+ 西财大金融** — 这三档留蓉就业,**腾讯 / 字节 / 华为 / 中铁 / 成都地铁 / 招行成都 招聘里跟川大冷门组校友地位差不多**(都是'成都本地 211 + 留蓉同档')。
>
> 别死磕川大冷门组(图书情报 / 哲学 / 工商管理) — 985 牌子救不了水专业,毕业出路反而不如电科大微电子 / 西南交大电气这种'211 + 强专业'。"

**真实案例(四川 540 分,意向电科大)**:
> "电科大物理类要 4,500-6,000 名,你 35,000 名,**根本到不了**。
>
> 但你能上**西华大学电气(国网四川对口)/ 成都信息工程大学计算机(气象信息化) / 西南医科大学医学影像** — 这三个双非头部留蓉就业,**起薪 8-12w + 编制路径**,普通家庭 ROI 不比电科大冷门组(其他理工)差。
>
> 你想要的是'电科大牌子'还是'IT 工科出口'?如果是前者,别纠结,分不够就是不够;如果是后者,西华电气 + 国网编制比电科大水专业更稳。"

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学 / 图书情报]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(理工科 + 普通家庭 + 想冲川大)**:
> "川大你 615 能冲 — 但只能进川大理工实验班(可能调到化学 / 生物 / 材料 / 物理)。**985 牌子 + 生化环材天坑** = 双重坑。
>
> 同分能上的电科大主流(微电子 / 通信 / 自动化)起薪 25-40w,出来的对口程度高 5 倍。冲川大冷门留一个心理慰藉位即可,主推电科大。"

**真实案例(文科 + 想冲川大)**:
> "川大文科组你能擦,但只能进**图书情报 / 档案管理 / 哲学** —— 川大这几个专业全国第 1 但**就业极窄,只能考公或做学术**。
>
> 同分能上的西财大金融 / 会计 / 西南交大经管 + 留蓉就业,银行 / 四大 / 央企对口 —— **'川大冷门第 1' < '211 财经强专业'**。
>
> 父母听到'川大'激动,但孩子 4 年后毕业找不到工作时,父母会更失望。"

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [川大华西临床八年制])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 8-12k**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**川大华西临床八年制**(西部医学神级,长期天花板碾压同龄人)。
>
> 撑不起 → **建议口腔(华西口腔全国第 1,5 年本科 + 3 年硕士能进诊所,起薪 10-15w,早 3 年挣钱)** + 民营成都口腔市场厚;**或者医学影像 / 检验技术 4 年本科进医院**(华西 / 西南医科大学 / 川北医学院 / 成都医学院);**或者放弃医学走 CS / 会计这种本科直接挣钱的赛道**。"

**真实案例(农村家庭 + 想学医)**:
> "你说想学医,我理解。但 8 年长周期 + 三甲门槛博士,**农村家庭 8 年无收入是绝路**。
>
> 唯一可行的医学路径:**国家专项 + 西南医科大学(泸州) / 川北医学院(南充)+ 农村订单医师** — 免学费 + 6 年回乡基层医院 + 编制。**别冲川大华西临床**(8 年烧钱 + 规培期低薪 + 家里撑不到博士),也别冲成都医学院(没订单医师就是双非临床天坑)。"

### 模式 D:意向城市 vs 院校层次 — "非成都不去"

**特征**:用户只想留某个城市("非成都不去" / "非川渝不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留成都没意义,要去西工大 / 哈工大),**要灵活退一步**。"

**真实案例(成都本地 + 想学金融 + 600 分历史类)**:
> "你只留成都,这位次 1,800,川大经济学院 / 西财金融都够 — 但川大法学 / 中文 也够。
>
> **留蓉最稳路径**:**西财金融 / 会计**(西部金融业封顶,招行 / 国金证券 / 四大成都所校招直签)+ 父母资源(若中产)+ CFA / CPA → 银行 / 券商 / 基金 路径。
>
> **不要为了'外省 985 牌子'去东北财经 / 哈工大经管 / 兰大经管 — 牌子有了但人脉断了 + 实习机会少了 + 留蓉竞争力反而下降**,综合不划算。"

**真实案例(普通家庭 + 想留川 + 600 分物理类)**:
> "你 600 分物理类(全省 5,000 名),想留川。
>
> 留川可冲 = **电科大主流(微电子 / 通信)+ 西南交大王牌(交通 / 车辆) + 西财大金融** — 三个 211 同档但赛道不同,**留蓉 IT / 工科 / 财经 都有顶配出口**。
>
> 出省同分能上 = 兰大 / 东北农大 / 中国海洋大学 主流组 —— **985 牌子但城市偏 + 留蓉 ROI 反而损失**。
>
> 留川更稳,父母近 + 房价友好 + 火锅自由 = 巴蜀幸福经济学。**除非你想冲清北复交人或一线总部,否则别为'985 名头'去东北 / 西北**。"

### 模式 E:民族优惠 / 三州专项用不用 — 农村 + 少数民族独有冲突(四川独家)

**特征**:用户是少数民族(彝 / 藏 / 羌)+ 农村家庭,享受民族优惠 + 三州专项,但**家长怕"被贴标签 / 出去被歧视"** 不愿意用。

**金句模板**:
> "你是 [民族],享受 [加分 + 民族班 + 三州专项 + 国家专项] 多重优惠 — **这不是'走后门',这是国家给民族地区的合法政策**,不用白不用。
>
> 父母担心'被贴标签'——其实在大学里没人在意,毕业后单位也只看你能不能干活。**优惠用了 = 跨阶级 1-2 档**(从双非到 985 / 从二本到 211)。
>
> 不用 = 主动放弃跨阶级机会。这相当于普通家庭孩子拿到提前批名额却不去用。"

**真实案例(凉山彝族 + 530 分理科)**:
> "你彝族 + 凉山州户籍 + 530 分,**单看裸分能上西华大学 + 成都医学院**;但加上 **民族优惠 30 分 + 国家专项 + 三州专项**,实际可冲 **川大临床(国家专项段)/ 电科大微电子(国家专项段)** — **985 跨阶级直接到位**。
>
> 父母可能不懂这套政策,你要主动跟父母解释:'这是国家给彝族 / 凉山州的合法政策,我用了 = 985 名校 + 华西医生编制 + 全家第一个 985'。
>
> 不用 = 主动放弃国家给的跨阶级杠杆,绝对是亏的。"

**真实案例(阿坝藏族 + 480 分物理类)**:
> "你藏族 + 阿坝州户籍 + 480 分,裸分只能上双非二本。
>
> 用上 **民族优惠 + 国家专项 + 三州专项**,你可冲:
> - **西南民族大学藏医学 + 民族班** — 学费减免 + 回阿坝藏医院编制 + 民族干部提拔
> - **川农大动物医学(国家专项)** — 双一流 + 高原畜牧对口 + 回阿坝畜牧局
> - **川大某专项段** — 985 + 跨阶级
>
> 三个路径都比裸分双非好 N 倍。**民族 + 三州专项 + 国家专项是国家给民族地区的合法政策杠杆,你不用谁用?**"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 川大 / 想学医 / 想留成都 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 四川独有的高频意向冲突

| 意向 | 高频原因 | Reality Check 要点 |
|---|---|---|
| 非川大不去 | 家长心理上限 + "西部清华"误解 | 川大≈ 武大 / 中大 / 华科 第二档,不是 C9;冷门组 ≤ 电科大 / 西南交大强专业 |
| 非成都不去 | 留蓉舒适度 + 父母老人观念 | 成都 211 强专业 > 出省 985 弱专业 (留蓉 ROI 高) |
| 非华西不学医 | 华西品牌效应 | 普通家庭撑不起 8 年华西 → 西南医科大 / 川北 / 成都医学院 + 农村订单 路径 |
| 想学金融非西财不可 | 西部财经第一执念 | 川大经济学院 + 西财双轨,综合性强用川大,纯金融对口用西财 |
| 拒绝去三州 / 民族地区 | 家长怕"偏远艰苦" | 三州补贴 + 民族优惠 + 提拔速度比成都快 2-3 倍 = 跨阶级捷径 |
| 拒绝中飞院因为"双非" | 牌子至上的认知 | 飞行员国内独家 + 30-50w 起薪 + 编制 = 反差顶级 ROI,牌子双非但行业封顶 |
| 想出省东部 985 | "去东部才有出息"的执念 | 东部 985 弱专业起薪 6-8w < 留蓉 211 强专业 15-25w + 房价 1/3 = 综合 ROI 留蓉胜 |
| 想冲清北复交但分不够 | 顶级名校情结 | 直说不可达 + 给等价路径(川大 / 电科大 + 留蓉 ROI 一档,不必为外省 985 冷门组牺牲) |

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**四川的额外原则**:**留川 ≠ 委屈**(成都生活质量 + 川大电科大顶级 + 房价友好 = 巴蜀幸福经济学);**民族优惠 + 三州专项 + 国家专项 ≠ 走后门**(国家给民族地区的合法跨阶级杠杆,不用白不用);**牌子双非 ≠ 就业弱**(中飞院飞行员 / 成中医针推 / 川农大动医 / 西南医科大学 都是反差顶级 ROI)。
