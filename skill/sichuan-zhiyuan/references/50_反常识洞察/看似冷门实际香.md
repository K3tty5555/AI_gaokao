# 看似冷门实际香的专业 — 四川视角

## 核心结论

家长普遍**追热门而避冷门**,但很多"冷门"专业的就业稳定性、考公友好度、性价比远超表面热门专业。**对普通家庭尤其友好** —— 因为不卷、门槛适中、出路明确。

**四川独家"冷门实际香"路径**:**水电(雅砻江 / 大渡河) / 民航(中飞院飞行员) / 中医针推(成中医 + 海外大蓝海) / 川农大动物医学(宠物经济) / 西南交大轨道(中铁中车) / 三州专项 / 民族优惠** — 这些四川考生独有的反差路径,普通家庭善用可以跨阶级 1-2 档。

## 关键事实

### 1. 汉语言文学 — 考公王者(四川家长最该重视)
- 国考、省考能报考的岗位数,**汉语言文学常年第一**(明显多过法学、计算机、会计)
- 三不限岗位(对专业不限制)所有人都能报,但加上"汉语言文学"限制的岗位还是非常多
- 适合所有想考公考编的四川学生,**特别是普通家庭女生**
- **川师大公费师范汉语言** = 学费免 + 编制 + 留川回乡 + 父母近,是四川普通家庭最稳路径

### 2. 电气工程及其自动化 — 国家电网 + 水电央企双通道
- 进国家电网四川公司 = 央企铁饭碗 + 普通家庭逆袭
- **四川独家**:**水电央企(国电大渡河 / 雅砻江流域 / 长江电力 / 华电金沙江)** — 比国网工资高,接受山区驻点 5 年攒首付路径
- **西南交大轨道供电** = 各地地铁公司 + 中铁电气化局,都市编制岗
- 详见 `10_行业就业潜规则/电气_电网.md`

### 3. 飞行技术(中飞院飞行员定向班)— 普通家庭顶级反差 ROI
- **国内独家培养基地**:中飞院(广汉)三大航定向班毕业即编制
- **录取分约本科特控线 + 体检过 + 政审过 = 起薪 30-50w + 5-8 年升机长 80-120w**
- **远超绝大多数 985 工科**,普通家庭男生顶级反差路径
- **硬门槛**:视力 4.5 以上 + 身高 168-185 + 五官端正 + 政审三代清白
- 女生想搞民航 → 选**空中交通管理 / 签派 / 机场管理**(编制 + 高薪 + 不上天 + 反卷洼地)

### 4. 中医学 / 针灸推拿(成中医)— 西部封顶 + 海外大蓝海
- **成中医中药学全国前 5(双一流)+ 针灸推拿全国前 5**
- **针灸推拿** 是反卷洼地之王 — **海外华人医疗大需求**(北美 / 欧洲 / 澳新 / 东南亚),毕业出国开诊所年薪 50-100w 美刀级别
- 国内路径:华西医院中医科 / 省中医院 / 各市县中医院 + 编制
- **女生 + 普通家庭学中医** = 留川医疗系统跨阶级路径

### 5. 测绘工程 / 遥感科学与技术
- 武大第一,**川大测绘地理信息 + 西南交大测绘 + 成都信息工程大学测绘** 都强
- 毕业进国测局、中铁、中交、各省测绘院、自然资源部门、北斗导航集团,**铁饭碗居多**
- 注意:基层岗有野外作业,体力要求,女生慎重
- **四川考生独家**:**国土测绘 + 川藏铁路勘察设计 + 北斗导航(电科大相关)** 出路稳定

### 6. 殡葬学 / 殡葬服务与管理
- 全国只有 4 所院校开设(长沙民政、福建华南女子、武汉民政、北京社管)
- **就业率 100%,入职即编制**(殡仪馆事业单位),**收入比想象高很多**(月入 1-2w)
- 行业刚需 + 人力极少 + 社会偏见正在减少
- 适合不在意社会偏见 + 想要绝对稳定的家庭
- **四川考生考长沙民政路径稳**(出湘 4 年回川各市殡仪馆编制)

### 7. 兵器类专业(弹药工程、装甲车辆等)— 四川军工独家
- 限定院校:北理工、南理工、中北大学、西工大等"兵器八校"
- **四川独家衔接出口**:**电科大微电子 → 中物院(绵阳九院核武器研究院)/ 中航工业成飞 / 中电科 30 / 29 / 10 所** 全在四川 — 军工央企吸纳量大
- 毕业进兵工集团、航天科工、中船等军工央企,**绝大多数有保密等级要求**
- 专业限制大但**进入门槛后稳定性极高**,基本一辈子在体制内
- **绵阳九院 / 成飞 / 长虹军工** = 留川军工编制独家路径

### 8. 医学影像技术 / 医学检验技术
- 三甲医院技术岗,**不需要医师资格证就能上岗**(影像技师/检验师)
- 不用像临床医学那样"5+3+规培"长周期,**4 年本科就能进医院**
- 适合喜欢医学但不想读 8 年的学生
- **四川强校**:川大华西 / 西南医科大学 / 川北医学院 / 成都医学院

### 9. 农林类(植物保护、动物医学、水产养殖)— 川农大独家
- 在农业大学读这些**真的有出路**(农技推广、宠物医院、水产养殖企业)
- 别去综合性大学读这些,要去农林专业院校(川农大 / 华农 / 西农 / 中农 等)
- **四川独家**:**川农大动物医学 + 成都宠物经济爆发**(成都宠物市场全国前 3) — 宠物医生 5 年后 15-30w
- **新希望集团(成都本土巨头) + 温氏 / 牧原 / 双胞胎** 校招主力 = 川农大动科 / 动医对口
- **川农大林学 / 园艺** 进林业局 / 自然资源部门 编制
- **川农大食品科学** = 五粮液 / 郎酒 / 海底捞 / 老干妈 校招主力

### 10. 数学 / 统计学 — 万金油基础
- 本科出路相对窄,但**是研究生阶段转 CS / 金融 / 量化的最佳跳板**
- 数学好的考生,本科读数学比直接读金融更有未来 —— 顶级量化基金只要数学/物理出身
- 适合数学单科 130+ 的学生
- **川大数学 / 电科大数学** = 西部数学跳板首选,**强基计划开通**

### 11. 轨道交通 / 车辆工程(西南交大独家)— 中铁中车铁饭碗
- **西南交大交通运输全国第 1 + 车辆工程(轨道方向)全国前 5**
- 出路:**中铁集团 / 中国铁建 / 中车集团 / 各地地铁公司 / 中国铁路总公司** 校招直签
- 起薪 12-18w + 项目补贴 + 房补(基层),**进各地地铁是都市编制岗** + 户口 + 子女教育
- **四川考生独家**:**中铁二院总部成都 + 成都地铁 + 重庆地铁 + 中车成都长客** 留蓉央企编制路径

### 12. 空中交通管制(中飞院 / 南航空管学院)
- **进民航空管局编制 + 起薪 25-35w + 户口 + 子女教育**
- **比飞行员体检要求低 + 不用上天 + 体制内稳定**
- 反卷洼地之王 — 行业需求大但每年招生少
- **四川考生独家**:中飞院在广汉(德阳),留川对口

### 13. 藏医学 / 民族医学(西南民大 / 成中医)— 四川独家
- 西南民大 + 成中医 都开设藏医学
- **少数民族(藏 / 彝 / 羌)考生**民族优惠 + 民族班 + 减免学费
- 出路:**藏区中医院 / 民族地区医疗 + 编制 + 民族干部提拔**(藏滇川甘对口)
- **海外藏医也有市场**(欧美对藏医文化兴趣)

### 14. 警校(四川警察学院)
- **本科 + 公安联考 + 编制 + 留川公安系统**
- 录取分中等,但**毕业进编是确定路径**
- **男生体检过 + 政审过 = 警察编制**(刑警 / 派出所 / 缉毒)
- **四川独家**:**凉山缉毒 + 阿坝高原警察 + 三州民警** 提拔速度比成都快

### 15. 农村订单医师(西南医科大学 / 川北医学院 / 成都医学院)
- **国家专项 + 农村订单 = 免学费 + 6 年回乡基层医院 + 编制**
- 适合农村家庭 + 学医兜底路径(避开 8 年长周期)
- 出路稳定 + 县乡医院 + 服务期满后回县城 / 市州医院

## 典型 case(供 agent 引用)

- **Case A**:四川自贡考生,580 分物理类,普通工薪家庭。家长本想报"金融"(双非),建议改报**川师大汉语言文学公费师范**,毕业回自贡市某中学,**家庭逆袭** + 学费免 + 编制 + 寒暑假 + 父母近
- **Case B**:四川绵阳考生,560 分物理类,普通家庭男生。本想报"工商管理"(三本),建议改报**西华大学电气工程 + 国电大渡河水电(校招特殊通道)**,**起薪 14-18w + 项目补贴 + 5 年攒首付 + 5 年后回成都管理层**
- **Case C**:四川达州考生,540 分物理类,农村家庭男生。本想报"市场营销"(二本),建议改报**中飞院飞行员定向班 + 体检过**,**毕业三大航副驾 30-50w + 5 年升机长 80-120w**(顶级反差 ROI)
- **Case D**:四川凉山(西昌)彝族考生,500 分理科(三州专项 + 民族优惠 30 分),农村家庭。本想报双非工商管理。建议改报**西南民族大学法学 + 民族班 → 凉山州定向考公** → 4 年免费 + 民族干部提拔通道 + 3-5 年副科级
- **Case E**:四川宜宾考生,565 分物理类,普通家庭女生。本想报"会计"(双非)。建议改报**川农大动物医学(雅安校区)**,毕业进新希望成都(动医研发) + 成都宠物医院,**起薪 10-15w + 行业大缺口 + 留蓉**
- **Case F**:四川南充考生,610 分物理类,中产家庭男生。本想报"金融"(西财)。建议**主推电科大微电子 + 备选西财金融** — 微电子 IC 设计起薪 25-40w + 国家战略红利,比西财金融起薪 12-18w 高 2 倍 + 长期更稳
- **Case G**:四川内江考生,550 分文科,普通家庭女生。本想报"新闻"(双非)。建议改报**成中医针灸推拿** → 4 年学针推 + 海外开诊所 / 留川中医院,**反卷洼地 + 长期稳定**
- **Case H**:四川阿坝藏族考生,470 分物理类(三州专项 + 民族优惠 + 国家专项),农村家庭男生。建议**国家专项 + 川大临床医学(国家专项) + 民族优惠** → 进川大华西临床八年制(国家专项段),**整个家族第一个 985 + 华西医生**

## 易错认知(agent 要纠正用户的)

- "**冷门 = 没前途**" — 错。冷门 = 报的人少 = 不卷 + 行业稳定的概率高
- "**学这种又不能挣大钱**" — 错。普通家庭追求"挣大钱"概率失败,追求"稳定"概率成功
- "**汉语言文学就是当老师**" — 错。汉语言考公比当老师香 100 倍,四川每年省考可报岗位数惊人
- "**测绘 / 海洋工程都是又苦又累**" — 半对。基层岗确实苦,但晋升后管理岗 + 央企福利远好于互联网卷王
- "**殡葬太丧 / 太晦气**" — 老一代认知。年轻一代消除偏见 + 稳定收入两不误
- "**数学统计本科找不到工作**" — 半对。本科确实就业一般,但是**最好的研究生跳板专业之一**
- "**中飞院是双非,不值得报**" — 严重错误。**民航飞行员国内独家**,飞行员定向班 30-50w 起薪 + 编制,**牌子双非但行业封顶**
- "**水电央企就是去山里,不值得**" — 错。**国电大渡河 / 雅砻江流域 / 长江电力工资比国网高 30%**,5 年攒首付 + 5 年后回成都管理层 = 跨阶级路径
- "**川农大是农村专业,看不上**" — 严重错误。**川农大 2017 双一流升级 + 作物 / 动医 / 食品 全国前列 + 西部农林行业封顶 + 新希望 / 五粮液 / 郎酒校招主力**
- "**成中医是双非,不如学西医**" — 错。**中医药全国前 5 + 双一流学科 + 海外针推大蓝海 + 行业不卷**,普通家庭学中医 ROI 不输学西医
- "**三州 / 民族岗位太偏远**" — 错。**艰苦补贴 + 民族优惠 + 提拔速度比成都快 2-3 倍** = 农村少数民族家庭独有跨阶级杠杆
