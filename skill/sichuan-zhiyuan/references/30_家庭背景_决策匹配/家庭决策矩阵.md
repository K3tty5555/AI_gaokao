# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(四川视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**四川视角的特殊性**:
- **留川率 70%+** — 大多数四川家庭希望孩子留蓉 / 川渝双圈,沟通成本极低,这是家庭决策的隐性主轴
- **成都生活舒适度全国前 5** — 火锅自由 + 房价友好 + 父母近 + 茶馆悠闲 = "巴蜀幸福经济学",家长普遍接受"留川胜于出省"
- **三州(凉山 / 阿坝 / 甘孜)+ 民族优惠 + 国家专项** — 农村 / 少数民族家庭独有跨阶级路径
- **华西医院 / 成都互联网大厂 / 中铁中车 / 国电大渡河水电央企** — 留川头部岗位生态厚

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **四川体制内家庭典型**:省直机关公务员 + 市州干部 + 国电大渡河 / 雅砻江流域 / 川投能源 / 五粮液 / 长虹 等省属国企

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化);**川大 / 电科大 / 西南交大 / 西财 是四川选调主供给校**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校(中国人民警察大学 / 四川警察学院)+ 公安联考 = 父母编制资源能用上;**财政税务系统(西财对口)**也是体制内家庭的标准复刻路径

**典型 case**:
- 成都某体制内家庭(父亲省直机关,母亲建行四川分行)→ 孩子 605 分历史类 → 推**川大法学** → 毕业选调进省委办,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去电科大 CS → 毕业 32w 起薪很高,但家长不满"不稳定 / 容易裁员",劝其离职考公,**两年的时间损耗 + 心理纠结**
- 成功 case:绵阳某中航工业体制内家庭(父亲中物院科研编制,母亲学校教师)→ 孩子 600 分物理类 → 推**川大法学 + 家庭复刻军工编制**或**电科大微电子 + 进中物院 / 中航成飞**(父母行业资源直接复用)

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道
- **四川典型**:华西医院系 + 省人民医院系 + 各市三甲医院家庭;成都七中 / 树德 / 石室 / 嘉祥 教师家庭;成都律师家庭(蜀都 / 泰和泰 / 君合成都 / 中伦成都)

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(川师大);医生家庭 → 临床 / 口腔(8 年长周期父母能撑,川大华西首选)
2. **行业相关延伸**:律师家庭 → 法学(川大法学院);工程师家庭 → 对应工科(电科大 / 西南交大)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲成都七中语文老师 + 父亲普通工薪 → 孩子 615 分历史类 → **公费师范生汉语言**(川师大) → 毕业回成都本区编制 / 七中分校 编制,**母亲资源直接复用**
- 父母都是华西临床医生 → 孩子 670 分物理类 → **川大华西临床八年制** → 父母能撑 8 年读书 + 华西医院推荐 → **典型子承父业路径**(华西系内部圈子)
- 律师家庭 + 孩子 600 分历史类 → **川大法学院** → 毕业进父母同行红圈所成都分所 / 蜀都律所,**家庭法律资源直接复用**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **四川典型**:成都新希望系 / 通威集团系 / 蓝光发展系 / 海特高新系 私企高管;**自贡 / 内江 / 宜宾 / 泸州 民营家族企业**(食品 / 化工 / 调味品);成都软件外包 + 互联网创业小老板

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校,西财首选)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(西财 ACCA 实验班 / 川大海外项目 / 香港高校)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本(川大艺术学院 / 川美 / 四川音乐学院)
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 成都某新希望集团高管家庭(年入 200w+) → 孩子 580 分物理类 → 推**香港中文大学(深圳)/ 香港城市大学(中外合作金融)** (学费 8-15w/年家里能撑) → 出国背景做家族企业接班
- 失败 case:私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**
- 自贡某调味品家族企业 → 孩子 550 分物理类 → **西南财大经济学(温江校区)+ 实习接班** → 学财经 + 接管家族企业供应链 → **典型川南民营家庭复刻路径**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 10-30 万为主。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **四川典型**:**绵阳长虹工厂工人 / 攀枝花钢铁工人 / 自贡盐厂工人 / 成都富士康 / 成都京东方工人**;成都 / 绵阳 / 德阳 服务业(火锅店 / 茶馆 / 商超 / 物业);**21 个市州县城公职低薪 + 私企小职员**

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(川师大 / 西华师大)** = 高考分适中 + 直接编制 + 无学费
   - **警校(四川警察学院 / 中国人民警察大学)+ 公安联考** = 进警察系统编制
   - **医学技术(医学影像 / 检验) — 川大华西 / 西南医科大学 / 川北医学院 / 成都医学院** = 三甲医院技术岗 + 4 年本科即可
   - **殡葬专业(长沙民政) = 100% 编制 + 收入意外不错**(四川考生考长沙民政路径稳)
3. **次推稳定就业型**:
   - **电气工程进国家电网 / 水电央企**(分够 985/211 / 西华大学等性价比之选)
   - **师范类(汉语言 / 数学师范) — 川师大 / 西华师大**
   - **护理(本科,专科也行) — 成中医 / 西南医科大学 / 川北医学院**
   - **西南交大轨道运输 / 车辆工程 / 电气供电 → 中铁 / 中车 / 各地地铁公司编制**
   - **中飞院飞行员定向班(男生体检视力过)** = 起薪 30-50w + 编制(顶级反差 ROI)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 7-9w,跟双非工科没差;成都软件外包公司是天坑)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起 → 改医学技术 / 护理)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- **绵阳长虹工厂家庭** → 孩子 590 分物理类 → 推**西南交大电气工程(轨道供电)** → 毕业进成都地铁电气运维,**月入 1.3w + 编制 + 户口 + 房补,家庭逆袭**
- **自贡盐厂工人家庭** → 孩子 540 分文史类 → 推**川师大公费师范汉语言** → 毕业回自贡某中学教书,**学费免 + 编制 + 寒暑假 + 父母近,家庭命运改变**
- **泸州工薪家庭** → 孩子 580 分物理类 → 推**西南医科大学(泸州本地)临床医学** → 毕业进泸州市医院 + 规培完成 30 岁稳定 + 8-12w + 编制(留泸路径,父母资源 + 本地认可)
- **绵阳工薪男生** → 605 分物理类 → 推**电科大微电子** → 校招海光成都(IC 设计) 26w → **跨阶级 + 留蓉**
- **达州县城工薪家庭** → 孩子 500 分物理类 → 体检视力过 → **中飞院飞行员定向班(三大航)** → 毕业飞行员副驾 30-50w + 编制,**普通家庭跨阶级最反差路径**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **四川典型**:**凉山 / 阿坝 / 甘孜 三州山区农牧家庭(彝族 / 藏族 / 羌族)** + **川东北秦巴山区(达州 / 巴中 / 广元)农村家庭** + **川南乡镇贫困家庭(宜宾 / 泸州 / 自贡 山区)** + **成都周边郊县农村(蒲江 / 邛崃 / 大邑 / 金堂)家庭**

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(川师大 / 西华师大)** = 无学费 + 编制 = 农村家庭神器
   - **国家专项计划(川大 / 电科大 / 西南交大 / 西财 / 川农大 都有名额) = 农村专属优惠**(分数比统招低 20-40 分)
   - **三州专项(凉山 / 阿坝 / 甘孜定向)** = 加分 + 民族优惠 + 回乡编制
   - **警校 / 军校(四川警察学院 / 中国人民警察大学)** = 无学费 + 编制 + 包分配
   - **农林牧水(川农大国家专项 / 西南民大民族班)** = 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起;改医学影像 / 护理 / 农村订单医师)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:四川农村户籍,985/211 名校多个专项指标(分数比统招低 20-40 分);**川大 / 电科大 / 川农大 / 西财 都有数百个专项名额**
   - **少数民族优惠**(彝 / 藏 / 羌 / 苗 等 12 个本省少数民族):加分 + 民族班 + 三州专项
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会(川大 / 电科大 / 兰大 / 西安交大 都开)
   - **殡葬专业(长沙民政)** + 四川考生(冷门但 100% 编制 + 收入不错)
   - **农村订单医师**(西南医科大学 / 川北医学院 / 成都医学院)— 免学费 + 6 年回乡基层医院 + 编制
   - **中飞院飞行员定向班**(普通家庭男生顶级 ROI 路径,体检过 = 跨阶级)

**典型 case**:
- **凉山(西昌)彝族农村家庭** → 孩子 530 分物理类(享受民族优惠 30 分 + 三州专项) → 通过**国家专项 + 民族优惠**进**川大临床医学(国家专项)** → 985 牌子 + 国家专项编制路径 + 华西系毕业回州医院,**整个家族第一个 985**
- **达州山区农村女孩** → 605 分文史类 → 推**川师大公费师范汉语言(达州定向)** → 4 年免学费 + 毕业回达州某中学编制,**最适合农村家庭的"零风险"路径**
- **阿坝藏族家庭男孩** → 480 分物理类(三州专项 + 民族优惠) → 推**西南民族大学藏医学 + 民族班** → 4 年学费减免 + 毕业回阿坝藏医院 + 编制,**民族家庭独有路径**
- **巴中农村家庭男孩** → 570 分物理类 → 推**川农大动物医学(国家专项)** → 985 待遇双一流 + 毕业进新希望集团(成都) / 县级畜牧局编制,**农林对口跨阶级**
- **成都郊县农村家庭男孩** → 540 分物理类 → **中飞院飞行员定向班 + 体检过** → 起薪 30-50w + 编制,**农村家庭顶级反差**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 四川独有维度的额外约束

- **留川偏好**:**70%+ 四川家庭希望孩子留川**(成都 / 川渝双圈)— 这是 L2 之上的隐性约束。**如果 L2 是 ④ 或 ⑤ 普通家庭,留川约束几乎是绝对**(出省 ROI 损失 + 父母焦虑 + 文化适应)
- **三州 / 民族优惠**:农村 + 少数民族 双重buff,**国家专项 + 民族优惠 + 三州专项** 三个独立加分通道,普通家庭善用可以跨阶级 2 档
- **成渝双城圈**:**留蓉 + 重庆 互通**——四川考生选重庆大学 / 西南大学(重庆) 也算"留川"心理范畴(高铁 1 小时直达 + 川渝家庭文化亲近)
