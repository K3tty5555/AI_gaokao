# 考公优选专业表(四川本地视角)

## 核心结论

**专业决定考公选岗范围**。四川家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**四川考公的体量在全国前 5**:**省考(全省 + 21 个市州联考)+ 国考(成都 / 各市州海关 / 税务 / 中央驻川单位) + 选调生(川大 / 电科大 / 西南交大 / 西财 主供给)+ 三州专项(凉山 / 阿坝 / 甘孜艰苦边远岗) + 成渝双圈选调** — 路径多 + 岗位密 + 留川友好。

## 关键事实(2024 国考 / 四川省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 四川省考特殊性
- 四川省考 + 21 个市州联考 + 成都市考 + 攀西凉山专项,**汉语言文学和法学并列考公第一专业**
- 四川各地市公务员岗位**对法学要求高**(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)
- **三州专项(凉山 / 阿坝 / 甘孜艰苦边远岗)**:**相对低分门槛 + 民族优惠 + 加分 + 提拔快** — 农村 / 少数民族家庭独有路径
- **成渝双圈选调**:四川 / 重庆 互认选调指标,川大 / 电科大 / 西南交大 / 西财 + 重庆大学 / 西南大学 都进圈

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(四川本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- **四川选调主供给校**:**川大 / 电科大 / 西南交大 / 西南财大 / 川农大** + **985 跨省毕业生回川**
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、四川警察学院 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,川大法学院 / 西南财法 / 西南民大法学 对口

### 四川特色"非编但准编"岗位
- **国电大渡河 / 雅砻江流域 / 长江电力 / 川投能源** 央企子公司岗位:**编制类似国家电网,工资比公务员高**(电气 / 水电 / 自动化 专业对口)
- **中物院(绵阳九院)/ 中航工业成飞 / 中电科第 30 / 29 / 10 所** :**军工科研编制 + 户口 + 房补**(电子 / 机械 / 物理 / 数学 对口)
- **华西医院系 / 省人民医院 / 各市三甲医院** 编制:医学相关专业对口

## 四川本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业
- **四川大学法学** — 全国前 15,**西部司法系统老大,法考通过率高,选调路径最优**
- **四川大学中国语言文学 / 历史学 / 哲学** — A 类强势,**四川选调主供给**(中文 / 历史 / 哲学 三选一是文科考公主流)
- **四川大学经济学院** — A 类,综合就业 + 考公双友好
- **西南财大金融 / 会计 / 财政 / 税务** — 211 双一流,**财政税务系统 + 海关 + 银保监 编制对口**(四川考公认可度极高)
- **电子科技大学公共管理学院** — 985 牌子 + 公共管理 / 行政管理(冷门反差,理工科男生考公冷门洼地)
- **西南交通大学交通运输 / 土木 / 电气** — 211,**铁路系统 + 国家电网 + 各地地铁 编制对口**(行业内"准编制")
- **川师大汉语言文学(公费师范生)** — 不是考公但是教师编制,**等同于考公友好,普通家庭跨阶级最稳路径**

### 双非 + 性价比考公专业
- **西华大学(成都) 汉语言文学 / 法学 / 行政管理** — 双非但**留川考公认可度不错**(西华是省属重点),**绵阳 / 德阳 / 自贡 等市州本地考公成功率高**
- **四川师范大学法学 / 政治学** — 双非但师范底子厚,**川师政治学考公(选调对口)**性价比高
- **西南民族大学法学 / 民族学** — 双非但**少数民族 + 民族地区岗位独有优势**(三州专项 + 民族干部通道)
- **西华师范大学(南充)汉语言 / 政治** — 双非,**川东南充本地考公主供给**

### 公安系统专属
- **四川警察学院**(成都) — 本科,**公安联考路径,毕业进四川各地公安系统概率极高**(基层警察 / 派出所 / 刑侦 / 缉毒)
- **中国人民公安大学**(北京) — 全国顶配公安,出省读 + 回川考公或留京公安
- **西南政法大学(重庆)** — 211,法学西部前列,**川渝双圈考公认可顶级**(虽在重庆但川渝互认)
- **西南民大侦查学 / 监狱学** — 进司法系统(基层法院 / 检察院 / 监狱)

### 央企"准编制"专属(四川独家)
- **电科大微电子 / 电子 → 中物院(绵阳九院)/ 中航工业成飞 / 中电科 30 所 29 所 10 所** = 军工科研编制 + 户口 + 房补
- **西南交大电气 / 轨道供电 → 国家电网 / 成都地铁 / 重庆地铁 / 中铁电气化局** = 国企编制
- **川大水利 / 电气 / 西华大学电气 → 国电大渡河 / 雅砻江流域 / 长江电力 / 川投能源** = 水电央企编制(收入比公务员高)

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:四川达州考生,540 分文史类,**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报西华大学汉语言文学**,毕业当年考上达州市直某机关公务员,**家庭命运改变**(西华双非但本地考公 ROI 高于跨省 211)
- **Case B(选调路径)**:四川成都考生,650 分文史类,中产家庭。家长想报"金融"(西财金融)。**改报川大法学**,**毕业获得川大选调生资格,直接进省委组织部**,起点远超经济学就业
- **Case C(失败路径)**:四川绵阳考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了川师大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:四川家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(三州反差路径)**:四川凉山(西昌)彝族考生,550 分文史类(享受民族优惠 + 三州专项),农村家庭。**报西南民族大学法学 + 民族班** → 毕业回凉山州考公,**民族干部提拔通道 + 三州专项岗位 + 5-8 年提拔副处级**(普通家庭跨阶级跃迁路径)
- **Case F(成渝双圈)**:四川宜宾考生,620 分历史类,普通家庭。报**重庆大学法学** → 毕业获得重庆大学选调生资格,可选定向回川或定向重庆,**川渝双圈互认 + 留蓉 / 留渝 都行**(成渝一体化考公通道)

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(四川 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是四川家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**川大法学不如人大法学**" — 半对。**绝对实力人大顶 + 选调全国流向**,但**留川考公 + 留蓉司法系统,川大法学院 ROI 高于跨省去人大**(四川本地校友网密 + 留蓉户口 + 父母近)
- "**三州岗位太偏远不值得**" — 错。**三州艰苦岗位补贴 + 民族优惠 + 提拔速度比成都快 2-3 倍** — 农村 / 少数民族考生 5-8 年提拔副科 / 副处的速度远超成都基层 15 年原地踏步
- "**水电央企不算考公,工资低**" — 错。**国电大渡河 / 雅砻江流域 / 长江电力工资比成都市公务员高 30-50%** + 编制 + 项目补贴(只是要接受山区驻点 5 年攒首付)

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是四川家长被严重低估的考公王者**。

**四川考生的考公杠杆**:
1. **省考 + 21 个市州联考 + 成都市考** = 岗位密度全国前 5
2. **三州专项(凉山 / 阿坝 / 甘孜)+ 民族优惠 + 加分** = 农村 / 少数民族家庭独有跨阶级路径
3. **成渝双圈选调互认** = 川大 / 电科大 + 重庆大学 / 西南大学 互通,留川 / 留渝 都行
4. **央企"准编制"路径** = 中物院 / 成飞 / 大渡河 / 雅砻江 / 长江电力 / 中航成飞 + 各地地铁 + 国家电网 — 工资比公务员高 + 编制确定
