## 关键提醒(填报陷阱)

1. **校区分配是大坑**:
   - **雅安校区(本部,雅安市)**:**老校区,部分动科 / 动医 / 农学 在这里**,**雅安离成都 130 km(高铁 1.5 小时)+ 县城氛围**,接受不了的别冲。
   - **成都校区(温江,主流本科)**:**90% 本科生在温江**,跟西财温江校区相邻,地铁 4 号线可达。
   - **都江堰校区**:**部分园林 / 林学 / 旅游管理在都江堰**,**离成都 50 km + 风景区氛围**。
   - **报志愿前必查 2026 年招生章程具体专业校区**。
2. **物理类 / 历史类专业组分化**:
   - **王牌组**:作物学 / 动物科学 / 动物医学 / 食品科学(王牌组录取分相对中等,因农林冷门)
   - **主流组**:园艺 / 林学 / 风景园林 / 农资环
   - **冷门组**:经管 / 信息 / 部分理工
3. **服从调剂注意**:中分组可能调到草业 / 农林经济 / 信管,接受不了别勾。
4. **农林行业的现实**:
   - **基层是真的基层**:农场 / 牧场 / 林场 / 县乡农业局,**接受不了下乡别报**——但**留川农林系统编制 = 公务员铁饭碗 + 工作稳定**。
   - **行业整体不卷,稳定性高**,但起薪不如互联网 / 金融。
   - **考研率高(35%+)**,本科作跳板进 985 农林 PhD 路径不错。
5. **川农大 vs 川大农学院**:川大有动物 / 食品方向但川农大才是西部农林的核心(川大农林边缘);**学农林 → 川农大 > 川大**。
