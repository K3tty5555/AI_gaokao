## 一句话总结

**双非但中医药全国前列 + 西部中医药唯一"双一流"**(中药学双一流学科),跟北中医 / 上中医 / 广中医 / 南中医 一档,**四川中医院系统对口顶配**,**留川学中医 / 中药 + 进华西 / 省中医院 + 考公编制** 普通家庭性价比之王。

## 真实地位

- **双非(非 211 / 非 985)+ 双一流(中药学双一流学科)** + 国家中医药管理局 / 教育部 / 四川省共建 + **十二桥(老校,成都市内)/ 温江(本部,主流本科)/ 汪家拐(华西坝旁)** 三校区。
- **中医药"四老"之一**(北京 / 上海 / 广州 / 成都四所建国早期中医药院校),**新建两所跟"四老"齐名的(南京中医药 / 天津中医药)+ 黑龙江中医药** = "中医药 7 强",**成中医在 7 强中排名前列**。
- **四川本省地位**:**双非但中医药行业内 ≥ 多数 211**——华西医院 / 省中医院 / 各市中医院 招聘中医师,成中医认可度封顶,**比川大医学院学中医更对口**(川大华西强西医,中医选成中医)。
- **同档对比**:跟北中医 / 上中医 / 广中医 / 南中医 同为"老牌中医药",**成中医的特色是中药学(双一流)+ 川派中医 + 西部中医药唯一**——西部中医药招聘量大,出路稳。
- 学风**严谨 + 中医文化氛围浓 + 古籍背诵 + 实习多** + **女生比例 70%+** + 学制长(中医临床本科 5 年 + 规培 3 年 + 研究生 3 年 = 11 年苦读)。

## 关键提醒(填报陷阱 + 中医路径硬约束)

1. **校区分配**:
   - **温江校区(本部)**:**90% 本科生 4 年在温江**,跟西财 / 川农大温江校区相邻,**离市区 30 分钟地铁(4 号线)**,新校区设施好但离市区有距离。
   - **十二桥校区(老校)**:**成都市内武侯区**,**主要是研究生 + 部分高年级本科 + 中医临床实习**(对接华西坝医院群)。
   - **汪家拐**:**华西坝旁,跟华西医院共享部分医疗资源**,部分实习用。
2. **中医路径学制长 + 苦学**:
   - **中医本科 5 年 + 规培 3 年 = 8 年**(跟西医一样长)
   - **中医硕士 / 博士 + 5 年 = 13 年**(进华西 / 省中医院 主治医师层 = 30 岁 + 起步 8-12w)
   - **接受不了苦学 + 想 4 年毕业找工作** → 别选中医临床,选中药学 / 针推 / 护理(4 年制)
3. **物理类 / 历史类专业组分化**:
   - **王牌组**:**中药学 / 中医学 / 针灸推拿 / 中西医结合**
   - **主流组**:**药学 / 中药资源 / 眼视光 / 中医骨伤**
   - **冷门组**:**护理 / 公共事业管理 / 藏医 / 民族医学**
4. **服从调剂注意**:中分组可能调到护理 / 公共事业管理 / 信管,**中医临床报不上的话调到护理也有体制内出口**(中医院护士 + 编制),但工商管理 / 信管接受不了别勾。
5. **中医行业现实**:
   - **三甲医院中医科招聘门槛高(硕博 + 规培过)** → 本科直接进华西 / 省中医院 难,大多去市县中医院 + 民营中医诊所。
   - **中医行业整体编制 + 稳定 + 越老越值钱** = 跟西医同档收入但前期慢。
   - **海外中医(尤其针灸 / 推拿)是大蓝海**:北美 / 欧洲 / 东南亚华人对中医针灸需求大,**毕业出国开诊所 + 高收入**(年薪 50-100w 美刀级别,稀少但路径存在)。
6. **成中医 vs 川大华西临床**:
   - **学西医临床 → 川大华西**(全国前 10)
   - **学中医 / 中药 / 针灸 → 成中医**(全国前 5)
   - **学中西医结合 → 看个人,成中医中西医结合科 + 川大华西中医科 都行**
   - **铁了心做中医师 → 成中医比川大医学院更对口**(行业认可度成中医高)。

## 适合谁

- 四川考生 **物理类省排 70,000 名内 / 历史类 18,000 名内** + 想学中医药。
- **女生 + 想留川 + 想进中医院系统**:成中医女生比例 70%+ + 中医师氛围适合。

- **想做针灸推拿师 + 海外开诊所**(海外针推大蓝海,**反差 ROI 高**)。
- **农村出身 / 县城出身回乡当中医师**(县乡中医院编制 + 体面 + 越老越值钱)。

- **铁了心走中医路径 + 不想西医** 的考生(成中医比川大华西更对口中医)。

## 不适合谁

- **不接受学制长 + 想 4 年毕业** → 中医临床要规培,选 4 年制专业(中药 / 针推 / 护理 / 卫管)。
- **想做西医 / 外科医生 / 口腔医生** → 选川大华西,成中医不对口。
- **不喜欢背古籍 + 接受不了中医理论体系** → 中医苦在背诵《黄帝内经》《伤寒论》,不爱读古文别冲。
- **男生 + 不接受女多氛围**:成中医女生 70%+,工科男容易感觉不适应。
- **铁了心要出川 + 想去东部** → 成中医留川对口最强,出省认可度不如北中医 / 上中医。
- **想搞 IT / 工科 / 财经** → 选 211,成中医这些是边缘。
- **追求高起薪 + 不接受规培期低薪 + 中医前期慢** → 中医前 8 年低薪苦熬,接受不了走西医或互联网。

## 关于学中医的最后告诫

**中医不是"学不会西医的退路"**,中医是独立完整的医学体系 + 文化传承。报中医的孩子要做好心理准备:

1. **苦学 11 年** — 5 本 + 3 规培 + 3 硕士 才是三甲中医师起步
2. **理论体系跟现代医学不同** — 接受不了别学(尤其理科强 + 唯物论 + 不信中医的孩子)
3. **本科找工作难** — 大多去市县中医院 / 民营诊所,**三甲门槛硕博**
4. **越老越值钱** — 中医师 40+ 才是巅峰,跟西医的"35 岁危机"完全相反

**适合的路径**:
- **中医临床(成中医)** = 长周期 + 规培 + 进中医院编制(中产以上家庭)
- **针灸推拿** = 4 年本科 + 反卷洼地 + 海外大蓝海(普通家庭友好 + 出国路径)
- **中药学** = 4 年本科 + 中药企业(国药 / 同仁堂 / 太极)+ 编制(普通家庭友好 + 不用规培)
- **藏医学 / 民族医学** = 少数民族独家 + 民族优惠 + 回藏区编制

**不适合的路径**(选了浪费成中医牌子):
- **成中医 CS / 经管 / 工商 / 公管 / 信管** = 双非水专业,失去成中医核心 ROI
