## 性价比专业

- **集成电路 / 微电子**:**国家战略 + 行业大缺口**,**录取分比 CS 略低但天花板更高**(IC 设计起薪 25-40w),反卷洼地。
- **网络空间安全**:**国家战略 + 行业薪资跟 CS 拉平 + 录取分相对低**,适合理工兴趣考生。
- **光电信息(光学工程方向)**:**录取分比 CS 低 5-10 分**,但中电科 / 光电研究所对口稳定。
- **电子科学与技术(英才实验班 / 试验班)**:**保研率 40%+,直博华为天才少年 / 海归博士路径**。

## 坑专业(电科大里相对弱)

- **文科 / 经管 / 法学 / 公共管理**:在电科大是边缘学科,**学文科直接选川大,别在电科大学文科**。
- **机械 / 土木**:中等,**不如川大或西南交大**。
- **生物 / 化学(纯理)**:除了医工方向,**生化环材在电科大是工具人专业**。
- **英语 / 商务英语**:工科校的英语系出路一般。

## 适合谁

- 四川考生 **物理类省排 6,000 名内** + 男生 + 想做互联网 / 通信 / IC / 国防科工。
- **想拿华为 / 中兴 / 腾讯 / 字节 起薪 25-40w** 的工科男生(对口直签)。
- **普通家庭男生 + 想跨阶级 + 接受工科严谨 / 男多 / 996 节奏**。
- **想留川 + 进腾讯成都 / 字节成都 / 华为成都** 研发中心 → 电科大校招直签认可度封顶。
- **想搞 IC / 集成电路** 的国家战略赛道考生(行业 10 年红利)。
- 想读电子 / 通信 PhD 出国 / 直博的学霸(电科大保研率 30%+)。

## 不适合谁

- **女生 + 不爱工科 + 怕男多氛围**:电科大女生比例约 20%,**对口岗位多偏硬核工程**,接受不了别来。
- **学医 / 文 / 法 / 财经** → 选川大或西财,电科大这些是边缘。
- **想学农林兽医** → 川农大。
- **想学综合性 / 通识教育**:电科大工科氛围浓,综合性选川大或武大。
- **不接受高强度学习**(电科大挂科率比川大高,工科压力大)。
- **铁了心要出川**:电科大留川 ROI 极高,腾讯成都跟腾讯深圳薪资差距 < 房价差距,**留蓉性价比之王**。
