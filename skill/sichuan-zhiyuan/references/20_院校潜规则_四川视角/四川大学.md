## 一句话总结

**四川"心理上限"高校 + 综合 985 第二档**(Top 15-20),**口腔医学全国第 1 + 华西医学独家神级**,文理医全能,工科中等。**留蓉考公 / 学医 / 学法 / 学文** 普通家庭跨阶级最稳路径。

---

## 真实地位

- **985 + 双一流 + 教育部直属** + 望江(老牌)/ 华西(医学)/ 江安(新)三校区。
- **全国 985 第二档**,跟华科 / 中山 / 武大 一档,综合实力比兰大 / 东北 / 中农 强半档。
- **四川本省地位**:**川大 = 西部综合性最强 985**,文理医都能打,父母听到"川大"会觉得跟清华一样,要纠正:**川大 ≈ 武大 / 中大 / 华科**,不是 C9。
- **华西医学独家神级**:口腔 / 临床 / 护理 全国前 5,**川大华西比某些 C9 医学院还顶**——口腔医生这职业,华西毕业生跟北大口腔毕业生薪资基本一样。
- 学风综合性 + 自由散漫,文科氛围浓,男女比平衡。

## 性价比专业

- **法学**:全国前 15,**留川考公考律所对口**,**西部司法系统川大法学院最硬**——比跨省去人大政法对四川考生 ROI 更高。
- **历史 / 哲学 / 马克思主义理论**:**录取位次低 + 留川考公选调对口**,文科冷门组性价比组合。
- **预防医学 / 基础医学**:**比临床录取分低**,但走研究 / 公共卫生 / 疾控编制路径,**疫情后被低估**。
- **法医学**:全国前列,**进公安系统编制**(法医专业警察),冷门顶级。

## 坑专业(川大里相对弱)

- **机械 / 电子 / 通信**:川大工科中等,**直接选电科大或西南交大**,别在川大学这些。
- **轨道 / 交通**:川大没这块强,**选西南交大**。
- **航空航天**:川大无,**别报**。
- **农林**:川大农林边缘,**选川农大**。
- **工商管理 / 行政管理 / 公共管理**:985 牌子也救不了,水专业。
- **生化环材(非华西医学方向)**:必须读博 + 研究院出口,本科直接就业难。

## 录取分布(四川考生)

**2021-2024 旧高考(理 / 文)位次区间**:

- **理科**:全省 **800-3,500 名段**(王牌组华西临床 / 口腔 在 800-1,500 名,主流组 2,000-3,500 名)
- **文科**:全省 **300-1,200 名段**(法学 / 中文 / 经济 在 300-600 名)

**2025 首届新高考(物理 / 历史)位次区间**:

- **物理类**:全省 **800-4,500 名段**(王牌组顶到 800-1,800,中段组 2,500-4,500)
- **历史类**:全省 **300-1,500 名段**(法学经济 300-700,中文历史 700-1,500)

**段位定位**:**川大物理类省排 4,500 名内可冲,1,500 名内挑王牌组**;**历史类 1,500 名内可冲,500 名内挑法学经济**。**以一分一段表反查为准,不编分数**。

## 适合谁

- 四川考生 **物理类省排 4,500 名内 / 历史类 1,500 名内**,想留川或回川发展。
- **学医(口腔/临床/护理) → 华西是西部医学顶级 + 全国封顶**,口腔尤其。
- **学法 → 川大法学院 + 西部司法系统**,留川考公 / 律所最硬路径。
- **学中文 / 历史 / 哲学 → 留川考公选调 + 高校教师** 文科稳路径。
- **学经济 / 工商 → 留蓉金融 / 互联网 / 国企** 综合路径(跟西财互补)。
- 父母听了川大就觉得"娃考上了清华一档"的家庭(沟通成本最低)。
- 普通家庭跨阶级,**走"川大法学/中文 + 留川公务员"** 的稳路径。

## 不适合谁

- **想学顶级电子 / IT / 通信** → 电科大,川大工科中等。
- **想学轨道交通 / 高铁产业** → 西南交大。
- **想学农林兽医** → 川农大。
- **分够清北复交人** → 别在川大将就医学之外的专业。
- **不接受工科中等就业天花板**(川大工科出口比电科大低一档)。
- **铁了心要出川冲东部一线**(川大 + 留川 ROI 最高,出川走 985 弱专业不划算)。
