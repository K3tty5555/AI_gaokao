## 一句话总结

**双非但民航飞行员国内独家培养基地 + 民航局直属**(中国 80%+ 民航机长出自这里),**东航 / 南航 / 国航 三大航定向班对口**,飞行员定向班毕业即进体制,**起薪 30-50w / 机长 80-120w**——**普通家庭男生 + 视力体检过 + 政审过 = 顶级 ROI 路径,远超大多数 985**。

## 真实地位

- **双非(非 211 / 非 985)+ 中国民航局直属高校**(全国唯一)+ **广汉(本部,德阳广汉)/ 洛阳 / 绵阳 / 遂宁 / 新津 五大分院**(每个分院主飞一种机型)。
- **民航飞行员国内独家培养基地**——中国民航 80%+ 现役机长出自这里,**院系内"中飞院"地位 ≈ 飞行员领域清华**,跟北航(985 但飞行员培养比中飞院少)/ 南航(211 含部分定向)拉开差距。
- **四川本省地位**:**双非但行业内顶配** + **民航系统编制对口最直接** + **跟成都中医药 / 成都信息工程 同为四川"行业独家双非"**——一个学校跟一个职业(飞行员)绑定,**报志愿不能用综合排名衡量**。
- **同档对比**:**民航飞行员赛道国内独家无替代**,北航 / 南航 / 西工大有航空航天但飞行员招生量小,**飞行员 90%+ 出自中飞院**——**牌子双非但行业封顶,反差 ROI 极高**。
- **学风**严谨准军事化(飞行员训练强度大)+ 男女比 8:2(飞行员几乎纯男生)+ **接受体能 / 体检 / 政审三关** + 实操多于理论。

## 性价比专业(普通家庭顶级 ROI)

- **飞行技术(三大航定向班 / 提前批)**:**普通家庭顶级 ROI 之王**——**录取分约本科特控线(物理类全省 25,000-50,000 名)+ 体检过 + 政审过 = 毕业进三大航当副驾**,**起薪 30-50w + 副驾 5-8 年升机长 + 机长年薪 80-120w**,**远超绝大多数 985 工科**。
- **空中交通管理(管制员方向)**:**进民航空管局编制**,**起薪 25-35w + 编制 + 户口 + 子女教育**,**比飞行员体检要求低 + 不用上天 + 体制内稳定**——**反卷洼地之王**。
- **航空机务工程**:**进三大航维修工程师**,**起薪 12-18w + 编制 + 包吃住**,**比飞行员门槛低 + 稳定**。
- **交通运输(签派 / 调度方向)**:**进民航局或航空公司运行控制中心**,**编制 + 高薪 + 工作稳定**。

## 坑专业(中飞院里相对弱)

- **经管 / 行政管理 / 工商管理**:**民航相关也只是边缘**,**学财经选西财,学管理选 211 综合**。
- **新闻 / 文学 / 法学**:**完全边缘**,**不是中飞院核心赛道**。
- **空中乘务(高职 / 本科)**:**行业内卷严重 + 颜值身高门槛 + 工作 5-8 年容易转岗** → **不是顶级 ROI 路径,慎选**(尤其女生别冲空乘想着躺赢,容颜衰老后职业路径窄)。

## 关键提醒(填报陷阱 + 飞行员硬约束)

1. **飞行员定向班是顶级路径但有 4 道硬关**:
   - **民航体检关**(招飞体检):**视力 4.5 以上 + 身高 168-185 + 五官端正 + 无色弱 + 心电图 / 血压全过**(**中飞院招飞体检比公务员体检严 10 倍**——任何小问题都直接刷)
   - **政审关**:**三代直系亲属无重大违法记录 + 无境外背景**(**祖父母 / 外祖父母 / 父母 / 兄弟姐妹** 都查)
   - **心理素质关**:**面试 + 抗压测试**
   - **签订定向协议**:**毕业必须去签约航司服役 N 年,违约赔偿百万级**
2. **报飞行员的失败成本**:**体检不过 → 退回普通批 / 调剂到非飞行专业**(中飞院非飞行专业出口一般,**报飞行员要确保自己体检和政审过得了**)。
3. **三大航定向班 vs 自费飞行员**:
   - **定向班**:**学费由航司承担 + 毕业必去 + 编制确定** = 普通家庭路径(**90% 中飞院飞行员走这条**)
   - **自费飞行员**:**学费 70-100 万自付 + 毕业自找航司** = 富裕家庭路径(中飞院少见)
4. **物理类专业组分化**:
   - **王牌组(提前批 / 飞行员定向)**:**飞行技术 + 空管 + 民航工程**
   - **主流组(本科批)**:**飞机维修 / 航电 / 民航管理 / 交通运输**
   - **冷门组**:**部分理工 / 经管 / 文科**(**报中飞院别冷门组,失去核心 ROI**)
5. **女生报中飞院**:**飞行员录取女生比例 < 5%**(**身高 / 体检 / 行业偏好**),**女生想搞民航选空管 / 签派 / 机场管理 / 航空机务** → 编制 + 高薪 + 不用上天,**比空乘 ROI 高 3-5 倍**。
6. **中飞院 vs 南航(211)**:**南航航空航天工业 + 部分飞行员定向**(分高 + 比中飞院飞行员体检略宽);**中飞院飞行员独家 + 实操多 + 行业内认可度封顶**——**铁了心当飞行员选中飞院**。

## 录取分布(四川考生)

**2021-2024 旧高考(理 / 文)位次区间**:

- **理科**:全省 **30,000-90,000 名段**
   - **飞行员定向班(提前批)**:**全省 25,000-50,000 名 + 必过体检政审**(**分数比裸进南航航空航天低 30-50 分**——这是核心 ROI)
   - **空中交通管理 / 民航工程**:全省 30,000-55,000 名
   - **飞机维修 / 航电**:全省 50,000-75,000 名
   - **冷门组**:全省 75,000-90,000 名
- **文科**:全省 **15,000-35,000 名段**(招生少,经管 / 民航管理为主)

**2025 首届新高考(物理 / 历史)位次区间**:

- **物理类**:全省 **25,000-95,000 名段**(飞行员定向 25,000-50,000 / 空管民航工程 30,000-55,000 / 维修航电 50,000-75,000)
- **历史类**:全省 **15,000-35,000 名段**(招生少)

**段位定位**:**中飞院飞行员定向 25,000-50,000 名最优**(分数中等 + 体检过 = 顶级 ROI),**空管 30,000-55,000 名是反卷洼地**,**普通本科批 50,000-95,000 名性价比中等**。**以一分一段表反查,不编分数**。

## 适合谁

- 四川考生 **物理类省排 25,000-90,000 名 / 历史类 15,000-35,000 名** + 想搞民航。
- **男生 + 视力 4.5 以上 + 身高 168-185 + 体检合格 + 政审清白 + 想当飞行员**:**飞行员定向班是顶级 ROI 路径**(**比 985 工科收入高 3-5 倍**)。
- **不想当飞行员但想搞空管 / 民航工程**:**反卷洼地 + 编制 + 高薪**,女生友好。
- **普通工薪 / 农村家庭男孩** + 想要稳定央企编制 + 高薪:**中飞院 = 跨阶级路径**。
- **接受准军事化训练 + 体能要求 + 实操多于理论** 的考生。
- **想留川或回川**(川航 / 双流 / 天府 / 西部空管局 都在四川)。

## 不适合谁

- **女生 + 想当飞行员**:**女飞 < 5%**,体检和身高门槛卡得严,绝大多数女生进不去飞行员定向班。
- **视力差 / 体检不过 / 政审有问题**:**别冒险报飞行员**——失败成本是退回普通批 + 中飞院非飞行专业出口一般。
- **不接受体能训练 + 准军事化纪律**:中飞院飞行员训练强度大,体能差的人进去也撑不住。
- **想搞综合性 / 通识教育 / 自由学风**:中飞院是行业实操校,跟川大综合性氛围天差地别。
- **想搞文科 / 财经 / 法学 / IT** → 中飞院非民航专业是边缘,选 211。
- **怕高 / 怕坐飞机 / 怕远离家**:民航是空中职业 + 工作地点全国飞,接受不了别报。
- **追求"光鲜双 985 牌子" + 看不起双非**:**中飞院是行业内顶级反差 ROI,牌子双非不代表就业弱**——飞行员是反例之王。
