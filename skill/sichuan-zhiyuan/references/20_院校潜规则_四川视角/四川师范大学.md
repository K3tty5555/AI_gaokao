## 一句话总结

**双非师范主力 + 留川教师对口校**,**四川中小学教师 60%+ 出自川师大**,跟广西师大 / 河南师大 / 湖南师大(湖师大有 211)同档,**普通家庭女生 + 想留川当老师 + 教编铁饭碗** 最稳路径。

---

## 真实地位

- **双非(非 211 / 非 985)+ 教师教育"国优计划"试点高校** + 四川省属重点 + **狮子山(本部,成都市内)/ 成龙(新校,东三环外)** 双校区。
- **双非师范第一梯队**(跟广西师大 / 河南师大 / 福建师大 / 江西师大 一档,**湖南师大已升 211**),**四川省内师范类绝对老大**——四川中小学骨干教师 60%+ 出自川师大。
- **四川本省地位**:**双非里牌子封顶**(在川大 / 电科大 / 西南交大 / 西财大 / 川农大 5 个 211 之后是双非,川师大是双非之首),**留川考教师编制 = 川师大 > 多数 211**(川大文科除外)。
- **同档对比**:跟成都中医药大学(医科双非)/ 成都信息工程大学(气象双非) 同为成都市内双非头部,但**师范赛道川师大独占**——四川教育系统招聘川师大认可度超过 211 工科校。
- 学风**实用 + 考公考编友好 + 务实**,**女生比例 70%+**,师范氛围浓。

## 性价比专业

- **公费师范生(部省两级)**:**录取分相对低 + 毕业进编制 + 学费免 + 生活补贴**——**普通家庭跨阶级最稳路径之一**(类似华中师大公费师范),**川师大公费师范分数比裸进师范专业低 5-10 分**。
- **学前教育 / 小学教育**:**录取分较低 + 行业大缺口 + 编制对口稳**,女生友好。
- **思想政治教育(师范)**:**录取分相对低 + 考公对口顶配**(政治学背景考公优势)。
- **体育教育**:**录取分低 + 中小学体育老师编制 + 体测加分政策**,男生反卷选项。

## 坑专业(川师大里相对弱)

- **CS / 软件工程 / 网络工程**:**双非工科 CS,出口不如电科大 / 西南交大**,**学纯 IT 别选川师大**。
- **经管 / 法学 / 工商管理**:在川师大是边缘,**学财经选西财,学法选川大**。
- **新闻传播 / 广播电视(非师范)**:出口一般,改行率高。
- **非师范类工科 / 理科**:**川师大牌子救不了非师范工科**——师范师范师范,选了师范赛道才有 ROI。

## 关键提醒(填报陷阱)

1. **校区分配**:
   - **狮子山校区(本部)**:**成都市内(锦江区)**,**地铁可达 + 城市便利**,**研究生 + 部分高年级本科**在这里。
   - **成龙校区(新校)**:**成都东三环外(龙泉驿区)**,**90% 本科生在这里**,**离市区 30 分钟地铁**,新校区设施好但离市区有距离。
2. **师范 vs 非师范两条路**:
   - **师范专业**(后缀"师范"):**毕业拿教师资格证 + 教育系统校招 + 考教编 = 川师大核心 ROI**
   - **非师范专业**(同名无后缀):**川师大牌子在非师范赛道一般** = 多个双非随便选其实差不多
   - **报志愿一定看清是不是"师范"专业**——信息错位是大坑。
3. **公费师范生 vs 普通师范生**:
   - **公费师范生**:**学费免 + 生活补贴 + 毕业 6 年内必须回签约市州当老师** = 体制内编制确定路径
   - **普通师范生**:**自由就业 + 自考教编 / 自找学校** = 灵活但需自己跑
   - **农村出身 + 笃定回川 → 公费师范是顶级 ROI**。
4. **物理类 / 历史类专业组分化**:
   - **王牌组**:语文 / 数学 / 英语 / 物化生(中学主科师范)
   - **主流组**:政史地 / 心理 / 教育学
   - **冷门组**:学前 / 小教 / 艺术 / 体育(部分单招)
5. **服从调剂注意**:可能调到非师范专业(信管 / 工商管理 / 旅游),**接受不了的别勾**(失去川师大核心优势)。
6. **川师大 vs 西华师大(南充)**:**川师大成都地理 + 牌子大**,**西华师大南充地理偏 + 牌子稍弱**——成都生源进川师大是性价比之选,南充本地考生才考虑西华师大。

## 录取分布(四川考生)

**2021-2024 旧高考(理 / 文)位次区间**:

- **理科**:全省 **40,000-90,000 名段**(王牌物化生师范 在 40,000-55,000,主流师范 55,000-75,000,冷门 75,000-90,000)
- **文科**:全省 **10,000-25,000 名段**(王牌中文 / 历史师范 在 10,000-15,000,主流师范 15,000-22,000,冷门 22,000-25,000)
- **公费师范生**:**比普通师范低 3,000-8,000 名**(同档专业)

**2025 首届新高考(物理 / 历史)位次区间**:

- **物理类**:全省 **40,000-95,000 名段**(王牌 40,000-55,000 / 主流 55,000-75,000 / 冷门 75,000-95,000)
- **历史类**:全省 **10,000-28,000 名段**(王牌 10,000-15,000 / 主流 15,000-22,000 / 冷门 22,000-28,000)

**段位定位**:**川师大物理类省排 95,000 名内可冲,55,000 名内挑师范主力**;**历史类 28,000 名内可冲,15,000 名内挑王牌**。**双非里牌子封顶,普通家庭性价比之王**。**以一分一段表反查,不编分数**。

## 毕业出口(2024 数据)

- **留川就业**:**约 80-85%**(**成都 + 各市州中小学为主**,**成都七中 / 树德 / 石室 / 嘉祥 / 西川 / 各市重点中学 + 各县乡中学** 校招主力,**川师大留川教师生态最厚**)
- **出省就业**:约 10-15%(主要是西部其他省份 / 沿海重点中学聘用)
- **考研 / 读博**:约 20-25%(主要考川大 / 华东师大 / 北师大 教育学硕)
- **出国**:约 3-5%
- **教师编制 + 考公选调**:**约 50-55%**(**川师大主战场,师范生 70% 走教编路径**)
- **进民营教培 / 互联网教育**:约 10%(新东方 / 学而思 / 高途 / 跟谁学 等)
- **起薪范围**:**成都中小学教师编制 8-12w + 编制 + 五险一金 + 寒暑假**(成都重点中学 12-18w),**县乡中学教师编制 5-8w + 编制 + 房补**,**民营教培老师 10-20w**(高薪但行业波动),**考研后高校 / 教育局机关 8-15w**。

## 适合谁

- 四川考生 **物理类省排 95,000 名内 / 历史类 28,000 名内** + 想当中小学老师。
- **女生 + 想留川 + 想要教师编制铁饭碗**:川师大女生比例 70%+ + 师范氛围匹配。
- **普通家庭跨阶级 + 公费师范路径**:学费免 + 编制确定 + 留川回乡当老师。
- **想做幼儿园 / 小学老师**(学前教育 + 小教是行业大缺口)。
- **想考公选调对口**(政治学 / 教育学 / 中文 / 历史考公友好)。
- **接受成龙校区(成都郊区)+ 师范实用风** 的考生。
- **农村县城考生回乡当老师**(教师在县乡是体面职业 + 编制 + 寒暑假 + 子女教育优惠)。

## 不适合谁

- **不想当老师 + 想搞工科 / 金融 / IT** → 选 211(电科大 / 西财 / 西南交大),川师大非师范专业出口一般。
- **男生 + 不接受女生为主的校园氛围** → 川师大男生约 30%,介意的别冲。
- **铁了心要出川 + 不想留川** → 川师大主战场是四川教育系统,出川认可度不如 211 师范。
- **追求高起薪 + 不接受教师 8-12w 起薪** → 选互联网 / 金融赛道。
- **不喜欢教书 + 喊家长烦** → 教师职业是良心活 + 跟人打交道,内向考生慎选。
- **分够川大文学院 / 数学院** → 川大综合性 985 + 高中编制路径优于川师大。
