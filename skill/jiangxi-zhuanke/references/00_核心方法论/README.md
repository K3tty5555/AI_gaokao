# 江西专科 skill 核心方法论

## 跟湖北版的关键区别

江西专科和湖北专科**不能套同一套话术**。三个本质差异:

### 1. 经济基本盘不同
- 湖北有光电(华工科技 / 烽火 / 长飞)/ 汽车(东风)/ 钢铁(武钢)/ 制药 等多条腿
- 江西本省支柱**集中在矿冶(江铜 / 江钨)+ 农业 + 红色旅游**,**新兴产业弱**
- 直接结果:**江西专科生本省就业的"行业宽度"比湖北窄**,推荐时要更早问"打不打算出省"

### 2. 出省方向不同
- 湖北专科生出省主要去广深、长沙(地理近 + 文化近)
- 江西专科生出省主要去**长三角(苏州 / 杭州 / 宁波)+ 珠三角(广深 / 东莞)**
- 江西**不少县市本身就是劳务输出大县**(吉安 / 抚州 / 上饶 县乡居民去长三角打工是常态),家庭对"专科出省"接受度比湖北高

### 3. 高考改革节奏不同
- 湖北 2021 首届 3+1+2(2026 届是第六届,数据沉淀厚)
- 江西 2024 首届 3+1+2(2026 届只是第三届,**新高考专科批数据样本只有 2 届**)
- 推荐时务必标注:用 2023 及之前的老高考数据 = 文理科线差换算,**不能直接用**

## agent 输出风格底线

- **不套用湖北话术**:"武汉七校""华科 vs 武大"这类术语在江西版完全不能出现
- **不编数字**:江西新高考样本少,引用录取率 / 投档线时要么标年份要么直接说"目前样本不够,建议查招生章程"
- **直面"江西穷"**:不回避江西工资低、岗位少的事实,但要给清晰的应对策略(专升本 / 出省 / 锁定央企)
- **case 必须用江西本地地名**:南昌 / 九江 / 赣州 / 上饶 / 吉安 / 景德镇 / 抚州 / 宜春 / 萍乡 / 鹰潭 / 新余,不能出现湖北黄冈 / 宜昌之类
