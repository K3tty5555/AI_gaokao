# 华中科技大学(HUST)— 工科顶配 985

## 性价比专业(同样 985 牌子,录取分相对低)

- **新闻传播**:**比 CS 录取分低 5-10 分**,但全国前 5 出路远好于双非 CS
- **建筑学 / 城乡规划**:**专业课要求,录取位次相对低**,行业景气下降但底子还行
- **公共卫生**:疫情后更被关注,行业出口稳定

## 坑专业(华科里相对弱)

- **法学 / 工商管理 / 国贸**:华科文科类不强,**直接选中南财法或武大**
- **经济金融**:不如中央财经 / 上海财经 / 中南财法 头部财经院校
- **生化环材**:虽然学校综合实力顶级,但**生化环材本身坑** + 必须读博

## 关键提醒(填报陷阱)

1. **华科物理类专业组分组逻辑**:
   - **(03)/(04) 顶级组**(光电 / 机械 / 计算机 / 临床)→ 录取位次最低 3033 名
   - **(05)-(08) 中段组**(各种工科 + 部分医学)→ 录取位次 6000-7700 名
   - **(01) 提前批**(强基 / 国防 / 军校方向)→ 录取位次 5800-6500 名
   - **末流组少**:**华科最弱专业组也比一般 211 强**,所以专业组数量不多
2. **华科 CS 不是闭着眼报 - 看你能进哪个组**:CS 主流方向在 (03)/(04) 顶级组,需要 3000 名内;中段组的 CS 是分校区或国际班,出路不同
3. **服从调剂注意**:华科顶级组内部专业差异不大都是工科顶配;但中段组可能含相对冷门专业(材料/船舶/采矿等)
4. **华科 vs 武大**:理工医选华科,文科综合选武大

## 毕业去向(2024 数据)

- **留湖北就业**:约 25-30%(湖北本地工科就业不如长三角珠三角)
- **出省(上海/深圳/北京)就业**:约 50-55%(华为 / BAT / 互联网大厂主战场)
- **考研 / 读博**:约 30-35%(华科保研率 ~30%)
- **出国**:约 8-12%
- **进国家电网 / 央企**:约 15-20%(电气类毕业生主要去向)
