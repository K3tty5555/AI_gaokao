# 武汉理工大学(武理工)— 211 工科特色

## 一句话定位

**三校合并的工科 211**(原武汉工业 + 武汉交通科技 + 武汉汽车工业),**材料 / 车辆 / 船舶 / 交通**全国前 5,湖北本地工科第二选择(仅次于华科)。

---

## 湖北物理类录取位次分布(实测)

| 年份 | 普通类位次范围 | 普通类分数范围 |
|---|---|---|
| 2024 | **5,326-21,511** | 592-636 |
| 提前批 | 21,500-25,200 | 585-592 |

**段位定位**:位次跨度大(5,300-21,500),专业组分化明显:
- 高分组(车辆 / 材料 / 船舶):5,300-7,000 名
- 中段组(机械 / 自动化等):7,000-13,000 名
- 低分组(其他工科):16,000-21,500 名

615 分(~8,880 名)**完美匹配中段组,稳档**;**低分组保档稳过**。

## 王牌专业(全国顶级)

| 专业 | 学科评估 | 行业地位 |
|---|---|---|
| **材料科学与工程** | A+ | 全国前 5(但材料是天坑) |
| **船舶与海洋工程** | A | 全国前 5 |
| **车辆工程** | A | 全国前 10,**对应汽车行业(东风 / 比亚迪)** |
| **交通运输工程** | A | 强势 |
| **物流工程** | A | 强势 |

## 性价比专业

- **车辆工程**:不在材料天坑里,**对应中国汽车业崛起红利**(新能源 / 智能驾驶)
- **船舶与海洋工程**:**进中船 / 中海油 / 中远海运**,央企铁饭碗,行业相对冷门 → 录取分较低 → 性价比高
- **轮机工程 / 油气储运**:行业内对口央企就业稳定

## 坑专业(在武理工里相对弱)

- **计算机科学与技术**:**比华科 CS 弱一档**,**别为了 CS 来武理工,直接选华科或武大**
- **经济金融类**:武理工不是财经类强校,**学财经直接选中南财法**
- **文科类(法学 / 文学 / 新闻等)**:武理工是工科为主,文科边缘
- **材料(虽然全国第 1)**:**学科评估顶级,但材料是四大天坑专业**,本科出路差,必须读博

## 关键提醒(填报陷阱)

1. **物理类专业组分组逻辑(2024 数据)**:
   - **(08)-(10) 高分组**(5,326-5,982 名):车辆工程 / 材料科学 / 船舶 王牌组
   - **(11)-(13) 中分组**(6,777-12,158 名):机械 / 自动化 / 控制工程 / 交通工程
   - **(14) 中低组**(21,511 名):其他工科 / 偏冷门
   - **(06) 不限组**(19,063 名):综合类(选科要求宽松)
2. **服从调剂注意**:中分组可能被调到化工 / 矿物加工 / 安全工程等偏冷门方向,**接受不了的别勾**
3. **武理工 vs 武大 vs 华科**:
   - **想学车辆 / 船舶 / 材料 / 交通** → 武理工
   - **想学 CS / 机械 / 电气 / 光电** → 华科
   - **想学法学 / 综合实力 / 文科** → 武大
4. **"武理工 CS 跟华科 CS 差不多"是湖北家长的头号误区**:**毕业薪资差 2 倍以上**,选 CS 跨校不犹豫

## 毕业去向(2024 数据,粗略)

- **留湖北就业**:约 30%(主要进东风汽车 / 中铁 / 武钢等湖北本地大企业)
- **出省(长三角珠三角)就业**:约 50%(车辆 / 船舶 / 材料行业出省较多)
- **考研 / 读博**:约 20-25%(材料 / 化学等读研率高,因为本科出路差)
- **进央企**:约 20-25%(中国汽车 / 中船 / 中铁 等)

## 给 agent 用的卡片填充字段

**武理工组内通常涉及专业**(基于历年招生章程):

- **(08)-(10) 高分组**:车辆工程 / 材料科学与工程 / 船舶与海洋工程 / 矿物加工工程
