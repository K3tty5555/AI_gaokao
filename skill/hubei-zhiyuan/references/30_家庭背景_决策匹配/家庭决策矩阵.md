# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

---

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校 / 公安专业(湖北警官学院)+ 公安联考 = 父母编制资源能用上

**典型 case**:
- 武汉某中产体制内家庭(父亲省直机关,母亲银行)→ 孩子 605 分历史类 → 推中南财法法学 → 毕业选调进湖北省委办,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去华科 CS → 毕业 35w 起薪很高,但家长不满"不稳定",劝其离职考公,**两年的时间损耗 + 心理纠结**

---

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范;医生家庭 → 临床 / 口腔(8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → 法学;工程师家庭 → 对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲华师附中语文老师 + 父亲普通工薪 → 孩子 615 分历史类 → **公费师范生汉语言**(华师) → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是临床医生 → 孩子 650 分物理类 → **同济医学院八年制临床** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**

---

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 武汉某私企老板家庭(年入 200w+) → 孩子 580 分物理类 → 推**香港城市大学 / 中外合作办学**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班
- 失败 case:私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 10-30 万为主。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - 公费师范生(华师 / 湖大)= 高考分适中 + 直接编制 + 无学费
   - 警校(湖北警官学院)+ 公安联考 = 进警察系统编制
   - 医学技术(医学影像 / 检验)= 三甲医院技术岗 + 4 年本科即可
   - 殡葬专业 = 100% 编制 + 收入意外不错
3. **次推稳定就业型**:
   - 电气工程进国电网(分够 985/211 / 三峡大学等性价比之选)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-10w,跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 湖北襄阳工厂家庭 → 孩子 580 分物理类 → 推**三峡大学电气**(2024 进国家电网 644 人,全国 TOP 2)→ 毕业进湖北电网,**月入 1.2w + 编制,家庭逆袭**
- 湖北黄冈工薪家庭 → 孩子 540 分文史类 → 推**湖北大学汉语言文学**(双非但考公王者)→ 毕业当年考上湖北省直机关,**家庭命运改变**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - 公费师范生(无学费 + 编制)= 农村家庭神器
   - 国家专项计划 / 高校专项 = 农村专属优惠
   - 警校 / 军校(无学费 + 编制 + 包分配)
   - 农林牧水(华农国家专项)= 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - 国家专项计划:湖北农村户籍,985/211 名校多个专项指标(分数比统招低 20-30 分)
   - 强基计划:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - 殡葬专业(冷门但 100% 编制 + 收入不错)

**典型 case**:
- 湖北恩施农村家庭 → 孩子 590 分物理类 → 通过**国家专项**进**武汉大学环境工程**(比统招分低 30 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985**
- 湖北黄冈农村女孩 → 605 分文史类 → 推**华师公费师范汉语言** → 4 年无学费 + 毕业回原县编制,**最适合农村家庭的"零风险"路径**

## 矩阵速查表(给 agent 用)

| 家庭档 | 关键词 | 推 | 避 |
|---|---|---|---|
| ① 体制内 | 考公友好 + 选调路径 | 汉语言/法学/经济/会计/警校 | CS/金融头部/创业类 |
| ② 专业人员 | 子承父业 + 拐杖最大化 | 师范(教师)/医学(医生)/法学(律师) | 完全无父母资源的领域 |
| ③ 私企/创业 | 可冒险 + 上限高 | 商科头部/出国/创业/艺术 | 体制内基层 |
| ④ 普通工薪 | 编制 + 稳定 | 公费师范/电气/医学技术/汉语言 | 双非金融CS/生化环材/医学长周期 |
| ⑤ 农村/临工 | 牌子 + 100% 编制 | 国家专项/公费师范/警校/华农 | 长周期投入/出国/双非折腾 |

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。
