# 湖北 3+1+2 高考政策

## 核心结论

**湖北从 2021 年起实行新高考"3+1+2"模式**(2021 年入学、2024 年首届高考)。**没有"理科 / 文科"了,改成"物理类 / 历史类"**;**录取按"院校专业组"投档**,**专业组内服从调剂**。这套规则比老高考复杂,**家长普遍弄不清楚**,导致填报时容易踩坑。

## 关键事实

### 考试结构
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(关键!!)
- **物理类**(类型代号 2073)— 选物理为首选的考生
- **历史类**(类型代号 2074)— 选历史为首选的考生
- **两类完全分开排名、分开录取**,**互不影响**
- 物理类报考人数 ≈ 70%,历史类 ≈ 30%(湖北 2024 数据)
- **物理类专业选择面广(约 96%);历史类专业选择面窄(约 50%)**

### 12 种选科组合
首选 2 选 1 × 再选 4 选 2 = 12 种组合。常见组合及对应可报专业:

| 选科组合 | 可报专业范围 | 评价 |
|---|---|---|
| 物 + 化 + 生 | **97% 专业**,理工医全能 | 万金油,首选 |
| 物 + 化 + 地 | 96% 专业,工科+地学 | 优秀 |
| 物 + 化 + 政 | 96% 专业 + 考公友好 | 平衡型 |
| 物 + 生 + 政 | 90% 专业,但医学受限(部分医学要求"再选化学") | 一般 |
| 物 + 生 + 地 | 89% 专业 | 一般 |
| 物 + 政 + 地 | 80% 专业(理工受限,文理混报) | 慎重 |
| 史 + 政 + 地 | **传统文综组合**,可报 50%+ 专业 | 文科首选 |
| 史 + 政 + 生 | 文史 + 部分医学 | 偏文 |
| 史 + 政 + 化 | 罕见组合 | 慎重 |
| 史 + 化 + 地 | 罕见组合 | 慎重 |
| 史 + 化 + 生 | 罕见组合 | 慎重 |
| 史 + 生 + 地 | 罕见组合 | 慎重 |

### 再选科目专业限制(2024 年最新)
- **再选必含化学**:绝大多数医学(临床、口腔、护理)、化学、化工、材料、生物科学等
- **再选必含生物**:部分医学(生命科学方向)、生物、农林牧、动植物相关
- **再选必含化学和生物**(双选):临床医学、口腔医学的部分院校
- **再选必含政治**:马克思主义理论、政治学、国际关系、思想政治教育、部分公安院校
- **再选必含地理**:地理科学、地质学(部分院校)
- **绝大多数文史经管法学**:再选不限

### 院校专业组(投档单位)
- **不再按"学校"投档,按"院校专业组"投档**
- 一所学校可以有多个专业组(比如武汉大学物理类,可能有 5-10 个专业组)
- **同一学校的不同专业组独立投档,可以独立填报**
- **服从调剂只在本专业组内调剂**(不会被调到其他组)
- 一个专业组内通常 5-15 个专业

### 填报志愿数量
- **45 个志愿**(每个志愿 = 1 个院校专业组)
- 每个志愿组内可选 1-6 个具体专业 + 是否服从调剂
- 比老高考的 9 个志愿大幅放宽,**填报策略空间变大**

### 投档与录取流程
1. 按位次投档:位次靠前的考生先选自己的 45 个志愿
2. 系统按 1-45 顺序检索投档:**第一个能投到的志愿组,投档**
3. 投档后,本志愿组内按专业最低分录取(如果没录取上具体专业,**服从调剂会被调到本组其他未录满专业**)
4. 不服从调剂 + 没录取上 → **退档,本批次落榜**(滑档)

### 一分一段表(湖北位次)
- 高考结束后湖北招办发布"一分一段表",**用于换算分数 ↔ 全省位次**
- **位次比分数更准**:不同年份卷子难度不同,但同样位次的考生水平相对稳定
- **报志愿应该看位次,不是看分数**(这是新手家长最常踩的坑)

## 决策映射

| 考生情况 | 应该怎么选 |
|---|---|
| 物化生 / 物化地 | 几乎不限,可报理工医农林全部专业,**最佳选择** |
| 物化政 | 理工 + 考公友好,**平衡型** |
| 史政地 | 文史考公主流路径,**文科生首选** |
| 想读临床医学 | **必选化学(部分院校还要生物)**,湖北家长一定要确认 |
| 想读师范 | 选你想教的学科对应的科目(教数学就选物理,教语文就史政地) |
| 想报警察 / 公安 | **必选政治**(几乎所有公安院校要求) |
| 想读师范类政治学科 | **必选政治** |
| 想读国际关系 / 外交 | **必选政治** |
| 想读地质 / 地理 | 必选地理 |

## 典型 case(供 agent 引用)

- **Case A(选科正确)**:湖北宜昌考生,初中数理化好,选物化生。**高三时进武大医学**, 选科组合允许她报临床医学
- **Case B(选科踩坑)**:湖北考生选物 + 政 + 地。高三时想报临床医学发现**无法报考**(必须再选化学)。**只能改报其他专业,留下遗憾**
- **Case C(选科聪明)**:湖北考生选物 + 化 + 政。高三同时保留了**理工(化学)+ 考公(政治)+ 警察(政治)** 三条出路,**选科最灵活**
- **Case D(填报踩坑)**:湖北考生 600 分物理类。把武大某专业组放第 1 志愿,但**没看清楚组内最低分专业是"图书情报"**。被投档后,**被调剂到图书情报**,大学 4 年抑郁

## 易错认知(agent 要纠正用户的)

- "**还是按文科 / 理科算的吧**" — 严重过时。湖北 2021 年起就没文理分科了,**只有物理类和历史类**
- "**3+1+2 跟老高考差不多,只是叫法不同**" — 错。**录取规则不同,投档单位不同,服从调剂规则不同**
- "**45 个志愿都是学校,选哪个学校都行**" — 严重错误。**45 个志愿是 45 个"院校专业组",同一学校可能占多个志愿位**。同一学校的不同专业组录取分可能差几十分
- "**服从调剂会被调到本校其他专业**" — 错。**只在本专业组内调剂**,不会跨组
- "**首选物理一定比首选历史好,因为可报专业多**" — 错。**适合自己的才是好的**。物理类竞争更激烈,历史类专业窄但学得轻松
- "**专业最低分就是录取最低分**" — 半对。**整个组的最低分(投档线)≤ 组内最低分专业的录取分**
- "**新高考赋分对孩子有利 / 不利**" — 都对。**赋分对相对成绩好的有利,对相对成绩差的不利**(因为是按全省排名转换)
- "**孩子分数 580,看哪些 580 能上的学校就行了**" — 错。**应该看 580 对应的全省位次,然后看历年这个位次能上哪些学校**

## 关键提醒(agent 必须强调)

**新高考最容易被忽视的事实**:
1. **45 个志愿组的填报顺序**很重要,要"冲稳保"梯度排列
2. **服从调剂**通常推荐勾选(不勾就有滑档风险),**但要确认本专业组内你能接受的最差专业**
3. **看位次而不是分数**(分数受当年卷子难度影响很大)
4. **再选科目限制**(必选化学/必选政治等)是硬约束,**填报前一定核对每个目标专业**

**新高考的"院校专业组"机制让填报变得更精细,也更容易踩坑**。**家长没经历过新高考,普遍跟不上规则**。这正是 agent 价值的核心 —— 把这些规则用通俗话讲明白。
