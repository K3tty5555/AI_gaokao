# 出分前咨询(L1-A)— 模考期方向性建议

## 适用场景

**用户在高考出分前来咨询**(高三全程 / 模考期 / 家长提前规划)。
- 没有高考分数,没有官方一分一段位次
- 只有模考分数 + 学校年级排名
- 需求:**方向性建议**(我大致什么档位 / 适合哪些方向),**不是 45 志愿表**

## 双口径估算(核心方法)

由于无法精确知道全省位次,用**两条独立信号**做粗估,**冲突时取保守值**:

### 口径 1:学校层次 × 年级排名 → 全省位次区间

**学校层次分 3 档**(粗分,实际可参考百度/掌上高考的"湖北省示范性高中"名单):

| 档 | 代表 | 年级前 50 名对应全省位次 | 年级前 200 名 | 中游(年级前 50%) |
|---|---|---|---|---|
| ① **省级示范 / 国家级**(约 50-100 所) | 华师一附中 / 武汉外校 / 黄冈中学 / 襄阳四中 / 襄阳五中 / 武钢三中 / 沙市中学 / 鄂南高中 / 钟祥一中 / 仙桃中学 等 | 全省 ~500-1000(冲清北复交) | ~5000(末流 985 / 头部 211) | ~15000-25000(末流 211 / 头部双非) |
| ② **市级重点 / 一般省级示范** | 各地市排第 2-5 的高中(老二中 / 老三中 / 老一中) | ~3000-8000(中段 985 - 末流 985) | ~15000-25000(双非一本) | ~40000-60000(普通本科) |
| ③ **普通高中**(县级 / 镇级) | 县城高中 / 乡镇中学 | ~10000-25000(末流 211 / 双非一本) | ~50000+(普通本科 - 二本) | ~100000+(二本 - 专科) |

**使用方法**:
- 用户报"湖北 X 中第 Y 名,年级 Z 人" → 算 Y/Z 比例 → 对照上表插值
- 例:省级示范第 100 名 / 年级 800 人 = 12.5% 位置 ≈ 全省 8000-15000(双非一本到末流 211)

### 口径 2:模考分数 → 大致分段

**模考分有参考价值但不能等同于高考分**。原因:
- 模考是学校自己出 / 区联考,卷子难度跟高考可能不一致(一般模考更难一点)
- 模考排名是相对学校 / 区,不是全省

**简单粗估**(湖北模考 → 高考分大致换算,假设模考难度 = 高考难度):

| 模考总分(物理类) | 大致对应全省位次 |
|---|---|
| ≥ 640 | 前 1500(冲清北华 5 / 头部 985) |
| 600-640 | 1500-8000(中段 985) |
| 570-600 | 8000-20000(末流 985 - 中段 211) |
| 540-570 | 20000-40000(末流 211 - 头部双非一本) |
| 500-540 | 40000-70000(双非一本 - 末流一本) |
| 460-500 | 70000-120000(本科批) |
| ≤ 460 | 专科 / 复读警戒线 |

(历史类 + 30-50 分对应同档位次,因历史类分数线整体高 30-50)

### 双口径校准

| 口径 1(学校×排名)结论 | 口径 2(模考分)结论 | 综合判断 |
|---|---|---|
| 985 中段 | 985 中段 | **稳定 985 中段**(高一致,精度高) |
| 985 中段 | 末流 211 | **取保守:中段 211 - 头部双非**(模考可能没发挥) |
| 末流 985 | 末流 985 | **稳定末流 985 - 头部 211** |
| 头部 211 | 普通本科 | **取保守:双非一本**(可能学校排名虚高,要看高考实际) |

**核心规则**:**两口径相差大时取靠后位次**(保守估计)。这避免给用户错误的"高估期望"。

## 输出格式(L1-A 推荐)

**不是 45 志愿表,也不是"全省 X-Y 名"具体范围,而是用户能看懂的"档位语言"**:

### 档位定义(按湖北 3+1+2 物理类近 3 年录取实际分布)

| 档位 | 大致水平 | 用户能直接理解 |
|---|---|---|
| **冲清北华 5 / 头部 985** | 全省前 ~1500 | "顶级 985 档" |
| **中段 985** | 1500-8000 | "985 中段(武大华科哈工等)" |
| **末流 985 / 头部 211** | 8000-20000 | "末流 985 / 强 211(湖大兰大苏大等)" |
| **中段 211** | 20000-40000 | "中段 211 / 末流 211" |
| **头部双非一本** | 40000-70000 | "好的双非一本(湖工大 / 长江 / 武科大 等)" |
| **普通双非一本** | 70000-100000 | "普通双非一本 / 末流一本" |
| **本科批** | 100000-180000 | "二本 / 末流本科" |
| **专科批** | > 180000 | "专科 / 复读警戒线" |

### 输出模板(用档位语言,不出具体位次范围)

```
## 你大致定位

**档位:[XX 档]**(参考语:你大概在"末流 985 / 强 211"这个段)

判断依据:
- 学校层次 ① / 排名 X% → 估算指向 [档1]
- 模考 580 → 估算指向 [档2]
- (取保守:[档1] 和 [档2] 中靠后的那个)

**这个档位的可能院校(举几个例子,出分前不出具体推荐)**:
- 武汉大学(末流专业组)/ 苏州大学 / 西安电子科大 等

## 适合的专业大方向

[根据 L4 兴趣 + 家庭 + 学科底子,给 2-3 个方向]
- 方向 1:XX 类(因为 XX)
- 方向 2:XX 类(因为 XX)

## 高三冲刺空间

**当前档:**[末流 985 / 强 211]
**冲一档可达:**[中段 985](需要再提 ~20 分,主要从弱科补)
**保一档兜底:**[中段 211](即使后面发挥不佳大概率能稳)

[基于学科画像]
- 强科(>85%):保分,不用大投入
- 中科(65-84%):花大头时间提分,这是主战场
- 弱科(<65%):基础补,重点不是冲高分而是不要拖后腿

## 出分后再来

出分后(知道高考分 + 一分一段官方位次)请回来走 L1-B 完整流程,拿具体 45 志愿表。
出分前的档位估算精度 ±1 档(可能跨档,不要过度依赖)。
```

## L1-A 提问模板

agent 进入出分前场景后这样问(分 2 轮收集):

**第 1 轮(基础定位)**:
> "出分前的方向性咨询,我需要先了解你的水平段。请告诉我:
> 1. 你的学校层次:① 省级示范 / 国家级(华师一 / 武汉外校 / 黄冈中学 / 襄阳四中五中 / 武钢三中 等)/ ② 市级重点(各地市排前几的)/ ③ 普通高中(县乡级)
> 2. 学校具体名字(让我做更精准估算)
> 3. 当前年级排名 + 年级总人数(如:600 人中第 80 名)
> 4. 选科:物化生 / 物化政 / 史政地 等 12 选 1
> 5. 物理类还是历史类"

**第 2 轮(模考分校准)**:
> "再给我 1-2 次最近的模考分数(语数英 + 选科 3 科分数 + 总分),用来跟年级排名做交叉校准"

之后给中间反馈,然后进 L2-L5(家庭 / 未来锚点 / 兴趣 / 风险偏好),输出"方向性建议"而非具体志愿表。

---

## 重要纪律

1. **出分前不出具体志愿表**。任何"具体院校 + 专业组"的推荐都要等出分后(因为模考排名波动大,模考前 100 实际高考可能掉到 200,反之亦然)
2. **冲刺建议要保守**。不能让用户因为方向性建议放松冲刺(如"你现在能上 211" → 用户松懈 → 实际滑到双非)
3. **必须重申"出分后再来"**:出分前给的是方向 + 备选清单,**精确填报必须基于真实位次**
4. **对学校排名的偏差有觉悟**:省级示范的"年级第 100"和普通高中的"年级第 5"可能是同一个全省位次。不要用绝对名次,用百分位
5. **数据不存在的部分要承认**:本系统**没有湖北各高中历年高考表现的精确数据**,估算是粗的,**告诉用户"这是粗估,精度有限"**
