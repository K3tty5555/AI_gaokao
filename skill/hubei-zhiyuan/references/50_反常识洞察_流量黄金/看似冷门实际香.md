# 看似冷门实际香的专业

## 核心结论

家长普遍**追热门而避冷门**,但很多"冷门"专业的就业稳定性、考公友好度、性价比远超表面热门专业。**对普通家庭尤其友好** —— 因为不卷、门槛适中、出路明确。

## 关键事实

### 1. 汉语言文学 — 考公王者(湖北家长最该重视)
- 国考、省考能报考的岗位数,**汉语言文学常年第一**(明显多过法学、计算机、会计)
- 三不限岗位(对专业不限制)所有人都能报,但加上"汉语言文学"限制的岗位还是非常多
- 适合所有想考公考编的湖北学生,**特别是普通家庭女生**

### 2. 电气工程及其自动化 — 国家电网神券
- 进国家电网 = 央企铁饭碗 + 普通家庭逆袭
- 详见 `10_行业就业潜规则/电气_电网.md`

### 3. 测绘工程 / 遥感科学与技术
- 武大第一,毕业进国测局、中铁、中交、各省测绘院,**铁饭碗居多**
- 注意:基层岗有野外作业,体力要求,女生慎重
- 武大测绘是**全国第 1**,湖北本地学生应试性价比极高

### 4. 海洋工程 / 船舶与海洋工程
- 中船集团、中海油、中远海运为主要去向,**央企就业稳定**
- 武汉理工的船舶专业全国前列
- 适合男生 + 想稳定 + 不介意去港口/海上工作

### 5. 殡葬学 / 殡葬服务与管理
- 全国只有 4 所院校开设(长沙民政、福建华南女子、武汉民政、北京社管)
- **就业率 100%,入职即编制**(殡仪馆事业单位),**收入比想象高很多**(月入 1-2w)
- 行业刚需 + 人力极少 + 社会偏见正在减少
- 适合不在意社会偏见 + 想要绝对稳定的家庭

### 6. 假肢矫形工程
- 全国只有 2 所院校(首都医科大学、上海理工大学)
- 医疗器械方向稀缺人才,毕业进医疗器械公司或假肢矫形中心
- 收入起薪 7-10w,**需求稳定增长**(老龄化 + 残疾人服务)

### 7. 兵器类专业(弹药工程、装甲车辆等)
- 限定院校:北理工、南理工、中北大学、西工大等"兵器八校"
- 毕业进兵工集团、航天科工、中船等军工央企,**绝大多数有保密等级要求**
- 专业限制大但**进入门槛后稳定性极高**,基本一辈子在体制内

### 8. 医学影像技术 / 医学检验技术
- 三甲医院技术岗,**不需要医师资格证就能上岗**(影像技师/检验师)
- 不用像临床医学那样"5+3+规培"长周期,**4 年本科就能进医院**
- 适合喜欢医学但不想读 8 年的学生

### 9. 农林类(植物保护、动物医学、水产养殖)
- 在农业大学读这些**真的有出路**(农技推广、宠物医院、水产养殖企业)
- 别去综合性大学读这些,要去农林专业院校(华农、南农、西农等)
- 动物医学(兽医)在城市宠物经济推动下,薪资稳定上升

### 10. 数学 / 统计学 — 万金油基础
- 本科出路相对窄,但**是研究生阶段转 CS / 金融 / 量化的最佳跳板**
- 数学好的考生,本科读数学比直接读金融更有未来 —— 顶级量化基金只要数学/物理出身
- 适合数学单科 130+ 的学生

## 决策映射

| 学生情况 | 推荐 |
|---|---|
| 普通家庭 + 想考公 + 不挑专业 | 汉语言文学(首选) |
| 普通家庭 + 男生 + 不怕吃苦 + 求稳定 | 电气、测绘、船舶、海洋工程 |
| 不在意偏见 + 求绝对稳定 | 殡葬专业 |
| 喜欢医学但不想读 8 年 | 医学影像 / 检验 |
| 数学单科很强 + 中产家庭 | 数学 / 统计学(本科为研究生跳板) |
| 农村或半农村家庭 + 喜欢动物 / 植物 | 兽医 / 园艺(华农优先) |

## 典型 case(供 agent 引用)

- **Case A**:湖北黄冈考生,580 分物理类,普通工薪家庭。家长本想报"金融"(双非),建议改报湖北某二本汉语言文学,毕业考湖北省考一次成功,**家庭逆袭**
- **Case B**:湖北武汉考生,560 分物理类,普通家庭男生。本想报"工商管理"(三本),建议改报三峡大学电气,毕业进湖北电网,**月入1.2w + 编制**
- **Case C**:湖北恩施考生,540 分物理类,农村家庭。本想报"市场营销"(二本),建议改报海洋工程(湖北二本招生少,实际录取华中农大水产),进中海油,**改变家庭命运**

## 易错认知(agent 要纠正用户的)

- "**冷门 = 没前途**" — 错。冷门 = 报的人少 = 不卷 + 行业稳定的概率高
- "**学这种又不能挣大钱**" — 错。普通家庭追求"挣大钱"概率失败,追求"稳定"概率成功
- "**汉语言文学就是当老师**" — 错。汉语言考公比当老师香 100 倍,湖北每年省考可报岗位数惊人
- "**测绘 / 海洋工程都是又苦又累**" — 半对。基层岗确实苦,但晋升后管理岗 + 央企福利远好于互联网卷王
- "**殡葬太丧 / 太晦气**" — 老一代认知。年轻一代消除偏见 + 稳定收入两不误
- "**数学统计本科找不到工作**" — 半对。本科确实就业一般,但是**最好的研究生跳板专业之一**
