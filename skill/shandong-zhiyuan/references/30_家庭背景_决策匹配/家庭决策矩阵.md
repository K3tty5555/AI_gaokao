# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(山东视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

**山东的家庭画像有几个区别于湖北 / 江苏 / 广东 的特点**:
1. **儒家文化体制内偏好极强** — 山东家长对"考公 / 考编 / 进国企"的偏好是全国最浓的几个省之一(跟河南 / 河北 / 东北 一档),**80% 以上的山东家长本质期待孩子端铁饭碗**
2. **"留鲁"心态极重** — 山东人不愿出省(尤其女生),哪怕考清北也常想回济南 / 青岛
3. **独生子女男生压力大** — "儿子要靠谱 / 稳定 / 不能瞎折腾",对男生选 CS / 创业 / 出国 接受度低于沿海省份
4. **工薪家庭比例高** — 山东产业以"制造 + 能源 + 农业"为主,工薪家庭占多数,中产 / 私企家庭比例低于江苏 / 广东 / 浙江

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**山东特殊性**:山东体制内家庭比例**全国 Top 3**(仅次于河南 / 河北),济南 / 青岛 / 烟台 / 潍坊 等地市的"公务员 + 事业编 + 国企"基础家庭极多。

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **山东特色**:体制内家庭对"留鲁"几乎是硬要求,对孩子出省去北上广深极度抵触

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(山东体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化)。**山大 / 中海大 / 中石大 / 哈工威 选调对接山东省委组织部最直接**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校(山东警察学院)+ 公安联考 = 父母编制资源能用上;山东省内军校 / 国防生路径
5. **山东特色推荐**:**曲阜师范大学考研路径**(双非但考公考研上岸率惊人,体制内家庭懂这个梗)

**典型 case**:
- 济南某中产体制内家庭(父亲省直机关,母亲银行)→ 孩子 615 分历史类 → 推**山大法学** → 毕业选调进山东省委办,**家庭路径完美匹配**
- 青岛体制内家庭(父亲青岛海关,母亲青岛城投)→ 孩子 605 分文史类 → 推**山大文学院汉语言** → 选调留青岛,父母给岗位推荐
- 失败 case:同样体制内家庭,孩子被推去山大青岛校区 CS → 毕业 30w 起薪很高但要去北京字节,家长不满"不稳定 + 不留鲁",劝其离职考公,**两年时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**山东特殊性**:
- **山东医生 / 教师 家庭比例 高于全国平均**(医疗教育资源密集,济南 / 青岛 三甲医院多 + 山师 / 曲师 教师血脉广)
- 山东医生家庭对"孩子学医"几乎是默认期待 + 父母人脉直接落地齐鲁医院 / 山东省立 / 青大附属

**推荐策略**:
1. **优先子承父业**:教师家庭 → 山师汉语言 / 山师公费师范;医生家庭 → 山大齐鲁医临床 / 八年制(父母能撑 + 齐鲁医院推荐)
2. **行业相关延伸**:律师家庭 → 山大法学 / 中政法;工程师家庭 → 对应工科(山大 / 哈工威 / 中石大)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(山东金融行业弱,没金融行业资源会很难)

**典型 case**:
- 母亲山师附中语文老师 + 父亲普通工薪 → 孩子 620 分历史类 → **山师汉语言公费师范** → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是齐鲁医院临床医生 → 孩子 660 分物理类 → **山大齐鲁医学院八年制临床** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 父亲青岛大学附属医院主治医师 → 孩子 640 分物理类 → **青大医学部临床** → 留青岛进青大附属

## 档位 ③ 私企管理 / 创业家庭

**山东特殊性**:山东私企家庭比例**全国中等偏下**(山东产业以制造 + 国企为主,纯民营经济不如浙江 / 广东 / 福建 / 江苏)。但**胶东半岛(青岛 / 烟台 / 威海)有一批做外贸 / 制造 / 海产品 的中小企业主家庭**,这一档相对集中。

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **山东特色**:山东私企老板很多 50 岁以上 + 信息差大,**对"孩子出国 / 学创业 / 不进体制" 接受度比浙江 / 广东低**,需要 agent 做更多"为啥孩子可以不考公" 的破局工作

**推荐策略**:
1. **可选商科 / 创业方向**:山大经济学院 / 山大管理学院 / 东财(辽宁) / 中央财经 等头部院校
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:山大威海中外合作 / 香港城市大学 / 港中文(深圳)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **山东特色**:**胶东外贸家庭 → 推 商务英语 / 国际经济与贸易 / 物流管理(青岛海运)**,父母资源直接复用

**典型 case**:
- 青岛某外贸老板家庭(年入 200w+) → 孩子 580 分物理类 → 推**山大威海中外合作 / 香港城市大学** (学费 8-15w/年家里能撑) → 出国背景做家族外贸接班
- 烟台某海产品加工厂老板 → 孩子 600 分物理类 → 推**中海大水产养殖**(985 + 海洋特色 + 父母行业延伸)
- 失败 case:山东私企家庭 → 孩子被推考公(因为父母自己当年没考上心有遗憾)→ 进基层公务员后被父母嫌"没出息"(因为父母实际财富水平已超公务员)→ **家庭基因不对路 + 心理纠结**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**山东特殊性**:**山东工薪家庭比例 全国 Top 3**(与河南 / 河北 同档),工业制造 + 服务业为主,**家长对"稳定 + 编制"的执念全国最强之一**。

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **山东特色**:**对"留鲁"几乎是硬要求**(尤其女生家长)+ **对"考公考编"几乎是宗教式信仰**

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **山东师范大学公费师范生汉语言文学 / 数学**(山东工薪家庭神级选项,0 学费 + 4 年后回原县编制)
   - **曲阜师范大学汉语言** = 双非但考公考研上岸率惊人,**山东工薪家庭"上岸率隐藏王者"**
   - **滨州 / 潍坊 / 济宁医学院 医学影像技术 / 检验技术 / 护理**(4 年本科 + 三甲技师编制,**山东工薪女生神级路径**)
   - **山东警察学院 + 公安联考**(进山东本地公安编制)
3. **次推稳定就业型**:
   - **电气工程进国家电网山东省公司 / 山东能源 / 兖矿能源**(分够 山大 / 哈工威 / 中石大 / 山科 / 山东理工)
   - **师范类(汉语言 / 数学师范)**
   - **护理(本科,专科也行)**
   - **山东海洋类**:中海大水产 / 海洋技术 / 海洋资源开发 — 进国家海洋局 / 中远海运 / 中海油 编制
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局,山东金融业本身就弱)
   - 双非 CS(2024 起薪 8-10w,跟双非工科没差,且山东 CS 留鲁出口窄)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 临床医学(5+3+规培 8 年长周期,工薪家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)
   - 新闻学 / 广告学 / 传播学(行业凋零)

**典型 case**:
- 山东临沂工厂家庭 → 孩子 580 分物理类,省排 4w → 推**山科电气**(青岛)→ 毕业进山东电网临沂分公司,**月入 9k + 编制,家庭逆袭**
- 山东菏泽工薪家庭 → 孩子 540 分文史类,省排 6w → 推**曲阜师范大学汉语言文学** → 4 年内卷 + 应届考公成功 → **进菏泽某区公务员编制,家庭命运改变**
- 山东潍坊工薪女生 → 孩子 555 分物理类,省排 5w → 推**滨州医学院医学影像技术** → 毕业进潍坊三甲影像科技师岗,**起薪 7k + 编制 + 22 岁参加工作**(比临床 8 年早 4 年)
- 山东淄博工厂家庭 → 孩子 605 分历史类,省排 8000 → 推**山东师范大学汉语言文学公费师范** → 0 学费 + 毕业回淄博某中学语文老师编制,**山东工薪女生终极理想路径**

## 档位 ⑤ 农村 / 临工家庭

**山东特殊性**:山东农村家庭主要分布在**鲁西南(菏泽 / 临沂 / 聊城)+ 鲁北(德州 / 滨州)+ 沂蒙山区**,跟胶东富裕地区差距大。

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **山东特色**:**孔孟之乡农村家庭重男轻女文化犹存**,儿子读书全家撑,女儿往往被"早工作早嫁人"

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **山师 / 曲师 公费师范生**(无学费 + 编制)= 山东农村家庭神器
   - **国家专项计划 / 高校专项**:山东农村户籍,山大 / 中海大 等多个专项指标(分数比统招低 20-30 分)
   - **警校 / 军校**(无学费 + 编制 + 包分配):山东警察学院 / 解放军信息工程大学(军校免费)
   - **农林牧水**:山东农业大学(国家专项)= 编制 + 山东农业行业有出路
3. **避免长周期投入**:
   - 临床医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:山东农村户籍考生在 山大 / 中海大 / 哈工威 / 中石大 等高校有专项指标(分数比统招低 20-30 分)
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会冲山大强基
   - **山东海洋经济专属**:鲁东 / 烟台地区农村考生 → 中海大水产 / 烟台大学海洋类 → 进中远海运 / 山东港口 编制

**典型 case**:
- 山东菏泽农村家庭 → 孩子 590 分物理类,省排 1.6w → 通过**国家专项**进**山大青岛校区计算机**(比统招分低 25 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985**
- 山东临沂农村女孩 → 605 分文史类 → 推**山师汉语言公费师范** → 4 年无学费 + 毕业回原县(临沂某区)编制,**最适合山东农村女生的"零风险"路径**
- 山东聊城农村男生 → 580 分物理类 → 推**曲阜师范大学汉语言文学** → 双非但考公成功率惊人,**毕业上岸聊城某区公务员**
- 山东德州农村家庭 → 孩子 560 分物理类 → 推**山东农业大学(泰安)动物医学**(国家专项)→ 编制 + 山东养殖业行业人脉

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 山东特殊提醒(给 agent 的 4 条铁律)

1. **山东工薪家庭推 CS = 大概率挖坑**:除非分够山大 / 哈工威 + 接受出省,否则 CS 不是给山东工薪家庭的菜
