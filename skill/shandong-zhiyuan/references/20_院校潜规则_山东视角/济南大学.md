# 济南大学(济大,UJN)— 双非综合 + 山东轻工业 / 建材产业对口 + 留济南本土

## 一句话定位

**双非综合性大学 + 山东省政府重点支持**(原济南联合大学 + 山东建材学院 + 济南化工学校 等合并),**材料科学全国前 50**(原山东建材学院底子),**山东陶瓷 / 玻璃 / 水泥 / 轻工业 对口**。**留济南就业方便 + 二段线上能上 + 工科双非性价比** = 山东工薪家庭男生想留济南 + 学工科的合理选择。**省会综合双非 + 学科齐全(工 / 文 / 理 / 经 / 法 / 教育 / 医)**,**没有 211 资源但本土认可度高**。

---

## 真实地位

- **双非综合性大学 + 山东省 + 教育部 + 国家建材局 共建**,济南本土综合双非主力,跟青岛大学 / 山师大 / 烟大 同档(都是山东省属双非 + 综合性)。
- **材料科学是核心王牌**(全国前 50,**山东建材学院血脉**),**化工 / 土木 / 机械 / 计算机** 工科底子扎实,文管 / 经法 / 师范 全学科覆盖。
- **山东本省地位**:**济南本土综合双非头部**,跟山师大(师范主力)/ 山财大(财经主力)三足鼎立济南双非市场,**留济南就业本土认可度高**(山东轻工业 / 建材 / 化工产业链对口)。
- **主校区(舜耕)+ 西校区(老校区)+ 长清校区(新校区,部分专业)**,济南地理 + 省会便利 + 山东半岛工业带辐射。

## 山东录取位次区间(综合改革 3+3,750 总分)

参考近 5 年掌上高考 + 山东一分一段表反查:

### 普通类一段(综合,750 总分)

- **顶尖组(临床医学 / 计算机 / 材料英才 / 师范类)**:**全省 60,000-90,000 名**
- **王牌主流组(材料 / 化工 / 土木 / 自动化 / 机械)**:**全省 90,000-130,000 名**
- **主流综合组(数学 / 物理 / 文学 / 经管 / 法学)**:**全省 110,000-160,000 名**
- **冷门组(部分管理 / 文管 / 农林边缘)**:**全省 130,000-180,000 名**

**段位定位**:**冲济大基本要省排 180,000 名内**,130,000 名内可挑王牌工科,90,000 名内可冲临床医学 / CS。**普通类一段线上即可,顶尖组接近 211 边缘**。**以一分一段表反查为准**。

## 性价比专业(同样济大牌子)

- **材料科学与工程**:**全国前 50 + 山东建材产业链对口**(山东陶瓷 / 玻璃 / 水泥 集中),**双非里材料学科顶级**,本科直接进山东建材企业起薪 6-10w + 五险一金。
- **化学工程**:**齐鲁石化 / 万华化学 留鲁化工产业链对口**,**男生 + 想进山东国企 + 不冲央企** 的好选择。
- **机械工程**:**重汽 / 潍柴动力 / 山东装备制造对口**,留鲁工科男生稳赚路径。
- **计算机 / 自动化**:**浪潮 / 海尔海信 / 中创软件** 校招对济大 IT / CS 友好(济南本土对口)。

## 坑专业 / 慎选(在济大里相对弱)

- **农林 / 医学(高级临床)**:**济大没纯农林 / 临床医学相对弱**,**学医直接选山大齐鲁 / 青大医,学农林选山农大**。
- **新闻传播 / 广播电视 / 编辑出版**:典型双非水专业,**毕业改行率高**。
- **工商管理 / 市场营销 / 行政管理**:双非综合的水管理类,慎入。
- **国际经济与贸易**:行业凋零 + 双非校的财经边缘。
- **教育技术 / 学前(济大非师范主力)**:**学师范走山师大,济大师范不如山师**。

## 关键提醒(填报陷阱)

1. **济大 vs 山师大 vs 山财大(济南双非三巨头)**:
   - **济大 = 综合双非 + 工科 / 材料强 + 山东轻工建材对口**(适合男生工科)
   - **山师大 = 师范主力 + 生物化学双一流 + 公费师范**(适合女生当老师)
   - **山财大 = 财经主力 + 会计金融 + 山东金融对口**(适合考公 + 留济南金融)
2. **物理类专业组分化**:济大组内可能含化工 / 材料 / 环境 / 食品多个方向,**服从调剂前务必查 2026 招生章程**(可能调到食品 / 环境冷门)。
3. **多校区分布**:**主校区(舜耕)+ 西校区 + 长清新校区**,**填报时关注校区分配**(长清相对偏远但环境好)。
4. **二段线考生策略**:**济大顶尖组(临床 / CS)实际在一段线上**,**二段线考生只能选冷门组**,**冲一段线上稳工科王牌组才是济大正确打开方式**。
5. **山东建材产业链的现实**:**山东是全国陶瓷 / 玻璃 / 水泥 大省**(临沂陶瓷 / 淄博玻璃 / 山水水泥 集中),**济大材料 + 山东建材产业链对口 = 双非里产业对口最直接**,本科就业不愁。

## 毕业出口(2024 数据)

- **留山东就业**:**约 70-75%**(**济南主导 50%+**:浪潮 / 中创软件 / 鲁能 / 山东建工 / 山东建研院 / 重汽 / 各大医院;青岛 10%:海尔海信 / 万华化学;烟台 / 潍坊 / 淄博 10-15%:山东半岛工业带)
- **出省到京津**:约 8-10%(部分央企 + 北京就业)
- **出省到长三角(沪苏)**:约 10-12%(长三角制造 + 电子产业链)
- **保研 / 考研**:**约 25-30%**(保研率 ~3-5%,双非中位)
- **出国**:约 2-4%
- **进央企 / 国企概率**:工科 / 经管类约 15-20%(山东国企对口为主)
- **起薪范围**:济南双非工科起薪 6-10w(浪潮 / 中创 / 重汽);材料 / 化工央企国企 8-12w + 编制(齐鲁石化 / 万华);文管类 5-8w + 考公编制路径。

**山东考生主流路径**:**济大材料 → 山东陶瓷 / 玻璃 / 万华化学**(山东轻工建材对口);**济大化工 → 齐鲁石化 / 鲁南化工**(留鲁国企);**济大 CS / 自动化 → 浪潮 / 中创软件 / 鲁能**(济南 IT 对口);**济大文管 → 山东选调 / 济南考公**(双非考公路径)。

## 适合谁

- 山东综合改革 **全省排 90,000-180,000 名 + 想留济南 + 工科方向 + 不冲 985/211** 的考生
- **男生 + 想学材料 / 化工 / 土木 / 机械 + 山东轻工建材对口** 的工薪家庭考生
- **家庭普通工薪 / 农村家庭** + 想留济南就业 / 考公 + 离父母近
- **化学 / 物理强 + 不冲顶级 → 济大材料 / 化工 是双非材料学科顶级**
- **想做济南公务员 / 山东体制内** + 文管 / 法学方向(济大文管 + 济南考公友好)
- **二段线上 / 一段线下徘徊** 的考生(济大覆盖一段中下到二段中上)

## 不适合谁

- **学医想做医生**:**济大临床医学双非中位 + 出口窄**,学医直接选山大齐鲁 / 青大医
- **学师范当老师**:**学师范直接选山师大**(济大师范不如山师)
- **学财经金融**:**学财经直接选山财大**(济大财经边缘)
- **想出省 + 不留济南**:济大留鲁率 70%+,**想出省走 211 + 行业对口更合适**
- **分够 211(山大 / 中海大 / 中石大 / 哈工威)→ 别 stuck 济大**(双非天花板比 211 低)
- **女生 + 不喜欢工科 + 想做都市白领**:济大工科氛围重,可选青大综合 / 山财大财经
