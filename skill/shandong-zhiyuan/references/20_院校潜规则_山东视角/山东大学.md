# 山东大学(山大,SDU)— 综合 985 + 山东全省独苗 + 三校区分散

## 一句话定位

**山东全省唯一 985 + 211 + 双一流 A 类全占的高校**,**齐鲁医学血脉**(临床医学全国前 10),**数学 / 中文 / 历史 全国前 10**。**3 校区分散(济南本部 / 青岛 / 威海),文凭注明校区,资源稀释明显**。**山东本省考生进山大 = 把就业 + 户口 + 父母满意度 一起锁定**,留鲁就业生态(齐鲁医院 / 浪潮 / 海尔海信)直接对口,**齐鲁实在厚重,不浮夸,但底子很硬**。

---

## 真实地位

- **985 + 211 + 双一流 A 类全占**,**山东全省唯一**,2024 软科全国 #18-20。
- **齐鲁医学血脉**:原山东医科大学并入,临床医学全国前 10(跟北医 / 协和 / 复旦 / 上交 同档行业认可度),齐鲁医院 / 山东省立医院 体系直接对口。
- **基础学科底子顶级**:数学 / 中文 / 历史(齐鲁文化 + 古文献研究)全国前 10,材料科学全国前 10。
- **山东本省心理上限**:山东物理类省排前 3,000 内 / 历史类省排前 500 内的天花板,本省考生进山大是最高价值标的。
- **3 校区分散(关键!!)**:济南本部 / 青岛校区 / 威海校区,**分别招生 + 文凭注明校区**(青岛 / 威海文凭与本部不同),**这是山大跟其他 985 最大区别 — 校区分散导致资源稀释**,但 985 牌子统一。

## 山东录取位次区间(综合改革 3+3,750 总分)

参考近 5 年掌上高考 + 山东一分一段表反查(**只给位次,不编分**):

### 普通类一段(综合,750 总分)

- **顶尖组(临床医学八年制 / 齐鲁医学班 / 强基 / 数学英才)**:**全省 500-2,000 名**(逼近清北边缘)
- **本部王牌主流组(数学 / 中文 / 历史 / 计算机 / 经管法)**:**全省 2,000-4,500 名**
- **本部主流工科组(机械 / 材料 / 电气 / 化工 / 土木)**:**全省 4,500-8,000 名**
- **青岛校区(新工科 / 海洋相关 / 信息科技)**:**全省 6,000-12,000 名**(比本部低 2,000-4,000 名)
- **威海校区(综合)**:**全省 8,000-15,000 名**(985 牌子但资源最稀,分数最低)

**段位定位**:**冲山大本部基本要省排 8,000 名内**,4,500 名内可挑王牌专业,2,000 名内可冲齐鲁医学;**青岛 / 威海 校区门槛低 2,000-7,000 名**。**以一分一段表反查为准**。

## 性价比专业(同样山大牌子,录取相对低)

- **历史学 / 考古学 / 古文献**:**齐鲁文化底蕴 + 全国前 10**,录取分比 CS / 经管低,**适合考公选调 + 走学术** 的考生(山大文科牌子在山东体制内极硬)。
- **山大青岛校区计算机 / 海洋 / 新工科**:**985 牌子 + 青岛地理(海尔海信浪潮对口)**,比本部低 2,000-4,000 名,性价比之选。
- **山大威海校区(综合)**:985 牌子但分数最低,**普通工薪家庭刷 985 牌子的合理捷径**(但威海地理偏远,资源稀释明显)。
- **山大基础学科强基(数学 / 物理 / 化学 / 生物 / 中文 / 历史)**:**比裸分进山大低 5-15 分,但直博绑定**,适合学术苗子。

## 坑专业 / 慎选(在山大里相对弱)

- **农林 / 矿冶**:边缘学科,**学农林直接选山农大,学矿冶直接选山科大或中国矿大**。
- **新闻传播**:行业凋零,**山大新闻不如复旦 / 人大**,毕业大量改行考公。
- **生物科学 / 生物技术(纯理学)**:跟其他 985 一样的"必须读博"现实,**慎选,除非笃定走学术**。
- **威海校区部分文管类**:威海地理偏远 + 资源稀,**冷门文管出口窄**。

## 关键提醒(填报陷阱)

1. **三校区文凭与资源不同(关键!!)**:
   - **济南本部**= 正牌山大 + 文 / 理 / 医 / 工 / 经管 全学科,资源最厚
   - **青岛校区**= 985 牌子 + 文凭注明"青岛校区" + 新工科 / 计算机 / 海洋,师资部分外聘
   - **威海校区**= 985 牌子 + 文凭注明"威海校区" + 综合性较小 + 资源最稀
   - **学医 / 文 / 历史 一定选本部**,**学新工科 / CS + 想留青岛 → 青岛校区合理**,**只要 985 牌子 + 分不够本部 → 威海校区**
2. **物理类专业组分化大**:山大本部组内可能含化学 / 生物 / 材料 / 物理等多个方向,**服从调剂前务必查 2026 招生章程具体组内有什么**。
3. **强基 vs 裸分**:强基低 5-15 分进山大,但**直博绑定 + 不能转专业**,慎选。
4. **山大医学院 vs 上交医 / 复旦上医**:山大齐鲁医学全国前 10,**北方临床顶配**,但跟上交瑞金 / 复旦中山差一档,**笃定走医的尖子生分够建议优先上交医 / 协和**。
5. **三位一体 / 综合评价招生**:山大有综合评价,本省顶尖高中(山东实验 / 济南外国语 / 青岛二中)+ 学考全 A 才有价值,**普通考生别浪费机会**。

- **出省到长三角(沪苏)**:约 12-18%(上海金融 / 字节 / 阿里 / 长三角制造)
- **保研 / 考研 / 读博**:**约 50%+**(保研率 ~25%,985 中位)

## 适合谁

- 山东综合改革(3+3)**全省排 8,000 名内 + 想留鲁就业 / 考公 / 进体制** 的考生(山大本部首选)
- **想做医生 → 齐鲁医学院**(留鲁医生天花板 + 齐鲁医院体系)
- **学数学 / 中文 / 历史 / 古文字 → 山大本部基础学科顶级**(齐鲁文化底蕴)
- **学计算机 / 海洋相关 + 想留青岛 → 山大青岛校区**(海尔海信浪潮对口)
- **要 985 牌子 + 分不够本部 → 山大威海校区**(性价比刷牌子,但威海地理偏远要接受)
- **家庭普通工薪 + 求稳 + 留鲁** → 山大基础学科 + 考公选调路径

## 不适合谁

- **铁了心冲清北的考生**:分够清北直接清北,**别在山大将就**
- **想做顶级临床医生**:分够上交医 / 协和 / 复旦上医 别在山大医学院将就
- **想做顶级金融 / 投行**:复旦 / 上交 / 上财 在上海金融圈对口度更高
- **学海洋 / 水产**:**中海大全国第 1 + 国家海洋局对口**,比山大青岛校区海洋方向更专
- **学石油 / 化工对口央企**:**中石大(华东)石油工程全国前 3**,比山大化工对口更直接
- **不想留山东 + 想冲北上深一线**:山大留鲁率 50%+,想出省的 985 选项更多

## 大小年 / 趋势

- **2022 年**:山大三校区招生改革深化 + 强基计划稳定 → 本部主流组录取分小幅抬升,**齐鲁医学院八年制比 2021 年高约 500 名位次**
- **2023 年**:CS 寒冬 + 山东 3+3 选科改革 → 山大 CS 组录取分小幅回落,**但齐鲁医学 + 数学英才组继续上扬**(山东工薪家庭对"医生 + 体制"信仰加成)
- **2024 年**:双一流第二轮评估山大 13 个学科入选 → 本部继续稳定,**威海校区 985 牌子需求回升**(性价比党回流)
- **2025-2026 趋势预测**:山大本部主流组录取位次稳定在 4500-8000 名;**齐鲁医学院八年制 → 全省 1500 名内** 是顶配;威海校区 985 牌子仍是最便宜的山东 985

## 校友圈 / 实习生态

- **山东体制内校友密度第 1**:**山大校友占山东省委 / 省直机关 / 各市直机关 中高层 35%+**,**山东选调 + 公考 + 国企校招 山大系 是隐性 VIP 通道**
- **齐鲁医院校友圈**:山东省内三甲医院主任级 70%+ 是齐鲁医校友 / 同济医校友(华中科技),**山大医学院血脉是山东医疗圈最厚的人脉网**
- **浪潮 + 鲁能 + 山东能源**:这一系列山东央企 中高层校友占比 40%+,山大本部校招认可度极高
- **缺点**:校友圈强但偏向"留鲁" — 想做北上深互联网 / 金融,**山大校友圈不如复旦上交北邮 那么直接**(北邮 CS 在字节 / 阿里圈是嫡系,山大 CS 是中段)

## 山东典型 case(山大)

- **Case A(济南体制内 + 选调路径)**:济南某中产体制内家庭(父亲省直机关,母亲银行)→ 孩子 658 分历史类,省排 800 → 山大法学(本部)→ 大三参加山大选调营 → 毕业进山东省委组织部,**起点直接在地市副科级**,父母资源用满
- **Case B(青岛中产 + 学医)**:青岛市南区医生家庭 → 孩子 670 分物理类,省排 400 → 山大齐鲁医学院八年制 → 8 年后博士 → **进齐鲁医院心内科**,父母圈子直接复用,30 岁后年薪 30w+,40 岁主任级年薪 80w+
- **Case C(山东内陆农村 + 国家专项)**:菏泽鄄城农村男生,615 分物理类,省排 8000 → 国家专项进山大数学英才(本部,比统招低 25 分)→ 保研中科院数学所 → **整个家族第一个 985 + 学术路径**
- **Case D(山大青岛校区 CS + 出省)**:济南工薪家庭,650 分物理类,省排 4500 → 山大青岛校区 计算机 → 实习字节(北京)→ 校招拿到字节 SP offer 35w → **出省北京**(父母最初不情愿,5 年后年薪 60w 父母才认)
- **Case E(山大威海性价比)**:潍坊工薪家庭,605 分物理类,省排 1.5w → 父母想要 985 牌子但分不够本部 → 山大威海校区 法学 → 985 文凭(注明威海)+ 留威海考公 → **进威海某区公务员,985 牌子用在了考公出口对口**
- **Case F(山大本部冷门组踩坑)**:济宁中产家庭,635 分物理类,省排 6000 → 想冲山大本部 → 服从调剂被分到化学 / 材料 → **生化环材天坑** → 5 年后被迫读硕博 / 转行,**父母后悔没听老师劝改报中海大主流组或山大青岛校区 CS**

## 关键提醒(再强调)

1. **山大三校区不是"等同 985"** — 本部 > 青岛 > 威海,文凭注明,**学医 / 学历史 / 学中文 必须本部**
2. **山大本部冷门组(化学 / 材料 / 生物 / 农林)对工薪家庭是天坑** — 必须读博才有出路,普通家庭撑不起 → 不如山大青岛校区主流组 / 中海大主流组
3. **山大选调是隐性王牌** — 山大本硕(尤其法学 / 汉语言 / 经济 / 马理论)毕业,**山东选调营内部竞争激烈但比国考省考容易**,起点直接副科级
4. **山东顶尖考生分够清北复交别 stuck 山大** — 这是张雪峰式硬话:山大留鲁 anchor 强但**清北复交 + 出省 上限明显高一档**,家庭支持出省的话别为了"留鲁 + 山大执念" 浪费分数

## 山东本省考生选山大的 5 大决策困境(agent 要识别 + 给判断)

### 困境 1:"分够山大本部冷门组 vs 中海大 / 哈工威 主流组" — 怎么选?
**判断**:看孩子未来锚点。**笃定考公 / 选调 / 留鲁体制内** → 山大本部冷门组(山大选调 anchor 强);**走行业 / 工科 / 央企** → 中海大海洋主流 / 哈工威工科主流 更对口(行业派 985 价值更直接)

### 困境 2:"山大本部 vs 山大青岛 vs 山大威海" — 三校区怎么选?
**判断**:**学医 / 中文 / 历史 / 数学 必须本部**(资源 + 校区核心氛围);**学新工科 / CS + 想留青岛** → 青岛校区合理;**只为 985 牌子 + 分不够本部 + 接受地理偏远** → 威海校区(性价比 985 牌子)

### 困境 3:"山大法学(选调路径)vs 中南财法 法学" — 留鲁 vs 出鲁?
**判断**:山东选调 + 留鲁体制 → 山大法学绝对优(山东省委组织部嫡系);全国流通 + 想去外省体制 → 中南财法 / 中政法 / 西政 更广

### 困境 4:"山大齐鲁医学院八年制 vs 北医 / 协和 / 上交医" — 同档分数怎么选?
**判断**:留鲁做医生 + 父母医生圈在山东 → 山大齐鲁(齐鲁医院体系直接);想去北上广做顶级医生 → 协和 / 上交医 / 北医 高一档(齐鲁医比这三家差半档,但留鲁仍是顶配)

### 困境 5:"山大本部 vs 北航 / 同济 / 华师 等外省 985 同档校" — 留鲁 vs 出省?
**判断**:山东工薪 / 体制内家庭 + 留鲁 anchor 强 → 山大本部(校友圈 + 选调对口);山东私企 / 中产家庭 + 接受出省 + 想去北上深 → 出省 985 在所在城市的就业生态更厚(山大留鲁圈子虽厚但出省后弱)

## 山东本省家长常见误区(山大专项)

1. **"山大就是 985,3 校区都一样"** — 严重错误。**本部 > 青岛 > 威海**,文凭注明,**学医 / 中文 / 历史 / 数学 必须本部**(本部资源 + 教授 + 科研环境集中)
2. **"山大青岛校区 = 山大分校"** — 错。**青岛校区是山大主体的扩展校区**(2015 年正式启用),**新工科 / 计算机 / 海洋 / 信息科技 主要在青岛**,师资有相当部分来自本部 + 海归青年教师,资源不弱;**但文凭注明青岛校区**
3. **"山大威海校区是骗分的,不该去"** — 半对。威海校区资源稀于本部,**但 985 文凭 + 山大威海标签** 对工薪家庭刷 985 牌子有价值,适合"求 985 牌子 + 接受地理偏远"的考生
4. **"山大本部什么专业都好"** — 错。**山大冷门组(化学 / 材料 / 生物 / 农林)对工薪家庭是天坑** — 必须读博才有出路,普通家庭撑不起 → 不如山大青岛主流组 / 中海大主流组
5. **"山大齐鲁医学院八年制 = 顶配"** — 在山东顶配,但全国看 **协和 / 上交医 / 北医 / 复旦上医 高一档**;**留鲁做医生 → 山大齐鲁是顶配;想去北上广做顶级医生 → 协和 / 上交医 / 北医 高一档**
6. **"山大选调 = 闭眼考公"** — 错。山大选调内部竞争极激烈(山大每年想走选调的学生 1500+ 人,实际录取约 300-400),**山大选调营 + 优秀学生荣誉项目 + 中央 / 山东省委组织部 三层筛选** — 不是闭眼,但**资格内的竞争比国考省考容易**

## 山大冷知识
