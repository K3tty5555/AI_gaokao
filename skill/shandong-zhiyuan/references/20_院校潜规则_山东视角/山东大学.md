# 山东大学(山大,SDU)— 综合 985 + 山东全省独苗 + 三校区分散

## 一句话定位

**山东全省唯一 985 + 211 + 双一流 A 类全占的高校**,**齐鲁医学血脉**(临床医学全国前 10),**数学 / 中文 / 历史 全国前 10**。**3 校区分散(济南本部 / 青岛 / 威海),文凭注明校区,资源稀释明显**。**山东本省考生进山大 = 把就业 + 户口 + 父母满意度 一起锁定**,留鲁就业生态(齐鲁医院 / 浪潮 / 海尔海信)直接对口,**齐鲁实在厚重,不浮夸,但底子很硬**。

---

## 真实地位

- **985 + 211 + 双一流 A 类全占**,**山东全省唯一**,2024 软科全国 #18-20。
- **齐鲁医学血脉**:原山东医科大学并入,临床医学全国前 10(跟北医 / 协和 / 复旦 / 上交 同档行业认可度),齐鲁医院 / 山东省立医院 体系直接对口。
- **基础学科底子顶级**:数学 / 中文 / 历史(齐鲁文化 + 古文献研究)全国前 10,材料科学全国前 10。
- **山东本省心理上限**:山东物理类省排前 3,000 内 / 历史类省排前 500 内的天花板,本省考生进山大是最高价值标的。
- **3 校区分散(关键!!)**:济南本部 / 青岛校区 / 威海校区,**分别招生 + 文凭注明校区**(青岛 / 威海文凭与本部不同),**这是山大跟其他 985 最大区别 — 校区分散导致资源稀释**,但 985 牌子统一。

---

## 山东录取位次区间(综合改革 3+3,750 总分)

参考近 5 年掌上高考 + 山东一分一段表反查(**只给位次,不编分**):

### 普通类一段(综合,750 总分)

- **顶尖组(临床医学八年制 / 齐鲁医学班 / 强基 / 数学英才)**:**全省 500-2,000 名**(逼近清北边缘)
- **本部王牌主流组(数学 / 中文 / 历史 / 计算机 / 经管法)**:**全省 2,000-4,500 名**
- **本部主流工科组(机械 / 材料 / 电气 / 化工 / 土木)**:**全省 4,500-8,000 名**
- **青岛校区(新工科 / 海洋相关 / 信息科技)**:**全省 6,000-12,000 名**(比本部低 2,000-4,000 名)
- **威海校区(综合)**:**全省 8,000-15,000 名**(985 牌子但资源最稀,分数最低)

**段位定位**:**冲山大本部基本要省排 8,000 名内**,4,500 名内可挑王牌专业,2,000 名内可冲齐鲁医学;**青岛 / 威海 校区门槛低 2,000-7,000 名**。**以一分一段表反查为准**。

## 性价比专业(同样山大牌子,录取相对低)

- **历史学 / 考古学 / 古文献**:**齐鲁文化底蕴 + 全国前 10**,录取分比 CS / 经管低,**适合考公选调 + 走学术** 的考生(山大文科牌子在山东体制内极硬)。
- **山大青岛校区计算机 / 海洋 / 新工科**:**985 牌子 + 青岛地理(海尔海信浪潮对口)**,比本部低 2,000-4,000 名,性价比之选。
- **山大威海校区(综合)**:985 牌子但分数最低,**普通工薪家庭刷 985 牌子的合理捷径**(但威海地理偏远,资源稀释明显)。
- **山大基础学科强基(数学 / 物理 / 化学 / 生物 / 中文 / 历史)**:**比裸分进山大低 5-15 分,但直博绑定**,适合学术苗子。

## 坑专业 / 慎选(在山大里相对弱)

- **农林 / 矿冶**:边缘学科,**学农林直接选山农大,学矿冶直接选山科大或中国矿大**。
- **新闻传播**:行业凋零,**山大新闻不如复旦 / 人大**,毕业大量改行考公。
- **生物科学 / 生物技术(纯理学)**:跟其他 985 一样的"必须读博"现实,**慎选,除非笃定走学术**。
- **威海校区部分文管类**:威海地理偏远 + 资源稀,**冷门文管出口窄**。

## 关键提醒(填报陷阱)

1. **三校区文凭与资源不同(关键!!)**:
   - **济南本部**= 正牌山大 + 文 / 理 / 医 / 工 / 经管 全学科,资源最厚
   - **青岛校区**= 985 牌子 + 文凭注明"青岛校区" + 新工科 / 计算机 / 海洋,师资部分外聘
   - **威海校区**= 985 牌子 + 文凭注明"威海校区" + 综合性较小 + 资源最稀
   - **学医 / 文 / 历史 一定选本部**,**学新工科 / CS + 想留青岛 → 青岛校区合理**,**只要 985 牌子 + 分不够本部 → 威海校区**
2. **物理类专业组分化大**:山大本部组内可能含化学 / 生物 / 材料 / 物理等多个方向,**服从调剂前务必查 2026 招生章程具体组内有什么**。
3. **强基 vs 裸分**:强基低 5-15 分进山大,但**直博绑定 + 不能转专业**,慎选。
4. **山大医学院 vs 上交医 / 复旦上医**:山大齐鲁医学全国前 10,**北方临床顶配**,但跟上交瑞金 / 复旦中山差一档,**笃定走医的尖子生分够建议优先上交医 / 协和**。
5. **三位一体 / 综合评价招生**:山大有综合评价,本省顶尖高中(山东实验 / 济南外国语 / 青岛二中)+ 学考全 A 才有价值,**普通考生别浪费机会**。

## 毕业出口(2024 数据)

- **留山东就业**:**约 50-55%**(**济南 30%+**:齐鲁医院 / 山东省立 / 浪潮 / 鲁能 / 山东能源 / 中创软件;**青岛 15%+**:海尔 / 海信 / 青啤 / 万华化学青岛 / 海洋经济;烟台 5%:万华化学总部 / 烟台港)
- **出省到京津**:约 15-20%(国家部委 / 央企总部 / 北京三甲 / 互联网大厂)
- **出省到长三角(沪苏)**:约 12-18%(上海金融 / 字节 / 阿里 / 长三角制造)
- **保研 / 考研 / 读博**:**约 50%+**(保研率 ~25%,985 中位)
- **出国**:约 10-15%
- **进央企概率**:工科 / 经管类约 25-30%
- **起薪范围**:**齐鲁医学院八年制 → 齐鲁医院编制 12-18w + 主任医师退休年薪 60-100w 是常态**;CS / AI 方向 18-30w(浪潮 / 海尔 / BAT);基础学科读博后 15-25w;文科考公进山东体制起薪 10-15w + 编制。

**山东考生主流路径**:**山大齐鲁医 → 齐鲁医院体系**(留鲁医生天花板);**山大数学 / 中文 / 历史 → 山东选调 / 高校 / 出版**(齐鲁文化对口);**山大青岛校区 CS → 海尔海信浪潮**(青岛科技对口)。

## 适合谁

- 山东综合改革(3+3)**全省排 8,000 名内 + 想留鲁就业 / 考公 / 进体制** 的考生(山大本部首选)
- **想做医生 → 齐鲁医学院**(留鲁医生天花板 + 齐鲁医院体系)
- **学数学 / 中文 / 历史 / 古文字 → 山大本部基础学科顶级**(齐鲁文化底蕴)
- **学计算机 / 海洋相关 + 想留青岛 → 山大青岛校区**(海尔海信浪潮对口)
- **要 985 牌子 + 分不够本部 → 山大威海校区**(性价比刷牌子,但威海地理偏远要接受)
- **家庭普通工薪 + 求稳 + 留鲁** → 山大基础学科 + 考公选调路径

## 不适合谁

- **铁了心冲清北的考生**:分够清北直接清北,**别在山大将就**
- **想做顶级临床医生**:分够上交医 / 协和 / 复旦上医 别在山大医学院将就
- **想做顶级金融 / 投行**:复旦 / 上交 / 上财 在上海金融圈对口度更高
- **学海洋 / 水产**:**中海大全国第 1 + 国家海洋局对口**,比山大青岛校区海洋方向更专
- **学石油 / 化工对口央企**:**中石大(华东)石油工程全国前 3**,比山大化工对口更直接
- **不想留山东 + 想冲北上深一线**:山大留鲁率 50%+,想出省的 985 选项更多
