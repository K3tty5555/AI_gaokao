# 电气工程及其自动化 / 电网 — 山东视角

## 核心结论

**普通家庭男生通过 CS 逆袭的窗口已关,但通过电气进国家电网的路在山东依然敞着 — 而且山东电网招聘体量在全国排前三**。这是当前**山东工薪 / 农村家庭最适合的工科专业之一**,前提是学校 + 专业方向选对。**山东电力产业生态特殊:除了国家电网,还有山东能源 / 兖矿能源 / 鲁能集团 这一系列省属能源央企,本省电气出口比湖北还多元**。

## 关键事实

### 行业格局(山东特殊性)
- **国家电网山东分公司 = 央企铁饭碗**,**每年校招 2000+ 人**(全国省网招聘 Top 3,跟河南 / 河北并列大户)
- **南方电网在山东无业务**(山东属于国网范围),所以山东考生本省就业方向 = 国网为主
- **山东能源(济南)** + **兖矿能源(济宁)** + **鲁能集团(济南)** + **华能山东 / 国电山东 / 大唐山东** 这一堆能源央企的电气岗,**山东考生本地就业池 比 湖北 / 江西 大不少**
- **山东风电 / 光伏产业链强**(滨州 / 东营 / 烟台 等地),金风科技 / 远景能源 / 龙源电力 在山东设厂,新能源电气岗增长快
- **进电网后基本一辈子稳定,内部晋升清晰**,离职率极低

### 招聘门槛(2024 山东电网实况)
- **985/211 电气专业 ≈ 闭眼进山东省电网管理岗**(济南本部 / 青岛 / 烟台分公司)
- **"电力八校"(华北电力 / 武大 / 华科 / 重大 / 西交 / 东南 / 浙大 / 上交)电气** ≈ 进山东省网概率极高,**很多山东考生为了进山东电网,会跨省读华北电力**
- **山东本省的 山大电气 / 山科电气 / 青岛大学电气** = 进山东省网管理岗主力
- **双非一本电气** → 硕士可以进省网,**本科只能进市级或基层**
- **二本三本电气** → 基本只能进基层(县乡变电站、抢修班),**也是编制**

### 薪资水平(山东电网 2024 实况)
- **山东省公司管理岗**:9000-15000/月 + 五险一金 + 公积金 12% + 各种补贴 + 年终奖 4-6 个月
- **济南 / 青岛 地市公司**:8000-13000/月
- **烟台 / 潍坊 / 临沂 等地市公司**:7000-11000/月
- **县级公司**:6000-10000/月
- **山东电网薪资在全国省网中等偏上**(高于河南 / 江西,低于江苏 / 浙江省网),**全部带编制 + 福利住房 / 子女教育**

### 工作内容现实
- **基层岗**:抢修、巡线、检修、调度,**有夜班 + 户外 + 体力要求**(女生慎重)
- **管理岗**:办公室、运营、规划、营销,体力要求小,需 985/211 学历
- **专业技术岗**:研究院、调度中心,**对学历要求高,硕士起步**

## 决策映射

| 学生情况 | 推荐路径 |

| 男 + 省排 3w 内 + 想进国网 | 山科 / 青大 / 山东理工 电气,**做好考研准备**,本科直接进省网管理岗有点紧 |
| 男 + 省排 5w 外 + 不怕基层 | 山东建筑 / 烟台大学 / 临沂大学 等二本电气,**目标县级电网编制** |
| 女 + 学校好(985/211)+ 不介意基层 | 慎重,**电气基层有体力要求**,女生进省级管理岗有竞争 |

| 父母电网系统 / 能源央企 | **强烈推荐** — 电气 + 父母行业资源 = 进网概率最高,**子承父业典型路径** |

## 山东本地院校梯队(电气专业)

### 第一梯队(电力八校 + 985,山东电网管理岗主力)
- **山东大学 电气工程及其自动化** — 985,本部济南,**山东电网管理岗主要供给校之一**,毕业进山东省网 / 华北电网 / 央企发电集团 没问题
- **哈尔滨工业大学(威海)电气** — 985 牌子(C9),哈工大电气全国前 5,**威海校区毕业进山东省网管理岗稳**
- **华北电力大学(保定 / 北京)** — 211,**电力行业第一校**,山东考生跨省读这个就为了进国网,**毕业进山东电网管理岗几乎闭眼**

### 第二梯队(山东性价比之选)
- **中国石油大学(华东)电气** — 211,青岛,**电气 + 石油背景双向加分**,毕业进山东电网 / 中石化山东 / 山东能源 都有路径
- **山东科技大学 电气** — 强双非,青岛,**山东本地电网就业老牌**(尤其是青岛 / 烟台 / 潍坊 地市公司),性价比高
- **青岛大学 电气** — 强双非,青岛,本地认可度好,毕业进山东电网基层 / 海尔 / 海信 电气方向都行

### 第三梯队(可选)
- **山东理工大学 电气**(淄博)— 双非,本地认可,毕业可进淄博 / 滨州 电网基层
- **济南大学 电气** — 双非,济南本地国企 / 电网基层就业还行
- **山东建筑大学 电气** — 双非,跟建筑结合的电气方向(楼宇自动化)

### 第四梯队(避坑或仅本地)
- **烟台大学 / 临沂大学 / 聊城大学 / 鲁东大学 电气** — 二本,**本科直接进省网管理岗概率极低**,只能做基层抢修。普通家庭可以接受基层就报,**要管理岗就别幻想**
- **山东独立学院 / 民办院校的电气** — **直接避坑**,这一档电气进电网都难,不如学护理 / 学前

## 典型山东 case(供 agent 引用)

- **Case A**:山东临沂考生,普通家庭男生,580 分物理类,省排 4w。**首选山科电气**(青岛),毕业进山东电网临沂分公司,起薪 8.5k + 编制。**4 年后年薪 16w,父母彻底放心**(山东工薪家庭眼里"最理想的儿子工作")
- **Case B**:山东青岛考生,工薪家庭男生,650 分物理类,省排 6000。报哈工威电气,**校招拿到国家电网山东省公司(济南)管理岗 offer,起薪 13w + 编制**
- **Case C**:山东潍坊考生,普通家庭女生,560 分物理类。**家长强烈想报电气**(听说"进电网铁饭碗")。**建议改报山东师范汉语言文学(公费师范)** — 女生进电网基层吃力,且家长不知道汉语言考公比电气进网更稳,且公费师范是 0 学费 + 编制
- **Case D**:山东东营考生,父亲在胜利油田 + 母亲在中石化,中产家庭男生,620 分物理类。**首选中石大(华东)电气**(青岛)— 电气 + 石油双背景 + 父母行业资源,**毕业进胜利油田电力公司基本闭眼**,典型子承父业
- **Case E**:山东淄博考生,工厂家庭男生,550 分物理类,省排 5.5w。报山东理工电气,毕业进淄博电网基层做检修,**起薪 6k + 编制 + 福利住房**,虽然不光鲜但 30 年稳定到退休

## 易错认知(agent 要纠正用户的)

- "**学电气一定能进电网**" — 错。**电网每年招 2-3 万人,看学校 + 专业排名 + 综合表现**。**双非毕业不考研基本只能进基层**
- "**进电网就是当电工**" — 错。管理岗、调度岗、市场营销岗都是办公室工作。基层电工只是其中一种岗位
- "**山东电气就只能进国网**" — 错。**山东电气出口比大多数省宽** — 还有山东能源 / 兖矿能源 / 鲁能 / 华能山东 等省属能源央企,以及金风科技 / 远景能源 等新能源公司
- "**女生不适合电气**" — 半对。基层不适合(体力 + 户外),**省级管理岗女生完全 OK**,但门槛高(985/211)
- "**电气 = 自动化**" — 错。**电气 = 强电(电网、电机、电力系统)**,自动化 = 弱电(控制、传感、机械控制)。**进电网认电气,不认自动化**(山东电网招聘明确写"电气工程及其自动化",不要报错成"自动化"专业)
- "**山大电气一定比山科电气强**" — 大体对但有例外。**山科电气在山东本省地市电网系统认可度极高**(山科血脉),**山大本部电气虽然是 985,但毕业生很多去外省 / 央企总部,留鲁地市电网比例反而低于山科**

## 山东电气和湖北 / 河北 的差异

- **山东电气考生 vs 河北电气考生**:河北考生很多想"出河北留京津",所以华北电力(保定)对河北考生是"留省"路径;山东考生 留鲁倾向更强,华北电力对山东考生是"出省读书然后回山东进电网" 的曲线路径
- **山东电气考生 vs 湖北电气考生**:湖北有"三峡大学电气" 这个性价比之王(进国网 644 人),**山东对应的性价比之王 = 山科 + 中石大(华东)+ 山东理工**(三所合计进国网体量也很大,但单校不如三峡大学集中)

## 关键提醒

**报电气不是为了"学技术",是为了"进电网"或者"进能源央企"**。如果学校层次不够进不了电网管理岗,**这个专业的吸引力大打折扣**(技术含量不比其他工科高,薪资也不如 CS)。**所以学校选择是这个专业的核心决策**。

**山东工薪 / 农村家庭男生,如果分够二本一本电气 + 不怕基层 + 父母想要"稳定铁饭碗" — 这是除了公费师范之外最优的"零风险"路径**(比 CS / 金融 / 工商管理 都稳)。
