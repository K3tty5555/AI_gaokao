# 考公优选专业表(山东本地视角)

## 核心结论

**专业决定考公选岗范围**。山东家长普遍知道"考公好",但不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**山东作为儒家文化发源地 + 体制内偏好极强的省份(全国 Top 3)**,考公文化比湖北 / 江苏更浓。**山东省考 + 各市公考 + 选调生 + 事业编 加起来每年新增体制内岗位 5 万 +**,**但 60% 以上集中在汉语言 / 法学 / 经济 / 会计 / 公共管理 几个大类**。专业选错,可报岗位差 5 倍。

## 关键事实(2024 国考 / 山东省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 山东省考特殊性(2024 实况)
- **山东省考规模 全国 Top 5**,每年招录 6000-8000 人(基础公务员)
- **汉语言文学 + 法学 并列考公第一专业**,可报岗位约占 30%(山东省考结构跟全国基本一致,但儒家文化加成 + 体制内执念让"汉语言进体制" 成功率更高)
- **山东各地市公务员**对法学要求高(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)

### 山东选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(山东本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- **山东选调对接特别好的院校**:山大 / 中海大 / 中石大(华东) / 哈工威 / 山东师大 / 曲师大(部分岗位)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **山东选调对江苏 / 浙江 / 北京 985 学生也开放**(全国选调,跟省内选调并行),所以山大选调内部竞争激烈

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、山东警察学院 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,山东省内中国政法 / 山大法学 主供给

## 山东本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业
- **山东大学 法学** — 985,**齐鲁文化 + 全国前 10 法学**,**法考通过率高,选调路径最优**(山东省委组织部 / 中央选调 双向通)
- **山东大学 文学院 汉语言** — 985 + 山大中文全国前 10 + 齐鲁文化,**山东选调首选 + 体制内招聘王者**
- **山东大学 历史学院 / 哲学院** — 985 + 历史 / 哲学 全国前 10,**学界 / 选调 / 出版 / 党群岗** 多向出口
- **中国海洋大学 法学 / 经济学** — 985 牌子,**青岛地方公务员认可度高**
- **中国石油大学(华东) 法学 / 经济学** — 211,青岛,**石油 + 法学 / 经济双背景** 进山东能源系统编制有优势
- **山东师范大学 思想政治教育 / 公费师范汉语言** — 不是考公但是教师编制,**等同于考公友好**

### 双非 + 性价比考公专业
- **曲阜师范大学 汉语言文学 / 法学** — **山东"考研考公神校"**,本科氛围内卷 + 应试导向 + 上岸率全国闻名,**山东工薪家庭双非求上岸的核心选项**
- **聊城大学 / 临沂大学 / 鲁东大学 / 济南大学 汉语言文学 / 法学** — 双非二本,但**山东本地省考 / 市考 编制路径**,毕业考公成功率比 CS / 工商管理 都高
- **山东政法学院 法学** — 山东省属政法院校,**山东法检系统认可度高**(类似河南"郑州警察学院" 之于河南)
- **山东财经大学 财政学 / 会计学 / 税务** — 山东双非财经龙头,**山东税务 / 财政 / 海关 / 国税 编制路径核心校**

### 公安系统专属
- **山东警察学院** — 本科,公安联考路径,**毕业进山东本地公安概率极高**(基层警察)
- 中国人民公安大学(山东定招生) — 全国公安顶配,毕业进部委 / 省厅
- 中国刑事警察学院(沈阳) — 公安刑侦特色

## 典型山东 case(供 agent 引用)

- **Case A(逆袭路径)**:山东菏泽考生,540 分文史类,省排 6w,**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报曲阜师范汉语言文学**,毕业当年考上山东省直某机关公务员,**家庭命运改变**。曲师大本身牌子不响,但**应试氛围 + 考公考研内卷 + 学校就在曲阜便于全身心备考** = 山东工薪家庭神级路径

- **Case B(选调路径)**:山东济南考生,650 分文史类,中产家庭。家长想报"金融"(山大经济学院)。**改报山大法学**,**毕业获得山大选调生资格,直接进山东省委组织部**,**起点远超经济学就业**(山东选调极看重法学 / 汉语言 / 马理论)

- **Case C(失败路径)**:山东烟台考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了山东工商学院计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**

- **Case D(误区路径)**:山东青岛家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**

- **Case E(警校路径)**:山东临沂工薪家庭男生,540 分物理类,省排 8w → 推**山东警察学院 治安学 / 侦查学** → 毕业通过山东省公安联考进临沂某区公安编制,**4 年读完 22 岁直接编制 + 工薪家庭神器**

- **Case F(山东财经路径)**:山东济南工薪家庭女生,580 分历史类,省排 1w → 推**山东财经大学 税务 / 会计** → 毕业考山东国税 / 济南税务 编制,**山东税务系统每年从山财大量招录**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(山东 3+3 制度允许大部分专业组合,首选物理也能报多数考公专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是山东家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**曲阜师范大学是普通双非**" — 错。**曲师大的考研 / 考公上岸率是全国双非天花板**,在"考公考研内卷" 单点维度上 高于很多 211
- "**选调要去山大才行**" — 半对。**山大选调对接最直接,但山东师大 / 曲师大 / 山东财大 部分岗位也开放选调**(尤其是教育 / 财税 / 党群相关岗位)

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是山东家长被严重低估的考公王者**。

**山东特别提醒**:
1. **山东工薪 / 农村家庭考公,优先级:山师公费师范 > 曲师汉语言 > 山大法学 / 汉语言(分够的话)> 山东财大税务 > 山东警察学院**
2. **不要被"行政管理 / 公共管理"听起来对口骗了** — 实际可报岗位比汉语言 / 法学 少 50% 以上
3. **山东省考 vs 国考**:山东省考竞争激烈但本省岗位多;国考更卷但天花板高,**家庭希望孩子留鲁 → 主攻省考 + 各市公考;家庭支持出省 → 国考 + 山东选调外省路径(去江苏 / 浙江)**
4. **山东人均编制岗位密度全国 Top 10**(机关 + 事业 + 国企 + 教师 加起来),**山东工薪家庭考公的"上岸率底层概率"高于河南 / 河北**
