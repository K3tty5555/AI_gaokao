# 山东 3+3 高考政策

## 核心结论

**山东 2017 年成为新高考第二批试点省**(跟北京 / 天津 / 海南同批,**比湖北/江苏/湖南早 4 年**),**2020 年首届实行 3+3** —— 体系跟浙江/上海/北京/天津一致(语数外 + 6 选 3 + 等级赋分),但**不是 7 选 3**(没有"技术"科目)。**总分 750**(跟北京/天津/湖北同,跟上海 660、海南 900 不同)。**录取批次:本科批用普通类一段 / 二段 + 特殊类型招生控制线,不分本一本二**(类似浙江段制,但浙江是 3 段、山东是 2 段)。

## 关键事实

### 考试结构(3+3 体系,与湖北/江苏的 3+1+2 完全不同!)

- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分,**用原始分**)
- **3 = 选考科目**:从**物理 / 化学 / 生物 / 政治 / 历史 / 地理** 中**选 3**
  - **山东没有"技术"科目**(浙江独有,山东无此)
  - 共 **6 选 3 = 20 种组合**(湖北 3+1+2 是 12 种,山东比湖北多 8 种)
  - 每科 100 分,**用等级赋分制**(20 等级,每级约 3 分,21-100 分)
  - **1 次选考机会**(山东不像浙江有 2 次)
- **总分 = 750 分**(语数外 450 + 选考 3 × 100)

### 等级赋分制(关键!!)

- **赋分公式**:把每科原始分按比例换算成 20 个等级(每等约 3 分,从 21 分起步,顶 100 分)
- **比例**:卷面前 1% → 100 分,前 2% → 97 分,前 3% → 94 分,...,**末等 → 21 分**
- **意义**:无论原始分多低,**至少拿 21 分**(保底)
- **影响**:**用户告诉你的山东 6 选 3 三科分都是赋分后分数,不是原始分**

### 段次录取(山东最重要的特殊性!)

**山东 2020 起取消"本一/本二/本三/专科"批次划分**,改用"普通类一段/二段 + 特殊类型招生控制线"分段录取:

| 线名 | 划线方式 | 大致对应 | 占考生比例 |
|---|---|---|---|
| **特殊类型招生控制线**(特控线) | 卷面前约 20% | 原"一本线" | 约前 20% |
| **普通类一段线**(本科线) | 划本科批投档线 | 原"二本线" 上面到本科最低 | 约前 60% |
| **普通类二段线**(专科线) | 划专科批投档线 | 原"专科线" | 约前 90% |

**关键**:
- **没有"本一""本二"的概念**,所有本科都在一段批填,二段是专科批
- **特控线**用于**强基计划 / 综合评价 / 高校专项** 等特殊招生类型的资格门槛(不是录取线,是"达不到这条线就不能报")
- **跟浙江最大差异**:浙江是 3 段(本科 + 高水平专科 + 普通专科分 3 段),山东是 2 段(本科一段 + 专科二段),**山东更接近"传统本专科分批"的两段**

### 院校专业组(山东特色 — 96 个志愿!)

- **山东本科批 96 个院校专业组志愿**(全国前列,跟河北 96 同档,比浙江 80 多 16 个)
- 每个志愿是"院校 + 专业组"组合,服从调剂只在本组内
- 一段、二段分别填报 96 个 / 60 个,**两段录取互不交叉**(一段没录走二段)

### 综合评价 + 强基计划(山东独有招生方式)

- **山东省内重点大学综合评价**:山大 / 中海大 / 中石大(华东) / 哈工威 / 山师 / 山农 / 青大 等多所参加
  - 高考分(60-85%)+ 校测(15-30%)+ 学考(5-10%)
  - **跟浙江三位一体类似,但分数权重更高**(山东综合评价给高考分的权重更大)
- **强基计划**:山大、中海大有强基(数学/物理/化学/生物/中文/历史 等基础学科)
  - **强基只能填 1 所**,要求过特控线

## 山东特殊性(关键!!)

### 1. 山东高校生态(1 所 985 + 3 所 211 + 海洋/石油 行业顶配)

- **1 所 985 = 山东大学**(山大,济南/青岛/威海三校区,综合性 985)
- **3 所 211**:**山东大学**(985 兼 211)、**中国海洋大学**(中海大,青岛,985 兼 211 — 原 985 行业类)、**中国石油大学(华东)**(中石大,青岛,211 + 双一流)
- **C9 校区**:**哈尔滨工业大学(威海)**(哈工大三大校区之一,985 牌子但分数比哈工大本部低 30+ 分)
- **行业顶配双子**:
  - **中国海洋大学** — **海洋科学全国第 1**(国家海洋局对口)
  - **中国石油大学(华东)** — **石油工程全国前 3**(中石油 / 中海油 校招主力)
- **儒家文化**:**曲阜师大**(曲阜)中文 / 历史 强,孔子故里
- **山东本省经济多元**:
  - **寿光蔬菜**(全国蔬菜枢纽)
  - **胶东工业**(青岛海尔 / 海信 / 青啤 / 烟台万华 / 潍坊潍柴动力)
  - **济南金融**(山东金融总部 + 浪潮 IT)
  - **能源化工**(中石化齐鲁石化 / 兖矿 / 山东能源)
- **山东考生 ~80w/年**(高考人数大省,跟河南 ~130w / 广东 ~80w / 四川 ~80w 同档,远超浙江 36w / 江苏 40w)

### 2. 选考组合 6 选 3 = 20 种(同浙江以外其他 3+3 省)

| 维度 | 山东 6 选 3 | 浙江 7 选 3 | 湖北 3+1+2 |
|---|---|---|---|
| 组合数 | **20 种** | 35 种 | 12 种 |
| 物理是否必选 | **否(可不选)** | 否 | 物理类必选 |
| 历史是否必选 | **否** | 否 | 历史类必选 |
| 技术科目 | 无 | 有(信息+通用) | 无 |
| 选考次数 | 1 次 | 2 次取最高 | 1 次 |

**影响**:**山东考生不选物理也能上理工科**(如选化生地 + 学计算机),但**部分顶级 985 工科要求必选物理**(限制减少灵活性)。**山大计算机 / 哈工威工科 / 中海大海洋工程 都要求物理**,**中石大油气工程要物理 + 化学双必选**。

### 3. 一段线下没有独立本科段(跟浙江不同!)

**山东最特殊**:**山东只有 2 段**(一段 = 本科批 / 二段 = 专科批),**一段没录的考生只能掉到二段(专科)**,没有"末段补救本科"的机制。

这意味着:
- **一段冲档失败 = 直接掉到专科段**,跟湖北/江苏一冲不中就慌的逻辑接近
- **影响推荐策略**:山东冲档要谨慎(不像浙江有二段补救本科),**冲稳保比例默认 1:2:5 而非 2:3:5 是合理的**

### 4. 山东考生留鲁率 70%+(全国前列)

- 济青烟 = 山东三大就业极
- **济南**:山东省政府 + 山东金融 + 浪潮 IT + 鲁能 / 山东能源 总部
- **青岛**:海尔 / 海信 / 青啤 / 中海大 / 中石大 / 哈工威 / 国家海洋局青岛站 / 青岛港 / 万华化学青岛基地
- **烟台**:万华化学 / 张裕 / 富士康烟台 / 烟台港
- **威海**:哈工威 / 山大威海 / 三角集团 / 威海港
- 山东考生**有较强本省偏好**(山东文化 + 留齐鲁照顾父母 + 体制内吸引力强),但跟浙江(留浙率 80%+)比略低
- **跟江苏的"留长三角"模式不同**:山东更纯粹是"留鲁",较少跨省到沪苏浙

### 5. 山东是考公大省(权重比浙江/江苏更高)

- 山东省考竞争烈,**省考报名人数全国前 3**(跟河南 / 广东同档)
- 山东人"考公文化"深入,体制内地位最高 — 比浙江私企导向 / 江苏均衡 更倾向考公
- **影响推荐**:山东考生考公意愿权重要额外加,**汉语言 / 法学 / 经济 / 会计 / 计算机** 等考公友好专业要主推

| 考生情况 | 选科建议 |
|---|---|
| 想读临床医学(山大齐鲁 / 青大医学院 等) | **必选化学 + 生物 + 物理**(主流要求) |
| 想读计算机 / 电子(山大 / 中海大 / 哈工威 / 中石大) | **必选物理,部分校还要化学** |
| 想读石油 / 油气工程(中石大华东) | **物理 + 化学 双必选** |
| 想读海洋科学 / 海洋工程(中海大) | **物理 + 化学 双必选** |
| 想读师范(山师大 / 曲阜师大 公费师范) | 选你想教的学科对应科目 |

| 想读基础学科(山大强基 / 中海大强基) | **物理 + 化学 + 数学方向**(强基要求) |

## 易错认知(agent 要纠正用户的)

- **"山东只有山大一所 985,所以志愿无悬念"** — 错。**山大 + 中海大(原 985 行业类,985 兼 211)+ 哈工威(985 + C9 牌子)** 都是 985 资源,加上 **3 所 211 + 海洋/石油 行业顶配**,山东高校层级很丰富
- **"山东没本一本二,直接看分数选学校"** — 错。**段次只是分数线划分**,具体院校投档分差距巨大,要看每个院校专业组的历年位次
- **"特控线 = 一本线 = 必须达到才能报本科"** — 错。**特控线只是特殊招生(强基/综评)的资格门槛**,过一段线就可以报本科批
- **"山东 96 个志愿可以乱填随便选"** — 错。**96 个志愿是冲稳保的精细化梯度**,要按 1:2:5 或 2:3:5 比例分布,不是随便选 96 个
- **"赋分制就是水分,实际原始分高才行"** — 半对。**赋分制是相对排名**,你的赋分高代表你在该科目排名靠前,不是水分;但**冷门科目赋分容易**(如政治)、**热门科目赋分难**(如物理),选科要考虑这个
- **"哈工威是哈工大本部分校,文凭一样"** — 半对。**哈工威是 985 牌子(同发哈工大文凭)**,但**录取分比本部低 30+ 分,师资 / 资源 是哈工大三大校区分配模式**,不能完全等同本部
- **"中海大就是地方海洋学院"** — 大错。**中海大是 985 + 211 + 双一流**,海洋科学全国第 1,国家级海洋研究主力

## 关键提醒(agent 必须强调)

1. **山东是 96 个志愿**(全国前列,要花时间精细分档)
2. **山东是分段录取不是分批次**(一段 / 二段),给用户明确判断标准
3. **特控线 vs 一段线**两条线意义不同(特控线是特殊招生门槛,一段线是本科线)
4. **选考赋分**(用户告诉你的分数都是赋分后,不是原始分)
5. **综合评价是山东本省独有路径**(山大 / 中海大 / 中石大 等多校参加,可能比统招分数低 10-20 分)
6. **山大 + 中海大 + 中石大 + 哈工威 = 山东 4 张顶级牌**,加上济青烟就业生态,**留鲁率 70%+** 是默认推荐方向
7. **一段冲档失败 = 直接掉到专科**(没有浙江式的中段补救),冲稳保要稳健一些
8. **山东考公竞争烈**,考公友好专业(汉语言 / 法学 / 经济 / 会计)要额外加权

## 山东 96 志愿冲稳保策略(给 agent 用)

**山东 96 志愿是全国前列**(浙江 80,湖北 / 江苏 45,河北 96)。但 96 志愿不是简单"填满 96 个",**核心是 1:2:5 或 2:3:5 的冲稳保比例**:

### 推荐分布(96 志愿,普通工薪 / 风险厌恶型)
- **冲档 12 个**(12.5%):比孩子位次高 1500-3000 名的院校专业组
- **稳档 24 个**(25%):比孩子位次高 0-1500 名 / 接近孩子位次的院校专业组
- **保档 60 个**(62.5%):比孩子位次低 1500-8000 名的院校专业组

### 推荐分布(96 志愿,中产 / 平衡型)
- **冲档 20 个**(20.8%):冲一些 985/211 + 头部专业组
- **稳档 30 个**(31.3%):稳的 211 + 强双非
- **保档 46 个**(47.9%):安全保底的双非综合

### 推荐分布(96 志愿,激进型)
- **冲档 30 个**(31.3%):冲名校 + 王牌专业
- **稳档 30 个**(31.3%):稳的好学校 + 主流专业
- **保档 36 个**(37.5%):保底足够即可

**山东 96 志愿的关键陷阱**:
- 96 志愿不是"无限尝试" — 一冲不中直接掉二段(专科),所以保档绝对不能少于 30 个
- 山东本省院校专业组分得很细(山大本部一个学校就能拆出 10+ 个专业组)— 不要一所学校刷 10 个组,**分散到不同学校 + 不同方向**

## 山东综合评价 / 强基计划 / 国家专项 详解

### 综合评价(山东本省独有 + 北京 / 浙江 / 上海 模式)
- **执行高校**:山大(本部 / 青岛 / 威海)/ 中海大 / 中石大(华东) / 哈工威 / 山师大 / 山农大 / 青大 / 山东中医药大学 等
- **录取规则**:**高考分(60-85%)+ 校测(15-30%)+ 学考(5-10%)**
- **意义**:**比统招分数低 5-15 分**(山大综合评价比裸分低约 10 分)
- **门槛**:过特控线 + 学考成绩好(全 A 优先)+ 校测面试通过
- **适合**:**山东顶尖高中生**(山东实验 / 济南外国语 / 青岛二中 / 烟台一中 等)+ 学考全 A + 想冲山大但裸分边缘的考生

### 强基计划(山大 / 中海大 有)
- **山大强基**:数学 / 物理 / 化学 / 生物科学 / 中国语言文学 / 历史学 / 哲学 / 古文字学
- **中海大强基**:海洋科学(独家)
- **特殊**:**强基只能填 1 所**;**直博绑定**(本研衔接);**不能转专业**;**比裸分低 5-15 分**
- **适合**:**笃定学术 + 数学 / 物理 / 化学 单科 130+ + 接受直博绑定** 的考生

### 国家专项 / 高校专项
- **山东农村户籍考生** 在 山大 / 中海大 / 中石大 / 哈工威 / 山农大 等高校有专项指标
- **录取分**:**比统招低 20-30 分**
- **影响**:农村家庭逆袭神器,**毕业不限服务地区(高校专项)** / **毕业服务原籍 / 农村基层(国家专项部分项目)**

## 山东 6 选 3 选科常见组合 + 优劣势(针对 2026 届及之后)

| 组合 | 可报专业覆盖率 | 学习难度 | 赋分难度 | 推荐人群 |
|---|---|---|---|---|
| 物理 + 化学 + 生物("理化生") | 96%+ | 高 | 中(物理化学卷) | 学医 / CS / 工科 |
| 物理 + 化学 + 地理 | 95%+ | 中高 | 较易(地理赋分宽) | 工科 + 想避开生物背诵 |
| 物理 + 化学 + 政治 | 90%+ | 中高 | 政治赋分较易 | 工科 + 想考公考研便利 |
| 物理 + 历史 + 政治 | 70%+ | 中 | 文科赋分较易 | 想读法学 / 文科 + 留物理选项 |
| 历史 + 政治 + 地理("文综") | 50% | 较低 | 较易 | 笃定文科考公 / 师范 / 法学 |
| 化学 + 生物 + 地理 | 60% | 中 | 较易 | 不喜欢物理但要保留化学专业 |

**山东 3+3 是 6 选 3 不是 3+1+2**,**不强制选物理或历史 但要看专业要求**:
- 山大临床八年制 / 中海大海洋 / 中石大油气 / 哈工威工科 → **物理 + 化学 双必选**
- 山大数学英才 / 中海大海洋科学(基础) / 中石大化工 → **物理必选**
- 警察 / 公安 / 思政 → **政治必选**
- 师范类(对应学科)→ 选你想教的学科

**山东 6 选 3 跟湖北 3+1+2 / 浙江 7 选 3 的区别**:山东可以"完全文科"(历史 + 政治 + 地理)能上很多专业;湖北物理 / 历史 二选一更硬性

## 关键提醒(再强调)

1. **山东 96 志愿冲稳保比例 1:2:5 是工薪家庭默认安全比例**(不要因为 96 志愿多就乱冲档)
2. **特控线 ≠ 一本线**(特控线是强基 / 综评门槛;一段线才是本科线)
3. **赋分不是水分** — 你的赋分高代表该科目排名靠前,但要注意冷门科目赋分容易 / 热门科目赋分难
4. **山东考公专业权重要额外加** — 汉语言 / 法学 / 经济 / 会计 / 公安专业 在山东推荐里要主推
5. **"留鲁"是山东家长隐性 anchor** — 推荐方案要尊重这个 anchor(尤其是工薪家庭),不要按"分数最大化"硬推外省 985
