# 用户意向冲突 — Reality Check 金句库(山东视角)

很多家长 / 考生有具体的意向("想上山大"、"非青岛不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

**山东版特殊性**:山东家长 / 考生有几个高频"意向 anchor",agent 必须特别识别 + 处理:
1. **"非山大不上"** — 山东全省唯一 985,本省考生执念极重
2. **"非青岛 / 济南不去"** — 留鲁 + 留大城市,工薪家庭最常见
3. **"必须考公 / 进编制"** — 儒家文化 + 体制内偏好,常常压过孩子兴趣
4. **"孩子要稳定不要折腾"** — 工薪家长对 CS / 创业 / 出国 系统性抵触

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **山东工薪家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对工薪家庭抗风险能力差,要硬讲清楚
6. **山东家庭对"留鲁 + 编制"的隐性 anchor** 必须 surface 出来,然后跟客观最优方案做对比,让家长自己权衡

---

## 4 类意向冲突 + 金句模板(山东本地化)

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 500 分要清华 / 580 分要山大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [山东 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(山东 580 分 物理类,意向山大本部)**:
> "山大本部主流组在山东物理类省排 4500-8000 名内。你 32450 名,差 2.5 万名,**山大本部没戏**。
>
> 但你能上山大威海校区(985 牌子,文凭注明威海)+ 中石大(华东)+ 山科大 + 青大 — 这几所留鲁就业,**山东本地国企 / 体制内招聘里跟山大本部冷门组校友地位差不多**(都是'山东 985/211 + 留鲁同档')。"

**真实案例(山东 600 分 物理类,意向清北)**:
> "清北在山东物理类要省排 80 名内。你省排 8000 名,差 7900 名,**清北是不可能**。但你能稳上山大本部 + 哈工威 + 中海大,**省内 985 牌子全到位**;想冲外省名校就报中央财大 / 北航 / 同济 / 西交 这一档,**对应你这位次正好**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学 / 历史]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(山东理工 + 工薪家庭)**:
> "山大本部你 8000 名能擦 — 但只能进生命科学 / 草学 / 化学 / 材料 这几个组。**985 牌子 + 生化环材** = 双重坑(本科出口窄 + 必须读博才有戏)。
>
> 同分能上的中海大水产 / 中石大化工(同样 985/211,但行业对口央企稳)出来对口程度更高。**冲山大留一个心理慰藉位即可,主推中海大或中石大主流组**。"

**真实案例(山东 615 分,意向山大本部 但只能进冷门)**:
> "山大本部 615 分 + 山东物理类历史类 都吃力,大概率只能进哲学 / 历史 / 古文献 / 生化环材 这一档。
>
> 但你父母最看重的'山大牌子',**山大威海校区文凭也写'山东大学'**(只是注明威海),你冲威海校区计算机 / 法学 / 经济 这种主流组,**985 牌子 + 主流专业 + 留鲁就业** 三件套全到位,比山大本部冷门组香 100 倍。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [山大齐鲁医八年制])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(山东工薪家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k**。山东工薪父母还要供 8 年。
>
> 撑得起 → 推山大齐鲁医学院 / 青大医学部临床,长期天花板高(齐鲁医院主任医师退休年薪 60-100w)。
>
> 撑不起 → **建议滨州医学院 / 潍坊医学院 医学影像技术(4 年本科直接进三甲技师岗,起薪 7-9k,早 4 年挣钱)**,或者放弃临床走山师汉语言公费师范这种本科直接编制的赛道。"

**真实案例(山东农村家庭 + 想读博走学术)**:
> "你说想读博走学术 — 山东农村家庭撑得起吗?博士 4 年 + 期间无收入 + 30 岁后才能进高校 / 科研院所 + 高校教职竞争极卷。
>
> 客观说不可能。**改路径:山师汉语言公费师范 → 4 年后回县中学语文老师编制**;有机会就业后读在职硕士 / 博士。'稳定就业 + 在职深造'是山东农村家庭跑学术路径的唯一可行方案。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"(山东高频)

**特征**:用户只想留某个城市("非济南不去" / "非青岛不去" / "非山东不去"),拒绝出省 985。**山东这种 anchor 出现频率全国最高**(山东人留鲁倾向极强)。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留济南没意义,要去西工大),**要灵活退一步**。"

**真实案例(山东 + 非济南不去 + 600 分理科)**:
> "你只留济南,这位次 1.2 万,山大本部主流组够不上。
>
> **留济南最稳路径**:山东师范大学(山师汉语言 / 数学公费师范 / 师范类)+ 山东财经大学(财税 / 会计)+ 山东建筑大学(建筑 / 工程类),这一档济南 211 / 强双非全在 1.2 万位次内可达。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大 / 西部某 985 冷门组 — 牌子有了但**人脉断了 / 实习机会少了 / 留济南竞争力反而低**,综合不划算。"

**真实案例(山东 + 非青岛不去 + 580 分理科)**:
> "你只留青岛,这位次 3 万,中海大本部主流组够不上(中海大主流组在 1.5 万内)。
>
> **留青岛最稳路径**:中石大(华东)主流组(石油 / 化工 / 储运)+ 青岛大学(医学 / 师范 / 计算机)+ 山东科技大学(电气 / 矿业 / 计算机)+ 山东大学(青岛校区)冷门组。**这一档 211 + 强双非 全在 3 万位次内可达**,留青岛就业生态成熟。
>
> 别为了'外省 985'去东北 / 西部 985 冷门组 — 毕业回青岛没竞争力。"

**真实案例(山东 + 非山东不去 + 顶级理科生)**:
> "你 660 分 + 省排 800,清北复交都够,但'必须留山东' = 只能选山大本部 / 中海大主流组。
>
> **客观说**:这分留山东就是浪费。山东留鲁就业天花板比上海 / 北京 / 深圳 低一档,**清北复交毕业回山东都是 VIP 待遇**。
>
> 但如果你父母 anchor 是'家里独子不放出去 + 山东体制内有资源' — 那 山大齐鲁医学院八年制 / 山大数学英才 / 山大法学选调 是合理选择,**起点高 + 留鲁就业生态对口**,客观损失 20% 上限但满足家庭 anchor。**家长要明白这是用 20% 上限换 100% 安心,值不值你们决定**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 山东特殊高频意向 anchor + 处理

### Anchor 1:"必须留鲁"
- **识别信号**:家长说"孩子离家近一点"/"独生子不能跑太远"/"山东不愿意出省"
- **处理**:
  - 分够清北复交 → reality check:留鲁损失多大值不值
  - 分够山大本部主流组 → 满足留鲁
  - 分够中海大 / 中石大 / 哈工威 → 满足留鲁 + 985/211 牌子
  - 分够山东双非 → 推山师 / 曲师 / 山财 / 山科 等留鲁性价比之选

### Anchor 2:"必须考公 / 进编制"
- **识别信号**:家长说"求稳定"/"不挑级别就要编制"/"父母都是公务员"
- **处理**:
  - 分够 985/211 → 山大法学 / 汉语言 + 选调路径
  - 分够双非一本 → 山师 / 曲师 / 山财 + 公考路径
  - 分够二本 → 曲师 / 山东警察学院 / 滨州医学院医学技术 + 编制路径
  - **绝对避开**:CS / 金融头部 / 创业 / 出国(跟 anchor 完全冲突)

### Anchor 3:"必须山大"(山大本部执念)
- **识别信号**:家长说"山东就这一所 985,孩子必须上"
- **处理**:
  - 分够山大本部主流组 → 满足
  - 分边缘冷门组 → 双轨推荐(山大冷门组 vs 中海大 / 哈工威 主流组)+ 让家长权衡
  - 分不够 → 推山大威海校区(985 文凭注明威海)+ 哈工威(985 牌子)双备选

### Anchor 4:"想做大事 / 不想考公"
- **识别信号**:孩子说"想做生意"/"想出国"/"想做研发",但家长是体制内
- **处理**:
  - 这是**孩子 anchor vs 家长 anchor 的冲突**,需要 agent 帮孩子说话
  - 给出"双轨推荐":轨道 1 是孩子 anchor(山大 CS / 商科 / 出国);轨道 2 是家长 anchor(山大法学 / 公费师范 / 考公)
  - **明确写出代价**:走孩子路径 → 孩子开心 + 父母 5 年焦虑;走家长路径 → 父母安心 + 孩子可能 30 岁后悔
  - 让家长 + 孩子一起在双轨之间选,不要 agent 替家庭决定

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 山大 / 想学医 / 想留济南 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**山东特别提醒**:山东家长的 anchor 通常比其他省更顽固("留鲁"+"考公"+"山大"三连锚),agent 不能怕得罪家长就不做 reality check。**不做 reality check 等于把孩子推进火坑,家长 5 年后会回来骂你**。
