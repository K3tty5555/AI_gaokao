# 铁路 / 航空 / 旅游(四川专科)

## 核心结论

**这三个行业放一起讲,因为它们都是"四川作为西南交通枢纽 + 文旅大省"的产业红利**,而且对四川专科生**留省发展 + 进国企 / 央企 / 体制内** 都有专属通道。

| 方向 | 主要出口 | 起薪 | 编制 | 适合 |
|---|---|---|---|---|
| **铁路类** | 国铁成都局 / 地铁成都 / 中铁中铁建 西南分公司 | 5-8k | 多有 | 男 / 部分女(乘务) |
| **航空类** | 国航西南 / 川航 / 双流机场 / 天府机场 | 4-7k | 部分有 | 形象好的男女均可 |
| **旅游 / 文旅** | 文旅集团 / 景区国企 / 酒店集团 / 文化公司 | 3.5-6k | 部分有 | 文科生 / 服务意识强 |

**对四川专科生的特殊价值**:
- 国铁成都局是**全国最大的铁路局之一**,辖管川渝黔三省一市,**专科招聘量大**
- 双流 + 天府是中西部最大双机场,**地勤 / 安检 / 空乘 / 货运 都对专科开放**
- 四川文旅大省(九寨沟 / 峨眉山 / 都江堰 / 大熊猫 / 三星堆 / 稻城亚丁),**文旅集团 / 景区国企 招专科生做服务 / 解说 / 运营**

## 一、铁路类:国铁成都局 + 城市地铁

### 真相
- **国铁集团成都局** 每年招聘量大,辖管成都 / 重庆 / 贵阳 / 昆明部分 / 西安部分铁路
- 工作岗位:**列车员 / 机务段(司机助理 → 副司机 → 司机) / 工务段(铁路线维护) / 客运 / 调度 / 通信信号**
- **成都地铁集团**:成都地铁线网全国前列,招聘大量专科生做站务员 / 安检 / 司机
- **中铁中铁建西南分公司**:做西部铁路工程施工,吸纳专科铁路工程类毕业生

### 适合什么人
- **男生**(铁路一线大多数岗位需要男性)
- **接受出差 / 跑车 / 三班倒 / 半军事化管理**
- **女生**:适合做客运乘务 / 票务 / 站务岗(高铁乘务员有形象要求)
- 不怕辛苦 / 体力工作

### 真实薪资(四川 2024 大致区间)
- 成都局 一线工人:5-7k 起,5 年后 8-11k
- 成都地铁站务员:5-6k 起 + 三班倒补贴
- 高铁列车员:5-7k 起 + 餐补 + 公积金
- 工务段(轨道维护):6-9k 起,有夜班

### 推荐院校
- **成都铁路工程学校** — 注意是中职,不是高职,慎选
- **四川铁道职业学院** — **成都铁路局对口主力学校**(校招就是回家)
- **成都工业职业技术学院** — 城轨方向(对口成都地铁)
- **四川交通职业技术学院**(成都温江)— 综合交通类强校,**成都地铁主供给学校之一**

### 关键证书
- 进铁路:**普通话证书 + 铁路通信信号 / 行车 类证书**
- 进地铁:**普通话 + 城轨从业证 + 体能要求过关**(身高 / 视力 / 色盲)

### 关键提醒
- 铁路行业属于半军事化管理,**纪律性要求高**(迟到 / 缺勤直接处分)
- 一线工人岗 5-10 年后晋升机会有限,**想做管理岗需要本科**(可走专升本)

## 二、航空类:川航 + 双流 / 天府机场

### 真相
- **国航西南分公司**(总部成都) — 全国国航四大基地之一,招专科生做地勤 / 货运 / 维修助理
- **四川航空(川航)** — 总部成都,主基地双流 + 天府,**专科空乘是川航主要招聘来源**
- **成都双流国际机场 + 天府国际机场** — 中西部最大双机场,**地勤 / 安检 / 货运 / 维修 / 后勤** 招大量专科生
- **西南航空货运 / 顺丰航空成都基地** — 货运方向

### 适合什么人
- **形象气质好** 的男女(空乘 / 地勤 / 安检都有形象要求)
- **能接受倒班 + 高强度站立工作**(机场地勤一站 8-10 小时)
- **空乘**:身高 / 体重 / 视力 / 五官 / 普通话 / 英语都有要求
- **机务维修**:数物较好的男生,需要钳工 / 电工基础

### 真实薪资(四川 2024 大致区间)
- 川航空乘:6-10k 起(含飞行小时费),国际航班更高
- 川航地勤 / 安检:4-6k 起 + 餐补 + 倒班补
- 双流 / 天府机场地勤:4-5k 起
- 飞机维修助理:5-8k 起

### 推荐院校
- **四川西南航空职业学院**(成都) — **川航 + 国航西南 对口最强学校**,**民办但是行业强校**(注意:这是少数值得选的民办)
- **四川航天职业技术学院** — 航天方向(对口航天科技集团 7 院,不是民航)
- **成都航空职业技术学院** — **公办,航空机务对口主力**,主供国航 / 川航 / 成飞维修
- **四川交通职业技术学院** — 综合交通,部分专业对口民航

### 关键证书
- 空乘:**英语等级 + 体检 + 普通话 + 形象筛选**
- 机务:**民航维修执照(M / 1 / 2 部件签字资格)**,在校期间考起步证

### 关键提醒
- **空乘是吃青春饭**,30 岁后大多数会转岗地勤 / 行政
- **机务维修才是吃技术 + 寿命长** 的赛道,起薪 5-8k,工作 10 年能到 1.5-2w

## 三、旅游 / 文旅:四川大省红利

### 真相
- **四川是文旅大省**(九寨沟 / 峨眉山 / 都江堰 / 青城山 / 乐山大佛 / 稻城亚丁 / 三星堆 / 大熊猫 / 武侯祠 / 宽窄巷子)
- **峨眉山旅游股份(上市)/ 九寨沟管理局 / 都江堰文旅集团 / 成都文旅集团 / 西岭雪山** 等都招专科生做运营 / 解说 / 服务 / 营销
- **成都酒店业**(锦江 / 希尔顿 / 万豪等)— 招专科生做前台 / 礼宾 / 餐饮服务
- **大熊猫国家公园 + 大熊猫繁育研究基地** — 招少量解说员 / 后勤

### 适合什么人
- **服务意识强 + 形象气质好** 的男女(尤其女生)
- **接受工作环境分散**(可能在景区 / 酒店 / 文创公司轮岗)
- **小语种能力 +** 是加分项(峨眉山 / 九寨沟有大量日韩 / 东南亚游客)

### 真实薪资(四川 2024 大致区间)
- 景区运营 / 解说员:3.5-5k 起(底薪低 + 旺季提成)
- 五星酒店前台 / 礼宾:4-5k 起 + 服务费分成
- 文旅集团运营岗:4-6k 起(有编制的 4-5k,无编制可达 6k+)
- 旅行社 / 旅游电商:3-5k 起 + 业绩提成

### 推荐院校
- **四川旅游学院** — **本科**,但其专科部分对口最强,主供文旅集团 / 高端酒店
- **成都纺织高等专科学校** — 旅游 / 酒店管理专业有特色
- **四川商务职业学院** — 旅游 / 会展方向
- **峨眉山旅游学校 / 九寨职业学校** — 中专,慎选(高职选项请选成都本部)

### 关键证书
- **导游证(全国通用)**
- **酒店管理类**:外语能力(英语 / 日语 / 韩语)
- **会展专业**:活动策划 + 项目管理

### 关键提醒(旅游业的真相)
- **旅游业整体偏卷,起薪低 + 季节性强**(旺季忙死 + 淡季工资低)
- **如果不进文旅集团编制 / 大型酒店,纯做小旅行社 = 坑**
- **新冠后旅游业刚恢复,但岗位质量参差不齐**,要挑大平台
- **旅游专业出来不一定做旅游**,很多人转行做销售 / 会展 / 文创

## 四、决策映射(给 agent 用)

| 用户情况 | 推荐方向 |
|---|---|
| 男 + 留川 + 求编制 + 接受三班倒 | **铁路类**(四川铁道职院) → 国铁成都局 |
| 男 + 想进地铁 | **四川交通职院 / 成都工业职院** 城轨方向 → 成都地铁 |
| 形象好 男女 + 想飞 | **四川西南航空职院** 空乘方向 → 川航 / 国航西南(注意吃青春饭) |
| 男 + 数物好 + 想长期飞机维修 | **成都航空职业技术学院** 机务方向 → 国航 / 川航 / 成飞 维修岗 |
| 想留景区 / 文旅 / 服务行业 | **四川旅游学院 / 成都纺专 / 川商职院** 旅游酒店类 → 文旅集团 / 高端酒店 |
| 女 + 想做空乘但分数低 | **西南航空职院** 空乘 → 注意学费贵(民办)+ 行业天花板低 |
| 想专升本 + 留交通系统 | 选**铁道工程 / 交通运输** → **西华大学 / 西南民大** 升本 |

## 五、专升本路径

### 铁路类
- 对口专业:**交通运输 / 物流管理 / 铁道工程**
- 接收公办:**西华大学 / 西南民族大学 / 成都信息工程大学**(部分)
- **西南交通大学不接收专升本**
- 升本后优势:进铁路局管理岗 / 调度员(纯一线工人难晋升,本科可)

### 航空类
- 对口专业:**交通运输 / 飞行器制造工程 / 民航服务**
- 接收公办:**西华大学 / 中国民航飞行学院**(成都广汉,部分)
- 升本后优势:从机务工人 → 助理工程师

### 旅游类
- 对口专业:**旅游管理 / 酒店管理 / 会展经济与管理**
- 接收公办:**四川旅游学院 / 西华大学 / 成都大学**
- 升本后优势:进文旅集团管理岗 / 高端酒店管培生

## 六、典型 case

### Case A:四川铁道职院进国铁成都局
- 凉山农村男生 → 360 分(物理类) → 报**四川铁道职业学院 铁道运输**
- 大学 3 年:专业绩点稳 + 普通话证 + 体测过关 + 实习去成都局
- 毕业:**校招进国铁成都局工务段,起薪 6k + 编制 + 公积金 + 餐补 + 高原补贴(部分线路)**
- 工作模式:跟着铁路维护班跑铁路线,户外 + 三班倒,**辛苦但稳定**
- 5 年后晋升班长:月薪 8-10k

### Case B:川航空乘成功路径(吃青春饭)
- 成都女生(身高 168,形象好) → 320 分(历史类) → 报**四川西南航空职院 空乘**
- 大学 3 年:形象训练 + 英语 + 服务礼仪
- 毕业:**校招进川航,空乘 5 年,月薪 8-12k(含飞行费)**
- **30 岁后转岗地勤,月薪 6-7k,稳定但工资天花板低**
- **注意学费**:民办高职,3 年学费 + 形象训练投入约 6-8w

### Case C:成都航空职院机务路径(长寿命)
- 自贡男生 → 400 分(物理类) → 报**成都航空职业技术学院 飞机机电设备维修**
- 大学 3 年:民航维修执照备考 + 实习成飞 / 国航西南
- 毕业:**进国航西南维修车间助理,起薪 6k + 五险一金**
- 工作 10 年:拿全部维修执照,**月薪 1.5-2w**(机务是技术工人吃寿命的赛道)

### Case D:文旅集团运营成长路径
- 雅安女生 → 350 分(历史类) → 报**四川旅游学院 旅游管理(专科)**
- 大学 3 年:导游证 + 英语 + 实习峨眉山旅游
- 毕业:进峨眉山旅游股份做运营助理,起薪 4k + 旺季奖金
- 工作 5 年:晋升运营经理,月薪 7-9k

### Case E(失败):民办空乘+没飞成
- 绵阳家庭 → 280 分 → 报某民办高职"航空服务"专业(学费 1.5w / 年)
- 大学 3 年:学校跟航空公司没合作,空乘面试失败
- 毕业:只能去机场地勤外包公司,起薪 3.5k
- **5 万学费没换到飞机舱里**,如果选公办职院学其他专业更稳

## 七、易错认知

- **"铁路就是开火车"** — 错。**机务段开火车要求高(身高 / 体能 / 视力)**,专科生主要做工务 / 客运 / 调度
- **"成都地铁好进"** — 半对。**站务员 / 安检员 招聘多但薪资不高**,司机岗有体测要求
- **"空乘飞 10 年退休"** — 错。**空乘没退休,30-35 岁后大多数会被劝退或主动转岗**,要早做规划
- **"机务维修又脏又累"** — 真,但**寿命长 + 薪资曲线好**,40 岁还能做
- **"旅游专业出来就是导游"** — 错。**导游只是入门岗,真正的出路是文旅集团运营 / 酒店管培生 / 会展策划**
- **"四川航空学校都好"** — 错。**只有成都航空职院 + 西南航空职院** 有行业认可度,其他打着"航空"招牌的民办大多坑
- **"专科空乘比专科其他薪资高"** — 半对。**飞行期高 + 失业风险高 + 转岗难**,综合算性价比未必更好
- **"文旅是夕阳行业"** — 错。**四川文旅消费持续增长,但要选大型平台(文旅集团 / 上市公司),小旅行社才是夕阳**
- **"国铁成都局有编制就稳"** — 真,但**编制岗也分核心 / 边缘**,核心岗(调度 / 司机)难进,边缘岗(车站清洁 / 食堂)虽然有编但没意义
