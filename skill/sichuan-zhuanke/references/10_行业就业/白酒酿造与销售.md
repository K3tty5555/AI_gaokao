# 白酒酿造与销售(四川专科)

## 核心结论

**这是四川独有的专科出口,其他省没法照搬**。逻辑:四川是中国白酒主产区(全国 60%+ 产能集中在川南),五粮液(宜宾) / 泸州老窖(泸州) / 郎酒(古蔺) / 剑南春(绵竹) / 沱牌舍得(射洪) / 水井坊(成都) 这一圈大厂每年招大量专科生做**酿造工 / 制曲工 / 包装 / 质检 / 销售 / 物流**,本地家庭里"父亲在厂里上班,儿子高考完进厂接班" 是普遍现象。

**适合的考生**:
- 川南(宜宾 / 泸州 / 古蔺 / 自贡 / 内江)本地家庭
- 父辈在白酒厂上班,有内推 / 接班资源
- 接受车间体力工作 + 三班倒 + 酒糟气味
- 不打算留成都,想留本地的考生

## 一、四川白酒大厂速查

| 厂家 | 地点 | 性质 | 专科主要岗位 |
|---|---|---|---|
| **五粮液集团** | 宜宾 | 国企(混改) | 酿造 / 制曲 / 包装 / 销售 / 物流 / 行政 |
| **泸州老窖** | 泸州 | 国企(部分上市) | 酿造 / 制曲 / 销售 / 包装 |
| **郎酒** | 泸州古蔺县 | 民企(汪俊林) | 酿造 / 销售 / 行政 |
| **剑南春** | 绵竹 | 国企(改制) | 酿造 / 包装 / 销售 |
| **沱牌舍得** | 射洪 | 上市公司 | 酿造 / 销售 |
| **水井坊** | 成都邛崃 | 外资(帝亚吉欧) | 酿造 / 高端销售 |
| **丰谷 / 江口醇 / 文君酒 / 等中小厂** | 川内各地 | 民企 / 国企 | 各类基层岗 |

**共同点**:
- 大多是**本地国企或老牌民企**,在当地就是"铁饭碗 + 人脉中心"
- **专科起薪 4-6k**,**有内推家庭背景能进核心车间或销售**
- 工作环境:**车间高湿度 + 酒糟气味 + 三班倒(连续发酵车间)**,接受度因人而异
- **销售岗薪资可冲 8k-1.5w**,但要求接受频繁出差 / 应酬

## 三、推荐院校梯队(四川白酒方向专科)

### 第一梯队:对口最深的本地院校
- **宜宾职业技术学院** — **五粮液对口主力**,部分专业是"五粮液订单班",入学就内定进厂
- **泸州职业技术学院** — **泸州老窖 + 郎酒 对口主力**,本地强校
- **四川轻化工大学**(自贡)— 严格说是本科,但其食品 / 酿酒类专业是川南酒企最对口的升本路径(专升本走这里)

### 第二梯队:绵阳 / 成都辐射
- **四川工程职业技术学院**(德阳)— 食品类专业对口剑南春 / 成都酒企
- **绵阳职业技术学院** — 食品方向,对口绵竹剑南春
- **成都农业科技职业学院** — 食品科技,对口成都各酒企

### 第三梯队:综合性高职
- **南充职业技术学院 / 内江职业技术学院 / 自贡职业技术学院** — 综合性,本地酒企有定向招聘但量小

### 关键提醒
- **优先选择"订单班 / 校企合作班"**,这种班入学时已经跟酒厂签了协议,毕业直进
- 没有订单班的话,**优先川南本地高职**,实习能去酒厂

## 四、决策映射(给 agent 用)

| 用户情况 | 推荐方向 |
|---|---|
| 宜宾本地 + 父辈在五粮液 | **宜宾职院 酿酒技术 / 食品生物技术** → 五粮液车间 |
| 泸州本地 + 父辈在泸州老窖 | **泸州职院 酿酒技术** → 泸州老窖 / 郎酒 |
| 绵竹本地 / 想进剑南春 | **绵阳职院 食品类 / 川工程职院** → 剑南春 |
| 川南家庭 + 没父辈资源 + 想吃酒厂红利 | **宜宾职院 / 泸州职院 订单班**(没订单班选普通班 + 实习冲) |
| 想做销售 + 接受出差应酬 | 任意高职 **市场营销** + 主动找酒企销售实习 → 五粮液 / 泸州老窖 渠道 |
| 想留成都 + 想做白酒 | **成都农业科技职院 食品类** → 水井坊 / 邛崃酒企 / 高端酒销售 |
| 求专升本(食品方向) | **四川轻化工大学** 升本(自贡,食品 / 酿酒主力) |

## 五、专升本路径(白酒类)

### 对口本科专业
- **食品科学与工程 / 食品质量与安全 / 生物工程 / 酿酒工程**
- 主接收:**四川轻化工大学**(自贡,**白酒类升本第一选**)
- 其他:**西华大学 / 宜宾学院 / 成都大学**

### 升本后优势
- 进酒厂技术管理岗(车间副主任 / 工艺主管 / 质量经理)
- 起薪从 5k 跳到 7-9k
- **本科 + 食品工程师证 + 酒厂工作经验** = 35 岁前能做到中层管理
- **能考公**(四川省 / 市食品药品监督管理岗位对食品类专业有要求)

## 六、销售岗的特殊路径(高薪高压)

### 真相
- 白酒销售岗薪资**远高于车间技术岗**,但要求高
- **典型路径**:专科市场营销 → 进五粮液 / 泸州老窖 经销商体系 → 做区域业务员 → 升经销商支持 → 自己做经销商
- **薪资曲线**:起薪 4-5k(底薪低,有提成) → 工作 3 年能到 8-12k → 做到经销商可冲年入 30w+

### 适合什么人
- **能喝酒 + 会应酬 + 抗压强**(销售必备)
- **有经销商 / 商超 / 餐饮渠道资源** 的家庭(父辈做生意 / 餐饮 / 商超)
- **能接受 70% 时间出差** 的人

### 不适合
- 内向型 + 不喝酒 + 不会应酬 — 直接 pass
- **agent 必须明确告诉用户**:**白酒销售岗 = 高薪 + 高压 + 应酬重 + 健康代价**,选之前想清楚

## 七、典型 case

### Case A:宜宾本地子承父业
- 宜宾翠屏区男生,父亲是五粮液车间班长 → 高考 320 分(物理类) → 报**宜宾职业技术学院 酿酒技术**(订单班)
- 大学 3 年:稳学习 + 父亲内部引荐
- 毕业:**直接进五粮液包装车间技术员,起薪 5k + 五险一金 + 食堂宿舍**
- 工作 5 年:**晋升班长,月薪 8-10k + 双职工福利**
- **典型川南家庭跨代稳定**

### Case B:川东走郎酒销售路径
- 古蔺县男生 → 290 分(历史类) → 报**泸州职业技术学院 市场营销**
- 大学 3 年:绩点一般,但参加郎酒经销商体系实习
- 毕业:进郎酒成都区域办做销售助理,起薪 4k + 提成
- 工作 3 年:做到区域业务经理,月薪 1-1.5w + 年终
- 工作 5 年:**自己开了郎酒经销商分销点,年入 25w+**

### Case C:专升本走食品工程
- 自贡女生 → 350 分 → 选**自贡职业技术学院 食品检测技术**
- 大学 3 年:绩点稳 + 备考专升本
- 大三:升上**四川轻化工大学 食品质量与安全**(本部就在自贡)
- 升本毕业:**进泸州老窖 质量管理部,起薪 7k + 五险一金**
- **走的是技术管理岗,不是销售岗,稳但工资曲线慢**

### Case D(慎选):没资源进民营小酒厂
- 内江工薪家庭 → 280 分 → 报某综合高职"食品营养与检测"
- 没考虑订单班 / 实习 / 家庭资源
- 毕业:进川内某中型民营酒厂做质检,起薪 3.5k,**民营厂福利差 / 无社保 / 加班严重**
- **教训**:白酒类专科生**必须依托校企对口或家庭资源,纯靠简历投递进民营小厂是坑**

## 八、易错认知

- **"白酒夕阳产业,不要学"** — 错。**川酒是国家级支柱产业,五粮液 / 泸州老窖 是中国国企里最赚钱的一批**。年轻人少了不代表行业没了
- **"酿造工就是体力工"** — 半对。**基础岗确实是体力 + 三班倒**,但**有专科学历 + 工作 5 年 = 能晋升技术管理岗**
- **"白酒厂招聘看关系"** — 真,但**订单班 / 校企对口班 + 绩点高 + 有食品工程师证** = 没关系也能进
- **"销售岗就是陪喝酒"** — 半对。**核心销售确实要应酬,但区域协调 / 渠道管理 / 电商运营 这些岗位应酬少**
- **"白酒销售比技术工资高"** — 真,但**销售压力大 + 不稳定**,**技术岗稳但慢**
- **"五粮液 / 泸州老窖 是国企铁饭碗"** — 半对。**五粮液混改后 + 泸州老窖部分上市,核心岗位有编制属性,但合同制岗位也很多**
- **"郎酒最好"** — 错。**郎酒是民企,薪资和销售业绩强相关;五粮液 / 泸州老窖 国企背景更稳**
- **"白酒行业不需要学历"** — 错。**车间班长以上必须本科**,所以**专升本对白酒行业晋升非常关键**
