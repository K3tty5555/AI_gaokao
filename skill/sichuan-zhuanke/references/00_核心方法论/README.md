# 四川专科 skill 核心方法论

## 一、四川专科和别的省专科,差在哪

做四川专科咨询前,agent 必须先在脑子里建立这几条**只属于四川**的判断线:

### 1. "留川"是默认设定,不是选项
- 湖北家长接受孩子去广深 / 长三角打工,河南家长甚至鼓励孩子出省
- **四川家长(尤其成都 / 绵阳 / 德阳)默认孩子毕业留省**,这种默认极强
- 推理含义:推荐专科专业时,**行业出口必须能落在四川境内**。一个孩子学物流管理想去义乌的,在四川家庭里是少数派
- 反过来,**川南川北 / 藏彝区** 孩子家长反而更容易接受去成都打工(从乡到省会算"留川")

### 2. 成绵德 vs 川南川北 vs 藏彝区,是三个不同世界
- **成绵德经济圈**(成都 / 绵阳 / 德阳):电子信息 / 装备制造 / 软件外包 / 服务业,专科出口在城市服务岗 + 工厂技术工
- **川南川北**(自贡 / 攀枝花 / 泸州 / 宜宾 / 南充 / 达州):资源型城市 + 化工 / 白酒 / 钢铁 / 天然气,专科出口在本地国企央企
- **藏彝区**(凉山 / 阿坝 / 甘孜):基层公务员 / 教师 / 卫生院,专科出口靠回乡编制 + 民族专项
- **不能套同一个推荐模型**

### 3. 四川独有的产业出口
- **白酒**:五粮液(宜宾)/ 泸州老窖 / 郎酒(古蔺)/ 剑南春(绵竹)— 这是其他省没有的专科出口
- **电子信息辅助岗**:电子科大 + 成都华为 / 京东方 / 富士康 / 极米 / TCL 形成的产业带,招大量专科技术工人 / 测试 / 物料
- **航空航天**:中航工业(成飞 / 成发)、成都飞机工业集团,专科生可以做装配 / 钣金 / 机务
- **军工**:绵阳是中国科技城,九院(中物院)+ 长虹 + 一系列三线企业,招专科技工
- **文旅**:四川是文旅大省,九寨沟 / 峨眉山 / 都江堰 / 大熊猫,专科旅游 / 酒店管理对口

### 4. 统招专升本(四川版)和湖北不一样
- 四川叫"统招专升本",录取率近年比湖北高(40% vs 30%),但 **2024 年改革后**门槛变高
- 接收院校以**省内公办二本**为主(西华大学 / 成都大学 / 成都信息工程 / 西华师大 等)
- 详见 `references/30_专升本路径/四川专升本规则.md`

### 5. 藏彝区专项是隐藏路径
- 凉山 / 阿坝 / 甘孜 + 少数民族户籍 = 国家专项 / 地方专项 / 高校专项 + 民族加分
- 在专科上有"民族班 / 9+3 计划"等政策
- agent 遇到这类用户必须**先单独走专项分析路径**,不要混在普通推荐里

## 三、对话节奏要点

### 别一上来就推院校
四川专科咨询里,agent 容易犯的一个错误是:用户给个分数就吐 5 个院校。这是错的。

正确节奏:
1. **先确认户籍**(成都市区 / 郊县 / 川南川北 / 藏彝区)— 决定推荐池
2. **再确认升本意愿**(强度 1-5)— 决定专业池
3. **再确认产业偏好**(留城市做服务 / 进厂当技工 / 回家进国企 / 考编制)
4. **最后才出院校 + 专业组合**

### 大白话讲话,别讲 PPT
专科考生家长里有相当比例自己学历不高,**别用"行业景气度""产业链协同效应"这种黑话**,要说"五粮液每年招酿造工,管吃管住起薪 5k""成都京东方招测试员,白班夜班轮换"。

### 不要劝复读,但也不要把专科吹上天
- **专科不是失败**,但也不是"换条路一样能成功"的鸡汤。客观说:"专科出来有几条稳的路 + 一些坑要避,选对了能拿编制 / 进国企,选错了 5 万学费打水漂"
- 用户问"要不要复读",原则:**不轻易劝复读**(复读心理压力 + 不确定性大),但**列清楚两条路的差异让用户自己判**

### case-specific,别造数字
- 不写"四川 2024 年专科录取人数 X 万"这种**没数据来源就编**的内容
- 写**有出处的、可验证的、不会过期的**逻辑(比如"五粮液在宜宾本地招专科酿造工"是结构性事实,不是年度数字)

## 四、跟主 skill (sichuan-zhiyuan) 的衔接

- 主 skill 检测到分数低于二本线,且高于专科线时,通过对话引导转到本 skill
- 本 skill 的 L1 硬数据 **复用** 主 skill 的 score_to_rank / predict / query_school 脚本
- 用户在本 skill 里如果突然说"我想试试复读冲二本",**不阻止**,转回主 skill 评估复读路径
