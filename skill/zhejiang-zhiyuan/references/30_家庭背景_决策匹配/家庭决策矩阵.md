# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(浙江视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

**浙江独家:中国民营经济密度最高的省 + 创业家庭比例全国第一 + 私企家庭对体制偏好弱**。**浙江家庭画像跟河南 / 山东 / 湖北的"考公为主"截然不同**:**温州 / 义乌 / 台州民营企业主家庭占比极高 + 杭州互联网中产家庭密度全国第二 + 出国留学比例全国前列**。**因此浙江 5 档家庭决策跟其他省差异最大**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**家庭画像**(浙江视角):
- 抗风险能力中等(收入稳但天花板低,**浙江体制内收入全国前列但天花板仍低于阿里 / 网易**)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公是路径之一,不是默认**(浙江体制内家庭也常推商科 / 出国 — 受民营经济文化影响)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **浙江体制内家庭比例**:全省 ~15-20%(明显低于山东河南的 30-40%)

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 财政学(体制内对口岗位多)
2. **985/211 选调生路径**:**浙大 / 复旦 / 上交 / 中科大 选调名额浙江有倾斜**,**走选调生比国考省考更优**(起点更高、竞争内部化)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:**浙江警察学院 + 公安联考** = 父母编制资源能用上;**浙大法学 + 浙江政法系统** 选调

**典型 case**:
- 杭州某中产体制内家庭(父亲杭州市直机关,母亲银行)→ 孩子 615 分综合改革(浙江全省 4,000 名)→ 推浙大法学 → 毕业选调进浙江省委办,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去浙大 CS → 毕业 35w 起薪很高,但家长不满"不稳定不在杭州市编制",**两年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**(浙江视角):
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道
- **浙江特色**:**杭州 / 宁波 / 温州 三甲医院 + 重点中学 集群密度高 → 子承父业资源强**

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(浙师大 / 杭师);医生家庭 → 临床 / 口腔(8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → 法学;工程师家庭 → 对应工科;医药行业家庭 → 制药 / 药学(浙工大制药 / 温医大药学)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲杭二中语文老师 + 父亲普通工薪 → 孩子 615 分综合改革 → **浙师大公费师范汉语言** → 毕业回原校 / 同区编制,**母亲资源直接复用 + 杭州教师编年薪 18-30w**
- 父母都是浙大附一临床医生 → 孩子 660 分综合改革(浙江全省 1,500 名)→ **浙大医学院八年制临床** → 父母能撑 8 年读书 + 邵逸夫推荐 → **典型子承父业留浙顶级三甲路径**

## 档位 ③ 私企管理 / 创业家庭(★ 浙江最大档位)

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**(浙江视角):
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **浙江特色**:**温州 / 义乌 / 台州 民营企业主家庭比例全国第一**(估计占浙江全省 35-45%),**家长普遍重私企 / 创业 / 出国 > 体制内**;**家族企业接班** 是浙江独家场景

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:**浙江出国留学比例全国前列**,**香港 8 大 / 美本 / 英本 / 中外合作办学** 是浙江私企家庭主流路径(学费 8-30w/年家里能撑)
4. **可走小众路径**:艺术(国美)/ 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **接班路径**:**家族企业接班** = 浙江独家场景,**学商科 / 工科 + 出国留学 + 回家接班** 是温州 / 义乌 / 台州主流模板
6. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 温州某民营企业老板家庭(年入 200w+) → 孩子 580 分综合改革 → 推**香港大学 / 香港中文大学 / 中外合作办学(西交利物浦 / 宁诺 / 上纽)** → 出国背景做家族企业接班
- 义乌跨境电商家庭(年入 150w+) → 孩子 600 分综合改革 → 推**浙工商大国贸 + 阿里实习 + 自家电商兼营**,**毕业接班家族电商业务**
- 失败 case:温州民营家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路,3 年纠结后辞职**
- **浙大经管 / 浙大管院**:浙江中产私企家庭顶配选择,**阿里管培 / 蚂蚁 / 长三角金融**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 10-30 万为主。

**家庭画像**(浙江视角):
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **浙江特色**:**杭州 / 宁波 / 温州 工薪家庭 + 房价高** → 孩子留浙买房压力大;**留浙编制 / 留浙阿里中产** 是普通工薪家庭核心目标

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径 + 高收入工科**:
   - **浙师大 / 杭师大 公费师范**(高考分适中 + 直接编制 + 无学费)
   - **浙江警察学院 + 公安联考** = 进警察系统编制
   - **医学技术(医学影像 / 检验)** = 三甲医院技术岗 + 4 年本科即可(杭医 / 嘉兴 / 绍兴文理 / 温医大)
   - **浙大 / 杭电 CS**(普通工薪家庭跨阶级最强路径之一)= **浙江独家**:留杭 + 阿里中产 = 锁定杭州户口 + 房子 + 父母满意度
3. **次推稳定就业型**:
   - **电气工程进国网浙江**(分够 985/211 / 杭电 / 浙工大电气 性价比之选)
   - **浙工大化工进浙石化 / 华海**(留浙化工铁饭碗)
   - **师范类(汉语言 / 数学师范)**(浙师大 / 杭师 / 宁师)
   - **温医大眼视光技术**(全国独家,留浙做视光师 + 民营连锁)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - **双非 CS**(2024 起薪 8-10w,跟双非工科没差,**浙江尤其残酷因为阿里只要浙大 / 杭电**)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 浙江丽水山区工薪家庭 → 孩子 580 分综合改革(全省 35,000 名)→ 推**浙工大电气**(进国网浙江丽水公司)→ 毕业进电网,**月入 1.2w + 编制 + 留浙**,**家庭逆袭**
- 浙江绍兴工薪家庭 → 孩子 540 分综合改革 → 推**湖州师范汉语言文学**(双非但浙江省考王者)→ 毕业当年考上浙江省直某机关,**家庭命运改变**
- **浙江最强跨阶级 case**:杭州工厂家庭 → 孩子 670 分综合改革(浙江全省 1,000 名)→ **浙大 CS** → 阿里 P6 起薪 35w → 30 岁年收入 80-100w + 杭州房产 → **普通工薪家庭单代跨阶级**(全国独有的"杭州互联网 + 浙大"红利)

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。

**家庭画像**(浙江视角):
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **浙江特色**:**浙江农村比例全国最低之一**(浙江已经基本城镇化),**农村家庭主要分布在丽水山区 / 衢州山区 / 温州山区 / 浙南**;**对比河南 / 江西 / 甘肃,浙江农村经济水平已经接近内地工薪家庭**

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(浙师大金华 / 杭师 / 浙江省属公费师范)** = 农村家庭神器(无学费 + 编制)
   - **国家专项计划 / 高校专项 / 浙江省专项** = 浙江山区 / 偏远县农村专属优惠(分数比统招低 20-30 分)
   - **浙江警察学院 + 公安联考**(无学费 + 编制 + 包分配)
   - **农林牧水(浙大农学 + 浙海大水产)** = 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **浙江省专项计划**:浙江丽水 / 衢州 / 温州山区户籍,**浙大 / 浙工大 / 浙工商 等省属高校多个专项指标**
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会(浙大强基)
   - **浙大顶尖学霸 + 农村家庭 → CS = 跨阶级最强路径**(浙江独家:全国仅有的"农村 → 浙大 → 阿里 → 杭州中产"4 年模板)

**典型 case**:
- 浙江丽水山区农村家庭 → 孩子 590 分综合改革 → 通过**浙江省专项**进**浙大环境工程 / 农学**(比统招低 20-30 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985**
- 浙江衢州农村女孩 → 605 分综合改革 → 推**浙师大公费师范汉语言** → 4 年无学费 + 毕业回原县编制,**最适合农村家庭的"零风险"路径**
- **浙江独家逆袭 case**:浙江温州山区农村男孩 → 670 分综合改革(全省 1,000 名)→ 浙大 CS → 阿里 P6 → 30 岁年收入 80-100w + 杭州房产 → **从山区到杭州中产单代跨阶级**(浙江独有的"互联网杠杆")

## 浙江 5 档跟其他省的差异(关键!)

### vs 山东 / 河南 / 湖北("体制为主"省)

- **浙江私企档比例 35-45% vs 山东河南 10-15%** → 浙江推荐策略要"重商科 / 创业 / 出国"
- **浙江体制内偏好弱** → 浙江工薪家庭也愿意推 CS / 阿里中产路径,不是只盯考公
- **浙江出国留学比例全国前 3** → 私企家庭普遍考虑香港 / 美本 / 中外合作

### vs 上海 / 北京("超中产"省)

- **浙江中产家庭分布更下沉**(温州 / 台州 / 义乌 县城级民营企业主大量) → 比上海中产更接地气
- **浙江"留浙率 80%+"** → 推荐时强烈推荐"留浙路径",不像北京上海"留京 / 留沪"那么固定

### vs 江苏("苏南苏北分化"省)

- **浙江内部经济差距小**(杭甬温台 4 经济体 + 衢丽舟山区,**比江苏苏南苏北分化小**)
- **浙江"全省民营经济均匀"** → 5 档矩阵中私企档跨地市分布广

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业 / 接班)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**浙江特色**:**家庭档位 ③ 私企 / 创业 是浙江最大档位**,agent 必须警惕"用湖北 / 山东 / 河南思维默认推考公"的错误,浙江私企家庭基因不对路。
