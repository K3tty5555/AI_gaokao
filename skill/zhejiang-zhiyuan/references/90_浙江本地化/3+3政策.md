# 浙江 3+3 高考政策

## 核心结论

**浙江 2014 年成为新高考第一批试点省**(跟上海同批,**比湖北/江苏早 7 年**),**2017 年首届实行 3+3** —— 浙江是全国新高考改革"试验田",政策最成熟、最折腾、调整最多的省份之一。**总体规则跟上海一致(3+3 + 选考赋分),但浙江有几个**关键本地特殊性**:**段次录取(不分本一本二)+ 80 个院校专业组志愿(全国最多)+ 选考赋分 21 等级(40-100 分)**。

## 关键事实

### 考试结构(3+3 体系,与湖北/江苏的 3+1+2 完全不同!)

- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分,**用原始分**)
- **3 = 选考科目**:从**物理 / 化学 / 生物 / 政治 / 历史 / 地理 / 技术(信息+通用)** 中**选 3**
  - **浙江独有"技术"科目**(信息技术 + 通用技术,各占 50% — 全国唯一)
  - 共 **7 选 3 = 35 种组合**(湖北 3+1+2 是 12 种,浙江比湖北多 23 种组合)
  - 每科 100 分,**用等级赋分制**(40-100 分,21 等级,每级 3 分)
  - **2 次选考机会**,取最高分(浙江独有,2017-2019 是 2 次,后调整)
- **总分 = 750 分**

### 等级赋分制(关键!!)

- **赋分公式**:把每科原始分按比例换算成 21 个等级(每等 3 分,从 40 分起步,顶 100 分)
- **比例**:卷面前 1% → 100 分,前 3% → 97 分,前 6% → 94 分,...,**末等 → 40 分**
- **意义**:无论原始分多低,**至少拿 40 分**(保底)。所以**总分计算时各科最低 40 分**,而不是 0 分
- **影响**:**用户告诉你的浙江选考分都是赋分后分数,不是原始分**

### 段次录取(浙江最重要的特殊性 — 跟其他省完全不同!)

**浙江 2017 起取消"本一/本二/专科"批次划分**,改用"普通类一段/二段/三段"分段录取:

| 段次 | 划线方式 | 大致对应 | 占考生比例 |
|---|---|---|---|
| **一段线** | 卷面前 20% | 原"一本线" | 约前 20% |
| **二段线** | 卷面前 60% | 原"二本线" | 约前 60% |
| **三段线** | 卷面前 90% | 原"专科线" | 约前 90% |

**关键**:**没有"本一""本二"的概念**,所有本科 + 部分高水平专科都在一段填,二段是中段本科 + 多数专科,三段以专科为主。**双一流非 985/211 的部分院校**也可能在一段录取(段次主要看分数线,不看院校批次)。

### 院校专业组(浙江特色 — 80 个志愿!)

- **浙江本科批 80 个院校专业组志愿,全国最多**(湖北 45 个 / 江苏 40 个 / 河北 96 个 是少数比浙江多的省)
- 每个志愿是"院校 + 专业组"组合,服从调剂只在本组内
- 一段、二段分别填报 80 个,**两段录取互不交叉**(一段没录走二段)

### 三位一体(浙江独有招生方式)

- **浙江省内重点大学三位一体**:高考分(50-60%)+ 校测(30-40%)+ 学考(10%)
- **浙大、复旦、上交、中科大、同济、北外、北科、北外** 等高校都对浙江三位一体
- 高考分要求略低于普通批,但需要校测面试 + 学考成绩(浙江学考独有)
- **极适合学考成绩好 + 面试发挥好的本省考生**(三位一体录取约占浙大本省名额的 30-40%)

### 浙江强基计划

- 浙大有强基(数学/物理/化学/生物/中文/历史 等基础学科)
- **强基只能填 1 所**,跟三位一体冲突时谨慎选(三位一体性价比通常更高)

## 浙江特殊性(关键!!)

### 1. 浙江高校生态(1 所 985 + 双一流非 211 + 互联网生态)

- **1 所 985 = 1 所 211**(**浙大,985 兼 211**,浙江全省独苗)
- **双一流非 985/211**:**宁波大学**(力学双一流)、**杭州电子科技大学**(双一流学科)、**浙江工业大学**(双一流学科)、**中国美术学院**(美术学世界一流)等
- **西湖大学**(2018 创办)— 双非但**院士师资 + 小班 + 直博**,**科创导向顶级**(类似加州理工模式)
- **互联网生态**:**阿里巴巴(杭州)+ 网易(杭州)+ 海康威视(杭州)+ 字节跳动杭州 + 大华(杭州)+ 蚂蚁金服(杭州)+ 哔哩哔哩(上海近邻)** = 浙江高校学生校招主战场,**起薪 25-40w**
- 浙江考生 ~36w/年(比江苏 40w 少 4w,比湖北 45w 少 9w)

### 2. 选考组合 7 选 3 = 35 种(全国最多)

| 维度 | 浙江 7 选 3 | 湖北 3+1+2 |
|---|---|---|
| 组合数 | **35 种** | 12 种 |
| 物理是否必选 | **否(可不选)** | 物理类必选 |
| 历史是否必选 | **否** | 历史类必选 |
| 技术科目 | **有(信息+通用)** | 无 |

**影响**:**浙江考生不选物理也能上理工科**(如选化生地 + 学计算机),但**部分顶级 985 工科要求必选物理**(限制减少灵活性)。**浙大计算机要求物理或技术**,西湖大学物理化学双必选。

### 3. 一段线下二段线上的独立填报段

**浙江最特殊**:一段没录的考生**重新一次性填 80 个二段志愿**(类似征集志愿但是独立段次)。这意味着:
- **一段冲档失败 ≠ 直接掉到三段**,还有完整的二段补救机会
- **影响推荐策略**:浙江冲档可以更激进(冲不上还能在二段挑好的),不像湖北/江苏一冲不中就慌

### 4. 浙江考生本省留率 80%+(全国最高之一)

- 杭州互联网生态 + 宁波制造业 + 温州民营 = 充分本地就业岗位
- **阿里 / 网易 / 海康 / 大华 / 蚂蚁** 校招主力 = 浙大 + 杭电 + 浙工大 + 宁大 学生
- 浙江考生**没有强烈出省动机**,与江苏(留长三角)、湖北(出湖北)的迁徙模式都不同

## 7 选 3 选科决策映射(供 agent 用)

| 考生情况 | 选科建议 |
|---|---|
| 想读临床医学(浙大医学院 / 温医大 等) | **必选化学 + 生物 + 物理**(主流要求) |
| 想读计算机/电子(浙大 / 杭电 / 浙工大) | **必选物理或技术,部分校还要化学** |
| 想读师范(浙师大 / 杭师 公费师范) | 选你想教的学科对应科目 |
| 想报警察 / 公安(浙江警察学院) | **必选政治** |
| 想读西湖大学 | **物理 + 化学 双必选**(基础学科导向) |
| 想读国美(美术学院) | **不限选科**(走美术专业考试) |
| 想报浙大三位一体 | 选你优势科目 + 学考 A 等以上 |

## 易错认知(agent 要纠正用户的)

- **"浙江只有浙大一所 985,所以志愿无悬念"** — 错。**1 所 985 + 双一流非 211 + 西湖大学 + 国美** 的浙江高校层级很丰富,选错院校的代价跟选错专业一样大
- **"浙江没本一本二,直接看分数选学校"** — 错。**段次只是分数线划分**,具体院校投档分差距巨大,要看每个院校专业组的历年位次
- **"浙江 80 个志愿可以乱填随便选"** — 错。**80 个志愿是冲稳保的精细化梯度**,要按 1:2:5 或 2:3:5 比例分布,不是随便选 80 个
- **"赋分制就是水分,实际原始分高才行"** — 半对。**赋分制是相对排名**,你的赋分高代表你在该科目排名靠前,不是水分;但**冷门科目赋分容易**(如政治)、**热门科目赋分难**(如物理),选科要考虑这个
- **"浙大三位一体走捷径"** — 错。**三位一体校测残酷**(考综合能力/英语口语/数学竞赛级题目),没准备的人很难发挥;**本省顶尖高中考生才有竞争优势**

## 关键提醒(agent 必须强调)

1. **浙江是 80 个志愿**(全国最多,要花时间精细分档)
2. **浙江是分段录取不是分批次**(一段 / 二段 / 三段),给用户明确判断标准
3. **选考赋分**(用户告诉你的分数都是赋分后,不是原始分)
4. **三位一体是浙江本省独有路径**(顶尖高中考生务必考虑,可能比统招分数低 20-30 分)
5. **浙大独苗 985 + 互联网生态留浙率 80%+**,推荐时强烈推荐"留浙路径"(浙大 / 杭电 / 浙工大 + 阿里网易海康对口)
6. **二段补救机制存在** → 一段可以适度激进,不慌
