# 考公优选专业表(浙江本地视角)

## 核心结论

**专业决定考公选岗范围**。浙江家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**浙江考公独家事实**:
- **浙江体制内偏好全国最弱**(民营经济碾压体制内,**浙江公考报考人数 / 岗位数 < 山东河南湖北的一半**)
- **浙江公考竞争平稳**(不像山东河南那么卷,**浙江省考三不限岗位约 200-500:1,远低于山东 1000+:1**)
- **浙江选调全国友好**(浙大本省名额倾斜 + 浙江省直机关接收浙大选调生路径完整)
- **浙江户籍门槛**:**浙江省考多数岗位要求浙江户籍 / 浙江高校生源**,**外省考生考浙江公务员有门槛**

## 关键事实(2024 国考 / 浙江省考分析)

### 国考可报岗位数 排名(Top 10 大类)

1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 浙江省考特殊性

- **浙江省考 + 杭州 / 宁波 / 温州 市考**,**汉语言文学和法学并列考公第一专业**
- **浙江各地市公务员岗位对法学要求高**(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(浙江三不限 200-500:1,**比山东河南宽松**)
- **浙江省考报考人数 / 岗位数比例约 35-50:1**,**全国最低之一**(山东河南是 80-150:1)
- **杭州 / 宁波 编制吃香**:杭州市直 / 宁波市直 公务员年薪 18-25w + 公积金 + 杭州户口,**比互联网中产稳定 + 杭州房产门槛更低**

### 选调生(不是普通公务员,是高潜力路径)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(**浙江本地的选调生定向计划基本只对 985/211 + 浙江省内重点**)
- **浙江选调生主要来源**:**浙大(本省名额倾斜)+ 复旦 / 上交 / 中科大 等长三角顶配 985**
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **浙江选调生路径**:**浙大法学 / 经济 / 汉语言 → 浙江省委组织部 / 省直机关后备干部 → 5 年内升副处** = 浙江顶配考公路径

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、**浙江警察学院** 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**浙江警察学院 / 浙大法学 / 浙工商法学** 对口

### 浙江户籍 / 高校生源门槛(关键!)

- **浙江省考多数岗位要求**:**浙江户籍 OR 浙江高校生源 OR 父母浙江户籍**
- **杭州市考 / 宁波市考**:多数岗位要求**杭州 / 宁波户籍 OR 在杭 / 在甬高校生源**
- **影响**:**外省考生想考浙江公务员 → 必须先读浙江高校(浙大 / 杭电 / 浙工大 / 浙师大 等)** 或 **本科毕业后 1-2 年内入户**
- **对策**:**外省考生 + 想留浙考公 → 一定要选浙江高校,不要盲目去省外 211**

## 浙江本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业

- **浙江大学法学** — **全国前 15**(华东 985 法学梯队),**法考通过率高 + 浙大选调路径最优 + 浙江省委组织部直接接收**
- **浙江大学经济学院** — 综合就业 + 考公双友好,**浙大经济 + 浙江选调 = 顶配**
- **浙江大学汉语言文学** — 985 牌子,综合就业宽,**浙大本省选调倾斜**
- **浙江大学公共管理学院** — 行政管理方向,**选调友好**

### 双非 + 性价比考公专业

- **浙江工商大学法学 / 会计学 / 财政学** — 双非财经 + 法学,**浙江本省考公认可度高**(浙工商在浙江财税系统 / 法检系统是仅次浙大的供给源)
- **浙江财经大学会计学 / 财政学 / 税务学** — **浙江财税系统对口校**,**毕业进浙江省税务局 / 浙江省财政厅** 概率高
- **浙江师范大学法学 / 汉语言**(金华)— 双非中等,**汉语言是浙江省考王者**,毕业考公成功率高
- **湖州师范学院 / 温州大学 / 宁波大学(法学 / 汉语言)** — **浙江本地认可,法考 + 考公双路径**
- **杭州师范大学法学 / 汉语言** — 双非中等,**杭州本地考公倾斜**

### 公安系统专属

- **浙江警察学院** — 本科,公安联考路径,**毕业进浙江本地公安概率极高**(基层警察)
- **浙大法学侦查学方向 / 浙工商法学** — 进浙江司法系统

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:浙江绍兴考生,540 分综合改革,**普通工薪家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报湖州师范汉语言文学**,毕业当年考上浙江省直某机关公务员,**家庭命运改变 + 杭州户口**
- **Case B(浙大选调顶配)**:浙江杭州考生,650 分综合改革,中产家庭。家长想报"金融"(浙大经济学院)。**改报浙大法学**,**毕业获得浙大选调生资格,直接进浙江省委组织部**,起点远超经济学就业 + 5 年内副处级
- **Case C(失败路径)**:浙江温州考生,580 分综合改革,普通家庭男生。家长想"考公兜底"。**报了杭电计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次双非阿里又进不去,温州本地中小厂月薪 8k,两头不靠**
- **Case D(浙江私企家庭反向 case)**:浙江义乌考生,580 分综合改革,**民营企业主家庭(年入 100w+)**。父母推"汉语言考公"。**反向劝退 → 改报浙工商国贸 + 接班家族电商业务**,**家庭基因 + 行业匹配 + 年收入远超公务员**
- **Case E(误区路径)**:浙江家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case F(外省考生留浙考公)**:江苏籍考生 600 分,想留浙考公。**必选浙工商或浙财大经济 / 法学 → 入浙江高校生源** → 毕业后符合浙江省考浙江高校生源资格

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科组合不适合考公**" — 错。理科组合考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(浙江 7 选 3 制度允许多数组合报这些专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是浙江家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**浙江公考竞争激烈,不如山东河南好考**" — **严重错误**。**浙江公考实际竞争平稳**(报考人数 / 岗位 = 35-50:1),**比山东河南宽松一半**;**只是浙江岗位总数少**,**但相对录取率反而高**
- "**浙江私企家庭也该让孩子考公兜底**" — **严重错误**。**浙江私企家庭基因不对路**,**孩子毕业被推考公 → 父母嫌没出息 + 孩子没归属感 → 3 年内辞职** 是常见路径
- "**外省考生可以随便考浙江公务员**" — 错。**浙江省考多数岗位要求浙江户籍或浙江高校生源**,**外省考生 + 不读浙江高校 = 留浙考公门槛高**

## 浙江特色(关键!)

### 1. 浙江公考竞争 vs 山东河南湖北

| 维度 | 浙江 | 山东 | 河南 | 湖北 |
|---|---|---|---|---|
| 体制内偏好 | **弱** | 极强 | 强 | 强 |
| 报考人数 / 岗位 | **35-50:1** | 80-150:1 | 100-200:1 | 60-120:1 |
| 三不限岗位竞争 | **200-500:1** | 1500+:1 | 1500+:1 | 800+:1 |
| 顶配考公路径 | 浙大选调 | 鲁大 / 山大选调 | 郑大选调 | 武大 / 中南财法选调 |

**结论**:**浙江公考是"被低估的高性价比赛道"** — 竞争比山东河南宽松,但浙江家长普遍觉得"民营经济好不考公",反而给真要考公的家庭留了空间。

### 2. 浙江选调生路径 = 浙大独家顶配

**浙大选调生**(本省名额最多 + 浙江省直机关定向接收)= **浙江本省考公最强路径**:
- **浙大法学 / 经济 / 汉语言 → 浙江省委组织部 / 省直机关 / 杭州市直 后备干部**
- **5 年内副处级**(全国选调生政策)
- **杭州户口 + 编制 + 杭州房产购房资格**
- **农村 / 工薪家庭通过浙大选调跨阶级 = 浙江独家路径**

### 3. 杭州 / 宁波编制 vs 阿里中产对比

**杭州市直公务员**(法学 / 汉语言考公成功路径):
- **年薪 18-25w + 公积金 + 杭州户口 + 5 年公积金贷款买房**
- **稳定 + 父母满意 + 不加班**
- **vs 阿里 P5/P6**:**阿里年薪 25-40w 但 996 + 35 岁危机 + 户口需要 1 年居住证**
- **结论**:**普通工薪家庭 → 杭州公务员 vs 阿里 P5 = 选哪个看孩子性格**(求稳选公务员,求高薪选阿里)

## 关键提醒

**考公是普通家庭最稳定的上升通道**。**对浙江普通工薪 + 农村家庭** 而言,考公 + 浙江选调依然是稳定路径;**对浙江私企 / 创业家庭** 而言,**考公基因不对路,别盲目推考公**。

**汉语言文学是浙江家长被严重低估的考公王者**(虽然不如山东河南那么受重视,但对真要考公的家庭仍是首选)。

**浙江独家**:**浙大选调 = 本省顶配跨阶级路径**;**浙工商 / 浙财大 = 浙江财税法律系统对口校**;**外省考生想留浙考公必须选浙江高校 + 入浙江户籍**。
