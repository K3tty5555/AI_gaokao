# 用户意向冲突 — Reality Check 金句库(浙江视角)

很多家长 / 考生有具体的意向("想上浙大"、"非杭州不去"、"想学医"、"想进阿里"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

**浙江特色冲突类型**:
1. **"非浙大不嫁"**(浙江全省独苗 985,本省家长心理上限)
2. **"非杭州不去"**(留杭执念 + 阿里中产路径)
3. **"想进阿里 / 网易"**(浙江独家"互联网梦")
4. **"想出国留学"**(浙江私企家庭独家诉求,占比远高于其他省)
5. **"想接班家族企业"**(浙江温州 / 义乌 / 台州独家场景)

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **浙江独家**:**家庭基因匹配权重最高** — 私企家庭推考公 / 工薪家庭推出国 都是基因不对路

---

## 5 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万位次

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 580 分要浙大主流组 / 500 分要复旦)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作双一流强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(浙江 580 分,意向浙大)**:
> "浙大主流组在浙江综合改革 5,500-8,000 名。你 32,450 名,差 2.5 万名,**浙大没戏**。
>
> 但你能上**杭电(电子双一流)+ 浙工大(化工双一流)+ 宁大(力学双一流)** — 这三所留浙就业,**阿里 / 网易 / 海康 / 国网浙江 招聘里跟浙大冷门组校友地位差不多**(都是'浙江本省双一流非 211'同档)。**杭电 CS + 阿里 P5 实际起薪 25w 起,跟浙大冷门组毕业差距没你想的大**。"

**真实案例(浙江 500 分,意向复旦)**:
> "复旦在浙江综合改革 1,500-3,000 名。你 60,000 名,差 5.7 万名,**完全不可能**。
>
> 同档你能上**浙江本省双非顶配(浙工商 / 浙财大 / 浙理工)** + 留浙就业生态。**别盲目冲省外末流 211 弱专业** — 留浙的杭电 / 浙工大 + 阿里实习,实际出口比省外末流 211 弱专业强。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(浙江擦边冲浙大 + 普通家庭)**:
> "浙大你 7,500 名能擦边冲 — 但只能进生命科学 / 农学 / 海洋(舟山校区)/ 哲学。**985 牌子 + 浙江家长面子 + 生化环材天坑** = 三选一 — **农学 / 海洋(舟山)其实是性价比之选**(浙大农学全国第 1 + 浙海洋舟山校区低 1,000 位次)。
>
> 但**生命科学 / 化工 / 哲学** = 必须读博才有出路,普通工薪家庭撑不起。
>
> 同分能上的**杭电 CS / 浙工大化工 / 温医大眼视光医学** 出来对口程度更高 + 起薪不比浙大冷门组低。冲浙大留一个心理慰藉位即可,主推 [杭电 / 浙工大 / 温医大]。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [浙大医学院八年制])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制 / 温医大眼视光技术 4 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(浙江普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 6-9k(浙江三甲略高)**。普通工薪父母还要供 8 年 + 杭州房价压力。
>
> 撑得起 → 推浙大医学院八年制 / 上交医,长期天花板高(邵逸夫主治年薪 30-50w)。
>
> 撑不起 → **建议口腔(5 年本科直接进诊所,起薪 8-15w,早 3 年挣钱)**,或者**温医大眼视光医学(7 年制,中国独家)→ 全国眼科医院 + 视光中心** 行业上升期顶配,或者放弃医学走 CS / 会计这种本科直接挣钱的赛道。"

---

### 模式 D:意向城市 vs 院校层次 — "非杭州不去"

**特征**:用户只想留某个城市("非杭州不去" / "非浙不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211/双一流] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211/双一流 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留杭州没意义,要去西工大),**要灵活退一步**。"

**真实案例(浙江 + 想留杭 + 590 分)**:
> "你只留杭州,这位次 12,000,浙大主流组够不上,但**杭电 / 浙工大 / 浙工商大 / 浙财大 / 杭师** 都够。
>
> **留杭最稳路径**:**杭电 CS / 电子(双一流)+ 阿里实习** → 留杭中产路径(P5 起薪 25w + 杭州户口)。**或者浙工大化工 → 浙石化 / 华海(留浙化工铁饭碗)**。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门组 — 牌子有了但**留杭就业 / 校友网络 / 阿里实习机会全没了**,综合不划算。
>
> **特例**:想做军工 / 航天 → 必须出省(西工大 / 哈工大),浙江本省没强校。"

### 模式 E:浙江独家 — 私企家庭推考公 / 工薪家庭推出国 / "非阿里不嫁"

**特征(浙江独家)**:
- **私企家庭推孩子考公** → 基因不对路(父母期待跟孩子选择冲突)
- **工薪家庭推孩子出国** → 撑不起学费 + 出国后回国劣势
- **"非阿里不嫁"** → 双非孩子非要冲互联网,简历过不了 ATS

#### 子模式 E1:浙江私企家庭推考公(反向劝退)

**金句模板**:
> "你父母在 [温州 / 义乌 / 台州 / 杭州] 做 [外贸 / 制造 / 电商],家庭年入 [100w+]。这种家庭推孩子考公 = **基因不对路**。
>
> 我见过太多温州 / 义乌 民营家庭让孩子去考公务员 — 进去 2 年后被父母嫌'没出息',孩子也不甘心,3 年内辞职去帮家里做生意。**两头不靠**。
>
> 你家庭基因是民营企业 / 创业,孩子最优解是:
> - **学商科 / IT / 设计** + 出国 / 中外合作
> - **回家接班家族企业**(温州鞋服 / 义乌小商品 / 台州医药)
> - **浙工商 / 浙财大 + 阿里 / 民企接班** = 浙江私企家庭主流模板
>
> 别让孩子在编制里浪费 5 年。"

#### 子模式 E2:浙江工薪家庭推出国(反向劝退)

**金句模板**:
> "你家庭是工薪 / 普通中产,父母想送孩子去 [香港 / 美本 / 中外合作],学费 [15-30w/年]。
>
> 你算过总成本吗?**4 年学费 100-200w + 生活费 + 回国后劣势**(出国学历贬值 + 海归不再吃香 + 国内 985 校友网络断了)。
>
> 工薪家庭最稳路径:
> - **浙大 / 杭电 + 阿里 / 国网浙江 + 杭州户口** = 单代跨阶级
> - **浙师大公费师范 + 杭州教师编 = 留杭稳定路径**
> - **温医大医学技术 + 三甲编制 = 普通家庭学医路径**
>
> 出国是中产 / 私企家庭的奢侈品,工薪家庭别硬上。"

#### 子模式 E3:"非阿里不嫁" — 双非孩子冲互联网

**金句模板**:
> "你想进阿里 / 网易,这分数你能上 [双非]。
>
> 阿里 / 网易 校招主力是浙大 / 杭电 / 浙工大 / 复旦 / 上交,**双非孩子简历进 ATS 都过不了筛选**。
>
> 别拿"互联网梦"赌 4 年时间。
>
> 替代路径:
> - **冲杭电 CS / 软件**(分够杭电就有阿里 P5 实习直通)
> - **不够杭电 → 学电气进国网浙江 / 学化工进浙石化 / 学医学技术进三甲** = 这些行业起薪不比双非互联网月薪 8k 差
> - **真想进阿里 → 双非读研冲浙大 / 杭电硕** = 多读 3 年但有概率"
>
> **死局**:**双非 CS 本科直接冲阿里 = 0 概率**,改路径。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **浙江独家踩坑**:**用湖北 / 山东思维默认推考公**(浙江私企家庭基因不对路)、**用北京上海思维默认推出国**(浙江工薪家庭撑不起)

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 浙大 / 想学医 / 想留杭州 / 想进阿里 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。**浙江独家:家庭基因 + 留浙生态 + 民营经济文化 是 3 个 reality check 的浙江独有维度**。
