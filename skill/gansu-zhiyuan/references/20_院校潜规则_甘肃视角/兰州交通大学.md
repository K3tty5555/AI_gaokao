# 兰州交通大学(兰交大,LZJTU)— 双非但铁道工程全国前列

## 一句话定位

**原"兰州铁道学院"**(1958 年由北方交通大学 + 唐山铁道学院 分迁建立),**铁道 / 土木 / 交通 + 中铁系统对口**双非顶配。**男生 + 普通家庭 + 想进中铁 / 中铁建 / 各铁路局 + 不怕基层跑工地 = 兰交大是性价比之王**。**兰州读书 + 全国铁路就业**,**中铁兰州局 / 西宁局 / 乌鲁木齐局 / 成都局** 直接对口。

---

## 真实地位

- **双非 + 教育部 / 国家铁路局 / 甘肃省共建**(原铁道部直属底子,**1958 年北方交通大学(今北交大)+ 唐山铁道学院(今西南交大)分迁兰州建校**,**铁道部三所老校之一**)
- **类似河北石家庄铁道大学的地位**(铁路系统对口),**双非里"细分领域顶配"** + 行业系统认可顶配
- **学科评估**:**交通运输工程 B+**,**土木工程 B**,**测绘科学与技术 B+**(双非里铁道方向第一档)
- **甘肃本省地位**:**留甘 + 想进国企铁路系统 = 兰交大独家选项**(兰大交通方向不强,这块兰交大独占)
- **校区**:**兰州七里河区**(本部,主战场)+ 博文学院(独立学院,**报志愿别看错代码**)
- **男女比**:**男多女少约 7.5:2.5**(铁道工科底子)
- **特点**:**兰州当地学校,但全国铁路系统就业**(铁路项目全国分布,出省比例约 50%)

- **物理类主流组(电气 / 机械 / 自动化 / 测绘 / 道桥)**:全省 **18,000-30,000 名**

### 2021-2023(老高考)

- 理科:省排 **10,000-50,000 名**(王牌组 10,000-18,000,主流 18,000-30,000,冷门 30,000-50,000)
- 文科:省排 **8,000-18,000 名**

**段位定位**:**甘肃物理类省排 50,000 名内可冲兰交大**,**18,000 名内可挑铁道王牌组**,**10,000 名内可冲铁道顶级组**。**国家专项可再低 5,000-10,000 名**。

## 性价比专业(兰交大独家)

- **交通运输(铁道运输方向)**:**进中国铁路总公司 / 各铁路局 调度运输管理岗** 直接路径,**铁路系统 = 西北版"国家电网"**,**录取分相对低 + 出口稳定**,性价比之王
- **土木工程(铁道桥梁方向)**:**中铁 / 中铁建 / 中交集团** 校招对口,**桥梁隧道方向比普通土木出口稳得多**,**中铁兰州局 / 西宁局 / 乌鲁木齐局 / 成都局 / 西安局** 直接对口
- **机车车辆工程**:**冷门但独家**,**中车集团 / 各铁路局机务段** 直接对口,**国企编制 + 技术工种**
- **电气工程(铁路电气化)**:**中铁电气化局 / 各铁路局电务段** 对口,**电气专业里铁路方向是稳定铁饭碗**
- **测绘工程**:**中铁勘测 / 西北测绘院** 对口,**冷门但西北基建 / 国土资源对口**
- **轨道交通信号与控制**:**中国通号 / 各铁路局电务段 / 地铁公司** 对口,**冷门但稀缺**

## 坑专业(在兰交大里相对弱)

- **文科 / 经管 / 法学 / 行政管理**:**兰交大是工科底子,文科边缘**,**学文科直接选西北师大 / 兰财大**
- **计算机 / 软件工程**:**兰交大 CS 不如外省双非沿海**,**对口铁路 IT 才是核心优势**(铁路信息化方向),**学纯互联网 CS 别选兰交大**
- **普通土木(非铁道方向)**:**跟一般工科双非差不多**,**进不了中铁 / 中铁建,只能走小设计院 / 房产开发**(行业下行)
- **新闻传播 / 广播电视**:工科校的文科系,**毕业改行率高**
- **理学院(数学 / 物理 / 化学纯理科)**:**双非纯理科本科出口窄**,除非读研读博

## 关键提醒(填报陷阱)

1. **铁路系统对口校 = 行业内顶配双非**:**兰交大牌子在中铁 / 中铁建 / 各铁路局 校招里跟外省 211 持平**,但**出铁路系统找工作就吃双非亏**,**关键看是不是要走铁路对口行业**
2. **物理类专业组分化**:王牌组(铁道 / 土木 / 电气)与冷门组(经管 / 部分文科)位次差 25,000+ 名,**勾服从前查清组内有什么**
3. **服从调剂注意**:中分组可能调到信管 / 电子商务 / 部分文科 / 边缘工科,**接受不了的别勾**
4. **铁路系统的现实**:**对口央企(中铁 / 中铁建)项目常在工地 / 山区 / 高铁沿线**,**前 5 年基层出差跟着工程跑**,工资稳定 + 项目奖金 + 房补,**接受不了基层别报铁道方向**
5. **兰交大 vs 西南交大(成都,211)**:**兰交大双非但铁道方向行业认可顶配**;**西南交大 211 + 全国铁道老大**;**分够 211 直接选西南交大**;**分不够走对口行业留西北 → 兰交大最优**
6. **兰交大 vs 石家庄铁道大学**:**两校都是铁道双非顶配**,**石铁大近京津 + 出口华北铁路系统**;**兰交大近西北 + 出口西北铁路系统**,**留甘 / 西北选兰交大,留华北选石铁大**
7. **本部 vs 博文学院**:**本部是公办兰交大**,**博文学院是独立学院**(已在转设),**学费贵 + 牌子差**,**报志愿别看错代码**

## 毕业出口(2024 数据)

- **留甘就业**:约 **45-50%**(**兰州铁路局 + 兰州地铁 + 中铁西北分公司 + 中铁第一勘察设计院**(兰州),留甘比例铁道双非里最高)
- **去西安**:约 **15-20%**(西安铁路局 / 中铁第一勘察设计院 / 中铁电气化局 等,**西安是铁道枢纽**)
- **去京津**:约 **5-8%**(中国国家铁路集团总部 / 中铁建总部 / 京津地铁公司)
- **去沿海(长三角 / 大湾区)**:约 **8-10%**(上海铁路局 / 杭州地铁 / 广州地铁 / 深圳地铁)
- **去新疆 / 西藏**:约 **8-10%**(乌鲁木齐铁路局 / 西藏铁路 / 一带一路项目,**边疆补贴高 + 专业对口**)
- **进央企 / 国企概率**:**约 55-65%**(**铁路系统央企招聘量极大**:中铁集团 / 中铁建 / 中铁电气化 / 中铁大桥局 / 中车 / 各铁路局)
- **保研 / 考研**:约 **15-20%**(部分保到西南交大 / 北交大 / 同济)
- **起薪范围**:**铁路局 6-10w + 项目补贴 + 房补**(在兰州算高,**房价低 + 编制稳**);中铁 / 中铁建 8-13w + 出差补贴;**5 年内可达 13-20w 中级工程师**;一带一路 / 边疆项目 12-18w + 边疆补贴 + 海外补贴

**甘肃考生主流路径**:**兰交大铁道方向 → 各铁路局 / 中铁系统央企** = 行业最对口铁饭碗;**留甘的 → 兰州铁路局 + 中铁第一勘察设计院** = 留甘稳定路径。

## 适合谁

- 甘肃物理类 **省排 10,000-50,000 名** 的男生(兰交大主要工科 + 物理类)
- **男生 + 普通工薪 / 农村家庭 + 想要稳定铁饭碗** → 铁路系统 = 西北版"国家电网"
- **不怕跑工地 / 接受铁路项目基层** + **想进央企国企**
- **想留甘 / 西北 / 出新疆西藏** → 兰交大留甘比例西北铁道双非最高 + 一带一路项目对口
- 务实 + 工科严谨派 + **不在意"双非"标签**(行业内牌子顶配)
- 想做铁路设计 / 桥梁隧道工程师 / 铁路调度 / 电气化工程师 / 测绘工程师

## 不适合谁

- **女生 + 不想跑工地 + 追求都市稳定**:**铁路前 5 年基层出差是常态**,**不适合追求都市 office 生活的女生**
- **不进铁路系统的别选铁道方向**:**对口性极强,转行难**,跟着行业走才值
- **学文科 / 财经 / 法学**:兰交大文科边缘,选西北师大 / 兰财大
- **学纯互联网 CS**:**兰交大 CS 不如外省双非沿海**,**对口铁路 IT 才是核心优势**
- **追求纯科研 / 学术天花板**:双非工科本科出口对口央企好,但学术天花板有限
- **铁了心要留兰州市区 + 不接受出差**:**兰交大对口工作 60%+ 在外地工地**,只想留兰州市区可能跟主流路径错位

## 大小年趋势 / 历史录取节奏(2021-2025)

- **2021-2023(老高考)**:兰交大理科录取分稳定在省排 10,000-50,000 名,**铁道运输 / 土木铁道 / 道桥 / 机车 长期热门**;**经管 / 边缘文科 长期冷门**
- **2024 年**:**铁路系统招聘量略缓**(疫情后高铁建设速度放缓),**铁道方向录取位次微降 1,000-2,000 名**(冲分窗口);**电气铁道电气化反而升**(国铁兰州局 / 中铁电气化局 校招扩大)
- **2025 年(新高考首届)**:**铁道工程 / 土木 / 测绘 / 电气 合并成新王牌组**;**机车车辆 / 流体 / 部分文科为中分组**;**首届 3+1+2 录取波动大,有冲机会**
- **大小年规律**:**铁道运输 / 土木铁道 = 长期热门**(铁路系统校招主力);**电气铁道电气化 = 趋势上升**(国铁电务段扩招);**机车车辆 = 冷门稳定**(中车集团对口);**经管 / 文科 = 长期冷门(慎选)**
- **一带一路项目对兰交大的红利**:**中老铁路 / 中亚铁路 / 巴基斯坦铁路 / 非洲铁路 项目** 让中铁系统国际项目岗位增多,**兰交大铁道方向毕业 + 海外项目补贴 = 5 年内年薪 18-25w + 海外补贴**

## 校园 / 生活质量(西北铁道双非本科 4 年的真实体验)

- **七里河本部**:**兰州七里河区,与兰理工同区**,**铁道实训车间 / 隧道实验室 / 桥梁结构实验室 设施完整**(全国双非铁道里第一档)
- **博文学院**:**独立学院**(已转设),**学费贵 + 牌子差**,**本部学生 ≠ 博文学生**,**报志愿别看错代码**
- **学风**:**工科严谨派 + 铁路对口务实**,**实验楼 / 车间 / 实训环境真实**(尤其铁道运输 / 信号 / 桥梁实习,行业对口性强);**考研氛围浓,部分保送西南交大 / 北交大 / 同济**
- **男女比 7.5:2.5**:工科本色,**找对象主要靠隔壁西北师大 / 西北民大 / 甘农大** 安宁校区;**校内女生主要在经管 / 文科组**
- **兰州七里河 / 安宁生活质量**:**比城关区相对外围**,**生活成本低 + 兰州牛肉面 / 西关清真寺 / 七里河商场 配套足**;**铁路职工子弟氛围强**(很多家长是国铁职工)

## 国家专项 / 民族优惠 / 铁路定向培养(甘肃农村 / 民族家庭注意)

- **国家专项计划**:兰交大每年甘肃 28 个国贫县农村户籍专项指标 80-120 个,**比统招分低 5,000-10,000 名**(物理类约 30,000-50,000 名也能进王牌组);**陇南 / 甘南 / 临夏 / 定西 / 庆阳 / 平凉 农村户籍重点考虑**
- **铁路定向培养**(部分专业):**少数定向给中铁兰州局 / 西宁局 / 乌鲁木齐局** 的提前批名额,**毕业直接进对应铁路局编制**,**冷门但 100% 出口**
- **少数民族优惠**:**回族 / 藏族 / 东乡族 / 撒拉族 / 裕固族** 学生有部分专业民族岗位倾斜
- **农村专项 + 兰交大铁道工程** = **甘肃农村男生跨阶级路径**(中铁兰州局编制 + 西北铁路系统铁饭碗)
