# 西北师范大学(西北师大,NWNU)— 双非但西北师范主力

## 一句话定位

**西北最大的师范龙头**(陕师大是 211 但属"教育部六大师范"垫底,**西北师大是甘宁青新藏五省师范主力供给**)。**留甘 + 陕 + 宁 + 青 + 新疆 当老师 = 西北师大编制路径**。**普通工薪家庭 + 想做老师 + 公费师范** = 性价比之王,**学非师范别为"师大牌子"来**。

---

## 真实地位

- **双非 + 教育部 / 甘肃省共建**(原"国立北平师范大学"分迁西北的师范主力,1939 年迁至兰州,**西北师范的鼻祖**)
- **学科评估**:**教育学 B+ 全国前 30**(双非里第一档),**历史学 / 中国语言文学 / 心理学 / 美术学** 双非里强势
- **西北五省师范龙头**:**甘 / 陕 / 宁 / 青 / 新疆** 中学老师主力供给,**比陕师大更接地气(陕师大走全国路线,西北师大走西北根据地)**
- **校区地理**:**兰州市安宁区**(安宁四校连片:**西北师大 / 兰理工 / 甘农大 / 西北民大**),宿舍 / 食堂 / 学风都不错,**比兰大榆中校区舒服多了**
- **男女比**:**女多男少约 3:7**(师范文科底子)
- **甘肃公费师范主要供给校**:本省公费师范 + 留甘编制路径核心

## 甘肃录取位次区间

参考 2021-2025 甘肃录取数据(以一分一段表反查为准):

### 2024-2025(物理 / 历史)

- **物理类公费师范组(数学/物理/化学/生物 师范)**:全省 **8,000-15,000 名**
- **物理类普通组(教育学 / 心理学 / 部分理工)**:全省 **15,000-25,000 名**
- **物理类冷门组(部分非师范理工)**:全省 **25,000-40,000 名**
- **历史类公费师范组(汉语言/历史/政治/英语 师范)**:全省 **2,500-5,500 名**
- **历史类普通组(中文 / 历史 / 哲学 / 心理)**:全省 **5,500-9,000 名**
- **历史类冷门组(部分非师范文科)**:全省 **9,000-15,000 名**

### 2021-2023(老高考)

- 文科:省排 **2,500-15,000 名**(公费师范 2,500-5,500,普通 5,500-15,000)
- 理科:省排 **8,000-40,000 名**(公费师范 8,000-15,000,普通 15,000-40,000)

**段位定位**:**甘肃理科 / 物理类省排 40,000 名内可冲西北师大**,**15,000 名内可挑公费师范**;**文科 / 历史类 15,000 名内可冲**,**5,500 名内可挑公费师范**。

## 性价比专业(西北师大独家)

- **公费师范生(数学 / 物理 / 化学 / 英语 / 汉语言)**:**学费 + 住宿费全免 + 月补贴 800-1000 + 毕业回甘进编制服务 6 年**,**普通工薪 / 农村家庭零成本上双非 + 编制铁饭碗**,**留甘当老师最稳路径**
- **历史学(敦煌学方向)**:**与兰大共享敦煌资源**,**西北独家学科**
- **美术学 / 音乐学**:**西北艺术师范龙头**,艺术生重点考虑(比中央美院 / 中央音乐分低很多但留甘对口)
- **中国语言文学(汉语言)**:**考公王者**,留甘党政机关 / 教育系统编制对口

## 坑专业 / 慎选(在西北师大里相对弱)

- **工科(机械 / 化工 / 计算机)**:**西北师大几乎不强**,**别为了"师大牌子"学非师范工科**,出甘跟双非工科没差
- **经济金融 / 工商管理**:**师范校的经管系**,**留甘考公还行,跨省竞争弱**,学经管选兰财大或出省
- **法学**:一般,**留甘考公够用,跨省律所没竞争力**
- **新闻传播 / 广告**:**师范校的文科边缘系**,毕业改行率高
- **教育技术学(非师范)**:**听起来像师范但不是公费**,**当心被忽悠**(普通批录取 + 自找工作)

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生**:
   - 名字里有"师范"且是**提前批录取** → 公费师范(免学费 + 编制 + 服务 6 年)
   - 名字里有"师范"但是**普通批录取** → 普通师范(自费 + 自找工作 + 自考编)
   - **千万分清,差几十万学费 + 工作落差**
2. **公费师范的"原籍服务 6 年"是硬约束**:**违约要赔学费 + 写违约记录**,影响以后考公考编。**家长一定要跟孩子聊清楚这 6 年要回原籍**
3. **甘肃籍 vs 跨省籍公费师范**:甘肃学生上西北师大公费师范,毕业回甘各市州编制(兰州 / 天水 / 武威 / 张掖 / 酒泉 / 庆阳 / 平凉 / 陇南 / 临夏 / 甘南 等);**跨省学生回原籍**
4. **服从调剂**:西北师大物理类组内可能调到教育技术 / 心理学 / 部分理工,**接受不了的别勾**
5. **西北师大 vs 陕师大**:**陕师大 211 + 全国师范六校之一,牌子稍硬**;**西北师大双非但留甘 / 西北根据地最深**;**留甘当老师 → 西北师大;出省做师范 → 陕师大或北师大**
6. **西北师大 vs 兰州城市学院 / 天水师院**:**西北师大是西北师范主力**,城市学院 / 天水师院是地方师范二本,**层级差一档**
7. **想去东部当老师 → 西北师大牌子在东部不如华师 / 北师 / 上师**,慎选

## 毕业出口(2024 数据)

- **留甘就业**:约 **55-60%**(兰州 + 各市州中学 + 教育系统 + 党政机关,**留甘比例西北师大全省最高**)
- **去陕 / 宁 / 青 / 新疆**:约 **20-25%**(西北根据地路径,**特别是新疆建设兵团 / 青海玉树 / 宁夏银川 中学教师**)
- **去京津**:约 **5-8%**(北京读研 / 北师大读硕)
- **去沿海**:约 **8-10%**(出省考编 / 培训机构 / 部分跨行)
- **公费师范生**:**100% 进入教师编制**(回甘各市州中学)
- **普通师范生**:约 **50-60% 通过省考 / 市考考编**,**约 25% 进民办学校 / 培训机构,约 15% 改行**
- **非师范类**:约 30% 留甘考公,**约 40% 出省**,**就业不如纯综合双非**(因为西北师大牌子在非师范圈认可度低)
- **保研 / 考研**:约 **15-20%**(双非中等水平,部分保到北师大 / 华师 / 陕师大)
- **起薪范围**:留甘中学教师 5-8w + 编制 + 住房补贴(乡镇 + 县城稳定 + 生活成本低);留兰州市区中学 8-12w + 编制;新疆建设兵团教师 6-10w + 边疆补贴;改行去沿海 6-12w(双非师范在沿海私企认可度低)

## 同档对比

| 维度 | 西北师大 | 陕师大 | 北师大 | 兰州城市学院 |
|---|---|---|---|---|
| 牌子 | 双非 | **211(教育部六大)** | **985(全国师范第 1)** | 双非二本 |
| 师范实力 | **西北根据地** | 全国前 5 | 全国第 1 | 一般 |
| 留甘就业 | **极高** | 中(陕西路径) | 一般 | 中(本省二本) |
| 公费师范名额 | 多(甘肃主供) | 多(全国) | 多(全国) | 无 |
| 录取分(甘肃) | **基准** | +20-30 分 | +50-80 分 | -20 分 |

**简单结论**:**留甘 / 西北当老师 → 西北师大 + 公费师范 是稳赢组合**;**分够 211 + 想出省做师范 → 陕师大**;**分够 985 + 全国通用师范牌 → 北师大**;**分不够西北师大 → 兰州城市学院 / 天水师院 二本师范**。

## 适合谁

- 甘肃物理类 **省排 8,000-40,000 名** / 历史类 **2,500-15,000 名** 的考生
- **想当老师 + 留甘 / 西北 + 普通工薪 / 农村家庭** → 西北师大 + 公费师范是稳赢组合
- **女生 + 文科 + 性格内向稳健** → 师范是匹配性最高的职业方向
- **想做敦煌学 / 西北文学 / 民族文化研究** → 西北师大文科 + 留西北学术路径
- **艺术生(美术 / 音乐) + 想留甘 / 西北做艺术老师** → 西北师大艺术师范龙头
- 想读研深造做学问(教育学 / 心理学 / 历史学方向)的学术苗子

## 不适合谁

- **完全不想做老师** → 公费要求服务 6 年,违约赔钱 + 留违约记录,**别为牌子签约**
- **想读非师范专业(经管 / CS / 工科)** → **西北师大非师范不强**,选兰理工 / 兰交大 / 兰财大对口
- **想去东部做老师**:**西北师大牌子东部认可度不如华师 / 北师 / 上师**,慎选
- **男生 + 想冲高薪市场化** → 师范不是匹配方向,选工科或出省
- **ENTP / 不适合流程化教育的性格**:中学老师工作压力 + 体制内规矩多,慎选
- **想做高校教师**:**西北师大本科 → 高校教师** 路径需要硕博加持,**本科直接进高校机会少**
