# 兰州大学(兰大,LZU)— 985 + 西部唯一综合 985

## 一句话定位

**全国排名虚低、学科评估实力全国前 30 的西部老牌综合 985**,**化学 / 数学 / 物理 / 大气 / 生态 / 草学 / 敦煌学** 全国前列。**普通家庭甘肃考生用低分上 985 的隐藏路径** —— 沿海考生不来兰州读,你来。**学术派 + 想读硕读博 + 不怕兰州干燥的甘肃考生闭眼选兰大,没有比这更划算的 985**。

---

## 真实地位

- **985 + 211 + 双一流 + 西部唯一综合性 985**(西交大偏工科,西工大偏军工,兰大是文理医工综合,定位独特)
- **学科评估全国前 30**:化学 A、生态学 A-、大气科学 A-、地理学 A-、生物学 A-、马克思主义理论 A、民族学 A-、**草学 A+**(全国第 1)、物理 B+、数学 B+
- **学术地位真实在第一档**:出过任继周(草学院士)、葛墨林(物理院士)、周绪红(土木院士)、刘人怀(力学院士),"两弹一星"功勋人才链中有兰大背景多人。**李政道早年曾在兰大讲学,任继愈、段子俊** 等元老与兰大渊源深。
- **为什么排名虚低**:兰州距京沪 2000+ 公里,沿海考生用脚投票不来兰州,**生源拖累综合排名**;**本科招生分比同档 985 低 20-40 分**(物理类约比中山 / 厦大低 20-30 分)
- **加持**:**中科院兰州分院**(近物所 / 寒旱所 / 化物所)+ 兰大共建,学术圈层全国前列
- **校区**:城关本部(榆中校区 + 盘旋路本部 + 医学校区),榆中校区距市区 50 公里,**大一大二在榆中**,大三回市区
- **男女比**:接近 1:1(综合性大学,文理医工平衡)

## 甘肃录取位次区间

参考 2021-2025 甘肃录取数据(以一分一段表反查为准,本档不写绝对分数):

### 2024-2025(新高考首届,物理 / 历史)

- **物理类王牌组(化学 / 数学 / 物理 / 临床医学 / 计科)**:全省 **800-2,000 名**
- **物理类主流组(理工实验班 / 大气 / 生态 / 生物)**:全省 **2,000-3,500 名**
- **物理类冷门组(部分材料 / 力学 / 资源勘查)**:全省 **3,500-5,500 名**
- **历史类(中文 / 历史 / 哲学 / 法学 / 经管)**:全省 **400-1,200 名**

### 2021-2023(老高考,文 / 理)

- **理科**:省排 **800-5,000 名**(王牌组 800-2,000,主流组 2,000-3,500,冷门组 3,500-5,500)
- **文科**:省排 **400-1,500 名**

**段位定位**:**甘肃理科 / 物理类省排 5,500 名内可冲兰大**,**2,000 名内可挑王牌组**;**文科 / 历史类省排 1,500 名内可冲**,**500 名内任选**。**国家专项可再低 1,000-3,000 名**,农村户籍重点考虑。

## 性价比专业(同样 985 牌子,录取相对低)

- **草业科学**:**全国第 1 + 双一流**,录取分比化学 / 数学低,**学术路径性价比之王**(任继周院士奠基,西部草原畜牧顶配)
- **大气科学 / 地理学 / 生态学**:**全国前 5-10**,行业冷门 → 录取相对低,**进气象局 / 自然资源部 / 中科院** 编制路径
- **敦煌学 / 民族学 / 历史学**:**全国独家 + 兰大文科顶配**,**敦煌研究院定向**,留甘文化系统对口
- **核科学技术**:**冷门但中科院近物所直通**,**国防 / 核电系统编制**,本科分相对低
- **强基计划(数学 / 物理 / 化学 / 生物 / 历史)**:**比裸分进兰大低一档**,直博绑定 + 不能转专业,适合学术苗子

## 坑专业 / 慎选(在兰大里相对弱)

- **经济金融**:**兰大里很边缘**(兰州金融市场弱,本地实习资源差),**想做金融的别选兰大经管**,出省央财 / 上财更对口
- **计算机 / 软件工程**:有但不强,**双非沿海 CS 录取实际就业更好**(兰大 CS 牌子有,但实习地理差,大厂校招不下兰州)
- **工程类(机械 / 土木 / 电气)**:**兰大里非主流**,专选这些不如去兰理工 / 兰交大对口专业,**分数还低**
- **新闻传播 / 广告学**:文科里偏边缘,**毕业改行率高**
- **生物科学 / 生物技术**:全国前 15 也救不了"必须读博"现实,**慎选,除非笃定走学术**
- **材料 / 化工**:生化环材天坑组合,**985 牌子救不了本科直接就业的尴尬**

## 关键提醒(填报陷阱)

1. **榆中校区 vs 本部校区**:**大一大二在榆中**(距兰州市区 50 公里,荒凉),**大三回盘旋路本部**;医学院在医学校区。**怕基础设施差的提前心理建设**
2. **物理类专业组分化**:王牌组(化学 / 数学 / 物理 / 临床)与冷门组(力学 / 资源勘查)位次差 3,000+,**勾服从前查清组内有什么**
3. **服从调剂注意**:中分组可能调到生物 / 材料 / 力学等天坑,**接受不了的别勾**
4. **强基计划 vs 裸分**:强基低 5-15 分进兰大,但**直博绑定 + 不能转专业**,慎选
5. **兰大医学院 vs 西安交大医**:**兰大医西北综合医学顶配 + 兰大一院 / 二院国家区域医疗中心**;**西交医分高一档但全国认可度更广**;**留西北当医生兰大医够用**
6. **兰大 vs 西交大**:**学化学 / 数学 / 物理 / 大气 / 生态 / 草学 / 敦煌 → 兰大顶配**;**学工科 / 医学 / 管理 → 西交大更强,但分高 30-50 分**
7. **兰州地理的真实约束**:**学术路径(读硕读博 / 进研究所)兰大无差**;**市场化高薪(互联网 / 金融)兰大不如沿海 985,实习地理远,大厂校招不下兰州**

## 毕业出口(2024 数据)

- **留甘就业**:约 **45-50%**(兰州为主,**兰大附属医院 / 中科院兰州分院 / 兰州石化 / 兰州国企** 是主要去向)
- **去西安**:约 **15-20%**(兰大本 → 西安体制内 / 央企西北分公司 / 西交大读研,**西安是兰大最大出甘吸纳口**)
- **去京津**:约 **10-15%**(京津央企总部 / 中科院系统 / 北京高校读研)
- **去沿海(长三角 / 大湾区)**:约 **10-15%**(沿海大厂 / 设计院 / 高校读研)
- **保研 / 考研 / 读博**:约 **40-45%**(保研率约 **20-22%**,985 中等水平,**保研到清北复交西交的接受度极高**)
- **出国**:约 5-8%
- **进央企 / 国企**:约 **30-35%**(中石油 / 中石化兰州分公司 / 中科院系统 / 国家电网西北分部 / 西北勘测设计院 / 兰州石化)
- **西部对口出口**:**西部能源(中石油兰州 / 玉门油田)+ 敦煌文旅(敦煌研究院)+ 西北气象(中国气象局兰州中心)+ 中科院兰州分院** = 兰大独家路径
- **起薪范围**:化学 / 生物读博后 15-25w,CS / 数学方向 18-30w,文科考公进体制 12w + 编制,医学进西北三甲 12-18w + 项目奖金

## 适合谁

- 甘肃理科 / 物理类 **省排 800-5,500 名** / 历史类 **400-1,500 名** 的考生
- **学术派**(想读硕读博 / 进研究所 / 进高校) → 兰大是西部最优 + 中科院兰州分院加持
- **普通家庭 + 想要 985 牌子 + 不想出省花 15-20 万** → 兰大是"用低分上 985"最优解
- **想做敦煌学 / 民族学 / 草学 / 大气 / 生态** → 兰大全国独家
- **想留西北当医生**:兰大医学院 + 兰大一院 / 二院是西北顶配
- 学风务实派 + 不怕兰州天气干燥(冬天有沙尘 + 干燥)

## 不适合谁

- **想做互联网大厂 / 市场化高薪 / 金融** → 兰大牌子有,但实习地理差,大厂校招不下兰州,出省考研更优
- **不能接受榆中校区 2 年荒凉生活** → 慎选(大一大二必在榆中)
- **女生不爱兰州气候**:冬天干燥 + 沙尘 + 暖气虽好但室外冷 → 提前心理建设
- **分够清北复交西交 + 想冲顶配**:出省更优,兰大保留作保底
- **铁了心进央企对口工科(铁路 / 电力 / 装备制造)**:**兰交大 / 兰理工 对口更直接,分还低**
