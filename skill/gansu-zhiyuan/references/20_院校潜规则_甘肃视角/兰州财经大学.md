# 兰州财经大学(兰财大,LZUFE)— 双非但财经类省内第一

## 一句话定位

**甘肃省内财经龙头**,**会计 / 金融 / 经济 / 统计** 在甘肃考公 / 进银行系统 / 国企财务 对口。**双非财经,跟二线财经大学(浙财 / 安徽财经)接近,不如央财 / 上财 / 西财**。**留甘考公 + 进银行 + 进国企财务 = 兰财大稳定路径**;**想去东部金融机构 → 慎选**(双非财经在沿海拼不过对口学校)。

---

## 真实地位

- **双非 + 甘肃省人民政府主管**(原"甘肃财经学院",**1952 年创建,西北财经研究老底子**)
- **学科评估**:**应用经济学 / 工商管理 / 统计学** 双非里中上,**会计学 / 金融学 / 统计学 / 经济学 是甘肃考公 / 银行系统对口主力**
- **甘肃本省地位**:**省内财经第一**(碾压陇东学院 / 河西学院 等地方二本财经),**留甘考公 / 进银行 / 国企财务 主供校**
- **校区**:**兰州城关区段家滩**(本部)+ **和平校区**(部分专业)
- **男女比**:**女多男少约 3:7**(财经文科底子)
- **特点**:**甘肃省内财经独家,但全国财经圈层级靠后**(双非财经在全国大约第 50-80 位)

## 性价比专业(兰财大独家)

- **会计学**:**留甘进银行 / 国企财务 / 会计师事务所 = 甘肃省内财经第一选择**,**录取分相对低 + 出口稳定**,性价比之王
- **税收学 / 财政学**:**留甘考公税务局 / 财政局 编制对口**,**双非财经里考公友好**(税收专业全国考公竞争比小)
- **统计学**:**统计局编制 + 银行数据岗 + 数据分析方向**,**冷门但稀缺**
- **审计学**:**审计署甘肃 / 国企审计 + 会计师事务所**,**冷门但出口对口**

## 坑专业 / 慎选(在兰财大里相对弱)

- **国际经济与贸易**:**全国通病的水专业**,**留甘没有跨境电商生态**,**毕业改行率高**,**慎选**
- **工商管理 / 市场营销**:**典型水专业**,**双非 + 工商管理 = 万金油但啥都不专**,**慎选**
- **金融学(想做市场化金融)**:**兰财金融牌子在东部不如双非沿海财经**,**实习地理远(兰州无金融生态),想做基金 / 券商 / 投行 → 慎选**
- **法学**:**兰财法学非强项**,**学法学选西北师大 / 兰大 / 出省**
- **计算机 / 信息管理**:**兰财 CS 不存在意义**,学 CS 选兰理工 / 兰大或出甘
- **新闻传播 / 广告**:**财经校的文科边缘**,**毕业改行率高**

## 关键提醒(填报陷阱)

1. **兰财大本部 vs 兰财大长青学院**:**兰财大本部是双非主力**,**长青学院是独立学院**(已在转设),**学费贵 + 牌子差**,**报志愿别看错代码**
2. **物理类 / 历史类 专业组分化**:王牌组(会计 / 金融 / 统计)与冷门组(国贸 / 工商管理 / 边缘文科)位次差较大,**勾服从前查清组内有什么**
3. **服从调剂注意**:中分组可能调到国贸 / 工商管理 / 公共事业管理 等水专业,**接受不了的别勾**
4. **甘肃金融市场的现实**:**甘肃金融生态弱**(无券商总部 / 无基金公司 / 银行系统在西北分公司),**留甘金融 = 银行柜员 + 国企财务**,**不是市场化金融(基金 / 券商 / 投行 / VC)**
5. **想做市场化金融 → 兰财不如出省**:**双非沿海财经(浙财 / 上海立信 / 上海对外经贸 / 东北财经)实习地理近** + **东部金融机构校招实习更对口**
6. **兰财大 vs 央财 / 上财 / 西财**:**央财 / 上财 / 西财 是 211 财经顶配 + 全国财经圈层级**;**兰财双非但留甘考公 / 进银行 / 国企财务 对口**;**分够 211 财经直接选央财 / 上财 / 西财;留甘做财经 → 兰财**
7. **兰财大 vs 浙财 / 安徽财经**:**双非财经同档**,**浙财近长三角 + 出口民企 + 互金机会多**;**兰财留甘 + 出口体制内 / 国企**;**看你想去哪里就业**

## 毕业出口(2024 数据)

- **留甘就业**:约 **55-60%**(**甘肃银行业(工商 / 农业 / 建设 / 中国 / 兰州银行) + 甘肃国企财务(兰州石化 / 金川 / 酒钢 / 玉门石油) + 甘肃考公(税务 / 财政 / 审计 / 统计 / 海关) + 会计师事务所(立信 / 信永 等甘肃所)**,留甘比例财经双非里最高)
- **去西安**:约 **12-18%**(西安银行业 / 西安国企财务 / 陕西考公 / 西安会计师事务所)
- **去京津**:约 **3-5%**(北京读研 / 央企总部财务岗,**比例不高**)
- **去沿海(长三角 / 大湾区)**:约 **15-20%**(**深圳 / 广州 / 上海 民企财务 / 互金机构 / 跨境电商财务,起薪 8-15k**,**比留甘高 2 倍但生活成本也高**)
- **进央企 / 国企概率**:约 **15-20%**(国企财务 / 银行 / 保险)
- **进编制(税务 / 财政 / 审计 / 统计 / 海关)**:约 **20-25%**(留甘考公主路径)
- **保研 / 考研**:约 **10-15%**(部分保到央财 / 上财 / 西财 / 兰大读研)
- **起薪范围**:**留甘银行柜员 5-8w + 编制 + 房补**(稳定 + 生活成本低);**留甘国企财务 6-9w + 编制**;**留甘税务 / 财政 / 审计 编制 5-8w + 编制铁饭碗**;**沿海民企财务 8-15w**(深圳 / 上海);**会计师事务所(出甘到京沪) 10-18w + 加班 + 出差**

**甘肃考生主流路径**:**兰财大会计 / 财政 / 税收 → 留甘考公 + 银行 + 国企财务** = 留甘稳定路径;**想冲市场化高薪 → 出甘到沿海双非财经或央财 / 上财**。

## 适合谁

- 甘肃文科 / 历史类 **省排 5,500-30,000 名** / 物理类 **15,000-60,000 名** 的考生
- **想留甘考公 / 进银行 / 国企财务 + 学财经 + 普通家庭** → 兰财会计是低分稳定选择
- **女生 + 文科 + 求稳 + 想要编制铁饭碗** → 留甘税务 / 财政 / 审计 / 统计 编制
- **想做基础财务工作 + 不追求高薪 + 重视生活质量(兰州生活成本低 + 编制稳)**
- **甘肃农村户籍 + 想跨阶级到县城 / 兰州体制内** → 兰财 + 国家专项 + 留甘考公 是稳赢路径

## 不适合谁

- **想做市场化金融(基金 / 券商 / 投行 / VC)** → 兰财牌子不够 + 实习地理远,**慎选**,出甘到央财 / 上财 / 西财或双非沿海财经
- **想去东部金融机构** → 兰财在东部认可度弱,**慎选**
- **男生 + 想冲高薪市场化** → 财经不是匹配方向,**学工科或出省**
- **学文科非财经方向** → 选西北师大文科或兰大文科
- **怕"双非财经"标签** → 兰财牌子在出甘求职时受双非拖累,**有 985 / 211 想法的别选兰财**
- **想做 IT / 数据分析** → 兰财 CS / 信管不强,**学 CS 选兰理工 / 兰大或出省**

- **2024 年**:**会计学进一步收紧**(中产女生扎堆冲会计 → 录取位次升 1,000-1,500 名);**金融学因甘肃市场化金融弱反而平稳偏冷**;**税收 / 财政 / 审计 = 考公族首选,平稳热门**
- **2025 年(新高考首届,3+1+2)**:**经济学 / 会计学 / 金融学 / 统计学 / 财政学 = 物理类 + 历史类 双线热门**;**国贸 / 工商管理 / 信管 / 文科法学 = 冷门组**;**首届 3+1+2 录取波动大**

## 国家专项 / 民族优惠(甘肃农村 / 民族家庭注意)

## 典型 case(供 agent 引用)

- **Case A(留甘女生路径)**:**兰州考生,580 分历史类,普通工薪家庭女生**。报兰财大会计学 → **大三考过初级会计 + 大四进甘肃中行** → 起薪 6k + 编制 + 单位福利房 → **女生留甘最稳路径**
- **Case B(国家专项 + 农村跨阶级)**:**陇南宕昌县农村女生,540 分历史类(国家专项)**。**通过国家专项进兰财大税收学** → 毕业回陇南某县税务局编制 → **整个家族第一个进体制 + 跨阶级**
- **Case C(税务局编制)**:**酒泉考生,560 分文史类,工薪家庭女生**。报兰财大税收学 → **毕业考酒泉市税务局编制成功** → 起薪 5.5k + 编制 + 5 年内涨到 1w → **女生留甘考公最稳路径**
- **Case D(银行系统子承父业)**:**兰州中产家庭女生,父亲甘肃工行,610 分历史类**。报兰财大金融学 → **毕业进甘肃工行兰州分行(父辈资源)** → 编制 + 起薪 7k + 房补 → **典型子承父业**
- **Case E(失败 case — 不该选国贸)**:**白银考生,575 分历史类,普通家庭女生**。**家长以为"国贸国际化高大上"报兰财大国际经济与贸易** → 毕业找不到对口工作(甘肃无跨境电商生态) → **被迫转行做销售月薪 4k** → 选错赛道
- **Case F(出甘冲市场化金融)**:**兰州中产家庭男生,640 分物理类**。**家长想报"金融"但分够央财 / 上财** → **改报央财金融**(出省冲) → 毕业进上海某证券公司投行部 → **市场化金融路径**(兰财不行,出省冲)

## 易错认知(agent 要纠正用户的)

- "**财经类专业 = 高薪金融**" — 错。**双非财经留甘 = 银行柜员 / 国企基础财务 / 税务局基层编制**,**起薪 5-8k**,**不是市场化金融的高薪**
- "**学金融就能进基金 / 券商 / 投行**" — 严重错误。**市场化金融 = 央财 / 上财 / 西财 + 中产家庭 + 北上广实习** 三件套,**双非 + 兰州 + 普通家庭 = 进市场化金融基本无可能**
- "**国际经济与贸易 = 跨境电商 / 进出口高大上**" — 严重错误。**全国通病的水专业**,**留甘没有跨境生态**,**毕业改行率 70%+**
- "**工商管理 / 市场营销学了能当老板**" — 错。**典型水专业,本科水分大**,**双非工商管理 = 万金油但啥都不专**
- "**兰财大 = 全国财经第一档**" — 严重错误。**兰财大 = 双非财经 + 全国财经圈第 50-80 位**,**留甘对口 + 出甘竞争力弱**
- "**男生学财经丢人**" — 错。**男生学税收 / 财政 / 审计 + 留甘考公 = 编制路径**,**只是甘肃普通家庭男生学财经的少**(多数选工科电气 / 机械)

## 三支一扶 / 西部志愿者 + 兰财大 = 甘肃农村家庭隐藏跨阶级路径

- 兰财大本科 + 三支一扶服务 2 年(支农 / 扶贫 / 财税基层) → **服务期满定向考甘肃市州县区编制**
- **甘肃 28 个国贫县基层财政 / 税务 / 审计 岗位** 经常向"三支一扶服务期满 + 财经类本科" 倾斜
- **农村家庭分不够兰财大王牌组的孩子,可以考虑兰财大冷门组(国贸 / 工商管理) + 三支一扶 → 服务期满转编**,曲线进编路径

## 兰财大 vs 兰州城市学院 / 陇东学院 经管类的层级差

- **兰财大 = 甘肃省内财经第一档**(双非但财经主校),**留甘考公 / 进银行 认可度高**
- **兰州城市学院 / 陇东学院 / 河西学院 / 天水师院 经管系** = 地方二本经管,**层级比兰财大低一档**,**留甘考公时投档单位 + 用人单位认可度** 兰财大占优
- **甘肃农村家庭分够兰财大就别选地方二本经管** — **兰财大留甘考公 / 进银行 概率比地方二本高 30-50%**
