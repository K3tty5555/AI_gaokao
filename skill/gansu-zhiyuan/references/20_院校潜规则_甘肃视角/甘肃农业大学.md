# 甘肃农业大学(甘农大,GSAU)— 双非但草学 / 动物科学全国前列

## 一句话定位

**农业部 + 甘肃省共建**,**草业科学全国前 5 + 动物科学 / 兽医 / 园艺 强势**,**西部草原 / 河西走廊农业 / 牛羊肉产业链 主力供给校**。**农村户籍 + 想做基层农技 / 畜牧 + 走"农林专项"** → 甘农大是低分上专业的最优解。**祁连山 / 河西走廊 / 甘南草原 = 甘农大调研区**,实战环境西北独家。

---

## 真实地位

- **双非 + 农业农村部 / 甘肃省 共建**(原"国立兽医学院",**1946 年创建,西北农牧研究老底子**)
- **学科评估**:**草业科学 / 动物科学 / 动物医学 / 园艺** 双非里前列(全国前 5-15),**草学跟兰大并列西北畜牧研究双子星**
- **甘肃本省地位**:**西北草原畜牧 / 河西走廊农业 / 西北农技推广 主力供给**,**牛羊肉产业链(临夏 / 张掖 / 酒泉 / 甘南)对口**
- **校区**:**兰州安宁区**(安宁四校连片:**西北师大 / 兰理工 / 甘农大 / 西北民大**)
- **男女比**:接近 1:1(农林文理工平衡,**兽医 / 动科男多,园艺 / 食品女多**)
- **特点**:**西部独家畜牧农业研究基地**,**祁连山 / 河西走廊 / 甘南草原 / 青海湖 全是甘农大调研区**

## 性价比专业(甘农大独家)

- **草业科学**:**全国前 5 + 双非里第一档** + **任继周院士奠基(任继周已是兰大草学奠基人,甘农大草学跟兰大互通)**,**西北草原 / 牛羊产业链 / 农业部 草原管理 直接对口**,**录取分相对低,性价比之王**
- **动物科学(畜牧学方向)**:**临夏牛羊肉产业(中国最大牛羊肉集散地)+ 张掖肉牛 + 甘南牦牛 / 藏羊** 直接对口,**西北畜牧业是甘农大的根据地**
- **动物医学(兽医)**:**基层兽医站编制(乡镇农业农村局)+ 动物检疫(海关 / 农业部)+ 宠物医院**(宠物经济兴起),**留甘考公编制路径稳**
- **园艺(酿酒葡萄方向)**:**河西走廊(武威 / 张掖 / 酒泉)是中国第二大酿酒葡萄产区**,**张裕 / 莫高 / 紫轩 等酒厂直接对口**,冷门独家
- **食品科学与工程**:**伊利 / 蒙牛 / 雪顶 / 庆阳苹果 / 静宁苹果 / 牛羊肉加工厂** 校招对口

## 坑专业(在甘农大里相对弱)

- **文科 / 经管 / 法学**:**农业大学的文科边缘**,**学文科直接选西北师大 / 兰财大**
- **工科 / CS / 自动化**:**几乎不强**,**学工科选兰理工 / 兰交大**
- **生物工程 / 生物技术(非农方向)**:**双非生物本科出口窄**,除非读研读博
- **新闻传播 / 广告**:**农大文科边缘系**,毕业改行率高
- **理学院(数学 / 物理 / 化学纯理科)**:**双非纯理科本科出口窄**

## 关键提醒(填报陷阱)

1. **甘农大本部 vs 甘农大职业技术学院**:**甘农大本部是双非主力**,**职业技术学院是专科**,**层级差一档**,**报志愿别看错代码**
2. **物理类专业组分化**:王牌组(草学 / 动科 / 兽医 / 园艺)与冷门组(经管 / 边缘工科)位次差 30,000+ 名,**勾服从前查清组内有什么**
3. **服从调剂注意**:中分组可能调到农学 / 资源环境 / 草坪 / 林学,**接受不了的别勾**
4. **学农 / 畜牧的现实**:**对口工作 70%+ 在乡镇 / 农场 / 草原 / 牛羊基地 / 林场**,**前 5 年基层工作是常态**,工资稳定 + 编制 + 房补 + 农业项目奖金,**接受不了"基层 + 偏远"地理别选这些方向**
5. **农林专项的隐藏路径**:**甘农大有农林公费定向(乡镇农技员 / 兽医站 / 林草局)**,**毕业回原籍乡镇基层服务 6 年 + 编制铁饭碗** + **学费补贴**,**农村户籍超划算**
6. **甘农大 vs 西农(211)**:**西农 985 / 211 + 全国农林顶配**;**甘农大双非但西北畜牧 + 河西农业根据地最深**;**留甘 / 西北做农 → 甘农大 + 公费农学 / 农林专项;出省做农 → 西农**
7. **甘农大 vs 中国农大**:**中国农大 985 + 全国农林老大**;**甘农大双非但留甘 / 西北最对口**;**分够 985 → 中国农大;留甘做农 → 甘农大**

## 毕业出口(2024 数据)

- **留甘就业**:约 **55-60%**(**甘肃农业农村系统(省 / 市 / 县 / 乡镇农业农村局 + 兽医站 + 农技站) + 甘肃林草局 + 河西农业 + 临夏牛羊肉产业 + 兰州食品企业**,留甘比例农林双非里最高)
- **去陕 / 宁 / 青 / 新疆 / 藏**:约 **15-20%**(**新疆建设兵团农业 / 青海玉树畜牧 / 宁夏中卫农业 / 西藏那曲畜牧 + 一带一路项目**,**西部农牧路径**)
- **去京津**:约 **5-8%**(中国农大读研 / 农业农村部直属院所 / 中国农科院读硕)
- **去沿海**:约 **8-12%**(伊利 / 蒙牛 / 双汇 / 沿海食品企业 / 农业银行 / 出省考研)
- **进央企 / 国企概率**:约 **20-25%**(伊利 / 蒙牛 / 雪顶 / 双汇 / 中粮 / 益海嘉里 / 农业银行)
- **进编制(乡镇农业农村局 / 兽医站)**:约 **30-35%**(留甘考编路径,**农林专项定向毕业即编制**)
- **保研 / 考研**:约 **15-20%**(部分保到中国农大 / 西农 / 兰大读研)
- **起薪范围**:**乡镇农业农村局 / 兽医站(基层编制)5-7w + 编制 + 房补**(生活成本低 + 稳定);兰州食品企业 / 农业产业 7-10w;伊利 / 蒙牛 等大食品企业 8-13w(出甘到沿海或内蒙古);新疆建设兵团 / 西藏畜牧 8-13w + 边疆补贴(收入不低 + 生活艰苦);宠物医院 / 农兽医诊所 8-15w(看个人接诊量)

**甘肃考生主流路径**:**甘农大草学 / 动科 / 兽医 → 乡镇农业农村系统 / 临夏牛羊肉 / 河西农业 / 新疆建设兵团 / 西藏畜牧** = 西部农牧编制铁饭碗。

## 适合谁

- 甘肃物理类 **省排 22,000-75,000 名** / 历史类 **12,000-25,000 名** 的考生
- **农村户籍 + 想做基层农技 / 畜牧 / 兽医 + 走"农林专项" / 公费农学** → 甘农大是低分上专业的最优解
- **想做西北畜牧 / 河西农业 / 临夏牛羊肉产业** → 甘农大独家根据地
- **想留甘 / 西北 + 进乡镇农业农村系统编制** → 编制铁饭碗 + 生活成本低
- **女生 + 园艺 / 食品 / 农林经管** → 甘农大女生比例不错 + 适合温和派
- **男生 + 兽医 / 动物科学 + 不怕基层 + 想做实在的农牧人** → 西部畜牧业振兴顺周期

## 不适合谁

- **不想做农业相关** → 别为了"农大"牌子来,**甘农大非农林专业不强**
- **想做市场化高薪** → 农林行业起薪低 + 工作地偏远,**学经管 / CS 出甘更优**
- **学文科 / 财经 / 法学**:甘农大文科边缘,选西北师大 / 兰财大
- **怕基层 / 偏远 / 牛羊农场**:**甘农大对口工作 70%+ 在乡镇 / 农场 / 草原**,接受不了别选
- **想做高校教师 / 学术天花板**:**甘农大本科 → 高校教师** 路径需要硕博加持(可保研到西农 / 中国农大)
- **想做精致都市生活**:农林行业不匹配,选其他方向

## 大小年趋势 / 历史录取节奏(2021-2025)

- **2021-2023(老高考)**:甘农大理科录取分稳定在省排 22,000-75,000 名,**草学 / 动物科学 / 动物医学 西北顶配 + 长期热门**;**农学 / 林学 / 食品 / 园艺 中等**
- **2024 年**:**动物医学(兽医) 升温**(城市宠物医院扩张 + 农村畜牧振兴);**酿酒葡萄(园艺) 升温**(贺兰山东麓 / 河西走廊葡萄酒产业);**农林专项指标继续扩**
- **2025 年(新高考首届)**:**物理类专业组合并**(草学 / 动科 / 动医 / 园艺 王牌组);**首届 3+1+2 录取波动大,有冲机会**
- **大小年规律**:**草学 / 动物科学 / 动物医学 = 长期热门稳定**(西北畜牧业刚需);**酿酒葡萄 / 食品科学 = 趋势上升**(产业升级);**林学 / 设施农业 = 平稳**;**经管 / 文科 = 长期冷门(慎选)**
- **乡村振兴政策红利**:**国家"十四五"乡村振兴战略让乡镇农技 / 畜牧站 / 农业农村局 编制岗位增多**,**甘农大本科 + 三支一扶 / 特岗 / 公费农学 = 跨阶级路径**

## 国家专项 / 农林专项 / 公费农学叠加(甘肃农村家庭核心红利)

**1. 国家专项计划**
- 甘农大每年甘肃 28 个国贫县农村户籍专项指标 100-150 个,**比统招分低 5,000-10,000 名**(物理类约 50,000-65,000 名也能进王牌组)
- **陇南 / 甘南 / 临夏 / 定西 / 庆阳 / 平凉 农村户籍重点考虑**

**2. 农林专项**(全国农林大学专属)
- **农村户籍学生** 报甘农大 / 西农 / 中国农大 等农林专项 → **比统招分再低 1,000-3,000 名**
- **甘肃农村家庭男女生 + 想做农林 = 双低分进甘农大**(国家专项 + 农林专项叠加)

**3. 公费农学(部分专业)**
- 甘农大有少量"公费农学" / "服务三农定向培养" 名额
- **回甘各市州农业农村局 / 农技站 / 畜牧站 服务 5-6 年 = 直接编制**
- **类似公费师范但人数少 + 相对冷门** = **甘肃农村家庭隐藏神器**

**4. 三支一扶 / 特岗 / 西部志愿者 + 甘农大背景**
- 甘农大本科 + 三支一扶(支农 / 扶贫 / 特岗教师) → 服务期满定向考甘肃乡镇编制
- **甘肃 28 个国贫县基层农技 / 畜牧 / 兽医 岗位** 经常向"农林本科 + 三支一扶服务期满" 倾斜

## 典型 case(供 agent 引用)

## 易错认知(agent 要纠正用户的)

- "**农业大学出来就是农民**" — 错。**甘农大本科出口 70%+ 是乡镇农业农村局 / 农技站 / 畜牧站 / 兽医站 编制 + 农业产业公司技术岗**(不是种地);**编制 + 行业内对口性强**
- "**学兽医 = 给猪羊看病的乡村大兽医**" — 半对。**乡镇兽医是常见出口**;**也可以做城市宠物医院兽医**(月入 8-15k);**或做规模化养殖企业技术岗**(月入 6-12k);**多元化**
- "**草学 = 放牛羊**" — 严重错误。**兰大草学 / 甘农大草业科学 = 国家粮食安全战略学科**;**进中科院寒旱所 / 西北畜牧研究所 = 学术 + 编制路径**
- "**酿酒葡萄是种葡萄的**" — 错。**园艺(酿酒葡萄方向)= 葡萄园管理 + 酿酒师 / 品酒师 / 葡萄酒产业链**;**贺兰山东麓 / 河西走廊葡萄酒产业升温 = 行业红利**
- "**学农就一定回乡村,没城市选择**" — 半对。**农林专业留乡村是主流**(留甘农村比例 50%+);**也可以进兰州 / 西安 / 武威 / 张掖 等城市农业局 / 农技推广站 / 农产品贸易公司**
- "**甘农大不如西农**" — 半对。**西农(陕西杨凌)= 985 + 211 + 全国农林前 5**;**甘农大双非但西北畜牧 / 河西农业 / 临夏牛羊肉产业链 对口性更强**;**留甘做农 → 甘农大;出甘做农 → 西农**
- "**学农起薪太低,没出路**" — 半对。**起薪 4-7k 确实低**;**但乡镇农技编制 / 进国企农产品 / 接班家族产业 / 三支一扶 / 公费农学 = 长期稳定 + 父母老人陪伴 + 生活成本低**;**农林是普通家庭"低分进编制"路径**
