# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(甘肃版)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪家庭和中产家庭的最优解可能完全相反**。

**甘肃家庭的特殊点**:
- **农村家庭比例极高**(全省农村户籍 > 55%,**陇南 / 甘南 / 临夏 / 定西 农村比例 > 70%**)
- **少数民族家庭独特**(回族 / 藏族 / 东乡族 / 裕固族 / 撒拉族 等,**国家专项 + 民族优惠政策**用得上)
- **甘肃整体经济落后**(全国倒数 5 名),普通家庭抗风险能力比东中部省份再低一档
- **"出甘"心理门槛特别高**(地理偏远 + 父母老人观念重 + 兰大本科生留甘比例反而比清北留京低很多),**留甘 = 稳定 + 父母满意**,**出甘 = 跨阶级但风险大**

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障(甘肃口径:**省直机关 / 兰州市直 / 各市州县区机关 / 甘肃省国资委下属国企(读者出版 / 甘肃电投 / 甘肃公航旅 / 兰州石化等)/ 国家电网甘肃 / 甘肃移动电信联通 / 各级公立学校教师编 / 各级公立医院编制**)。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **甘肃地域特色**:**家庭根扎兰州 / 市州的接受度极高**,孩子留甘是默认期待

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(甘肃省考对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化)— **兰大选调 / 西北师大选调 / 兰理工选调 是甘肃本省主供给**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:**甘肃警察学院 + 公安联考** = 父母编制资源能用上,**留甘各市州公安机关编制**
5. **甘肃国企对口专业**:**兰州石化(化工) / 甘肃电投(电气) / 公航旅(土木) / 甘肃读者(汉语言)**,父母资源能直接用

**典型 case**:
- **兰州某体制内家庭(父亲省直机关,母亲甘肃中行)→ 孩子 605 分历史类 → 推兰大法学 → 大四获选调生进甘肃省委办**,**家庭路径完美匹配**
- **失败 case**:同样家庭,孩子被推去兰大 CS → 毕业 18w 起薪去深圳腾讯,但**家长不满"不稳定 + 离家远"**,劝其离职考公,**两年的时间损耗 + 心理纠结**
- **天水某市直机关家庭 → 孩子 580 分物理类 → 推兰理工电气 → 毕业进国网甘肃天水供电公司编制**,**留甘 + 父母资源叠加**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师 / 律师)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域(甘肃口径:**兰大附属医院 / 甘肃省人民医院 / 各市州中学教师 / 兰州市设计院工程师 / 甘肃律所律师 / 中科院兰州分院科研人员**)。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:
   - 教师家庭 → **西北师大公费师范汉语言 / 数学 / 物理 / 英语 / 化学**(母亲资源直接复用)
   - 医生家庭 → 兰大医学院八年制临床 / 5+3 一体化 / 口腔(8 年长周期父母能撑)
   - 律师家庭 → 兰大法学 / 中南财法法学(出甘冲)
   - 工程师家庭 → 兰理工 / 兰交大对应工科
2. **行业相关延伸**:中科院兰州分院家庭 → 兰大化学 / 物理 / 数学(基础学科双一流,与中科院共建)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难,且甘肃金融行业本身体量小)

**典型 case**:
- **母亲西北师大附中语文老师 + 父亲普通工薪 → 孩子 615 分历史类 → 公费师范生汉语言(西北师大)**,**毕业回西北师大附中 / 同区编制,母亲资源直接复用**
- **父母都是兰大一院临床医生 → 孩子 645 分物理类 → 兰大医学院 5+3 一体化** → **父母能撑 8 年读书 + 兰大一院推荐 → 典型子承父业路径**
- **父亲中科院兰州寒旱所研究员 → 孩子 620 分物理类 → 兰大大气科学**(全国前 5)→ **直博本所导师组,父子两代寒旱所**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主(甘肃口径:**兰州本地民营经济偏弱**,**主要是中药材贸易商(陇南 / 岷县 / 武威 / 临夏)+ 兰州本地建材 / 商贸 + 河西走廊农业产业 + 嘉峪关 / 酒泉 民营矿业服务**)。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **甘肃地域特色**:**民营经济总量比湖北 / 浙江 / 广东小一档,但仍有特定细分赛道(中药材 / 河西农业 / 文旅 / 风电服务)**

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校,**出甘冲西交大 / 上财 / 央财**)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(**甘肃中外合作办学选项少,主要走出省**)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **甘肃中药材家庭独家**:孩子可考虑**甘肃中医药大学中药学**(全国前 10)+ 接班 + 走"陇药"出口路径

**典型 case**:
- **陇南某中药材贸易家庭(年入 200w+) → 孩子 580 分物理类 → 推甘肃中医药大学中药学**(全国前 10)→ **接班家族中药材生意 + 行业内强校** = 双赢
- **嘉峪关某民营矿业服务家庭 → 孩子 600 分物理类 → 出省冲西安交大材料 / 矿业** → 学完回嘉峪关接班(矿业行业仍然有空间)
- **失败 case**:**酒泉某风电服务公司老板家庭 → 孩子被推考公 → 进酒泉市供电公司基层 → 父亲嫌"没出息" → 家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限(甘肃口径:**兰州石化工人 / 兰州各国企工人 / 各市州小公务员单位科员 / 兰州市区服务业 / 各市州县城工薪 等**),家庭年收入 8-25 万为主(**甘肃口径整体比湖北低一档**)。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**(甘肃版神器组合):
   - **西北师大公费师范汉语言 / 数学 / 物理 / 英语 / 化学** = 高考分适中 + 直接编制 + 无学费 + 月补贴
   - **甘肃警察学院**(警校)+ 公安联考 = 进甘肃省 / 各市州公安系统编制
   - **医学影像 / 检验**(甘肃医学院 / 河西学院)= 三甲 / 二甲 医院技术岗 + 4 年本科即可
   - **甘肃护理本科**(甘肃医学院 / 西北民大医学院)= 县级医院编制
3. **次推稳定就业型**(甘肃口径):
   - **电气工程进国网甘肃**(分够兰理工 / 985 / 211)— 男生神器路径
   - **铁道方向(兰交大)进国铁兰州局 / 中铁电气化** — 男生神器路径
   - **新能源(兰理工 新能源科学与工程)进国电投甘肃 / 华能甘肃 风电基地** — 男生路径
   - **师范类(汉语言 / 数学师范)** — 留甘市州中学教师编制
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局,**甘肃金融行业容量小,出甘竞争更弱**)
   - **双非 CS**(2024 起薪 6-9k,**甘肃本地 CS 容量比湖北还小,反而更不推荐**)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- **天水某工厂家庭 → 孩子 580 分物理类 → 推兰理工电气工程**(甘肃电气双非顶配)→ 毕业进国网甘肃天水供电公司,**月入 8k + 编制,家庭逆袭**
- **庆阳工薪家庭 → 孩子 540 分历史类 → 推西北师大公费师范汉语言** → 4 年免学费 + 月补贴 800 + 毕业回庆阳某中学语文教师编制,**家庭命运改变**(零学费投入 + 直接编制)
- **酒泉工薪家庭男生 → 孩子 560 分物理类 → 推兰交大铁道工程** → 毕业进中铁兰州局电务段,**起薪 7k + 编制 + 单位福利房**

## 档位 ⑤ 农村 / 临工家庭(甘肃版核心)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万(甘肃口径,比东中部农村再低一档)。**甘肃农村比例极高,这一档是甘肃 agent 最常遇到的家庭画像**。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **甘肃地域特色**:**陇南 / 甘南 / 临夏 / 定西 山区贫困户 → 整个家族第一个上大学的孩子**(承担巨大期待)

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
   - **甘肃农村家庭出甘 = 极大决心,但兰大已经是低分上 985 的最优解** — 留甘 + 985 + 国家专项 三全其美
2. **优先 100% 编制 / 100% 出口的路径**:
   - **西北师大公费师范汉语言 / 数学 / 物理**(无学费 + 月补贴 + 编制)= **甘肃农村家庭神器**
   - **国家专项计划**:甘肃农村户籍考生,985/211 名校多个专项指标(分数比统招低 15-30 分),**兰大国家专项 / 兰理工国家专项 / 西交大国家专项 / 北师大国家专项 等**
   - **高校专项计划**(原"贫困地区专项")= 农村专属优惠,**甘肃 28 个国贫县 / 省贫县 农村户籍专属**
   - **甘肃警察学院**(无学费 + 编制 + 包分配)/ 各军校
   - **农林牧水**(甘肃农业大学国家专项)= 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **甘肃农村家庭特殊机会**:
   - **国家专项计划 + 兰大** = 比裸分进兰大低 1500-3000 名,**省内农村跨阶级最佳路径**
   - **强基计划 + 兰大数学 / 物理 / 化学**:农村学生单科特别强可冲
   - **甘肃定向师范(各市州教育局定向)** = 部分县区有"农村教师定向培养"政策(免学费 + 回原县编制)
   - **少数民族专属**:**回族 / 藏族 / 东乡族 / 裕固族 / 撒拉族** 学生有民族优惠 + 民族院校优惠(西北民大有大量民族专项指标)

**典型 case**:
- **临夏回族农村家庭 → 孩子 590 分物理类 → 通过国家专项进兰大化学**(比统招分低 25 分)→ **985 牌子 + 国家专项编制路径,整个家族第一个 985**
- **甘南藏族农村家庭 → 孩子 555 分历史类 → 推西北民大民族学(国家专项)** → **毕业回甘南州民委 / 教育局编制 + 民族补贴**
- **陇南山区农村女孩 → 605 分历史类 → 推西北师大公费师范汉语言** → 4 年无学费 + 毕业回陇南某县编制,**最适合甘肃农村家庭的"零风险"路径**
- **定西农村家庭男生 → 565 分物理类 → 推甘肃医学院医学影像技术** → **毕业进定西某二甲医院技术岗编制 + 起薪 5k + 包食宿**,**4 年回乡反哺家庭**
- **庆阳农村男生 → 580 分物理类 → 推兰交大铁道工程国家专项** → **毕业进中铁兰州局基层编制**,**5 年内涨到 1.4w + 单位福利房**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 甘肃地域特殊提醒

**"出甘"心理门槛**:**甘肃父母对孩子"出甘 + 留沿海"接受度极低**(地理偏远,父母老人不能跟过去),**这是甘肃 vs 湖北 / 江苏 / 浙江最大的家庭文化差异**。**agent 必须在 L4.5(意向锚点)环节确认**:**家长是否接受孩子出甘?接受范围(西安 ✓ / 北京 ✓ / 沿海 ?)**。

**留甘 = 默认期待**,**出甘需要家庭明确同意**。这条规则比湖北更绝对。
