# 计算机科学与技术 / 软件工程(CS / SE)— 甘肃视角

## 一句话总结

**CS 已经过了"闭眼报"的黄金时代,在甘肃这个时代过得更早**。沿海互联网大厂 2022 年起裁员潮 + 算法岗硕士起步 + 甘肃本地几乎没有像样的互联网企业,**甘肃考生学 CS 90% 路径是"出甘"**(去西安、北京、深圳)。**留甘 CS 出口极窄**(只有兰州本地几家做政务系统 / 国企信息化的小厂 + 中科院兰州分院少量算法岗),**双非 CS 在甘肃几乎等于浪费 4 年**——还不如学电气进甘肃电网。

---

## 真相 1:甘肃本地 CS 就业市场容量小到尴尬

- **兰州无互联网产业基础**:没有华为研究所(西安有 / 成都有),没有阿里 / 字节办公室,没有像样的独角兽企业
- **本地 IT 主要去向**:**省政务云 / 兰州石化信息化 / 国家电网甘肃电力信息中心 / 中科院兰州分院 IT 岗** — 这些岗位**总量不超过 2000/年**,而甘肃 CS 毕业生(兰大 + 兰理工 + 兰交大 + 西北师大 + 西北民大 + 兰州城市学院 + 各市州二本三本)**总数超 8000/年**
- **结论**:**留甘 CS = 80% 流向中小外包公司 / 培训机构销售 / 转行**

## 真相 2:出甘 CS 的真实路径只有 2 条

**路径 A:兰大 / 985 分够 → 出甘去西安 / 北京 / 深圳大厂**
- 兰大 CS 毕业去向:**约 60% 出甘**(西安华为 / 北京字节 / 深圳腾讯 / 上海拼多多),起薪 18-25w
- 兰大 CS 牌子在沿海大厂校招里**勉强够入围**(不如华科武大,但好于双非)
- **保研路径**:兰大 CS 保到清北复交浙的概率比中部 985 略低(地理偏远导师推荐力度弱),**主要保到西交大 / 哈工大 / 北航**

**路径 B:双非 CS + 考研出甘**
- 兰理工 / 兰交大 / 西北民大 CS → **本科直接就业基本进不了大厂**
- 唯一出路:**考研到西交大 / 哈工大 / 北邮 / 北航 → 然后大厂 SP**
- 考研失败 = 留甘做政务外包 / 跟培训机构讲课,**起薪 6-9k 上限明显**

## 真相 3:35 岁危机 + 甘肃本地缓冲弱

- 沿海大厂 35 岁被裁的甘肃出身程序员,**回甘退路极窄**(本地 IT 容量小)
- 比湖北 / 四川 / 山东等省更尴尬:**这些省回省内还能进省政务、省国企信息化、省内中型软件公司**;**甘肃本地接得住的体面岗位极少**
- **30+ 想"回兰州躺平"** 的甘肃 CS 程序员往往最后选**改行进国企做信息化** / **回老家市州做事业单位 IT 岗** — 收入掉一半但稳定

## 真相 4:甘肃考公 CS 路径有但少

- 国考 / 省考"信息岗"(网信办 / 大数据局 / 公安网安)甘肃约 80-150 个/年
- **比汉语言、法学少 5-10 倍**
- **不要为了"考公"读 CS** — 甘肃考公优选专业是汉语言、法学,详见 `40_未来锚点决策/考公优选专业表.md`

## 适合什么人

- **数学好**(高中数学 130+ 是硬指标)
- **能上兰大 / 出省 985/211 CS** — 沿海大厂 / 西安华为 校招认可
- **接受出甘 + 加班 + 35 岁危机**
- **中产以上家庭**(撑得起 4 年读书 + 实习设备 + 考研复读 1-2 年)
- **明确想读研的双非生**(本科 4 年是考研跳板,本科直接就业基本无路)

## 不适合什么人

- **数学差**(高中数学 110 以下学 CS 就是硬熬)
- **想留甘 / 留兰州的** — 甘肃本地 CS 容量太小
- **农村家庭 + 双非分数** — 这个组合学 CS 等于浪费 4 年(双非本科直接就业进不了大厂,考研失败 = 留甘做外包月入 6k)
- **追求安稳 + 想考公** — 甘肃考公 CS 岗位远少于汉语言 / 法学
- **女生 + 不喜欢钻研技术 + 只想进大厂图高薪** — 性别在 IT 行业有客观隐性歧视,跨地域后竞争更惨烈

## 甘肃本地 CS 院校真实分层

### 第一梯队(能去外省大厂)
- **兰州大学 计算机科学与技术 / 软件工程** — 985,西部老牌综合,**学科评估 B+**(在 985 里偏弱,但牌子救场)。**毕业去向:60% 出甘,主要在西安华为研究所、北京字节、深圳腾讯/华为南研**;留甘约 25%(中科院兰州分院 / 兰大附属医院 IT / 省政务云)
- **西安交大 / 西工大 CS(出省)** — 甘肃考生最常见的出甘冲分选项,**比兰大 CS 录取分高 20-40 分**,但牌子在大厂校招认可度高一档(西交大 + 西工大 是西北 IT 主供给)

### 第二梯队(双非但行业内有口碑)
- **兰州理工大学 计算机** — 双非,**省内一般认可**,出甘进大厂极难,**主要走考研路径**(部分保到西交大 / 兰大),本科直接就业去向:**省内政务外包公司 / 兰州石化 IT / 国家电网甘肃电力信息中心**(5-8k 起薪)
- **兰州交通大学 计算机 / 软件工程** — 双非,**铁路 IT 方向是亮点**(中铁系统的信号控制、调度系统),**对口铁路系统 IT 有出口**(各铁路局信息中心 / 中国铁路通信信号集团),**纯互联网方向不如兰理工**
- **西北师范大学 计算机科学(师范方向)** — 双非师范,**主要出口是中学信息技术老师 / 教育系统 IT 岗**,**别为了"师大牌子"学计算机想做程序员** — 师大 CS 毕业进互联网大厂极难

### 第三梯队(避坑)
- **兰州城市学院 / 天水师范学院 / 河西学院 CS** — 二本师范 / 应用型本科,**学 CS 基本只能毕业去培训机构当销售 / 改行**。普通家庭学这个不如学护理、电气基层、师范类
- **西北民族大学 CS** — 双非民族院校,**民族学生有民族优惠政策但 CS 专业本身在民大不强**,出甘竞争力弱
- **甘肃农业大学 / 兰州财经大学 等"非 CS 主校"的 CS 系** — 边缘专业,**不如这些学校的强势专业**

## 决策映射(给 agent 用)

| 学生情况 | 推荐 |
|---|---|
| 兰大分够 + 中产家庭 + 男生 + 想冲 IT | **兰大 CS / 软件工程** + 做好出甘准备 |
| 兰大分够 + 普通家庭 | **兰大数学 / 化学**(基础学科双一流)+ 研究生转码,本科出口比 CS 更稳 |
| 211 分(西交 / 西工 / 哈工 / 北邮)+ 中产家庭 | **出省冲西交 CS / 西工 软件 / 北邮**(强烈推荐,牌子比兰大 CS 硬一档) |
| 双非分 + 想学 CS + 中产家庭 | **铁了心做 IT → 兰理工 CS + 考研出甘**;**否则改电气进甘肃电网** |
| 双非分 + 普通工薪家庭 | **直接放弃 CS → 改电气 / 测绘 / 师范类公费**(留甘编制路径) |
| 农村家庭 + 想跨阶级 | **直接放弃 CS** → 改公费师范 / 电气 / 警校(详见 `30_家庭背景_决策匹配/家庭决策矩阵.md`) |
| 想考公 + 想学技术 | **改报汉语言 / 法学**,**考公 CS 岗位远少于这两类** |

## 典型 case(供 agent 引用)

### Case A:兰大 CS 男生(兰州中产家庭)
- 兰大 CS → 大三去深圳腾讯实习 → 校招拿到字节跳动 SP offer 32w → 入行
- **但工作 5 年后想回兰州**,发现兰州唯一接得住他薪资的 IT 岗只有兰州石化信息化(年薪掉到 12w),**跨地域逆袭后回不去**
- 这是甘肃考生 CS 真实路径:**出甘是可行的,但回甘退路弱**

### Case B:兰理工 CS 男生(天水普通工薪家庭)
- 兰理工 CS → 考研失败 → 校招进兰州某政务外包公司 月薪 6.5k
- **5 年后跳槽到兰州石化信息中心** → 月薪涨到 1w + 编制
- 这是双非 CS 留甘的常见路径:**起薪低 + 5 年后稳定但天花板明确**

### Case C:西北民大 CS 女生(临夏回族家庭)
- 民大 CS → 找不到 IT 工作 → 转行做兰州某中小学信息技术老师(无编制)月薪 5k
- **典型踩坑** — 家长以为"学了计算机就能赚钱",**学校层次 + 地域 + 性别 三重劣势叠加**

### Case D:庆阳农村男生 — 改报后逆袭
- 庆阳考生 580 分物理类,**家长本想报兰理工 CS**(听邻居说"计算机好就业")
- 改报兰交大铁道电气化 → **毕业进中铁兰州局电务段 月入 9k + 编制 + 单位福利房**
- **与同班 CS 同学 5 年后差距:CS 同学留兰州做政务外包月入 7k 无编;铁道电气化在中铁兰州局 月入 1.4w + 编制 + 房补**

## 易错认知(agent 要纠正用户的)

- "**CS 就业最好**" — **5 年前的认知**。今天的真相:**985 CS 依然好就业,双非 CS 就业不如双非师范 / 电气**(尤其在甘肃这种 IT 容量小的省)
- "**学了计算机就能进华为 / 腾讯**" — 错。**双非 CS 简历进不了沿海大厂筛选系统**,需要 985 牌子或硕士学历
- "**留兰州学 CS 也能找到工作**" — 半对。**能找到,但只能找中小外包公司 / 国企信息化基层岗,起薪 5-8k**,跟你想象的"互联网高薪"完全不是一回事
- "**兰大 CS 跟华科 CS 差不多**" — 严重错误。**兰大 CS 学科评估 B+,华科 CS 全国前 10**,**沿海大厂校招认可度差一档**(兰大勉强入围,华科保送 SP)
- "**男生学 CS 才能挣大钱**" — 对一半。**前提是 985 + 中产家庭撑实习 + 抗压**,**普通工薪家庭男生学 CS 大概率挣不到大钱**
- "**考研可以救双非 CS**" — 对。**但要做好考一年 + 二战的心理准备**,西交 / 哈工 / 北邮 CS 卷度逐年上升,双非 CS 一战考上的不到 30%
- "**兰州的就业市场会越来越好**" — 半对。**兰州 IT 市场十年内的扩容主要看政务数字化 + 中科院兰州分院扩招 + 一带一路央企信息化**,**总盘子不大**

## 给甘肃家长的金句

> "你想让孩子学 CS,**先问自己:接受孩子毕业出甘吗?** 如果接受,且分够兰大 / 西交 → 学;如果只想孩子留兰州,**学 CS 不如学电气 / 公费师范**,后两者留甘编制路径明确。"

> "甘肃家长最容易踩的坑:**听邻居孩子说'去深圳搞互联网月入 3w'就觉得 CS 一定好**。那个邻居孩子大概率是 985 + 男 + 中产 + 数学竞赛底子。**你家孩子能复刻吗?复刻不了就别盲信**。"

> "**双非 CS 在甘肃 = 4 年浪费 + 考研复读 1-2 年 + 出省竞争**。同样的家庭投入,**改报兰理工电气 / 兰交大铁道 / 西北师大公费师范**,毕业直接进国家电网甘肃 / 中铁兰州局 / 甘肃市州中学编制 — 路径稳得多。"
