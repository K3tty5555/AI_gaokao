# 甘肃老高考与 3+1+2 过渡

## 核心结论

**甘肃 2021 年加入新高考第四批**(同安徽/江西/广西/贵州/黑龙江/吉林),**2021 入学高一 → 2024 首届 3+1+2 高考**。所以:

- **2021、2022、2023 高考 = 老高考**(文科 / 理科,文综 / 理综)
- **2024、2025、2026+ 高考 = 3+1+2 新高考**(物理类 / 历史类,12 种选科组合)

agent 必须根据用户届别判断走哪套口径,**不能默认所有用户都是 3+1+2**。

## 关键事实

### 老高考(2021-2023)结构
- 语文 / 数学 / 英语,各 150 分
- **文科**:文综(政治+历史+地理,共 300 分)
- **理科**:理综(物理+化学+生物,共 300 分)
- **总分 750 分**
- 用 **全国卷**(甘肃用全国 II 卷过渡到新高考 II 卷)

### 3+1+2 新高考(2024+)结构
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2024+)
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- 甘肃物理类约 60-65%,历史类约 35-40%

### 数据现状(`data/yifenduyiduan/`)
- 2021、2022、2023 → `<年>_文科_gansu.csv` / `<年>_理科_gansu.csv`(老高考)
- 2024、2025+ → `<年>_物理类_gansu.csv` / `<年>_历史类_gansu.csv`(3+1+2)
- agent 调 score_to_rank / query_school 时,**type 参数必须根据年份选对**(2024 之前用文科/理科,2024 起用物理类/历史类)

### 院校专业组(2024+ 起用)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **甘肃本科批普通类约 45 个院校专业组志愿**(具体以省考试院当年方案为准)

### 老高考填报模式(2021-2023)
- 按"院校 + 专业"模式(平行志愿)
- 服从调剂在全校范围内
- 2022 起本科一批 / 二批合并为本科批

## 甘肃特殊性(关键!!)

### 1. 1 所 985(兰州大学)= **西部唯一综合 985**

- **兰州大学**(教育部直属,985 + 双一流 A 类),化学 / 数学 / 物理 / 大气 / 生态学 / 草学 / 敦煌学 全国前列
- 兰大是**西部 12 省唯一一所综合性 985**(西交是工科见长,川大综合但不在西部腹地,兰大是西北腹地唯一综合 985)
- 出过"两弹一星"元勋多人,**学术氛围全国第一档**(但全国排名因地理偏远虚低,详见 `甘肃强校真实地位.md`)
- 211 在甘肃只有 1 所(兰大,985 也是 211)
- **甘农大、西北师大、兰交大** 都是双非但学科评估强势

**结果**:**普通家庭考生选兰大是"用低分上 985"的隐藏路径**(兰大录取分数比同档 985 低 20-40 分,因为兰州偏远导致考生用脚投票)。

### 2. 西部欠发达 = 经济落后但兰大是西部唯一综合 985

- 甘肃 GDP 全国排名后 5(2024 约 1.2-1.3 万亿,人均 GDP 全国后列)
- **没有沿海 / 长三角 / 珠三角的就业辐射**
- 兰州工业是 **石化(兰州石化)/ 铁路(兰州局集团)/ 冶金(金川公司、酒钢)/ 装备制造**
- 但**兰大的牌子在全国学术圈分量很重**(尤其化学 / 物理 / 大气 / 生态),**考研保研出口不输东部 985**

**结果**:**留甘就业的话工科+央企(铁路/石化/电网/中字头)是主流**,文科/经管在甘肃就业天花板较低,**想去市场化高薪岗位基本要出省**。

### 3. 西北民族大学 = 国家民委直属

- **西北民族大学**(原西北民院,2003 升格)是**国家民委直属高校**,藏学 / 维吾尔学 / 蒙古学 / 回族研究 / 中亚研究 强
- 培养少数民族干部、宗教研究、边疆治理人才
- **录取分数对甘肃汉族考生不算友好**(预科 / 民族班招生为主),但**对藏 / 回 / 维 / 蒙 等民族考生是政策性首选**
- **甘南 / 临夏 / 酒泉 / 张掖 等民族地区**考生应该重点关注

### 4. 中国科学院兰州分院 = 不是大学但科研重镇

- **寒区旱区环境与工程研究所(寒旱所)** — 全国冰冻圈 / 沙漠 / 高原研究 No.1
- **近代物理研究所** — 重离子物理国家级,出过国家最高科技奖得主
- **兰州化学物理研究所(兰州化物所)** — 润滑材料 / 催化全国前列
- **甘肃自然能源研究所** — 太阳能 / 风能研究

→ **兰大 + 中科院兰州分院** 的科研生态在西部独一档,**学术路径(读硕读博)的考生留兰州非常香**(兰大本 → 中科院兰州分院硕博,标准路径)

### 5. 甘肃考生约 24 万 / 年(全国中等偏小)

- 2024 高考报名 ~24-25 万(物理类约 14-15 万 / 历史类约 9-10 万)
- **录取压力比河南/山东/河北/广东 好得多**(考生少 + 兰大本省名额多)
- 甘肃考生上 985 / 211 的比例**实际比河北、河南还高**(因为兰大本身在甘肃,本地名额倾斜)

### 6. 甘肃考生**出省战略**主流(陕西/京津/沿海)

由于本省名校只有兰大 1 所 985,大部分高分考生(尤其想读非兰大优势学科 / 想去沿海就业的)都**出省**。主流流向:

| 流向 | 主要原因 |
|---|---|
| **陕西**(西安主流) | 西交 / 西工大 / 西电 / 长安大学 / 陕师大 / 西大 等 985/211,文化习惯接近,高铁 3 小时 |
| **北京/天津** | 清北 + 二线 985/211 多,实习机会丰富,**高分考生首选** |
| **沿海**(沪宁苏浙粤) | 高薪就业、长三角 / 珠三角 985/211,**留沿海难度大** |
| **东北**(大连/哈尔滨) | 大工 / 哈工大 等 985,分数性价比高 |
| **湖北**(武汉) | 武大 / 华科,工科强 |
| **四川**(成都) | 川大 / 电子科大,西部人脉相通 |

### 7. 留甘率 ≈ 50%

- 兰大本身在兰州 → 留甘比例比"本省 0 985"省份(河北/海南/内蒙古)高
- 留甘率约 50%(本科生)+ 兰大研究生留甘约 40%
- 比东北流失严重的省(吉林留省 30%、黑龙江 25%)好,**比东部沿海(留省 60-70%)低**

## 易错认知(agent 要纠正用户的)

- **"甘肃高考一直都是文科/理科"** — 错。**2024 起改 3+1+2**,2021-2023 老高考届的位次跟 2024+ 不可直接比
- **"兰大是 985 但全国排名 30+,所以不如东部 211"** — 严重错。**兰大学科评估全国前 30 的多**,只是因为兰州偏远导致考生用脚投票造成排名虚低,**保研 / 考研到东部 985 的接受度极高**(兰大 → 清北复交硕博常见)
- **"甘肃没几个好学校,只能出省"** — 半错。**普通家庭甘肃考生选兰大是性价比天花板**(用比东部 985 低 20-40 分的代价换 985 牌子 + 西部唯一综合 985 学术氛围)
- **"45 个志愿都是学校,选哪个学校都行"** — 严重错误(2024+)。**甘肃是 45 个左右院校专业组**,组内可调专业,不同组完全独立投档
- **"兰州偏远 + 没好就业,所以兰大不香"** — 不全对。**学术路径(读研读博 / 进高校)的考生兰大是西部最优**;**进市场化大公司就业** 才需要权衡兰大 vs 出省 985
- **"西北民大随便报"** — 错。**西北民大主要是少数民族倾斜招生**,汉族考生招生比例和分数线跟普通双非接近,但**学校特色 = 民族 / 边疆研究**,普通工科文科水平在西北属中等,**不要为了"民大牌子"瞎选**

## 关键提醒(agent 必须强调)

1. **甘肃约 45 个院校专业组志愿**(以当年省考试院方案为准)
2. **2024 是 3+1+2 首届**,数据参考性比老高考届差,**多看位次少看分数**
3. **再选科目限制**(必选化学/必选政治等)是硬约束,agent 要主动 check
4. **兰大本省录取倾斜明显**(本省名额多,本省考生进兰大比江苏考生进南大容易得多)
5. **西部唯一综合 985 = 兰大** 是甘肃考生的天然优势,普通家庭重点考虑
6. **兰交大铁道 / 兰理工机械 / 西北师大教育** 是甘肃双非里的"细分领域顶配",**留甘就业 + 走对口央企** 性价比极高
7. **少数民族考生**(藏 / 回 / 维 / 蒙)记得问预科 / 民族班 / 西北民大 / 民族专项 等政策路径

## 甘肃 3+1+2 投档录取流程(2024+ 起)

1. **按位次投档**:位次靠前的考生先选自己的 45 个志愿
2. **系统按 1-45 顺序检索投档**:第一个能投到的志愿组,投档
3. **投档后,本志愿组内按专业最低分录取**(如果没录取上具体专业,**服从调剂会被调到本组其他未录满专业**)
4. **不服从调剂 + 没录取上 → 退档,本批次落榜**(滑档)
5. **本科批征集志愿**:本批次落榜 → 走征集志愿(剩余名额,通常院校 / 专业层次差一档)

## 甘肃 3+1+2 与其他省份对比

| 维度 | 甘肃(第四批) | 湖北(第二批) | 江苏(第二批) | 河南(第五批) |
|---|---|---|---|---|
| 启动届 | 2024 首届 | 2021 首届(老练) | 2021 首届 | 2025 首届(同甘肃 / 山西 / 陕西) |
| 志愿数 | 约 45 | 45 | 40 | 待定(约 45) |
| 录取节奏 | 新手期波动大 | 已稳定 | 已稳定 | 新手期波动大 |
| 一分一段表 | 物理类 + 历史类 | 物理类 + 历史类 | 物理类 + 历史类 | 物理类 + 历史类 |

**结论**:**甘肃第四批 3+1+2 跟湖北 / 江苏 同模式,但湖北 / 江苏 已稳定 3-5 年,甘肃 2024 首届数据参考性差** → **agent 在 2025-2026 届为甘肃考生服务时,要明示"参考位次 + 不参考绝对分数",并在置信度声明中说明数据稳定性弱**。

## 甘肃考生填报常犯的 6 个错误

1. **盲目冲兰大冷门组(力学 / 资源勘查 / 生命科学)** — 985 牌子救不了天坑专业
2. **不勾服从调剂导致滑档** — 甘肃考生总数少,但服从调剂仍然必要
3. **看分数不看位次** — 2024 是新高考首届,绝对分数参考性差,**位次更稳**
4. **忽视国家专项 / 农林专项 / 公费师范 / 公费农学 等政策** — 甘肃农村家庭最大红利
5. **以为"汉语言文学就是当老师"** — 错过了考公王者专业
6. **追"计算机 / 金融 / 工商管理"等"全国热门专业"** — 在甘肃这些专业出口窄,留甘 = 死局

## 甘肃考生 6 月报志愿时间线

- **6 月 7-8 日**:高考
- **6 月下旬**:出分 + 一分一段表发布(以省考试院公告为准)
- **6 月下旬 - 7 月初**:志愿填报(本科提前批 + 本科批 + 专科批,各批次时间不同)
- **7 月**:本科提前批录取(军校 / 警校 / 公费师范 / 国防科大 / 部分艺术院校)
- **7 月中下旬**:本科批正式投档录取
- **8 月初**:本科征集志愿(本批次落榜走征集)
- **8 月中下旬**:专科批录取

**特别提醒**:**甘肃志愿填报时间紧**(从出分到提交不到 7 天),**家长 + 学生 + agent 都要提前 1-2 个月做模拟规划**。
