# 用户意向冲突 — Reality Check 金句库(甘肃版)

很多家长 / 考生有具体的意向("想上兰大"、"非兰州不去"、"想学医"、"想出甘读 985"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。**甘肃版重点是 reality check "出甘 vs 留甘" + "兰大 vs 出省 985" + 长周期赛道(医 / 法)对甘肃普通家庭的可行性**。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 1.5 万位次以上(甘肃考生总数比湖北少,1.5 万位次差就是巨大差距),**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **甘肃家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对甘肃普通工薪 / 农村家庭抗风险能力差,**比湖北 / 江苏更要硬讲清楚**(经济落后 + 父母老人撑不起 8 年)
6. **甘肃地域特殊**:**"出甘"是巨大决心**,family resistance 比湖北强;**"留甘"是默认期待**,违背要明示代价

---

## 5 类意向冲突 + 金句模板(甘肃版)

### 模式 A:不可达型 — 分数差距 >30 分 / >1.5 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 480 分要兰大主流组 / 580 分要清华)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [甘肃本地 / 西北行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(甘肃 480 分,意向兰大)**:
> "兰大主流组在甘肃物理类省排 2,000-5,500 名。你按位次算大概 25,000 名,差 2 万名,**兰大没戏**。
>
> 但你能上**兰理工电气 + 兰交大铁道 + 西北民大** — 这三所在甘肃本地国企 / 体制内招聘里跟兰大冷门组校友地位差不多(都是'兰州本地高校 + 留甘同档')。**专业对口性 + 实际就业反而比兰大边缘组(力学 / 资源勘查)强**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(甘肃理工 + 普通家庭,580 分意向兰大)**:
> "兰大你 580 能冲 — **但只能进生命科学 / 草学 / 力学 / 资源勘查冷门组**(2024 年甘肃录取省排 4,000-5,500 名)。
>
> **985 牌子 + 普通家庭 + 生化环材** = 三重坑(本科直接就业惨 + 必须读博 + 普通家庭撑不起 5+5)。
>
> 同分能上的**兰理工电气工程 + 兰交大铁道** 出来对口程度更高(国家电网甘肃 / 中铁兰州局 直接进编制),**留甘起薪 + 编制 + 父母安心**全赢。冲兰大留一个心理慰藉位即可。"

**特殊提醒(草学例外)**:
> "如果用户能进**兰大草学**(草业科学,全国第 1 + 学科评估 A+),**这是兰大冷门组里的例外** — 不是天坑,而是西部生态 / 国家粮食安全战略学科 + 中科院寒旱所对口 + 留甘行业内顶配。**这个'冷门'要力推不要劝退**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退(甘肃版)

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。**甘肃家庭比湖北更撑不起,要更直接劝退**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [兰大医八年制 / 出省冲西交医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 检验 / 护理本科 4 年] — 早 4 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(甘肃普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k(兰州)**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**兰大医学院 5+3 一体化 / 八年制**,长期天花板高(兰大三甲医生年入 18-25w + 编制 + 兰州房子)。
>
> 撑不起 → **建议医学影像技术 / 检验技术(甘肃医学院 / 河西学院 / 兰大医)**,**本科 4 年进市州二甲医院技术岗 + 起薪 5-7k + 编制**,早 4 年挣钱。或者放弃医学走电气 / 公费师范这种本科直接挣钱 + 编制的赛道。"

**真实案例(陇南山区农村家庭 + 孩子想学医)**:
> "你家是陇南山区农村,父母种地为主。孩子想学医 — **我直接说,临床医学不可行**:8 年读书你家撑不起,毕业后兰州三甲只要博士 = 11 年,你家更撑不起。
>
> 替代路径 1:**甘肃医学院(平凉)护理本科 / 医学影像** = 4 年回家乡某县级医院技术岗 + 编制
> 替代路径 2:**河西学院医学院 检验技术** = 4 年回河西走廊各市州医院技术岗 + 编制
> 替代路径 3:**直接放弃医学,改西北师大公费师范** = 4 年免学费 + 月补贴 + 回陇南某县中学语文教师编制
>
> 这 3 条比'硬冲临床然后中途放弃'稳得多。"

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"(甘肃版)

**特征**:**甘肃版的核心冲突 = '出甘 vs 留甘'**。
- 模式 D-1:**"非兰州不去"**(留甘派,占甘肃家长 70%+)
- 模式 D-2:**"非北京 / 非上海不去"**(出甘派,中产家庭多)

**金句模板(D-1 留甘派)**:
> "你只想留兰州,那同档要在 [兰州 + 双非] 和 [外省 + 211 / 985] 之间选。
>
> **留兰州 + 兰理工 / 兰交大 / 兰财大 / 西北师大反而更稳** —
> - 本地校友网密度大,体制内 / 国企招聘有'本地优势'(国家电网甘肃 / 中铁兰州局 / 甘肃省直机关 / 兰州石化 都是本地校园招聘)
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回甘肃没竞争力**
> - 留甘你父母也安心 + 老人陪伴
>
> 但!如果你想做的方向甘肃没强校(如想学航天 → 出甘冲西工大;想学外贸 → 出甘冲对外经贸大学),**要灵活退一步**。"

**金句模板(D-2 出甘派)**:
> "你想出甘冲北京 / 上海 / 深圳 985,这位次 [X],能上的是 [外省 985 弱专业 / 211 强专业]。
>
> **现实问题** —
> - 出甘 + 沿海读书 + 沿海就业 = 跨阶级路径,**但你家撑得起 4 年生活费(沿海每月生活费比兰州贵 30-50%)+ 实习设备 + 4 年回甘车票** 吗?
> - 父母老人接受'孩子离 2000 公里'吗?**这个意向需要全家共识**,不是孩子单方面决定
> - 出甘后想回甘,**沿海大厂 5 年经验回甘退路弱**(甘肃接得住沿海薪资的岗位极少)
>
> 替代路径:**冲西安(西交大 / 西工大)= 半出甘**(火车 5 小时,父母可常来,孩子也能常回兰州),**比直接冲北京 / 上海更平衡**。"

**真实案例(兰州中产家庭 + 法学方向 + 600 分)**:
> "你家兰州中产,孩子想留兰州 + 学法学,这位次 [省排 2,000 名内]。
>
> **留兰最稳路径**:**兰大法学**(西北法学顶配 + 选调路径)+ 父母法律 / 体制内资源 + 法考 → **甘肃省直机关 / 兰州中级法院 / 大型律所** 路径全开。
>
> 不要为了'外省 985 牌子'去东北农大 / 吉大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 户口没了**,综合不划算。**兰大法学 + 留兰州 + 选调** = 比硬冲外省 985 弱专业 综合更优。"

**真实案例(陇南农村家庭 + "非北大不去")**:
> "你家陇南农村,孩子省排 4,000 名(物理类),想'非北大不去'。
>
> **直说不可能** — 北大在甘肃物理类录取省排 100 名内,你差 39 倍。
>
> **真正的选择 = 兰大国家专项 / 强基计划 / 普通批 vs 出省 985 弱专业(吉大 / 东北 / 兰大同档外省 985)**。
>
> **农村家庭强烈推荐:兰大国家专项 + 化学 / 草学 / 数学 / 大气 / 生态** = 985 + 双一流 + 留甘 + 学费便宜 + 中科院兰州分院加持 + 父母老人在 700 公里内 → 整个家族第一个 985 + 跨阶级 + 留西部。**比硬冲北大无望、硬冲外省 985 弱专业耗钱 都强**。"

### 模式 E:民族意向 vs 家庭实际(甘肃独家)

**特征**:**甘肃多民族(回族 / 藏族 / 东乡族 / 裕固族 / 撒拉族),民族家庭可能有民族文化情怀想读民族学 / 民族院校,但实际就业出口窄**。

**金句模板**:
> "你家是 [民族] 家庭,孩子想学民族学 / 民族院校 — 我理解情怀。但要看孩子的目标:
>
> - 想做民族文化研究 / 民委系统 / 民族地区编制 → **西北民大民族学 + 民族岗位优惠**(留甘南 / 临夏 / 民族地区编制)= 路径对口
> - 想跨阶级 / 出甘 / 大厂 → **民族学专业出口窄**,改读 **兰大法学(民族学生身份只是身份,选岗范围照样大)** 或 **西北师大公费师范汉语言** 更实用
>
> **民族身份是你的政策红利,但不要被'必须读民族专业'框住** — 政策红利可以用在国家专项 / 民族优惠 / 民族岗位 上,专业方向应该按孩子未来出口选。"

**真实案例(临夏回族中产家庭 + 想让女儿读民族学)**:
> "你家临夏回族中产,女儿 580 历史类。意向'西北民大民族学'(因为是民族家庭情怀)。
>
> **直说**:民族学本科出口窄,毕业基本只能进民族地区编制(临夏州民委 / 各市州民宗局)或读研做学术。**如果你家想要孩子留临夏当地编制**,这条路成立。
>
> 但更优:**报兰大法学 / 西北民大法学(民族岗位)** → 毕业考甘肃临夏州法院 / 检察院(民族岗位优惠),**编制 + 民族优惠 + 法学专业天花板高 + 兰州 / 临夏双向选**。比纯民族学路径出口宽 5 倍。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 兰大 / 想学医 / 想留兰州 / 想出甘 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**甘肃版补充**:**"出甘 vs 留甘"在大部分甘肃家庭不是孩子单方面能决定的,是家庭文化决定** — agent 必须在 L2(家庭背景)环节就确认家庭对"出甘"的态度,**不要在 L4.5 才发现冲突再 reality check**(那时已经晚了,arch 不合理)。
