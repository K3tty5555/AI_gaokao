# 考公优选专业表(甘肃本地视角)

## 核心结论

**专业决定考公选岗范围**。甘肃家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**甘肃考公特殊背景**:
- **甘肃考公密度高**(经济落后 + 体制内偏好极强 + 农村家庭跨阶级首选路径)
- **西部大开发岗位倾斜**:甘南 / 临夏 / 陇南 / 定西 等基层岗位**国考 + 省考 + 三支一扶 + 西部志愿者** 多通道叠加
- **少数民族岗位**:回族 / 藏族 / 东乡族 / 裕固族 / 撒拉族 等民族岗位有专属指标
- **甘肃选调生 = 985/211 主供给**(兰大 / 西北师大 / 兰理工 / 兰交大 + 出甘 985/211 回甘选调)

## 关键事实(2024 国考 / 甘肃省考分析)

### 国考可报岗位数 排名(Top 10 大类)

1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 甘肃省考特殊性

- **甘肃省考 + 兰州市考**:**汉语言文学和法学并列考公第一专业**
- **甘肃各市州公务员岗位**对法学要求高(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **甘南 / 临夏 / 陇南 民族地区岗位**:有民族优惠(藏族 / 回族 / 撒拉族 等),**民族学 / 法学 / 汉语言** 是主供给
- **三支一扶 / 西部志愿者** 服务期满后定向考公:**甘肃 28 个国贫县 / 省贫县基层岗位** 服务期满后定向编制路径
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 800+ 比 1)

### 甘肃选调生(不是普通公务员,是高潜力路径)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(甘肃本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- **甘肃选调主要供给校**:**兰州大学**(主力)/ **西北师范大学** / **兰州理工** / **兰州交通大学** + **出甘 985/211 回甘选调**(西交大 / 西工大 / 哈工大 / 武大 / 等)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、**甘肃警察学院**等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**甘肃境内监狱系统**(兰州监狱 / 武威监狱 / 平凉监狱 等)主要从兰大法学 / 西北民大法学 招

### 甘肃西部大开发 + 三支一扶 / 西部志愿者特殊路径

- **三支一扶**(支教 / 支农 / 支医 / 扶贫)= 服务期 2 年后**定向考公编制**(甘肃市州县区)
- **西部志愿者**(西部计划)= 1-3 年服务期,**服务期满后考公考研有加分**
- **农村教师特岗**(甘肃 28 个国贫县)= 3 年服务期满后**定向转编**
- **甘肃农村家庭 + 三支一扶 / 特岗 = 隐藏跨阶级路径**(本科分数低也能进编)

## 甘肃本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业

- **兰州大学法学** — 985,**西北法学顶配,法考通过率高,选调路径最优**
- **兰州大学汉语言文学(文学院)** — 985,**甘肃考公王者,选调直通**
- **兰州大学经济学(经济学院)** — 985,**甘肃财政 / 税务 / 银保监对口**
- **兰州大学历史学 / 哲学 / 马克思主义理论** — 985,**党群岗 / 选调 / 党校教师**
- **兰州大学公共管理学院** — 985,行政管理 / 政治学 + 选调路径
- **西北师范大学 汉语言文学(公费师范方向)** — 不是考公但是教师编制,**等同于考公友好**

### 双非 + 性价比考公专业

- **兰州财经大学 法学 / 财政学 / 经济学 / 会计学** — 双非但财经主校,**甘肃考公认可度高,留甘考公成功率高**
- **兰州城市学院 / 天水师院 / 陇东学院 / 河西学院 汉语言文学 / 法学** — 二本中等,但**汉语言是省考王者**,**毕业考公成功率高**
- **西北民族大学 法学 / 汉语言 / 民族学** — 双非民族校,**民族学生有政策优惠**,**民族地区考公主供给**
- **甘肃政法大学**(原甘肃政法学院,**新升本科**)— **甘肃法学专业类校**,**留甘公检法系统对口**

### 公安系统专属

- **甘肃警察学院** — 本科,公安联考路径,**毕业进甘肃本地公安概率极高**(基层警察)
- **西北政法大学**(陕西西安,**出甘冲**)— **法学顶配 + 司法系统对口**
- **兰大法学 / 西北民大法学 → 监狱学方向** — **进甘肃境内监狱 / 司法系统**

### 三支一扶 / 特岗 / 西部志愿者(普通家庭跨阶级路径)

- **甘肃农业大学 / 河西学院 / 陇东学院 任意专业 + 三支一扶** → 服务期满定向编制
- **甘肃医学院(平凉) / 河西学院医学院(张掖) 护理 / 医学技术 + 支医** → 县级医院编制
- **任何师范类(西北师大 / 兰州城市学院 / 天水师院)+ 农村教师特岗** → 3 年服务期满转编

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:**陇南农村考生,540 分文史类**,普通农村家庭。家长本想报"国际经济与贸易"(听起来高大上)。**改报陇东学院汉语言文学**,毕业当年考上甘肃陇南某市直机关公务员,**家庭命运改变**
- **Case B(选调路径)**:**兰州考生,650 分文史类,中产家庭**。家长想报"金融"(兰大经济)。**改报兰大法学**,**毕业获得兰大选调生资格,直接进甘肃省委办**,起点远超经济学就业
- **Case C(失败路径)**:**张掖考生,580 分理科,普通家庭男生**。家长想"考公兜底"。**报了兰理工计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行做政务外包但因双非 CS 薪资也低,两头不靠**
- **Case D(误区路径)**:**甘肃家长以为"行政管理"是考公专业** — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(三支一扶逆袭)**:**定西农村考生,520 分理科**,**报河西学院汉语言** → **毕业三支一扶 2 年(支教定西某乡镇中学)** → **服务期满定向考甘肃定西某县编制成功**,**农村家庭跨阶级路径**
- **Case F(民族岗位)**:**临夏回族考生,560 分历史类** → **报西北民大法学** → **毕业考甘肃临夏州民委编制(民族优惠岗位)** → **回民族家乡 + 编制 + 民族补贴**
- **Case G(警校路径)**:**酒泉考生,520 分物理类,普通家庭男生** → **报甘肃警察学院侦查学** → **毕业通过公安联考进酒泉市公安局编制** → **男生普通家庭最稳路径之一**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(甘肃 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是甘肃家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**甘肃西部大开发已经过去了,没什么政策红利**" — 严重错误。**西部大开发 + 一带一路 + 乡村振兴 三重叠加**,**甘肃基层公务员 / 三支一扶 / 特岗 / 西部志愿者 政策红利仍在**
- "**三支一扶就是去农村吃苦,没前途**" — 错。**甘肃三支一扶服务期满 = 定向编制路径**,**对农村家庭分数低的孩子是隐藏跨阶级机会**
- "**民族岗位只针对少数民族学生**" — 错。**部分民族岗位"汉族 + 民族学专业 / 民族大学背景 + 当地民族文化了解" 也能报**(西北民大文凭 / 中央民大文凭 是优势)

## 关键提醒

**考公是甘肃普通家庭最稳定的上升通道**。**甘肃考公密度比湖北 / 浙江 / 江苏 都高一档**(经济落后 + 体制内偏好强 + 农村家庭刚需),**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。

**汉语言文学是甘肃家长被严重低估的考公王者**。**甘肃普通家庭最优配置 = 西北师大公费师范汉语言**(零成本 + 直接编制) **或 兰州城市学院 / 陇东学院 / 河西学院 汉语言文学**(双非 + 考公王者 + 留甘对口)。

**甘肃农村家庭独家提醒**:**国家专项 / 高校专项 / 三支一扶 / 特岗教师 / 西部志愿者 / 民族优惠** 这 6 条隐藏路径,**至少能比"裸分硬冲"多走出 2-3 条逆袭路径**。**家长不知道这些政策 = 错过孩子最重要的机会**。
