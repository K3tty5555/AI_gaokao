# 用户意向冲突 — Reality Check 金句库(宁夏视角)

很多家长 / 考生有具体的意向("想上宁大"、"非银川不去"、"想学医"、"必须出宁夏"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑)— 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 5000 位次以上(宁夏体量小,5000 位次 ≈ 沿海 2 万位次),**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **宁夏特色:留宁 vs 出区是核心议题** — 出区可能换来牌子但失去本省 211 + 本省体制内人脉,**家庭抗风险弱时留宁可能更优**

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >5000 名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 400 分要清华 / 500 分要宁大化工双一流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 千名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 211 牌子的执念,还是把 [替代校] 当作双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(宁夏 500 分,意向宁大化工双一流组)**:
> "宁大化工双一流组在宁夏物理类 2,500-4,500 名。你 9000 名,差 5000 多名,**宁大化工没戏**。
>
> 但你能上**宁医大医学影像 / 检验**(留宁三甲医院技术岗 + 编制) + **宁师院公费师范物理 / 化学**(回原籍中学教书 + 编制) + **宁夏理工学院电气 / 化工**(留宁神宁煤业基层岗也是编制)— 这三条留宁路径,**国企 / 体制内招聘里跟宁大冷门组的留宁出口实际差不多**(都是'留宁本科 + 编制 + 工作稳')。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'211 就是 211',但 **211 的材料 / 农林 / 边缘文科 出来,本科直接就业惨,工资比双非好专业还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 性价比之选]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(宁夏物理类 5500 名,意向宁大)**:
> "宁大你 5500 名能擦 — 但只能进生命科学 / 农学 / 草学 这种冷门组。**211 牌子 + 西北偏远 + 农林天坑** = 三重坑(虽然农林是宁大特色,但'草学 / 农学'本科出口偏研究院 / 政府农林,跟你想的'好就业'不是一回事)。
>
> 同分能上的 **宁医大临床 5+3 一体化**(双非顶配 + 留宁三甲编制 + 8 年医学路径) 出来对口程度更高。冲宁大冷门组留一个心理慰藉位即可。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村 / 山区家庭,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [西交医 / 宁医大 5+3])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像技术 / 护理 / 农村订单定向 / 宁医大 5+3] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(固原西吉农村家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 6-9k**。农村家庭还要供 8 年学费 + 生活费 + 不能挣钱的精神焦虑。
>
> 撑得起 → 推宁医大 5+3 一体化(双非但 4 证齐全 + 留宁三甲编制),分够直接选。
>
> 撑不起 → **建议农村订单定向医学生 + 宁医大临床 5 年制**(免学费 + 6 年回原县乡卫生院服务 + 编制保底)— 类似公费师范的医学版,**农村家庭跨阶级最稳路径**;或者放弃临床走**宁医大医学影像技术 / 检验 / 护理**(4 年本科 + 三甲技术岗 + 早 4 年挣钱)。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去" / "非出宁夏不去"

**特征**:用户只想留某个城市("非银川不去")或反过来"必须出宁夏看世界"。

**金句模板(留宁版)**:
> "你只想留银川,那同档要在 [银川 + 宁大 / 宁医大 / 北民大 / 宁师院] 和 [出区 + 985 弱专业] 之间选。
>
> **留宁夏 211 反而更稳** —
> - 本省校友网密度大,体制内 / 国企招聘有'本地优势'(宁大选调生 / 神宁煤业 / 宁夏电网 都本省优先)
> - [出区 + 弱专业 985] 牌子硬但专业坑,**毕业回宁夏没本省人脉,二次找工作很难**
> - 留宁夏你父母也安心
> - **银川房价 6-9k/㎡,生活成本极低**,留宁实际购买力 ≥ 出区
>
> 但!如果你想做的方向 [意向城] 没强校(如想学 CS → 留银川没意义,要去西电 / 北邮),**要灵活退一步**。"

**金句模板(出宁版)**:
> "你想出宁夏看世界 — 我理解。但要算清楚 3 个成本:
> - **学费 + 生活费 4 年**:出区一线城市生活成本是宁夏 2-3 倍
> - **本省人脉断层**:你回宁夏工作时,出区同学不能给你宁夏体制内 / 央企内推
> - **二次迁移成本**:出区 985 弱专业毕业,回宁夏跟本科宁大 211 强专业的同档竞争,**不一定占优**
>
> **真要出**:必选 985 + 强专业(西交 / 兰大 / 哈工大 / 北邮 / 上海大学等),**别为了'出宁夏'去末流 985 烂专业**。"

**真实案例(银川中产 + 法学方向 + 600 分历史类)**:
> "你 600 分历史类,全省 800 名。
>
> **留宁路径**:**宁大法学 + 选调生定向**(本省 211 + 父母资源对接体制内)→ 毕业直接进宁夏自治区委办 / 银川市直机关。**起点比你出区中流 985 法学高**(因为本省名额倾斜)。
>
> **出宁路径**:**中国政法大学 / 西北政法 / 西南政法**(法学专业强校)→ 毕业要回宁夏,本省人脉不如宁大同学。
>
> **判断**:你父母在银川市直机关 → **宁大法学 + 选调** 完全碾压出区。你父母没有体制资源 → 出区 985 法学也合理(走律所 / 出宁夏发展)。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**:
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 宁大化工 / 想学医 / 想留银川 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 宁夏地名 / 院校特色案例库(给 agent 引用用)

### 银川中产 + 想 985 + 不打算考研

> "你想出宁夏冲 985,但分数到末流 985 边缘。**末流 985 弱专业(国贸 / 工商管理 / 农林天坑) 不如留宁夏宁大强专业(法学 / 化工 / 葡萄酒)+ 本省体制内路径**。**别被'非 985 不去'的执念拖累**,宁夏 211 名额倾斜是普通家庭天然红利。"

### 固原山区农村 + 想出宁夏 + 父母务农

> "你想出宁夏看世界,出发点没错。但农村家庭出区有 3 个隐形成本:① 学费 + 生活费比留宁高 50%,② 大学 4 年没本省同学,毕业回宁找工作没人脉,③ 出区 985 弱专业毕业,跟宁大 211 强专业 + 国家专项的同学比,**起点反而低**。
>
> **建议路径**:**国家专项 + 宁大化工 / 法学 / 汉语言** = 用比统招低 1500-2000 名分换 211 + 双一流 + 本省人脉。出宁路径只在分够 985 强专业时才推。"

### 吴忠回族 + 想做民族干部 / 民族研究

> "你是回族 + 想走民族文化路径,**北方民族大学是国家民委直属 + 政策对口首选**。
>
> 不要为了'出宁夏'去中央民大(分高一档 + 留北京可能性低,毕业还得回宁) — **留宁北民大 + 民族班 + 民委系统编制** 比出区民族大学的体制路径更直接。
>
> 例外:分够 985(中央民大要求物理类宁夏 1500 名内 / 历史类 500 名内),且明确想走全国民族研究学术路径。"

### 银川一中考生 + 想学医 + 普通工薪家庭

> "你 580 分物理类,普通工薪家庭。**宁医大临床 5+3 一体化** 录取分约 3000-5500 名,你够了。
>
> 不要冲西交医 / 兰大医(分高一档 + 出区生活成本高 + 8 年自费),**留宁医大 5+3 = 双非顶配 + 留宁三甲编制 + 4 证齐全**。
>
> 如果家长说'必须 985 才行',反问他们:'你家撑得起出区 8 年自费医学吗?如果撑不起,985 牌子换不来三甲医院 offer。'"

### 中卫农村 + 想读 CS 进互联网大厂

> "**银川没有真互联网公司**(阿里 / 腾讯 / 字节都不在)。你想做大厂程序员,**本科必须出区**(西电 / 北邮 / 哈工大 / 西交 CS)。
>
> 如果分不够出区 985 CS,**改方向**:
> - **宁大化工 + 神宁煤业** = 留宁工科男生最稳
> - **宁师院公费师范数学** = 编制 + 寒暑假
> - **宁医大医学影像 / 护理** = 三甲医院技术岗
>
> **千万别报双非 CS 留宁** = 银川 IT 圈死局,改行率 50%+。"

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**宁夏特色补充**:
- **留宁 vs 出区** 是宁夏 reality check 的核心议题(其他省份没这么强烈)
- **本省 211 名额倾斜 + 国家专项 + 民族班** 是宁夏独家政策红利,**普通 / 农村 / 回族家庭闭眼用,千万别错过**
- **银川房价 6-9k/㎡ + 生活成本极低 + 体制内编制密度高** = 留宁实际生活质量不输沿海,**别被"宁夏没出息"的偏见绑架**
