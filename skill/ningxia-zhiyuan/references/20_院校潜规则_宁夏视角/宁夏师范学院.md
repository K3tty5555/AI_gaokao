# 宁夏师范学院(宁师院,NXNU)— 双非师范第二档,固原山区基层教师主供校

## 一句话定位

**宁夏第二档师范** —— 宁大也有师范但综合性,宁师院专攻师范。**地处固原**(宁夏南部六盘山革命老区,贫困山区),**生源 + 就业偏六盘山区域**,银川认知度低;**留宁南部山区(固原 / 中卫 / 吴忠 山区) 当中学 / 小学老师 + 公费师范 / 县级定向 + 普通家庭** → 宁师院是闭眼选;**想去东部 / 银川重点中学 / 不想当老师** → 别选宁师院。

---

## 真实地位

- **双非 + 宁夏自治区直属师范类本科院校**(**前身 1975 年宁夏师范学校,2006 年升为宁夏师范学院,2024 年更名宁夏师范大学申报中**)
- **宁夏南部师资培养主供校** —— 固原 / 中卫 / 吴忠 / 海原 / 西吉 等南部山区(六盘山革命老区) 中小学教师 50%+ 来自宁师院
- **学科评估**:**师范类专业(汉语言文学 / 数学 / 英语 / 思政 / 历史 / 地理 / 物理 / 化学 / 生物 / 体育 / 学前教育 / 小学教育)** 是核心,**非师范专业偏弱**
- **宁夏本省地位**:**留宁基层 / 山区 教育系统主力供给校 + 公费师范 / 县级定向师范 政策友好**
- **校区**:**固原市原州区**(本部,主战场,**宁夏南部六盘山革命老区**)
- **男女比**:女生明显多(师范类常态,部分院系女生 70%+)
- **辐射地理**:**固原 / 中卫 / 吴忠 / 海原 / 西吉 / 隆德 / 泾源 / 彭阳 / 同心** 宁夏南部山区为主 + **银川 / 石嘴山** 部分

## 宁夏录取位次区间

参考 2021-2025 宁夏录取数据(以一分一段表反查为准):

### 2025(物理 / 历史首届 3+1+2)

- **物理类王牌组(数学师范 / 物理师范 / 化学师范 / 生物师范)**:全区 **9,000-13,500 名**
- **物理类主流组(英语师范 / 计算机师范 / 体育)**:全区 **13,500-18,000 名**
- **物理类冷门组(部分非师范 / 应用类专业)**:全区 **18,000-25,000 名**
- **历史类王牌组(汉语言文学师范 / 思政师范 / 历史师范 / 学前教育 / 小学教育)**:全区 **3,500-6,000 名**
- **历史类主流组(英语师范 / 地理师范 / 旅游管理)**:全区 **6,000-9,000 名**
- **历史类冷门组(部分非师范 / 文科边缘)**:全区 **9,000-12,000 名**

### 2021-2024(老高考文 / 理)

- 文科:全区 **3,500-12,000 名段**(王牌 3,500-6,000,主流 6,000-9,000,冷门 9,000-12,000)
- 理科:全区 **9,000-25,000 名段**(王牌 9,000-13,500,主流 13,500-18,000,冷门 18,000-25,000)

### 公费师范 / 县级定向师范 / 国家专项

- **公费师范(自治区公费师范)**:**比普通批高 1,000-2,500 名**(竞争激烈,因为免学费 + 编制 + 回原籍服务)
- **县级定向师范(乡村教师定向)**:**比普通批低 1,000-3,000 名**,**回县级 / 乡镇服务 6 年 + 编制**
- **国家专项 / 地方专项**:**比普通批低 1,500-4,000 名**,**农村 / 县城考生超大红利**

**段位定位**:**宁夏物理类 25,000 名内 / 历史类 12,000 名内 可冲宁师院**;**公费师范 + 县级定向 + 国家专项** 是普通家庭跨阶级最稳路径。**以一分一段表反查为准**。

## 性价比专业(宁师院核心 / 公费师范)

- **公费师范生(自治区公费师范)**:**学费 + 住宿费全免 + 每月生活补贴 + 毕业回原籍服务 6 年(乡镇 / 县级中小学)+ 编制保底**,**农村 / 县城家庭普通家庭跨阶级首选** —— 类似华师 / 陕师 公费师范的本省版,**6 年服务期满后可考研 / 跳槽县级 / 市级中学**;**录取分比普通批高 1,000-2,500 名,但成本回报极高**
- **县级定向师范(乡村教师定向计划)**:**比公费师范分低 + 同样回县级 / 乡镇服务 6 年 + 编制保底**,**农村 / 县城家庭普通分数考生 = 闭眼选**;固原 / 西吉 / 海原 等贫困县乡村教师缺口大,**编制铁饭碗**
- **思想政治教育(师范)**:**留宁中学政治老师 + 党校 + 公务员考试黄金专业** —— 思政是公务员考试和事业编里最对口的专业之一,留宁考公友好,**家庭体制内导向 = 闭眼选**
- **小学教育 / 学前教育**:**宁夏基层教育铁饭碗** —— 小学 / 幼师缺口大,留宁 / 出区都好就业,**女生考公 + 编制 = 普通家庭稳定路径**
- **汉语言文学(师范)+ 公费师范**:**留宁中学语文老师** —— 语文老师全宁夏中小学缺口大 + 公费师范零成本

## 坑专业 / 慎选(在宁师院里相对弱)

- **非师范方向**:**宁师院非师范专业基本都弱**,**学非师范选宁大 / 北民大对口**
- **工科 / CS / 自动化**:**几乎不存在或很弱**,**学工科选宁大化工 / 兰理工 / 西电**
- **经济金融 / 经管(非师范)**:**双非师范的非师范经管 = 跨省竞争弱 + 留宁出口窄**,**学经管选西财 / 西交经管**
- **旅游管理 / 酒店管理**:**听起来好玩但就业窄**,**银川旅游业小,毕业改行率高**
- **应用心理学(非师范)**:**双非心理学本科出口窄**,**除非读研读博,否则就业难**
- **想去东部 / 银川重点中学当老师** → **宁师院牌子不够**(银川好中学倾向陕师大 / 西北师大 / 宁大师范),**需要慎选**

## 关键提醒(填报陷阱)

1. **公费师范 vs 普通师范 vs 县级定向**:**自治区公费师范(提前批) = 免学费 + 编制 + 回原籍 6 年服务**(分高);普通师范(普通批) = 自费 + 自己考编(分低);**县级定向(提前批) = 免学费 + 编制 + 回县乡 6 年服务**(分中)。**千万分清,差几十万学费 + 6 年服务期**
2. **公费师范"原籍服务 6 年"是硬约束**:违约要赔学费 + 写违约记录 + 影响考公考编;**家长一定要跟孩子聊清楚 6 年回原籍服务**
3. **固原 vs 银川硬约束**:**宁师院在固原,不在银川**,地理偏远 + 生活条件弱于银川;**接受 4 年固原 + 毕业回原籍县乡,与银川都市生活无关**
4. **服从调剂注意**:可能调到非热门师范(地理 / 体育 / 音美) 或非师范专业,接受不了别勾
5. **宁师院 vs 宁大师范**:宁师院 = 双非 + 固原 + 基层 / 山区 / 县乡主供 + 公费友好(分低);**宁大师范 = 211 + 双一流 + 银川 + 重点中学认可**(分高一档)。**想去银川 / 市区** → 宁大师范;**想去县乡 / 公费师范** → 宁师院
6. **2024 申报更名宁夏师范大学**:升大成功后牌子升级,但学科实力短期内不变;若 2025/2026 升大成功,录取分会上涨

## 毕业出口(2024 数据)

- **留宁 70-75%**(固原 / 中卫 / 吴忠 / 海原 / 西吉 / 隆德 / 泾源 / 彭阳 / 同心 中小学教师 + 编制 + 公费师范回原籍,基层教育路径极稳)
- **去陕甘内蒙 8-12%**(县乡中小学 + 编制 + 民办) / **去京津长三角大湾区 3-5%**(民办 / 培训机构,牌子限制大)
- **进编制 70-80%**(公费师范 100% + 县级定向 100% + 普通师范 50-60% 考编);**民办 / 培训 15-20%**;**保研考研 8-12%**(保陕师大 / 西北师大 / 北师大 / 华中师大);**改行 8-15%**(公务员 / 国企)
- **起薪**:公费师范留宁原籍县城 4-7w + 编制 + 房补 + 山区补贴 + 寒暑假(固原房价 3000-5000/㎡,生活极轻松);普通师范考编后留宁 5-8w;民办 / 培训 6-12w(不稳定);改行公务员 5-8w + 编制

**主流路径**:**公费师范 / 县级定向 → 留宁原籍县城 / 乡镇 + 编制 + 寒暑假** = 普通家庭最稳;**保研 985 / 211 师范** = 学术上行;非师范 → 改行公务员 / 国企 = 备选。

## 适合谁 / 不适合谁

**适合**:宁夏物理类省排 9,000-25,000 名 / 历史类 3,500-12,000 名;**想当中小学老师 + 留宁夏南部 / 山区 / 县乡 + 农村 / 县城家庭** → 宁师院 + 公费师范 / 县级定向 闭眼选;**思政教育**(考公黄金专业);小学 / 学前教育(基层铁饭碗);女生 + 编制 + 寒暑假;接受固原 4 年生活 + 回原籍 6 年服务

**不适合**:想去银川 / 市区重点中学(选宁大师范 / 陕师大)、不想当老师 / 想做市场化高薪、怕固原 / 山区 / 县乡环境、学非师范专业(选宁大 / 北民大)、学工科 / CS / 经管(基本不存在)、想做学术顶级研究、不能接受公费师范 6 年服务期
