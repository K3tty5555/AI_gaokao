# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(宁夏视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪 / 农村家庭和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**宁夏特殊性**:
- 0 个 985 + 1 个 211(宁大,化工双一流)→ **本省 211 名额倾斜 + 普通家庭低分上 211 是天然红利**
- 神宁煤业 / 隆基绿能 / 国家电网宁夏 / 宁夏盐池天然气 = 留宁工科 + 编制路径标准
- 回族占 1/3 + 国家民委政策 + 宁夏南部山区(固原 / 海原 / 西吉) 国家专项 / 地方专项 红利极大
- 银川房价 6-9k/㎡ + 生活成本极低 → **留宁月薪 8k 等于沿海 1.5w 购买力**,对普通 / 农村家庭比沿海实际更友好

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障(如自治区直属机关 / 银川市直 / 各市州政府 / 宁夏电网 / 神宁煤业 / 国企事业单位)。

**家庭画像(宁夏视角)**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **宁夏体制圈子小**:银川某局长跟某科长可能相邻办公,父母人脉直接落到孩子岗位选择上

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 思政教育 / 行政管理(体制内对口岗位多)
2. **211 选调生路径**:**宁大(本省唯一 211 / 双一流)选调路径** = 宁夏体制内子女最优路径(本省名额倾斜 + 父母资源对接)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:宁夏警官职业学院 + 公安联考 = 父母编制资源能用上;**宁夏自治区公费师范** = 教师编路径

**典型 case**:
- 银川某中产体制内家庭(父亲自治区直属机关,母亲宁夏电网)→ 孩子 590 分历史类(全省 1500 名)→ 推**宁大法学** → 毕业选调进宁夏自治区委办,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去出区某 985 CS → 毕业 30w 起薪很高,但家长不满"不稳定 + 出宁夏",劝其离职考公,**两年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域(如宁医大总院医生、银川一中教师、宁夏电力设计院工程师、宁夏律所律师)。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:
   - 教师家庭 → 宁师院 / 宁大 师范 + 公费师范(回原籍服务)
   - 医生家庭 → 宁医大临床 5+3 / 口腔(8 年长周期父母能撑 + 三甲医院推荐通道)
   - 工程师家庭(宁夏电力 / 神宁煤业 / 隆基)→ 宁大电气 / 化工 / 自动化(行业资源直接对接)
2. **行业相关延伸**:律师家庭 → 法学(宁大法学 / 出区中国政法 / 西北政法);医生家庭 → 出区 985 医(西交医 / 兰大医)
3. **不必选最稳路径**:有专业拐杖,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(宁夏没金融行业资源,出宁夏家庭撑不起 5 年从零起步)

**典型 case**:
- **母亲银川一中语文老师 + 父亲普通工薪** → 孩子 540 分历史类(全省 3000 名)→ **宁师院公费师范汉语言**(回银川或周边县) → 毕业回银川或近郊编制,**母亲资源直接复用**(知道哪个学校好进、哪个区编制竞争小)
- **父母都是宁医大总院临床医生** → 孩子 600 分物理类(全省 3500 名)→ **宁医大临床 5+3 一体化** → 父母能撑 8 年读书 + 总院规培推荐 → **典型子承父业路径**
- **父亲宁夏电力公司工程师** → 孩子 580 分物理类(全省 4000 名)→ **宁大电气** → 暑期到父亲单位实习 → 校招直接进宁夏电网银川供电公司,**父子同事**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主(如宁夏建材老板 / 餐饮连锁 / 物流公司 / 葡萄酒酒庄主)。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **宁夏私企家庭比例不高**(经济结构以央企国企为主),但银川 / 吴忠 / 中卫 仍有一批中型私企家庭

**推荐策略**:
1. **可选商科 / 创业方向**:出区西财 / 西交经管 / 央财 / 上财(宁大经管偏弱)
2. **可冲名校弱专业**:有家庭兜底容错率高,可走"读研补救"路径
3. **可考虑出国 / 中外合作办学**:宁夏家庭出国比例不高,但中产私企家庭出国意愿在涨
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **可走葡萄酒 / 文旅产业**:**贺兰山东麓产区是中国葡萄酒第一产区** + **沙坡头 / 西夏王陵 / 镇北堡 文旅红利** → 葡萄与葡萄酒工程(宁大特色) / 旅游管理 / 文化产业管理 等可走家族产业接班
6. **避免:进体制内基层公务员**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 银川某餐饮连锁老板家庭(年入 100-200w)→ 孩子 580 分物理类 → 推**出区西安交大经管 / 中外合作办学**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班
- **银川贺兰山酒庄家庭** → 孩子 520 分物理类(全省 9000 名)→ **宁大葡萄与葡萄酒工程**(全国稀缺特色) → 家族酒庄接班 + 行业人脉(宁夏 200+ 酒庄圈子)
- 失败 case:私企家庭 → 孩子被推考公 → 进银川某区基层公务员后被父母嫌"没出息 + 一辈子月薪 6k" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员 / 神宁煤业一线)

**定义**:父母双方或一方稳定工作但收入有限(神宁煤业一线工人 / 银川各社区工作者 / 中卫 / 吴忠 中小企业员工 / 公交司机 / 出租车 等),家庭年收入 8-25 万为主。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **宁夏特殊**:父母可能本身就在神宁煤业 / 隆基 / 央企工作,**对工科 + 编制路径有直觉认同**

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(宁师院 / 宁大)** = 高考分适中 + 直接编制 + 无学费
   - **宁夏警官职业学院 + 公安联考** = 进警察系统编制
   - **农村订单定向医学生(宁医大)** = 公费医学 + 6 年回乡服务 + 编制
   - **医学影像技术 / 检验(宁医大)** = 三甲医院技术岗 + 4 年本科即可
3. **次推稳定就业型**:
   - **宁大电气 / 化工** + 神宁煤业 / 国家电网宁夏 / 隆基绿能(留宁工科男生神器)
   - 师范类(汉语言 / 数学师范)+ 留宁中小学
   - 护理(本科,出国跳板路径)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局,**留宁 + 双非经管 = 改行率 50%+**)
   - 双非 CS(银川没互联网公司,起薪跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 临床医学(5+3+规培 8 年长周期,撑不起 — 改 5+3 一体化或农村订单定向)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- **宁东神宁煤业工人家庭** → 孩子 580 分物理类(全省 4500 名)→ 推**宁大电气** → 毕业进宁夏电网或回神宁煤业,**月入 9-11k + 编制 + 房补,家庭逆袭**(银川房价 7000/㎡,真实购买力比沿海 1.5w 高)
- **银川某社区工作者家庭** → 孩子 540 分历史类(全省 3000 名)→ 推**宁夏大学汉语言文学** → 毕业当年考上银川市直机关公务员,**家庭命运改变**
- **中卫某出租车司机家庭** → 孩子 520 分物理类(全省 9000 名)→ 推**宁医大医学影像技术 / 护理学** → 毕业进中卫市三甲医院技术岗 + 编制,**普通家庭医学路径**
- **石嘴山某工厂家庭** → 孩子 480 分物理类(全省 13500 名)→ 推**宁师院公费师范数学 / 物理(回石嘴山服务)** → 毕业回原籍中学教书,**编制 + 寒暑假**

## 档位 ⑤ 农村 / 临工 / 山区家庭(宁夏南部六盘山区)

**定义**:父母务农 / 临时工 / 零散工作(固原 / 西吉 / 海原 / 隆德 / 泾源 / 彭阳 / 同心 等南部六盘山区,以及银川 / 中卫 / 吴忠 周边农村),家庭年收入通常 < 8 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **宁夏特殊**:**国家专项 / 地方专项 / 民族班 政策红利极大** — 宁夏南部山区是国家级贫困区(脱贫前是六盘山革命老区贫困带),政策倾斜密度全国前列

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 211(宁大)牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(宁师院 / 宁大)= 农村家庭神器**(无学费 + 编制 + 寒暑假)
   - **农村订单定向医学生(宁医大)= 公费医学**(无学费 + 编制 + 6 年回乡服务)
   - **国家专项 / 地方专项**:宁夏南部山区户籍的核心红利,985/211 专项指标多,分数比统招低 1500-4000 名
   - **宁夏警官职业学院 / 公安院校** = 无学费 + 编制 + 包分配
3. **避免长周期投入**:
   - 临床医学 8 年(撑不起,改农村订单定向 5 年制)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:宁夏农村户籍,985/211 名校多个专项指标(分数比统招低 1500-4000 名,**比湖北 / 河南 农村专项还猛**)
   - **地方专项**:回宁夏指定区县服务
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **少数民族骨干计划**(回族 / 藏族 / 维吾尔族 / 蒙古族):北方民族大学预科 + 专项
   - **宁夏自治区民族班 / 预科**:学制延长 1 年(预科 1 年 + 本科 4 年)+ 政策友好

**典型 case**:
- **固原西吉农村家庭** → 孩子 530 分物理类(全省 9000 名,但有南部山区户籍)→ 通过**国家专项**进**宁夏大学化工(双一流)**(比统招分低 2000+ 名)→ 毕业进神宁煤业宁东基地,**整个家族第一个 211 + 第一个央企编制**
- **海原回族农村女孩** → 525 分历史类(全省 4500 名)→ **宁师院公费师范汉语言**(免学费 + 回原县中学服务 6 年) → **农村跨阶级 + 整个村庄第一个本科生**
- **同心回族男生** → 510 分物理类(全省 12000 名)→ **农村订单定向 + 宁医大临床 5 年制**(免学费 + 6 年回原乡卫生院服务)→ 整个家族第一个医生
- **彭阳农村男生** → 数学单科 140+ 但总分 540 → **强基计划 + 出区西交数学**(比统招分低 60-80) → **985 + 跨阶级路径**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 宁夏额外约束(agent 必查)

**判定家庭档位时,宁夏额外要问 3 个问题**:

1. **户籍 — 银川主城 / 银川周边县乡 / 石嘴山 / 中卫 / 吴忠 / 固原南部六盘山区?**
   - 南部山区(固原 / 海原 / 西吉 / 隆德 / 泾源 / 彭阳)= **国家专项 / 地方专项 / 民族班 红利核心区**,普通 / 农村家庭闭眼报专项
2. **回族 / 汉族 / 其他少数民族?**
   - **回族 + 想走民族干部路径** → 北方民族大学是政策性首选(国家民委直属)
   - **汉族 + 学非民族特色专业** → 北民大不如其他对口
3. **父母是否在神宁煤业 / 国家电网 / 国家能源集团 / 隆基绿能 / 大唐 / 华能 / 宁夏建投 等央企国企?**
   - 是 → 走档位 ②(专业人员家庭),工科 + 子承父业路径
   - 否 → 走档位 ③ / ④ / ⑤
