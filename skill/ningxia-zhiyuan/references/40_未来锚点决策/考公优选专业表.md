# 考公优选专业表(宁夏本地视角)

## 核心结论

**专业决定考公选岗范围**。宁夏家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**宁夏考公独特优势**:
- 考生约 7 万 / 年(全国最少之一),**省考竞争比 1:20-1:30 起,远低于沿海 1:200+**
- **南部山区(固原 / 海原 / 西吉 / 同心)基层岗位经常报名不满**,农村 / 县城考生几乎闭眼上岸
- **宁夏选调生路径** 主要走宁大(本省唯一 211 / 双一流),本省考生天然优势
- **西部大开发 + 民族(回族)双倾斜** = 体制内身份天花板比沿海高

## 关键事实(2024 国考 / 宁夏省考分析)

### 国考可报岗位数 排名(Top 10 大类)

1. **法学** — 法院 / 检察院 / 监狱 / 纪委监委 等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政 / 税务 / 海关 / 银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗 / 办公室 / 宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗 / 网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局 / 税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗 / 宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局 / 纪委 → 约 3%
9. **医学相关** — 卫健委 / 疾控 / 医院管理 → 约 3%
10. **外语(英语 / 阿拉伯语 / 维吾尔语 等)** — 外交部 / 海关 / 商务部 → 约 2%(**宁夏阿语 / 维语对一带一路驻外岗有特殊红利**)

### 宁夏省考特殊性

- **宁夏自治区直属机关 / 银川市直 / 5 个地市考公** = 体量小但岗位齐全
- **汉语言文学和法学并列考公第一专业**
- **宁夏各地市公务员岗位对法学要求高**(法院 / 检察院 / 司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言 / 行政管理 / 法学 / 思政教育** 仍占主流
- **南部山区(固原 / 海原 / 西吉 / 隆德 / 泾源 / 彭阳)基层岗** 经常报名不足,**愿意去山区的考生几乎闭眼上岸**
- **三不限岗位**:**所有人都能报,但竞争最激烈**(可能 1:50-1:100,跟沿海比仍算友好)
- **宁夏选调生** = 党政机关后备干部储备,**起点比普通公务员高**
- **宁大 211 + 双一流 是宁夏选调生定向计划主供** + 部分省内重点本科

### 选调生(不是普通公务员,是高潜力路径)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(宁夏本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- **宁大本科 + 优秀党员 / 学生干部** = 进选调生定向名单概率极高(本省名额倾斜)
- 优势专业:**法学 / 汉语言文学 / 马克思主义理论 / 思政教育 / 行政管理 / 经济学**

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学 / 中国刑警学院 / 宁夏警官职业学院 / 西北政法 等)+ 通过公安联考
- **法院 / 检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱 / 戒毒**:法学 + 监狱学 (中央司法警官 / 宁夏警官职业学院 对口)

### 宁夏的"民族岗 / 双语岗"特殊机会

- **回族干部岗 + 阿拉伯语 / 维吾尔语 / 蒙古语 干部岗** = 宁夏 / 临夏 / 吴忠 / 同心 / 海原 等回族聚居区有专项
- **北方民族大学**(民族学 / 阿语 / 维语)= 民族岗对口
- **国家民委系统 / 各级民委**(自治区 / 银川市 / 各地市) = 政策性岗位,专业对口要求高(民族学 / 阿拉伯语 / 民族语言文学)
- **海关 / 边检(中宁夏没有海关边境,但银川海关 + 中阿自贸区相关岗) + 中阿合作论坛办公室**(银川主办)= 阿语 / 阿拉伯研究 对口

## 宁夏本地院校 × 专业组合(考公视角)

### 211 + 强势考公专业

- **宁大法学** — 全省最强,**法考通过率高 + 选调路径优**
- **宁大马克思主义理论** — B+ 学科评估,**选调生黄金专业**
- **宁大汉语言文学** — 211 文学院,留宁考公 / 进文化系统编制对口
- **宁大经济学 / 财政学 / 会计学** — 211 经管,留宁财税 / 国企对口

### 双非 + 性价比考公专业

- **宁师院汉语言文学 / 思想政治教育(师范)** — 双非但**汉语言 + 思政是省考王者**,毕业考公成功率高
- **北民大法学 / 民族学 / 阿拉伯语** — 双非但**民族岗 + 一带一路对口**,**回族考生 + 民族干部路径** 政策红利
- **宁医大公共卫生与预防医学** — 双非但卫健委 / 疾控 / 海关检疫岗对口

### 公安系统专属

- **宁夏警官职业学院** — 专科 / 本科,**公安联考路径,本省录用率高**(宁夏公安系统主供校)
- **中国人民公安大学 / 中国刑警学院 / 中国人民武装警察部队学院** — 出区公安顶配
- **西北政法大学 侦查学 / 监狱学** — 进司法系统 + 西北体制内
- **中央司法警官学院 监狱学** — 全国监狱系统主供校

## 典型 case(供 agent 引用)

### Case A(逆袭路径):固原西吉农村考生
- 540 分文史类(全省 3000 名),普通农村家庭。家长本想报"国际经济与贸易"(听起来高大上)
- **改报宁夏大学汉语言文学 + 国家专项**(比统招分低 1500-2000 名),毕业当年考上**宁夏自治区直属某机关公务员**
- **整个村庄第一个本科生 + 第一个公务员**,家庭命运改变

### Case B(选调路径):银川一中考生
- 600 分历史类(全省 800 名),中产家庭(父亲银川市直机关)。家长想报"金融"(出区央财)
- **改报宁大法学 / 思政**,**毕业获得宁夏自治区委选调生定向资格,直接进自治区委组织部**,起点远超出区金融就业(银川生活 + 父母资源对接)

### Case C(失败路径):中卫考生
- 580 分理科,普通家庭男生。家长想"考公兜底"
- **报了宁大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行做程序员但银川没大厂,工资也低,两头不靠**

### Case D(误区路径):银川考生
- 家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**

### Case E(回族民族干部路径):吴忠回族考生
- 530 分文史类(全省 4500 名)。**北民大民族学 / 阿拉伯语 + 民族班** → 毕业进**国家民委系统 / 宁夏自治区民委 / 中阿合作论坛办公室** 政策性岗位
- **回族干部主供校 + 国家民委直属牌子** + 宁夏 / 临夏 / 吴忠 等回族聚居区干部缺口

### Case F(山区基层闭眼上岸):彭阳农村女生
- 510 分文史类(全省 5500 名)。**宁师院公费师范汉语言 + 县级定向(回原县彭阳)**
- 毕业回彭阳县中学语文老师 + 编制 + 寒暑假
- **编制门槛极低**(山区报名不满)+ 公费师范零成本,**农村女生跨阶级最稳路径**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(宁夏 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸 / 工商管理) = 不如 211 + 好专业(法学 / 汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**(宁夏警官职业学院本省录用率高)
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对宁大学生而言**,选调生比国考省考好考(本省名额倾斜 + 211 资格自动具备)
- "**汉语言文学就是当老师**" — 严重错误。**这是宁夏家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**宁夏考公竞争跟河南山东一样卷**" — 错。**宁夏考生 7 万 / 年 + 体制岗位齐全 + 山区基层报名不满 = 整体竞争比沿海低 5-10 倍**
- "**民族岗只有少数民族能报**" — 错。**民族岗有专项,但部分综合岗汉族也能报**;**真要走民族干部路径 → 北民大对口**
- "**汉语言文学是女生专业**" — 严重错误。**男生考公学汉语言更香**(行测优势 + 男生考公成功率不输女生 + 宁夏体制内男干部需求大)

## 关键提醒

**考公是宁夏普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。

**宁夏考公的几条最稳路径**:
1. **宁大汉语言 / 法学 / 思政 + 选调生定向** = 本省 211 + 体制内高起点
2. **宁师院公费师范 + 县级定向 + 教师编** = 农村 / 县城家庭跨阶级最稳路径(教师也是事业编)
3. **宁大或双非汉语言 + 银川市直 / 自治区直属考公** = 留银川 + 体制内
4. **山区基层岗(固原 / 海原 / 西吉 / 同心)+ 任何文科专业** = 几乎闭眼上岸(报名不满)
5. **北民大民族学 / 阿语 + 国家民委 / 民族干部岗** = 回族考生政策性首选
6. **宁夏警官职业学院 + 公安联考** = 公安系统编制(本科即可)

**汉语言文学是宁夏家长被严重低估的考公王者**(跟河南 / 河北 / 山东 同理,且因宁夏体量小竞争更友好)。
