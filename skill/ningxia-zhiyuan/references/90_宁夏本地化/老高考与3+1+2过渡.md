# 宁夏老高考与 3+1+2 过渡

## 核心结论

**宁夏 2022 年加入新高考第五批**(同四川/河南/山西/云南/青海/内蒙古/新疆/西藏),**2022 入学高一 → 2025 首届 3+1+2 高考**。所以:

- **2021、2022、2023、2024 高考 = 老高考**(文科 / 理科,文综 / 理综)
- **2025、2026+ 高考 = 3+1+2 新高考**(物理类 / 历史类,12 种选科组合)

**宁夏比甘肃晚一届进新高考**(甘肃 2021 入学 / 2024 首届,宁夏 2022 入学 / 2025 首届),agent 必须根据用户届别判断走哪套口径,**不能默认所有用户都是 3+1+2**。

## 关键事实

### 老高考(2021-2024)结构
- 语文 / 数学 / 英语,各 150 分
- **文科**:文综(政治+历史+地理,共 300 分)
- **理科**:理综(物理+化学+生物,共 300 分)
- **总分 750 分**
- 用 **全国卷**(宁夏过去用全国 II 卷,跟甘肃 / 陕西 一脉)

### 3+1+2 新高考(2025+)结构
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2025+)
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- 宁夏物理类约 60-65%,历史类约 35-40%(预估,首届数据待出)

### 数据现状(`data/yifenduyiduan/`)
- 2021、2022、2023、2024 → `<年>_文科_ningxia.csv` / `<年>_理科_ningxia.csv`(老高考)
- 2025+ → `<年>_物理类_ningxia.csv` / `<年>_历史类_ningxia.csv`(3+1+2)
- agent 调 score_to_rank / query_school 时,**type 参数必须根据年份选对**(2025 之前用文科/理科,2025 起用物理类/历史类)

### 院校专业组(2025+ 起用)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **宁夏本科批普通类约 45 个院校专业组志愿**(具体以自治区考试院当年方案为准)

### 老高考填报模式(2021-2024)
- 按"院校 + 专业"模式(平行志愿)
- 服从调剂在全校范围内
- 本科一批 / 二批合并为本科批的时间略晚于沿海

## 宁夏特殊性(关键!!)

### 1. 0 所 985 + 1 所 211(宁夏大学)= **西部计划升级的隐藏路径**

- **宁夏大学**(教育部 + 自治区共建,**211 + 双一流**,**化学工程双一流**),宁夏唯一 211/双一流
- **没有 985**,本省顶级大学只有宁大一所 211
- **北方民族大学**(国家民委直属,银川)双非但少数民族研究强
- **宁夏医科大学**(银川)双非但临床医学全国前列
- **宁夏师范学院**(固原)双非师范第二档

**结果**:**普通家庭考生选宁大是"用低分上 211"的隐藏路径**(宁大本科录取分数比同档 211 低 30-50 分,因为宁夏地理偏远 + 银川认知度低,沿海考生不来报)。

### 2. 西部欠发达 + 自治区体量小 = 经济落后但本科分数线偏低

- 宁夏 GDP 全国排名末位区间(2024 约 5500-6000 亿,人均 GDP 中等)
- **没有沿海 / 长三角 / 珠三角的就业辐射**
- 银川经济支柱:**煤炭(宁东能源化工基地)/ 光伏(隆基绿能等新能源)/ 葡萄酒(贺兰山东麓产区)/ 装备制造**
- 但**宁大的化工双一流 + 宁夏煤化工基地**对口度高,留宁工科+央企走得通

**结果**:**留宁就业的话工科+能源央企(煤炭/光伏/化工/电网)是主流**,文科/经管在宁夏就业天花板较低,**想去市场化高薪岗位基本要出区**。

### 3. 回族多元 = 自治区民族特色明显

- **回族占自治区人口约 35%**(全国回族最集中的地区,临夏、银川、吴忠、固原 都是回族聚居区)
- **北方民族大学**(银川,国家民委直属)是**回族 + 藏族 + 维吾尔族 + 蒙古族 干部培养主力校**
- **宁夏医科大学** 有**回族医学**(中医结合回回药方研究)特色
- **清真饮食友好** + **回族文化研究** 在宁夏有深厚基础

**结果**:**回族考生 + 想走民族干部 / 民族研究路径** → 北方民族大学是首选(政策倾斜 + 民族班);**汉族考生** 选北方民大要看具体专业。

### 4. 宁夏 211 名额相对宽松 = 普通家庭低分上 211 隐藏路径

- 宁夏考生约 7 万 / 年(全国最小高考省份之一,跟青海 / 西藏 / 海南 一档)
- **宁大本科招生约 4500-5000 人/年,本省名额占 50%+**(远高于沿海 985 投本省比例)
- **宁夏考生上 211 比例**(主要靠宁大消化)实际比河北、河南 高得多
- 国家专项 / 地方专项 / 民族班 政策倾斜明显

**结果**:**普通家庭宁夏考生选宁大是性价比天花板**(用比东部 211 低 30-50 分换 211 牌子 + 双一流学科 化工)。

### 5. 银川经济支柱 = 煤炭 / 光伏 / 葡萄酒 / 装备制造

- **宁东能源化工基地**(神宁煤化工 / 国家能源集团 宁夏煤业):全国煤化工龙头之一,**宁大化工 / 宁大材料 对口**
- **隆基绿能 / 中环光伏**(宁夏光伏制造):国内光伏头部,**电气 / 自动化 / 材料 对口**
- **贺兰山东麓葡萄酒产区**(全球新兴产区,跟法国波尔多齐名):**葡萄与葡萄酒工程**(宁大食品 / 宁夏大学葡萄酒学院)对口
- **石嘴山装备制造**(国电吴忠 / 宁夏共享集团):**机械 / 材料 对口**

**结果**:**留宁工科 + 进央企 / 国企**(神宁煤业、隆基绿能、宁夏电网、宁夏建设投资集团)是宁夏本地最稳路径,起薪不高但**生活成本低 + 编制稳**。

### 6. 宁夏考生约 7 万/年(全国最小)

- 2024 高考报名 ~7 万(理科约 4-4.5 万 / 文科约 2.5-3 万)
- **录取压力比河南/山东/河北 好得多**(考生少 + 宁大本省名额倾斜)
- 本科分数线偏低,因为体量小 + 欠发达地区不卡线

### 7. 宁夏考生**出区战略**主流(陕西/甘肃/京津/沿海)

由于本省名校只有宁大 1 所 211,大部分高分考生(尤其想读非宁大优势学科 / 想去沿海就业的)都**出区**。主流流向:

| 流向 | 主要原因 |
|---|---|
| **陕西**(西安主流) | 西交 / 西工大 / 西电 / 长安大学 / 陕师大 / 西大 等 985/211,文化习惯接近,高铁 5 小时 |
| **甘肃**(兰州) | 兰州大学(西部唯一综合 985)+ 兰交大铁道 + 兰理工机械,文化最接近 |
| **北京/天津** | 清北 + 二线 985/211 多,实习机会丰富,**高分考生首选** |
| **沿海**(沪宁苏浙粤) | 高薪就业、长三角 / 珠三角 985/211,**留沿海难度大** |
| **新疆 / 内蒙** | 石河子 / 内大 等 211,西部计划路径 |

### 8. 留宁率 ≈ 40-50%

- 宁大本身在银川 → 留宁比例不算特别低
- 留宁率约 40-50%(本科生)
- 比东北流失严重的省(吉林留省 30%、黑龙江 25%)略好,**比东部沿海(留省 60-70%)低**

## 易错认知(agent 要纠正用户的)

- **"宁夏高考一直都是文科/理科"** — 错。**2025 起改 3+1+2**,2021-2024 老高考届的位次跟 2025+ 不可直接比
- **"宁大是双非吧?"** — 严重错。**宁大是 211 + 双一流(化学工程)**,只是因为宁夏地理偏远 + 沿海考生不报,**录取分数比同档 211 低 30-50 分**,**普通家庭低分上 211 的隐藏路径**
- **"宁夏没几个好学校,只能出区"** — 半错。**普通家庭宁夏考生选宁大是性价比天花板**(用比东部 211 低 30-50 分的代价换 211 牌子 + 化工双一流学科)
- **"45 个志愿都是学校,选哪个学校都行"** — 严重错误(2025+)。**宁夏是 45 个左右院校专业组**,组内可调专业,不同组完全独立投档
- **"银川偏远 + 没好就业,所以宁大不香"** — 不全对。**留宁工科+能源央企** 路径(神宁煤业 / 隆基光伏 / 宁夏电网)起薪不低,生活成本极低,编制稳;**进市场化大公司就业** 才需要权衡宁大 vs 出区 985/211
- **"北方民大 = 普通双非"** — 不全对。**北方民大是国家民委直属**,**少数民族干部培养** 是国家战略对口,**回 / 藏 / 维 / 蒙 / 哈 等族考生** 优先;**汉族考生** 看具体专业,非民族特色专业水平 = 普通双非
- **"宁夏 211 名额倾斜很大"** — 对!**这是宁夏考生的天然红利**,本省考生进宁大比江苏考生进南大容易得多,**普通家庭重点利用**

## 关键提醒(agent 必须强调)

1. **宁夏约 45 个院校专业组志愿**(以当年自治区考试院方案为准)
2. **2025 是 3+1+2 首届**,数据参考性比老高考届差,**多看位次少看分数**
3. **再选科目限制**(必选化学/必选政治等)是硬约束,agent 要主动 check
4. **宁大本省录取倾斜明显**(本省名额多,本省考生进宁大比江苏考生进南大容易得多)
5. **西部 0 985 / 1 211(宁大)= 普通家庭低分上 211 隐藏路径**,普通家庭重点考虑
6. **宁大化工双一流 + 神宁煤业 / 隆基光伏 / 贺兰山葡萄酒** 是宁夏本地工科性价比顶配,**留宁就业 + 走对口央企** 的男生重点考虑
7. **回族 / 藏 / 维 / 蒙 等少数民族考生**记得问预科 / 民族班 / 北方民大 / 民族专项 等政策路径
8. **宁夏体量小 = 报名压力小**,这是天然优势,**别盲目复制河南河北的"卷"叙事**

## 2025 年宁夏 3+1+2 首届特殊性(agent 必读)

### 数据参考性问题
- **2025 是宁夏 3+1+2 首届,无历年位次可对比**
- **位次换算口径变了**:老高考"理科 1 万名"和新高考"物理类 1 万名"**不能直接划等号**(物理类报考人数预计占 60-65%,历史类 35-40%)
- **agent 务必告诉用户**:2025 届位次跟 2021-2024 老高考届位次**只能粗略参考,不能精确对照**

### 位次换算粗略口径(给 agent 参考)
- 老高考"理科 X 名"≈ 新高考"物理类 X × 0.7-0.8 名"(物理类报考人数比老理科少一点,因为部分老文科考生选物理后变成"物理类")
- 老高考"文科 X 名"≈ 新高考"历史类 X × 1.1-1.2 名"(历史类报考人数比老文科多一点,因为部分理科生选历史)
- **这只是粗略估计,精确数据要等 2025 一分一段表出来后**

### 老高考届考生(2024 届及之前)的特殊处理
- **2024 高考及之前是老高考(文 / 理)**,如果用户是老高考届考生(已经毕业 / 复读),走老高考口径(`<年>_文科_ningxia.csv` / `<年>_理科_ningxia.csv`)
- **2025 起用 3+1+2(物理 / 历史)**,走新口径
- **复读生注意**:2025 起复读生也按新高考报考,需要重新选科 + 适应院校专业组规则

## 出分前规划场景(模考期 agent 触发口径)

宁夏家长在**模考阶段**(高三上学期 11-12 月模考 / 高三下学期一二三模) 来咨询的常见问题:

| 场景 | agent 应对 |
|---|---|
| "孩子模考 540,能上什么学校?" | **先用 score_to_rank 粗估位次**,再讲"位次比分数更准 + 模考分数水分大,看趋势不看绝对值" |
| "选科还能不能改?" | 高一选科确定后基本不能改,**但 2026/2027 届还有选科窗口期**(高一上学期末 / 高二上学期前) |
| "孩子物 / 化 / 政,临床医学能报吗?" | **必须再选化学**,但部分医学院还要再选生物,**先 check 目标院校招生章程** |
| "孩子物 + 政 + 地能报临床吗?" | **不能**(必须再选化学)。**改方向**:中医学(部分院校允许) / 医学技术 / 公共卫生(看具体院校) |

## 出分后填报场景(7 天紧急填报)

宁夏出分通常在**6 月 23-25 日**,本科批填报通常在**6 月底-7 月初**(具体看当年自治区考试院方案):

1. **第 1-2 天**:出分 → 查一分一段表 → 确定全省位次 → 计算冲稳保 3 档分数线
2. **第 3-4 天**:筛选可达学校(按位次)+ 确定意向城市 / 行业 → **本文件 + 20_院校档案 + 50_反常识 一起用**
3. **第 5-6 天**:填 45 个院校专业组志愿 → 排"冲(8-12)→ 稳(15-20)→ 保(8-15)" 梯度
4. **第 7 天**:确认服从调剂 + 检查再选科目限制 + 提交

**agent 在出分后场景的关键工作**:
- 用 query_school 拿目标校历年录取位次
- 反算用户位次能上的"冲 / 稳 / 保" 院校组
- **强烈提醒服从调剂注意事项**(组内最差专业是否能接受)
- **专业代码核对**(医学影像技术 vs 医学影像学 / 宁大本部 vs 新华学院 等易混淆代码)
