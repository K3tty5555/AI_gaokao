# 青海大学医学院(原青海医学院,2002 年并入青大)— 青海唯一 211 临床 + 高原医学全国独家

## 一句话定位

**原青海医学院 2002 年整建制并入青海大学**,现为**青海大学医学院**(对外仍可称"青医"),**毕业证 = 青海大学(211 + 双一流)**,**学历层次真实在 211 第一档**(不是普通医科大学)。**青海全省临床医学主力供给校 + 青大附属医院青海三甲龙头 + 高原医学 / 藏医学 全国独家**。**普通家庭青海考生想留青当医生闭眼选,分数比兰大医学院低 30-50 分**,性价比天花板。

> 提醒:青海大学医学院是青大的医学校区,**走青大本科批 / 提前批录取**,部分专业仍以"青海大学医学院"独立招生代码。**毕业证盖青海大学章 + 211 + 双一流**,**比报普通双非医科大学性价比高一档**。

## 真实地位

- **211(青大)+ 双一流(青大生态学,医学院共享 211 加成)+ 教育部 / 青海省 / 清华大学 共建**(2001 年起清华大学对口支援青大,**青大医学院师资来自协和 + 清华医学院**)
- **青海唯一 211 临床医学** + **青海唯一藏医学本科 / 硕士 / 博士点** + **青海唯一高原医学研究中心**
- **学科评估**:**临床医学 B(青海唯一 211 临床)+ 藏医学全国独家(跟西藏藏医学院并列)+ 高原医学全国独家**(跟川大华西高原医学组 / 西藏医学并列)
- **附属医院**:**青大附属医院** = **青海规模最大三甲 + 青海医学最高峰 + 实习留院无缝衔接**;**青海省人民医院**(共建)/ **西宁市第一人民医院**(教学医院)
- **校区**:**西宁城北区**(青大主校区)+ 医学院教学楼 + 青大附院(临床实习基地)
- **男女比**:女多男少约 4:6(医学专业女生稍多)
- **特色**:**清华对口支援医学院**(协和 + 清华医学院教授来教学,**保研到协和 / 北医接受度极高**)
- **辐射地理**:**青海各州县三甲 / 二甲医院 + 西藏 / 甘南 / 川西藏区 医院 + 援藏援青医疗队主供**

## 青海录取位次区间

参考 2021-2025 青海录取数据(以一分一段表反查为准,**青海本科线低 + 体量小**):

### 2025(新高考首届,物理类为主)

- **物理类王牌组(临床医学 5+3 一体化 / 临床医学本博)**:全省 **600-1,500 名**
- **物理类主流组(临床医学 5 年制 / 预防医学 / 口腔医学)**:全省 **1,500-3,000 名**
- **物理类冷门组(藏医学 / 公共卫生 / 护理学 / 药学)**:全省 **3,000-6,500 名**

### 2021-2024(老高考)

- 理科:省排 **600-6,500 名**(王牌 600-1,500,主流 1,500-3,000,冷门 3,000-6,500)
- (临床医学 / 藏医学 不招文科 / 历史类)

**段位定位**:**青海理科 / 物理类省排 6,500 名内可冲青大医学院**,**3,000 名内可挑临床医学 5 年制**,**1,500 名内可冲临床医学 5+3 一体化 / 本博连读**。**国家专项 + 西部专项 + 公费医学(青海定向)可再低 1,000-2,500 名**,农村户籍重点考虑。

## 性价比专业(青大医学院独家)

- **临床医学 5+3 一体化**:**青海唯一 211 临床 + 本硕连读省去考研规培焦虑**,**毕业留青大附院或青海各州医院都对口**,**清华对口支援的隐藏福利:本科生有机会被协和 + 清华医学院教授直接教,保研到协和 / 北医接受度极高**
- **临床医学 5 年制(青海公费医学定向)**:**学费 + 住宿费全免 + 月补贴 + 毕业回青海各州县医院服务 6 年**,**普通家庭零成本上 211 临床 + 编制铁饭碗**,青海各州县医院招生倾斜,**留青当医生最稳路径**
- **藏医学**:**全国独家**(跟西藏藏医学院并列藏医学双子星),**藏区行医 / 民族医药企业 / 文化传承** 三重价值,**藏族考生政策对口**
- **高原医学(研究方向)**:**全国独家研究领域**(高原病 / 高原适应 / 高原氧疗 / 高原药学),**学术路径冷门但稀缺**,跟川大华西高原医学组 / 西藏医学院 是国内仅有的三大研究阵地
- **预防医学(高原公共卫生)**:**高原疾病预防 / 包虫病防治 / 鼠疫监测 全国独家**(青海是包虫病 / 鼠疫高发区),**青海疾控 / 卫健委 / 援藏援青卫生项目** 编制路径
- **护理学**:**青海护理主供 + 青大附院实习留院 + 编制铁饭碗**,女生 + 普通家庭 + 想留青当护士的稳赢路径

## 坑专业 / 慎选(在青大医学院里相对弱)

- **非医学专业**:几乎没有(青大医学院专攻医学),**专心读临床 / 藏医 / 护理 / 公共卫生**
- **临床医学(普通本科 5 年制)+ 不读研**:**现在临床本科直接就业天花板低**,**必须考研 / 规培 + 进三甲**,**接受不了 5+3+x 路径长 → 慎选医学**
- **护理学(男生)**:有少量男生护理岗位(ICU / 急诊 / 麻醉),**留青大附院 OK 但跨省男护就业窄**
- **公共卫生(本科直接就业)**:**疾控 / 卫健委 编制需求有限**,本科出口窄,**笃定考公或继续读研才选**

## 关键提醒(填报陷阱)

1. **青大医学院 vs 青大本部**:**青大医学院 2002 年整建制并入青大,毕业证 = 青海大学(211)**,**部分专业以"青海大学医学院"独立招生代码,但学历层次完全 = 青大**,**比报普通双非医科大学性价比高一档**
2. **5+3 一体化 vs 5 年制 vs 公费医学**:
   - **5+3 一体化(本硕连读)= 5 年本科 + 3 年硕士 / 规培,8 年毕业**,**直接进规培有编制规培医院**
   - **5 年制(普通临床)= 5 年本科 + 自找规培 + 自考研**,**比 5+3 路径多 1-3 年**
   - **公费医学(青海定向)= 5 年本科免学费 + 毕业回青海各州县医院服务 6 年**,**普通家庭零成本路径**
3. **公费医学的"原籍服务 6 年"是硬约束**:**违约要赔学费 + 写违约记录**,**家长一定要跟孩子聊清楚这 6 年要回青海各州县医院**(可能是玉树 / 果洛 / 海西 等高海拔州县)
4. **高原适应期**:**西宁海拔 2200m + 青海各州县海拔 3000-4500m**,新生第一年需 1-2 周适应,**心血管 / 严重贫血 学生提前体检 + 心理建设**;**毕业去玉树 / 果洛 等高海拔州县医院 = 长期高原工作**
5. **服从调剂注意**:青大医学院组内可能调到护理 / 公共卫生 / 药学,**只想读临床的 → 慎勾**(读护理 / 药学 vs 不读医的取舍)
6. **临床医学 5+3 vs 兰大医学院 / 西交医**:
   - **青大医学院 5+3 = 青海唯一 211 临床 + 清华对口支援 + 分低 30-50 分(留青最对口)**
   - **兰大医学院 = 985 + 兰大附属医院(西北顶配)+ 分高一档(留西北范围广)**
   - **西交医 = 985 + 西交一附院 / 二附院(西北最强)+ 分再高一档(全国通吃)**
   - **想留青当医生 → 青大医学院最对口;想出青到兰州 / 西安 / 全国 → 分够上兰大 / 西交医更优**
7. **藏医学的硬约束**:**藏医学 = 藏区行医 / 民族医药为主**,**毕业出口 80% 在青藏区**,**汉族考生 + 不愿去藏区行医 → 慎选**;**藏族考生 + 想做民族医学传承 = 全国独家路径**
8. **临床医学 vs 藏医学的区别**:**临床医学 = 现代西医**(执业医师资格证全国通用);**藏医学 = 民族医学**(执业范围以藏区 / 民族医院为主),**别混淆**

## 毕业出口(2024 数据)

- **留青就业**:约 **65-70%**(**青大附属医院 + 青海省人民医院 + 西宁市第一医院 + 青海各州县三甲 / 二甲医院**,**留青比例青大医学院全省最高,医学院专业出青难度大于综合专业**)
- **去甘肃 / 西藏 / 川西藏区**:约 **10-15%**(**援藏援青医疗队 + 兰大医学院读研 + 西藏 / 甘南 / 川西藏区医院**)
- **去京津**:约 **8-12%**(**协和 / 北医 / 清华医学院 读硕博**(清华对口支援的真实福利,**保研到协和 / 北医接受度极高**)/ 京津三甲读研)
- **去沿海 / 西安**:约 **5-10%**(西交医 / 长三角三甲读硕博 / 沿海三甲读研)
- **保研 / 考研**:约 **35-40%**(医学院保研率高于青大本部,**保研到协和 / 北医 / 华西 / 西交医 / 兰大医 接受度极高**(对口支援红利),**学术路径青大医学院不输东部 211 医**)
- **公费医学生**:**100% 进入青海各州县医院编制服务 6 年**(**编制铁饭碗 + 高原补贴 + 援藏援青津贴**)
- **进编制(青大附院 / 省人民医院 / 各州县医院)**:约 **50-55%**(医学专业编制需求稳定)
- **起薪范围**:**留青大附院规培 6-9w + 项目奖金**;**留青海各州县医院 6-10w + 编制 + 高原补贴**(玉树 / 果洛 / 海西 等高海拔州县补贴更高,综合收入不低);**公费医学生回原籍 5-9w + 编制 + 房补 + 援藏援青津贴**;**藏医院 6-9w + 编制**;**援藏援青医疗队 8-13w + 高原补贴 + 项目津贴**(收入不低 + 生活艰苦);**保研协和 / 北医后学术路径 12-25w**

## 适合谁

- 青海理科 / 物理类 **省排 600-6,500 名** 的考生
- **想留青当医生 + 普通家庭 + 想要 211 牌子** → 青大医学院是性价比天花板(分比兰大医低 30-50 分)
- **公费医学定向 + 农村 / 牧民家庭 + 想做青海各州县医院医生** → 零成本上 211 + 编制 + 高原补贴
- **想做藏医 + 民族医学传承** → 青大藏医学是全国独家(跟西藏藏医学院双子星)
- **想做高原医学 / 高原病研究 + 学术路径** → 青大高原医学研究中心 + 协和 / 北医读博路径
- **想做援藏援青医疗 / 高原公共卫生** → 青大公共卫生 + 预防医学 是高原医疗主供
- **女生 + 想做护士 + 留青大附院 / 青海各州医院** → 青大护理学 + 编制铁饭碗
- 学风务实 + 不怕高原气候(冬天干燥 + 海拔 2200m + 紫外线强) + 接受医学路径长(8 年起步)

## 不适合谁

- **想做都市三甲医生 / 协和 / 北医 / 华西** → 直接报东部 985 医(分够),青大医学院读硕博曲线达成可,但本科直接路径不通
- **不能接受高原气候 / 不接受偏远州县服务 6 年** → 公费医学生服务期是硬约束,**心血管 / 严重贫血学生 + 不愿去高海拔州县 → 慎选**
- **不接受医学路径长(8-11 年)+ 想本科直接就业** → 慎选医学专业
- **想做市场化高薪医美 / 整形 / 私立医院** → 青大医学院导向公立体制,跟市场化路径不匹配
- **学非医学专业 + 想要青大牌子** → 选青大本部专业,别选医学院的非医专业(几乎没有,医学院专攻医学)
- **想做藏医但不愿去藏区行医** → 藏医学毕业出口 80% 在青藏区,**汉族考生慎选**
