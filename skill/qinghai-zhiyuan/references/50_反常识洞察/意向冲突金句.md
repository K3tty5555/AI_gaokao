# 用户意向冲突 — Reality Check 金句库(青海版)

很多家长 / 考生有具体的意向("想上青大"、"非西宁不去"、"想学医"、"想出青不回"),但**意向不一定跟分数 / 家庭实际匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 5000 位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **青海特别版**:**"出青 vs 留青" 是青海考生最常见的意向冲突**,要做明确权衡(出青投入大 + 二次迁移成本 vs 留青稳定 + 编制对口)

---

## 4 类意向冲突 + 金句模板(青海版)

### 模式 A:不可达型 — 分数差距 >30 分 / >5000 名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 400 分要清华 / 480 分要西安交大物理类主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 千名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(青海 480 分理科,意向西安交大)**:
> "西安交大主流组在青海理科约 800-2,000 名。你 480 分大概 12,000 名,差 1 万名,**西交大没戏**。
>
> 但你能上**青海大学(本省 211 + 双一流 + 清华支援)+ 兰州理工大学(双非工科顶配)+ 长安大学(出省 211)**这三所留西北就业,**国企 / 体制内招聘里跟西交大冷门组校友地位差不多**(都是'西北 211 + 留西北同档')。"

**真实案例(青海 530 分理科,意向北邮)**:
> "北邮 CS 在青海理科约 500-1,200 名。你 530 分大概 5,500 名,差 4 千名,**北邮 CS 没戏**。
>
> 同分能上**西安电子科技大学(西北 CS 顶配 211)+ 杭州电子科技大学(双一流)+ 青海大学 CS(211 + 清华支援)**,西电毕业进华为 / 字节 / 腾讯 跟北邮一个层级,只是分数低一档。**别为了"北邮"两个字执着**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(青海理工科 + 普通家庭,想冲兰大)**:
> "兰州大学(出省甘肃 985)你 540 能冲 — 但只能进生命科学 / 草学 / 大气科学。**985 牌子 + 西部偏远 + 生化环材** = 看似三重坑,但**对青海考生不一样**:**兰大草学 / 生态学 跟青大 草学 / 生态学 并列西部双子星**,**学术路径选这个反而对**;**怕的是兰大的化学 / 生物 (本科直接就业惨)**。
>
> 同分能上的青海大学 + 双一流(生态学)+ 清华对口支援(本科 → 清华读硕博接受度高)对口程度更高 + 留青就业稳。**冲兰大留一个心理慰藉位即可,主推青大本省 211**。"

**真实案例(青海考生想冲青大医学院 但分数擦边)**:
> "青大医学院临床医学在青海理科约 1,500-3,500 名。你 4,200 名,擦边能进**但只能进临床冷门方向 / 公共卫生 / 预防医学 / 护理 / 医学影像技术**。
>
> 想做医生 → 这个分能进的不是 5 年制临床医学(主流组),而是**预防医学 / 公共卫生**(出口窄 + 不能直接当临床医生);想留青稳定 → **改报青大医学影像 / 检验 / 护理**反而是同分能进的"医学技术路径",**4 年本科 + 留青进青大附院技师岗 + 编制**,比硬冲临床冷门组香得多。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村 / 牧民,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华临床 / 北医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(青海普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-10k 综合**(青海规培期工资 + 高原补贴)。普通工薪 / 农牧父母还要供 8 年。
>
> 撑得起 → 推**青大医学院 5+3 一体化临床**(青海唯一 211 临床 + 清华支援 + 留青当医生顶配),长期天花板高。
>
> 撑不起 → **建议青大医学影像 / 检验 / 护理(4 年本科直接进医院技师岗,起薪 7-9k + 高原补贴 + 编制)**,**早 4 年挣钱**;或者放弃医学走电气 / 公费师范 这种本科直接挣钱的赛道。"

**真实案例(青海农牧家庭 + 想做基础学科博士)**:
> "想做物理 / 数学 / 化学博士 ≈ 27-30 岁前不挣钱,而且博士毕业找教职竞争极卷。**农牧家庭撑不起这条路**。
>
> 但**青大数学(本科)+ 出省 985 读硕博** + **本科期间国家专项 / 民族班 + 出省补贴 + 助学贷款** 这套组合,**农牧家庭学术路径可达**。**关键是博士毕业前家里能不能撑住**,这个要诚实回答。
>
> 撑不起 → 改公费师范物理 / 数学(青师大,零成本 + 编制 + 服务 6 年回青海各州中学) + **想做学术工作 5 年后再考研** = 同样能走学术,但风险低很多。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去" / "不留青"

**特征**:用户只想留某个城市 / 拒绝出省 985,或者反过来"铁了心要出青不回"。**这是青海考生最常见的意向冲突**。

**金句模板 D1(铁了心留青)**:
> "你只想留青海,那同档要在 [青大 / 青师大本省双非] 和 [出省 985 弱专业] 之间选。
>
> **留青大 / 青师大反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - 出省 985 弱专业牌子硬但专业坑,**毕业回青没竞争力**
> - 留青父母也安心
>
> 但!如果你想做的方向青海没强校(如想学航天 → 留青没意义,要去西工大),**要灵活退一步**。"

**金句模板 D2(铁了心出青不回)**:
> "你想出省发展不回青海,这是合理选择,但要**算清楚 3 个成本**:
>
> 1. **出省 4 年学费 + 生活成本**:沿海 985 4 年综合 15-20w(青大 + 青师大公费 = 几乎零成本),普通家庭撑得起吗?
> 2. **留沿海就业难度**:青海籍 985 毕业生想留北上深杭,**实习 + 校招要拼过本地考生**,且**找不到工作毕业回青的 1-2 年损耗**很常见
> 3. **二次迁移成本**:如果 3-5 年后职业不顺要回青,**回青的二次迁移 + 重新考公考编 + 在青海重新建立人脉** 也是大成本
>
> **如果家里 8-15 万学费 + 25 岁前不指望孩子挣钱 撑得起 + 你确实想留沿海发展** → 出省 985 / 211 是对的;
>
> **如果家里普通工薪 / 农牧 + 想要孩子稳定 + 父母老人需要照顾** → **留青大 + 公费师范青师大** 反而是性价比天花板,别为了"出青"执念葬送家庭性价比"。

**真实案例(青海农牧家庭 + 590 分 + 铁了心出青)**:
> "你 590 分理科(全省 ~3500 名),分够出省 985 弱专业(兰大 / 中山大学 / 厦门大学冷门组)或211 主流组(西电 / 长安大学 / 中国矿大 等)。
>
> **农牧家庭出省 985 弱专业** = 兰大草学 / 中山地理 / 厦大海洋(看着 985 牌子)→ 毕业沿海就业难 + 回青没本地优势 → **大概率回青海考公**,绕一圈还是青海考公;
>
> **同分留青大** = 211 + 双一流 + 清华支援 + 国家电网青海 / 盐湖股份 / 黄河上游水电 直接对口 + 公费医学 / 公费师范 zero-cost → **直接编制 + 高原补贴 + 综合月入 1-1.5w + 父母老人就近照顾**。
>
> **农牧家庭算清楚**:**留青可能是更优解**,**别被'出青 = 跨阶级'的执念绑架**。"

**真实案例(青海中产家庭 + 600+ 分 + 想出青留沿海)**:
> "你 605 分理科(全省 ~2500 名),中产家庭撑得起出省学费 + 沿海生活成本。
>
> **分够出省 985 主流组**(西交 / 同济 / 哈工大 / 北航 / 北理工 等)→ 大厂校招 / 留沿海就业是对的;
>
> **铁了心要进沿海 985** + 不接受青大 → **西交 / 哈工大 / 同济 / 中山大学 主流组** 闭眼推,不要选 985 冷门组(生化环材 / 哲学 / 农林),**985 弱专业不如 211 强专业**;
>
> **如果家庭希望你毕业回青** → 出省读 985/211 + 走青海定向选调 = 回青起点高,**起步就在西宁市直 / 各州副秘书长**。"

## Agent 处理意向的 4 步(青海版)

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向
5. **【青海版额外】问"留青 vs 出青"** — 这是青海考生意向的关键维度,推荐策略完全不同

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ 默认所有青海考生都想出省 — **错!农牧家庭 / 体制内家庭 / 父母老人需要照顾的家庭很多希望孩子留青**
- ❌ 默认所有青海考生都想留青 — **错!中产家庭 / 想做沿海发展的孩子很多想出青**

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### 青海版额外:留青 / 出青 双轨必给

**对青海考生,即使意向明确(只想留青 / 只想出青),Agent 也应在备注中给出"对面"路径的简短对比**,理由是青海考生的"留青 vs 出青"决策影响极大,**家庭可能事先没充分讨论**。

例如:
- 用户说"只想留青" → 主推留青卡片,但备注一句"如果你或家人未来想发展沿海/北京,出省 985 + 青海定向选调 是另一条路径"
- 用户说"只想出青" → 主推出省卡片,但备注一句"如果家庭撑学费有压力 / 父母希望就近照顾,青大 211 + 公费 是性价比之王"

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 青大医学院 / 想出青留沿海 / 想留青当医生 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**青海版额外**:**"留青 vs 出青"是青海考生最重要的意向决策**,**不要替家长替孩子做这个选择,但要让他们看清两边的真实成本和收益**。
