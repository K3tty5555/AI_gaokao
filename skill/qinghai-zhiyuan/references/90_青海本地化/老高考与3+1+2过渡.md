# 青海老高考与 3+1+2 过渡

## 核心结论

**青海 2022 年加入新高考第五批**(同甘肃/吉林/黑龙江/内蒙古/陕西/宁夏/新疆/西藏),**2022 入学高一 → 2025 首届 3+1+2 高考**。所以:

- **2021、2022、2023、2024 高考 = 老高考**(文科 / 理科,文综 / 理综)
- **2025、2026+ 高考 = 3+1+2 新高考**(物理类 / 历史类,12 种选科组合)

**青海是新高考最后一批省份之一,2025 才首届**。agent 必须根据用户届别判断走哪套口径,**不能默认所有用户都是 3+1+2**。

## 关键事实

### 老高考(2021-2024)结构
- 语文 / 数学 / 英语,各 150 分
- **文科**:文综(政治+历史+地理,共 300 分)
- **理科**:理综(物理+化学+生物,共 300 分)
- **总分 750 分**
- 用 **全国卷**(青海一直用全国乙卷/全国 II 卷)

### 3+1+2 新高考(2025+)结构
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2025+)
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- 青海物理类约 60-65%,历史类约 35-40%(参考甘肃/陕西比例)

### 数据现状(`data/yifenduyiduan/`)
- 2021、2022、2023、2024 → `<年>_文科_qinghai.csv` / `<年>_理科_qinghai.csv`(老高考)
- 2025+ → `<年>_物理类_qinghai.csv` / `<年>_历史类_qinghai.csv`(3+1+2)
- agent 调 score_to_rank / query_school 时,**type 参数必须根据年份选对**(2025 之前用文科/理科,2025 起用物理类/历史类)

### 院校专业组(2025+ 起用)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **青海本科批普通类约 40-45 个院校专业组志愿**(具体以省考试院当年方案为准)

### 老高考填报模式(2021-2024)
- 按"院校 + 专业"模式(平行志愿)
- 服从调剂在全校范围内
- 青海长期保留本科一批 / 二批 / 专科批

## 青海特殊性(关键!!)

### 1. 0 所 985 + 1 所 211(青海大学)= **西部计划升级 211,清华对口支援**

- **青海大学**(青大,西宁城北区,教育部和青海省共建,**211 + 双一流**)— **青海唯一 211**,生态学入选双一流
- **清华大学对口支援青海大学**(从清华请教授来教学 / 共建学科 / 联合培养),这是青大被严重低估的隐藏优势
- 临床医学 / 作物学 / 生态学 / 草学 全国前列(高原学科特色)
- **985 数量 = 0**(青海是西北 985 空白省之一,跟宁夏/西藏/新疆类似)
- **青师大、青民大、青医**(已并入青大)都是双非但区内主力

**结果**:**普通家庭考生选青大是"低分上 211"的最佳路径**(青大本省录取分数比同档 211 低 30-50 分,因为青海地理偏远 + 体量小导致考生用脚投票,但有清华对口支援 + 双一流学科)。

### 2. 青海考生约 5w/年 = **全国最小高考省**

- 2024 高考报名 ~5 万左右(物理类约 3 万 / 历史类约 2 万),**全国最小高考省份**(只比西藏高一点)
- **本科分数线极低**(体量小 + 985 名额相对宽松,即使省内 0 所 985,出省 985 给青海的招生计划倾斜)
- 青海考生上 985 / 211 的比例**实际比河南、河北、山东都高**(因为录取计划相对人数倾斜)
- **录取压力是全国最低档之一**(跟西藏/新疆/宁夏相当)

**结果**:**普通家庭青海考生用 500-550 分就能上 211(青大)**,500+ 出省 985 也有机会(国家专项 + 民族地区倾斜)。这在内地省份不可想象。

### 3. 民族多元 = 藏族 24% / 回族 14% / 土族 / 撒拉族

- **藏族 ~24%、回族 ~14%、土族 ~4%、撒拉族 ~2%**,合计少数民族约 47%(汉族占比 53%)
- 玉树州 / 果洛州 / 海南州 / 黄南州 = 藏区为主
- 海东 / 西宁 = 汉族 / 回族 / 撒拉族 / 土族混居
- **少数民族考生政策性优势明显**(民族班 / 预科 / 民族专项 / 西部计划)
- **青海民族大学 / 中央民大 / 西北民大** 是少数民族干部培养主力

### 4. 生态保护区 = 三江源 + 青海湖

- **三江源国家公园**(长江/黄河/澜沧江源头,玉树/果洛/黄南/海西)— 全国生态保护核心区
- **青海湖**(国家级自然保护区)— 候鸟栖息地
- **祁连山国家公园**(青海段)
- 这些保护区 + 高原 → **青海生态学 / 高原生态 / 草学 / 大气科学** 是全国独家研究阵地(青大生态学双一流的底层逻辑)
- 留青做生态研究 / 自然保护区管理 → 青大 / 青师大对口

### 5. 盐湖资源 / 光伏 / 水电 = 青海产业链

- **盐湖资源**(察尔汗盐湖、茶卡盐湖)— 钾肥 / 锂资源(全国战略储备),**盐湖股份**(A 股) 是青海上市龙头
- **光伏发电**(海南州/海西州)— 全国最大集中光伏基地之一(高海拔光照足),晶科 / 隆基 等都在青海建基地
- **水电**(黄河上游龙羊峡 / 拉西瓦 / 公伯峡水电站)— 国家电网青海有大量水电央企岗位
- **新能源(锂电池 / 储能)** — 青海锂资源带动产业链

**结果**:**留青就业的对口路径 = 盐湖 / 光伏 / 水电 / 国家电网 / 中铁青海 / 青藏铁路** 等央企国企。**青海大学化工 / 材料 / 电气 / 水利 / 地质 是这些产业的对口供给校**。

### 6. 留青率 ≈ 50%

- 青大本身在西宁 + 本省名额倾斜 → 留青比例较高
- 留青率约 50%(本科生),出省主要去 **兰州 / 西安 / 京津**
- 出省以工科 + 央企 + 考研为主,文科多回青海考公
- **留青就业相对稳定**(国家电网青海 / 盐湖股份 / 水电央企 / 青藏铁路 / 公务员 编制),起薪不高但生活成本低 + 稳

### 7. 青海考生**出省战略**主流(陕西/兰州/京津)

由于本省名校只有青大 1 所 211,大部分高分考生(尤其想读非青大优势学科 / 想去沿海就业的)都**出省**。主流流向:

| 流向 | 主要原因 |
|---|---|
| **甘肃**(兰州主流) | 兰大 / 兰交大 / 兰理工 / 西北师大,高铁 2-3 小时,文化习惯接近 |
| **陕西**(西安主流) | 西交 / 西工大 / 西电 / 长安大学 / 陕师大,西北最多 985/211,高铁 5-6 小时 |
| **北京/天津** | 清北 + 二线 985/211,实习机会丰富,**高分考生首选** |
| **沿海**(沪宁苏浙粤) | 高薪就业、长三角 / 珠三角 985/211,**留沿海难度大,但西部专项倾斜** |
| **四川**(成都) | 川大 / 电子科大,西部人脉相通 |

## 易错认知(agent 要纠正用户的)

- **"青海高考一直都是文科/理科"** — 错。**2025 起改 3+1+2**,2021-2024 老高考届的位次跟 2025+ 不可直接比
- **"青海大学只是个普通 211"** — 严重错。**青大是 211 + 双一流(生态学)+ 清华对口支援**,临床医学 / 作物学 / 生态学是高原独家学科,**普通家庭青海考生选青大是"低分上 211"的最佳路径**
- **"青海没好学校,只能出省"** — 半错。**普通家庭青海考生选青大性价比天花板**(用比同档 211 低 30-50 分换 211 牌子);留青 + 央企(电网/盐湖/水电) 也是稳定路径
- **"45 个志愿都是学校,选哪个学校都行"** — 严重错误(2025+)。**青海 40-45 个左右院校专业组**,组内可调专业,不同组完全独立投档
- **"青海本科线低,所以 985/211 也容易"** — 部分对。**本科线低是真的(~330)**,但**青海考生上 985 比例确实高于内地省份**(因为体量小+计划倾斜),**不要轻视青海考生的录取实力**
- **"少数民族就一定能上民族班"** — 错。民族班 / 预科 / 民族专项有具体政策,要看院校具体计划,且**对汉族也有民族地区专项**(青海整体属于西部专项倾斜区)

## 关键提醒(agent 必须强调)

1. **青海约 40-45 个院校专业组志愿**(以当年省考试院方案为准)
2. **2025 是 3+1+2 首届**,数据参考性比老高考届差,**多看位次少看分数**
3. **再选科目限制**(必选化学/必选政治等)是硬约束,agent 要主动 check
4. **青海本科线低,普通家庭可低分上 211(青海大学)** — 这是青海考生最大的隐藏福利,普通家庭重点考虑
5. **青大本省录取倾斜明显**(本省名额多,本省考生进青大比湖北考生进武大容易得多)
6. **西部专项 / 国家专项 / 民族地区倾斜** 是青海考生的隐藏路径,可上比平时分高 30-80 分的院校
7. **少数民族考生**(藏 / 回 / 土 / 撒拉)记得问预科 / 民族班 / 西北民大 / 中央民大 / 民族专项 等政策路径
8. **留青就业的主路径 = 国家电网青海 / 盐湖股份 / 水电央企 / 青藏铁路 / 编制内** — 青大 / 兰理工 / 西安交大 是供给主力

## 老高考(2021-2024)→ 3+1+2(2025+)位次换算注意事项

### 1. 旧理科 ↔ 物理类

- 2021-2024 理科考生约 3 万 / 年(总体量)
- 2025+ 物理类考生预估 3 万左右(略有增加)
- **位次换算**:**旧理科省排 X 名 ≈ 新物理类省排 X 名**(体量基本不变,**位次可直接参考**)
- **但是** — **新高考赋分制改变了部分组合的难易度**(化学 / 物理选考人数下降 → 物理类考生整体水平更稳,**头部位次质量更高**)

### 2. 旧文科 ↔ 历史类

- 2021-2024 文科考生约 2 万 / 年
- 2025+ 历史类考生预估 1.8-2.2 万
- **位次换算**:**旧文科省排 X 名 ≈ 新历史类省排 X 名**(体量基本不变)
- **但是** — **3+1+2 后部分原本"理科生 + 想读文科专业"的考生分流到历史类**(选历史 + 政地组合,出于"行测好考"目的),**历史类竞争略有加剧**

### 3. 一分一段表使用规则

- **2021-2024 数据(老高考)**:用文科 / 理科一分一段表,**位次跟新高考可参考但不可机械照搬**
- **2025+ 数据(3+1+2)**:用物理类 / 历史类一分一段表
- **agent 实战策略**:**优先用 2024 / 2023 老高考的位次数据 + 2025 物理类 / 历史类对照修正**(因为 2025 是首届,数据少)
- **预计 2026-2027 数据稳定后,完全用新高考数据**

### 4. 院校在青海招生位次的变化趋势

- **2025 物理类 / 历史类首届**,**院校招生位次普遍波动 10-20%**(高校招生计划重新分配)
- **2026-2027 趋于稳定**,**位次参考 2025 + 内地省份的对应规律**
- **核心建议**:**2025 报考时多冲多保**(波动大),**2026 之后可参考 2025 数据 + 微调**

## 12 种选科组合在青海的覆盖度

跟江苏 / 湖北 / 甘肃 / 陕西一致(参考 `_shared/references/00_核心方法论/采集_rubric.md` L1)。**青海考生选科特别关注**:

### 物理类高覆盖组合(青海主流)
- **物化生**:几乎不限,可报理工医农林全部专业 ✓ ★
- **物化地**:理工 + 部分医学,**地理对青大生态学 / 地理学 加分**
- **物化政**:理工 + 考公友好,平衡型 ✓
- **物生地 / 物生政**:可读非临床医学 / 部分理工 / 经管(覆盖度比物化弱一档)
- **物地政 / 物生地**:**冷门但可报青大水利 / 工程 + 留青考公**

### 历史类高覆盖组合
- **史政地**:文史考公主流路径(适合留青考公 / 青师大公费师范) ✓
- **史政生 / 史地生**:加生物可读护理 / 部分医学相关
- **史生地 / 史生政**:**冷门**,但**可读青师大地理 / 生物方向**

### 选科陷阱(青海家长易踩)
- **想读临床医学(青大医学院 / 出省 985 医)**:**必选化学**(部分院校还要生物)
- **想读西医 / 中医 / 藏医**:**必选化学**(部分要生物)
- **想报警察 / 公安(青海警官职业学院、提前批公安院校)**:**必选政治**
- **想进国家电网青海**:**必选物理**(青大 / 兰理工 / 西安交大 电气都是物理类)
- **想进盐湖 / 光伏 / 水电央企**:**必选物理 + 化学**(化工 / 材料 / 电气对口)
- **想读生态学 / 草学 / 大气科学(青大 / 兰大)**:**必选物理 + 化学/生物**(青大生态学双一流)
- **想读藏学 / 民族学(青民 / 西北民大 / 中央民大)**:历史类即可
- **想读藏汉双语翻译(青民)**:历史类(青民藏汉双语翻译对口)

## 易错认知(agent 要纠正用户的)

- **"青海高考一直都是文科/理科"** — 错。**2025 起改 3+1+2**,2021-2024 老高考届的位次跟 2025+ 不可直接比
- **"青海大学只是个普通 211"** — 严重错。**青大是 211 + 双一流(生态学)+ 清华对口支援**,临床医学 / 作物学 / 生态学是高原独家学科,**普通家庭青海考生选青大是"低分上 211"的最佳路径**
- **"青海没好学校,只能出省"** — 半错。**普通家庭青海考生选青大性价比天花板**(用比同档 211 低 30-50 分换 211 牌子);留青 + 央企(电网/盐湖/水电) 也是稳定路径
- **"45 个志愿都是学校,选哪个学校都行"** — 严重错误(2025+)。**青海 40-45 个左右院校专业组**,组内可调专业,不同组完全独立投档
- **"青海本科线低,所以 985/211 也容易"** — 部分对。**本科线低是真的(~330)**,但**青海考生上 985 比例确实高于内地省份**(因为体量小+计划倾斜),**不要轻视青海考生的录取实力**
- **"少数民族就一定能上民族班"** — 错。民族班 / 预科 / 民族专项有具体政策,要看院校具体计划,且**对汉族也有民族地区专项**(青海整体属于西部专项倾斜区)

## 青海考生 5 大隐藏福利(普通家庭别浪费)

### 福利 1:本科线极低 + 985/211 计划倾斜

- **理科一本线 ~330-345**,**用 330 分就能上一本**,内地省份不可想象
- **985/211 在青海招生计划相对人数倾斜**,**青海考生上 985/211 的实际比例高于河南 / 河北 / 山东 等内地大省**

### 福利 2:青大用低分上 211(本省 + 双一流 + 清华支援)

- **青大本科招生分比同档 211 低 30-50 分**(因青海地理偏远 + 体量小生源拖累)
- **211 + 双一流(生态学)+ 清华对口支援**(2001 年起 24 年)
- **本科 → 清华 / 北医 / 协和保研接受度极高**(对口支援红利)

### 福利 3:民族 / 西部 / 国家专项 三重叠加

- **少数民族(藏 / 回 / 土 / 撒拉 / 蒙古)**:民族班 / 预科 / 民族岗
- **西部专项**:中央部委专项,**对青海考生超友好**
- **国家专项 / 高校专项**:**农牧户籍 + 普通家庭** 享受
- **三重叠加 → 实际可低 30-80 分上 985/211**

### 福利 4:留青就业稳 + 央企对口

- **国家电网青海 / 黄河上游水电 / 盐湖股份 / 青藏铁路 / 中铁青海** = 留青央企集群
- **青大电气 / 水利 / 化工 / 材料 / 地质** = 这些央企最对口供给校
- **青海考公竞争比 1:20-30**(全国最低档之一,远低于江浙沪 1:200+)

### 福利 5:藏区编制综合收入 > 西宁城区

- **基础工资略低 + 高原 / 边远 / 民族 / 房补 综合补贴 8-15k/月**
- **玉树 / 果洛 / 海西 等高海拔州县编制综合月入 1.5-2.5w**(比西宁城区中产工薪还高)
- **藏区考公竞争比 1:5-15 + 民族岗 1:3-10 超低**

**关键结论**:**普通家庭青海考生有内地省份不可想象的政策福利,合理利用 = 性价比天花板;不知道 / 不利用 = 浪费**。
