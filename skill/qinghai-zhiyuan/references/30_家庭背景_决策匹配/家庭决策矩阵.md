# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(青海视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪、农村 / 牧民家庭和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。**青海特殊性**:**牧民 / 农村 / 藏区家庭比例显著高于内地省份**(青海农牧业从业比例约 30-40% 远高于湖北的 15%),**民族成分多元(汉 / 藏 / 回 / 土 / 撒拉 / 蒙古)**,这两点显著影响推荐策略。

---

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。**青海体制内典型 = 西宁市 / 海东市机关公务员 + 青海各州县机关 + 国家电网青海 / 盐湖股份 / 青藏铁路 / 青海移动联通电信 等央企国企编制员工**。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **青海特别版**:**父母可能是青海各级机关 / 央企青海分公司 / 教育系统 / 医疗系统的编制员工**,**信息差比内地体制内家庭更小**(青海体制圈子小 + 互相熟)

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化);**青海定向选调走青大 + 兰大 + 西北师大 + 陕师大 + 出省 985**
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:青海警官职业学院 + 公安联考 = 父母编制资源能用上;**青海公费师范青师大** + 父母教育系统资源 = 直接进青海中学编制
5. **进央企青海分公司路径**:**国家电网青海 / 黄河上游水电 / 盐湖股份 / 青藏铁路 / 青海移动联通电信 / 三大运营商** = 父母如果在这些央企,孩子学电气 / 通信 / 化工 / CS 留青进同公司 是默认路径

**典型 case**:
- 西宁某中产体制内家庭(父亲省直机关,母亲青海移动)→ 孩子 590 分历史类(2025) → 推**陕师大法学公费师范** 或 **西北师大法学** → 毕业回青海省委办 / 青海各州法院,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去出省 985 CS → 毕业 25w 起薪很高,但家长不满"不稳定 + 离家远",劝其离职考公,**两年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。**青海典型 = 青海各级医院医生 + 青海各级中学教师 + 青大 / 青师大 / 青民大 高校教师 + 国家电网青海 / 盐湖股份 / 黄河上游水电 等央企工程师 + 青海各设计院工程师**。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:教师家庭 → **青师大公费师范 / 陕师大公费师范 / 北师大公费师范**;医生家庭 → 青大临床 / 5+3 一体化(父母能撑 8 年)
2. **行业相关延伸**:律师家庭 → 法学(青大 / 兰大 / 出省 985 法学);工程师家庭 → 对应工科(青大 / 西交 / 兰理工 / 兰交大)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)
5. **青海央企工程师家庭(国电网 / 盐湖 / 水电)子女路径**:**孩子学青大电气 / 化工 / 水利 / 材料,父母直接帮"对口央企内部推荐 + 校招优势"**,这是青海央企工程师家庭独有的隐藏路径

**典型 case**:
- 母亲西宁某重点中学语文老师 + 父亲普通工薪 → 孩子 605 分历史类 → **公费师范生汉语言**(青师大 / 陕师大) → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是青大附院医生 → 孩子 650 分物理类 → **青大医学院 5+3 一体化临床(本省 + 父母资源)** 或 **协和 / 北医 5+3+3**(父母能撑 8 年读书 + 三甲医院推荐)→ **典型子承父业路径**
- 父亲是国家电网青海工程师 + 母亲老师 → 孩子 580 分物理类 → **青大电气工程**(本省 211 + 父亲单位对口)→ 毕业进国家电网青海(父亲单位内部推荐 + 校招)→ **完美对接**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。**青海私企典型 = 西宁本地餐饮 / 商贸 / 物流 / 建材 / 矿产小老板**(青海私企经济不强,**真正大私企不多**),**藏药 / 牦牛肉 / 青稞 / 矿产 等青海特色产业老板**。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **青海特别版**:**青海私企整体规模小**(青海 GDP 全国倒数 + 私企经济不发达),**真正"中产以上 + 创业家庭"比例低**,但有一些做藏药 / 矿产 / 建材发家的中型企业主家庭

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(青海中产以上家庭把孩子送出青是普遍诉求)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **青海特殊机会**:**家族产业接班路径**(藏药企业 / 牦牛肉 / 青稞 / 矿产)→ 孩子学相关专业(中医 / 食品 / 化工 / 工商管理)+ 接班

**典型 case**:
- 西宁某中型藏药公司老板家庭(年入 200w+) → 孩子 580 分物理类 → 推**北中医中医学 / 上中医中药学 / 出省 985 化工 / 中外合作办学** → 学成回家接班青海家族藏药企业(本科 + 硕士国际化背景)
- 失败 case:私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主。**青海工薪典型 = 西宁市区工人 / 服务业 / 出租车司机 / 文员 / 中小学教师辅助岗 / 公交司机 / 各州县城工人**(青海工薪家庭年收入比内地省份普遍低一档,**因为青海工资基数低**)。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **青海特别版**:**青海工薪家庭对孩子"留青当老师 / 当医生 / 进电网"的诉求极强**,**对"出省发展"既有期待又有担忧**(担心孩子毕业不回青)

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范青师大**(汉语言 / 数学 / 物理 / 化学 / 英语)= **零成本 + 直接编制 + 青海各州中学服务 6 年**(普通家庭神器)
   - **陕师大公费师范 / 北师大公费师范(青海名额)** = **211 / 985 + 公费 + 编制**(分高一档)
   - **青大临床医学**(国家专项 / 青海本省高额名额)= **本科 5 年留青当医生**
   - **青大医学影像 / 检验 / 护理** = **4 年本科即可进医院**(普通家庭最优解)
   - **青海警官职业学院 + 公安联考** = 进青海各级警察系统编制
3. **次推稳定就业型**:
   - **青大电气进国家电网青海** / **青大水利进黄河上游水电** / **青大化工进盐湖股份**(分够青大铁定推)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科 + 大专)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(青海本地无互联网公司,留青死局)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起 → 改医学技术 / 护理)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 西宁工薪家庭(父亲出租车司机,母亲商场销售) → 孩子 580 分物理类(2025,全省 ~3500 名)→ 推**青大电气工程**(本省 211 + 国家电网青海对口) → 毕业进国家电网青海西宁市公司,**月入 1.1w + 编制 + 高原补贴,家庭逆袭**
- 海东工薪家庭 → 孩子 480 分文科(2024) → 推**青师大汉语言文学公费师范**(双非但青海考公 + 教师编王者) → 毕业回海东市中学,**编制 + 家庭命运改变**
- 西宁工薪家庭女生 → 540 分物理类 → 推**青大医学影像技术**(本科 4 年 + 留青进青大附院技师岗)→ 起薪 7-9k + 编制 + 高原补贴,**普通女生最稳路径**

## 档位 ⑤ 农村 / 牧民 / 藏区家庭(青海特殊关键档)

**定义**:父母务农 / 牧民 / 临时工 / 零散工作,家庭年收入通常 < 8 万。**青海特别版 = 海东 / 海南 / 海北 / 黄南 / 玉树 / 果洛 / 海西 等农牧区家庭**(青海农牧业从业比例约 30-40%,**牧民家庭独有现金流不稳 + 牛羊为资产 + 信仰藏传佛教 / 伊斯兰教 / 信仰藏传文化**等特点)。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **青海农牧家庭独有**:
  - **现金流不稳**(牧民收入 = 牛羊价格 + 草料 + 牧草年景),**牛羊为资产但变现需要卖**
  - **路途遥远**(玉树 / 果洛 / 海西 离西宁 800-1500km,**孩子上大学 = 全家半年见不到**)
  - **少数民族优惠 + 西部专项 + 国家专项 + 民族班 多重叠加**(青海 985/211 名额对藏区考生倾斜尤其大)
  - **藏汉双语家庭**(部分孩子藏语为母语,汉语普通话非母语,**学汉语言 / 出省读书有适应期**)

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
   - **青海农牧家庭独家**:**青大用低分上 211 + 清华师资** = 比内地农村家庭考省外 985 性价比还高(成本低 + 留青就业稳)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **青师大公费师范汉语言 / 数学 / 物理**(零学费 + 编制 + 服务 6 年回青海各州县) = **农牧家庭神器**
   - **国家专项 / 高校专项** = 青海农牧户籍上 985 / 211 专项指标,**比统招分数低 20-50 分**
   - **西部专项**(中央部委专项,对青海农牧考生超友好)
   - **民族专项 / 民族班**(藏 / 回 / 土 / 撒拉考生独家,可低 30-80 分上 985/211)
   - **青海警官职业学院 + 公安联考** = 进青海各州县警察系统编制
   - **青大医学影像 / 检验 / 护理 + 国家专项** = 留青进医院技师 / 护士,**本科 4 年 + 编制**
   - **青大临床医学(国家专项 + 民族班)** = 留青当医生(分够,本省名额多)
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会(青海农牧家庭独家)**:
   - **国家专项计划**:青海农牧户籍,985/211 名校多个专项指标(分数比统招低 30-50 分)
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农牧学生有机会
   - **青大藏医学**(青海 + 藏区 + 民族家庭独家)→ 留藏区做藏医,**家庭文化亲近 + 编制 + 政策红利期**
   - **青民大藏汉双语翻译 / 藏学** → 留藏区做基层公务员 / 双语教师,**藏区家庭最对口**
   - **乡村振兴 / 三支一扶 / 选调生(青海定向)** = 毕业回藏区 / 农村 服务后定向晋升

**典型 case**:
- **玉树州牧民家庭男孩**(藏族) → 孩子 560 分理科(2024) → 通过**国家专项 + 民族班**进**青海大学临床医学(本科 5 年)** → 毕业回玉树州人民医院当医生,起薪 8-12k + 高海拔补贴 + 编制(综合月入 1.5-2.2w),**家庭命运改变 + 整个家族第一个大学生**
- **海东农村家庭女孩**(撒拉族) → 580 分文科 → 推**青师大公费师范汉语言文学** → 4 年无学费 + 毕业回海东中学编制,**最适合农牧家庭的"零风险"路径**
- **果洛州牧民家庭男孩**(藏族,藏文母语) → 530 分文科(民族班 + 国家专项) → 推**青民大藏汉双语翻译**(全国独家)→ 毕业回果洛州政府做基层公务员,**藏汉双语优势直接变现 + 民族干部晋升路径**
- **海西州格尔木农民家庭** → 540 分理科 → 推**青大水利水电工程**(国家专项)→ 毕业进黄河上游水电拉西瓦水电站,**起薪 1w + 编制,留青稳定**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 青海家庭维度的额外提醒(agent 必查)

### 1. 民族成分对推荐的影响

agent 在 L2 阶段必须问"汉族 / 藏族 / 回族 / 土族 / 撒拉族 / 蒙古族 / 其他":
- **少数民族(藏 / 回 / 土 / 撒拉 / 蒙古)** → 民族班 / 民族专项 / 西部专项 多重叠加,**录取分可低 30-80 分上 985/211**
- **少数民族 + 藏汉双语 / 蒙汉双语 家庭** → 青民大双语翻译 / 民族学 / 藏学 是独家路径
- **汉族但农牧户籍** → 国家专项 / 高校专项 仍然适用,**分可低 20-30 分**

### 2. 户籍地对选调 / 专项的影响

- **西宁城区户籍** → 大部分专项不适用
- **海东 / 海南 / 海北 / 黄南 / 玉树 / 果洛 / 海西 农牧户籍** → 国家专项 + 高校专项 + 西部专项 全部可用
- **藏区 6 州户籍**(玉树 / 果洛 / 黄南 / 海南 / 海北 / 海西 中部分) → 民族优惠 + 西部艰苦地区专项 双重叠加

### 3. 家庭对"留青 vs 出青"的核心诉求

agent 必须显式问:**家庭是否要求孩子毕业回青海工作?**
- **家庭强烈要求留青** → 推荐策略偏向青大 / 青师大 / 青民大 + 公费 + 央企青海
- **家庭接受孩子出省发展** → 推荐策略可拓宽到出省 985 / 211(西交 / 兰大 / 中山 等)
- **家庭希望孩子出青长见识但毕业回青** → 出省 211/985 + 考公回青(青海公考竞争比低,**回青上岸概率高**)
