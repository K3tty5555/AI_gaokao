# 计算机科学与技术 / 软件工程(CS / SE)— 青海视角

## 一句话总结

**CS 已经过了"闭眼报"的黄金时代**。青海考生学 CS 的真相比内地还残酷:**留青 = 几乎没有互联网公司**(西宁仅有政务云 / 国网信通分公司 / 极少数本地软件外包),**学 CS 必须出省**,而出省又意味着对学校层次有更硬的要求。**青大 CS(双一流支援 + 211 牌子)是青海考生唯一能"低分换 CS 牌子"的本省路径,但实习地理远 + 校招公司不下西宁,本科直接进大厂极难;双非 CS 在青海几乎是死局**。

---

## 真相 1:留青就业 ≠ CS 出口

**全省 IT 真实结构**:
- **国家电网青海信通公司**(国网青海下属) — 电力 IT 岗位,招的还是电气 + CS,**对口校是华电 / 青大**,**这不是真"互联网"公司,是央企 IT 岗**
- **盐湖股份信息中心 / 盐湖工业信息部** — 工业控制 IT,招的本质是化工 + CS
- **青海移动 / 青海联通 / 青海电信** — 三大运营商青海分公司,**编制内 IT,但对口校是西电 / 北邮 / 南邮 / 重邮**,青大 / 兰理工本地稍占便宜
- **西宁 / 海东 / 海西 政务云 + 大数据中心** — 编制内 / 国企岗位,不是互联网
- **本地软件外包 / 弱小本土公司** — 月薪 4-6k,**比兰州还差一档**
- **互联网大厂(阿里 / 字节 / 腾讯 / 华为)在青海 0 个研发岗位**(华为有政企销售办事处但不是研发)

**结论**:**学 CS 想做"互联网"在青海几乎没有出口**。留青 CS = 进国网信通 / 三大运营商 / 政务云 / 盐湖信息中心,本质是"央企 / 国企 IT 岗",**性质更接近电气 / 通信而不是互联网**。

---

## 真相 2:寒冬 + 分化 — 青海考生只能选"出省"或"换专业"

- 2022-2024 互联网大厂裁员潮(腾讯 / 阿里 / 美团 / 字节 大规模优化),**应届生 offer 数量比 2020 年峰值少了至少 30%**
- 头部学校的 CS 学生仍然有 30w+ 起薪,中下层学校的从原来的 15w 起薪掉到了 8-10w,**两极分化加剧**
- **青海考生现实**:
  - 分够 985(西交 / 哈工大 / 浙大 / 中科大) → 出省 985 CS,大厂校招目标校
  - 分够 211 头部(北邮 / 西电 / 电子科大 / 北航) → CS 顶配校,起薪 25w+ 没问题
  - 分够双一流非 211(深大 / 杭电) → 沿海大厂目标校,起薪 18-25w
  - **分只够青大 CS** → 双一流支援是名,本质 211 中下水平 CS,**实习地理远 + 大厂校招不下西宁,本科直接进互联网极难,需要考研出省**
  - **分只够青师大 / 青民大 / 青大昆仑学院 CS / 青海各二本 CS** → **青海 CS 死局,劝退**

---

## 真相 3:本科 < 硕士的差距越来越明显(青海考生尤其要懂)

- 5 年前 985 本科 CS 毕业可以直接拿 SP offer,现在 985 本科 CS 起薪可能跟 211 硕士差不多甚至略低
- **大厂校招在向"硕士起步"倾斜**,本科想拿好 offer 必须**实习 + ACM + 项目**三件套都拿到顶
- **青海考生地理劣势**:**实习集中在北上深杭**,**青海 / 西宁 0 个大厂研发岗**,本科生想拿大厂实习要去北上深杭蹲 3-6 个月,**普通家庭撑不起**
- **结论**:青海考生学 CS 想吃红利,**本科 → 出省 985/211 + 大三大四去北上深杭实习 + 考研留东部** 这条链是必选

---

## 真相 4:转码内卷已经到顶

- 2018-2022 大量文科生 / 工科生通过培训班转码成功,这个窗口已经关闭
- 现在企业对"科班 CS"偏好极强,非科班想转码越来越难
- **青海考生别幻想"先学个稳定专业,以后再转 CS"** — 这条路已经走不通

## 适合什么人(青海考生 specific)

- **数学好**(高中数学 130+,这是硬指标)
- **抗压能力强 + 不怕加班**
- **有自学能力**,因为大学课程跟不上行业实际需求
- **985/211 出身,或者愿意读研读博出省**
- **家庭中产或愿意撑** — 大三大四去北上深杭实习 1 万 +/月生活费,加暑期班 / 培训 / 设备,**4 年 CS 总投入比文科多 5-10 万**
- **青海考生独有约束**:**心理上接受"必须出省 4 年 + 不留青"** — 留青就业基本浪费 CS 专业

## 不适合什么人

- **数学差**(高中数学 110 以下慎重)
- **追求安稳 / 不想 996**
- **农村 / 牧民家庭 + 不打算考研** — 这个组合学 CS 等于 4 年浪费,**留青找不到对口岗,出省竞争不过沿海考生**
- **学校只够双非二本 CS** — 普通家庭直接换专业(电气 / 公费师范 / 临床 / 汉语言)
- **女生 + 不喜欢技术钻研 + 只图高薪** — 行业对女性有客观存在的隐性歧视,**普通女生学 CS 不如学公费师范汉语言**
- **铁了心留青** — 留青 CS 出口不如电气 / 临床 / 汉语言,**别为"听起来高大上"选 CS**

## 青海本地 CS 院校真实分层

### 第一梯队(青海本省最优)
- **青海大学 计算机科学与技术** — **211 + 双一流(清华支援口袋专业)**,师资来自清华支援,**学历层次真实在 211**,但**留青 CS 出口窄**(国网信通 / 三大运营商 / 盐湖信息),**想做互联网必须考研出省**(保研到清华 / 北邮 / 北航的接受度高,这是青大 CS 的隐藏福利)。**适合普通家庭青海考生用低分换 211 CS 牌子 + 考研出省**

### 第二梯队(双非但留青 OK)
- **青海师范大学 计算机科学与技术 / 教育技术学** — **双非 + 师范底子**,**别选**(师范校学 CS 是怪胎,留青进中学当信息技术老师还行,**当真互联网出口几乎没有**)
- **青海民族大学 计算机科学与技术** — **双非 + 民族院校**,**别选**(民大 CS 是凑数专业,留青基础 IT 岗 / 政务云外包还行)

### 第三梯队(避坑)
- **青海大学昆仑学院(青大独立学院,2024 转设)CS** — 二本独立学院,**慎选**,可以考虑专升本路径
- **青海各民办 / 二本 CS / 大专 CS** — **直接避坑**。这一档学 CS 不如学护理 / 师范 / 会计等有明确出路的专业。**普通家庭孩子在这些学校学 CS 出来基本就业极差,你以为的"敲代码进大厂"不会发生**

### 出省青海考生 CS 性价比首选
- **西安电子科技大学 CS / 网络空间安全** — **211 双一流,西北 CS 顶配**,西安距西宁高铁 5-6 小时,**青海考生出省 CS 性价比之王**(分数比北邮 / 北航低 + 西北就业有本地优势)
- **兰州大学 CS** — **985 但 CS 不算强**,**冲牌子可以,冲就业不如西电 / 北邮**
- **西安交大 CS** — **C9,顶配**,分够铁定推
- **电子科技大学(成都)CS** — 211 双一流,与西电并列 CS 双子星
- **北邮 / 北航 / 北理 CS** — 北京 CS 顶配,**分够铁定推**

## 典型 case(供 agent 引用)

### Case A:青海西宁考生(中产家庭) — 出省 211 CS
- 西宁市直某中产家庭男生,2025 物理类 605 分(全省 ~3500 名)
- 报**西安电子科技大学 计算机科学与技术** → 大三去深圳腾讯实习 → 校招拿到字节深圳 25w 起薪
- **逆袭路径**,**典型青海中产家庭通过出省 211 + 大厂实习走 CS 的样本**

### Case B:青海海东考生(农村家庭) — 青大 CS + 考研路径
- 青海海东农村家庭男生,2025 物理类 545 分(全省 ~5000 名)
- 报**青海大学 计算机科学与技术**(211 + 清华支援) → 大学期间考研到北邮 → 北京头部互联网 → 起薪 22w
- **青大 CS 路径**:本科 → 出省考研 → 出省就业,**家庭省了 4 年学费 + 211 牌子 + 清华支援保研路径,综合性价比之王**

### Case C:青海玉树考生(牧民家庭) — 青大 CS 留青进央企
- 玉树州牧民家庭男生,2024 理科 510 分(西部专项 + 民族优惠)
- 报**青海大学 计算机科学与技术** → 校招进国家电网青海信通公司
- 起薪 9k + 编制 + 高原补贴 + 高海拔补贴,**家庭逆袭样本**(留青央企 IT 起薪虽不如沿海大厂,但综合稳定性高)

### Case D(反面):青海西宁考生(普通家庭) — 双非 CS 死局
- 西宁工薪家庭男生,2024 理科 460 分(全省 ~12000 名)
- 报**青海大学昆仑学院 CS** → 毕业找不到 IT 工作 → 转行做销售
- **典型踩坑**,家长以为"学了计算机就能赚钱",**学校层次决定一切**,如果当时改报青师大公费师范物理(免学费 + 编制),**家庭命运完全不一样**

## 易错认知(agent 要纠正用户的)

- "**留青学 CS 也能进大厂远程办公**" — 错。**互联网大厂极少给应届生 remote 名额**,且远程办公一旦裁员第一波被砍。**学 CS 想做互联网必须人在东部**
- "**青大 CS 是双一流就是真双一流**" — 半对。**青大双一流学科是生态学,CS 是清华对口支援的"口袋专业"享受双一流口径但学科评估实际 B-**。**牌子用,但别迷信**
- "**计算机考公也行**" — 半对。**信息岗 / 网信办 等 CS 对口考公岗位有但少**,**计算机考公成功率显著低于汉语言**;留青考公选汉语言 + 法学更稳
- "**双非 CS + 考研也能逆袭**" — 半对。**双非 CS 想考研到 985,本身就比 211 难**(本科基础 + 复试老师认可度);**普通家庭走这条路 = 高风险**
- "**青海有大数据 / 算力中心,CS 留青有出路**" — 半对。青海确实有大数据 / 算力基地建设(西宁 / 海西州),但**这些岗位招的还是央企 IT,不是真互联网**,薪资跟内地央企 IT 一个水平,跟互联网大厂差 3-5 倍

---

## 关键提醒

**青海考生学 CS 本质是"必须出省"的专业**。如果家庭不接受出省 + 不接受未来不留青,**别选 CS**;如果家庭能撑出省 + 孩子分够 211 + 愿意考研 → CS 仍然是青海考生的高薪赛道。**普通家庭 + 双非 + 留青预期 = 死局**,这种组合下学 CS 不如换公费师范汉语言 / 临床 / 电气进电网。
