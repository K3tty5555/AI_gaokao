# 考公优选专业表(青海本地视角)

## 核心结论

**专业决定考公选岗范围**。青海家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**青海考公独有特点**:
1. **青海考公竞争比 1:20-30**(远低于江浙沪 1:200+),**报考门槛低 + 上岸概率高**,是青海考生最大的隐藏福利
2. **藏区 / 高原边远地区岗位多 + 高原艰苦补贴 8-15k/月** → 玉树 / 果洛 / 黄南 / 海西 等基层公务员实际综合收入高于西宁城区
3. **少数民族(藏 / 回 / 土 / 撒拉)+ 民族岗位** = 双语岗位 + 民族干部专项,**民族考生独家路径**

## 关键事实(2024 国考 / 青海省考分析)

### 国考可报岗位数 排名(Top 10 大类,青海考生视角)

1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 青海省考特殊性

- 青海省考 + 西宁市考 + 各州县岗位,**汉语言文学和法学并列考公第一专业**,合占约 40-45% 岗位
- 青海各州县公务员岗位**对法学要求高**(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 50+ 比 1,但比内地 1000+ 比 1 仍宽松)
- **青海省考整体竞争比 1:20-30**(国考 1:30-50),**远低于江浙沪 1:200+**
- **藏区州县岗位**(玉树 / 果洛 / 黄南 / 海北 / 海南 等)**经常竞争比 1:5-15**(超低),但**艰苦边远地区有 5 年最低服务期**
- **民族岗位 / 双语岗位**(藏汉 / 蒙汉)**仅限对应民族报考**,**竞争比 1:3-10**(超低)

### 选调生(青海定向 + 中央选调)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(青海定向选调对青大 + 出省 985/211 + 部分双非顶配开放)
- **青海定向选调主要供给校**:**青大 + 兰大 + 西北师大 + 陕师大 + 出省 985(西交 / 同济 / 复旦 / 北大 / 清华 等)**
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **青海"博士选调"**:对青大本博 + 出省 985 博士 开放,**起点为副处级,西宁市直机关 / 各州副秘书长起步**

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、青海警官职业学院等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,青海各州监狱系统有专项

### 三支一扶 / 西部计划 / 大学生村官(青海考生独家)

- **西部计划**:中央团委 + 教育部专项,**青海各州县基层服务 1-3 年**,服务期满后**考公考研有政策倾斜**
- **三支一扶**:支教 / 支医 / 支农 / 扶贫,**青海各州县岗位多 + 服务期满定向考公**
- **特岗教师**:青海各州县中学教师专项,服务 3 年后转编

## 青海考公独有路径(藏区 / 高原 / 民族)

### 路径 1:汉语言 / 法学 + 留青进西宁 / 海东市直机关

- **西宁市直 / 海东市直 / 海西州直 公务员** = 青海考公的"舒适区"
- **青大 / 青师大 / 西北师大 / 兰大 + 汉语言 / 法学** = 青海留青考公主供
- 综合月入 7-11k + 编制 + 公积金,生活成本低,稳定

### 路径 2:汉语言 / 法学 / 民族学 + 进藏区州县基层

- **玉树 / 果洛 / 黄南 / 海西 / 海南 / 海北 等藏区州县基层公务员** = 高海拔 + 高原艰苦补贴 + 远郊补贴
- **青大 / 青师大 / 青民大 + 汉语言 / 法学 / 民族学 / 藏学** = 直接对口
- 综合月入 8-15k(基础工资略低,但**高原补贴 5-15k/月 + 房补 + 援青补贴 + 边远补贴**)
- **服务期 5 年硬约束**(违约赔偿 + 影响后续考公考编)
- **藏区考公竞争比 1:5-15**(超低),**民族岗 1:3-10**

### 路径 3:藏汉双语翻译 / 民族学 + 民族干部路径

- **青民大藏汉双语翻译 / 民族学 / 藏学** = 全国独家
- **藏区州县基层公务员 + 双语岗位** = **少数民族干部晋升通道**
- **青海政府机关 + 民族宗教事务厅 + 各州县民族宗教委 + 教育系统 双语岗** = 直接对口

### 路径 4:大学生村官 / 三支一扶 / 西部计划 → 定向考公

- 大学毕业先服务青海各州县基层 1-3 年(待遇 4-7k + 食宿) → 服务期满**定向考公** = **避开统招激烈竞争**
- 适合普通家庭 + 想要稳定 + 不介意先去基层

### 路径 5:青大博士 / 出省 985 博士 + 青海博士选调

- 博士起点为副处级,**西宁市直 / 各州副秘书长** 起步
- **青海博士选调对青大本博 + 出省 985 博士开放**
- **起点高 + 晋升快**,适合学术型 + 想做高级公务员的考生

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:青海海东考生,460 分文史类(2024),**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报青师大公费师范汉语言文学** → 毕业回海东市某中学,**编制 + 稳定 + 月入 7-9k + 高原补贴 + 房补**,**家庭命运改变**

- **Case B(选调路径)**:青海西宁考生,650 分文史类(2024),中产家庭。家长想报"金融"(青大经管)。**改报兰州大学法学**(出省甘肃 985)→ **毕业获兰大选调生资格,直接进青海省委组织部**,起点远超经济学就业

- **Case C(失败路径)**:青海西宁考生,540 分理科,普通家庭男生。家长想"考公兜底"。**报了青大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行做销售**。如果当时改成青师大公费师范汉语言文学,**家庭命运完全不一样**

- **Case D(误区路径)**:青海家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**

- **Case E(藏区独家)**:玉树州牧民家庭藏族男孩,420 分文科(2024,民族班 + 国家专项 + 西部专项)→ **青民大藏汉双语翻译方向** → 毕业**通过双语岗考玉树州政府基层公务员**,**月入 1.2-1.7w(基础工资 + 高原补贴 + 边远补贴 + 房补)+ 编制**,**比西宁城区中产工薪还高,家庭巨大跃迁**

- **Case F(高潜路径)**:青海西宁中产家庭男生,605 分历史类(2025) → **西交大法学**(出省 211 / 双一流) → 毕业**走青海定向选调生进省检察院**,**起点远超普通考公**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(青海 3+1+2 制度允许首选物理报多数文科专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是青海家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**藏区考公太苦,别去**" — 严重错。**藏区考公综合收入(基础 + 高原 + 边远 + 房补)实际远高于西宁城区**(基础工资略低但补贴高),**且竞争比超低(1:5-15)+ 民族岗 1:3-10**,**对农牧家庭 / 民族家庭 = 性价比天花板路径**(只是要接受 5 年服务期)
- "**公费师范不是考公**" — 半对。**公费师范本质是直接进编(教师编制) = 跟考公等价的稳定路径**,且青师大公费师范零成本 + 服务 6 年回青海各州中学,**对青海普通家庭比考公还稳**
- "**少数民族优惠是给真正贫困的**" — 错。**只要少数民族户籍**(户口本上民族成分填藏 / 回 / 土 / 撒拉 / 蒙古)**就有民族优惠**,**民族班 / 预科班 / 民族岗 / 双语岗 都可报**,**汉族户籍但西部专项地区也可享受西部专项优惠**

## 关键提醒

**考公是青海普通家庭最稳定的上升通道,而且青海考公竞争比是全国最低档之一**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是青海家长被严重低估的考公王者**。

**青海考公独有福利**(普通家庭必须知道):
1. **青海考公竞争比 1:20-30**(全国最低档之一,**比江浙沪宽松 5-10 倍**)
2. **藏区考公综合收入 > 西宁城区编制**(基础 + 高原 + 边远 + 房补 综合月入 1.2-2 万)
3. **民族岗 / 双语岗 1:3-10**(超低竞争比,民族家庭独家)
4. **公费师范 = 等同考公编制 + 零成本**(青师大公费师范汉语言是普通家庭最稳路径)
5. **西部计划 / 三支一扶 / 大学生村官 → 定向考公**(避开统招激烈竞争)
6. **青海博士选调 = 副处级起点**(青大本博 + 出省 985 博士独家路径)
