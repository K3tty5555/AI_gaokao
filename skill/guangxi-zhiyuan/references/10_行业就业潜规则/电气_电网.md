# 电气工程及其自动化 / 电网 — 广西视角

## 核心结论

**广西不属于国家电网管辖,广西是南方电网大本营之一**。这是广西考生学电气最该先搞清楚的事 — **国家电网招聘对广西考生没意义,要瞄准的是南方电网广西公司**。**南方电网 + 中电建广西 + 广西水电(红水河水电基地)三条线,是普通家庭男生在广西最稳的工科逆袭路径**,前提是学校选对(西大/桂电/桂林理工 三选一)。

## 关键事实

### 行业格局(广西特色)
- **南方电网 = 广东 / 广西 / 云南 / 贵州 / 海南** 五省区电网,总部深圳
- **南方电网广西电网公司** 总部南宁,**广西考生进电网 = 进南网广西**(不是国网)
- **国家电网广西没有管辖区,所以"国家电网"在广西招聘体量极小**(只有部分新能源 / 抽水蓄能项目偶尔招广西人)
- 南方电网每年校招 8000-10000 人,广西公司占 1500-2000 人,**本科生比例 60%+**
- 进南网广西后稳定,**离职率极低,内部晋升清晰**

### 广西特色:水电央企 + 红水河基地
- **广西是中国第二大水电基地**(仅次于四川),红水河流域装机容量超 1500 万千瓦
- **大唐 / 华能 / 国电投 / 中电建 红水河流域公司** 在广西密集招聘
- **三峡集团广西分公司**(西江水电开发)— 西大 / 桂电 / 桂林理工 电气是主供给
- **桂冠电力**(广西本土水电央企)、**广投集团广西水电** — 区属国企体量大

### 广西特色:北部湾电网 + 边境电网
- **北部湾经济区电网建设**(防城港核电 / 钦州港 / 北海)— 区域电网工程岗位
- **中越边境电网 + 跨境电力贸易**(凭祥 / 东兴 与越南北部电网互联)— 小众但稀缺方向

### 招聘门槛(2024 实况,南网广西视角)
- 985/211 电气 ≈ 闭眼进南网广西管理岗(南宁 / 各地市公司)
- "电力八校"(华北电力 / 武大 / 华科 / 重大 / 西交 / 东南 / 浙大 / 上交)电气 ≈ 进南网广西概率极高,起点直接是地市公司
- **西大电气**(广西区内 211 双一流候选)→ **南网广西本科主供给**,基本闭眼进
- **桂电电气** → 南网广西 + 中电建广西 + 三峡广西 都收
- **桂林理工电气**(地质背景但电气也行)→ 南网广西基层 + 水电站现场
- **广西科技大学(柳州)电气** → 柳州工业带 + 南网广西基层
- 双非二本电气(广西民大行健 / 北部湾大学 等)→ 基本只能进县级供电所基层(也是编制)

### 薪资水平(南网广西,2024 实况)
- 南宁公司管理岗:7000-13000/月 + 五险一金 + 公积金 12% + 各种补贴
- 地市公司(柳州 / 桂林 / 玉林 / 北海 等):6000-11000/月
- 县级公司(各县供电所):5000-9000/月,**艰苦地区还有边远补贴**(如靖西 / 那坡 / 大化 等山区)
- 广西水电央企(三峡 / 大唐 / 华能):**水电站现场补贴高,起薪 8-12k 但常驻偏远水电站**
- 全部带编制,福利住房 + 子女教育 + 医疗 + 退休稳定

### 工作内容现实(广西版)
- 基层岗:抢修、巡线、检修、调度,**广西山区多,巡线野外作业常态(尤其桂西/桂西北)**(女生慎重)
- 管理岗:办公室、运营、规划、营销,体力要求小
- 水电站岗:常驻红水河 / 西江流域水电站,**地理偏僻,但补贴高**
- 边境电网岗:中越边境工程,**小众但稀缺**

| 男 + 桂林理工/广西科大电气 | 报,**目标南网广西基层 + 水电央企现场岗**,慢慢晋升 |

| 女 + 学校好(西大/桂电)+ 不介意南宁地市 | 报,**南网广西管理岗女生没问题**,但门槛高 |

## 广西本地院校梯队(电气专业)

### 第一梯队(电力八校 + 985,出区)
- **华北电力大学 电气**(广西考生分够可冲)— 全国电气第一档,毕业可挑南网总部 / 华南分部 / 国网各省
- **武汉大学 电气** / **华中科技大学 电气** — 985,毕业南网广东 / 广西管理岗

### 第二梯队(广西区内顶配)
- **广西大学 电气工程及其自动化** — **广西本省电气最佳之选**,211 + 双一流综合性,**南网广西本科主供给**(广西家长口碑顶配)
- **桂林电子科技大学 电气** — 双非但电子信息底子强,**南网广西 + 中电建广西** 都收,**性价比之王**

### 第三梯队(广西本地认可)
- **桂林理工大学 电气** — 双非,水电方向有底子(地学背景,水利水电相关),**适合三峡/大唐红水河水电站现场岗**
- **广西科技大学(柳州)电气** — 双非,**柳州工业带 + 南网广西柳州公司** 主要来源

### 第四梯队(避坑提醒)
- **广西民大行健 / 北部湾大学 / 玉林师院 等独立学院/二本三本电气** — 学校层次不够,**进南网广西管理岗概率极低**,只能做基层抢修。**普通家庭可以接受基层就报,要管理岗就别幻想**

## 典型 case(供 agent 引用)

- **Case A**:广西百色考生(壮族),普通农村家庭男生,560 分物理类。**国家专项 + 民族班** 进西大电气(比统招低 30 分)。**毕业直接进南网广西百色公司,起薪 7k + 编制**。**4 年后年薪 14w,父母彻底放心,整个壮族村寨第一个进电网**
- **Case B**:广西南宁考生,普通工薪家庭男生,580 分物理类。**首选桂电电气**,毕业拿到中电建广西分公司 offer,**起薪 9k + 项目奖金**,5 年外派东南亚(中越/中老电力工程)。**广西男生隐藏跃迁路径**
- **Case C**:广西河池考生,普通家庭女生,540 分物理类。家长强烈想报电气("听说电网铁饭碗")。**建议改报汉语言文学考公** — 桂林理工电气毕业大概率进南网河池基层(山区巡线女生吃力),**汉语言考公比电气进网更稳**
- **Case D**:广西柳州考生,工人家庭男生(父亲柳工集团工人),550 分物理类。**首选广西科大电气**,毕业进南网广西柳州公司基层 → 5 年内调地市公司 → **比父亲在柳工的工厂工人路径稳**
- **Case E**:广西桂林考生,普通家庭男生,610 分物理类。家长想报"留桂林"。**强烈建议出广西冲华北电力大学电气**(华北电力广西生源约 30 人/年),**毕业可挑南网/国网各省,顶配路径**

## 易错认知(agent 要纠正用户的)

- "**学电气一定能进电网**" — 错。南网广西每年招 1500-2000 人,**广西区内电气专业毕业生几千,不是人人都能进**。**双非毕业不考研基本只能进县级供电所**
- "**国家电网比南方电网好**" — **对广西考生没意义**。广西是南方电网管辖区,**南网广西就是你能进的"电网"**,不要纠结国网
- "**进南网就是当电工**" — 错。管理岗、调度岗、市场营销岗都是办公室工作。基层电工只是其中一种岗位
- "**女生不适合电气**" — 半对。基层不适合(尤其广西山区巡线 + 体力 + 户外),**南宁/桂林/北海地市公司管理岗女生完全 OK**,但门槛高(西大/桂电及以上)
- "**电气就是南方电网,没别的出路**" — 错。**广西电气还有大唐/华能/国电投/中电建/三峡 红水河水电基地**,以及**广投/桂冠 区属国企**,**北部湾防城港核电** 等多条出路
- "**电气和自动化是一回事**" — 错。**电气 = 强电(电网、电机、电力系统)**,自动化 = 弱电(控制、传感、机械控制)。**南网广西校招认电气,不认自动化**
- "**广西电气不如出粤学华南理工电气**" — 半对。华南理工电气 985 顶配,但**广西考生华南理工电气位次要求极高**(物理类 1500 名内);**够不上华工 → 西大电气是广西本省最佳替代**

## 广西特色路径 — 中越边境 + 东盟电力工程

广西考生学电气有一条**冷门但补贴极高的路径**:**中电建国际广西分公司 / 中能建广西 / 三峡国际** 的**东盟电力工程**(中越中老中柬中泰电力外送项目)。

- 国家"一带一路"东盟基础设施输出,广西是桥头堡
- 西大 / 桂电电气 + 通晓越南语 / 东南亚语 = **稀缺人才**
- 起薪 12-18k(国内基础工资 + 海外补贴),**3-5 年存款 100w+ 不难**
- 缺点:常驻东南亚国家(越南河内 / 老挝万象 / 柬埔寨金边),家庭压力大

**广西男生想出广西又不去深圳卷 IT,这条线值得考虑**。

## 关键提醒

**报电气不是为了"学技术",在广西是为了"进南网广西" + "进水电央企" + "进编制"**。如果学校层次不够进不了南网广西管理岗,只能去县级基层或水电站现场,**这个专业的吸引力大打折扣**(技术含量并不比其他工科高,薪资也不如出粤 CS)。

**广西电气的核心决策**:
1. **分够西大 / 桂电** → 闭眼冲,南网广西本科主供给
2. **分够桂林理工 / 广西科大** → 报,目标基层 + 慢慢晋升
3. **只能去广西二本三本电气** → 农村家庭可以接受县级供电所就报,**城市家庭男生不如改换专业**

**广西农村壮族 / 瑶族 / 苗族男生 + 国家专项 / 民族班 + 西大/桂电电气 = 全广西最稳的跨阶级路径**,没有之一。
