# 广西老高考与 3+1+2 过渡

## 核心结论

**广西 2021 年加入新高考第四批,2024 年高考首届实行 3+1+2**(跟黑龙江、吉林、安徽、江西、贵州、甘肃 同批,比湖北/江苏晚 3 年)。**2021-2023 三届还是老高考(文科/理科)**,**2024 起切到物理类/历史类**。**2023 入高一 → 2026 高考是广西第三届完整 3+1+2**(2024 是首届,数据稀缺;2025 是第二届,大小年风险高)。

## 广西考生基本盘(关键!)

### 1. 高考人口与名校稀缺度

- **2024 年广西高考报名约 45 万人**(全国第 7-8 位,比湖北 / 湖南略多,远低于河南/山东/四川/河北)
- **本科上线人数约 18-20 万**,一本上线人数约 5-6 万
- **985 录取率约 1.2%**(全国均值 ~1.6%,广西略低于均值)
- **211 录取率约 4%**(全国均值 ~5.5%,广西明显偏低)
- **省内 985 = 0**,**省内 211 = 1 所(广西大学)** —— 名校稀缺度跟河北、河南、贵州、海南同档,**广西考生想留区内读名校的路非常窄,出省战略是常态**

### 2. 壮族自治区 + 少数民族加分(广西特殊性 1)

- **壮族占广西总人口约 32%**,加上瑶族、苗族、侗族、毛南族 等,少数民族占比近 40%
- **少数民族加分政策**(以广西招办最新文件为准,常见档位):
  - 山区、边境县少数民族考生:加 5-20 分(具体看县级/族裔分类)
  - 城市少数民族考生:0-5 分
  - **加分政策仅限广西区内高校录取使用**(部分院校接受,部分不接受;出省院校通常不认可少数民族加分)
- **agent 必须在 L1-B / L2 阶段问壮族 / 瑶族 / 苗族 等身份**,加分会显著影响录取概率
- 国家专项 + 民族班 + 预科班 是广西农村少数民族考生的"三重通道"

### 3. 东盟门户(广西特殊性 2)

- **广西跟越南陆地接壤(凭祥/东兴边境口岸)**,跟老挝、缅甸、泰国 海陆相通
- **中国-东盟博览会** 永久落户南宁,广西是国家"一带一路 海上丝绸之路 重要门户"
- **广西外语类(越南语/泰语/老挝语/缅甸语 / 印尼语 / 柬埔寨语)是全国独家产业链**,广西民族大学的东南亚语言全国第一
- **跨境电商 + 边贸 + 中越铁路 + 国际陆海贸易新通道(西部陆海新通道)** 是广西独有的就业方向
- 外交部、商务部、海关总署、跨境电商企业 对广西东盟语对口考生有特殊招录通道

### 4. 粤港澳大湾区辐射(广西特殊性 3)

- **广西毗邻广东**,梧州/贺州/玉林 高铁到广州 2-3 小时,南宁到广州 4 小时
- **广东工厂大量吸纳广西务工人员 + 大学毕业生**,广西考生留粤工作占比 35%+
- **大湾区起薪比广西本地高 2-3 倍**(广西本地公务员/事业编 起薪 4-6k vs 深圳/广州 IT/制造业起薪 12-25k)
- **agent 推荐时务必把"出粤大湾区"作为广西考生的默认就业辐射圈**,比留桂工资高、上升空间大

### 5. 桂林教育资源(广西特殊性 4)

- **桂林是广西的"教育高地"**:广西师范大学(广师大)+ 桂林电子科技大学(桂电)+ 桂林理工大学(桂工)+ 桂林医学院 + 桂林旅游学院 + 陆军特种作战学院 等聚集
- **桂林"出版社 + 课外辅导 + 旅游服务"** 三位一体,师范类 + 旅游类 + 文创类 就业链完整
- **桂电的电子信息全国前列**(原电子工业部直属),华为/中兴对口
- 但桂林产业体量比南宁小,留桂林对应的就业是"教师 + 出版 + 旅游 + 边缘工科",对应南宁的"行政 + 央企 + 银行 + 医疗"

## 老高考(2021-2023 届)

### 考试结构

- **3 = 语文 + 数学 + 英语**(全国 II/III 卷,各 150 分)
- **文综 / 理综**(各 300 分)
  - **文科**:政治 + 历史 + 地理(综合卷)
  - **理科**:物理 + 化学 + 生物(综合卷)
- **总分 = 750 分**

## 新高考 3+1+2(2024 届起)

### 实施时间表

- **2021 年秋季**(2021 届高一)入学开始按新高考要求选科
- **2024 年高考**:**首届 3+1+2 高考**(2021 届高一 → 2024 届高三)
- **2025 年高考**:第二届(数据相对积累,但大小年风险高)
- **2026 年高考**:第三届(2023 届高一 → 2026 届高三),数据相对稳定

### 考试结构(同湖北/江苏)

- **3 = 语文 + 数学 + 英语**(各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2024 起)

- **物理类**(类型代号 2073)— 选物理为首选
- **历史类**(类型代号 2074)— 选历史为首选
- 广西物理类约 65-70%,历史类约 30-35%(沿袭老高考文理比)

### 12 种选科组合

| 物理类 6 种 | 历史类 6 种 |
|---|---|
| 物化生 / 物化政 / 物化地 | 史化生 / 史化政 / 史化地 |
| 物生政 / 物生地 / 物政地 | 史生政 / 史生地 / 史政地 |

### 院校专业组规则

- **按"院校专业组"投档,服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **再选科目限制是硬约束**(必选化学的医学、必选政治的警校等)

### 广西本科批志愿数

**广西本科批 96 个志愿**(2024 起)— **数量是全国最多档之一**(比湖北/湖南/江苏的 40-45 个志愿翻倍多),志愿表填报量极大
- **志愿数多 = 容错率高,但也意味着填报工作量极大**,填报时每个志愿都要走"院校专业组 + 选科限制 + 历年位次"三重 check
- **服从调剂建议默认勾选**(否则一旦组内分数不够会直接滑档)
- 96 个志愿要从冲(15-20)、稳(40-50)、保(30-40)梯度均匀铺开

### 历年批次线(3+1+2,2024 起)

| 年份 | 物理本科 | 物理特控 | 历史本科 | 历史特控 |
|---|---|---|---|---|
| 2024 | 待补 | 待补 | 待补 | 待补 |
| 2025 | 待补 | 待补 | 待补 | 待补 |

(2024 是首届,具体批次线以广西招办公布为准。2024-2025 数据由 agent 调 score_to_rank 实时获取)

- **东盟语方向**:广西民族大学的越南语/泰语 在历史类录取也接受,**这是广西独有路径**

## 广西考生战略要点

### 1. **出省战略是大多数广西考生的最佳路径**

- 同分情况下,**外省 985/211 平台 > 区内西大/广师大**(西大除外,西大留区是首选)
- 例:广西理科 1.5 万名,**区内只能保西大某专业组**;**出省可冲川大、重大、西交、华中科大、华南理工、中山大学** 等老牌 985
- **首选流向**(基于地理 + 文化 + 政策):
  - **粤港澳**(中大/华工/暨南/深大,广西毕业生留粤主流)
  - **西南**(川大/重大/西南财经/电子科大,西部 985 集群,招生名额相对友好)
  - **华中**(武大/华科/中南/湖大,中部交通方便)
  - **北上**(分数门槛高,平台最高)
  - **东盟方向出省**(云大/广外 — 广东外语外贸 — 接东盟语种就业链)

### 2. **国家专项 + 地方专项 + 民族班 + 预科班(广西特殊四通道!)**

- **国家专项**:广西是国家专项重点省份,**农村户籍考生** 可申请专项,**降分录取顶级 985/211**
- **地方专项**:留区内,西大/广师大/广医大 等一本招专项
- **民族班**:壮族/瑶族/苗族 等少数民族 + 一定条件 → 单独招生 + 降分录取
- **预科班(本科预科)**:少数民族考生预科 1 年 + 本科 4 年(共 5 年),录取分比正招低 30-50 分
- **农村普通家庭少数民族考生务必查清四通道资格**,这是广西独有的"四重保险"

### 3. **考研大区 + 双非逆袭路径**

- 广西考研意愿强(尤其留区考生),**广西大学每年考研报名 1.5 万 +**
- 大量本科双非考生通过**考研逆袭** 到 985/211(走广西本科 → 华南理工/中山/武大 985 硕)
- 推荐时若用户考研意愿 ≥ 4,**双非"性价比段"院校** 也可推(桂林理工/桂电式路径)

### 4. **考公考编 + 留桂职业路径**

- 广西考公人数中等偏上,**体制内吸引力对农村/县城考生极强**
- **考公友好专业**:汉语言文学 / 法学 / 经济 / 会计 / 计算机 / 财政学 / 行政管理
- **公费师范生**:推荐区内师范(广西师大 / 广西民族师范 / 玉林师院)+ 教育部直属六大师范
- **留桂体制内 vs 出粤民企**:广西考生最经典的家庭决策矛盾,详见 `广西强校真实地位.md`

### 5. **东盟方向独家路径(重要!!)**

- 广西民族大学东南亚语言(越南语 / 泰语 / 老挝语 / 缅甸语 / 印尼语)— **全国第一**,毕业生进外交部 / 商务部 / 中越边贸企业 / 跨境电商 / 国际旅游 等独家就业链
- **2024 起东盟自贸区 + RCEP 落地,广西东盟语种就业景气度上升**
- **女生 + 文科类 + 跨境贸易兴趣 + 国际化思维 → 广民大东盟语种 是广西独家最优路径**

### 6. **避免错误认知**

- **❌ "广西分数线低,我家孩子分高"** —— 错。**看位次不看分数**,广西分数线低是因为人少 + 试卷相对友好,跨省看位次才公平
- **❌ "西大跟其他 985 一样好"** —— 错。**西大是 211 不是 985**,广西本省没有 985,西大在区内地位高,但全国排名跟 中游 211 接近
- **❌ "区内 211 不如出区双非"** —— **半错**。西大在广西本地考公考编 + 国企招聘有天然优势,出粤双非起薪可能更高,**取决于用户家庭+未来方向**
- **❌ "读完西大就一定留广西"** —— 错。西大学生读研出区 / 工作出粤比例 30%+,**牌子是平台,不是地理绑定**
- **❌ "壮族加分政策不重要"** —— 严重错误。**少数民族加分 + 民族班 + 预科班 是广西农村少数民族考生最值钱的政策资源**,绝不能忽略

## 给 agent 的硬规则

1. **L0 之后必问届数**(2023 届及以前老高考 OR 2024 届首届 3+1+2 OR 2025 届及以后),决定走老高考还是 3+1+2 数据口径
2. **L2 必问壮族 / 少数民族身份**(广西加分政策 + 民族班 + 预科 通道)
3. **老高考考生**调用 `score_to_rank --type 文科|理科`(不是物理类/历史类)
4. **3+1+2 考生**调用 `score_to_rank --type 物理类|历史类` 同时收集选科组合
5. **跨届数据预测要标注精度警告**(2023 老数据 → 2024 预测大幅失真,2024 → 2025 大小年风险高)
6. **区内 vs 出区 偏好** 必问(L3 地域接受度),默认建议把"粤港澳"作为广西考生的天然辐射圈,理科考生考虑出粤进华为/中兴/比亚迪
7. **不美化广西教育现状**:区内 985=0 / 211=1 西大,这是事实,要敢说;但同时强调东盟门户 + 大湾区辐射 是广西独家就业优势,不悲观
8. **96 个志愿**(2024 起)填报工作量大,推荐时按"冲 15-20 / 稳 40-50 / 保 30-40"梯度示意,不是只给 5-8 所
