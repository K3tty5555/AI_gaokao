# 考公优选专业表(广西本地视角)

## 核心结论

**专业决定考公选岗范围**。广西家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

广西考公的特殊性:
1. **西部大开发岗位倾斜**(国考 / 央选 在广西有专项岗位)
2. **少数民族岗位 + 民族优惠**(壮/瑶/苗/侗 等岗位限定)
3. **边境艰苦边远补贴**(凭祥/东兴/那坡 等基层岗 = 月入 6-8k 起)
4. **东盟外交 + 跨境贸易岗**(广西区位独特,中国-东盟博览会主办地)
5. **广西公务员工资水平在全国中下,但生活成本低 + 体制内地位极高**

## 关键事实(2024 国考 / 广西区考分析)

### 国考可报岗位数 排名(广西籍考生视角)
1. **法学** — 法院、检察院、监狱、纪委监委、广西公安厅边检 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务(国家税务总局广西税务局)、海关(南宁/凭祥/东兴海关)、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办、政务大数据局 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门、共青团广西区委 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 越南语 / 泰语 / 老挝语 / 柬埔寨语)** — 外交部、海关、商务部、广西外事办 → 约 2%(**广西特色:东盟语种比英语更稀缺**)

### 广西区考特殊性
- 广西区考(自治区公务员考试)+ 各市直 + 县乡 + 选调生,**汉语言文学和法学并列考公第一专业**
- 广西各地市公务员岗位**对法学要求高**(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 800-1500 比 1)
- **边境基层岗位**(凭祥/东兴/那坡/龙州/靖西/大新):**汉语言/行政管理/法学 主力**,报名人少 + 补贴高 = **隐藏好岗**
- **少数民族岗位**(限壮/瑶/苗/侗/仫佬/毛南/京 等):**民族家庭独家**,竞争小

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(广西本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **广西选调主供给**:**广西大学(本省 211)+ 出区 985(中山/华工/武大/华科/暨大 等)**
- **广西选调有"区内定向"和"中央选调"两条路**:中央选调可去中央部委(国务院广西工作办、广西驻京办 等),**广西籍 985 学生独家路径**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、广西警察学院 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,广西警察学院对口
- **边检**:广西边检站(凭祥/东兴/水口/友谊关 等)— **要求公安+边境管理对口**

| 明确要考公 + 理科生 + 不挑岗位 | **汉语言文学**(理科生学汉语言行测更强) |
| 明确要考公 + 理科生 + 想去税务/财政/海关 | **会计学 / 经济学 / 统计学** |

## 广西本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业
- **广西大学法学** — 区内顶配,**广西法考通过率高,选调路径最优**
- **广西大学汉语言文学** — 211 综合校汉语言,**留桂考公王者**
- **广西大学行政管理 / 经济学 / 会计学** — 留桂考公性价比顶配
- **出区 985 法学**(中山/武大/华科/西南政法 等)— 分够冲,毕业可挑出区央选 / 广西定向

### 双非 + 性价比考公专业(广西)
- **广西师范大学(桂林)汉语言文学 / 法学** — **公费师范汉语言可走教师编**,**法学留桂考公 主流路径**
- **广西民族大学(南宁)行政管理 / 法学 / 汉语言** — 双非但**广西区直机关认可度高**,**留南宁考公性价比高**
- **南宁师大 / 玉林师院 / 河池学院 / 百色学院 / 钦州学院 汉语言 / 法学** — 二本三本,**广西县乡考公 + 中学教师编 优秀跳板**
- **广西民大行健 / 西大行健 / 桂电信科 等独立学院汉语言 / 法学** — 民办独立学院,**仍能考公**(只要本科文凭就有资格),**最低成本编制路径**

### 公安系统专属(广西)
- **广西警察学院**(南宁)— 本科,公安联考路径,**毕业进广西本地公安概率极高**(基层警察)
- 广西警察学院**侦查学 / 监狱学 / 边境管理** — 对口边检 / 司法系统
- 出区 → **中国人民公安大学 / 中国刑事警察学院**(广西考生分够可冲,毕业进部委)

### 东盟外交 / 跨境贸易专属
- **广西民族大学**(南宁)东盟语种(越南语 / 泰语 / 老挝语 / 柬埔寨语 / 印尼语)— **全国第 1**
- 出口:**外交部 + 商务部 + 各级外事办 + 广西区驻东盟办事处 + 北部湾跨境贸易**
- **广西考生独家区位优势**

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:广西河池考生(壮族),540 分文史类,**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报广西民族大学汉语言文学 + 民族班加分**,毕业当年考上河池市直某机关公务员,**家庭命运改变**
- **Case B(选调路径)**:广西南宁考生,650 分文史类,中产家庭。家长想报"金融"(西大经济)。**改报广西大学法学**,**毕业获得西大选调生资格,直接进广西区委组织部**,起点远超经济学就业
- **Case C(失败路径)**:广西柳州考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了广西师大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:广西家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(边境路径)**:广西崇左凭祥考生,520 分历史类,**农村壮族家庭**。**报广西民大行健文理学院汉语言**(独立学院,普通家庭也能上)→ 毕业回凭祥**乡镇公务员定向培养(汉语言 + 民族 + 边境 三重优惠)** → 一次上岸,**月薪 6-8k(基础+边境补贴+民族补贴),比同班留南宁的同学还多**
- **Case F(东盟路径)**:广西防城港考生,580 分历史类,普通家庭。**报广西民族大学越南语** → 毕业进**广西区驻河内办事处 / 友谊关海关 / 中越边贸合作中心** → 月薪 8-10k + 跨境补贴,**广西区位独家路径**
- **Case G(选调中央路径)**:广西桂林考生,675 分物理类,中产家庭。**冲武汉大学法学** → 毕业获得武大选调生资格 + 广西籍中央选调指标 → **进国务院广西工作办 / 司法部** → 顶配跃迁路径

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(广西 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是广西家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**广西考公工资低,不如出粤打工**" — 半对。广西公务员基础工资低(月薪 4-7k),但**广西生活成本也低**,**编制+稳定+体制内地位** 综合性价比对农村家庭仍是首选;**出粤打工除非进大厂否则月薪 6-8k 跟广西公务员差不多但没编制**
- "**少数民族优惠是骗人的,加几分没用**" — 错。**广西少数民族加分 5-20 分 + 民族班加分 + 国家专项加分** 叠加可达 30-50 分,**等于上一档学校**,**农村壮族 / 瑶族 / 苗族 不善用这些政策等于把最大优势浪费**
- "**边境艰苦,基层岗谁去**" — 错。**凭祥/东兴/那坡 等边境基层岗,月薪 6-8k 起(比南宁普通公务员还高),三年期满优先回原市县**,**农村家庭返乡稳路径**

## 关键提醒

**考公是广西普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是广西家长被严重低估的考公王者**。

**广西考公的 4 个隐藏路径(外省没有的)**:
1. **少数民族岗位 + 民族优惠加分** — 壮 / 瑶 / 苗 / 侗 / 仫佬 / 毛南 / 京 家庭独家
2. **边境县乡定向公务员** — 凭祥 / 东兴 / 那坡 / 靖西 / 龙州 / 大新,补贴高 + 报名少
3. **东盟外交 / 跨境贸易岗** — 广民大东盟语种 + 外事办 / 海关 / 跨境贸易,广西区位独家
4. **国家专项 + 选调生中央指标** — 农村考生进西大 / 出区 985 + 中央选调,顶配跃迁

**广西考生善用这 4 条路径,跨阶级稳路径远多于沿海省份的同档考生**。
