# 看似冷门实际香的专业(广西视角)

## 核心结论

广西家长普遍**追热门而避冷门**(尤其追"金融/计算机/国贸"幻想),但很多"冷门"专业的就业稳定性、考公友好度、性价比远超表面热门专业。**对广西普通家庭尤其友好** — 因为不卷、门槛适中、出路明确。

广西特殊优势:**少数民族扶持 + 边境政策 + 东盟区位 + 西部大开发** 让一些全国通用冷门专业在广西的 ROI 进一步放大。

## 关键事实

### 1. 汉语言文学 — 广西考公王者(广西家长最该重视)
- 广西区考、各市直、县乡考能报考的岗位数,**汉语言文学常年第一**(明显多过法学、计算机、会计)
- 三不限岗位(对专业不限制)所有人都能报,但加上"汉语言文学"限制的岗位还是非常多
- 适合所有想考公考编的广西学生,**特别是普通家庭女生 + 农村少数民族考生**
- 详见 `10_行业就业潜规则/汉语言_新闻.md`

### 2. 电气工程及其自动化 — 南方电网神券(广西版)
- 进南方电网广西公司 = 央企铁饭碗 + 广西普通家庭逆袭
- 西大电气 / 桂电电气 / 桂林理工电气 都是南网广西本科主供给
- 详见 `10_行业就业潜规则/电气_电网.md`

### 3. 测绘工程 / 遥感科学与技术
- 广西特色:**北部湾经济区 + 西江流域水利建设 + 中越边境测绘** 项目大量招测绘人
- **桂林理工大学测绘工程**(国土资源部共建,西部测绘强校)— 毕业进广西国土厅 / 中铁广西 / 中交广西 / 北部湾港集团
- 武大测绘是**全国第 1**(广西考生分够可冲),毕业进国测局/中铁/中交/各省测绘院,**铁饭碗居多**
- 注意:基层岗有野外作业,体力要求,女生慎重
- **广西的测绘人在中越边境测绘项目上有独家区位优势**

### 4. 海洋工程 / 船舶与海洋工程
- **广西北部湾海洋经济区** 国家战略,**北海/钦州/防城港 三港 + 自由贸易试验区**
- 中船集团广西分公司、中海油广西分公司、中远海运 在广西密集招聘
- **广西大学海洋学院 / 北部湾大学海洋专业** 是区内主要供给
- 适合男生 + 想稳定 + 不介意去港口/海上工作

### 5. 中医学 / 壮医学(广西独家)
- **广西中医药大学壮医学专业 = 全国唯一**(国家民族医药扶持政策)
- 出口:**广西国际壮医医院 / 各市民族医院 / 中医院 / 县乡卫生院中医方向**
- 国家政策推动:中医院扩招 / 中西医结合 / 中医诊所放开
- 广西区中医院 + 各市中医院 + 国际壮医医院 主供给
- **冷门红利**:报的人比临床少,但政策正在推

### 6. 殡葬学 / 殡葬服务与管理
- 全国只有 4 所院校开设(长沙民政、福建华南女子、武汉民政、北京社管)— **广西本省没有此专业,需出省**
- **就业率 100%,入职即编制**(殡仪馆事业单位)
- **收入比想象高很多**(广西殡仪馆月入 8k-1.5w),**比广西公务员基础工资还高**
- 行业刚需 + 人力极少 + 社会偏见正在减少
- 适合不在意社会偏见 + 想要绝对稳定的家庭
- **广西考生选这个的人更少 → 竞争更小**

### 7. 医学影像技术 / 医学检验技术
- 三甲医院技术岗,**不需要医师资格证就能上岗**(影像技师/检验师)
- 不用像临床医学那样"5+3+规培"长周期,**4 年本科就能进医院**
- **广西医疗资源紧张 + 县乡医院刚需 → 影像/检验技术员闭眼进**
- 广医大 / 桂林医学院 / 右江民族医学院 都是性价比之选

### 8. 农林类(植物保护、动物医学、水产养殖)— 广西特色
- 广西是全国甘蔗主产区(占全国 60%+)+ 桑蚕第 1 + 木薯第 1 + 八角第 1 + 罗汉果第 1
- 在西大读作物学 / 园艺学(双一流)= **广西甘蔗糖业 / 茉莉花茶 / 沙田柚 / 罗汉果产业** 主力供给
- **西大动物科学(双一流)**:广东温氏 / 牧原 / 新希望 大量招,起薪 8-12k(出粤后)
- **北部湾大学水产养殖**:北海珍珠 + 海水养殖产业链对口
- **广西本地农林毕业 + 县乡农技推广员编制** = 农村家庭返乡稳路径

### 9. 兵器类专业(弹药工程、装甲车辆等)
- 限定院校:北理工、南理工、中北大学、西工大等"兵器八校"(广西本省没有)
- 毕业进兵工集团、航天科工、中船等军工央企,**绝大多数有保密等级要求**
- 专业限制大但**进入门槛后稳定性极高**,基本一辈子在体制内
- **广西考生分够冲北理工/南理工兵器类 = 出区跃迁路径**

### 10. 数学 / 统计学 — 万金油基础
- 本科出路相对窄,但**是研究生阶段转 CS / 金融 / 量化的最佳跳板**
- 数学好的考生,本科读数学比直接读金融更有未来 — 顶级量化基金只要数学/物理出身
- 广西考生数学好的可以**借数学专业考研出广西**(西大数学 / 广西师大数学 都是不错的考研跳板)
- 适合数学单科 130+ 的学生

### 11. 东盟语种(越南语 / 泰语 / 老挝语 / 柬埔寨语 / 印尼语)— 广西独家
- **广西民族大学**(南宁)东盟语种**全国第 1**
- 出口:**外交部 + 商务部 + 各级外事办 + 广西区驻东盟办事处 + 北部湾跨境贸易 + 中国-东盟博览会主办系统**
- **广西考生独家区位优势**,出区考生很少跟广西考生抢
- 起薪 8-12k(跨境贸易 / 海关 / 外事办)+ 跨境补贴
- 缺点:小语种圈子小,改行难;但**广西边境贸易 + 东盟外交 政策红利期** 至少 10 年

### 12. 中医药材 / 中药学(广西特色)
- 广西是**全国中药材主产区之一**(玉林是全国最大中药材集散地),罗汉果/桂枝/八角/田七/砂仁 等道地药材
- 广西中医药大学中药学 + 玉林中药材产业 = 区内本土路径
- 适合玉林/南宁/桂林本地中药商家庭子承父业,或对中医药文化有兴趣的考生

### 13. 公共卫生 / 预防医学 — 后疫情红利
- 各级疾控中心(广西区疾控/各市疾控)+ 海关检疫(凭祥/东兴/友谊关 边境海关检疫)+ 卫健委
- **广西特色:边境疫情防控 + 东盟跨境疫情合作** = 公卫人才稀缺 + 政策倾斜
- 广医大 + 桂林医学院 公共卫生主供给

### 14. 海关管理 / 边检相关
- 广西有 **20+ 个国家级口岸**(凭祥/东兴/水口/友谊关/龙邦/平孟 等),全国对越南口岸最密集
- 中央财经大学 / 上海海关学院 等海关相关专业,**广西考生分够冲毕业进广西海关 / 边检 = 隐藏稳路径**
- **南宁海关/凭祥海关/东兴海关 月薪 8-12k + 编制 + 边境艰苦补贴**

## 决策映射

| 学生情况 | 推荐 |
|---|---|
| 普通家庭 + 想考公 + 不挑专业 | 汉语言文学(首选) |
| 普通家庭 + 男生 + 不怕吃苦 + 求稳定 | 电气、测绘、船舶、海洋工程 |
| 不在意偏见 + 求绝对稳定 | 殡葬专业(出区) |
| 喜欢医学但不想读 8 年 | 医学影像 / 检验 |
| 数学单科很强 + 中产家庭 | 数学 / 统计学(本科为研究生跳板) |
| 农村或半农村家庭 + 喜欢动物 / 植物 | 兽医 / 园艺(西大优先,双一流学科) |
| 想做外贸 / 跨境贸易 / 外交 | **广民大东盟语种(广西独家)** |
| 玉林本地 + 中药材家庭 | 中医药 / 中药学(广西中医药大) |
| 北海/钦州/防城港 沿海家庭 | 海洋工程 / 水产养殖(北部湾大学) |
| 广西籍想进海关 / 边检 | 海关管理 + 公安专业 + 边境管理 |

## 典型 case(供 agent 引用)

- **Case A**:广西河池考生(瑶族),540 分历史类,普通工薪家庭。家长本想报"金融"(双非)。建议改报玉林师院汉语言文学,毕业考广西区考一次成功,**家庭逆袭**
- **Case B**:广西崇左考生,560 分物理类,普通家庭男生。本想报"工商管理"(三本)。建议改报桂电电气,毕业进南网广西崇左公司,**月入 8k + 编制**
- **Case C**:广西防城港考生,580 分历史类,普通家庭女生。本想报"国际经济与贸易"(双非)。建议改报**广西民族大学越南语** → 毕业进东兴海关 → 月薪 9k + 跨境补贴,**广西区位红利路径**
- **Case D**:广西玉林考生,520 分物理类,中药材商家庭。家长本想报金融。建议改报**广西中医药大学中药学** → 毕业回玉林做家族中药材产业升级,**子承父业 + 区位优势**
- **Case E**:广西百色考生(壮族),570 分物理类,农村家庭。本想报临床医学。建议改报**右江民族医学院 农村订单定向医学生(免费医学生)** → 学费全免 + 生活补贴 + 毕业回百色县乡医院,**几乎零成本进医疗编制**
- **Case F**:广西桂林考生,610 分物理类,普通家庭男生。本想报金融。建议改报**桂林理工测绘工程** → 毕业进广西国土厅 / 中铁广西 → 月薪 7-9k + 编制,**测绘冷门高 ROI 路径**

## 易错认知(agent 要纠正用户的)

- "**冷门 = 没前途**" — 错。冷门 = 报的人少 = 不卷 + 行业稳定的概率高
- "**学这种又不能挣大钱**" — 错。普通家庭追求"挣大钱"概率失败,追求"稳定"概率成功
- "**汉语言文学就是当老师**" — 错。汉语言考公比当老师香 100 倍,广西每年区考可报岗位数惊人
- "**测绘 / 海洋工程都是又苦又累**" — 半对。基层岗确实苦,但晋升后管理岗 + 央企福利远好于互联网卷王
- "**殡葬太丧 / 太晦气**" — 老一代认知。年轻一代消除偏见 + 稳定收入两不误
- "**数学统计本科找不到工作**" — 半对。本科确实就业一般,但是**最好的研究生跳板专业之一**
- "**东盟语种是小语种,没用**" — 错。**广西考生独家区位优势**,**北部湾经济区 + 中国-东盟自贸区 + 海上丝路** 政策红利期 10 年以上,东盟语种 = 广西考生进外事办 / 海关 / 跨境贸易 的最稀缺专业
- "**广西中医药大学不是 211,不值得读中医**" — 错。**广西中医药大学是中医药领域的区域强校 + 壮医学全国唯一**,广西本地中医医院招聘主供给,留桂中医路径稳
- "**农村孩子读农林是没出息**" — 错。**西大作物学 / 动科 / 林学 是双一流学科**,**农村孩子本身就有农林感觉 + 毕业回县乡农技推广员编制 + 大型农业央企(温氏/牧原/新希望)** = 农村家庭返乡稳路径

## 广西特色冷门 — 与外省的关键差异

| 冷门专业 | 全国情况 | 广西特殊红利 |
|---|---|---|
| **东盟语种** | 全国普通小语种 | **北部湾 + 东盟外交 + 中越边境 = 广西独家** |
| **壮医学** | 不存在 | **广西中医药大全国唯一** |
| **海洋工程 / 水产** | 普通理工科 | **北部湾经济区 + 北海珍珠 + 防城港自贸** |
| **作物学 / 园艺(甘蔗 / 茉莉花 / 罗汉果)** | 普通农林 | **西大双一流 + 广西全国第一甘蔗主产区** |
| **边境管理 / 海关** | 普通海关 | **20+ 个对越口岸 + 跨境贸易枢纽** |
| **少数民族学(壮 / 瑶 / 苗)** | 冷门 | **广西区位 + 民族扶持政策 + 民族干部岗** |

**广西考生善用这些独家冷门 = 比"冲热门双非金融/CS"性价比高 5-10 倍**。
