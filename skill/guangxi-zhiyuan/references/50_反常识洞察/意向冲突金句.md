# 用户意向冲突 — Reality Check 金句库(广西版)

很多家长 / 考生有具体的意向("想上西大"、"非南宁不去"、"想学医"、"非出粤不可"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑)— 必须做 reality check + 给出替代方案。

广西特殊性:**意向冲突常常涉及"留桂 vs 出粤"的核心抉择**(不像湖北省内 985 多,广西全省只有 1 所 211),所以广西的意向冲突场景跟内陆省份不一样。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **广西特色:"留桂"vs"出粤"是核心权衡** — 不要简单说"出广西就好",也不要简单说"留广西稳" — 看家庭 + 锚点

---

## 4 类意向冲突 + 金句模板(广西版)

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 380 分要西大顶配组 / 580 分要中山大学)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985/211 牌子的执念,还是把 [替代校] 当作双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(广西 580 分,意向中山大学)**:
> "中山大学在广西物理类 1500-3000 名。你 18000 名,差 1.5 万名,**中山没戏**。
>
> 但你能上**广西大学 + 桂林电子科技大学**,广西大学是本省唯一 211 + 双一流,留桂考公考编 + 广西公检法 + 央企广西分公司认可度顶配。
>
> 桂电出粤进华为/中兴/比亚迪/OPPO,大湾区电子信息招聘主力,**论出粤就业,桂电 CS 比中山非 CS 专业还有竞争力**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'211 就是 211',但 **211 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 区内强专业]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(广西考生 + 意向西大)**:
> "西大你 600 能擦边 — 但只能进生命科学 / 林学 / 哲学。**211 + 西部 + 生化环材** = 三重坑。
>
> 同分能上**桂林电子科技大学 CS / 软件工程 / 通信(B 类工科)** 出来对口程度更高,大湾区校招认可度强于西大冷门组。
>
> 西大留一个心理慰藉位即可,主推桂电工科组。"

**真实案例(广西考生 + 意向出区 985)**:
> "你 595 想冲兰州大学 / 东北大学。**985 牌子有了,但只能进生化环材 / 草学 / 矿冶**。
>
> 同分留广西能上**西大土木工程(双一流)/ 西大法学 + 选调路径**,**论留桂体制内出口 + 央企广西分公司,西大双一流 > 兰大冷门组**。
>
> 兰大留一档冲,主推西大双一流方向。"

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村壮族瑶族苗族,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [广医大临床 5+3 一体化 / 出区中山医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 检验 / 护理 / 免费医学生 — 早 3 年挣钱]),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(广西普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 6-10k**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**广医大临床 5+3 一体化**(留桂顶配)。
>
> 撑不起 → **建议医学影像技术 / 医学检验技术(4 年本科直接进医院技师岗,起薪 5-8k,早 4 年挣钱)**,或者**农村订单定向医学生(免费医学生)** — 学费全免 + 生活补贴 + 毕业回县乡医院 6 年。"

**真实案例(广西农村壮族 + 想学法学)**:
> "你想学法学进法院 — 真相是法学本科出来基本找不到对口工作,**5+3 法考 + 实习 5 年才能进省级法院,8 年长周期**。
>
> 农村壮族家庭撑得起吗?家里没法律行业资源。
>
> 撑不起 → 改报**广西大学法学 + 民族班 + 国家专项**(降分 30+ 进 211)→ **毕业选调直接进广西区委组织部 / 各市政法委** — **比硬磕法学 + 法考 8 年路径快 5 年**。
>
> 想做律师 → 建议本科考公 / 选调先稳住,工作 3-5 年再考虑法考转律师(年龄不是问题,体制内转法律行业有积累)。"

---

### 模式 D:意向城市 vs 院校层次 — "非南宁不去"/"非出粤不可"

**特征**:用户只想留某个城市("非南宁不去" / "非出粤不可"),拒绝其他选项。

#### D1:广西特色 — 留南宁 vs 留桂林 vs 留柳州 vs 出粤

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211/双非] 和 [外地 + 985 弱专业] 之间选。
>
> **留 [意向城] 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外地 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留南宁没意义,要去西工大),**要灵活退一步**。"

**真实案例(广西考生 + 非南宁不去)**:
> "你只留南宁,这位次 12000,西大主流够不上 / 出区 985 也不可能。
>
> **留南宁最稳路径**:**广西民族大学 / 南宁师范大学** 法学/汉语言/行政管理(留南宁考公主供给) → 毕业进南宁市直 / 区直机关。
>
> 不要为了'外地 985 牌子'去东北农大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 留南宁竞争力不强**,综合不划算。"

**真实案例(广西考生 + 非出粤不可)**:
> "你坚定要出粤,这位次 8000,够不上中山 / 华南理工。
>
> **出粤最稳路径**:**桂电 CS / 通信 / 电子**(大湾区电子信息校招主力,起薪 8-15k);或者**广州大学 / 深圳大学**(广东双非但留粤就业有地利)。
>
> 不要为了'西大 211 牌子'留桂吃低工资 — 你既然想出粤,**桂电出粤 ROI 远高于西大留桂**(月薪差 2-3 倍)。"

#### D2:广西特色 — "出广西"分两种意向

**金句模板**:
> "你说想出广西,要先分清楚:
> - **想出粤(进大湾区拼经济)** → 桂电 CS / 桂电电子 / 西大经管 + 大三主动出粤实习
> - **想出区进省会城市当公务员 / 进央企** → 西大法学 / 西大汉语言 + 选调中央指标 / 国家专项
> - **想出国 / 留学** → 广西本地中外合作办学少,主要走北上广出国通道
>
> 不要笼统说'出广西',目标不同路径完全不同。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比(广西 2024 起新高考分物理/历史,2021-2023 是老高考文/理,**对比时要分两段**)
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ 广西特色错误:**简单推"出广西就好"** — 这是不负责任的,要分清出粤拼经济还是出省考公;广西农村壮族家庭留桂用民族班 + 选调反而比出区强

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

广西特色的双轨常见:
- **轨道 1:留桂**(西大/桂电/广师大/广医大 + 编制路径)
- **轨道 2:出粤**(桂电出粤 IT / 中山华工 / 暨大新闻 + 大湾区路径)
- **轨道 3(农村少数民族独有)**:民族班 + 国家专项 + 选调中央指标(性价比顶配)

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 西大 / 想学医 / 想留南宁 / 想出粤 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

| 用户意向 | 常见 reality check 输出 |
|---|---|
| "想上西大不能少" | 看分数 + 民族 + 户籍。够 = 闭眼报西大;不够 = 桂电/广医大/广师大替代;农村壮瑶苗 + 民族班 / 专项可降 30+ 分进 |
| "非南宁不去" | 留南宁 211 = 西大;双非 = 广民大 / 南宁师大(留南宁考公主力);**广医大留南宁医学性价比** |
| "非出粤不可" | 出粤 IT = 桂电;出粤综合 = 中山/华工(分极高)/ 暨大;出粤普通双非 = 广州大学/深圳大学 |
| "想学医一定要" | 顶配 = 出区中山医/南方医;留桂顶配 = 广医大 5+3;**普通家庭 = 医学影像/检验/护理/免费医学生** |
| "想做警察" | 区内 = 广西警察学院 + 公安联考;出区 = 中国人民公安大学 / 中国刑警学院 |
| "想做外贸 / 跨境" | **广民大东盟语种(广西独家区位优势)** + 海关 / 外事办路径 |
| "想读金融" | 双非金融 = 死局;**改西大经管(留桂)/ 中南财法(出区)/ 不要双非金融** |
| "不想出广西也不想读师范医学" | 这个组合最难;西大法学/汉语言 + 选调;桂电电气进南网;广西本地编制路径 |

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**广西特色补充**:**"留桂"还是"出粤"不是简单的好坏题,而是 family-specific 的取舍题** — 农村少数民族 + 体制内偏好 → 留桂 + 民族班杠杆是顶配;城市中产 + IT 锚点 → 出粤桂电是顶配;**不要给所有广西考生一个统一答案**。
