# 广西医科大学(广医大,GXMU)— 双非但临床医学全国前列,广西医院系统主力供给

## 一句话总结

**广西医院系统的主力供给校,临床医学是国家一流本科 + 学科排名全国前列(双一流学科建设备选)**。**类似河南郑大医学部 / 河北医科大学 的地位** —— **双非牌子,但临床实力跟中游 211 医学院相当**。**广西区内医院 80% 以上的医生出自广医大**。**学医普通家庭要算清 11 年长学制 + 规培成本是否撑得住**,撑得住 = 留桂铁饭碗 / 出粤三甲 / 东盟医疗输出 三重出口。

---

## 真实地位

- **双非但临床医学是国家一流本科**(部分专业接近"准 211"档),**双一流学科建设备选**(医学方向)。
- **本省地位**:**广西医院系统主力供给**,广医大附一 / 附二 / 肿瘤医院 / 五附院 等是广西顶级三甲,**广西区内医生 80%+ 出自广医大**,**地位无替代**。
- **同档对比**:跟河南郑大医学部(部分独立)/ 河北医科大学 / 山西医科大学 / 重庆医科大学 一档(双非但临床顶级),**比一般双非医学院学科评估强,但牌子受双非拖累(出区认可度弱于一般 211 医学院)**。
- **校区地理**:**南宁市青秀区**(主校区)+ **武鸣校区**(新生主要就读),**南宁是广西首府 + 北部湾医疗中心 + 中国-东盟医疗合作主基地**。

## 广西物理类录取位次区间(医学类必须物理 + 化学 / 生物组)

- **顶级组(临床医学 5+3 一体化 / 口腔医学 5+3)**:全省 **3,000-5,500 名**(分数对标西大顶级组)
- **王牌组(临床医学 5 年制 / 口腔 / 麻醉 / 影像)**:全省 **5,500-9,000 名**
- **主流组(预防医学 / 护理 / 药学 / 检验)**:全省 **9,000-18,000 名**
- **冷门组(医学边缘类:英语 / 管理)**:全省 **18,000-30,000 名**(**别选**)

## 广西历史类(广医大历史类极少,主要文管类)

- 历史类只招少量医院管理 / 英语方向,全省 **5,000-10,000 名**

## 2021-2023 文/理 位次参考(老高考)

- 理科:**临床 5+3 全省 4,000 名内**;**临床 5 年制 5,500-9,000 名**;**预防/药学/护理 9,000-25,000 名**

**段位定位**:广西物理类 **临床 5+3 一体化是医学顶配冲档**(省排 5,500 名内),**临床 5 年制是医学主流档**(省排 9,000 名内),**护理/检验是医学保底档**(省排 30,000 名内)。**以一分一段表反查为准**。

## 性价比专业(广医大独家)

- **临床医学 5+3 一体化**:**本硕连读 8 年 + 毕业即研究生 + 直接进三甲规培**,**普通家庭学医的最优路径**(免去单独考研的不确定性)。
- **预防医学**:**进广西疾控 / 各市疾控 = 公务员事业编**,经过疫情后疾控扩编,**铁饭碗路径明确**,录取分相对临床低一档,性价比顶配。
- **麻醉学**:**医院最缺人岗位之一 + 工资高 + 录取分低于临床**,**普通家庭学医的隐藏赛道**(注:学医普遍长学制 + 高强度,慎选)。
- **东盟医疗输出方向**:广医大跟越南/老挝/缅甸医院有合作,**部分毕业生进东盟医疗援助 / 跨境医疗**,起薪 + 海外补贴 = 8-15k。

## 坑专业 / 慎选(在广医大里相对弱)

- **英语 / 医学管理 / 公共事业管理**:在医科大里边缘,**别选**(医学校的非医学专业是水分,出区无优势)。
- **生物医学工程**:听起来像医工交叉,**实际就业不如纯临床 / 纯计算机**,**慎选**。
- **护理学男生**:护理本身不坑,但**男护就业受隐性偏好限制**(护理需求大但岗位偏女),**男生学医优先临床/麻醉/影像**。

## 关键提醒(填报陷阱)

1. **临床医学 5+3 一体化 vs 5 年制 vs 4 年制**:
   - **5+3 一体化**(临床医学 / 口腔):**本硕连读 8 年 + 毕业进三甲规培**,**最稳路径**,分数高一档
   - **5 年制**:本科毕业要单独考研 / 规培 3 年 = **8-11 年学制起步**,**不冲 5+3 慎入**
   - **4 年制**(护理 / 药学 / 检验等):本科直接就业,**学制短但工资 / 编制天花板低**
2. **学医的"长学制 + 高强度"现实**:
   - **本科 5 年 + 规培 3 年 = 8 年起步**(临床 5+3 一体化是 8 年本硕)
   - **想做主治医师**:**本硕博 8+ 年 + 规培 3 年 = 11 年起步**
   - **普通工薪家庭要算清 11 年学习成本能不能撑住**(学费/生活费/规培期低工资 5-8k)
3. **广医大本部 vs 广西医科大学武鸣校区**:**新生主要在武鸣校区**(南宁市武鸣区,**离市区 30 分钟车程**),高年级回市区临床实习。
4. **服从调剂注意**:中分组可能被调到护理 / 检验 / 英语 / 管理,**接受不了护理/管理的别勾**。
5. **广医大 vs 桂林医学院 vs 广西中医药大学**:**临床顶配 → 广医大**;**分不够广医大临床 → 桂林医学院 / 右江民族医学院 也是双非选项,部分专业有定向培养**;**学中医 → 广西中医药大学**(中医方向另一条赛道)。

## 毕业出口(2024 数据)

- **留广西就业**:**约 60-65%**(南宁广医大附属医院 + 广西各市三甲为主,**南宁占大头**)
- **去粤港澳大湾区**:**约 20-25%**(广州 / 深圳 / 佛山三甲招广西临床大量,**广东医院缺人 + 接收量大**)
- **东盟出口**:约 3-5%(中越/中老/中缅 跨境医疗援助 + 跨境医疗合作 + 东盟医院进修)
- **考研 / 读博**:约 30-35%(临床 5+3 一体化是直接连读;5 年制需要单独考研,**双非考研有学校歧视风险但临床专业相对宽松**)
- **进体制内 / 事业编概率**:**约 50%+**(广西公立三甲 / 疾控 / 卫健委)

**起薪反差**:
- **留南宁三甲(规培期)**:5-8k(规培期 3 年是低工资期),**规培后 8-15k**(主治后 15-25k)
- **留广西基层县医院**:规培期 4-6k,正式 6-10k
- **出粤广州 / 深圳三甲**:规培期 8-12k,**正式 15-30k+**(深圳三甲临床更高),**比留桂高 2-3 倍**
- **东盟医疗援助方向**:8-15k + 海外补贴(跨境医疗合作项目)

**留桂工资低 vs 出粤高的反差**:广医大临床毕业生**留南宁三甲规培期 5-8k vs 出粤三甲规培期 8-12k**,**差距长期累积更大**。但广西医院"顶配三甲(广医大附一/附二)"在区内是顶级地位,留桂长期发展(主任医师/教授级别)比出粤新人更有空间。**家庭权衡:稳定留桂 vs 收入出粤**。

## 同档对比

| 维度 | 广医大 | 西大医学相关 | 出区中山医 / 南方医 | 桂林医学院 |
|---|---|---|---|---|
| 牌子 | 双非但临床顶级 | 211(综合)+ 医学边缘 | **985 / 一线医学** | 双非保底 |
| 临床实力 | **广西第一** | 弱(西大不强医学) | **全国 Top 10** | 中段 |
| 留桂认可度 | **顶配** | 一般 | 强(品牌溢出) | 强(基层) |
| 大湾区认可度 | 中(临床) | 弱 | **顶配** | 弱 |
| 录取分(广西) | 高(临床组) | 中 | **极高** | 中低 |

**简单结论**:**留广西学医 → 广医大临床是首选**;**分够 + 想冲顶配医学 → 出区中山医 / 南方医 / 协和**;**分不够广医大临床 → 桂林医学院 / 右江民族医学院 保底**。

## 适合谁

- 广西物理类 **省排 3,000-30,000 名** + 必选化学 / 生物 + 明确想当医生。
- **明确想当医生 + 留广西 + 普通家庭(能撑长学制 8-11 年)** → 广医大临床是首选。
- **想进疾控系统(公务员事业编)** → 预防医学是性价比之王。
- **想学口腔 + 民营齿科连锁路径** → 口腔医学 5+3 一体化对口。
- **想做东盟医疗援助 / 跨境医疗** → 广医大有东盟医疗合作通道。

## 不适合谁

- **不明确要做医生 / 怕长学制 / 怕规培低工资期** → **别学医**(选其他专业,**学医是不可逆的人生选择**)。
- **分够冲中山医 / 南方医 / 协和** → 优先出区(顶配医学院在大湾区/全国认可度更强)。
- **不想做纯医学想要医学边缘(医院管理 / 医学英语)** → 这些在广医大不强,**出区或选别的方向**。
- **想学中医** → 广西中医药大学是另一条赛道,中医西医不混。
- **女生 + 不能接受规培期高强度 / 长时间值夜班** → 学医前先了解临床真实工作强度。
