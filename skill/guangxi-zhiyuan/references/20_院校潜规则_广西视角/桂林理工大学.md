# 桂林理工大学(桂工,GLUT)— 双非但地质资源/有色金属强,中色集团对口

## 一句话总结

**原中国有色金属工业总公司部属高校**,**地质资源与地质工程 / 有色金属冶金 / 测绘 / 旅游管理 全国前列**(地质资源与地质工程是双一流学科建设方向)。**中色集团(广西平果铝业 / 柳州华锡 等)+ 中冶集团 + 广西本地矿企** 直接对口。**双非里"细分领域顶配"**,跟成都理工(地质强)、长安大学(部分专业)是邻档。**男生 + 不怕地勘 / 跑工地 / 进央企国企 = 桂工是性价比之王**。

---

## 真实地位

- **双非但地质资源 / 有色金属冶金 / 测绘 学科强势**(**地质资源与地质工程是双一流学科建设方向**),**部分专业接近"准 211"档**。
- **历史血统**:**1956 年建校,原中国有色金属工业总公司部属**(跟昆明理工 / 中南大学 部分专业 同系统的"有色金属"+"地质"基因),**广西有色金属丰富(全国第一锰矿大省 + 大量铝土矿/铅锌矿/锡矿)= 桂工生存土壤**。
- **本省地位**:**广西第二工科**(位列西大 / 桂电之后),**广西矿业 / 地质 / 有色金属 / 桂林旅游 主力供给**。
- **同档对比**:**地质学科水平跟成都理工同档**(双非里地质两强),**有色金属冶金跟昆明理工同档**(双非里有色两强),**牌子在中色集团 / 中冶集团 / 广西矿企 内部认可度极高**。
- **校区地理**:**桂林市雁山区**(屏风校区主校区)+ **雁山校区 / 安吉校区 / 南宁校区**(分校区,**南宁分校区 = 部分专业 + 实习就近**)。**桂林山水甲天下 → 旅游产业链 → 桂工旅游管理 = 完整闭环**。

- **王牌组(地质工程 / 资源勘查工程 / 测绘工程 / 冶金工程)**:全省 **20,000-32,000 名**(矿业类录取分相对低,**性价比专业**)
- **主流组(土木 / 化工 / 环境 / 旅游管理)**:全省 **15,000-25,000 名**(土木 / 化工 在桂工分高一些)
- **冷门组(部分材料 / 经管 / 文科)**:全省 **32,000-50,000 名**

## 广西历史类录取位次区间

- 历史类主要旅游管理 / 经管 / 法学,全省 **8,000-15,000 名**

- 理科:**地质/资源/测绘 全省 22,000-35,000 名**(矿业类略低);**土木/化工/旅游 全省 18,000-28,000 名**;**冷门组 35,000-55,000 名**

## 性价比专业(桂工独家)

- **地质资源与地质工程(双一流)**:**双非里学地质,桂工跟成都理工是天花板**(其他双非地质跟桂工差距明显)。**进中国地质调查局 / 中色集团 / 中铁地质勘察 + 各省地勘院 + 矿企 = 央企国企铁饭碗**,**起薪 8-12k + 野外津贴 + 项目奖金**。
- **冶金工程(有色金属方向)**:**广西是全国第一锰矿大省 + 大量铝土矿 / 铅锌矿 / 锡矿** → **中色集团(广西平果铝业 / 柳州华锡)直接对口**,**起薪 7-12k + 矿企待遇好**(国企福利 + 食堂 + 宿舍)。
- **测绘工程**:**国家测绘地理信息局 + 广西测绘院 + 中铁/中建/中交测绘部门**,**起薪 6-10k + 编制内**(测绘是公务员事业编主力专业之一)。**性价比顶配**(录取分相对低 + 出路稳定)。
- **旅游管理(桂林特色)**:**桂林山水甲天下 + 桂工旅游产业链对口**,**进万豪 / 希尔顿 / 洲际 国际酒店 + 桂林本地高端酒店 + 东盟跨境旅游(中越/中泰)**。**起薪 4-7k 不高,但喜欢旅游 + 国际化路径的考生对口**。

## 坑专业 / 慎选(在桂工里相对弱)

- **文科 / 经管 / 法学**(非旅游管理)**:在桂工里边缘**,选广师大文科 / 西大法学 / 出区综合性大学。
- **计算机 / 软件工程**:**桂工计算机不如桂电**,想做 IT 选桂电 / 西大,**桂工计算机是双非通病**。
- **部分材料 / 化工 / 部分理科(非地质相关)**:**接受不了天坑材料的别勾服从**。
- **市场营销 / 信息管理与信息系统**:水分大,**毕业改行率高**。

## 关键提醒(填报陷阱)

1. **"准 211"不是 211 (★)**:**就业认可度仍受双非牌子拖累**,但**地质资源 / 冶金 / 测绘 在中色集团 / 中冶 / 地勘系统 内部认可度极高**(因为对口 + 工科底子厚 + 行业稀缺)。**校招卡 211 时**桂工学生要解释"双非但学科强 + 行业对口"。
2. **桂工适合"行业对口央企"路径 (★★)**:
   - **本科 → 桂工地质 / 冶金 / 测绘 → 直接进中色集团 / 中冶 / 地勘院 / 矿企** 是经典路径
   - **行业央企对桂工本科接受度极高**(原有色总公司亲缘 + 对口)
   - **本科直接就业进央企铁饭碗 = 桂工最优路径**
3. **地质 / 矿业 / 测绘 行业的"现实"**:
   - **对口央企(中色 / 中冶 / 地勘院)项目常在西部 / 山区 / 矿区 / 边远地带**,**前 5 年基层出差跟着工程跑**,**工资稳定但生活不舒服**
   - **接受不了野外勘察 / 跑工地 / 矿区生活的别报地质矿业**
   - **野外津贴 + 项目奖金 + 食堂宿舍** 是这条路径的隐性收入(基本工资 + 各种补贴 = 实际收入 1.5-2 倍)
4. **桂工本部 vs 桂工博文管理学院 / 南宁分校区**:**屏风校区(主校区,桂林)= 公办本部**,**博文管理学院 = 独立学院 / 民办**,**南宁分校区 = 公办分校(部分专业 + 离南宁实习近)**,**报志愿别看错代码**。
5. **服从调剂注意**:中分组可能被调到部分材料 / 化工 / 文科边缘,**接受不了的别勾**。
6. **桂工 vs 桂电**:**学电子/通信/计算机 → 桂电**;**学地质/冶金/测绘/化工 → 桂工**;**两者都不是综合性,选错方向后悔**。

## 毕业出口(2024 数据)

- **留广西就业**:**约 35-40%**(南宁中色集团 / 柳州华锡 / 河池华锡 / 广西测绘院 / 广西地勘院 / 桂林旅游业)
- **去粤港澳大湾区**:**约 20-25%**(广州 / 深圳 / 佛山 / 珠海 — 中色广东分公司 + 大湾区基建测绘 + 国际酒店)
- **去全国矿业基地**:**约 15-20%**(云南 / 贵州 / 江西 / 四川 / 内蒙古 — 中色 / 中冶 / 紫金矿业 / 江铜 / 各省地勘院 项目分布)
- **东盟出口**:**约 3-5%**(中越/中老/中缅 跨境地质勘察 + 中色集团东盟项目 + 东盟跨境旅游)
- **考研 / 读博**:约 20-25%(保研率 ~7-10%;**地质类考研武大 / 中国地质大学 / 中南大学接受度高**)
- **进央企 / 国企概率**:**约 35-40%**(中色集团 / 中冶 / 地勘院 / 矿企 招聘量极大,**桂工是央企招聘大户**)

**起薪反差**:
- **留南宁 / 柳州矿企 / 测绘院**:6-9k(国企编制 + 食堂宿舍)
- **野外项目(全国矿区 / 地勘项目)**:**8-12k + 野外津贴 + 项目奖金 = 实际 12-18k**(基本工资 + 各种补贴)
- **出粤(广州/深圳)中色分公司 / 大湾区基建**:**10-15k**(出粤行业溢价)
- **东盟跨境项目(中色 / 中冶 越南 / 老挝 / 缅甸 矿业)**:**15-25k + 海外补贴**(出差多 + 收入高)
- **桂林旅游业**:4-7k(本地旅游业起薪低,**喜欢旅游不计较起薪的考生对口**)

**留桂工资低 vs 出省 / 野外项目高的反差**:桂工地质矿业学生**留南宁 6-9k vs 全国野外项目 12-18k vs 东盟项目 15-25k**,**差距 2-3 倍**。**桂工矿业类"留桂"是放弃野外项目高补贴的代价**,**愿意跑野外的桂工学生收入并不低**。

## 同档对比

| 维度 | 桂工 | 桂电 | 成都理工(同档对标) | 西大土木 | 出区中南大学冶金 |
|---|---|---|---|---|---|
| 牌子 | 双非"准 211" | 双非"准 211" | 双非"准 211" | **211 + 双一流** | **985 + 双一流** |
| 地质 / 冶金 / 测绘 | **B+ 全国前列** | 弱 / 不开 | **B+ 全国前列** | 中等 | A+ 全国 Top 3 |
| 中色 / 中冶 央企认可 | **顶配(对口)** | 弱 | 顶配 | 中(土木对口中铁) | **顶配** |
| 大湾区认可度 | 中 | **顶配(电子)** | 中 | 强(土木) | 强 |

**简单结论**:**学地质 / 冶金 / 测绘 + 进中色 / 中冶 → 桂工是广西最优**;**学电子 / IT → 桂电**;**学土木 / 综合 → 西大**;**分够冲 985 冶金 → 中南大学(全国冶金顶配)**;**分不够桂工 → 部分双非工科保底**。

## 适合谁

- 广西物理类 **省排 15,000-50,000 名**(矿业类组 32,000 名内,土木旅游组 25,000 名内)。
- **男生 + 不怕地勘 / 跑工地 / 矿区生活 + 想要央企国企铁饭碗** → 桂工地质 / 冶金 / 测绘 是性价比之王。
- **进中色集团 / 中冶 / 地勘院 / 矿企** 路径明确的考生(**对口校招优势极大**)。
- **想做旅游 / 酒店管理 + 留桂林 + 不计较起薪** → 桂工旅游管理是好选项(**桂林山水产业链对口**)。
- **想做测绘公务员事业编**(测绘是事业编主力专业)→ 桂工测绘对口。
- **农村壮族 / 瑶族 + 国家专项 + 想跨阶级到央企** → 桂工对口中色 / 中冶 是隐藏跃迁通道。

## 不适合谁

- **追求 985 名校牌子** → 分够选中南大学冶金 / 武大地质 / 长安大学测绘。
- **不想做地质矿业 / 不能接受野外跑** → **别选桂工矿业类**(选桂工土木/化工/旅游 OK,**别勾矿业类的服从**)。
- **想做 IT / 电子 / 通信** → 选桂电,桂工计算机弱。
- **想做纯文科 / 经管 / 师范** → 选广师大 / 西大,桂工文科边缘。
- **女生 + 不接受男女比 7:3 + 不接受野外** → 桂工矿业类男生为主,**女生选旅游管理 / 化工 / 环境工程 OK**(这些组女生比例正常)。
- **怕国企传统 + 想互联网快节奏** → 桂工对口央企国企传统行业,**接受不了"传统行业稳定"的别选**。
