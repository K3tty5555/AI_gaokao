# 广西师范大学(广师大,GXNU)— 双非但广西师范主力,马列/中文/教育全国前列

## 一句话总结

**广西师范主力高校,桂林教育生态圈核心**,**马克思主义理论 / 中国语言文学 / 教育学 / 历史学 / 出版学 全国前列**(部分双一流学科 B+ 档)。**留桂当老师 + 进出版社 / 桂林课外辅导产业** 的标准路径。**师范类双非里"中等偏上"档**,跟河北师大 / 江西师大 / 安徽师大 同档。**普通家庭广西女生最稳的"铁饭碗"路径(公费师范)**。

---

## 真实地位

- **双非师范**(无 211 / 985 牌子,**马克思主义理论是双一流学科 B+** 接近"准 211"档),**广西第二师范主力**(广西师院已并入广师大)。
- **本省地位**:**广西公费师范主力供给校**,广西各市县中学 / 师专 老师大量出自广师大,**桂林本地教育生态主导**。
- **同档对比**:跟河北师大 / 江西师大 / 安徽师大 / 福建师大 同档(双非师范中等偏上),**比一般双非师范学科评估强,但牌子受双非拖累**。
- **校区地理**:**桂林市**(主校区:雁山校区 + 王城校区 + 育才校区),**桂林是广西教育/文化高地 + 旅游名城**,生活成本低,但实习/就业资源不如南宁。

- **王牌组(数学 / 物理 / 化学 师范方向)**:全省 **15,000-25,000 名**(公费师范分高一些)

- **冷门组(非师范理工)**:全省 **38,000-55,000 名**

## 广西历史类录取位次区间(广师大主战场)

- **王牌组(汉语言文学 / 历史学 / 英语 师范方向)**:全省 **3,000-6,000 名**(公费师范)
- **主流组(教育学 / 思政 / 学前 / 小学教育)**:全省 **6,000-10,000 名**
- **冷门组(非师范文科)**:全省 **10,000-18,000 名**

## 2021-2023 文/理 位次参考(老高考)

- 理科:全省 **20,000-50,000 名**
- 文科:全省 **3,500-15,000 名**(广师大文科是主战场)

**段位定位**:广西历史类 **省排 18,000 名内可冲广师大**,**6,000 名内可冲公费师范**;**物理类 55,000 名内可冲非师范组,25,000 名内可冲师范组**。**以一分一段表反查为准**。

## 公费师范生(广师大最大特色 ★★★)

**公费师范生政策**(广西区属公费师范,跟教育部直属六大师范的全国公费师范不同):

- **学费 + 住宿费 全免**(广西区财政承担)
- **生活补贴**:每月约 600-800 元(比教育部直属公费师范低一些)
- **毕业回原籍服务 6 年**(广西各市县中学,**违约要赔学费 + 信用记录**)
- **录取分较高**:历史类约 6,000 名内,物理类约 25,000 名内
- **覆盖专业**:汉语言 / 数学 / 英语 / 物理 / 化学 / 历史 / 政治 / 地理 / 生物 / 美术 / 音乐 / 体育(师范方向)

**最适合**:
- 普通工薪 / 农村家庭(零成本上一本师范)
- 父母希望孩子做老师 / 进体制内
- 性格内向稳健 + 笃定回老家工作
- **广西女生 + 留广西 + 想要铁饭碗** → 公费师范是最稳路径

**最不适合**:
- 完全不想做老师的(违约成本高)
- 想出广西就业的(回原籍约束硬)

## 性价比专业(广师大独家)

- **公费师范汉语言 / 数学**:**学费全免 + 编制 + 留桂林或回原籍** = 普通家庭最稳路径
- **马克思主义理论(双一流学科)**:广西党校 / 区直机关思政 / 高校思政教师对口,考公考编友好
- **出版学**:**桂林出版业** 区内最大产业链,广师大出版学是独家,**编辑/出版社路径对口**

## 坑专业 / 慎选(在广师大里相对弱)

- **大部分理工科非师范类(机械 / 化工 / 计算机)**:在广师大边缘,**别为"师大牌子"学非师范工科**,出区跟双非工科没差。
- **经管 / 法学**:双非师范的经管法学,**出区竞争力弱**。
- **新闻传播 / 广告**:文科非王牌,**毕业改行率高**。
- **数学与应用数学(非师范)**:**听起来像师范但不是公费**,**当心被忽悠**(广西区内非公费的话不如出区)。

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生**:
   - 名字里有"师范"且是**提前批 / 国家专项 / 区属定向** → 公费师范(免学费 + 编制)
   - 名字里有"师范"但是**普通批录取** → 非公费师范(自费 + 自找工作)
   - **千万分清,差几万学费 + 编制保障**
2. **服从调剂**:广师大物理类组内可能含心理学 / 教育技术 / 部分非师范理工,**接受不了的别勾**。
3. **公费师范的"原籍服务 6 年"是硬约束**:违约要赔学费 + 写违约记录,影响考公考编。**家长一定要跟孩子聊清楚**。
4. **广师大本部 vs 漓江学院**:**本部 = 一本批次 + 公办**,漓江学院已转设,但**报志愿别看错代码**。
5. **男生慎选广师大**:**广师大男女比约 3:7**,工科氛围弱,男生选桂电 / 桂工 / 西大 更适合。

## 毕业出口(2024 数据)

- **公费师范生**:**100% 进入广西各市县中学编制**(回原籍服务 6 年)
- **非公费师范生**:**约 50% 通过省考 / 市考考编**(广西本地中学/师专),约 30% 进民办学校 / 培训机构(留桂林居多),约 20% 改行
- **非师范类**:约 40% 留广西(南宁/桂林为主),**约 25% 出粤(广州/深圳教培行业)**,约 35% 改行 / 考研
- **东盟出口**:约 2-3%(国际中文教育 / 东盟中文学校,**带着中文教师身份去越南/泰国/印尼**)
- **考研 / 出国**:约 15-20%(保研率 ~5-8%,双非师范偏低)

**起薪反差**:
- **留桂林 / 南宁中学编制(公费师范)**:5-7k(含编制保障 + 寒暑假 + 五险一金)
- **留桂林民办学校 / 培训机构**:4-6k
- **出粤(广州 / 深圳)中学编制**:深圳中学甚至开 25-35w 年薪招广师大研究生(**深圳中学卷起师范名校招聘大战**),广州 / 佛山普通中学 8-15w 年薪
- **东盟方向(国际中文教师)**:海外补贴 8-15k,生活成本低

**留桂工资低 vs 出粤高的反差**:广师大学生**留桂林 5-6k vs 出粤 8-15k**,**深圳中学招广师大研究生年薪 25w+**,广师大公费师范"留区"是放弃出粤大头收入的代价。

## 适合谁

- 广西物理类 **省排 25,000-55,000 名** / 历史类 **6,000-18,000 名** 的考生。
- **女生 + 想当老师 + 留广西** → 广师大公费师范是首选,**普通家庭最稳路径**。
- **想做出版 / 文创 / 编辑** → 广师大中文 / 出版学,**桂林产业链完整**。
- **想做思政教师 / 进党校 / 进区直机关思政** → 广师大马列学科顶配。
- **想做国际中文教师 + 东盟方向** → 广师大对外汉语 + 东盟国际中文教育对口。

## 不适合谁

- **男生 + 工科方向** → **别选广师大**,选桂电 / 桂工 / 西大。
- **想做 IT / 互联网 / 电子** → 广师大计算机 / 信息技术专业弱,选桂电。
- **想出广西就业 + 不想做老师** → 广师大牌子在非师范圈 + 出区认可度弱,**出粤竞争力受双非拖累**。
- **明确想冲 985 师范牌子** → 分够选华师 / 北师,**不要为留广西强行选广师大**。
- **不能接受"回原籍服务 6 年"约束** → **别选公费师范**,选非公费师范(但要承担学费 + 自找工作)。

## 大小年趋势 + 录取波动(广西本省视角)

- **2021-2023 老高考**:**公费师范汉语言/数学/英语 录取分稳步走高**(教师编热);**非公费师范分数稳**;**非师范理工类分数偏低**(广师大非师范本就不强,适合捡漏)
- **2024 新高考首届(广西 3+1+2)**:**历史类 + 政治/地理 组对应汉语言/历史/思政师范 → 录取分进一步上抬**;**物理类 + 化学/生物 组对应数学/物理/化学师范 → 分数相对稳**(因为物理类考生更多冲西大/桂电)
- **大小年规律**:**公费师范几乎没有"小年"**(广西本省考生考公考编热),**非公费师范有小年捡漏机会**(部分家长嫌"自费师范没编制保障")
- **关键认知**:**广师大公费师范 vs 非公费师范是两个不同赛道,录取分差异大**(公费师范分高一档 + 编制保障;非公费师范分低一档 + 自找工作)
- **"双减"政策影响**:**校外培训机构受打击 → 公费师范进体制内中学更稀缺 + 更值钱**(2021 双减后广师大公费师范分数明显走高)

## 转专业 / 大类招生政策

- 广师大转专业**门槛中等**(GPA 前 15-20% + 笔试),**师范类专业转入相对容易**(本身就是学校强项),**非师范理工类转入师范类难**
- **公费师范的"原籍服务 6 年"约束硬**:**违约要赔学费 + 写违约记录,影响考公考编**;**报志愿前家长一定要跟孩子聊清楚**
- **建议**:**填志愿时直接报心仪师范专业**;**赌"非公费师范进来再转公费师范"路径几乎不可行**(公费师范名额是单独计划)

## 校园生活 + 男女比 + 生源结构

- **男女比**:整体 3:7 女多(师范校 + 文科为主),**师范类组男女比 2:8**,**少量理工组男女比正常**
- **生源结构**:**广西本省 ~75-80%**(师范校主供给本省中学),**外省生源 ~20%**(主要广东/湖南/江西/福建/贵州/云南 等)
- **少数民族比例**:**约 35-40%**(壮/瑶/苗/侗/仫佬/毛南 等),**民族文化氛围浓**(壮族山歌 / 三月三 / 民族歌舞节)
- **校区**:**桂林(主校区:王城+雁山+育才)**,**桂林是广西教育/文化高地 + 旅游名城**;**生活成本低 + 风景好**;**雁山校区是新校区 + 主要新生宿舍**
- **校园文化**:**学风务实** + 师范氛围浓;**晚上去图书馆 + 自习室 + 备课** 是常见画面;**桂林 4 月最美 + 6-9 月闷热多雨**;**饮食以桂林米粉 + 辣椒酱 + 桂林菜为主**
- **学风**:**整体偏务实 + 留区考公教师编导向**;**研究生导师团队整体强**(马克思主义理论 + 教育学 + 中文 是学科评估强项)

## 留桂校友网络 + 行业人脉

- **广师大校友占据广西各市县中学语文/数学/英语/物理/化学/历史/政治 老师 + 教育局 + 师专 + 区教育厅**
- **校友会以中学 + 教育局为节点,留桂网络密度极高**
- **跟出区师范名校(华师/北师)校友比**:**广西本地中学广师大校友密度 = 绝对垄断**;**北师/华师在广西本地中学的校友少**(北师/华师毕业生大量去深圳/广州/北京等大城市)
- **关键认知**:**留广西教书 → 广师大校友网 = 整个广西教育系统**;**出粤教书(深圳中学) → 北师/华师 > 广师大**(深圳中学卷起师范名校招聘大战,北师/华师博士在深圳中学开 25-35w 年薪)

**广师大是广西考生想做老师的核心选择题**:
