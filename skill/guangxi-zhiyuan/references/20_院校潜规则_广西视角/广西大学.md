# 广西大学(西大,GXU)— 广西唯一 211 + 双一流,本省第一首选

## 一句话总结

**广西全省综合实力第一,广西唯一 211,也是双一流(土木工程 + 动物科学)**,**留桂考公考编 + 进区直机关 + 中字头央企广西分公司 = 西大独家 buff**。本省考生想要 211 牌子留广西,**无替代**。但全国 211 排名靠后(中游 211 档),出广西到一线就业牌子有限,不如分够冲华南理工 / 中山 / 武大 / 华科 等出粤 985。

---

## 真实地位

- **教育部与广西区"区部共建"老牌综合性 211 + 双一流**(土木工程 / 动物科学 / 作物学 三方向建设),**广西唯一 211**。
- **本省地位**:广西全省综合实力第一,**广西公检法 + 区直机关 + 央企广西分公司 招聘看西大背景**,本地认可度顶配。
- **同档对比**:跟山西大学 / 海南大学 / 宁夏大学 / 内蒙古大学 一档(中游偏后 211),全国 211 排名靠后,**牌子在西部 / 大湾区认可度还可以,出长三角 / 京津就普通**。
- **校区地理**:**南宁市西乡塘区**,主校区在南宁市中心偏西,**南宁是广西首府 + 北部湾经济区核心 + 中国-东盟博览会主办地**,实习/就业资源在区内最强。

## 广西物理类录取位次区间

参考近 5 年掌上高考数据 + 广西一分一段表(2024 起新高考分物理/历史):

- **顶级组(临床医学预科 / 计算机 / 电气工程 / 土木卓越)**:全省 **3,500-6,500 名**
- **主流组(土木工程 / 机械 / 化工 / 经管 / 法学)**:全省 **6,500-12,000 名**
- **中段组(动物科学 / 作物学 / 林学 / 部分文理)**:全省 **12,000-18,000 名**

## 广西历史类录取位次区间

- **王牌组(法学 / 汉语言文学 / 行政管理)**:全省 **1,200-2,800 名**
- **主流组(经管 / 新闻 / 历史)**:全省 **2,800-4,500 名**

## 2021-2023 文/理 位次参考(老高考)

- 理科:全省 **5,000-18,000 名**(临床/计算机靠前,农林靠后)
- 文科:全省 **1,500-4,500 名**(法学/汉语言靠前,部分边缘文科靠后)

**段位定位**:广西物理类 **省排 18,000 名内可冲西大**,**12,000 名内可挑专业**,**6,500 名内可冲王牌组**。**以一分一段表反查为准**。

## 性价比专业(西大独家)

- **土木工程(双一流方向)**:**广西基建 + 中字头央企** 直接对口,中铁/中建广西分公司大量招西大土木,**普通家庭进央企铁饭碗最直接路径**。
- **法学 + 行政管理**:**广西公检法 + 区直机关** 西大背景占比极高,**留桂考公性价比之王**。
- **动物科学(双一流)**:**广东温氏 / 牧原 / 新希望** 大量招西大动科,**起薪 8-12k**(比留区高一截),性价比隐藏。

## 坑专业 / 慎选(在西大里相对弱)

- **哲学 / 宗教学 / 部分边缘文科**:在西大也是凑数,出区竞争力弱。
- **新闻传播 / 广告**:工科底子的综合校文科系,毕业改行率高。
- **部分经管类**:出区跟央财 / 上财 / 中山管院 比没优势,**留桂还行,出区不值**。
- **计算机**:在西大不弱,但**论电子信息底子和大湾区认可度,桂电更对口**,西大计算机不如桂电计算机。

## 关键提醒(填报陷阱)

1. **西大本部 vs 西大行健文理学院**:**只有本部是 211**,行健文理是独立学院,**学费贵 + 牌子差**,**报志愿别看错代码**。
2. **物理类专业组分化**:王牌组(土木双一流 / 临床预科 / 计算机)与冷门组(部分文理 / 农林)位次差 8,000+ 名,**勾服从前查清组内有什么**。
3. **服从调剂注意**:中分组可能被调到农林动物 / 边缘文科,**接受不了的别勾**。
4. **西大 vs 出区 985**:**分够华南理工 / 中山 / 武大 / 华科 → 优先出区**;**笃定留广西 + 体制内 → 西大无替代**。
5. **少数民族优惠政策**:**壮族 / 瑶族 / 苗族 农村考生用上少数民族加分 + 民族班 + 国家专项**,可降 30-50 分进西大,**西大是这些政策的最大受益面**。

## 毕业出口(2024 数据)

- **留广西就业**:约 50-55%(南宁 / 柳州 / 桂林,**南宁占大头**)
- **去粤港澳大湾区**:约 20-25%(广州 / 深圳 / 佛山为主,**广东接收量大**)
- **东盟出口**:约 3-5%(中越边贸 / 跨境工程 / 东盟基建,土木 / 经贸专业为主)
- **考研 / 出国**:约 20-25%(保研率 ~10-12%,中游 211 档)
- **进央企 / 国企概率**:**约 30-35%**(中铁广西 / 中建广西 / 南方电网广西 / 广投集团 等)

**起薪反差**:
- **留南宁**:工科 4-6k,文科 / 经管 4-5k,公务员 5-7k(含津贴)
- **出粤广州 / 深圳**:工科 8-15k,计算机 12-20k,**比留桂高 2-3 倍**
- **东盟方向(跨境工程 / 边贸)**:8-15k(出差多但补贴高)

**留桂工资低 vs 出省高的反差** = 西大学生最大的"价值认知矛盾",**家长普遍低估"出粤性价比"**。

## 同档对比

| 维度 | 西大 | 桂电 | 广医大 | 出区中山 / 华工 |
|---|---|---|---|---|
| 牌子 | **211 + 双一流** | 双非 | 双非 | **985** |
| 综合性 | **强(广西第一)** | 工科为主 | 医学单一 | 985 综合 |
| 留桂认可度 | **顶配** | 强(工科) | 强(医学) | 一般 |
| 大湾区认可度 | 中 | **强(电子)** | 中 | **顶配** |
| 录取分(广西) | **本省最高** | 中高 | 高(医学组) | **极高** |

**简单结论**:**留广西要 211 牌子 + 综合性 → 西大**;**出粤进 IT/电子 → 桂电**;**学医留桂 → 广医大**;**分够出区 985 → 优先出区**。

## 适合谁

- 广西物理类 **省排 6,500-18,000 名** / 历史类 **1,200-4,500 名** 的考生。
- **留广西 + 想要 211 牌子 + 综合性发展** 的考生(无替代)。
- **想进央企土木 / 中字头央企广西分公司** 的男生(西大土木 + 中字头是经典路径)。
- **想留桂考公考编 / 进区直机关** 的考生(西大法学 / 行政管理 / 经管 是性价比之王)。
- **农村壮族 / 瑶族 / 苗族 考生 + 国家专项 / 民族班** 政策可用 → 西大是最佳承接校。

## 不适合谁

- **分够华南理工 / 中山 / 武大 / 华科 等出粤 985** → 优先出区,西大牌子在出区竞争中弱于一般 985。
- **明确想做 IT / 电子 / 通信 + 出粤就业** → 桂电更对口大湾区。
- **明确想当医生** → 广医大临床比西大医学相关专业更对口。
- **明确想做东盟语种 / 跨境贸易** → 广民大东盟语全国第 1。
- **想读纯文科 / 经管 + 出区一线** → 西大文科出区竞争力一般,选出区央财 / 上财 / 中山管院 更值。

## 大小年趋势 + 录取波动(广西本省视角)

- **2021 老高考末届**:理科一本线波动正常,西大主流组录取分稳定;**部分医学预科组录取分被忽视(因为新生武鸣校区距南宁市区 30 分钟,有学生不愿去)**
- **2022-2023 老高考冲刺届**:**临床预科组分数走高**(疫情后医学热),**部分文科冷门组(哲学/历史/边缘文)录取分下降**(这些组适合捡漏 + 后转专业)
- **2024 新高考首届(广西 3+1+2)**:**物理类 +化学/生物 组 是医学/化工/生命相关唯一通道,导致这类组录取分相对走高**;**纯物理 + 政治/地理 组适合考公/法学方向,录取分稳**;**历史类竞争比预期激烈**(广西文科大省传统,历史类位次相对集中)
- **大小年规律**:西大主流组**几乎没有"大年"**(广西本省考生选择有限),冷门组(农林/哲学)有小年捡漏机会
- **关键提醒**:**广西考生不要把外省 985 大小年规律套到西大**(西大主要是本省生源,波动小)

## 转专业 / 大类招生政策

- 西大大一末转专业**有名额但门槛高**(GPA 前 10% + 笔试 + 面试),**热门专业(临床预科 / 计算机 / 法学)转入难,转出容易**
- **大类招生**:经管类 / 工科大类 / 农林大类 等大类入学,大二分流;**大类内分流主要看 GPA + 志愿,不一定能进想要的方向**
- **建议**:**填志愿时直接报心仪专业,不要赌"转专业"路径**(广西 211 转专业难度比 985 高,因为西大本身整体竞争已经激烈)
- **少数民族班 + 预科班**:预科 1 年 + 本科 4 年,**预科期间补习数学 / 英语 / 物理等弱势科目,顺利升本**;**民族班和普通生混班教学,只是录取通道不同**

- **少数民族比例**:**约 35-40%**(壮/瑶/苗/侗/仫佬/毛南/京 等),**民族文化氛围在 211 里独特**
- **校园文化**:**山水校园(校园内有西山 + 君武湖)**,**农林氛围浓**(双一流学科里农林占 2 个),**南宁夏天热 + 雨水多**,**饮食以广西米粉 + 螺蛳粉 + 粤式 + 桂菜为主**

## 留桂校友网络 + 行业人脉

- **西大校友占据广西区直机关 + 各市机关 + 公检法 + 央企广西分公司 + 区属国企(广投/北部湾港/广西交投) 中高层**
- **校友会在南宁/柳州/桂林/玉林/北海 等地都有活跃组织**,**校招内推 + 同事推荐路径稳**
- **跟出省 985 校友比**:**广西本地校友密度西大 > 任何 985**(西大每年广西本省毕业 6000+,985 在广西本地工作的校友每年只有几百)
- **关键认知**:**留桂工作的话,西大校友网比 985 牌子更管用**(地缘+网络效应);**出粤工作的话,985 牌子 > 西大校友网**

- **保研率**:整体 ~10-12%(中游 211 档),**双一流学科(土木/动科/作物)保研到本校 + 985 比例较高**
- **考研友好方向**:
  - **土木工程 → 武大/同济/河海/重庆大学** 接受度高
  - **动物科学 → 华农/南农/西农** 接受度高(广西农林毕业到这几所是经典路径)
  - **法学 → 武大/中南财法/华政/西政** 接受度高
  - **经管 → 厦大/中大/中南财法/暨大** 接受度高(适合留桂出粤兼顾)
- **出国路径**:

## 易错认知(agent 要纠正用户的)

- "**西大是 211,跟武大华科一档**" — 错。**西大全国 211 排名靠后,跟武大华科(985)差 2 个档**;**留桂西大顶配,出区西大牌子普通**
- "**西大什么专业都能选,因为是综合 211**" — 错。**西大双一流学科是土木 / 动科 / 作物,这三个是真强;法学/经管/汉语言是区内顶配但全国普通;边缘文科/工科是凑数**;**选错专业 = 浪费西大 211 牌子**
- "**西大医学跟广医大医学一样**" — 严重错误。**西大没有独立医学院**(只有部分医学相关专业),**广西医学顶配是广医大**,**学医坚定选广医大**
- "**民族班 / 预科班学生水**" — 错。**预科是补习一年再读本科,毕业证一样**;**民族班和普通班混班教学,只是录取通道不同**;**农村少数民族家庭善用民族班 = 最大降分杠杆**(可降 30-50 分)
- "**广西考生不需要选西大,出区 985 都比西大强**" — 半对。**分够 985 出区当然好**(华南理工/中山/武大等),**够不上 985 + 想留桂 + 想要 211 牌子 → 西大无替代**
- "**西大本部跟行健文理学院一样**" — 严重错误。**西大本部是 211 公办**,**行健文理学院是独立学院 / 民办(已转设过程中)**,**学费贵 + 牌子差**,**报志愿一定看清代码**
- "**留南宁工作 = 选西大 = 起薪低**" — 半对。留南宁工资确实低(4-7k),但**西大 + 央企广西分公司(中铁/中建/南网/广投)起薪 7-10k + 编制**,**比双非留南宁高 2k**;**追求高薪本就不该留南宁**

## 关键提醒(总结)

**西大是广西考生绕不开的选择题**:
- **分够 985(华南理工/中山/武大/华科 等出粤/出省)** → **优先出区**(西大牌子在出区竞争中弱于一般 985)
- **分不够 985 + 想留桂 / 要 211 / 想综合性** → **西大无替代**(广西唯一 211 + 双一流)
- **农村少数民族 + 国家专项 / 民族班 / 预科** → **西大是最大受益面**(可降 30-50 分进 211)
- **明确想做工科电子 / 大湾区 IT** → **桂电 > 西大 CS**(对口校优势)
- **明确想当医生** → **广医大 > 西大医学**(医学单一校)
- **明确想做东盟语种 / 跨境贸易** → **广民大 > 西大语种**(东盟语全国第 1)

**广西普通家庭最被低估的西大路径**:**国家专项/民族班 + 西大土木双一流 + 中铁/中建广西分公司 = 农村壮/瑶/苗/侗 跨阶级最稳路径**,没有之一。
