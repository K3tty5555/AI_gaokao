# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(广西版)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**广西普通工薪和中产家庭的最优解可能完全相反**。

广西特殊性:**少数民族家庭比例 > 38%(壮/瑶/苗/侗/仫佬/毛南 等)+ 农村家庭比例高 + 边境县乡多 + 留桂偏好强 + 出粤心理近(高铁 2-3h)**。这导致广西的家庭决策矩阵跟内陆省份(湖北/河南/湖南)有显著差异。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入 + L2.3 民族),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在广西区直机关 / 各市机关 / 公检法 / 教育系统 / 医疗系统 / 区属国企(广投集团 / 北部湾港集团 / 广西交通投资 等)有稳定编制。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低,广西公务员工资比沿海低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易、**广西区直机关 / 公检法系统人脉**

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(广西区考对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化);广西选调主要走西大 + 出区 985(中山/华工/武大等)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校(广西警察学院)+ 公安联考 = 父母编制资源能用上;边境定向公务员(凭祥/东兴/那坡)+ 父母在区内体制 = 有人情资源

**典型 case**:
- 南宁某中产体制内家庭(父亲广西区委办,母亲银行)→ 孩子 605 分历史类 → 推**广西大学法学** → 毕业选调进广西区委组织部,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去桂电 CS → 毕业出粤进华为 25w 起薪很高,但家长不满"不稳定 + 离家远",劝其离职考公,**两年的时间损耗 + 心理纠结**
- 柳州某体制内家庭(父亲柳州市政府)→ 孩子 580 分物理类 → 推**广西警察学院 + 公安联考** → 直接进柳州市公安局,**父亲资源直接复用**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域(广医大附属医院医生、广西师大教师、柳工/玉柴工程师、南宁律师等)。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(广西师大);医生家庭 → 临床 / 口腔(广医大,8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → 法学(西大法学);柳工/玉柴工程师家庭 → 对应工科(机械/汽车,广西科大或西大);电网工程师家庭 → 电气(西大/桂电)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难,广西金融行业本就弱)

**典型 case**:
- 母亲广西师大附属外国语学校语文老师 + 父亲普通工薪 → 孩子 605 分历史类 → **公费师范生汉语言**(广西师大)→ 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是广医大附一院医生 → 孩子 650 分物理类 → **广医大临床 5+3 一体化** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径,留桂三甲**
- 父亲柳工集团总工程师 → 孩子 580 分物理类 → 推**西大机械工程** → 毕业进柳工 / 玉柴(父亲推荐),**子承父业 + 留柳路径**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主(广西本地民营经济相对弱,主要在南宁/柳州/玉林,典型如玉柴民营配套商、柳州五菱配套商、北海珍珠养殖户、玉林中医药材商、横州茉莉花茶商 等)。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **广西特色**:私企主家庭比例比沿海低,但**外贸/边贸/中越商贸 创业家庭独特**(凭祥水果商 / 东兴海产商 / 防城港集装箱物流商)

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(广西本地中外合作办学少,可考虑出区或出国)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **广西特色:东盟语种 + 跨境贸易**:**广西民族大学东盟语种(越南语/泰语/老挝语/柬埔寨语)** 是广西区位优势,创业家庭学这个=区位+家业+语种 三料齐全
6. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 凭祥某外贸商家庭(中越水果跨境贸易,年入 200w+) → 孩子 580 分物理类 → 推**广西民族大学越南语 / 国际经济与贸易**(双语方向) → 毕业接手家族跨境贸易 + 自己开扩大路径
- 玉林某中医药材商家庭 → 孩子 600 分物理类 → 推**广西中医药大学中药学 / 中医** → 毕业回玉林做药材产业升级
- 失败 case:玉林某私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(广西工资水平比湖北略低)。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **广西特色**:柳州工业带工人家庭(柳工/上汽通用五菱/玉柴 子弟)+ 南宁服务业家庭 + 玉林家具厂家庭 + 北海旅游业家庭 等

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - 公费师范生(广西师大)= 高考分适中 + 直接编制 + 无学费
   - 警校(广西警察学院)+ 公安联考 = 进警察系统编制
   - 医学技术(医学影像 / 检验)= 三甲医院技术岗 + 4 年本科即可
   - 农村订单定向医学生(广医大/桂林医学院/右江)= 学费全免 + 县乡医院编制
   - 边境定向公务员 = 边境县乡 + 艰苦补贴 + 三年回原市
3. **次推稳定就业型**:
   - 电气工程进南方电网广西公司(西大/桂电/桂林理工 性价比之选)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(留南宁起薪 5-7k 封顶,跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 柳州工人家庭(父亲柳工厂工人) → 孩子 580 分物理类 → 推**桂电电气**(南网广西本科主供给)→ 毕业进南网广西柳州公司,**月入 8k + 编制,家庭逆袭**
- 玉林服务业家庭 → 孩子 540 分历史类 → 推**玉林师院汉语言文学**(双非但考公王者)→ 毕业当年考上玉林市直机关,**家庭命运改变**
- 北海旅游业家庭 → 孩子 560 分物理类 → 推**广西医科大学医学影像技术**(4 年本科)→ 毕业进北海市人民医院技师岗,**编制 + 月薪 6-8k**
- 南宁普通工薪家庭 → 孩子 590 分物理类 → 推**桂电 CS + 大三出粤实习** → 毕业进比亚迪深圳,**起薪 22w,家庭逆袭出粤**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **广西特色**:**农村壮族 / 瑶族 / 苗族 / 侗族 比例极高**,**民族优惠 + 国家专项 + 民族班 是这一档的最大杠杆**;**桂西/桂西北山区(百色/河池/崇左)/ 中越边境县(凭祥/东兴/那坡)** 农村家庭尤其需要善用政策

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - 公费师范生(无学费 + 编制)= 农村家庭神器
   - **国家专项计划 / 高校专项计划 = 广西农村专属优惠**(西大/广西师大 等区内 + 出区 985 名校多个专项指标,分数比统招低 30-50 分)
   - **民族班 / 预科班** = 壮/瑶/苗/侗/仫佬/毛南 等少数民族专属(西大/广师大/广民大 重点招收)
   - 警校 / 军校(无学费 + 编制 + 包分配)
   - **农村订单定向医学生** = 学费全免 + 县乡医院编制
   - **免费师范生 + 民族优惠** 叠加 = 几乎零成本编制路径
3. **避免长周期投入**:
   - 医学 8 年(撑不起,但**免费医学生 / 定向培养 例外**)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:广西 50+ 个国家专项贫困县考生,985/211 名校多个专项指标(分数比统招低 30 分起)
   - **民族班 / 预科班**:广西大学 / 广西师大 / 广西民大 / 广西医大 都有民族班专项
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会冲西大 / 出区 985
   - **边境定向公务员**:凭祥/东兴/那坡/靖西 等边境县乡定向培养,农村壮族/瑶族 加分

**典型 case**:
- 百色右江区壮族农村家庭 → 孩子 590 分物理类 → 通过**国家专项 + 民族班** 进**广西大学土木工程**(双一流,比统招分低 35 分)→ 211 牌子 + 中铁广西/中建广西 央企编制路径,**整个家族第一个 211**
- 河池都安瑶族山村家庭 → 孩子 555 分历史类 → 推**广西师大公费师范汉语言**(免学费)→ 4 年无学费 + 毕业回原县编制,**最适合农村家庭的"零风险"路径**
- 崇左凭祥(中越边境)农村家庭 → 孩子 530 分历史类 → 推**广西民族大学行政管理 + 民族班 + 边境定向** → 毕业回凭祥做边境公务员(基础工资 + 边境艰苦补贴 + 民族补贴 = 6-8k),**比留南宁普通公务员还多 1-2k**
- 河池巴马农村家庭(壮族)→ 孩子 510 分物理类 → 推**右江民族医学院 农村订单定向医学生(免费医学生)**(学费全免 + 生活补贴 + 毕业回河池/百色县乡医院 6 年)→ **几乎零成本进医疗编制**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 + 民族**(L2)→ **本文件主导**,锁定推荐策略大方向(广西要额外问民族,因为民族优惠是普通家庭的最大杠杆)
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 广西特色 — 民族 + 户籍政策杠杆

广西普通家庭做志愿决策最该重视的杠杆:

### 民族优惠加分(2024 政策)
- **少数民族考生(壮/瑶/苗/侗/仫佬/毛南/京 等)**:总分加 5-20 分(具体看县乡)
- **农村少数民族**:加分更多
- **边境少数民族**:边境县乡考生加分政策叠加

### 国家专项 / 高校专项 / 地方专项
- 广西 50+ 个国家专项贫困县考生 → 985/211 院校专项录取(分数比统招低 30 分起)
- 广西区内高校专项 → 西大 / 广师大 等区内重点校面向农村考生降分

### 民族班 / 预科班
- 广西大学 / 广西师大 / 广西民大 / 广医大 等都有民族班 / 预科班
- 预科 1 年 + 本科 4 年,**预科期间补习** + 顺利升本

### 边境县乡定向
- 凭祥 / 东兴 / 那坡 / 靖西 / 大新 / 龙州 等边境县乡
- **公务员 + 教师 + 医生 定向培养**,**农村家庭返乡稳路径**

**农村壮族 / 瑶族 / 苗族家庭如果不善用这些政策,等于把最大的优势浪费**。**广西普通家庭决策的核心动作之一就是把民族 + 户籍 + 边境 政策叠加最大化**。
