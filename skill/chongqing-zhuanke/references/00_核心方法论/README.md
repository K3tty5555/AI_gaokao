# 重庆专科 skill 核心方法论

## 1. 重庆专科填报的三大独特红利(必须吃透)

### 红利 A:产业链直通车
重庆有 **3 条全国级产业链** 可以让专科生直接对接:
- **汽车**:长安 / 福特 / 赛力斯(华为问界)/ 上汽红岩 / 庆铃 + 1000+ 零部件厂
- **笔电 / 电子**:惠普 / 富士康 / 广达 / 仁宝 + SK 海力士 / 京东方
- **轨道交通**:重庆轨道集团(西南最大城轨)+ 中铁成都局

→ 这些产业的**专科技术工人需求是真实的、长期的、且有清晰校招渠道的**。
→ 推荐时**优先匹配产业 → 学校 → 专业**,而不是"哪个学校分数线高报哪个"。

### 红利 B:直辖市编制密度
重庆 38 个区县 + 中央直管,**编制总量大但考生总量不算大**(~30 万),意味着:
- 主城三甲医院 / 主城公立园编制 = 卷,但可考
- **区县医院 / 乡镇公立园 / 区县公务员**编制 = 真正的红利,**渝东北 / 渝东南考生回老家有真实优势**
- 西部大开发 + 边远艰苦补贴对部分区县岗位倾斜

### 红利 C:留渝接受度高
- 生活成本低 + 火锅文化 + 山城烟火气 = 重庆人不抗拒留本地
- 这跟"专科本来就该扎根本省"的逻辑天然契合
- **不像一线城市那种"专科被本科卷死、毕业被户籍逼走"的处境**

## 2. 推理顺序(给 agent 在对话中用)

### Step 1: 锁定意愿强度
- **专升本强度 1-5**——这是分流的第一道闸门
- 强度 5 → 学校优先(公办 + 升学路径) > 专业次之
- 强度 1 → 专业优先(产业对口 + 校招) > 学校次之

### Step 2: 锁定户籍 / 地理
- **主城**:主城公办 第一梯队
- **渝东北**(万州 / 云阳 / 奉节 等):**重庆三峡医高专 / 重庆幼专(万州) / 重庆三峡职业** + 主城公办 双路径
- **渝东南**(黔江 / 秀山 / 酉阳 等):黔江民族职教 + 主城公办 双路径
- **渝西**(永川 / 璧山 等):主城 / 江津 / 永川 公办均可

### Step 3: 锁定行业偏好
照"产业 → 学校"对应表:
| 想进 | 优先学校 |
|---|---|
| 汽车产业链(长安 / 赛力斯) | **重工职 / 重电职(汽车电子方向)** |
| 笔电 / 电子 / 半导体 | **重电职** |
| 轨道交通(重庆轨道) | **重庆公共运输职业学院 / 重水电职** |
| 国铁(中铁成都局) | 重公运职 / 跨省铁院 |
| 医院 / 护理 | **重庆医高专 / 重庆三峡医高专(渝东北)** |
| 学前教育 | **重庆幼专 / 重庆第二师范** |
| 民政 / 养老 / 社区 | **重庆城市管理职业学院** |
| 国网 / 水利 / 能源 | **重水电职 / 重庆工程职业** |
| 煤矿 / 工程 / 建筑央企 | **重庆工程职业 / 重庆建筑工程** |

### Step 4: 排除民办避坑
- 民办专科学费 1.5-2.5 万 / 年(公办 5-8 千)= 3 年差 3-5 万
- 民办的"高大上文科专业"(国贸 / 工商管理 / 行政管理)= 专科最坑
- 例外:**重庆机电职业技术大学**(本科职业大学新形态)可纳入考虑

## 4. 风格约束

- **大白话**:不绕弯,不堆术语
- **case-specific**:举重庆本地的 case(渝东北农村 / 主城工薪 / 涪陵 / 江津 等)
- **本省视角**:不套湖北的"武汉七校 / 三峡大学 / 湖北电网"——用重庆的"长安 / 赛力斯 / 重庆轨道 / 重邮"
- **不编数字**:招生人数 / 录取率不确定的,**说"约""大致""近年"**,不拍胸脯保证
- **承认劣势**:重庆本科院校少 → 专升本接收名额紧;笔电产能近年部分外迁 → 普工岗有不确定性。**实事求是**
