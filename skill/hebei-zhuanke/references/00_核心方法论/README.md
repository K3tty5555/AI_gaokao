# 河北专科 skill 核心方法论

## 一、河北专科的独有视角(agent 必须吃透)

### 1. 京津冀地理近 = 出口完全不一样

**河北专科生的就业地理图**:
- **本省**(石家庄 / 保定 / 唐山 / 廊坊):60% 的常规出口
- **京津**(北京基层岗 / 天津滨海 / 燕郊通勤):**30% 的隐藏红利**(其他内陆省专科生很难复制)
- **跨省**(长三角 / 珠三角):10%(主要是计算机 / 跨境电商)

**实操含义**:agent 推荐时不能套湖南 / 河南"出省"的逻辑 — 河北专科生的"出省"主要是出到**京津**,而京津给河北专科生的出口比给河南 / 安徽专科生的多得多。

### 2. 雄安新区是河北独有政策红利

雄安建设 2017 年启动,2024 年已进入大规模建设阶段。**带动**:
- 建工 / 测绘 / 建筑机电 类专科岗位激增
- 城轨 / 京雄城际 类专科岗位
- 医疗 / 教育 配套岗位

**实操含义**:推荐保定 / 廊坊 / 沧州 的考生时,**可以提雄安建设的隐藏出口**(其他省 agent 不会想到)。

### 3. 河北叫"专接本"不叫"专升本"

**本地词差异**:
- 全国通用:专升本
- 河北 / 河南 / 江苏部分:专接本
- 广东:专插本

**实操含义**:agent 输出文案要用"专接本",但**内部知道两个词等价**。如果用户问"湖北专升本规则跟河北一样吗?",agent 要解释**叫法不同但本质相同**,只是接收院校 / 报名平台不同。

### 4. 河北产业禀赋 = 钢铁 / 电力 / 化工 / 汽车

跟湖南(中南/工程机械) / 湖北(华科/汽车光电) 完全不同。河北专科的"对口产业"是:
- **钢铁**:唐山 / 邯郸(全国 ~15% 钢铁产量)
- **电力**:国网河北 / 风电(承德 / 张家口)
- **化工**:沧州渤海新区 / 石家庄医药化工
- **汽车 / 装备**:保定长城汽车 / 中车唐山(高铁制造)

**实操含义**:推荐的对口专科不能是"湖南那套"或"全国通用那套",必须**贴河北产业**。

## 二、推荐输出的方法论

### 2.1 优先级:专业 > 院校 > 地理

专科决策的核心是**专业**(就业出口决定一辈子),**而不是院校牌子**。

agent 输出时:
- 第一句应该是**"建议学 XX 专业,因为 XX 行业出口好"**
- 第二句才是**"对口院校是 XX,在 XX 城市"**
- 第三句是地理 / 家庭因素调整

### 2.2 必谈三件事

1. **是否专接本**(强度 1-5)— 决定 3 年学习节奏
2. **想留河北 / 出京津 / 出省**(默认河北或京津)— 决定院校地理
3. **接受体力 / 三班倒 / 户外吗**(传统专科出口很多有体力要求)— 影响专业方向

### 2.3 必避三个坑

1. **不要推荐专科里"听起来高大上"的水专业**(国贸 / 工商管理 / 行政管理 / 文秘 / 市场营销)
2. **不要把民办捧得跟公办平起平坐**(学费 + 就业差距巨大)
3. **不要承诺"一定能录取 / 一定能进 XX 央企"**(都是要绩点 + 证书 + 实习)

## 四、与主 skill (hebei-zhiyuan) 的关系

- **主 skill** 处理本科批考生(物理类约 440+ / 历史类约 450+)
- **本 skill** 处理专科批考生(本科线下 + 专科线上)
- 主 skill 的 `score_to_rank.py` 检测到考生分数处于"between_undergrad_and_vocational" 时,**主动建议切换到本 skill**
- 用户主动说"我考了 X 分要报专科" / "孩子分数不够本科了"等关键词,直接触发本 skill

数据可复用主 skill 的 `data/gaokao_hebei_<YYYY>.db`(若已爬本科 + 专科数据)+ `query_school.py`。

## 五、安全 / 边界

- **不承诺"一定能录取"**
- **不诋毁专科教育**(专科生不是失败者,是另一条路径)
- **政策每年变**,涉及专接本具体规则的,建议用户查河北省教育考试院最新文件
- **不推荐第三方培训机构 / 补习班**
- 推荐方案末尾必须加免责声明
