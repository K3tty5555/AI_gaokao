# 考公优选专业表(河南本地视角)

## 核心结论

**专业决定考公选岗范围**。河南家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**河南考公的特殊性**:
- **考公人数全国前 3**(每年河南省考报名 100w+,国考河南考点 10w+)
- **省考竞争极卷**(基层岗位 100:1 起步,冷门岗位 30-50:1)
- **选调走 985 + 河南本地校**(郑大 / 河大 / 出豫 985 河南籍学生 是主力)
- **岗位多但门槛高**(地市基层岗位多,但中央 / 省级岗位向 985 倾斜)
- **学历门槛逐年提高**(2024 年河南省考省直机关岗位 70%+ 要求硕士)

## 关键事实(2024 国考 / 河南省考分析)

### 国考可报岗位数 排名(Top 10 大类)

1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 河南省考特殊性

- **河南省考 + 各地市公务员**,**汉语言文学和法学并列考公第一专业**
- **河南各地市公务员岗位对法学要求高**(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学、财经类**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1500+ 比 1,**河南三不限岗位是全国最卷的**)
- **河南公检法系统对中南财法 / 西政 / 华政 / 西北政法 / 郑大法学 认可度高**

### 选调生(不是普通公务员,是高潜力路径)

- **河南选调生 = 党政机关后备干部储备**,**起点比普通公务员高**
- **985/211 才有资格报**(河南本地的选调生定向计划基本只对 985/211 + 郑大 + 河大 + 教育部直属六大师范)
- **优势专业**:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **选调生主要面向河南籍** —— **出豫读 985 / 211 的河南籍学生 4 年后回豫考选调** 是高潜力路径

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、河南警察学院、铁道警察学院 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**中央司法警官学院在河南郑州,是河南家长经常忽视的隐藏优选** —— 司法部直属 + 公安联考路径(实际是司法警察联考)+ 编制保障

## 河南本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业(省内 / 出豫)

- **郑州大学法学** — **河南本地考公认可度顶配**,**省内法检院招聘主力**
- **郑州大学汉语言文学** — 985 牌子 + 河南选调生主供给
- **中南财经政法大学法学 / 经济学 / 会计学** — 211 双一流,**河南考公认可度极高**(中南财法是河南考生出豫考公第一选择之一)
- **西南政法大学 / 中国政法大学 / 华东政法大学 / 西北政法大学 法学** — 政法五院四系,**法考通过率高,河南选调路径最优**
- **河南师范大学公费师范汉语言文学**(等同于教师编制)— 不是考公但是教师编制,**等同于考公友好**
- **教育部直属六大师范公费师范汉语言**(华师 / 北师 / 陕师 / 西南大学 / 华东师大 / 东北师大)— 出豫读完回河南教师编

### 双非 + 性价比考公专业

- **河南大学法学 / 汉语言文学** — **双一流学校 + 文科底子**,**留豫考公第二梯队**
- **河南财经政法大学法学 / 会计学 / 财政学** — 河南本地财政税务系统认可度高
- **郑州航空工业管理学院汉语言** — 双非但分数低,**省考公主力跳板**
- **信阳师院 / 商丘师院 / 周口师院 公费师范汉语言** — **农村家庭考教师编主力**(分数低 + 编制保障)

### 公安系统专属

- **中国人民公安大学** — 全国公安系统顶配,**河南家长应该重点了解**(2024 年河南考生约录 30-40 人)
- **中国刑事警察学院**(沈阳)— 公安部直属,**侦查 / 刑技方向**
- **铁道警察学院**(郑州)— **公安部直属 + 在郑州**,**河南本地考公安铁路系统神级路径**(隶属铁路公安系统,毕业进各级铁路公安局)
- **河南警察学院** — 河南警察主力来源校,**公安联考路径,毕业进河南本地基层公安概率极高**
- **中央司法警官学院**(保定)— 司法部直属,**毕业进监狱 / 戒毒所系统编制**

## 典型 case(供 agent 引用)

### Case A(逆袭路径):河南周口考生,540 分文史类,普通农村家庭
- 家长本想报"国际经济与贸易"(听起来高大上)
- **改报河南大学法学** 或 **信阳师院公费师范汉语言**
- 法学路径:毕业当年考上河南省直某机关公务员 / 周口市检察院,**家庭命运改变**
- 公费师范路径:回周口本地县中学做语文老师,**编制 + 稳定**

### Case B(选调路径):河南郑州考生,650 分文史类,中产家庭
- 家长想报"金融"(郑大经济学院或出豫财大)
- **改报武大法学** 或 **中南财法法学**(同分够)
- **毕业获得武大 / 中南财法选调生资格,直接进河南省委组织部 / 省直机关**,起点远超经济学就业

### Case C(失败路径):河南南阳考生,580 分理科,普通家庭男生
- 家长想"考公兜底"
- **报了河南师大计算机**(以为计算机考公也行)
- **毕业考公发现:可报岗位远少于汉语言**,2 年没考上
- 改行当程序员但因学校层次不够薪资也低,两头不靠

### Case D(误区路径):河南家长以为"行政管理"是考公专业
- **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**
- **本科水分大,考研也卷** —— 河南家长头号误区之一

### Case E(隐藏神级路径):河南安阳考生,580 分物理类
- 家长不知道**铁道警察学院 / 中央司法警官学院**
- **改报铁道警察学院侦查学**(郑州本地,公安部直属,公安联考)
- 毕业进**郑州铁路公安局**,**编制 + 月入 7-8k + 父母在郑州有面子**
- **铁道警察学院在郑州 + 毕业稳定进铁路公安系统 = 河南家长被严重低估的考公路径**

### Case F(公费师范胜过考公):河南信阳农村家庭,560 分历史类女生
- 家长想让她"考公兜底",**改报信阳师院公费师范汉语言**
- 毕业直接定岗信阳本地县中学,**比考公还稳**(公费师范 = 100% 编制,公考 = 30-100:1 概率)

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(河南 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是河南家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**铁道警察学院就是个二本警察学校**" — 严重错误。**铁道警察学院是公安部直属本科院校(在郑州),公安联考路径,毕业稳定进铁路公安系统**
- "**中央司法警官学院冷门**" — 错。**司法部直属 + 公安联考(司法警察)+ 100% 编制**,**农村家庭男生隐藏神级路径**

## 关键提醒(河南视角)

**考公是河南普通 / 农村家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。

**河南家长应该知道的 5 个考公真相**:
1. **汉语言文学是河南考公王者** —— 比法学、计算机、会计都好,可报岗位最多
2. **公费师范 = 比考公更稳的"教师编"** —— 100% 编制,无须考试上岸
3. **铁道警察学院 / 中央司法警官学院 / 中国人民公安大学** —— 河南家长经常忽视的"公安系统编制路径"
4. **选调生比国考省考更优** —— 但要 985/211 才有资格,出豫读名校 4 年后回豫考选调是高潜力路径
5. **省内 985/211 + 强势考公专业 > 出豫 985 + 弱专业** —— 郑大法学 / 中南财法法学 在河南省考认可度顶配
