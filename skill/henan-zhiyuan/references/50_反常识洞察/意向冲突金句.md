# 用户意向冲突 — Reality Check 金句库(河南视角)

很多家长 / 考生有具体的意向("想上郑大"、"非郑州不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **河南普通 / 农村家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **河南考生:出豫战略要敢推** — 河南家长情感上想留省内,但同分外省 985 / 211 平台明显好,**要敢直说"留省内是情感选择,不是最优选择"**

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 500 分要清华 / 600 分要郑大顶级组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(河南 595 分物理类,意向郑大)**:
> "郑大物理类主流组在河南 12000-22000 名段。你 25000 名,差 3000-13000 名,**郑大主流组没戏**。
>
> 但你能上**华水水利水电组(双非但水利全国前列)+ 河农作物组(双一流学科)+ 郑州轻工业大学(食品 / 烟草加持)**。这三个留豫就业,**国企对口招聘 + 中烟河南 / 牧原 / 双汇 / 中信重工 等大型企业认可度,跟郑大冷门组(国贸 / 工商管理)校友地位差不多**。"

**真实案例(河南 615 分理科 老高考,意向 211 头部)**:
> "你 615 分,全省理科约 12000 名段。**211 头部如哈工大 / 北航 / 西交 / 中山 等,全国位次都要 5000-8000 段** —— 差距明显。
>
> 但同档能上 **东北大学(老牌 985 + 性价比段)/ 兰州大学(985 + 国家专项加持)/ 大连理工(985 + 工科强)** —— 这些"末流 985 + 强势专业"出来,**回河南考公考编 / 国企招聘照样认 985 牌子,4 年平台白赚**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(河南理工科 + 普通家庭,意向郑大边缘)**:
> "郑大你 615 能擦 — 但只能进材料组 / 生物组(郑大双一流学科,但生化环材天坑)。**985 牌子 + 河南本省 + 生化环材** = 想读研读博才有出路,**普通家庭撑不起 4+3+3 长周期**。
>
> 同分能上的**华水水利水电(双非但水利全国前列,毕业进黄委会 / 国电水电)**出来对口程度更高,起薪不输郑大材料硕士。冲郑大材料留一个心理慰藉位即可。"

**真实案例(河南文科生 + 意向河大)**:
> "河大文科你 590 能上 — 但只能进哲学组 / 历史组冷门方向。**留豫 + 双一流牌子 + 哲学历史**,毕业出路:考研 / 教师编 / 留开封文化系统 月薪 5-6k。
>
> 同分能上**河南师大公费师范汉语言文学(免学费 + 编制)**或**信阳师院公费师范汉语言**,出来直接编制定岗,**比河大哲学硕士还稳**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华临床 / 北医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(河南农村家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k**。河南农村父母还要供 8 年,**这是高风险陷阱**。
>
> 撑得起 → 推郑大医学院或国家专项冲华西 / 齐鲁医学,长期天花板高。
>
> 撑不起 → **推荐新乡医学院医学影像技术 / 医学检验技术(4 年本科直接进医院技师岗,起薪 6-8k,早 3 年挣钱)**,或者放弃医学走**华水电气进国网 / 河农烟草进中烟** —— 本科直接挣钱的赛道。"

**真实案例(河南信阳农村家庭 + 想学法律做大律师)**:
> "学法是 5 + 3 + 法考 + 律所摸爬滚打 5 年的路径,**前 8-10 年不挣钱 + 红圈所只要五院四系 + 北上广平台**。
>
> 你信阳老家不是法律高地,本科出来回老家做律师 = 县城婚姻继承案 月入 3-5k。
>
> 撑得起 → 出豫读西政 / 华政 + 北上广实习 + 法考 + 留京沪律所
>
> 撑不起 → **改报郑大法学 + 选调生** 或 **河南师大公费师范汉语言** —— **法律方向 + 体制内** 比律所稳得多,且符合河南家长'稳定 + 编制'期待。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非郑州不去" / "非河南不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留河南没意义,要去西工大),**要灵活退一步**。"

**真实案例(河南考生 + 强烈想留豫 + 600 分物理类)**:
> "你只留河南,这位次 18000 名,郑大主流组刚够擦边,但**只能进国贸 / 工商管理 / 公共管理 等冷门组**。
>
> **留豫最稳路径**:**华水水利水电组(双非但水利全国前列,黄委会对口)+ 河农作物 / 烟草组(双一流学科 + 中烟河南对口)+ 河南理工安全工程(应急管理部对口)** —— 这三所双非的强势专业 + 留郑州 / 留豫国企编制,**比郑大冷门组就业更稳**。
>
> 但!**如果你说'非要郑大 985 牌子'** —— 那只能进郑大冷门组,要做好读研补救专业的准备,8 年以后才能体现 985 价值。"

**真实案例(河南农村家庭 + 想出豫但父母担心)**:
> "你 580 分 + 农村户籍 + 国家专项资格 —— **完全可以冲国家专项进兰大 / 哈工大 / 大连理工 / 东北大学**(降 30-50 分录取),**985 牌子 + 国家专项是河南农村家庭最便宜的逆袭路径**。
>
> 父母担心的'孩子出豫不回来' —— 错觉。**985 毕业 4 年后回河南考公考编 / 进国企 / 进银行,分数 + 牌子双双碾压留豫的同班同学**。**出豫 4 年是平台投资,不是地理迁移**。"

**真实案例(河南郑州中产家庭 + 想留郑州)**:
> "你 615 分,留郑州可以保郑大或河大龙子湖校区。但**同分出豫能冲山大 / 吉大 / 大连理工**,4 年后回郑州考公 / 进河南国企照样认 985 牌子。
>
> 留郑大的好处:本地校友密度高 + 父母资源能用上(如果父母在体制内 / 国企)。
>
> 出豫的好处:平台高一档 + 4 年视野不一样 + 回豫照样吃 985 牌子红利。
>
> **如果父母在郑州体制内有资源** → 留郑大走选调路径最优
>
> **如果父母资源有限 + 你自己想跨阶级** → 出豫读老牌 985 是更优投资"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**(对河南考生通常是"出豫战略")

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 郑大 / 想学医 / 想留河南 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 河南考生 5 个最常见意向冲突 + 标准应对

### 冲突 1:"必须留河南 + 想冲 985 牌子" → **Reality Check**:留河南只有郑大 1 所 985,且郑大是末班车 985,同分出豫能上更强的 985

### 冲突 2:"想学 CS + 留河南 + 跨阶级" → **Reality Check**:河南没强势 CS 平台,留豫学 CS 等于浪费红利,改推**电气 / 水利 / 烟草** 或 **出豫读 CS**

### 冲突 3:"想学医 + 农村普通家庭 + 想稳定" → **Reality Check**:临床医学 8 年长周期 + 三甲门槛博士 = 农村家庭撑不起,改推**新乡医学院医学技术 / 护理**

### 冲突 4:"想做大律师 + 留省内" → **Reality Check**:大律师要北上广平台 + 红圈所 + 五院四系学历,**留豫做律师 = 县城婚姻继承案**,改推**郑大法学 + 选调** 或 **公费师范**

### 冲突 5:"女生 + 想冲名校 + 父母只让她去离家近的" → **Reality Check**:豫北 / 豫东农村女生家庭决策权弱,**agent 必须主动确认女生本人意愿,并把家长'离家近'诉求和'孩子未来'对比清楚**,不能盲从家长

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**对河南考生的特殊原则**:**留豫是情感选择,不是最优选择** —— 这句话要敢说出来。
