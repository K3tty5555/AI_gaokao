# 河南老高考政策与 3+1+2 过渡

## 核心结论

**河南是高考人口大省**(年报名 100w+,占全国 1/8,长期全国第一),但教育资源极其稀缺。**2024 年是河南最后一届老高考(文科/理科),2025 年起切到新高考 3+1+2(物理类/历史类)**。**2023 年入高一的考生,2026 年高考是河南第一届完整意义上的 3+1+2**(2025 届是过渡届,选科机制刚落地)。

## 河南考生基本盘(关键!)

### 1. 高考人口全国第一

- **2024 年河南高考报名 136 万人**(全国 1342 万,占比约 10%)
- **本科上线人数 ~50 万**,**一本上线人数 ~10 万,一本率约 7.4%(全国倒数)**
- 985 录取率 ~1.1%(全国平均 ~1.6%),211 录取率 ~3.7%(全国平均 ~5.5%)
- **同样位次,在河南的"含金量"远高于其他省**:河南理科 1 万名 ≈ 全国前 1 万 → 大概率 985 段;但在山东/江苏 1 万名只能上中游 211

### 2. 一本率 7%(全国倒数前三)

河南分数线居高不下的根本原因:
- **考生人数多**(分母大)
- **省内一本院校少**(郑大 + 河大 + 几所双一流学科建设高校 + 部分外省一本在豫名额)
- **一本招生名额绝对值不少,但相对河南考生总人数比例极低**

### 3. 省内 985/211 极度稀缺

- **985:1 所** —— 郑州大学(2017 年由 211 升级 985 进双一流,**末班车 985**,全国 985 排名靠后,类似宁波大学/海南大学)
- **211:2 所** —— 郑州大学 + 河南大学(河大 2017 年双一流学科建设高校,严格说不是传统 211,但常被并称为"河南双一流")
- **对比**:江苏 11 所 211 / 湖北 7 所 211 + 2 所 985 / 北京 26 所 211 / 上海 10 所 211
- **结论**:**河南考生想留省内读名校的路非常窄,大量考生被迫出省**

## 老高考(2024 届及以前)

### 考试结构

- **3 = 语文 + 数学 + 英语**(语文/英语用全国乙卷,数学用全国乙卷,各 150 分)
- **文综 / 理综**(各 300 分)
  - **文科**:政治 + 历史 + 地理(综合卷,分科目算分)
  - **理科**:物理 + 化学 + 生物(综合卷)
- **总分 = 750 分**

## 新高考 3+1+2(2025 届起)

### 实施时间表

- **2022 年秋季**(2022 届高一)入学开始按新高考要求选科
- **2025 年高考**:**首届 3+1+2 高考**(2022 届高一 → 2025 届高三)
  - 但 2025 届实际是过渡届,选科机制刚落地,数据稀缺
- **2026 年高考**:**第一届完整意义上的 3+1+2**(2023 届高一 → 2026 届高三)
  - **2023 入高一 → 2026 高考第一届完整 3+1+2**

### 考试结构(同湖北/江苏)

- **3 = 语文 + 数学 + 英语**(各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2025 起)

- **物理类**(类型代号 2073)— 选物理为首选
- **历史类**(类型代号 2074)— 选历史为首选
- 河南物理类约 65-70%,历史类约 30-35%(沿袭老高考文理比)

### 12 种选科组合

| 物理类 6 种 | 历史类 6 种 |
|---|---|
| 物化生 / 物化政 / 物化地 | 史化生 / 史化政 / 史化地 |
| 物生政 / 物生地 / 物政地 | 史生政 / 史生地 / 史政地 |

### 院校专业组规则

- **按"院校专业组"投档,服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **再选科目限制是硬约束**(必选化学的医学、必选政治的警校等)

### 河南本科批志愿数

**河南本科批 36 个志愿**(注意!**比湖北/湖南的 45 个少 9 个,比江苏的 40 个还少 4 个**)
- 数量比邻省更少,**填报时每个志愿都要更慎重**
- **服从调剂建议默认勾选**(否则一旦组内分数不够会直接滑档)

(注:具体志愿数以河南招办最终公布为准,以上为预估,2025 首届以官方文件为准)

## 河南考生选科建议(3+1+2 部分,2025 届起)

### 硬约束(专业限制)

| 想报方向 | 选科要求 |
|---|---|
| 临床医学 / 口腔 / 麻醉(顶级医学) | **必选物理 + 必选化学**(部分院校还要生物) |
| 中医学 / 中药学 | 物理 / 历史均可,但**化学 + 生物 加分** |
| 师范(各学科师范) | 选你想教的学科对应科目 |
| 警校 / 公安 | **必选政治** |
| 国防 / 军校 | 物化生 / 物化地 优先 |
| 地学 / 海洋 / 测绘 | **必选地理** |
| 法学 | 物理 / 历史均可,**首选历史 + 政治组合**对考公更友好 |
| 经济 / 金融 | 物理 / 历史均可,**首选物理对考研路径更宽** |
| 计算机 / 工科 | **必选物理**(几乎所有 985/211 工科) |

### 软建议(基于河南考生情况)

- **省内顶级层次(985/211 段)**:**首选物理 + 物化生 / 物化地**(选择面最宽,工科 + 医学 + 理科都能报)
- **省内中段(一本中下到二本)**:首选物理也优于历史(就业 + 考研都更宽)
- **历史类适合**:**明确想做老师 / 公务员 / 法律 / 文科类研究** 的考生,但**历史类招生名额比物理类少 60%**,要求位次更靠前

## 河南考生战略要点

### 1. **出省战略是河南考生的最佳路径**

- 同分情况下,**外省 985/211 平台 > 省内郑大/河大**
- 例:河南理科 1.5 万名,**省内只能保郑大**;**出省可冲山大、吉大、四川大学、东北大学、大连理工等老牌 985**
- **首选流向**(基于地理 + 文化 + 政策):
  - **山东**(山大/中海大/中石油华东,鲁豫接近)
  - **陕西**(西交大/西工大/西电/西农,西部 985 集群,招生名额相对友好)
  - **江苏**(南大/东南/苏大,长三角就业,但分数高)
  - **北京天津**(分数门槛高,但平台最高)
  - **湖北**(武大/华科,中部交通方便)

### 2. **国家专项 + 地方专项**

- 河南是国家专项重点省份,**农村户籍考生** 可申请专项,**降分录取顶级 985/211**
- **地方专项**留河南本省,但仅郑大、河大等省内一本招专项
- **农村普通家庭考生务必查清专项资格**

### 3. **考研大省**

- **河南考研报名人数全国前列**(郑大每年考研报名 4 万 +)
- 大量本科双非考生通过**考研逆袭** 到 985/211
- 推荐时若用户考研意愿 ≥ 4,**双非"性价比段"院校** 也可推(湘大式路径)

### 4. **考公考编主力省**

- **河南考公人数全国前列**,体制内吸引力极强
- **考公友好专业**:汉语言文学 / 法学 / 经济 / 会计 / 计算机 / 财政学 / 行政管理
- **公费师范生**:推荐河南本省师范(河南师大 / 信阳师院 / 商丘师院)+ 教育部直属六大师范

### 5. **避免错误认知**

- **❌ "河南分数线高,我家孩子分低"** —— 错。**看位次不看分数**,河南分数线高是因为人多 + 试卷难度,跨省看位次才公平
- **❌ "郑大跟其他 985 一样好"** —— 错。**郑大是末班车 985**,全国排名靠后,综合实力跟川大/吉大/山大有明显差距,**只是河南唯一 985**
- **❌ "省内 211 不如出省双非"** —— 错。**牌子还是有用的**,郑大/河大在河南本地考公考编 + 国企招聘有天然优势
- **❌ "读完郑大就一定留在河南"** —— 错。郑大学生读研出省 / 工作出省比例不低,**牌子是平台,不是地理绑定**
