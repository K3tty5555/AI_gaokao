# 采集 Rubric — 用户回答 → 标准档位 → 推荐倾向

## 核心原则

agent 在 L2-L5 提问时**必须用本文件里的离散选项 / 量表**,**禁止接受定性模糊回答**。
所有定性回答(还行/一般/差不多)必须追问到本文件的标准档位。

---

## 推荐排序权重(关键!)

**就业看的是学校牌子 + 城市平台 + 个人努力,专业是起点不是终点**。所以推荐时应按以下权重做最终排序:

| 排序权重 | 维度 | 决定什么 |
|---|---|---|
| **1(最高)** | **学校层次**(985 / 211 / 双一流学科 / 普通双非) | 校招平台门槛,**很多大公司只筛 985/211**,这是硬门槛 |
| **2** | **城市层级**(一线 / 新一线 / 省会 / 地级市) | 实习机会、人脉、跳槽空间、生活质量 |
| **3** | **专业方向**(对口 / 友好 / 坑) | 起点 + 课程内容,但**毕业后大量人转行**,不是终点 |
| **4(最低)** | **学科底子匹配**(挂科风险) | 仅做风险警示,**不做硬过滤** |

### 实战推论

- **双非 CS 在一线城市 > 双非 CS 在中西部省会**(就业差距来自城市,非专业)
- **985 工商管理在北京 > 211 工商管理在中西部**(平台差距覆盖了专业差距)
- **211 普通专业在长三角珠三角 > 985 弱专业在偏远地区**(这是为什么"东北/西北 985"对追求就业的考生不一定划算)
- **学校相同 + 城市相同 + 双非 + CS / 工商管理**:差距才主要来自专业(因为都进不了大厂筛选,本地小公司看简历看专业)

### 跟家庭背景的交互

**家庭决定能不能去大城市**(经济档位):
- 家庭 ① < 10 万 → 学费高 + 生活贵的一线/中外合作禁止;只能就近 / 国家专项
- 家庭 ⑤ > 200 万 → 完全无负担,城市 + 学校随选

**家庭决定要不要冒险**(职业档位):
- 体制内家庭 → 优先稳定,**专业权重提升**(选考公/国企友好的)
- 私企家庭 → 优先平台,**城市权重提升**(去就业市场大的地方)

## L1 学科强弱判断(从单科分数客观推算)

**输入**:语数英 + 首选(物/史)+ 再选 2 科 各科分数(满分:语数英 150,其他 100)

**计算规则**:把每科分数标准化到百分制,然后:
- 该科 ≥ 85 分对应原始分 → **强项**
- 65-84 → **中等**
- < 65 → **弱项**

| 科目 | 满分 | "强项" 阈值 | "弱项" 阈值 |
|---|---|---|---|
| 语 / 数 / 英 | 150 | ≥ 128 | < 98 |
| 物 / 史 / 化 / 生 / 政 / 地 | 100 | ≥ 85 | < 65 |

**学科组合判断**(供推理用):
- 数学+物理 都强 → 适合 CS / 电气 / 数学 / 物理 / 量化金融
- 数学强 + 物理弱 → 适合 经济 / 金融 / 会计 / 统计
- 物理强 + 数学中等 → 适合 工科类(机械/电气/材料)
- 化学强 → 医学 / 化工 / 材料(避坑)/ 制药 加分
- 生物强 → 医学加分(但生物本科本身坑)
- 政治+历史+地理 都强 → 文史考公友好
- 语文+英语 强 → 汉语言 / 外语 / 新闻 / 法学加分
- 各科平均偏低(均分 < 60%)→ **避免选基础学科**(数学物理化学等需要硬技术),侧重就业型应用专业

### ⚠️ 单科分数两档制：极端 = 硬降级，中等 = 软警示

**改进背景**:大学课程多数从基础重学 + 60 分及格制,**高中分数和大学课程只是弱相关**。但极端情况(物理 40 / 数学 80)仍有真实挂科风险。**实测踩坑**:把"软警示"当默认导致推荐了物理 40 分考生报电气，硬挂大学物理。

**两档规则**:

| 单科条件 | 档位 | 硬降级的专业大类 | 推荐时怎么说 |
|---|---|---|---|
| **首选物理 < 50 分(< 50%)** | 🔴 **硬降级** | CS / 软件 / 电气 / 自动化 / 机械 / 材料 / 土木 / 数学 / 物理 / 航空 / 电子 | "你物理 X 分，工科/CS 大学挂科率极高，**主推列表不放这类专业**；如你坚持，可选卡位给一张，自己权衡" |
| **数学 < 105 分(< 70%)** | 🔴 **硬降级** | 数学 / 物理学 / CS 算法岗 / 量化金融 / 统计学 | "你数学 X 分，高数/离散/概率论挂科率高，**主推不放纯理工路径**" |
| **首选物理 50-65 分** | 🟡 软警示 | 同硬降级大类 | "你物理 X 分，大学物理会比较吃力，**可选但要心理准备**，挂科风险高于平均" |
| **数学 105-128 分** | 🟡 软警示 | 同硬降级大类 | "你数学 X 分，高数会吃力，**有思想准备仍可选**" |
| **化学 < 50 分(50%)** | 🟡 软警示 | 化学 / 化工 / 材料 / 制药 / 临床医学 / 口腔 | "你化学 X 分，有机化学/分析化学**及格能过但要补底子**" |
| **生物 < 50 分(50%)** | 🟡 软警示 | 临床医学 / 生物科学 / 农学 / 兽医 / 食品 | "你生物 X 分，生理/生化/解剖**入门要多看书**" |
| **英语 < 90 分(60%)** | 🟡 软警示 | 外语类 / 国际经济贸易 / 中外合作 / 国际班 | "你英语 X 分，**外语类/全英文教学专业不建议**" |

**硬降级操作**:对应专业**不出现在 5 推 + 3 避坑主列表**。如果用户 L5 坚持，可以在末尾加一张"第 6 张可选卡"，并写明高风险。

**注意：硬降级 = 专业降级，不是行业降级**。物理 40 堵了 CS 专业，**不代表堵了 IT 行业** — 可以走"任意专业 → 产品经理/运营"曲线路径（见 L4.2 曲线救国表）。

**L4 主动排除 > 单科硬降级**:用户在 L4 勾选"绝对排除该方向" → 该大类完全不出现，包括可选卡位。

## L2.1 父母职业(5 选 1)→ 推荐倾向

| 档 | 职业大类 | 推荐倾向 | 原因 |
|---|---|---|---|
| ① | 体制内(公务员/事业编/国企) | **强烈考公友好型**:汉语言/法学/会计/经济;鼓励选调生路径 | 父母懂体制游戏规则,孩子考公几乎是默认期待,且家里能给资源 |
| ② | 教师/医生 等专业人员 | 师范 / 医学 友好(可能子承父业);**也可推考公** | 专业资源 + 行业人脉积累,孩子学这些有"拐杖" |
| ③ | 私企管理 / 自主创业 | **可冒险**:可选商科 / 创业相关;不必非选铁饭碗 | 家庭抗风险能力强,孩子不必走最稳路径 |
| ④ | 普通工薪(工厂/服务业/文员) | **重出路稳定**:电气/电网、师范公费、护理、考公 | 抗风险能力低,失败成本高,优先稳定大于兴趣 |
| ⑤ | 务农 / 临工 | **跨阶级路径**:重学校牌子(985/211)+ 高就业专业;考虑公费师范 / 警校 / 殡葬等"100% 编制"专业 | 信息差最大,机会成本最高,牌子比专业重要(到一定程度) |

## L2.2 家庭年收入(5 档)→ 推荐倾向

| 档 | 年收入 | 出省承担力 | 推荐倾向 |
|---|---|---|---|
| ① | < 10 万 | **极困难** | 优先省内 + 公费师范 + 国家专项 + 二本编制专业;**禁止冲外省学费贵的** |
| ② | 10-30 万 | **可承担但要算账** | 省内+邻省优先,长三角珠三角性价比之选;避免高消费城市(北上深)+ 高学费(中外合作) |
| ③ | 30-80 万 | **可承受任意大学** | 不限地域,但中外合作/出国 学费(20-50w/年)仍要慎重 |
| ④ | 80-200 万 | **舒适承担** | 可考虑出国预备 / 中外合作 / 一线城市 |
| ⑤ | > 200 万 | **完全无负担** | 可冒险选小众专业 / 直接出国 / 不在乎学校牌子选自由路径 |

## L2.3 亲戚资源(多选)→ 推荐倾向加权

每勾选一项,对应专业方向**权重 +20%**:

| 资源 | 加权方向 |
|---|---|
| 体制内有亲戚 | **考公全家桶**:汉语言/法学/会计/经济;选调生路径 |
| 医疗系统亲戚 | 医学(临床/口腔/影像)— 但仍建议核对家庭收入档 ≥ ② |
| 教育系统亲戚 | 师范类(数/语/英/物理),公费师范优先 |
| 金融行业亲戚 | 金融/会计/经济(但仍需 985/211 头部院校) |
| 法律行业亲戚 | 法学(5 院 4 系 / 省内顶级 985 法学院 / 财经类政法院校)+ 法考路径 |
| 都没有 | **无加权**,纯按家庭情况推 |

## L3 意愿量表(1-5)→ 决策权重

| 用户答 | agent 解读 | 推荐影响 |
|---|---|---|
| **考公意愿 5** | 锁定考公主赛道 | 候选必含汉语言/法学/会计;**避坑国贸/工商管理/旅游** |
| **考公意愿 4** | 强倾向考公 | 推荐时偏向考公友好专业,但也可选小众工科 |
| **考公意愿 3** | 中立 | 默认平衡推荐 |
| **考公意愿 1-2** | 不考公 | 推荐时不强调考公专业,可看就业市场专业 |
| **考研意愿 5** | 必读研 | 可推荐"本科出路差但研后好" 的专业(数学/统计/物理/化学) |

## L3 地域接受度(多选)→ 院校过滤

agent 根据用户勾选,在 query_school 之后过滤候选:

| 选项 | 包含省份 |
|---|---|
| 只本省 | 用户所在省份 |
| 省会城市 | 用户所在省份的省会 |
| 邻近省份 / 区域 | 用户所在省份 + 周边 3-5 个省份(同一大区,如华中/华东/华南/西南/华北/东北) |
| 长三角珠三角 | 上海/江苏/浙江/广东/福建 |
| 北京上海 | 北京/上海 |
| 接受东北西北/西南偏远 | 东三省/陕甘宁青/云贵川渝 |
| 全国不限 | 不过滤 |

**默认逻辑**:多选取并集。如果用户勾"只本省 + 长三角",则只推荐这两个区域的院校。

**特别提醒**:本省考生**默认应该问是否优先本省**,本省籍 + 本省院校 + 本省就业 是最稳的组合(熟人网络、考公本地优势、生活成本低)。

## L4.1 性格 — 两档制

agent 提问时**先问用户:"测过 MBTI 吗?有就直接告诉我类型,没有就答 3 道二选一"**。

### 档 A:简版(3 道情境题)

| 题 | A 选项 | B 选项 | A 计 1 内向分 / B 计 1 外向分 |
|---|---|---|---|
| 周末 | 约朋友外出 | 自己在家 | B = 内向 |
| 决策 | 谨慎权衡 | 果断快速 | A = 内向 |
| 学习 | 小组讨论效率高 | 独自钻研效率高 | B = 内向 |

**总分 ≥ 2 内向分** = 内向倾向;**= 1** = 中性;**= 0** = 外向倾向

**推荐影响**:
- **内向**:适合技术研究类(工科/数学/物理/CS),**避免**强调销售/谈判类(市场营销/国贸/广告/导游/服务业)
- **外向**:适合需要沟通的方向(法律/管理/师范/医生临床/营销/媒体);**纯技术研究类相对不利但不排除**
- **中性**:无强约束,按其他维度推

| **ISFJ** | 守卫者 | 护理/教师(中小学)/社工/HR/儿科/图情管理 | 强竞争商科/创业 |

**MBTI 加权强度**:**比简版 ±10% 的额外权重**(MBTI 是软提示,不能硬过滤)。**有 MBTI 信息时可以给出更具体的"专业适配理由"**,例如:
- "INTJ + 数物双强 + 考公 5 → 推电气工程,但要注意电气基层岗 INTJ 容易嫌烦琐,建议奔技术研究或调度方向"
- "ENFP + 文科强 + 考公 3 → 推汉语言/新闻,但 ENFP 做基层公务员容易内耗,建议方向是宣传/教育/媒体岗"

### ❗ MBTI 例外规则:慢启动赛道 + 普通家庭 = 不主推

**血泪教训(2026-05-07 实测)**:**ENTP 适合律师 ≠ 普通工薪家庭应该报法学**。

下列 MBTI **rubric 主推方向**带"慢启动 / 高风险" 属性:
| MBTI | rubric 主推方向 | 慢启动属性 |
|---|---|---|
| **ENTP** | 律师 / 咨询 / 创业 / 创意 | **5 年慢启动**(法考+律所助理) / 创业失败率 90%+ |
| **ENFP** | 心理咨询 / 媒体 | 心理咨询要硕博 / 双非新闻就业惨 |
| **ENTJ** | 律师 / MBA / 创业 / 政界 | 同上 |
| **INFP** | 写作 / 心理学 | 心理硕博 / 写作天花板低 |
| **INFJ** | 心理学 / 教育 | 心理硕博 / 教育稳但收入低 |

**当用户家庭档为 ④ 普通工薪 / ⑤ 农村 + 学科底子 OK(没硬阻断)时**:
**不要硬推这些慢启动赛道**。普通家庭撑不起 5 年慢启动期(房租 + 证书 + 应酬),且失败成本极高。

**应该降级处理**:
- 把 MBTI 主推方向标为"**可选**"(如果用户和父母强烈坚持试)
- 优先推**学科匹配 + 起步收入 + 出口稳定**的赛道:
  - **理科 OK + 末流 985/强 211 段** → CS / 工科 / 电气进央企 / 行业 211 通信 IT
  - **学科底子均衡 + 想挣钱** → 选起薪 15-25w 的工科+大厂赛道,**不选起薪 5-8k 的法学/创业**
- 在推荐文字里**明确说明**:"按 ENTP rubric 适合律师 / 咨询,但你普通工薪家庭 + 5 年慢启动撑不起,所以降级为可选方向"

**反例(我犯过的错)**:
给 615 分 / ENTP / 普通工薪独子男 推某财经类政法院校法学(主推)→ 用户挑战"为什么推法学" → 反思发现:法学 5 年慢启动 + 双非财经天花板低,**应主推工科+央企/IT 赛道**(省内 985 工科类 / 行业 211 通信电子 / 省内 211 工科类)。

### 重要纪律

**性格不是硬约束,是软提示**。即使 MBTI 不匹配,如果其他维度(家庭/未来/兴趣)都强力指向某个专业,**该推还是推,只是给出"性格上需要适应"的提醒**。
**MBTI 软提示 < 家庭硬约束**:家庭抗风险能力决定能不能走慢启动路径,不要让 MBTI 适配性覆盖家庭实际承受力。

## L4.2 向往行业(多选)→ 召回优先级

### ❗ 关键概念:行业 vs. 专业 是两层(必读)

**行业 ≠ 专业**。把这两者混了会犯严重错误(实测案例:agent 因"物理 40 不能学 CS 专业"误堵了"想做产品经理"路径,但 PM 不需要物理)。

- **专业 = 大学读什么**(由学科分数硬阻断 + 选科组合 + 排除项决定)
- **行业 = 毕业去哪里工作**(由综合能力 + 学校层次 + 城市决定,**不被专业完全锁定**)

很多行业岗位**不限专业**,常见的"任何专业都可入"行业岗:

| 行业 | 不限专业的岗位 | 隐性门槛 |
|---|---|---|
| IT 互联网 | 产品经理 / 内容运营 / 商务 / 销售 / 市场 / HR | **985/211 校招优先**;低学历需先做小公司 2-3 年再跳 |
| 金融 | 银行柜员 / 客户经理 / 保险代理 | 无,但天花板低 |
| 媒体内容 | 自媒体 / 公众号运营 / 短视频策划 | 看个人能力,不看专业 |
| 销售 | 医药代表 / 快消销售 / B 端 BD | **不限学历不限专业**,看抗压 + 业绩 |
| 教育 | 培训机构教师 / 教研 / 销售 | 不限,但编制体制内才看专业 |

**所以推理时**:用户被硬阻断某些专业(如物理弱无法学 CS),**不代表他被排除整个对应行业**。如果他想去 IT,可以选"非工科专业 → IT 行业里非技术岗位"路径。

### 行业 → 专业 直接对应表(本科直接对口)

| 行业 | 对应专业(召回时优先) |
|---|---|
| IT 互联网 | 计算机/软件/数据科学/电子工程(**注意 985/211 才推荐**) |
| 金融 | 金融学/会计/经济学/数学/统计(**头部院校才推荐**) |
| 医学医疗 | 临床/口腔/医学影像/护理/药学 |
| 教育 | 汉语言/数学(师范)/物理(师范)/学前教育 |
| 法律 | 法学/侦查学(**只推 5 院 4 系 + 头部财经政法 985/211**) |
| 工程制造 | 机械/车辆/电气/船舶/材料/航空航天 |
| 政府体制内 | 汉语言/法学/会计/经济(考公优先) |
| 媒体内容 | 新闻(**只推 985 头部新闻强势校**)/广播电视/数字媒体 |
| 能源电力 | 电气/水利水电/新能源 |
| 农林牧 | 园艺/兽医/食品(优先涉农 985 / 省属农业大学顶配) |
| 文化艺术 | 美术/音乐/设计(**专业课要求高**) |
| 服务业 | 旅游/酒店管理(**避坑**) |
| 其他 / 无明确偏好 | 不影响,按其他维度推 |

### 行业被硬阻断时的曲线救国路径

如果用户的硬约束(如物理 40 / 数学偏弱)**堵了直接对口专业**,但他**仍想进某行业**,给曲线路径:

| 用户想去 | 直接路径被堵的原因 | 曲线路径(明示风险) |
|---|---|---|
| IT 互联网 | CS 专业被物理硬阻断 | 任意专业 → 内容运营 / PM 助理 → 转 PM(3-5 年,起步小公司) |
| 金融 | 数学偏弱学不了金融头部 | 会计 / 银行实务 → 银行柜员 → 客户经理(稳路径,天花板低) |
| 媒体内容 | 双非新闻已被避坑名单否决 | 汉语言/广告/营销 + 业余自媒体 → 转岗 |
| 律师高薪 | 985 法学上不了 | 双非法学 + 法考 + 基层律所 → 5 年熬资历 |

## 综合决策示例(给 agent 的 few-shot)

### 案例 A:普通家庭考公型
- L2:父母 ④ 普通工薪 + 收入档 ② 10-30 万 + 亲戚资源 体制内
- L3:考公 5 + 出国 1 + 留本省
- L4:数学 138 物理 92 化学 78 → 数学物理强 → 工科适合
- L5:② 平衡

→ **强锁定:省内重点工科院校电气 / 省属一本法学 / 省内财经政法类会计**(都是考公友好 + 家庭档位匹配 + 留本省)

### 案例 B:中产家庭兴趣导向
- L2:父母 ③ 私企管理 + 收入档 ④ 80-200 万 + 亲戚资源 都没有
- L3:考研 4 + 出国 4 + 不限地域
- L4:数学 142 物理 95 化学 88 → 全科理工强;向往 IT 互联网
- L5:③ 求冲

→ **强锁定:省内 985 综合 CS / 邻省 985 工科 CS / 中科大数学 / 上交计算机**(分够就冲,考研出国都行)

### 案例 C:农村跨阶级
- L2:父母 ⑤ 务农 + 收入档 ① < 10 万
- L3:考公 4 + 考研 3 + 留本省或邻省
- L4:数学 130 物理 88 → 中上;无亲戚资源
- L5:① 求稳

→ **强锁定:省属师范大学公费师范汉语言 / 涉农 985 国家专项 / 省内重点工科院校电气**(100% 编制 + 无学费 + 考公友好)

### 案例 D:ENTP + 想挣钱 + 物理弱(从实测中学到的)
- L1:550 分 物理类 物化生 / **物理 40(硬阻断工科) / 化学 80 + 生物 90 双强 / 英语 120 偏上**
- L2:父母 ④ 普通工薪 + 收入档 ② 10-30 万 + 都没亲戚 + 独子男 + 某地级市
- L3:考研 3 + 考公 3 + 出国 1 + 排除大西北
- L4:**MBTI = ENTP** + 向往"多挣钱"(无具体行业)+ 排除工程/师范/临床医学
- L5:② 平衡(默认)

**关键推理链**:
1. 物理 40 触发**风险警示** → 工科 / CS / 电气 / 数学物理 大学课程挂科风险高 → "电气进电网逆袭" 这条主路径**风险过高,降级**(用户仍可选,但要明示挂科概率;权衡下用其他路径替代更稳)
2. 化学+生物双强 + 英语偏上 → **指向药学 / 制药 / 食品 / 医学技术**(学科底子匹配,大学课程不吃力)
3. ENTP 适合销售导向 + 不流程化 + 商业敏感 → **指向医药代表 / 快消销售**
4. 普通家庭抗风险低 + 想挣钱 → 选 **"学校层次门槛低 + 业绩驱动 + 上限高"** 的赛道

→ **强锁定:专业类药科大学(沈阳药科 / 广东药科 等) + 省内综合大学留本省 + 邻省医科大学 + 省属农业大学食品 — 全部指向"药学/制药 → 医药代表"赛道**

**这个案例的隐藏教训**(给 agent):
- 当用户说"想多挣钱"且硬数据堵死高薪主路径(金融/CS/律师)时,**不要硬推不匹配的高薪路径**(实测错误:推过"双非新闻 + PR")
- 转而看用户**学科底子能撑哪个行业** + **MBTI 是否适配该行业的工作模式**,**两者交叉处才是真正可行的"挣钱路径"**
- 化学+生物强的男生 + ENTP + 想挣钱 = **医药代表赛道**(不限学校层次,业绩驱动,顶级月入 3-5w),这是被低估的普通家庭男生路径
- **不要被"销售听起来不体面"的家长偏见绑架** —— 主动告诉用户和家长这个路径,让他们做有信息的选择

### 案例 E:ENTP + 普通工薪 + 理科 OK 615 分(从 case D 反推 + 实测校准)
- L1:615 分 物理类 物化生 / 省内位次 8880 / **理科都 OK 语文一般**(无硬阻断)/ 服从调剂 Y
- L2:省会本地 + 父母 ④ 普通工薪 + 收入档 ② 10-30 万 + 都没亲戚 + 独子男
- L3:考研 3 + 考公 3 + 出国 1 + 地域不限
- L4:**MBTI = ENTP** + 想挣钱(无具体行业)+ 不挑排除
- L5:② 平衡(默认)

**第一反应推理(❌ 错的,实测踩坑)**:
- ENTP rubric → 法学 / 律师 / 创业 / 创意 → 推头部财经类政法院校法学 + 中国政法 + 综合类财经组
- 这是 over-fit MBTI rubric,**忽略了普通工薪家庭撑不起 5 年慢启动**

**校准后推理(✓ 对的)**:
1. **学科 OK + 没硬阻断** → CS / 工科赛道完全开放
2. **普通工薪 + 独子** → 起步收入比天花板更重要,优先**起薪 15-25w 的工科+央企/大厂**而非"5 年慢启动的法学"
3. **想挣钱 + 末流 985/强 211 段** → 重点匹配 **省内 985 工科平台 / 行业 211 顶配(北邮/西电类)/ 留省会 211 工科**
4. ENTP 适配性是软提示(±10%),**不能覆盖"普通家庭抗风险低"硬约束**

→ **强锁定:省内 985 工科类中段工科冲 / 北邮通信 / 西电信电 / 省内 211 工科类(留省会)**
→ **法学/财经降级为"可选"**(头部财经政法院校作为第 6 张可选卡,如用户和父母明确想试律师赛道)

**这个案例的最大教训**:
- **MBTI 的"适配方向"是性格画像,不是职业成功率**。ENTP 适合律师 ≠ ENTP 律师容易做成
- **普通工薪家庭做职业选择时,起步收入 + 路径明确性 > 天花板高度**
- **学科底子 OK 没硬阻断是重要资产**,**别浪费在"性格匹配但实际成功率低"的慢启动赛道**
- **agent 推荐前必须做 ROI sanity check**:推这条路 → 5 年成功率 / 起步收入 / 家庭撑得起几年慢启动?如果跟用户家庭档位冲突,降级
