# 低分场景分流：复读 vs 专科填报 决策指引

适用场景：`score_to_rank.py` 返回 `batch.bracket = "between_undergrad_and_vocational"`（分数在本科线下、专科线上），用户犹豫是否复读。

---

## 核心决策矩阵

| 关键条件 | 倾向结论 | 原因 |
|---|---|---|
| 差本科批线 ≤ 20 分 + 家庭经济支撑得住 | **认真考虑复读** | 20 分以内复读成功率相对高；差得越少越值 |
| 差 21-50 分 + 目标明确（知道想学什么） | **复读风险中等，需细评** | 50 分以内能否提升，高度依赖学生状态 |
| 差 > 50 分 | **不建议复读** | 提分难度大，机会成本高；专科 + 专升本路径更确定 |
| 家庭经济紧张（收入 < 10 万/年） | **直接上专科** | 复读成本 = 1 年生活费 + 心理代价；专科更早出来挣钱 |
| 强烈专升本意愿 | **上专科 + 专升本 > 复读** | 3 年专科 + 1 年专升本 = 4 年，和复读 + 本科差不多；路径更确定 |
| 发挥严重失常（平时能上本科线） | **复读值得认真考虑** | 正常发挥有本科，这次是意外；复读是纠偏 |
| 正常发挥（这就是真实水平） | **专科为主** | 复读一年不一定能过线；建议先接受现实再做决策 |
| 女生 + 护理/学前意向 | **直接上专科** | 这两个方向就业稳定，专科足够；复读没必要 |
| 技能型意向（数控/铁路/电力/电子） | **直接上专科** | 技能岗看证书不看学历；专科反而是正途 |

---

## 话术模板

**用户犹豫时，这样问：**

```
"你差了 X 分。我帮你想两件事：

第一，这次是不是正常发挥？
  A. 发挥失常（平时模考能过本科线）→ 复读有意义，是纠偏
  B. 正常发挥（这就是你的真实水平）→ 复读不确定性大

第二，家里情况能支持你再读一年吗？
  （复读费用 + 生活费，通常 2-3 万/年）"
```

**根据回答，给出具体建议（不绕弯子）：**

- A + 经济支持 → "建议复读。选复读学校时看历年提分率，优先省会城市大型复读机构。"
- A + 经济紧张 → "复读也可以，但建议走免费/低费复读，或问问原高中是否接收。"
- B + 任何经济 → "你的真实水平对应专科批，复读成功率不高。建议直接上专科 + 专升本，3 年后拿本科文凭，路径更确定。"
- 不确定发挥 → "先别急着决定。告诉我你最近几次模考多少分，我帮你判断这次是不是失常。"

## 切换到专科模式

用户决定走专科时，立即切换（不需要用户重开对话）：

1. lazy-load `skill/{PROV}-zhuanke/references/30_专升本路径/`
2. lazy-load `skill/{PROV}-zhuanke/references/20_院校梯队/`
3. 按专科维度继续 L2：专升本意愿（1-5 分）/ 目标行业 / 学费预算

**已知的分数、位次、科类直接带入专科流程，不要重新问。**

---

## 注意事项

- **不要主动推荐复读**：等用户自己问到，才用上面矩阵。主动推复读等于暗示用户"你差"，容易引起情绪反应
- **不承诺提分幅度**：上面的"成功率相对高"是定性描述，不要给具体数字（如"80% 的人能过线"），那是假数据
- **复读学校不推荐**：不推荐具体复读机构名称，风险太高；建议用户问原高中班主任或当地教育局
