# 考公优选专业表(江西本地视角)

## 核心结论

**专业决定考公选岗范围**。江西家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**江西考公的特殊性**:
1. **江西人才外流严重 → 留赣考公竞争比湖南 / 湖北宽松**(留下来的人少,岗位却多)
2. **江西基层公务员收入低**(月薪 5-7k + 基层补贴),但**编制稳定 + 江西生活成本低 + 父母老人观念**让"考公"是江西普通家庭默认路径
3. **江西选调走南昌大学 + 江西师大 + 江西财大**(本省 985/211 极少,选调名单有限)
4. **江西基层考公"赣东北 / 赣西南 / 罗霄山区"基层岗多**(扶贫倾斜),艰苦补贴在 1500-3000/月

## 关键事实(2024 国考 / 江西省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 江西省考特殊性
- 江西省考 + 各地市考(南昌 / 九江 / 赣州 / 上饶 等),**汉语言文学和法学并列考公第一专业**
- **江西各地市公务员岗位对法学要求高**(法院、检察院、司法局、监狱)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **赣东北 / 赣西南 / 罗霄山区基层岗** 倾斜,艰苦补贴高(部分岗 1500-3000/月)
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 800+ 比 1)
- **江西选调"市县乡三级倾斜"**:**985/211 出身报江西选调,初始就分到地市级,5 年内能上副处的不少**

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(江西本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **江西本省选调名单**:**南昌大学 / 江西师大 / 江西财大** + 部分江西农大 / 江西中医药大学 / 华东交大 — **江西本省 985/211 极少 → 江西选调名单有限 → 出省 985/211 + 回赣选调是江西考生的优解**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、**江西警察学院** 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**江西监狱系统对中南财法 / 西政 / 华政 等校认可**
- **江西警察学院** = 留赣进江西公安系统的最佳路径(本科即可,无学历劣势,公安联考通过率高)

## 决策映射

| 学生 / 家庭目标 | 推荐专业 |
|---|---|
| 明确要考公 + 文科生 + 不挑岗位 | **汉语言文学(可报岗位最多,竞争中等)** |
| 明确要考公 + 文科生 + 想去法检院 | **法学(南昌大学 / 江财大首选)** |
| 明确要考公 + 理科生 + 不挑岗位 | **汉语言文学**(理科生学汉语言行测更强) |
| 明确要考公 + 理科生 + 想去税务 / 财政 | **会计学 / 经济学 / 统计学(江财大首选)** |
| 明确要考公 + 想做党政干部 | **马克思主义理论 / 行政管理**(选调生友好) |
| 想考警察 / 公安岗 + 留江西 | **江西警察学院 + 公安专业**(本科即可,无学历劣势) |
| 985/211 头部院校 + 想做高潜力路径 | **法学 / 经济学 / 汉语言** + 选调生路径(江西选调或出省回赣选调) |
| 江西普通家庭 + 双非 + 求编制 | **汉语言文学(最稳)** > 行政管理 > 经济学 |
| 不想考公 / 公考意愿不强 | 不应该围绕考公选专业,**回归兴趣 + 行业** |

## 江西本地院校 × 专业组合(考公视角)

### 211 + 强势考公专业
- **南昌大学法学** — 江西本省法学顶配,**江西法考通过率 + 江西选调 + 江西法检院** 三重对口
- **南昌大学汉语言文学** — 综合就业 + 考公双友好
- **南昌大学经济学** — 综合就业 + 考公双友好

### 双非 + 性价比考公专业
- **江西财经大学 法学(经济法 / 财税法方向)** — **双非但江西法考 + 江西税务系统认可度极高**,**财经 + 法学 = 考公王者双专业**
- **江西财经大学 财政学 / 税收学 / 会计学** — **进国家税务局 / 江西税务系统 / 各地财政局** 对口
- **江西师范大学 汉语言文学 / 思想政治教育 / 马克思主义理论** — **江西教师编 + 江西基层公务员** 双友好
- **江西本省二本汉语言**(宜春学院 / 上饶师院 / 九江学院 / 赣南师大 等)— **江西本地省考的优秀跳板**(双非毕业 + 考公成功 = 编制)
- **南昌大学医学院公共卫生** — 卫健委 / 疾控 / 医院管理对口

### 公安系统专属(留赣进江西公安系统)
- **江西警察学院**(原江西警察学院,本科)— **江西公安联考路径,毕业进江西本地公安概率极高**(基层警察)
- **中国人民公安大学 / 中国人民警察大学**(分够走) — 全国公安系统顶配,江西考生分够推
- **南昌大学侦查学 / 治安学** — 江西考公司法 / 公安系统的路径

### 出省 + 回赣选调路径(高潜力)
- **武汉大学法学 / 中南财法法学 / 西南政法 / 华东政法** — 出省读 + 回赣选调 / 江西法检院
- **中央财经大学 / 上海财经大学 / 中南财大 财经类** — 出省读 + 回赣税务系统 / 江西国企财务

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:**江西吉安考生,540 分文史类,普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报江西师大汉语言文学**,毕业当年考上江西省直某机关公务员,**家庭命运改变**

- **Case B(选调路径)**:**江西南昌考生,650 分文史类,中产家庭**。家长想报"金融"(江财大经济学院)。**改报武大法学**,**毕业获得武大选调生资格,直接回江西省委组织部任职**,起点远超经济学就业

- **Case C(失败路径)**:**江西赣州考生,580 分理科,普通家庭男生**。家长想"考公兜底"。**报了南昌大学计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**

- **Case D(误区路径)**:**江西宜春家长**以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**

- **Case E(警察路径)**:**江西九江考生,560 分物理类,普通工薪家庭男生**。父母希望孩子留赣 + 进编制。**报江西警察学院 + 治安学** → **大四参加江西公安联考** → 进九江某区公安分局,**编制 + 留赣 + 父母满意**

- **Case F(财税路径)**:**江西新余考生,580 分历史类,普通家庭女生**。**报江西财经大学财政学 / 税收学** → **毕业考江西税务系统国考** → 进新余市税务局,**双非但财税专业对口性极强,考公成功率高于其他专业**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(江西 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸 / 工商管理) = 不如 211 + 好专业(法学 / 汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是江西家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**江西考公竞争小,啥专业都行**" — 半对。江西考公整体比湖南 / 湖北宽松(因为人才外流),但**专业对口性仍然决定可报岗位数**。**汉语言 / 法学 + 江西考公 = 双重红利**
- "**江西财大双非,考公不如南昌大学**" — 错。**江财大财经 + 法学专业,在江西财政 / 税务 / 法检院系统认可度极高**,**专业对口性强 → 考公成功率反而高过南昌大学非对口专业**

## 江西考生考公"出省 vs 留赣"决策

| 目标 | 留赣 | 出省 + 回赣 |
|---|---|---|
| 江西省直机关 | 南昌大学 / 江财大 / 江师大 + 选调 | 武大 / 中南 / 上交 / 复旦 + 江西选调 |
| 江西地市公务员 | 南昌大学 / 江财大 / 江师大 + 江西本省二本 | 多数出省 211/985 都接受 |
| 江西基层 / 县乡 | 江西本省二本 + 江师大 + 公费师范 | 大材小用 |
| 江西法检院 | 南昌大学法学 / 江财大法学 + 法考 | 西政 / 华政 / 中南财法 / 武大法学 + 江西选调 |
| 江西公安系统 | **江西警察学院** + 公安联考 | 中国人民公安大学 + 公安联考 |
| 江西税务系统 | **江财大财政 / 税收 / 会计** | 央财 / 上财 / 西财 + 国考 |

**江西考生考公最优组合**:
- **顶配**:出省 985 + 法学 / 经济 / 汉语言 + 回赣选调 = 5 年内副处
- **中配**:南昌大学 / 江财大 / 江师大 + 考公友好专业 = 江西省直 / 地市公务员
- **下配**:江西本省二本 + 汉语言 + 江西基层考公 = 县乡编制

## 关键提醒(江西特化)

**考公是江西普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是江西家长被严重低估的考公王者**。

**江西考公的"反认知"**:**江西考公竞争比想象中宽松**(人才外流)→ **江师大 / 江财大 / 江西本省二本汉语言 + 法学 = 江西普通家庭考公性价比之王**。**别因为"双非"标签放弃这条最对口的路径**。
