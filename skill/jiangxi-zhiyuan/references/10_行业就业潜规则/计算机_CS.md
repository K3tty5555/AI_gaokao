# 计算机科学与技术 / 软件工程(CS / SE)— 江西视角

## 一句话总结

**江西考生学 CS 的最大特殊性是"留赣还是出省"二选一**。**江西本省 IT 产业薄弱**(没有头部互联网公司,本地 IT 龙头如泰豪 / 思创 / 江西科骏年薪也就 8-12w),**真正赚 CS 红利必须出省**(长三角 / 武汉 / 珠三角)。**江西考生 + 双非 CS = 留赣本地 IT 中段 + 月薪 7-9k 编外**,跟想象中的"敲代码进大厂"差距巨大。

---

## 真相 1:CS 黄金时代已过,但江西考生分化更极端

- 2022-2024 互联网寒冬,**应届生 offer 数量比 2020 年峰值少 30%+**
- 但**头部学校的 CS 学生仍有 35w+ 起薪**(华科 / 武大 / 上海交大 / 浙大),长三角 + 武汉是江西考生最近的"出省 CS 红利圈"
- **江西考生留赣 CS = 留赣本地 IT 公司**(泰豪 / 思创 / 用友 / 蓝代斯 等)月薪 7-9k 起,**跟国家电网普通员工差不多**
- 出省 CS 跟留赣 CS,5 年差出 30w 年薪,**这是江西考生的核心赌局**

**结论**:**江西考生学 CS,核心问题不是"学不学",而是"分够不够出省"**。够不出省,慎重学 CS。

---

## 真相 2:35 岁危机存在,业务型程序员淘汰风险大

- 35 岁危机集中在**业务型程序员**(增删改查、调用别人轮子的那类)
- **核心技术岗(底层、算法、架构、芯片)的 35 岁不是危机,是黄金期**
- 区别:你是"会写代码的人"还是"懂技术的人"
- **江西本省双非 CS 学生很难进入核心技术岗赛道**(没有竞赛氛围 / 缺乏头部实习机会 / 同伴差距大)

**结论**:**江西考生想做核心技术岗,本科必须是 985 + 出省 + 自驱**。这条件江西考生达不到比例不低。

---

## 真相 3:本科 < 硕士的差距,在江西更突出

- 5 年前 985 本科 CS 直接拿 SP offer
- 现在 985 本科 CS 起薪 ≈ 211 硕士甚至略低
- 大厂校招向"硕士起步"倾斜
- **江西考生想吃 CS 红利,本科 + 硕士 985 双保险是更稳的选择**(南昌大学 CS 本 → 985 硕,这条路接受度高)
- **南昌大学 CS 本科直接进互联网大厂机会有限**(校招不在南昌大学列重点校),要么读研要么走江西本地路径

---

## 真相 4:转码内卷已到顶,在江西更难

- 2018-2022 大量文科生 / 其他工科生转码成功的窗口已关闭
- 现在企业对"科班 CS"偏好极强,**非科班想转码越来越难**
- **江西考生想转码 = 必须出省 + 拼实习**(本省连转码培训机构都不强,信息差大)

---

## 适合什么人(江西视角加权)

- **数学好**(高中数学 130+,这是硬指标 — 江西高考数学相对全国卷难度中等,135+ 才算真好)
- **抗压能力强 + 不怕加班**
- **有自学能力**(大学课程跟不上行业实际,**江西本省高校 CS 课程更新慢**,自学比例要求更高)
- **985 出身,或者愿意读研甚至读博**(江西考生 985 = 必须出省)
- **接受出省 = 长三角 / 武汉 / 珠三角就业**(留赣 CS 红利极弱)
- **家庭中产以上**,能撑 4 年读书 + 设备 + 实习生活成本

## 不适合什么人(江西视角加权)

- **数学差**(高中数学 110 以下慎重)
- **追求安稳生活、不想 996**
- **双非家庭 + 不打算考研 + 想留江西** = CS 三重坑(双非 CS 留赣 = 本地 IT 中段月薪 7-9k)
- **江西本省二本三本 CS** = **直接避坑,不如学护理 / 师范 / 会计** 有明确出路
- **家庭强烈不希望孩子出省**:CS 留赣 = 平庸路径,跟其他工科差不多

## 江西本地 CS 院校真实分层

### 第一梯队(留赣 + 顶配,但放全国是中等)
- **南昌大学 CS** — 江西唯一 211,**全国 50-80 名**,是江西本省 CS 天花板。**留赣进江西本地 IT 龙头(泰豪 / 思创 / 江西科骏)+ 部分进长三角中段互联网**(美团美业 / 阿里部分团队 / 网易杭研)。**校招地位**:**不在头部互联网校招重点校列表**(BAT 重点校是华科 / 武大 / 西交 / 浙大 / 上交 / 北邮 等),所以南昌大学 CS 出身想进大厂要靠**实习 + 自驱 + 读研**。

### 第二梯队(细分领域 + 双非)
- **华东交通大学 软件工程** — 双非,**铁路系统 IT 部门对口**(中铁 / 各铁路局信息中心),稳定但天花板低
- **江西理工大学 计算机** — 双非,**赣州 + 矿业 IT 系统对口**,留赣州 / 赣西方向
- **江西财经大学 信息管理与信息系统** — 双非,**财经 + IT 复合**,适合做企业 IT / 财务系统

### 第三梯队(双非一本 / 二本)
- **南昌航空大学 计算机 / 软件工程** — 双非,中等水平,留赣进洪都航空 IT 部
- **江西师范大学 计算机** — 双非师范学校学 CS,**师范 + IT 是怪胎,不推荐**(除非走教育技术方向当中学信息老师)
- **南昌工程学院 / 九江学院 CS** — 二本,留地市本地 IT 公司

### 第四梯队(避坑)
- **江西本省的二本三本独立学院 CS**(南昌大学共青学院 / 江财大现代经济管理学院 等)— **请直接避坑**。这一档学 CS 不如学护理 / 师范 / 会计等有明确出路的专业。普通家庭的孩子在这些学校学 CS 出来基本就业极差。

## 江西考生 CS 的"出省战略"地图(关键!)

| 目标 | 出省方向 | 推荐校 |
|---|---|---|
| 顶配 CS + 大厂 | 长三角 / 北京 | 上交 / 浙大 / 复旦 / 北航 / 北邮 / 西电(分够走) |
| 中部 CS 大厂 | 武汉 | 华科 / 武大 / 武理工(跟江西离得近,出省成本最低) |
| 沿海 CS 民企 | 广东 | 中山大学 / 华南理工 / 深圳大学(分够走) |
| 211 牌子 + CS 中段 | 长三角 | 苏州大学 / 上海大学 / 华东理工 / 上海理工 |
| 留赣 + CS 顶配 | 江西本省 | 南昌大学 CS(不出省的天花板) |

**江西考生主流出省 CS 路径**:**南昌 → 武汉 / 长三角 / 珠三角**,**长三角是 CS 红利最大的方向**(月薪 25-40w,生活成本中等)。

## 典型 case(供 agent 引用)

### Case A:南昌某重点中学考生(中产家庭,父母都是公务员)
- 高考 645 分物理类,**主推华科 CS**(出省武汉,离南昌近 + 985 + CS 全国前 10)
- 实习字节武汉,校招拿到字节 SP offer 35w 起 → **逆袭路径**
- **江西考生跨阶级 CS 路径模板**

### Case B:九江某二本 CS 男生(普通工薪家庭)
- 高考 540 分,被江西本省二本独立学院 CS 录取
- 毕业找不到 IT 工作,**最终去南昌某培训机构做销售月薪 6k**
- **典型踩坑**,家长以为"学了计算机就能赚钱",**双非二本 CS 在江西出口极差**

### Case C:赣州某农村家庭考生
- 高考 580 分物理类,普通家庭,本想报"南昌大学计算机"
- 改建议:**南昌大学 CS** vs **湖南大学 / 中南大学某专业** — **同分能上中南大学(985)的话,直接出省**
- 最终报中南大学,毕业进长沙 / 深圳大厂,**跨阶级成功**

### Case D:吉安某考生(中产 + 父母想孩子留赣)
- 高考 612 分物理类,够南昌大学 CS,但出省可上中下 985
- **家长意向"留赣"**:推南昌大学 CS,毕业进江西本地泰豪 / 思创,月薪 8-10k 起
- **5 年后**:跟同分上中南大学 / 武大的同学比,年薪差 15-20w
- **江西考生最经典的"留赣 vs 出省"分岔点**

### Case E:抚州某双非考生(普通家庭)
- 高考 510 分物理类,**主推江西科技师范学院 CS** vs **华东交大软件工程**
- 改建议:**华东交大软件工程**,**进铁路系统 IT 部门** = 编制 + 稳定 8-10k
- **比双非 CS 留赣进民企不知道强多少**
