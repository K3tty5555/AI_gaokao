# 江西老高考与 3+1+2 过渡

## 核心结论

**江西 2021 年加入新高考第四批,2024 年高考首届实行 3+1+2**(跟黑龙江/吉林/安徽/甘肃/贵州/广西 同批)。**2021-2023 仍是文/理科老高考体系**,2024 起切换到物理类/历史类。**这意味着江西 2024 是新高考首届,数据极其稀缺(仅 1 年新高考样本),推荐时务必谨慎,不能拿老高考文/理科数据直接套**。

## 关键事实

### 江西新高考时间线

| 年份 | 高考类型 | 备注 |
|---|---|---|
| 2021-2023 | **老高考(文/理科)** | 文综(政史地)/ 理综(物化生),全国乙卷 |
| 2024 | **3+1+2 首届** | 物理类/历史类首次,部分采用全国新高考卷 |
| 2025 | 3+1+2 第二届 | 数据未到位(本 skill 数据库目前只到 2024) |

**对比**:
- 湖北/湖南/广东/河北 = 2021 首届 3+1+2(已经 5 届数据)
- 江苏/福建/重庆/辽宁 = 2021 首届
- **江西 = 2024 首届(只有 1 届数据)** — **这是江西志愿咨询最大的数据短板**

### 考试结构(2024+)

- **3 = 语文 + 数学 + 英语**(全国新高考卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2024+)

- **物理类**:选物理为首选,理工类为主
- **历史类**:选历史为首选,文史类为主
- 江西物理类约 60%,历史类约 40%

### 院校专业组(2024+)

- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量(2024+)

- **江西本科批 96 个院校专业组**(每个专业组内含若干专业)— **数量比湖北 / 湖南 45 个 / 江苏 40 个 都多**
- 专科批也有较多名额

**关键提醒**:**江西 96 志愿是新高考最多之一**,意味着家长信息过载风险更高。志愿规划师的价值更大 —— 帮考生从 96 个里筛出真正合适的 5-10 所主推。

## 老高考 vs 新高考 数据可比性

### 文科 ↔ 历史类(粗略可比)

- 文科 = 政史地必选,**等价于 3+1+2 的"史政地"组合**
- 历史类 = 物理类的对立面,**包含史政地 / 史化生 / 史化政 等所有以历史为首选的组合**
- **文科考生位次 ≈ 历史类考生位次**(粗略,不精确)

### 理科 ↔ 物理类(粗略可比)

- 理科 = 物化生必选,**等价于 3+1+2 的"物化生"组合**
- 物理类 = **包含物化生 / 物化政 / 物化地 / 物生政 等所有物理首选组合**
- **理科考生位次 ≠ 物理类考生位次**(物理类盘子更大,因为政地组合纳入了)

### 2024 首届数据使用纪律

- **首届物理类/历史类录取分数线没有历史可比性**(没有 5 年数据,只有 1 年)
- **大小年风险无法预测**(σ 标签需要 ≥ 3 年数据)
- 推荐时优先用 2024 数据 + 备注"江西 2024 是新高考首届,数据样本不足,大小年风险不可预测,请家长保留 buffer"
- 2021-2023 的文/理科数据 **仅作院校强弱趋势参考**,不能直接作为录取位次

## 江西最大痛点 — 名校稀缺

### 名校数量对比(给家长直观感受)

| 省份 | 985 数量 | 211 数量 | 主流出省方向 |
|---|---|---|---|
| **江西** | **0** | **1**(南昌大学) | 长三角 / 武汉 / 珠三角 |
| 河南 | 0 | 1(郑大,2017 升 985) | 山东 / 陕西 / 江苏 / 北京 |
| 河北 | 0 | 1(河工大,在天津) | 京 / 津 / 陕 / 鲁 |
| 湖北 | 2 | 5 | (本省 211 多,留鄂为主) |
| 湖南 | 3 | 1 | (本省名校多,留湘为主) |
| 江苏 | 2 | 11 | (本省 211 多,留苏为主) |

**结论**:**江西是中部六省里名校最稀缺的(跟河南河北一档)**。**江西 50w/年考生,只有 1 所 211**,意味着江西考生想要 211/985 牌子,**绝大多数得出省**。

### 江西考生主流出省路径

| 流向 | 主要去处 | 适合人群 |
|---|---|---|
| **长三角(沪苏浙)** | 上海 / 南京 / 苏州 / 杭州 / 无锡 | 想去发达地区 + 经济条件 OK |
| **武汉** | 武大 / 华科 / 武理工 / 中南财法 / 华师 | 想要 985/211 牌子 + 文科理科都吃 |
| **珠三角(粤)** | 中大 / 华工 / 暨大 / 深大 | 想去发达地区 + 接受南方气候 |
| 北京 | 清北 + 一票 211 | 顶尖学生 |
| 中部其他(湘鄂豫皖)| 中南 / 湖大 / 郑大 / 中科大 | 同档考生 |

**江西本省经济不发达** → **出省就业是主流**(回赣比例约 30-40%,其他省份回流率显著更低)。**这是江西考生最大的战略选择**。

## 江西特殊本地化要素

### 1. 红色文化 / 革命老区

- **井冈山 / 瑞金 / 南昌起义旧址 / 萍乡安源** — 革命传统教育资源
- **井冈山大学**(吉安)— 红色文化招牌,但学科一般
- 涉及党政军 / 党史相关专业,江西本地有特色

### 2. 陶瓷工业(景德镇)

- **景德镇陶瓷大学** — **全国唯一以陶瓷命名的本科院校**,陶瓷工程 / 陶瓷艺术全国第 1
- 非遗传承 / 文创 / 艺术陶瓷 / 工业陶瓷 全产业链
- **江西本地特色路径** — 想做陶瓷艺术家 / 文创 / 国货品牌设计的独家选项

### 3. 稀土资源(赣州)

- **赣州 = 中国稀土之都**,稀土储量全国前列
- **江西理工大学**(赣州)— 稀土工程全国第 1 + 中国稀土集团对口
- 关联产业:新能源车永磁电机 / 军工材料 / 半导体材料

### 4. 矿产资源 / 有色金属

- 铜(德兴铜矿,亚洲最大露天铜矿)/ 钨(赣南钨矿)/ 锂(宜春锂矿,2022 锂电材料热点)
- 江西理工 / 东华理工(原华东地质学院,抚州)对口

### 5. 农业大省

- **江西农业大学**(南昌)— 双非但农业领域强
- 鄱阳湖渔业 / 茶叶 / 柑橘 等

## 易错认知(agent 要纠正用户的)

- **"江西 2024 是新高考首届,数据少没事,看 2021-2023 文/理科数据就行"** — 错。**老高考文/理科分数体系跟新高考物理类/历史类不可直接比对**,只能参考院校强弱趋势
- **"江西 211 只有 1 所太少,所以南昌大学含金量不高"** — 半错。**南昌大学是 211 + 双一流**(食品科学 A+ 全国第 1),含金量在江西本省**毋庸置疑第一**,但放到全国排名约 60-80 名(类似郑大 / 苏大 一档)
- **"江西本省没好大学,直接全部出省"** — 半错。**江西本省双非里有几个细分领域王者**(江西财大 / 华东交大 / 江西理工 / 景德镇陶瓷大学等),特定路径下不输 211
- **"江西本科批 96 个志愿,随便填都能上"** — 严重错误。**96 志愿不等于"随便填",每个院校专业组都要研究**,服从调剂还得逐个 check
- **"江西考生留赣 vs 出省差不多"** — 严重错误。**江西本省经济发展弱于长三角/珠三角**,出省就业是主流,**留赣意味着接受双非 + 本地就业市场**

## 关键提醒(agent 必须强调)

1. **江西 2024 是新高考首届,数据样本不足**,大小年风险不可预测,推荐时家长务必保留 buffer
2. **2021-2023 文/理科数据只能作趋势参考**,不能直接作为录取位次
3. **看位次不看分数**(新高考与老高考分数体系独立)
4. **再选科目限制**(必选化学/必选政治等)是硬约束
5. **江西本科批 96 个志愿**,信息过载风险高,志愿规划师的筛选价值更大
6. **江西 985=0 / 211=1**,出省战略是主流,要主动跟家长讲清
