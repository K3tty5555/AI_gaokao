# 用户意向冲突 — Reality Check 金句库(江西视角)

很多家长 / 考生有具体的意向("想上南昌大学"、"非留南昌不可"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

**江西考生意向冲突的特殊性**:**江西本省名校稀缺(985=0 / 211=1)+ 经济落后 + 人才外流** → **江西家长最大的认知误区是"留赣"是默认值**。但**江西考生用同样分数出省,经常能拿到一档高的牌子 + 一档高的就业市场**。**reality check 的重点之一是:打破"留赣"默认 + 给出"出省"替代**。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **江西普通家庭别被"留赣"绑架** — **留赣 = 接受双非牌子(除南昌大学)**,出省 = 同分能上 211/985,这个差距江西考生必须看清
6. **江西普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

---

## 5 类意向冲突 + 金句模板(江西第 5 类是江西特化)

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 480 分要南昌大学主流组 / 580 分要清华)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 211 牌子的执念,还是把 [替代校] 当作双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(江西 480 分,意向南昌大学)**:
> "南昌大学主流组在江西物理类 8000-14000 名。你 35000 名,差 2 万名,**南昌大学没戏**。
>
> 但你能上**江西财经大学(双非但财经全国前 10)/ 华东交通大学铁道方向(进南昌铁路局)/ 江西理工大学冶金方向(赣州,稀土对口)**— 这三所留赣就业,**江西国企 / 体制内招聘里跟南昌大学冷门组比**,因为对口性强,**入职门槛和起薪反而差不多**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'211 就是 211',但 **南昌大学的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 出省 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(江西考生 + 普通家庭)**:
> "南昌大学你 22000 名能冲 — 但只能进材料(非 LED 方向)/ 林学 / 部分文科边缘专业。**211 牌子 + 江西本地 + 生化环材 / 文科边缘** = 三重坑(没出省红利 + 专业坑)。
>
> 同分能上的**江西财经大学会计 / 金融 / 税收 + 长三角就业** 平台对口性更强。冲南昌大学留一个心理慰藉位即可,主推江财大 / 华交大对口专业。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**江西普通家庭撑不起 30 岁前不挣钱**(江西普通工薪月薪 5-8k,8 年长周期等于全家压力极大)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [华科同济 / 武大医 / 出省 985 临床])
> - 撑不起 → 走 **[替代短路径]**(如 [南昌大学医学影像技术 / 检验技术 / 护理本科 — 早 4 年挣钱 + 三甲技术岗编制]),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(江西普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-7k(江西低于一线)**。江西普通工薪父母还要供 8 年,**家庭压力极大**。
>
> 撑得起 → 推**南昌大学 5+3 一体化临床 / 出省 985 临床八年制**,长期天花板高。
>
> 撑不起 → **建议南昌大学医学影像技术 / 医学检验技术 / 护理本科**(4 年本科 + 进江西三甲医院技术岗 + 编制 + 起薪 5-7w),**早 4 年挣钱**,或者放弃医学走 CS / 会计这种本科直接挣钱的赛道。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非南昌不去" / "非北京不去"),拒绝出省 / 拒绝留赣。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 双非] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 双非反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留南昌只有南昌航大双非,要去西工大 / 北航),**要灵活退一步**。"

**真实案例(江西籍 + 法学方向 + 590 分)**:
> "你只留南昌,这位次 8000,南昌大学法学主线刚够擦边但只能冷门组。
>
> **留南昌最稳路径**:**江西财经大学法学**(双非但江西法考 + 江西法检院 + 江西税务系统认可度极高)+ 父母资源 + 法考通过 → 江西法检院 / 律所路径仍然能走,**比南昌大学冷门组好**。
>
> 不要为了'外省 985 牌子'去东北 / 西北 985 冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 江西考公优势没了**,综合不划算。"

---

### 模式 E(江西特化):"留赣"vs"出省" — 江西考生最经典分岔点

**特征**:江西考生家庭(尤其是普通工薪 / 农村)默认"留赣"(信息差 + 不爱折腾),但**用同样分数出省能拿到 211/985 牌子 + 长三角 / 武汉 / 珠三角就业市场**。**这是江西 agent 必须主动打破的信息差**。

**金句模板**:
> "你 [分数 / 位次] 在江西能上 [本省双非 / 南昌大学冷门组],但出省能上 [出省 211/985 + 主流专业]。
>
> **江西最大的真相是**:本省经济发展弱(中部六省靠后)+ 985=0 / 211=1 + 名校稀缺。**留赣 = 接受双非牌子 + 江西本地就业市场天花板**(江西月薪比湖北 / 湖南低 1-2k)。**出省 = 同分能上 211/985 + 长三角 / 武汉 / 珠三角就业市场**。
>
> 你的家庭情怀是'留赣陪父母',但客观选择是 [出省替代路径]。
>
> **5 年后你会感谢自己 18 岁出省的决定**(同样位次差,留赣双非 vs 出省 211 → 5 年薪资差 5-10w/年)。
>
> 出省成本(4 年学费 + 生活费比留赣多 5-10w),vs 出省红利(平台 + 城市 + 人脉),**值得家庭算清楚**。"

**真实案例 1(江西吉安农村家庭 605 分文史类)**:
> "你父母想让你报江师大 + 留江西。**江师大公费师范是江西农村家庭的优解**,但你 605 分够上**国家专项 + 武大 / 华师 / 中南民族大学等 985/211**(国家专项分比统招低 20-30 分)。
>
> **国家专项 + 出省 985/211 = 江西农村家庭跨阶级最大杠杆**,牌子打开整个家族的圈子。
>
> 但**农村家庭兜不起 4 年生活费 5-10w 的差额** → 那就**江师大公费师范 + 0 学费 + 编制 + 回乡**,这也是好路径,**但你要知道:留赣 = 你的天花板就锁在县乡教师这一档**。"

**真实案例 2(江西南昌中产家庭 645 分物理类)**:
> "你够上**南昌大学计算机 + 留南昌**(中产家庭 + 父母希望孩子留赣,典型决策)。
>
> 但同分够上**华中科技大学计算机 / 武汉大学计算机 / 中南大学计算机 / 上海交大次档** — **985 + CS 全国前 10 + 长三角 / 武汉就业 = 跟南昌大学 CS 完全不是一个市场**。
>
> 5 年后差距:**南昌大学 CS 留赣 = 月薪 8-10k**(江西本地 IT 龙头);**华科 CS + 长三角就业 = 月薪 25-35k**(字节 / 阿里 / 美团)。**5 年差 30w+ 年薪**。
>
> **你父母的'留赣情怀'值不值这个差距?这是家庭要决策的事**。"

## Agent 处理意向的 5 步(江西特化)

收到 L4.5 意向锚点后,**强制做这 5 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向
5. **江西特化:主动给"留赣 vs 出省"双轨** — **不能默认按"留赣"出推荐**,必须主动算同分出省方案

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **江西特定:默认按"留赣"出推荐而不主动算出省方案** — 这是江西 agent 价值的核心,不能省

## 当意向跟 rubric 推荐冲突时的输出处理(江西特化)

### 推荐输出双轨(江西版,经常是三轨)

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨 / 三轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向(留赣)**(可能不是客观最优)
- **轨道 2:放弃留赣意向但客观更优(出省 211/985)**
- **轨道 3(江西特色)**:**留赣双非 + 细分领域王者**(江财 / 华交大 / 江理工 / 景德陶大 / 南昌航大 / 东华理工)— 介于留赣和出省之间,**对口性强 = 江西考生的"第三条路"**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 南昌大学 / 想留江西 / 想学医 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]

[ 江西特化:留赣 vs 出省的对比 + 同分外省方案 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 江西 agent 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。**对江西考生,reality check 的核心是打破"留赣"默认,给出"出省"替代**,**否则你就跟江西本地的"志愿填报机构"一样,只会按家长的意向出方案,而不是给出真正能改变孩子未来 20 年的判断**。
