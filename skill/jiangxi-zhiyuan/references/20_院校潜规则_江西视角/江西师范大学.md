# 江西师范大学(江师大,JXNU)— 双非但江西师范主力

## 一句话定位

**江西本省师范主力**,留赣当老师对口校。**双非师范,跟二档师范大学差不多**(不如华师 / 北师 / 华东师大,接近东北师大下一档,跟河北师大 / 河南师大 / 安徽师大 一档)。**想留江西当老师 + 普通工薪家庭 + 编制思维 = 江师大是江西本省最稳路径**。**师范类留赣率 70-80%,出省师范不占优势**。

---

## 真实地位

- **双非 + 江西省 / 教育部 共建**(江西省属师范龙头,本省师资认可顶配)
- **江西本省地位**:**留赣当老师 = 江师大是默认路径**(南昌大学师范类不强,这块江师大独占)
- **江西公费师范生主要供给校**(教育部直属六大师范是华师 / 北师 / 华东师大 / 西南师大 / 陕师 / 东北师大,**江师大不是六大但是江西省公费师范主力**)
- **校区**:瑶湖校区(主校区,本科多在此)+ 青山湖校区(老校区,部分专业)
- **特点**:女多男少(约 3:7 反过来,**师范校 70% 女生**),南昌瑶湖大学城环境一般

## 公费师范生(江师大特色 ★★★)

**江西省公费师范生政策**(江师大执行,跟教育部六大师范类似但执行的是省级):

- **学费 + 住宿费 全免**(江西省财政承担)
- **生活补贴**:每月约 600-800 元
- **毕业直接编制**:**回原籍服务 6 年**(江西省内定向到县乡中学概率高,**南昌市区编制不一定保**)
- **录取分较高**:江西物理类约 25,000-32,000 名(公费师范名额竞争激烈)

**最适合**:
- 普通工薪 / 农村家庭(经济压力大,公费 = 零成本上大学 + 编制)
- 父母希望孩子做老师 / 进体制内
- 接受去江西县乡基层中学服务 6 年

**最不适合**:
- 完全不想做老师的(公费要求服务 6 年,违约要赔学费 + 写违约记录)
- 追求南昌市区编制(**公费师范定向到县乡中学概率高,南昌市区不一定保**)
- 性格外向 + 想做生意 / 创业

## 性价比专业

- **公费师范汉语言文学**:**留赣编制铁饭碗** + **考公友好(汉语言是考公王者之一)**
- **教育学 / 心理学**:**进高校辅导员 / 中学心理老师 / 教育系统行政编** 多路径
- **马克思主义理论(思政师范)**:**思政教师 + 党政机关** + 考公,**冷门但出口稳定**
- **数学师范**:**所有学科里最稀缺的中学教师**,留赣编制竞争相对小

## 坑专业(在江师大里相对弱)

- **非师范专业(理学院 / 工科 / 经管 / 法学)**:**江师大非师范专业不强**,**别为了师大牌子学非师范**,**非师范出口跟双非二本差不多**
- **教育技术学**:听起来像师范但**不是公费 + 不是教师编制对口**,**当心被忽悠**(命名陷阱)
- **数学与应用数学(非师范方向)**:跟数学师范同校但**非师范出口窄**
- **科学技术学院 / 共青学院**:**独立学院 / 民办**,**不是江师大本部**,**牌子差 + 学费贵**,填报别看错代码

## 毕业出口(2024 数据)

- **留江西就业**:约 **70-80%**(**师范类留赣率全省最高**,江西各市县中学是主战场)
  - 南昌市区编制(竞争最激烈)
  - 江西其他地市(九江 / 赣州 / 宜春 / 上饶 / 吉安等)中学编制
  - 县乡中学编制(公费师范定向多在此)
- **出省到长三角 / 广东 / 武汉**:约 **15-20%**(**师范类出省 = 民办学校 / 培训机构 / 部分公办教师** + 非师范类去长三角民营 / 武汉)
  - 武汉:作为中部龙头,部分湖北就业 / 培训机构
  - 长三角:上海 / 杭州民办学校 / 培训机构(双减后机构萎缩)
  - 广东:深圳教师招聘 / 民办学校(深圳教师待遇高,但卡牌子)
- **考研 / 读博**:约 **15-20%**(保研率约 5-8%)
- **考公 / 考编**:**师范类直接考教编**(占 50%+),**非师范类考公务员**(汉语言 / 法学 / 思政考公王者)

**江西考生主流路径**:**江师大公费师范 → 江西县乡中学编制**(7-9 万年薪 + 编制铁饭碗) = 留赣稳定路径;**江师大普通师范 → 自己考教编(南昌市区 / 长三角民办)** = 灵活路径但不保编;**江师大非师范 → 出省找工作或考公** = 出口跟双非二本差不多。

## 同档对比

| 维度 | 江师大 | 华师(211) | 北师 / 华东师大(985) | 南昌大学师范 |
|---|---|---|---|---|
| 综合排名 | 双非 | **211(教育部直属六大)** | **985(顶配师范)** | **211(综合性)** |
| 师范实力 | **江西本省第一** | **华中第一** | **全国第 1-3** | 弱(非主打) |
| 留江西就业 | **极高(70-80%)** | 高 | 中 | 中(走综合) |
| 公费师范名额 | 多(省级) | 多(部级) | 多(部级) | 无 |
| 录取分 | 中等(双非) | 高一档(211) | 顶配(985) | 高一档(211) |

**简单结论**:**留江西当老师 + 公费师范** → 江师大独家路径(不出省);**分数够 211 / 985 + 想做老师 + 想出省**:优先华师(湖北)/ 华东师大(上海)/ 北师(北京)三选一,**985 / 211 师范牌子明显高一档**;**学综合性专业** → 南昌大学(本省 211 牌子)。

## 适合谁

- 江西物理类 **省排 25,000-75,000 名** / 历史类 **4,000-20,000 名** 的考生
- **想当老师 + 留江西** → 江师大是默认路径
- **女生 + 求稳 + 编制思维** → 公费师范 + 教编路径
- **普通工薪 / 农村家庭** + 想要稳定就业 + 接受县乡基层
- 性格内向稳健 + 适合教学工作 + 喜欢跟孩子打交道
- 接受南昌瑶湖大学城环境(地处南昌郊区,生活相对单调)

## 不适合谁

- **想当老师但分数能上华师 / 北师 / 华东师大**:**优先 985/211 师范,出省牌子明显高一档**
- **完全不想做老师**:**江师大非师范专业不强,出口跟双非二本差不多**,选江师大非师范是赔了平台
- **追求南昌市区编制** + **怕去县乡基层**:**公费师范定向到县乡中学概率高**,**追求南昌市区的 → 师大非定向 + 自己考教编 更灵活**
- **追求高薪互联网 / 金融 / 投行就业**:江师大平台对接不上,选江财大或外省 211
- **性格外向 + 想做生意 / 创业 + 不喜欢流程化**:不适合教师职业 + 公费 6 年服务期捆绑

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生**:
   - 名字里有"师范"且是 **提前批录取** → 公费师范(免学费 + 编制 + 6 年服务期)
   - 名字里有"师范"但是 **普通批录取** → 普通师范(自费 + 自找工作)
   - **千万分清,差几十万学费 + 编制差异**
2. **江师大本部 vs 科学技术学院 vs 共青学院**:**只有瑶湖 / 青山湖本部是江师大正牌**,科学技术学院 / 共青学院是独立学院 / 民办,**学费贵 + 牌子差**,**填报别看错代码**
3. **公费师范的"原籍服务 6 年"是硬约束**:**违约要赔学费 + 写违约记录**,**影响以后考公考编**。**家长一定要跟孩子聊清楚这 6 年要回原籍 + 大概率到县乡**
4. **教育技术学 ≠ 师范 + 公费**:**听起来像师范但不是教师编制对口**,**别被名字忽悠**
5. **物理类 vs 历史类**:**师范类历史类录取分明显高于物理类**(江西文科扎堆),**历史类报江师大要更高位次**
6. **江师大公费 vs 华师公费**:**华师公费 = 全国通用 + 牌子 211 + 留湖北 / 跨省服务**;**江师大公费 = 仅限江西 + 双非牌子 + 留赣服务**;**江西籍考生分数够华师公费的 → 优先华师(牌子 + 平台高一档)**
