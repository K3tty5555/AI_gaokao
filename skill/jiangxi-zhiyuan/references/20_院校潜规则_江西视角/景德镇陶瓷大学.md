# 景德镇陶瓷大学(景德陶大,JCI)— 双非但陶瓷工程全国唯一

## 一句话定位

**全国唯一以陶瓷命名的本科院校**,**陶瓷工程 / 陶瓷艺术 全国第 1**(独家行业地位),**景德镇本土 = 千年瓷都**,**中国陶瓷工业唯一对口校**。**冷门但顶配** — 陶瓷工业 / 文创 / 非遗传承 / 国货品牌设计 的唯一国内路径。**国货崛起 + Z 世代消费 + 海外"洋景漂"现象** = 景德镇陶瓷产业链反而在扩张,**就业天花板不低,但路径偏小众**。

---

## 真实地位

- **双非 + 教育部 / 江西省 / 工信部 共建**(行业内独家牌子,跟其他双非完全不同的赛道)
- **全国唯一以陶瓷命名的本科院校**:**陶瓷工程 + 陶瓷艺术 + 陶瓷设计 三位一体**,无其他高校替代
- **景德镇本土 = 千年瓷都 + 中国陶瓷之都**:产业链完整(原料 / 烧制 / 设计 / 销售 / 出口 / 文创),**就业不离开景德镇也活得下去**
- **行业属性极强**:**进陶瓷工业 / 文创 / 非遗传承 / 国货品牌设计 = 景德陶大独家路径**;**出陶瓷行业 = 双非牌子吃亏**
- **校区**:湘湖校区(主校区,新区)+ 新厂校区(老校区,部分艺术类专业)
- **特点**:**艺术 + 工科双底子**,**男女比相对均衡(艺术类女生多)** + 景德镇地理偏(江西东北,小地级市)

---

## 江西物理类录取位次区间

参考 2021-2025 江西历年录取 + 一分一段表反查:

- **王牌工科组(材料科学陶瓷方向 / 无机非金属材料)**:**全省 50,000-75,000 名**
- **主流组(陶瓷工程相关 / 工业设计 / 工科边缘)**:**全省 70,000-95,000 名**
- **冷门组(部分文科 / 经管)**:**全省 90,000-120,000 名**

## 江西历史类录取位次区间

- **主流文科组**:**全省 18,000-30,000 名**(陶瓷大文科非主流,**主要走美术艺考 + 物理类工科**)

## 美术艺考类(关键!)

- **景德陶大美术类录取分较高**:江西美术统考 + 文化课综合分,**陶瓷艺术设计 / 雕塑 / 美术学** 都是顶级招牌
- **陶瓷艺术设计 = 全国艺术院校陶瓷方向天花板**(跟央美 / 国美 / 鲁美 陶瓷工作室同档)

**段位定位**:**江西物理类省排 120,000 名内可冲景德陶大**,**75,000 名内可挑陶瓷材料王牌组**;**美术艺考类按统考 + 文化课综合分,陶瓷艺术设计是该校最强招牌**。**以一分一段表反查为准**。

## 性价比专业

- **材料科学(陶瓷方向)**:**全国唯一专业级独家** — 不是材料工程的二级方向,是陶瓷材料的一级独立专业。**进国家陶瓷工程中心 / 高端陶瓷企业 / 半导体陶瓷 / 航天陶瓷** 直接对口,**冷门 + 录取分相对低 = 性价比之王**
- **陶瓷艺术设计**:**国货新消费 + 文创崛起 + 海外艺术家市场** 三条出路,**比纯美术院校陶瓷方向就业网络更深**(景德镇本土产业链完整)
- **工业设计(陶瓷方向)**:**国货品牌设计 + 出口陶瓷外贸** 对口,**双语 + 设计 + 陶瓷三件套** 海外路径明显
- **雕塑(非遗方向)**:**国家非遗传承人路径** + 公共艺术,**冷门但天花板高**

## 坑专业(在景德陶大里相对弱)

- **文科 / 经管 / 法学**:**景德陶大是艺术 + 工科底子,文科边缘**,**学文科直接选江西师大 / 江财大**
- **普通材料(非陶瓷方向)**:**跟一般工科双非差不多**,**学普通材料选江理工(LED / 永磁)/ 南昌大学(LED 半导体)** 都更优
- **计算机 / 软件工程**:**景德陶大 CS 不强**,**学 CS 选南昌大学或外省双非沿海**
- **普通机械(非陶瓷装备方向)**:**对口性弱 + 不走陶瓷行业的话牌子吃亏**

## 毕业出口(2024 数据)

- **留江西就业**:约 **35-45%**(**景德镇本土主导 + 南昌部分**)
  - **景德镇**:陶瓷企业(华光陶瓷 / 景德镇陶瓷股份 / 唐英陶瓷)/ 文创 / 自主创业品牌 / 设计工作室 — **景德镇陶瓷产业链完整,就业不愁**
  - **南昌**:江西文化系统 / 设计公司
- **出省到长三角**:约 **20-25%**(**上海 / 杭州 / 苏州 国货品牌设计 / 文创 / 高端陶瓷企业**:陶溪川长三角分部 / 朱炳仁铜艺 / 国货新消费品牌)
- **出省到广东**:约 **15-20%**(**广州 / 深圳 国货新消费 / 出口陶瓷外贸 / 文创**:广州陶瓷展会 / 深圳设计周 / 出口陶瓷外贸公司)
- **出省到武汉**:约 **3-5%**(武汉作为中部龙头,部分文创 / 设计就业)
- **考研 / 读博**:约 **20-25%**(**保研率约 5-7%**,**陶瓷大本 + 央美 / 国美 / 鲁美 / 清华美院 陶瓷工作室硕**,接受度高)
- **海外创业 / 留学**:约 **5-10%**(**"洋景漂"现象**:海外艺术家来景德镇创业 + 中国学生海外艺术留学 / 创业)
- **进央企 / 国企概率**:约 **10-15%**(陶瓷不是央企密集行业,以民营 + 自主创业为主)
- **起薪范围**:**陶瓷企业 6-10w + 提成 / 设计师 8-15w + 作品提成 / 文创自主创业 浮动大(年收入 5-50w 都有)/ 海外艺术家市场 浮动大**

**江西考生主流路径**:**景德陶大陶瓷艺术 / 设计 → 国货品牌设计 / 文创 / 海外艺术家市场** = 个人天花板高路径;**景德陶大材料(陶瓷方向) → 高端陶瓷企业 / 半导体陶瓷 / 航天陶瓷** = 工业路径;**留景德镇 + 自主创业品牌** = "景漂"路径(年轻人居多)。

## 适合谁

- 江西物理类 **省排 50,000-120,000 名** + 想学陶瓷 / 设计的考生
- **江西美术艺考类考生** + 想做陶瓷艺术家 / 文创 / 国货品牌设计 / 非遗传承
- **女生 + 艺术倾向 + 想做有"匠人精神"的工作** → 独家路径
- **想做陶瓷材料工程师 / 高端陶瓷 / 半导体陶瓷 / 航天陶瓷** → 全国唯一专业级独家
- **接受景德镇地理偏 + 喜欢小城慢节奏 + 喜欢手工艺**
- **想自主创业 / 做"景漂" / 国货品牌创业** → 景德镇创业生态完整
- 普通工薪家庭 + 不在意双非牌子 + 想要独家行业属性

## 不适合谁

- **不想做陶瓷相关的别选**:**行业属性极强,转行成本高**,**不走陶瓷 = 双非牌子吃亏**
- **想做大众材料工程(非陶瓷)**:**选江理工(冶金 / 永磁)/ 南昌大学(LED 半导体)更优**
- **想做大众设计(平面 / UI)** :**选南昌大学 / 江财大设计 / 长三角设计名校** 更主流
- **必须出省冲北上深就业 + 大众路径**:**景德陶大牌子在大众就业市场认可度有限**(行业内顶配,行业外双非)
- **追求南昌市区或大城市生活**:**景德镇地处江西东北,小地级市,生活相对单调**
- **铁了心要 211 牌子**:**景德陶大是双非**,分够 211 + 想做综合性专业 → 选南昌大学
- **追求高薪互联网 / 金融 / 投行就业**:**景德陶大平台对接不上**,选江财大或外省 211

## 关键提醒(填报陷阱)

1. **王牌专业 = 陶瓷相关 / 美术艺考类**:**非陶瓷 / 非美术专业的报景德陶大就是浪费学校独家属性**,**学普通工科 / 经管 / 文科直接选其他学校**
2. **景德镇地理偏的现实**:**景德镇是江西东北小地级市(瓷都旅游属性强 + 工业生活节奏慢)**,**不是大学城便利的环境**,接受不了的别选
3. **物理类 vs 美术艺考类录取**:**陶瓷艺术设计 / 雕塑 / 美术学 主要走美术艺考(美术统考 + 文化课综合分)**;**材料科学陶瓷 / 工业设计 / 工科 主要走物理类**;**录取规则不同,别混着报**
4. **陶瓷材料 vs 普通材料**:**景德陶大材料专业 = 陶瓷方向(独家)**,出口是高端陶瓷工业;**学普通材料工程(电池 / 半导体 / 永磁)选南昌大学 / 江理工**
5. **服从调剂注意**:**陶瓷大热门组(材料 + 艺术设计)分高,中分组可能调到机械 / 边缘工科 / 经管,服从前问问能不能接受**
6. **就业要看行业窗口期**:**国货崛起 + Z 世代消费 + 海外"洋景漂"现象** 是景德陶大近 5 年就业扩张的根本原因,**这条路径不是冷门绝路,是冷门顶配**
7. **海外路径**:**陶瓷艺术 + 出口陶瓷 + "洋景漂"** 让景德陶大有独特的海外艺术家市场出口,**英语 + 设计 + 陶瓷三件套** 的学生可以走海外创业路径
