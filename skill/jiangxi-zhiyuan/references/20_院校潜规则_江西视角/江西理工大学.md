# 江西理工大学(江理工,JXUST)— 双非但稀土工程全国第 1

## 一句话定位

**原冶金工业部直属高校**(2000 年下放江西),**稀土工程 / 冶金工程 全国第 1**(赣州本土 = 中国稀土之都),**中国稀土集团总部对口校**(2021 年由五矿、中铝、赣州稀土集团等合并组建,**总部驻赣州**)。**男生 + 普通家庭 + 想进稀土 / 锂电 / 冶金 / 矿业系统 = 江理工是细分领域顶配**。**赣州地理偏但产业链完整**,**新能源车永磁电机 / 锂电池 / 半导体材料上游产业链对口**。

---

## 真实地位

- **双非 + 江西省 / 工信部 / 国防科工局 / 教育部 共建**(原冶金部直属底子,行业系统牌子重于一般双非)
- **稀土 / 冶金 / 矿业 全国前列**:**赣州 = 中国稀土之都 + 中国钨都**(全球 70% 稀土储量在赣州);**宜春 = 亚洲锂都**(2022 年宜春锂矿热点)
- **中国稀土集团总部对口**:2021 年在赣州组建总部,**江理工是独家供给校**
- **江西本省地位**:**留赣州 + 想进稀土 / 锂电 / 矿业系统 = 江理工独家选项**(其他江西院校稀土方向都不强)
- **校区**:赣州黄金校区(主校区)+ 赣州红旗校区(老校区)+ **南昌校区**(部分研究生 / 部分本科,**别忽略,有些专业在南昌**)
- **特点**:**赣州地理偏(江西西南,离南昌 4 小时高铁)** + 工科底子男多女少(约 7:3)+ 行业属性强

**段位定位**:**江西物理类省排 100,000 名内可冲江理工**,**55,000 名内可挑稀土王牌组**,**35,000 名内可冲冶金顶级组**。**地理偏 + 双非 + 行业冷门导致录取分相对低,性价比凸显**。**以一分一段表反查为准**。

## 性价比专业

- **稀土工程 / 稀有金属冶金**:**全国独家专业**(其他高校都是材料 / 冶金二级方向,江理工是一级独立专业),**进中国稀土集团 / 北方稀土 / 厦门钨业** 直接对口,**录取分相对低 + 行业窗口期(新能源 + 永磁电机 + 半导体上游)**,性价比顶配
- **金属材料工程(永磁 / 锂电方向)**:**新能源车永磁电机 + 锂电池正极材料** 上游产业链对口,**赣锋锂业(全球锂业龙头)/ 永磁电机制造商** 直接招聘
- **采矿工程**:**冷门但稳定**,中国矿大之外的最大供给校,海外矿业项目年薪可达 30-50w
- **测绘工程**:**冷门 + 国土系统对口**,考公友好

## 坑专业(在江理工里相对弱)

- **文科 / 经管 / 法学 / 行政管理**:**江理工是工科底子,文科边缘**,**学文科直接选江西师大 / 江财大**
- **计算机 / 软件工程 / 电信**:**江理工 CS 一般**,出口窄;**学 CS 选南昌大学或外省双非沿海**
- **普通工科(非冶金 / 材料 / 矿业方向)**:**跟一般工科双非差不多**,**进不了对口央企**
- **应用技术学院**:**独立学院**,**牌子差 + 学费贵**,填报别看错代码
- **金融 / 经管类**:**跟江财大比明显弱一档**,**学财经直接选江财大**

## 毕业出口(2024 数据)

- **留江西就业**:约 **40-50%**(**赣州 + 南昌主导**)
  - **赣州**:中国稀土集团 / 章源钨业 / 赣州稀土集团 / 江西铜业 — **赣州本土龙头国企对口**
  - **南昌**:江铜集团 / 江西本地制造业
  - **宜春**:**赣锋锂业(全球锂业龙头)** / 宜春锂矿产业链
- **出省到广东**:约 **15-20%**(**广东锂电 / 永磁电机 / 半导体上游产业链**:比亚迪 / CATL 华南分部 / 中科三环 / 横店东磁)
- **出省到长三角**:约 **15-20%**(上海 / 江苏冶金 / 半导体材料 / 锂电材料公司)
- **出省到武汉**:约 **5-10%**(武钢 / 中冶武勘院 / 中国地大读研)
- **考研 / 读博**:约 **20-25%**(**保研率约 6-8%**,**江理工本 + 中南大学 / 北科大 / 东北大学冶金硕,接受度高**)
- **进央企 / 国企概率**:**约 35-45%**(**冶金 / 稀土 / 矿业系统央企招聘量极大**:中国稀土集团 / 五矿 / 中铝 / 江西铜业 / 紫金矿业 / 赣锋锂业)
- **起薪范围**:**冶金 / 稀土央企 8-13w + 项目补贴**;锂电正极厂 12-18w(行业窗口期)/ 永磁电机厂 10-15w;海外矿业项目 30-50w(可观但艰苦)

**江西考生主流路径**:**江理工冶金 / 稀土 → 中国稀土集团 / 江西铜业 / 赣锋锂业** = 行业最对口铁饭碗;**江理工材料 / 矿业 → 广东锂电 / 永磁产业链** = 出省高薪路径;**新能源车 + 半导体上游产业窗口期** = 当下江理工出口比 5 年前好得多。

## 适合谁

- 江西物理类 **省排 35,000-100,000 名** 的男生(江理工以工科 + 物理类为主)
- **男生 + 普通工薪 / 农村家庭 + 想进冶金 / 稀土 / 矿业 / 锂电系统** → 性价比之王
- **江西本地考生 + 想留赣州 / 江西西部** → 地理对口最优(中国稀土集团总部就在赣州)
- **接受赣州地理偏 + 工业产业链工作** + **不在意双非牌子**(行业内顶配)
- 想做新能源车永磁电机 / 锂电池正极材料 / 半导体上游材料 工程师
- 务实 + 工科男 + 不怕去工业园区 / 矿区 / 冶炼厂

## 不适合谁

- **女生 + 不想跑工地 / 矿区 / 冶炼厂 + 追求都市生活**:**冶金矿业一线工作环境艰苦**,不适合追求都市 office 生活的女生
- **不进矿业 / 冶金系统的别为牌子选江理工**:**地理偏 + 行业窄 + 转行难**
- **学文科 / 财经 / 法学**:**江理工文科边缘**,选江财大 / 江西师大 / 南昌大学
- **学纯互联网 CS**:**江理工 CS 不强**,**学 CS 选南昌大学或外省双非沿海**
- **追求南昌市区或大城市生活**:**赣州地理偏(江西西南山区,离南昌 4 小时高铁)**,接受不了的别选
- **铁了心要 211 牌子**:**江理工是双非**,分够 211 直接选南昌大学或外省冶金 211(北科大 / 安徽工业大学 等)

## 关键提醒(填报陷阱)

1. **本部 vs 应用技术学院**:**只有黄金 / 红旗本部是江理工正牌**,**应用技术学院**牌子差 + 学费贵,**填报别看错代码**
2. **赣州校区 vs 南昌校区**:**江理工部分专业 / 部分研究生在南昌**,**填报前查清专业在哪个校区**(**别想着"江理工 = 都在赣州"**)
3. **物理类专业组分化**:王牌组(冶金 / 稀土 / 材料 / 矿业)与冷门组(经管 / 信管)录取位次差 30,000+ 名,**勾服从前查清组内有什么**
4. **稀土行业的现实**:**对口央企(中国稀土集团 / 五矿 / 中铝)项目常在赣州 / 包头 / 西部矿区**,**前 5 年基层环境艰苦**,**接受不了基层别报矿业 / 冶金方向**
5. **新能源车 + 半导体上游产业窗口期**:**江理工材料 / 永磁 / 锂电方向当下出口比 5 年前好得多**(2022 年宜春锂矿热点 + 永磁电机配套 + 半导体国产替代),**行业窗口期里录取分相对低 = 性价比凸显**
6. **江理工 vs 中南大学(985,长沙)冶金**:**江理工双非但稀土独家(全国第 1)**;**中南综合 985 + 冶金顶配 + 长沙地理好**;**分够 985 直接选中南**;**分不够走对口行业留赣 / 留中部** = 江理工最优
7. **赣州本地报考的特殊性**:**赣州本地考生留赣州读江理工 + 留赣州进中国稀土集团** = 完整本土路径,**这是江西西南考生的独家优势**

## 江西家长报考江理工的常见 FAQ(给 agent 用)

**Q1:江理工是 211 吗?**

**Q2:江理工跟北科大(京 211)/ 中南大学(985)冶金 比怎么样?**
