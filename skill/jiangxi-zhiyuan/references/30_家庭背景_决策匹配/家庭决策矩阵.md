# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(江西视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

**江西特殊性**:**江西本省经济发展相对落后**(中部六省靠后),**985=0 / 211=1**(本省名校稀缺),**人才外流严重**(去江浙沪 / 广东)。**江西考生家庭决策的最大特殊性是"留赣 vs 出省"二选一**,这个选择跟家庭档位强相关:**普通工薪 / 农村家庭倾向留赣**(信息差大 + 不爱折腾);**中产 / 体制内家庭倾向出省**(知道出省红利)。**这正是 agent 要做 reality check 的核心场景**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**江西画像**:
- 抗风险能力中等(收入稳但天花板低)— 江西基层公务员收入低于湖北 / 湖南
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)— **江西人才外流严重 → 留赣考公成功率反而高**
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **南昌 / 九江 / 赣州 体制内家庭 vs 县乡体制内家庭** — 信息差有别,前者更接近中产决策

**推荐策略(江西特化)**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:**江西选调走南昌大学 / 江西师大 / 江西财大 + 出省 985/211**,**985/211 选调比国考省考更优**(起点更高、竞争内部化)
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:**江西警察学院**(南昌)+ 公安联考 = 父母编制资源能用上
5. **父母在江西国企(江铜 / 赣锋锂业 / 江西铜业 / 江中药业)** → 子承父业:**江理工冶金 / 锂电 / 江中医药 / 南昌大学化学** 是行业对口路径

**典型 case**:
- **南昌某中产体制内家庭**(父亲省直机关,母亲江西银行)→ 孩子 605 分历史类 → 推**南昌大学法学 + 江财大法学(双轨)** → 毕业选调进江西省委办,**家庭路径完美匹配**
- **失败 case**:同样家庭,孩子被推去出省 985 学 CS → 毕业 35w 起薪很高,但家长不满"不稳定 + 出省回不来",劝其离职考公,**两年的时间损耗 + 心理纠结**
- **赣州某父亲在赣州市政府工作的家庭** → 孩子 580 分文史类 → 推**赣南师大汉语言文学**(留赣州 + 父亲资源用得上)→ 毕业进赣州市某区文化局,**编制 + 离父母近**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**江西画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道
- **江西本省专业人员家庭比例不低**(教师 / 县医院医生 / 县城律师 / 国企工程师)

**推荐策略(江西特化)**:
1. **优先子承父业**:
   - 教师家庭 → **江西师大公费师范汉语言 / 数学**(回原校 / 同区编制)
   - 医生家庭 → 南昌大学医学院临床 / 口腔(8 年长周期父母能撑)
   - 律师家庭 → 南昌大学法学 / 江财大法学
   - 江西国企工程师家庭 → 江理工 / 华东交大 / 南昌航大对口工科
2. **行业相关延伸**:律师家庭 → 法学;医生家庭 → 医学技术 / 护理(同行业不同岗)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- **母亲南昌某重点中学语文老师 + 父亲普通工薪** → 孩子 615 分历史类 → **公费师范生汉语言**(江师大)→ 毕业回原校 / 同区编制,**母亲资源直接复用**
- **父母都是江西临床医生** → 孩子 650 分物理类 → **南昌大学医学院 5+3 一体化临床** → 父母能撑 8 年读书 + 江西三甲推荐 → **典型子承父业路径**
- **父亲赣锋锂业(新余)工程师** → 孩子 580 分物理类 → **江西理工大学冶金 / 材料(锂电方向)**(赣州校区,父亲行业对口)→ 毕业进赣锋锂业 / 宁德时代宜春,**家庭工业链路径**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**江西画像**:
- 抗风险能力高(收入有上限但天花板高)— 但**江西本省私企比例低于浙江 / 福建 / 广东**,主要集中在赣商小型企业 + 长三角 / 珠三角创业的赣商
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **江西赣商**:虽然历史上不及徽商 / 浙商 / 闽商,但有抚州 / 上饶 / 宜春的小型家族企业

**推荐策略(江西特化)**:
1. **可选商科 / 创业方向**:工商管理(头部院校)/ 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(**江西本省中外合作办学少,主要走出省 / 出国**)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **景德镇 + 私企家庭**:**景德陶大陶瓷艺术 / 设计 / 文创** = 子承父业(陶瓷企业接班 / 国货品牌)
6. **避免:进体制内基层**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- **南昌某私企老板家庭**(年入 200w+) → 孩子 580 分物理类 → 推**香港城市大学 / 中外合作办学**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班
- **景德镇某陶瓷工厂主家庭** → 孩子 540 分历史类 → **景德陶大陶瓷艺术设计 / 工业设计** → 毕业回家族陶瓷工厂做产品设计 + 品牌升级,**江西特色子承父业路径**
- **抚州某农产品贸易家族** → 孩子 600 分物理类 → **南昌大学食品科学与工程**(全国第 1)+ 出省读研 → 回乡做农产品深加工,**家族企业升级路径**
- **失败 case**:**九江某私企家庭** → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(江西比湖北 / 湖南低 5-10 万)。

**江西画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **江西普通工薪家庭比例最高**(地市 / 县城工厂工人 / 服务业从业者)

**推荐策略(江西特化)**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **江西师大公费师范**(汉语言 / 数学 / 物理 等)= 高考分适中 + 直接编制 + 无学费 + 留赣定向 6 年
   - **江西警察学院** + 公安联考 = 进江西本地公安系统编制
   - **南昌大学医学影像技术 / 医学检验 / 护理** = 江西三甲医院技术岗 + 4 年本科即可
   - **赣南医学院 / 九江学院 护理本科** = 江西地市三甲 / 县医院编制
3. **次推稳定就业型(国企对口)**:
   - **南昌大学电气** 进国家电网江西省公司
   - **华东交大铁道电气化 / 交通运输** 进南昌铁路局(等同电网编制)
   - **江理工稀土工程** 进中国稀土集团 / 赣锋锂业(新能源上升期)
   - **南昌航大航空类** 进洪都航空 / 中航工业(军工系统)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 7-9k,跟双非工科没差,**江西本地 IT 红利极弱**)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- **江西宜春工厂家庭** → 孩子 580 分物理类 → 推**南昌大学电气**(进江西省网南昌分公司)→ 毕业进电网,**月入 8-10k + 编制,家庭逆袭**
- **江西吉安工薪家庭** → 孩子 540 分文史类 → 推**江西师大公费师范汉语言**(无学费 + 编制)→ 4 年零学费 + 毕业回吉安某县中学,**家庭命运改变**
- **江西新余工薪家庭(母亲赣锋锂业生产线工人)** → 孩子 520 分物理类 → 推**江西理工大学锂电 / 冶金方向** → 毕业进赣锋锂业 / 宁德时代宜春工程师岗,**月薪 8-10k + 锂电行业上升期**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万(江西农村经济水平低于湖北 / 湖南农村)。

**江西画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **江西农村家庭比例不低**(赣东北 / 赣西南山区 / 鄱阳湖周边 / 罗霄山区)

**推荐策略(江西特化)**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
   - **江西农村考生出省 985 = 跨阶级最大杠杆**(留赣 211 含金量低于出省 985)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **江西师大公费师范**(无学费 + 编制 + 回原县乡)= **江西农村家庭神器**
   - **国家专项计划 / 高校专项**:江西农村户籍,可冲外省 985/211(分数比统招低 20-30 分)
   - **江西警察学院 / 江西警官学院 / 中国人民警察大学**(无学费 + 编制 + 公安联考)
   - **农林牧水(江西农大 / 出省华农)**= 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:江西农村户籍,**外省 985/211 名校多个专项指标**(分数比统招低 20-30 分)— **江西农村考生跨阶级最大杠杆**
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **赣南苏区振兴 + 罗霄山区扶贫** 政策红利(部分扶贫专项计划)

**典型 case**:
- **江西赣州寻乌县农村家庭** → 孩子 590 分物理类 → 通过**国家专项**进**武汉大学环境工程**(比统招分低 30 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985**
- **江西吉安永新县农村家庭(罗霄山区)** → 605 分文史类 → 推**江西师大公费师范汉语言** → 4 年无学费 + 毕业回原县编制,**最适合江西农村家庭的"零风险"路径**
- **江西鹰潭余江区农村家庭** → 580 分物理类 → 推**南昌大学医学影像技术**(走南昌大学国家专项)→ 毕业进南昌大学一附院技师岗,**江西三甲技术岗编制 + 编内**

## 江西特殊维度:留赣 vs 出省

**这是江西考生家庭决策的"第二维度",必须跟档位交叉判断**:

| 家庭档 | 留赣倾向 | 出省倾向 | 建议 |
|---|---|---|---|
| ① 体制内 | 中(父母希望孩子留赣) | 中(知道出省红利) | **985/211 + 江西选调** = 出省读 + 回赣选调 |
| ② 专业人员 | 中(行业资源在赣) | 中(知道行业差距) | **看行业**:留赣行业(教师 / 江西国企)→ 留赣;全国性行业(互联网 / 金融)→ 出省 |
| ③ 私企 / 创业 | 低(知道江西商业弱) | **高** | **出省 + 国际化** 是默认 |
| ④ 普通工薪 | **高**(信息差 + 不爱折腾) | 低 | **agent 要 reality check**:同分能上的外省 985/211 vs 留赣双非,差距明显 |
| ⑤ 农村 / 临工 | **极高**(从未离开过家乡) | 低 | **agent 要 reality check**:**国家专项 + 出省 985 是跨阶级最大杠杆**,留赣双非是路径浪费 |

**江西考生最容易踩的坑**:**家庭档位低 + 留赣倾向高 → 用同等分数选了双非弱专业**(本可以走国家专项 / 出省 211/985)。**这是江西 agent 必须打破的信息差**。

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 × 留赣 / 出省**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**江西特殊提醒**:**留赣 vs 出省的判断要主动做,不能被动等用户提**。江西考生默认"留赣",但不少情况"出省"才是最优解,agent 要主动给出这个选项。
