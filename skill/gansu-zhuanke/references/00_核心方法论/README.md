# 甘肃专科 skill 核心方法论

## 一、甘肃专科与东部省份的核心差异(agent 必须先建立的认知)

甘肃专科填报**不能套湖北 / 河南 / 江苏的逻辑**。下面这几条差异,**没意识到就会推荐错方向**:

### 1. 甘肃专科是"留甘 + 央企 / 体制内"主导,不是"出省 + 民营"主导
- **湖北 / 江苏专科生**有相当比例去东部沿海打工 / 进民企
- **甘肃专科生**主要出口是**本省央企**(中石油兰州石化 / 国网甘肃 / 兰州铁路局)+ **本省体制内**(县乡编制 / 三支一扶)
- 出甘的甘肃专科生**普遍劣势**(学历 + 户口 + 房价 三重劣势)
- **agent 默认建议留甘**,除非用户有强烈个人 / 家庭理由

### 2. 甘肃公办 vs 民办专科分化极大,经济考量真实
- 甘肃农村家庭比例高,**民办专科 1.5-2 万 / 年学费 vs 公办 4-6 千 / 年** 是真实负担
- 4 万学费差对甘肃农村家庭可能等于全家半年收入
- **agent 必须先问家庭经济档,再做民办 / 公办建议**

### 3. 甘肃 985/211 稀缺导致专升本路径窄
- 甘肃只有兰大 1 所 985,2 所 211
- **专升本只能在甘肃省内升,且兰大不接收专升本**
- 这导致甘肃专升本"赛道宽度"远小于湖北 / 河南
- **选错专科 = 砍半本科选择,在甘肃比湖北严重**

### 4. 甘肃有"三支一扶 / 特岗 / 西部计划"的特殊跃迁通道
- **服务期满免笔试升本 + 转编 + 公考加分**——甘肃这条通道是其他省份不容易复制的
- **农村专科生务必了解**,这是被很多家长忽视的"上岸默认通道"
- **agent 推荐时应主动告知,不要等用户问**

### 5. 甘肃地缘红利极强
- **嘉峪关 / 玉门 / 庆阳 / 兰州**:央企工人子弟接班通道(中石油 / 长庆油田 / 玉门油田 / 兰州石化)
- **甘南 / 临夏**:民族地区 + 民族优惠 + 民族干部路径
- **陇南 / 静宁 / 庆阳**:苹果 / 林果产区,园艺技术 + 回乡创业 路径
- **酒泉**:风电光伏大基地,新能源运维赛道
- **agent 推荐时必须问"家在哪",不能像东部那样默认"院校 + 专业"为主**

### 6. 甘肃 2025 年首届 3+1+2(新高考)
- 主 skill (`gansu-zhiyuan`) 处理本科,本 skill 处理专科
- **2025 是甘肃 3+1+2 第一届**,选科组合数据 + 录取数据**仅 1 年样本**,**预测难度大于已经新高考多年的省份**
- **agent 推荐时要明确告知"政策第一年,数据可能不稳",建议结合招办文件**

## 四、agent 输出风格规范

### 必须做
- **先问家在哪**(地缘强相关,不问会推错方向)
- **先问家庭经济档**(影响民办 / 公办决策)
- **主动告知三支一扶 / 特岗 / 免试升本** 这些甘肃特色通道
- **强调"留甘 = 性价比之王"**,不要默认推用户出甘
- **推荐方案末尾必须加免责声明**

### 必须避免
- **不要套湖北逻辑**(湖北专科生出省比例高,甘肃专科生留省比例高)
- **不要默认"公办专科都差不多"**(甘肃行业对口校 vs 综合高职差距比东部大)
- **不要诋毁专科教育**(对甘肃农村孩子,专科 + 央企 / 编制 是合理的好路径)
- **不要承诺"一定能录取"**(2025 是新高考第一届,数据样本不足)
- **不要建议"民办凑合读"**(甘肃农村家庭民办学费是真实经济压力)
- **不要建议出甘读东部专科**(东部省份对甘肃高职认可度低 + 跨省专升本不通)

## 五、典型反模式(agent 不要这样答)

### 反模式 A:套东部"出省路径"
- ✗ "甘肃专科生可以考虑去江浙读高职,毕业留东部就业"
- ✓ "甘肃专科生留甘是性价比之王。东部省份对甘肃高职认可度低,且专升本不能跨省"

### 反模式 B:不问家在哪就推院校
- ✗ "推荐你报兰州石化职业技术大学"(没问家庭背景)
- ✓ "你父母在中石油 / 玉门油田工作吗?如果是,兰州石化职大对口度最高 + 接班通道顺;如果不是,我们再看其他对口校"

### 反模式 C:默认民办也行
- ✗ "如果公办专科上不了,可以考虑民办,反正都是 3 年"
- ✓ "甘肃农村家庭民办学费是真实负担。如果分数到不了公办专科,可以考虑(1)复读(2)走三支一扶 / 特岗路径(3)读公办中职再升专。**不建议直接报民办专科**"

### 反模式 D:不提三支一扶 / 特岗
- ✗ "你报甘肃农职 → 毕业找工作"
- ✓ "甘肃农职毕业后有 3 个路径:(1)直接就业 (2)专升本到甘肃农大 (3)**走三支一扶'支农',2 年期满可免笔试升本 + 转编**——这是甘肃农村专科生最稳的跃迁通道,务必了解"
