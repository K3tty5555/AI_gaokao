# 青海专科 skill 核心方法论

## 青海专科填报与内地省份的根本差异

agent 在跑流程时必须理解 ——**青海不是内地大省的"缩小版",决策逻辑完全不同**。

### 1. 盘子小,选项极少
- 青海每年高考考生 ~5 万,全国最少之一
- 青海公办专科只有 6-8 所(对比河南 100+ 所 / 山东 80+ 所)
- 青海能接收专升本的本科只有 3 所(青大 / 青师大 / 青民大)
- → **不能照搬"湖北 5 所专科冲稳保"逻辑**,选项本来就少

### 2. 体制内 + 高原补贴 = 隐藏跃迁路径
- 牧区州县乡基层岗 = 编制 + 4-6k 高原补贴 + 双语补贴 + 边远艰苦补贴
- **实发月薪 9-13k 的牧区编制岗,在内地一线城市本科生都拿不到**
- 这是青海专科生最被低估的跃迁路径
- → agent 必须主动告知,不能默认"专科生只能找私企打工"

### 3. 民族 + 双语 = 不可替代的红利
- 藏族 / 蒙古族 / 回族 / 撒拉族 / 土族 在青海体制内有政策倾斜
- 藏汉双语 / 蒙汉双语 在牧区幼师 / 兽医 / 医院 / 文旅 都是稀缺
- → agent 必须先问民族 + 户籍,**这是青海决策的前置条件**(内地大省没这一步)

### 4. 留青 vs 出省 = 核心决策点
- 出省读专科 = 失去青海专升本资格 + 失去应届体制内招聘资格
- 但西宁海东汉族家庭部分孩子有"看世界"诉求
- → agent 必须早期就问清楚意愿,**不能默认"留省最好"也不能默认"出省视野广"**

### 5. 季节性 / 高原 / 牧区 = 行业特质
- 青海湖 / 茶卡 旅游是 7-9 月旺季为主
- 牧区岗位有海拔适应要求(玉树果洛 4000+)
- 盐湖企业在格尔木 / 大柴旦 等偏远地区
- → agent 推荐时必须把"工作地点 + 工作环境"讲透,不能只看薪资数字

## 推荐流程(MVP 版,基于 SKILL.md)

1. **L1 硬数据**:分数 + 位次 + 选科 + 民族 + 户籍(民族 / 户籍是青海特有问题)
2. **L2 关键决策**:专升本意愿 + 留青 vs 出省 + 接受高原牧区否 + 性别敏感
3. **L3 家庭与个人**:家庭经济 + 民族 + 海拔适应 + 性格
4. **输出**:5 所推荐(冲 1 / 稳 2 / 保 2)+ 关键提醒(青海特色)

## agent 在推荐时必须做的事

1. **早期问民族 + 户籍**(决定是否享受民族优惠 / 双语红利 / 牧区基层岗)
2. **问留青 vs 出省**(决定是否优先省内专科)
3. **问专升本意愿**(决定专科选什么对口专业)
4. **介绍"高原补贴 + 编制"路径**(很多家长 / 学生不知道这个红利)
5. **不要默认"只想出省发展"**(青海体制内留省路径其实更稳)
6. **不要默认"专科是失败者"**(青海专科 + 编制 = 比内地很多本科岗都香)

---

## agent 不能做的事

1. **不能套用湖北 / 河南 / 山东的逻辑**(青海盘子 / 选项 / 政策都不同)
2. **不能编薪资数字**(写"约 X-Y k"的区间,不写"6800 元"这种精确数字)
3. **不能编录取分数线 / 位次**(用 query_school.py 召回真实数据)
4. **不能贬低专科教育**(在青海尤其不能 — 青海专科进编制不丢人)
5. **不能假装懂民族优惠 / 双语补贴的精确细节**(让用户去青海招办官网核对最新文件)
6. **不能推荐第三方志愿填报机构 / 补习班**(本 skill 本身就是 AI 规划师)

## 待补优先级

1. ⏳ **计算机软件专科**(青海互联网弱,优先级低,但仍有部分考生关心)
2. ⏳ **机电一体化专科**(对接盐湖 / 建筑 / 交通行业,部分内容散在其他文档)
3. ⏳ **会计 / 财务管理专科**(青海私企薄,体制内会计岗稀缺,价值有限)
4. ⏳ **民办专科避坑专项**(目前在 院校梯队.md 中分散,可独立)
