# 宁夏专科 skill 核心方法论

## 一、为什么宁夏专科要单独写一份

宁夏省情决定专科逻辑跟内地大省(湖北 / 河南 / 河北)完全不同:

1. **高校选项极少**:本科拿得出手就 3 所(宁大 / 宁医大 / 北方民大);专科本地能选的也就十来所。**专科生在宁夏不像在湖北那样要"PK 几十所",而是"几乎挑得见底"**。这反而让选择变简单,但前提是 agent 要先告诉用户"这就是你能选的全部",不要拿湖北思维硬套。

2. **本地央企校招权重极高**:神华宁煤(国能集团)/ 宁夏电投 / 中石油宁夏分公司 / 中铝宁夏 这些大户,**校招就盯着宁夏职业技术学院 / 宁夏工业职业学院 / 宁夏建设职业技术学院 几所对口高职**。出省读专科 = 失去这条最有效的就业通道。

3. **西部 / 民族 / 山区三个补贴叠加**:这是宁夏专科生 vs 内地专科生最大差异化优势。
   - 西部大开发 → 央企在宁招工补贴
   - 民族(回族占全省 1/3) → 民族岗位 + 民族院校专项
   - 山区(西海固:固原 / 海原 / 同心 等) → 三支一扶 / 特岗教师 / 乡村医生定向

4. **专升本极卷**:宁夏接收专升本的公办本科少(本科本来就 3 所拿得出手),**录取率比内地省份还低,要把专升本难度估到 30% 而不是 50%**。

5. **2025 是 3+1+2 首届**:政策衔接期,招生章程 / 专业组划分会有反复,agent 要提醒用户"以最新招生章程为准"。

## 四、风格约定

每篇 references **必须**:
- 用宁夏本省视角(出口央企 / 院校 / 城市 / 民族 / 山区都用具体名字)
- 大白话(不堆概念),case 优先
- 不编精确数字(给区间 + 标注"参考"),不抄湖北 / 河南数据
- 末尾必须有"易错认知"段(给 agent 用来纠正用户)
- 末尾必须给 1-3 个真实可推演的 case(姓 + 城市 + 分数档位 + 路径 + 5 年后状态)

每篇格式参考主 skill (`ningxia-zhiyuan/references/`) 已落地的章节风格。
