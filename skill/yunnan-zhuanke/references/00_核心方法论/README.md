# 云南专科咨询核心方法论

## 一、本 skill 的定位

云南专科填报咨询 ≠ 云南本科填报的迷你版。两者底层逻辑完全不同。

agent 跟用户对话时,**不能把本科那套"学校层次 + 城市偏好 + 专业冷热"直接搬过来**,会南辕北辙。

云南专科生需要的是:
1. **行业出口能不能落地**(进不进得了对口央企 / 国企?进得了 = 改命,进不了 = 流水线)
2. **专升本能不能跑通**(选错专科 = 砍半本科选择面)
3. **本省政策能不能薅到**(民族 / 边境 / 农村 / 定向项目 = 隐藏 buff,不利用就浪费)
4. **3 年后的下限是什么**(失败状态长什么样,用户要心理有数)

---

## 二、云南专科 vs 内地专科(湖北 / 山东 / 河南)的差异

agent 不能套湖北 / 山东 / 河南的专科逻辑,因为云南有四个本省独有的特色:

### 差异 1:有色冶金 + 烟草 = 本省独家王牌赛道
- 内地省份没有"云南铜业 / 云南锡业 / 云南铝业 / 驰宏锌锗"这种规模的有色金属国企集群
- 内地省份没有"红塔 / 红云红河 + 烟农体系"这种烟草王国
- **昆明冶金高专 + 云南农业职业**这两所学校是云南独家的"国企门票",内地没有对应物

### 差异 2:民族 + 边境 = 隐藏 buff 多
- 25 个少数民族 + 8 个边境州市 = 政策倾斜密集
- 民族骨干计划(专升本)+ 边境州专项(专升本 + 招聘)+ 民族双语教师专项 + 乡村医生定向 + 特岗教师定向 + 乡村教师定向
- 内地除了贵州 / 广西 / 新疆 / 西藏 部分类似,**云南的政策密度是少数省份才有**
- agent 在 L1 阶段必须问"民族 + 户籍",不能跳过

### 差异 3:旅游业陷阱
- 云南旅游业繁荣 ≠ 旅游专科生混得好
- 内地考生家长 / 学生看到"云南旅游业发达 → 学旅游肯定就业好"是最常见误判
- agent 必须主动踩刹车 + 把行业真相讲清楚(详见 `10_行业就业/旅游_酒店_导游.md`)

### 差异 4:留滇 vs 出滇心理
- 云南气候好 + 生活舒适 + 父母老人观念 → **"留滇"是很多家庭的默认偏好**
- 但留滇 = 工资低(昆明白领 4-6k);出滇 = 跳到江浙广能多赚 50-100%
- agent 在 L2 阶段必须问"留滇 vs 出滇",不能默认湖北那种"出鄂闯荡"心态

## 三、对话节奏(MVP 版)

### L1 硬数据(同主 skill,不啰嗦)
- 高考总分 + 全省位次
- 选科组合 + 物理 / 历史类
- 是否服从调剂
- **民族**(汉族 / 25 个少数民族中哪个)
- **户籍地**(边境州 / 民族州 / 昆明城区 / 内地州市)

**这两条云南独有,本科 skill 也要问但专科 skill 必须深度问**(影响定向 / 专项)。

### L2 关键决策
- 专升本意愿(强度 1-5)
- 留滇 vs 出滇
- 是否考虑定向项目(乡村医生 / 特岗教师 / 乡村教师)
- 接受野外 / 边远 / 三班倒吗
- 男女比失衡专业可接受吗

### L3 家庭与个人(简版)
- 家庭经济(影响民办 vs 公办)
- 民族 + 户籍叠加 buff
- 性格 / 兴趣(简版 3 题)

## 四、推荐输出的核心约束

### 必须包含
1. **位次 → 大致专科档位**(公办老牌高职 / 一般公办 / 民办)
2. **5 所院校(冲 1 / 稳 2 / 保 2)+ 每所的对口出口**
3. **专升本路径**(对口本科 + 接收院校)
4. **隐藏 buff**(民族 / 边境州 / 农村定向 是否触发)
5. **关键提醒**(避坑 + 失败状态 + 免责声明)

### 必须避免
1. **不要套湖北 / 山东 / 河南 的专科话术**(他们没有云南这套民族 + 边境 + 烟草 + 有色冶金)
2. **不要默认推旅游**(陷阱赛道,要严格筛选用户条件)
3. **不要回避"民办 vs 公办"的真实差距**(用户可能不知道这个)
4. **不要美化 / 妖魔化乡村医生 / 特岗教师**(实事求是讲服务期 + 编制 + 调动可能性)
5. **不要假装数据精确**(薪资 / 录取率 是大致区间,不是精确数字)
6. **不要承诺"一定能录"**(末尾必须加免责声明)

## 六、家庭决策矩阵(云南版)

| 家庭档 | 默认推荐方向 | 备注 |
|---|---|---|
| ⑤ 农村 + 少数民族 + 边境州 | **乡村医生定向 / 特岗教师 / 乡村教师定向 / 民族双语教师** | 改命密度最高的组合 |
| ⑤ 农村 + 汉族 | **烟草农艺 / 电气 / 铁路 / 护理 / 学前** + 升本 | 走国企央企 + 编制 |
| ④ 普通工薪 + 想留云南 | **昆明冶金高专(国企)/ 云南农业职业(烟草)/ 昆明卫生职业(护理) / 云南师大高职部(教师)** | 优先公办 + 行业对口 |
| ④ 普通工薪 + 想出云南 | **机电 / 计算机 / 护理 + 升本** + 出江浙广深 | 升本是关键 |
| ③ 私企管理 / 个体户(茶厂 / 民宿 / 烟农 / 旅游) | 看是否家族产业接班,选**对口专科 + 茶学 / 旅游 / 烟草** | 接班路径 |
| ② 专业人员(医生 / 教师 / 工程师) | 优先**升本路径 + 对应行业**(护理升本 → 临床、学前升本 → 教师) | 父母资源能延续 |
| ① 体制内 | **学前 / 护理 / 农艺 + 升本 + 考公** | 走家族体制内路径 |

## 八、安全与边界

1. 不承诺"一定能录"(录取受当年招生计划 / 报考人数 / 分数线波动影响)
2. 不诋毁专科教育(云南乡村医生 / 特岗教师 / 烟草工人 / 电网工人 / 矿企工人 都是社会刚需)
3. 不推荐第三方机构 / 培训班(本 skill 自己就是规划师)
4. 涉及政策的(专升本 / 民族优惠 / 定向项目)→ 提醒以云南省招考院 / 教育厅最新文件为准
5. 推荐方案末尾必须加免责声明
