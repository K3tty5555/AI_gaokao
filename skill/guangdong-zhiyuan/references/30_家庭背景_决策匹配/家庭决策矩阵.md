# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(广东版)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

**广东特殊性**:
- **私企 / 创业家庭比例全国前 3**(仅次于浙江 / 福建),很多潮汕 / 客家家族企业;**私企家庭决策逻辑跟体制内家庭天差地别**
- **粤东西北 vs 珠三角分化悬殊**:同样"工薪家庭",珠三角中产年收入 30-60w,粤东西北可能只有 8-15w
- **"留粤"是普遍偏好**(广东人不愿出省比山东人还强),这影响所有档位的决策

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入)+ **籍贯(珠三角 / 粤东 / 粤西 / 粤北)**,按本文件的 5 档矩阵 + 地理修正套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**广东特殊画像**:
- **比例低于湖北山东**(广东体制内家庭占比约 15-20%,湖北约 25-30%)— 因为广东民营经济发达,大量家庭在私企
- 抗风险能力中等(收入稳但天花板低,**广深公务员综合 18-25w 高于湖北但低于深圳互联网中产**)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公在广深可能不是默认路径**(很多体制内父母因为看到深圳互联网薪资高,会让孩子先去互联网试 5 年再考公兜底)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(广东省委选调生定向中大 / 华工 / 暨大);**广东选调生进省委组织部起点高**
3. **粤东西北体制内家庭** → 强推汉语言考公 + 回乡(竞争小,父母资源在本市可以直接用上)
4. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
5. **特殊机会**:警校(广东警官学院)+ 公安联考 = 父母编制资源能用上

**典型 case**:
- 广州某中产体制内家庭(父亲省直机关,母亲银行)→ 孩子 615 分历史类 → 推中大法学 → **毕业获中大选调名额进广东省委组织部**,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去华工 CS → 毕业 35w 起薪很高,但父亲不满"不稳定",劝其离职考公,**两年时间损耗 + 心理纠结**
- 揭阳工薪体制内家庭(父亲乡镇公务员)→ 孩子 565 分历史类 → 推广州大学汉语言文学 → 毕业回揭阳考公成功,**父亲资源在揭阳本市直接用上**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**广东特殊画像**:
- **比例适中**(广州医生 / 律师 / 工程师 家庭多)
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高(尤其医生家庭 → 子女学医)
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:教师家庭 → 师范 / 公费师范(华师);医生家庭 → 临床 / 口腔(中山医 / 南医大)+ 8 年长周期父母能撑
2. **行业相关延伸**:律师家庭 → 法学(中大 / 暨大);工程师家庭 → 对应工科(华工)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难,广东金融拐杖在深圳券商 / 港岛投行)
5. **广东医生家庭 + 子承父业** = 学医成功率全国最高(中山医校友体系强)

**典型 case**:
- 母亲华师附中语文老师 + 父亲普通工薪 → 孩子 625 分历史类 → **公费师范生汉语言**(华师)→ 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是中山医毕业的临床医生 → 孩子 660 分物理类 → **中山医八年制临床** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 深圳某律师家庭(父亲红圈所合伙人)→ 孩子 640 分历史类 → 推中大法学 → 父亲红圈所实习 → 毕业留深律所,**律所传承路径**

## 档位 ③ 私企管理 / 创业家庭(广东比例最高的一档)

**定义**:父母私企中高管 / 自主创业 / 企业主。**广东这一档比例约 35-40%,远高于湖北 / 山东**,尤其潮汕 / 客家家族企业普遍。

**广东特殊画像**:
- 抗风险能力高(收入有上限但天花板高)— **潮汕家族企业普遍年入 100-500w 不稀奇**
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **潮汕 / 客家家族独子男生** → 接班压力大,大学方向往往跟家族产业对口
- **珠三角私企家庭** → 出国留学比例高(把孩子送香港 / 美国 / 英国读本科 / 研究生)

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(中大管院 / 华工经管) / 经济学 / 金融 / 国贸(暨大 / 广外)
2. **可冲名校弱专业**:家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **大量家庭选择出国 / 中外合作办学**:**港中文(深圳)/ UIC(珠海)/ 中大中外合作 / 西交利物浦深圳分校**;学费 6-15w/年家里能撑;**香港 / 美国本科直读** 比例高
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **潮汕 / 客家独子男生 + 家族企业接班** → 推**国际商务 / 国际贸易 / 工商管理 + 海外经历**(对接家族外贸 / 跨境电商业务)
6. **避免:进体制内基层**(跟家庭基因不匹配,父母资源全用不上;**家族企业老板的孩子去乡镇公务员是巨大资源浪费**)

**典型 case**:
- 潮州某家族纺织企业(年入 300w+)→ 独子 580 分物理类 → 推**华工国际经济与贸易 / 西交利物浦深圳分校国际商务** → 出国背景做家族跨境电商接班,**首年家族给 30w 工资 + 接班路径明确**
- 深圳某 IT 创业家庭(父亲腾讯出来创业)→ 孩子 640 分物理类 → 推**港中文(深圳)CS / 南科大 CS** → 毕业直接进父亲推荐的中型 IT 公司,**典型 IT 二代**
- 东莞某制造业老板家庭(年入 200w+)→ 孩子 605 分物理类 → 推**华工机械 / 工业工程** → 毕业进父亲工厂做技术副总,**子承父业路径**
- 反面 case:潮汕家族企业 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,珠三角家庭年收入 20-50 万,粤东西北家庭年收入 8-20 万。

**广东特殊画像**:
- **粤东西北 vs 珠三角分化大**:同样"工薪",珠三角中产可能比粤东西北体制内家庭还宽裕
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **特别注意:粤东西北 + 工薪 vs 珠三角 + 工薪 推荐路径不同**(后者可以更冒险一点)

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - 公费师范生(华师)= 高考分适中 + 直接编制 + 无学费;**深圳教师起薪 22-30w 全国最高**
   - 警校(广东警官学院)+ 公安联考 = 进警察系统编制
   - 医学技术(医学影像 / 检验)/ 护理 = 三甲医院技术岗 + 4 年本科即可;**广深护士起薪 22-28w**
   - 殡葬专业 = 100% 编制 + 收入意外不错
3. **次推稳定就业型**:
   - 电气工程进南方电网(分够华工 / 广工)
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
4. **粤东西北工薪家庭 + 想留乡** → 推汉语言考公 + 回乡 / 本市供电局 / 本市三甲医院技师 / 本市教师编;**比去广深当外地人内卷更稳**
5. **珠三角工薪家庭 + 想留珠三角** → 推电气南网 / 教师编 / 医学技术 / 公费师范;**广深生活成本压力大但工资高**
6. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-12w,广深生活成本高反而压力大)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起;但医学技术 / 护理 OK)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 珠海工薪家庭(父母都在港口物流工作)→ 孩子 580 分物理类 → 推**广工电气**(进南网珠海供电局)→ 毕业首年 18w + 编制,**家庭逆袭**
- 湛江工薪家庭 → 孩子 540 分历史类 → 推**广东医科大学护理学** → 毕业留湛江市三甲护士,首年 12w + 编制,**粤西本地最稳路径**
- 茂名工薪家庭(父亲茂名石化普通员工)→ 孩子 590 分物理类 → 推**华师公费师范汉语言** → 毕业回茂名某中学教语文,首年 14w + 编制 + 学费全免
- 佛山工薪家庭 → 孩子 615 分物理类 → 推**南方医科大学医学影像技术** → 毕业留佛山三甲医院影像科,首年 16w + 编制

## 档位 ⑤ 农村 / 临工家庭(广东以粤东西北为主)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。**广东这一档主要分布在粤东(汕头 / 揭阳 / 汕尾 / 梅州 / 潮州)/ 粤西(湛江 / 茂名 / 阳江)/ 粤北(韶关 / 清远 / 河源)**。珠三角农村其实并不多(因为珠三角 80% 城镇化)。

**广东特殊画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解;**粤东很多家庭信息差跟河南山区类似**)
- 期待孩子跨阶级,跳出当前生活;**潮汕农村家庭对独子接班 vs 跨阶级 有撕裂**
- 资源:零,完全靠孩子自己 + 学校
- **粤东西北农村家庭对"留粤"诉求强**:跨阶级 = 走到广深,而不是走到上海北京

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对粤东西北农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - 公费师范生(华师 / 韶关学院公费师范)= 农村家庭神器;**深圳新教师起薪 22-30w 比湖北华师公费师范综合待遇高 30%+**
   - **国家专项计划 / 高校专项 = 广东农村专属优惠**(中大 / 华工 / 暨大 / 华师 都有专项指标,比统招分低 20-40 分)
   - 警校 / 军校(无学费 + 编制 + 包分配)
   - 农林牧水(华农国家专项)= 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划:广东粤东西北农村户籍**,中大 / 华工 / 暨大 / 华师 / 华农 都有专项指标(分数比统招低 20-40 分)
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **殡葬专业**(冷门但 100% 编制 + 收入不错)
   - **粤东西北本地认同 + 回乡考公** = 双非汉语言 + 回乡公务员 = 最稳路径(本市竞争比省直小)

**典型 case**:
- 梅州山区农村家庭 → 孩子 605 分物理类 → 通过**国家专项**进**中山大学环境工程**(比统招分低 30 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985,直接跨阶级**
- 揭阳农村女孩 → 605 分历史类 → 推**华师公费师范汉语言** → 4 年无学费 + 毕业回揭阳县城高中教语文,**最适合粤东农村家庭的"零风险"路径**
- 湛江农村男生 → 540 分物理类 → 推**广东医科大学护理(本科)** → 4 年后回湛江市三甲医院做男护士,**男护士稀缺 + 编制 + 留乡**
- 韶关农村女生 → 575 分物理类 → 推**韶关学院公费师范** → 毕业回韶关本地中学教书,**留乡 + 编制 + 父母身边**
- 潮汕农村独子男生 → 580 分物理类,**家族独子有接班压力但家族无产业**(纯务农)→ 推**广工电气** → 毕业进汕头供电局,**留乡 + 编制 + 家族体面**

## 矩阵速查表(给 agent 用)

| 家庭档 | 关键词 | 推 | 避 |
|---|---|---|---|
| ① 体制内 | 考公友好 + 选调路径 | 汉语言/法学/经济/会计/警校 | CS/金融头部/创业类 |
| ② 专业人员 | 子承父业 + 拐杖最大化 | 师范(教师)/医学(医生)/法学(律师) | 完全无父母资源的领域 |
| ③ 私企/创业(广东比例最高) | 可冒险 + 上限高 + 接班 | 商科头部/出国/港中深/创业/家族对口 | 体制内基层 |
| ④ 普通工薪 | 编制 + 稳定 + 留粤 | 公费师范/电气南网/医学技术/汉语言 | 双非金融CS/生化环材/医学长周期 |
| ⑤ 农村/临工(粤东西北为主) | 牌子 + 100% 编制 + 国家专项 | 国家专项/公费师范/警校/华农 | 长周期投入/出国/双非折腾 |

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 × 籍贯**(L2)→ **本文件主导**,锁定推荐策略大方向
   - **粤东西北籍 + 工薪 / 农村** → 留乡考公 / 教师编 / 本市供电局
   - **珠三角籍 + 工薪 / 中产** → 留珠三角 + 编制路径
   - **珠三角籍 + 私企 / 创业** → 出国 / 港中深 / 商科 / 接班
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位 + 籍贯是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 广东特有的"潮汕家族独子困局"

潮汕农村独子男生 + 家族企业接班压力 vs 个人想跨阶级出去 — 这是广东咨询时高频出现的冲突,**别套北方"出省 = 跨阶级"的思路**:

- **潮汕独子留乡接班** ≠ "没出息";**家族产业 + 同辈关系网 = 资本**
- **潮汕独子出广深 + 双非 CS** = 大概率失败;**反不如留乡接班**
