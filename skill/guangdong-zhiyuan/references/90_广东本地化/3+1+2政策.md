# 广东 3+1+2 高考政策

## 核心结论

**广东是全国第三批新高考改革省份**(2018 年启动选科,**2021 年首届 3+1+2 高考**)。**没有"理科 / 文科"了,改成"物理类 / 历史类"**;**录取按"院校专业组"投档**,**专业组内服从调剂**。**广东特色:院校专业组拆分极细(中大 / 华工 都拆成多个组)、港澳高校跨境招生通道独特、中外合作办学组数量全国前列**。这套规则比老高考复杂,**家长普遍弄不清楚**,导致填报时容易踩坑。

## 关键事实

### 考试结构(同湖北)
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(关键!!)
- **物理类** — 选物理为首选的考生
- **历史类** — 选历史为首选的考生
- **两类完全分开排名、分开录取**,**互不影响**
- 物理类报考人数 ≈ 65-70%,历史类 ≈ 30-35%(广东 2024 数据)
- **物理类专业选择面广(约 96%);历史类专业选择面窄(约 50%)**

### 12 种选科组合(同湖北,推荐方向相同)

| 选科组合 | 可报专业范围 | 评价 |
|---|---|---|
| 物 + 化 + 生 | **97% 专业**,理工医全能 | 万金油,首选 |
| 物 + 化 + 地 | 96% 专业,工科+地学 | 优秀 |
| 物 + 化 + 政 | 96% 专业 + 考公友好 | 平衡型 |
| 物 + 生 + 政 | 90% 专业,但医学受限(部分医学要求"再选化学") | 一般 |
| 物 + 生 + 地 | 89% 专业 | 一般 |
| 物 + 政 + 地 | 80% 专业(理工受限,文理混报) | 慎重 |
| 史 + 政 + 地 | **传统文综组合**,可报 50%+ 专业 | 文科首选 |
| 史 + 政 + 生 | 文史 + 部分医学 | 偏文 |
| 史 + 政 + 化 | 罕见组合 | 慎重 |
| 史 + 化 + 地 | 罕见组合 | 慎重 |
| 史 + 化 + 生 | 罕见组合 | 慎重 |
| 史 + 生 + 地 | 罕见组合 | 慎重 |

### 再选科目专业限制(2024 年最新)
- **再选必含化学**:绝大多数医学(临床、口腔、护理)、化学、化工、材料、生物科学等
- **再选必含生物**:部分医学(生命科学方向)、生物、农林牧、动植物相关
- **再选必含化学和生物**(双选):中山医学院 / 南方医科大学 / 广州医科大学 临床医学/口腔医学多数院校
- **再选必含政治**:马克思主义理论、政治学、国际关系、思想政治教育、部分公安院校
- **再选必含地理**:地理科学、地质学(部分院校)
- **绝大多数文史经管法学**:再选不限

### 院校专业组(投档单位)— 广东特色注意!

- **不再按"学校"投档,按"院校专业组"投档**
- **广东特殊性:院校专业组数量比其他省更多**。中大物理类拆出 5-10 个组(临床医学组/计算机组/经管组/人文组/工科组/中外合作组等),华工物理类也类似
- **同一学校的不同专业组独立投档,可以独立填报**
- **服从调剂只在本专业组内调剂**(不会被调到其他组)
- 一个专业组内通常 5-15 个专业,**广东中外合作组 / 高收费组单独成组**(动辄 6-12 万学费)

### 填报志愿数量(广东特色)

- **本科批次:45 个院校专业组**(广东本科批 = 45 个志愿,每个志愿 = 1 个院校专业组)
- 每个志愿组内可选 1-6 个具体专业 + 是否服从调剂
- **比湖北 / 江苏 一致**(都是 45 个),比老高考的 9 个志愿大幅放宽

### 港澳高校招生通道(广东特殊!!)

- **香港大学 / 香港中文大学 / 香港科技大学 / 澳门大学 等港澳高校在广东录取**
- **多数港校走"提前批 / 单独批次 / 自主面试"**,**不在普通本科批 45 个志愿内**
- 香港中文大学(深圳)、北师大-香港浸会联合国际学院(UIC)等**中外合作 / 内地分校**走普通批
- **港校认可度**:广东家长对港校特别看重,QS 世界大学排名 + 软科排名是参考依据
- **学费**:港校学费 12-20 万/年,4 年下来 50-80 万 + 生活费,**普通家庭慎报**
- **录取流程**:港大 / 港中文 / 港科大 用"6 月 30 日截止 + 7 月初面试"模式,**强制英语口语 + 综合素质**

### 中外合作办学组(广东特别多)

- **UIC(北师大-香港浸会联合国际学院,珠海)**
- **西交利物浦大学深圳分校**
- **昆山杜克大学**(虽不在广东但广东招生多)
- **温州肯恩大学**(虽不在广东)
- **中大 / 华工 中外合作组**(动辄 6-10 万/年学费)
- **广东以色列理工学院**(汕头)
- **特点**:学费贵、英语门槛高(部分要 BC 等级以上)、部分发双学位、不接受调剂入

### 投档与录取流程
1. 按位次投档:位次靠前的考生先选自己的 45 个志愿
2. 系统按 1-45 顺序检索投档:**第一个能投到的志愿组,投档**
3. 投档后,本志愿组内按专业最低分录取(如果没录取上具体专业,**服从调剂会被调到本组其他未录满专业**)
4. 不服从调剂 + 没录取上 → **退档,本批次落榜**(滑档)

### 一分一段表(广东位次)
- 高考结束后广东省教育考试院发布"一分一段表",**用于换算分数 ↔ 全省位次**
- **位次比分数更准**:不同年份卷子难度不同,但同样位次的考生水平相对稳定
- **报志愿应该看位次,不是看分数**(这是新手家长最常踩的坑)

### 广东批次线(2024 年参考)

| 类型 | 本科线 | 特殊类型招生控制线(特控线) |
|---|---|---|
| 物理类 | 442 分 | 539 分 |
| 历史类 | 428 分 | 543 分 |

(注:特控线 ≈ 一本线对标,一线 985 / 211 普遍要求超过特控线 30-80 分)

### 广东本省考生上 985 难度(关键!)

- **广东本省考生数量大(2024 年高考 75 万 +)**,985/211 招生比例严重失衡
- **中山大学**:物理类录取**省排前 6000 名**,历史类**前 1500 名**
- **华南理工**:物理类录取**省排前 1.5w 名**,历史类几乎不招(招生量极小)
- **暨南大学**(211):物理类**前 2-3w**,历史类**前 4000-6000**
- **华南师范**(211):物理类**前 3w**,历史类**前 5000-8000**
- **对比湖北 / 湖南**:广东本省 985 比例约 0.8%(湖北约 1.2%,湖南约 1.0%)— **广东上 985 难度全国前列**
- **结论**:广东中分考生(550-590)被强烈挤压向"双非顶级(深大 / 南科大 / 广工)"或"出省 211"

### 选科建议(同湖北)

- **想读医**:必选化学,**最稳是物 + 化 + 生**
- **想考公**:**必选政治**(警校 / 公安全部要求),**物 + 化 + 政** 或 **史 + 政 + 地**
- **大湾区互联网/工科**:物 + 化 + 生 / 物 + 化 + 地 都行,看具体院校要求
- **想留港澳 / 出国**:看目标港校要求,通常物 + 化 + X 或 史 + 政 + X 都接受

## 决策映射

| 考生情况 | 应该怎么选 |
|---|---|
| 物化生 / 物化地 | 几乎不限,可报理工医农林全部专业,**最佳选择** |
| 物化政 | 理工 + 考公友好,**平衡型** |
| 史政地 | 文史考公主流路径,**文科生首选** |
| 想读临床医学 | **必选化学(部分院校还要生物)**,中大医学院 / 南医大 / 广医大 一定要确认 |
| 想读师范 | 选你想教的学科对应的科目(教数学就选物理,教语文就史政地) |
| 想报警察 / 公安 | **必选政治**(几乎所有公安院校要求) |
| 想冲港澳高校 | 物 + 化 + X 或 史 + 政 + X 普遍接受 + 英语必须强 |
| 想读地质 / 地理 | 必选地理 |

## 典型 case(供 agent 引用)

- **Case A(选科正确)**:广州考生,物 + 化 + 生,**620 分进中大临床医学**,选科组合允许她报临床医学
- **Case B(选科踩坑)**:深圳考生选物 + 政 + 地。高三时想报临床医学发现**无法报考**(必须再选化学)。**只能改报其他专业,留下遗憾**
- **Case C(选科聪明)**:佛山考生选物 + 化 + 政。高三同时保留了**理工(化学)+ 考公(政治)+ 警察(政治)** 三条出路,**选科最灵活**
- **Case D(填报踩坑)**:广州考生 590 分物理类。把华工某专业组放第 1 志愿,但**没看清楚组内最低分专业是"轻工业"**。被投档后,**被调剂到食品包装方向**,大学 4 年后悔
- **Case E(港校认知误区)**:深圳考生 650 分,坚持要冲港大,**但忘了港大学费一年 17 万 + 生活费**,普通家庭根本撑不起,最后还是回填中大 / 华工

## 易错认知(agent 要纠正用户的)

- "**还是按文科 / 理科算的吧**" — 严重过时。广东 2021 年起就没文理分科了,**只有物理类和历史类**
- "**3+1+2 跟老高考差不多,只是叫法不同**" — 错。**录取规则不同,投档单位不同,服从调剂规则不同**
- "**45 个志愿都是学校,选哪个学校都行**" — 严重错误。**45 个志愿是 45 个"院校专业组",同一学校可能占多个志愿位**。中大 / 华工 在广东物理类各占 5-10 个志愿位
- "**服从调剂会被调到本校其他专业**" — 错。**只在本专业组内调剂**,不会跨组
- "**港校就是港大 / 港中文,直接填普通批**" — 半错。**多数港校走提前批 + 自主面试**,不在 45 志愿内
- "**广东孩子上 985 容易**" — 严重错。**广东本省 985 比例全国排名靠后**,中大物理类要省排前 6000 名,跟一线省份难度持平
- "**深大是双非,不如 211**" — 错。**深大物理类录取分接近 211 中段**,留深圳就业生态全国独家
- "**新高考赋分对孩子有利 / 不利**" — 都对。**赋分对相对成绩好的有利,对相对成绩差的不利**(因为是按全省排名转换)
- "**孩子分数 580,看哪些 580 能上的学校就行了**" — 错。**应该看 580 对应的全省位次,然后看历年这个位次能上哪些学校**

## 关键提醒(agent 必须强调)

**新高考最容易被忽视的事实**:
1. **45 个志愿组的填报顺序**很重要,要"冲稳保"梯度排列
2. **服从调剂**通常推荐勾选(不勾就有滑档风险),**但要确认本专业组内你能接受的最差专业**
3. **看位次而不是分数**(分数受当年卷子难度影响很大)
4. **再选科目限制**(必选化学/必选政治等)是硬约束,**填报前一定核对每个目标专业**
5. **广东特有:中外合作 / 高收费组单独成组**,看清楚学费(动辄 6-12 万/年),普通家庭慎报
6. **港澳高校单独批次**,要早做功课,英语口语 + 综合素质面试 是硬门槛

**新高考的"院校专业组"机制让填报变得更精细,也更容易踩坑**。**广东家长的额外难题是"中大/华工 都拆成多组,选哪个组对位次精度要求极高"**,选错组可能差几十名位次。这正是 agent 价值的核心 —— 把这些规则用通俗话讲明白。
