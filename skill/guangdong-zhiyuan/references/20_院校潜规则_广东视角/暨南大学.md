# 暨南大学(暨大,JNU)— 211 综合 + 华侨高校

## 一句话定位

**全国唯一华侨高校**,211 综合,**新闻传播全国前 5 / 经济学 / 法学 / 临床医学** 强势,广州番禺 + 五山 + 珠海三校区,**港澳生源 30%+,氛围国际化**。**广东学新闻 / 经管 / 港澳通道方向首选 211**。

---

## 真实地位

- **全国 211 综合排名 Top 30 211**,**南方报业 / 央视华南 / 华南金融机构 / 港澳中资企业** 主流来源。
- **广东本省地位**:广东 211 录取分**仅次于中大华工**,**新闻传播 / 经济学 / 法学 / 工商管理** 在大湾区认可度极高(部分专业组分数压外省末段 985)。
- **同档对比**:类似武汉中南财法的地位 —— 211 但行业认可度顶级 + 港澳通道独家。
- **华侨高校定位**:港澳台 + 海外华侨学生占 30%+,**氛围多元(粤语 + 普通话 + 英语混杂)**,留学 / 港澳就业通道独家。

---

## 广东物理类录取位次区间

参考近 5 年掌上高考 + 广东一分一段表:

- **顶级组(临床医学 / 王牌经管 / 法学 / 新闻传播)**:全省 **6,000-12,000 名**。
- **主流组(工商管理 / 国贸 / 中文 / 经济类)**:全省 **12,000-20,000 名**。
- **冷门组(部分工科 / 一般文理 / 珠海校区)**:全省 **20,000-30,000 名**。

**段位定位**:广东物理类 **省排 3w 名内可冲暨大**,2w 名内挑专业,**1.2w 名内可冲王牌组**。**以一分一段表反查为准**。

## 广东历史类录取位次区间

历史类是暨大主战场,**新闻传播 / 法学 / 经济学** 招生量大,全省 **1,000-3,500 名**。

| **经济学 / 国际经济与贸易** | A 强势 | 大湾区贸易 / 港澳金融 / 招商 / 平安 / 中国银行港澳 |

## 性价比专业(同样暨大牌子,录取相对低)

- **临床医学(5+3)**:**暨大附一院在天河**(地理位置极好),**录取分比中山医低一档**,适合分数不够中山医但想做医生的考生。
- **生物医学工程 / 药学**:大湾区医疗科技产业链对口,**行业景气度高于纯生物**。
- **珠海校区组(中文 / 历史 / 经济 等)**:**录取分比本部低 5,000+ 名**,适合分数中段但想要 211 + 港澳氛围的考生。

## 坑专业 / 慎选(在暨大里相对弱)

- **工科核心(机械 / 电气 / 自动化 / 土木 / 材料)**:暨大工科边缘,**学硬工科直接选华工 / 广工**。
- **农林相关**:暨大不是农业强校,**学农林选华农**。
- **能源 / 矿业 / 环境**:边缘冷门,行业出口窄。
- **行政管理 / 公共事业管理**:文科非王牌,**毕业改行考公率高**。
- **独立学院 / 番禺学院方向**:跟暨大本部牌子有差,**勾报志愿前看清楚是不是本部**。

## 关键提醒(填报陷阱)

1. **暨大有三个校区**:**石牌(五山)校区(老校区,本科生主流)** / **番禺校区(新校区,部分本科 + 研究生)** / **珠海校区(部分专业 + 港澳氛围最浓)**。**报志愿前看清楚专业归属哪个校区** —— 番禺校区在番禺远郊,珠海校区在珠海湾仔。
2. **港澳生比例高,氛围独特**:**部分课程粤语普及度高**(虽然全部官方授课用普通话),**听不懂粤语的外省考生可能稍有适应期**(广东本地生没问题)。
3. **新闻传播是暨大最大亮点**,**录取分压中大新闻**,但**新闻行业整体凋零**——做好"毕业改行 / 自媒体 / 互联网 PR / 考公"的心理预期。
4. **服从调剂注意**:专业组内可能含暨大非王牌专业(如部分工科 / 行政管理),**勾服从前查清组内有什么**。
5. **暨大 vs 华师 vs 广外**:学新闻 / 经管 / 法 / 港澳通道 → 暨大;学师范 / 心理学 / 当老师 → 华师;**学外语 / 国贸 / 翻译** → 广外(广东外语外贸大学,双非但语言类强势)。
6. **港澳生录取通道独立**:本地生跟港澳生分开招,本地高考考生不享受港澳生优惠。

## 毕业出口(2024 数据)

- **留广东就业**:约 60-65%(广州 30-35% / 深圳 20-25% / 港澳 5-8%)— **广东 + 港澳合计 70%+**
- **留深圳具体**:约 18-22%(深圳互联网 / 招商 / 平安)
- **去港澳**:约 8-12%(**全国大学最高比例之一**,港澳实习 + 跨境就业通道)
- **出省(上海/北京)**:约 10-15%
- **考研 / 出国**:约 30-35%(**出国比例高,港澳深造尤其容易**)
- **保研率**:约 12-15%(211 中段)
- **进央企概率**:约 15-20%(中国银行港澳 / 中海外港澳 / 招商系)
- **起薪范围**:新闻传播 12-18w(行业过冬),CS / 金融 18-30w,临床医学规培 8-12w,法学律所 15-25w,文科考公编制 10-15w。

## 适合谁

- 广东物理类 **省排 3w 名内** / 历史类 **3,500 名内** 的考生。
- **学新闻 / 经管 / 法学 / 国际经贸 / 临床医学** 任一方向(暨大王牌)。
- **想去港澳工作 / 跟港澳家人方向 / 港澳实习** → 暨大独家通道。
- **想出国 + 211 牌子** → 暨大留学率高(港澳深造容易)。
- 多元文化适应力强 + 想接触港澳台同学 + 不介意校区分散。
- 想留广州天河 + 进南方报业系 + 大湾区金融 → 暨大对口。

## 不适合谁

- **铁了心要学硬工科 / 学医顶级** → 暨大工科一般、医学第二档,不如华工 / 中大。
- **想做老师 + 进广东编制** → 选华师(暨大教育学院弱)。
- **必须出省冲北上深就业 + 不在意 985 牌子** → 暨大牌子在出省竞争中弱于中大华工。
- **不喜欢多元 / 嘈杂校园氛围**(港澳台生 + 海外华侨混杂) → 暨大不是安静的纯本地校。
- 笃定要做农林 / 兽医 / 食品 → 选华农 / 华工。
