# 深圳大学(深大,SZU)— 双非但深圳本土巨头

## 一句话定位

**深圳本土超级 IP**,双非但**腾讯马化腾 / 平安马明哲 / 华为早期员工**母校,**深圳就业生态王者**,**计算机 / 光电 / 工商管理 / 建筑** 强势,**留深圳就业 + 进腾讯 / 平安 / 华为 / 大疆校招碾压一般 985**。**广东留深圳就业的双非首选**。

---

## 真实地位

- **双非但深圳本土超级 IP**,**部分专业组分数压外省末段 985 + 普通 211**(物理类省排前 1.5w-2w 名)。
- **广东本省地位**:**深圳考生留深圳就业的天选**,**广州考生想留深圳的优选**,深大本地家长口碑炸裂。
- **同档对比**:**类似武汉的"武汉大学双非分支"(虚构)、上海的上海大学**——双非但本土生态 + 财政重金 + 校友资源加持。**深圳财政持续投入 + 校园基建国际化**,部分专业实质碾压一般 211。
- **校友网络恐怖**:**腾讯系 / 平安系 / 华为系 / 万科系 / 招商系 / 中兴系 大半早期高管来自深大**,深圳科技 + 金融行业校友资源堪比清北复交。
- 男女比平衡 + 校园在深圳南山区 + **本地学生比例高(30%+)**。

---

## 为什么双非分这么高?(深圳本土 + 深圳财政 + 校友 + 就业生态)

1. **深圳财政持续重金投入**:从校园(南山区核心地段,海景校区)到师资(挖了一票海归院士),教育经费全国双非顶配。
2. **腾讯 / 平安 / 华为 / 招商 / 万科 校友资源恐怖**:深圳本地大厂校招把深大列为"重点合作校"(权重高于外省末段 985)。
3. **留深圳就业生态独家**:**毕业留深圳 80%+** —— 深圳互联网 / 金融 / 半导体校招深大本地生有"主场优势"。
4. **新办医学院(2008 建)**:**深大医学院在追赶**,深大附属第一医院 / 第三医院已具备规模。
5. **深圳本地家长口碑**:**深圳本地中产家长心目中"分数够末段 985 也愿意选深大留深圳"** —— 这是"深圳特色家长心态"独家现象。

---

## 广东物理类录取位次区间

参考近 5 年广东一分一段表反查:

- **顶级组(计算机 / 金融 / 临床医学 / 建筑)**:全省 **1.2w-1.8w 名**(**接近末段 211**)。
- **主流组(光电 / 电子信息 / 工商管理 / 经济类)**:全省 **1.8w-3w 名**。
- **冷门组(传统工科 / 部分文理)**:全省 **3w-5w 名**。

**段位定位**:广东物理类 **省排 5w 名内可冲深大**,3w 名内挑专业,**1.8w 名内可冲王牌组**。**以一分一段表反查为准**。

## 广东历史类录取位次区间

历史类招生量小(主要法学 / 经管 / 中文),全省 **3,000-8,000 名**。**深大历史类不强,不是首选**。

## 性价比专业(同样深大牌子,录取相对低)

- **设计学(产品设计 / 视觉传达 / 交互设计)**:**腾讯 / 华为 / 大疆 UI 设计师对口**,**深圳互联网设计岗起薪 25w+**,行业景气度高。
- **金融学 + CS 双学位 / 微专业**:深大近年推"金融 + 科技复合人才",**对接深圳金融科技 + 量化** 行业。
- **建筑学**:**深圳建筑设计行业本地校认可度极高**,虽行业过冬但深大毕业生在深圳本地竞争力强。
- **新闻传播 + 互联网**:深圳互联网 PR / 内容运营,起薪 18-25w。

## 坑专业 / 慎选(在深大里相对弱)

- **传统工科(土木 / 机械 / 化工 / 材料)**:**深大工科除 CS / 光电外不强**,**学硬工科直接选华工 / 广工**。
- **农林相关 / 食品**:**深大没农林学院**,选华农。
- **医学(本科直接就业)**:**深大医学院新办,医院资源在追赶但不如中山医 / 南医大**;**学医优先选老牌医学院**;**笃定深圳生活的中段考生 + 接受新办校 + 想做医生** 才适合深大医学院。
- **行政管理 / 公共事业管理**:文科非王牌,毕业改行率高。
- **历史类专业**:深大历史类不强,**学历史类选中大 / 暨大**。

## 关键提醒(填报陷阱)

1. **深大有两个校区**:**粤海校区(老校区,本科生主流,深圳南山区核心地段)** / **丽湖校区(新校区,部分本科 + 研究生,西丽地铁可达)**。**报志愿前看清楚专业归属哪个校区** —— 粤海校区在地铁科苑站(腾讯总部隔壁),丽湖校区在西丽湖。
2. **物理类专业组分化大**:王牌组(CS / 金融 / 建筑)与冷门组(传统工科)录取位次差 1w+ 名,**勾服从前查清组内有什么**。
3. **深大牌子的"地理依赖"**:**留深圳就业碾压一般 985**,**但出深圳出广东就业认可度低于 211**(校招筛简历看名字)。**笃定要出广东就业的考生 + 想要 985 牌子 → 深大牌子吃亏**。
4. **深大医学院新办**:**5+3 一体化在 2018 后开设**,医院资源在追赶,**笃定走医的中段考生有顾虑可选南医大或暨大医**。
5. **服从调剂注意**:专业组内可能含传统工科 / 行政管理等弱专业,**勾服从前预想最差专业能否接受**。
6. **深大 vs 南科大 vs 哈工大(深圳)**:
   - **深大**:留深圳就业最直接 + 大厂校友最多 + 学费低
   - **南科大**:科研顶级 + 直博出国 + 综合评价录取
   - **哈工大(深圳)**:985 真牌子 + 工科顶级 + 学费普通
   **三选一看追求**:**留深圳就业稳定** → 深大;**搞科研 + 出国** → 南科大;**985 牌子 + 留深圳** → 哈工大(深圳)。

## 毕业出口(2024 数据)

- **留深圳就业**:**约 75-80%**(**全国大学留深圳率最高**,腾讯 / 华为 / 平安 / 大疆 / 招商 / 万科 / 中兴 / OPPO 等深圳总部主流来源)
- **进腾讯具体**:**深大本地生在腾讯校招占比仅次于清北华科**(深大校友 + 本地优势)
- **留广东其他(广州 / 佛山东莞)**:约 8-12%
- **去港澳**:约 3-5%(港大 / 港中文研究生 + 香港金融)
- **出省(上海 / 北京)**:约 5-8%
- **保研 / 考研 / 出国**:约 25-30%(保研率 ~10-12%,部分专业出国率高)
- **进央企 / 国企**:约 12-18%(招商系 / 平安系 / 中国移动深圳)
- **起薪范围**:CS / 金融 25-40w(深圳大厂顶级 30-50w),光电 / 电子 18-30w,建筑学 12-20w(行业过冬),设计学 18-30w(互联网 UI),临床医学规培 8-12w,法学律所 15-25w。

| 维度 | 深大 | 南科大 | 哈工大(深圳) | 暨大 |
|---|---|---|---|---|
| 牌子 | **双非(深圳本土王)** | 双非(科研顶级) | **985(老牌工科)** | **211(综合)** |

## 适合谁

- 广东物理类 **省排 5w 名内** + **想留深圳就业**的考生。
- **深圳本地考生** + 不愿出广东 + 父母希望孩子留深圳就业 → 深大天选。
- **想进腾讯 / 华为 / 平安 / 大疆 / 招商 / 万科 等深圳大厂** + 不在意双非牌子。
- 学**计算机 / 光电 / 金融 / 建筑 / 设计** 任一深圳对口方向。
- 普通工薪家庭 + 想留深圳就业 + 学费低(深大学费 5000/年,极便宜) + 起薪高 → 性价比之王。
- 不想搞科研 / 不想出国 / 想本科直接就业出活的考生。

## 不适合谁

- **想出广东就业 / 出省北上就业** → 深大牌子在出省竞争中吃亏,选 211(暨大 / 华师)或末段 985 更稳。
- **想搞科研 / 想直博 / 想出国** → 选南科大(深圳本地科研顶级)。
- **想要 985 牌子 + 留深圳** → 选哈工大(深圳)/ 中大深圳校区。
- **学硬工科核心(机械 / 化工 / 土木)** → 选华工 / 广工(深大硬工科一般)。
- **学文科 / 哲学 / 历史 / 师范** → 深大文科一般,选中大 / 暨大 / 华师。
- 笃定要做老师 → 选华师。

## 大小年与位次趋势(广东视角)

- **2021-2023 趋势**:深大 CS / 软工 位次连年上涨(全省 1.8w 名涨到 1.2w 名,**追平外省末段 985**);**金融 / 经济 位次稳定**;**临床医学位次跟随医院资源建设缓慢上涨**。
- **2024 实况**:**深大 CS / 金融 位次首次"压过部分末段 985"**(因深圳互联网招聘扩张 + 校友资源加持);**设计学位次涨**(深圳互联网 UI 设计师起薪压一些 211)
- **2025-2026 预判**:**CS / 金融 / 设计 位次会继续高位**;**深大医学院 + 深大附院**资源持续扩张,**临床医学位次会继续涨**;**冷门组(传统工科)是性价比洼地**。
- **大小年现象**:**深大冷门组(土木 / 化工 / 行政管理)每 2 年有一次"分数雪崩"**,适合分数 4w 名外但坚持要留深圳的考生抄底,**但要做好"被调剂到弱专业"的心理准备**。

## 留省内 vs 出省的 5 年路径对比

### 留省内(深圳为主) — 主流路径(80%+)
- **深圳大厂校招直供**:深大 CS = 腾讯 / 华为 / 大疆 / 平安 / 招商 校招主流;深大金融 = 招商 / 平安 / 中信深圳校招主流;深大设计 = 腾讯 / 华为 / OPPO UI 设计师对口
- **校友资源密度恐怖**:**腾讯系 / 平安系 / 华为系 / 万科系 / 招商系 / 中兴系 大半早期高管来自深大**,深圳科技 + 金融行业校友资源堪比清北复交
- **物理半径短 + 实习便利**:粤海校区在腾讯总部隔壁(地铁科苑站),**深大 CS 学生实习腾讯 / 字节深圳是常态**
- 5 年后典型路径:腾讯 P5-P6 / 华为 14 级 / 招商总行管培 / 深圳建筑设计院助理建筑师 / 深大附院主治

### 出省(主要去上海 / 北京) — 极少(5-8%)
- **挑战**:**深大牌子在出省竞争中吃亏**(校招筛简历看名字),双非身份要被多次证明
- **优势**:**腾讯 / 华为 / 平安 内部转岗**(深大校友进深圳总部后转岗到上海北京分公司)是隐藏路径
- 5 年后典型路径:腾讯上海分公司中层 / 华为北研所工程师 / 招商上海分行中层

### 出国 / 港澳
- **约 8-12%**(主要去港大 / 港中文 / NUS 研究生 + 美国 CS / 金融硕士)
- **港岛中资金融 + 深圳跨境业务** = 主流出口
