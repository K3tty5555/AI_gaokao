# 华南师范大学(华师,SCNU)— 211 师范第一档

## 一句话定位

**广东师范第一**,211 师范,跟北师大 / 华中师大 / 东北师大同档,**心理学全国前 5 / 教育学全国前 10**,**广东中学校长 / 名师 / 教育系统主流来源**,广州石牌 + 大学城 + 南海三校区。**广东想做老师就业首选 211**。

---

## 真实地位

- **全国 211 排名 Top 30 211 师范类**,**心理学 / 教育学 / 体育学 / 数学物理(师范类)** 全国前列。
- **广东本省地位**:**广东师范第一**,广东省直 + 各市公立中学校招把华师列为重点合作校,**广东编制路径最直**。
- **同档对比**:**师范专业** 跟北师大 / 华中师大 / 东北师大 同档,但**非师范专业弱于同档 211**。
- 教育部六大直属师范大学不含华师(北师大 / 华东师大 / 东北师大 / 华中师大 / 西南师大 / 陕西师大),但华师是省级公费师范生 + 广东师资网络垄断校。

---

## 广东物理类录取位次区间

参考近 5 年掌上高考 + 广东一分一段表:

- **顶级组(心理学 / 师范类公费 / 数学物理师范)**:全省 **8,000-15,000 名**。
- **主流组(各类师范 / 教育学 / 经管 / 文科)**:全省 **15,000-25,000 名**。
- **冷门组(非师范理工 / 部分文科 / 南海校区)**:全省 **25,000-40,000 名**。

**段位定位**:广东物理类 **省排 4w 名内可冲华师**,2.5w 名内挑专业,**1.5w 名内可冲王牌师范组**。**以一分一段表反查为准**。

## 广东历史类录取位次区间

历史类是华师强项,**师范类 / 中文 / 历史 / 教育学** 招生量大,全省 **2,500-6,000 名**。

## 性价比专业(同样华师牌子,录取相对低)

- **公费师范生(省级)**:**广东省直公费师范生名额**,毕业回户籍地中学任教 + 编制保底,**录取分比同等师范低 5-15 分**,适合家境普通 + 想稳定。
- **马克思主义理论 / 思想政治教育(师范)**:**广东选调路径 + 中学政治老师**,录取分相对低。
- **南海校区组(部分专业)**:**录取分比本部低 5,000+ 名**,但南海校区地理偏(佛山南海),**学费 / 校园体验有差**,适合想要 211 牌子但分数有限。
- **学前教育 / 特殊教育**:行业新兴 + 大湾区民办教育产业 + 国际幼儿园对口。

## 坑专业 / 慎选(在华师里相对弱)

- **非师范类工科(机械 / 电气 / 自动化 / 计算机非师范)**:华师工科边缘,**学硬工科直接选华工 / 广工**。
- **非师范类经管(金融 / 工商管理 / 国贸)**:**不如暨大 / 中大经管**,毕业找工作华师牌子在金融行业不如暨大。
- **非师范类法学**:**不如中大法学院**,法学就业华师牌子吃亏。
- **生物科学 / 化学 / 物理(非师范纯理)**:生化环材天坑,**师范方向反而出路更稳**。
- **新闻传播**:**不如暨大新闻**,毕业改行率高。

## 关键提醒(填报陷阱)

1. **华师有三个校区**:**石牌校区(老校区,广州天河,本科生主流)** / **大学城校区(广州番禺,部分本科 + 研究生)** / **南海校区(佛山南海,部分专业,地理偏)**。**报志愿前看清楚专业归属哪个校区**。
2. **师范 vs 非师范务必分清**:**华师只有"师范类"专业是顶级**,**非师范"理工经管文"专业在华师是次牌子**。**如果不想做老师,在华师学非师范是浪费 211 牌子**——同样 211 牌子选暨大经管 / 中大法学性价比更高。
3. **公费师范生(省级)绑定就业** :**毕业必须回户籍地教 6 年**,违约要赔钱 + 影响档案。**家庭普通 + 想稳定 + 接受小城市教书** 才适合。
4. **教师编制竞争激烈**:广州深圳重点中学编制竞争"卷出天际",**华师本科考广州外国语学校 / 深圳中学等顶级校老师编也不容易**,**心理预期要分清"编制 vs 顶级中学"**。
5. **服从调剂注意**:专业组内可能含华师弱专业(部分工科 / 非师范经管),**勾服从前查清组内有什么**。
6. **华师 vs 北师大 vs 华中师大**:**广东本省考分 + 想留广东就业 + 想做老师** → 华师最对口;**分够北师大 / 华中师大 + 想去外省名校** → 老牌教育部直属师范牌子更硬。

## 毕业出口(2024 数据)

- **留广东就业**:约 70%+(广州 30-35% / 深圳 15-20% / 佛山东莞 + 其他广东市 20-25%)— **广东师范生留粤主导,广东编制路径明确**
- **进入教育系统**:约 50-55%(公立中小学 / 民办名校 / 教育部门 / 培训机构,**师范类专业 70%+ 进教育系统**)
- **留深圳具体**:约 15-20%(深圳教师编制 + 互联网 HR / 用户研究)
- **去港澳**:约 2-3%(港澳教学 / 国际学校)
- **出省**:约 8-12%
- **考研 / 出国**:约 25-30%(保研率 ~12-15%)
- **进央企 / 国企**:约 8-12%
- **起薪范围**:广深公办教师 12-25w(深圳头部中学起薪 30w+),广东其他市 8-15w + 编制,心理学进互联网 HR 18-25w,非师范经管文 10-15w。

## 同档对比

| 维度 | 华师 | 暨大 | 北师大 | 华中师大 |
|---|---|---|---|---|
| 综合排名 | 211(师范) | 211(综合) | 985(师范) | 211(师范) |
| 师范类 | **强(广东第一)** | 弱 | **更强(全国第一)** | **强(同档)** |
| 心理学 | **A 全国前 5** | 弱 | **A+ 全国第一** | A |
| 教育学 | A 全国前 10 | 弱 | **A+ 全国第一** | A |
| 非师范经管 | 弱 | **强** | 中 | 中 |
| 体育学 | **强(华南)** | 弱 | 中 | 中 |
| 留粤 + 教师编制 | **极易(广东主战场)** | 中 | 出广东要竞争 | 出湖北要竞争 |

**简单结论**:**广东想做老师 + 留粤 + 进编制 → 华师最对口;不想做老师在华师是浪费 → 选暨大或中大;分够北师大 + 想出省 → 北师大更硬牌**。

## 适合谁

- 广东物理类 **省排 4w 名内** / 历史类 **6,000 名内** 的考生。
- **铁了心想做老师 + 留广东进编制**(华师是广东师范天选)。
- **想读心理学**(华师心理学全国前 5,跨学科可走 HR / 用户研究 / 心理咨询师 等大湾区路径)。
- 想做体育老师 / 体育产业(华师体育学华南龙头)。
- 普通工薪家庭 + 想稳定 + 接受教书职业 → 公费师范生 + 编制路径。
- 学马克思主义理论 / 思政 + 走选调路径。

## 不适合谁

- **不想做老师 + 想学经管法 / 工科** → **不要来华师**,在这里学非师范是浪费 211 牌子,选暨大 / 中大 / 华工对口。
- **铁了心要学硬工科 / 学医** → 选华工 / 中大 / 南医大。
- **想冲北上深互联网大厂 / 金融** → 华师非师范牌子在大厂校招吃亏。
- **不愿意当老师但又想要 211 牌子** → **慎选**,华师除师范 / 心理学外几乎没有"独有招牌"。
