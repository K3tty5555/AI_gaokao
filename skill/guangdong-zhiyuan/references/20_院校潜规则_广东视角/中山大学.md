# 中山大学(中大,SYSU)— 综合性 985 第一档

## 一句话定位

**广东本省"心理上限"高校**,综合排名 Top 10-15 985,文/理/医/法/经管全能,**广东文科理科第一首选**,广州 + 珠海 + 深圳三校区,大湾区医生/律师/金融/选调主流来源。

---

## 真实地位

- **全国排名 Top 10-15 985**,跟南大武大同档,**华南综合性高校天花板**,C9 之外的综合性顶级。
- **广东本省地位**:广东物理类省排前 6,000 内 + 历史类省排前 800 内的天花板,本省录取分压复旦交大同济(广东人优先留粤心态)。
- **同档对比**:文/理/医/法/经管全面强于华工,工科明显不如华工,医学(中山医)是华南医学顶级。
- 广东家长心目中"读完出来体面 + 广深就业不愁 + 大湾区医院律所选调有指标"的代名词。

---

## 广东物理类录取位次区间

参考近 5 年掌上高考 + 广东一分一段表反查:

- **顶级组(临床医学八年制 / 中山医 / 岭南经管法 / CS)**:全省 **前 800-2,500 名**。
- **主流组(理工类 / 文科类 / 一般经管)**:全省 **2,500-4,500 名**。
- **深圳校区组(医学 / 微电子 / 材料新工科)**:全省 **3,500-5,500 名**(深圳校区分数年年涨,逐渐追平本部冷门组)。
- **珠海校区组(海洋 / 大气 / 旅游 / 中法核工)**:全省 **4,500-6,500 名**(珠海校区分数最低,**性价比组**)。

**段位定位**:广东物理类 **想冲中大基本要省排 6,500 名内**,2,500 名内可挑王牌专业,800 名内任选。**具体分数以当年一分一段表反查为准**。

## 广东历史类录取位次区间

- 主流文科组(中文 / 历史 / 哲学 / 法学 / 经管):全省 **前 200-700 名**。
- 历史类压复旦,**800 名外基本无戏**;珠海校区文科组可放宽到 1,000 名。

## 性价比专业(同样中大牌子,录取相对低)

- **珠海校区组(海洋 / 大气 / 旅游 / 中法核工程)**:全国第 1/前 5 学科,但珠海地理"偏"印象拉低录取分,**位次比本部低 2,000+**,适合学术或想留珠海。
- **哲学 / 历史学 / 古文字学**:广东文科考公选调路径,**中大文科牌子在广东体制内极硬**。
- **海洋科学 / 大气科学**:全国前 5 但行业冷门,适合喜欢学术 + 不在意就业广度。

## 坑专业 / 慎选(在中大里相对弱)

- **纯工科核心(机械 / 自动化 / 土木 / 材料)**:**中大工科不如华工**,大湾区制造业校招进华工更顺,**这些专业直接选华工**。
- **农学 / 林学**:仅作存在,不是中大顶级方向,**学农林选华农**。
- **生物科学 / 生物工程 / 化学(纯理学)**:生化环材天坑组合,**中大牌子救不了"必须读博"的现实**。
- **新闻传播 / 行政管理**:行业凋零,中大新闻不如暨大 / 复旦 / 人大,**毕业大量改行考公**。

## 关键提醒(填报陷阱)

1. **三校区分数差距大**:广州校区(南/北/东) > 深圳校区(医工 / 新工科) > 珠海校区(海洋 / 大气 / 旅游)。**校区不同,体验完全不同**:广州校区中山纪念碑老校区氛围,深圳校区新建工地感重,珠海校区偏远但风景好。**报志愿前先想清楚四年要在哪过**。
2. **物理类专业组多达 8-10 个**,顶级组(经管法 / 临床)与冷门组(海洋 / 大气)录取位次差 4,000+ 名。**勾服从调剂前查清组内有什么**——如理工实验班可能含化学/生物/材料,被调剂未必接受。
3. **中山医 vs 南方医科 vs 暨大医**:中山医顶级三甲资源最强,但**临床八年制录取分压清华上交医**;**分数够中山医临床八年制就别在南医大将就**;**笃定走医的中段考生,南方医科大临床全国排名靠前(双非但医院资源强)**。
4. **中大 vs 华工 vs 港中文(深圳)**:学医/文/法/经管选中大;学工科/建筑选华工;**分够港中文(深圳)且家庭撑得起 + 想国际化** → 港中深也是替代选项(但学费一年 12-15w)。
5. **强基计划(数学 / 物理 / 化学 / 生物 / 哲学)**:本科直博 + 不能转专业,适合学术苗子,**比裸分低 5-15 分进中大**。

## 毕业出口(2024 数据)

- **留广东就业**:约 50-55%(广州 30%+ / 深圳 20%+ / 珠海 + 佛山东莞 5-8%)— **广东考生留粤主导**
- **留深圳具体**:约 20-25%(腾讯 / 华为 / 平安 / 招商 / 中国平安总部就在深圳)
- **去港澳**:约 5-8%(港大 / 港中文研究生 + 香港金融业 + 澳门博彩 / 政府)
- **出省(上海/北京)**:约 15-20%(上海金融 / 北京央企)
- **保研 / 考研 / 读博**:约 45-50%(中大保研率 ~25-28%,985 中段水平)
- **出国**:约 10-15%
- **考公 / 选调**:约 10-15%(中大有省级选调指标,广东省直 / 大湾区公务员主流来源)
- **起薪范围**:CS / 金融 25-40w,中山医临床(规培期)8-15w 但长期顶级,法学律所 15-30w,文科考公编制 12-18w。

## 适合谁

- 广东物理类 **省排 6,500 名内** / 历史类 **800 名内** 的考生。
- 学**医学 / 法学 / 经管金融 / 文史哲 / 基础学科** 任一方向。
- **想留广州 / 深圳 / 珠海**(本地家庭 + 不愿出省)。
- 中产以上家庭 + 鼓励读研读博 + 重视综合性体验 → 中大老牌氛围最合适。
- 想做医生 / 律师 / 选调 / 大湾区金融人 → 中大是广东对口校。

## 不适合谁

- **铁了心要学顶级工科**(机械 / 电气 / 建筑) → 选华工更对口。
- **想做新闻传播 / 港澳通道方向** → 选暨大。
- **想做老师** → 选华师(广东编制路径)。
- **笃定要进腾讯 / 华为校招 + 分数刚够中大冷门组** → 不如稳深大 CS(留深圳就业生态更直接)。
- 想做农林 / 食品 / 兽医 → 选华农。
