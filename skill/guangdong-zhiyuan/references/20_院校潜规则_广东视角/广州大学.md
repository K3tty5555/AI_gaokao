# 广州大学 — 广州本地就业通行证，出省即折半

## 一句话定位

**广州市属重点双非高校**，广州本地政府机关 + 教育系统 + 国企认可度高，**师范 / 网络安全 / 土木（本地）有竞争力**，出广州后竞争力断崖式下跌，适合打定主意留广州就业的考生。

---

## 广东物理类录取位次分布（实测）

| 年份 | 位次范围（物理类） | 分数范围 | 备注 |
|---|---|---|---|
| 2024 | 39,000–95,000 | 532–562 | 最低组为土建类专业组，最高组为地理类 |
| 2023 | 39,000–213,265 | 453–609 | 土建类 2023 年爆冷跌穿二本线，最低仅 453 |
| 2022 | 42,000–65,000（估算） | 557–573 | 物理类最低位次约 42,138，分散度较小 |

**段位定位**：广东物理类省排 **4w–10w 名**，主流专业组约 **5.5w–7w 名**，属典型中档双非区间。

> 大小年特征：土建类（土木 / 建筑 / 城规）出现明显大小年——2023 年土建组最低分仅 453 分（位次超 21w），是全校最大波动组；CS / 网络安全 / 师范类相对稳定。**利用土建大年抄底不推荐**，行业持续下行，进去了也难受。

## 王牌专业（行业地位）

| 专业 | 评估/排名 | 行业地位 | 备注 |
|---|---|---|---|
| **网络空间安全** | 国家一流专业，软科前 10 | 华南地区网安人才供应校 | 广州本地互联网 / 政务安全对口 |
| **数学与应用数学** | 国家一流专业 | 精算 / 数据分析 | 广州金融 / 保险入职认可 |
| **教育学 / 心理学** | 省级重点 | 广州市教师编 | 广州公立学校招聘认可度高 |
| **应用心理学** | 软科 A 级 | 广东省心理卫生领域 | 广州本地心理咨询认可度高 |
| **新闻传播 / 广播电视学** | 省级特色 | 广州媒体圈 | 广州电视台主持人历史占比 40%+ |
| **土木工程** | 省级重点 | 广东省内建筑设计院 | 行业过冬，但广州本地认可度尚可 |

## 性价比专业

- **网络空间安全**：广州本地政务网安 + 互联网甲方安全岗，同档双非里录取位次中等但出路相对好，广州公司对广大网安接受度高。
- **数学与应用数学（精算方向）**：广州本地金融 / 保险 / 精算师通道，广大数学专业考研上岸概率较其他双非高，考研目标校可到中山大学、华南理工。
- **应用心理学**：广州高校对广大心理系认可，考编 + 进学校心理中心是稳妥出路。

## 坑专业（配理由）

- **土木工程 / 建筑学 / 城乡规划**：行业深度调整，2023 年爆冷证明市场已不认账；双非土建毕业找到好设计院 or 施工单位越来越难，工资压缩严重，延毕风险高（建筑学 5 年）；**除非笃定广州本地施工 / 设计小院方向，否则强烈慎选**。
- **行政管理 / 工商管理**：广州双非管理类学生毕业即"全市场竞争"，广大牌子无法对抗暨大 / 华工 211 身份；考公上岸率有限，进外企或大厂竞争力弱。
- **法学**：广大法学缺乏律所 / 大厂校招绑定，广州法律圈认可度中等，考研上岸竞争激烈（广大、暨大法考研内卷）；有意学法直接冲暨大更划算。
- **历史学 / 汉语言文学（非师范方向）**：广大文科培养体量大，但非师范方向出口窄，广州市场这类岗位认可中大 / 暨大 > 广大。

## 关键填报提醒

1. **广大校区分散严重**：大学城校区（本科生主体，番禺，地铁大学城南站）+ 桂花岗校区（研究生 + 部分本科）+ 黄石校区（艺术类），**报志愿时务必确认专业对应哪个校区**；大学城校区距广州市中心约 40 分钟地铁，生活圈成熟。
2. **物理类专业组分化很大**：网安 / 数学 / 师范类位次 4–5w，土建类曾跌至 21w；**同一志愿批次中组内专业差距巨大，勾服从前仔细看组内专业名单**。
3. **出广州竞争力骤降**：广大牌子在广州本地（政府 / 国企 / 广州本地企业校招）认可度尚可，但到北京 / 上海 / 深圳简历筛选时，面对 985/211 基本无优势；**打算去深圳大厂 / 北京互联网，广大不是好选择**。
4. **考研是广大毕业生最常规的升值路径**：本科读广大 + 考研冲中山大学 / 华南理工是广州中产家庭高频路径，**如果选广大一定要有考研规划**。

## 毕业去向（官方数据参考）

- **留省就业**：约 91.6%（主要在广州，其次深圳）
- **留广州就业**：约 40.8%（在省内就业中占最大比例）
- **考研升学**：约 21.5%（国内 + 境外合计）
- **进体制内（政府 / 事业单位）**：约 36.3%（政府机关 + 科研及事业单位合计）
- **数据来源**：广州大学 2023 届毕业生就业质量年度报告

## 跟同档院校对比

| 维度 | 广州大学 | 广东工业大学 | 深圳大学 |
|---|---|---|---|
| 综合实力 | 中（文理均衡偏文） | 中（工科强） | 中偏强（理工 + 财政重投） |
| 行业认可 | 广州本地政府 / 教育系统 | 广东制造业 / 工程 | 深圳大厂 / 金融（本地王） |
| 地理位置 | 广州番禺大学城 / 越秀桂花岗 | 广州番禺大学城 | 深圳南山区（腾讯旁） |
| CS/网安 | 中（网安有特色） | 强（工科老牌） | 强（深圳 IT 直供） |
| 师范/教育 | 强（广州教编认可高） | 弱 | 弱 |
| 出广东认可度 | 低 | 低 | 低（但深圳本地强） |

**简单结论**：想留广州进政府 / 学校 / 国企，广大性价比尚可；想进深圳大厂或出广东，直接选深大或广工；学工科选广工更稳。

## 适合谁

- 广东物理类省排 **5w–9w 名** + 目标留广州就业（公务员 / 教师编 / 广州国企）。
- 想学师范 / 心理 / 网安 + 留广州的考生。
- 有考研规划、本科先落脚广州、考研冲中大 / 华工的考生。
- 广州本地考生（减少生活成本 + 本地家庭资源加持留广州就业）。

## 不适合谁

- 打算去深圳大厂 / 北京互联网就业 → 广大牌子出广东几乎没有竞争力，不如选广工或深大。
- 想学土木 / 建筑的考生 → 行业持续下行，广大土建毕业就业已相当困难。
- 打算本科直接就业进外企或互联网大厂 → 双非广大在大厂校招中不在重点校名单。
