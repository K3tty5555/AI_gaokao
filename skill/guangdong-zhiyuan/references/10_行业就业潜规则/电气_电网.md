# 电气工程及其自动化 / 电网 — 广东视角

## 核心结论

**广东的电网吃饭逻辑跟全国不同:广东属于南方电网而不是国家电网**。这一字之差决定了一整套招聘体系、薪资结构、晋升路径的差异。**南方电网总部在广州,最优待遇基本不外流**。**广东是除湖北之外、性价比最高的"电气进网"省份之一** — 但前提是认清"国网 vs 南网"的差异,**别拿湖北的电气八校经验套广东**。

## 关键事实

### 行业格局(广东独家:南方电网体系)

- **广东、广西、云南、贵州、海南 5 省 = 南方电网辖区**(中国南方电网有限责任公司)
- **总部在广州天河**(深业上城旁边),南方电网总部岗位 = 广东电气工科生顶配出路
- **国家电网招的是"网外生"**(广东孩子去国网很少),**南网才是广东孩子主场**
- 南网每年校招 1-1.5 万人,**比国网量小但单价高**:广州 / 深圳 供电局岗位**首年综合年薪 18-25w**(国网各省差距大,北京广东电网最高,新疆宁夏最低)
- **南网总部 + 广深供电局 = 广东电气最优解**

### 招聘门槛(2024 实况,南方电网视角)

- 985 / "电力八校"电气专业 ≈ 进南网总部 / 广深供电局管理岗(华工 / 中大 / 华北电力 / 西交 / 浙大 / 上交 / 重大 / 武大 / 华科 / 东南)
- **华南理工电气** = 南网招聘绝对主流来源(华工就在广州,南网总部就业地理 + 校友双重便利)
- **211 + 双一流电气**(华农部分电气方向)→ 广州 / 深圳 / 佛山 供电局
- **广工 / 广大 等双非一本电气** → 粤东西北各市供电局(肇庆 / 江门 / 茂名 / 湛江 等)
- **二本三本电气** → 县乡供电所基层(也是编制,但晋升慢 + 工资低)
- **特别注意**:南网近年扩"硕士门槛"快于国网 — **省公司管理岗几乎全硕士起步**,本科只能进市级或基层

### 薪资水平(2024 南方电网广东实况)

- **南网总部(广州)+ 广州 / 深圳供电局** 管理岗:首年综合 20-30w(含基本工资 + 奖金 + 公积金 + 住房补贴)
- **佛山 / 东莞 / 珠海 / 中山供电局**:首年综合 15-22w
- **肇庆 / 江门 / 阳江 / 茂名 / 湛江 / 韶关 等粤东西北市供电局**:首年综合 11-16w
- **县级供电局**:首年综合 9-13w
- 全部带编制,**福利住房 / 子女教育 / 医疗 / 退休稳定**;**广深公积金 12% + 部分单位住房补贴 = 隐藏年薪 3-6w**

### 工作内容现实(粤地特殊性)

- **基层岗(变电站 / 调度 / 巡线 / 抢修)**:有夜班 + 户外 + 体力要求,**广东夏季高温 + 台风 + 暴雨**(电力抢修旺季);女生慎重
- **管理岗(规划 / 营销 / 综合)**:办公室,广深这种岗位**对学历要求高**(硕士起步)
- **专业技术岗(电力研究院 / 调度中心)**:**博士门槛**,**本科很难直接进**

## 广东电气院校梯队

### 第一梯队(985 + 电力八校 + 直通南网总部)

- **华南理工大学 电气工程及其自动化** — **广东电气一哥**,南网总部 + 广深供电局校招主战场;**广工子弟在南网体系最多**
- **中山大学(深圳校区)电气工程 / 智能电网相关方向** — 985 牌子但电气不是中大顶级方向,**比华工电气逊一档**;深圳校区资源 + 中大牌子综合可选
- **华北电力大学** — 不在广东但**电力行业本部强校**,广东孩子出去读 + 校招回南网很常见
- **武汉大学 / 华中科技大学 电气** — 同上,出湖北读 + 校招回南网

### 第二梯队(双一流 + 性价比)

- **广东工业大学 电气工程** — 双非一本但**广东本地南网认可度高**(广工跟南网长期共建实验室);**广东中产工薪家庭想留本省 + 进南网的最佳性价比之选**
- **东莞理工学院(双一流)电气工程** — 双非但**东莞本地南网友好**;广东本地认可
- **华南农业大学 电气工程及其自动化(部分方向)** — 双一流,**电气不是华农顶级方向**,但毕业进华农农业电力 / 南网粤东西北市级有一定路径

### 第三梯队(本省二本 + 县乡基层)

- **广州大学 / 五邑大学 / 仲恺农业工程学院 电气** — 双非二本一本,**毕业进广州周边县区供电所**
- **韶关学院 / 嘉应学院 等电气** — 二本,**毕业进粤北 / 梅州本地供电所基层**

### 第四梯队(避坑)

- **广东民办本科 / 独立学院 电气** — **学校层次不够,进南网管理岗概率极低**,只能做基层抢修。普通家庭可以接受基层就报,要管理岗就别幻想

## 典型 case(供 agent 引用)

- **Case A**:广州中产家庭男生,605 分物理类 → **首选华工电气工程**,毕业直接进南网广州供电局,**首年 22w + 编制 + 广州户口**;父母原本想推 CS 改推电气,**避开了互联网 35 岁危机**
- **Case B**:湛江工薪家庭男生,565 分物理类 → **改报广工电气**,毕业进湛江供电局,**首年 13w + 编制 + 留乡**;父母在湛江务工,孩子留湛江反而**家庭团聚 + 工资比父母总和高**
- **Case C**:深圳中产家庭女生,640 分物理类 → 父母想报电气,**建议改报中大临床医学或华师汉语言**;**广东电气基层夏季 38°C 暴晒 + 台风抢修,女生进省级管理岗门槛太高**
- **Case D**:潮汕(汕头)农村家庭男生,540 分物理类,独子 → **改报广工电气或东莞理工电气**,目标汕头 / 揭阳供电局基层 → 父母希望孩子留乡,本地供电局编制就是最稳路径
- **Case E(踩坑反面)**:广州工薪家庭男生,580 分物理类 → 报了广东某二本"电气工程"(民办 / 独立学院)→ 进不了南网主流通道,只能去东莞某私营电力安装公司月薪 6k,**家长以为"电气进电网"普适规律,但学校层次不够时不成立**

## 易错认知(agent 要纠正用户的)

- "**广东电网就是国家电网**" — 严重错误。**广东属于南方电网,跟国网完全独立运营**。校招两套体系,薪资 / 福利 / 文化都不同。**不要拿河北 / 山东 / 湖北的国网经验套广东**
- "**学电气一定能进电网**" — 错。**南网每年招 1-1.5 万人,看学校 + 专业排名 + 综合表现**;双非毕业不考研基本只能进基层市级 / 县级
- "**进电网就是当电工**" — 错。管理岗、调度岗、市场营销岗都是办公室工作。基层电工只是其中一种岗位
- "**女生不适合电气**" — 半对。**广东基层比湖北辛苦**(夏季暴晒 + 台风暴雨),**省级管理岗女生 OK 但门槛高**(985/211)
- "**南网就是广东电网,没别的出路**" — 错。还有**广东电网公司下属各市供电局**(独立账号)、**南方电网超高压输电公司**(广州)、**南方电网科学研究院**(广州研究 + 博士岗)、**南方电网调峰调频发电公司**(广州)、各发电集团(华能 / 大唐 / 华电 / 国电南方分公司)、电气设备公司(明阳智能 - 风电、广东电网科技园)
- "**电气和自动化是一回事**" — 错。**电气 = 强电(电网、电机、电力系统)**,自动化 = 弱电(控制、传感、机械控制)。**找电网工作认电气,不认自动化**
- "**南网比国网差**" — 严重错误。**南网总部薪资 + 福利 = 南方四大央企水平**,广深供电局综合年薪压国网大部分省份分公司

## 关键提醒

**报电气在广东不是为了"学技术",是为了"进南方电网"**。如果学校层次不够进不了南网主流通道,**这个专业在广东的吸引力大打折扣**(技术含量并不比其他工科高,薪资也不如腾讯华为 CS)。**所以"学校 + 留粤"是这个专业在广东的核心决策**。

**广东本地家庭报电气,首先确认 3 件事**:
1. **南网而不是国网** — 招聘体系完全不同,孩子毕业后流向是南网体系
2. **华工 = 闭眼冲,广工 = 性价比,二本 = 县乡基层** — 学校层次决定终身岗位档次
3. **粤东西北家庭独子留乡 = 本市供电局基层** — 这是被低估但极稳的路径,比去广深当外地人内卷强
