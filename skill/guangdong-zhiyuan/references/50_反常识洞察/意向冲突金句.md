# 用户意向冲突 — Reality Check 金句库(广东版)

很多家长 / 考生有具体的意向("想上中大"、"非深圳不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **广东特有:留粤 / 留珠三角 / 留深圳 / 留港 vs 出省** — 这几个意向冲突在广东咨询里高频出现,处理逻辑跟北方省份不同

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 500 分要清华 / 580 分要中大主流组 / 580 分要港中深)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [大湾区 / 粤东西北 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作双非顶配的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(广东 580 分,意向中大)**:
> "中大主流组在广东物理类省排 2,500-4,500 名。你 32,500 名,差近 3 万名,**中大没戏**。
>
> 但你能上深大 + 广工 + 暨大冷门组 — 这三所留深圳 / 广州就业,**腾讯 / 华为 / 南方电网 校招里跟中大冷门组校友地位差不多**(都是'广东本地双非顶配 / 211 + 留粤同档')。"

**真实案例(广东 590 分,意向港中深)**:
> "港中深(香港中文大学深圳)金融 / 数据科学组在广东物理类省排 1,500-3,000 名。你 30,000 名,差近 3 万名,**港中深没戏**。
>
> 而且港中深一年学费 12-15w,4 年下来加上生活费要 100w,**普通家庭也撑不起**。
>
> 你能上深大金融 / 经济组,**留深圳就业生态跟港中深差距没那么大**(都是深圳本地校友 + 留深就业)。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(理工科 + 普通家庭 + 冲中大)**:
> "中大珠海校区组你 615 能擦 — 但只能进海洋 / 大气 / 材料。**985 牌子 + 珠海偏远 + 生化环材** = 三重坑(海洋例外,海洋全国前 5 但行业冷门)。
>
> 同分能上的南方医科大学医学影像技术(双非但医院资源强 + 4 年就业)出来对口程度更高,**广深三甲技师起薪 16-22w**。冲中大留一个心理慰藉位即可。"

**真实案例(冲华工但只能进冷门工科)**:
> "华工分够,但**只能进华工的资源勘查 / 高分子材料 / 轻化工程**。这些是华工里相对弱的方向,**毕业大概率改行 + 考研**。
>
> 同分能上的暨大经济学院 / 华师汉语言文学 / 深大 CS,**留粤就业 + 考公 / 大厂 / 教师编路径都清晰**。华工冷门组留一个冲档位即可。"

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。**广东特别要注意:广深生活成本高,8 年规培期撑不起**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [中山医临床八年制 / 北医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制 / 护理 4 年] — 早 3-4 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(粤东普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 6-9k**,广深三甲规培期生活费就要 5k+。普通工薪父母还要供 8 年。
>
> 你家是揭阳工薪,父母年入 12w,撑不起 8 年广深生活 + 学费。
>
> 撑得起(中产家庭)→ 推中山医临床 / 南医大临床,长期天花板高。
>
> **撑不起(你家)→ 强烈建议医学影像技术 / 护理学(本科 4 年直接进医院),广深三甲护士首年 22-28w + 编制,4 年就开始挣钱,反而比 8 年规培完毕的医生先攒下首付**。"

**真实案例(广州中产 + 想做律师 / 法学)**:
> "你家是广州中产(父母年入 50w),撑得起。法学是长周期 — 本科 4 年 + 法考 + 律师助理 3-5 年才能独立带案。
>
> 但**红圈所合伙人天花板极高**(广州金杜 / 君合 / 中伦合伙人年入 200-500w),只要熬过前 5 年。
>
> 推中大法学 / 暨大法学 + 红圈所实习。**家里撑得起 5 年 = 长期收益压互联网**。"

### 模式 D:意向城市 vs 院校层次 — 广东特有"留粤 / 留深 / 留港 / 留乡 4 选 1"

**特征**:广东考生意向城市冲突频繁,跟北方省份"留京"二选一不同,**广东是 4 个城市意向博弈**:留广州 / 留深圳 / 留港澳 / 留粤东西北本市。

**金句模板(广州意向)**:
> "你只想留广州,那同档要在 [广州 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留广州 211 反而更稳** —
> - 当地校友网密度大,**广州体制内 / 国企招聘有'本地优势'**
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回广州没竞争力**
> - 留广州你父母也安心
>
> 但!如果你想做的方向广州没强校(如想做芯片 / 半导体 → 留北京清华微电子 / 西电),**要灵活退一步**。"

**金句模板(深圳意向)**:
> "你只想留深圳,**深圳本地高校选项有限**(中大深圳校区 / 哈工大深圳 / 港中深 / 南科大 / 深大),其他 985/211 在深圳没分校。
>
> 留深的两条主流路径:
> - **冲分够的** → 中大深圳校区 / 哈工大深圳 / 南科大 / 港中深(港中深要中产以上)
> - **分够不到顶配的** → **深大 CS / 金融 / 经济学**(深大本地认可度压一些 211)
>
> 不要为了留深圳去深圳的双非民办,**深大已经是双非里的天花板**;**深大 vs 中大冷门组怎么选** = 留深就业看深大,牌子硬看中大。"

**金句模板(留港 / 港澳意向)**:
> "你想留港澳,**港大 / 港中文 / 港科大** 走提前批 + 自主面试,**学费 12-20w/年 + 生活费 6-8w/年 = 4 年 80-120w**。
>
> 你家撑得起吗?**普通家庭真撑不起,别为了'港校牌子'压垮家庭**。
>
> 替代路径:
> - **港中文(深圳)** = 内地分校学费 12-15w/年但留深圳就业(替代港岛留深)
> - **暨大 + 港澳侨学生氛围** = 211 + 港澳通道(暨大本部在广州但港澳校友多)
> - **中大深圳校区 + 港股投行实习** = 留深就业 + 港岛资源对接(性价比最高)"

**金句模板(留粤东西北本市意向)**:
> "你是潮汕 / 湛江 / 梅州本地家庭,父母希望孩子留乡。这意向**不要被'要出去看看'的同辈话术绑架** — 你家庭画像里独子 + 父母无社保 + 留乡接班 / 考公,**留乡才是最优解**。
>
> 留乡路径:
> - **本市师范 + 教师编**(韶关学院 / 嘉应学院 公费师范)
> - **本市供电局 + 电气南网**(广工电气 + 回本市供电局)
> - **本市三甲医院技师 / 护士**(广东医科大学 / 汕头大学医学院)
> - **本市公务员**(广州大学汉语言 + 回本市考公)
>
> **不要为了'冲广深'报双非 CS,毕业既留不下广深也回不去本市**(本市没大厂)。"

**真实案例(广州 + 法学方向 + 615 分)**:
> "你只留广州,这位次 8000 名内,中大法学要 4500 名,你够不上。
>
> **留广州最稳路径**:暨大法学 / 华师法学(中大冷门组也可冲)+ 父母广州本地律师 / 公检法资源 + 法考 → 红圈所助理 / 公检法路径仍然能走。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**广州人脉断了 / 实习机会少了 / 户口没了**,综合不划算。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **粤东西北独子 + "去广深看看"鸡汤** — 留乡才是最优解,别让虚荣绑架家庭

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 中大 / 想学医 / 想留深圳 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 广东特有的 5 类高频意向冲突

| 意向 | 冲突点 | Agent 处理 |
|---|---|---|
| **"非中大不去"** | 分数不够中大主流组 | reality check + 推暨大主流组 / 华工冷门 / 深大 CS |
| **"必须留深圳"** | 深圳本地高校选项有限 | 深大 / 港中深(中产以上)/ 哈工大深圳 / 中大深圳校区 |
| **"想学医 + 普通家庭"** | 8 年长周期撑不起 | 推医学技术 / 护理(广深起薪全国第一)|
| **"想做大厂 + 双非 CS"** | 双非进不了腾讯华为主流通道 | 推华为 OD / SHEIN / 跨境电商 + 警示长期路径 |
| **"潮汕独子 + 出广深 vs 留乡"** | 家族接班压力 vs 个人虚荣 | 看家族产业,有产业留乡接班,无产业冲国家专项 985 |

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**广东版加一条:留粤 / 留深 / 留港 / 留乡 是 4 选 1 不是必然要"出去",尤其粤东西北独子家庭 — 不要让"看世界"鸡汤绑架家庭决策**。
