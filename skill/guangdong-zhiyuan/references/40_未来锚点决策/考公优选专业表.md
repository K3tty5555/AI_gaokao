# 考公优选专业表(广东本地视角)

## 核心结论

**专业决定考公选岗范围**。广东家长普遍不知道:**广东体制内偏好弱于湖北 / 山东 / 河南**(因为民营经济发达分流人才),所以**广东考公竞争比湖北弱、岗位单价高**。**广深公务员综合年薪 18-30w(深圳市直特区编制全国前 3)**;粤东西北市县乡公务员综合年薪 12-18w 但**留乡 + 编制 + 父母身边** 是普遍家庭偏好。

**广东特有的"户籍 + 选调 + 选岗" 三维度**:
- **粤东西北岗位需要本地户籍**(汕头岗位限汕头户籍 / 湛江岗位限湛江户籍 等)— 这是广东省考的隐藏规则
- **广东选调生定向中大 / 华工 / 暨大 / 华师**,**起点比国考省考高**
- **深圳市直 / 广州市直 编制 = 全国体制内综合待遇前 3**

如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小 + 户籍匹配"展开**,而不是看专业本身的"高大上"程度。

## 关键事实(2024 国考 / 广东省考分析)

### 国考可报岗位数 排名(Top 10 大类)

1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部、**广州海关 / 深圳海关 主力**→ 约 2%

### 广东省考特殊性

- **广东省考竞争比湖北 / 河南弱**(因为民营经济分流) — 广深岗位 30-50:1,粤东西北岗位 8-20:1
- **粤东西北岗位需要本地户籍**(广东省考公告里"限本地户籍"岗位约占 30%)— **这是广东独有的规则,粤东西北本地家庭独子优势大**
- **三不限岗位**(对专业不限制 + 不限户籍):**所有人都能报,但竞争最激烈**(广州 / 深圳 三不限岗 200-500:1)
- **广州市考 + 深圳市考 + 广东省考 = 三套独立体系**(深圳市考时间跟省考错开,可同时报)

### 广深市直编制 — 全国体制内综合待遇前 3

- **深圳市直公务员**:首年综合 25-35w(基本工资 + 奖金 + 公积金 12% + 住房补贴),**全国体制内前 3**;深圳市直三不限岗位录取分压清华北大
- **广州市直公务员**:首年综合 18-25w,广州户口 + 编制 = 大湾区稀缺资源
- **粤东西北市县乡公务员**:首年综合 11-16w,**对粤东西北本地家庭独子 = 留乡 + 编制 + 父母身边**

### 选调生(广东特殊高潜力路径)

- **广东省委选调生定向中大 / 华工 / 暨大 / 华师 + 部分省外 985**;**省级选调生起点 = 副科级储备**
- **985/211 才有资格报**(广东本地的选调生定向计划基本只对中大 / 华工 / 暨大 / 华师 + 部分省外 985)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **广东选调生进省委组织部 / 广深市委组织部** = 起点远高于国考省考
- **粤东西北籍 + 中大 / 华工 选调生 + 回乡定向** = 隐藏跃迁路径(分配到本市做副科级储备,**回乡时已经超越大部分同辈**)

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、广东警官学院等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,广东本地中山大学 + 暨南大学法学对口

## 广东本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业

- **中山大学法学** — 全国前 15,**法考通过率高,广东选调路径最优**
- **中山大学经济学院 / 岭南学院 经济学 / 财政学** — **大湾区财税系统对口**
- **中山大学中国语言文学类** — 综合就业 + 考公双友好
- **华南理工法学 / 工商管理** — 985 牌子 + 工科背景 + 法学 / 经管,**适合理工科考公**
- **暨南大学法学 / 经济学 / 行政管理** — 211 + **港澳侨学生比例高 + 广州地理 + 选调生友好**
- **华南师范大学公费师范汉语言文学** — 不是考公但是教师编制(广深教师起薪 22-30w),**等同于考公友好**

### 双非 + 性价比考公专业

- **广东外语外贸大学(广外)英语 / 法语 / 法学** — 双非但**广州海关 / 深圳海关 / 外交部驻港澳机构 对口**;**广东外语类考公王者**
- **广州大学汉语言文学 / 法学** — 双非但**广州市考考公成功率高**;广州本地认可
- **深圳大学汉语言文学 / 法学 / 经济学** — 双非但**深圳市考考公成功率高**;**深大本地认可压一些 211**
- **广东工业大学行政管理 / 法学** — 双非一本,**广州本地市考 / 县区考公**
- **广东财经大学(原广东商学院)会计学 / 财政学 / 经济学** — 双非但**广东本省财税系统认可度高**
- **韶关学院 / 嘉应学院 / 五邑大学 等汉语言文学 / 法学** — 二本但**粤北 / 粤东 本市考公友好**

### 公安系统专属

- **广东警官学院** — 本科,公安联考路径,**毕业进广东本地公安概率极高**(基层警察)
- 中山大学 / 暨南大学的**法学**(可走司法考试 + 进司法系统)

## 典型 case(供 agent 引用)

- **Case A(粤东逆袭路径)**:汕头农村家庭考生,540 分历史类,**普通工薪家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报广州大学汉语言文学**,毕业当年考上汕头市直某机关公务员(限汕头户籍岗,竞争 12:1),**家庭命运改变**
- **Case B(广东选调路径)**:广州考生,640 分历史类,中产家庭。家长想报"金融"(中大岭南)。**改报中大法学**,**毕业获得中大选调生资格,直接进广东省委组织部**,起点远超经济学就业
- **Case C(粤西性价比)**:湛江工薪家庭,565 分文史类,**孩子想留乡考公**。**报广东医科大学行政管理**(双非但广东医院系统对口),**毕业回湛江市直机关公务员(限湛江户籍岗)**,**留乡 + 编制 + 父母身边**
- **Case D(深圳市考高薪)**:深圳考生,625 分历史类,工薪家庭。**报暨大法学**,**毕业考深圳市直公务员(三不限岗)**,**首年综合 28w + 深圳户口**;父母在深圳务工,孩子留深考公**单人收入压全家**
- **Case E(失败路径)**:东莞考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了华南师大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**
- **Case F(误区路径)**:广东家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case G(广外海关路径)**:佛山中产家庭,600 分历史类,**想做大湾区国际化工作**。**报广外英语 / 国际商务**,毕业**考上广州海关**(限相关专业 + 限广东户籍),**首年综合 22w + 广州户口**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(广东 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对中大 / 华工 / 暨大 / 华师 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是广东家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**广东人不爱考公**" — 半对。**广深中产 / 创业家庭确实不太爱考公**(因为深圳互联网薪资高);**但粤东西北家庭考公意愿不弱于湖北山东**;广深市直编制综合年薪压一些互联网中层
- "**深圳考公没意义,不如去腾讯华为**" — 严重错。**深圳市直公务员综合 25-35w + 编制 + 深圳户口 + 不会 35 岁危机**;互联网 35w 起薪但 35 岁后大概率被裁,**长期算下来公务员胜出**
- "**粤东西北考公没用,工资低**" — 错。**粤东西北本地考公 + 父母身边 + 留乡 + 房价低** = 综合幸福度可能压广深;**留乡公务员一辈子不愁,广深外地人 35 岁失业 + 房贷 = 翻身难**

## 关键提醒

**考公是普通家庭最稳定的上升通道,在广东尤其是 3 类场景**:

1. **粤东西北本地家庭独子 / 独女 + 留乡考公** — 广东省考"限本地户籍"岗位竞争小,本市本县考公比省直 / 广深三不限岗成功率高 5-10 倍
2. **广深市直编制 + 综合待遇全国顶级** — 深圳市直 25-35w + 深圳户口,**这是全国都羡慕的体制内待遇**
3. **中大 / 华工 / 暨大 / 华师 选调生 + 起点高** — 直接进省委 / 市委组织部,**5 年内副科级储备**

**考公专业选择必须围绕"可报岗位多 + 户籍匹配 + 对口竞争小"三个维度**,而不是表面的"专业高大上"。**汉语言文学是广东家长被严重低估的考公王者**(尤其粤东西北本地家庭独子的最稳路径)。
