# 天津专科 skill 核心方法论 — 索引

天津专科填报的核心思考框架,以及 references 各文件的导航。

## 一、天津专科的特殊性(决定一切的前提)

天津专科 ≠ 一般地级市专科,有 4 个独特变量必须先想清楚:

1. **直辖市单一城市**:**天津考生只有 1 个本市选项 + N 个外省选项**(湖北 / 江苏考生有十几个本市地市选择,天津没有)
   - 留津 vs 出津 是非此即彼的选择,**没有"先去武汉再回鄂西" 这种过渡空间**
   - 出津的现实选项:**北京(京津两栖)/ 河北 / 长三角 / 外省专科**

2. **天津户口红利**(留津的核心吸引力)
   - 天津户口 ≈ 北方 户籍价值最高之一(教育 + 高考 + 公租房 + 医保 等综合福利)
   - **专科 + 留津工作 + 缴社保 = 户口红利兑现**(对天津户籍考生)
   - **专升本 + 留津工作 1 年 + 缴社保 = 人才引进落户路径**(对非津户籍考生)

3. **京津两栖**(隐藏的高薪选项)
   - 北京岗位薪资比天津高 30-50%,**高铁通勤 30 分钟**
   - 适合**计算机 / 物流 / 部分服务业** 专科生
   - 不适合**护理 / 学前 / 化工 / 港口** 等强地域属性的专科生

4. **3+3 选科 + 6 万考生量小**(竞争结构特殊)
   - 选科组合多于 3+1+2,**赋分 + 等级排位** 计算更复杂
   - 考生量小 → 位次比分数更准
   - **专升本** 也是 3+3 体系,接收本科只在天津本市

## 二、专科推荐的核心逻辑(优先级)

```
专升本意愿 > 留津意愿 > 行业偏好 > 院校梯队 > 分数定位
```

### 1. 专升本意愿(强度 1-5)
- 5 = 必升本 → 选**升本对口面广 + 公办专科 + 升学氛围浓** 的学校(海河教育园院校优先)
- 1 = 直接就业 → 选**行业出口清晰 + 院校行业对口强** 的学校(天津港 / 渤化 / 一汽丰田 等对口院校)
- **决定专科 3 年的所有学习节奏**

### 2. 留津意愿
- 必留津(户口红利兑现) → 推天津本地国企 / 天津产业链对口专科
- 接受京津两栖 → 推计算机 / 物流类(可去北京)
- 接受出津 → 慎重(天津专科出省竞争不强,**只有计算机 / 部分专精方向能跨区域**)

### 3. 行业偏好(天津 6 大对口行业)
- **港口物流 / 海事**(滨海新区 / 天津港) — 天津特色,**升本路径基本封死**
- **化工 / 医药**(滨海新区) — 高薪 + 国企编制,**但环境硬**
- **护理 / 中医药**(海河园 / 三甲医院) — 稳定 + 编制,**男护士有红利**
- **机电 / 汽车 / 制造**(西青 / 武清 / 滨海) — 一汽丰田 / 长城 / 空客对口
- **学前 / 师范**(海河园) — 女生稳定,**必须升本才有公办园编制**
- **计算机 / 数字技术**(海河园 / 滨海高新) — 京津两栖最佳赛道

### 4. 院校梯队
- 第一梯队公办(天职大 / 天电信 / 天机电 / 天现代 / 天渤海)— 强烈推荐
- 第二梯队行业公办(天医高专 / 天海运 / 天交通 / 天商务 等)— 行业明确选这些
- 第三梯队一般公办 — 兜底
- 第四梯队民办 — **避坑**

### 5. 分数定位
- 复用 `tianjin-zhiyuan/scripts/score_to_rank.py`
- 位次比分数更准(天津考生量小,分数波动大)

## 四、agent 推理顺序建议

1. **先问专升本意愿**(L2 第一题)— 没确认这个,后面都是错的
2. **再问留津意愿**(L2 第二题)— 决定行业方向收窄
3. **再问行业偏好 / 性别 / 工作环境接受度** — 收窄到 1-2 个行业
4. **结合分数 / 位次** 给出院校梯队推荐(冲 1 / 稳 2 / 保 2)
5. **最后给关键提醒** + **免责声明**

## 五、red flags(agent 必须警告用户的)

- ❌ 选民办专科(除非家庭经济宽裕 + 不愿复读)
- ❌ 选**港口 / 海事 / 邮轮乘务** + 强升本意愿(本市无对口本科)
- ❌ 选**国际邮轮乘务**(疫情后重创 + 升本死路)
- ❌ 选**建筑 / 房地产 / 测绘 类**(行业景气下降)
- ❌ 选**跨境电商运营** 听起来时尚但坑多
- ❌ 选**纯外语类专科**(商务英语 / 应用日语 等,**升本对口几乎无,就业出口窄**)

## 六、核心免责声明

- 不承诺"一定能录取"
- 不诋毁专科教育(专科生不是失败者,是另一条路径)
- 不夸大"京津两栖"(承认它是少数人路径)
- 涉及天津专升本 / 户口政策的,**建议用户咨询天津市教育招生考试院 / 学校招生办**(政策每年变)
- 推荐方案末尾必须加免责声明
