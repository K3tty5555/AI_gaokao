# 海南专科 skill 核心方法论

## 这个 skill 跟其他省专科 skill 的本质区别

海南专科填报跟湖北 / 湖南 / 河南 这些大省**不能套同一套方法论**。原因:

1. **海南是 3+3 政策 + 标准分制度**(满分 900,不是 750)— 选科 + 分数体系跟绝大多数省都不同
2. **海南本省高校选项极少**(就 11 所专科,其中民办还要剔除几所)— 大多数考生要面对"留岛 vs 出岛"的二选一,这是其他省没有的痛点
3. **自贸港政策红利是核心抓手** — 旅游 / 跨境电商 / 免税 / 国际邮轮 / 海洋经济 这些行业在海南有真实出口,在其他省学是大坑
4. **专升本是封闭体系**(出岛专科生回不来海南考专升本)— 这一条 lock-in 力度比其他省都强,直接决定专科填报策略

所以这个 skill 不能照抄湖北 / 湖南专科 skill 的模板,**所有 references 都要海南本地化**。

## 海南专科填报的核心逻辑

### 第一步:确认是不是真的应该报专科
- 标准分接近本科线但够不上 → 复读 vs 专科 要权衡
- 标准分低于专科线 → 没办法,只能考虑民办或复读
- **海南考生总盘子小** → 复读的边际收益其实比大省高(竞争压力没那么大)

### 第二步:确认留岛还是出岛
这是海南专科填报的**第一决策点**(其他省专科 skill 没有这个层次):

- **专升本意愿强 → 必须留海南本省读专科**(出岛回不来)
- **专升本意愿弱 + 家里有海南本地资源 → 留岛**
- **专升本意愿弱 + 想去大城市发展 → 出岛公办**(广东 / 广西 / 湖南邻省)
- **海南公办没考上 + 不打算专升本 → 出岛公办 > 海南民办**

### 第三步:确认专业方向
专业方向决定了**留岛 vs 出岛 + 院校选择 + 未来 5-10 年路径**。海南专科的核心方向就那几个:

1. **旅游 / 酒店 / 邮轮** — 海南本地真红利,**铁了心留岛的首选**
2. **跨境电商 / 免税 / 国际贸易** — 自贸港政策红利,**留岛专属赛道**
3. **护理 / 医护** — 全国通用 + 海南本地老龄化 / 旅居康养加成
4. **海洋 / 水产 / 渔业** — 海南独特赛道,**家族产业 + 体制内** 路径
5. **国际邮轮 / 航海** — 三亚邮轮母港 + 国际化高薪
6. **计算机 / 软件 / 学前 / 机电** 等通用专业 — 海南本地竞争力一般,可考虑出岛

### 第四步:确认院校
- 公办 > 民办(永远的原则)
- 专业对口的强校 > 综合性院校
- 实习资源 + 校企合作 > 学校排名
- 海口 > 三亚 > 其他地市(但行业对口的话三亚反超)

## 针对海南家庭的特殊话术

### 海南家庭普遍特点
- **熟人社会 + 本地化倾向重**:很多家庭就想孩子留在身边,海南岛太美,父母舍不得让孩子去内地
- **家族产业普遍**:旅游 / 餐饮 / 民宿 / 渔业 / 海产品 / 商贸 — 海南家族企业比例不低
- **信息差不算大但选项少**:海南考生家庭对"清北 / 985 / 211"概念清楚,但**海南本省高校少 + 出岛距离远** = 选项受限

### agent 跟海南家庭对话要点
1. **直接问"想不想留岛"**(不要绕弯子,这是核心决策)
2. **问家里有没有家族产业**(海南这点特别普遍,直接影响推荐)
3. **问父母对孩子未来的核心期待**(留海南体制内 / 接管家族 / 出岛闯荡)
4. **不要诋毁海南**(很多家长真心觉得海南最适合生活,这不是井底之蛙,是真实判断)
5. **要提醒自贸港政策红利**(很多家庭不一定意识到这是真红利,需要 agent 拉通)

## 安全规则

- 不诋毁专科教育
- 不承诺录取
- 涉及自贸港封关后的具体政策 → 强烈建议查最新海南教育考试院 / 商务厅 / 自贸港管委会文件
- 涉及专升本接收名额 → 建议查海南教育考试院最新公告
- 推荐方案末尾必须加免责声明
