# 广西专科 skill 核心方法论

## 一、广西专科咨询的底层认知(和湖北 / 其他省的差别)

广西专科生的真实处境,**和湖北 / 河南 / 山东 等中部 / 北方省份不一样**。agent 在咨询时必须有这个底层认知,否则推荐方向会失真:

### 1. 广西不是制造业大省 → 专科生的本省工业出口窄
- 广西本省工业体量集中在**柳州**(汽车 / 工程机械)和**北部湾**(港口 / 跨境电商 / 核电)两个点
- 桂西 / 桂北山区基本没有像样的制造业,大多数县乡专科生默认是"出柳州 / 出广东打工"
- **不要套湖北那套"留武汉就能找到好工作"的话术**——广西的"留省"本质上是"留南宁 / 留柳州 / 留桂林 / 留北部湾"

### 2. 广西离广东太近 → 出桂打工是主流
- 不像湖北 / 江西出省要远走,广西出广东就是几小时高铁
- 很多家庭抱着"广西专科 → 去珠三角拧螺丝 / 学技术 / 做跨境电商"的预期,这是**真实而合理的家庭预期**
- agent **不能默认"考公考编 / 留省发展" 是唯一好路径**——尊重出桂打工的家庭选择

### 3. 中越边境 / 北部湾 是广西独有的赛道
- **凭祥 / 东兴 / 防城港 / 北海** 跨境电商 + 港口物流 + 越南语 是其他省没有的赛道
- **京族 / 壮族 + 边境长大** 的孩子在这条赛道有方言 + 地缘双重优势
- 这条赛道**自营老板路径** 概率比"考公进体制"还高,适合有家族资源的边境籍家庭

### 4. 民族优惠 + 国家专项是真实通道
- 壮 / 瑶 / 苗 / 侗 / 仫佬 / 京 等少数民族加分后,能踩到更好的公办专科档
- 民族地区定向培养 / 国家专项 给农村专科生提供"服务期满转编"路径
- agent 询问时要主动问民族成分(广西默认要问)

### 5. 3+1+2 才刚刚落地 → 数据预测要保守
- 广西 2024 首届 3+1+2,前几年的"位次预测"参考价值有限
- 要明确告诉用户"位次只是参考,实际录取波动可能比湖北 / 江苏更大"

### 6. 广西专升本 985/211 几乎为零
- **广西大学几乎不收专升本**(和湖北华师 / 武纺收专升本不同)
- 专升本能上的"好本科"档位整体比湖北窄一档,期望值要降一档
- 但**广西师大 / 桂林电子科大 / 广西科大 / 广西医科大** 等公办本科仍然是值得冲的目标

## 二、咨询流程的关键问题(Top 5)

### Q1:民族成分 + 是否符合专项?(广西必问)
- 壮 / 瑶 / 苗 / 侗 / 京 / 仫佬 / 毛南 等加分情况
- 国家专项 / 地方专项 / 高校专项 的资格(山区县 / 农村)
- 这一项直接影响档位推荐

### Q2:留桂还是出桂?
- 留桂(优先南宁 / 柳州 / 桂林 / 北部湾) → 专业 + 城市要匹配本地产业
- 出桂(主要去广东) → 选技能跨地域通用的专业(机电 / 计算机 / 跨境电商)
- 不能默认假设,要问出来

### Q3:专升本意愿 1-5?
- 5 → 选公办 + 升学率高的专业 + 大一就开始备考
- 1-2 → 选行业对口 + 央企 / 国企校招接得住的专业
- 中间值 → 平衡型,选两边都能走的专业

### Q4:家里有边贸 / 物流 / 边境地缘资源吗?(广西特有)
- 凭祥 / 东兴 / 防城港 / 北海 籍家庭 → 跨境电商 + 越南语 + 港口物流 是隐藏优势赛道
- 城市 / 内陆 籍家庭 → 默认走"机电 / 铁路 / 电力 / 护理 / 学前" 五大主流路径

### Q5:接受工厂 / 户外 / 三班倒 / 边境艰苦地区吗?
- 接受 → 铁路 / 电力 / 机电 / 边境岗位 是最稳的赛道
- 不接受 → 护理 / 学前教育 / 跨境电商运营 / 会计 等室内岗位
- 这一项决定了能否走"国企 / 央企 / 编制" 路径

## 三、Top 5 推荐路径速查(给 agent 决策用)

### 路径 1:留桂铁路 / 电网 / 央企(男生主力)
- 院校:柳州铁道职业 / 广西水利电力职业 / 广西电力职业
- 出口:南宁铁路局 / 南方电网广西分 / 广西水利电力集团 / 广投能源
- 适合:农村 / 工薪男生,接受三班倒 / 户外,求稳定 + 编制

### 路径 2:留桂柳州工业(机电男生主力)
- 院校:柳州职业 / 广西机电职业 / 玉林职业
- 出口:上汽通用五菱 / 柳工 / 玉柴 / 东风柳汽
- 适合:数物较好男生,接受工厂环境,想留柳州本地

### 路径 3:护理 / 学前教育(女生 + 部分男生主力)
- 院校:广西卫生职业 / 广西幼儿师范高专 / 柳州医专 / 桂林师专
- 出口:广西县乡医院编制 / 公办幼儿园 / 私立连锁
- 适合:工薪 / 农村女生,求稳定 + 编制 + 离家近;男生有稀缺红利

### 路径 4:边贸 / 跨境电商 / 越南语(广西独有)
- 院校:广西国际商务职业 / 北海职业 / 防城港职业
- 出口:凭祥 / 东兴 / 防城港 跨境电商 / 边贸 / 北部湾港口集团 / 自营创业
- 适合:边境县家庭 / 想做生意 / 不甘心打工,接受语言学习

### 路径 5:出桂去广东(打工型)
- 院校:广西机电职业 / 南宁职业 / 各类计算机 / 跨境电商专业
- 出口:深圳 / 东莞 / 广州 / 佛山 的电子厂 / 汽车厂 / 跨境电商公司
- 适合:不甘留桂 + 想赚更多钱 + 接受珠三角生活成本和竞争

## 四、agent 输出风格要求

1. **大白话**:不要用"赋能 / 双轮驱动 / 战略协同"这种词
2. **case-specific**:举例要落到广西具体地名(凭祥 / 玉林 / 河池 / 北海),不要用"某地"
3. **本省视角**:用广西人能听懂的逻辑("出桂去广东""留柳州进五菱""考广西师大专升本"),不要套北方 / 中部省份的话术
4. **不编数字**:薪资 / 录取率 / 招聘人数 给区间(5-7k / 15-20%),不要给"刚好 6543 元"这种假精确
5. **承认不知道**:政策每年变,涉及具体年份数字时主动说"以官方最新公告为准"
