# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(重庆视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**重庆视角的特殊性**:**直辖市编制密度高 + 留渝舒适度高(火锅 / 山城 / 房价友好)+ 工薪家庭比例高 + 渝东南 / 渝东北少数民族优惠** → **重庆考生整体偏向"留渝考公 / 编制路径",对"出省冒险"的容忍度比江浙沪低**。家长画像里有一句要常默念:**"工薪家庭独子男 + 留渝心态强 → 走稳的"**。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。**重庆作为直辖市,体制内家庭密度高于多数省份**(市级机关 + 区机关 + 街道办 + 国企子弟比例大)。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **重庆体制内家庭多分布在主城九区(渝中 / 江北 / 渝北 / 沙坪坝 / 九龙坡 / 南岸 等)**

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学(西政!) / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化)。**重庆选调主要走重大 + 西南大学 + 西政,这三所是重庆选调指标大户**。
3. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:**重庆警察学院 / 西政侦查学 + 公安联考** = 父母编制资源能用上,**重庆警察学院公安联考通过率 90%+ 是确定性铁饭碗**

**典型 case**:
- 渝中区某中产体制内家庭(父亲市直机关 + 母亲银行)→ 孩子 605 分物理类 → 推**西南政法大学法学** → 毕业选调进重庆市委办,**家庭路径完美匹配**(西政在重庆司法 / 政法系统认可度等同 211)
- 失败 case:同样家庭,孩子被推去重大 CS → 毕业去字节成都 25w 起薪很高,但家长不满"不稳定 / 离家远",劝其回渝考公,**两年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道
- **重庆专业人员家庭典型分布**:沙坪坝(高校系)/ 渝中(医院系)/ 江北(专业人员混合)

**推荐策略**:
1. **优先子承父业**:教师家庭 → **西南大学公费师范 / 重师汉语言**;医生家庭 → 重医临床 / 口腔(8 年长周期父母能撑)
2. **行业相关延伸**:律师家庭 → **西政法学**(重庆司法系统校友网最强);工程师家庭 → 对应工科(重大机械 / 电气 / 土木)
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲巴蜀中学语文老师 + 父亲普通工薪 → 孩子 615 分历史类 → **西大公费师范汉语言** → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是重医附一临床医生 → 孩子 650 分物理类 → **重医临床八年制 / 川大华西临床八年制** → 父母能撑 8 年读书 + 重医附一推荐 → **典型子承父业路径**(留渝当医生重医路径最熟)

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业
- **重庆私企家庭典型领域**:**汽车配件 / 火锅餐饮连锁 / 小商品贸易 / 房地产开发**(重庆民营经济重车圈和餐饮)

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(重大经管 / 西南财经成都 / 头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(**重庆中外合作办学如重大-辛辛那提合作 / 西南大学合作办学** 可考虑)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 江北观音桥某私企老板家庭(火锅连锁 / 年入 200w+)→ 孩子 580 分物理类 → 推**香港城市大学 / 重大-辛辛那提中外合作办学**(学费 8-15w/年家里能撑)→ 出国背景做家族企业接班 / 升级老火锅产业链
- 失败 case:私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息 / 不会赚钱" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(**重庆工薪家庭收入比江浙沪低 20-30%,但生活成本也低**)。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级
- **重庆工薪家庭典型分布**:**沙坪坝 / 大渡口(钢厂 / 车厂家属)/ 涪陵(化工 / 食品)/ 万州(三峡库区)/ 黔江(渝东南)**
- **重庆工薪家庭典型行业**:**长安汽车 / 重钢 / 重庆建工 / 长江电力 / 富士康涪陵 / 笔电产业链工人**

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **西南大学公费师范** = 高考分适中(比西大正常专业低 30-40)+ 直接重庆 / 川渝编制 + 无学费 ★ **重庆工薪家庭神器**
   - **重庆警察学院**(双非)+ 公安联考 = 进重庆警察系统编制(联考通过率 90%+)
   - **重医医学技术(影像 / 检验)**= 重庆三甲医院技术岗 + 4 年本科即可
   - **陆军军医大学(普通家庭男生顶级 ROI)** = 包学费 + 包分配 + 军官编制
3. **次推稳定就业型**:
   - **重大电气**进国家电网西南片区(分够 985 / 重邮 / 重三峡学院 性价比之选)
   - 师范类(西大 / 重师 汉语言 / 数学师范)
   - 护理(重医本科,**男生学护理在重庆三甲被抢**)
   - **重邮通信进华为成都研究所**(双非里工科性价比之王)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-10w,跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学临床(5+3+规培 8 年长周期,家庭撑不起)— **改军医或医学技术路径**
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 大渡口钢厂家庭 → 孩子 580 分物理类 → 推**重邮通信工程**(校招进华为成都研究所 22w 起)→ **月入 1.8w + 留成渝,家庭逆袭**
- 涪陵化工厂家庭 → 孩子 540 分文史类 → 推**重庆师范大学汉语言文学**(双非但本地考公王者)→ 毕业当年考上涪陵区委办公室,**家庭命运改变**
- 沙坪坝长安汽车工人家庭 → 孩子 545 分物理类 → 推**陆军军医大学医学影像技术** → **军方编制 + 8 年后军官身份**,**普通家庭男生顶级 ROI**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校
- **重庆农村家庭典型分布**:**渝东南(黔江 / 武隆 / 秀山 / 酉阳 / 彭水,土家苗族)/ 渝东北(万州 / 巫山 / 奉节 / 巫溪 / 城口,三峡库区)/ 渝西南(綦江 / 江津 / 永川 等山区乡镇)**
- **重庆农村家庭重要补贴**:**少数民族(渝东南土家族 / 苗族 / 仡佬族)+ 三峡库区移民 + 国家专项 + 高校专项**

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985 / 211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **西南大学公费师范**(无学费 + 重庆编制)= 重庆农村家庭神器 ★
   - **国家专项计划 / 高校专项 / 民族优惠** = **重庆渝东南 / 渝东北 农村户籍专属优惠,985/211 名校多个专项指标(分数比统招低 20-30 分)**
   - **重庆警察学院 / 陆军军医大学 / 武警警官学院**(无学费 + 编制 + 包分配)
   - 农林牧水(西大动物科学 / 农学 / 蚕学,**蚕学全国第 1 + 国家专项**)= 编制 + 行业有出路
3. **避免长周期投入**:
   - 临床医学 8 年(撑不起)— **改军医或医学技术**
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:重庆农村户籍(尤其渝东南 / 渝东北),**重大 / 西大 / 西政 等本省 985/211 都有专项指标**(分数比统招低 20-30 分)
   - **少数民族加分**:**渝东南土家族 / 苗族 + 5-15 分**(根据具体县区政策),报本省院校时优势更大
   - **强基计划**:数学 / 物理 / 化学 / 生物 单科特别强的农村学生有机会(重大强基)
   - **西南大学公费师范定向回原县**:渝东南 / 渝东北 农村孩子读西大公费师范 + 毕业直接回原县中学,**零风险跨阶级**

**典型 case**:
- 黔江土家族农村家庭 → 孩子 590 分物理类 → 通过**国家专项 + 民族加分**进**重庆大学采矿工程**(冷门但西部矿冶央企对口)→ 985 牌子 + 西部矿冶央企编制路径,**整个家族第一个 985**
- 武隆农村女孩 → 605 分文史类 → 推**西大公费师范汉语言** → 4 年无学费 + 毕业回武隆中学编制,**最适合农村家庭的"零风险"路径**
- 巫山三峡库区农村男生 → 545 分物理类 → 推**陆军军医大学**(包学费 + 包分配 + 军官编制),**8 年后中尉军衔 + 三甲军医院,跨阶级最快路径**

| 家庭档 | 关键词 | 推 | 避 |
|---|---|---|---|

| ② 专业人员 | 子承父业 + 拐杖最大化 | 西大公费师范(教师)/重医临床(医生)/西政法学(律师) | 完全无父母资源的领域 |
| ③ 私企/创业 | 可冒险 + 上限高 | 重大经管/西南财经/中外合作/出国 | 体制内基层 |
| ④ 普通工薪 | 编制 + 稳定 | 西大公费师范/陆军军医/重医医学技术/重邮通信/重大电气 | 双非金融CS/生化环材/临床医学长周期 |
| ⑤ 农村/临工 | 牌子 + 100% 编制 | 国家专项+重大/西大公费师范/陆军军医/民族加分 | 长周期投入/出国/双非折腾 |

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 重庆视角的总览金句

> "**重庆工薪家庭独子男 + 留渝心态强 → 走稳的**——**陆军军医 / 重大电气进国网 / 重邮通信进华为 / 西大公费师范** 这四条是重庆普通家庭的 4 大铁饭碗路径,对应不同分数段。"

> "**渝东南 / 渝东北农村孩子,先把民族加分 + 国家专项 + 公费师范这三个杠杆拉满**,这是重庆农村家庭专属的"低门槛 985 + 编制"组合拳——比江浙农村孩子还多一层杠杆(民族优惠)。"

> "**重庆体制内家庭别迷信"出省名校"**——孩子毕业去深圳上海卷不动金融 / 互联网,被父母劝回渝考公,**两年青春损耗**。**走西政法学 + 重大经管 + 重庆选调** 这条路,资源全用上,起点更高。"
