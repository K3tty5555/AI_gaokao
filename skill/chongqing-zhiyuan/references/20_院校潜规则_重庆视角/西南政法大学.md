# 西南政法大学(西政,SWUPL)— 双非但法学全国前 5

## 一句话定位

**双非牌子,但在司法系统等同于顶级 211**。**"五院四系"之一**(跟华政 / 中政 / 西北政法 / 中南财法 一档),法学全国前 5,**司法部 / 最高法 / 最高检 / 各省法检院** 校友遍布。**学法学的重庆 / 西部考生,西政是性价比最优解,认可度比许多 211 法学高**。

---

## 真实地位

- **双非**(没有 211 牌子,**也没有"双一流"**),但**法学是教育部 A 级学科评估 / 全国前 5**。
- **"五院四系"**老牌:五院 = 西政 / 华政 / 中政 / 西北政法 / 西南政法 等(实际口径上"五院"通常指中政 + 华政 + 西政 + 西北政法 + 中南财法 5 所政法院校),**西政 = 老牌政法五院之一**,新中国法律人才培养摇篮。
- **重庆本省地位**:**法学顶级**,**留渝考公 / 进法检院 / 律所** 认可度比重大法学高得多——这是重庆志愿填报最反直觉的事。
- **西部 / 西南地区(川黔滇藏渝)司法系统的"西政帮"是真的**:本科直接进体制(检察官 / 法官 / 公务员)路径在西部省份极强。
- 校区在**渝北区 / 沙坪坝区(老校区)**,渝北校区为主校区,环境一般,但**地理位置在重庆主城**,实习方便。

---

## 司法考试 / 法考通过率(西政核心招牌)

- **西政法考通过率长期全国前 5**(跟华政 / 中政 / 五院 一档),**首次通过率约 50-60%**(全国平均 13-15%)。
- **西政学生大三 / 大四就开始备考法考**——这是西政文化的一部分。
- **法考 + 公务员考试 + 选调** 是西政三大主流出路。

## 法检院校友网络(西政帮)

- **司法部 / 最高人民法院 / 最高人民检察院** 西政校友比例可观。
- **重庆 / 四川 / 贵州 / 云南 / 西藏 法院 + 检察院** 西政校友占主导地位——**西政帮在西部司法系统是真的**。
- **重庆律协 / 各大律所(中豪 / 华立 / 索通 等)** 西政人是主力。
- **国家司法考试命题专家 + 各高校法学院教授** 西政校友众多。

## 性价比专业(西政独家招牌)

- **侦查学**:**全国第 1**,**直接进公安系统**(警校体制 + 公务员身份),录取分相对法学低,**普通家庭男生稳进体制路径**。
- **经济法 / 民商法**:**学律师做经济法方向**——西政经济法是发源地,律所认可度顶级。
- **法学 + 英语双学位**:**进涉外律所必修**,**中豪 / 君合 / 金杜 等顶级所招涉外法务必看**。

## 坑专业(在西政里相对弱)

- **行政管理 / 公共事业管理**:**水专业**,西政非法学专业整体一般。
- **新闻传播 / 广告学**:西政文科边缘,**学新闻别选西政**(去武大 / 华科)。
- **经济学 / 金融学**:**远不如西南财经 / 中南财法**,西政经济类只是法学陪衬,**别报西政非法学专业**——这是西政的核心提醒。
- **管理科学**:水牌子,**西政全部价值在法学**。

## 重庆物理类录取位次区间

参考近 5 年掌上高考 + 重庆一分一段表(粗略):

- **顶级组(法学 / 经济法 / 民商法 / 法英双学位)**:全市 **5,000-9,000 名**。
- **主流组(法学一般方向 / 侦查学)**:全市 **9,000-13,000 名**。
- **冷门组(行政管理 / 经济学边缘)**:全市 **13,000-18,000 名**。

## 重庆历史类录取位次区间(西政历史类大头!)

- **顶级组(法学核心 / 经济法 / 民商法)**:全市 **1,500-3,500 名**。
- **主流组(法学一般 / 国际法 / 侦查学)**:全市 **3,500-5,500 名**。
- **冷门组(行政管理 / 新闻 / 文科边缘)**:全市 **5,500-9,000 名**。

**段位定位**:**重庆历史类前 9,000 名 / 物理类前 18,000 名内可冲西政**。**法学核心专业要前 3,500 名(历史)/ 9,000 名(物理)**。**以一分一段表反查为准,不编分数**。

**关键提醒**:**西政分数高于很多 211 普校**,**不要因为是"双非"觉得占便宜**——西政法学录取分长期高于重大法学,部分年份甚至高过重大经管。

## 毕业出口(成渝双城 vs 出省东部)

- **留成渝就业**:**约 50%**(重庆 35% + 成都 15%),**重庆 / 四川法检院 + 律所** 西政对口最强。
- **出省(沪苏京广深)就业**:约 25-30%,主要是顶级律所(君合 / 金杜 / 中伦 等)+ 央企法务 + 互联网大厂法务。
- **考研 / 读博**:约 20-25%(保研率约 8-10%,双非里高的)。
- **考公 / 选调**:**约 30-35%**——**西政考公比例在所有重庆高校里最高**(法学是考公王者专业,西政对口)。
- **进体制(法检院 / 公务员 / 选调)**:**约 35-40%**——这是西政独家的"铁饭碗率"。
- **进律所**:约 25%(顶级律所 + 各类省市律所)。

**直白讲**:**西政毕业生 80% 进体制 / 律所**——这是法学专业的本质。**学法学进西政 = 留渝考公考编 / 进法检院 / 当律师** 三选一,**全是稳定铁饭碗路径**。

| 法学顶级度 | **A 全国前 5** | A+ 全国第 1 | A 全国前 5 | A 全国前 5 | B+ 末流 |
| 牌子 | **双非** | 211 | 双非 | **211** | 985 |
| 五院四系 | **是** | 是 | 是 | 是(财法结合) | 否 |
| 地理 | 重庆 | 北京 | 上海 | 武汉 | 重庆 |
| 西部司法认可 | **极高** | 高 | 中 | 中 | 中 |

**简单结论**:**学法学留西部 / 留渝 → 西政性价比顶级**;**学法学冲北京央政机关 → 中政首选**;**学法学留长三角顶级律所 → 华政首选**;**学法学财经结合 + 留中部 → 中南财法**;**重大法学不要选,差距太大**。

## 适合谁

- 重庆 / 四川 / 西部 物理类 **5,000-18,000 名** / 历史类 **1,500-9,000 名** + **明确想做律师 / 法官 / 检察官 / 公务员** 的考生。
- **女生学法学求稳进体制** → 西政考公 / 进法检院是顶级路径。
- **男生学侦查学进公安系统** → 西政侦查学全国第 1。
- 普通家庭 + 想用法学跨阶级 + 不在意双非牌子 + 看重行业认可度 + 重庆人嘛**直爽**接受现实的考生。
- 想留成渝 / 西部 + 考公考编铁饭碗 + 不想出省卷的考生。

## 不适合谁

- **不是真的想学法学 / 只是想要法学牌子**:**法学行业整体卷**,西政法学每年毕业 3000+,**法考通过率 60% 也意味着 40% 通不过**——做好准备。
- **想学财经金融**:**西南财经 / 中央财经 / 上财 远胜西政**,别在西政学经济。
- **想出省冲互联网金融大厂**:西政在沪苏深认可度不如华政,**学法学出省去华政或中政更对口**。
- **家庭条件好 + 想做顶级律师**:**清北复人 / 华政 / 中政 顶级律所认可度更高**,西政性价比但不是顶配。
- **不想做体制 / 律师**:法学专业本身就是冲体制 / 律师方向,不想走这条路别选法学。
- **嫌弃双非牌子的家长**:西政是行业牌子不是综合排名牌子,**家长心理预期调好**——司法系统等同顶级 211,但综合排名榜单会觉得"双非好像不行"。
