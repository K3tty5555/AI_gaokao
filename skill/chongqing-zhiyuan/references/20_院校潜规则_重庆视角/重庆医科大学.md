# 重庆医科大学(重医,CQMU)— 双非但临床医学全国前列

## 一句话定位

**双非牌子,但临床医学全国前 20**。**重庆 + 川渝医院大本营**,**80% 重庆医生从重医毕业**——重庆人民医院 / 各区县医院 / 川渝二线医院 全是重医校友。**学医留渝 = 重医 > 重大医学院**,差距很大。**报重医就是为了学医,其他专业别报**。

---

## 真实地位

- **双非**(没有 211 牌子),但**临床医学是教育部 A- / 全国前 20**——医学院校排名跟综合大学排名是两套体系,别混。
- **1956 年由上海第一医学院(现复旦上海医学院)西迁分建**——根正苗红的"上医一脉",**学风严谨,临床实力强**。
- **重庆本省地位**:**重庆医院系统的主导力量**——重庆医科大学附属第一医院 / 第二医院 / 儿童医院 都是重庆顶级医院,留渝当医生**重医是首选**。
- **同档对比**:跟**首都医科大 / 南京医科大 / 哈尔滨医科大 / 中国医科大** 一档(都是双非但临床顶级的医科大学),低于"协和 / 北医 / 复旦上医 / 华西 / 湘雅 / 同济医" 一线医学院。
- 校区分散:**袁家岗校区(老校区,主城)/ 缙云校区(大学城)/ 第一临床学院 / 儿研院** 等,**前两年大学城**(虎溪 / 缙云一带)**后期回主城实习**——心理预期调好。

## 性价比专业(重医独家招牌)

- **儿科学**:**重医儿研院全国前 5**,**儿科医生全国短缺,重医儿科毕业进儿童专科医院是稳的**——但**儿科是医学里最累的科室之一**,做好心理准备。
- **临床医学 5+3 一体化**:**5 年本科 + 3 年规培 = 8 年医生养成**,重医在重庆三甲医院的对口分配率高,**留渝当主治医师的标准路径**。
- **药学**:**药企 / 医院药剂科** 双向出路,比临床轻松一些 + 收入中等稳定。
- **护理学**:**本科护士在三甲医院起薪 6-10k**,女生稳定铁饭碗路径,但护理工作辛苦 + 三班倒。

## 坑专业(在重医里相对弱 / 注意!)

- **重医只有医学相关专业,没有其他专业**——这是重医的特点。**报重医就是为了学医**,**没有医学之外的好专业**。
- **生物医学工程 / 医学技术**:**算医学边缘**,出口窄,**学这些不如直接学临床**。
- **法医学**:**冷门 + 工作环境特殊(尸检)**,**心理承受力差的别报**。
- **预防医学 / 公共卫生**:CDC 编制少 + 出口窄,**不如临床医学**——但**疫情后公卫地位有所上升**,中等性价比。
- **思想政治教育 / 英语**(医学院校的非医学专业)**水牌子**,别报。

## 重庆物理类录取位次区间

参考近 5 年掌上高考 + 重庆一分一段表(粗略):

- **顶级组(临床医学 8 年制 / 5+3 一体化 / 儿科学)**:全市 **3,500-7,000 名**。
- **主流组(临床医学 5 年制 / 口腔 / 药学)**:全市 **7,000-12,000 名**。
- **冷门组(预防 / 检验 / 护理 / 医学技术)**:全市 **12,000-20,000 名**。

**段位定位**:**重庆物理类前 20,000 名内可冲重医**,**前 7,000 名内可挑临床顶级组**。**以一分一段表反查为准,不编分数**。

## 重庆历史类录取

重医历史类招生量小(主要是英语 / 思政等非医学专业),**不是文科考生主选**。学医必须选物理类(化学 + 生物组合),历史类报重医基本是**水专业陪跑**,慎报。

---

## 毕业出口(成渝双城 vs 出省东部)

- **留成渝就业**:**约 65-70%**(重庆 50%+ 成都 15-20%)——**重医毕业留渝率是重庆所有高校里最高的**,因为**重庆 / 川渝医院体系全是重医校友**。
- **出省(沪苏京广深)就业**:约 10-15%,主要是 8 年制博士 / 顶级硕士去东部三甲医院。
- **考研 / 读博 / 5+3 升 8 年制**:**约 60%+**——**学医必须读研,本科直接就业很难进三甲**。
- **出国**:约 3-5%(部分去美国 / 欧洲做博后)。
- **进医院体制(三甲医院 / 区县医院 / 编制岗)**:**80%+**——**学医本质就是进医院**,这是医学教育的特点。

**直白讲**:**重医毕业生 80% 留成渝当医生**——这是重医的核心定位。**想出省卷北京上海三甲?重医本科很难**,**要 8 年制 / 优秀硕博才有机会**。**留渝当三甲医生 = 重医的标准路径**。

**学医的现实**(重要!):
- **8 年制起步月薪 8-15k**,**30 岁前别想买房**(规培期 + 主治医师晋升期)。
- **三甲医院主治医师 35 岁后才稳定**,**副主任医师 40+,主任医师 45+**。
- **学医苦** + **三班倒** + **医患关系紧张** + **工作强度大**——**家庭抗风险弱的慎重报**。

## 同档对比

| 维度 | 重医 | 华西医(川大) | 协和 / 北医 | 湘雅(中南) | 重大医学院 |
|---|---|---|---|---|---|
| 临床顶级度 | **全国前 20** | **全国前 5** | **全国第 1-3** | **全国前 5** | 末流(新建) |
| 牌子 | 双非 | **985** | 985 / 协和 | **985** | 985 |
| 留渝当医生 | **顶级首选** | 中(成都为主) | 出省顶级 | 出省 | **远不如重医** |
| 录取分 | 中(双非) | 高(985 + 顶级医) | **极高** | 高 | 高(985) |
| 性价比 | **顶级** | 中等 | 顶级但门槛高 | 中等 | 差(远不如重医) |

**简单结论**:**学医留渝 → 重医首选**;**学医冲西部顶级 → 川大华西医 / 中南湘雅**;**学医冲全国顶级 → 协和 / 北医 / 复旦上医**;**重大医学院不要选**——**重医 > 重大医学院**,差距很大,这是重庆医学填报的核心反直觉点。

## 适合谁

- 重庆 / 四川 / 西部 物理类 **3,500-20,000 名** + **明确想当医生 + 想留渝 / 川渝** 的考生。
- **能接受 8 年起步学医周期 + 工作强度大 + 30 岁前不富裕** 的考生。
- 家庭抗风险强(可以养孩子到 30 岁主治医师为止)+ 看重稳定铁饭碗的家庭。
- 想做儿科医生 → **重医儿科全国前 5,独家招牌**。
- 想做药学 / 药企方向 + 不想做临床的考生 → 重医药学是好选择。
- **重庆人想当医生但分数够不到湘雅 / 协和 / 华西** → 重医是退而求其次的稳路径。

## 不适合谁

- **不确定要不要学医**:学医是一辈子的事,**不喜欢医学别冲重医**,中途转专业极难(医学课程跟综合大学完全不同)。
- **家庭抗风险弱 / 必须早工作早赚钱**:**8 年起步学医周期太长**,普通家庭吃不消——可以**考虑陆军军医大学(军编 + 包分配 + 月津贴)**。
- **想出省去东部互联网金融大厂**:学医出口就是医院,**不是 IT / 金融 / 法律 灵活路径**。
- **怕脏 / 怕累 / 怕三班倒 / 怕医患**:重医临床本科 + 实习 + 规培,**4-8 年都在医院熬夜**,做好准备。
- **数理化基础薄弱**:**学医背书量大 + 解剖 / 生化 难度高**,理科基础差吃力。
- **想学医但又想综合性大学体验**:**川大华西医 / 中南湘雅 / 协和北医 是综合性顶级医**,但分数高一档,慎重抉择。
