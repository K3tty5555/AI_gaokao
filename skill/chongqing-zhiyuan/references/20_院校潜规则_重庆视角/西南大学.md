# 西南大学(西大,SWU)— 211 师范+农林双一流

## 一句话定位

**重庆唯一 211**,北碚校区,**师范 + 农林 + 心理 + 蚕学** 特色。**重庆 70% 中小学老师从西大毕业**,公费师范是留渝当老师的标准路径。**师范不进西大可惜,非师范进西大浪费 211 牌子**——这是西大最反直觉的事。

---

## 真实地位

- **211 + 双一流**,**部省合建**(教育部 + 农业农村部 + 重庆市 共建)。
- **不是教育部直属六大师范**(北师 / 华东师 / 华中师 / 东北师 / 陕师 / 西南大学一直在边缘——严格讲西大是合并校,师范只是其中一支)。
- **2005 年由原西南师范大学 + 西南农业大学合并而来**——所以**师范 + 农林**双轨,这是西大独有的基因。
- **重庆本省地位**:**师范类首选**,公费师范留渝编制 + 重庆中小学优先招聘。
- **同档对比**:综合排名 211 中段,跟**华农 / 北林 / 东华 / 河海 / 华师** 一档。比 985 弱半档,但师范 / 农林 / 心理 / 蚕学是真顶级。
- 校区在**北碚**(主城区西北方向,从市区开车 1 小时),**远离市中心,生活气息浓但娱乐少**——心理预期调好。

## 性价比专业(西大独家牌子)

- **公费师范 / 优师计划**:**留渝当老师铁饭碗**,签约后免学费 + 包毕业去向(重庆中小学编制),**普通家庭女生跨阶级稳路径**。
- **蚕学 / 茶学**:**全国第 1 / 第 2**,冷门但**就业率高 + 央企对口** + 录取分相对低。
- **心理学**:**全国前 15**,师范类强 + 重庆心理咨询 / 教育心理学 出口稳定。
- **马克思主义理论**:**考公选调神器**,西大马院全国前 20。

## 坑专业(在西大里相对弱)

- **CS / 软件工程**:**远不如重邮 / 电子科大**,西大 CS 中下水平,**学 CS 别选西大**。
- **法学 / 行政管理**:不如**西政 / 重大**,师范综合校的法学是水牌子。
- **金融 / 经济学**:不如重大经管,更不如出省的西南财经(成都),**学财经别在西大将就**。
- **非师范工科**(机械 / 化工 / 材料):西大工科非主线,**学工科直接选重大**。
- **新闻传播**:水专业,西大不强。

## 重庆历史类录取位次区间

- **顶级组(教育学 / 心理学 / 中文师范 / 公费师范)**:全市 **2,500-5,000 名**。
- **主流组(历史 / 哲学 / 一般文科师范)**:全市 **5,000-9,000 名**。

**段位定位**:**重庆历史类前 9,000 名 / 物理类前 22,000 名内可冲西大**。**以一分一段表反查为准,不编分数**。

## 毕业出口(成渝双城 vs 出省东部)

- **留成渝就业**:**约 60-65%**(重庆 45% + 成都 15-20%),**师范类几乎全部留渝当老师**——这是西大的核心定位。
- **出省(沪苏京广深)就业**:约 15-20%,主要是心理学 / 食品 / 部分理学考研后跨专业出去。
- **考研 / 读博 / 保研**:约 25-30%(保研率 ~13%,211 中段)。
- **出国**:约 3-5%。
- **考公 / 选调**:约 20%(**马院 / 行政管理 / 法学 出选调多**)。
- **进编制(教师 / 公务员)**:**约 40%+**——这是西大独家的"铁饭碗率",在 211 里相当高。

**直白讲**:**西大 = 留渝当老师的最稳路径**。想出省卷一线大厂 / 互联网,西大牌子不够用——但**留渝当老师 + 考公 + 进农林央企** 这三条铁饭碗路径,西大是性价比之王。

**简单结论**:**学师范留渝 → 西大公费师范首选**;**学心理 / 蚕学 / 茶学 / 农林 → 西大独家**;**学工科 / CS → 重大或重邮**;**想出省当中学老师 → 华师(教育部直属)更对口**。

## 适合谁

- 重庆物理类 **9,000-22,000 名** / 历史类 **2,500-9,000 名** + 想留渝当老师 / 进编制的考生。
- **女生 + 普通家庭 + 想要稳定教师铁饭碗** → 公费师范是顶级 ROI 路径。
- 想做心理咨询师 / 教育心理学方向 + 不想出省的考生。
- 想搞**农林 / 蚕学 / 茶学 / 食品** + 不在意冷门 + 求稳的考生。
- 留北碚生活节奏慢 + 性格内向 + 想要安稳大学体验的考生。

## 不适合谁

- **学 CS / 互联网方向**:别在西大学 CS,**重邮 / 电子科大 / 重大 都比西大强**。
- **学财经金融**:**西南财经(成都)/ 中央财经 远胜西大**,别在西大将就。
- **想做大律师 / 法官 / 检察官**:**西政 > 西大法学**,差距很大。
- **不想当老师**:在西大学非师范是浪费 211 牌子,**这话讲难听点你必须接受**。
- **想出省进互联网金融大厂**:西大牌子在沪苏深认可度有限,出省卷不过同分 211。
