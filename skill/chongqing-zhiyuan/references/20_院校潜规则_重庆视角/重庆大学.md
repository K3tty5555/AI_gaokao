# 重庆大学(重大,CQU)— 综合性 985 第二档

## 一句话定位

**重庆唯一 985,本省心理上限**。综合排名 30 名外的**985 第二档**(跟兰大 / 东北 / 中海大 / 中农 一档),**老牌机械 / 土木 / 电气 / 建筑老八校** 是真招牌,但 CS / 法学 / 文科 / 医学都是末流 985 水平。**别拿重大当复旦看**——它更像兰大。

---

## 真实地位

- **985 + 双一流**,综合排名长期在 30-40 名,**985 第二档**(末流但不至于最差)。
- **建筑老八校之一**(跟天大 / 同济 / 哈工大 / 东南 / 西建大 / 华南理工 / 清华 一脉),建筑学 / 土木 行业认可度顶级。
- **重庆本省地位**:**心理上限**——重庆考生分够就冲,本地家长普遍认为"重庆人就该读重大"。
- **同档对比**:跟兰州大学 / 东北大学 / 中海大 / 西北农林 / 中国农大 一档,**比中南 / 湖大 / 山东大 / 厦大 弱半档**。
- 校区分散:A 区(老校区,沙坪坝)/ B 区(沙坪坝)/ C 区(虎溪,新校区)。**虎溪偏远但新生几乎都在虎溪**,心理预期要调好。

---

## 性价比专业

- **采矿工程 / 冶金工程**:**录取分相对低**,**毕业进西部矿冶央企稳**(中铝 / 中铜 / 西部矿业),冷门但铁饭碗。
- **电气工程**:进**国家电网西南片区(川渝藏)** 是稳的,起薪 12-18w + 编制。
- **建筑学**:**老八校牌子在设计院顶级**,虽然房地产下行但央企设计院还吃这个牌子。

## 坑专业(顶级 985 牌子救不了)

- **CS / 软件工程**:全国 30-40 名,**比电子科大 / 重邮 弱**——**学 CS 分够别在重大将就,选成都电子科大**。
- **法学 / 新闻 / 中文**:重大文科边缘,**学法学直接选西政**(虽然双非但法学全国前 5)。
- **医学(重大医学院新建)**:**远不如重医**,重庆人留渝当医生**重医 > 重大医学院**,别报错。
- **农林**(几乎没这块):报错就是浪费 985 牌子。
- **生化环材**:典型天坑组合,985 牌子救不了"必须读博"的现实。

## 重庆物理类录取位次区间

参考近 5 年掌上高考 + 重庆一分一段表(粗略):

- **顶级组(建筑 / 电气 / CS 高分组)**:全市 **1,500-3,500 名**。
- **主流组(机械 / 土木 / 化工 / 自动化)**:全市 **3,500-6,500 名**。
- **冷门组(采矿 / 冶金 / 部分文科理科基础类)**:全市 **6,500-10,000 名**。

**段位定位**:**重庆物理类前 10,000 名内可冲重大**,**前 3,500 名内可挑王牌组**。**以一分一段表反查为准,不编分数**。

## 重庆历史类录取位次区间

- **主流组(经管 / 法学 / 文科类)**:全市 **1,200-3,000 名**。
- 历史类招生量小,**文科考生想冲重大要前 3,000 名内**。

---

## 毕业出口(成渝双城 vs 出省东部)

- **留成渝就业**:**约 50-55%**(重庆 30-35% + 成都 15-20%),**重大在成渝双城认可度顶级**——重庆本地央企 / 国家电网西南 / 长安汽车 / 重庆设计院都吃重大牌子。
- **出省(沪苏京广深)就业**:约 25-30%,**主要是 CS / 金融方向出省**,出去打互联网大厂或一线设计院。
- **考研 / 读博 / 保研**:约 25%(保研率 ~20%,985 中段水平)。
- **出国**:约 5-8%。
- **考公 / 选调**:约 15-20%(**重庆 / 四川选调指标多**,经管 + 工科 都友好)。

**直白讲**:**重大毕业生 70% 留成渝**,这是重庆 985 的归宿——**留渝舒服 + 父母近 + 房价友好**,出省卷不动东部 985 的考生,留成渝就是对的选择。

## 同档对比

| 维度 | 重大 | 兰大 | 中南 | 电子科大 |
|---|---|---|---|---|
| 综合排名 | 30+ | 30+ | 25-30 | 30+ |
| 985 档位 | **末流** | 末流 | **中段** | 中段 |
| 王牌 | 建筑/电气/机械/土木 | 数学/化学/草学 | 矿冶/材料/交通 | **CS/电子顶级** |
| 地理 | 重庆 | 兰州 | 长沙 | **成都(成渝双城)** |
| CS | 中等 | 弱 | 中上 | **顶级** |
| 文科 | 弱 | 中 | **强(文新)** | 弱 |
| 留本省舒服度 | **高** | 中 | 高 | **高** |

**简单结论**:**学建筑 / 电气 / 机械 / 土木 → 重大首选**;**学 CS / 电子 → 分够选电子科大(成都,成渝双城任选)**;**学综合性留中部 → 中南**;**分够冲华五五院别在重大将就**。

## 适合谁

- 重庆 / 四川物理类 **省排 1,500-10,000 名** + 想留成渝 + 要 985 牌子的考生。
- 笃定走 **建筑 / 电气 / 机械 / 土木 / 城规** 行业,认央企对口路径的男生。
- **国家电网西南片区 / 长安汽车 / 重庆设计院 央企铁饭碗** 路径的考生。
- 想留渝考公考编 + 用 985 牌子做敲门砖的本地考生。
- 不想离开成渝 / 父母舍不得放孩子去东部的家庭。

## 不适合谁

- **学 CS 分够 600+**:别在重大将就,选**电子科大成都 / 西电 / 北邮**。
- **学医**:**重医 > 重大医学院**,留渝当医生别选重大。
- **学法学**:**西政 > 重大法学**,差距不止一档。
- **想冲华五 / 北航复交一线 985**:重大兜不住一线 985 的对标。
- **想去东部互联网金融大厂**:重大牌子在沪苏深不如同分东部 985 / 强 211(华师 / 上财 / 北邮 / 西交)。
