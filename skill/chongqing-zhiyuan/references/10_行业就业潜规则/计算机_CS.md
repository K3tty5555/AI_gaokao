# 计算机科学与技术 / 软件工程(CS / SE)— 重庆视角

## 一句话总结

**CS 已经过了"闭眼报"的黄金时代**。重庆考生学 CS 有两条不同结局:**走出去去成都 / 北上深 → 还能吃到红利;留渝 → 重庆 IT 生态比成都弱一档,起薪天花板压得死**。**双非以下的 CS 在重庆几乎等于"码农培训",别再做"敲代码进大厂"的旧梦**。

---

## 真相 1:寒冬是阶段性的,但分化是结构性的

- 2022-2024 互联网大厂裁员潮(腾讯 / 阿里 / 美团 / 字节大幅优化),应届生 offer 数量比 2020 年峰值少了至少 30%。
- **头部学校 CS 学生仍然有 35w+ 起薪**,但中下层学校的学生从 15w 起薪掉到 8-10w,**两极分化加剧**。
- 行业总需求仍在(AI / 芯片 / 云计算),但门槛抬高 — 没有 985 学历或过硬项目经验,简历进不了筛选系统。

**结论**:CS 不是不能学,但**学校决定一切**。重庆考生想学 CS,**电子科大(成都)/ 重邮 / 重大** 是三道分水岭——过这道线值得读,过不了就要重新评估。

---

## 真相 2:35 岁危机存在,但不是所有 CS 人都会被淘汰

- 35 岁危机集中在**业务型程序员**(增删改查 / CRUD / 调用别人的轮子)。
- **核心技术岗(底层 / 算法 / 架构 / 芯片)的 35 岁不是危机,是黄金期**,薪资还在涨。
- 区别:你是"会写代码的人"还是"懂技术的人"。

**结论**:目标是核心技术岗,本科就要有意识训练算法 / 底层 / 数学。**重邮的通信信号处理 / 重大的电气控制 这两条非纯 CS 路径,反而更容易走到底层岗**(信号 / 控制 / 嵌入式人才比"前端切图仔"耐造)。

---

## 真相 3:本科 < 硕士的差距越来越明显

- 5 年前 985 本科 CS 毕业可以直接拿 SP offer,现在 985 本科 CS 起薪可能跟 211 硕士差不多甚至略低。
- 大厂校招在向"硕士起步"倾斜,本科想拿好 offer 必须**实习 + ACM + 项目**三件套都拿到顶。
- **重庆考生学 CS 一个特殊现实**:重大 / 重邮 本科出来想去深圳腾讯 / 字节 / 华为,**没硕士打底很被动**——成都电子科大的本科生在大厂里口碑明显比重大本科生硬,这是事实。

---

## 真相 4:转码内卷已经到顶

- 2018-2022 年大量文科 / 工科生通过培训班转码成功,这个窗口已经关闭。
- 现在企业对"科班 CS"的偏好极强,**非科班想转码越来越难**。
- 想吃 CS 的红利,本科就该选 CS,中途想转的窗口已经很窄。

---

## 适合什么人

- **数学好**(高中数学 130+,这是硬指标)
- **抗压能力强 + 不怕加班**
- **有自学能力**,因为大学课程跟不上行业实际需求
- **985 出身,或者愿意读研甚至读博**
- **家庭中产**,能撑 4 年读书 + 设备 + 实习城市生活成本(去深圳 / 杭州 实习半年都是 2-3w 开销)

## 不适合什么人

- **数学差**(高中数学 110 以下慎重)
- **追求安稳生活、不想 996**(留渝心态强但选 CS = 路径不一致)
- **双非家庭 + 不打算考研**(这个组合学 CS 等于浪费 4 年)
- **学校层次不够 + 个人没有强自学动力**
- **女生中讨厌技术钻研只想图高薪的**(行业对女性有客观存在的隐性歧视)

---

## 重庆视角 — 本地 CS 院校真实分层

### 第一梯队(全国可比 / 走出去吃红利)

- **电子科技大学(成都)CS / 软件工程** — 严格说不是重庆学校,但**成渝双城就业一体**,川渝考生很多人冲电子科大,**本地家长普遍把电子科大列为"第一选择"**。CS 全国前 10,毕业去华为 / 腾讯 / 字节硬通货。重庆考生分够 640+ 物理类基本只去这里,不会留重大。
- **重庆大学 CS / 软件工程** — 985,**全国 30-40 名,跟电子科大 CS 不在一个段**。本地认可度高、考公友好,但出省进互联网大厂明显比电子科大本科吃亏。**重大 CS 的真实定位:留渝考公 / 川渝央企 IT 岗 OK,冲深圳大厂吃力**。

### 第二梯队(重庆性价比之选 / 行业对口型)

- **重庆邮电大学(重邮)CS + 通信工程** — **双非但通信 / 电子全国前 10**,**原邮电部直属 6 校之一**(跟北邮 / 南邮 / 西邮 一脉)。**华为 / 中兴 / 三大运营商对口校招**,重邮通信 + CS 双向上是性价比之王。**学 CS 不能进电子科大就来重邮,不要在重大将就 CS**——重邮工科氛围比重大 CS 学院更纯粹,实习机会更对口。
- **重庆邮电大学 软件工程 / 物联网工程 / 网络空间安全** — 重邮的"曲线 CS"路径,**比直接报重邮 CS 录取分低 10-20 分**,毕业出口跟 CS 差不多(华为 / 运营商 / 中兴),性价比更高。

### 第三梯队(重庆本地认可,出省就业一般)

- **重庆理工大学 CS** — 一本中下,**军工背景(原兵工部直属)+ 长安汽车 / 重庆兵装集团对口**,毕业进本地装备制造业 IT 部 / 长安汽车软件中心 是稳的,但想冲互联网大厂吃力。**男生 + 留渝 + 进央企装备 IT 岗 → 重理工 OK**。
- **重庆交通大学 CS** — 一本中下,交通行业 IT 对口(中交 / 中铁 / 重庆交通规划院的智慧交通方向),**专业组要小众但对口**。
- **重庆师范大学 / 重庆工商大学 CS** — 师范 / 财经院校的 CS 是怪胎,**计算机+教育技术 / 计算机+电商 这种交叉方向,毕业出口窄**,**不推荐**。

### 第四梯队(避坑)

- **重庆的二本院校 / 民办院校 / 独立学院 CS** — **请直接避坑**。这一档学 CS 不如学护理、师范、会计等有明确出路的专业。普通家庭的孩子在这些学校学 CS 出来基本就业极差,你以为的"敲代码进大厂"不会发生,实际是**月薪 5-7k 的本地外包公司,3 年内被裁**。

## 重庆典型 case(供 agent 引用)

### Case A:重大 CS 男生(普通家庭 / 渝北 / 物理类 615 分)
- 重大 CS → 实习字节成都 → 校招拿到字节成都 SP offer 28w 起 → 留成渝
- **典型逆袭路径**:985 名校 + 行业红利 + 个人努力。**留成渝即吃到 CS 红利又留父母身边**——这是重庆考生学 CS 最理想的归宿。

### Case B:电子科大 CS 男生(中产家庭 / 沙坪坝 / 物理类 645 分)
- 电子科大 CS → 实习腾讯深圳 → 校招拿到腾讯深圳 SP offer 36w → 出省
- **顶配路径**,但要接受**离开成渝去深圳**的代价。家长心理预期要调好。

### Case C:重邮通信男生(工薪家庭 / 万州 / 物理类 595 分)
- 重邮通信工程 → 校招进华为成都研究所 起薪 22w
- **双非性价比之王**,留成渝 + 拿大厂薪。**比同分双非 CS 学校吃香一倍**。

### Case D(反面):重庆某双非 CS 男生(工薪家庭 / 涪陵)
- 二本独立学院 CS → 找不到 IT 工作 → 本地外包月薪 6k
- **典型踩坑**,家长以为"学了计算机就能赚钱",学校层次决定一切。**当时改成重邮通信 / 重交工程造价 / 西大公费师范 都是更稳的归宿**。

### Case E(反面):重庆某二本院校女生 CS(工薪家庭 / 黔江)
- 民办独立学院 CS → 培训机构销售 → 月薪 5k 跑路销售
- **女生 + 双非 + CS = 重灾区组合**。如果当时报重庆师范汉语言考公 / 重庆医科护理,**铁饭碗早到手了**。

## 给重庆家长的金句

> "**'计算机一定好就业'是 5 年前的认知**。今天的真相是:**电子科大 / 重大 CS 依然好就业,双非 CS 不如双非通信 / 师范**。重庆 IT 生态比成都弱一档,留渝学 CS 性价比更要看学校牌子。"

> "孩子分数够 640+,**直接冲电子科大,别在重大将就 CS**——电子科大本科去深圳大厂硬通货,重大本科得读研。差 20 分天差地别。"

> "孩子分数 580-620 段,**重邮通信 / 网安 / 物联网 比同分双非 CS 学校强一倍**——华为 / 运营商 校招直签,这是重庆双非里最顶的工科性价比。"

> "重庆家长最容易踩的坑是 — 觉得'重庆理工 CS 跟重大 CS 差不多',这俩**毕业薪资差 2-3 倍**,一个进长安汽车 IT 部月薪 8k,一个进字节成都月薪 25k+。"

> "重庆考生学 CS,记住成渝双城就业是底色——**留成渝是重庆考生的舒适区**,但**留渝的 CS 起薪比留蓉低 20-30%**(因为成都互联网生态比重庆好)。能去成都的尽量去成都,房价差一半但生态强一倍。"
