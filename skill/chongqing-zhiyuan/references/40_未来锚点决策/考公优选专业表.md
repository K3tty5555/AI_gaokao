# 考公优选专业表(重庆本地视角)

## 核心结论

**专业决定考公选岗范围**。重庆家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**重庆视角的特殊性**:
1. **直辖市编制密度高**——市级机关 + 38 个区县机关 + 街道办 + 事业单位编制密度比一般地级市高一档,**重庆市考岗位总量大 / 上岸概率高于四川省考、贵州省考**
2. **西部大开发岗位倾斜**——重庆部分艰苦地区(渝东南 / 渝东北)岗位有特殊政策(降分录取 / 安家补贴)
3. **西南地区选调走重大 + 西南大学 + 西政**——重庆三大本省重点是选调指标主战场
4. **公安联考的重头戏**——重庆警察学院公安联考通过率 90%+,是重庆考公里**确定性最高的铁饭碗路径**

## 关键事实(2024 国考 / 重庆市考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 重庆市考特殊性

- **重庆市考 + 各区县考,汉语言文学和法学并列考公第一专业**
- **重庆作为直辖市,编制密度高于多数省份**——市级机关(市委 / 市府 / 市政协 / 市监委)+ 38 个区县机关 + 各街道办,**法学 / 汉语言 / 经济学 三类专业可报岗位比四川省考多 30%+**
- **重庆各区县公务员岗位对法学要求高**(法院、检察院、司法局)— **西政是重庆司法系统校友网最强**
- **基层乡镇 / 渝东南 / 渝东北公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流;**渝东南山区岗位有民族优惠 + 安家补贴 + 降分录取**(尤其黔江 / 武隆 / 石柱 / 秀山 等)
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)

### 选调生(不是普通公务员,是高潜力路径)

- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(重庆本地的选调生定向计划基本只对 **重大 / 西大 / 西政 + 部分省外 985/211**)
- **重庆选调生定向高校**:**重大 + 西大 + 西政 是三大主战场**;部分定向计划放给电子科大 / 川大 / 西南交大(成都 985/211 也算川渝地区"自家娃")
- 优势专业:**法学(西政顶级)、汉语言文学、马克思主义理论、行政管理、经济学**

### 公检法岗位的硬要求

- **公安**:多数岗位要求"公安专业"(中国人民公安大学、**重庆警察学院** 等)+ 通过公安联考。**重庆警察学院是重庆考公确定性最高的铁饭碗路径**(联考通过率 90%+,远高于市考)
- **法院 / 检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)。**西政是西部司法系统认可度最高的法学院**,五院四系成员
- **监狱、戒毒**:法学 + 监狱学,**西政侦查学 + 监狱学**对口

## 重庆本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业

- **西南政法大学 法学 / 经济法 / 国际法 / 侦查学** — **法学全国前 5**,**重庆司法系统校友网最强**,**法考通过率全国前列**,**等同于 211 法学认可度**
- **重庆大学 法学 / 经济学 / 工商管理** — 985 牌子,**法学是重大弱专业(双非西政完爆重大法学)**,但 **985 牌子加经济学 / 经管 + 选调路径**有优势
- **西南大学 公费师范汉语言文学 / 教育学 / 行政管理** — 211,**选调生主战场之一**,公费师范是教师编制专属路径(等同考公友好)
- **西南大学法学 / 经济学** — 211 牌子下中等学科,**比双非考公友好,但法学不如西政**

### 双非 + 性价比考公专业

- **重庆师范大学 汉语言文学 / 法学** — 双非,**重庆本地考公王者**,毕业考公成功率高,**重庆区县机关 + 街道办 + 重庆区县中学(语文老师编制)双向稳**
- **重庆工商大学 会计学 / 财政学 / 税收学** — 双非,**重庆财税系统对口**,毕业进重庆国税 / 地税(已合并为税务局)/ 财政局 的概率较高
- **重庆理工大学 法学 / 知识产权** — 双非,**军工背景**,毕业进重庆军工央企法务 / 区县机关 OK
- **西南政法大学 行政管理 / 经济学**(西政非法学专业)— 在西政里相对弱,但**借西政司法系统校友网仍可考公**

### 公安系统专属

- **重庆警察学院** — 本科,**公安联考路径,毕业进重庆本地公安概率极高**(基层警察)— ★ 重庆考公确定性最高路径,**联考通过率 90%+**,**普通家庭男生求稳的标准答案之一**
- **西政侦查学 / 监狱学** — 进司法系统(法院 / 检察院 / 监狱)
- **中国人民公安大学 / 中国刑警学院**(出省顶配)— 重庆考生分够也可冲

### 军校 / 军编制路径(重庆独家)

- **陆军军医大学** — 军方编制,**包学费 + 包分配**,毕业进军队医院系统(西南医院 / 新桥医院 / 大坪医院)
- **武警警官学院 / 陆军勤务学院 / 陆军边海防学院**(都在重庆)— 普通家庭男生军编制路径,**比公务员考更早进编**

## 重庆典型 case(供 agent 引用)

- **Case A(逆袭路径)**:涪陵考生,540 分文史类,**普通家庭独生女**。家长本想报"国际经济与贸易"(听起来高大上)。**改报重庆师范大学汉语言文学**,毕业当年考上涪陵区委办公室,**家庭命运改变**——**重庆作为直辖市,涪陵区编制密度比四川省的同档地市州高,汉语言考公成功率本来就高一档**。

- **Case B(选调路径)**:沙坪坝考生,650 分文史类,中产家庭。家长想报"金融"(西南财经成都)。**改报西南政法法学**,**毕业获得西政选调生资格(西政是重庆三大选调高校之一),直接进重庆市委组织部**,**起点远超经济学就业**——西政在重庆司法 + 政法系统的校友网是顶级配置。

- **Case C(失败路径)**:綦江考生,580 分物理类,普通家庭男生。家长想"考公兜底"。**报了重大某学院计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校 CS 不算重大强项薪资也只到 12k(还得去成都),两头不靠**——**学计算机不是为了考公,是为了进互联网大厂或华为系统央企**。

- **Case D(误区路径)**:重庆家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**。

- **Case E(渝东南路径)**:黔江土家族考生,565 分文史类,**农村家庭独子**。**民族加分 + 国家专项 + 西南大学公费师范汉语言文学定向回原县**——**毕业回黔江中学当语文老师 + 编制 + 安家费 + 父母近**,**重庆农村孩子最稳的跨阶级路径**。

- **Case F(警校路径)**:大渡口考生,普通工薪家庭男生,535 分物理类。**报重庆警察学院** → 4 年后**公安联考通过率 90%+,直接进沙坪坝区或大渡口区基层公安局**,**月薪起步 7-9k + 公安编制 + 公积金,30 岁前正股级**。

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**。
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(重庆 3+1+2 制度允许首选物理报多数专业)。
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关。
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)。**重大经管考公 < 西政法学考公**(重庆司法 / 政法系统认西政不认重大法学)。
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**。**重庆警察学院公安联考通过率 90%+ 是重庆考公确定性最高路径**。
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对重大 / 西大 / 西政学生而言**,选调生比市考好考。
- "**汉语言文学就是当老师**" — 严重错误。**这是重庆家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`。
- "**重庆是直辖市考公竞争一定大**" — 错。**直辖市编制密度高 + 岗位多 / 上岸率比四川省考、贵州省考更友好**,尤其汉语言 / 法学等大类专业。

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。

**重庆视角的总览金句**:

> "**重庆考公性价比之王 = 西政法学 + 重庆警察学院 + 西大公费师范 + 重师汉语言** — 这四条对应不同分数段不同家庭的最优考公路径,本省家长却很少完整知道。"

> "**重庆作为直辖市,体制内岗位密度比一般省高一档**,**汉语言考公在重庆比在四川 / 贵州更稳**——别拿"省内卷"的逻辑套重庆,重庆"市内"才是更准确的描述。"

> "**渝东南 / 渝东北农村孩子,先把民族加分 + 国家专项 + 公费师范这三个杠杆拉满**,然后再考虑"考公还是当老师"——其实公费师范本身就是终身编制,跟考公等价。"
