# 重庆 3+1+2 高考政策

## 核心结论

**重庆 2018 年加入新高考第三批,2021 年高考首届实行 3+1+2**(跟湖北/湖南/广东/江苏/福建/河北/辽宁 同批)。**总体规则跟湖北一致**,但重庆有几个**重要本地特殊性**值得注意——尤其是 **96 个院校专业组志愿**(全国最多档之一)和 **军校大本营**身份。

---

## 关键事实

### 考试结构(同湖北)
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类**(类型代号 2073)— 选物理为首选
- **历史类**(类型代号 2074)— 选历史为首选
- 重庆物理类约 65-70%,历史类约 30-35%(理科占比比湖北略高,直辖市理科氛围浓)

### 院校专业组(同湖北)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量(关键!!)
- **重庆本科批 96 个院校专业组志愿**
- 跟河北、辽宁同档,**全国最多档之一**(湖北 / 湖南 / 江苏 是 40-45 个)
- 含义:**冲档名额超富余,可以冲 5-8 所、稳 30 所、保 50 所**,容错空间巨大
- 专科批 96 个

## 重庆特殊性(关键!!)

### 1. 直辖市但教育资源中等(关键认知!)
- **985 仅 1 所**:重庆大学(且是 985 第二档,综合排名 30 名外)
- **211 仅 2 所**:重庆大学 + 西南大学(西大是 211 + 双一流)
- **对比直辖市同档**:北京 985 有 8 所、上海 4 所、天津 2 所——**重庆作为直辖市,985 数量倒数第一**
- **认知误区**:很多重庆家长以为"直辖市 = 教育强省" → 错。重庆教育资源**比湖北 / 江苏 弱很多**,985/211 数量跟河北 / 山西 / 江西 差不多

### 2. 西政:双非但法学全国前 5(国情特例!)
- **西南政法大学**虽然是双非,但**法学全国前 5**,**法学界"五院四系"之一**
- 司法考试通过率全国前列,**司法系统对口神校**(政法部、最高法、最高检、省级法检院 校友极多)
- **认可度 ≈ 211 法学顶级**,本省家长一定要知道:**西政法学 > 重大法学 > 西大法学**
- 但只法学吃香,西政其他专业别报

### 3. 军校大本营(全国独有特色!)
重庆是**军校最密集的城市之一**,提前批多个军校招生:
- **陆军军医大学**(原第三军医大学)— 军医顶级,临床医学/军医路径
- **陆军勤务学院** — 后勤保障专业
- **陆军边海防学院** — 边防方向
- **武警警官学院** — 武警系统
- **国防科大重庆校区** — 信息工程方向
- **认可度**:**包分配 + 包学费 + 编制**,普通家庭男生顶级 ROI 路径
- **门槛**:政审 + 体检(视力 / 身高严格)+ 提前批分数(物理类约本科线 +80)

### 4. 成渝双城就业一体化(西部独有!)
- 重庆考生留渝就业率约 50%,去成都约 15-20%,**成渝合计 ≈ 70%**
- 成渝双城经济圈国家战略,**就业市场基本一体**(类似长三角 沪宁苏锡常)
- 互联网:腾讯西部总部 / 阿里西南 / 字节西南 — 重庆 + 成都同等候选
- 制造业:长安汽车 / 赛力斯 (问界) / 重庆钢铁 / 川渝化工 — 留渝主力
- 金融:招商银行 / 重庆农商行 / 成都本地金融 — 成渝同投
- **跨省就业 vs 留渝**:除非冲 985 北上广深一线,**留成渝性价比 > 出去东部双非**

### 5. 重庆卷难度(同全国卷)
- 重庆用全国甲卷(2024 起改全国新课标二卷),**难度跟川滇贵接近**
- 不像江苏苏州数学那种压人,**分数体系跟湖北/河南可比**(分数线也差不多)
- **关键**:重庆考生 580 分约 = 湖北 580 分,可以横向比较

## 易错认知(agent 要纠正用户的)

- **"重庆是直辖市,985/211 应该多"** — 错。**重庆只有 1 所 985 + 2 所 211**,数量跟河北/山西可比,远不如湖北/江苏。要清醒
- **"西政是双非,不如 211"** — 严重错误。**西政法学全国前 5**,在司法系统认可度 ≈ 顶级 211 法学。但**只法学,其他专业不香**
- **"重医是双非,医生路径选不动"** — 错。**重医临床全国前列**,重庆 80% 的医院从重医毕业,**留渝当医生重医比许多 211 医学院更对口**
- **"96 个志愿都填好像很烦"** — 错。**96 个是优势**,容错空间最大,普通家庭最不该浪费(冲档 + 兜底都能塞够)
- **"重庆军校跟普通大学差不多"** — 错。**军校 = 包分配 + 服役 6-8 年 + 政审/体检严格**,独子男 / 视力差 / 不愿服役的别报

---

## 关键提醒(agent 必须强调)

1. **重庆 96 个院校专业组志愿**(全国最多档之一,跟河北 / 辽宁同档)
2. **重大是 985 第二档**(综合排名 30 名外),不要拿它跟清北华五比
3. **西政法学 = 双非顶配**,司法系统认可度极高,法学生本省第一选择
4. **军校大本营**:陆军军医 / 陆军勤务 / 陆军边海防 / 武警警官 都在重庆,提前批必看
5. **成渝双城就业一体**,留渝 + 去成都 = 70% 重庆考生去向
6. **再选科目限制**(必选化学/必选政治等)是硬约束

## 重庆 12 种选科组合详细分析

### 物理 + 化学 + 生物(老理科组,医工通用)

- **专业覆盖率 ~ 95%**(可报几乎所有理工医专业)
- **适合**:想学医(必选化生)/ 想学理工科 / 想保留最大选择空间的考生
- **典型院校 + 专业**:**陆军军医所有专业 / 重医临床 / 重大工科主流 / 重邮工科**
- **缺点**:学习强度大(化生赋分制需排名靠前)

### 物理 + 化学 + 政治(法学 / 公安通用)

- **专业覆盖率 ~ 92%**(可报理工 + 法学 + 部分军医)
- **适合**:想学法学 / 想考公 / 想报西政侦查 / 想报军校的考生
- **典型院校 + 专业**:**西政法学(物理类) / 西政侦查学 / 重庆警察学院 / 陆军军医部分专业**
- **重庆特有路径**:**军校 / 警校 / 公安系统招生大多要"必选政治"**——男生工科考生想留体制内的可考虑

### 物理 + 化学 + 地理(地学 / 测绘 / 桥梁通用)

- **专业覆盖率 ~ 90%**
- **适合**:想学地学 / 测绘 / 山区桥梁 / 城乡规划的考生
- **典型院校 + 专业**:**重交桥梁 / 武大测绘 / 西南交大测绘 / 重大建筑(部分)**

### 物理 + 生物 + 政治(医学 + 法学 跨界,小众)

- **专业覆盖率 ~ 75%**
- **适合**:想学法医 / 公共卫生 / 公安医学 / 中医的考生
- **典型院校**:**西政法医方向 / 重医公卫 / 中医**

### 物理 + 生物 + 地理

- **专业覆盖率 ~ 80%**
- **适合**:想学生物医学工程 / 环境工程 / 农林的考生
- **典型院校**:**西大动物科学 / 西大蚕学 / 西大食品科学**

### 物理 + 政治 + 地理(冷门理科组)

- **专业覆盖率 ~ 65%**
- **适合**:理科生想转考公 / 想学军事 / 想学旅游管理的考生
- **慎选**:覆盖率较低,**专业选择窄**

### 历史 + 政治 + 地理(老文科组)

- **专业覆盖率 ~ 50%**(只能报文史哲教法管经)
- **适合**:确定不学理工医的考生
- **典型院校 + 专业**:**西政法学(历史类) / 西大公费师范 / 重师汉语言 / 重庆工商财经类**
- **重庆考公友好组合**(汉语言 / 法学 / 公安联考 都对口)

### 历史 + 政治 + 化学(冷门跨界)

- **专业覆盖率 ~ 55%**
- **慎选**:文理夹生,**多数大学不友好**

### 历史 + 政治 + 生物(冷门跨界)

- **专业覆盖率 ~ 55%**
- **慎选**:同上

### 历史 + 化学 + 地理 / 历史 + 化学 + 生物 / 历史 + 地理 + 生物

- **专业覆盖率 ~ 50-65%**
- **极冷门**:除非有特殊兴趣,**重庆考生很少这样选**

## 重庆考生选科决策矩阵

| 目标方向 | 推荐选科 | 备注 |
|---|---|---|
| **学医**(临床 / 口腔 / 中医 / 重医所有) | **物 + 化 + 生** | 所有医学院校强制要求化生 |
| **军医 / 陆军军医** | **物 + 化 + 生** | 军方医学专业要求化生 + 政审体检 |
| **学法学 / 西政** | **物 + 化 + 政** 或 **史 + 政 + 地** | 历史类对法学略友好(西政历史类录取分常高) |
| **考公 / 文科主导** | **史 + 政 + 地** | 公考行测对文科友好,且专业选择多 |
| **学工科 / 重大 / 重邮 / 重交** | **物 + 化 + 生** 或 **物 + 化 + 地** | 工科必选物化 |
| **学公费师范 / 西大** | 看你想教的学科 | 对应学科选科必须包含(教数学必选数学相关组合) |
| **学公安 / 重庆警察学院 / 西政侦查** | **物 + 化 + 政** 或 **史 + 政 + 地** | 必选政治 |
| **学财经 / 重大经管 / 西南财经成都** | **物 + 化 + 生** 或 **史 + 政 + 地** | 经管类大多文理通选 |
| **想保留最大选择空间** | **物 + 化 + 生**(物理类首选) | 覆盖 95% 专业 |

## 选科陷阱(重庆家长容易踩的)

### 陷阱 1:为了"避开高难度科目"乱选

- **错误案例**:孩子物理较好但化学一般,家长劝选"物理 + 政治 + 地理"避开化学——**结果丢失了 95% 医学 + 多数工科 / 部分理科 的选择权**。
- **正确做法**:**物理类首选物 + 化 + 生**,这是最通用 / 选择面最广的组合,除非孩子化学严重短板才考虑替换。

### 陷阱 2:盲目选历史类以为"考公更稳"

- **错误案例**:孩子明明物理化学都不错,家长劝选历史类"考公更稳"——**结果丢失了所有理工科选项,只剩文史哲法管经**。
- **正确做法**:**理科生选物 + 化 + 政**(可学理工 + 可学法学 + 可考公),**比纯历史类专业选择多一倍**。

### 陷阱 3:不查具体院校的再选科目要求

- **错误案例**:孩子想学西政侦查学,选了"物理 + 生物 + 地理"组合——**到填志愿才发现西政侦查学要求"必选政治"**,被卡死。
- **正确做法**:**填志愿 1 年前先查目标院校 + 目标专业的选科要求**,**重庆教育考试院官网会公布每个院校每个专业的"选科要求表"**。

### 陷阱 4:盲信"3+1+2 跟老高考差不多"

- **错误**:**赋分制**(化学 / 生物 / 政治 / 地理)≠ 原始分,**一个考生考 70 分但全市排名靠前可能赋分到 90+;考 70 分但全市排名靠后可能赋分到 50-60**。
- **关键**:**再选科目要看排名,不只看分数**——**多数考生选化学是因为化学考生本身水平高,赋分容易吃亏**。**化学是赋分大坑,但医学专业又必选化学**——这是重庆 / 全国 3+1+2 考生的两难。

## 选科调整窗口

- **高一下学期定选科**(2024 年起执行):**学校组织摸底考试 + 家长会 + 班主任建议**。
- **高二下学期可微调**(部分学校允许换 1 科)——**最后机会调整,过了高二下不能换**。
- **重庆主城 + 区县中学** 都可办选科调整,**但城乡差异**:主城中学(巴蜀 / 南开 / 一中 / 八中 / 育才)选科辅导专业;**渝东南 / 渝东北 县中** 选科辅导参差,**家长要主动咨询**。

## 关键建议(给重庆考生家长)

1. **确定选科前,先想清楚孩子目标方向**——**学医 / 学法 / 学工 / 考公 / 当老师** 5 个方向决定不同选科,**不要"先选科再想方向"**。

2. **重庆 96 个院校专业组志愿是优势,不是负担**——**冲 5-8 所、稳 30 所、保 50 所** 这种比例完全可以,**容错空间大,不要浪费**。

3. **填报时一定看清楚专业组内的所有专业**——**服从调剂只在专业组内**,**专业组里有"坑专业"(化工 / 哲学 / 思政等冷门)就要慎重**。

4. **提前批军校 / 警校 / 公费师范 不冲突本科批**——**这些是免费的"额外冲档机会"**,**普通家庭男生强烈建议提前批至少填 1-2 个**(陆军军医 / 武警警官 / 重庆警察学院 / 西大公费师范)。

5. **国家专项 / 高校专项 / 民族优惠** 是渝东南 / 渝东北 农村孩子专属杠杆——**叠加使用,500-540 分就能上重大 / 西大 / 西政**,**这条路被太多家长低估**。
