# 上海 3+3 高考政策

## 核心结论

**上海 2014 年作为全国第一批新高考综合改革试点(跟浙江同批),2017 年首届新高考毕业**(全国最早执行 3+3 的省份)。**上海是 3+3 体系,不是 3+1+2** —— 这是跟湖北/江苏/湖南/广东等省最大的政策差异。**总分 660,不是 750**;**不分文理类,只有"综合"一个口径**。

## 关键事实

### 考试结构(3+3,不是 3+1+2)
- **3 = 语文 + 数学 + 英语**(各 150 分,**英语一年两考取高分**)
- **3 = 选考 6 选 3**:物理 / 化学 / 生物 / 政治 / 历史 / 地理(任选 3 科,每科 70 分,**全部赋分制**)
- **总分 = 150 × 3 + 70 × 3 = 660 分**
- **不分文理类**,只有"综合"一个考试口径

### 选考赋分制(关键!)
- 每科原始分卷面成绩 → 按全市排名换算成等级 → 等级转赋分
- **A+(前 5%)= 70 分**(满分)
- **A(前 5-10%)= 67 分**
- **A-(前 10-20%)= 64 分**
- **B+ ~ B-(20-50%)= 61/58/55 分**
- **C+ ~ C-(50-80%)= 52/49/46 分**
- **D+ ~ D-(80-99%)= 43/40 分**
- **E(后 1%)= 40 分(保底)**
- 含义:**只要你选了这门,卷面再差也至少 40 分**;但拿满 70 分需要全市前 5%,**比原始分卷难得多**

### 院校专业组(同其他新高考省份)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- 选科要求按"专业组"维度限制(如复旦理工类专业组要求物理 + 化学)

### 填报志愿数量(关键!)
- **本科批 24 个院校专业组**(注意!**比湖北/湖南 45 个少 21 个,比江苏 40 个少 16 个**)
- 综评批 1-4 个(看院校,复旦/上交/同济/华师大/上财 等开放综评)
- 专科批另算

### 批次设置(注意!)
- **不分本一/本二/本三**,**只有"本科批 + 特殊类型招生控制线"**
- "特殊类型招生控制线"≈ 老的一本线,可参加综评 / 强基 / 高水平艺体
- "本科控制线"≈ 老的二本线,可填本科批

## 上海特殊性(关键!!)

### 1. 上海高考是全国"最小"的高考
- **每年考生约 5-6 万**(全国最小高考省/直辖市,湖北/江苏 30-40 万)
- 考生池小 → 一分一段表"密度低",**位次差 100 名,分数可能差 1-2 分**
- 影响:**不要被"位次差几百名"吓到,在上海这个差距很小**

### 2. 4 所 985 + 9+ 所 211 集中在上海
- **4 所 985**:复旦大学 / 上海交通大学 / 同济大学 / 华东师范大学
- **9+ 所 211**:上海财经大学 / 华东理工大学 / 东华大学 / 上海大学 / 上海外国语大学 / 上海海事大学 / 上海海洋大学 / 第二军医大学(海军军医大学) / 等
- **加上中外合办**:上海纽约大学 / 上海科技大学(双非但顶级) / 西交利物浦(苏州) 等
- **结论**:**全国教育资源最密集的城市**,上海考生上 985 / 211 的本地名额比例远高于其他省

### 3. 综评批 — 上海特色(必懂!)
- **复旦 / 上交 / 同济 / 华师大 / 上财 / 华理 / 上大 / 东华 / 上外 / 上理工 / 上海海事 / 上海海洋** 等开放综评
- **录取 = 高考成绩 60% + 校测面试 30% + 学考成绩 10%**(不同院校权重略有差异)
- **复旦 / 上交综评录取占其全部上海招生的 50% 以上**(部分专业接近 100%)
- **如果只看普通批,你大概率冲不进复旦/上交** —— 综评是上海考生的"主战场"
- **流程**:5 月报名 → 6 月高考 → 6 月底初审名单 → 7 月初校测(面试)→ 综合分录取

### 4. 春考 vs 秋考 — 上海独家双轨
- **春考(春季高考)**:1 月考试,**上海独有**
  - 主要面向应届生兜底,部分院校(如上海海事/上海海洋/上海工程技术大学/上海第二工业 等)以春考方式招生
  - 春考被录取 = 提前锁定本科,**可以放弃**(不影响秋考),不放弃就不能再参加秋考
- **秋考(夏季高考)**:6 月考试,主流通道,985/211 主要在秋考招生
- **战略**:春考冲本科兜底(目标分应届生平均 ~440-500),秋考冲 985/211(目标 600+)

### 5. 沪籍 vs 非沪籍 — 录取分数线差异
- **沪籍考生**:正常参加本市高考,享受所有本地名额
- **非沪籍随迁子女**:满足上海居住证 + 父母社保 7 年 + 中考在沪 等条件可在沪高考,**但部分院校录取分数线略高**
- 影响:**非沪籍家庭实际录取门槛高 5-15 分**,选校要更稳

### 6. 总分 660 跟 750 不可比 —— 必须换算
- **粗略换算**:上海 600 分 ≈ 750 制 680 分,**位次百分位才是硬通货**
- 上海一本(特殊类型招生控制线)2024 ≈ 503 分,2025 ≈ 504 分(数值跟外省 540 一本线很接近,但人数比例更小)
- **农村家长容易上当**:看到孩子上海 580 分,以为只够上一本中段,实际可能是 985 段

|---|---|---|

| 2022 | 400 | 503 |

### 6 选 3 的 20 种组合(简化建议)

**最热**:物化生(医学/工科通吃) / 物化地(理工通吃,文科退路) / 物生政(医学+考公) / 史政地("纯文科") / 化生地(医学退路)

**最冷**:政史地(纯文科,不能报理工 80%专业) / 物政生(理工组合中最少人选)

**Agent 提醒纪律**:**没选物理 = 70%以上工科/计算机/医学专业封锁**;**没选化学 = 90%医学专业封锁** —— 这俩缺一不可。

## 易错认知(agent 要纠正用户的)

- **"上海满分 750"** — 错。**上海满分 660**,跟外省 750 不可比,看位次百分位
- **"上海卷难"** — 错。上海卷整体难度中等(数学略难),**不要因为"上海"就紧张**,看位次
- **"24 个志愿不够填"** — **24 个院校专业组够了**,3+3 体系下专业组维度更细,不需要 45 个
- **"综评是给学霸的,我不够格"** — 错。**普通本一线以上(503+)就能报综评**,只是录取要看校测发挥
- **"春考是差生兜底"** — 错。**春考也有 985 部分专业** + 春考是上海特色保险,不亏
- **"上海 985 录取要 660 满分"** — 错。综评批考分要求往往是 580-620 段,**校测才是分水岭**

## 关键提醒(agent 必须强调)

1. **总分 660,不是 750** — 数值跟外省不可比
2. **24 个志愿,按"院校专业组"投档** — 比 45 志愿省份少
3. **综评批是上海主战场**(复旦/上交录取占大头),只看普通批等于丢一半选项
4. **6 选 3 选科限制硬性**(医学必选化生,工科必选物理)
5. **春考 / 秋考双轨**,春考兜底战略不能忽略
6. **沪籍 vs 非沪籍录取门槛差** 5-15 分
7. **不分文理,统一"综合"口径**,不要套用 3+1+2 的"物理类/历史类"概念

## 上海综合评价批(综评批)深度解析

### 综评批是什么(沪上家长头号迷雾)
- **沪上综评批 = 高考成绩 60% + 校测面试 30% + 学考成绩 10%**(部分校权重略不同)
- **不是"自主招生"**(自主招生 2020 年已取消),综评是新高考综合改革的核心招生方式
- **复旦 / 上交 / 同济 / 华师大 / 上财 / 华理 / 上大 / 东华 / 上外 / 上理工 / 上海海事 / 上海海洋 / 上科大** 都开放综评
- **复旦 / 上交综评录取占其上海招生 50%+**,**上科大基本只通过综评录取**

### 综评批 vs 普通批 报志愿策略
- **沪上家长标准玩法**:**综评批 + 普通批两手准备**,完全不冲突
- **5 月**:报名综评(选 4-5 所校) → 6 月初:学校发布初审通过名单
- **6 月**:高考(秋考)
- **6 月底**:高考分数公布 + 综评校测时间确认
- **7 月初**:综评校测(笔试 + 面试,通常 1-2 天)
- **7 月中**:综评录取确认 → 综评录取后不能再走普通批
- **7 月下**:普通批投档录取
- **关键点**:**只要不被综评录取,就可以参加普通批**;被综评录取后必须去那所学校,**不能反悔**

### 综评校测难度对比
- **复旦综评校测**:笔试(数学 + 物理 / 历史)+ 面试(中英文综合)— **难度高考拓展级**
- **上交综评校测**:笔试(数理化)+ 面试 — **难度比复旦更高**(数理工科向)
- **同济综评校测**:笔试(数理 + 综合)+ 面试 — 数理基础强 + 设计美学问题
- **华师大综评校测**:面试为主(教育素养 + 学科方向 + 综合)— **难度最低**
- **上财综评校测**:笔试(数学 + 英语)+ 面试(财经场景题)— 数学英语扎实
- **上科大校测**:数理化竞赛级 + 英文面试 — **难度全国前列,接近清北强基**

### 综评批最大的认知陷阱
- **"综评是给学霸的,我不够格"** — 错。**普通本一线以上(503+)就能报综评**
- **"综评只看校测,可以低分逆袭"** — 错。**高考成绩占 60%**,低分上不去
- **"综评校测临时准备就行"** — 错。**至少提前 3-6 个月准备**(校测难度高考拓展级)
- **"综评录取后还能反悔"** — **错!被综评录取后不能再走普通批**

## 上海春考(春季高考)深度解析

### 春考是什么(上海独家)
- **上海春考 = 1 月考试**(2024 年 1 月 6-8 日,2025 年 1 月 4-6 日)
- **考试科目**:语数英 + 校测综合
- **总分 600**(语数英各 150,校测综合 150)
- **2024 年春考报名约 5 万人**(应届生 + 部分往届)

### 春考 vs 秋考 战略选择
- **春考目标**:**沪上 9 所市属本科**(上海海事 / 上海海洋 / 上海工程技术 / 上海第二工业 / 上海应用技术 / 上海立信会计金融 / 上海政法 / 上海电力 / 上海杉达)
- **秋考目标**:**985 / 211 + 综合性大学**(走综评 + 普通批)
- **沪上家长策略**:
  - 春考冲本科兜底(目标 440-500 分,进上海海事 / 海洋 / 应用技术 等)
  - 秋考冲 985/211(目标 600+)
- **春考被录取 = 必去那所校,放弃就不能去**(但不影响秋考报名)

### 春考的特殊价值
- **沪上工薪家庭兜底神器**:孩子分数中等 + 想留沪本科 → 春考冲上海海事 / 上海应用技术 + 秋考冲 211 = 两手准备
- **沪上电力大学(原 211 边缘)走春考也能进** = 沪上电气 / 国网上海 编制路径
- **春考不影响秋考**:即使春考没考好,秋考全力以赴

### 春考的冷门误区
- **"春考是差生兜底"** — 错。**沪上中产家庭也有走春考兜底再冲秋考**的策略
- **"春考考上就不能反悔"** — 半对。**报到注册前可以放弃**(就是不去那所校),**不影响秋考**;但**注册了就不能反悔**

## 沪籍 vs 非沪籍 深度差异

### 沪籍家庭(上海户籍)
- **正常参加本市高考**,享受所有本地名额
- **录取门槛**:同等位次 = 同等录取
- **政策红利**:沪上 985/211 本地名额比例高(复旦本地招约 30-40%)
- **沪上中学校友圈**:沪上重点中学 → 沪上 985/211 录取概率显著高

### 非沪籍随迁子女(满足条件)
- **条件**:**居住证 + 父母社保 7 年 + 中考在沪**
- **可在沪高考**,但**部分院校录取门槛高 5-15 分**
- **沪上 985/211 给非沪籍指标少**(复旦给非沪籍指标只占 5-10%)
- **非沪籍核心诉求 = 走选调 / 考公拿沪户口 / 央企指标**

### 非沪籍随迁子女的 3 条留沪路径
1. **选调生路径**:985/211 + 沪上选调 → 沪户口 + 公务员编制
2. **央企指标路径**:985/211 + 沪上央企(国网 / 中船 / 中石化) → 沪户口指标
3. **三甲医院技术岗路径**:沪上医学院 + 三甲医院技师 → 沪户口指标
4. **公费师范路径(注意!)**:**非沪籍读公费师范要回原籍服务 6 年**(不会留沪)

## 上海一分一段表反查方法(沪上家长必学)

### 反查步骤(沪上版本)
1. **6 月 25 日左右** 上海招办发布一分一段表
2. 用孩子分数查对应位次(沪上 660 制 → 沪上累计排名)
3. **跟意向校近 3 年最低位次比较**(从掌上高考查)
4. 判断可达性:
   - **位次 < 历年最低位次 1000 名以内** = 稳冲
   - **位次 = 历年最低位次** = 边缘
   - **位次 > 历年最低位次 1000 名以上** = 不可达

### 沪上一分一段表特点
- **沪上考生池极小(5-6 万)** → 位次密度低
- **位次差 100 名 ≈ 分数差 1-2 分**(湖北 100 名 ≈ 0.3-0.5 分)
- **意味着 1 分的价值在沪上极高**(湖北丢 1 分掉 200 名,沪上丢 1 分掉 500-1000 名)

### 沪上家长头号坑:看分数不看位次
- **错例**:沪籍家长看到孩子 580 分,以为只够二本
- **真相**:580 分(660 制) ≈ 沪上 5000-7000 名 = 同济 / 华师大段位
- **应对**:**报志愿前必须查一分一段表**,**不要只看分数数值**

## 上海高考特殊案例与应对

### Case A:沪籍中产 + 想冲复旦交大 → 综评 + 普通批两手准备
- 沪籍中产女生 → 595 分(660 制) → 报复旦 / 上交综评 + 同济 / 华师大综评 → 普通批同时报同济 / 华理 / 上大
- **结果**:综评校测拿到同济录取 → 同济录取确认 → **不进普通批**
- **沪上家长标准玩法**

### Case B:沪籍工薪 + 春考兜底 → 上海电力大学
- 沪籍工薪男生 → 春考 480 分 → 春考录取上海电力大学电气 → 注册确认 → **春考兜底成功**
- **秋考再考也无意义**(已经被春考锁定)

### Case C:非沪籍 + 走综评批 → 复旦
- 非沪籍中产女生(满足 7 年社保条件)→ 综评批报复旦 → 校测过关 → 高考 590 分 → 综评录取复旦中文
- **非沪籍跨阶级路径**:综评 + 985 + 沪户口路径

### Case D(失败):沪籍 + 只看普通批 → 错失复旦
- 沪籍男生 → 595 分 → 没参加复旦综评 → 普通批投档复旦未中(因为复旦综评占 50%+,普通批分数线水涨船高)→ 退到同济
- **典型踩坑**:**只看普通批 = 自废一半名额**

### Case E:沪籍 + 选科踩坑(医学梦想)
- 沪籍中产女生 → 选科物理 + 政治 + 地理 → 高三想报临床医学发现**必选化学 / 生物**(医学硬约束)→ 只能改报其他专业
- **典型踩坑**:**选科组合不能覆盖目标专业**
- **应对**:**高一选科前必须确认目标专业**,**医学必选化生**,**工科必选物理**

## 沪上家长头号 5 大政策误区

### 误区 1:总分 660 是数值小所以"高考容易"
- **错**。沪上考生池小不代表竞争小,**前 5000 名争 4 所 985 名额** 比湖北 30000 名争 1 所 985 还卷

### 误区 2:春考是差生兜底
- **错**。**春考也有 985 部分专业**(上海海事大学 / 上海中医药大学 等部分专业)+ 春考是上海特色保险

### 误区 3:综评不重要,看普通批就够
- **严重错误**。**沪上 985/211 综评录取占 50%+**,只看普通批 = 自废一半名额

### 误区 4:24 个志愿不够填
- **错**。**24 个院校专业组够了**,3+3 体系下专业组维度更细,不需要 45 个

### 误区 5:沪上一本线 503 = 一本水平
- **错**。**沪上一本线 503(660 制) ≈ 750 制 570 一本线**,**沪上 600 分 ≈ 750 制 680 分**(985 段位)

## 关键提醒(给 agent 用)

**沪上家长报志愿,核心 4 件事**:
1. **看一分一段表反查位次**(不要看分数)
2. **综评批 + 普通批两手准备**(综评校测提前 6 个月准备)
