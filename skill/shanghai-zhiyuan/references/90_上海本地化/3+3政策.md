# 上海 3+3 高考政策

## 核心结论

**上海 2014 年作为全国第一批新高考综合改革试点(跟浙江同批),2017 年首届新高考毕业**(全国最早执行 3+3 的省份)。**上海是 3+3 体系,不是 3+1+2** —— 这是跟湖北/江苏/湖南/广东等省最大的政策差异。**总分 660,不是 750**;**不分文理类,只有"综合"一个口径**。

## 关键事实

### 考试结构(3+3,不是 3+1+2)
- **3 = 语文 + 数学 + 英语**(各 150 分,**英语一年两考取高分**)
- **3 = 选考 6 选 3**:物理 / 化学 / 生物 / 政治 / 历史 / 地理(任选 3 科,每科 70 分,**全部赋分制**)
- **总分 = 150 × 3 + 70 × 3 = 660 分**
- **不分文理类**,只有"综合"一个考试口径

### 选考赋分制(关键!)
- 每科原始分卷面成绩 → 按全市排名换算成等级 → 等级转赋分
- **A+(前 5%)= 70 分**(满分)
- **A(前 5-10%)= 67 分**
- **A-(前 10-20%)= 64 分**
- **B+ ~ B-(20-50%)= 61/58/55 分**
- **C+ ~ C-(50-80%)= 52/49/46 分**
- **D+ ~ D-(80-99%)= 43/40 分**
- **E(后 1%)= 40 分(保底)**
- 含义:**只要你选了这门,卷面再差也至少 40 分**;但拿满 70 分需要全市前 5%,**比原始分卷难得多**

### 院校专业组(同其他新高考省份)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- 选科要求按"专业组"维度限制(如复旦理工类专业组要求物理 + 化学)

### 填报志愿数量(关键!)
- **本科批 24 个院校专业组**(注意!**比湖北/湖南 45 个少 21 个,比江苏 40 个少 16 个**)
- 综评批 1-4 个(看院校,复旦/上交/同济/华师大/上财 等开放综评)
- 专科批另算

### 批次设置(注意!)
- **不分本一/本二/本三**,**只有"本科批 + 特殊类型招生控制线"**
- "特殊类型招生控制线"≈ 老的一本线,可参加综评 / 强基 / 高水平艺体
- "本科控制线"≈ 老的二本线,可填本科批

## 上海特殊性(关键!!)

### 1. 上海高考是全国"最小"的高考
- **每年考生约 5-6 万**(全国最小高考省/直辖市,湖北/江苏 30-40 万)
- 考生池小 → 一分一段表"密度低",**位次差 100 名,分数可能差 1-2 分**
- 影响:**不要被"位次差几百名"吓到,在上海这个差距很小**

### 2. 4 所 985 + 9+ 所 211 集中在上海
- **4 所 985**:复旦大学 / 上海交通大学 / 同济大学 / 华东师范大学
- **9+ 所 211**:上海财经大学 / 华东理工大学 / 东华大学 / 上海大学 / 上海外国语大学 / 上海海事大学 / 上海海洋大学 / 第二军医大学(海军军医大学) / 等
- **加上中外合办**:上海纽约大学 / 上海科技大学(双非但顶级) / 西交利物浦(苏州) 等
- **结论**:**全国教育资源最密集的城市**,上海考生上 985 / 211 的本地名额比例远高于其他省

### 3. 综评批 — 上海特色(必懂!)
- **复旦 / 上交 / 同济 / 华师大 / 上财 / 华理 / 上大 / 东华 / 上外 / 上理工 / 上海海事 / 上海海洋** 等开放综评
- **录取 = 高考成绩 60% + 校测面试 30% + 学考成绩 10%**(不同院校权重略有差异)
- **复旦 / 上交综评录取占其全部上海招生的 50% 以上**(部分专业接近 100%)
- **如果只看普通批,你大概率冲不进复旦/上交** —— 综评是上海考生的"主战场"
- **流程**:5 月报名 → 6 月高考 → 6 月底初审名单 → 7 月初校测(面试)→ 综合分录取

### 4. 春考 vs 秋考 — 上海独家双轨
- **春考(春季高考)**:1 月考试,**上海独有**
  - 主要面向应届生兜底,部分院校(如上海海事/上海海洋/上海工程技术大学/上海第二工业 等)以春考方式招生
  - 春考被录取 = 提前锁定本科,**可以放弃**(不影响秋考),不放弃就不能再参加秋考
- **秋考(夏季高考)**:6 月考试,主流通道,985/211 主要在秋考招生
- **战略**:春考冲本科兜底(目标分应届生平均 ~440-500),秋考冲 985/211(目标 600+)

### 5. 沪籍 vs 非沪籍 — 录取分数线差异
- **沪籍考生**:正常参加本市高考,享受所有本地名额
- **非沪籍随迁子女**:满足上海居住证 + 父母社保 7 年 + 中考在沪 等条件可在沪高考,**但部分院校录取分数线略高**
- 影响:**非沪籍家庭实际录取门槛高 5-15 分**,选校要更稳

### 6. 总分 660 跟 750 不可比 —— 必须换算
- **粗略换算**:上海 600 分 ≈ 750 制 680 分,**位次百分位才是硬通货**
- 上海一本(特殊类型招生控制线)2024 ≈ 503 分,2025 ≈ 504 分(数值跟外省 540 一本线很接近,但人数比例更小)
- **农村家长容易上当**:看到孩子上海 580 分,以为只够上一本中段,实际可能是 985 段

## 上海批次线(2021-2025,综合)

| 年份 | 本科批控制线 | 特殊类型招生控制线(≈一本线) |
|---|---|---|
| 2021 | 400 | 503 |
| 2022 | 400 | 503 |
| 2023 | 405 | 504 |
| 2024 | 403 | 503 |
| 2025 | 402 | 504 |

**特点**:**批次线非常稳定**(总分 660 决定数值小,波动小),**位次更重要**。

## 选科决策映射(供 agent 用)

| 考生情况 | 选科建议 |
|---|---|
| 想读临床医学(复旦上医 / 交大医学院 / 同济医学院 / 上中医) | **必选化学 + 生物**(物化生 主流) |
| 想读 CS / 工科(上交 / 同济 / 复旦 / 华理) | **必选物理**,加化学覆盖更多专业 |
| 想读金融经济(上财 / 复旦经管 / 上交安泰) | **必选物理或历史 + 政治** 加权 |
| 想读法学(复旦法学院 / 华政) | 选政治 + 历史,语数英要强 |
| 想读师范(华师大 / 上师大) | 选你想教的学科对应科目 |
| 想报警察 / 公安(上海公安学院 等) | **必选政治** |
| 想冲综评(复旦 / 上交) | **必选物理**(理工综评要求高),搭配化学 + 数学强 |

### 6 选 3 的 20 种组合(简化建议)

**最热**:物化生(医学/工科通吃) / 物化地(理工通吃,文科退路) / 物生政(医学+考公) / 史政地("纯文科") / 化生地(医学退路)

**最冷**:政史地(纯文科,不能报理工 80%专业) / 物政生(理工组合中最少人选)

**Agent 提醒纪律**:**没选物理 = 70%以上工科/计算机/医学专业封锁**;**没选化学 = 90%医学专业封锁** —— 这俩缺一不可。

## 易错认知(agent 要纠正用户的)

- **"上海满分 750"** — 错。**上海满分 660**,跟外省 750 不可比,看位次百分位
- **"上海卷难"** — 错。上海卷整体难度中等(数学略难),**不要因为"上海"就紧张**,看位次
- **"24 个志愿不够填"** — **24 个院校专业组够了**,3+3 体系下专业组维度更细,不需要 45 个
- **"综评是给学霸的,我不够格"** — 错。**普通本一线以上(503+)就能报综评**,只是录取要看校测发挥
- **"春考是差生兜底"** — 错。**春考也有 985 部分专业** + 春考是上海特色保险,不亏
- **"上海 985 录取要 660 满分"** — 错。综评批考分要求往往是 580-620 段,**校测才是分水岭**

## 关键提醒(agent 必须强调)

1. **总分 660,不是 750** — 数值跟外省不可比
2. **24 个志愿,按"院校专业组"投档** — 比 45 志愿省份少
3. **综评批是上海主战场**(复旦/上交录取占大头),只看普通批等于丢一半选项
4. **6 选 3 选科限制硬性**(医学必选化生,工科必选物理)
5. **春考 / 秋考双轨**,春考兜底战略不能忽略
6. **沪籍 vs 非沪籍录取门槛差** 5-15 分
7. **不分文理,统一"综合"口径**,不要套用 3+1+2 的"物理类/历史类"概念
