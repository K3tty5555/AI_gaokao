# 用户意向冲突 — Reality Check 金句库(上海版)

很多家长 / 考生有具体的意向("想上复旦"、"非上海不去"、"想学医"、"非外企不去"),但**意向不一定跟分数 / 家庭情况匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**),针对**沪上特殊语境** 改写。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 1 万位次以上,**不要绕弯子**。沪上家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **沪上家长别被精致绑架** — **沪上中产家庭普遍"重精致 / 国际化 / 海派"**,但**沪上工薪家庭 + 非沪籍家庭最优解可能是"沪户口 + 编制"路径**,不要让家庭基因不匹配的孩子去走"中外合作 / 出国"这条路

---

## 4 类意向冲突 + 金句模板(上海版)

### 模式 A:不可达型 — 分数差距 >30 分 / >1 万名(上海一分一段表)

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 480 分要复旦 / 520 分要上交主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 千名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [沪上 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(沪上 530 分,意向复旦)**:
> "复旦主流组在上海综合 600-1500 名,你 4500 名,差 3000 名,**复旦没戏**,**复旦综评批最低也是 5000 名内**。
>
> 但你能上华东师大 + 上财 + 同济(冷门组)+ 华政 — **这几所留沪就业,在沪上市考 / 选调 / 央企里跟复旦冷门组校友地位差不多**(都是'沪上 985/211 + 留沪同档')。
>
> 特别推荐华东师大公费师范汉语言或上财金融——**沪上工薪家庭这两个出路实际比复旦冷门组的图书情报学硬一档**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学 / 历史]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(沪上理工科 + 普通家庭)**:
> "复旦你 580 能冲 — 但只能进自然科学试验班(里面含化学 / 生物 / 材料)。**985 牌子 + 生化环材** = 双重坑。
>
> 同分能上的同济土木 / 华理化工(全国前 5,中海油 / 中石化校招主力)出来对口程度更高,起薪还高。**冲复旦留一个心理慰藉位即可,主推同济或华理**。
>
> 沪上家长别迷信复旦牌子——**复旦的弱专业 + 5 年后看,跟同济的强专业差距没你想的大**,但你浪费的是孩子最宝贵的本科 4 年方向。"

**真实案例(沪上中产 + 上交执念)**:
> "上交你 600 分能擦 — 但只能进船舶 / 海洋方向冷门组。**这个组你父母不接受**(觉得船舶 = 上船 = 苦),孩子又不愿意去交大冷门组。
>
> 同分能上的同济建筑 / 华师大经济(沪上认可度都不输上交弱组),要么你接受船舶进上交,要么你换学校。**鱼和熊掌不可兼得**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退(沪上版)

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 非沪籍工薪,**撑不起 5+3+8 / 30 岁前在沪上不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**沪上长周期成本比湖北高 2 倍**(因为上海生活成本高)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [上医交医临床八年制])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像技术 4 年 / 中医 5 年 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(沪上工薪家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**沪上规培期月薪 6-10k,但租房 + 通勤 + 餐饮就要 8k+**,**沪上工薪父母还要补贴 8 年**。
>
> 你父母年收入 30-50w(沪上工薪) + 还有房贷 + 妹妹上小学,**这个家庭撑临床 8 年是地狱模式**。
>
> 撑得起 → 推交医临床八年制,长期天花板高(50-80w)。
>
> 撑不起 → **建议医学影像技术 4 年(沪上三甲技术岗,起薪 8k + 编制 + 沪户口续保,本科直接挣钱)**,或者**口腔(5+3 但能自己开诊所)**,**这两条路在上海比湖北的 8 年临床稳得多**。
>
> 沪上家长有个误区——觉得'学医就要学临床,不然没意义'。**错。沪上三甲医院技术岗 + 编制 + 沪户口 + 不卷 = 比临床医生 30 岁前还在租房的体面 1 倍**。"

**真实案例(非沪籍 + 想学法学)**:
> "你想学法学 + 留沪做律师,但你家庭是河南农村,父亲打工年入 8w,你妹妹还在上初中。
>
> **沪上律师本科毕业进红圈所需要的 = 复旦法学本科 + 法考一次过 + 实习 4 段** — 这套路径 5 年内你家供得起 1 个但供不起 2 个。
>
> 撑得起 → 报复旦法学,走选调生路径(沪上选调直接进市委办,起薪 25w + 沪户口 + 编制),**比做律师稳得多**。
>
> 撑不起 → 报华东政法大学法学(沪上司法系统主供给,法考通过率高),**毕业先进上海某区检察院 / 法院 / 司法局,3-5 年后再考虑跳律所**,**这条路对工薪家庭更稳**。
>
> 不要硬冲复旦交大法学 + 想做律师 — **你 5 年后律师执业开张时,你家是支撑不起你的**。"

### 模式 D:意向城市 vs 院校层次 — "非上海不去"

**特征**:用户只想留上海("非上海不去" / "非复旦交大不去"),拒绝出沪 985。

**金句模板**:
> "你只想留上海,那同档要在 [沪上 211] 和 [外省 985 弱专业] 之间选。
>
> **留上海 211 反而更稳** —
> - 沪上校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回上海没竞争力**
> - 留上海你父母也安心
>
> 但!如果你想做的方向 [上海] 没强校(如想学航天 → 留沪没意义,要去西工大),**要灵活退一步**。
>
> 沪籍家庭特别注意:**沪户口本身就是 200w+ 隐性资产**,你出沪 985 + 没拿到外地户口 + 回沪上户口续保有政策风险——**这是沪籍学生最隐形的'留沪福利'**。"

**真实案例(沪籍 + 法学方向 + 580 分)**:
> "你只留上海,这位次 4500,复旦法学 / 上交凯原 / 华政全够不上(都要 2500 名内)。
>
> **留沪最稳路径**:**上海政法学院法学 / 上海大学法学 / 上财法学 + 父母律所家族资源 + 法考** → **沪上区级法院 / 检察院 + 律所合伙人** 路径仍然能走。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门法学 — 牌子有了但**沪上法律行业人脉断了 / 实习机会少了 / 沪户口续保问题** ,综合不划算。"

**真实案例(非沪籍 + 想留沪 + 600 分)**:
> "你 600 分,复旦交大没戏(都要 580 名内),但同济 / 华师大 / 上财 / 上交医学院冷门组够。
>
> **不要硬要回户籍省冲 985 弱专业** — 你家庭目标是留沪 + 沪户口,**沪上 211 + 选调生路径 = 拿沪户口最稳路径**。
>
> 同济土木 / 华师大公费师范 / 上财金融 / 上交医学院技术岗 → 4 条路都通沪户口,**比你回省里上 985 弱专业更对口你的目标**。"

## 沪上特有的第 5 类意向冲突:**意向出国 vs 家庭撑不撑得起**

**特征**:沪上家长普遍国际化诉求强(出国留学 / 中外合作办学 / NYU 上海),但**家庭实际财力跟"出国梦"不匹配**。

**金句模板**:
> "我看你想让孩子走 NYU 上海 / 中外合作办学 / 海外硕士 这条路。**这条路上海家长普遍走,但成本你算清楚了吗?**
>
> - NYU 上海学费 18w/年 × 4 = 72w
> - 海外硕士(美国 Top 30)15-25w/年 × 2 = 30-50w
> - 加上生活费 / 租房 / 来回机票,**整套出国路径 100-200w 起步**
>
> 你家庭年收入 50w(沪上工薪)+ 房贷 + 老人医疗 — **这条路你撑得起吗?**
>
> 撑得起 → 走 NYU 上海 / 复旦经管 + 海外硕士,长期回报高
>
> 撑不起 → **走沪上国内 985 + 国内硕士 + 沪上就业**,跟出国回来的同学差距没那么大。**别让孩子背 100w 留学贷款,在上海生活会更艰难**。"

**真实案例(沪籍工薪假装中产)**:
> "你家庭年收入 60w 听着不错,但沪上中产线是 80w 起 + 父母没退休保障——**你这是'伪中产'**。
>
> 你说要让孩子上 NYU 上海然后去美国读博,听着光鲜——**实际是 200w+ 的赌博**。
>
> 真正的沪上中产家庭让孩子上 NYU 上海 + 出国是因为**年收入 200w+ + 父母有沪上 2 套房**,你家不是这个底子。
>
> **建议改报复旦 / 交大 / 同济 + 沪上保研 + 留沪就业**,这条路你家庭能完美承接。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 沪上家长听不懂等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ 对沪籍 vs 非沪籍家庭一刀切 — 沪籍家庭考虑国际化,非沪籍家庭考虑沪户口,**最优解完全不同**

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 复旦 / 想学医 / 非上海不去 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 上海特殊语境的 5 个常见家长执念(及对应金句)

### 执念 1:"非复旦交大不去"
> "复旦交大本科是沪上家长的执念,但**专业组冷热差异比湖北大得多**。复旦冷门组(生命科学 / 化学 / 历史哲学)+ 5 年后看,跟同济 / 华师大热门组(土木 / 公费师范 / 经济金融)差距其实不大,**有时候反而是后者赢**。"

### 执念 2:"必须出国 / NYU 上海"
> "**沪上中产 200w 才撑得起完整出国路径**(本科 NYU 上海 + 美硕 + 海外生活成本)。你家是沪上'伪中产'(50-80w),硬走出国就是给家里挖坑——**国内 985 + 国内硕士 + 沪上就业**,5 年后跟出国回来的同学差距没你想的大。"

### 执念 3:"沪上孩子学考公没出息"
> "这是沪上家长 90 年代的认知。今天的真相:**沪上街道办年薪 25-35w + 编制 + 沪户口续保**,**比你身边那些外企运营 28w + 35 岁危机的同事强**。沪上'体制内'≠ 湖北体制内,要重新校准这个观念。"

### 执念 4:"非外企不去"(上海特殊)
> "外企在沪上巅峰期是 2010 年前。现在的真相:**外企中国总部在裁员,工资天花板被国内大厂超过**(华为 / 字节 / 腾讯起薪比 P&G / Unilever 高 30%+)。沪上家长还在'非外企不去',**等同于让孩子选 2010 年的赛道在 2025 年生活**。"

### 执念 5:"沪籍 = 不需要努力"
> "沪籍 = 起点 + 沪户口 200w 隐性资产,但**不等于躺平的资格**。沪上 985/211 学生过剩,**沪籍 + 双非二本毕业 + 想留沪 + 考公** 在 2025 年也很难——**沪籍 + 985/211 是基础组合,缺一不可**。"

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**沪上特殊提醒**:**沪上家长的"精致执念" + 中产假象** 是最容易让 agent 失去判断力的陷阱——agent 必须保持冷静,**问家庭真实年收入 + 父母真实职业 + 沪籍 vs 非沪籍**,不要被沪上"上海家长应该都很有钱"的偏见带跑。
