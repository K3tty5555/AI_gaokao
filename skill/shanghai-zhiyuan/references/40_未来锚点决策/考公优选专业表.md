# 考公优选专业表(上海本地视角)

## 核心结论

**专业决定考公选岗范围**。沪上家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**上海考公的特殊性**:
1. **沪上选调生 = 全国唯三优渥**(跟江苏 / 北京并列):**复旦 / 上交 / 同济 / 华师大 / 上财 / 华政** 都是上海定向选调高校,**起点直接进市直机关 / 区直机关**,跳过基层
2. **上海市考竞争极卷**(报录比 50-100:1 起步,湖北只 20:1)→ **学校层次比湖北要求更高**
3. **沪户口本身就是隐性"考公福利"**:沪上市考 / 区考 优先沪籍,**非沪籍想留沪考公必须走选调生路径**
4. **沪上"半体制"路径独有**:**金融监管局上海分局 / 央行上海分行 / 银保监上海局 / 海关 / 外交部上海分部 / 上海自贸区管委会 / 长三角一体化办公室** = "比公务员高薪的体制内"

## 关键事实(2024 国考 / 上海市考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%(**沪上特别多**:海关 / 外交 / 央行)
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语 / 西语 等)** — 外交部、海关、商务部、国际组织 → **沪上特别有用**(占比约 2%,沪上对口岗位 5%+)

### 上海市考特殊性

- 上海市考 + 16 区区考 + 街道办,**汉语言文学 / 法学 / 经济学 三专业并列考公第一**
- 上海各市直机关**对法学要求高**(法院、检察院、司法局、市政府法制办)
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(沪上经常 1500+ 比 1)
- **基层公务员 / 街道办岗位**:沪上街道办年薪 25-35w + 沪户口续保(湖北街道只有 8-12w),**沪上基层比湖北中层吃香**
- **沪上限户籍岗位**:80% 岗位要求沪籍(本地户籍),**非沪籍只能报 20% 岗位**(主要靠选调生路径绕开户籍要求)

### 选调生(沪上版本,不是普通公务员,是高潜力路径)

- **沪上选调生 = 党政机关后备干部储备**,**起点比普通公务员高 1-2 级**
- **985/211 才有资格报**(沪上选调对象高校:复旦 / 上交 / 同济 / 华师大 / 华东理工 / 东华 / 上财 / 上海大学 / 华政 / 上外 + 部分外省 985)
- 优势专业:**法学 / 中文 / 马克思主义理论 / 行政管理 / 经济学 / 财政学 / 公共管理**
- **上海定向选调** = 录取后必须留沪服务 5 年,**直接给沪户口 + 起点四级主任科员**(非沪籍跨阶级最强路径之一)
- **中央选调到上海** = 中央组织部统一选调,**起点更高,直接进上海市直机关或国务院在沪机构**

### 公检法岗位的硬要求(沪上版本)

- **公安**:**多数岗位要求"公安专业"(中国人民公安大学、上海公安学院、华政警务方向)+ 通过公安联考**
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证),**沪上司法系统极硬**(华政 / 复旦法学 / 交大法学 = 沪上司法主供给)
- **监狱、戒毒**:法学 + 监狱学,**华东政法 / 上海政法学院** 对口

### 沪上"半体制"路径(独家,湖北家长想不到)

- **央行上海总部 / 上海分行**:**经济金融顶配 + 公务员编制 + 起薪 30-40w**(湖北的央行武汉分行只有 18w),**上财 / 复旦 / 上交 经济金融** 主供给
- **金融监管总局上海分局 / 上海证监局 / 银保监上海局**:同上,**沪上独有的"金融体制内 + 高薪"**
- **海关上海办事处 / 浦东海关 / 外高桥海关**:**外语 + 财经 + 法学** 都能报,**起薪 25-35w + 编制**
- **外交部驻沪机构 / 国务院发展研究中心上海分部**:**复旦 / 上外 / 上交** 国际政治 / 外交学
- **上海自贸区管委会 / 浦东新区政府**:**改革开放前沿 + 特殊政策 + 高薪 + 编制**
- **上海港务集团 / 上海机场集团 / 上海地铁集团**:**国企编制 + 30-40w 年薪**
- **三大运营商上海分公司 / 国家电网上海公司 / 中石化上海石化**:**央企编制 + 沪户口续保**

## 上海本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业

- **复旦法学** — 全国前 10,**沪上选调路径最优 + 法考通过率 90%+**,**进市委办 / 市政府办公厅主力**
- **华东政法大学(华政)法学** — **五院四系之一,沪上司法系统主供给**(法院 / 检察院 / 公安 / 司法局),**法考通过率全国前列**
- **上海交大凯原法学院** — 985 牌子 + 法学,**沪上选调高校**
- **复旦中文** — **沪上选调指标 + 市委办文秘综合岗**
- **华师大中文 / 公费师范** — 不是考公但是教师编制,**等同于考公友好**(沪上重点中学教师编 = 24-30w 年薪 + 寒暑假)
- **上财金融 / 经济 / 财政 / 会计** — **沪上财政税务 / 央行 / 金融监管 主供给**
- **复旦经济 / 国际经济** — 同上 + 海关 / 外交
- **上外英语 / 日语 / 西语 / 法语** — **海关 / 外交部 / 央行外汇业务** 对口
- **上交安泰经管 + 公共管理** — **沪上选调 + 国务院发展研究中心** 对口

### 双非 + 性价比考公专业

- **上海大学 汉语言文学 / 法学** — 211,**汉语言是沪上市考王者**,毕业考公成功率高
- **上海师范大学 汉语言文学 / 历史学** — 双非但**沪上教师编制次选 + 沪上市考友好**
- **上海政法学院 法学** — 双非但**沪上司法系统 + 监狱 / 戒毒 / 司法行政对口**
- **上海海事大学 海商法** — **海事法系统 + 海关 / 海事局** 沪上特色岗位

### 公安系统专属

- **上海公安学院 / 华政警务方向** — **沪上公安联考 + 进沪上各分局**
- 中国人民公安大学(在京,但沪上招生指标多)
- 中国刑警学院(在沈阳,但毕业可分回上海)

## 典型 case(供 agent 引用)

### Case A(逆袭路径):非沪籍工薪家庭考生
- 安徽合肥工薪家庭 → 660 分(660 制) → **华师大中文 + 沪上定向选调** → 毕业进上海市委办公厅文秘岗 → **沪户口 + 起点四级主任科员 + 年薪 25w + 编制**
- **典型非沪籍跨阶级路径**:不是顶级 985 + 通过选调生绕过户籍门槛 + 起点直接进市直机关

### Case B(沪上金融体制路径):沪籍中产
- 沪籍中产家庭 → 600 分 → **上财金融 + 央行上海分行公考** → 毕业进央行上海总部 → **起薪 35w + 公务员编制 + 留沪闭环**
- **沪上独有路径**:**金融体制内 = 央行 / 金融监管 / 银保监,这条路湖北没有**

### Case C(选调路径顶配):沪籍中产
- 沪籍中产家庭 → 620 分 → **复旦法学 + 中央选调到上海** → **毕业直接进上海市委组织部 + 起点正科级**
- **沪上选调生顶配路径**:复旦 + 法学 + 中央选调 = 政治路径全国前列

### Case D(失败路径):非沪籍工薪 + 双非
- 河南农村家庭 → 580 分 → 上海某二本经济学 → 毕业想留沪考公 → **沪上市考限户籍 + 双非学历不够选调** → 2 年没考上,**只能退回河南考省考**
- **典型踩坑**:非沪籍 + 双非 = 上海考公双重死局,**应该走国家专项 → 985/211 → 选调生**

### Case E(误区路径):沪籍 + 工商管理
- 沪籍中产家庭 → 580 分 → **被推上交工商管理**(以为"管理类好考公") → **毕业发现可报岗位远少于汉语言 / 法学** → 2 年没考上,**改行进外企但因专业水也找不到好的外企岗**
- **典型误区**:工商管理是沪上考公"看着对口实际坑"的代表

### Case F(沪上隐藏路径):沪籍 + 上外
- 沪籍中产家庭 → 580 分 → **上外英语 → 浦东海关公考** → **毕业进浦东海关 + 起薪 28w + 沪户口续保 + 编制**
- **沪上特殊路径**:外语 + 海关 = 沪上独有的"高薪体制内",湖北家长想不到

### Case G(沪上女生最稳):沪籍工薪
- 沪籍工薪 → 540 分 → **华师大公费师范汉语言** → 毕业回浦东重点初中语文老师 → **年薪 22w + 编制 + 寒暑假 + 沪户口续保**
- **沪上工薪女生最稳路径**:不卷不焦虑 + 编制 + 双休 + 寒暑假

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**。沪上很多家长被"管理"听起来对口迷惑,实际可报岗位差很多
- "**理科生不适合考公**" — 错。**沪上理科生考公完全可以**,只是学专业要选**汉语言、法学、经济学等文科为主的考公友好专业**(上海 3+3 制度 物理 / 历史可灵活报考多数文科)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。**沪上公安体系是公务员但要走"公安联考"专门通道**,多数公安岗位只对公安专业开放
- "**选调生比考公好考**" — 错。**选调生 = 985/211 才有资格,但是资格内的竞争小**,所以**对沪上 985/211 学生而言,选调生比国考省考好考**
- "**汉语言文学就是当老师**" — 严重错误。**这是沪上家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**沪上家长不需要考公**" — 错。**沪上中产家庭 30%+ 实际还是想孩子考公**(因为沪上房价 + 教育成本压力),但他们要的是"高级公务员"(选调生 / 央行 / 海关 / 自贸区),不是基层公务员
- "**非沪籍考公没希望**" — 错。**非沪籍走选调生路径 = 沪户口 + 公务员编制 + 起点高**,**比沪籍考普通市考更值**

## 关键提醒

**考公是普通家庭 + 非沪籍家庭最稳定的上升通道**。沪上版本的考公独特性:

1. **沪上选调生 = 全国前三优渥**(跟江苏 / 北京并列):**985/211 + 沪上定向选调 / 中央选调到上海** = 起点直接市直机关 + 沪户口 + 编制
2. **沪上"半体制"是隐藏金矿**:**央行 / 海关 / 金融监管 / 自贸区 = 比普通公务员高薪 + 编制**,**沪上独有**
3. **非沪籍想留沪考公必须走选调生**(沪上市考 80% 限户籍)
4. **沪上"基层公务员"≠ 湖北基层公务员**:**沪上街道办年薪 25-35w + 编制 + 沪户口**,这是湖北"基层"想不到的高度
5. **汉语言文学 + 法学 = 沪上考公双王者**,但**沪上学校层次门槛比湖北高一档**(湖北双非汉语言能考省考,沪上市考至少 211 起步)

**农村家庭 / 非沪籍家庭 注意:沪上选调生路径 = 跨阶级最强工具,优先级高于一切**。
