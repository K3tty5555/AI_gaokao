# 复旦大学(复旦,FDU)— 综合性 985 第一档(沪上文理顶配)

## 一句话定位

**沪上文理医顶配 985**,综合排名稳居 Top 5(复交清北浙南),**经济 / 新闻 / 管理 / 临床医学 / 文史哲 / 数理化** 全国前列。**上海考生分够清北边缘 + 想留沪 = 复旦首选**,海派精致的代名词。

---

## 真实地位

- **全国排名 Top 5 985**,跟北大并列"江南文理顶配",C9 联盟里"自由 + 综合 + 都市"的代表。
- **上海本地心理上限**:沪籍考生家长心目中,**复旦 = 留沪最体面的 985**,跟交大并列上海双子星,本省录取分常年压一票外地 985。
- **同档对比**:文理基础学科 + 医学 + 经管 跟北大同档;工科明显不如上交 / 同济;新闻 + 经济在长三角无人可比。
- **海派文化代表**:校风自由、精致、国际化,跟交大的工科卷形成鲜明对比。
- **上医校友圈 = 沪上三甲医院主力**(中山 / 华山 / 肿瘤 / 儿科),这种本地资源去外地拿不到。

---

## 上海综合录取位次区间

参考近 5 年掌上高考 + 上海一分一段表反查(上海总分 660,3+3 模式,**只有"综合"一个口径**):

- **顶级组(强基 / 经济管理实验班 / 临床八年制 / 数理拔尖)**:全市 **前 200-600 名**,基本对应 590+(660 制)。
- **主流组(经管 / 新闻 / 数理化 / 文史哲)**:全市 **600-1,500 名**。
- **冷门组(技术科学实验班部分方向 / 历史地理类小众)**:全市 **1,500-2,500 名**。

**段位定位**:上海考生 **想冲复旦基本要全市 2,500 名内**,**1,500 名内可挑专业**,**500 名内任选 + 冲强基**。**位次比分数硬,以当年一分一段表反查为准**。

**综评批占大头(必懂!)**:复旦 **综评批录取占 50%+**,本一线以上(503+)就能报,**初试笔试 + 校测面试 + 学考成绩** 综合录取。**只看普通批 = 主动放弃一半名额**,所有上海考生都要尝试综评。

## 性价比专业(同样复旦牌子,录取相对低)

- **历史学 / 哲学 / 古文字**:全国前 5 但行业冷门,录取分比经管低,**适合考公选调路径**,复旦文科牌子在沪上体制内极硬。
- **强基计划(数学 / 物理 / 化学 / 生物 / 历史 / 哲学)**:**比裸分进复旦低 5-15 分**,但承诺直博 + 不能转专业,适合学术苗子。
- **技术科学实验班 / 自然科学实验班**:大类招生,大二分流,**冲复旦牌子的"备胎组"**。

## 坑专业 / 慎选(在复旦里相对弱)

- **工科核心(机械 / 电气 / 自动化 / 土木)**:**复旦工科不如上交 / 同济**,出来跟上交同方向比薪资差一截,**这些专业直接选上交或同济**。
- **生命科学 / 生物技术**:全国前 5 也救不了"必须读博 + 生化环材天坑"的现实,**慎选,除非笃定走学术 + 出国**。
- **材料 / 化学(纯理学方向)**:同上,生化环材本科出口窄。
- **农林**:复旦没有(这点要清楚)。

## 关键提醒(填报陷阱)

1. **综评批必报**:复旦综评占录取 50%+,**只看普通批等于自废一半名额**。综评校测笔试 + 面试,准备方向跟普通批不同,要提前 2-3 个月练。
2. **专业组多达 6-8 个**:复旦综合类专业组里"自然科学试验班""技术科学试验班""经济管理试验班"等大类,**组内可能含化学 / 生物 / 材料 / 微电子等多个方向**,服从调剂前务必查 2026 年招生章程具体组内有什么。
3. **强基 vs 裸分**:强基低 5-15 分进复旦,但**直博绑定 + 不能转专业**,慎选(尤其历史哲学强基,本科直接就业窄)。
4. **复旦上医 vs 交医**:**上医临床(中山华山系)+ 交医临床(瑞金仁济系)** 是沪上双子星,**笃定走医选哪个都不亏**;**上医基础医学 + 公卫 + 口腔更全面**,**交医临床手术系更硬核**。
5. **复旦 vs 上交**:**学文理医基础选复旦,学工科 CS 选上交**;医学方向两家都顶级,看你想去哪个三甲系。
6. **非沪籍 vs 沪籍**:非沪籍录取门槛比沪籍高 5-15 分,但只要满足居住证 + 社保 7 年 + 中考在沪即可报。

## 毕业出口(2024 数据)

- **留沪就业**:约 70-75%(沪上 985 留沪率最高之一,**陆家嘴 + 张江 + 国际化路径完整**)
- **出省(北深)就业**:约 10-15%(主要是 BAT / 字节 / 腾讯总部)
- **保研 / 考研 / 读博**:约 50%+(复旦保研率 ~30%,985 第一档)
- **出国**:约 20-25%(上海家庭出国意愿全国最高,**复旦海外名校直通**)
- **考公 / 选调**:约 8-12%(沪上选调指标 + 中央选调)
- **起薪范围**:经管金融 25-40w,临床医学规培期 12-18w(规培后翻倍),CS 25-35w,文科考公编制 15w+。
- **进外资 / 国际组织概率**:全国第一档(海派 + 国际化 + 英语强 三件套)

## 适合谁

- 上海综合排名 **2,500 名内** 的考生(普通批),**5,000 名内** 可冲综评。
- 喜欢**基础学科 / 文史哲 / 经管金融 / 医学** 的综合通识型选手。
- 家庭中产以上 + 父母不限定行业 + 鼓励读研读博 / 出国 → 复旦最合适。
- 想留上海 + 走外资 / 国际化 / 媒体 / 金融 / 体制内任意路径的考生。
- **海派精致型**(对自由校风 + 国际化 + 都市生活有要求)。

## 不适合谁

- **铁了心要学顶级工科 / CS** → 选上交更对口(复旦工科一般)。
- **家庭普通工薪 + 想本科直接就业出活**:复旦基础学科多数要读研读博,**本科直接就业不如上交工科出活快**。
- **笃定考公进基层 / 县乡** → 复旦海派路径在基层不如华师大 / 上财 直接对口。
- **特别在意"性价比"** → 复旦录取分顶配,要分要位次,不算性价比型选项。
