# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(上海版)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。**上海的特殊性在于 5 档家庭分层比湖北更细 + 沪籍 vs 非沪籍是隐性第六维度** —— 同样位次同样选科,**沪籍中产 vs 非沪籍工薪 的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入)+ **沪籍 vs 非沪籍**,按本文件的 5 档矩阵 + 户籍维度套对应策略。

**上海版的特殊维度**:
- **家庭年收入 50w 在上海 ≈ 湖北 25w**(生活成本要打对折)
- **沪上中产 = 家庭年收入 80-200w 才算**(湖北中产 30-80w)
- **沪籍 vs 非沪籍 = 隐藏的家庭抗风险维度** —— 沪户口本身就是 200w+ 隐性资产(浦东学区房资格)

## 档位 ① 体制内家庭(公务员 / 事业编 / 央企国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。沪上特殊:**包括外资 / 中资银行总行 / 央企总部 / 三甲医院 / 高校 / 党政机关**,沪上"体制内"比湖北宽得多。

**家庭画像**:
- 抗风险能力中等偏上(沪上体制内收入比湖北高,**沪上市直机关公务员年薪 25-40w + 沪户口**,湖北只有 12-18w)
- **懂沪上体制游戏规则**(知道选岗 / 公考 / 选调生 / 中央选调上海生源)
- **孩子考公是默认路径之一,但不是唯一**(很多沪上体制家庭让孩子先去外企 / 金融,30 岁后再考虑回体制)
- 资源:能给孩子推荐合适岗位、知道沪上选调生定向校(复旦 / 上交 / 华师大)

**推荐策略**:
1. **强烈考公友好型**:复旦 / 上交 / 华师大 法学 / 经济学 / 公共管理 / 中文 / 财政学 → **走中央选调到上海或上海定向选调路径**(起点直接进市直机关)
2. **985/211 选调生路径**:沪上选调走**复旦 / 上交 / 同济 / 华师大 / 上财 / 华政**,**比国考省考更优**(起点更高、竞争内部化)
3. **避免体制外才有出路的专业**:CS / 互联网创业 — 跟父母期待冲突,**沪上体制家庭对"互联网996"接受度比湖北家长还低**(因为他们见过太多 996 然后被裁的同事)
4. **特殊机会**:**上财金融 / 财政学** + 央企总部财务 / 银行总行 = 沪上体制家庭的"半体制内 + 高薪"路径
5. **海事大学 / 国际海事 法学** + 海事法系统 = 上海特色司法路径

**典型 case**:
- 沪籍中产体制内家庭(父亲市委办公厅干部,母亲华东医院护士长)→ 孩子 600 分(660 制)→ 推**复旦法学** → 大三参加沪上选调生选拔 → 毕业进上海市委组织部,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去交大 CS → 毕业 35w 起薪很高,但家长不满"不稳定 + 996",**劝其离职考公,2 年时间损耗 + 心理纠结**(沪上体制家庭这种 case 比湖北还多,因为 35w 在沪上买不起房,家长更焦虑)

## 档位 ② 专业人员家庭(医生 / 教师 / 律师 / 工程师)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。沪上特色:**包括外资律所合伙人 / 三甲医院主任 / 985 高校教授 / 高级金融分析师**(沪上专业人员家庭天花板高)。

**家庭画像**:
- 抗风险能力高(沪上专业人员收入 + 行业人脉密度全国最强)
- **行业拐杖最有力**:沪上**子承父业的成功率比湖北高 50%**(因为沪上行业资源更密集 + 实习机会多 + 校友圈强)
- 通常重视教育投入,**孩子从小学开始就走"复旦附中 / 交大附中 / 上中"路径**
- 资源:能给孩子推荐内部实习、考研导师、就业渠道,**沪上专业人员的"内推"含金量比湖北高一个数量级**

**推荐策略**:
1. **优先子承父业**:**医生家庭 → 上医 / 交医临床八年制(父母能撑 8 年读书 + 三甲医院推荐 + 校友圈直通)**;教师家庭 → 复旦中文 / 华师大 + 公费师范;律师家庭 → 复旦 / 华政 / 交大法学(沪上"五院四系"格局)
2. **行业相关延伸**:工程师家庭 → 同济土木 / 交大机械(同济土木 + 父亲设计院 = 沪上设计院行业拐杖)
3. **不必选最稳路径**:有专业拐杖的话,**可以选行业上限较高但起步辛苦的专业**(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难,沪上金融比湖北更看人脉)

**典型 case**:
- 父亲律师 + 母亲普通工薪 → 孩子 590 分(660 制) → **复旦法学 + 走父亲律所路径** → 大三父亲律所实习 + 法考通过 → 毕业进父亲律所做 trainee → **3 年后红圈所合伙人路径**
- 父母都是中山医院主治医生 → 孩子 620 分 → **上医临床八年制** → 父母行业资源 + 中山校友圈 + 8 年长周期家庭撑得起 → **典型沪上子承父业医生路径**
- 父亲华师大教授 + 母亲华东医院主任 → 孩子 580 分 → **华师大公费师范 + 留沪当老师** → **沪上专业人员家庭"半佛系"路径**(不卷不焦虑 + 体面收入)

## 档位 ③ 中产管理 / 私企老板家庭

**定义**:父母私企中高管 / 自主创业 / 企业主 / 外企总监级 / 金融高管。沪上"中产"= **家庭年收入 80-300w**(湖北中产 30-80w)。

**家庭画像**:
- 抗风险能力极高(收入有上限但天花板很高,**沪上家庭可承担 50w/年子女出国留学**)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 国际视野 / 商业敏感度
- 资源:**沪上中产家庭 = 商业人脉 + 海外校友 + 跨国公司 know-how + 可能继承家业**
- **教育投资观全国最国际化**:**孩子高中开始考虑出国 / 国际课程 / 中外合作办学**

**推荐策略**:
1. **可选商科 / 创业方向**:**复旦经管 / 上交安泰 / 上财金融 / 中欧国际 / 港大 / 港中文 / NYU 上海 / 上纽**(选择面比湖北宽 5 倍)
2. **中外合作办学是沪上中产家庭隐藏神器**:**纽约大学上海(NYU 上海)/ 上海科技大学 / 西交利物浦(在苏州) / 香港大学上海办公室 / 上海大学悉尼工商学院** —— 学费 8-15w/年家里能撑,**国际背景 + 留沪闭环**
3. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,**沪上中产家庭普遍走"本科冲名校 + 硕士去美国常春藤"** 路径
4. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野
5. **可走小众路径**:**艺术(上戏 / 中央美院 / 罗德岛) / 设计(同济设计 / 上海视觉)/ 自由职业 / 创业 / 量化基金** — 父母给得起 5-10 年试错成本
6. **避免:进体制内基层 / 县乡公务员**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 沪籍私企老板家庭(年入 500w+,做外贸)→ 孩子 580 分(660 制) → 推**纽约大学上海(NYU 上海)经济学** → 学费 18w/年家里轻松 → 大三海外交换 + 暑期高盛香港实习 → 毕业进高盛上海 IBD,**起薪 60w + 海外团队** → **典型沪上中产顶配路径**
- 沪籍金融高管家庭 → 孩子 620 分 → **上交安泰经济管理实验班** → 大三去 LSE 交换 → 校招进摩根斯坦利上海 / 高盛上海,**起薪 80w + 沪上金融家族延续**
- 沪籍私企家庭(餐饮连锁年入 200w)→ 孩子 540 分 → **同济建筑 / 上戏导演系**(给孩子兴趣 + 商业延展) → 毕业接父母家族企业 + 自己开新业务

## 档位 ④ 普通工薪家庭(沪籍 / 非沪籍 / 国企工人 / 服务业)

**定义**:沪上工薪 = 父母双方稳定工作但收入有限,**家庭年收入 20-60 万为主**(湖北工薪是 10-30w)。

**家庭画像**:
- **抗风险能力中等偏低**(沪上生活成本高,失业 / 失败的代价比湖北大,**沪上租房 + 通勤 + 餐饮 = 月支出 1.5-2w 起步**)
- 信息差比湖北小(因为身边都是沪上中产),**但对体制 / 行业 / 圈子的真实门槛仍然有偏差**
- 通常希望孩子稳定 / 编制 / 不要折腾 / 留沪
- **沪籍工薪 vs 非沪籍工薪**:
  - **沪籍工薪 = 有沪户口 + 父母没什么资源**:孩子需要"沪户口续保 + 编制"两件套
  - **非沪籍工薪 = 拿沪户口是核心诉求**(隐性 200w+ 资产)

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径(沪上版本)**:
   - **华师大公费师范生(汉语言 / 数学 / 物理 / 英语)** = 沪上工薪最稳路径 + 编制 + 寒暑假 + 沪户口续保
   - **沪上三甲医院技术岗(医学影像 / 检验)+ 上海健康医学院** = 编制 + 沪户口
   - **国家电网上海公司 + 上海电力大学电气** = 央企编制 + 沪户口续保
   - **沪上市考 / 区考 + 上财 / 上大 中文 / 法学** = 公务员编制 + 沪户口续保
3. **次推稳定就业型**:
   - **上交 / 同济 工科主流(机械 / 电气 / 土木) → 央企(中船 / 上汽 / 中车 / 中建)**
   - **同济建筑 / 设计学院** + 沪上设计院系统(虽然行业下行,沪上设计院仍有蓝海)
   - **复旦 / 华东师大 师范** + 沪上重点中学教师编(浦东 / 黄浦 / 静安区有留沪指标)
   - **上财 / 华理 / 东华** 强专业(金融 / 化工 / 服装设计)+ 沪上对口央企国企
4. **避免高风险方向**:
   - **金融 / 经济 / 工商管理(双非这些 = 死局)**:**沪上金融校招完全看复旦交大上财清北外加海外 Top30**,双非金融在上海等于自杀
   - **双非 CS**(2024 沪上双非 CS 起薪 12w,跟外企运营同档)
   - **生化环材**(必须读博才有出路,普通家庭撑不起)
   - **临床医学**(沪上 5+3+规培 8 年长周期 + 房价 + 生活成本,工薪家庭撑不起)
   - **心理学 / 历史学 / 哲学**(本科出口窄,必须读研)
   - **任何沪上民办二本三本** —— 沪上 985/211 学生过剩,民办 = 自动出局

**典型 case**:
- 沪籍工薪家庭(父亲国企工人,母亲银行柜员)→ 孩子 540 分(660 制) → **上海电力大学电气** → 毕业进国网上海浦东郊区局,**月薪 1.5w + 编制 + 沪户口续保**,**家庭逆袭**
- 沪籍工薪家庭 → 孩子 520 分 → **上海师范大学公费师范英语** → 毕业回浦东某重点初中英语老师,**年薪 18w + 编制 + 寒暑假**
- 非沪籍工薪 → 孩子 660 分(660 制 = 全省 Top 5%) → **华师大中文系 + 沪上选调指标** → 毕业进上海市委办公厅,**沪户口 + 公务员编制 + 起点四级主任科员**(非沪籍最强跨阶级路径)
- 非沪籍工薪 → 孩子 580 分 → **上海健康医学院 医学影像技术** → 毕业进沪上某三甲医院影像科,**起薪 8k + 编制 + 沪户口指标 + 不卷不焦虑**

## 档位 ⑤ 农村 / 临工 / 蓝领家庭(沪上罕见,但非沪籍考虑)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 20 万。**沪上极少**(沪上户籍人口几乎没有这一档),**多数是非沪籍学生从外省考来上海**。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差极大(对沪上 / 大学 / 行业完全不了解)
- 期待孩子跨阶级 + 留沪
- 资源:零,完全靠孩子自己 + 学校
- **核心诉求 = 沪户口 + 编制 + 长期稳定**

**推荐策略**:
1. **学校牌子 + 沪上学校 + 编制路径** 三件套
   - 沪上 985/211 牌子能直接打开城市 + 圈子,**跨阶级首要工具**
   - 同等分数下,**沪上 211 + 留沪编制 > 外省 985 + 弱专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **华师大公费师范生(汉语言 / 数学)** = 沪上农村家庭神器 + 无学费 + 编制 + 沪户口
   - **国家专项计划 → 复旦 / 上交 / 同济** = 沪上 985 名校多个专项指标(分数比统招低 20-30 分)
   - **海军军医大 / 武警特警学院上海** = 军校(无学费 + 编制 + 包分配 + 沪户口)
   - **上海电力大学电气 + 国家电网上海** = 央企编制 + 沪户口续保
   - **上海健康医学院 + 沪上三甲技术岗** = 编制 + 沪户口
3. **避免长周期投入**:
   - 临床医学 8 年(沪上撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划 → 复旦 / 上交**(分数比统招低 20-30 分)
   - **强基计划(数学 / 物理 / 化学)** 单科特别强的农村学生有机会
   - **海军军医大学** = 军校(无学费 + 编制 + 包分配)
   - **公费师范生 → 华师大**(无学费 + 编制 + 寒暑假)

**典型 case**:
- 安徽农村家庭非沪籍 → 孩子 660+ 分 → **国家专项进复旦中文 → 沪上选调** → **整个家族第一个上海公务员 + 沪户口**
- 河南农村家庭非沪籍 → 孩子 690+ 分 → **国家专项进上交电气 → 国网上海** → **农村家庭跨阶级 = 沪户口 + 央企编制 + 1.8w 起薪**
- 江西农村家庭非沪籍 → 孩子 580 分 → **海军军医大学医学技术** → **免学费 + 包分配 + 留沪**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位 + 沪籍 vs 非沪籍**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**沪上特别注意**:**沪籍 vs 非沪籍 的隐性维度,agent 必须主动追问**(很多用户不会主动告知,但这决定了是否要"沪户口路径")。**非沪籍 + 想留沪 = 沪户口路径优先级高于一切**。
