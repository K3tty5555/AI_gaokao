# 湖北高考专科填报咨询(MVP 框架)

## 一、定位

**专科 ≠ 本科的 mini 版**。两者的录取批次、决策逻辑、就业路径、上升通道**完全不同**。

| 维度 | 本科填报(主 skill) | 专科填报(本 skill) |
|---|---|---|
| 录取批次 | 普通本科批(分 6-7 月初) | 高职高专批(分 7-8 月) |
| 院校选择重点 | 学校层次 + 城市 + 专业 | **专业 + 行业出口 + 专升本资格** |
| 就业逻辑 | 校招平台 + 个人能力 | **技能型岗位 + 行业入门 + 资格证** |
| 上升通道 | 考研 / 出国 | **专升本 / 自考 / 考证 / 工作经验** |
| 时间投入 | 4 年 | 3 年 + (2 年专升本若选) |

## 二、触发场景

由主 skill (`hubei-zhiyuan`) 检测到用户分数处于"本科线下,专科线上",通过 `score_to_rank.py` 的 `batch.bracket = "between_undergrad_and_vocational"` 信号,引导用户切换到本 skill。

或用户直接说"湖北专科怎么填""我考了 350 分要报专科"等明确触发。

## 三、对话流程(MVP 简版)

### L1 硬数据
1. **高考总分** + **全省位次**(优先用 `hubei-zhiyuan/scripts/score_to_rank.py` 跨 skill 复用)
2. **选科组合 + 物理/历史类**
3. **是否服从调剂**(Y/N,**专科同样建议 Y**)

### L2 关键决策(专科特有)

1. **打不打算专升本?** Y/N + 强度 1-5
   - 强度 5 → 选**专升本对口本科多的专科专业 + 公办院校**
   - 强度 1 → 直接看就业,选**技能强的专业**(护理 / 电子商务 / 学前教育 / 机电类)
2. **想留湖北还是出省?**(默认湖北,因为湖北专科本地认可度更高)
3. **接受男女比失衡的专业吗?**(护理/学前教育女生为主;机电/汽车男生为主)
4. **接受野外/户外/三班倒工作吗?**(铁路/电力/化工很多专科岗位有体力要求)

### L3 家庭与个人

简化版,只关心:
- 家庭经济(影响民办 vs 公办选择,民办专科学费 1.5-2.5 万 / 年,公办 5-8 千 / 年)
- 性别(很多专科专业有性别倾向)
- 性格(简版 3 题,跟主 skill 一致)

## 四、推荐输出(简版)

```
## 你大致定位

分数 X(物理类 / 历史类),全省位次 Y → 大致专科档位:
  公办老牌高职 / 一般公办高职 / 民办院校三选一档

## 推荐 5 所(冲 1 / 稳 2 / 保 2)

[基于 query_school.py 复用 — 用户位次过滤后取专科批数据]

## 关键提醒

- 优先公办,民办学费贵 + 认可度低
- 优先技能强的专业(护理 / 电子商务 / 学前教育 / 机电 / 铁路 / 电力)
- 避坑:专科里"听起来高大上"的专业(国贸 / 工商管理 / 行政管理 — 跟本科一样坑,且专科出来更没竞争力)
- 专升本 = 改命的最大机会,选**专升本对口率高的专业**
- 以上为参考建议,实际填报请结合最新招生章程
```
