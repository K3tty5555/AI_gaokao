# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(山西视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**山西工矿子弟和煤老板家庭的最优解可能完全相反**。山西特殊性:**经济萎缩 + 民企稀缺 + 央企(电网 / 焦煤 / 太钢 / 兵器 / 国防)对口度极强**,**这意味着山西家长决策中"央企编制"的权重比湖北 / 浙江高得多**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企 / 央企子弟)

**山西特殊性**:山西体制内家庭比例**全国前列**(煤炭央企子弟 + 电网子弟 + 公务员家庭),**山西有"国家电网子弟" / "焦煤子弟" / "太钢子弟" / "潞安子弟" / "中物院子弟" 等独特群体** —— 这些家庭抗风险能力强 + 父母系统对口资源丰富。

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程 / 央企内部规则)
- **孩子考公 / 进父母系统几乎是默认路径**
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易、央企子弟岗内部推荐通道

**推荐策略**:
1. **优先父母系统对口**:
   - 国网子弟 → 电气工程(华电 / 太理工 / 中北)→ 国网山西
   - 焦煤 / 潞安 / 阳煤子弟 → 化学工程(太理工双一流)/ 矿业工程(太理工)
   - 太钢子弟 → 材料科学(太理工 / 太科大)
   - 中物院 / 兵器集团子弟 → 兵器科学(中北)/ 探测制导(中北)
   - 山西公务员家庭 → 法学 / 汉语言 / 经济(山大 / 中南财法 / 山财)+ 选调生
2. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
3. **985/211 选调生路径**:如果孩子能上 985/211,**走选调生比国考省考更优**(山西定向选调走山大 / 太理工 / 中北 + 出省 985)
4. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
5. **特殊机会**:警校 / 公安专业(山西警察学院) / 山医法医 — 进山西公安系统 + 父母编制资源能用上

**典型 case**:
- 山西大同某焦煤子弟家庭(父亲山西焦煤集团中层)→ 孩子物理类省排 12000 名 → **太理工化学工程**(双一流) → 毕业回山西焦煤集团进管理培训生路径,**父辈系统延续 + 编制完美对接**
- 山西太原公务员家庭(父亲省直机关 + 母亲银行)→ 孩子历史类省排 4000 名 → **山大法学 / 中南财法法学** → 毕业选调进山西省委办,**家庭路径完美匹配**
- 山西阳泉某国网子弟家庭(父亲国网阳泉)→ 孩子物理类省排 18000 名 → **中北电气**(进国网山西阳泉基层)→ 父辈系统延续 + 留本地
- 失败 case:同样焦煤子弟家庭,孩子被推去出省 985 学 CS → 毕业出省做程序员 35w 起薪,但父母不满"放弃集团子弟岗",**亲情 + 编制双重纠结**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师)

**山西特殊性**:山西教师家庭(山西教育系统老化,教师比例高) + 医生家庭(山医系统裙带文化强) + 工程师家庭(太钢 / 太重 / 国电投 等技术岗工程师) — **拐杖效应明显**。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:
   - 山西教师家庭 → 山西师大 / 山大 师范 / 公费师范 → 进入父母系统
   - 山西医生家庭(山医系统) → 山医临床 / 5+3 一体化 → 山医一附院 / 二附院 实习推荐
   - 山西工程师家庭(太钢 / 太重 / 国电投 等) → 太理工 / 太科大 对应工科 → 父辈单位实习 + 校招优势
2. **行业相关延伸**:律师家庭 → 山大法学 / 中南财法;山西工程师 → 太理工对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(山西金融家庭基本不存在,没行业资源会很难)

**典型 case**:
- 母亲太原五中语文老师 + 父亲普通工薪 → 孩子历史类省排 4500 名 → **公费师范生汉语言**(山西师大) → 毕业回原校 / 太原市内重点中学 + 编制,**母亲资源直接复用**
- 父母都是山医一附院临床医生 → 孩子物理类省排 5000 名 → **山医 5+3 一体化临床(留晋)** 或 **西安交大医学部** → 父母能撑 8 年读书 + 山医 / 山西医院推荐 → **典型山西子承父业路径**
- 父亲太重技术岗工程师 → 孩子物理类省排 18000 名 → **太科大重型机械** → 毕业回太重 / 中国一重 / 中国二重 + 父辈技术口推荐 → **山西工矿家庭最稳跨代延续**

## 档位 ③ 私企管理 / 创业 / 煤老板家庭

**山西特殊性**:山西私企家庭比例**比湖南 / 安徽低**(山西民营经济相对萎缩),但**山西煤老板家庭独特**(吕梁 / 朔州 / 临汾 等煤产区有批中小煤老板,资产从几百万到上亿不等)+ **少数文旅 / 新能源 创业家庭**(平遥 / 大同 文旅 / 朔州光伏 等)。

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高 / 煤老板尤甚)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 商业敏感度 / 自主性
- 资源:商业人脉、行业 know-how、可能继承家业

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校) — 山西煤老板第二代接班思路
2. **可冲名校弱专业**:中产 / 煤老板家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野(山西煤老板二代去英美留学比例不低)
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **山西文旅 / 新能源创业家庭** → 孩子可学旅游管理 / 文物保护 / 新能源工程,接班路径

**典型 case**:
- 山西吕梁某煤老板家庭(年入 1000w+) → 孩子物理类省排 22000 名 → **出省 211 弱专业 + 出国读研** → 出国背景做家族企业接班
- 山西平遥古城旁文旅创业家庭 → 孩子历史类省排 8000 名 → **山大文物与博物馆学**(山西文博资源全国前列)+ 留晋接班文旅 → 路径独特
- 失败 case:山西煤老板家庭 → 孩子被推考公 → 进山西基层公务员后被父母嫌"端那点死工资没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂工人 / 服务业 / 文员)

**山西特殊性**:山西工矿子弟很多 — 焦煤普通工人 / 太钢一线工人 / 太重一线工人 / 国电投一线工人 等,**这些是不带子弟岗优惠的普通工薪**(跟①档央企管理层子弟不同)。**抗风险能力比湖北襄阳 / 武汉工薪家庭弱** — 山西工矿企业 5-10 年内还在收缩,父母自己都担心被优化。

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主。

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大,且山西本省工矿企业还在收缩)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(山西师大 / 山大)** = 高考分适中 + 直接编制 + 无学费 → 山西农村县市教师 / 重点中学
   - **山西警察学院 + 公安联考** = 进山西警察系统编制
   - **山医法医学** = 进山西公安系统 / 司法鉴定 + 公务员编制(山西独家路径)
   - **医学技术(医学影像 / 检验 / 护理)** = 山医 / 长治医学院 / 山西大同大学医学院,4 年本科即可
3. **次推稳定就业型(山西本土央企对口)**:
   - **电气工程(太理工 / 中北)** → 国家电网山西公司
   - **化学工程(太理工双一流)** → 山西焦煤集团 / 潞安化工 / 山西国新能源
   - **兵器科学(中北)** → 中物院 / 兵器集团 / 航天科工(出省工作但稳定)
   - **机械(太科大)** → 太重 / 中国一重 / 中国二重(出省工作 + 山西本土)
   - **汉语言文学(山大 / 山西师大)** = 山西考公 / 教师编王者
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局,山西金融岗少)
   - 双非 CS(山西本省 IT 岗稀缺,毕业留晋月薪 6-8k 跟工科持平)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 临床医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- **山西大同某焦煤普通工人家庭** → 孩子物理类省排 14000 名 → 推**太理工电气工程**,毕业进国家电网山西大同分公司,**月入 9k + 编制 + 留大同**,家庭逆袭
- **山西临汾普通工薪家庭** → 孩子历史类省排 7000 名 → 推**山西师大公费师范汉语言**(免学费 + 毕业回临汾县城教师编制),**4 年家庭零负担 + 直接编制**
- **山西吕梁山区普通工薪家庭** → 孩子物理类省排 25000 名 → 推**中北兵器科学**,毕业进中物院 / 兵器集团 — 接受偏远基地 = **工矿子弟跨阶级最稳路径**
- **山西忻州普通工薪家庭** → 孩子物理类省排 32000 名 → 推**山医法医学**(分能上),进山西公安系统 + 公务员编制,**4 年本科 + 5+3 后直接进编制**

## 档位 ⑤ 农村 / 临工家庭

**山西特殊性**:山西农村家庭比例不低(吕梁山区 / 太行山区 / 雁门关地区 经济欠发达),且**山西国家专项 / 高校专项 / 地方专项 名额比河北 / 河南 多**(因山西考生少 + 国家专项指标按省分配)。**农村家庭逆袭路径在山西比"出去打工"更需要靠谱跨阶级 toolkit**。

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(山西师大)** = 无学费 + 山西基层县市编制 = **山西农村家庭神器**
   - **国家专项计划 / 高校专项 / 地方专项** = 山西农村专属优惠(分数比统招低 20-40 分)
   - **山西警察学院 + 公安联考** = 山西基层警察编制(部分免学费)
   - **山医法医学**(山西公安编制 + 4 年本科 + 5+3 不太长)
   - **山医医学影像 / 检验 / 护理**(本科 4 年 + 进山西县级 / 地市三甲技术岗 + 编制)
3. **避免长周期投入**:
   - 临床医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **山西国家专项**:山西农村户籍,985/211 名校多个专项指标(分数比统招低 20-40 分)
   - **山西强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **山西师大公费师范**(山西本省最重要的农村跨阶级 toolkit)
   - **中北兵器**(分数门槛友好 + 央企编制 + 不挑家庭背景)

**典型 case**:
- **山西吕梁山区农村家庭** → 孩子物理类省排 8000 名 → 通过**山西国家专项**进**西安交大材料**(比统招分低 30 分)→ 985 牌子 + 国家专项编制路径,**整个家族第一个 985**
- **山西忻州农村女孩** → 历史类省排 6000 名 → 推**山西师大公费师范汉语言** → 4 年无学费 + 毕业回原县编制,**最适合农村家庭的"零风险"路径**
- **山西临汾农村男孩** → 物理类省排 28000 名 → 推**中北兵器** → 进中物院 / 兵器集团基地编制,**月入 8k + 编制 + 跨阶级,接受偏远基地工作**
- **山西阳泉农村女孩** → 物理类省排 35000 名 → 推**长治医学院医学影像技术** → 4 年本科 + 进晋东南某市三甲技术岗 + 编制,**最稳普惠路径**

## 山西 vs 其他省的家庭决策差异

- **山西比湖南 / 安徽 民营经济弱 → 体制内权重更高**
- **山西比内蒙 央企对口度更细分 → 工矿子弟岗有清晰对口专业**(电气进电网 / 化工进焦煤 / 材料进太钢 / 兵器进中物院)
- **山西比山东 民营企业 / 私企岗少 → ③ 档私企家庭比例低,煤老板独特存在**
- **山西比河北 留省吸引力低**(河北人留京津更近;山西人留晋只能在太原 / 各地市 + 经济萎缩)
- **山西考生留晋率 50%-60% < 河南 / 山东** — **出省战略是山西考生的常态**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**山西特殊提醒**:**普通家庭 / 农村家庭 + 山西考生 = 进央企编制 / 教师编 / 公安编制 是最稳路径**,这一点比沿海省份更重要 — 山西本身缺民企岗,体制外失败的回旋余地小。
