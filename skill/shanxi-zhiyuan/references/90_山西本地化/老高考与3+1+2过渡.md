# 山西老高考与 3+1+2 过渡 — 2025 首届新高考关键背景

## 核心结论

**山西 2022 年加入新高考第五批**(全国倒数第二批,跟陕西/青海/宁夏/甘肃 同批),**2025 年高考是首届 3+1+2 实战考**。**2021-2024 全是老高考文/理体系**,2025 才切换为物理/历史类。这意味着:

- **2025 年的录取数据是首届新高考,只有 1 年新数据**(数据极稀薄,以位次定档为主,**分数仅参考**)
- **2021-2024 老数据跨体系,只能间接换算**(文 → 历史类、理 → 物理类,但不能直接套用分数线)
- **agent 推荐时务必提示用户:山西新高考数据样本少,所有分数线/位次都要打折看,实际填报偏保守**

## 二、考试结构(2025 起)

- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- 山西物理类约 60-65%,历史类约 35-40%(沿袭老高考理多文少格局)

## 三、山西考生规模与录取格局

### 考生数
- 山西高考考生约 **28 万/年**(2024 约 29.4 万),全国中等偏小
- 比湖北(45 万)/ 河北(80 万)/ 河南(130 万)少很多
- 但**本省 985/211 名额也极少**(0 所 985 + 1 所 211)

### 留晋率
- **本省经济萎缩**(煤炭单一产业 + 人口外流),留晋率约 **50%-60%**
- 大量考生**出省战略**:京津/西安/沿海(华东/华南)
- **山西本省高校承接能力有限**,留晋大头集中在太理工 + 山大 + 中北 + 山医 + 山财 + 太科大 这几所

## 四、山西本省高校格局(关键!)

### 985:**0 所**

### 211:**1 所(太原理工大学)**
- **太原理工大学(太理工)** — 山西**唯一**的 211,2017 年双一流第一轮**落选过**(差点掉队),2022 年第二轮**成功新增双一流**(化学工程与技术学科)
- 山西的"211 独苗",家长压力极大

### 双一流非 211:**1 所(山西大学)**
- **山西大学(山大)** — 双一流(物理学 + 哲学双一流学科),**但不是 211**
- 历史原因:**1995 年首批 211 评估错失**(当年体量不够 + 山西教育投入不足),后来再无机会
- **学科评估全国前列,实力堪比中等 211**,但**牌子是双非**
- 这是山西考生**最容易踩的认知坑**(详见 `山西强校真实地位.md`)

### 强势双非
- **中北大学**(原华北工学院) — 兵器科学全国前列
- **山西医科大学** — 法医学全国前 5
- **山西财经大学** — 山西省内财经第一
- **太原科技大学**(原太重机械学院) — 重型机械全国前列
- **山西师范大学**(临汾) — 山西师范主力

## 五、选科建议(山西特殊角度)

### 推荐选科组合(按优先级)

| 选科组合 | 适合方向 | 山西特殊性 |
|---|---|---|
| **物化生** | 临床医学(山医必选化学+生物) / 双一流理科 / 工科 | 山医、山大物理、太理工材料化工 都对口 |
| **物化政** | 公安 / 国防 / 物理类考公 | 物理 + 政治 有政审优势 |
| **物化地** | 工程 / 地质 / 矿业(山西煤大对口) | **山西煤炭/采矿工科** 必选 |
| **史政地** | 文科考公 / 师范 / 法学 | 山大历史学/哲学 + 山西师大 + 山财法学 对口 |
| **史化生** / **史生地** | 历史类但保留理科底子 | 二级学科空间大 |

### 强提醒
- **想读医的必选化学 + 生物**(山医 / 长治医学院 / 山西中医药大 都有要求)
- **想报煤炭采矿工科**(中国矿大山西煤业 / 太理工煤化工 / 太科大重机)→ 物化地优先
- **想考公考编**(山西基层考公岗多)→ 政治选上加分

## 六、院校专业组与志愿数

### 投档方式
- 按"院校专业组"投档(同湖北/江苏)
- 服从调剂只在本专业组内
- 一个专业组通常 5-15 个专业

### 山西本科批志愿数
- **本科批 96 个院校专业组志愿**(注意:**比湖北/湖南的 45 个多一倍多,跟广东 45 / 江苏 40 完全不同**)
- 专科批志愿数另算
- **96 个志愿数 → 必须冲稳保比例更宽松,可适度增加冲档数量**

### 关键提醒
- **96 个志愿不是"全部填满名校" 的意思**,而是要有梯度:冲 15-20 / 稳 30-40 / 保 30-40
- 默认冲稳保 1:2:2 在山西可调整为 2:3:5(更多保底空间)

## 九、易错认知(agent 要纠正用户的)

- **"山西 2024 分数线 506 一本,我孩子能过就行"** — 严重错。**2025 起没有一本/二本概念**,改为"本科批 + 特控线",且 2025 是首届新高考,文理 → 物理/历史 体系跨越,2024 数据**只能参考不能套用**
- **"山西大学不是 211,所以不如太理工"** — 错。**山大学科评估实力堪比 211**(物理学/哲学双一流),太理工是 211 但学科评估部分专业反而弱于山大
- **"山西考生少,上 211/985 容易"** — 半错。**山西考生少但 211/985 名额也少**(本省 0 985 + 1 211),实际录取比例跟河北/河南差不多艰难
- **"96 个志愿都是学校,选哪个学校都行"** — 严重错误。**山西是 96 个院校专业组志愿,且服从调剂只在组内**
- **"我看 2024 太理工录取 530,我考 540 就稳了"** — 严重错。**2025 是首届新高考体系,2024 老理科分数线和 2025 物理类分数线之间的换算需要看位次,不是看分数差**

## 十、关键提醒(agent 必须强调)

1. **山西本科批 96 个院校专业组志愿**(比湖北/湖南的 45 个多一倍多)
2. **2025 是首届 3+1+2 新高考**,1 年数据样本极稀薄,**所有推荐以位次定档为主,分数仅参考**
3. **2021-2024 老高考文/理数据跨体系**,推荐时只能粗略换算(文 → 历史类、理 → 物理类),不能精确套分数线
4. **再选科目限制**(必选化学/必选政治等)是硬约束
5. **山西考生留晋率 50%-60%**,大量出省京津/西安/沿海,推荐时务必考虑出省成本
6. **山西卷难度 + 考生少**,分数线比湖北高 20-40 分,但不代表山西比湖北难,**看位次不看分数**
7. **山西本省 0 985 + 1 211**,稀缺性比湖北/江苏/湖南严峻,出省战略是常态而非例外
