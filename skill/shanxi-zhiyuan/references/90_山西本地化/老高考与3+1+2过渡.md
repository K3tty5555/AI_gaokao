# 山西老高考与 3+1+2 过渡 — 2025 首届新高考关键背景

## 核心结论

**山西 2022 年加入新高考第五批**(全国倒数第二批,跟陕西/青海/宁夏/甘肃 同批),**2025 年高考是首届 3+1+2 实战考**。**2021-2024 全是老高考文/理体系**,2025 才切换为物理/历史类。这意味着:

- **2025 年的录取数据是首届新高考,只有 1 年新数据**(数据极稀薄,以位次定档为主,**分数仅参考**)
- **2021-2024 老数据跨体系,只能间接换算**(文 → 历史类、理 → 物理类,但不能直接套用分数线)
- **agent 推荐时务必提示用户:山西新高考数据样本少,所有分数线/位次都要打折看,实际填报偏保守**

## 二、考试结构(2025 起)

- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- 山西物理类约 60-65%,历史类约 35-40%(沿袭老高考理多文少格局)

## 三、山西考生规模与录取格局

### 考生数
- 山西高考考生约 **28 万/年**(2024 约 29.4 万),全国中等偏小
- 比湖北(45 万)/ 河北(80 万)/ 河南(130 万)少很多
- 但**本省 985/211 名额也极少**(0 所 985 + 1 所 211)

### 留晋率
- **本省经济萎缩**(煤炭单一产业 + 人口外流),留晋率约 **50%-60%**
- 大量考生**出省战略**:京津/西安/沿海(华东/华南)
- **山西本省高校承接能力有限**,留晋大头集中在太理工 + 山大 + 中北 + 山医 + 山财 + 太科大 这几所

## 四、山西本省高校格局(关键!)

### 985:**0 所**

### 211:**1 所(太原理工大学)**
- **太原理工大学(太理工)** — 山西**唯一**的 211,2017 年双一流第一轮**落选过**(差点掉队),2022 年第二轮**成功新增双一流**(化学工程与技术学科)
- 山西的"211 独苗",家长压力极大

### 双一流非 211:**1 所(山西大学)**
- **山西大学(山大)** — 双一流(物理学 + 哲学双一流学科),**但不是 211**
- 历史原因:**1995 年首批 211 评估错失**(当年体量不够 + 山西教育投入不足),后来再无机会
- **学科评估全国前列,实力堪比中等 211**,但**牌子是双非**
- 这是山西考生**最容易踩的认知坑**(详见 `山西强校真实地位.md`)

### 强势双非
- **中北大学**(原华北工学院) — 兵器科学全国前列
- **山西医科大学** — 法医学全国前 5
- **山西财经大学** — 山西省内财经第一
- **太原科技大学**(原太重机械学院) — 重型机械全国前列
- **山西师范大学**(临汾) — 山西师范主力

## 五、选科建议(山西特殊角度)

### 推荐选科组合(按优先级)

| 选科组合 | 适合方向 | 山西特殊性 |
|---|---|---|
| **物化生** | 临床医学(山医必选化学+生物) / 双一流理科 / 工科 | 山医、山大物理、太理工材料化工 都对口 |
| **物化政** | 公安 / 国防 / 物理类考公 | 物理 + 政治 有政审优势 |
| **物化地** | 工程 / 地质 / 矿业(山西煤大对口) | **山西煤炭/采矿工科** 必选 |
| **史政地** | 文科考公 / 师范 / 法学 | 山大历史学/哲学 + 山西师大 + 山财法学 对口 |
| **史化生** / **史生地** | 历史类但保留理科底子 | 二级学科空间大 |

### 强提醒
- **想读医的必选化学 + 生物**(山医 / 长治医学院 / 山西中医药大 都有要求)
- **想报煤炭采矿工科**(中国矿大山西煤业 / 太理工煤化工 / 太科大重机)→ 物化地优先
- **想考公考编**(山西基层考公岗多)→ 政治选上加分

## 六、院校专业组与志愿数

### 投档方式
- 按"院校专业组"投档(同湖北/江苏)
- 服从调剂只在本专业组内
- 一个专业组通常 5-15 个专业

### 山西本科批志愿数
- **本科批 96 个院校专业组志愿**(注意:**比湖北/湖南的 45 个多一倍多,跟广东 45 / 江苏 40 完全不同**)
- 专科批志愿数另算
- **96 个志愿数 → 必须冲稳保比例更宽松,可适度增加冲档数量**

### 关键提醒
- **96 个志愿不是"全部填满名校" 的意思**,而是要有梯度:冲 15-20 / 稳 30-40 / 保 30-40
- 默认冲稳保 1:2:2 在山西可调整为 2:3:5(更多保底空间)

## 九、易错认知(agent 要纠正用户的)

- **"山西 2024 分数线 506 一本,我孩子能过就行"** — 严重错。**2025 起没有一本/二本概念**,改为"本科批 + 特控线",且 2025 是首届新高考,文理 → 物理/历史 体系跨越,2024 数据**只能参考不能套用**
- **"山西大学不是 211,所以不如太理工"** — 错。**山大学科评估实力堪比 211**(物理学/哲学双一流),太理工是 211 但学科评估部分专业反而弱于山大
- **"山西考生少,上 211/985 容易"** — 半错。**山西考生少但 211/985 名额也少**(本省 0 985 + 1 211),实际录取比例跟河北/河南差不多艰难
- **"96 个志愿都是学校,选哪个学校都行"** — 严重错误。**山西是 96 个院校专业组志愿,且服从调剂只在组内**
- **"我看 2024 太理工录取 530,我考 540 就稳了"** — 严重错。**2025 是首届新高考体系,2024 老理科分数线和 2025 物理类分数线之间的换算需要看位次,不是看分数差**

## 十一、2025 首届新高考志愿填报实战要点

### 老高考 vs 新高考 投档机制对比

| 维度 | 老高考(2024 及之前) | 3+1+2 新高考(2025 起) |
|---|---|---|
| 批次 | 一本 / 二本 / 三本 / 高职高专 | 本科批(合并 + 特控线对标原一本) / 高职专科 |
| 投档单位 | 院校(一个学校只投一个志愿) | **院校专业组**(一个学校可分多个专业组,每组单独投档) |
| 服从调剂 | 院校内部各专业之间调剂 | **只在专业组内调剂**(组内服从 / 组外不调) |
| 志愿数 | 本科一批 8 个院校 + 二批 8 个院校 等分批次 | **本科批 96 个院校专业组**(一次性填报) |
| 选考 | 无,文科理科二选一 | **首选物理 / 历史 + 再选 4 选 2 赋分制** |

### 96 个专业组志愿的填报哲学

**冲稳保 1:2:2 不再适用山西** — 96 个志愿数 → 比例可调整为 **2:3:5(冲 20 / 稳 30 / 保 46)** 或 **冲 15-20 / 稳 30-40 / 保 30-40**。

**关键提醒**:
1. **本科批一次性 96 个志愿,投档后不补录** — **保底志愿一定要保住**(底线意识)
2. **专业组组内调剂** — 调剂只在组内,**接受不了组内任何专业的别勾"服从调剂"**
3. **专业组拆分密集** — 同一所学校可能有 5-15 个专业组,**每个组的录取分不同**(强势组分高 + 冷门组分低)
4. **再选科目是硬约束** — 报志愿前看清楚专业组的"再选科目要求"(必选化学 / 必选政治 / 任选 等)

### 物理类 / 历史类 招生比例(山西 2025 估测)

| 专业大类 | 物理类 | 历史类 |
|---|---|---|
| 工科(电气 / 化工 / 机械 / 土木 等) | **物理类必选 100%** | 0%(历史类不能报) |
| 医学(临床 / 医学技术) | **物理类必选 90%+** | 极少 |
| 经管(会计 / 金融 / 经济) | 物理类 60-70% / 历史类 30-40% | |
| 文科(汉语言 / 法学 / 历史) | 物理类 30-40% / 历史类 60-70% | |
| 师范(部分学科) | 学科分化(数学物理理科 / 中文历史文科) | |

- **史政化 / 史政生**:**保留理科底子 + 部分财经类历史类组对口**

### 山西特殊提醒
- **想读医必选化学 + 生物**(山医 / 长治医学院 / 山西中医药大 都有要求)

- **山西国防对口(中北兵器涉密专业)有政治偏好**

## 十三、2025 vs 2024 数据换算的现实约束

### 不能直接套分数线
- **2024 老高考一本理 506 分 ≠ 2025 物理类本科批特控线 X 分**
- **2024 老高考一本文 516 分 ≠ 2025 历史类本科批特控线 X 分**
- 即使总分相同,**考生构成 + 投档机制 + 专业组划分 都变了**

### 位次的相对稳定性
- **位次比分数相对稳定**(年度间考生总数变化不大)
- **山西物理类约 17-18 万考生 / 历史类约 10-11 万考生**(估测)
- 用 2024 老高考理科位次 → 折算 2025 物理类位次 ≈ 同位次稍偏高(因再选赋分制对中段有利)
- 用 2024 老高考文科位次 → 折算 2025 历史类位次 ≈ 同位次稍偏高

### Agent 推荐位次时的"打折"原则
- **2025 是首届新高考,样本极稀薄(1 年数据)**
- **推荐冲档位时务必偏保守 5-10%**(原本能冲的位次 → 推荐时往下保 5-10%)
- **保底志愿务必比往年放低 10-15%**(防止 2025 数据异常)
- **特别提醒用户**:**位次定档为主,分数仅参考,实际填报偏保守 + 把握底线**

## 十四、山西考生最容易踩的 7 个填报陷阱

### 陷阱 1:用 2024 文科 / 理科分数线套 2025 物理 / 历史类
**严重错**。2024 老高考 + 2025 新高考完全不同体系,**不能直接套分数**。**位次定档为主,分数仅参考**。

### 陷阱 2:96 个志愿都填满热门校
**严重错**。96 个志愿要梯度 — 冲 / 稳 / 保 比例。**全填热门校 = 全部滑档 + 进入征集志愿(剩余的差校 / 差专业)+ 浪费分数**。

### 陷阱 3:不勾服从调剂
**慎重**。不勾服从调剂 → 进了组但专业不对口 → 可能直接退档(本批次彻底滑档)。**勾服从调剂 → 可能调到组内冷门(矿业 / 哲学 / 农林 等)**。**接受组内冷门 → 勾;不接受 → 不勾但要确保第一专业能录取**。

### 陷阱 4:把独立学院当 985/211 本部
**严重错**。**山大商务学院 ≠ 山大本部** / **太理工现代科技学院 ≠ 太理工本部** / **山财华商学院 ≠ 山财本部** / **山西师大现代文理学院 ≠ 山西师大本部** / **太科大华科学院 ≠ 太科大本部**。**独立学院学费贵 + 牌子差 + 出口窄,千万别看错代码**。

### 陷阱 5:再选科目限制读错
**慎重**。**专业组的"再选科目要求"是硬约束**(必选化学 / 必选政治 / 任选 等)。**报志愿前一一确认**,**再选不符合 = 直接退档**。

### 陷阱 6:盲信 2024 老数据
**严重错**。2024 是老高考最后一届 + 2025 是新高考第一届,**2024 数据样本对 2025 参考价值有限**。**优先看 2025 数据(虽然只有 1 年)+ 把往年位次往下保 5-10%**。

### 陷阱 7:把山西分数比湖北 / 江苏分数
**严重错**。**山西卷难度 + 山西考生少 + 山西一本投放比例不同 → 山西分数线比湖北 / 江苏 / 河南 高 20-40 分**。**不能直接比分数,要看位次**。

## 十五、2025-2026 期间填报的特别建议

1. **位次比分数实在,2025 首届新高考分数仅参考**
2. **保底志愿往下放 10-15%**(防止 2025 异常)

4. **再选科目要求一一确认**(尤其想读医 / 想读煤炭工科 / 想报警校)

7. **山西本省高校选项有限 → 出省战略是常态**(0 985 + 1 211 的现实)
8. **山西考生家长 = 务必看本文 + 山西强校真实地位.md + 30_家庭决策矩阵.md** 这三份文档
