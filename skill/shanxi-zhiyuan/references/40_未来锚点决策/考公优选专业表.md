# 考公优选专业表(山西本地视角)

## 核心结论

**专业决定考公选岗范围**。山西家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**山西考公的特殊性**:
- **山西经济萎缩 + 民企岗位有限 → 考公编制权重比沿海高**
- **山西基层岗位多**(吕梁山区 / 太行山区 / 雁门关地区 等),**乡镇公务员竞争比省直温和**
- **山西选调走山大 / 太理工 / 中北 + 部分省外 985** → 985/211 选调路径独特
- **山西公检法系统**对法学要求高 + **山医法医毕业进山西公安系统是独家路径**
- **山西国考体量小**(山西考生总数少 + 本省国考岗位也少),**山西省考是主战场**

## 关键事实(2024 国考 / 山西省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 山西省考特殊性
- **山西省考 + 太原市考,汉语言文学和法学并列考公第一专业**(汉语言 22-25% + 法学 14-16%)
- 山西各地市公务员岗位**对法学要求高**(法院、检察院、司法局)— 太原 / 大同 / 长治 / 临汾 公检法系统对口
- **山西基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **山西吕梁 / 太行山区 / 雁门关地区 基层岗位**:艰苦边远补贴 + 服务期满后调动机会 + 本地户籍优先
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(山西三不限岗经常 800-1500 比 1)

### 山西选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(山西本地的选调生定向计划基本只对 985/211 + 山大 / 太理工 / 中北 + 部分省外 985)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**
- **山西定向选调生** 走山大 / 太理工 / 中北 + 出省 985(清北 / 复交 / 西交 / 哈工 / 华中科 等)
- **山西人在外地 985 读书 → 回山西选调生** 是隐藏跃迁路径(京津 / 西安 985 山西籍学生**毕业回山西选调进入省直机关**比例不低)

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、**山西警察学院** 等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**山西本地 山大法学 / 太理工法学(弱) / 中南财法(出省) 对口**
- **山医法医** = **进山西公安系统刑警技术处 / 检察院司法鉴定中心 = 独家路径**(医学背景的公检法岗,起步公务员编制 + 山西独家王牌)

## 山西本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业(出省 / 山西本地)
- **山西大学法学** — 山西省内法学第一,**留晋当公检法 / 律师 + 山西考公认可度高**
- **山西大学汉语言文学** — 老牌强势,**山大文科基础 + 留晋考公选调路径顺**
- **太原理工大学(山西唯一 211)+ 法学 / 经济学(弱)** — 太理工文科边缘,**别为了 211 牌子学太理工法学/经济**,选山大或山财更对口
- **出省 985 法学 / 经济学(西交 / 武大 / 华中科大 / 中南财法 等)** — 山西物理类 5000-8000 名内可冲,**回山西选调路径优**

### 双非 + 性价比考公专业
- **山西师范大学公费师范汉语言** — 二本中等,**毕业回山西基层县市当老师 + 编制**(不算严格意义考公,但等同稳定编制)
- **山西大学商务学院 / 山西大同大学 等的汉语言 / 法学** — 山西本地认可,**双非但留晋考公成功率高**(因为山西本地考公认山西本省高校)
- **山西财经大学法学 / 经济学** — **山财法学 + 山西财政厅 / 税务局 / 银保监 对口**

### 公安系统专属
- **山西警察学院** — 本科,公安联考路径,**毕业进山西本地公安概率极高**(基层警察)
- **山医法医学** — **独家路径**:进山西公安系统刑警技术处 / 司法鉴定中心 / 检察院技术处 = **直接公务员编制**

### 山西工矿央企子弟岗(等同于编制)
- **太理工化学工程 / 矿业 + 山西焦煤 / 潞安化工 集团子弟岗** — 不算严格考公,但**山西工矿央企编制等同公务员稳定性**
- **太理工电气 + 国家电网山西公司** — 央企编制
- **中北兵器 + 中物院 / 兵器集团 / 航天科工** — 国防央企编制

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:山西临汾考生,540 分(老高考文科,折历史类约省排 5500 名),**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报山西大学汉语言文学**,毕业当年考上山西省直某机关公务员,**家庭命运改变**
- **Case B(选调路径)**:山西大同考生,610 分历史类,中产家庭。家长想报"金融"(山西财经大学)。**改报西交法学 + 山西定向选调生资格**,**毕业获得西交选调资格,直接进山西省委组织部**,起点远超山财金融留晋进城商行
- **Case C(失败路径)**:山西运城考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了山西大学计算机**(以为计算机考公也行)。**毕业考公发现:山西可报岗位远少于汉语言**,2 年没考上,**改行做程序员但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:山西家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(山西独家路径)**:山西忻州考生,530 分理科(物理类省排 30000 名),普通工薪家庭男生。**报山医法医学** → 5+3 后进山西公安刑警技术处 → 直接公务员编制 + 山西本地稳定 → **山西独家王牌路径**
- **Case F(基层逆袭路径)**:山西吕梁山区农村女孩,500 分文科(历史类省排 7500 名)。**报山西师大公费师范汉语言** → 毕业回吕梁某县当语文老师 + 编制(等同于考公稳定)→ **农村家庭 4 年零负担 + 直接编制 = 最稳跨阶级路径**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(山西 3+1+2 制度允许首选物理报多数专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**(**山西警察学院** 是山西本省主路径)
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是山西家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**山西考生少,考公容易**" — 错。**山西考生少但岗位也少**,**山西省考竞争比想象激烈**(基层岗 50-100 比 1,省直岗 200-500 比 1)
- "**山西基层岗艰苦不要去**" — 半错。**山西基层艰苦边远补贴高** + **服务期满后调动机会**(回太原 / 调省直)+ **本地户籍优先**,**山西农村家庭子弟回原县考公是最稳路径**
- "**山医法医只能做尸检,工作恶心**" — 严重错。**山医法医是山西独家王牌**:全国前 5 + 进山西公安刑警技术处 / 检察院 = **直接公务员编制 + 起点比普通公务员高**

## 关键提醒

**考公是山西普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是山西家长被严重低估的考公王者**;**山医法医是山西独家王牌 sleeper hit**;**山西师大公费师范是农村家庭最稳跨阶级路径(等同编制)**;**山西警察学院是想做警察的本省最直接路径**。

山西讲实在 — 编制 + 稳定 + 留本地 = 山西考生考公的核心价值,这一点比沿海省份更重要。
