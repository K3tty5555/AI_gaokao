# 计算机科学与技术 / 软件工程(CS / SE)— 山西视角

## 一句话总结

**CS 在山西已经没有"闭眼报"的空间了**。山西本省 CS 是双输:本省互联网产业基本不存在,留晋走 CS 等于"去太原跟运营商打杂",出省又卷不过西电 / 北邮 / 杭电 / 川大。**山西考生想吃 CS 红利只有一条路 — 出省**,而且必须是 985 或者电子类强校。**留晋学 CS 不如学化工进焦煤,这是山西最反常识的真相**。

---

## 真相 1:山西本省没有互联网产业

- 山西支柱产业是煤炭、钢铁、电力、文旅,**没有任何一家全国性互联网公司总部 / 大型研发中心在太原**
- 太原本地 IT 岗 = 山西移动 / 联通 / 电信 IT 部门 + 国网山西信通 + 山西本地软件外包公司 + 政府数字化项目
- **太原 CS 起薪 6-10w**,跟同档双非工科持平甚至略低,完全没有"互联网光环"
- 想做真正的程序员,毕业第一件事是出省 — 去北京 / 西安 / 杭州 / 成都 / 深圳

**结论**:**留晋 CS 是水牌子组合**。CS 只有出省才有意义。

---

## 真相 2:山西高校 CS 排名全国靠后

- 山西本省 CS 最强的是**太原理工 + 山大**,但**全国 CS 排名都在 100 名开外**
- 跟出省同分能上的电子科技类强校(西电 / 北邮 / 杭电 / 南邮 / 成电)比,**山西本土 CS 是降一档的选择**
- **中北 CS / 山大 CS / 太理工 CS** 这一档,毕业进互联网大厂校招通过率极低,基本只能进山西本地或回老家的中小厂

**结论**:**山西分够 211 想学 CS,首选出省**。出省 211/双一流的 CS 比留晋 211(太理工)的 CS 强 2 个档次。

---

## 真相 3:35 岁危机对山西考生影响更大

- 35 岁危机在北上广深确实存在,但**山西考生还有一个隐性危机:出省打工 5-10 年后想回太原,本省没岗位接住**
- 35 岁出省码农回山西 → 太原 IT 岗位有限 + 体制内进不去(年龄超了考公 + 编制无门)
- **湖南 / 安徽 / 四川 这些有"省会能接住返乡程序员"的省份,跟山西完全不同**
- 山西考生选 CS 必须想清楚:**毕业留省外一辈子,还是 35 岁后转行 / 考编**

---

## 真相 4:山西工科家庭对 CS 的认知严重过时

- 山西很多工矿子弟家庭(焦煤 / 太钢 / 太重 / 阳煤 / 潞安 子弟)父母觉得"CS = 高薪铁饭碗"
- 这是 5-10 年前的认知。**现在 CS 是高度分化的赛道**:
  - 985 CS = 高薪但卷,35 岁有压力
  - 双非 CS = 起薪 8-10w 跟双非工科一样,没有溢价
  - 山西本地高校 CS 留晋 = 月薪 6-8k,跟"国家电网山西基层抢修工"差不多但没编制
- 工矿家庭子弟最稳路径其实是**子承父业(进央企子弟岗) / 太理工化工 / 中北兵器 / 国网山西**,不是去卷 CS

**结论**:**山西工矿家庭的孩子学 CS,大概率比父辈过得差**(没编制 + 房价 + 35 岁压力)。

---

## 适合什么人

- **数学好**(高中数学 130+,这是硬指标)
- **能 / 愿意出省**(这是山西考生学 CS 的硬前提,不出省=浪费 4 年)
- **目标至少 985 / 电子类双一流(西电 / 北邮 / 成电 / 杭电)**
- **山西分够 985 工科 + 数学好 + 男生 + 中产以上**
- **抗压能力强 + 不怕加班 + 愿意 35 岁前一直卷**

## 不适合什么人

- **想留山西就业**(山西没真 CS 岗,直接劝退)
- **数学差**(高中数学 110 以下)
- **山西分只够双非 + 普通家庭**(双非 CS 在山西的边际价值=0,选汉语言/电气/化工更稳)
- **想要稳定 / 编制 / 不卷**(CS 跟"稳定"根本不是一条路)
- **女生 + 求稳定 + 家庭希望留晋**(完全不匹配 CS 的就业地理)

## 山西考生 CS 学校真实分层

### 第一梯队(山西考生应该冲的出省 985 / 电子类双一流)
- **西安交大 / 哈工大 / 华中科大 / 北航 / 北邮 / 西电 / 电子科大** — 山西物理类省排 5000 名内可冲,**这才是 CS 真正的入场券**
- 西电 / 北邮 / 成电 — **电子类专业领域校,山西考生进华为 / 中兴 / 字节 / 腾讯 都认**

### 第二梯队(出省 211 / 强双非)
- **杭电 / 南邮 / 重邮 / 燕山 / 西安邮电** — 山西物理类 8000-15000 名可冲,**互联网 / 通信对口**
- **湖南大学 / 中南大学 / 川大 / 武大 CS** — 山西物理类省排 6000 名内,综合 985 牌子 + 留长沙 / 成都 / 武汉 互联网中型公司

### 第三梯队(山西本地 + 同档双非,留晋唯一选项)
- **太原理工 CS** — 山西物理类 5000-9000 名,**留晋唯一 211 CS**,但**毕业进山西本地,出省校招吃亏**
- **山大 CS** — 山西物理类 8000-13000 名,**双一流牌子 + CS 不强**,留晋当老师 / 留晋 IT 还行
- **中北 CS** — 兵器系学校的 CS,**进国防系统 IT 还可以**(中物院 / 兵器集团信息所),其他出口一般

### 第四梯队(避坑)
- **太原科技大学 / 山西农大 / 山西师大 / 山西大同大学 等的 CS** — **直接避坑**。山西二本 CS 毕业基本只能进太原小公司或转行,**学这种不如学护理 / 师范 / 会计**
- **山西大学商务学院 / 太原理工现代科技学院 等独立学院 CS** — 学费贵 + 牌子差 + 出口最窄,**典型大坑**

## 山西本地家长金句(纠正用户认知用)

> "**山西的孩子学 CS,出省是必选项,不是可选项。** 留太原学 CS 等于学了一门没用武之地的手艺 — 太原本地没互联网,你 4 年学的 Java / Python 留晋后只能去山西移动 IT 部门当外包,跟煤炭子弟岗起薪一样还没编制。"

> "你说太理工是 211 + CS 也行 — 真不行。太理工 211 牌子是给化工 / 材料 / 机械的,CS 在太理工里就是边缘组,毕业进华为腾讯校招直接被卡。**同分能去西电 / 北邮 / 杭电,别在太理工将就 211 牌子。**"

> "**山西工矿家庭的孩子,父辈在焦煤 / 太钢 / 阳煤端铁饭碗,你卷 CS 大概率过得比他们差。** 没编制 + 北上广房价 + 35 岁危机 — 这一套逻辑工矿家长得先想清楚。学化工进焦煤集团比学 CS 进字节稳。"

> "山西考生学 CS 唯一不亏的路径:**省排 8000 内 + 男生 + 中产 + 出省 985/电子类双一流 + 接受北上广深定居**。这 4 个条件少一个,CS 都不如其他专业稳。"

## 易错认知(agent 要纠正)

- "**计算机一定好就业**" — 5 年前的认知。今天的真相:**985 CS 依然好就业,双非 CS 不如双非师范 / 电气**
- "**太理工 211 + CS = 稳定**" — 严重错。**太理工 CS 在 211 里属于尾部 + 留晋无互联网**,出省校招被卡,留晋月薪 6-8k 跟双非工科持平
- "**山西移动 / 联通 / 电信 IT 也是互联网啊**" — 错。运营商 IT = 国企编制 + 月薪 6-9k + 但跟"互联网"的工作内容、薪资、上升通道**完全不是一回事**
- "**学 CS 进国家电网山西信通也行**" — 半对。国网信通公司 CS 岗确实有,但**对学校层次要求高**(985/211),双非 CS 进不去
- "**女生学 CS 也行,工资高**" — 错。山西女生 + 双非 CS = 大概率毕业找不到对口岗位,**改医学影像 / 师范 / 财经更稳**
