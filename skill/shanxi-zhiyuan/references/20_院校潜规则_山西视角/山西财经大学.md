# 山西财经大学(山财,SXUFE)— 双非但省内财经第一

## 一句话总结

**山西省内财经类第一**,**会计 / 财政 / 金融 + 山西本土银行 / 国资 / 财政系统对口**,**双非里财经类中等**(跟河北经贸 / 内蒙古财经 / 安徽财大 同档,**不如央财 / 上财 / 西财 / 中南财法 / 东北财 等老牌财经 211**)。**留晋进银行 / 财政 / 国资是山财的最稳路径**。

---

## 真实地位

- **双非 + 山西省属重点 + 部省合建**(财政部 + 国家税务总局 + 教育部 + 山西省政府),**山西唯一独立建制财经类高校**。
- **山西本省地位**:**山西财经类头牌 + 录取分山西物理 / 历史类财经组天花板**,**山西考公财政 / 税务 / 银行系统 山财校友网最密**。
- **同档对比**:类似河北经贸大、内蒙古财经大、安徽财大、河南财经政法大学的省内财经独苗地位。**全国双非财经里中段**(不如东北财大 + 老 211 财经,**接近天津财大 / 江西财大 / 河南财经政法**)。
- 太原校区(坞城本部 + 迎泽东大街 + 国际交流学院),**女生为主 + 商科风**,学风务实。

## 性价比专业

- **会计学**:**山西省内第一 + CPA 路径友好**,**山西本地国资 / 银行 / 民企会计岗 校友网密集**,**录取分本校顶级但毕业出路稳**。
- **财政学 / 税收学**:**对口山西省财政厅 / 各市财政局 / 税务系统**,**山西考公进财税系统首选**,**录取分相对会计低 + 但留晋考公性价比顶配**。
- **统计学**:**对口山西统计局**,**录取分本校中段 + 留晋考公友好**,**性价比好**。

## 坑专业 / 慎选(在山财里相对弱)

- **非财经类专业(汉语言 / 行政管理 / 信息管理 / 工商管理 一般组)**:**山财是财专,非财经边缘**,**别为了"山财牌子"学非财经**。
- **金融工程 / 投资学**:**山财金融出省做投行 / 券商不对口**,**学投行 / 一线金融 → 出省央财 / 上财 / 西财 / 中南财法**。
- **国际经济与贸易**:**山西外贸体量小 + 出省没山财牌子优势**,**学国贸优先东南沿海财经**。
- **法学(非经济法方向)**:**山财法学是经济法 + 律师方向**,**学法学进公检法 → 山大法学更对口**。

## 关键提醒(填报陷阱)

1. **山财本部 vs 山西财经大学华商学院**:**本部才是山财**,华商学院是独立学院,**学费贵 + 牌子差**,**报志愿别看错代码**。
2. **会计学 vs 财务管理 vs 审计学**:**三个名字相近的专业,核心都是财会方向,出路差不多**,**山财会计学是头牌 + 财管 / 审计是次档**。
3. **金融学(出省) vs 山财金融(留晋)**:**山财金融留晋进山西本地银行可以**,**但出省做金融 = 校招卡 211 财经名单 + 山财不在**,**铁了心做投行 / 券商 → 出省央财 / 上财 / 西财**。
4. **服从调剂注意**:中分组可能调到信息管理 / 工商管理 / 部分边缘文管,**接受不了的别勾**。
5. **山财 vs 山大经管 怎么选**:**学财经 + 留晋进银行 / 财政 → 山财对口度高 + 校友网密**;**学经济学 + 走考研路径 → 山大综合性 + 双一流学科可冲 985 经济硕**。

## 毕业出口(2024 数据)

- **留山西就业**:约 60-65%(**太原 + 山西各市国资 / 银行 / 财政 / 税务系统 占大头**,**留晋率全省高校最高之一**)。
- **出省京津**:约 15-20%(**北京 / 天津国资 / 央企财务岗 + 部分继续读研在出省 985 财经**)。
- **出省长三角 / 珠三角**:约 10-15%(主要会计 / 金融方向,但出省竞争吃亏)。
- **考研 / 读博**:约 20-25%(**山财本 + 出省 985 财经硕(央财 / 上财 / 西财 / 中南财法)接受度尚可**)。
- **进央企 / 国资概率**:**约 25-30%**(山西本土国资 / 山西银行 / 农信社 / 焦煤财务岗 / 央企山西分公司)。
- **进体制内**:**约 25-30%**(**山西考公进财政厅 / 税务系统 / 各市财政局 / 国资委**,**山财在山西考公财税系统校友网最密**,**这一项是山财最强出口**)。
- **起薪范围**:会计师事务所 8-12w(山西本地)/ 12-18w(出省),银行柜员起步 8-10w + 编制,财政公务员 6-9w + 编制 + 退休金。

## 适合谁

- 山西物理类 **省排 15,000-45,000 名** / 历史类 **3,500-15,000 名** 的考生。
- **女生 + 想留山西进银行 / 财政 / 国资 / 税务**:山财对口度高 + 校友网密 + 考公性价比顶配。
- **普通工薪 / 农村家庭女孩 + 想要体制内编制**:山财 + 山西考公财税系统是最稳路径。
- **想做会计师 / CPA 路径 + 留晋**:山财会计学是省内第一,毕业进山西本地事务所 / 国资财务岗顺。
- **本科 + 考研** 路径 + 想冲 985 财经硕(央财 / 上财 / 西财),山财本科基础够用。

## 不适合谁

- **想做投行 / 券商 / 一线金融 / 私募基金**:**山财不对口**,**出省央财 / 上财 / 西财 + 北上深地理是硬条件**。
- **男生 + 想跨阶级 + 不愿留晋**:**山财留晋编制路径稳但天花板低**,**男生想冲互联网 / 一线民企 → 出省 211 财经 + 跨城市更值**。
- **学非财经专业**:**山财非财经边缘**,**学法学去山大,学管理去出省综合性**。
- **铁了心要进体制内但不限财税**:**山大文科 + 山西考公进党政机关比山财更直接**(山财校友网集中在财税系统)。
- **分够老牌 211 财经(央财 / 上财 / 西财 / 中南财法)**:**别在山财将就**,**211 财经牌子 + 一线城市地理 比"留晋双非" 值得多**。

## 山财家长高频问题(FAQ)

### Q1:山财是 211 吗?
A:**不是**。山财是双非 + 山西省属重点 + 部省合建(财政部 + 国家税务总局 + 教育部 + 山西省政府),**山西唯一独立建制财经类高校**。**没有 211 牌子,但山西本省财经 / 财税系统校友网最密**。

### Q2:山财会计 vs 央财 / 上财 / 西财 怎么选?
A:**留晋进银行 / 财政 / 国资 / 税务 → 山财对口度高 + 校友网密**(山西考公财税系统走山财校友推荐)。**出省做投行 / 券商 / 一线金融 → 央财 / 上财 / 西财 + 北上深地理是硬条件**。**山财金融出省校招吃亏 + 留晋金融岗少,这是山财金融的核心约束**。

### Q3:山财的 CPA 通过率怎么样?
A:**全国双非财经里中上**。**山财会计学是山西省内第一 + 学风浓厚 + CPA 通过率约 25-35%**(行业平均约 20%)。**会计学 + CPA 通过 + 留晋四大本地所 = 山财女生最稳路径**。

### Q4:山财金融 vs 山大经济 怎么选?
A:**留晋进银行 / 农信社 / 国资金融 → 山财金融对口度高**(山西本地银行校招认山财)。**走考研路径冲 985 经济硕(央财 / 上财 / 西财) → 山大经济双一流综合性背景对考研更有优势**。**直接就业看校友网 → 山财;走考研 → 山大**。

### Q5:山财非财经专业怎么样?
A:**边缘**。山财是财经类专业校 + 非财经专业(汉语言 / 行政管理 / 信息管理 / 工商管理 一般组)= 双非中下水平 + 出口窄 + 改行率高。**别为了"山财牌子"学非财经** — 学法学去山大,学行政管理去山大或山西师大,学 CS 去太理工或出省。

### Q6:山财华商学院和山财本部有啥区别?
A:**完全不同**!**山财本部** = 公办双非 + 山西省内财经第一 + 学费 5500/年。**山财华商学院** = 独立学院 + 学费 15000-20000/年 + 牌子差 + 出口窄。**报志愿前看清招生代码 + 招生章程**!

### Q7:女生学山财能进银行吗?
A:**山西本省银行 / 农信社系统 + 山财校友网密 → 女生进山西本地银行编制概率高**。但要注意:**银行柜员起步 + 编制但晋升慢 + 月薪 6-8k**。**想做投行 / 私募 → 山财不对口**,**想做银行管理岗 → 山财本 + 出省 985 经济硕 + 银行总行管培生路径**。
