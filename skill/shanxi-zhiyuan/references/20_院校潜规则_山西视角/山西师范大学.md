# 山西师范大学(山西师大,SXNU)— 双非师范主力

## 一句话总结

**山西本省师范主力 + 公费师范主要供给校**,**留晋当中小学老师对口**。**双非师范,跟二档师范大学差不多**(不如华师 / 北师大 / 南师 / 华南师范 / 陕西师大,**接近河北师大 / 内蒙古师大 一档**)。**2022 年主校区已迁至太原(原临汾老校区作为现山西师范大学现代文理学院 / 临汾分部使用)**,**留晋当老师 + 公费师范 = 山西师大最稳路径**。

---

## 真实地位

- **双非 + 山西省属重点 + 部省合建**(教育部 + 山西省政府),**山西省属师范类龙头**(山西大同大学 / 长治学院 等师范也存在但不如山西师大)。
- **山西本省地位**:**山西公费师范主要供给校**(教育部直属六大公费师范是华师 / 北师 / 陕师 / 西南大 / 东师 / 华东师,**山西师大是省属公费师范**),**录取分山西物理 / 历史类师范类中段**。
- **同档对比**:**双非师范里二档**,**比河北师大 / 内蒙古师大 略低 + 接近曲阜师大 / 上海师大 师范方向**,**全国师范排名约 30-50 段**。
- **2022 年主校区由临汾迁太原**(太原小店区新校区),**老校区临汾办作为现代文理学院 / 临汾分部**,**报志愿务必看清校区代码**(新生大多在太原新校区 / 但部分专业仍在临汾)。
- **男女比 3:7 偏女**,**学风温和师范风**,留晋当老师氛围浓。

- **顶级组(数学 / 物理 / 化学 师范 / 公费师范)**:全省 **30,000-45,000 名**。
- **主流组(生物 / 地理 / 心理学 / 教育技术)**:全省 **45,000-60,000 名**。
- **冷门组(部分非师范理工 / 信息管理)**:全省 **60,000-80,000 名**。

## 山西历史/文科录取位次区间

- **顶级组(汉语言文学 / 历史 / 思政 师范 / 公费师范)**:全省 **8,000-13,000 名**。
- **主流组(英语 / 教育学 / 心理学)**:全省 **13,000-20,000 名**。
- **冷门组(行政管理 / 文化产业)**:全省 **20,000-28,000 名**。

**段位定位**:山西 **物理类省排 80,000 名内 / 历史类省排 28,000 名内可冲山西师大**,**公费师范组录取分明显高一档**。**2025 首届新高考分数仅参考,以位次反查为准**。

## 性价比专业

- **公费师范汉语言文学 / 数学 / 物理 / 化学**:**学费 + 住宿费全免 + 生活补贴 + 毕业回原籍服务 6 年(山西省属公费,服务山西本地中小学)+ 直接编制**,**普通工薪 / 农村家庭性价比顶配**,**录取分本校顶级组但毕业出路稳**。
- **教育学 / 心理学**:**全国前列(山西省内第一)+ 适合读研 + 进高校教育系统**,**录取分本校中段**,**走学术 + 学校管理路径性价比好**。
- **思想政治教育(师范)**:**山西本地中学政治老师 + 部分进党政机关**,**考公友好**。

## 坑专业 / 慎选(在山西师大里相对弱)

- **非师范类专业(行政管理 / 文化产业 / 信息管理 / 经管 一般组)**:**师范院校的非师范专业 = 双非综合性中下水平**,**毕业改行率高**,**别为了"师大牌子"学非师范**。
- **教育技术学 / 数学与应用数学(非师范)**:**听起来像师范但不是师范类(无教师资格证免试 + 不能走教师编)**,**当心被忽悠 + 看清专业代码后缀"师范" 字眼**。
- **CS / 软件工程**:**山西师大 CS 不强 + 师范院校学非师范 CS 是怪胎**,**学 CS 出来跟双非二本 CS 没差**,**学 CS 选太理工或出省**。
- **法学 / 经济学**:**师范院校的法学经济学边缘 + 毕业出口窄**,**学法管去山大或山财**。

## 关键提醒(填报陷阱)

1. **太原新校区(主校区)vs 临汾老校区(分部 / 现代文理学院)**:**2022 年主校区已迁太原**,**新生大多在太原小店区新校区**,**但部分专业 + 现代文理学院仍在临汾**,**报志愿前看清校区代码 + 招生章程**。
2. **公费师范生 vs 非公费师范生 vs 非师范专业**:
   - **名字里有"师范"且是提前批 / 公费师范批录取** → 公费师范(免学费 + 编制)
   - **名字里有"师范"但是普通批录取** → 普通师范(自费 + 自找工作 + 考教师编)
   - **名字没有"师范"(如数学与应用数学 / 教育技术学 / 化学)** → 非师范专业,**毕业不能直接走教师编 + 要单独考教资 + 改行率高**
   - **千万分清,差几十万学费 + 路径完全不同**
3. **公费师范"原籍服务 6 年"是硬约束**:**山西省属公费 = 回山西原籍服务 6 年**,**违约要赔学费 + 写违约记录**,**影响以后考公考编**,**家长 + 孩子聊清楚这 6 年要回原籍当老师**。
4. **服从调剂注意**:中分组可能调到部分非师范 / 信息管理 / 教育技术,**接受不了的别勾**(因为非师范在师大里出口窄)。
5. **山西师大 vs 出省 211 师范(陕师大 / 西南大学 / 华师 / 南师)**:**山西师大留晋当老师 + 离家近 + 考山西教师编对口度高**;**出省 211 师范牌子全国通用 + 但回山西考编反而吃亏(山西编制本地校友网密)**。**笃定留晋当老师 → 山西师大首选**;**想出省当老师 / 走全国师范路径 → 出省 211 师范**。

## 毕业出口(2024 数据)

- **公费师范生**:**100% 进入山西本地中小学教师编制**(回原籍 / 各市县服务 6 年)。
- **普通师范生**:**约 50% 通过山西省考 / 市考考编进山西公办中学**,约 25-30% 进民办学校 / 培训机构 / 一线城市机构,约 20-25% 改行(考公 / 进国资 / 转行)。
- **非师范类**:**约 40-50% 留山西**(党政机关 / 国资 / 民企),**约 30-40% 出省京津 / 西安**(继续读研为主),**就业不如纯综合性山大** + **不如太理工 211 牌子**。
- **考研 / 读博**:约 15-20%(**师范生考研主要冲北师 / 华师 / 陕师 985/211 师范硕**,**汉语言 / 数学 / 教育学保研接受度尚可**)。
- **留山西就业**:约 60-65%(**山西师大留晋率全省高校最高之一**)。
- **起薪范围**:中学教师编制起步 6-9w + 编制 + 寒暑假(山西本地)/ 12-15w(一线城市民办 / 培训机构),党政事业编 6-9w + 退休金。

## 同档对比

| 维度 | 山西师大 | 山西大学(教育系) | 华师 / 北师(211/985 师范) | 河北师大 / 内蒙古师大 |
|---|---|---|---|---|

**简单结论**:**想留山西当中小学老师 + 公费师范 → 山西师大首选**;**想出省当老师 / 全国师范路径 → 出省 211 师范(华师 / 陕师 / 南师 / 西南大)**;**学综合性教育学 / 心理学 + 走考研路径 → 山大也可以但师大更对口**。

## 适合谁

- 山西物理类 **省排 30,000-80,000 名** / 历史类 **8,000-28,000 名** 的考生。
- **想留山西当中小学老师 + 公费师范**:山西师大是标准路径。
- **女生 + 性格温和 + 想要稳定职业 + 寒暑假**:**师范 + 教师编 + 山西本地 = 性价比顶配**。
- **普通工薪 / 农村家庭女孩 + 公费师范零成本上大学 + 直接编制**:山西师大公费师范是最稳路径。
- **学教育学 / 心理学 + 想读研冲 985 师范硕**:山西师大本科基础够用。

## 不适合谁

- **想跨省当老师 / 出省走全国师范路径**:**出省 211 师范(华师 / 陕师 / 南师 / 西南大)优先**,**山西师大出省牌子认可一般**。
- **男生 + 不想当老师 + 想跨阶级**:**师范院校男生少 + 非师范专业边缘**,**学非师范别来山西师大,选太理工或出省工科**。
- **学非师范专业(法学 / 经管 / CS)**:**山西师大非师范 = 双非中下**,**别为了"师大牌子"学非师范**。
- **不想被"原籍服务 6 年"绑死**:**公费师范要回原籍服务 6 年违约影响大**,**接受不了的别报公费**。
- **分够 211 师范(华师 / 陕师 / 南师 / 西南大)**:**别在山西师大将就 + 出省 211 师范牌子全国通用**。
- **想留太原当中学老师**:**山西师大主校区已迁太原 + 太原中学编制竞争激烈**,**太原本地的山大 / 山财师范类 + 太原中学校招校友网也密**,**笃定回太原而非各市县的话留心校区 + 考编竞争**。

## 山西师大家长高频问题(FAQ)

### Q1:山西师大是 211 吗?
A:**不是**。山西师大是双非 + 山西省属重点 + 部省合建(教育部 + 山西省政府),**山西本省师范主力 + 公费师范主供给校**。**没有 211 牌子,但留晋当中小学老师对口度顶配**。

### Q2:山西师大的公费师范和教育部直属公费师范怎么选?
A:**完全不同**!**教育部直属公费师范** = **华师 / 北师 / 陕师 / 西南大 / 东师 / 华东师 6 所**(2024 年起新增更多但 6 所是核心),**全国通用 + 服务期满后可在全国流动 + 但回山西考编反而吃亏(山西本地编制看山西校友网)**。**山西师大公费师范 = 山西省属公费 + 服务山西本地中小学 6 年**(回原籍服务),**适合笃定留山西的农村 / 工薪家庭**。

### Q3:山西师大 vs 出省 211 师范(陕师大 / 西南大学 / 华师 / 南师) 怎么选?
A:**笃定留山西当中小学老师 + 农村 / 工薪家庭 + 求 100% 编制 → 山西师大公费师范**(零成本 + 直接编制)。**想跨省当老师 / 全国师范路径 / 中产家庭可承受出省 → 出省 211 师范**(陕师大 / 西南大公费师范 + 全国通用编制流动)。

### Q4:公费师范服务 6 年违约会怎样?
A:**服务期未满擅自违约 = 退还学费 + 写违约记录 + 影响以后考公考编**。**山西省属公费师范要求回山西原籍服务 6 年(中小学教师)**,**违约影响极大**。**家长 + 孩子聊清楚这 6 年要回原籍当老师,接受不了的别报公费**。

### Q5:山西师大主校区到底在太原还是临汾?
A:**2022 年起主校区已迁太原(小店区新校区)**,**新生大多在太原新校区**。**部分专业 + 现代文理学院仍在临汾**(临汾分部),**报志愿前看清招生章程的校区代码**!**别看到"山西师大"就以为在太原 — 部分专业仍在临汾**。

### Q6:山西师大非师范专业怎么样?
A:**边缘**。山西师大是师范类专业校 + 非师范专业(行政管理 / 文化产业 / 信息管理 / CS / 经济学)= 双非中下水平 + 出口窄 + 改行率高。**别为了"师大牌子"学非师范** — 学 CS 去太理工或出省,学行政管理去山大或山财,学法学去山大。

### Q7:女生学山西师大公费师范有什么风险?
A:**风险 1:6 年原籍服务**(回山西原籍县市,不能调动)。**风险 2:基层县市生活**(吕梁山区 / 太行山区 / 雁门关地区 等,生活条件 + 文娱 + 婚恋市场都跟太原不同)。**风险 3:公费师范工资偏低**(基层县中学起薪 5-7k)+ 但 + 编制 + 寒暑假。**接受不了基层 6 年生活的别报公费,做好心理预期**。
