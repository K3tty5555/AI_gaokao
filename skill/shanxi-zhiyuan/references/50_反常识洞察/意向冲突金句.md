# 用户意向冲突 — Reality Check 金句库(山西视角)

很多家长 / 考生有具体的意向("想上太理工"、"非太原不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)+ 山西本地化案例。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 1.5 万位次以上(山西考生少,1.5 万 ≈ 湖北 2 万),**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一,在山西尤其成立 — 山西本省 985 = 0,跟"省内 211 vs 出省 985"的逻辑跟其他省不同)
5. **山西普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **山西本省 0 985 + 1 211 → "留晋"和"出省"是核心冲突轴**,跟湖北 / 河南 / 四川等"留省吸引力强"的省份完全不同

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >1.5 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 400 分要清北 / 540 分要太理工主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [山西本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 211/双一流 牌子的执念,还是把 [替代校] 当作双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(山西物理类省排 25000 名,意向太理工)**:
> "太理工主流组在山西物理类 9000-15000 名。你 25000 名,差 1 万多名,**太理工主流组没戏**。
>
> 但你能上**中北大学兵器组(15000-22000)+ 太科大重机(22000-32000)+ 山医医学影像(22000-35000)** — 这三所留晋就业 / 进央企,**山西本地国企 / 体制内招聘里跟太理工冷门组校友地位差不多**(都是'山西本地双非工科 + 央企对口同档')。
>
> 太理工冷门(矿业 / 安全 / 部分文管)能擦边,但**矿业组进山西煤炭工业是一辈子在山区基层 + 行业还在收缩**,慎重。"

**真实案例(山西物理类省排 8000 名,意向清北)**:
> "清北在山西物理类录取一共 60-70 个名额,集中在省排 200 名内。你 8000 名,差 7800 名,**清北根本不在讨论范围**。
>
> 山西 8000 名能上的是**西交主流 / 哈工 / 同济医学院 / 中科大冷门组 / 北航部分组**,这些都是 985 主流强专业组,**5 年后跟清北弱专业的差距远小于山西家长的想象**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'211/985 就是 211/985',但 **211/985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 山西强专业]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(山西物理类省排 8500 名,意向太理工)**:
> "太理工你 8500 能擦化工双一流 — 但只能进矿业 / 安全 / 资源勘查组。**211 + 山西矿业 + 行业收缩** = 三重坑。
>
> 同分能上的**中北兵器主组(15000-22000 你完全够)+ 山大物理双一流(8000-13000)** 出来对口程度更高。冲太理工矿业留一个心理慰藉位即可,**主推中北兵器或山大物理**。"

**真实案例(山西物理类省排 12000 名,意向出省 985)**:
> "你 12000 能擦兰州大学 — 但只能进生命科学 / 草学。**985 牌子 + 西部偏远 + 生化环材** = 三重坑。
>
> 同分能上的**太理工化工双一流(9000-15000 你够)** 留晋进山西焦煤 / 潞安化工 + 山西本土央企对口直接,出来对口程度更高。冲兰大留一个心理慰藉位即可。"

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村 / 工矿子弟,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [山医 5+3 一体化 / 出省协和北医])
> - 撑不起 → 走 **[替代短路径]**(如 [山医医学影像技术 / 山医法医 / 长治医学院影像 — 4 年本科即可] — 早 4 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(山西普通工薪家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k**(山西本地三甲规培期更低)。普通工薪父母还要供 8 年。
>
> 撑得起 → 推山医 5+3 一体化 / 西交医学部 / 出省 985 医,长期天花板高。
>
> 撑不起 → **建议山医法医学(5+3 但毕业进山西公安系统 + 公务员编制,起点比临床稳)**,或者**山医医学影像技术(4 年本科直接进医院技师岗 + 6-8k 起薪 + 编制)**,或者放弃医学走电气 / 化工这种本科直接进央企的赛道。"

**真实案例(山西农村家庭 + 想学法)**:
> "你说想学法学进公检法 — 山大法学是省内最好的,但你 540 分历史类(省排 9000 名),**山大法学在 4500-7500 名,你冲不上**。
>
> 普通农村家庭学法的真相:**法考通过率全国 10% + 律所前 5 年月薪 3-5k + 进公检法要法考 + 选调** = **8 年起才能稳定**。
>
> 替代方案:**山西师大公费师范汉语言** = 4 年本科 + 免学费 + 毕业回县城教师编制 = 4 年就稳定。或者**山医法医学**(分数能擦)= 进山西公安刑警技术处 + 直接公务员编制 + 不用法考。这两条路对农村家庭比法学法考稳得多。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去" / "非太原不去" / "非北上广不去"

**特征**:用户只想留某个城市("非太原不去" / "非出省不去"),拒绝出省 985 或拒绝留晋。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211/双一流] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211/双一流 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留太原没意义,要去西工大),**要灵活退一步**。"

**真实案例(山西考生 + "非太原不去" + 580 分物理类)**:
> "你只留太原,这位次 12000,出省 985 主流组(西交 / 哈工)能擦,但你坚持留太原。
>
> **留太原最稳路径**:**太理工电气主流组(9000-15000 你够)+ 国家电网山西公司管理岗** → 起薪 9k + 编制 + 留太原。或者**山大法学(8000-13000 你够) + 山西选调生** → 直接进山西省委办。
>
> 这两条比'外省西交 985 牌子但专业弱(去了西交矿业 / 农林组)+ 毕业回太原没人脉'强得多。**留太原 + 211/双一流 + 强专业 = 山西考生最稳的'留晋 + 编制'组合**。"

**真实案例(山西考生 + "非北上广不去" + 580 分物理类)**:
> "你 12000 名想去北京,北京 985 你够不上(清北人北 6000 名内 / 北航 / 北理 / 央财 8000 名内 / 北邮 8500 名内),北京 211 弱专业组能擦(对外经贸冷门 / 北科大冷门)。
>
> **去北京最稳路径**:**北邮 / 北科大 / 央财 弱组 + 北京户口拼搏路径**。但**北京户口对山西农村 / 工薪家庭门槛极高**(2024 北京应届生留京户口指标 < 2 万 → 大部分山西考生毕业被迫离京)。
>
> 替代:**留晋太理工电气(留太原 + 国网编制 + 4 年挣钱) vs 北京 211 弱专业(漂北京 + 高房价 + 35 岁危机)** — 山西普通家庭算清楚 4 年后实际净收入 + 户口 + 父母距离,**留晋反而是优解**。"

### 模式 E(山西特有):"留晋 vs 出省" 撕裂型 — 父母想留 / 孩子想出 OR 反之

**特征**:山西考生家庭特有矛盾 — 父母经历过山西经济萎缩 / 子女外流,**强烈希望孩子出省**;或者反之父母想留孩子在身边而孩子想出去。

**金句模板**:
> "山西本省 0 985 + 1 211,**留晋意味着接受双非或一所 211 独苗**。出省意味着用同分能上 985/211 + 出省机会大。
>
> 这是个**家庭抗风险能力 + 父母未来期望** 的决策,不是单纯的"哪个学校好"。
>
> - 如果家庭中产 + 父母希望孩子留太原 + 孩子想要 985 牌子 → **冲突**:推 **太理工 211 + 强专业(电气 / 化工)** 或 **山大双一流 + 选调路径**(留晋的最优解)
> - 如果普通工薪 + 父母希望孩子出省 + 孩子也想出 → **共识**:推 **出省 985/211 + 山西定向选调**(毕业回山西编制最稳)
> - 如果父母希望出省 + 孩子想留 → **直接说服**:山西本省经济萎缩 + 民企岗少 + 出省读 985 后回晋选调比留晋读 211 起点更高"

**真实案例(山西临汾农村家庭 + 父母希望孩子出省)**:
> "你父母希望你出省 — 这个判断**对**。山西农村家庭跨阶级最稳路径就是 **出省 985 + 山西国家专项**(分数比统招低 30-40 分)+ 毕业 985 选调回山西。
>
> 你 590 分物理类(省排 8000 名),走山西国家专项可冲**西安交大主流组 / 哈工大 / 同济医学院**。这条路 5 年后比'留晋读太理工电气'起点高 1 个层级(西交 985 选调 vs 太理工电气进国网基层)。
>
> **听父母的,出省。**山西农村家庭这个共识对。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比(山西 2025 是首届新高考,数据稀薄,**位次定档 + 分数仅参考**)
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ 套用湖北 / 江苏 / 浙江的"留省"逻辑 — 山西本省 0 985 + 1 211,**"留晋 vs 出省"决策完全不同**

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 太理工 / 想学医 / 想留太原 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 山西本地化金句库(常用)

> "**山西最大的真相是:本省名校稀缺,留山西 = 接受双非或一所 211 独苗。** 想要 211/985 牌子,得做好出省的心理准备 — 这不是缺点,这是山西考生的常态。"

> "**山西大学不是 211,但学科实力堪比 211**。1902 年创办的老牌综合性大学,跟北大并列三大学堂,物理 / 哲学双一流。**别因为'非 211'就放弃** — 学物理化学文史哲考研路径,山大比太理工还强。"

> "太理工是山西唯一 211,**煤化工 / 材料 / 机械 + 山西本地央企对口稳**,但**文科 / 经管 / CS 别来太理工**,牌子用不上。"

> "中北大学全国兵器工业头部,**进中物院 / 兵器集团 / 航天科工铁饭碗**。男生 + 不冲 211 + 想进国防工业 → 这是双非顶配。"

> "**别迷信'留山西'**。山西本省经济萎缩 + 0 985 + 1 211,留山西意味着接受双非或一所 211 独苗。**用同样分数出省,京津/西安/沿海 都有 211/985 可选**。"

> "山西讲实在 — **位次比分数实在,专业比牌子实在,央企对口比 211 牌子实在**。"

> "学校跟你 4 年,专业跟你一辈子 — **山西本省 985 = 0,这句话比其他省更成立**。同分情况下,出省 985 弱专业 vs 出省 211/双一流 强专业,后者更值。"

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。**山西考生的特殊 reality check 维度 = "留晋 vs 出省" + "本省 211 独苗的相对劣势"** — 这两点跟其他省份完全不同,agent 必须 internalize。
