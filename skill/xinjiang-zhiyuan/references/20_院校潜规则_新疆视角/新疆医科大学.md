# 新疆医科大学(新医大,XJMU)— 双非但临床 / 维吾尔医学 全国前列,新疆医生主力供给校

## 一句话定位

**自治区直属医学主力校 + 新疆医生第一供给校** —— **临床医学 / 维吾尔医学 / 中医学(哈医方向)/ 公共卫生 / 民族药学** 在新疆是龙头。**维吾尔医学全国独家**(全国唯一独立设维医的医学院校,**民族医药事业核心阵地**)。**新疆医大第一附属医院 / 第二附属医院 / 第五附属医院** 是新疆顶级三甲。**双非但医学行业本土对口顶配**,**临床本硕连读 + 留疆三甲编制 + 普通家庭学医最优解**。

---

## 真实地位

- **双非但医学学科特色独家**(临床医学 / 维医学 / 中医学 / 公共卫生 / 药学 在新疆是龙头)
- **历史血脉**:**1954 年新疆医学院**(自治区独立设医学主力,周恩来总理批准)→ 1998 年与新疆中医学院合并定名新疆医科大学,**自治区第一医学主力 + 国家民委 / 自治区卫健委 重点建设**
- **本省地位**:**新疆医生第一供给校**(自治区三甲医院 / 各地州医院 / 兵团医院 主要医师来源),**新医大第一附属医院 / 第二附属医院 / 第五附属医院** 是新疆顶级三甲(**新医大附一是新疆唯一的国家区域医疗中心 + 新疆三甲天花板**)
- **学科评估**:临床医学 B(双非里强势 + 全国前 50)、维吾尔医学(独家 A 类专业,全国唯一)、中医学(包含哈萨克医学方向)B、药学 B(包含民族药方向)、公共卫生与预防医学 B-、口腔医学 中等
- **同档对比**:**全国医学类双非"中等"档,跟内蒙古医大 / 宁夏医科大 / 甘肃中医药大 同档**(都是西北省属医学主力,**维吾尔医学是新医大独家招牌,全国唯一**)
- **校区地理**:**乌鲁木齐新市区(本部)+ 鲤鱼山校区 + 仓房沟校区**(分散办学),**靠近新医大第一附属医院 / 第二附属医院 / 第五附属医院 实习基地最强**
- **男女比**:**3:7**(医学院女生占多数,临床 / 护理 / 医技 女生比例高;**找对象友好但医学生学习压力大**)

### 2021-2025(老高考,文 / 理)

- **理科王牌专业(临床医学 5+3 / 临床医学 5 年制 / 口腔医学)**:全区 **2,500-5,500 名**

- **理科冷门专业(护理学 / 公共事业管理 / 部分理工边缘)**:全区 **12,000-20,000 名**

**段位定位**:**新疆理科全区 20,000 名内可冲新医大,5,500 名内可挑王牌(临床 5+3 / 5 年制 / 口腔)**;**文科全区 7,500 名内可冲(主要护理)**。**国家专项 + 南疆专项 + 公费医学(订单定向农村 / 基层医师)+ 民族班(维医) 可再低 2,000-4,000 名**,**农村户籍 + 少数民族 + 南疆生源 重点利用**。**临床医学 5+3 一体化分较高 + 出口稳**(本硕连读省去考研规培焦虑)。

## 性价比专业(新医大独家 + 政策性人才)

- **临床医学(5+3 一体化 ★★)**:**B 全国前 50 + 双非里顶配** + **本硕连读省去考研规培焦虑** + **新医大附一是新疆唯一国家区域医疗中心** + **留疆三甲铁饭碗** + **石大临床也强但 5+3 招生量小**,**新医大 5+3 是新疆学医的天花板路径之一**(与石大 5+3 并列)。
- **维吾尔医学(全国独家 ★)**:**全国唯一独立设维医的医学院校** + **少数民族考生独家政策性人才培养** + **自治区维医医院 + 民族医药研究院 + 民族药企业** 路径独家,**冷门但出口稳 + 民族干部路径**。
- **中医学(哈萨克医学方向)**:**民族医药全国前列** + **自治区中医医院 / 哈医医院 / 中草药研究** + **少数民族考生政策红利**,**留疆民族医药铁饭碗**。
- **公费医学定向(订单定向农村 / 基层医师)**:**学费免 + 生活补贴 + 毕业回乡服务 6-10 年 + 编制保障**,**普通家庭 / 农村家庭 学医最稳路径**(回基层卫生院 / 县医院 + 编制 + 政策红利)。
- **公共卫生 / 预防医学**:**自治区疾控中心 / 各地州疾控 / 兵团疾控 + 编制稳定**,**比临床医学竞争小 + 工作压力小 + 留疆铁饭碗**。
- **儿科学**:**国家紧缺方向 + 政策倾斜** + **留疆三甲儿科 + 各地州儿科** 对口,**冷门但出口稳 + 行业红利**。
- **药学(民族药方向)**:**自治区药企 + 民族药企 + 中医院** 对口,**录取分相对低 + 出口稳定**。

## 坑专业 / 慎选(在新医大里相对弱)

- **非医学专业(护理 / 卫生管理之外的文管 / 经管)**:**新医大里很边缘**,**别为"医科大学"牌子选非医学**
- **公共事业管理(医学方向)**:**学卫生管理出口窄,留疆考公还行**
- **法学(医事法律方向)**:**新医大法学边缘**,**学法学选新大法学** 更对口
- **新疆医科大学厚博学院 / 独立学院**:**民办,牌子差一档 + 学费贵**,**填报别看错代码**

## 关键提醒(填报陷阱)

1. **新医大 vs 石大医学院(怎么选学医)**:
   - **新医大**:乌鲁木齐 + **新疆医生第一供给校 + 新医大附一是国家区域医疗中心 + 维吾尔医学独家** → 想留乌鲁木齐 / 进自治区三甲 / 学维医 / 学民族医 选新医大
   - **石大医学院**:石河子 + **211 + 北大对口支援** + 石大附一是北疆三甲顶配 + **临床 5+3** → 想要 211 牌子 + 兵团子弟 + 北大保研机会 选石大
   - **录取分**:石大临床 5+3 比新医大 5+3 略高 10-30 分(211 牌子加成)
   - **简言之**:**两条不同的医学路径**(自治区医学主力 vs 兵团 211 医学),**新医大附一国家区域医疗中心是独家加成,但石大有 211 + 北大对口支援**,**看孩子未来扎根在乌鲁木齐还是石河子 + 是否要 211 牌子**
2. **临床医学 5+3 一体化 vs 5 年制**:**5+3 分较高(理科 3,000-4,500 名)但出口稳**(本硕连读 + 直接进三甲规培 + 编制路径);**5 年制要单独考研规培**,**不冲 5+3 的慎入临床冷门方向(可能调到护理 / 检验 / 影像)**
3. **维吾尔医学 = 民族干部独家路径**:**全国唯一独立设维医的医学院校** + **少数民族考生独家政策性人才** + **自治区维医医院 / 民族医药研究院 + 编制保障**,**少数民族考生闭眼选**
4. **公费医学定向(订单定向农村)= 隐藏跃迁通道**:**学费免 + 生活补贴 + 毕业回乡服务 6-10 年 + 编制保障**,**农村家庭 / 普通家庭 学医最稳路径**(回基层卫生院 / 县医院 + 编制 + 政策红利)
5. **理科专业分化**:王牌(临床 5+3 / 5 年制 / 口腔)与冷门(护理 / 卫管 / 检验)位次差 6,000+,**勾服从前查清全校有哪些专业**(老高考下服从调剂在全校范围内)
6. **服从调剂注意**:中分段可能调到护理 / 检验 / 影像 / 公共事业管理,**接受不了护理 / 非临床医学的别勾**(想做医生的别被调到护理)
7. **想去内地当医生** → **新医大牌子在内地不如内地 985 医(协和 / 北医 / 上交医 / 复旦上医 / 中山医 / 华西医)**,**只在新疆 / 西北吃得开**(出疆考研 + 进内地三甲是路径)
8. **少数民族考生(维 / 哈 / 蒙)+ 想做民族医 / 中医** → 新医大民族医学方向 + 民族班 + 民族专项 三叠加 = **首选**
9. **南方娃 + 怕新疆冬天 + 高强度医学学习** → 提前心理建设(医学院学习压力大 + 实验课多 + 临床实习强度高)

## 毕业出口(2024 数据)

- **留疆就业**:约 **70-75%**(新医大留疆率高,主要是医院编制岗位)—— **乌鲁木齐 35-40%(自治区三甲 + 新医大附属医院系) + 各地州市(伊犁 / 喀什 / 阿克苏 / 和田 / 库尔勒 / 哈密 / 吐鲁番)三甲 + 兵团医院**
  - **自治区三甲 + 各地州三甲**:约 45-50%(**新医大附一 / 附二 / 附五 + 自治区人民医院 + 自治区中医医院 + 各地州医院**)
  - **基层卫生院 / 县医院(订单定向)**:约 15-20%
  - **兵团医院系统**:约 5-8%
  - **疾控 / 卫健委 / 药监**:约 3-5%
- **去西安 / 兰州**:约 **5-8%**(西交医 / 兰大医 读研 / 央企医院西北分部 / 部分西北三甲就业)
- **去京津**:约 **3-5%**(协和 / 北医读研 / 北京三甲 / 民族医药研究)
- **去沿海(长三角 / 大湾区)**:约 **3-5%**(上海中山医 / 复旦上医读研 / 沿海三甲 / 民营医疗)
- **保研 / 考研 / 读博**:约 **35-40%**(保研率约 8-12%,**医学保研 + 考研出疆是常态**,**新医大保研协和 / 北医 / 西交医 / 中山医 有少量名额**)
- **进编制概率**:**约 65-70%**(医院编制 + 卫健系统 + 疾控编制,**这是新医大最大优势**)
- **新疆独家出口**:**自治区三甲医院 + 维吾尔医学(全国独家)+ 民族药企 + 兵团医院 + 基层卫生院** = 新医大独家路径
- **起薪范围**:临床医学规培期 8-12w + 房补 + 项目奖金,临床 5+3 进三甲住院医师 12-18w + 项目奖金,维医 / 中医 进民族医院 8-12w + 编制,公费医学定向(基层卫生院)6-10w + 编制 + 边远津贴

## 适合谁

- 新疆理科 **全区 2,500-20,000 名** / 文科 **3,500-7,500 名** 的考生(老高考)
- **想学临床医学 + 留疆 + 普通家庭** → 新医大临床 5+3 是首选(石大临床也强,二选一)
- **少数民族考生(维 / 哈 / 蒙)+ 想做民族医 / 中医 / 民族药学** → 新医大维医 / 中医 + 民族班是首选(政策倾斜)
- **农村家庭 + 想学医 + 公费医学定向** → 新医大公费医学是稳赢组合(学费免 + 编制保障 + 回基层服务)
- **女生 + 想要稳定医院编制 + 工作环境舒适** → 新医大女生友好(3:7)
- **想做疾控 / 公共卫生 / 卫健系统** → 新医大公共卫生强 + 自治区疾控对口
- **想做兵团医生** → 新医大有兵团医院系统对口(石大也有,二选一)
- **南疆生源(和田 / 喀什 / 阿克苏 / 克州)+ 想回南疆当医生** → 新医大有南疆专项 + 公费医学定向南疆倾斜

## 不适合谁

- **想去内地当医生** → 新医大牌子在内地三甲不如内地 985 医,**只在新疆 / 西北吃得开**(出疆考研 / 援疆班更优)
- **不想学医 + 只为新医大牌子来** → 别选(新医大非医学专业弱 + 出口同普通双非)
- **怕医学高强度学习 + 怕值夜班 + 怕规培 5+3 长周期** → 慎选(医学行业是长周期 + 高强度 + 高责任)
- **南方娃 + 怕新疆冬天 -25℃ + 干燥 + 沙尘** → 提前心理建设
- **男生 + 不喜欢医学院女生比例高(3:7)的氛围** → 慎选
- **分够援疆班上 985 医学 + 接受回疆服务** → **援疆班(协和 / 北医 / 西交医)更优**
- **不接受公费医学 6-10 年回乡服务** → 别选公费医学定向
