# 新疆老高考政策与改革推迟

## 核心结论(必须严格采用)

**新疆 2021-2025 全部仍是老高考(文科 / 理科,文综 / 理综,总分 750)**。

**原定 2025 首届 3+1+2 改革已被推迟,首届新高考实际是 2027 年**(2024 年 9 月入高一 → 2027 高考)。详见新疆教育考试院公告。

所以:
- **2021、2022、2023、2024、2025 高考 = 老高考**(文科 / 理科)
- **2026 高考仍是老高考**(2023 年 9 月入高一的届)
- **2027 高考 = 新疆首届 3+1+2 新高考**(2024 年 9 月入高一的届)

**agent 必须严格按"新疆 2021-2025 全部是老高考"的口径处理数据,不能引用"2025 首届 3+1+2"这个错误说法**。

## 关键事实

### 老高考(2021-2025,且 2026 仍是)结构
- **语文 / 数学 / 英语**,各 150 分(共 450)
- **文科**:文综(政治 + 历史 + 地理,共 300 分)
- **理科**:理综(物理 + 化学 + 生物,共 300 分)
- **总分 = 750 分**
- 用 **全国乙卷**(过渡到 2027 时换新高考卷)

### 录取批次(老高考)
- **本科一批**(本一 / 重点本科 / 一本线)
- **本科二批**(本二 / 普通本科 / 二本线)
- **专科批**(高职高专)
- **提前批**(军校 / 公安 / 国家专项 / 公费师范 / 民族专项 等)
- **不是新高考的"本科批 + 特控线"** —— 这点常错,新疆仍然有本一 / 本二之分

### 投档模式(老高考)
- 按"**院校 + 专业**"模式平行志愿投档,**不是"院校专业组"**
- **服从调剂在全校范围内**(被调可能到该校任意未招满专业,不是组内)
- **本科批不合并**:本一 / 本二线分别划定,本一线下考生不能填本一院校

### 数据现状
- `data/yifenduyiduan/` 下 2021-2025 全部是 `<年>_文科_xinjiang.csv` / `<年>_理科_xinjiang.csv`
- **没有任何 物理类 / 历史类 数据**(因为新疆这几年压根没改新高考)
- agent 调 `score_to_rank.py` / `query_school.py` / `predict.py` 时,**type 参数永远是 `文科` 或 `理科`**

## 新疆班型 / 招生类型(老高考下仍然存在,关键!)

- **普通班**(汉族考生 + 民考汉的统招,主流)
- **汉语言班**(少数民族学生用汉语授课,跟普通班录取分数线接近,但单列计划)
- **民语言(双语)班**(用民族语言 + 汉语双语教学,单列计划,分数线低)
- **民考汉**(民族考生用汉语答卷,等同普通班)
- **预科班**(本科预科 / 民族预科,先读 1 年预科再升本科)

**agent 拿录取数据时默认看普通班 / 汉语言班的数据**(这两条线数据可比);民语言 / 双语 / 预科 单列分析。**L1 必须问清楚班型**。

## 新疆考生独家政策红利(老高考下都适用)

### 1. 援疆班 / 内地高校援疆专项

国家组织全国 19 个省份对口支援新疆,**部分省份高校在新疆有单列招生计划**(分数线比内地考生低 30-80 分),**毕业回疆服务一定年限**(一般 5-10 年)。

- 北京(北大 / 清华 / 人大 / 北航 / 北邮 / 中国农大等)
- 上海(复旦 / 上交 / 同济 / 华东师大等)
- 江苏(南大 / 东南 / 河海 / 南农大等)
- 浙江 / 广东 / 山东 / 河北 / 辽宁 等

**普通家庭逆袭性价比首选**:用比裸考低 30-80 分的代价上 985/211,毕业回疆有编制。

### 2. 兵团专项

**新疆生产建设兵团**辖 14 个师 + 200+ 团场,**兵团子弟回兵团就业有政策倾斜**:
- **石河子大学**(兵团唯一 211 + 双一流化工 + 北大对口支援)是兵团子弟首选
- **塔里木大学**(兵团一师驻地,沙漠绿洲农业)对口南疆兵团一师
- 兵团央企(新疆天业 / 青松建化 / 天富 / 国统管道等)定向招聘

### 3. 南疆专项 / 国家专项

- **南疆四地州**(和田 / 喀什 / 阿克苏 / 克州)考生有"南疆专项"录取倾斜
- **国家专项**:面向农村户籍考生,中央部委高校单列名额(分数线低 30-50 分)
- 新大 / 石大 / 喀什大学 / 塔大 等本省高校都有南疆专项

### 4. 民族专项 / 民族班 / 民族预科

- 少数民族考生(维 / 哈 / 蒙 / 柯 / 塔等)有民族班 / 民族预科
- 民语言班录取分最低,但毕业去向多在新疆 / 民委系统
- **agent 必须问清楚民族 + 班型**,数据口径不同

## 选科建议(老高考下:文 / 理 二选一)

**新疆 2021-2025 是老高考,只有文科 / 理科二选一,没有 12 种选科组合**。agent 不要再问"物化生 / 物化政"等新高考组合。

| 想做什么 | 文 / 理 选择 |
|---|---|
| 学医(临床 / 口腔 / 中医 / 维医) | **理科**(必须) |
| 工科(电气 / 机械 / 化工 / 土木 / 计算机) | **理科**(必须) |
| 理科基础(数学 / 物理 / 化学 / 生物) | **理科** |
| 农林牧(棉花 / 林果 / 兽医) | **理科** |
| 师范(数学 / 物理 / 化学 / 生物 师范方向) | **理科** |
| 师范(语文 / 历史 / 政治 / 英语 师范方向) | **文科** |
| 法学 / 中文 / 历史 / 民族学 / 中亚研究 | 文 / 理皆可,文科覆盖更专 |
| 经管 / 会计 / 金融 | 文 / 理皆可,**理科覆盖更多专业** |
| 警察 / 公安 | 文 / 理皆可 |
| 阿语 / 俄语 / 哈语 / 中亚贸易 | 文 / 理皆可,文科主流 |

**核心结论**:**理科覆盖更多专业**(医学 / 工科 / 理科 / 大部分农林经管),**文科主要覆盖文史哲法 + 部分经管 + 师范文科方向**。**新疆考生想留多条路 → 选理科**(除非孩子物化生明显弱)。
