# 用户意向冲突 — Reality Check 金句库(新疆视角)

很多新疆家长 / 考生有具体的意向("想上新大"、"非乌鲁木齐不去"、"想学医"、"非援疆班 985 不去"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 1 万位次以上(新疆考生量小,1 万位次差距已经是巨差),**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **新疆独家:援疆班 + 国家专项 + 南疆专项 + 民族专项 + 兵团专项 政策红利** — agent 必须主动告知(很多家长不知道这些政策存在)

---

## 5 类意向冲突 + 金句模板(新疆视角)

### 模式 A:不可达型 — 分数差距 >30 分 / >1 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 350 分要清华 / 全区文科 5000 名要新大法学主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 千名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [新疆 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 211 牌子的执念,还是把 [替代校] 当作双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(新疆理科 5000 名,意向新大主流)**:
> "新大主流组在新疆理科全区 1500-3500 名。你 5000 名,差 1500 多名,**新大主流组没戏**。
>
> 但你能上**石大化学工程**(211 + 双一流 + 北大对口支援,录取比新大主流低)、**新疆农大作物学**(新疆棉花产业链铁三角)、**新疆财大会计**(留疆考公 + 进银行)— 这三所留疆就业,**国企 / 自治区机关 / 兵团央企 招聘里跟新大冷门组校友地位差不多**(都是'新疆本地 211 / 双非顶配 + 留疆同档')。"

**真实案例(新疆理科 4000 名,意向援疆班北邮)**:
> "援疆班北邮 CS 在新疆理科要全区 2000-3000 名(援疆班分比裸考低 30-50 分,但 CS 是热门专业,反向卷)。你 4000 名,**援疆班北邮 CS 没戏**。
>
> 但同档你能上 **援疆班 西安电子科技 / 西北工业 / 北航 / 哈工大 等其他 985 的非热门工科 / 数学 / 物理**(援疆班 + 弱专业反而更便宜),**回疆有编制 + 服务期满后跳沿海大厂** 的路径不变。**别只盯着北邮 CS,援疆班的核心价值是'用普通分数换 985 牌子 + 回疆编制',不是'必须北邮'**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工天坑 / 哲学]**。
>
> 你父母可能觉得'211 就是 211',但 **211 的材料 / 部分边缘工科(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(新疆理科 + 普通家庭 + 意向新大)**:
> "新大你 6000 名能擦边冲 — 但只能进**部分材料 / 资源勘查 / 边缘农学**。**211 牌子 + 边远地理 + 生化环材** = 三重坑。
>
> 同分能上的**石大化学工程双一流**(B+ 全国前 50 + 北大对口支援 + 进独山子石化 / 克拉玛依油田直接对口)出来对口程度更高。冲新大留一个心理慰藉位即可,**主推石大化工**。"

**真实案例(援疆班北大边缘)**:
> "援疆班北大冷门组(如哲学 / 历史 / 部分理论物理)新疆理科 800-1500 名能擦,但**北大冷门 + 4 年 + 北大牌子 + 5-10 年回疆服务期** = 你父母期待的"北大光环"和实际就业的差距很大。
>
> 同档分能上的**援疆班 协和医学院 / 北大医学部 / 西交医临床**(直接对口三甲医院 + 回疆有医生编制) → **临床医学的牌子+实操+编制三重叠加,远比北大哲学回疆当公务员强**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村 / 牧民,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [援疆班协和临床 / 援疆班北医临床])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k**(新疆三甲规培薪资比内地略低)。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**援疆班协和 / 北医临床 / 石大临床 5+3 一体化**,长期天花板高,毕业回疆三甲。
>
> 撑不起 → **建议口腔(5 年本科直接进新疆诊所,起薪 8-12k,早 3 年挣钱)**,或者**医学影像 / 检验技术(4 年本科进新疆三甲技师岗 + 编制 + 边远补贴)**,**早 4 年挣钱 + 不读规培 + 编制保障 + 工作压力小** 普通家庭性价比之王。"

**真实案例(农村 + 想学法考做律师)**:
> "学法律 + 做律师 = 至少 5 年(本科 4 + 法考 1 + 实习期 1-3)。普通新疆农村家庭 + 5 年起步律师没收入(新疆律师起步月入 3-6k,远低于沿海) — **你父母撑得起 5 年吗?**
>
> 撑不起 → **改报新大法学 / 援疆班法学 + 直接考公 / 选调** → 同样学法律,**毕业当年直接进自治区检察院 / 法院 + 编制**,**5 年后年薪 10-15w + 公积金 + 房补,远比律师起步稳定**。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非乌鲁木齐不去" / "非内地不去" / "非北上广深不去"),拒绝其他选择。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留乌鲁木齐没意义,要走援疆班西工大),**要灵活退一步**。"

**真实案例(乌鲁木齐户籍 + 想留乌鲁木齐 + 全区理科 4500 名)**:
> "你只想留乌鲁木齐 + 留新疆,这位次 4500,**新大主流组完全够**(理科主流 3500-6500 名)。
>
> **留疆最稳路径**:**新大软件工程 / 化学 / 法学**(留疆考公 / 进自治区机关 / 进新疆移动电信 / 国电新疆 直接对口)+ **援疆班 985 弱专业**(回疆有编制 + 服务期满自由跳,等同'用普通分数换 985 牌子 + 留疆编制'两不误) → 这两条都不冲突,可以双轨。
>
> 不要为了'援疆班 985 牌子'去东北农大 / 兰大 冷门 — 牌子有了但**回疆服务期 + 父母在乌鲁木齐看不到 + 实习机会少 + 户口未必好转**,综合不划算。"

**真实案例(沿海情结 + 全区理科 6000 名)**:
> "你说'非沿海不去',这位次 6000,**沿海 985 / 211 完全够不上**(沿海 985 在新疆要全区 1500 名内,211 也要 4000 名内)。
>
> **真相**:你这分**沿海双非工科(深大 / 浙工大 / 上大 部分专业)** 能上 — 但**沿海双非 + 新疆户籍 + 无家底** = 毕业留沿海 5 年内买不起房 + 父母接不过去 + 户口未必能解决。
>
> **同分能上石大化工 / 新大软工 / 援疆班 985 弱专业** + **回疆有编制 + 父母在身边 + 5 年内买房** + **服务期满后想跳沿海再跳** = 综合性价比远超裸考沿海双非。"

---

### 模式 E:援疆班的纠结 — "援疆班限制太多 / 不想回疆"(新疆独家)

**特征**:用户家庭不了解援疆班政策细节,**误以为"援疆班 = 强制回疆 + 服务期长 = 不要去"**;或者**反过来,只盯援疆班最热门的北邮 CS / 协和临床等不可达组合**。

**金句模板**:
> "援疆班的核心价值是'用比裸考低 30-80 分代价上 985 / 211 + 回疆有编制 + 服务期满后自由跳'。
>
> 你的诉求是 [意向 X],我们看下援疆班和裸考哪个更对路:
> - **想沿海高薪 + 不想回疆**:援疆班服务期违约成本高(违约金 + 影响征信),**慎选**
> - **想稳定 + 普通家庭 + 接受 5-10 年回疆服务**:**援疆班是新疆考生最强政策红利**(用比裸考低 30-80 分上 985 + 回疆有编制 + 服务期满自由跳)
> - **服务期满后**:已有 985 学历 + 5-10 年职场经验,**跳沿海也强,留疆继续晋升也通**"

**真实案例(普通工薪 + 全区理科 4000 名 + 怕援疆班服务期)**:
> "你父母听说'援疆班要回疆服务 5 年 / 10 年'就想躲开。**这是误解** — 援疆班不是'罚款式服务',是'用普通家庭分数换 985 牌子 + 回疆编制' 的国家政策性人才培养。
>
> 你 4000 名:
> - **裸考路径**:新大主流(211 + 留疆) → 没问题,但你想要 985 牌子拿不到
> - **援疆班路径**:用比裸考低 50 分上**援疆班北航 / 西电 / 哈工大 / 西交大 工科**(985) + 毕业回疆服务 5-10 年(进自治区政务云 / 兵团信息化 / 援疆央企新疆公司 + 编制 + 月入 1-1.5w)+ 服务期满后**已有 985 牌子 + 5 年项目经验 + 想跳沿海跳** = **比裸考新大综合更优**
>
> **限制服务期 5-10 年**:你父母觉得长,但**内地裸考出来的非援疆班学生服务期满时已经在沿海漂了 5 年还没编制 + 没户口 + 没买房**,**算清楚账,援疆班反而是普通家庭新疆考生最划算的路径**。"

## Agent 处理意向的 5 步(新疆增加一步:政策红利筛查)

收到 L4.5 意向锚点后,**强制做这 5 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **政策红利筛查(新疆独家)** — 检查考生是否符合 援疆班 / 国家专项 / 南疆专项 / 民族专项 / 兵团专项 资格,**有资格的必须主动告知政策红利**
3. **打 3 档**(可达 / 边缘 / 不可达)
4. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
5. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择
- ❌ **新疆独家:遗漏政策红利**(援疆班 / 国家专项 / 南疆专项 / 民族专项 / 兵团专项 主动告知,**农村牧民 / 少数民族 / 兵团子弟 / 南疆生源 家长普遍不知道这些政策**)

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 新大 / 想学医 / 想留乌鲁木齐 / 想去援疆班北邮 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]

[ 政策红利提醒(新疆独家):援疆班 / 国家专项 / 南疆专项 / 民族专项 / 兵团专项 是否符合 + 价值 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向 + 主动告知政策红利,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check + 政策红利告知 是咨询师的职责** — 三者都要,且 reality check + 政策红利告知 优先。
