# 南华大学 — 双非但医学 + 核工程双特色

## 一句话定位

**衡阳的双非工医院校**,**核工程 + 医学 双特色**,与中核集团共建。**进中核集团 / 三大核电基地** 的对口校。**想做医生但分数不够湘雅** + **男生想进核工业** 的湖南考生选择。

## 性价比专业(南华独家)

### 1. 核工程与核技术(★★★★★)
- **全国双非里核工程第一档**
- **进中核集团 / 中广核 / 国家电投**:湖南本省进核工业的对口校
- 三大核电基地(浙江秦山 / 广东大亚湾 / 福建宁德)主要招聘
- **男生 + 想进央企稳定 + 不怕去东南沿海**:这是好路径
- 缺点:**核电基地多在偏远地区**,湖南家长可能不希望孩子去

### 2. 临床医学(双非里医学的"次选")
- **湘雅是湖南医学顶配,但分数极高**(全省前 1500-3000 名)
- 南华临床医学是**湘雅的退而求其次**:**全省 30,000-50,000 名能上**
- **5 + 3 / 5 + 规培** 路径,8 年才独立行医
- **毕业进湖南二级医院 / 县医院 / 民营医院** 为主
- 适合:**想做医生但分数不够湘雅 + 家庭能撑 8 年**

## 坑专业(南华里弱项)

- **CS / 经管 / 文科**:南华是工医为主,**学非工医专业是浪费南华特色**
- **法学 / 教育**:同档分数选湘潭大学(法学)/ 湖师大(师范)更好
- **化工 / 材料(纯)**:**生化环材天坑**,本科出路差

## 关键提醒(填报陷阱)

1. **核工程的现实门槛**:
   - **进中核集团校招看绩点 + 实习 + 政审**(部分核电涉密)
   - **不是默认包就业**,要拼前 30% 才有戏
2. **临床医学 8 年路径**:
   - **本科 5 年 + 规培 3 年才能独立行医**
   - **三甲医院基本不要双非临床**(要博士)
   - **南华临床毕业 → 湖南二级医院 / 县医院** 是主流
   - **普通工薪家庭撑不起 8 年长周期**(参考 _shared/医学.md)
3. **南华 vs 中南湘雅**:
   - 分数够湘雅 → 中南湘雅(8 年制顶级)
   - 分数不够湘雅但想做医生 → 南华(5+3 路径,二级医院)
   - 分数不够南华但还想学医 → 医学影像 / 检验技术 等 4 年路径(更普通家庭友好)

## 适合什么人

- **男生 + 想进核工业**(理工科基础好 + 接受去核电基地)
- **想做医生但分数不够湘雅 + 家庭能撑 8 年**
- **湖南本省 + 留湘就业(进湖南二级医院)**
- **不在意双非牌子 + 看重行业对口**

## 不适合什么人

- **要冲三甲医院**:三甲基本要博士 + 985 临床
- **想做研究 / 学术**:南华学术资源不如 985
- **追求名校牌子**:双非在大公司认可度受限
- **不能接受去衡阳读书 + 偏远工作**

## 跟同档院校对比

| 维度 | 南华(双非) | 中南湘雅(985) | 长理(双非工科) |
|---|---|---|---|
| 医学 | **临床 + 核医学双特色** | 湘雅顶级 | 无医学 |
| 核工程 | **双非顶配** | 弱 | 弱 |
| 工科其他 | 一般 | **矿冶/材料/交通顶** | 交通/电气强 |
| 牌子 | 双非 | **985** | 双非 |
| 留湖南就业 | 高(临床进湘内医院) | **极高** | 高 |

**简单结论**:湖南考生学医 → 优先湘雅,够不到选南华;湖南男生想进核工业 → 南华是首选;**学其他工科选长理或中南**。

## 毕业去向(典型,粗略)

- **进湖南二级 / 县医院**(临床医学):约 30-35%
- **进中核 / 核电基地**(核工程):约 20-25%
- **留衡阳就业**(其他):约 15-20%
- **出省就业**:约 20%
- **考研 / 读博**:约 15-20%(医学考研深造率较高)

## 给 agent 用的卡片填充字段

**南华大学组内通常涉及专业**:

- **(高分组) 医学组**:临床医学 / 口腔医学 / 麻醉学 / 医学影像 / 医学检验
- **(高分组) 核工程组**:核工程与核技术 / 核技术 / 辐射防护与核安全 / 资源勘查工程
- **(中段组) 其他工科**:计算机 / 自动化 / 机械工程 / 化学工程
- **(低分组) 文经管**:法学 / 工商管理 / 行政管理 等(慎选)
