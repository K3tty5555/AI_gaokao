## 性价比专业(顶级牌子但录取分相对低)

- **矿业工程**:**全国第 1 但行业冷门**,录取位次比 CS / 临床低一档
- **冶金工程**:同上,**进中铁 / 宝武是稳定铁饭碗**
- **测绘工程**:类似武大测绘的湖南版

## 坑专业(中南里相对弱)

- **法学 / 文学 / 新闻**:中南文科边缘,**学法学/财经直接选湘潭大学或湖南大学**
- **经管 / 工商管理**:不如湖大经管学院
- **生物 / 化学(纯理)**:学科评估有但**生化环材天坑**,本科出路差

## 关键提醒(填报陷阱)

1. **专业组分组逻辑**(基于 2024 数据):
   - **(107)/(108)/(109) 中段工科组**:6,800-7,100 名 / 含矿冶 / 材料 / 自动化 / 机械等
   - **(110) 顶级组**:899 名(湘雅八年制 / 部分核心 CS)
   - **(101)-(106) 提前批 / 国家专项 / 强基**:分数特殊
2. **服从调剂关键提醒**:
   - 中段组(107)-(109) 可能调到**矿业 / 冶金 / 材料**等"全国第 1 但行业冷门"的方向
   - 矿冶 = 进中铁 / 中冶 / 宝武等央企(稳定但要去工地)
   - 材料 = 全国前 5 但**生化环材天坑,要读博**
3. **湘雅医学院冲档要慎重**:
   - 八年制录取要全省前 1,000-1,700 名
   - 5 年制(普通临床)要全省前 3,000-5,000 名
   - **冲不到八年制就退而求其次 5 年制 + 规培,8+ 年长周期,普通家庭撑不起**
4. **中南 vs 湖大 vs 国防科大**:
   - **学医 / 矿冶 / 材料 / 交通 → 中南**
   - **学经管 / 设计 / 文科 → 湖大**
   - **当军人 / 包分配 → 国防科大**(政审过关)

## 毕业去向(2024 数据,粗略)

- **留湖南就业**:约 30%(主要进湖南本地大企业 + 中铁中冶湖南分公司)
- **出省(广深 / 长三角)就业**:约 50%(医学 / 工科出省较多)
- **考研 / 读博**:约 30-35%(材料 / 化学等读研率高,因为本科出路差)
- **进央企**:约 25%(中铁 / 中冶 / 宝武 / 中核 等矿冶交通央企对口)

## 跟同档院校对比

| 维度 | 中南 | 湖大 | 武大 |
|---|---|---|---|
| 综合排名 | Top 30 | Top 30 | Top 10 |
| 工科 | **强**(矿冶/材料/交通) | 强(机械/化学) | 弱 |
| 医学 | **湘雅顶级** | 无 | 较强(口腔) |
| 经管 | 一般 | **更强** | 强 |
| 文科 | 弱 | 强 | **更强** |
| 男女比 | 男多(理工医) | 平衡 | 平衡 |

**简单结论**:湖南考生学医 / 矿冶 / 工科 → 中南;学经管 / 文科 → 湖大;分够武大且想综合体验 → 武大(出省)。
