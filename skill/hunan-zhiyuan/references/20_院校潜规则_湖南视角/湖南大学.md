# 湖南大学(湖大)— 985 文工经

## 一句话定位

**985 千年学府(岳麓书院)**,综合排名 Top 30,**机械 / 设计 / 经管 / 化学 强势**。湖南考生学经管 / 设计 / 文科的第一选择。

## 性价比专业

- **化学化工**:全国前 10 但**生化环材天坑**,本科要读研
- **新闻传播**:湖大新闻有底子但**新闻行业本身凋零**(参考 _shared/汉语言_新闻.md)
- **历史 / 哲学**:文科底蕴足,**适合考研做学术**

## 坑专业(湖大里相对弱)

- **医学**:**湖大没医学院**,学医必须避开湖大,选中南湘雅
- **矿冶 / 材料**:湖大不强,选中南
- **CS**:湖大 CS 全国 30 名左右,**比中南 CS 弱**;**双非 CS 跑湖大 CS 是浪费 985 牌子**(因为湖大 CS 不是真顶级)
- **工商管理 / 会计学(双非视角)**:虽然湖大经管全国前列,但**985 经管出来不一定就是金融精英** — 头部金融要清北复交(985 经管去银行柜台仍很常见)

## 关键提醒(填报陷阱)

1. **专业组分组逻辑**(基于 2024 数据):
   - **(106)-(108) 主流组**(7,326-7,431 名):机械 / 化学 / 工科主体
   - **(105) 低分组**(13,216 名):**含工商管理 / 经济类 / 部分文科**,**慎选**(可能水专业混杂)
   - **(A02) 提前批 / 强基组**(2025):特殊招生
2. **服从调剂关键提醒**:
   - 主流组内可能含**化学 / 生物 / 材料**等天坑组
   - **(105) 低分组慎勾服从** — 可能进入工商管理 / 信息管理等水专业
3. **湖大 vs 中南**:
   - 学医 / 矿冶 / 材料 / 工科核心 → 中南
   - 学经管 / 设计 / 化学 / 文科 → 湖大
   - 综合体验 + 校园文化(岳麓书院)→ 湖大
4. **岳麓书院光环 ≠ 综合实力**:湖大有"千年学府"招牌但**综合排名不高于中南**

## 毕业去向(2024 数据,粗略)

- **留湖南就业**:约 30%
- **出省(广深 / 上海 / 北京)就业**:约 50-55%(经管 / 设计 / 化学专业出省较多)
- **考研 / 读博**:约 25-30%
- **出国**:约 10%(湖大经管 + 设计 出国率较高)
- **进央企 / 国企**:约 15-20%
