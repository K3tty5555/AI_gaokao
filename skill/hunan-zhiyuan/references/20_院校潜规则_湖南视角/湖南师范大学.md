# 湖南师范大学(湖师大)— 211 师范第一(中南六省第二)

## 一句话定位

**中南六省师范老二**(仅次于华师),教育部直属六大师范之一(待定;以政策文本为准),"湖南本省师范主流招收"。**想做老师的湖南考生首选**,但**非师范专业别来**。

## 公费师范生(湖师大特色)

**注意**:湖师大严格说**不在教育部直属六大师范**(那六所是北师大 / 华师大 / 华中师范 / 东北师范 / 陕西师范 / 西南大学),**所以"教育部公费师范"指标少**。

但**湖南省公费师范生政策**给了湖师大大量名额:
- 学费 + 住宿费 全免
- 毕业后 6 年回**湖南省内服务**(乡镇或县级中学为主)
- **录取分较高**(湖南物理类约 9,000-13,000 名)
- **是湖南普通家庭跨阶级最稳的路径**(零成本上 211 + 编制)

## 性价比专业

- **教育学 / 心理学**:全国前 30,**适合读研 + 进高校教育系统 / 出版社**
- **公费师范汉语言**:湖南本地编制 + 留汉就业 + 考公友好

## 坑专业(湖师大里相对弱)

- **法学 / 经济学 / 金融**:湖师大非财经法律强校,**学法学财经 选湘潭大学(法学)或 中南/湖大(财经)**
- **计算机 / 工程类**:**师范院校学非师范计算机是怪胎**,出来跟双非一本 CS 没差
- **教育技术学 / 数学与应用数学(非师范)**:**听起来像师范但不是公费**,**当心被忽悠**

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生**:
   - 名字带"师范"且**提前批录取** → 公费师范(免学费 + 编制)
   - 名字带"师范"但**普通批录取** → 普通师范(自费 + 自找工作)
   - **千万分清,差几十万学费**
2. **公费师范的 "原籍服务 6 年" 是硬约束**:**违约要赔学费 + 写违约记录**,影响以后考公考编
3. **湖师大 vs 华师**:
   - 学费 + 编制都行 + 留湖南 → 湖师大
   - 想去全国发展 / 985 牌子 → 华师(同档 211 但教育部直属六大)
4. **服从调剂**:湖师大物理类组内可能含心理学、教育技术等冷门,被调剂能否接受?

## 毕业去向(2024 数据,粗略)

- **公费师范生**:100% 湖南省内中小学编制(乡镇 / 县级 / 部分地级市)
- **普通师范生**:**约 50-60% 通过省考 / 市考考编**,约 25-30% 进民办学校 / 培训机构,约 15-20% 改行
- **非师范类(湖师大里弱项)**:**约 40% 留湖南**,**约 60% 出省**(但就业不如纯综合 211)

## 跟同档院校对比

| 维度 | 湖师大 | 华师 | 北师 |
|---|---|---|---|
| 综合排名 | 211 | 211 | **985** |
| 师范实力 | 中南六省第二 | **华中师范第一** | 全国第 1 |
| 留湖南就业 | **极高** | 一般 | 一般 |
| 公费师范名额 | 多(湖南省内) | 多(教育部直属) | 多 |

**简单结论**:湖南考生想做老师 → 湖师大(留湘);分够 985 想做老师选北师(全国通用);跨省发展可考虑华师 / 西南大学。
