# 湖南 3+1+2 高考政策(本地版)

## 核心结论

**湖南 2018 年加入新高考第三批,2021 年高考首届实行 3+1+2**(跟湖北 / 河北 / 辽宁 / 福建 / 广东 / 重庆 / 江苏 同批)。**总体规则跟湖北一致**,但有几个**湖南特定**细节要注意 —— 包括**长沙四大名校(长郡 / 雅礼 / 师大附中 / 长沙一中)的强校效应**、**国家专项 + 民族优惠 在湘西 / 怀化 / 邵阳 / 永州 山区** 的额外影响、**湖南中职考生新高考路径** 等。

## 关键事实

### 考试结构(同湖北 / 全国新高考第三批)
- **3 = 语文 + 数学 + 英语**(全国卷 II,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(关键!!)
- **物理类**(类型代号 2073)— 选物理为首选的考生
- **历史类**(类型代号 2074)— 选历史为首选的考生
- **两类完全分开排名、分开录取**,**互不影响**
- 湖南物理类报考人数 ≈ 60-65%,历史类 ≈ 35-40%(**湖南历史类比例比湖北高**)
- **物理类专业选择面广(约 96%);历史类专业选择面窄(约 50%)**

### 12 种选科组合
跟湖北一致(物 + 化生 / 物 + 化政 / 物 + 化地 / 物 + 生政 / 物 + 生地 / 物 + 政地 / 史 + 化生 / 史 + 化政 / 史 + 化地 / 史 + 生政 / 史 + 生地 / 史 + 政地)。

| 选科组合 | 可报专业范围 | 评价 |
|---|---|---|
| 物 + 化 + 生 | **97% 专业**,理工医全能 | 万金油,首选 |
| 物 + 化 + 地 | 96% 专业,工科+地学 | 优秀 |
| 物 + 化 + 政 | 96% 专业 + 考公友好 | 平衡型 |
| 物 + 生 + 政 | 90% 专业,但医学受限(部分医学要求"再选化学") | 一般 |
| 物 + 生 + 地 | 89% 专业 | 一般 |
| 物 + 政 + 地 | 80% 专业(理工受限,文理混报) | 慎重 |
| 史 + 政 + 地 | **传统文综组合**,可报 50%+ 专业 | 文科首选 |
| 史 + 政 + 生 | 文史 + 部分医学 | 偏文 |
| 史 + 政 + 化 | 罕见组合 | 慎重 |
| 史 + 化 + 地 | 罕见组合 | 慎重 |
| 史 + 化 + 生 | 罕见组合 | 慎重 |
| 史 + 生 + 地 | 罕见组合 | 慎重 |

### 再选科目专业限制(2024 年最新)
- **再选必含化学**:绝大多数医学(临床、口腔、护理)、化学、化工、材料、生物科学等
- **再选必含生物**:部分医学(生命科学方向)、生物、农林牧、动植物相关
- **再选必含化学和生物**(双选):临床医学、口腔医学的部分院校(湘雅医学院 5 年制临床要求物 + 化 + 生)
- **再选必含政治**:马克思主义理论、政治学、国际关系、思想政治教育、部分公安院校(**湖南警察学院多数岗位要求政治**)
- **再选必含地理**:地理科学、地质学(部分院校)
- **绝大多数文史经管法学**:再选不限

### 院校专业组(同湖北)
- 不再按"学校"投档,**按"院校专业组"投档**
- 一所学校可有多个专业组
- 同一学校的不同专业组独立投档
- **服从调剂只在本专业组内调剂**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量(湖南特定!)
- **湖南本科批 45 个志愿**(每个 = 1 个院校专业组)
- **专科批同样 45 个**
- 跟湖北一致(均为 45 个)
- 每个志愿组内可选 1-6 个具体专业 + 是否服从调剂

### 一分一段表(湖南位次)
- 湖南教育考试院每年发布
- 从掌上高考 / dxsbb / 各教育媒体可获取
- **位次比分数更准**(同湖北原则)
- **报志愿应该看位次,不是看分数**(这是新手家长最常踩的坑)

### 投档与录取流程
1. 按位次投档:位次靠前的考生先选自己的 45 个志愿
2. 系统按 1-45 顺序检索投档:**第一个能投到的志愿组,投档**
3. 投档后,本志愿组内按专业最低分录取(如果没录取上具体专业,**服从调剂会被调到本组其他未录满专业**)
4. 不服从调剂 + 没录取上 → **退档,本批次落榜**(滑档)

| 2025 | 405 | 466 | 432 | 488 |

**湖南 vs. 湖北 批次线对比(2024)**:
- 物理本科:湖南 422 / 湖北 437(湖南更低 15 分)
- 历史本科:湖南 438 / 湖北 432(几乎一样)
- 物理特控:湖南 481 / 湖北 525(湖南更低 44 分!**湖南物理类竞争比湖北轻**)

**关键含义**:**同样分数在湖南比在湖北能上更好的学校**(尤其物理类)。例:湖南物理 580 分 → 全省 23180 名;湖北物理 580 分 → 全省 28233 名(差 5000 名)。

## 湖南独家:长沙四大名校 + 高中分层

湖南家长报志愿前要先理解一个现实:**湖南高中教育资源高度向长沙集中**。

### 第一梯队(长沙四大名校)
- **长郡中学(长沙)** — 长郡系包含长郡本部 + 长郡梅溪湖 + 长郡双语 + 长郡中学云麓校区 等
- **雅礼中学(长沙)** — 雅礼系包含雅礼本部 + 雅礼洋湖 + 雅礼天心 等
- **湖南师大附中(长沙)** — 师大附系包含师大附中本部 + 师大附中梅溪湖 等
- **长沙市第一中学** — 老牌名校

**特点**:
- **每年北清录取 + 985 录取占湖南全省的 60%+**
- **顶级生源**(尖子生集中)+ 顶级师资
- 学费 / 择校费高(本部约 2-3w/年,分校略低)

### 第二梯队(湖南各地市重点)
- **岳阳市一中、岳阳县一中、平江县一中**(岳阳)
- **常德一中、桃源县一中、石门一中**(常德)
- **株洲二中、株洲一中**(株洲)
- **湘潭一中**(湘潭)
- **衡阳市八中、衡阳市一中**(衡阳)
- **邵阳市一中、邵阳市二中**(邵阳)
- **郴州市一中**(郴州)
- **怀化一中**(怀化)
- **吉首一中**(湘西州)

### 第三梯队(地市普通中学 / 县中)
- 湖南各县城重点高中
- 教育资源相对有限,但**国家专项 + 高校专项 在县中考生中分配较多**

### 民办 / 国际高中
- **长沙麓山国际(湖大附中)、长沙南雅中学** 等
- **国际部 / AP / IB 等出国路径**:主要服务长沙中产以上家庭

**对志愿填报的含义**:
- **长沙四大名校的孩子分数 + 信息差** 通常远超县中孩子
- **县中孩子**可能不知道国家专项 / 民族优惠 / 公费师范 等隐藏路径
- agent 必须问清楚高中,**因为这影响"信息差校正"的强度**

## 国家专项 / 高校专项 / 民族优惠(湖南独家细则)

### 国家专项计划
- **湖南省定的专项目录县**(贫困 / 农村县,湘西州 8 县 + 邵阳 / 怀化 / 永州部分县 + 张家界部分县)
- **985 / 211 在专项内招生**:**比统招分低 20-30 分**
- **报名条件**:户籍 + 学籍 + 农村户口
- **服务要求**:部分专项有"服务期满"约定(如医学 + 师范专项要求回基层)

### 高校专项计划(自强计划 / 圆梦计划等)
- **985 高校面向贫困地区** 单独招生
- 中南 / 湖大 / 国防科大 都有湖南专项指标
- **要参加高校的"专项考核"**(笔试 + 面试)
- 录取分比统招低,但有专门审核

### 少数民族加分(湖南本省)
- **湘西州 8 县**(吉首 / 凤凰 / 花垣 / 保靖 / 古丈 / 永顺 / 龙山 / 泸溪)的土家族、苗族、白族 等少数民族考生:**加 5 分**(部分校加 10 分)
- **张家界 / 怀化部分县** 类似政策
- **加分仅在录取时使用**,不影响一本分数线判断
- **少数民族考生报民族院校(如吉首大学民族班 / 中南民族 / 西南民族 / 中央民族)** 可有降分

### 公费师范(湖南省级)
- **湖师大 + 部分湖南本省高校**有公费师范名额
- **录取分约全省物理类 1.0-1.3 万 / 历史类 0.4-0.6 万 名**(比统招高,因为编制吸引力)
- **6 年回原市州服务期**,部分名额回乡镇

## 典型 case(供 agent 引用)

### Case A(选科正确)
- 长郡中学考生(物化生)→ 高三时进湘雅医学院 5 年制临床医学
- 选科组合允许她报临床医学(必选化学 + 部分院校要求生物)

### Case B(选科踩坑)
- 长沙某中学考生选物 + 政 + 地
- 高三时想报临床医学发现**无法报考**(必须再选化学)
- 只能改报其他专业,**留下遗憾**

### Case C(选科聪明)
- 雅礼中学考生选物 + 化 + 政
- 高三同时保留了**理工(化学)+ 考公(政治)+ 警察(政治)** 三条出路
- **选科最灵活**

### Case D(填报踩坑)
- 长沙考生 600 分物理类
- 把湖大某专业组放第 1 志愿,但**没看清楚组内最低分专业是"信息管理"**
- 被投档后,**被调剂到信息管理**,大学 4 年抑郁

### Case E(湘西国家专项)
- 湘西州永顺县考生(土家族,580 分物理类)
- 国家专项 + 民族加分 → 实际位次提升 → 进中南大学
- **如果走统招:全省 23000 名,无戏中南**;**走专项 + 加分:实际录取相当于全省 18000 名**

### Case F(高中影响信息差)
- 邵阳某县中考生 615 分历史类(全省 1500 名,十分罕见)
- 县中老师不知道"湘大法学"的双非顶配价值
- 家长只听"中南 / 湖大 = 985 = 好"
- **最后报中南文学(中南文学是边缘),浪费分数**
- **如果在长郡 / 雅礼这种长沙四大名校,老师会推荐"湘大法学韶峰班 + 强基"路径**

## 易错认知(agent 要纠正用户的)

- **"还是按文科 / 理科算的吧"** — 严重过时。湖南 2021 年起就没文理分科了,**只有物理类和历史类**
- **"3+1+2 跟老高考差不多,只是叫法不同"** — 错。**录取规则不同,投档单位不同,服从调剂规则不同**
- **"45 个志愿都是学校,选哪个学校都行"** — 严重错误。**45 个志愿是 45 个"院校专业组"**
- **"服从调剂会被调到本校其他专业"** — 错。**只在本专业组内调剂**,不会跨组
- **"湖南本科线 422 比湖北 437 低 15 分,是说湖南简单 15 分?"** — 错。**两省试卷不同 + 考生数不同 + 招生名额不同**,不能直接对比
- **"专业最低分就是录取最低分"** — 半对。**整个组的最低分(投档线)≤ 组内最低分专业的录取分**
- **"国家专项就是降低分数,什么人都能用"** — 严重错误。**必须户籍 + 学籍 + 父母农村户口 三件套都满足才能用**;**长沙城市户口考生不能用国家专项**
- **"少数民族加分都是 5 分,所有人一样"** — 半错。**湘西州 8 县汉族不加分**;**少数民族在不同情景下加分 5-10 分**;**有的校(如吉首大学民族班)是降分而不是加分,机制不同**
- **"公费师范一辈子要在乡镇"** — 错。**6 年服务期,期满可以考公考研 + 跨省调动有限制但省内可以调**
- **"长郡 / 雅礼孩子分数高就一定上 985"** — 半对。长沙四大名校尖子生竞争激烈,中下游学生压力比县中大;县中尖子生因为竞争小反而能拿专项

## 关键提醒(agent 必须强调)

**新高考最容易被忽视的事实**:
1. **45 个志愿组的填报顺序**很重要,要"冲稳保"梯度排列
2. **服从调剂**通常推荐勾选(不勾就有滑档风险),**但要确认本专业组内你能接受的最差专业**
3. **看位次而不是分数**(分数受当年卷子难度影响很大)
4. **再选科目限制**(必选化学/必选政治等)是硬约束,**填报前一定核对每个目标专业**
5. **湖南家长不要拿湖北 / 江西 / 河南分数线对照**(虽然政策一样,但分数体系完全独立)

**湖南独家提醒**:
1. **湘西 / 怀化 / 邵阳 / 永州 / 张家界 农村户籍考生** 一定要先查"是否在国家专项目录县" + "是否少数民族"
2. **想做老师的考生** 一定要分清"公费师范 vs 普通师范" + "本校提前批 vs 普通批"
3. **想做警察的考生** 一定要选"政治"作为再选科目
4. **想报国防科大的考生** 一定要先过县武装部预审

**新高考的"院校专业组"机制让填报变得更精细,也更容易踩坑**。**家长没经历过新高考,普遍跟不上规则**。这正是 agent 价值的核心 —— 把这些规则用通俗话讲明白。
