# 湖南 3+1+2 高考政策

## 核心结论

**湖南 2018 年加入新高考第三批,2021 年高考首届实行 3+1+2**(跟湖北 / 河北 / 辽宁 / 福建 / 广东 / 重庆 / 江苏 同批)。**总体规则跟湖北一致**,但有几个**湖南特定**细节要注意。

## 关键事实

### 考试结构(同湖北)
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类**(类型代号 2073)— 选物理为首选
- **历史类**(类型代号 2074)— 选历史为首选
- **两类完全分开排名、分开录取**
- 湖南物理类约 60-65%,历史类约 35-40%(比湖北历史类比例略高)

### 院校专业组(同湖北)
- 不再按"学校"投档,**按"院校专业组"投档**
- 一所学校可有多个专业组
- 同一学校的不同专业组独立投档
- **服从调剂只在本专业组内调剂**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量(湖南特定!)
- **湖南本科批 45 个志愿**(每个 = 1 个院校专业组)
- **专科批同样 45 个**
- 跟湖北一致(均为 45 个)
- 每个志愿组内可选 1-6 个具体专业 + 是否服从调剂

### 一分一段表(湖南位次)
- 湖南教育考试院每年发布
- 从掌上高考 / dxsbb / 各教育媒体可获取
- **位次比分数更准**(同湖北原则)

### 12 种选科组合
跟湖北一致(物 + 化生 / 物 + 化政 / 物 + 化地 / 物 + 生政 / 物 + 生地 / 物 + 政地 / 史 + 化生 / 史 + 化政 / 史 + 化地 / 史 + 生政 / 史 + 生地 / 史 + 政地)。

可报专业范围参考详见 `_shared/references/00_核心方法论/采集_rubric.md` L1 单科分数判断。

## 湖南特定的批次线(与湖北对比)

| 年份 | 物理本科 | 物理特控 | 历史本科 | 历史特控 |
|---|---|---|---|---|
| 2021 | 434 | 504 | 466 | 521 |
| 2022 | 414 | 488 | 451 | 507 |
| 2023 | 415 | 481 | 428 | 503 |
| 2024 | 422 | 481 | 438 | 496 |
| 2025 | 405 | 466 | 432 | 488 |

**湖南 vs. 湖北 批次线对比(2024)**:
- 物理本科:湖南 422 / 湖北 437(湖南更低 15 分)
- 历史本科:湖南 438 / 湖北 432(几乎一样)
- 物理特控:湖南 481 / 湖北 525(湖南更低 44 分!**湖南物理类竞争比湖北轻**)
- 历史特控:湖南 496 / 湖北 530(湖南低 34 分)

**关键含义**:**同样分数在湖南比在湖北能上更好的学校**(尤其物理类)。例:湖南物理 580 分 → 全省 23180 名;湖北物理 580 分 → 全省 28233 名(差 5000 名)。

## 湖南本省高考考生数(对比湖北)

| 年份 | 湖南物理 | 湖南历史 | 湖南合计 | 湖北物理 | 湖北历史 |
|---|---|---|---|---|---|
| 2024 | ~31 万 | ~13 万 | ~44 万 | ~25 万 | ~10 万 |

**湖南考生数比湖北多约 25%**,但**湖南本省 985/211 名额(中南 + 湖大 + 国防科大 + 湖师大)总数比湖北少**(湖北有武大/华科双 985 + 5 个 211)。**结果:湖南考生上 985/211 比湖北难**。

## 决策映射(供 agent 用)

| 考生情况 | 选科建议 |
|---|---|
| 物化生 / 物化地 | 几乎不限,可报理工医农林全部专业 ✓ |
| 物化政 | 理工 + 考公友好,平衡型 ✓ |
| 史政地 | 文史考公主流路径 ✓ |
| 想读临床医学(湘雅 / 南华)| **必选化学**(部分院校还要生物) |
| 想读师范(湖师大公费) | 选你想教的学科对应科目(教数学物理就选物理,教语文就史政地)|
| 想报警察 / 公安(湖南警察学院 等)| **必选政治**(几乎所有公安院校要求) |
| 想报国防科大军校 | 物化生 / 物化地 优先(理工要求高) |
| 想读地质 / 地理 | 必选地理 |

## 易错认知(agent 要纠正用户的)

- **"还是按文科 / 理科算的吧"** — 严重过时。湖南 2021 年起就没文理分科了,**只有物理类和历史类**
- **"3+1+2 跟老高考差不多,只是叫法不同"** — 错。**录取规则不同,投档单位不同,服从调剂规则不同**
- **"45 个志愿都是学校,选哪个学校都行"** — 严重错误。**45 个志愿是 45 个"院校专业组"**
- **"服从调剂会被调到本校其他专业"** — 错。**只在本专业组内调剂**,不会跨组
- **"湖南本科线 422 比湖北 437 低 15 分,是说湖南简单 15 分?"** — 错。**两省试卷不同 + 考生数不同 + 招生名额不同**,不能直接对比
- **"专业最低分就是录取最低分"** — 半对。**整个组的最低分(投档线)≤ 组内最低分专业的录取分**

---

## 关键提醒(agent 必须强调)

1. **45 个志愿组的填报顺序**很重要,要"冲稳保"梯度排列
2. **服从调剂**通常推荐勾选,**但要确认本专业组内你能接受的最差专业**
3. **看位次而不是分数**(分数受当年卷子难度影响很大)
4. **再选科目限制**(必选化学/必选政治等)是硬约束,**填报前一定核对每个目标专业**
5. **湖南家长不要拿湖北分数线对照**(虽然政策一样,但分数体系完全独立)
