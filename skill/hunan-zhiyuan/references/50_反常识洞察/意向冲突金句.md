# 用户意向冲突 — Reality Check 金句库(湖南视角)

很多家长 / 考生有具体的意向("想上中南"、"非长沙不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

**湖南独家原则**:
- **湖湘文化里的"硬气"经常体现为"非中南 / 非湖大不去"** —— 但**长株潭一体化 + 湘大法学 + 长理电气 + 湖师大公费师范** 这些非 985 路径,在湖南本地就业市场比"中南弱专业"更稳
- **湘西 / 怀化 / 邵阳 农村家庭的"非 985 不去"很常见** —— 但他们不知道**"国家专项 + 民族优惠 + 公费师范" 三件套** 才是真正的跨阶级路径

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 580 分要中南主流组 / 600 分要湘雅八年制)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 / 双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(湖南 580 分,意向中南)**:
> "中南主流工科组在湖南物理类 4500-7500 名。你 23000 名,差 1.5 万名,**中南没戏**。
>
> 但你能上**湘潭大学法学 / 长沙理工电气 / 湖南农大动物医学** —— 这三所留湘就业,**国企 / 体制内招聘里跟中南弱专业(管理类、文科边缘)校友地位差不多**(都是'湖南本省 双非/211 + 留湘同档')。
>
> 而且**湘大法学全国前 30,长理电气进国网湖南**,这俩的'专业出路'比中南弱专业强。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(湖南理工科 + 普通家庭)**:
> "中南大学你 622 能擦 — 但只能进材料 / 矿冶 / 化工组(中南中段工科)。**985 牌子 + 矿区 / 钢厂工作 + 生化环材** = 三重坑,普通家庭不一定撑得住前 5 年的工地生活。
>
> 同分能上的**长沙理工电气(进国网湖南各地市公司)** 出来对口程度更高,**5 年后年薪比中南材料毕业生稳定**。冲中南留一个心理慰藉位即可。
>
> 但!如果你父母认可**'男生先苦 5 年工地,后享 20 年央企铁饭碗'**,那中南矿冶 / 冶金(全国第 1/2)是真的香,只是要先想清楚。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [中南湘雅八年制 / 北医])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(湖南普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 8-12k**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**中南湘雅八年制 / 5 年制临床**,长期天花板高(湘雅是中国医学史招牌)。
>
> 撑不起 → 建议:
> - **南华大学临床(衡阳)** = 5+3 路径,毕业进湖南二级医院 / 县医院,**降一档但能走通**
> - **南华 / 湖南医药学院 医学影像 / 检验技术** = 4 年本科直接进医院技术岗,起薪 6-9k,**早 3-4 年挣钱**
> - **湖南医药学院(怀化)护理本科** = 4 年本科 + 编制
>
> 或者放弃医学走 CS / 会计这种本科直接挣钱的赛道。"

---

### 模式 D:意向城市 vs 院校层次 — "非长沙不去"

**特征**:用户只想留某个城市("非长沙不去" / "非湖南不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留长沙没意义,要去西工大),**要灵活退一步**。"

**真实案例(湖南考生 + 法学方向 + 600 分历史)**:
> "你只留长沙,这位次 5500,中南法学 / 湖大法学主线刚刚够擦边(中南法学不是强项可能能进,湖大法学要冲)。
>
> **留湘最稳路径**:**湘潭大学法学(双非但全国前 30 + 法考通过率高)** + 父母资源 + 法考 → 长沙律所 / 湖南省直 / 长沙市直 公务员路径,**不输于中南法学的弱专业组合**。
>
> 不要为了'外省 985 牌子'去东北财经 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 户口没了**,综合不划算。"

**真实案例(长沙籍 + 想做记者 + 590 分历史)**:
> "你想做记者 + 想留长沙 → 默认选项是中南或湖大新闻冲芒果系。
>
> 但!**芒果系编制岗近 5 年大幅压缩**,新员工 90% 是合同制,**进了不等于'考公编制'**。
>
> 真心想做内容 → **湖师大公费师范汉语言** 是更稳的隐藏路径(教师编制 + 业余写公众号 / 短视频也行,很多名师业余做自媒体反而做得好)。
>
> 真心想拼传媒 + 接受合同制 → 中南或湖大新闻 + 大量长沙广电实习。"

---

### 模式 E(湖南独家):**湘西 / 山区家庭 + 想冲 985 出去**

**特征**:湘西州 / 张家界 / 怀化 / 邵阳 / 永州 山区考生 + 农村家庭,意向"出湖南 985 = 跨阶级"。

**金句模板**:
> "你想出湖南冲 985,我理解 — 但你**不知道湖南本省给你保留的'国家专项 + 民族优惠 + 公费师范' 三件套**,这些组合可能比'强冲外省 985 弱专业'更香。
>
> 让我先问你 3 个问题:
> 1. 你是不是少数民族(土家族 / 苗族 / 侗族 / 白族 / 瑶族)?
> 2. 你户籍县是不是国家专项目录县(湘西州 8 县 / 怀化部分县 / 邵阳部分县 / 永州部分县)?
> 3. 你愿不愿意服务期满回原县(公费师范 6 年)?
>
> 如果答案是 yes:**国家专项 + 民族加分 → 中南 / 湖大 / 985 名校** 比统招分低 20-30 分;**或公费师范 → 4 年免学费 + 编制 + 回原县**。
>
> 这俩任何一个,都比'强冲外省 985 弱专业 + 自费 + 毕业回老家失业' 稳。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 中南大学 / 想学医 / 想留长沙 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**湖南独家提醒**:湖南家长经常陷入两个极端 —— 一种是**"非中南 / 湖大 / 国防科大不去"**(过度追 985 牌子,忽视专业坑);另一种是**"反正在湖南考公,差不多的学校都行"**(过度依赖体制兜底,忽视专业适配)。**两个极端都要 reality check**。
