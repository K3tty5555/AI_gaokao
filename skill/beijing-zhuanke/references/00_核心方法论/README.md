# 北京专科 skill 核心方法论 — 路线图

## 北京专科 vs 全国专科:三个根本不同

写这个 skill 之前先把这件事钉死,**不要照搬湖北 / 湖南专科逻辑**。

### 1. 单一城市 vs 全省视野
湖北专科可以分"留武汉 / 留宜昌 / 留地市";北京专科**没有这个维度** —— 全市就一个北京。
所以北京专科的核心冲突不是"在省内哪个城市读",而是 **"北京 vs 出京"**,而对京籍生来说出京基本等于自废武功。

### 2. 户口 = 隐性资产
湖北 / 湖南专科:学校 + 专业 + 专升本 = 三大决策变量。
北京专科:**户口 + 留京岗位 + 专升本** = 三大决策变量。

agent 第一句必须问"是不是京籍"。京籍 / 非京籍走的是两条完全不同的路径,推荐策略不能混。

### 3. 行业出口高度集中在央国企总部
全国专科 → 大量进民营 / 二线央企地方分公司。
北京专科 → 进的是**央企总部底层岗 / 北京地铁 / 国网北京 / 北京公交集团 / 协和等三甲基础岗**,这些单位在外省专科生眼里是"高不可攀",但对北京公办专科生是**校招主战场**。

这是北京专科最大的隐性红利,也是 agent 要反复强调的。

## 风格约束

- **大白话**:不写"赋能 / 价值闭环 / 一站式"这种黑话
- **Case-specific**:每个 reference 必须有 2-3 个具体 case(虚构但合理),不要堆抽象原则
- **本省视角**:北京独特性优先,不要套湖北逻辑(比如不要写"建议出省去强专科",北京几乎不存在这个选项)
- **不编数字**:招聘人数 / 录取率 / 薪资范围只给"近年来""约""多数情况"等模糊表述,**不编精确数字**
- **不诋毁专科**:北京专科 + 京籍 + 对的行业 = 比外省双非本科还稳的路径,这是事实
