# 辽宁专科 skill 核心方法论(agent 推理总纲)

## 一、辽宁专科 ≠ 普通专科

普通专科决策模型:**专业 + 升学 + 就业**。

辽宁专科决策模型:**专业 + 升学 + 就业 + 留辽 vs 南下 + 父母编制信仰 + 重工业体力底子**。

多出来的几个变量是辽宁本地的"地方引力",不能套用全国通版的专科推荐逻辑。

---

## 二、辽宁专科生的三类典型用户(agent 心里要有画像)

### A. 沈阳 / 大连工人家庭子弟(占比最大)
- 父亲 / 母亲是鞍钢 / 沈飞 / 沈鼓 / 大船 / 抚顺石化 等老国企工人或退休职工
- 家庭月收入 4-8k,有房没存款
- 父母最大的诉求:**孩子也进国企 / 体制内**(怕折腾)
- 推荐路径:**对口国企央企的专科专业**(装备制造 / 电气 / 石化 / 铁路 / 港口)+ **辽宁本地公办专科**
- 最大风险:孩子选了听起来好听但对口率低的专业(国贸 / 行政 / 市场营销)

### B. 锦州 / 营口 / 丹东 / 抚顺 等地级市普通家庭
- 父母是个体户 / 小微企业职工 / 公务员基层
- 家庭月收入 5-10k
- 诉求:**孩子专升本 + 公办本科 + 留辽宁体制内**
- 推荐路径:**升学率高的对口专业**(护理 / 学前 / 机电 / 计算机)+ **辽宁公办专科**
- 最大风险:被"民办专科 + 包过专升本"的招生话术骗

### C. 抚顺 / 鞍山 / 本溪 资源枯竭型城市家庭(经济最弱)
- 父母多在转型期失业 / 待岗 / 提前退休
- 家庭月收入 3-6k,经济压力大
- 诉求:**孩子尽快出来挣钱 + 专科最好别出辽宁(出省花销大)**
- 推荐路径:**就业出口最近的专业**(护理 / 学前 / 机电基础工种)+ **本地或沈阳公办专科**
- 最大风险:贪图"民办包就业"陷阱(学费贵,实际就业还不如公办)

## 三、辽宁专科推荐的 6 条铁律

### 1. **公办优先,民办几乎一票否决**
辽宁民办专科的性价比在全国都属于偏低区间,原因:
- 学费 1.2-1.8 万 / 年 vs 公办 4-6 千 / 年(差 3-4 倍)
- 民办的实习资源、专升本指导、行业人脉**远弱于公办**
- 辽宁本地用人单位(国企 / 央企)对民办认可度低
- 除非考分实在到不了任何公办专科,否则**不要选民办**

### 2. **专业 > 学校(对专科尤其成立)**
本科决策"学校 > 专业"还能成立(平台、校招、人脉),专科**完全反过来**——3 年读完直接看技能 + 资格证 + 行业出口,**专业才是命根子**。

举例:沈阳职业技术学院的国贸专业 vs 辽宁交通高等专科学校的道路桥梁工程,后者就业起薪 + 稳定性碾压前者,即便前者听起来更"综合"。

### 3. **辽宁本地国企央企对口的专业 = 性价比之王**
辽宁专科生最优出路就是**进鞍钢 / 沈飞 / 沈鼓 / 大船 / 大连港 / 营口港 / 抚顺石化 / 中石油辽宁公司 / 沈阳铁路局 / 国网辽宁电力**等本地央企国企。

进这些单位的捷径就是**对口专科**——很多央企国企会指定从某几所专科招技工层。如:
- 沈飞 / 中航工业 → 沈阳航空职业技术学院
- 大船重工 → 渤海船舶职业学院 / 大连海事大学(本科)
- 大连港 → 辽宁省交通高等专科学校 / 大连海洋大学(本科)
- 抚顺石化 / 盘锦石化 → 辽宁石化职业技术学院
- 沈阳铁路局 → 辽宁铁道职业技术学院 / 沈阳铁路职业技术学院

### 4. **东北体制内偏好 → 专升本权重要拉满**
辽宁体制内招聘**普遍卡本科**(部分基层岗放专科,但晋升受限)。

辽宁专科生的"专升本"不是可选项,是**必选项**(除非家里能直接给安排私企岗位)。

→ agent 在 L2 阶段必须优先确认专升本意愿,意愿 ≥3 的同学,推荐时**升学率权重 ≥ 就业率权重**。

### 5. **留辽 vs 南下 — 这个问题要正面问,不能装糊涂**
辽宁专科生有两条主流路径:
- **留辽**:进国企 / 央企 / 体制内,稳定但天花板低,薪资追不上沿海
- **南下**:山东(青岛 / 烟台)、长三角(苏州 / 无锡 / 杭州)、珠三角(广深 / 东莞),民营制造业 / 服务业,起薪高 + 上限高,但脱离家庭支持

**两条路都有人成功也都有人翻车**。agent 不要预判,要把两条路的代价和收益摊开让用户选。

### 6. **避坑专业清单(辽宁版)**
专科里这几类专业**听起来好但实际上对口率低 / 起薪差 / 升学也不好升**:
- **国际贸易 / 工商管理 / 行政管理 / 市场营销 / 电子商务**(典型四不像专业)
- **法律事务**(专科法律基本无对口出路,本科法学都难就业)
- **新闻采编 / 广告设计 / 传媒**(纯吃流量 + 内卷重灾区,不适合专科起步)
- **酒店管理 / 旅游管理**(行业景气度低 + 一线服务岗多)

辽宁版避坑里**特别加一条**:**资源型 / 矿业类专科要慎选**——辽宁的煤炭 / 矿山行业整体在收缩(阜新 / 抚顺 / 本溪 资源枯竭),除非能确定家里有对口资源,否则别选。

## 四、agent 推理总纲(对话顺序)

```
1. 拿分数 + 位次(score_to_rank.py)
2. 确认本批次:专科批
3. 抛出"专升本意愿 1-5"问题(强制)
4. 抛出"留辽 vs 南下"问题(强制)
5. 询问家庭情况(经济 / 父母行业 / 性别)
6. 根据 1-5 + 用户意愿,从 references/10_行业就业/ 选 2-3 个候选方向
7. 从 references/20_院校梯队/ 选对应档位 5-8 所
8. 输出冲 1 / 稳 2 / 保 2 标准卡片
9. 末尾强制免责声明 + 提示查招生办最新文件
```

---

## 五、agent 不要做的事

- 不要默认推荐沈阳 / 大连大城市的专科(锦州 / 营口 / 抚顺 / 鞍山 的对口专科很多场景下出路更好)
- 不要因为家长焦虑就推荐复读(辽宁复读成本不低,且专科 + 专升本是更稳的路)
- 不要把南方专科的逻辑(浙江 / 江苏)硬套辽宁(产业结构 / 民营生态完全不一样)
- 不要承诺"一定能进 XX 国企"(对口专科 ≠ 包就业,要绩点 + 证书 + 实习表现)
- 不要诋毁专科生(专科 + 专升本 + 编制 = 辽宁普通家庭的最稳路径之一)
