# 山东专科 skill 核心方法论

## 一句话定位

**山东专科填报 ≠ 山东本科填报的 mini 版**。两套完全不同的逻辑:本科看学校 + 城市 + 专业;专科看**专业 + 行业出口 + 专升本资格**(尤其山东要看 **3+2 贯通**)。

---

## 推荐时的山东本省视角(必须内化)

### 1. 山东人留鲁心态极强 → 优先山东本省专科
- 山东人(尤其农村 / 工薪家庭)极不愿出省
- 山东本省专科网络认可度高(对口央企齐鲁石化 / 济南铁路局 / 山东港口集团 / 国网山东 都只在本省招专科)
- **跨省读山东专科 = 浪费**(出省读外省专科一般是因为分数到不了山东专科,是次优解)

### 2. 体制内文化极重 → 编制 + 公办优先
- 山东"父母对孩子考公考编是默认期待"(全国前列)
- 公办专科 4.5-6 千 / 年学费,民办 1.2-2 万 / 年
- **民办专科在山东本省社会评价极差**,除非分数实在不够否则不推

### 3. 3+2 专本贯通是山东特产 → 优先抢
- 高考时直接报"3+2 专本贯通"招生计划
- 录取后 3 年专科 + 2 年本科(免考转段)
- **求稳家庭顶配选择**,但分数比同校普通专科高 30-60 分

### 4. 沿海 vs 内陆 山东内部分化
- 沿海(青岛 / 烟台 / 威海 / 日照)= 港口 / 海洋 / 化工(万华)/ 海员 / 报关 红利
- 内陆(济南 / 淄博 / 临沂 / 菏泽 / 济宁)= 电力 / 铁路 / 化工(齐鲁石化)/ 山东能源 / 农业食品 红利
- **不是所有山东学生都该走"海洋路径"**,要看家庭所在地与未来就业地

### 5. 山东特有家庭画像
- 普遍工薪家庭 + 重视编制
- "留鲁"心态 — 出省读书 OK,但工作大概率回山东
- 独生子女男生压力大(山东重男轻女文化犹存,父母对儿子学历期待极高)
- **父母是否体制内**会影响推荐方向(山东"靠关系进编外"的隐性资源仍然存在)

---

## 推荐流程速查

### Step 1:确定专升本意愿(强度 1-5)
- 5 → 优先 3+2 贯通,够不到则选公办专科 + 升学率高的专业
- 3-4 → 平衡升学率 + 就业率
- 1-2 → 直接看就业,选技能强的专业

### Step 2:确定行业方向
| 用户画像 | 推荐方向 |
|---|---|
| 男 + 求稳 + 数物中等 + 内陆 | 电气 / 铁路 / 电力 / 化工 |
| 男 + 接受海上 + 想攒钱 | 航海 / 轮机(高薪赛道) |
| 男 + 接受三班倒 + 化工厂 | 石化 / 化工(齐鲁石化 / 万华) |
| 男 + 留沿海 + 求稳 | 港口运营 / 港口机械 |
| 女 + 求稳定 + 接受医院 | 护理 |
| 女 + 沿海 + 单证报关 | 港口物流 / 报关 |
| 女 + 求编制 + 学前 | 学前教育(待补) |

### Step 3:对应学校梯队
**优先级**:对口行业顶配 > 3+2 贯通 > 综合类双高 > 一般公办 > 民办(基本不推)

详见 `20_院校梯队/山东专科院校梯队.md`。

### Step 4:输出推荐(冲 1 + 稳 2 + 保 2)+ 关键提醒

## 给 agent 的"红线"

- **不承诺一定能录取**
- **不诋毁专科教育**(专科生不是失败者,是另一条路径)
- **不展开"靠关系进编外"的具体操作建议**(只点出这是山东客观现象)
- **涉及 3+2 贯通对接名单 / 专升本对口名单,必须建议用户查山东省教育招生考试院最新文件**(每年微调)
