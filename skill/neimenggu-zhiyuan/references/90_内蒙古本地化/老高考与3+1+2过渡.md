# 内蒙古老高考与 3+1+2 过渡

## 核心结论

**内蒙古 2022 年加入新高考第五批,2025 年高考首届实行 3+1+2**(跟河南、山西、陕西、青海、宁夏、新疆、四川、云南 同批,是全国最晚一批切新高考的省份之一)。**2021-2024 四届还是老高考(文科/理科)**,**2025 起切到物理类/历史类**。**2025 是首届 3+1+2,数据稀薄,只有 1 年新高考录取数据**。**2026 是第二届,大小年风险高**。

## 内蒙古考生基本盘(关键!)

### 1. 高考人口与名校稀缺度

- **2025 年内蒙古高考报名约 18 万人**(全国靠后,比湖北/湖南少一半,跟海南/宁夏/青海同档,自治区体量小)
- **本科上线人数约 7-8 万**,一本上线人数约 2-2.5 万
- **985 录取率约 1.6-1.8%**(全国均值 ~1.6%,内蒙古因体量小 + 985 名额相对宽松,实际录取率略高于均值)
- **211 录取率约 5.5-6%**(全国均值 ~5.5%,内蒙古略高于均值)
- **省内 985 = 0**,**省内 211 = 1 所(内蒙古大学)** —— 名校稀缺度跟广西、河北、贵州、海南、宁夏 同档,**内蒙古考生想留区内读名校的路非常窄,出区战略是常态**
- **关键认知差**:**内蒙古本科分数线偏低**(体量小 + 985 名额相对宽松)→ 家长容易误以为"分数容易上"实际**位次才是真相**,出区竞争看位次不看分数

### 2. 民族多元 + 蒙古族加分(内蒙古特殊性 1)

- **蒙古族占内蒙古总人口约 17-18%**,加上回族、满族、达斡尔族、鄂温克族、鄂伦春族 等,少数民族占比近 20%
- **蒙古族民族加分政策**(以内蒙古招办最新文件为准,常见档位):
  - 牧区、边境旗县蒙古族考生:加 5-10 分
  - 城市蒙古族考生:0-5 分(逐年递减)
  - 回族 / 达斡尔族 / 鄂温克族 / 鄂伦春族 / 满族 等其他少数民族:加 5 分
  - **加分政策仅限内蒙古区内高校录取使用**(部分院校接受,部分不接受;出区院校通常不认可民族加分)
- **agent 必须在 L1-B / L2 阶段问蒙古族 / 回族 / 满族 等身份**,加分会显著影响录取概率
- **国家专项 + 民族班 + 蒙古族预科 是内蒙古牧区 / 旗县少数民族考生的"三重通道"**
- **蒙汉双语教学** 在内师大 / 内民大 等院校有特色专业组,蒙古族考生有独家路径

### 3. 资源型工业产业链(内蒙古特殊性 2)

- **内蒙古是全国资源大区**:**煤炭(鄂尔多斯/锡林郭勒)+ 稀土(包头白云鄂博,全球最大稀土矿)+ 风能(全国第 1 风能资源)+ 光伏(全国前列)+ 煤化工(鄂尔多斯/呼伦贝尔)** 五大产业链
- **央企吸纳通道完整**:**国家能源集团(神华)/ 国家电投 / 中煤集团 / 包钢集团 / 中国稀土集团 / 中广核 / 国电投** 等央企在内蒙古有大量基地,工科生进央企是稳路径
- **内蒙古工业大学 / 内蒙古科技大学(原包头钢铁学院)** 是这条产业链的对口高校
- **起薪 8-15k**(央企内蒙古基地)+ **编制稳定** + **房价低**,普通家庭工科男生最稳路径

### 4. 草原畜牧业产业链(内蒙古特殊性 3)

- **内蒙古是全国畜牧业大区**:**伊利 / 蒙牛 / 鄂尔多斯羊绒 / 小尾羊 / 草原兴发 / 圣牧高科** 等本土千亿级民企
- **草原生态学 / 草学 / 动物科学 / 食品工程**(乳业方向) 是内蒙古独家产业链
- **内蒙古农业大学 / 内蒙古大学** 是这条产业链的对口高校
- **伊利 / 蒙牛** 是全球前 10 乳业巨头,招聘内蒙古本土院校 + 出区农林院校(中农 / 西农 / 华农) 毕业生

### 5. 京津冀辐射(内蒙古特殊性 4)

- **内蒙古东部(赤峰/通辽/兴安盟/呼伦贝尔)毗邻东三省**,西部(乌海/阿拉善)毗邻宁夏甘肃
- **呼和浩特到北京高铁 2 小时**,**包头到北京 3-4 小时**,**鄂尔多斯到北京 1.5 小时(飞)**
- **京津冀工作占内蒙古毕业生留外比例最高**(约 25-30%)
- **留蒙率 50% 左右**,大量去京津 / 沿海 → 出区战略是内蒙古考生的常态
- **agent 推荐时务必把"出京津"作为内蒙古考生的默认就业辐射圈**

## 老高考(2021-2024 届)

### 考试结构

- **3 = 语文 + 数学 + 英语**(全国 II 卷,各 150 分)
- **文综 / 理综**(各 300 分)
  - **文科**:政治 + 历史 + 地理(综合卷)
  - **理科**:物理 + 化学 + 生物(综合卷)
- **总分 = 750 分**

### 文理招生比例

内蒙古文理比约 **3:7**(理科考生远多于文科)。文科考生少但招生名额也少,**文科 211 名次比理科更稀缺**。

### 历年批次线(老高考)

| 年份 | 理科一本 | 理科二本 | 文科一本 | 文科二本 |
|---|---|---|---|---|
| 2021 | 418 | 301 | 488 | 392 |
| 2022 | 427 | 323 | 459 | 366 |
| 2023 | 434 | 333 | 468 | 379 |
| 2024 | 471 | 360 | 478 | 381 |

(数据以内蒙古招办公布为准,可能按年份小幅修正)

## 新高考 3+1+2(2025 届起,首届)

### 实施时间表

- **2022 年秋季**(2022 届高一)入学开始按新高考要求选科
- **2025 年高考**:**首届 3+1+2 高考**(2022 届高一 → 2025 届高三)
- **2026 年高考**:第二届,大小年风险高
- **2027 年高考**:第三届,数据相对稳定

### 考试结构(同湖北/江苏/广西)

- **3 = 语文 + 数学 + 英语**(各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类(2025 起)

- **物理类** — 选物理为首选
- **历史类** — 选历史为首选
- 内蒙古物理类约 65-70%,历史类约 30-35%(沿袭老高考文理比)

### 12 种选科组合

| 物理类 6 种 | 历史类 6 种 |
|---|---|
| 物化生 / 物化政 / 物化地 | 史化生 / 史化政 / 史化地 |
| 物生政 / 物生地 / 物政地 | 史生政 / 史生地 / 史政地 |

### 院校专业组规则

- **按"院校专业组"投档,服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **再选科目限制是硬约束**(必选化学的医学、必选政治的警校等)

### 内蒙古本科批志愿数

**内蒙古本科批 96 个志愿**(2025 起)— 数量是全国最多档之一

- **志愿数多 = 容错率高,但也意味着填报工作量极大**,填报时每个志愿都要走"院校专业组 + 选科限制 + 历年位次"三重 check
- **服从调剂建议默认勾选**(否则一旦组内分数不够会直接滑档)
- 96 个志愿要从冲(15-20)、稳(40-50)、保(30-40)梯度均匀铺开

### 录取数据

- 录取数据库:`data/gaokao_neimenggu_<YYYY>.db`
- **老高考(2021-2024)与 3+1+2(2025+)数据不可直接合并对比**:科类口径不同 / 选科限制不同 / 院校专业组拆分不同
- **2024 → 2025 是断层切换**,跨届预测精度极低

### 跨年使用注意(关键!!)

- **2024 老数据预测 2025 录取** → **慎用**,科类切换 + 院校专业组重新拆分,投档线大幅变动,**这是 2025 届首届考生踩过的最大坑**
- **2025 数据预测 2026 录取** → **数据稀薄(只 1 年)**,**首届大小年风险高**,**以位次定档为主,分数仅供参考**
- **2026+ 起**(数据积累 2 年以上)预测精度才相对稳定
- 推荐时**新高考届只能给 1 年数据(2025),老高考届给 2021-2024 四年数据**,标注精度受限

## 内蒙古考生战略要点

### 1. **出区战略是大多数内蒙古考生的最佳路径**

- 同分情况下,**外区 985/211 平台 > 区内内大某专业组**(内大除外,内大留区是首选)
- 例:内蒙古理科 1.5 万名,**区内只能保内大某专业组**;**出区可冲川大、重大、西交、华中科大、华南理工** 等老牌 985(内蒙古名额相对宽松)
- **首选流向**(基于地理 + 文化 + 政策):
  - **京津冀**(北京一线 985 + 天津大学 / 南开 / 华北电力 / 北京交大,内蒙古学生留京主流)
  - **东北**(吉大 / 哈工大 / 东北大学 / 大连理工,跨边境通勤近)
  - **华北/华中**(北方工大 / 中农 / 北邮 / 北科大 / 武大华科,中部 985 集群)
  - **西北**(西交 / 兰大 / 西北农林,西部 985 群,招生名额相对友好)
  - **沿海**(分数门槛高,平台最高)

### 2. **国家专项 + 地方专项 + 民族班 + 蒙古族预科(内蒙古特殊四通道!)**

- **国家专项**:内蒙古是国家专项重点省份,**农村/牧区户籍考生** 可申请专项,**降分录取顶级 985/211**
- **地方专项**:留区内,内大/内工大/内农大/内师大 等一本招专项
- **民族班**:蒙古族/回族/达斡尔族 等少数民族 + 一定条件 → 单独招生 + 降分录取
- **蒙古族预科班**:蒙古族考生预科 1 年 + 本科 4 年(共 5 年),录取分比正招低 30-50 分
- **农村普通家庭蒙古族考生务必查清四通道资格**,这是内蒙古独有的"四重保险"

### 3. **考研大区 + 双非逆袭路径**

- 内蒙古考研意愿强(尤其留区考生),**内蒙古大学每年考研报名 1 万 +**
- 大量本科双非考生通过**考研逆袭** 到 985/211(走内蒙古本科 → 北方工大 / 北邮 / 北科大 / 中农 985 硕)
- 推荐时若用户考研意愿 ≥ 4,**双非"性价比段"院校** 也可推(内工大 / 内科大 路径)

### 4. **考公考编 + 留蒙职业路径**

- 内蒙古考公人数中等偏上,**体制内吸引力对农村/旗县考生极强**
- **考公友好专业**:汉语言文学 / 法学 / 经济 / 会计 / 计算机 / 财政学 / 行政管理
- **公费师范生**:推荐区内师范(内蒙古师大 / 内蒙古民族大学)+ 教育部直属六大师范
- **留蒙体制内 vs 出区民企**:内蒙古考生最经典的家庭决策矛盾,详见 `内蒙古强校真实地位.md`

### 5. **资源型央企独家路径(重要!!)**

- **国家能源集团(神华)/ 国家电投 / 包钢集团 / 中国稀土集团 / 中广核** 在内蒙古有大量基地,**工科生进央企稳路径**
- **内工大 / 内科大** 毕业生进神华 / 包钢 / 国电 起薪 8-15k + 编制 + 内蒙古房价低 → **普通家庭工科男生最稳路径**
- **2025 起新能源(风电+光伏+储能)+ 煤化工 双产业链** 是内蒙古独家就业景气度上升赛道
- **男生 + 工科 + 进央企不在乎大城市 → 内工大 / 内科大 + 央企内蒙古基地 是隐藏宝藏**

### 6. **草原畜牧业 + 乳业巨头独家路径**

- 内蒙古农业大学(草学/动物科学)对口 **伊利 / 蒙牛 / 鄂尔多斯羊绒 / 小尾羊** 等本土千亿级民企
- **食品科学与工程 + 乳业方向**:伊利 / 蒙牛 招内农大 / 江南大学(乳业全国第一)/ 中农大 起薪 8-12k
- **女生 + 学农林牧 + 不嫌弃畜牧业 + 想稳就业** → 内农大草学 / 食品工程 是性价比之王

### 7. **避免错误认知**

- **❌ "内蒙古分数线低,我家孩子分高"** —— 错。**看位次不看分数**,内蒙古分数线低是因为人少 + 名额相对宽松,跨区看位次才公平
- **❌ "内大跟其他 985 一样好"** —— 错。**内大是 211 不是 985**,内蒙古本省没有 985,内大在区内地位高,但全国排名跟 中游 211 接近(西部计划升级 211)
- **❌ "区内 211 不如出区双非"** —— **半错**。内大在内蒙古本地考公考编 + 央企内蒙古基地招聘有天然优势,出京津双非起薪可能更高,**取决于用户家庭+未来方向**
- **❌ "读完内大就一定留内蒙古"** —— 错。内大学生读研出区 / 工作出京津比例 30%+,**牌子是平台,不是地理绑定**
- **❌ "蒙古族加分政策不重要"** —— 严重错误。**民族加分 + 民族班 + 蒙古族预科 是内蒙古牧区蒙古族考生最值钱的政策资源**,绝不能忽略
