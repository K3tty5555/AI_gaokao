# 用户意向冲突 — Reality Check 金句库(内蒙古版)

很多家长 / 考生有具体的意向("想上内大"、"非北京不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 1 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **内蒙古特殊**:**家长普遍倾向"留蒙"(地理远 + 心理压力大)**,但 reality check 时要客观比较"留蒙双非"vs "出区 211" 的真实 5 年 ROI,**不要被家长的"留蒙情怀"绑架推荐烂专业**

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >1 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 400 分要清北 / 500 分要内大主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985/211 牌子的执念,还是把 [替代校] 当作双非强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(内蒙古 530 分,意向内大)**:
> "内大主流组在内蒙古物理类 8000-12,000 名。你 25,000 名,差 1.3 万名,**内大没戏**(除非用足蒙古族 + 民族班 + 国家专项 四通道叠加)。
>
> 但你能上**内蒙古工业大学(电气 / 化工 / 矿业)+ 内蒙古农业大学(草学 / 食品)+ 内蒙古科技大学(冶金 / 包钢对口)**—— 这三所留蒙就业,**央企内蒙古基地招聘里跟内大冷门组校友地位差不多**(都是'内蒙古本地双非工科 + 留蒙同档')。**而且工科专业进神华 / 国电 / 包钢 / 蒙电网起薪 8-15k,比内大法学应届考公期间(0 收入)实际更稳**。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'211 就是 211',但 **211 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 强势 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(内蒙古工科 + 普通家庭)**:
> "兰州大学你 540 能冲 — 但只能进生命科学 / 草学 / 大气科学。**985 牌子 + 西部偏远 + 生化环材** = 三重坑。
>
> 同分能上的**内蒙古农业大学草学(全国第 1 + 双一流学科)** 出来对口度更高(伊利 / 蒙牛 / 牧场企业直供),**留蒙性价比远超兰大冷门组**。冲兰大留一个心理慰藉位即可。"

**真实案例(内大边缘)**:
> "内大你 17,000 名能擦,但只能进**化学 / 部分生物 / 哲学 / 边缘文科**。
>
> 这些组在内大也不是最强,**留蒙 211 牌子 + 这种冷门组合** = 毕业要么读研(生物去中科院草原所还行)要么转行(哲学去考公,但 211 牌子没用上)。
>
> 同分能上**内蒙古工业大学化工 B+(直供鄂尔多斯煤化工)/ 内蒙古农业大学草学(全国第 1)/ 太原理工煤化工(出区行业 211)** —— 这些专业 5 年后实际收入和编制率超过内大冷门组。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 牧区,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [协和 / 北医 / 同济医])
> - 撑不起 → 走 **[替代短路径]**(如 [内医大医学影像 / 麻醉 / 口腔本科 5 年制 / 蒙医] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 5-8k**(内蒙古略低)。普通工薪父母还要供 8 年。
>
> 撑得起 → 推协和 / 北医,长期天花板高。
>
> 撑不起 → **建议内医大口腔(5 年本科直接进诊所,起薪 6-12k,鄂尔多斯能源型富裕家庭对口腔消费需求高,留蒙开诊所路径)**,或者**内医大医学影像技术(4 年本科,直接进盟市三甲医院技师岗,起薪 5-7k + 编制)**,或者**内医大蒙医(蒙古族学生 + 民族医学红利)**;或者放弃医学走电气 / 化工 / 会计这种本科直接挣钱的赛道。"

**真实案例(普通家庭 + 想做律师)**:
> "你想做律师我懂。但律师本质是 5 年慢启动 — 法学本 + 法考 + 律所助理 5-8k 月薪,**前 3-5 年生活靠家里贴**。你父母能贴吗?
>
> 撑得起 → 推中国政法 / 中南财法 / 内大法学走律师赛道。
>
> 撑不起 → **改推内大法学 + 留蒙法检院** —— 公检法系统编制起薪 6-8k + 编制,虽然不是律所合伙人天花板,**但 5 年内稳挣稳收**;**或者改电气 / 化工 / 会计本科直接进央企**(理科 OK 段)。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非北京不去" / "非呼和浩特不去"),拒绝出区或拒绝出某城。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留呼和浩特没意义,要去西工大),**要灵活退一步**。"

**真实案例(内蒙古考生 + "非呼市不去" + 530 分历史类)**:
> "你只留呼和浩特,这位次 8,000+,内大法学主线全够不上。
>
> **留呼最稳路径**:**内蒙古师范大学汉语言文学(公费师范) / 内蒙古财经大学会计** —— 双非但留呼和浩特考公 / 教师编制率高,**5 年后跟内大冷门组毕业的同年纪同事差距很小**。
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 留蒙就业没优势了**,综合不划算。"

**真实案例(内蒙古考生 + "必须出区到京")**:
> "你只留北京,这位次 6,000(物理类),清北人北航全够不上,北邮 / 北科大 / 北理工边缘可冲。
>
> **留京最稳路径**:**北邮通信(行业 211 顶配)/ 北科大冶金(对口包钢内蒙古基地)/ 北航主流组** —— 这几所毕业留京 IT / 央企总部,**起薪 15-25w + 北京户口资源**,**比内大主流组留蒙起薪 8-12k 高出一档**。
>
> 但你要懂的事:**北京生活成本年 8-12 万**(房租 4-6w + 生活 4-6w),你父母能撑 4 年吗?如果家庭年收入 < 15 万,出区到北京读书 4 年的实际负担 > 留蒙读内大 4 年。**要算这笔账**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") —— 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") —— 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") —— 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") —— 弱化了判断,让家长无从选择
- ❌ 被"留蒙情怀"绑架推烂专业 —— 内蒙古家长普遍倾向留蒙,但留蒙 ≠ 推内大冷门组 / 推双非烂专业;要客观比较"留蒙双非工科进央企" vs "出区 211 主流组"的真实 ROI

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 内大 / 想学医 / 想留呼和浩特 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 内蒙古独有的 3 个高频意向冲突

### 1. "我家孩子是蒙古族,想用足民族优惠" → 不一定一直加分有用

**Reality Check**:
> "蒙古族加分 5-10 分 + 民族班(降 30+) + 蒙古族预科(降 30-50) + 国家专项(降 30-60) = '四通道叠加' —— **真实情况是 4 个通道不能同时叠加,要看具体院校政策**。
>
> 内大 / 内师大 / 中央民族大学 等民族高校能用足 3-4 个通道;但出区 985(北航 / 北科大 等)只认全国统一加分(蒙古族 +5)+ 部分国家专项,不认民族班。
>
> **务实路径**:
> - 留蒙 → 内大 / 内师大 + 民族班 + 国家专项 + 加分 → 隐藏跃迁通道
> - 出区 985 → 只用加分 + 国家专项,不要指望民族班降分太多
>
> **不要被'民族优惠能让我上清北'误导** —— 顶级 985 民族优惠权重极小。"

### 2. "我们家在鄂尔多斯,孩子毕业必须留鄂尔多斯" → 鄂尔多斯就业盘子虽富但窄

**Reality Check**:
> "鄂尔多斯收入水平内蒙古第一,但**就业盘子窄,主要是煤炭 / 煤化工 / 风电 / 光伏 / 矿区配套行业**。
>
> 你孩子要留鄂尔多斯就业,**专业方向选择极有限**:
> - **煤化工 / 化工**(神华煤制油 / 久泰能源 / 中天合创)→ 内蒙古工业大学化工 / 太原理工煤化工 / 中国矿大化工
> - **电气 / 自动化**(国家能源集团 / 大唐火电 / 风电场)→ 华北电力 / 内工大电气
> - **矿业 / 地质**(神华煤炭 / 中煤集团) → 中国矿大 / 内工大矿业
> - **金融 / 财会**(鄂尔多斯本土金融 / 国企财务)→ 内蒙古财经大学 / 中央财经
> - **公务员 / 事业编**(鄂尔多斯各级党政) → 内大法学 / 行政管理
>
> **不要让孩子学'国贸' '工商管理' '电子商务'然后回鄂尔多斯找不到对口工作** —— 鄂尔多斯虽富但产业链单一。"

### 3. "我家孩子是牧区蒙古族,想出去看看" → 反向劝降警示

**Reality Check**:
> "牧区孩子想出区,这是一种正向情怀,但要 reality check:
>
> 1. **从未离开过盟市的孩子,直接去北京 / 西安 / 兰州 / 长春 / 大连读书,前 1-2 年水土不服(气候 + 饮食 + 文化差异)极常见**,休学 / 退学率比城里孩子高
> 2. **家庭抗风险能力**:牧区家庭年收入波动极大(草场 / 雪灾 / 市场价格),出区年生活费 8-10w 是真实负担;不是一定要拒绝,而是**要算账**
> 3. **务实建议**:
>    - 走"出区 985 / 211 国家专项 + 民族班 + 加分" 隐藏跃迁通道(分数比常规批低 30-60 分),且学校在选录时对牧区蒙古族学生有适应性帮助(导师辅导 + 同乡校友网)
>    - **首选地理近 + 同乡多的城市**:北京(中央民族大学 / 北科大 / 北邮)+ 西安(西交大 / 西北农林)+ 长春(吉大)+ 大连(大连理工)→ 这些城市有内蒙古同乡会 + 蒙古族留学生群体支持
>    - **慎选南方城市**(广州 / 深圳 / 厦门 / 上海)→ 内蒙古牧区孩子文化适应难度大 + 家长出行成本高
> 4. **'出去看看'后能不能回来**:出区 985 选调返蒙路径仍开放(对蒙古族 + 牧区户籍考生友好),**学成 4-7 年后回内蒙古党政基层 + 选调晋升** 是隐藏跃迁路径。"

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**对内蒙古考生**:**家长普遍倾向"留蒙"是文化心理事实,不是刚需** —— 要客观对比"留蒙双非"vs"出区 211 主流组"的 5 年 ROI,**不要让家长的留蒙情怀代替孩子的实际跃迁机会**。
