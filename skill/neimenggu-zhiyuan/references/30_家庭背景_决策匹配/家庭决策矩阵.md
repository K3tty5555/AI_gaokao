# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(内蒙古版)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

**内蒙古特殊性(必读)**:
- 内蒙古整体经济水平低于湖北 / 江浙,**5 档家庭分布偏中下**(③ 私企管理 / 创业档比例较低,④ 普通工薪 / ⑤ 牧区临工档比例较高)
- **鄂尔多斯能源型富裕家庭(煤老板 / 矿企主)是内蒙古独有的"看似 ④ 实际 ③"画像** —— 名义上是私企但收入高,要按 ③-④ 之间归档
- **牧区家庭(锡林郭勒 / 呼伦贝尔 / 阿拉善 / 通辽 / 鄂尔多斯西部)** 是内蒙古独有的 ⑤ 档画像,**比湖北 / 江浙的"农村家庭"更贫困 + 信息差更大 + 出区心理压力更大**
- **蒙古族 + 双语考生** 在 5 档基础上**还有"民族通道"红利**(加分 + 民族班 + 蒙古族预科 + 国家专项 四通道叠加)—— 这是内蒙古独家的"超档跃迁"工具
- **内蒙古考生出区"心理距离"比湖北大**:湖北襄阳家长送孩子去武汉 = 1.5h 高铁,内蒙古鄂尔多斯家长送孩子去北京 = 8h 高铁 / 飞机,**家长普遍倾向"留蒙"**

## 档位 ① 体制内家庭(自治区 / 盟市 党政 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障,包括:
- 自治区直机关 / 各盟市党政
- 事业单位(医院 / 学校 / 文化系统)
- **国企**:**包钢 / 神华 / 国家能源集团 / 内蒙古移动 / 国网内蒙古东部 / 蒙电网 / 伊利 / 蒙牛 中层及以上**(内蒙古特殊:大型央企 / 国企在区内编制密集,父母在央企管理岗 = 体制内画像)

**家庭画像**:
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易
- **内蒙古特色**:体制内家庭普遍懂"民族岗"红利,会主动让孩子学"汉语言 + 蒙语" / 法学 / 行政管理走双语岗或民族岗

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上 985/211(包括内大),**走选调生比国考区考更优**(起点更高、竞争内部化)
3. **内大法学 / 行政管理是内蒙古区直机关主供给** —— 父母在内蒙古区直机关 + 孩子内大法学 = 校友 + 父母资源叠加,留蒙考公组合拳
4. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
5. **特殊机会**:警校(中国人民公安大学 / 内蒙古警察职业学院)+ 公安联考 = 父母编制资源能用上
6. **蒙古族 + 双语考生**:父母在民族岗位 → 强推内大蒙古学 / 蒙古语言文学 + 民族岗专项 = 隐藏顶配跃迁

**典型 case**:

- **呼和浩特某中产体制内家庭**(父亲自治区直机关副处,母亲银行)→ 孩子 580 分历史类 → 推内大法学 → 毕业选调进自治区委办,**家庭路径完美匹配**
- **包头某体制内家庭**(父母都在包钢中层管理)→ 孩子 600 分物理类 → 推内大法学 / 内大行政管理 → 毕业进包头市级党政,**父母校友 + 包钢人脉双重叠加**
- **失败 case**:同样家庭,孩子被推去出区华南理工 CS → 毕业 25w 起薪很高,但家长不满"不稳定 + 离家远",劝其离职考公,**两年的时间损耗 + 心理纠结**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师 等专业领域。

**家庭画像**:
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道
- **内蒙古特色**:**包钢工程师 / 鄂尔多斯能源企业工程师 / 神华工程师 / 国家电网工程师** 是内蒙古独有的"工科专业人员家庭"画像,**子承父业进央企更顺**

**推荐策略**:
1. **优先子承父业**:
   - 教师家庭 → 师范 / 公费师范(内师大主战场)
   - 医生家庭 → 临床 / 口腔(8 年长周期父母能撑)+ 内医大 / 出区医学院
   - **包钢 / 神华 / 国电 工程师家庭** → 冶金 / 矿业 / 化工 / 电气(内科大 / 内工大 / 北科大 / 太原理工)
2. **行业相关延伸**:律师家庭 → 法学;工程师家庭 → 对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:

- **呼和浩特母亲师大附中语文老师 + 父亲普通工薪** → 孩子 580 分历史类 → **公费师范生汉语言**(内师大) → 毕业回原校 / 同区编制,**母亲资源直接复用**
- **包头父母都是包钢工程师** → 孩子 600 分物理类 → 推**内蒙古科技大学冶金 / 北科大冶金** → 毕业回包钢 + 父母校友 + 子承父业,**包钢工程师家庭隐藏跃迁通道**(包钢校友 + 内科大对口度极高)
- **鄂尔多斯神华煤化工工程师家庭** → 孩子 590 分物理类 → 推**内蒙古工业大学化工 / 太原理工煤化工 / 中国矿大化工** → 毕业回鄂尔多斯神华煤制油 / 久泰能源,**起薪 12-16k + 父母引荐**
- **父母都是临床医生** → 孩子 640 分物理类 → **同济医学院八年制临床 / 北医** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**内蒙古特殊画像**:
- **鄂尔多斯能源企业主 / 矿主 / 煤老板** —— 内蒙古独有,收入水平接近一线富裕家庭(年入 100-500w+),**家庭兜底极厚**
- **包头 / 呼和浩特 中型私企管理层** —— 中产创业 / 制造业 / 物流贸易
- **鄂尔多斯羊绒产业链 + 牧场企业主** —— 畜牧业转型为现代企业
- **内蒙古一般民营企业** —— 收入水平接近湖北 / 江浙的中产创业家庭

**家庭画像**:
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **鄂尔多斯能源型富裕家庭独家路径**:出国 / 中外合作 / 一线 985 商科 — **家庭兜底强 + 鄂尔多斯能源型家庭普遍计划孩子接班或出国**

**典型 case**:

- **鄂尔多斯东胜某煤老板家庭**(年入 200w+) → 孩子 580 分物理类 → 推**香港城市大学 / 中外合作办学 / 美国本科**(学费 8-15w / 年家里能撑) → 出国背景做家族企业接班
- **包头某中型物流私企老板** → 孩子 590 分历史类 → 推**对外经济贸易大学 / 中央财经大学 / 上海财经大学** → 一线财经做接班准备
- **呼和浩特某餐饮连锁创业家庭** → 孩子 560 分物理类 → 推**香港中文大学(深圳)/ 西交利物浦** → 商科 + 国际视野
- **失败 case**:鄂尔多斯能源型家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主。

**内蒙古特殊画像**:
- **包钢 / 神华 / 国家能源 / 内蒙古移动 / 国网 一线工人 / 普通员工** —— 内蒙古独有的"央企一线工薪"画像
- **呼和浩特 / 包头 / 鄂尔多斯 服务业 / 文员 / 个体小生意**
- **盟市政府基层科员 / 事业编一般岗** —— 名义体制内但收入跟普通工薪差不多

**家庭画像**:
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **公费师范生(内师大)= 高考分适中 + 直接编制 + 无学费**
   - 警校(中国人民公安大学 / 内蒙古警察职业学院)+ 公安联考 = 进警察系统编制
   - 医学技术(医学影像 / 检验,内医大)= 三甲医院技术岗 + 4 年本科即可
   - 殡葬专业 = 100% 编制 + 收入意外不错
3. **次推稳定就业型**:
   - **电气 / 化工 / 矿业 进央企内蒙古基地**(内大 / 内工大 / 内科大 / 太原理工 / 北科大 / 华北电力)—— **内蒙古普通家庭男生工科性价比之王**
   - 师范类(汉语言 / 数学师范)
   - 护理(本科,专科也行)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 7-10w,跟双非工科没差;**留蒙双非 CS 几乎无盘**)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起;但可选**医学技术 / 护理 / 蒙医** 4 年本科捷径)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:

- **包头工矿区工薪家庭** → 孩子 580 分物理类 → 推**内蒙古科技大学冶金 / 内蒙古工业大学电气** → 毕业进包钢 / 国家能源集团内蒙古基地,**月入 1-1.4w + 编制 + 包头房价低,家庭逆袭**
- **呼和浩特工薪家庭** → 孩子 540 分历史类 → 推**内蒙古大学汉语言文学(双非但考公王者)/ 内师大汉语言公费师范** → 毕业当年考上自治区直机关 / 留呼市当语文老师,**家庭命运改变**
- **鄂尔多斯东胜工薪家庭(非煤老板)** → 孩子 590 分物理类 → 推**内蒙古工业大学化工 / 太原理工煤化工** → 毕业回鄂尔多斯神华煤制油 / 久泰能源,**起薪 12-15k + 项目奖金 + 鄂尔多斯收入水平内蒙古第一**
- **通辽工薪家庭** → 孩子 520 分物理类 → 推**内蒙古农业大学动物科学 / 食品工程** → 毕业进伊利通辽分公司 / 蒙牛 / 牧场企业,**起薪 8-12k + 编制(国企级别)**

## 档位 ⑤ 牧区 / 农村 / 临工家庭

**定义**:父母务农 / 牧民 / 临时工 / 零散工作,家庭年收入通常 < 8 万。

**内蒙古特殊画像**:
- **牧民家庭**(锡林郭勒 / 呼伦贝尔 / 阿拉善 / 通辽东部 / 鄂尔多斯西部 / 兴安盟 / 巴彦淖尔 北部)—— 内蒙古独有,主要靠养羊 / 养马 / 养骆驼 / 草原承包,收入波动极大(草原 / 雪灾 / 市场价格)
- **农村家庭**(河套地区 / 通辽 / 赤峰 / 鄂尔多斯南部农区)—— 主要种植玉米 / 葵花 / 小麦,半牧半农
- **旗县城关乡镇临工**(各旗县区中心镇打零工 / 个体小生意)
- **多数家庭是蒙古族 / 蒙汉杂居**,**民族通道(加分 + 民族班 + 蒙古族预科 + 国家专项)是隐藏跃迁工具**

**家庭画像**:
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- **出区心理压力比内地农村家庭大**(地理远 + 文化差异 + 牧区孩子从未离开过盟市)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校 + 民族 / 国家政策

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对牧区 / 农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **公费师范生(内师大,蒙古族双语方向是隐藏顶配)= 无学费 + 编制**
   - **国家专项计划 / 高校专项 = 内蒙古农村 / 牧区户籍专属优惠**(分数比统招低 30-60 分)
   - **民族班 / 蒙古族预科** = 蒙古族学生专项,降 30-50 分
   - **加分** = 蒙古族 +5 / 蒙汉双语 +10
   - **四通道叠加** = "加分 + 民族班 + 预科 + 国家专项" 可让二本档冲内大 211
   - 警校 / 军校(无学费 + 编制 + 包分配)
   - **农林牧水**(华农 / 内农大 / 西农 国家专项)= 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **国家专项计划**:内蒙古农村 / 牧区户籍,985/211 名校多个专项指标(分数比统招低 30-60 分);**对蒙古族牧区家庭尤其友好**
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **殡葬专业**(冷门但 100% 编制 + 收入不错)
   - **三支一扶 / 西部计划**:服务期满定向编制,**内蒙古边远盟市岗位竞争小**

**典型 case**:

- **锡林郭勒蒙古族牧区家庭**(蒙古族 +5 加分 + 双语)→ 孩子 510 分物理类 → 用足"加分 + 民族班 + 国家专项"四通道叠加 → **进内蒙古大学法学(国家专项 + 民族班)** → 实际录取等同 460 分常规批 → 毕业进自治区民委 / 锡林郭勒盟党政 → **整个家族第一个 211 + 编制**
- **呼伦贝尔牧区蒙古族家庭** → 孩子 580 分历史类 → **公费师范生蒙汉双语(内师大)+ 蒙古族预科** → 4 年无学费 + 毕业回呼伦贝尔蒙古族学校编制,**最适合牧区家庭的"零风险"路径**
- **通辽农区家庭** → 孩子 540 分物理类 → **内蒙古农业大学草学(国家专项)/ 动物科学** → 毕业进伊利 / 蒙牛 / 牧场企业,**起薪 8-12k + 编制 + 留蒙生活质量好**
- **阿拉善蒙古族牧区家庭** → 孩子 490 分历史类 → **内蒙古师范大学蒙古语言文学(国家专项 + 民族班)** → 毕业进阿拉善盟民族宗教委 / 阿拉善蒙古族学校,**民族岗专项 + 编制锁定**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

**内蒙古特殊纪律**:
- **民族通道(蒙古族 + 双语 + 牧区户籍)是 ④ ⑤ 档家庭的"超档跃迁"工具**,推荐时务必问清楚是否蒙古族 / 双语 / 牧区户籍
- **鄂尔多斯能源型家庭看似 ④ 实际 ③** —— 不要被"父母在矿区 / 厂里"误导,要按收入档位实际归类
- **内蒙古考生出区心理距离比湖北大** —— 推荐"出区"路径时务必明示家庭出区成本(年生活费 8-12w),让家长有数;不要假设"出区都能撑"
