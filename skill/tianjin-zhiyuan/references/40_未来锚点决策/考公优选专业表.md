# 考公优选专业表(天津本地视角)

## 核心结论

**专业决定考公选岗范围**。**京津冀考公生态独特** —— **国考北京 + 中央部委 + 央企总部 + 京津冀省市考** 构成全国最密集的体制内岗位群,**天津户籍 + 在津高校 是双重红利**。天津家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

## 关键事实(2024 国考 / 天津市考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 日语 / 法语等)** — 外交部、海关、商务部 → 约 2%

### 国考北京岗 / 天津岗的特殊红利(京津考生独享)
- **国考北京岗 = 中央部委 + 央企总部 + 在京事业单位**,**总量占国考的 25%+**(全国最密)
- **国考天津岗 = 海关 / 税务 / 银保监 / 海事局 / 滨海新区央企 / 北方海关**,**总量占国考的 5-7%**(直辖市级别岗位密)
- **天津户籍考生报国考北京岗 / 天津岗 多数无户籍门槛**(部分岗位有"京籍优先")
- **天津考生 + 京籍朋友圈 + 通勤距离短** = 信息渠道 + 内推机会比河北 / 山东考生强

### 天津市考特殊性
- **天津公务员考试岗位** = 天津市直机关 + 各区机关 + 滨海新区管委会 + 天津各国企事业单位
- **市内六区岗位竞争激烈**(和平 / 河西 / 南开 主城区岗位是大热门),**远郊蓟州 / 武清 / 静海 岗位相对宽松**
- **滨海新区岗位** = 自贸区 + 央企管委会 + 滨海行政区,**专业要求工科 / 经管偏多**
- **汉语言文学和法学并列考公第一专业**
- **天津各区公务员岗位**对法学要求高(法院、检察院、司法局)
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 1000+ 比 1)

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(天津本地的选调生定向计划基本只对 985/211 + 部分省内重点)
- **南开 / 天大 选调名额** 在全国选调中竞争力强 —— **京津冀岗位 + 全国跨省岗位 双向供给**
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学**

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(中国人民公安大学、中国刑警学院、中国人民警察大学(廊坊)等)+ 通过公安联考
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**南开法学 / 中央政法大学 对口**

## 天津本地院校 × 专业组合(考公视角)

### 985 + 强势考公专业
- **南开大学法学** — 全国前 15,**法考通过率高,选调路径最优**;**京津冀法检院系统首选**
- **南开大学周恩来政府管理学院**(行政管理 / 政治学 / 公共管理) — **选调生友好** + **京津冀党政机关认可度极高**;**周恩来总理母校的政管学院,在体制内有特殊符号意义**
- **南开大学汉语言文学 / 历史学 / 哲学** — **京津冀考公选调路径硬**
- **南开大学经济学院 / 金融学院** — **进财政 / 税务 / 海关 / 银保监会 对口** + 综合就业双友好
- **天大经管学院**(管理科学与工程方向)— 央企管理岗对口,但考公友好度不如南开经管
- **南开大学马克思主义学院** — **体制内最对口**,选调路径硬

### 211 + 强势考公专业
- **天津医科大学(医学相关考公)** — **进卫健委 / 疾控 / 海关卫生检疫 / 医院管理岗** 对口
- **河北工业大学行政管理 / 公共管理 / 法学** — 弱(河工大文科边缘),**别为了考公来河工大学非工科**

### 双非 + 性价比考公专业
- **天津财经大学 会计 / 财政 / 税务 / 经济** — 双非但天津财经领头;**留津进财政 / 税务 / 银保监会天津局 / 海关** 对口;**会计学是双非里的好选择**
- **天津师范大学汉语言文学 / 法学 / 政治学** — 双非中等,但**汉语言是省考王者**,毕业考公成功率高;**马克思主义理论 / 政治学 是天师大双非里少见的 B+ 学科,体制内对口**
- **天津外国语大学(英语 / 日语 / 韩语 / 法语 / 俄语等)** — **进外交部 / 海关 / 商务部 / 国际贸易局** 对口;**京津冀外语口岗位密度高**(海关 / 北方海事局 / 中央企业外贸口)

### 公安系统专属
- **中国人民公安大学 / 中国刑警学院 / 中国人民警察大学(廊坊)** — 本科,公安联考路径,**毕业进京津冀本地公安概率极高**
- **南开法学 / 北京政法大学侦查学 / 监狱学** — 进司法系统

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:天津武清考生,565 分综合,**普通工薪家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报天师大公费师范汉语言文学**,**毕业直接给武清区中学编制 + 备考公务员两年成功上岸天津税务局武清分局**,**家庭命运改变**
- **Case B(选调路径)**:天津和平区考生,650 分综合,中产家庭。家长想报"金融"(南开经济学院)。**改报南开法学**,**毕业获得南开选调生资格,直接进天津市委组织部**,起点远超经济学就业
- **Case C(失败路径)**:天津滨海考生,585 分综合,普通家庭男生。家长想"考公兜底"。**报了天工大计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行当程序员但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:天津家长以为"行政管理"是考公专业 — **错**。**公共管理 / 行政管理虽然听起来对口,但实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(国考北京岗)**:天津南开区考生,640 分综合,中产家庭。**报南开汉语言** → 大四考国考(报北京中央部委综合岗)→ **一次上岸进国家发改委** → **京津户籍考生通过国考北京岗进入中央部委的典型路径**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。**天津 3+3 不分文理**,理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;**会计考公还行但要学会计相关 + 优先天财大 / 央财 / 上财**
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。**公安体系是公务员但要走"公安联考"专门通道**,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。**选调生 = 985/211 才有资格,但是资格内的竞争小**,所以**对 985/211 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是天津家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**国考天津岗只有北京户籍能报**" — 错。**天津户籍考生报国考天津岗 + 国考北京岗 都没户籍门槛**(部分岗位有"京籍优先");**天津考生进入中央部委 / 央企总部的概率比想象中高**
- "**天津户口含金量比北京低,考公优势没有北京**" — 半对。**天津户口在京津冀考公生态里仍有红利**(国考北京岗 + 国考天津岗 + 天津市考 三重选择 + 京津通勤一小时)
- "**南开选调比天大选调好**" — 半对。**南开文科背景 + 选调对口党政机关**优势更顺;天大工科背景 + 选调对口规划 / 工业 / 国企管理 也吃香,**看走哪条体制内路径**

## 关键提醒

**考公是普通家庭最稳定的上升通道**。如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。**汉语言文学是天津家长被严重低估的考公王者**。

**给天津家长的金句**:

> "**京津冀考公是天津考生的隐藏红利** — 国考北京岗 + 国考天津岗 + 天津市考 + 京津双向选调,**这套组合是河北 / 山东 / 河南考生没有的**;**别浪费'京津户籍 + 邻近北京'这个优势**,选汉语言 / 法学 / 经济 是最大化利用它的路径。"

> "想考公就老老实实选**南开法学 / 南开汉语言 / 南开经济 / 天师大公费师范汉语言 / 天财大会计** —— 别被'公共管理就是为考公设的'这种话误导,**实际可报岗位数和考公成功率,公共管理远不如汉语言**。"

> "**国考北京中央部委 + 京津冀央企总部** 是天津家长最该重视的两个考公主战场。**南开 / 天大 + 汉语言 / 法学 / 经济 的组合**,通过国考进国家发改委 / 商务部 / 财政部 / 中信集团 等的概率,比河北 / 山东考生高 30%+。"
