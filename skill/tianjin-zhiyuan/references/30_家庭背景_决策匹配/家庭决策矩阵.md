# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(天津视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。**天津的特殊性:京津冀就业一体 + 京津户口含金量 + 滨海新区央企密度** —— 同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**天津典型画像**:
- **父母多是天津市直 / 各区机关 / 国企(渤化 / 天津港 / 一汽丰田 / 天津地铁 / 渤海银行 等)**;**滨海新区央企子弟 + 滨海行政职级家庭** 常见
- **父母 70 后 / 80 后初** 起步,**很多是改革开放后第一代"单位人"**;子女多是独生子女(尤其和平区 / 河西区中产体制内家庭)
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易

**推荐策略**:
1. **强烈考公友好型**:**汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理**(京津冀考公对口岗位多)
2. **985/211 选调生路径**:孩子能上 985/211,**走选调生比国考省考更优**(起点更高、竞争内部化);**南开 / 天大选调名额 在全国选调中竞争力强**(京津冀岗位)
3. **避免体制外才有出路的专业**:**CS / 金融头部 / 创业类** — 跟父母期待冲突,孩子毕业容易被劝回考公,3 年损耗
4. **特殊机会**:警校 / 公安专业(中国人民公安大学在京 / 中国刑警学院 等)+ 公安联考 = 父母编制资源能用上

**典型 case**:
- 天津和平区某中产体制内家庭(父亲市直机关副处,母亲渤海银行支行长)→ 孩子 615 分综合 → 推**南开法学** → 毕业选调进天津市委办,**家庭路径完美匹配**
- 失败 case:同样家庭,孩子被推去**天大 CS** → 毕业 35w 起薪很高 + 在北京字节工作,**但家长不满"不在天津 + 不稳定"**,劝其离职考公,**两年的时间损耗 + 心理纠结**
- 天津滨海新区某央企子弟(父亲渤化研究院工程师,母亲一汽丰田管理岗)→ 孩子 590 分综合 → 推**天大化工** → 毕业进**中海油天津大港炼化总部**,**子承父业 + 留津 + 央企编制**

## 档位 ② 专业人员家庭(教师 / 医生 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**天津典型画像**:
- **父母多在天津总医院 / 医大总医院 / 第一中心 / 肿瘤医院 / 中医药大学一附院 等三甲医院,或南开附中 / 一中 / 耀华 / 新华中学 等市重点中学**
- **大学城(西青)/ 八里台(老南开)/ 河西(高校教师聚集区)** 中产高知家庭
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:**教师家庭 → 师范 / 公费师范**(天师大公费 + 北师大 / 华东师大 公费);**医生家庭 → 临床 / 口腔 / 中医**(8 年长周期父母能撑)
2. **行业相关延伸**:**律师家庭 → 法学(南开法学是首选)**;**工程师家庭 → 对应工科(天大化工 / 建筑 / 水利)**
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难)

**典型 case**:
- 母亲耀华中学语文老师 + 父亲普通工薪 → 孩子 605 分综合 → **天师大公费师范汉语言** → 毕业回耀华附属或河西区中学编制,**母亲资源直接复用**;**或冲北师大公费师范汉语言出市更顶**
- 父母都是天津总医院临床医生 → 孩子 660 分综合 → **天医大临床八年制** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 父亲是天大化工教授 → 孩子 645 分综合 → **天大化工 + 直博** → 父亲组里读研直博 + 出国博士后 + 回国进高校 → **学术路径子承父业**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**天津典型画像**:
- **天津本地民营企业主**(批发市场 / 物流 / 五金机电 / 装修建材 / 餐饮连锁 / 早期投资外贸的潮汕福建商人 / 北方装备制造小老板)
- **滨海新区**早期下海创业的中小企业主
- **比浙江 / 广东 私企家庭比例低**(天津国企 + 体制内主导的城市文化)
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业

**推荐策略**:
1. **可选商科 / 创业方向**:**工商管理(头部院校) / 经济学 / 金融 / 国贸**(头部院校,**南开经济 / 天财大会计 / 出市央财上财**)
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:**天津有香港城市大学(东莞)/ 香港中文大学(深圳)等粤港澳合作办学** + **天大佐治亚理工学院(深圳)** + **天津大学北洋园 / 福州校区** 等中外合作选项
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)

**典型 case**:
- 天津某餐饮连锁老板家庭(年入 300w+) → 孩子 595 分综合 → 推**香港城市大学(东莞)/ 中外合作办学**(学费 8-15w/年家里能撑) → 出国背景做家族企业接班 / 留学 + 回津继承
- 失败 case:私企家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息" → **家庭基因不对路**;天津私企老板对孩子"一辈子端铁饭碗"接受度比体制内家庭低
- 天津滨海某中小制造企业主家庭(年入 150w+) → 孩子 620 分综合 → 推**天大管理科学与工程 + 接班准备** → 毕业回家族企业做总经理助理 + 进央企见习 → **务实接班路径**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 10-30 万为主。

**天津典型画像**:
- **父母在天津本地国企 / 制造业基层** —— 一汽丰田 / 长城汽车 / 大众动力总成 / 天津电视机厂(曾经)/ 天津港装卸 / 渤海钢铁 等的一线工人 + 班组长
- **天津"卫嘴子"工薪文化** —— 务实 + 安稳偏好,**对孩子的期望基本就是"端铁饭碗 + 京津冀有套房 + 顺利结婚生子"**
- **市内六区(和平 / 河西 / 南开 / 河东 / 红桥 / 河北区)+ 环城四区 + 滨海新区 + 远郊** 工薪家庭的典型分布
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**:
   - **天师大公费师范** = 高考分适中 + 直接给天津编制 + 无学费
   - **中国民航大学(招飞 / 空管 / 航空电子)** = 进民航局 / 各航司 / 空管局
   - **天医大医学技术(医学影像 / 检验)** = 三甲医院技术岗 + 4 年本科即可
   - **殡葬专业(出市去长沙民政 / 北京社管)** = 100% 编制 + 收入意外不错
3. **次推稳定就业型**:
   - **电气工程进国电网(分够河工大 / 天大)**
   - **化工进中石化大港 / 中海油天津 / 渤化集团(分够天大化工 / 河工大化工)**
   - **师范类(汉语言 / 数学师范 — 天师大公费)**
   - **护理(本科,专科也行)**
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局)
   - 双非 CS(2024 起薪 8-10k,跟双非工科没差)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 天津宝坻工薪家庭(父亲一汽丰田工人,母亲超市理货)→ 孩子 605 分综合 → 推**河工大电气工程**(双一流,在天津北辰)→ 毕业进**国网天津宝坻供电公司**,**月入 8-10k + 编制 + 公积金 12%,家庭逆袭**
- 天津武清工薪家庭 → 孩子 565 分综合 → 推**天师大公费师范汉语言文学**(双非但天津公费师范主供给)→ 毕业回**武清区中学**编制,**家庭命运改变**
- 天津滨海新区工薪家庭(父亲渤化基层工人)→ 孩子 580 分综合 → 推**天医大医学影像技术** → 毕业进**滨海新区医院影像科**,**起薪 7-8k + 编制 + 留滨海**

## 档位 ⑤ 农村 / 临工家庭(天津远郊 / 外来务工)

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 10 万。

**天津典型画像(注:天津作为直辖市,严格意义"农村"占比小,但仍有)**:
- **远郊蓟州 / 武清 / 静海 / 宝坻 / 宁河** 部分农村家庭(粮食种植 / 经济作物 / 牲畜养殖)
- **天津城中村 / 城乡结合部** 部分外来务工家庭(户籍可能仍在外省,孩子在津借读)
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **天师大公费师范**(无学费 + 编制)= 农村家庭神器
   - **国家专项计划 / 高校专项 / 地方专项** = 天津也有(主要面向天津户籍 + 涉农区);分数比统招低 20-30 分
   - **警校 / 军校**(无学费 + 编制 + 包分配)— **武警工程大学 / 中国人民警察大学(廊坊)**等北方军警校
   - **农林牧水(华农国家专项 / 中国农大 / 天津农学院)** = 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起)
4. **特殊机会**:
   - **天津国家专项 / 高校专项**:涉农区户籍(蓟州 / 武清 / 静海 / 宝坻 / 宁河),985 / 211 名校多个专项指标(分数比统招低 20-30 分)
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会
   - **殡葬专业**(冷门但 100% 编制 + 收入不错)

**典型 case**:
- 天津蓟州农村家庭(父母务农)→ 孩子 605 分综合 → 通过**国家专项**进**天大水利水电工程**(比统招分低 20+ 分)→ 985 牌子 + 进中国电建 / 三峡集团,**整个家族第一个 985**
- 天津武清涉农家庭女孩 → 575 分综合 → 推**天师大公费师范汉语言文学** → 4 年无学费 + 毕业回武清区中学编制,**最适合涉农家庭的"零风险"路径**
- 天津静海农村家庭男生 → 590 分综合 → 推**中国民航大学(招飞)**(双非但民航对口 + 包分配 + 待遇好)→ 毕业进**国航 / 东航天津分公司**飞行员,**收入 25w+ 起,跨阶级**

| 家庭档 | 关键词 | 推 | 避 |
|---|---|---|---|

| ② 专业人员 | 子承父业 + 拐杖最大化 | 师范(教师)/ 医学(医生)/ 法学(律师)/ 工科(工程师) | 完全无父母资源的领域 |
| ③ 私企/创业 | 可冒险 + 上限高 | 商科头部 / 出国 / 中外合作 / 创业 / 艺术 | 体制内基层 |
| ④ 普通工薪 | 编制 + 稳定 | 天师大公费 / 河工大电气 / 天医大医技 / 民航大 / 汉语言 | 双非金融 CS / 生化环材 / 医学长周期 |

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 给天津家长的金句

> "**天津家庭的特殊性是'卫嘴子文化'+ 京津冀就业一体 + 国企央企密度极高** —— 父母期望端铁饭碗的比例比浙江 / 广东高得多。普通工薪家庭按这个文化逻辑给孩子选稳定路径反而是对的,**别被'要让孩子追梦'的鸡汤误导**。"

> "**滨海新区家庭和市内六区家庭推荐策略不一样** — 滨海央企子弟首选化工 / 港口物流 / 海洋技术(子承父业);市内六区中产体制内首选汉语言考公 / 法学选调 / 师范公费(对接父母行业)。"

> "**蓟州 / 武清 / 静海 / 宝坻 / 宁河 涉农家庭别忽视'国家专项 + 公费师范'双红利** — 这是天津户籍涉农考生独有优势,**分数比统招低 20-30 分进 985 / 211 + 100% 编制保障**,普通家庭跨阶级的最稳路径。"
