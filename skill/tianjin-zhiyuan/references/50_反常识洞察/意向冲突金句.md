# 用户意向冲突 — Reality Check 金句库(天津视角)

很多家长 / 考生有具体的意向("想上南开"、"非北京不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >5,000 名(天津考生量小,5,000 名在天津 ≈ 2 万名在湖北)

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 480 分要清北 / 580 分要南开主流组)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 千名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(天津 580 分,意向南开)**:
> "南开主流组在天津综合 800-3,500 名。你 12,000 名,差 9,000 名,**南开主流组没戏**。
>
> 但你能上**天医大临床(7,000 名)+ 河工大电气(8,000 名)+ 天工大纺织(15,000 名)** — 这三所留津就业,**京津冀国企 / 体制内招聘里跟南开冷门组校友地位差不多**(都是'天津本地 211 / 双非顶配 + 留津同档')。"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林 / 海洋等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学 / 海洋]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(理工科 + 普通家庭,天津 605 分)**:
> "南开你 4,500 名能擦 — 但只能进**化学 / 生命科学 / 哲学 / 部分材料**这种基础学科组。**985 牌子 + 基础学科 + 必须读博才有出路** = 普通家庭撑不起。
>
> 同分能上的**河工大电气工程(8,000 名)+ 天医大医学影像技术(8,500 名)** 出来对口程度更高 + 4 年本科直接就业。冲南开留一个心理慰藉位即可,**主推河工大电气进国网**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [天医大临床八年制 / 出市协和北医])
> - 撑不起 → 走 **[替代短路径]**(如 [天医大医学影像 / 医学检验 / 护理 — 早 3 年挣钱]),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(普通工薪家庭 + 想学医,天津 590 分)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 8-12k**。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**天医大临床五年(留津 + 进三甲) → 长期天花板高 + 京津冀就业**。
>
> 撑不起 → **建议天医大医学影像技术 / 医学检验技术 / 护理(4 年本科直接进三甲技术岗,起薪 7-9k + 编制,早 3-4 年挣钱)**,或者放弃医学走**汉语言考公 / 公费师范** 这种本科直接挣钱的赛道。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去"

**特征**:用户只想留某个城市("非天津不去" / "非北京不去" / "非上海不去"),拒绝出省 985。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留天津没意义,要去西工大;想学量子物理 → 出市清北中科大),**要灵活退一步**。"

**真实案例(天津户籍 + 留津意愿强 + 605 分综合)**:
> "你只留天津,这分综合 7,500 名,南开 / 天大主流组够不上。
>
> **留津最稳路径**:**天医大临床(留津进三甲对口)/ 河工大电气(留津进国网天津)/ 天财大会计(留津进银行 / 财政)**,这三个都是天津本地认可度最高的 211 / 双非顶配。
>
> 不要为了'外省 985 牌子'去**兰大基础学科 / 东北大学冷门 / 西农大冷门** —— 牌子有了但**人脉断了 / 实习机会少了 / 京津户口的'隐性红利'用不上 + 京津冀就业一体的红利全没**,综合不划算。"

**真实案例(天津户籍 + 想出市冲清北 + 660 分)**:
> "你 660 分,综合 1,500 名,**清北边缘** — 真要冲清北只能进冷门组(基础学科 / 工科冷门方向)。
>
> **理性算账**:**南开 / 天大主流组(法学 / 经济 / 化工 / 建筑)+ 留津就业 vs 清北冷门组 + 北京就业** — **5 年后差距没你想的那么大**;尤其**清北冷门组毕业回京津冀就业,跟南开 / 天大 主流组校友比没明显优势**。
>
> **保留清北冲一档**,**主推南开 / 天大主流强势组** — 这是最理性的'冲稳保'。"

---

### 模式 E(天津特有):"留津 vs 出市" 二选一

**特征**:用户在"留津舒服 + 父母老人"和"出市清北复交 + 长期发展"之间纠结。

**金句模板**:
> "天津的特殊性:**京津冀就业一体 + 京津户口含金量** = '留津' 实际上不是'放弃远大前程',而是'留在京津就业生态'里。
>
> **南开 / 天大 + 留津 ≈ 复旦 / 上交 + 留沪 ≈ 中大 / 华工 + 留粤** — **三个圈子,不存在哪个更好,只看你父母 / 自己未来生活基础在哪儿**。
>
> 但!**分够清北就出市去清北**(顶配牌子 + 全国通用,不是替代品),**分够复交但没清北 → 算清楚出沪 vs 留津**;**分只够人大 / 中山 / 武大 这一档 → 留津的南开 / 天大可能更稳(京津冀红利 + 校友网密度)**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 南开 / 想学医 / 想留天津 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 天津特有的 5 类高频意向冲突 case

### Case 1:"我想上南开 / 天大,留天津" + 综合 8,000 名外
**判断**:不可达。**主推河工大 / 天医大 / 天财大**。**别为南开冷门组挣扎**。

### Case 2:"我想出市去清北复交,不留天津" + 分够 985 但够不上清北
**判断**:**理性算账 — 出沪 / 出京 985 vs 留津南开 / 天大** 实际差距不大;**京津户籍 + 京津冀就业一体 + 京津通勤近 = 留津有隐性红利**。

### Case 3:"我想学医 + 不想出天津" + 普通工薪家庭
**判断**:**天医大临床 5+3 + 留津进三甲 是性价比天花板**。**普通工薪家庭撑得住就上,撑不住就改医学技术 / 护理 4 年路径**。

### Case 4:"我想学计算机 + 留天津"
**判断**:**Reality Check** — **天津本地没有像样的互联网公司,'留津 CS' = 进国企信息部 8-12k 月薪到退休**。要吃 CS 红利**必须接受去北京通勤 / 跨城** —— 然后**南开 / 天大 CS 是好选择**;**否则学 CS 不如学化工进渤化中海油**(留津 + 化工央企薪资天花板比国企信息部高)。

### Case 5:"我想学金融 + 留天津"
**判断**:**京津冀金融生态 = 北京中央金融(央行 / 银保监 / 投行)+ 天津地方金融(渤海银行 / 天津金融租赁 / 天津港金控)+ 河北二档金融**;**北京金融岗位密度高,天津主要是地方分行 + 央企财务 + 滨海新区金融岛(规模有限)**;**要做头部金融出市去央财 / 上财 / 复交 + 北京 / 上海**;**留津金融 = 南开经济 / 金融 / 天财大会计 → 进银行 / 央企财务**。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**给天津家长的金句**:

> "**南开 / 天大 不是清北的替代品,是另一个生态** — 京津冀就业一体 + 京津户口红利 + 校友网密度,这是出市冲清北复交都享受不到的。**家庭普通 / 父母在津 → 留津往往是最优解,不是妥协**。"

> "**家长说'我家孩子分够'就是不够** — 分够某校的标准是稳进主流组(综合排名前 50% 的专业组),擦边进冷门组不算够。**南开法学 / 经济 / 数学 / 化学 主流组 vs 南开冷门组(哲学 / 部分材料),录取分差 50+ 分位次差 3,000+,这就是分'够'和'不够'的真正区别**。"

> "**'非北京不去'对天津考生来说没意义** — **天津到北京 30 分钟高铁,京津通勤一体**。在天津读书 + 去北京就业 + 周末回津 是天津考生的常态,**别为'必须去北京读大学'放弃南开 / 天大主流组冲清北冷门组**。"
