# 天津 3+3 高考政策

## 核心结论

**天津 2017 年加入新高考第二批,2020 年高考首届实行 3+3**(跟北京 / 山东 / 海南 同批,**比湖北/湖南/河北的 3+1+2 早一届**)。**天津是 3+3 体系**,不分物理类/历史类,所有考生统一排名 + 统一录取(选考赋分制)。**天津最大的特殊性在于:京津冀虹吸,本地考生上 985 难度反而比河北/河南更大**。

## 关键事实

### 考试结构(3+3 体系,跟湖北/河北的 3+1+2 完全不同!!)
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分,**英语听说+笔试,有两次机会取最高**)
- **3 = 选考科目**:物理 / 化学 / 生物 / 政治 / 历史 / 地理 中**6 选 3**(各 100 分,**全部用赋分制**,起点 40 分)
- **总分 = 750 分**
- **不分文理 + 不分物理类/历史类**(关键差异点!!)

### 选考赋分制
- 每科按全市考生原始分排名,等比例转换成 21 个档位(40-100 分)
- **赋分制后,选考成绩失去原始分意义,只看相对位置**
- 对**选小众科目的人不一定占便宜**(分母小但分子也少)

### 录取统一排名
- **3+3 体系下,所有考生用同一份一分一段表排名**(不像 3+1+2 分物理类/历史类两份)
- 院校通过"选科要求"区分:必选物理 / 必选化学 / 必选物 + 化 / 任选 等

### 院校专业组
- 不再按"学校"投档,**按"院校专业组"投档**
- 一所学校可有多个专业组(按选科要求分组)
- 同一学校的不同专业组独立投档
- **服从调剂只在本专业组内调剂**
- 一个专业组内通常 5-15 个专业

### 填报志愿数量(天津特定)
- **天津本科批 50 个志愿**(2024 数据,具体年份以官方为准)
- **专科批 25 个**
- 每个志愿 = 1 个院校专业组 + 1 个专业(**注意!天津采用"院校专业组"+ 具体专业混合形式,与江苏/湖北略有差异**)
- **意义**:天津填报操作空间中等,但因为是 3+3 + 6 选 3 共 20 种组合,**选科匹配的院校专业组数量比 3+1+2 多**,需要更精细筛选

### 20 种选科组合
6 选 3 共 C(6,3) = 20 种(物化生 / 物化政 / 物化史 / 物化地 / 物生政 / 物生史 / 物生地 / 物政史 / 物政地 / 物史地 / 化生政 / 化生史 / 化生地 / 化政史 / 化政地 / 化史地 / 生政史 / 生政地 / 生史地 / 政史地)。

可报专业范围参考详见 `_shared/references/00_核心方法论/采集_rubric.md` L1 单科分数判断。

## 天津最大特殊性(关键!!)

### 1. 天津考生少,但顶级名校占比高

- 天津高考报名 ~5.6-5.8 万/年(全国最少档之一,跟北京/上海/海南/宁夏/青海/西藏 等同档)
- **本市 2 所 985**:**南开大学 + 天津大学**(综合 + 工科双顶配)
- **本市 2 所 211**:**天津医科大学 + 河北工业大学**(河工大行政归河北但校区在天津北辰区)
- **天津工业大学** 是双非但纺织科学全国第 1 等
- **结果**:天津本地名校供给在全国排前列(人均 985/211 名额仅次于北京)

### 2. 京津冀虹吸:**反而拖低天津本地考生上 985 的概率**

**天津考生上 985 比河北 / 河南还难**,根本原因:
- 北京户籍考生竞争激烈(北京 2 所顶配 985 + 一堆 211 但本地份额留得多)
- 天津作为京津冀次中心,**南开/天大对本地份额已经充分照顾**,但**总量有限**
- **京津高校实际分数线在天津依然偏高**(京籍学生不能报考天津录取份额,但天津考生要跟外省顶尖考生竞争南开/天大的少量名额)
- 天津 985 录取率虽然全国前列,**但分数门槛偏高**(尤其物理化学组合)

**关键数据点**:
- 天津南开/天大本地录取分数线(物理类对应口径)**比同分位次的湖北武大/华科分数线高 5-15 分**
- 这就是"天津考生考 985 难"的来源 —— **分数门槛 + 京津份额竞争**

### 3. 天津本科批合并 + 特殊类型招生控制线

- **2020 起本科批合并**:本科 A 段、本科 B 段统一为本科批,**不再分一本/二本**
- 设有"**特殊类型招生控制线**"(对应 985/211/双一流报考门槛 + 强基计划/综合评价 等)
- **本科批分数线**(对应原"二本线"):约 460-475 分(2024-2025 区间)
- **特殊类型控制线**(对应原"一本线"):约 555-575 分(2024-2025 区间)
- **985/211 实际投档线**:大多在 600+ 分

## 天津产业生态(就业去向)

### 1. 天津港 + 航空航天 + 高端制造("航空母舰"产业)
- **天津港** — 北方第一大港,**外贸 / 航运 / 物流 / 海事**对口
- **航空航天** — 中航工业天津 / 中国航天科工集团下属研究所多
- **高端制造** — 一汽丰田 / 长城汽车 / 大众动力总成 / 空客天津总装线

### 2. 滨海新区 — **互联网/金融/装备制造**
- 滨海新区 = 国家级新区,**金融/科技/制造三栖**
- 蓝鲸金融 / 渤海银行 / 天津金融租赁 / 一些互联网公司北方据点
- **就业生态比传统天津市区好,薪资天花板高**

### 3. 京津冀一体化(就业核心优势)
- **京津就业一体化**:天津考生留京津比例 70%+(京津通勤可达,北京就业回天津定居成为典型路径)
- **天津本地国企/事业编**:渤化集团 / 天津港集团 / 天津地铁 / 海河传媒等

## 出市 vs 留津决策(天津考生的核心问题)

| 流向 | 主要原因 | 适合谁 |
|---|---|---|
| **留津**(主流,70%+) | 京津冀就业一体 + 985/211 选择多 + 落户稳 | 中产 + 体制内倾向家庭 |
| **北京**(次主流) | 北京 985 牌子 + 互联网/金融机会 | 顶尖学生(分够清北/北航/北邮等) |
| **上海** | 复交同济 + 长三角就业 | 想跨地域闯荡的中高分段 |
| **南方**(广东/江苏/浙江) | 中山/南大/浙大/东南 + 经济活跃 | 想去南方就业的高分段 |
| **东北/西北**(大工/哈工大/西交) | 985 性价比 + 工科强 | 普通家庭 + 想保住 985 牌子 |

**关键提醒**:**天津考生留津的吸引力比湖北/湖南考生留省更大**(京津就业一体 + 落户友好 + 城市基础设施好),但**留津需要分数 + 名额双匹配**,分数不够时出市才是好选择。

## 易错认知(agent 要纠正用户的)

- **"天津 3+3 跟湖北 3+1+2 差不多"** — 严重错。**3+3 全部赋分,3+1+2 物理/历史用原始分**,赋分逻辑差很多;**3+3 不分物理类/历史类,3+1+2 分**,排名口径不同
- **"老高考一本/二本"思维** — 严重过时。**天津 2020 起本科批合并,只看特殊类型招生控制线 + 本科批 两条线**
- **"赋分让我占便宜"** — 不一定。**冷门学科分母小但顶尖也少**,赋分 ≠ 涨分;**重要的是相对位次,不是原始分**
- **"天津录取率高,所以好考"** — 错。**录取率高指总录取率,985/211 录取率天津只是中等偏上**;京津冀虹吸下,**天津考生上南开/天大反而比湖北上武大/华科还难**
- **"南开/天大跟清北一档"** — 错。**南开 ≈ 武大 / 中山 / 厦大档**(综合中游 985);**天大 ≈ 华科 / 哈工大 档**(工科顶级 985)
- **"河工大是天津的 211"** — 半错。**河工大行政归河北,但校区在天津北辰区**,从地理 / 实习 / 就业看是天津高校,从牌子 / 行政归属看是河北高校
- **"特殊类型招生控制线 = 老一本线"** — 半错。**类似但不完全等同**,新高考下特殊类型控制线主要用于:① 985/211/双一流报考门槛 ② 强基/综评/专项计划 等
- **"服从调剂会被调到本校其他专业"** — 错。**只在本专业组内调剂**,不会跨组

## 关键提醒(agent 必须强调)

1. **天津 50 个本科志愿**(中等数量),冲稳保梯度要精细铺开
2. **服从调剂**通常推荐勾选,**但要确认本专业组内你能接受的最差专业**
3. **看位次而不是分数**(分数受当年卷子难度影响很大,加上赋分波动)
4. **选科要求**(必选化学/必选物理化学等)是硬约束,**填报前一定核对每个目标专业**
5. **京津冀虹吸真相**:本地考生上 985 比河北/河南更难,**别拿"天津 985 多"当低门槛错觉**
6. **河工大在天津北辰区,不在河北**(行政归河北,但生活/实习/就业都在天津)
7. **天津考生留津率 70%+**,**选校时优先考虑京津冀辐射圈**(留津 / 北京 / 河北沿海 / 上海)
