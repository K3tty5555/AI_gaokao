# 延边大学(延大,YBU)— 211 民族类 + 双一流,朝鲜语全国第 1

## 一句话定位

**全国 5 所民族类 211 之一**(中央民族 / 中南民族 / 西南民族 / 西北民族 / 延边),**双一流学科:外国语言文学(朝鲜语)**,**朝鲜语全国第 1**,对口朝鲜 / 韩国 / 日本东北亚三国。**延吉地理偏远 + 录取分相对低 = 性价比之王**,**对韩日朝就业独家**,留学韩国通道极强。

---

## 真实地位

- **211 + 双一流 + 国家民委 / 教育部 / 吉林省 共建**
- **吉林第 2 所 211**(跟东北师大并列,吉大是 985)
- **延吉本土 = 中朝俄三国交界 + 朝鲜族自治州**:**朝鲜族学生 + 朝鲜语母语环境**
- **吉林本省地位**:民族特色 + 朝韩日东北亚就业独家 + **录取分相对低于东北师大**
- **校区**:**延吉主校区**(吉林延边朝鲜族自治州延吉市)
- **学风**:**朝汉双语环境 + 韩国留学氛围浓**,部分专业用韩语授课
- **韩国延世大学 / 首尔大学 / 高丽大学 校际合作密切**,留学韩国通道顺畅

参考近 5 年掌上高考 + 吉林一分一段表(延边大学省内录取分相对低):

- **王牌组(临床医学 / 朝鲜语相关)**:全省 **8,000-14,000 名**
- **主流组(理工普通专业 / 经管)**:全省 **14,000-22,000 名**
- **冷门组(部分边缘工科 / 农学)**:全省 **20,000-30,000 名**

## 吉林历史类录取位次区间(2024-2025)

- **王牌组(朝鲜语 / 朝鲜文学 / 日语)**:全省 **3,000-6,500 名**(朝鲜语录取分较高)
- **主流组(汉语言 / 历史 / 经管)**:全省 **5,000-10,000 名**
- **冷门组(部分文科边缘)**:全省 **9,000-15,000 名**

## 吉林文/理科录取位次区间(2021-2023 旧高考)

- **理科**:全省 **9,000-25,000 名**(临床医学 9,000-14,000,主流工科 14,000-22,000)
- **文科**:全省 **3,000-12,000 名**(朝鲜语 3,000-5,500,普通文科 5,500-12,000)

**段位定位**:**吉林物理类省排 30,000 名内可冲延大不同方向**,**14,000 名内可挑王牌组(临床/朝鲜语相关)**。**朝鲜语 / 临床录取分较高,其他专业相对低 = 性价比之王**。**以一分一段表反查为准**。

## 性价比专业

- **朝鲜语**:**全国第 1 + 双一流 + 录取分相对低**(比 985 朝鲜语低很多),**韩企/朝韩贸易/留学韩国 三条路独家**
- **日语**:延吉地理近日 + 师资强 + 留学日本通道,**比一般 211 日语对口度更高**
- **临床医学(211 牌子)**:延大医学双非中等水平,但**211 牌子 + 录取分相对低**,留东北就业认 211
- **历史学(东北亚研究)**:特色 + 录取分低 + 选调生 / 体制内对口

## 坑专业(在延大里相对弱)

- **计算机 / 软件工程**:**别为 211 牌子来延大学 CS**,延大工科弱,**学 CS 出省同档双非 + 强工科** 都更优
- **普通经管 / 法学 / 工商管理**:延大文科非传统强项,**学经管选东财,学法学选吉大**
- **普通工科(机械 / 土木 / 化工)**:延大工科底子弱,**学工科选吉大或哈工大**
- **农学(传统方向,非东北亚特色)**:对口性弱,选吉农大或中国农大

## 关键提醒(填报陷阱)

1. **延大牌子在京津长三角校招 = 211 等同认可度**:**民族类 211 跟普通 211 等同**,公考/选调认,**别误以为"民族学校水牌子"**
2. **延吉地理偏的现实**:
   - **延吉是吉林延边朝鲜族自治州首府**,**离长春 4-5 小时车程**,**离哈尔滨更近**
   - **小城慢节奏 + 朝鲜族文化氛围浓 + 韩餐多 + 接近朝鲜半岛**
   - **不喜欢小城 + 想要大城市便利 + 大学城氛围的别选**
3. **朝鲜语 vs 韩语 vs 日语 怎么选**:
   - **朝鲜语**:延大全国第 1,**对口朝鲜 / 韩国 / 朝韩贸易**(实质就是韩语)
   - **日语**:延大日语对口日企 + 留学日本
   - **想做韩国留学 + 韩企** → 朝鲜语是最优解
4. **服从调剂**:延大组内可能含农学 / 边缘工科,被调剂的话能不能接受?
5. **临床医学 211 牌子 vs 双非临床顶级 怎么选**:
   - **延大临床(211)** vs **吉大临床(985)** → 分够吉大选吉大,分不够选延大,**别选辽宁/黑龙江双非临床**
6. **延大的"留学韩国通道"**:**校际合作密切 + 学费奖学金 + 双学位** 路径多,**想留学韩国的考生延大是国内最优起点**
7. **必选化学 + 生物**:吉林 3+1+2 选科,临床医学必选化生

## 毕业出口(2024 数据估算)

- **留吉林就业**:约 **30-35%**(延吉 + 长春 + 吉林市,延大附属医院 / 朝鲜族企业 / 韩企在华)
- **京津出省**:约 **15-20%**(北京 / 天津 韩企 / 央企 / 互联网,**朝鲜语对口三星/LG/现代/韩国驻华使馆**)
- **长三角出省**:约 **15-18%**(上海 / 杭州 / 苏州 韩企 / 日企 / 互联网)
- **广东**:约 **8-10%**(深圳 / 广州 韩企 / 出口贸易)
- **东北其他**:约 **5-8%**(沈阳 / 大连 / 哈尔滨)
- **留学韩国**:约 **8-12%**(延世 / 首尔 / 高丽大学 校际合作 + 自主申请)
- **考研 / 读博**:约 **15-20%**(保研率约 8-10%)
- **公务员 / 选调**:约 **8-10%**(吉林选调 + 民族事务对口)
- **起薪范围**:留吉 5-10w,韩企在华 8-15w,留学韩国回国 12-20w,延大临床医学规培完 8-15w

## 同档对比

| 维度 | 延大 | 中央民族大学 | 东北师大 | 吉大 |
|---|---|---|---|---|
| 综合排名 | 211 | 985(民族顶配) | 211 | 985 |
| 朝鲜语 | **全国第 1** | 强势 | 弱 | 弱 |
| 民族特色 | **东北亚** | **全国民族顶配** | 弱 | 弱 |
| 临床医学 | 中上(211 牌子) | 弱 | 中上 | **顶级** |
| 留东北 | **延吉/长春** | **北京就业顶配** | **长春顶配** | **长春顶配** |
| 录取分 | **吉林 211 最低** | 高(北京 985) | 中 | 高 |
| 留学韩国通道 | **顶配** | 强 | 弱 | 弱 |

**简单结论**:**学朝鲜语 / 留学韩国 / 对口朝韩日 → 延大全国第 1**;**想要 985 民族顶配 + 北京就业 → 中央民族大学**;**学综合性 + 留东北 → 吉大 / 东北师大**;**性价比 211 + 录取分要求低 → 延大独家**。

## 适合谁

- 吉林物理类 **省排 8,000-30,000 名** + 想要 211 牌子 / 不介意延吉地理 的考生
- 吉林历史类 **省排 3,000-15,000 名** + 想学朝鲜语 / 日语 / 留学韩国 / 对口朝韩日就业
- **朝鲜族学生 + 母语优势** → 延大天然环境
- **想做韩国留学 + 韩企在华就业** → 朝鲜语是国内最优路径
- **想用 211 牌子 + 分数不够东北师大** → 延大性价比之王
- **想做民族事务 / 选调生 / 体制内 + 民族特色加分** → 民族学 / 历史学 / 朝鲜语
- **女生 + 文科 + 想做韩语翻译/韩企/留学** → 延大独家路径

## 不适合谁

- **学计算机 / 工科 / 机械 + 想冲大厂** → 延大工科弱,选吉大/哈工大/出省双非强工科
- **学经管 / 金融 + 想冲长三角金融** → 选东财/上财
- **不能接受延吉地理偏 + 小城生活** → 选长春的吉大/东北师大
- **完全不学朝鲜语 / 韩语 / 日语 / 民族特色专业 + 想要 211 牌子** → 性价比下降,**学非特色专业 + 211 牌子 = 延大没那么香**
- **分够吉大** → 别 stuck 延大,985 牌子 + 学科齐全更优
- **想做西医临床顶级** → 选吉大白求恩或大连医科大,延大临床中等
