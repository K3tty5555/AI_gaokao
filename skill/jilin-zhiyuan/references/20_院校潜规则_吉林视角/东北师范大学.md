# 东北师范大学(东北师大,NENU)— 211 师范全国前 5

## 一句话定位

**东三省师范第一**,**6 所教育部直属师范大学之一**(北师大 / 华师大 / 华中师大 / 西南大学 / 陕师大 / 东北师大),**师范全国前 5**,**公费师范生 = 高考分适中 + 直接编制**,留东北当老师顶级路径。**双一流学科:教育学 / 生态学 / 数学 / 化学 / 统计学**。

---

## 真实地位

- **211 + 双一流 + 教育部直属 6 大师范之一**
- **师范全国前 5**(跟北师大 / 华师大 / 华中师大 / 西南大学 同档),**比陕师大更强**
- **吉林本省地位**:**师范类顶配**,留吉当老师 = 东北师大封顶,公费师范名额多
- **校区**:**本部(净月校区) + 自由大路校区**,长春本地,生活便利
- **学风**:师范严肃 + 文科氛围浓 + **男女比严重失衡(女多男少,约 3:7)**
- **东北本省师范生需求大**,东北师大毕业生留东三省当老师就业率 90%+

## 吉林历史类录取位次区间(2024-2025)

- **提前批(公费师范汉语言/历史)**:全省 **800-2,500 名**(历史类公费师范分较高)
- **王牌组(教育学/历史/汉语言/思政)**:全省 **1,500-4,000 名**
- **主流组(普通文科师范类)**:全省 **3,000-6,500 名**

## 吉林文/理科录取位次区间(2021-2023 旧高考)

- **理科**:全省 **5,500-15,000 名**(公费师范物理 5,500-7,500,普通组 8,000-15,000)
- **文科**:全省 **1,500-6,500 名**(公费师范文科 1,500-3,000)

**段位定位**:**吉林物理类省排 18,000 名内可冲东北师大不同方向**,**10,000 名内可挑王牌组**。**公费师范分较高,普通批稳档**。**以一分一段表反查为准**。

## 公费师范生(东北师大最大特色 ★★★)

**公费师范生政策(教育部直属六大师范执行)**:

- **学费 + 住宿费 全免**(国家承担)
- **生活补贴**:每月约 800-1000 元
- **毕业直接编制**:**回原籍服务 6 年**(大多数省份要求)
- **录取分较高**:吉林物理类约 3,500-7,500 名,历史类约 800-2,500 名

**最适合**:
- 普通工薪 / 农村家庭(经济压力大,公费=零成本上 211)
- 父母希望孩子做老师 / 进体制内
- 性格内向稳健 + 想留东北家门口

**最不适合**:
- 完全不想做老师的(公费要求服务 6 年,违约要赔钱 + 影响考公考编)
- 想冲长三角/广东大厂 / 互联网的(公费锁死原籍)

## 性价比专业

- **教育学 / 心理学**:全国前列,**适合读研 + 进高校教育系统 / 教育局编制**
- **公费师范汉语言/数学/英语**:留吉当中学老师 + 编制 + 考公友好,**普通家庭性价比之王**
- **统计学**:双一流学科 + 数据分析就业出路宽,可转互联网/金融
- **生态学**:双一流学科 + 录取分相对低,自然保护区/林业/学术对口

## 坑专业(在东北师大里相对弱)

- **法学 / 经济学 / 金融**:东北师大非财经法律强校,**学法学选吉大,学财经选东财**
- **计算机 / 软件工程**:**师范院校学非师范 CS 是怪胎**,出来跟双非一本 CS 没差,选哈工大 CS 更优
- **教育技术学 / 数学与应用数学(非师范)**:**听起来像师范但不是公费**,**当心被忽悠**
- **工科 / 医学 / 农林**:全弱,**师范学校本来就不是工科基因**

## 关键提醒(填报陷阱)

1. **公费师范生 vs 非公费师范生**:
   - 名字里有"师范"且是**提前批录取** → 公费师范(免学费 + 编制)
   - 名字里有"师范"但是**普通批录取** → 普通师范(自费 + 自找工作)
   - **千万分清,差几十万学费 + 差一个铁饭碗**
2. **服从调剂**:东北师大物理类组内可能含心理学 / 教育技术 / 边缘理科,被调剂的话能不能接受?
3. **公费师范"原籍服务 6 年"是硬约束**:**违约要赔学费 + 写违约记录**,影响以后考公考编。**家长一定要跟孩子聊清楚这 6 年要回原籍**
4. **吉林籍 vs 跨省籍公费师范**:吉林学生上东北师大公费师范,毕业回吉林本地编制;**跨省学生回原籍**(如黑龙江学生回黑龙江,辽宁学生回辽宁)
5. **东北师大 vs 北师大 / 华师大 怎么选**:
   - **同分情况下选北师大 / 华师大**(地理优势 + 校招更广 + 985 牌子)
   - **分数不够 + 想留东北当老师** → 东北师大顶配
   - **分够 985 想做老师** → 北师大全国通用
6. **男女比失衡的现实**:**师范本身原因 + 化学/数学/物理类相对均衡,文科师范类女生占 80%+**

## 毕业出口(2024 数据估算)

- **留吉林就业**:约 **35-40%**(长春 + 各市县中学,公费师范主导)
- **东北其他**:约 **15-20%**(黑龙江 / 辽宁 中学,主要是跨省公费师范回原籍)
- **京津出省**:约 **15-18%**(北京 / 天津 重点中学 / 教育系统 / 互联网教育公司)
- **长三角出省**:约 **12-15%**(上海 / 杭州 重点中学 / 教育公司,**新一线城市抢师范生厉害**)
- **广东**:约 **8-10%**(深圳 / 广州 重点中学,**深圳中学起薪 30w+ 抢师范生**)
- **公费师范生**:**100% 进入教师编制**(回原籍各市县中学)
- **普通师范生**:约 50% 通过省考/市考考编,约 30% 进民办学校 / 培训机构,约 20% 改行
- **考研 / 读博**:约 **20-25%**(化学/数学/统计学保研率较高)
- **起薪范围**:吉林中学教师 6-10w + 编制,京津重点中学 15-25w,深圳重点中学 25-40w(深圳中学顶配)

## 同档对比

| 维度 | 东北师大 | 北师大 | 华师大 / 华中师大 | 陕师大 |
|---|---|---|---|---|
| 综合排名 | 211 | **985** | 211 / 211 | 211 |
| 师范实力 | **东北第 1 + 全国前 5** | 全国第 1 | 全国前 5 | 全国前 5 |
| 留东北就业 | **顶配** | 一般 | 弱 | 弱 |
| 公费师范名额 | 多 | 较多 | 较多 | **多** |

**简单结论**:**吉林学生想公费师范优先东北师大**(留东北 + 离家近 + 名额多);**分数够 985 想做老师选北师大**(全国通用 + 北京机会多);**冲长三角/华南就业选华师大/华中师大**;**陕师大留西北当老师对口**。

## 适合谁

- 吉林物理类 **省排 5,000-18,000 名** + 想当老师 / 进教育系统的考生
- 吉林历史类 **省排 800-6,500 名** + 想当文科老师 / 公考 / 体制内
- **女生 + 想当老师 + 留东北/京津家门口** → 东北师大师范类顶配
- **普通工薪 / 农村家庭** + 想要公费师范零成本 + 编制
- **想学化学 / 数学 / 统计 + 走学术保研路径** → 双一流学科支撑
- **想做行政 / 体制内 / 选调生** → 教育学 / 心理学 / 公管 都是省直机关认可路径

## 不适合谁

- **完全不想做老师的**:公费师范 6 年服务期是硬约束,**违约影响考公考编**
- **学法学 / 财经 / CS** → 选吉大 / 东财 / 哈工大,师范学校学非师范是怪胎
- **男生 + 不喜欢女多男少氛围**:东北师大女生比例 70%+,理科稍均衡
- **分够 985 想做老师** → 选北师大(全国通用 + 北京地理)
- **想冲长三角/广东大厂互联网**:东北师大留东北强,出省互联网弱
- **学工科 / 医学 / 农林** → 东北师大全弱,选吉大或对口院校
