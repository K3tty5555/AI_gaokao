# 长春中医药大学(长中医,CCUCM)— 双非但东北中医药唯一双一流

## 一句话定位

**东北中医药唯一双一流学科建设高校**(双一流学科:中药学),**中医药领域全国前列**,**长白山中药材产地优势 + 跟吉林农业大学人参研究形成产业链协同**。**省属重点 + 国家中医药管理局共建**。**学中医 / 中药 + 留东北 = 吉林本地最强路径**;出省校招认可度好于普通双非中医药校。

---

## 真实地位

- **双非 + 国家中医药管理局 / 吉林省 / 教育部 共建**(行业属性极强)
- **东北中医药唯一双一流学科建设高校**(中药学双一流) → **东北三省中医药领域顶配**
- **吉林本省地位**:**中医药顶配 + 学科独家** + 跟吉农大形成长白山中药材产业链协同
- **校区**:**长春净月校区(本部)**,长春本地,**位置相对偏(净月旅游区)**
- **学风**:中医药严谨 + 古籍 / 实验双管齐下 + **男女比约 3:7**(医学院典型,女生多)
- **就业方向**:中医院 / 药企(同仁堂 / 修正药业 / 通化金马 等吉林药企)/ 体制内中医药管理岗
- **东北中医药 vs 北中医 / 上中医 / 广中医**:**长中医东北顶配,出省看北中医 / 上中医 / 广中医(均为双一流 / 211)**

**段位定位**:**吉林物理类省排 55,000 名内可冲长中医不同方向**,**25,000 名内可挑王牌组(中医/中药/针推)**。**中医学录取分相对较高(中医临床医学需 5 年制 / 5+3),其他专业相对低**。**以一分一段表反查为准**。

## 性价比专业 / 关键路径

- **中药学(双一流学科)**:**全国前 10 + 吉林药企对口** + **保研 / 考研中科院长春应化所 / 北京中医药大学路径顺畅**
- **针灸推拿学**:**国内中医院 + 海外针灸师(海外针灸热,美国/欧洲针灸需求扩张)** + 起薪稳定 + 中医师证书路径
- **中医学 5+3 一体化**:**本硕连读 + 中医师证书 + 进中医院规培直通**,**性价比最高路径**
- **中药资源与开发**:**长白山药材产地独家 + 跟吉农大协同** + 录取分相对低 + 中药企业 / 农林对口

## 坑专业(在长中医里相对弱)

- **护理学**:**双非中医药护理 = 出口窄 + 起薪低 + 工作累**,**学护理出省北医协和护理 / 川大华西护理 才是顶配**
- **公共卫生 / 预防医学**:**双非公卫出口窄 + 疾控编制少**,**学公卫选吉大或医学院**
- **健康管理 / 中医养生**:**听起来时髦但出口模糊**,**主要走民营养生机构 / 自主创业**
- **不学中医中药 + 选长中医**:**学校独家属性是中医药**,**转行竞争力弱**

## 关键提醒(填报陷阱)

1. **王牌专业 = 中医 / 中药 / 针灸推拿**:**非中医药相关专业的报长中医就是浪费学校独家属性**,**学普通医学 / 经管 / 文科直接选其他学校**
2. **中医临床路径 vs 西医临床路径**:
   - **想做西医临床(综合医院主治医师)** → 选**吉大白求恩 / 中国医大 / 大医大** 等西医顶配,**别选长中医的中医临床**(中医临床 = 中医师 + 中医院/中西医结合医院,不进西医综合医院主流)
   - **想做中医师 + 进中医院 / 中西医结合医院** → 长中医顶配
3. **中医学 5+3 vs 5 年制 vs 中西医临床**:
   - **5+3 一体化**:本硕连读 8 年(出来硕士),**主流路径 + 中医院招聘卡硕士**
   - **5 年制中医**:本科 5 年,**必须考研才有医院要**,**实质要 7-8 年**
   - **中西医临床医学**:走综合医院中西医结合科 / 部分综合医院,**比纯中医路径出口宽一档**
4. **海外针灸师路径(关键 ★)**:
   - **美国 / 欧洲 / 澳大利亚 针灸师热度持续** —— 长中医针灸推拿专业有**海外执业资格证培训** + 校际合作
   - **女生 + 想做针灸师 + 海外路径** → 长中医独家
5. **服从调剂注意**:**长中医组内可能调到护理 / 公卫 / 边缘药学**,**接受不了的别勾**
6. **必选化学 + 生物**:吉林 3+1+2 选科,中医药专业必选化生
7. **长中医 vs 吉农大 / 吉大白求恩 怎么选**:
   - **学中医 / 中药** → 长中医东北唯一双一流
   - **学西医临床** → 吉大白求恩(全国前 15)
   - **学农业 / 食品 / 中药资源(产业链端)** → 吉农大
   - **三所协同**:中药学 = 长中医 + 吉农大;西医 = 吉大;互不抢生源

## 毕业出口(2024 数据估算)

- **留吉林就业**:约 **40-45%**(长春 + 各市县,**吉林本土中医院 + 紫鑫药业 / 长白山制药 / 通化金马 等药企 + 中医药管理岗**)
- **东北其他**:约 **10-15%**(沈阳 / 哈尔滨 中医院 + 中药企业)
- **京津出省**:约 **12-15%**(北京 / 天津 中医院 + 同仁堂 / 国药 + 中医药管理局)
- **长三角出省**:约 **15-18%**(上海 / 杭州 / 苏州 中医院 + 中药企业 + 民营中医诊所)
- **广东**:约 **8-10%**(广州 / 深圳 中医院 + 药企 + 中医诊所)
- **海外路径**:约 **3-5%**(海外针灸师 / 中医诊所,**美国/欧洲/澳大利亚** 主流目的地)
- **考研 / 读博**:约 **30-35%**(**保研率约 6-8%**,**北京中医药大学 / 上海中医药大学 / 中国中医科学院 / 长春应化所 是主流去向**)
- **进央企 / 国企概率**:约 **10-15%**(同仁堂 / 国药 / 紫鑫药业 / 通化金马 等中药企业)
- **起薪范围**:**中医院主治医师(规培完 3-5 年后)8-15w / 年**,**针灸推拿师 8-15w / 年 + 私立诊所提成**,**中药企业 10-18w / 年**,**海外针灸师 30-80w / 年(浮动大)**,**护理 / 公卫 5-10w / 年**(差距大)

## 同档对比

| 维度 | 长中医 | 北京中医药大学 | 上海中医药大学 / 广州中医药大学 | 吉大白求恩 |
|---|---|---|---|---|
| 综合定位 | 双非(双一流学科) | **211 + 双一流** | 双一流 / 双一流 | 985(西医顶级) |
| 中医药地位 | **东北顶配** | **全国第 1** | 全国前 5 / 华南顶配 | 弱(西医校无中医) |
| 留东北 | **顶配** | 弱 | 弱 | **西医顶配** |
| 录取分 | 双非中位 | **顶配 211** | 中(双一流) | 高(985) |
| 海外针灸师路径 | **强(校际合作)** | 顶配 | 顶配 | 无 |

**简单结论**:**学中医中药 + 留东北 → 长中医东北顶配**;**分够 211 北中医** → 出省顶配 + 北京地理;**学西医临床 + 留东北** → 吉大白求恩;**学华南中医** → 广中医(同档双一流)。

## 适合谁

- 吉林物理类 **省排 15,000-55,000 名** + 必选化生 + 想做中医师 / 中药 / 针灸推拿 / 留东北 的考生
- **女生 + 想做中医师 / 针灸推拿师 + 出口稳定** → 长中医顶配
- **想做中药学(双一流)+ 进吉林药企** → 紫鑫 / 长白山 / 修正 / 通化金马 等吉林药企对口
- **想做海外针灸师 / 中医诊所** → 长中医校际合作 + 海外执业资格培训
- **接受长春地理 + 净月偏远 + 中医药严谨学风**
- **想做中医院主治医师 + 进中西医结合科**
- **想考中医药管理岗 / 食药监 / 卫健委 中医药口** → 体制内对口

## 不适合谁

- **学西医临床 + 想做西医主治医师** → 选吉大白求恩 / 中国医大 / 大医大,**长中医的中医临床不是西医路径**
- **学护理 / 公卫 / 边缘药学但不爱中医** → **为了"双一流牌子"上边缘专业 = 出口和中医临床差距巨大**
- **没选化学 / 生物** → 吉林 3+1+2,中医药必选化生,**没选别冲**
- **家庭经济一般 + 急需就业挣钱** → 中医师路径 5+3 = 8 年,**经济回报延迟 + 普通家庭压力大**,**学西医或选东电大电气更快变现**
- **学经管 / 文科 / CS** → 选吉大 / 东北师大 / 长理工
- **不喜欢中医药行业 + 想冲互联网/金融/大厂** → 长中医对口中医药行业,互联网就业弱
- **分够北中医(211)** → 别 stuck 长中医,北中医 211 + 北京地理更优
