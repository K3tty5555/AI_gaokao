# 东北电力大学(东电大,NEEPU)— 双非但电气工程国家电网铁饭碗

## 一句话定位

**双非但电气工程全国前列**(类似华北电力 / 上海电力 / 三峡大学 在电气领域),**国家电网对口铁饭碗校**。**东北 / 华北 / 西北 国网招聘对东电大开门**,起薪 8-15w + 编制 + 跨地区流动好。**男生 + 普通工薪家庭 + 想稳定挣钱 → 东电大电气是双非最优路径**。**省部共建高校**(中央 + 吉林共建)。

---

## 真实地位

- **双非 + 教育部 / 国家电网 / 吉林省 共建**(行业属性极强)
- **电力领域"五朵金花"之一**:华北电力(211)/ 上海电力 / 三峡大学 / 东北电力 / 沈阳工程,**东电大跟上海电力 / 三峡大学同档,弱于华北电力(211)**
- **吉林本省地位**:**双非顶配 + 学科独家** + 国家电网对口铁饭碁
- **校区**:**吉林市校区(本部)**,**位于吉林省吉林市**(注意:学校在吉林市,不在长春!)
- **吉林市地理**:长春旁边的工业城市(松花江畔),生活成本低,大学城氛围一般,**比长春小一档**
- **学风**:工科严谨 + 电气硬核 + **男女比约 7:3**(工科典型)
- **就业稳定 + 编制路径 + 起薪 8-15w**(电网正式工)

## 性价比专业 / 关键路径

- **电气工程及其自动化**:**国家电网校招认可度等同 211 电气**,**东北/华北/西北国网招聘对东电大开门**,**起薪 8-15w + 编制 + 跨地区流动好**
- **能源动力工程**:**五大发电集团对口**(华能/大唐/华电/国电/中电投),**火电厂工作稳定 + 编制 + 起薪与电网拉齐**
- **核工程与核技术**:**中广核 / 中核 / 国电投 核电站**对口,**起薪 12-18w + 长期稳定**
- **新能源科学与工程**:光伏 / 风电 / 储能行业窗口期 + 出口扩张

## 坑专业(在东电大里相对弱)

- **非电气类专业(文科 / 经管 / 法学 / 师范类)**:**全弱**,**学文科直接选东北师大或吉大**
- **普通计算机 / 软件工程**:**电力校的 CS = 跟普通双非 CS 没差**,**学 CS 选吉大或哈工大**
- **普通工科(土木 / 化工 / 机械(非电力方向))**:对口性弱,**不走电力的话牌子吃亏**
- **不进电网 + 选东电大**:**学校独家属性是电力**,**不走电力路径 = 转行竞争力弱**

## 关键提醒(填报陷阱)

1. **王牌专业 = 电气 / 能源动力 / 核工程**:**非电力相关专业的报东电大就是浪费学校独家属性**,**学普通工科 / 经管 / 文科直接选其他学校**
2. **吉林市地理的现实**:
   - **学校在吉林市,不在长春**!**很多家长以为东电大在长春,这是误区**
   - **吉林市是长春旁边的工业城市**(开车 1 小时,松花江畔)
   - **生活成本低 + 大学城氛围一般 + 比长春小一档**
3. **国家电网招聘流程关键**:
   - **每年 2 批招聘**(秋招 11 月 / 春招 3 月),**第 1 批进国网核心**(省公司 / 直属单位),**第 2 批进基层**(市县公司)
   - **东电大电气校招进国网概率约 65-75%**(双非里仅次于华北电力)
   - **女生进国网技术岗录取率低**,但**进国网行政岗 / 财务岗 / 党群岗 也认电气专业**
4. **东电大 vs 华北电力(211) 怎么选**:
   - **分够华北电力(211 牌子) + 想冲电网核心 + 京津地理** → 华电(211 + 北京/保定 地理)
   - **分不够华电(211)** + **想进国网铁饭碗** → 东电大 = 双非里仅次于华电的电力校
5. **东电大 vs 长理工 怎么选(吉林双非两强)**:
   - **学电气 / 国家电网 / 工业电气** → 东电大
   - **学光电 / 航天 / 兵器** → 长理工
   - **两条铁饭碗路径,看个人专业方向**
6. **服从调剂**:东电大组内可能调到普通工科 / 经管 / 计算机,**接受不了的别勾**

## 毕业出口(2024 数据估算)

- **留吉林就业**:约 **30-35%**(吉林市 + 长春,**国家电网吉林公司 + 各市县电力公司 + 一汽**)
- **京津出省**:约 **18-22%**(北京 / 天津 国家电网总部 / 设计院 / 央企)
- **长三角出省**:约 **15-18%**(上海 / 苏州 / 杭州 国网华东分公司 / 五大发电 / 设计院)
- **广东**:约 **10-12%**(广州 / 深圳 南方电网 / 央企)
- **东北其他**:约 **15-20%**(沈阳 / 大连 / 哈尔滨 国家电网 / 五大发电)
- **西部**:约 **5-8%**(西安 / 成都 / 重庆 国网西北分公司)
- **进国家电网概率**:**约 50-60%**(电气专业,双非里顶配)
- **进五大发电集团概率**:**约 15-20%**(能源动力 / 热能动力)
- **考研 / 读博**:约 **15-20%**(保研率约 6-8%)
- **起薪范围**:**国家电网正式工 8-15w + 编制 + 房补**,**五大发电 8-12w + 编制**,**南方电网 12-18w**(广东深圳分公司更高),**民企电力相关 10-18w**

| 维度 | 东电大 | 华北电力(211) | 上海电力 | 三峡大学 |
|---|---|---|---|---|
| 综合定位 | 双非电力第 2-3 档 | **211 + 双一流** | 双非电力 | 双非电力(三峡集团对口) |
| 电气工程地位 | 全国双非里前列 | **全国前 5** | 中上 | 中上 |

| 录取分 | 双非中上 | **顶配 211** | 中上 | 中 |

**简单结论**:**分够华电(211) + 想冲北京/保定 → 华北电力**;**分不够华电 + 想进国网/华东** → **东电大(东北/华北方向) / 上海电力(华东方向)**;**分不够双非电力 + 想稳定** → 三峡大学(三峡集团对口)。

## 适合谁

- 吉林物理类 **省排 12,000-45,000 名** + 物理化学好 + 想进国家电网 / 五大发电的考生
- **男生 + 普通工薪家庭 + 想稳定挣钱 + 进国企编制** → 东电大电气是双非最优路径
- **接受吉林市地理 + 工业城市 + 大学城氛围一般**
- **想做电力技术岗 / 设计院 / 五大发电火电厂**
- **想跨地区流动**:国网在全国各省都有公司,**电气专业全国通用**
- **女生 + 想进电网行政岗 / 财务岗 / 党群岗** → 也认电气专业
- **农村家庭 / 工薪家庭男孩 + 不挑工作地点 + 想稳定铁饭碗**

## 不适合谁

- **学非电力方向 + 想用东电大牌子** → **学校独家属性是电力,非电力纯属浪费**,选其他学校
- **学经管 / 文科 / 师范 / 法学** → 选东北师大 / 吉大
- **女生 + 想做技术岗 + 想冲互联网/金融** → 国网技术岗女生录取率低,**学 CS / 财经 选吉大/东财**
- **分够华北电力(211)** → 别 stuck 东电大,华电 211 + 北京地理更优
- **不能接受吉林市地理 + 工业小城** → 选长理工(长春)或其他大城市电力校
- **想做大厂互联网 + 高薪** → 东电大对口电力国企,互联网就业弱
- **不喜欢电力行业的稳定性 + 想冒险创业** → 国网过度稳定,跳槽难
