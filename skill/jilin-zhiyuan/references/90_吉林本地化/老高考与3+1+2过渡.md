# 吉林高考:老高考 → 3+1+2 过渡(2024 首届)

## 核心结论

**吉林是 2021 年加入新高考第四批的省份**(跟黑龙江/甘肃/吉林/安徽/江西/贵州 7 省同批),**2024 年才迎来首届 3+1+2 高考**(高一 2021 入学的那批 → 2024 高考)。

**这意味着**:
- **2021-2023 高考还是老文理分科**(文综 / 理综,750 分制)
- **2024-2025 高考才是新 3+1+2**(物理类 / 历史类)
- **历史录取数据断裂**:2024 之前的"理科一本线"和 2024 之后的"物理类本科线"不能直接换算

**这是吉林 agent 必须先告诉用户的第一件事 —— 数据稀缺 + 类型断层 + 预测精度受限**。

- 不要拿 2023 理科分直接当物理类参考 —— 物理类 ≠ 老理科,赋分 + 选科分组都变了

## 二、3+1+2 考试结构

### 总体框架
- **3 = 语文 + 数学 + 英语**(全国卷,各 150 分)
- **1 = 首选科目**:物理 OR 历史(2 选 1,各 100 分,**用原始分**)
- **2 = 再选科目**:化学 / 生物 / 政治 / 地理(4 选 2,各 100 分,**用赋分制**)
- **总分 = 750 分**

### 物理类 vs. 历史类
- **物理类**(类型代号同其他 3+1+2 省) — 选物理为首选
- **历史类** — 选历史为首选
- 吉林物理类约 65%,历史类约 35%(参考 2024-2025 比例)

### 院校专业组(吉林本科批)
- 按"院校专业组"投档,**服从调剂只在本专业组内**
- 一个专业组内通常 5-15 个专业
- **吉林本科批志愿数量:60 个**(物理类 / 历史类各 60 个院校专业组,**远多于江苏 40 / 湖北湖南 45**)
- 这意味着**吉林考生填报时有更多保底空间,但筛选成本也高**

## 三、吉林特殊性(关键!!)

### 1. 吉林 985/211 数量结构小但质量集中
- **1 所 985**:**吉林大学**(综合性巨无霸,合并 5 所老校)
- **2 所 211**:**东北师范大学** + **延边大学**
  - 东北师大是 211 师范 + 双一流
  - **延边大学是民族类 211 + 双一流**(全国 5 所民族 211 之一,延吉)
- **没有别的 985/211**,但本省双非里有几所专业王牌(长理工光学、东电大电气、吉农大人参)

**对比东三省**:
- 黑龙江:1 所 985(哈工大,工科顶级)+ 3 所 211(哈工程 / 哈尔滨医大 / 东北农大)
- 辽宁:2 所 985(大工 / 东大)+ 2 所 211(辽大 / 大连海事)
- **吉林:1 所 985 + 2 所 211**,数量少但**吉大综合性 + 东北师大师范 + 延大民族特色**结构互补

### 2. 吉林考生数量小 → 本科分数线偏低
- 吉林高考考生约 **12-13 万 / 年**(**全国最小省之一**,仅多于西藏/青海/宁夏/海南)
- 对比:湖北 ~50 万、湖南 ~60 万、江苏 ~40 万、河南 ~130 万
- **考生体量小 + 名额相对宽松**,本科分数线偏低
  - 2024 物理本科线 345 分(同期湖北 437 / 江苏 462)
  - 2024 历史本科线 369 分(同期湖北 432 / 江苏 478)
- **但分数线低 ≠ 考生水平低,吉林考生位次思维更重要,看位次别看分数**

### 3. 留吉率仅 30-40% — 出省战略刚需
- 吉林经济结构偏老工业 + 国企 + 林农,**民企就业弱,毕业生大量外流**
- 留吉就业率仅 **30-40%**(对比辽宁 50%、黑龙江 40%)
- **典型流向**:京津 / 长三角 / 广东
- **典型反常识**:吉林考生用本省分数(分数线低)能换到出省 211/985 + 留京津长三角就业,这是吉林高分段的最优解

### 4. 数据现状(关键提醒)
- **2021-2023 文/理数据**:在数据库里,但**不能直接当 3+1+2 参考**
- **2024-2025 物理类/历史类数据**:首届 + 第 2 届,**样本小,大小年波动大**
- **预测精度声明**:agent 给推荐时必须主动说"基于 2024-2025 两年数据,首届新高考样本有限,大小年风险约 ±2000-3000 名,实际填报请结合招生章程"
- **数据缺失场景**:某些专业组只有 1 年数据(2025 新设)→ 标注"仅 1 年数据,趋势未知"

## 七、易错认知(agent 要纠正用户的)

### 误区 1:吉林本科线低,孩子分数低没希望
**错**。吉林考生体量小 + 名额宽松,**分数线低是结构性的,不是孩子水平低**。**看位次别看分数** —— 这是吉林考生第一课。物理类 600 分在吉林大约对应 5000-6000 名,跟其他省 985 分数段的位次基本一致。

### 误区 2:2024 之前的吉大录取分可以直接参考
**错**。2024 之前是老文理分科,**理科一本线 ≠ 物理类本科线**,赋分制 + 选科分组完全变了。**只看 2024-2025 两年新高考数据**,2023 之前的数据当历史参考即可。

### 误区 3:吉林大学合并校,牌子水
**严重错**。**吉大确实合并了 5 所老校(原吉大 + 吉工大 + 白求恩医大 + 长春科技大 + 长春邮电),校区分散是缺点,但学科底子是优点** —— 白求恩医大临床医学全国前列、原吉大法学/化学/材料/计算机全国前列。看专业别看综合排名。

### 误区 4:延边大学是少数民族学校,牌子水
**错**。**延边大学是 211 + 双一流,朝鲜语全国第 1**,对口朝鲜 / 韩国 / 日本三国,留学日韩通道极强。**民族类 211 牌子在京津长三角不吃亏**,公考 / 选调 / 国企校招都认。

### 误区 5:留吉好,东北经济回暖了
**错**。**留吉率仅 30-40%**,毕业生大量外流。东北经济衰退是结构性的,**国企铁饭碗多 + 民企就业弱**。高分段考生(物理类前 5000)留吉就业 = 主动放弃京津长三角薪资。**用本省分数线低的优势换出省 211/985 + 留京津长三角**,是吉林高分考生的常态。

## 九、吉林 3+1+2 选科组合详细评估

### 12 种组合在吉林的真实选择率(2024-2025 估算)

| 组合 | 物 / 史 | 选择率 | 可报专业范围 | 评价 |
|---|---|---|---|---|
| 物 + 化 + 生 | 物理类 | ~25% | **97% 专业** | 万金油,医学 / 理工 / 农林全开放 |
| 物 + 化 + 地 | 物理类 | ~12% | 96% | 工科 + 地学,留地学专业弹性 |
| 物 + 化 + 政 | 物理类 | ~10% | 96% | 工科 + 考公友好,**男生考公推荐** |
| 物 + 生 + 政 | 物理类 | ~8% | 90%(医学受限) | 一般 |
| 物 + 生 + 地 | 物理类 | ~7% | 89% | 一般 |
| 物 + 政 + 地 | 物理类 | ~3% | 80% | **慎重**(理工受限,文理混报) |
| 史 + 政 + 地 | 历史类 | ~22% | **传统文综** | **文科首选** |
| 史 + 政 + 生 | 历史类 | ~6% | 偏文 + 部分医学 | 偏文 |
| 史 + 化 + 地 | 历史类 | ~3% | 罕见 | 慎重 |
| 史 + 化 + 生 | 历史类 | ~2% | 罕见 | 慎重 |
| 史 + 政 + 化 | 历史类 | ~1% | 罕见 | 慎重 |
| 史 + 生 + 地 | 历史类 | ~1% | 罕见 | 慎重 |

**吉林考生最常见的 4 种组合**:物化生(理工医万能)/ 史政地(文综传统)/ 物化政(工科 + 考公)/ 物化地(工科 + 地学)。

### 吉林考生选科常见失误

**失误 1:朝鲜族考生选物化生想做医生 → 后悔没选政治**
- 朝鲜族学生很多想留延边自治州做民族岗医生
- **延边自治州民族岗位部分要求政治** —— 选物化生组合后可报民族岗减少
- **朝鲜族 + 延边自治州目标 → 物化政 / 史政地 + 朝鲜语优势** 更对口

**失误 2:工人家庭男生只选物理 + 化学 + 政治,后悔不能学医**
- 物化政可以报绝大部分工科 + 考公友好
- **但部分医学院要求"再选必含化学和生物"**(临床医学严格)
- 男生想保留医学选项 → 物化生最稳

**失误 3:文科生不选政治,后悔不能进体制内**
- 史政地是文综经典 → 考公 / 选调几乎全开放
- **史化地 / 史化生 / 史生地** = 不能报警校 / 国际关系 / 思想政治教育 师范
- **文科生想考公 → 政治必选**

**失误 4:物理 + 政治 + 地理 = "想保留考公又想学工科" 半文半理**
- 看起来灵活,**实际很多工科要求"再选化学"**(化工 / 材料 / 部分电气 / 部分医学)
- 物政地能报的工科有限,**真正灵活的是物化政**

## 十、吉林新高考填报 - 实操陷阱清单

### 陷阱 1:专业组志愿排序失误
- 吉林 60 个志愿组按"冲稳保"梯度排列 —— **典型分配:冲 15 个 / 稳 30 个 / 保 15 个**
- **新高考首届 + 第二届数据**,大小年波动可能 ±2000-3000 名,**保底要保得更厚**(冲稳保比例可调整为 12 / 30 / 18)

### 陷阱 2:服从调剂的吉林本地实际意义
- **吉大 / 东北师大 等顶级学校** —— 服从调剂可能调到边缘专业(吉大农学 / 东北师大教育技术),**接受不了别勾**
- **吉农大 / 长理工 / 东电大 等行业校** —— 不勾就有滑档风险,**勾的话评估"组内最差专业"**
- **吉林本地家长建议**:**服从调剂 + 接受非王牌专业 + 二次跳板(考研换专业 / 转专业 / 辅修)**

### 陷阱 3:再选科目限制(2024-2025 实测)
- **临床医学 / 口腔 / 中医临床 / 部分护理** = 必选化学 + 生物
- **化学化工 / 材料 / 食品 / 农学** = 必选化学
- **马克思主义理论 / 国际关系 / 公安院校** = 必选政治
- **地质 / 地理 / 测绘**(部分院校)= 必选地理

### 陷阱 4:吉林本地特殊招生类型(必报)
- **公费师范生(东北师大)** — 提前批,免学费 + 编制
- **公费医学生 / 中医订单定向** — 提前批,服务县乡
- **国家专项计划** — 吉林农村户籍,985/211 名校多个专项指标(分数比统招低 25-30 分)
- **少数民族预科** — 朝鲜族 / 满族 / 蒙古族 / 回族 集中地区,**降分录取 + 预科 1 年**
- **强基计划**(吉大化学 / 数学 等) — 单科特别强可冲

### 陷阱 5:大小年波动应对
- 吉大 / 东北师大 等热门校的大小年波动可能 ±2000 名
- **应对策略**:**冲档校选 2024 + 2025 两年都低位次的"冷门组"** + **稳档校多放 30 个 + 保底校扎实**

## 十二、吉林考生填报心态指南

### 错误心态 1:"分数高就该上吉大"
**纠正**:**吉大不同专业差距大,选错专业 = 选错学校**。物理类 5500 名上吉大可能进的是边缘工科,远不如同分的长理工光电 / 东电大电气对口。**看位次 → 看专业组 → 看专业**,三层穿透。

### 错误心态 2:"吉林经济不行,孩子必须出省"
**纠正**:**留吉 vs 出省 不是非黑即白**。东北师大公费师范 / 东电大电气 / 长中医中药 / 吉大白求恩临床 → 这些留吉路径的稳定性 + 编制 + 父母在身边,**对普通家庭比"出省双非折腾"更稳**。

### 错误心态 3:"考公太卷,学技术才是真本事"
**纠正**:**吉林本地的"技术活路"主要是国家电网 / 一汽 / 中车 / 中科院光机所** —— 这些都需要对口专业 + 学校层次。**双非 CS / 普通工科 留吉本地的工资和编制不如汉语言考公 / 公费师范** —— "技术 vs 考公"二选一在吉林并非考公输,需具体看路径。

### 错误心态 4:"必须 985,211 不行"
**纠正**:**吉林只有 1 所 985(吉大),分够吉大主流组的考生不到全省前 5000**。**用本省分数线低的优势出省 211(华北电力 / 华师大 / 西电 / 哈工程 等) → 比吉大边缘组 + 留东北 性价比可能更高**。

### 错误心态 5:"延边大学是民族校,牌子水"
**纠正**:**延大是 211 + 双一流(朝鲜语全国第 1)**,在京津长三角校招认可度跟普通 211 等同。**朝鲜族学生 + 朝鲜语 + 民族优惠 = 三重红利**,这是其他省份没有的吉林独家路径。
