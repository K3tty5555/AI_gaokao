# 考公优选专业表(吉林本地视角)

## 核心结论

**专业决定考公选岗范围**。吉林家长普遍不知道:**有些专业能报的岗位是其他专业的 3-5 倍**。如果家长 / 学生明确目标是考公,**专业选择应该围绕"可报岗位多 + 竞争相对小"展开**,而不是看专业本身的"高大上"程度。

**吉林考公的特殊红利**:
- **吉林公务员系统体量适中,竞争烈度低于河南 / 山东 / 江苏**
- **东北经济结构 = 体制内是稳定核心** —— 父母对孩子考公的支持度全国最高之一
- **吉林选调生倾斜本省 985/211**:吉大 / 东北师大 / 延大 三校 + 出省 985/211 吉籍学生 = 选调主力
- **基层艰苦边远岗位补贴高**(延边 / 白山 / 长白朝鲜族 / 西部白城)

## 关键事实(2024 国考 / 吉林省考分析)

### 国考可报岗位数 排名(Top 10 大类)
1. **法学** — 法院、检察院、监狱、纪委监委等 → 约 18% 岗位
2. **财政学 / 经济学 / 会计学** — 财政、税务、海关、银保监 → 约 15%
3. **汉语言文学 / 中文 / 新闻** — 综合岗、办公室、宣传 → 约 13%
4. **计算机 / 软件工程** — 信息岗、网信办 → 约 10%
5. **统计学 / 经济统计** — 统计局、税务 → 约 5%
6. **公共管理 / 行政管理** — 一般综合岗 → 约 5%(实际不如"汉语言"好)
7. **马克思主义理论 / 思想政治教育** — 党群岗、宣传部门 → 约 4%
8. **审计学 / 监察** — 审计局、纪委 → 约 3%
9. **医学相关** — 卫健委、疾控、医院管理 → 约 3%
10. **外语(英语 / 朝鲜语 / 日语 / 俄语)** — 外交部、海关、商务部、**吉林边境民族岗** → 约 2-3%

### 吉林省考特殊性
- 吉林省考 + 长春市考,**汉语言文学和法学并列考公第一专业**
- **延边自治州岗位** —— **朝鲜语 / 民族学 / 少数民族类专业 = 独家通道**(汉族考生没机会),**朝鲜族考生考延边州编制极有优势**
- **吉林边境市岗位**(白山 / 通化 / 延边)对**朝鲜语 / 俄语 / 日语 + 法学 / 行政管理** 有定向需求
- **基层乡镇公务员**:岗位多,大类放宽,但**汉语言、行政管理、法学**仍占主流
- **三不限岗位**(对专业不限制):**所有人都能报,但竞争最激烈**(经常 500-800 比 1)
- **吉林本地 vs 出省回吉考公**:吉林本地高校(吉大 / 东北师大 / 延大)毕业生 + 吉籍学生有"在地校友网"优势

### 选调生(不是普通公务员,是高潜力路径)
- 选调生 = 党政机关后备干部储备,**起点比普通公务员高**
- **985/211 才有资格报**(吉林本地的选调生定向计划基本只对**吉大 + 东北师大 + 延大** + 部分省外 985/211 吉籍学生)
- 优势专业:**法学、汉语言文学、马克思主义理论、行政管理、经济学、思想政治教育**
- **吉林选调主力供给**:吉大法学 / 吉大化学 / 东北师大教育学 / 延大民族学 是主要来源

### 公检法岗位的硬要求
- **公安**:多数岗位要求"公安专业"(**中国刑警学院 在沈阳辐射东三省 + 中国人民公安大学** 等)+ 通过**公安联考**
- **法院、检察院**:大多数岗位要求**法律相关专业 + 法考通过**(法考资格证)
- **监狱、戒毒**:法学 + 监狱学,**吉林本地中国刑警学院 / 吉大法学 对口**
- **吉林边境派出所** —— 朝鲜语 / 俄语 + 公安专业 = 民族地区岗,补贴高

## 吉林本地院校 × 专业组合(考公视角)

### 985/211 + 强势考公专业
- **吉林大学法学** — **东北法学顶级,全国前 10**,**法考通过率高,选调路径最优**(吉林选调主力供给)
- **吉林大学汉语言文学 / 哲学** — 985 牌子 + 文科底子,**留吉考公 / 出省回吉籍选调** 双稳
- **吉林大学经济学院 / 商学院** — 综合就业 + 考公双友好,**吉林税务 / 海关 / 银保监 校招对口**
- **东北师大公费师范汉语言 / 思想政治** — **不是考公但是教师编制**,等同于考公友好;**思想政治教育是吉林党政干部主要供给专业之一**
- **东北师大教育学 / 历史学** — 全国前 5,**进吉林教育系统 / 文物文化系统体制内顺利**
- **延边大学朝鲜语 / 民族学 / 朝鲜文学** — **延边自治州岗位独家通道**,朝鲜族学生 + 朝鲜语母语优势 = 边境民族岗

### 双非 + 性价比考公专业
- **北华大学 / 长春大学 / 吉林师范大学(四平) 汉语言文学 / 法学** — 二本中等,但**汉语言是吉林省考王者**,毕业考公成功率高
- **吉林师范大学(四平) 思想政治教育** — 师范二本,**进吉林乡镇公务员 / 中学政治老师 双稳**
- **长春师范大学 汉语言** — 同上,长春本地认可
- **吉林警察学院** — **本省公安系统对口** —— 但比中国刑警学院差一档,**主要面向吉林本地基层警察岗**

### 公安系统专属
- **中国刑警学院(沈阳)** — **东三省公安最强校,辐射吉林**,公安联考路径,**毕业进东三省公安概率极高**
- **中国人民公安大学(北京)** — 全国顶配,本科即可,公安联考 + 系统内最佳起点
- **吉林警察学院** — 本科,**毕业进吉林本地公安概率高**(基层警察)
- 吉大法学的**侦查学 / 监狱学** — 进司法系统

## 典型 case(供 agent 引用)

- **Case A(逆袭路径)**:吉林通化考生,540 分文史类,**普通农村家庭**。家长本想报"国际经济与贸易"(听起来高大上)。**改报北华大学汉语言文学**,毕业当年考上吉林省直某机关公务员,**家庭命运改变**
- **Case B(选调路径)**:长春考生,640 分文史类,中产家庭。家长想报"金融"(吉大经管)。**改报吉大法学**,**毕业获得吉大选调生资格,直接进吉林省委组织部**,起点远超经济学就业
- **Case C(失败路径)**:吉林市考生,580 分理科,普通家庭男生。家长想"考公兜底"。**报了长春工业大学计算机**(以为计算机考公也行)。**毕业考公发现:可报岗位远少于汉语言**,2 年没考上,**改行做软件外包但因学校层次不够薪资也低,两头不靠**
- **Case D(误区路径)**:吉林家长以为"行政管理"是考公专业 — **错**。公共管理 / 行政管理虽然听起来对口,但**实际可报岗位数比汉语言、法学都少**,**本科水分大,考研也卷**
- **Case E(朝鲜族特色路径)**:延吉朝鲜族家庭考生,510 分历史类。**改报延边大学朝鲜语 + 民族学双修**,**毕业考延边自治州民族事务委员会** —— 朝鲜族 + 朝鲜语母语 + 211 牌子 = 三重优势,延边民族岗对口录取,起薪不高但**编制 + 民族地区补贴 + 离家近**
- **Case F(警校路径)**:四平农村男孩,560 分物理类。**报中国刑警学院公安专业**,4 年学费全免 + 公安联考通过 → **进吉林省公安厅基层岗位**,**家庭跨阶级的最稳路径之一**

## 易错认知(agent 要纠正用户的)

- "**学公共管理 / 行政管理就是考公的**" — 错。**汉语言、法学的考公优势远超公共管理**
- "**理科生不适合考公**" — 错。理科生考公完全可以,**只是学专业要选汉语言、法学、经济学等文科为主的考公友好专业**(吉林 3+1+2 制度允许首选物理报多数文科专业)
- "**计算机 / 会计也能考公,选这个就稳了**" — 半对。**计算机考公岗位有但少**,本科学计算机的考公成功率显著低于汉语言;会计考公还行但要学会计相关
- "**985 牌子大,什么专业都行**" — 错。**985 + 烂专业(国贸、工商管理) = 不如 211 + 好专业(法学、汉语言)**(考公视角)
- "**警察就是公务员**" — 半对。公安体系是公务员但要走"公安联考"专门通道,**多数公安岗位只对公安专业开放**
- "**选调生比考公好考**" — 错。选调生 = 985/211 才有资格,但是**资格内的竞争小**,所以**对吉大 / 东北师大 / 延大 学生而言**,选调生比国考省考好考
- "**汉语言文学就是当老师**" — 严重错误。**这是吉林家长头号误区**,详见 `10_行业就业潜规则/汉语言_新闻.md`
- "**朝鲜语没用,不如学英语**" — 严重错误。**朝鲜族考生 + 朝鲜语 = 延边自治州民族岗独家通道**,这是其他外语无法替代的红利
- "**东北师大不是考公校**" — 错。**东北师大思想政治教育 / 教育学 / 历史学** 是吉林党政机关 + 教育系统的主要供给专业,**选调指标比想象的多**

## 关键提醒

**考公是吉林普通家庭最稳定的上升通道**,**比湖北 / 江苏 / 河南更稳** —— 因为:
1. **吉林考生体量小(12 万)**,本省公务员岗位竞争烈度低于河南 / 山东
2. **东北经济结构 = 体制内核心** —— 体制内招聘机会比民企机会多
3. **吉林选调倾斜本省高校**(吉大 / 东北师大 / 延大) —— 985/211 学生选调成功率高于其他省

如果家庭已经倾向考公,**专业选择必须围绕"可报岗位多"和"对口岗位竞争小"两个维度**,而不是表面的"专业高大上"。

**汉语言文学是吉林家长被严重低估的考公王者**。

**朝鲜族学生不要错过延大朝鲜语 + 延边民族岗这条独家路径** —— 这是吉林独有的、其他省份没有的考公红利。
