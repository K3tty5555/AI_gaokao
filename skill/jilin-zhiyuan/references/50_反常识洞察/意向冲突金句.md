# 用户意向冲突 — Reality Check 金句库(吉林视角)

很多家长 / 考生有具体的意向("想上吉大"、"非北京不去"、"想学医"),但**意向不一定跟分数匹配**。Agent 不能盲从意向(否则就跟"AI 数据查询工具"一样无脑) — 必须做 reality check + 给出替代方案。

本文是张雪峰式金句模式总结(基于公开直播 / 视频内容学习,**agent 不冒充其人设,只学方法论**)。

---

## 核心原则

1. **直说不可达** — 客观差距 30 分 / 2 万位次以上,**不要绕弯子**。家长来咨询不是听安慰话,是要决策。
2. **给等价替代路径** — 拒绝意向之后必须给"相同方向 + 分数能达"的替代,否则家长会茫然
3. **意向是软偏好** — 可达就优先满足;边缘就明确权衡;不可达就 reality check
4. **学校跟你 4 年,专业跟你一辈子** — 名校弱专业 vs 双非强专业,**不一定名校赢**(张雪峰核心观点之一)
5. **吉林普通家庭别被情怀绑架** — 长周期赛道(医、法、艺、博士导向)对普通家庭抗风险能力差,要硬讲清楚
6. **吉林考生用本省分数线低换出省** — 这是吉林独家战略,意向冲突时要记得这条退路

---

## 4 类意向冲突 + 金句模板

### 模式 A:不可达型 — 分数差距 >30 分 / >2 万名

**特征**:用户意向校 / 意向城市,跟分数完全不匹配(如 480 分要清华 / 530 分要吉大临床)。

**金句模板**:
> "你说想上 [意向校],客观说就是**不可能** — 这分数到 [意向校主流组] 差 [X 万名]。
>
> 但同档你能上 [替代校 1] / [替代校 2],这俩在 [本地 / 行业] 的认可度,**对你父母这个层级的就业资源来说不输 [意向校] 的弱专业**。
>
> 你愿意把 [意向校] 当作 985 牌子的执念,还是把 [替代校] 当作 211 强专业的实力?这两条路出来 5 年后差距没你想的那么大。"

**真实案例(吉林 530 分,意向吉大临床)**:
> "吉大临床 5+3 一体化在吉林物理类 800-2,500 名,你 18,000 名,差 1.6 万名,**吉大临床没戏**。
>
> 但你能上**长春中医药大学中药学(双一流)**+ **延大临床(211)+ 民族优惠** + **北华大学医学院(吉林市)+ 留吉就业认可**。这三所留吉就业,**吉林本地医院招聘里跟吉大临床冷门方向同档**(都是'吉林本地医学 + 留东北')。
>
> 想做医生 → 北华医学院 + 5 年本科 + 考研到吉大白求恩(二次跳板路径)
> 想做技术岗 → 任何一所的医学影像 / 检验 / 护理(4 年本科直接进医院)
> 想留长春产业链 → 长春中医药大学中药学(双一流 + 修正药业对口)"

---

### 模式 B:边缘可达 — 意向校能擦但只能进冷门专业组

**特征**:用户分数刚好够意向校,但只能进生化环材 / 哲学 / 农林等冷门组。**张雪峰最反对的就是这种"为名校而吃专业坑"**。

**金句模板**:
> "[意向校] 你能擦边冲,但**只能进 [冷门组,如材料 / 化工 / 哲学]**。
>
> 你父母可能觉得'985 就是 985',但 **985 的材料 / 化工(生化环材天坑)出来,本科直接就业惨,工资比双非 CS 还低**。
>
> 学校跟你 4 年,专业跟你一辈子。建议**主推 [对应方向的双非顶配 / 211 主流组]**,[意向校] 冷门组留一个冲档位但不主推。"

**真实案例(理工科 + 普通家庭)**:
> "吉大你 590 能冲 — 但只能进生命科学 / 农学 / 边缘文科。**985 牌子 + 校区分散 + 生化环材** = 三重坑(吉大新民 / 朝阳校区位置偏 + 设施老)。
>
> 同分能上的**长春理工大学光学工程**(双非但全国前 5,长春光机所血脉)出来对口程度更高 —— **进航天 / 中科院光机所 / 兵器系统的软件硬件岗**,起薪 10-15w + 涉密项目奖金。
>
> 冲吉大留一个心理慰藉位即可,**主推长理工光学工程**。"

**另一个案例(吉林 600 分理工男 + 想要 985 牌子)**:
> "你 600 分能擦吉大,但只能进吉大材料 / 部分边缘工科。**吉大材料是 985 + A 学科,但 '材料 = 生化环材天坑' 行业本身困境**,本科出来很难直接就业。
>
> 同分能上**东北师大化学(双一流学科 + 师范) + 公费师范物理(免学费 + 编制) + 长理工光电(双非但行业内强校)**。东北师大化学保研出国通道顺畅;公费师范是稳路;长理工对口长春光机所。
>
> **吉大材料 vs 这三个 → 5 年后差距没你想的那么大,某些路径甚至是反超**。"

---

### 模式 C:意向方向 vs 家庭抗风险 — 长周期赛道劝退

**特征**:用户想学医 / 法学 / 学术(博士导向)等长周期赛道,但家庭是普通工薪 / 农村,**撑不起 5+3+8 / 30 岁前不挣钱**。

**金句模板**:
> "[意向专业,如医学] 我理解你的想法。但 [意向专业] 是 [N] 年起步路径 — [本科 5 + 研究生 3 + 规培 N] 才能稳定就业,**普通家庭撑不起 30 岁前不挣钱**(张雪峰原话)。
>
> 你父母的承受力到哪儿?
> - 撑得起 → 走 [意向专业] 顶级方向(如 [清华临床 / 吉大白求恩八年制])
> - 撑不起 → 走 **[替代短路径]**(如 [医学影像 / 麻醉 / 口腔本科 5 年制] — 早 3 年挣钱),或者直接放弃 [意向方向] 转 [务实方向]"

**真实案例(吉林普通家庭 + 想学医)**:
> "学医本质是 8 年起步:5 年临床本科 + 3 年规培,**期间月薪 6-8k**(吉大附属医院规培生工资,东北医院规培收入比北上深低)。普通工薪父母还要供 8 年。
>
> 撑得起 → 推**吉大白求恩临床 5+3 一体化 / 八年制**,长期天花板高,**留东北就业认可顶配**(吉大附属医院 + 东三省三甲网络)。
>
> 撑不起 → **建议口腔(吉大口腔全国前 10,5 年本科直接进诊所)/ 中医(长春中医药大学双一流,5 年本科进中医院)**,或者**医学影像 / 检验 / 护理(4 年本科直接进医院技师岗,起薪 6-10w)**。
>
> 农村家庭 → **直接劝退临床** → 吉大白求恩医学影像技术(国家专项,分低 25 分)/ 北华医学院本科,**4 年直接进医院,父母不用供长周期**。"

---

### 模式 D:意向城市 vs 院校层次 — "非 X 城不去" / "必须留长春" / "必须出东北"

**特征**:用户只想留某个城市("非北京不去" / "非长春不去" / "必须出东北"),拒绝意向以外的选择。

**金句模板**:
> "你只想留 [意向城],那同档要在 [意向城 + 211] 和 [外省 + 985 弱专业] 之间选。
>
> **留 [意向城] 211 反而更稳** —
> - 当地校友网密度大,体制内 / 国企招聘有'本地优势'
> - [外省 + 弱专业 985] 牌子硬但专业坑,**毕业回 [意向城] 没竞争力**
> - 留 [意向城] 你父母也安心
>
> 但!如果你想做的方向 [意向城] 没强校(如想学航天 → 留北京没意义,要去西工大),**要灵活退一步**。"

**真实案例(吉林家庭 + 必须留长春 + 590 分)**:
> "你只留长春,这位次 9000,吉大主流组 / 东北师大主流组 都能擦边或稳上。
>
> **留长春最稳路径**:
> - 男生工科 + 求稳 → **东电大电气 + 国家电网** ★(吉林市,长春旁边,父母满意 + 编制 + 起薪 8-15w)
> - 男生想要 985 牌子 → 吉大主流组(机械 / 电气 / 化学 / 数学),做好出省找实习的心理准备
> - 女生 + 想当老师 → **东北师大公费师范汉语言 / 数学 / 英语**(免学费 + 编制 + 留长春)
> - 女生 + 想进医院 → **吉大白求恩医学影像 / 检验 + 长春三甲就业**
>
> 不要为了'外省 985 牌子'去东北农大 / 兰大冷门 — 牌子有了但**人脉断了 / 实习机会少了 / 长春户口没了**,综合不划算。"

**另一个案例(吉林家庭 + 必须出东北)**:
> "你坚决要出东北 + 590 分物理,这分数出省去 985 弱专业(末流 985 的生化环材)还不如**留吉大主流组 + 985 牌子 + 留东北就业稳**。
>
> 但如果想要的是'**北上深一线城市生活体验 + 互联网产业土壤**',那确实要出省 —— 推荐:
> - **北邮 / 西电 / 哈工大 CS**(分数擦不上 → 长理工 CS + 考研到这些校二次跳板)
> - **东财(沈阳)/ 山东大学经管**(吉林分数能擦,出省东三省以内不算'真出东北'但比留吉就业宽)
> - **南开 / 天大**(分数够的话直接出省一档,京津地理 + 综合 985 + 北方文化)
>
> **吉林 590 分的最优解不是'必须出东北'**,而是'吉大主流组 + 用本省 985 牌子 + 接受出省找工作'。学校在吉林,工作可以在京津长三角,这条路才是吉林考生的隐形红利。"

**第三个案例(吉林朝鲜族家庭 + 必须留延边)**:
> "你朝鲜族 + 想留延边 + 530 分历史类,这条路非常清晰 —
>
> **首选延边大学朝鲜语 / 民族学 / 朝鲜文学 / 临床医学**(211 + 双一流 + 民族优惠)→ 毕业回延吉考公 / 进朝韩对接产业 / 韩国留学,**朝鲜族 + 朝鲜语母语 + 211 牌子 = 三重优势**,延边自治州民族岗对口录取。
>
> 不要去外省学英语小语种,不要去内陆 985 学非朝鲜语方向 —— **延边大学留延边的性价比是吉林考生独有的,你的最优解就在这里**。"

## Agent 处理意向的 4 步

收到 L4.5 意向锚点后,**强制做这 4 步**:

1. **比对位次差距** — 用 score_to_rank 拿用户位次,跟意向校历年最低位次对比
2. **打 3 档**(可达 / 边缘 / 不可达)
3. **直接告诉用户** — 不可达就说不可达,边缘就讲"专业坑 vs 牌子"权衡
4. **给等价替代** — 不可达 / 不主推时,**必须给具体的替代校 / 专业 / 路径**,不能只拒绝不指方向

**禁止的反面行为**(实测踩过的坑):
- ❌ 委婉绕弯子("你这分数报这个学校可能有点紧张...") — 家长听不懂,等于白说
- ❌ 盲从意向("你想上 X,那我就推 X 的冷门组给你") — 这是数据查询工具,不是咨询师
- ❌ 拒绝但不给替代("X 不可能") — 家长更慌,不知道接下来怎么办
- ❌ 用"建议"代替"判断"("可以考虑 / 也许可以试试") — 弱化了判断,让家长无从选择

## 当意向跟 rubric 推荐冲突时的输出处理

### 推荐输出双轨

如果意向是**可达**:推荐时优先满足意向 — 卡片里 highlight "**符合你意向城 / 校 / 专业**"。

如果意向是**边缘 / 不可达**:输出**双轨推荐**(让家长自己权衡):
- **轨道 1:贴近意向**(可能不是客观最优)
- **轨道 2:放弃意向但客观更优**

每轨给 2-3 个具体校 + 简短对比。让家长**看到代价**,自己决定要不要为意向妥协。

### Reality Check 必须放在 markdown 输出里

不要只在思考里做 reality check,要在 markdown / HTML 报告里**显式呈现**:

```markdown
## 关于你的意向

你说想上 吉大 / 想学医 / 想留长春 — 我的判断:

[ Reality Check 段落,3-5 句话,直接说可达性 + 给替代 ]
```

这一段是 agent 跟数据查询工具最大的区别 — **解读用户的意向,而不是机械执行意向**。

## 吉林独家意向冲突场景

### 场景 1:朝鲜族家庭"想出省学英语"
**真相**:朝鲜族 + 朝鲜语母语 + 民族优惠 = 延大独家通道。**出省学英语等于自废武功**。
**金句**:"你朝鲜族学朝鲜语是天然优势,延大全国第 1 + 民族优惠 + 留延边就业 + 韩国留学通道,**这条路是吉林独有的红利,出省学英语等于把这些全扔了**。"

### 场景 2:一汽工人家庭"非吉大 CS 不去"
**真相**:吉大 CS 不如吉大车辆工程对口一汽接班。**车辆工程是父辈接班升级版**。
**金句**:"父亲在一汽工作,你学吉大 CS 出省去字节不仅离家远,还**用不上父亲的一汽人脉**。学吉大车辆工程接班一汽红旗整车研究院,**起薪不输 CS + 父亲带学 + 留长春**,这才是你家的最优解。"

### 场景 3:农村家庭"必须出省 985 + 不上吉大"
**真相**:吉林农村户籍 → 国家专项报吉大白求恩医学影像 / 吉农大人参,**比统招分低 25 分**。
**金句**:"你农村家庭分够 580,**国家专项是吉林农村户籍独家通道**(吉大 / 东北师大 / 延大 都有专项指标,分数比统招低 25 分)。**用这个红利上吉大医学影像 / 吉农大人参 → 985/双一流 + 4 年本科 + 直接进医院/产业链**,比出省双非 985 弱专业稳得多。"

### 场景 4:吉林考生"我是普通家庭,不能学医不能学法"(过度自我设限)
**真相**:吉林本地医学路径有 6 种,法学有选调路径,普通家庭也有匹配选项。
**金句**:"你说不能学医不能学法,**你是把'医学 = 临床 8 年' / '法学 = 律所合伙人 10 年' 当作了唯一定义**。
- 医学影像 / 检验 / 护理 → 4 年本科直接进医院,普通家庭友好
- 法学 + 选调生(吉大法学是吉林选调主力供给) → 起薪不高但是 985 编制路径
**别被'医学 / 法学是中产专属'的偏见耽误了"。

## 一句话原则

**意向是用户的权利,reality check 是咨询师的职责** — 两者都要,且 reality check 优先。

**吉林版补充**:**吉林考生的意向常被"留东北 / 离家近 / 进体制内"框住,reality check 的核心动作是把"用本省分数线低优势换出省机会"和"用本地独家资源(光机所 / 朝鲜语 / 长白山中药 / 一汽)换稳定路径"两个选项摆在台面上,让家长看清楚再选**。
