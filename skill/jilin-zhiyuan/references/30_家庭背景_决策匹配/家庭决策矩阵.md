# 家庭背景决策矩阵 — 5 档家庭 × 推荐策略(吉林视角)

## 核心结论

**家庭抗风险能力是专业选择的最强约束**,远超兴趣 / 学校牌子 / 行业景气度。同样位次同样选科,**普通工薪和中产家庭的最优解可能完全相反**。

**吉林视角的特殊性**:**留吉率仅 30-40% + 民企就业弱 + 编制就是护城河** —— 这意味着吉林普通家庭的最优解,普遍比湖北 / 江苏 普通家庭"更倾向编制 + 更倾向公费师范 + 更倾向出省 211/985 用本省分数线低优势"。

agent 在出推荐前必须先确认家庭档位(L2.1 父母职业 + L2.2 年收入),按本文件的 5 档矩阵套对应策略。

## 档位 ① 体制内家庭(公务员 / 事业编 / 国企 / 一汽工人)

**定义**:父母至少一方在体制内有稳定编制 + 退休保障。

**吉林本地画像**:
- **一汽工人家庭 / 中车长客 / 长春电影 / 长春光机所 / 各级机关事业编 / 国企铁饭碗** —— 吉林这类家庭比例极高,**长春几乎家家有人在一汽**
- 抗风险能力中等(收入稳但天花板低)
- **懂体制游戏规则**(知道选岗 / 公考 / 编制流程)
- **孩子考公几乎是默认路径**(父母期望 + 信息差小,东北体制内文化浓)
- 资源:能给孩子推荐合适岗位、知道哪些专业进体制易、能对接到一汽 / 中车 / 国网 工厂或机关人脉

**推荐策略**:
1. **强烈考公友好型**:汉语言文学 / 法学 / 经济学 / 会计学 / 行政管理(吉林省考体制内对口岗位多)
2. **985/211 选调生路径**:如果孩子能上吉大 / 东北师大 / 延大,**走选调生比国考省考更优**(起点更高、竞争内部化)
3. **一汽接班路径**:吉大车辆工程 / 机械工程 / 电气工程 → 一汽集团 / 红旗 / 中车长客 校招(父母在一汽的家庭,**这条路是接班升级版**)
4. **避免体制外才有出路的专业**:CS / 金融头部 / 创业类 — 跟父母期待冲突,孩子毕业容易被劝回考公,**3 年损耗**(吉林本地文化对"留京津打工"的容忍度低于湖南江苏)
5. **特殊机会**:**警校(中国刑警学院在沈阳辐射东三省 + 中国人民公安大学)+ 公安联考** = 父母编制资源能用上 + **吉林公安系统选调倾斜本省考生**

**典型 case**:
- 长春一汽工人家庭(父亲一汽红旗工程师 + 母亲事业编)→ 孩子 600 分物理类 → 推**吉大车辆工程** → 毕业进一汽红旗整车研究院,**父亲带学,接班升级版,典型东北家庭路径**
- 失败 case:同样家庭,孩子被推去吉大 CS → 毕业 30w 起薪很高(出省北京字节)→ 但家长不满"不稳定 + 离家远",劝其离职考公,**两年的时间损耗 + 心理纠结**
- 长春机关家庭(父亲省直 + 母亲事业编)→ 孩子 605 分历史类 → 推**吉大法学** → 毕业选调进吉林省委组织部,**家庭路径完美匹配**

## 档位 ② 专业人员家庭(教师 / 医生 / 工程师 等)

**定义**:父母至少一方在医疗 / 教育 / 工程师 / 律师等专业领域。

**吉林本地画像**:
- **吉大附属医院医生家庭 / 长春中学骨干教师 / 长春光机所工程师 / 一汽研究院工程师** —— 吉林这类家庭密度集中在长春
- 抗风险能力中等偏上(专业资源 + 行业人脉)
- **行业拐杖最有力**:子承父业的成功率高
- 通常重视教育投入,孩子成绩相对好
- 资源:能给孩子推荐内部实习、考研导师、就业渠道

**推荐策略**:
1. **优先子承父业**:
   - 教师家庭 → **东北师大公费师范 / 吉大学科教育**;医生家庭 → **吉大白求恩临床 / 口腔(8 年长周期父母能撑 + 医院推荐)**
   - 长春光机所工程师家庭 → **长理工光学工程 / 吉大物理 / 哈工大航天** 接班科研路径
   - 一汽工程师家庭 → **吉大车辆工程 / 同济车辆**(出省) 接班一汽研究院
2. **行业相关延伸**:律师家庭 → 法学(吉大法学东北顶级);工程师家庭 → 对应工科
3. **不必选最稳路径**:有专业拐杖的话,可以选行业上限较高但起步辛苦的专业(医学 / 律师 / CS)
4. **避免完全无拐杖的方向**:如金融头部(没金融行业资源会很难,吉林本地金融业本来就弱)

**典型 case**:
- 母亲长春外国语学校英语老师 + 父亲普通工薪 → 孩子 600 分历史类 → **东北师大公费师范英语**(留长春重点中学) → 毕业回原校 / 同区编制,**母亲资源直接复用**
- 父母都是吉大一院临床医生 → 孩子 660 分物理类 → **吉大白求恩八年制临床** → 父母能撑 8 年读书 + 三甲医院推荐 → **典型子承父业路径**
- 长春光机所研究员家庭 → 孩子 620 分物理类 → **长春理工大学光学工程**(双非但行业内强校 + 父亲带学保研到光机所) → **东北光电产业链接班**

## 档位 ③ 私企管理 / 创业家庭

**定义**:父母私企中高管 / 自主创业 / 企业主。

**吉林本地画像**:
- **东北民企比例本身偏低**,这类家庭在吉林相对少见
- 主要是**汽车配件厂 / 食品加工厂 / 长白山旅游 / 修正药业 / 民营医院 / 餐饮连锁** 等,以及一些**朝鲜族对韩贸易家庭**(延吉为主)
- 抗风险能力高(收入有上限但天花板高)
- **可冒险**:家庭兜底厚,失败成本低
- 通常更看重个人能力 / 创造力 / 商业敏感度
- 资源:商业人脉、行业 know-how、可能继承家业

**推荐策略**:
1. **可选商科 / 创业方向**:工商管理(头部院校) / 经济学 / 金融 / 国贸(头部院校) / 出省东财
2. **可冲名校弱专业**:中产家庭可以靠"读研补救"专业不对口,有家庭兜底容错率高
3. **可考虑出国 / 中外合作办学**:学费贵 + 国际视野 — **延吉朝鲜族家庭走韩国留学路径成本低**
4. **可走小众路径**:艺术 / 设计 / 自由职业 / 创业 — 父母给得起 5-10 年试错成本
5. **避免:进体制内**(跟家庭基因不匹配,父母提供的资源全用不上)
6. **接班路径**:汽配厂家庭 → 吉大车辆 / 机械接班;长白山药材家庭 → 长春中医药 + 吉农大中药资源接班;朝鲜族对韩贸易家庭 → 延大朝鲜语 + 经济交叉接班

**典型 case**:
- 长春汽车配件厂主家庭(年入 200w+) → 孩子 580 分物理类 → 推**吉大车辆工程 / 出省同济车辆** → 学完接班父辈汽配厂技术管理岗,**家族企业升级**
- 延吉朝鲜族对韩贸易家庭 → 孩子 550 分历史类 → 推**延边大学朝鲜语 + 国际经济与贸易** + **韩国延世大学交换** → 接班东北亚贸易业务
- 失败 case:吉林某餐饮连锁老板家庭 → 孩子被推考公 → 进基层公务员后被父母嫌"没出息"+ 家族生意没人接 → **家庭基因不对路**

## 档位 ④ 普通工薪家庭(工厂 / 服务业 / 文员)

**定义**:父母双方或一方稳定工作但收入有限,家庭年收入 8-25 万为主(吉林收入水平比江浙低)。

**吉林本地画像**:
- **一汽 / 中车 / 长春电影 / 通化药业 / 吉林化工 等老国企工人家庭 + 长春中小服务业 + 各市县文员销售员** —— 吉林这类家庭比例极高
- **抗风险能力低**(失业 / 失败的代价大)
- 信息差大,不太懂体制 / 行业 / 圈子
- 通常希望孩子稳定 / 编制 / 不要折腾 + **离家近**(东北父母不舍得孩子远走)
- 资源:几乎无,需要孩子靠学校 + 努力跨阶级

**推荐策略**:
1. **重出路稳定 > 兴趣 > 名校牌子**
2. **首推编制路径**(吉林普通家庭跨阶级核心路径):
   - **东北师大公费师范**(汉语言 / 数学 / 英语 等)= 高考分适中 + 直接编制 + 无学费,**吉林普通家庭神器**
   - **东北电力大学电气** + 国家电网 = 进电网编制 + 起薪 8-15w,**吉林男生跨阶级核心路径**
   - **中国刑警学院(沈阳)+ 公安联考** = 进公安系统编制
   - **医学影像技术 / 检验 / 护理**(吉大白求恩 / 北华医学院)= 三甲医院技术岗 + 4 年本科即可
   - **长春中医药大学**(双一流中药学)= 进吉林中医院 / 修正药业,留长春就业
   - **吉农大人参 / 食品科学** = 吉林农业产业链对口
3. **次推稳定就业型**:
   - **长春理工大学光学工程**(双非但全国前 5)= 进长春光机所 / 中科院系统 / 航天科工
   - 师范类(吉师 / 长师 汉语言 / 数学师范)
   - 一汽 / 中车 对口工科(吉大车辆 / 机械,分够上)
4. **避免高风险方向**:
   - 金融 / 经济 / 工商管理(双非这些 = 死局,吉林本地金融业本身弱)
   - **双非 CS 留吉**(2024 起薪 5-8k,跟双非工科没差,而且长春没有互联网产业)
   - 生化环材(必须读博才有出路,普通家庭撑不起)
   - 医学(临床 5+3+规培 8 年长周期,家庭撑不起)
   - 心理学 / 历史学 / 哲学(本科出口窄,必须读研)

**典型 case**:
- 吉林市工厂家庭 → 孩子 580 分物理类 → 推**东北电力大学电气**(2024 进国家电网 国网吉林公司)→ 毕业进国网四平供电公司,**月入 8.5k + 编制,家庭逆袭**
- 长春一汽工人家庭(下岗后做服务业)→ 孩子 600 分历史类 → 推**东北师大公费师范汉语言**(免学费 + 编制) → 毕业回长春重点中学当语文老师,**家庭命运改变**
- 通化普通工薪家庭 → 孩子 540 分物理类 → 推**长春中医药大学中药学**(双一流) → 毕业进通化金马药业,**留长春产业链稳定**

## 档位 ⑤ 农村 / 临工家庭

**定义**:父母务农 / 临时工 / 零散工作,家庭年收入通常 < 8 万。

**吉林本地画像**:
- **延边山区 / 通化山区 / 白山林区 / 松原松花江流域 / 白城西部农区** —— 吉林农村集中在边境 / 山区 / 西部农牧区
- **朝鲜族农村家庭(延边)有特殊出口**(韩国务工 / 留学韩国)
- **抗风险能力极低**(失败 = 整个家庭灾难)
- 信息差最大(对大学 / 城市 / 行业完全不了解)
- 期待孩子跨阶级,跳出当前生活
- 资源:零,完全靠孩子自己 + 学校

**推荐策略**:
1. **学校牌子 > 专业方向**(到一定程度)
   - 985/211 牌子能直接打开城市 + 圈子,跨阶级首要工具
   - 同等分数下,**末流 985 弱专业 > 头部 211 强专业**(对农村家庭而言)
2. **优先 100% 编制 / 100% 出口的路径**:
   - **东北师大公费师范**(无学费 + 编制)= 吉林农村家庭神器
   - **国家专项计划 / 高校专项**(吉林农村户籍,吉大 / 东北师大 / 延大 多个专项指标,分数比统招低 20-30 分)
   - **警校 / 军校**(无学费 + 编制 + 包分配)
   - 农林牧水(**吉林农业大学国家专项 + 人参中药资源方向**)= 编制 + 行业有出路
3. **避免长周期投入**:
   - 医学 8 年(撑不起)
   - 必须读博的基础学科(撑不起)
   - 出国 / 中外合作(撑不起,**朝鲜族家庭韩国留学是例外** —— 韩国留学成本远低于欧美)
4. **特殊机会**:
   - **国家专项计划**:吉林农村户籍,985/211 名校多个专项指标(分数比统招低 20-30 分)
   - **强基计划**:数学 / 物理 / 化学 单科特别强的农村学生有机会(吉大化学 / 数学是国家基础学科基地)
   - **延边朝鲜族民族优惠**:朝鲜族学生有民族优惠 + 延大降分 + 韩国留学通道
   - **少数民族预科**:满族 / 蒙古族 / 朝鲜族 / 回族 集中地区有预科政策
   - 殡葬专业(冷门但 100% 编制 + 收入不错;**长沙民政是首选,吉林本地少**)

**典型 case**:
- 吉林白山农村家庭 → 孩子 590 分物理类 → 通过**国家专项**进**吉大白求恩医学影像技术**(比统招分低 25 分)→ 985 牌子 + 4 年本科 + 进长春三甲医院技师岗,**整个家族第一个 985**
- 延边朝鲜族山区女孩 → 580 分历史类 → 推**东北师大公费师范朝语方向 / 延大朝鲜语** → 4 年无学费 + 毕业回延边某中学编制,**最适合朝鲜族农村家庭的"零风险"路径**
- 通化农村男孩 → 530 分物理类 → 推**长春中医药大学中药学**(双一流 + 录取分对农村友好) → 毕业回通化金马药业 / 各县中医院,**回流家乡产业**
- 白城农村家庭 → 孩子 560 分物理类 → 推**吉林农业大学人参研究方向**(国家专项,分数比统招低 25 分) → 毕业进吉林人参产业链,**农村家庭跨阶级**

## 与其他维度的交互(agent 推理顺序)

1. **学科底子硬阻断**(L1)→ 先 filter 掉硬挂科风险
2. **家庭档位**(L2)→ **本文件主导**,锁定推荐策略大方向
3. **未来锚点**(L3)→ 进一步收窄(考公 / 考研 / 出国 / 直接就业)
4. **学科兴趣**(L4)→ 在前 3 项允许范围内选喜欢的
5. **风险偏好**(L5)→ 决定冲稳保比例

**家庭档位是 #2 优先级,仅次于硬阻断,高于兴趣**。如果家庭情况和兴趣冲突,**家庭赢**(因为兴趣可以工作后弥补,选错路径的代价无法弥补)。

## 吉林家庭决策的特殊提醒

1. **"留东北"是吉林父母默认偏好** —— 但吉林留省率仅 30-40%,**孩子必然有一部分出省**。家庭决策时要提前谈清楚"接受出省的家庭" vs "坚决留吉的家庭",**不同前提下推荐策略完全不同**
2. **一汽 / 中车 / 国家电网 / 吉大附属医院**是吉林本地"四大铁饭碗系统",围绕这四条产业链选专业是吉林普通家庭的核心策略
3. **公费师范 + 东北师大 + 回原籍** —— 这条路对吉林普通家庭(尤其女生 + 农村家庭)的性价比远超双非工科 / CS / 经管。**别被"师范没出息"这种偏见耽误了女儿的编制路径**
4. **朝鲜族家庭有独特资源**(延大双一流朝鲜语 + 韩国留学 + 民族优惠) —— 朝鲜族家庭的最优解跟汉族不同,要单独处理
