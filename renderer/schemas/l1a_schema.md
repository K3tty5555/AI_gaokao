# L1-A 出分前方向性建议 JSON schema

`render_l1a_report.py` 的输入格式。skill agent 在 L5 输出方向性建议后,把咨询结果整理成下面的 JSON,然后调用渲染脚本生成自包含 HTML 报告。

**与 L1-B 区别**:出分前没真实位次,所以**不出 7 字段志愿卡 / 不出完整志愿表 / 不出历年录取数据**。改为输出"方向性建议"叙事(主推方向 + 避坑方向 + 高三冲刺空间 + 意向冲突 reality check)。

## 字段说明

### 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `meta` | ✓ | 报告元数据,`场景` 字段固定 "L1-A 出分前" |
| `用户画像` | ✓ | 顶部卡片,**不含分数/位次,改为学校/排名/标签** |
| `双口径估算` | ✓ | 学校×排名 vs 模考分 双校准 |
| `学科画像` | ✓ | 6 科分数 + 强弱判断 |
| `核心判断` | 推荐 | 3-5 句 narrative |
| `主推方向` | ✓ | 1-3 个推荐方向,每项含适配星级 + 代表院校 |
| `避坑方向` | 推荐 | 0-N 个明确避坑方向 |
| `意向冲突` | 推荐 | 用户意向 vs 实际可达性 reality check |
| `好校弱专业_vs_弱校强专业` | 推荐 | case-specific 判断 + 对比举例 |
| `高三冲刺空间` | ✓ | 保底/常规/冲档 三档 + 执行建议 |
| `必聊` | 推荐 | 1-3 个跟父母 / 自己讨论的事 |
| `下次再来` | 推荐 | 出分后回访提示 |
| `免责声明` | 默认 | 不填用兜底文案 |

### 用户画像(出分前版)

跟 L1-B 不同,出分前的画像**不含具体分数 / 位次**,改为:

| 字段 | 说明 |
|---|---|
| `学校` | 学校全名 + (就读地) |
| `学校层次` | ① 省级示范 / ② 市级重点 / ③ 普通高中 |
| `户籍` | 户籍所在地(影响录取省份判断) |
| `年级排名` | 形如 "1000 人中第 200 名" |
| `选科` | 数组,如 ["物理", "化学", "生物"] |
| `科类` | 物理类 / 历史类 |
| `标签` | 数组,3-6 个画像关键词 |
| `画像备注` | 选填,说明出分前精度 |

### 双口径估算

```json
"双口径估算": {
  "口径1": {名称, 估算位次, 估算档位},
  "口径2": {名称, 模考分(数组), 中位数, 波动, 估算位次, 百分位, 基准年},
  "校准结论": "高一致 ✅" / "中等一致 🟡" / "冲突 ⚠️ — 取保守",
  "最终定位": "末流 985 / 强 211 头部",
  "代表院校举例": [array of school names]
}
```

### 学科画像

`科目分数` 数组,每项:`{科目, 分数, 满分, 百分比, 档}`。
`关键观察` 数组,3-5 条 case-specific 观察(强项 / 短板 / 不平衡)。

### 主推方向

每个方向是一张"方向卡片":

```json
{
  "方向": "工科 + IT 央企",
  "适配星级": 5,  // 1-5
  "适配理由": "一句话,case-specific",
  "代表院校": [
    {
      "院校": "华科",
      "适配度": "⭐⭐⭐⭐⭐",
      "推荐专业": ["计算机科学与技术", "通信工程", "软件工程"],
      "理由": "..."
    }
  ]
}
```

**不带历年录取数据**(出分前没意义)。`推荐专业` 填 2-4 个具体专业名,出分前不做专业组编号(给不准),但必须给出具体专业方向让用户知道冲哪里。

### 避坑方向

每个避坑项:

```json
{
  "方向": "同济土木 / 海洋 / 建筑",
  "不推理由": "case-specific 一句话"
}
```

精简版,没替代路径(替代已经在主推方向里给了)。

### 意向冲突(可选)

L4.5 用户给了具体意向(意向校 / 意向城 / 意向行业)时填。

```json
{
  "意向": "用户原话",
  "可达性判断": [
    {"意向项": "复旦", "档": "❌ 不可达", "数据": "差 X 名 / Y 分"}
  ],
  "冲突结论": "下一步建议"
}
```

`档` 字段枚举:`✅ 可达` / `🟡 边缘` / `🟡 部分可达` / `❌ 不可达`

### 高三冲刺空间

3 档分数预估表:`保底` / `常规` / `冲档`,每档:

```json
{
  "档": "冲档",
  "描述": "物化生 +30 + 英语提到 130",
  "科目分数": {"语": 125, "数": 142, ...},
  "总分": 665,
  "档位": "中段 985",
  "代表校": [array]
}
```

`执行建议` 数组,3-6 条具体怎么提分。

## 缺值处理规则

| 字段 | 缺失 / null 时 renderer 行为 |
|---|---|
| `双口径估算.校准结论` 为 `null` | 显示"待出分后精确校准" |
| `高三冲刺空间` 为 `null` 或缺字段 | renderer 不渲染该区块 |
| `避坑方向` 为 `null` 或 `[]` | renderer 不渲染该区块 |
| `意向冲突` 为 `null` | renderer 不渲染该区块 |
| `主推方向[].代表院校` 为空数组 | 显示"出分后根据真实位次推荐具体院校" |
| `免责声明` 为 `null` | 使用兜底文案："本建议基于历史数据，精度 ±2000 名，实际填报以当年招生章程为准" |
| `下次再来` 为 `null` | 使用兜底文案："出分后带真实分和位次回来，走 L1-B 拿完整志愿表" |

## 调用渲染脚本

```bash
python3 scripts/render_l1a_report.py --json /tmp/zhiyuan_l1a.json --output output/zhiyuan_l1a_<省>_<分数>_<时间戳>.html
```

主题(默认 bloomberg,可切 editorial / stripe / spotify):
```bash
python3 scripts/render_l1a_report.py --json /tmp/x.json --theme bloomberg --output output/x.html
```
