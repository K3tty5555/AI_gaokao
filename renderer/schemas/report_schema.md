# 志愿咨询报告 JSON schema

`render_report.py` 的输入格式。skill agent 在 L5 输出推荐后,把咨询结果整理成下面的 JSON,然后调用渲染脚本生成自包含 HTML 报告。

## 字段说明

### 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `meta` | ✓ | 报告元数据 |
| `用户画像` | ✓ | 顶部卡片展示 |
| `核心判断` | 推荐 | 3-5 句 narrative,黄色边框块 |
| `推荐` | ✓ | 5-8 张完整卡片,带历年数据 |
| `避坑` | 推荐 | 0-3 张反面卡片,灰色基调 |
| `完整志愿` | 推荐 | 全志愿表(40/30/45 个,看省政策),梯度色 |
| `必聊` | 推荐 | 1-3 个跟父母 / 自己讨论的事,带圆形序号 |
| `免责声明` | 默认 | 不填用兜底文案 |

### 档位枚举

`档位` 字段决定卡片标签颜色:

- `冲` → 暖红(高风险冲档)
- `稳` → 沉绿(主力填报区间)
- `保` → 沉蓝(兜底)
- `避坑` → 灰(反面警告)

### 历年录取

`历年录取` 是数组,每项含 `年份` / `投档分` / `最低位次`。**避坑卡片可以传空数组** `[]`(用通用警告而非具体院校的历史数据)。

### 推理段落

`推理` 字段类型:**string 或 string[]** — renderer 兼容两种,数组会用空行拼起来。

case-specific 多行字符串,包含:
- 用户位次 / 该校组录取区间的对比
- 为什么这所匹配用户画像
- 风险点

不要写 generic 套话(如"该校综合实力强,适合学习态度认真的学生"),写具体到位次和家庭背景。

### 位次说明(可选)

`用户画像.位次说明` 是可选 string,用来承载"用户自报 vs 实测不一致"或"老高考 vs 新高考切换提醒"等画像层的注释。出现时在画像卡下方以黄色边框块展示。

典型用法:
- "用户自报省排 4500,score_to_rank 实测 32450,本报告按实测保守口径"
- "你是河南 2024 届(老高考最后一年文/理),2025 起切 3+1+2,本报告用 2024 文/理 数据"

### 替代建议(避坑专用,可选)

`避坑[].替代` 是可选 string,用来在"为什么不推"之外,告诉用户**正确的替代路径**(蓝色右箭头展示)。避坑卡片如果只说"不要选 X",家长会茫然;补一句"那应该选什么"价值很大。

典型用法:
- 避坑双非新闻 → "想做内容 / PM 路径:走法学 + 自媒体副业,正职兜底"
- 避坑双非生化环材 → "化生强建议方向:临床医学 / 药学 / 生物医学工程"

### 院校代码 / 组号(可选,**警告**)

`完整志愿[].院校代码` 和 `完整志愿[].组号` 是**可选**字段,**默认应为 null**。

> ⚠️ **掌上高考数据库不含招办章程的院校代码 / 专业组组号**(那是各省招办每年单独发布的数据)。**agent 严禁编代码 / 编组号** —— 编错了会害用户填错院校。
>
> 现状默认填 `null`,渲染脚本会在表上方显示"代码以招生章程为准"的警告。
>
> 只有当将来接入真招办章程数据时,才填这两个字段。届时 renderer 会自动展开 8 列(序号/档位/院校/代码/专业组/组号/参考位次/一句话),否则保持 6 列。

### 录取概率（可选）

`录取概率` 是**选填**字段，由 `compute_admission_probability()` 产出，放在推荐卡片（`推荐[]`）里：

| 字段 | 必填 | 说明 |
|---|---|---|
| `录取概率` | 选填 | `{"display":"72%","label":"较稳","probability":0.72}` — 由 `compute_admission_probability()` 产出 |

`label` 枚举：`安全` / `较稳` / `有风险` / `高风险` / `未知`。不存在时 renderer 跳过，不报错。

### 提醒

`提醒` 是数组,每条以 ⚠ 标注展示。典型内容:
- 服从调剂的具体专业风险(组内最差是 X,接受不了别勾)
- 大小年趋势提示
- 同名易混院校(如湖经 ≠ 中南财法)
- 校区差异(中大广州/深圳/珠海分数差)

### 完整志愿

`完整志愿` 字段的卡片是**精简版**,只含序号 / 档位 / 院校 / 专业组 / 参考位次 / 一句话。**不要重复完整推荐卡片**,这是用来快速浏览全表填报顺序的。

## 缺值处理规则

| 字段 | 缺失 / null 时 renderer 行为 |
|---|---|
| `推荐[].录取概率` | 不渲染概率徽章，不报错 |
| `推荐[].历年录取` 为空数组 `[]` | 显示"历年数据不足，请查招生章程" |
| `推荐[].历年录取` 不足 3 年 | 只显示有的年份，标注"仅 X 年数据（新开招生/换组）" |
| `完整志愿[].院校代码` 为 `null` | 显示"—" + 顶部警告横幅"代码以招生章程为准" |
| `完整志愿[].组号` 为 `null` | 同上 |
| `核心判断` 为 `null` 或空字符串 | renderer 不渲染该块 |
| `避坑` 为 `null` 或 `[]` | renderer 不渲染避坑区 |
| `推理` 为空字符串 | renderer 用"（暂无推理）"占位，不崩溃 |
| `免责声明` 为 `null` | 使用兜底文案："实际填报请结合当年招生章程 + 省招考院一分一段表" |

## 调用渲染脚本

```bash
# JSON 文件输入
python3 scripts/render_report.py --json /tmp/zhiyuan.json --output output/zhiyuan_<省>_<分数>_<时间戳>.html

# stdin 输入
cat /tmp/zhiyuan.json | python3 scripts/render_report.py --output output/x.html
```

输出路径建议:`output/zhiyuan_<省份代码>_<分数>_<YYYYMMDD>.html`(scripts 不强制此命名,但便于用户检索)。

## 测试样例

`scripts/render_report.py --json scripts/sample_report.json --output output/sample.html` 会渲染一个完整湖北 580 分案例,可作为 schema 参考。该 JSON 也是 `output/playground/` 4 主题的渲染数据源,**调主题时直接用这份**。
