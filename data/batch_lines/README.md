# 批次线数据 / Batch Lines

湖北 3+1+2 历年录取**批次控制线**数据。

## 文件

### `hubei.csv`

字段:
| 字段 | 说明 |
|---|---|
| `年份` | 高考年份 |
| `科类` | 物理类 / 历史类 |
| `批次` | 本科批 / 本科特控线 / 专科批 |
| `控制线分数` | 该批次的录取控制分数线 |
| `对应位次` | 该分数对应的全省累计位次(从 yifenduyiduan/<年份>_<科类>.csv 反查) |
| `数据来源` | 湖北招办公告 + 一分一段表反查 |

**批次定义**:
- **本科批控制线** = 本科批最低录取门槛(俗称"本科线"),分数 ≥ 此线才有本科可上
- **本科特控线** = 强基计划 / 综合评价 / 部分军校警校 / 港澳高校等特殊类型录取的最低线(俗称"特殊招生线",原"一本线"的近似替代)
- **专科批控制线** = 专科最低录取门槛,分数 < 此线只能复读 / 单招 / 自考

## 用途

1. **判断分数所属批次**:输入分数 + 科类 + 年份,告诉用户处于"特控以上 / 本科批 / 本科线下专科上 / 专科线下"哪一档
2. **L1 后产品分流**:本科线下用户走专科 skill 或复读咨询,不能机械套本科推荐流程
3. **跨年趋势观察**:本科线 ±10 分波动反映年度难度,辅助大小年判断

## 重要提醒

- 本科特控线 2021 / 2023 缺失(湖北招办在这两年公告里特殊招生线表述不统一,GitHub 数据集也没收齐)。**MVP 阶段先跳过,只用本科批 + 专科批两档**
- 专科批 200 分 是普通线,湖北民办 / 独立学院 / 部分省内市州高职可低至 150 分,本表用 200 作为统一标准
