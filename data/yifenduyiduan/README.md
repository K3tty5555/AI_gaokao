# 湖北一分一段表 / Hubei Score-Rank Distribution

湖北高考"一分一段表"历年数据,用于 score → rank 换算。

## 字段

```csv
分数,本段人数,累计人数
```

- **分数**: 该分段的分数(整数)
- **本段人数**: 该分(段)的考生人数,即"同分人数"
- **累计人数**: 该分及以上的考生总数,等价于"位次"(rank)

行按分数从高到低排列。

## 数据来源

- **2021–2024**: GitHub 仓库 [`sdgedfegw/Gaokao-score-distribution`](https://github.com/sdgedfegw/Gaokao-score-distribution),文件 `1996-2024年全国高考分段表.csv`,源头为湖北省教育考试院。该仓库 2021-2024 全国数据完整。
- **2025**: [新高考网 hfplg.com](https://www.hfplg.com/yfyd/3y57019233.html) 抓取的 HTML 表格(物理+历史并列两栏),源头为湖北省教育考试院 2025-06-25 公布的官方一分一段表。

注:2021-2024 数据下限为 150 分(官方公布的一分一段表通常到 150 分截止);2025 数据延伸到 0 分。

## 用法示例

Python:

```python
import csv

def load_yfyd(year, kind):
    path = f"data/yifenduyiduan/{year}_{kind}.csv"
    with open(path) as f:
        return [(int(r['分数']), int(r['本段人数']), int(r['累计人数']))
                for r in csv.DictReader(f)]

def score_to_rank(score, year, kind):
    """给定分数返回位次(累计人数)。低于最低分返回 None。"""
    rows = load_yfyd(year, kind)
    for s, _, cum in rows:
        if s <= score:
            return cum
    return None
```
