# AI 志愿规划师 — 全国 31 省高考志愿咨询 Skill

面向全国高考考生 / 家长的 Claude Code skill。通过结构化对话收集考生画像，结合 2021-2025 历年录取数据 + 各省本地潜规则知识库，输出本科 / 专科志愿推荐方案。

**覆盖范围**：31 省 × 本科（zhiyuan）+ 专科（zhuanke）= 62 个省级 skill，统一由 `gaokao-zhiyuan` 入口调度。

---

## 这是什么 / 为什么做

**夸克高考、掌上高考、优志愿**给了海量数据 + 多维筛选，但**用户面对 45 个志愿位时仍然不会决策**。它们是"专业工具"，不是"咨询师"。

真人志愿规划师（张雪峰式咨询）的价值不在数据，而在：
- 用 n 问把考生**还原成有家庭、性格、未来的具体人**
- 把行业 / 院校 / 地域的**潜规则**用大白话讲出来
- 给出**带故事感的推理**："你家这种情况，不建议去东北读 211…"

**LLM 恰好擅长这个**。本项目把"AI 志愿规划师"做成 Claude Code skill，定位：**深度咨询（对话式）而非数据查询（工具式）**。

---

## 核心特性

| 特性 | 说明 |
|---|---|
| **31 省全覆盖** | 3+1+2（23 省）/ 3+3（6 省）/ 老高考（西藏 + 河南过渡）三大体系完整实现 |
| **本科 + 专科双线** | 本科线上走 `*-zhiyuan`，本科线下专科线上自动分流到 `*-zhuanke`，同一对话无缝切换 |
| **5 层结构化提问** | L1 硬数据 → L2 家庭画像 → L3 未来锚点 → L4 学科兴趣/性格 → L5 风险偏好 |
| **定量化纪律** | 禁止"还行/一般"模糊回答，所有维度强制选档/给数字，推荐可复现 |
| **冲稳保三档召回** | `query_school.py` 基于位次窗口 + 选科 `sg_info` 匹配，支持无位次数据省份（西藏）自动降级为分数模式 |
| **精确位次换算** | `score_to_rank.py` 接入各省官方一分一段表，精度 ±0；无表时 fallback 线性插值 |
| **潜规则知识库** | 每省 7 大类 references（行业就业 / 院校潜规则 / 家庭决策 / 未来锚点 / 反常识洞察 / 本地化） |
| **Cross-check 纪律** | 推荐前必须对照已加载知识库，不允许推荐自己写过避坑的方向 |
| **HTML 报告输出** | L1-A（出分前方向性建议）/ L1-B（出分后完整志愿卡片）两套渲染模板，4 主题 |
| **专科完整实现** | 复读 vs 专科决策矩阵、专升本路径、技能型岗位分析、公办/民办筛选逻辑 |

## 快速上手

### 1. Clone（含 LFS 数据）

```bash
# 需要先安装 git-lfs（DB 文件通过 LFS 存储）
git lfs install
git clone git@github.com:K3tty5555/AI_gaokao.git
cd AI_gaokao

# LFS 文件默认随 clone 自动拉取
# 如只需要代码，跳过 DB：GIT_LFS_SKIP_SMUDGE=1 git clone ...
```

### 2. 打开 Claude Code

```bash
claude
```

`gaokao-zhiyuan` skill 已通过 `.claude/skills/gaokao-zhiyuan` 配置好，**自动可用**。

### 3. 直接对话

任何省份的志愿相关问题都会触发，省份在第一轮对话中自动识别：

```
"我孩子湖北 580 分物理类，选科物化生，推荐下学校"
"广东历史类 520，想留广东，怎么选"
"山东综合 490，志愿怎么填"
"湖北 380 分，上不了本科，专科怎么选"
"要不要复读，还是上专科"
```

### 4. 更新数据（每年 6-7 月）

```bash
# 爬取最新录取数据
python3 pipeline/crawl.py

# 导入批次控制线
python3 pipeline/import_batch_lines.py

# 导入一分一段表
python3 pipeline/import_score_dist.py

# 重新生成专科 SKILL.md（批次线数据表更新后）
python3 pipeline/gen_zhuanke_skill.py
```

### 5. 运行测试

```bash
python3 tests/e2e_all_provinces.py
# 预期：31/31 省通过，244/244 检查项全绿
```

## 工作原理

```
用户输入（任意省份、任意高考相关话题）
  ↓
[gaokao-zhiyuan] 识别省份 → 检测分数状态（已出分 / 出分前 / 紧急填报 / 征集志愿）
  ↓
[score_to_rank.py] 分数 → 全省位次 + 批次判断（本科 / 专科 / 复读建议区）
  ↓
  ├─ 本科线上 → 进入 {prov}-zhiyuan，走 L1-L5 主流程
  └─ 本科线下 → 进入 {prov}-zhuanke，走专科流程（复读决策 + 专科选校 + 专升本规划）
       ↓
[L1] 硬数据（分数 / 位次 / 科类 / 选科 / 应届or复读）
  ↓
[L2] 家庭画像（城市 / 职业 / 收入档 / 亲戚资源）
  ↓
[L3] 未来锚点（考研/考公/出国意愿 1-5 分 + 地域偏好）
  ↓
[L4] 学科兴趣（从真实单科分数自动判断）+ 性格（3 题情境 or MBTI）
  ↓
[L5] 风险偏好（冲稳保倾向 + 服从调剂）
  ↓
[query_school.py] 位次窗口 × 选科 sg_info 匹配 → 冲/稳/保 候选列表
  ↓
[lazy-load] 按用户画像选 2-4 篇 references 知识库
  ↓
[Cross-check] 推荐前对照知识库避坑列表，禁止自相矛盾
  ↓
[输出] 5 推荐卡片（冲 1 / 稳 2 / 保 2）+ 3 避坑 + HTML 报告
```

爬自**掌上高考**（中国教育在线旗下，`static-data.gaokao.cn`）的未加密静态 JSON 接口，各省考试院公开发布的录取数据。详见 [`data/README.md`](data/README.md)。

## 已知限制

1. **数据时效**：录取数据截至 2025 年，2026 年高考出分后需重新爬取并更新。
2. **知识库覆盖度**：各省 references 以高频院校/行业为主，冷门请求 agent 从通用知识答，深度可能不足。
3. **西藏无位次数据**：西藏官方不公布一分一段表，系统自动以分数窗口替代位次召回，精度低于其他省份。
4. **首届 3+1+2 数据不足**：内蒙古、陕西、山西、甘肃、宁夏、青海、新疆 2025 首届，历史数据仅 1 年，大小年预测精度低，输出会有数据不足警告。
5. **不替代官方渠道**：院校代码 / 专业组组号以当年招生章程为准，系统不编造这两个字段。
