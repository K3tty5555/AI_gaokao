# AI 志愿规划师 — 湖北高考志愿咨询 Skill

一个面向 **湖北高考考生 / 家长** 的 Claude Code skill,通过 5 层结构化对话收集考生画像,结合 2021-2025 历年录取数据 + 湖北本地潜规则知识库,输出针对性的院校 + 专业推荐方案。

---

## 这是什么 / 为什么做

**夸克高考、掌上高考、优志愿**这些工具给了海量数据 + 多维筛选,但**用户面对 45 个志愿位时仍然不会决策**。它们是"专业工具",不是"咨询师"。

而真人志愿规划师(张雪峰式咨询)的价值不在数据,而在:
- 用 n 问把考生**还原成有家庭、性格、未来的具体人**
- 把行业 / 院校 / 地域的**潜规则**用大白话讲出来
- 给出**带故事感的推理**:"你家这种情况,不建议去东北读 211..."

**LLM 恰好擅长这个**。本项目把"AI 志愿规划师"做成 Claude Code skill,定位:**深度咨询(对话式)而非数据查询(工具式)**。

---

## 核心特性

| 特性 | 说明 |
|---|---|
| **5 层结构化提问** | L1 硬约束(分数/位次)→ L2 家庭画像 → L3 未来锚点 → L4 兴趣性格(支持 MBTI 进阶版)→ L5 风险偏好 |
| **定量化纪律** | 禁止"还行/一般"模糊回答,所有问题强制选档/给数字,推荐才可复现 |
| **湖北 3+1+2 完整覆盖** | 物理/历史类、12 种选科组合、院校专业组、选科要求(`sg_info`)、招生类型(普通/国家专项/地方专项) |
| **冲稳保三档召回** | 基于位次窗口 + 选科匹配,自动按用户的风险偏好动态调整窗口 |
| **潜规则知识库** | 9 篇 markdown 覆盖行业(CS/电气/汉语言)、反常识洞察(看似冷门实际香 / 看似热门实际坑)、湖北本地化(3+1+2 政策、武汉七校真实地位)、考公优选 |
| **Cross-check 纪律** | Agent 推荐前必须对照已加载知识库,不允许推荐自己写过避坑的方向 |
| **单科分数硬阻断** | 物理 < 50% 自动 filter 掉工科,数学 < 63% filter 掉数学/CS 等核心数学课程,避免挂科退学 |

## 快速上手

### 1. clone

```bash
git clone <repo-url>
cd 志愿
```

### 2. 在项目目录下打开 Claude Code

```bash
claude
```

skill 已通过 `.claude/skills/hubei-zhiyuan` 符号链接配置好,**自动可用**。

### 3. 直接对话

聊任何湖北志愿相关问题就会触发 skill,例如:
- "我家孩子湖北 580 分物理类,选科物化生,推荐下学校"
- "湖北考公选什么专业最好"
- "武汉七校怎么选"
- "用 hubei-zhiyuan 这个 skill 帮我规划"(强制触发)

### 4. (可选)重新爬数据

每年 6-7 月新数据出来后:

```bash
python3 crawl.py
# 自动写入 data/gaokao_hubei_<当前年>.db,旧快照保留作归档
# 约 3-4 小时跑完(掌上高考静态接口,1 秒 sleep + 断点续传)
```

## 工作原理(给开发者)

```
用户输入
  ↓
[L1] 收集硬数据(分数/各科分数/位次/选科) — 调 score_to_rank.py 估算位次
  ↓ Agent 给中间反馈("你这位次大概是 985 中段")
[L2] 收集家庭画像(职业/收入/亲戚资源 — 全部离散档位) — lazy-load 采集_rubric.md
  ↓
[L3] 未来锚点(考研/考公/出国 1-5 量表 + 地域多选)
  ↓
[L4] 学科兴趣(从 L1 客观分数算 + MBTI 简版 3 题或进阶 16 型)+ 向往行业 + 排除项
  ↓
[L5] 风险偏好(冲稳保 3 档 + 二选一)
  ↓
[召回] query_school.py(位次窗口 × 选科 sg_info 匹配)
  ↓
[lazy-load 知识库] 根据用户家庭/未来/兴趣选 2-4 篇 references/
  ↓
[Cross-check] 推荐前对照知识库的避坑列表,不能违反自己写过的结论
  ↓
[输出] 5 推荐(冲 1 / 稳 2 / 保 2)+ 3 避坑 + 关键提醒
```

## 数据来源

爬自 **掌上高考**(中国教育在线旗下,`static-data.gaokao.cn`)的**未加密静态 JSON 接口**。本身就是各省考试院公开发布的录取数据,法律风险低。详细说明见 [`data/README.md`](data/README.md)。

---

## 已知限制

1. **score_to_rank 是 MVP 粗略版**:基于 province_scores 表里的 (分数, 位次) 锚点做线性插值,精度有限。**直接告诉 agent 自己的位次更准**(从湖北招办一分一段表查)。后续可接入官方一分一段表大幅提升精度。
2. **覆盖范围是湖北**:其他 3+1+2 省份(辽宁、江苏、广东等)需要改 prov_id + 重爬。
3. **知识库 9 篇**:覆盖高频场景但仍有空白(医学专项、师范公费、各专业组深度对比等)。冷门请求 agent 会从通用知识答,深度可能不足。
4. **数据时效约 1 年**:每年 6-7 月新数据出来后需重爬。
5. **不替代真人规划师**:决策最终需要结合招生章程、家庭具体情况、考生意愿等,agent 给的是参考方案。

## 实测一例(2026-05-07)

> 湖北襄阳 550 分物理类 / 物化生 / 普通工薪独子 / ENTP / 想多挣钱
>
> 关键约束:**物理 40 分**(硬阻断工科)/ 化学 80 + 生物 90 双强 / 49500 名

通常的"普通家庭男生通过电气进电网逆袭"路径被物理 40 堵死。Agent 经过推理(数据召回 + 知识库 + MBTI rubric)给出:**药学/制药 → 医药代表赛道**(沈阳药科 / 广东药科 / 江汉大学 等),核心理由:化学+生物双强对口药学 + ENTP 适配销售导向 + 医代不依赖学校层次只看业绩。

完整推理过程见 `references/00_核心方法论/采集_rubric.md` 案例 D。
